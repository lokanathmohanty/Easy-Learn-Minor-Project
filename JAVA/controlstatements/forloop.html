Java for Loop

In Java, a for loop is a repetition control structure used to execute a block of code a specific number of times. It is particularly useful when the number of iterations is known beforehand, making it an efficient way to automate repetitive tasks.

Syntax

The syntax of a for loop is:

for (initialization; condition; update) {
    // Statements
}

Structure of for Loop

  • Initialization: Defines and initializes the loop counter variable. Executes once at the start.
  • Boolean Expression (Condition): Evaluates before each iteration; loop runs if true, terminates if false.
  • Body: The statements executed repeatedly as long as the condition is true.
  • Update: Modifies the loop counter after each iteration.

Execution Process

The initialization runs first; the condition is checked before each iteration; if true, the body executes, followed by the update; this repeats until the condition is false.

Use Cases of Java for Loop

  • Iterating over a fixed range of numbers
  • Traversing arrays and collections
  • Implementing nested loops
  • Repeating tasks specific number of times
  • Using enhanced for-each loops

Example: Printing Numbers from 1 to 5

public class Test {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            System.out.println("Number: " + i);
        }
    }
}

Output:

Number: 1
Number: 2
Number: 3
Number: 4
Number: 5

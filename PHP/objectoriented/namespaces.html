PHP: Namespaces

**Namespaces** provide a way to logically group related PHP code (classes, functions, constants) under a unique name. This mechanism prevents naming conflicts when combining code from different sources, especially in large applications or when using third-party libraries.

Defining and Accessing Namespaces

  • A namespace is defined using the **namespace** keyword, which must be the **very first statement** in a PHP file (except for the opening <?php tag and the optional declare directive).
  • To define a namespace: namespace MyVendor\MyApp;
  • To access an item within a namespace, you must use its **Fully Qualified Name (FQN)**, which is the namespace followed by the item name, separated by the Scope Resolution Operator (\): MyVendor\MyApp\MyClass::method();
  • The built-in constant **__NAMESPACE__** holds the name of the current namespace.

Types of Namespace References

The way an item is referenced determines how PHP resolves its location:

  • **Unqualified Name:** No separator (e.g., hello()). PHP first looks in the **current namespace**, then in the global namespace.
  • **Qualified Name:** Contains a separator but doesn't start with one (e.g., SubSpace\hello()). PHP prepends the **current namespace** to the name.
  • **Fully Qualified Name (FQN):** Starts with a separator (e.g., \MyVendor\hello()). PHP resolves the name from the **global namespace** root.

The use Keyword (Importing)

The **use** keyword imports an external namespace, class, or function into the current file, allowing it to be referenced with an unqualified or shortened name (an **alias**).

  • **Importing a Class:** use MyVendor\MyApp\MyClass; allows you to use just new MyClass();.
  • **Aliasing:** You can assign a short alias to a long namespace or class name using the **as** keyword: use MyVendor\ExtraLongName as ShortName;

Advantages of Namespaces

  1. **Conflict Avoidance:** Prevents name collisions when using libraries or large codebases.
  2. **Readability:** The use keyword allows for shorter, cleaner code by aliasing long names.
  3. **Organization:** Groups related code logically.

Example Session

Using Namespaces and Aliasing

This example shows how two functions with the same name (calculate()) can coexist in different namespaces and how aliasing simplifies access.


// file: Calculator.php
namespace Math\Financial {
   function calculate() { return "Tax calculation result."; }
}
namespace Math\Geometry {
   function calculate() { return "Area calculation result."; }
}

// file: main.php
namespace App {
   // Import and alias the function from the Math\Financial namespace
   use function Math\Financial\calculate as calculateTax; 
   
   echo calculateTax();           // Calls Math\Financial\calculate()
   echo PHP_EOL;
   
   // Accessing the second function using its FQN
   echo \Math\Geometry\calculate(); // Calls Math\Geometry\calculate()
}
// Output: 
// Tax calculation result.
// Area calculation result.

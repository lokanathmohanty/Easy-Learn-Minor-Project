C - Loops

Loops are a programming construct that denote a block of one or more statements that are repeatedly executed a specified number of times, or until a certain condition is met.

Repetitive tasks are common in programming, and loops are essential to save time and minimize errors. In C programming, the keywords while, do while, and for are provided to implement loops.

Programming languages provide various control structures that allow for more complex execution paths. A loop statement allows us to execute a statement or group of statements multiple times.

Example: Repetitive Code Without Loops

#include <stdio.h>

int main() {
   int a = 1;

   printf("a: %d\n", a); a++;
   printf("a: %d\n", a); a++;
   printf("a: %d\n", a); a++;
   printf("a: %d\n", a); a++;
   printf("a: %d\n", a);

   return 0;
}

Output

  • a: 1
  • a: 2
  • a: 3
  • a: 4
  • a: 5

Manually repeating code like this is inefficient. Instead, we can use loops to perform the same action automatically.

Example: Using while Loop in C

#include <stdio.h>

int main() {
   int a = 1;

   while (a <= 100) {
      printf("a: %d\n", a);
      a++;
   }

   return 0;
}

Output

  • a: 1
  • a: 2
  • ...
  • a: 99
  • a: 100

Types of Loops in C

To constitute a loop, you need:

  • Looping statement (while, do while, or for)
  • Looping block (statements to be repeated)
  • Looping condition (termination check)

Loops can be categorized as follows:

Counted Loops

Repeat a known number of times. Example: for loop.

Conditional Loops

Repeat as long as a condition is true. Example: while, do while loops.

Loop Types in C

Loop TypeDescription
while loopRepeats while a condition is true. Tests condition before entering loop body.
for loopIdeal for counted loops. Manages initialization, condition, and increment in one line.
do while loopSimilar to while, but condition is checked after executing the loop body.
Nested loopsAllows one or more loops to be placed inside another loop.

Loop Control Statements in C

C provides control statements to alter loop execution flow:

StatementDescription
breakExits the loop or switch statement immediately.
continueSkips the current iteration and moves to the next loop cycle.
gotoJumps to a labeled statement elsewhere in the program.

Infinite Loops

A loop becomes infinite when the termination condition is never false. They may be intentional or due to logical errors.

Example: Infinite Loop using for

#include <stdio.h>

int main() {
   for( ; ; ) {
      printf("This loop will run forever.\n");
   }

   return 0;
}

Output

  • This loop will run forever.
  • This loop will run forever.
  • ...

In for(;;), since the condition is missing, it is considered true forever. You can terminate an infinite loop by pressing Ctrl + C during program execution.

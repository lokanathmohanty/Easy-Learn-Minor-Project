JavaScript - Hello World Program

Introduction

"Hello, World!" is often the first program programmers write when learning a new programming language. In JavaScript, it is a simple program used to demonstrate the basic syntax of the language. There are several methods to print "Hello World" in JavaScript.

Using document.write()

The document.write() method writes text directly to the HTML document or web page.

<script>
   document.write("Hello World");
</script>

We should place the document.write() inside <script> tags, which can be in either the <head> or <body> section.

Example

<html>
<head>
   <script>
      document.write("Hello World");
   </script>
</head>
<body>
</body>
</html>

Using alert() method

The alert() method displays a message in a dialog box.

<script>
   alert("Hello World");
</script>

We can also write it as window.alert(). Since window is the global object, it is optional to include.

Example

<html>
<head>
   <script>
      alert("Hello World");
   </script>
</head>
<body>
</body>
</html>

Using console.log()

The console.log() method prints messages to the web console, which is useful for debugging.

<script>
   console.log("Hello World");
</script>

Example

<html>
<head>
   <script>
      console.log("Hello World");
   </script>
</head>
<body>
   <p>Please open the console before running this code.</p>
</body>
</html>

Output in console: Hello World

Using innerHTML

The innerHTML property sets or returns the HTML content of an element. By targeting an element with an id, we can insert "Hello World" into the page.

Example

<html>
<head>
   <title>Using innerHTML property</title>
</head>
<body>
   <div id="output"></div>
   <script>
      document.getElementById("output").innerHTML = "Hello World";
   </script>
</body>
</html>

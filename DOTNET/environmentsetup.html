.NET Core Environment Setup Overview (Visual Studio)

To begin developing with **.NET Core**, which is a significant redesign of the classic .NET Framework, you can use one of two specific Visual Studio versions:

  • **Visual Studio 2015**
  • **Visual Studio 2017 RC**

Setup for Visual Studio 2015

To properly set up your environment with **Visual Studio 2015**, you must install two main components in the following order:

  1. **Microsoft Visual Studio 2015 Update 3**
  2. **Microsoft .NET Core 1.0.1 - VS 2015 Tooling Preview 2**

Installation Steps for Visual Studio 2015

Visual Studio 2015 Installation

  1. Run the Visual Studio 2015 installer after downloading.
  2. Click **Install** to start the process.
  3. Once installation completes, close the dialog and restart your computer if prompted.
  4. Open Visual Studio 2015 from the Start Menu; it may take a few minutes to load on first use.

.NET Core Tooling Installation

  1. After the Visual Studio installation is complete, close Visual Studio.
  2. Launch the **Microsoft .NET Core - VS 2015 Tooling Preview 2** installer.
  3. Check the required checkbox and click **Install**.
  4. Close the final dialog box upon completion.

Once both components are installed, your environment is ready for .NET Core application development.

Note on Visual Studio 2017

An experimental release of **.NET Core tools** is included with **Visual Studio 2017 RC**. The installation guidelines for this version are also available through the Microsoft official documentation.

Exponential Distribution

The Exponential Distribution is used to describe the time until the next event occurs, such as failure or success.

Parameters:

  • scale — The inverse of the rate parameter (similar to lam in the Poisson distribution). Defaults to 1.0.
  • size — The shape of the returned array.

The exponential distribution is often used to model waiting times between independent events that happen at a constant average rate.

Relation Between Poisson and Exponential Distributions

The Poisson distribution models the number of occurrences of an event in a fixed time period, while the exponential distribution models the time between these events.

Example: Generating Exponential Distribution Samples

Generate a 2x3 sample from an exponential distribution with a scale parameter of 2.0:

from numpy import random

x = random.exponential(scale=2, size=(2, 3))

print(x)

Visualization of Exponential Distribution

Visualize 1000 samples using Seaborn's KDE plot:

from numpy import random
import matplotlib.pyplot as plt
import seaborn as sns

sns.displot(random.exponential(size=1000), kind="kde")

plt.show()

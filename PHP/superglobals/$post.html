PHP `$_POST` Superglobal

The **`$_POST`** is a **superglobal associative array** in PHP used to collect data submitted from an HTML form using the **POST** method. Because the data is sent in the body of the HTTP request and not in the URL, the POST method is the standard and more secure way to transmit sensitive or large amounts of information.

Key Features of `$_POST`

  • **Superglobal:** It's accessible from any point in the script without needing the `global` keyword.
  • **Security/Privacy:** Data is **not visible in the URL** (unlike `GET`), making it suitable for passwords, personal information, or any data you don't want bookmarked or logged in server histories.
  • **Data Volume:** The POST method has no practical limit on the amount of data that can be sent (unlike GET, which has strict URL length limitations).
  • **Structure:** It's an associative array where the **keys** are the `name` attributes of the HTML form input fields, and the **values** are the user inputs.

Syntax to Access Data

You retrieve the submitted value by referencing the input field's name:

$_POST['key']

Example: If the input field is <input type="text" **name="first_name"** />, the value is accessed via $_POST['first_name'].

How Data is Submitted and Collected

For `$_POST` to be populated, the HTML form must use the attribute `method="post"`.

*HTML Form:*
<form action="handler.php" **method="post"**>
   <input type="text" **name="last_name"** />
   <input type="submit" />
</form>

*PHP Handler (handler.php):*
<?php
   echo "Last Name: " . **$_POST['last_name']**;
?>

A common pattern is to post the form data back to the same script by setting the action to `action=""`, allowing a single file to display the form and process the submitted data.

Python Serialization

Serialization is the process of converting an object into a format suitable for storage or transmission, which can later be reconstructed (deserialized) back into the original object.

It's useful for saving program state, data exchange, and caching.

Common Serialization Libraries

  • pickle: Python built-in for serializing arbitrary Python objects. Not secure against untrusted data.
  • json: Human-readable, language-independent format. Limited to basic data types.
  • yaml: Human-readable, supports complex structures. Requires external pyyaml package.

Pickle Module

Serialization (Pickling)

import pickle

data = {'name': 'Alice', 'age': 30, 'city': 'New York'}
with open('data.pkl', 'wb') as f:
    pickle.dump(data, f)
print("File created!")

Deserialization (Unpickling)

import pickle

with open('data.pkl', 'rb') as f:
    data = pickle.load(f)
print(data)

Output: {'name': 'Alice', 'age': 30, 'city': 'New York'}

Protocols

Pickle supports protocols 0 to 5 (introduced in Python 3.8). Higher protocols are more efficient.

Use pickle.HIGHEST_PROTOCOL to specify.

Pickler and Unpickler Classes

Advanced classes for controlling serialization/deserialization.

from pickle import Pickler, Unpickler

with open('data.bin', 'wb') as f:
    Pickler(f).dump({'a': 1, 'b': 2})

with open('data.bin', 'rb') as f:
    obj = Unpickler(f).load()
print(obj)

Pickling Custom Classes

import pickle

class Person:
    def __init__(self, name, age, city):
        self.name = name
        self.age = age
        self.city = city

person = Person('Alice', 30, 'New York')

with open('person.pkl', 'wb') as f:
    pickle.dump(person, f)

with open('person.pkl', 'rb') as f:
    person = pickle.load(f)
print(person.name, person.age, person.city)

Output: Alice 30 New York

JSON Serialization

Serialization

import json

data = {"name": "Alice", "age": 25, "city": "San Francisco"}
json_string = json.dumps(data)
print(json_string)

Output: {"name": "Alice", "age": 25, "city": "San Francisco"}

Serialization to File

with open('data.json', 'w') as f:
    json.dump(data, f)
print("Success!")

Deserialization

with open('data.json', 'r') as f:
    data = json.load(f)
print(data)

Output: {'name': 'Alice', 'age': 25, 'city': 'San Francisco'}

YAML Serialization

YAML supports complex data and is human-readable. Requires pyyaml package.

pip install pyyaml

Serialization

import yaml

data = {"name": "Emily", "age": 35, "city": "Seattle"}
with open('data.yaml', 'w') as f:
    yaml.dump(data, f, default_flow_style=False)
print("Success!")

Deserialization

with open('data.yaml', 'r') as f:
    loaded_data = yaml.safe_load(f)
print(loaded_data)

Output: {'age': 35, 'city': 'Seattle', 'name': 'Emily'}

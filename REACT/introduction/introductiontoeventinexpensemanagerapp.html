ReactJS - Introduce Events in Expense Manager APP

In the previous chapters, we have learned that events are actions performed by a user to interact with an application, such as hovering, clicking, dragging, or resizing. To handle these interactions, we define Event Handlers, which are functions or blocks of code executed when the event occurs.

In this chapter, we introduce events into the Expense Manager APP. Specifically, we will handle Mouse Events such as highlighting an expense entry when the user hovers over it.

Handling Events in Expense Manager APP

We want to highlight a row in the expense table when the user moves the cursor over it. Let us follow the step-by-step process below:

  • Step 1 − Add handleMouseEnter in ExpenseEntryItemList.js to highlight the row.
  • Step 2 − Add handleMouseLeave to remove highlight when the cursor leaves.
  • Step 3 − Add handleMouseOver to log mouse position (optional).
  • Step 4 − Bind these event handlers in the constructor.
  • Step 5 − Attach them to table rows and table element in render().

ExpenseEntryItemList Component

The updated component looks like this:

import React from 'react';
import './ExpenseEntryItemList.css';

class ExpenseEntryItemList extends React.Component {
  constructor(props) {
    super(props);
    this.handleMouseEnter = this.handleMouseEnter.bind();
    this.handleMouseLeave = this.handleMouseLeave.bind();
    this.handleMouseOver = this.handleMouseOver.bind();
  }

  handleMouseEnter(e) {
    e.target.parentNode.classList.add("highlight");
  }

  handleMouseLeave(e) {
    e.target.parentNode.classList.remove("highlight");
  }

  handleMouseOver(e) {
    console.log("The mouse is at (" + e.clientX + ", " + e.clientY + ")");
  }

  render() {
    const lists = this.props.items.map((item) =>
      <tr key={item.id} onMouseEnter={this.handleMouseEnter} onMouseLeave={this.handleMouseLeave}>
        <td>{item.name}</td>
        <td>{item.amount}</td>
        <td>{new Date(item.spendDate).toDateString()}</td>
        <td>{item.category}</td>
      </tr>
    );

    return (
      <table onMouseOver={this.handleMouseOver}>
        <thead>
          <tr>
            <th>Item</th>
            <th>Amount</th>
            <th>Date</th>
            <th>Category</th>
          </tr>
        </thead>
        <tbody>
          {lists}
        </tbody>
      </table>
    );
  }
}
export default ExpenseEntryItemList;

CSS Highlight

Create ExpenseEntryItemList.css and add the following style:

tr.highlight td {
  background-color: #a6a8bd;
}

index.js Usage

Finally, use the component in index.js with sample data:

import React from 'react';
import ReactDOM from 'react-dom';
import ExpenseEntryItemList from './components/ExpenseEntryItemList';

const items = [
  { id: 1, name: "Pizza", amount: 80, spendDate: "2020-10-10", category: "Food" },
  { id: 2, name: "Grape Juice", amount: 30, spendDate: "2020-10-12", category: "Food" },
  { id: 3, name: "Cinema", amount: 210, spendDate: "2020-10-16", category: "Entertainment" },
  ...
];

ReactDOM.render(
  <React.StrictMode>
    <ExpenseEntryItemList items={items} />
  </React.StrictMode>,
  document.getElementById('root')
);

Result

When you run the app using npm start and open http://localhost:3000, the application will:

  • Highlight an expense row when you hover over it.
  • Remove highlight when the cursor leaves the row.
  • Log the current mouse coordinates in the console while moving over the table.

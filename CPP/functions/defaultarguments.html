Default Arguments in C++ 🛠️

**Default arguments** are values assigned to function parameters during the function's declaration (prototype). These values are automatically used when the caller omits the corresponding argument during the function call. If the caller provides a value, it **overrides** the default.

This feature simplifies function calls and reduces the need for multiple function overloads.

return_type function_name(param1, param2 = v2, param3 = v3);

Core Rules for Default Arguments

  1. Declaration vs. Definition: Default arguments **must** be specified in the **function declaration (prototype)**, not in the function definition (implementation). Specifying them in both is an error. 
    // CORRECT: Declaration with default value
void greet(string name = "TutorialsPoint"); 

// CORRECT: Definition without default value
void greet(string name) { ... }
  2. Right-to-Left Assignment: Default arguments must be assigned starting from the **rightmost** parameter. Once a parameter has a default value, all subsequent parameters to its right must also have default values. 
    // VALID: funcA(int, string = "Default")
void funcA(int x, string y = "TutorialsPoint"); 

// INVALID: y has no default, but x does
// void funcC(int x = 2006, int y);
  3. Single Specification: Once a default argument is specified in a declaration, it cannot be redefined or modified in any subsequent declaration or definition.
  4. Ambiguity with Overloading: Default arguments should not be used in a way that creates ambiguity with existing overloaded functions. If two function signatures could potentially be matched by a single function call (e.g., calling a function with zero arguments matches two different overloads), a compilation error will occur.

Using Expressions and Function Calls as Defaults

Default values are not limited to constant literals; they can also be **expressions** or the result of a **function call**. The default expression is evaluated only once when the function is called without that specific argument.

  • Default as Expression: The expression is calculated when the function is called. 
    double total_price(double price, double discount = 12.0) {
    // 12.0 is used if no discount is passed
    return price - (price * discount / 100);
}
  • Default as Function Call: The default value is obtained by calling another function. 
    double getDefaultWidth() { return 5.0; } 

double cuboid_vol(double l, double h, double w = getDefaultWidth()) {
    // getDefaultWidth() is called if 'w' is omitted
    return l * w * h;
}

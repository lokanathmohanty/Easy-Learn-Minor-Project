Python - Inheritance

Inheritance is a key feature of object-oriented programming that enables a class (child or subclass) to inherit properties and behaviors from another class (parent or base class). It allows code reuse and models real-world relationships.

Basic Syntax

Parent (Base) class:

class ParentClass:
    # class body

Child (Derived) class:

class ChildClass(ParentClass):
    # class body

Types of Inheritance in Python

  • Single Inheritance
  • Multiple Inheritance
  • Multilevel Inheritance
  • Hierarchical Inheritance
  • Hybrid Inheritance

Single Inheritance Example

class Parent:
    def parent_method(self):
        print("Calling parent method")

class Child(Parent):
    def child_method(self):
        print("Calling child method")

c = Child()
c.child_method()
c.parent_method()

Output:
Calling child method
Calling parent method

Multiple Inheritance Example

class Division:
    def __init__(self, a, b):
        self.a = a
        self.b = b
    
    def divide(self):
        return self.a / self.b

class Modulus:
    def __init__(self, a, b):
        self.a = a
        self.b = b
    
    def modulus(self):
        return self.a % self.b

class DivMod(Division, Modulus):
    def __init__(self, a, b):
        Division.__init__(self, a, b)
        Modulus.__init__(self, a, b)
    
    def div_and_mod(self):
        return (self.divide(), self.modulus())

dm = DivMod(10, 3)
print("Divide:", dm.divide())
print("Modulus:", dm.modulus())
print("Div and Mod:", dm.div_and_mod())

Output:
Divide: 3.3333333333333335
Modulus: 1
Div and Mod: (3.3333333333333335, 1)

Method Resolution Order (MRO)

MRO defines the order Python follows to look for methods in multiple inheritance. It starts from the child class, then parents in order, then base classes, following the C3 linearization algorithm.

print(DivMod.mro())
# Output: [DivMod, Division, Modulus, object]

Multilevel Inheritance Example

class Universe:
    def universe_method(self):
        print("In Universe")

class Earth(Universe):
    def earth_method(self):
        print("On Earth")

class India(Earth):
    def india_method(self):
        print("In India")

i = India()
i.universe_method()
i.earth_method()
i.india_method()

Output:
In Universe
On Earth
In India

Hierarchical Inheritance Example

class Manager:
    def manager_method(self):
        print("Manager here")

class Employee1(Manager):
    def employee1_method(self):
        print("Employee1 here")

class Employee2(Manager):
    def employee2_method(self):
        print("Employee2 here")

e1 = Employee1()
e2 = Employee2()

e1.manager_method()
e1.employee1_method()
e2.manager_method()
e2.employee2_method()

Output:
Manager here
Employee1 here
Manager here
Employee2 here

Hybrid Inheritance Example

class CEO:
    def ceo_method(self):
        print("CEO here")

class Manager(CEO):
    def manager_method(self):
        print("Manager here")

class Employee1(Manager):
    def employee1_method(self):
        print("Employee1 here")

class Employee2(Manager, CEO):
    def employee2_method(self):
        print("Employee2 here")

e2 = Employee2()
e2.manager_method()
e2.ceo_method()
e2.employee2_method()

Output:
Manager here
CEO here
Employee2 here

Using super() in Inheritance

class Parent:
    def __init__(self, msg):
        self.msg = msg
    
    def show(self):
        print(self.msg)

class Child(Parent):
    def __init__(self, msg):
        super().__init__(msg)

c = Child("Welcome!")
c.show()

Output:
Welcome!

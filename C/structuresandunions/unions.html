Unions in C

What is a Union?

A union is a special data type in C that allows storing different data types in the same memory location. Only one member can contain a value at a time. Unions provide an efficient way of using the same memory location for multiple purposes.

All members share the same memory location, and the size of the union is defined by its largest member.

Defining a Union

Union variables are created similarly to structures. The keyword union is used to define unions in C.

Syntax:

union [union tag] {
  member definition;
  member definition;
  ...
} [one or more union variables];

The "union tag" is optional, and member definitions are normal variable declarations.

Accessing Union Members

Use the dot operator (.) to access union members.

Syntax:

union_variable.member_name;

Initializing Union Members

Assign values to union members using the assignment operator (=).

Syntax:

union_variable.member_name = value;

Example 1: Using Union

#include <stdio.h>
#include <string.h>

union Data {
  int i;
  float f;
  char str[20];
};

int main() {
  union Data data;

  data.i = 10;
  data.f = 220.5;
  strcpy(data.str, "C Programming");

  printf("data.i: %d \n", data.i);
  printf("data.f: %f \n", data.f);
  printf("data.str: %s \n", data.str);
  return 0;
}

Output:

data.i: 1917853763

data.f: 4122360580327794860452759994368.000000

data.str: C Programming

This shows that only the last assigned member holds a valid value; others show garbage.

Example 2: Using One Member at a Time

#include <stdio.h>
#include <string.h>

union Data {
  int i;
  float f;
  char str[20];
};

int main() {
  union Data data;

  data.i = 10;
  printf("data.i: %d \n", data.i);

  data.f = 220.5;
  printf("data.f: %f \n", data.f);

  strcpy(data.str, "C Programming");
  printf("data.str: %s \n", data.str);

  return 0;
}

Output:

data.i: 10

data.f: 220.500000

data.str: C Programming

Using one member at a time prevents garbage values.

Size of a Union

The size of a union is equal to the size of its largest member. Use sizeof() to determine the size.

Example: Size of a Union

#include <stdio.h>

union Data {
  int a;
  float b;
  char c[20];
};

int main() {
  union Data data;

  printf("Size of a: %lu bytes\n", sizeof(data.a));
  printf("Size of b: %lu bytes\n", sizeof(data.b));
  printf("Size of c: %lu bytes\n", sizeof(data.c));

  printf("Size of union: %lu bytes\n", sizeof(data));

  return 0;
}

Output:

Size of a: 4 bytes

Size of b: 4 bytes

Size of c: 20 bytes

Size of union: 20 bytes

Difference Between Structure and Union

  • Structures allocate separate memory for each member; unions share the same memory for all members.
  • Size of structure = sum of sizes of all members; size of union = size of largest member.
  • Only one union member can hold a value at a time; structure members can hold values simultaneously.

Example of union and struct definitions with the same members:

union myunion {
  int a;
  double b;
  char c;
};

struct mystruct {
  int a;
  double b;
  char c;
};

The union occupies memory equal to the largest member (double), while the struct occupies combined memory of all members.

Example: Memory Occupied by Union

#include <stdio.h>
#include <string.h>

union Data {
  int i;
  float f;
  char str[20];
};

int main() {
  union Data data;
  printf("Memory occupied by Union Data: %d \n", sizeof(data));
  return 0;
}

Output:

Memory occupied by Union Data: 20

Example: Memory Occupied by Structure

#include <stdio.h>
#include <string.h>

struct Data {
  int i;
  float f;
  char str[20];
};

int main() {
  struct Data data;
  printf("Memory occupied by Struct Data: %d \n", sizeof(data));
  return 0;
}

Output:

Memory occupied by Struct Data: 28

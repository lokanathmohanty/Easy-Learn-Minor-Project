Python Try-Finally Block

In Python, the try-finally block is used to ensure that certain code executes, regardless of whether an exception is raised or not. Unlike the try-except block, which handles exceptions, the try-finally block focuses on cleanup operations that must occur, ensuring resources are properly released and critical tasks are completed.

Syntax

try:
   # Code that might raise exceptions
   risky_code()
finally:
   # Code that always runs, regardless of exceptions
   cleanup_code()

In Python, when using exception handling with try blocks, you have the option to include either except clauses to catch specific exceptions or a finally clause to ensure certain cleanup operations are executed, but not both together.

Example

try:
   fh = open("testfile", "w")
   fh.write("This is my test file for exception handling!!")
finally:
   print("Error: can't find file or read data")
   fh.close()

If you do not have permission to open the file in writing mode, it will produce the following output: 

Error: can't find file or read data

Improved Example with Nested Try and Except

try:
   fh = open("testfile", "w")
   try:
      fh.write("This is my test file for exception handling!!")
   finally:
      print("Going to close the file")
      fh.close()
except IOError:
   print("Error: can't find file or read data")

When an exception is thrown in the try block, execution immediately passes to the finally block. After all statements in the finally block are executed, the exception is raised again and can be handled in the except block if present.

Exception with Arguments

An exception can have an argument providing additional information about the problem. You capture this argument by supplying a variable in the except clause: 

try:
   # code here
except ExceptionType as Argument:
   # You can print value of Argument here...

Example

def temp_convert(var):
   try:
      return int(var)
   except ValueError as Argument:
      print("The argument does not contain numbers\n", Argument)

temp_convert("xyz")

Output: 

The argument does not contain numbers
invalid literal for int() with base 10: 'xyz'

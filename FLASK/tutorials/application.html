Creating and Running a Basic Flask Application

To test a Flask installation, you can create a minimal application, often called "Hello World," which demonstrates the core components of the framework.

The Basic Flask Application Code (Hello.py)

The following script sets up the smallest working Flask web application:

from flask import Flask

app = Flask(__name__)

@app.route('/')

def hello_world():

return 'Hello World'

if __name__ == '__main__':

app.run()

Explanation of Code Components

  • **from flask import Flask:** Imports the necessary Flask class.
  • **app = Flask(__name__):** Creates an instance of the Flask class. This object, app, is your **WSGI application**. The argument __name__ is the name of the current module and is required for Flask to know where to look for resources.
  • **@app.route('/'):** This is the **route decorator**. It binds the URL path (the rule parameter), in this case the root '/', to the function defined immediately below it.
  • **def hello_world()::** The function associated with the route. Its return value (e.g., 'Hello World') is displayed in the user's web browser.
  • **app.run():** Starts the application on the local development server.

Running the Application and Default Settings

Execution

Execute the script from your Python shell:

python Hello.py

The console will output the running address:

* Running on http://127.0.0.1:5000/ (Press CTRL+C to quit)

Opening **localhost:5000** in a browser will display the "Hello World" message.

The app.run(host, port, debug, options) Method

The run() method is used to start the server and accepts several optional parameters:

ParameterDescriptionDefault Value
hostHostname to listen on. Set to 0.0.0.0 to make the server externally available.127.0.0.1 (localhost)
portThe port number the server runs on.5000
debugIf set to True, enables debug mode.False
optionsAdditional parameters for the underlying Werkzeug server.N/A

Enabling Debug Mode

During development, it's recommended to enable **debug mode** to automatically reload the server on code changes and provide a useful debugger for tracking errors. You can enable it in two ways:

1. Setting the property:

app.debug = True
app.run()

2. Passing a parameter to run():

app.run(debug = True)

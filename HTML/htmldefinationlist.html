HTML - Definition Lists

A description list is defined by <dl> tag along with the <dt> and <dd> tags. Where <dt> defines the definition term, and <dd> defines the corresponding definition.

HTML Definition Lists

HTML definition lists define list items having the structure of terms and their corresponding definitions. These are used to define listings where each term contains its corresponding explanation.

Definition List Tags

  • <dl>: Defines the definition list.
  • <dt>: Defines the description term.
  • <dd>: Defines the corresponding description.

Syntax

<dl>
  <dt>Term 1</dt>
  <dd>Definition for Term 1</dd>
  <dt>Term 2</dt>
  <dd>Definition for Term 2</dd>
</dl>

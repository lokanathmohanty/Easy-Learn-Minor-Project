C# Strings

Introduction to Strings

In C#, a **string** is a sequence of characters. The string keyword is an alias for the System.String class, which is a **reference type**. Unlike arrays of characters, the String class provides a rich set of features for manipulation and comparison.

Strings in C# are **immutable**, meaning once a string object is created, its value cannot be changed. Any operation that appears to modify a string (like concatenation or replacement) actually creates a **new** string object in memory.

Creating a String Object

A string object can be created in several ways:

  • Using a literal: The most common method. string message = "Hello, C#!";
  • Concatenation: Using the + operator. string fullname = fname + " " + lname;
  • From a character array: Using the String class constructor. string greetings = new string(letters);
  • Formatting: Using String.Format() or interpolation to convert values/objects to their string representation.

Common String Operations

1. Finding Length

Use the read-only **`Length`** property to get the number of characters in the string.

string str = "C# Programming";
int length = str.Length; // length is 14

2. Iterating Characters

Strings can be treated like arrays of characters, allowing iteration using a `foreach` loop.

string str = "C# by TP";
foreach (char ch in str) {
   Console.WriteLine(ch); // Prints each character on a new line
}

3. Comparing Strings

Use the static **`String.Compare()`** method or the equality operator (`==`) to check if two strings are equal or to determine their relative order.

string str1 = "Hello";
string str2 = "World";
if (String.Compare(str1, str2) == 0) {
   // Strings are equal
}

4. Substring and Checking Content

  • **`Contains()`:** Checks if a string includes a specified substring.
  • **`Substring()`:** Extracts a part of the string starting at a specified index (zero-based).
string str = "C# Programming Language";
string substr = str.Substring(3, 11); // Starts at index 3, takes 11 chars
// substr is "Programming"

5. Joining Strings

The static **`String.Join()`** method concatenates the elements of a string array using a specified separator.

string[] lines = { "C# is modern", "Object-oriented" };
string result = String.Join("\n", lines);
// result will include a newline between the elements

Handling Mutable Strings with `StringBuilder`

Since `string` objects are immutable, repeated modifications (like appending text in a loop) create many temporary string objects, which can be inefficient.

The **`System.Text.StringBuilder`** class is used when you need to perform extensive, efficient modifications (appending, inserting, replacing) to a string without generating new memory allocations for every change.

using System.Text;
StringBuilder sb = new StringBuilder("Hello");
sb.Append(" World!");
sb.Insert(6, "C# ");
sb.Replace("World", "Everyone");
// sb.ToString() returns "Hello C# Everyone!"

Common String Class Methods

The String class offers many powerful methods for manipulation:

  • `Trim()`: Removes all leading and trailing white-space characters.
  • `ToUpper()` / `ToLower()`: Converts the entire string to uppercase or lowercase.
  • `Replace()`: Replaces all occurrences of a specified substring with another.
  • `Split()`: Splits the string into an array of substrings based on specified delimiters.
  • `IsNullOrEmpty()` / `IsNullOrWhiteSpace()`: Essential for input validation and checking if a string is empty or contains only whitespace.

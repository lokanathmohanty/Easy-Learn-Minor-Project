.NET Core - Quick Guide & Overview

.NET Core Overview

.NET Core is the **latest general-purpose development platform** maintained by Microsoft. It was redesigned to be fast, flexible, and modern, enabling developers to build applications for various platforms including **Android, iOS, Linux, Mac, and Windows**, all within an **Open Source** ecosystem.

This quick guide covers the core characteristics of .NET Core, its platform components, prerequisites, and environment setup.

Characteristics of .NET Core

The major characteristics that define the .NET Core platform are:

  • Open Source: Implemented under MIT and Apache 2 licenses. It is a **.NET Foundation project** and available on GitHub, promoting community engagement and transparent development.
  • Cross-Platform: Supports code reuse and execution across three main operating systems: **Windows, Linux, and macOS**.
  • Flexible Deployment: Supports two main deployment models:
    • Framework-dependent deployment: The app relies on a system-wide version of .NET Core.
    • Self-contained deployment: The necessary .NET Core runtime is deployed alongside the app, allowing it to run side-by-side with other versions.
  • Command-line Tools: All product scenarios can be managed and exercised via the command line.
  • Compatible: Works with the .NET Framework, Xamarin, and Mono through the **.NET Standard Library**.
  • Modular: Functionality is released through NuGet as smaller, feature-centric assembly packages, rather than one large assembly like the .NET Framework. This modularity improves security, performance, and reduces servicing costs.

The .NET Core Platform Components

The .NET Core platform primarily consists of four main parts:

  1. .NET Runtime: Provides basic services like the type system, assembly loading, garbage collector, and native interop.
  2. Fundamental Libraries: A core set of framework libraries providing primitive data types and essential utilities.
  3. SDK & Compiler: The tools and language compilers necessary for the base developer experience, available within the **.NET Core SDK**.
  4. dotnet app host: Used to launch .NET Core apps. It selects and hosts the runtime, handles assembly loading policy, and starts the application.

.NET Core Prerequisites (Windows)

To deploy and run .NET Core applications on Windows, certain dependencies are required:

Supported Windows Versions

.NET Core is supported on various Windows versions, including:

  • Windows 7 SP1, Windows 8.1, Windows 10.
  • Windows Server 2008 R2 SP1, Windows Server 2012 SP1, Windows Server 2012 R2 SP1, and Windows Server 2016 (including Server Core and Nano Server).

Dependencies

For Windows versions earlier than Windows 10 and Windows Server 2016:

  • The **Visual C++ Redistributable for Visual Studio 2015** is required. This is installed automatically if using the official .NET Core installer. It must be manually installed if using the installer script or deploying a self-contained application.
  • For Windows 7 and Windows Server 2008, ensure **hotfix KB2533623** is installed via Windows Update.

Prerequisites with Visual Studio

While any editor can be used, developers using Visual Studio on Windows can use:

  • Visual Studio 2015: Projects defaulted to the **project.json** build system.
  • Visual Studio 2017 RC: Projects defaulted to the **MSBuild** build system.

.NET Core Environment Setup (Visual Studio 2015)

To set up the development environment using **Visual Studio 2015**, you must have:

  1. **Microsoft Visual Studio 2015 Update 3**
  2. **Microsoft .NET Core 1.0.1 - VS 2015 Tooling Preview 2**

Installation Steps for Visual Studio 2015

After downloading the installer from the Microsoft website:

  1. Run the installer and click **Install** to begin the setup.
  2. After the installation completes, close the dialog and restart the computer if prompted.
  3. Upon opening Visual Studio for the first time, it will initialize and load, displaying the main screen when ready for use.

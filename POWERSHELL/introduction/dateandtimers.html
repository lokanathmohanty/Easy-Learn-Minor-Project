PowerShell - Date and Time Operations

Following are examples of PowerShell scripts on System Date and Time.

Sr.No. Operation & Description
1 Get System Date
Example Script to show how to get system date using PowerShell scripts.
2 Set System Date
Example Script to show how to set system date using PowerShell scripts.
3 Get System Time
Example Script to show how to get system time using PowerShell scripts.
4 Set System Time
Example Script to show how to set system time using PowerShell scripts.

Example: Get System Date

Get-Date

Example: Set System Date

Set-Date -Date "2025-10-08"

Example: Get System Time

Get-Date -Format "HH:mm:ss"

Example: Set System Time

# Example requires admin rights
Set-Date -Date "2025-10-08 14:30:00"

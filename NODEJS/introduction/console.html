Node.js - Console

Overview

The console module in Node.js provides an easy way to output messages to standard output and error streams. It is widely used for debugging, logging, performance monitoring, and development feedback.

Why Use Console in Node.js?

  • Debugging: Tracks errors and helps debug code efficiently.
  • Logging: Records application events, warnings, and errors.
  • Performance Monitoring: Analyzes execution time and resource usage.
  • Development & Testing: Provides immediate feedback during code testing.

Basic Console Methods

Commonly used methods help log messages and warnings effectively:

console.log()
Outputs standard messages.
console.error()
Outputs error messages to standard error stream separately.
console.warn()
Outputs warning messages indicating potential but non-critical issues.
console.info()
Outputs informational messages similar to log but often used for status updates.

Examples

console.log("WELCOME");
console.error("An unexpected error occurred!");
console.warn("It is warning.!, Please check the Application.");
console.info("It is running on port 1212");

Output

WELCOME
An unexpected error occurred!
It is warning.!, Please check the Application.
It is running on port 1212

Advanced Console Methods

Advanced methods provide structured logging and debugging helpful for large-scale applications:

console.table()

Displays tabular data for arrays or objects:

const A = [
  {id:1, name:"BMW"},
  {id:2, name:"CIAZ"}
];
console.table(A);

Output:

| (index) | id |  name  |
|---------|----|--------|
|    0    | 1  | "BMW"  |
|    1    | 2  | "CIAZ" |

console.time() and console.timeEnd()

Measures time taken to execute code blocks:

console.time("Loop Execution Time");
for (let x=0; x<250; x++){
  // loop contents
}
console.timeEnd("Loop Execution Time");

Output example:

Loop Execution Time: 17.078s

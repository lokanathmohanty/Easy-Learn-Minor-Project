Pareto Distribution

The Pareto distribution follows Pareto's law, often referred to as the 80-20 rule (where 20% of factors cause 80% of the outcome).

Parameters:

  • a — Shape parameter.
  • size — The shape of the returned array.

Example: Generating Pareto Distribution Samples

Generate a 2x3 sample from a Pareto distribution with shape parameter 2:

from numpy import random

x = random.pareto(a=2, size=(2, 3))

print(x)

Visualization of Pareto Distribution

Visualize 1000 samples from a Pareto distribution using Seaborn:

from numpy import random
import matplotlib.pyplot as plt
import seaborn as sns

sns.displot(random.pareto(a=2, size=1000))

plt.show()

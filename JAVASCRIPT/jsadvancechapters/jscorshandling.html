JavaScript - CORS Handling

Overview

Cross-Origin Resource Sharing (CORS) is a browser-level security feature that restricts cross-origin HTTP requests. By default, browsers enforce the same-origin policy, which prevents a script from one domain from accessing resources on another. In this session, you will learn what CORS is, why it matters, and how to handle it using JavaScript and Express.js servers.

Learning Objectives

  • Understand the concept of CORS and its role in web security.
  • Learn why CORS is important for secure web applications.
  • Implement CORS handling in an Express.js server.
  • Test CORS-enabled endpoints with a vanilla JavaScript client.
  • Recognize and troubleshoot common CORS-related issues.

What is CORS?

CORS is a security feature enforced by browsers to prevent malicious sites from making unauthorized requests to other domains. It enforces the same-origin policy, meaning that a web page can only request resources from the domain it was loaded from. CORS allows servers to define which origins are permitted to access their resources, enabling secure cross-domain communication.

Importance of CORS

While CORS enhances security, it often introduces challenges for developers working with APIs hosted on different domains. Proper configuration ensures both security and functionality, allowing legitimate clients to interact with server resources without being blocked by the browser.

CORS Handling Using Express Server

One way to handle CORS is by configuring headers in an Express.js server. The Access-Control-Allow-Origin header specifies which origins can access resources.

Example: Basic Express.js Server with CORS Enabled

index.js

const express = require('express');
const server = express();

server.use((request, response, proceed) => {
  response.header('Access-Control-Allow-Origin', '*');
  response.header('Access-Control-Allow-Methods', 'GET, POST, PUT, DELETE');
  response.header('Access-Control-Allow-Headers', 'Origin, X-Requested-With, Content-Type, Accept');
  proceed();
});

server.get('/info', (request, response) => {
  response.json({ country: 'India', currencyCode: 'INR' });
});

server.listen(3000, () => {
  console.log('Application is live on port 3000');
});

Vanilla JavaScript Client

index.html

<!DOCTYPE html>
<html lang="en">
  <body>
    <h1>Data from Server</h1>
    <div id="infoDisplay"></div>
    <script>
      document.addEventListener('DOMContentLoaded', () => {
        const infoContainer = document.getElementById('infoDisplay');
        fetch('http://localhost:3000/info')
        .then(response => response.json())
        .then(info => {
          infoContainer.innerHTML = `<p>Country: ${info.country}</p><p>Currency Code: ${info.currencyCode}</p>`;
        })
        .catch(error => {
          console.warn('Failed to retrieve data:', error);
          infoContainer.innerHTML = '<p>Error retrieving data. Please try again later.</p>';
        });
      });
    </script>
  </body>
</html>

Common CORS Issues

Unauthorized Access Blocked by CORS

Error message: Access to XMLHttpRequest at 'URL' from origin 'Origin' has been blocked by CORS policy. This happens when the server does not permit the requesting origin.

Solution Example

const express = require('express');
const server = express();

server.use((request, response, proceed) => {
  response.setHeader('Access-Control-Allow-Origin', 'https://example.com');
  response.setHeader('Access-Control-Allow-Methods', 'GET, POST, PUT, DELETE');
  response.setHeader('Access-Control-Allow-Headers', 'Content-Type, Authorization');
  response.setHeader('Access-Control-Allow-Credentials', 'true');
  proceed();
});

server.get('/api/info', (request, response) => {
  response.json({ details: 'Information from the server' });
});

server.listen(3000, () => {
  console.log('Application active on port 3000');
});

Missing CORS Headers

If the server fails to return CORS headers, browsers block cross-origin requests.

Solution Example

const express = require('express');
const server = express();

server.use((request, response, proceed) => {
  response.setHeader('Access-Control-Allow-Origin', '*');
  response.setHeader('Access-Control-Allow-Methods', 'GET, POST, PUT, DELETE');
  response.setHeader('Access-Control-Allow-Headers', 'Content-Type, Authorization');
  response.setHeader('Access-Control-Allow-Credentials', 'true');
  proceed();
});

server.get('/api/info', (request, response) => {
  response.json({ info: 'Information from the server' });
});

server.listen(3000, () => {
  console.log('Application is now active on port 3000');
});

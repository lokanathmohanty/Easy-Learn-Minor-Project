Next.js Redirecting Routes ➡️

Overview of Redirection Methods

**Redirecting** is essential for guiding users from broken, incorrect, or unauthorized URLs to the correct destination. Next.js offers various methods for handling redirects, depending on where the logic needs to execute: at the **server edge**, the **server (build time)**, or the **client side**.

Method Purpose / Used At Execution Environment
`redirects()` in `next.config.js` Static, permanent redirects (e.g., fixing typos) Server (Build Time/Edge)
`useRouter` hook Programmatic client-side navigation/redirects Client Component
`NextResponse.redirect` (Middleware) Conditional logic (e.g., authentication checks) Server (Edge)

1. Static Redirecting (next.config.js)

This method is used for defining a list of known redirects, often for fixing old or broken links. The redirects are handled at the server edge, making them highly efficient.

// ./next.config.ts (Example: Redirecting /abouttt to /about)
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
    async redirects() {
        return [
          {
            source: "/abouttt",
            destination: "/about",
            permanent: true, // true for 301 (SEO-friendly), false for 302
          }
        ];
      },
};

2. Conditional Redirecting (Middleware)

Middleware executes code before a request is completed, allowing you to intercept and redirect requests based on custom server-side logic (e.g., checking a user's session or authentication status).

// file: middleware.ts (Example: Protecting /dashboard routes)
import { NextResponse, NextRequest } from 'next/server'

export function middleware(request: NextRequest) {
  const isAuthenticated = false; // Replace with actual logic
 
  // Redirect to login if user is not authenticated
  if (!isAuthenticated) {
    return NextResponse.redirect(new URL('/login', request.url));
  }
 
  return NextResponse.next();
}
 
export const config = {
  // Only run middleware on requests matching /dashboard or its sub-paths
  matcher: '/dashboard/:path*',
}

3. Client-Side Redirecting (`useRouter` Hook)

The `useRouter` hook is used for imperative navigation and redirects that are triggered by a client-side action (e.g., button click, form submission success). This must be used inside a **Client Component**.

"use client"; 
import { useRouter } from "next/navigation";

export default function ProductPage({ params }) {
    const router = useRouter();

    const handleClick = () => {
        alert("Order Placed...");
        // Use router.push() to navigate to the home page (which is a redirect)
        router.push("/"); 
    };
    
    return (
        <div>
            <h1>Product {params.id}</h1>
            <button onClick={handleClick}>Order Item</button>
        </div>
    );
}

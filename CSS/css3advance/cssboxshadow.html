CSS - box-shadow Property

The box-shadow property adds a shadow effect around an element. One or more shadow effects can be added, separated by commas. The shadow is defined by horizontal and vertical offsets, blur radius, spread radius, color, and optionally the inset keyword.

Syntax

box-shadow: none | h-offset v-offset blur spread color | inset | initial | inherit;

Property Values

  • none: No shadow (default).
  • h-offset: Horizontal offset. Positive → right, negative → left. (Required)
  • v-offset: Vertical offset. Positive → below, negative → above. (Required)
  • blur: Blur radius. Higher values = more blur. (Optional)
  • spread: Spread radius. Positive = bigger shadow, negative = smaller. (Optional)
  • color: Defines shadow color (name, hex, rgb, hsl). (Optional)
  • inset: Places the shadow inside the element.
  • initial: Sets the property to its default value.
  • inherit: Inherits from the parent element.

Examples of CSS Box Shadow Property

1. Basic Box Shadow

At least two values (horizontal and vertical offsets) are required. Depending on the signs of values, the shadow changes position.

box-shadow: 10px 10px;
box-shadow: 10px -10px;
box-shadow: -10px 10px;
box-shadow: -10px -10px;

2. Box Shadow with Blur

The third value sets the blur radius. Larger values make the shadow softer.

box-shadow: 10px 10px 10px;
box-shadow: 10px 10px 20px;
box-shadow: 10px 10px 40px;

3. Box Shadow with Spread

The fourth value defines spread size. Positive → larger shadow, negative → smaller shadow.

box-shadow: 10px 10px 10px 5px;
box-shadow: 10px 10px 20px 15px;
box-shadow: 10px 10px 40px -5px;

4. Box Shadow with Color

The shadow color can be defined using color names, hex, rgb, or hsl.

box-shadow: 10px -10px grey;
box-shadow: 10px 10px 20px rgb(51, 204, 0);
box-shadow: 10px 10px 40px -5px hsl(225, 100%, 50%);

5. Box Shadow with Inset

The inset keyword places the shadow inside the element.

box-shadow: 10px -10px red inset;
box-shadow: 10px 10px 20px rgb(51, 204, 0) inset;

6. Multiple Shadows

Multiple shadows can be applied by separating values with commas.

box-shadow: 10px -10px grey, 15px -15px black, 20px -20px brown;
box-shadow: 5px 5px red, 10px 10px blue, 15px 15px green;

Dereference Pointer in C

What Is Dereferencing?

The dereference (or indirection) operator * is used to access or modify the value stored in the memory location pointed to by a pointer. When applied to a pointer variable, it yields the variable it points to.

Syntax

To dereference a pointer:

*pointer_variable;

You can use the dereferenced pointer to both read and modify the value of the target variable.

How to Dereference a Pointer

  1. Declare a variable and a pointer.
  2. Initialize the pointer with the address of that variable.
  3. Use *pointer to access or modify the variable’s value.

Example: Simple Dereferencing

#include <stdio.h>

int main() {
  int x = 10;
  int *ptr;

  ptr = &x;  // pointer holds address of x

  printf("Value of x = %d\n", *ptr);
  return 0;
}

This program prints Value of x = 10, as *ptr retrieves the value stored in x.

Dereferencing Different Types

You can dereference pointers of different types to get values of those types:

#include <stdio.h>

int main() {
  int a = 10;
  int *b = &a;
  float x = 10.5f;
  float *y = &x;

  printf("Address of 'a': %p  Value of 'a': %d\n", (void *)b, *b);
  printf("Address of 'x': %p  Value of 'x': %f\n", (void *)y, *y);

  return 0;
}

Modifying Value by Dereferencing

You can assign to *pointer to change the value of the underlying variable:

#include <stdio.h>

int main() {
  int a = 10;
  int *b = &a;
  float x = 10.5f;
  float *y = &x;

  *b = 100;
  *y = 100.50f;

  printf("Address of 'a': %p  Value of 'a': %d\n", (void *)b, *b);
  printf("Address of 'x': %p  Value of 'x': %f\n", (void *)y, *y);

  return 0;
}

Dereferencing a Double Pointer

A double pointer (int **, etc.) holds the address of another pointer. You can dereference it twice to access the ultimate value:

#include <stdio.h>

int main() {
  int a = 10;
  int *b = &a;

  int **c = &b;

  printf("a: %d  Address of a: %p  *b: %d\n", a, (void *)b, *b);
  printf("b: %p  Address of b: %p  *c: %p\n", (void *)b, (void *)&b, (void *)*c);
  printf("Value of a via c: %d\n", **c);

  return 0;
}

Dereferencing a Structure Pointer

For a struct pointer, you often use the arrow operator -> to access fields. This is equivalent to dereferencing and then accessing a member:

struct Book {
  char title[20];
  double price;
  int pages;
};

struct Book b1 = { "LearnC", 650.50, 325 };
struct Book *ptr = &b1;

printf("Title: %s\nPrice: %.2f\nPages: %d\n",
       ptr->title, ptr->price, ptr->pages);

Summary

The dereference operator * allows you to access or modify the value stored at the memory address held by a pointer. With single, double, or struct pointers, proper use of dereferencing is key to working correctly and safely with pointers in C.

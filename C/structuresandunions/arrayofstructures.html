Array of Structures in C

Introduction

In C programming, a struct is a derived data type that groups variables under one name. An array of structures allows you to handle multiple records as in a database.

Defining and Initializing

Define a struct type called book with members like title, price, and pages:


struct book {
  char title[10];
  double price;
  int pages;
};

Initialize an array of such structs using nested curly braces:


struct book b[3] = {
  {"Learn C", 650.50, 325}, 
  {"C Pointers", 175, 225}, 
  {"C Pearls", 250, 250}
};

Accessing Elements

Access members by indexing and using the dot operator: 


printf("%s costs %.2lf and has %d pages\n", b[0].title, b[0].price, b[0].pages);

Modifying Struct Arrays

You can assign values using strcpy and direct assignment after declaration.

Sorting

Sort the array based on a member like price using nested loops and assignment:


struct book temp;
for (int i = 0; i < 2; i++) {
  for (int j = i + 1; j < 3; j++) {
    if (b[i].price > b[j].price) {
      temp = b[i];
      b[i] = b[j];
      b[j] = temp;
    }
  }
}

Pointers to Struct Arrays

You can use pointers to iterate over struct arrays and access members with the arrow operator:


struct book *ptr = b;
for (int i = 0; i < 3; i++) {
  printf("Title: %s Price: %.2lf Pages: %d\n", ptr->title, ptr->price, ptr->pages);
  ptr++;
}

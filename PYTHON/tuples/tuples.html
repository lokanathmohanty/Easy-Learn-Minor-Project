Python Tuples

Tuple is one of the built-in data types in Python. A Python tuple is a sequence of comma separated items, enclosed in parentheses (). The items in a Python tuple need not be of same data type.

Examples of Python tuples:

  • tup1 = ("Rohan", "Physics", 21, 69.75)
  • tup2 = (1, 2, 3, 4, 5)
  • tup3 = ("a", "b", "c", "d")
  • tup4 = (25.50, True, -55, 1+2j)

The empty tuple is written as two parentheses containing nothing − tup1 = ();

To write a tuple containing a single value you have to include a comma, even though there is only one value − tup1 = (50,);

Key Points About Tuples

  • Tuples are ordered collections and each item can be accessed by index starting at 0.
  • They can contain mixed data types unlike arrays in C/C++/Java.
  • Tuples are immutable — their values cannot be changed after creation.

Accessing Values in Tuples

Use square brackets with the index or slice to get values. Example:

tup1 = ('physics', 'chemistry', 1997, 2000);

print(tup1[0]) # physics

print(tup1[1:3]) # ('chemistry', 1997)

Updating Tuples

Tuples cannot be updated. You can concatenate tuples to create new ones.

tup3 = tup1 + tup2 produces a new tuple with combined values.

Deleting Tuples

You cannot delete individual elements but can delete the entire tuple using del statement.

Tuple Operations and Membership

  • Concatenation using +
  • Repetition using *
  • Membership check with in and not in

Indexing and Slicing

Support positive and negative indexing and slicing similar to lists and strings.

Built-in Functions with Tuples

  • len(tuple): Length of tuple
  • max(tuple): Max value
  • min(tuple): Min value
  • tuple(sequence): Convert sequence to tuple

Example Code

tup1 = ('physics', 'chemistry', 1997, 2000)
print("tup1[0]:", tup1[0])

tup2 = (1, 2, 3, 4, 5, 6, 7)
print("tup2[1:5]:", tup2[1:5])

tup1 = (12, 34.56)
tup2 = ('abc', 'xyz')
# tup1[0] = 100 # This will raise an error

tup3 = tup1 + tup2
print(tup3)

tup = ('physics', 'chemistry', 1997, 2000)
print(tup)
del tup
# print(tup) # This will raise an error because tup is deleted

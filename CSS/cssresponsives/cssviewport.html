CSS RWD Viewport

A viewport, in the context of responsive web design, is a virtual area used by the browser to render a web page. The viewport is essential to web development and creation of responsive designs that adapt to various devices and screen sizes.

What is a Viewport?

The viewport is the visible area for a user in a web page. It will vary with the device, and will be smaller on a mobile phone than on a computer screen.

On a desktop, the viewport is the window's size, excluding the toolbar and other elements that are not part of the web page. On a mobile device, it is the size of the screen.

Types of Viewport

  • Layout Viewport: It is the virtual area used by the browser to display the web page. The layout viewport is controlled by adding the meta viewport tag in the HTML head section.
  • Visual Viewport: It represents the part of the layout viewport that is currently visible on the screen. The visual viewport can be changed by zooming in and out.

Both viewports are mutable, meaning their dimensions can be altered after the page loads.

Setting the Viewport

We can control viewport width using the <meta> tag. The following line should be included inside the head section of all web pages for ensuring responsiveness:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

  • width=device-width: Sets the width of the viewport equal to the device's screen width.
  • initial-scale=1.0: Sets the initial zoom level to 100%.

Example with Meta Tag

This example includes the viewport meta tag, making the layout responsive and adaptive to different screen sizes. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta name="viewport" content="width=device-width, initial-scale=1">
</head>
<body>
    <div class="container">
        <h1>Responsive Layout with Viewport Meta Tag</h1>
        <div class="content">
            <p>
                This layout adapts to the device screen width, thanks to the viewport meta tag.
            </p>
        </div>
    </div>
</body>
</html>

Example without Meta Tag

This example does not include the viewport meta tag. As a result, the page will not be responsive on smaller screens, and users may encounter horizontal scrolling. 

<!DOCTYPE html>
<html lang="en">
<head>
</head>
<body>
    <div class="container">
        <h1>Non-Responsive Layout Without Viewport Meta Tag</h1>
        <div class="content">
            <p>
                This layout does not adapt to the device screen width, 
                because it lacks the viewport meta tag.
            </p>
        </div>
    </div>
</body>
</html>

CSS Units Related to Viewports

CSS provides units relative to the viewport dimensions. These are useful for making layouts adapt to different screen sizes.

  • vw (viewport width): 1vw = 1% of the viewport's width. Example: width: 10vw; → 10% of viewport width.
  • vh (viewport height): 1vh = 1% of the viewport's height. Example: height: 50vh; → half of the viewport's height.
  • vmin: Takes the smaller value of viewport width and height. Useful for adapting to both portrait and landscape.
  • vmax: Takes the larger value of viewport width and height. Useful for designs that maximize space in larger screens.

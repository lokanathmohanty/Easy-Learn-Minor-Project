Python - Sets

In Python, a set is an unordered collection of unique elements. Unlike lists or tuples, sets do not allow duplicate values. Sets are mutable, so elements can be added or removed after creation.

Creating a Set

Sets can be created using curly braces {} or the built-in set() function.

# Using curly braces
my_set = {1, 2, 3, 4, 5}
print(my_set)

# Using the set() function
my_set = set([1, 2, 3, 4, 5])
print(my_set)

Both will output:

{1, 2, 3, 4, 5}

Duplicate Elements

Duplicate elements in a set are automatically removed.

my_set = {1, 2, 2, 3, 3, 4, 5, 5}
print(my_set)  # Output: {1, 2, 3, 4, 5}

Mixed Data Types in Sets

Sets can contain different data types including numbers, strings, and tuples (if immutable).

mixed_set = {1, 'hello', (1, 2, 3)}
print(mixed_set)

Adding Elements

Use the add() method to add elements. Adding a duplicate element has no effect.

my_set = {1, 2, 3}
my_set.add(4)
print(my_set)  # Output: {1, 2, 3, 4}

Removing Elements

Use remove() to remove an element (raises error if not found) or discard() to remove safely.

my_set = {1, 2, 3, 4}
my_set.remove(3)
print(my_set)  # Output: {1, 2, 4}

my_set.discard(5)  # No error if element not present
print(my_set)      # Output: {1, 2, 4}

Membership Testing

my_set = {1, 2, 3, 4}
if 2 in my_set:
    print("2 is present in the set")
else:
    print("2 is not present in the set")

Output:

2 is present in the set

Set Operations

  • Union: Combines elements from both sets: set1 | set2 or set1.union(set2)
  • Intersection: Elements common to both sets: set1 & set2 or set1.intersection(set2)
  • Difference: Elements in one but not the other: set1 - set2 or set1.difference(set2)
  • Symmetric Difference: Elements in either set but not both: set1 ^ set2 or set1.symmetric_difference(set2)

Set Comprehensions

Create sets using comprehensions similarly to list comprehensions, but with curly braces.

squared_set = {x**2 for x in range(1, 6)}
print(squared_set)  # Output: {1, 4, 9, 16, 25}

even_set = {x for x in range(1, 11) if x % 2 == 0}
print(even_set)  # Output: {2, 4, 6, 8, 10}

Nested Set Comprehensions

nested_set = {(x, y) for x in range(1, 3) for y in range(1, 3)}
print(nested_set)  # Output: {(1, 1), (1, 2), (2, 1), (2, 2)}

Frozen Sets

A frozen set is an immutable set. It cannot be modified after creation.

my_frozen_set = frozenset([1, 2, 3])
print(my_frozen_set)  # Output: frozenset({1, 2, 3})
my_frozen_set.add(4)  # Raises AttributeError

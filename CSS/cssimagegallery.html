CSS - Icons

Icons are powerful visual elements in web design. They replace lengthy text labels with small graphics that are instantly recognizable, such as a magnifying glass for search or a trash can for delete. CSS provides multiple ways to add, style, and customize icons in a webpage.

Why Use Icons?

  • Improved Usability: Icons guide users quickly without reading text.
  • Visual Appeal: They make designs attractive and professional.
  • Lightweight: CSS icons or SVGs reduce load compared to images.
  • Responsive: Icons can scale smoothly on all devices.
  • Customizable: Developers can change size, color, and alignment using CSS rules.

Different Ways to Add Icons

  • Using inline SVG
  • Using icon fonts like Font Awesome
  • Using background images
  • Using pseudo-elements (::before and ::after)
  • Using Google Material Icons
  • Using Bootstrap Glyphicons

Example 1: Icons Using SVG

SVG icons are vector-based, meaning they are resolution independent. You can create complex icons with precise shapes using the <svg> element.

<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24">
  <path d="M23.707 22.293l-6.364-6.364..."/>
</svg>

Exercise: Try changing the viewBox and path values to design your own shape. For instance, create a simple circle or a star.

Example 2: Icons Using Icon Fonts

Font libraries such as Font Awesome provide thousands of ready-to-use icons. You only need to include their CDN link and call classes.

<link rel="stylesheet" 
      href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.0.0-beta3/css/all.min.css">

<i class="fas fa-search"></i>
<i class="fas fa-download"></i>
<i class="fas fa-cloud"></i>
<i class="fas fa-home"></i>

Exercise: Replace fa-home with another Font Awesome class like fa-user or fa-car and observe the change.

Example 3: Icons Using Background Images

Images can be set as icons using CSS background-image. This is useful when you want custom image-based icons.

<div class="icon-img"></div>

Exercise: Replace the image path with a different file and adjust background-size for scaling.

Example 4: Icons Using Pseudo-Elements

Pseudo-elements ::before and ::after can generate content before or after elements. This technique allows adding icons without extra HTML.

<ul>
  <li>Butterscotch</li>
  <li>Chocolate</li>
  <li>Coconut</li>
</ul>

<p>Paragraph with icon after text.</p>

Exercise: Add different icons before each list item by changing the content property to other symbols or Unicode values.

Example 5: Icons Using Google Icons

Google offers free Material Icons. Just include their stylesheet link and use the material-icons class with the icon name.

<link rel="stylesheet" 
      href="https://fonts.googleapis.com/icon?family=Material+Icons">

<span class="material-icons">pets</span>
<span class="material-icons">settings</span>
<span class="material-icons">attachment</span>
<span class="material-icons">person</span>

Exercise: Try replacing pets with other names like alarm, camera, or shopping_cart.

Python - Exception Handling

Introduction

Exception handling in Python refers to managing runtime errors that may occur during the execution of a program. These exceptions can arise from division by zero, accessing a missing file, or performing operations on incompatible data types.

Python provides mechanisms to deal with such errors gracefully:

What is an Exception?

An exception is an event that disrupts the normal flow of program execution. It is represented by a Python object and raised when something unexpected occurs. If not handled, the program terminates. Handled properly, the program can continue smoothly.

Exception Handling Syntax

try:
    # Code that may cause an exception
    ...
except ExceptionI:
    # Handle ExceptionI
except ExceptionII:
    # Handle ExceptionII
else:
    # Executes if no exception occurs

Key points about the try-except-else syntax:

  • A single try block can have multiple except clauses.
  • A generic except clause can catch any exception.
  • An optional else block runs only if no exceptions occur.

Examples

File Handling Example

try:
    fh = open("testfile", "w")
    fh.write("This is my test file for exception handling!!")
except IOError:
    print("Error: can't find file or read data")
else:
    print("Written content in the file successfully")
    fh.close()

Expected Output:

  • If file opens successfully: Written content in the file successfully
  • If file access fails: Error: can't find file or read data

The finally Clause

The finally block runs regardless of whether an exception occurs. It is typically used for cleanup tasks such as closing files or releasing resources. 

try:
    fh = open("testfile", "w")
    fh.write("Testing exception handling with finally block")
finally:
    print("Closing resources or performing cleanup")

Raising Exceptions

You can create and raise exceptions using the raise statement. Python also allows custom user-defined exceptions by inheriting from built-in classes. 

class NetworkError(RuntimeError):
    def __init__(self, arg):
        self.args = arg

try:
    raise NetworkError("Bad hostname")
except NetworkError as e:
    print(e.args)

Standard Exceptions

Python provides many built-in exceptions. Some common ones include:

  • ZeroDivisionError − Division by zero occurs.
  • ValueError − Invalid value passed to a valid datatype.
  • IOError − Input-output operation failure.
  • AttributeError − Invalid attribute reference.
  • TypeError − Operation applied to an object of inappropriate type.

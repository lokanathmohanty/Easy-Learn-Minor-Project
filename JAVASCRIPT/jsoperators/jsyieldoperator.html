JavaScript - Yield Operator

The yield operator in JavaScript is used to pause and resume the generator function asynchronously. Generator functions are special functions that can be paused or resumed during execution. They are defined using the function* syntax. The yield keyword can only be used inside a generator function.

The yield operator pauses the execution of the generator function and returns its operand (expression) to the generator’s caller.

Syntax

The syntax of the yield operator in JavaScript is:

yield expression;

Parameter

expression – The value to yield from the generator function via the iterator protocol. If omitted, undefined is yielded.

Return Value

It returns the optional value passed to the generator’s next() method to resume execution.

Yield Operator in Generator Function

When a generator function is called, it returns a generator object. Calling the next() method on this object resumes execution until a yield is encountered, which pauses the execution and returns the value after yield to the caller.

The next() method returns an iterator object with two properties: value (the yielded value) and done (a boolean indicating completion).

Example: Basic Generator Function

function* test() {
    console.log("I'm before yield expression");
    yield 20;
}
const genObj = test();
console.log(genObj.next());

Output:

I'm before yield expression
{ value: 20, done: false }

Example: Returning Multiple Values

function* test() {
    yield 20;
    yield [1,2,3];
    yield "Hello World";
}
let res = test();
console.log(res.next());
console.log(res.next());
console.log(res.next());
console.log(res.next());

Output:

{ value: 20, done: false }
{ value: [ 1, 2, 3 ], done: false }
{ value: 'Hello World', done: false }
{ value: undefined, done: true }

Example: Returning Undefined

function* test() {
    yield;
}
let res = test();
console.log(res.next());
console.log(res.next());

Output:

{ value: undefined, done: false }
{ value: undefined, done: true }

Example: Passing a Value to next()

function* test() {
    let result = yield 20;
    console.log("default value passed to next() method " + result);
}
let res = test();
console.log(res.next());
console.log(res.next(30));

Output:

{ value: 20, done: false }
default value passed to next() method 30
{ value: undefined, done: true }

Example: Yield in a Loop

function* test() {
    for (let p = 0; p < 6; p += 2) {
        yield p;
    }
}
let res = test();
console.log(res.next());
console.log(res.next());
console.log(res.next());
console.log(res.next());

Output:

{ value: 0, done: false }
{ value: 2, done: false }
{ value: 4, done: false }
{ value: undefined, done: true }

Use Cases

The yield operator is commonly used for:

  • Asynchronous operations
  • Lazy evaluations
  • Task scheduling
  • Iterating through large datasets
  • Creating custom iterators

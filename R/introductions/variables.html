R - Variables

A variable provides named storage that programs can manipulate. In R, a variable can store an atomic vector, a group of atomic vectors, or multiple R objects combined. Valid variable names consist of letters, numbers, dots (.) or underscores (_), and must start with a letter or a dot not followed by a number.

Variable Name Validity Reason
var_name2. Valid Contains letters, numbers, dot, and underscore
var_name% Invalid Contains character '%', only dot(.) and underscore allowed
2var_name Invalid Starts with a number
.var_name, var.name Valid Start with dot(.) not followed by a number
.2var_name Invalid Dot followed by a number
_var_name Invalid Starts with underscore, not allowed

Variable Assignment

Variables can be assigned values using leftward (<-), rightward (->), or equal to (=) operators. Values can be printed using print() or cat() functions. The cat() function concatenates multiple items into continuous output. 

# Assignment using equal operator
var.1 = c(0, 1, 2, 3)

# Assignment using leftward operator
var.2 <- c("learn", "R")

# Assignment using rightward operator
c(TRUE, 1) -> var.3

print(var.1)
cat("var.1 is ", var.1, "\n")
cat("var.2 is ", var.2, "\n")
cat("var.3 is ", var.3, "\n")

Output: 

[1] 0 1 2 3
var.1 is 0 1 2 3 
var.2 is learn R 
var.3 is 1 1

Note: The vector c(TRUE,1) mixes logical and numeric types; logical TRUE is coerced to numeric 1.

Data Type of a Variable

R is dynamically typed, so variables take the data type of the assigned object and can change type whenever reassigned. 

var_x <- "Hello"
cat("The class of var_x is ", class(var_x), "\n")

var_x <- 34.5
cat("Now the class of var_x is ", class(var_x), "\n")

var_x <- 27L
cat("Next the class of var_x becomes ", class(var_x), "\n")

Output: 

The class of var_x is character
Now the class of var_x is numeric
Next the class of var_x becomes integer

Finding Variables

To list all variables currently available in the workspace, use the ls() function. You can filter variables with a pattern. 

print(ls())

Sample output: 

[1] "my var" "my_new_var" "my_var" "var.1" "var.2" "var.3" "var.name" "var_name2." "var_x" "varname"

To list variables starting with "var": 

print(ls(pattern = "var"))

To list hidden variables starting with dot(.) use the argument all.names = TRUE: 

print(ls(all.names = TRUE))

Deleting Variables

Variables can be deleted using the rm() function: 

rm(var.3)
print(var.3)  # Throws error: object not found

To delete all variables: 

rm(list = ls())
print(ls())  # Outputs character(0)

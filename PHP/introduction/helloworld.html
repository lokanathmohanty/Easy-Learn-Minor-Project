PHP "Hello World" Program Guide

The "Hello World" program is the traditional first step in learning a new language, serving to **verify that your PHP environment is installed and working correctly**. Since PHP is a **server-side scripting language**, the code must be processed by a web server and the PHP module.

Setup: The Web Server Document Root

To be accessible via a web browser, the PHP code must be placed inside the web server's **document root** directory.

  • **Server Requirement:** This guide assumes the use of an all-in-one package like **XAMPP**. The Apache server must be started via the XAMPP control panel.
  • **Document Root Location:**
    • **Windows (XAMPP):** Typically `C:\xampp\htdocs\`
    • **Linux (XAMPP):** Typically `/opt/lamp/htdocs/`

Steps to Run "Hello World" in Browser

  1. **Create Script:** Create a new file named `hello.php` inside the document root folder (`htdocs`).
  2. **Add Code:** Open `hello.php` in a text editor and enter the following canonical PHP code:
    <?php
       echo "Hello World!";?>
  3. **Execute:** Open your web browser and navigate to the URL:

    http://localhost/hello.php

  4. **Output:** The browser will display the text: "Hello World!"

Mixing HTML and PHP

PHP is designed to be embedded directly into HTML. The `echo` statement sends its output directly to the browser as part of the HTML document.

Example: Embedding in an HTML Page

<!DOCTYPE html><html><body>
   <h1>My PHP Website</h1>
   <?php
      echo "Hello World!";
   ?>
</body></html>

Example: Outputting HTML Tags

You can include HTML tags directly within the string passed to the `echo` statement, and the browser will interpret them normally.

<?php
   echo "<h1 align='center'>Hello World!</h1>";?>

Running PHP from Command Prompt (CLI)

PHP scripts can also be executed without a web server using the **Command Line Interface (CLI)**, provided the PHP executable path (`php.exe`) is added to the system's PATH environment variable.

**Command:** C:\xampp\htdocs>php hello.php
**Output:** Hello PHP!!!!!

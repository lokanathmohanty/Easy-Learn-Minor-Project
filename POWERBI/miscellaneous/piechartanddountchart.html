Power BI - Pie Chart and Donut Chart

What is a Pie Chart?

A pie chart is a circular visual divided into colorful slices that represent portions of a whole. It is ideal for showcasing proportional data, such as sales distribution across regions. Power BI offers several formatting options for customizing the appearance and details of pie charts.

How to Generate a Pie Chart in Power BI?

  1. Load the Excel sheet (e.g., Sheet1) into Power BI. The dataset should include columns like Department, Employee ID, Name, New joiners, and Total number of employees in a Department.
  2. Select the Pie Chart from the Visualizations pane and resize it on the canvas.
  3. Drag the Department column into the Legend section, and the Total number of employees in a Department into the Values section.
  4. Drag Employee ID into the Details section and Name into the Tooltips section to enhance interactivity.
  5. Hovering over a slice reveals department details, employee information, and total employees in that segment.
  6. Click the Format visual button to customize the chart. You will find options like Legend, Slices, Detail Labels, and Rotation under the Visual tab.
  7. To reposition the legend, expand the Legend > Options and choose a new position (e.g., Center right).
  8. Customize text under the Text label by setting Font to Tahoma, Size to 21, Color to Orange, and Italic style.
  9. Modify slice colors by expanding the Slices > Colors section and changing each one as needed.

Donut Chart Visual in Power BI

The Donut Chart is a circular chart like a Pie Chart, but with a hole in the center. It’s useful for visualizing proportions while also providing a central space for additional data labels or values. It helps users analyze how each subset contributes to the whole.

Counting Employees in Distinct Departments

  1. Use a dataset named Dept_employee that contains fields like Department and Name.
  2. Switch to the Report View and select the Donut Chart visual.
  3. Drag Name into the Values section and Department into the Details section. The chart will display department-wise employee distribution.

To Count the Number of Active Users

  1. Load a dataset (e.g., Sheet2) containing software names and active user counts.
  2. In the Report Editor, select the Donut Chart visual.
  3. Drag the Active Users Account column into both the Values and Details sections. Each section will show the number and percentage of active users.
  4. To display only the number of users (not percentages), go to Format Your Visual, open the Details section, and select Data Value.
  5. To enhance readability, expand the Values section and set the font size to 30.

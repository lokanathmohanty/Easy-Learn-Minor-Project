Java Nashorn JavaScript Engine

Introduction to Nashorn (Java 8)

Nashorn is a high-performance **JavaScript engine** that was introduced in **Java 8** to replace the older Rhino engine. It is significantly faster (2 to 10 times) than its predecessor due to its ability to directly compile JavaScript code into **Java bytecode** in memory and by leveraging the dynamic features introduced in Java 7.

The Nashorn engine facilitates seamless interoperability between Java and JavaScript, allowing developers to:

  • Execute standalone JavaScript files and snippets using command-line tools.
  • Embed JavaScript logic within Java applications.
  • Call Java methods and use Java objects directly from JavaScript code, and vice versa.

Executing JavaScript via Command Line: jjs

Java 8 introduced the **jjs** command-line tool specifically for the Nashorn engine. jjs is a versatile tool used to interpret and execute JavaScript code.

Interactive Session

By typing jjs and pressing Enter, users can enter an interactive session to execute JavaScript code snippets directly. The session is closed by typing quit().

Executing a File

The jjs tool can execute a JavaScript file directly, interpreting all statements and functions within it.

Command: jjs sample.js

Passing Arguments

Arguments passed to the jjs command after -- are stored in a special JavaScript construct called **arguments** and can be accessed within the script.

Interoperability: Java and JavaScript

Calling JavaScript from Java

The Java API for executing script code remains the same as its predecessor, utilizing the **Scripting API** (javax.script package):

  • The **ScriptEngineManager** is used to locate and load the Nashorn engine instance using the name "nashorn".
  • The loaded **ScriptEngine**'s **eval(String script)** method executes the JavaScript code snippet.
  • Java variables can be passed into the JavaScript code, and results from JavaScript expressions can be cast back to Java types.

Calling Java from JavaScript

Within a Nashorn environment (like jjs or embedded code), Java classes can be accessed and utilized just like native JavaScript objects:

  • The **Java.type('fully.qualified.ClassName')** function is used to load a specific Java class (e.g., java.math.BigDecimal).
  • Once loaded, the JavaScript code can instantiate the Java class (new BigDecimal(...)) and call its static and instance methods.
  • This capability allows complex or specialized Java library functions to be easily integrated into JavaScript logic.

Example: Calling Java from JavaScript

Using the Java.type function to import and use the java.math.BigDecimal class to perform precise arithmetic:

// In sample.js
// Load the specific Java class
var BigDecimal = Java.type('java.math.BigDecimal');

function calculate(amount, percentage) {
   // Use BigDecimal methods (multiply, divide, etc.)
   var result = new BigDecimal(amount)
      .multiply(new BigDecimal(percentage))
      .divide(new BigDecimal("100"), 2, BigDecimal.ROUND_HALF_EVEN);
   
   return result.toPlainString();
}

var result = calculate(568000000000000000023, 13.9);
print(result);

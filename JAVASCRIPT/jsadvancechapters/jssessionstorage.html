JavaScript - SessionStorage

Introduction

The sessionStorage object in JavaScript is a property of the window object that stores data for the lifetime of a browser tab session. Each tab has its own session storage that is cleared when the tab is closed. Data stored here is specific to the protocol, hostname, and port.

It is useful for temporarily storing user-related data such as form input, UI preferences, or other session-based state information.

Syntax


window.sessionStorage;

Methods of SessionStorage

  • setItem(key, value) → Stores a value under the given key.
  • getItem(key) → Retrieves the value associated with the given key.
  • removeItem(key) → Deletes a specific item from session storage.
  • key(index) → Returns the name of the key at the specified index.
  • clear() → Removes all data from session storage.

Why Use SessionStorage?

  • Save the web-page interface state and restore it later in the same session.
  • Transmit data between pages without using hidden inputs or URL parameters.
  • Keep user-specific data persistent across reloads but temporary within the tab session.

Key Features

  • Temporary Storage → Cleared when the tab or window is closed.
  • Tab-specific → Not shared across tabs.
  • Persistent During Reloads → Data survives page reloads within the same tab.
  • Simple API → Easy to use methods for storing and retrieving data.
  • Storage Limit → Typically around 5MB per origin.

Examples

Example 1: Storing and Retrieving Objects


<html>  
<body>  
   <h4>Display Data Using sessionStorage in JavaScript</h4>  
   <p id="displayStudent"></p>  
   <p id="displayTutorial"></p>  

   <script>  
      const studentInfo = {  
         name: 'Amit',  
         rollNumber: 41,  
         website: 'Tutorialspoint',  
         learningMode: 'online',  
         age: 20,  
         subject: 'JavaScript'  
      };  

      const tutorialInfo = {  
         subject: 'JavaScript',  
         website: 'Tutorialspoint',  
         mode: 'online',  
         cost: 'Free',  
         targetAudience: 'students and beginners'  
      };  

      // Store data
      sessionStorage.setItem("studentInfo", JSON.stringify(studentInfo));  
      sessionStorage.setItem("tutorialInfo", JSON.stringify(tutorialInfo));  

      // Retrieve data
      document.getElementById('displayStudent').innerText = sessionStorage.getItem('studentInfo');  
      document.getElementById('displayTutorial').innerText = sessionStorage.getItem('tutorialInfo');  
   </script>  
</body>  
</html>

Example 2: Saving and Displaying Date & Time


<html>  
<body>  
   <h4> Display Data Using sessionStorage in JavaScript </h4>  
   <p id="displayStudentInfo"></p>  
   <p id="displayCurrentTime"></p>  

   <script>  
      const learnerDetails = {  
         name: 'Amit',  
         rollNumber: 52,  
         website: 'TutorialsPoint',  
         learningMode: 'online mode',  
         age: 22,  
         subject: 'JavaScript'  
      };  

      // Store student info
      sessionStorage.setItem("learnerDetails", JSON.stringify(learnerDetails));  

      // Display student info
      document.getElementById('displayStudentInfo').innerText = sessionStorage.getItem('learnerDetails');  

      // Store current time
      sessionStorage.setItem("currentDateTime", new Date());  

      // Display current time
      document.getElementById('displayCurrentTime').innerText = sessionStorage.getItem('currentDateTime');  
   </script>  
</body>  
</html>

Example 3: Interactive Session Storage Demo


<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Session Storage Example</title>
</head>
<body>
   <h1>Session Storage Demo</h1>
   <label for="name">Enter your name:</label>
   <input type="text" id="name" />
   <button onclick="saveName()">Save Name</button>
   <button onclick="showName()">Show Name</button>
   <button onclick="clearName()">Clear Name</button>
   <p id="result"></p>

   <script>
      function saveName() {
         let name = document.getElementById('name').value;
         sessionStorage.setItem('userName', name);
         document.getElementById('result').innerText = 'Name saved in session storage!';
      }
      function showName() {
         let name = sessionStorage.getItem('userName');
         if (name) {
            document.getElementById('result').innerText = 'Stored Name: ' + name;
         } else {
            document.getElementById('result').innerText = 'No name found in session storage!';
         }
      }
      function clearName() {
         sessionStorage.removeItem('userName');
         document.getElementById('result').innerText = 'Name cleared from session storage!';
      }
   </script>
</body>
</html>

Summary

  • sessionStorage stores data only for a single browser tab session.
  • Data persists across page reloads but is cleared when the tab is closed.
  • Use its methods (setItem, getItem, removeItem, clear) to manage stored data.

Python - Metaclasses

Metaclasses are a powerful feature in Python that allow customization of class creation. They enable adding specific behaviors, attributes, and methods to classes, providing flexibility and supporting metaprogramming.

Metaclasses are an OOP concept present by default in all Python code. Python uses type as the default metaclass, whose instances are classes. Any Python class is an instance of some metaclass.

Creating Metaclasses in Python

A metaclass defines how a class behaves. By default, Python uses type() to construct classes unless otherwise specified. The class body is executed in a new namespace, and the result is assigned to the class name via type(name, bases, namespace). 

class Demo:
   pass
   
obj = Demo()
print(obj)

Output example:

<__main__.Demo object at 0x7fe78f43fe80>

This shows obj is an instance of the Demo class.

Creating Metaclasses Dynamically

# Creating a class dynamically using type()
DemoClass = type('DemoClass', (), {})
obj = DemoClass()
print(obj)

Output example:

<__main__.DemoClass object at 0x7f9ff6af3ee0>

This creates a class dynamically with no bases or attributes.

Metaclasses with Inheritance

class Demo:
   pass

Demo2 = type('Demo2', (Demo,), dict(attribute=10))
obj = Demo2()

print(obj.attribute)
print(obj.__class__)
print(obj.__class__.__bases__)

Output example:

10

(<class '__main__.Demo'>,)

This shows inheritance and attribute assignment during dynamic class creation.

Customizing Metaclass Creation

You can customize how classes are created by defining your own metaclass. Overriding the __new__ and __init__ methods lets you modify class creation and initialization behavior. 

class MyMetaClass(type):
   def __new__(cls, name, bases, dct):
      dct['version'] = 1.0
      name = 'Custom' + name
      return super().__new__(cls, name, bases, dct)

class Demo(metaclass=MyMetaClass):
   pass

obj = Demo()
print("Class Name:", type(obj).__name__)
print("Version:", obj.version)

Output example:

Class Name: CustomDemo
Version: 1.0

Another Customization Example Using __init__

class MyMetaClass(type):
   def __init__(cls, name, bases, dct):
      print('Initializing class', name)
      cls.version = 10
      super().__init__(name, bases, dct)

class MyClass(metaclass=MyMetaClass):
   def __init__(self, value):
      self.value = value

   def display(self):
      print(f"Value: {self.value}, Version: {self.__class__.version}")

obj = MyClass(42)
obj.display()

Output example:

Initializing class MyClass
Value: 42, Version: 10

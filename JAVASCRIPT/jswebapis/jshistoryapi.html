JavaScript - History API

Web History API

In JavaScript, the History API allows us to access the browser's history. It can be used to navigate through the history.

The History API provides methods to manipulate the window.history object, which contains the array of visited URLs in the current session.

It is a powerful tool to create useful effects. For example, we can implement history-based undo/redo systems.

How to use JavaScript History API?

The History API is simple to use. It includes a few methods and a property:

  • back() − Navigates back to the previous page in the history.
  • forward() − Navigates forward to the next page in the history.
  • go() − Navigates to a specific page in the history using a relative position.
  • length − Returns the number of pages in the history list.

Syntax

// Load the previous URL
history.back();

// Load the next URL
history.forward();

// Load a specific page by relative position
history.go(-2); // 2 pages back
history.go(2);  // 2 pages forward

// Get the length of history list
const length = history.length;

Loading Previous Page in History List

The back() method loads the immediate previous page, while go() can load any previous page.

Example: Using back() method to load previous page

<html>
<body>
    <p>Click "Load Previous Page" button to load previous visited page</p>
    <button onclick="goback()">Load Previous Page</button>
    <p id="output"></p>
    <script>
        function goback() {
            history.back();
            document.getElementById("output").innerHTML += 
            "You will have gone to previous visited page if it exists";
        }
    </script>
</body>
</html>

Example: Using go() method to load the previous page

<html>
<body>
    <p>Click the button to load 2nd previous visited page</p>
    <button onclick="moveTo()">Load 2nd Previous Page</button>
    <p id="output"></p>
    <script>
        function moveTo() {
            history.go(-2);
            document.getElementById("output").innerHTML = 
            "You will have forwarded to 2nd previous visited page if it exists.";
        }
    </script>
</body>
</html>

Get the Length of the History List

The length property returns the total number of visited pages in the session.

Example

    <script>
        const output = document.getElementById("output");
        function moveTo() {
            output.innerHTML = history.length;

    </script>

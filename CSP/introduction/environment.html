C# Environment Setup and Tools

The .NET Framework and C#

C# is part of the **.NET Framework**, a platform used for writing multi-platform applications like **Windows applications**, **Web applications**, and **Web services**.

The .NET Framework's design allows it to be accessed by multiple languages (C#, C++, Visual Basic, etc.) and enables communication between them.

Key components of the .NET Framework include:

  • Common Language Runtime (CLR)
  • The .Net Framework Class Library
  • Common Language Specification (CLS) and Common Type System (CTS)
  • Metadata and Assemblies
  • Windows Forms, ASP.Net, ADO.Net, WPF, WCF, and LINQ

Integrated Development Environments (IDEs)

Microsoft provides several development tools for C# programming:

  • Visual Studio (VS): Full-featured IDE for C# development.
  • Visual Studio Code (VS Code): Lightweight and cross-platform editor.
  • **JetBrains Rider:** An advanced C# IDE.

Older or express tools mentioned include Visual C# 2010 Express and Visual Web Developer, which are trimmed-down, free versions of Visual Studio.

Cross-Platform Development (Example)

Although the original .NET Framework runs on Windows, **Mono** is an open-source alternative that includes a C# compiler and runs on operating systems like **Linux**, **Mac OS**, Android, iOS, and UNIX. Mono aims to run Microsoft .NET applications cross-platform.

Essential Setup Steps

Step 1: Installing .NET SDK

The **.NET SDK (Software Development Kit)** is mandatory. It contains the **C# Compiler (csc.exe)**, the **.NET CLI**, and the **.NET Runtime**. You can verify the installation by running dotnet --version in your terminal.

Step 2 & 3: Code Editor Setup

Choose an editor (VS Code is recommended for cross-platform) and install necessary extensions, like the **C# Dev Kit** in VS Code.

Step 4 & 5: Creating and Running a Project

Use the .NET CLI commands to start a project:

dotnet new console -o MyCSharpApp
dotnet run

Online editors are also available for running C# without installing the SDK.

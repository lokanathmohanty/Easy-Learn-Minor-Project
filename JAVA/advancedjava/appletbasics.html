Java Applet Basics

An applet is a Java program that runs inside a web browser with full access to the Java API. Unlike standalone applications, applets extend the java.applet.Applet class and do not have a main() method.

Applets are embedded within HTML pages, downloaded to the user's machine, and run in a JVM hosted by the browser or as a separate runtime. They operate under sandbox security rules to restrict harmful actions.

  • Applets use lifecycle methods like init(), start(), stop(), destroy(), and paint().
  • Applets interact with browsers, fetching parameters and resources through the Applet class API.

Simple Hello World Applet Example

import java.applet.*;
import java.awt.*;

public class HelloWorldApplet extends Applet {
   public void paint(Graphics g) {
      g.drawString("Hello World", 25, 50);
   }
}

This applet overrides only the paint() method to display "Hello World" inside the applet area.

Embedding Applet in HTML

Use the <applet> tag to embed an applet in HTML, specifying the class, width, and height:

<html>
  <title>The Hello, World Applet</title>
  <hr>
  <applet code="HelloWorldApplet.class" width="320" height="120">
    If your browser was Java-enabled, a "Hello, World" message would appear here.
  </applet>
  <hr>
</html>

Parameters can be passed into applets using the <param> tag within <applet>.

Applet Lifecycle Methods

  • init(): Initialization, called once after parameters are processed.
  • start(): Called after init() and when the user returns to the page.
  • stop(): Called when the user leaves the page.
  • destroy(): Called when the browser shuts down.
  • paint(): Called to render graphics.

Event Handling in Applets

Applets can handle events like mouse clicks by implementing listeners such as MouseListener and overriding event methods:

public class ExampleEventHandling extends Applet implements MouseListener {
   public void init() {
      addMouseListener(this);
      ...
   }

   public void mouseClicked(MouseEvent event) {
      // Respond to mouse click
   }
   // other mouse event methods...
}

Displaying Images and Playing Audio

Images can be loaded and drawn with drawImage() from the Graphics class, and audio can be played using the AudioClip interface from the java.applet package.

Examples exist to load and display images or play looping audio fetched via applet parameters.

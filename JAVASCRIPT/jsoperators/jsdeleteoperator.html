JavaScript - Delete Operator

The JavaScript delete operator deletes/removes a property from an object. It removes the property as well as its value. It works only with objects, not with variables or functions.

Since arrays in JavaScript are objects, you can use the delete operator to delete an element at a specific index. However, methods like pop(), slice(), or shift() are often used instead.

Syntax

To delete an object property:

  • delete obj.property;
  • delete obj["property"];

Return value: The operator returns true if the property is deleted, or false otherwise. Deleting a non-existent property still returns true.

To delete an array element:

  • delete arr[index];

Deleting Object Properties

The delete operator can be used to remove a property from an object.

Example: Deleting an Object Property


const obj = {
   product: "Mobile",
   price: 20000,
   color: "Blue",
}
delete obj.price;
console.log(obj.price); // undefined

Output: The property price is deleted, and accessing it returns undefined.

Deleting a Nonexistent Property


const obj = {
   product: "Mobile",
   price: 20000
}
console.log(delete obj.color); // true

Output: true, but the object remains unchanged.

Deleting Array Elements

The delete operator removes an array element but leaves the index empty. The array length remains unchanged.


const arr = [10, 20, 30, 40, 50, 60];
delete arr[1];
console.log(arr);    // [10, empty, 30, 40, 50, 60]
console.log(arr[1]); // undefined

Deleting Predefined Objects

The delete operator can attempt to remove predefined objects like Math or Date, but this is not advisable.


console.log(delete Math.PI); // false
console.log(delete Math);    // true
console.log(Math);           // ReferenceError

Can't Delete Variables and Functions

The delete operator cannot remove variables or functions declared with var, let, or const.


var x = 10;
function fun() { return 20; }

console.log(delete x);   // false
console.log(delete fun); // false

However, variables declared without var, let, or const (implicitly global) can be deleted, since they are treated as properties of the window object.


x = 10;
console.log(delete x); // true
console.log(x);        // ReferenceError

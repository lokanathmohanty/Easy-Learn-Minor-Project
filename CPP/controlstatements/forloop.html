C++ for Loop (Repetition Control) ⚙️

The **for loop** is a repetition control structure designed for efficiently writing loops that need to execute a **specific number of times**. It consolidates the three loop control steps—initialization, condition testing, and iteration—into a single, compact statement.

Syntax and Flow of Control

The syntax organizes the loop's control logic within the parentheses:

for ( init; condition; increment ) {
   // Statement(s) to execute repeatedly
}

The execution follows a strict sequence:

  1. **init (Initialization):** Executed **once** at the beginning. Used to declare and set the starting value of the loop control variable.
  2. **condition (Test):** Evaluated **before** each iteration.
    • If **true**, the loop body executes.
    • If **false**, the loop terminates, and control jumps to the statement after the loop.
  3. **Loop Body:** Executes if the `condition` is true.
  4. **increment (Update):** Executed **after** the loop body. This updates the loop control variable (e.g., `a++`, `a = a + 1`, etc.).

Steps 2, 3, and 4 repeat until the `condition` is false.

Example Analysis (a starts at 10)

The loop is defined to start `a` at 10, run as long as `a < 20`, and increase `a` by 1 after each iteration.

for( int a = 10; // Init
     a < 20;    // Condition (run if true)
     a = a + 1  // Increment
   ) {
      cout << "value of a: " << a << endl;
   }

The loop executes for $a = 10, 11, \ldots, 19$. When $a$ becomes 20, the condition ($20 < 20$) fails, and the loop stops. The output shows the values of $a$ printed during the iterations:

value of a: 10
value of a: 11
...
value of a: 18
value of a: 19

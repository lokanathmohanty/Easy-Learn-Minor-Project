Next.js Dynamic Routing 🔗

What is Dynamic Routing?

**Dynamic Routing** is a powerful mechanism that allows you to create **flexible and reusable URLs** (routes) where part of the path is variable, based on data like a user ID, a product slug, or a post title. This is essential for applications that serve content from a database, such as blog posts or e-commerce product pages, where you cannot define every possible URL statically.

Implementing Standard Dynamic Routes

In Next.js (using the App Router), dynamic routes are created by naming a folder segment using **square brackets** (`[paramName]`) within the routing directory.

Route Definition:

  • **File Structure:** `app/products/[id]/page.tsx`
  • **Matches Paths:** `/products/1`, `/products/laptop`, etc.

Accessing Parameters:

The parameter is available in the component via the **`params`** prop (for Server Components) or the **`useParams()`** hook (for Client Components, as shown below).

// app/products/[id]/page.tsx (Client Component Example)
"use client"
import { useParams } from 'next/navigation';

export default function ProductPage() {
  const { id } = useParams(); // 'id' matches the folder name '[id]'
  return (<h1>Product {id}</h1>);
}

Catch-All Routes ([...slug])

**Catch-All Routes** are a special type of dynamic route that matches all subsequent segments of a URL path. This is useful for complex nested paths, like documentation pages or categorized content.

Implementation:

To implement a catch-all route, the dynamic folder name must start with **three dots** (`[...slug]`).

  • **File Structure:** `app/products/[...slug]/page.tsx`
  • **Matches Paths:** `/products/a`, `/products/a/b`, `/products/a/b/c`, etc.
  • **Parameter Output:** The value returned is an **array of strings**, where each string is a segment of the path.
// Accessing the array of segments in the params prop
export default function ProductPage({ params }: { params: { slug: string[] } }) {
  // If URL is /products/electronics/laptop, params.slug is ['electronics', 'laptop']
  const matchedSegments = params.slug?.join(' / ');
  
  return (
    <div>
      <h1>Product Page</h1>
      <p>Matched Segments: {matchedSegments || 'None'}</p>
    </div>
  );
}

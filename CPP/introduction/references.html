C++ References (&)

A **reference variable** in C++ is an **alias** (another name) for an **already existing variable**. Once a reference is initialized to a variable, both the variable name and the reference name refer to the **same memory location**. Any change made through the reference name affects the original variable, and vice-versa.

Creating References

A reference is declared by placing an ampersand (&) immediately after the type in the declaration.

Syntax:

DataType& reference_name = existing_variable;

Example:

int i = 17;
int& r = i; // r is a reference to i.

In the above example, r and i are interchangeable names for the same integer value stored in memory.

References vs. Pointers

References are often confused with pointers, but they are fundamentally different and have strict rules:

  • Initialization: A reference **must be initialized** when it is created. Pointers can be initialized later.
  • Re-assignment: Once a reference is initialized to an object, it **cannot be changed** to refer to another object (it is fixed to its initial target). Pointers can be re-pointed at any time.
  • Null Value: You **cannot have NULL references**. A reference is always guaranteed to be bound to a legitimate piece of storage.

Primary Use Cases of References

References are mostly used in the context of functions to avoid expensive copies of large objects.

1. References as Parameters (Pass-by-Reference):

This allows a function to modify the original variable passed from the caller, or to simply access large objects efficiently without creating a copy (often called **pass-by-const-reference** for read-only access).

2. References as Return Values:

A function can return a reference to a variable. This allows the function call to be used on the left side of an assignment, effectively modifying the variable that was returned.

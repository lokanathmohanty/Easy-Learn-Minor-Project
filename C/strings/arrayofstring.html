Array of Strings in C

What is an Array of Strings?

An array of strings in C is a two-dimensional array where each row represents a null-terminated string. It allows storing multiple strings indexed by their position in the array.

Declaration and Initialization

To declare an array of strings, define a 2D char array specifying number of strings and max length of each string:

char strings[no_of_strings][max_length];

Example:


char langs[10][15] = {
  "PYTHON", "JAVASCRIPT", "PHP",
  "NODE JS", "HTML", "KOTLIN", "C++",
  "REACT JS", "RUST", "VBSCRIPT"
};

Memory Considerations

Each character occupies 1 byte, so total memory equals rows × columns. Strings shorter than max length have unused space after the null character.

Using an Array of Pointers

To save memory, use an array of pointers to strings instead of a 2D array. Each pointer refers to a separately allocated string. 


char *langs[10] = {
  "PYTHON", "JAVASCRIPT", "PHP",
  "NODE JS", "HTML", "KOTLIN", "C++",
  "REACT JS", "RUST", "VBSCRIPT"
};

String Operations

  • Printing strings using printf("%s") in a loop.
  • Finding longest string using strlen() function.
  • Sorting strings with strcmp() and swapping using strcpy().

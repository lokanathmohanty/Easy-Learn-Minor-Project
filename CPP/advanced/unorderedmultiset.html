C++ std::unordered_multiset 🧱

The **std::unordered_multiset** is an **Associative Container** from the C++ Standard Template Library (STL). It is defined in the <unordered_set> header file.

  • **Unordered:** Elements are stored in an **unspecified order** based on their hash value, offering fast access.
  • **Multiset:** It **allows duplicate values** (multiple occurrences of the same element).
  • **Implementation:** It is implemented using a **hash table**.

Syntax

#include <unordered_set>
std::unordered_multiset<Type> container_name;

***Example:*** `unordered_multiset<int> ums = {1, 2, 3, 3};`

Time Complexity and Performance

Because it uses a **hash table**, unordered_multiset offers highly efficient performance for core operations:

  • **Average Time Complexity (Best Case):** $\text{O}(1)$ for insertion (`insert`), deletion (`erase`), and lookup (`find`, `count`).
  • **Worst Time Complexity (Due to Hash Collisions):** $\text{O}(n)$, as the operation degrades to a linear search within a single bucket.

Key Member Functions

FunctionPurposeNote on Duplicates
**insert(elem)**Adds one or more elements.Always adds the element, regardless of existing duplicates.
**find(elem)**Returns an iterator to the **first occurrence** of the element, or `end()` if not found.Only points to one instance if duplicates exist.
**count(elem)**Returns the **number of occurrences** of the specified element.Returns $\ge 1$ for duplicates.

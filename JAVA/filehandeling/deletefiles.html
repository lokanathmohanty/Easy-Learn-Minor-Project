Java - Delete File

Java offers a straightforward way to delete files using the File.delete() method from the java.io.File class. This method attempts to remove a file or an empty directory at the given path, returning true if deletion succeeds and false otherwise.

Deleting a File

To delete an existing file, first create a File object and then call delete() after checking that the file exists:

File file = new File("C:/java/hello.txt");
if(file.exists()) {
   boolean success = file.delete();
   if (success) {
      System.out.println("The file has been successfully deleted.");
   } else {
      System.out.println("The file deletion failed.");
   }
} else {
   System.out.println("The file is not present.");
}

This process ensures you don't try to delete a file that is missing, and checks the result.

Deleting a Non-Existent File

If you attempt to delete a file that does not exist, delete() returns false:

File file = new File("test1.txt");
boolean success = file.delete();

if (success) {
   System.out.println("The file has been successfully deleted.");
} else {
   System.out.println("The file deletion failed.");
}

The output will indicate failure if test1.txt is not found.

Deleting All Files in a Directory

You can recursively delete all files within a directory by listing its contents and deleting each file individually:

public static void deleteFiles(File dirPath) {
   File filesList[] = dirPath.listFiles();
   for(File file : filesList) {
      if(file.isFile()) {
         file.delete();
      } else {
         deleteFiles(file);
      }
   }
}

File directory = new File("D:\\test");
deleteFiles(directory);
System.out.println("Files deleted.");

This approach will remove all files (and also recurse into subdirectories) within the specified directory.

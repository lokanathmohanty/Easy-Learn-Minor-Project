JavaScript - Object Constructors

An object constructor in JavaScript is a function that creates an instance of a class, which is typically called an object. A constructor is called when you declare an object using the new keyword. The purpose of a constructor is to create an object and set values if there are any object properties present.

There are two ways to create a template for the object in JavaScript:

  • Using a class
  • Using an object constructor

Whenever you need to create multiple objects with the same syntax, you require a template for the object. For example, if you are managing the car inventory, it is not efficient to create a new object every time using the object literal. In such cases, you can use object constructors. The main benefit of object constructors is that you can reuse the code.

Syntax

function Funcname(p1, p2, ... , pN) {
   this.prop1 = p1;
}
const obj = new Funcname(args);

In the above syntax:

  • Funcname() is a constructor function (you can replace it with any valid identifier).
  • p1, p2, ... , pN are parameters used inside the function body.
  • this represents the function context (the current instance of the object).

Example: Creating an object using a constructor function

function Tree() {
  this.name = "palm";
  this.age = 5;
}
const tree1 = new Tree();
console.log("name = " + tree1.name + ", age = " + tree1.age);

Output: name = palm, age = 5

Example: Constructor function with parameters

function Bike(name, speed, gear) {
  this.name = name;
  this.speed = speed;
  this.gear = gear;
}
const bike1 = new Bike("Honda", 100, 4);
const bike2 = new Bike("Yamaha", 200, 6);

console.log(bike1);
console.log(bike2);

Output:

  • The bike1 object is : {"name":"Honda","speed":100,"gear":4}
  • The bike2 object is : {"name":"Yamaha","speed":200,"gear":6}

Adding a Property or Method to a Constructor

The object constructor requires you to add the properties and methods while defining it. You cannot add them later directly to the constructor. For example:

function HouseAddress(no, street, city) {
  this.houseNo = no;
  this.street = street;
  this.city = city;

  this.getFullAddress = function () {
    return this.houseNo + ", " + this.street + ", " + this.city;
  };
}
const house = new HouseAddress(20, "Cooper Square", "New York");
console.log(house);
console.log(house.getFullAddress());

Output:

  • The house object is {"houseNo":20,"street":"Cooper Square","city":"New York"}
  • The full address of the house is 20, Cooper Square, New York

If you add a property like obj.prop = 20; it will only belong to that particular object, not the constructor.

JavaScript Object Prototype

Each object contains the prototype property by default. Since the constructor is also an object, you can add properties or methods to its prototype.

function Bike(name, speed, gear) {
  this.name = name;
  this.speed = speed;
  this.gear = gear;
}
Bike.prototype.BikeDetails = function () {
  return this.name + ", " + this.speed + ", " + this.gear;
};

const bike1 = new Bike("Honda", 100, 4);
const bike2 = new Bike("Yamaha", 200, 6);

console.log(bike1.BikeDetails());
console.log(bike2.BikeDetails());

Output:

  • The bike1 details is: Honda, 100, 4
  • The bike2 details is: Yamaha, 200, 6

Built-in Object Constructors in JavaScript

JavaScript provides several built-in constructors:

  • new Array() – To create an array
  • new String("Hello") – To create a string
  • new Number(92) – To create a number
  • new Boolean(true) – To create a boolean
  • new Set() – To create a set
  • new Map() – To create a map
  • new Object() – To create an object
  • new Function("x", "return x * x;") – To create a function
  • new Date() – To create a Date instance
  • new RegExp("\\d+") – To create a regular expression
  • new Error("new error.") – To create an error
  • Symbol("description") – To create a symbol

However, in most cases, it is preferable to use literal expressions (e.g., [] for arrays, {} for objects, " " for strings, etc.) when working with primitive values.

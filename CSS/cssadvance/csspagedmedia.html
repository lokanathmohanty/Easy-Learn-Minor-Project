CSS Paged Media

CSS paged media refers to a set of properties, @rules and pseudo-class selectors that are used for styling documents for printing.

CSS paged media provides additional features and properties specifically made for printed documents. With these properties we can control page breaks, margins, headers, footers, and more.

Some of the key properties of paged media are @page, orphans, widows, break-after, break-before, and break-inside.

Paged Media properties prevent uneven and awkward printing of webpages.

CSS Paged Media Related Properties

  • break-after: Used to forcefully break the page after a section in a print document.

    Example

    h2 {
    break-after: page;
}
  • break-before: Used to forcefully break the page before a section in a print document.

    Example

    h1 {
    break-before: page;
}
  • break-inside: Used to forcefully break the page or avoid breaking of page inside a section.

    Example

    div.chapter {
    break-inside: avoid;
}
  • orphans: Specify minimum number of lines placed at the bottom of a page when a whole paragraph cannot fit.

    Example

    p {
    orphans: 3;
}
  • widows: Specify minimum number of lines placed at the top of a page when a whole paragraph cannot fit.

    Example

    p {
    widows: 2;
}

CSS Paged Media @rules

  • @page: This is a media query, used to specify different CSS styles for printed pages.

    Example

    @page {
    margin: 2cm;
}

CSS Paged Media Pseudo-Classes

  • :first – Selects the first page of a document for styling separately.

    Example

    @page :first {
    margin-top: 5cm;
}
  • :left – Selects all the left-handed pages of a document for styling separately.

    Example

    @page :left {
    margin-left: 3cm;
}
  • :right – Selects all the right-handed pages of a document for styling separately.

    Example

    @page :right {
    margin-right: 3cm;
}

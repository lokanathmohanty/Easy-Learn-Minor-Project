JavaScript - Geolocation API

Geolocation API

The Geolocation API provides a JavaScript interface to access the user's geographical location data. It uses the device’s GPS, Wi-Fi, or network signals to detect location. Since location data is sensitive, browsers always ask for user permission before sharing it.

Real-time use cases include: ride-sharing apps, food delivery, location tagging, maps, and suggesting nearby places.

Real-time Use Cases

  • Get user’s coordinates and show them on a map.
  • Tag a user’s location on a photo.
  • Suggest nearby stores, petrol pumps, or restaurants.
  • Track product or food delivery location.
  • Pick up users from their current location in ride apps.

Using the Geolocation API

var geolocation = navigator.geolocation;

Example: Checking Browser Support

<html>
<body>
  <div id="output"></div>
  <script>
    const output = document.getElementById("output");
    if (navigator.geolocation) {
      output.innerHTML += "Geolocation is supported by your browser.";
    } else {
      output.innerHTML += "Geolocation is not supported by your browser.";
    }
  </script>
</body>
</html>

Geolocation Methods

  • getCurrentPosition() – Get current user location.
  • watchPosition() – Continuously track live location.
  • clearWatch() – Stop tracking a user’s location.

Location Properties

  • coords.latitude – Latitude in decimal degrees.
  • coords.longitude – Longitude in decimal degrees.
  • coords.altitude – Optional altitude in meters.
  • coords.accuracy – Accuracy of coordinates in meters.
  • coords.heading – Direction of movement (degrees).
  • coords.speed – Speed in meters per second.
  • timestamp – Time when location was retrieved.

Example: Getting User's Location

navigator.geolocation.getCurrentPosition(successCallback, errorCallback, options);
      
<html>
<body>
  <h3>Location Information</h3>
  <button onclick="findLocation()">Find Location</button>
  <p id="output"></p>
  <script>
    const output = document.getElementById("output");
    function findLocation() {
      if (navigator.geolocation) {
        navigator.geolocation.getCurrentPosition(getCords);
      } else {
        output.innerHTML += "Geo Location is not supported by this browser!";
      }
    }
    function getCords(coords) {
      output.innerHTML += "Latitude: " + coords.coords.latitude + "<br>";
      output.innerHTML += "Longitude: " + coords.coords.longitude + "<br>";
      output.innerHTML += "Accuracy: " + coords.coords.accuracy + "<br>";
    }
  </script>
</body>
</html>

Geolocation Errors

Common error cases:

  • User denied permission
  • Location unavailable
  • Request timed out
  • Unknown error

Example: Error Handling

navigator.geolocation.getCurrentPosition(successCallback, errorCallback);
      
function errorCallback(err) {
  switch (err.code) {
    case err.PERMISSION_DENIED:
      console.log("Permission denied");
      break;
    case err.POSITION_UNAVAILABLE:
      console.log("Position unavailable");
      break;
    case err.TIMEOUT:
      console.log("Request timed out");
      break;
    default:
      console.log("Unknown error");
  }
}

Geolocation Options

  • enableHighAccuracy – Request most accurate location.
  • timeout – Maximum wait time in ms.
  • maximumAge – Cache age limit in ms.

Example: Using Options

const options = {
  enableHighAccuracy: true,
  timeout: 5000,
  maximumAge: 0
};
navigator.geolocation.getCurrentPosition(success, error, options);

Watching the Current Location

The watchPosition() method tracks live location. Use clearWatch() to stop tracking.

Example: watchPosition()

let id = navigator.geolocation.watchPosition(getCoords);
setTimeout(() => {
  navigator.geolocation.clearWatch(id);
  console.log("Tracking stopped");
}, 30000);

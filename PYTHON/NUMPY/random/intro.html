Random Numbers in NumPy

A random number is a value that cannot be predicted logically. In computing, random numbers are generally pseudo-random — generated by algorithms and not truly random.

True randomness requires external unpredictable data like keystrokes or network activity. Most applications use pseudo-random numbers, which are sufficient except for cases like cryptography.

Generate a Random Integer

Generate a random integer from 0 to 100 using NumPy's randint() method:

from numpy import random
x = random.randint(100)
print(x)

Generate a Random Float

Use rand() to generate a random float in the range [0, 1):

from numpy import random
x = random.rand()
print(x)

Generate Random Integer Arrays

Create arrays of random integers using randint() with a size parameter describing the shape:

from numpy import random

# 1-D array with 5 random integers from 0 to 100
x = random.randint(100, size=(5))
print(x)

# 2-D array with 3 rows and 5 columns
x = random.randint(100, size=(3, 5))
print(x)

Generate Random Float Arrays

Generate arrays of random floats similarly, specifying shape as arguments:

from numpy import random

# 1-D array with 5 random floats
x = random.rand(5)
print(x)

# 2-D array with 3 rows and 5 columns
x = random.rand(3, 5)
print(x)

Generate Random Numbers from Array

The choice() method selects random values from a given array:

from numpy import random

# Pick a single random element
x = random.choice([3, 5, 7, 9])
print(x)

# Generate a 2-D array picking random elements from the array
x = random.choice([3, 5, 7, 9], size=(3, 5))
print(x)

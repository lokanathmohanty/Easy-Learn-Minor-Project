ReactJS - Refs and the DOM

React automatically updates the UI when the state of a component changes. This avoids the need for direct DOM manipulation. However, in some scenarios we may need direct access to DOM elements. React provides refs for this purpose, ensuring smooth integration with both the Virtual DOM and the actual HTML DOM.

Creating a Ref

React provides the createRef() function to create refs in class components. A ref is a mutable object that persists across re-renders. 

<refObj> = React.createRef()

Attach a ref to an element:

<input ref={refObj} />

Access the element using the current property:

const refElement = refObj.current

Example: SimpleRef Component

The following example demonstrates how to use createRef in a class component: 

import React from "react";
import { createRef } from "react";

class SimpleRef extends React.Component {
   constructor(props) {
      super(props)
      this.state = { count: 0 }
      this.handleClick = this.handleClick.bind(this);
      this.handleChange = this.handleChange.bind(this);
      this.inputRef = createRef()
      this.labelRef = createRef()
   }

   handleClick() {
      this.setState(prevState => ({ count: prevState.count + 1 }))
   }

   handleChange() {
      this.labelRef.current.innerText =
         this.inputRef.current.value === "" ? "World" : this.inputRef.current.value
   }

   render() {
      return (
         <div>
            <div>Counter: {this.state.count} 
               <button onClick={this.handleClick}>+</button>
            </div>
            <div>
               <label>Enter your name: </label>
               <input type="text" ref={this.inputRef} onChange={this.handleChange} />
               <br />
               <div>Hello, <span ref={this.labelRef}></span></div>
            </div>
         </div>
      )
   }
}

export default SimpleRef;
  • this.inputRef is attached to the input element.
  • this.labelRef is attached to the greeting message element.
  • handleChange updates the greeting message using refs directly, without re-rendering the component.

Behavior

  • Updating state (counter) triggers a re-render.
  • Updating the input field via refs does not trigger a re-render, but updates the DOM directly.
  • Refs persist values between re-renders.

Use Cases of createRef

  • Accessing JavaScript DOM API:
    • Focusing an input element
    • Selecting text
    • Controlling audio/video playback
  • Imperative animations: Using Web Animations API requires direct DOM access.
  • Integration with third-party libraries: Some libraries need raw DOM nodes to function.

Summary

  • React promotes state-driven UI updates.
  • Refs provide a clean API to directly access and manipulate DOM elements.
  • They are useful when using DOM APIs, animations, or third-party libraries.

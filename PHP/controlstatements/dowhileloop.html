PHP `do...while` Loop

The **`do...while`** loop is an **exit-controlled** looping construct in PHP. Unlike the `while` loop, which checks the condition at the start, the `do...while` loop checks the condition at the **end** of each iteration.

Key Characteristic: Guaranteed Execution

The main distinction is that the `do...while` loop is guaranteed to execute its code block at least **once**, regardless of whether the initial condition is true or false. This is because the code runs before the condition is ever checked.

**Syntax:**
do { statements; } while (expression);

Note the semicolon (`;`) after the `while (expression)`.

`do...while` vs. `while` Comparison

The difference is most obvious when the loop condition is initially false:

**Scenario:** Loop condition is `$j <= 5`, but the counter is initialized to `$j = 10`.

**`while` Loop:**
`while (10 <= 5)` is **False**. Loop body is **skipped**.

**`do...while` Loop:**
1. **`do`** body executes (prints "Iteration No: 10").
2. **`while (10 <= 5)`** is **False**. Loop terminates.

The `do...while` loop ran once, while the `while` loop ran zero times.

Practical Examples

Decrementing `do...while` Loop

The `do...while` loop can be used to count backward. The `do` block ensures the start value (`$j=5`) is processed, and the condition `$j>=1` controls subsequent iterations.

$j=5; do { echo "Iteration No: $j \n"; $j--; } while ($j>=1);

Output: Iteration No: 5 \n ... \n Iteration No: 1

Traversing a String in Reverse

By initializing the counter to the string length and decrementing it, we can use the `do...while` loop to read a string's characters from end to beginning.

$string = "Point"; $j = strlen($string); // j=5
do { $j--; echo "$string[$j] \n"; } while ($j>=0);

Output: t \n n \n i \n o \n P

Control Statements (`break` and `continue`)

The `break` and `continue` keywords work with `do...while` loops just as they do with `for` and `while` loops.

  • **`break`**: Immediately exits the loop, regardless of the `while` condition.
  • **`continue`**: Skips the remainder of the current iteration's code block and proceeds directly to re-evaluating the `while` condition for the next iteration.

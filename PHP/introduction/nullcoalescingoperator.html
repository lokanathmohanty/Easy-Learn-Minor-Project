PHP Null Coalescing Operator (`??`)

The **Null Coalescing Operator** (`??`), introduced in **PHP 7**, is a syntactic sugar operator that provides a concise alternative to using a ternary operator in conjunction with the **`isset()`** function. The term "coalescing" refers to uniting many things into one final value.

Function and Syntax

The `??` operator checks if its **first operand exists and is not `null`**. If it is, that first operand is returned; otherwise, the second operand is returned.

$Var = $operand1 **??** $operand2;

This is functionally equivalent to the following ternary statement:

$Var = **isset($operand1)** ? $operand1 : $operand2;

Ternary Operator (`? :`) vs. Null Coalescing (`??`)

Before PHP 7, checking for the existence of a variable (like a submitted form field) and providing a default value required verbose code:

**Ternary/`isset()`:**
$username = **isset($_GET['name'])** ? **$_GET['name']** : 'Guest';

**Null Coalescing (`??`):**
$username = **$_GET['name']** **??** 'Guest';

The `??` operator automatically handles the existence and non-null check, significantly cleaning up the code.

Chaining the Null Coalescing Operator

A powerful feature of the `??` operator is chaining, which allows for checking multiple potential values in sequence until a non-null, existing value is found.

$username = $_GET['name'] **??** $_POST['name'] **??** 'Guest';

In the chained example above, PHP will evaluate from left to right:

  1. If `$_GET['name']` is set and not null, `$username` is set to its value.
  2. **Else**, if `$_POST['name']` is set and not null, `$username` is set to its value.
  3. **Else**, `$username` is set to the default value, `'Guest'`.

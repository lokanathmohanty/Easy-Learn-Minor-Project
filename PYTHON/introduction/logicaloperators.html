Python - Logical Operators

Python logical operators are used to form compound Boolean expressions. Each operand for these logical operators is itself a Boolean expression.

For example:

  • age > 16 and marks > 80
  • percentage < 50 or attendance < 75

Along with the keyword False, Python interprets None, numeric zero of all types, and empty sequences (strings, tuples, lists), empty dictionaries, and empty sets as False. All other values are treated as True.

There are three logical operators in Python: and, or, and not. They must be in lowercase.

Logical "and" Operator

For the compound Boolean expression to be True, both the operands must be True. If any or both operands evaluate to False, the expression returns False.

Truth Table

  • F and F → F
  • F and T → F
  • T and F → F
  • T and T → T

Logical "or" Operator

The or operator returns True if any of the operands is True. For the compound Boolean expression to be False, both operands have to be False.

Truth Table

  • F or F → F
  • F or T → T
  • T or F → T
  • T or T → T

Logical "not" Operator

This is a unary operator. The state of the Boolean operand is reversed. As a result, not True becomes False and not False becomes True.

Truth Table

  • not F → T
  • not T → F

Evaluation of Logical Operators

x and y: First evaluates x. If x is False, its value is returned; otherwise, y is evaluated and returned.

x or y: First evaluates x. If x is True, its value is returned; otherwise, y is evaluated and returned.

Examples

Example 1: Logical Operators With Boolean Conditions

x = 10
y = 20
print("x > 0 and x < 10:", x > 0 and x < 10)
print("x > 0 and y > 10:", x > 0 and y > 10)
print("x > 10 or y > 10:", x > 10 or y > 10)
print("x%2 == 0 and y%2 == 0:", x%2 == 0 and y%2 == 0)
print("not (x+y>15):", not (x+y)>15)

Output:

  • x > 0 and x < 10: False
  • x > 0 and y > 10: True
  • x > 10 or y > 10: True
  • x%2 == 0 and y%2 == 0: True
  • not (x+y>15): False

Example 2: Logical Operators With Non-Boolean Conditions

x = 10
y = 20
z = 0
print("x and y:", x and y)
print("x or y:", x or y)
print("z or x:", z or x)
print("y or z:", y or z)

Output:

  • x and y: 20
  • x or y: 10
  • z or x: 10
  • y or z: 20

Example 3: Logical Operators With Strings and Tuples

a = "Hello"
b = tuple()
print("a and b:", a and b)
print("b or a:", b or a)

Output:

  • a and b: ()
  • b or a: Hello

Example 4: Logical Operators To Compare Sequences (Lists)

x = [1,2,3]
y = [10,20,30]
print("x and y:", x and y)
print("x or y:", x or y)

Output:

  • x and y: [10, 20, 30]
  • x or y: [1, 2, 3]

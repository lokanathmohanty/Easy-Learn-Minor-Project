PHP Return Type Declarations

Introduced in **PHP 7**, **Return Type Declarations** allow a function definition to explicitly specify the expected data type of the value the function will return. This acts as a contract, improving code reliability and clarity.

Syntax and Supported Types

The return type is declared by adding a colon (`:`) followed by the desired type after the function's parameter list.

function myfunction(type $par1): **type** { /* ... */ return $val; }

Supported return types include:

  • **Scalar Types:** `int`, `float`, `bool`, `string`
  • **Compound Types:** `array`, `callable`
  • **Custom Types:** Class and Interface names

Coercive vs. Strict Mode

Return type declarations follow the same coercive/strict rules as parameter type declarations, controlled by the `declare(strict_types=1);` statement at the top of the file.

Coercive Mode (Default)

In the default mode, PHP attempts to **coerce** the returned value into the declared return type if a simple conversion is possible.

  • **Behavior:** If a function declares `: int` but returns the float `2.0`, PHP will coerce it to the integer `2`. The script continues to execute.

function division(int $x, int $y): int { /* ... */ return $x/$y; }
division(20.5, 10); // Returns 2 (Input $x is coerced to 20, then $z=2.0 is coerced to int 2)

Strict Mode (Opt-in)

When `declare(strict_types=1);` is enabled, no coercion is allowed. The returned value's type must exactly match the declared return type.

  • **Behavior:** If the returned value's type does not strictly match the declared return type, PHP throws a **`TypeError`** (Fatal Error).

declare(strict_types=1);
function division(int $x, int $y): **int** { return (float)$x/$y; }
// Calling division(20, 10) results in a **TypeError** because the function explicitly returns a **float** (2.0) but declared **int**.

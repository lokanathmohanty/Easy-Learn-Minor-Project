CSS z-index Property

The CSS z-index property controls the stacking order of elements on a web page when they overlap. Elements with a higher z-index value are displayed in front of those with lower values.

Syntax

The general syntax of the z-index property is:

z-index: auto | number | initial | inherit;

Property Values

  • auto: Default value. The element inherits the stack level of its parent element.
  • <Integer>: Positive or negative integer defining the stack order.
  • initial: Resets the property to its default value.
  • inherit: Inherits the value from the parent element.

CSS z-index with auto Value

When set to auto, the element's stacking level is the same as its parent.

Example

.box1 { position: absolute; z-index: auto; }
.box2 { position: absolute; z-index: 1; }

Here, box1 appears behind box2 because auto resolves to the parent’s stack order.

CSS z-index with Positive Integer

Higher positive integers appear above lower ones.

Example

.box1 { position: absolute; z-index: 1; }
.box2 { position: absolute; z-index: 2; }
.box3 { position: absolute; z-index: 3; }

In this case, box3 overlaps box2, which overlaps box1.

CSS z-index with Negative Integer

Negative values push elements behind others, even the page background if no stacking context exists.

Example

.box1 { position: absolute; z-index: -3; }
.box2 { position: absolute; z-index: -2; }
.box3 { position: absolute; z-index: -1; }

Here, box1 is the furthest back.

Placing Text Over Image

You can overlay text on an image using position and z-index.

Example

.container { position: relative; }
img { display: block; }
.text { position: absolute; top: 20%; z-index: 2; }

This ensures the text is displayed above the image.

CSS z-index with Sticky Position

Sticky elements can be layered using z-index while scrolling.

Example

.box1 { position: sticky; z-index: 1; }
.box2 { position: sticky; z-index: 2; }
.box3 { position: sticky; z-index: 3; }

CSS z-index with Fixed Position

When used with position: fixed, elements stay in place as the page scrolls, respecting stack order.

Example

.box1 { position: fixed; z-index: 1; }
.box2 { position: fixed; z-index: 2; }

CSS z-index with Static Position

If an element has position: static, the z-index property has no effect.

Example

.box1 { position: static; z-index: 5; }

The stack order remains unchanged.

CSS z-index with Relative Position

When using position: relative, z-index works relative to the element’s original position in the document flow.

Example

.box1 { position: relative; z-index: 1; }
.box2 { position: relative; z-index: 2; }

Key Takeaways

  • z-index only works on positioned elements (relative, absolute, fixed, sticky).
  • Higher values stack on top of lower values.
  • Negative values push elements behind others.
  • static position ignores z-index.

Mastering z-index is essential for managing layouts, modals, dropdowns, and layered designs.

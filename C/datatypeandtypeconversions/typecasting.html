Type Casting in C

Type casting in C is the process of converting a variable from one data type to another. It can be performed implicitly by the compiler or explicitly by the programmer to manage type compatibility during expressions and calculations.

Implicit conversions happen automatically according to the C language's type promotion rules, while explicit conversions require the use of the cast operator.

Implicit Type Casting

  • Smaller data types like char and short are promoted to int before arithmetic operations.
  • If one operand is long, the expression is promoted to long.
  • If one operand is float, the expression is promoted to float.
  • If any operand is double, the expression is promoted to double.

Example: Implicit Type Casting


#include <stdio.h>

int main() {
  int i = 17;
  char c = 'c'; // ASCII 99
  
  int sum = i + c;

  printf("Value of sum: %d\n", sum);
  return 0;
}

Output:


Value of sum: 116

Explicit Type Casting

When converting between incompatible types or narrowing conversions (e.g., from floating point to integer), the cast operator (type) is used to explicitly specify the desired type.

Syntax:

(desired_type) expression

Example: Explicit Type Casting


#include <stdio.h>

int main() {
  int total = 17, count = 5;
  double mean;

  mean = (double) total / count;
  printf("Mean value: %f\n", mean);
  return 0;
}

Output:


Mean value: 3.400000

Additional Points

  • Casting impacts operation results and prevents unintended truncation.
  • Type casting is critical for clear, maintainable, and reliable code.
  • Implicit conversions follow strict rules to maintain promotion hierarchy during calculations.
  • Library functions like atoi() and itoa() also facilitate type conversion.

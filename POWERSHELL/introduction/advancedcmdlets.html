PowerShell - Advanced Cmdlets

A cmdlet or "Command let" is a lightweight command used in the Windows PowerShell environment. The Windows PowerShell runtime invokes these cmdlets at the command prompt. You can create and invoke them programmatically through Windows PowerShell APIs. Following are advanced usage examples of cmdlets.

Example: Get-Unique Cmdlet

Get-Content file.txt | Get-Unique

Example: Group-Object Cmdlet

Get-Process | Group-Object -Property ProcessName

Example: Measure-Object Cmdlet

Get-ChildItem | Measure-Object -Property Length -Sum

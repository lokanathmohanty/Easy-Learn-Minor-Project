Django User Management and Superuser Creation 🧑‍💻

Django provides a robust, built-in user management system via the **django.contrib.auth** and **django.contrib.admin** apps, which are included in INSTALLED_APPS by default. User objects are managed through the django.contrib.auth.models.User model.

User Types and Privileges

Django distinguishes between different user types based on key properties:

  • **Superuser:** Has all permissions (can perform CRUD operations on all models) and can log into the Admin site. A superuser's is_staff and is_superuser properties are set to True.
  • **Staff User:** Any user with the **is_staff** property set to **True** can log into the Admin site, but their permissions are restricted by what's explicitly granted (unless they are also a Superuser).
  • **Active User:** All users are active by default (is_active=True). A normal active user cannot log into the Admin site unless they also have the is_staff privilege.

Creating a Superuser

A Superuser, necessary to access the Admin interface initially, can be created through two main methods:

1. Command Line (Recommended)

Run the following command from the project's parent directory and follow the prompts for username, email, and password:

$ python manage.py createsuperuser

2. Programmatically (Via Django Shell)

A Superuser can also be created by calling the create_superuser() method on the User manager (or using create_user() and manually setting is_staff and is_superuser):

>>> from django.contrib.auth.models import User
>>> usr = User.objects.create_user('testusr', 'test@example.com', 'pass123')
>>> usr.is_staff = True
>>> usr.save()

After creation, you can log in to the Admin site at http://localhost:8000/admin/.

Creating New Users via the Admin Interface

Once logged in as a Superuser, new users are created through the **Users** model section on the Admin homepage. Key steps for new user creation include:

  • Entering the **Username** and **Password**.
  • Manually scrolling down to set the **Staff status (is_staff)** if the new user needs the privilege to log in to the Admin site.
  • Optionally setting other details like name and email.

Groups and Permissions

Django allows for granular control over user permissions using the **Groups** model:

  • **Groups:** A Group is a collection of permissions that can be assigned to multiple users. A single user can belong to any number of groups.
  • **Permission Assignment:** Permissions can be added to a Group via the Admin site. When a user is added to a Group, they instantly inherit all permissions assigned to that Group. Additional permissions can still be assigned to the user directly, alongside those obtained from their groups.

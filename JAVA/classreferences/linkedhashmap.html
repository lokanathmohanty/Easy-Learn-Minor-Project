Java LinkedHashMap Class Summary 🔗🗺️

The **java.util.LinkedHashMap** class is a hash table and **doubly-linked list** implementation of the **Map** interface. It extends HashMap, retaining its fast $O(1)$ performance for fundamental operations but adding a key feature: **predictable iteration order**.

I. Key Feature: Predictable Ordering

Unlike a regular HashMap, which makes no guarantees about the order of its elements, LinkedHashMap maintains a linked list running through its entries. This structure ensures that when iterating over the map (using keySet(), entrySet(), or values()), the elements are returned in a defined sequence.

  • Insertion Order (Default): The elements are returned in the order in which they were first inserted into the map. This is the default behavior.
  • Access Order (Optional): The elements are returned in the order of their last access, from least-recently accessed to most-recently accessed. This mode is enabled by passing `true` to the accessOrder parameter in the special constructor: LinkedHashMap(int initialCapacity, float loadFactor, boolean accessOrder).

II. Use Case: Implementing LRU Caches

The **access order** feature makes LinkedHashMap the ideal class for easily implementing a basic **Least Recently Used (LRU) Cache**. In an LRU cache, the least-recently accessed element is the first one to be evicted when the cache limit is reached. Since access-ordered LinkedHashMap always puts the recently accessed element at the tail, the head always contains the LRU element.

III. Performance and Structure

  • **Time Complexity:** Basic operations (`get()`, `put()`, `remove()`) remain **$O(1)$ (constant time)**, inherited from HashMap, because the core structure is still a hash table.
  • **Iteration Cost:** Iterating over a LinkedHashMap is typically less expensive than a standard HashMap because the iteration only follows the linked list structure, avoiding the need to traverse the entire underlying array buckets (many of which might be empty).
  • **Inheritance:** It is a **subclass of HashMap**, inheriting all its methods and capacity management features (initial capacity, load factor).
  • **Nulls:** Like HashMap, it **permits null keys and null values**.

The example demonstrates **Insertion Order** preservation:

// Insertion order: 1, 2, 3
newmap.put(1, 1);
newmap.put(2, 2);
newmap.put(3, 3); 

// Output (Iteration Order) is the same as Insertion Order
Initial map elements: {1=1, 2=2, 3=3}

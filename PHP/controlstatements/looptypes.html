PHP Loop Types and Control Statements

**Loops** are essential programming constructs that allow a block of code to be executed repeatedly, reducing code redundancy and optimizing programs for repetitive tasks like displaying data or processing collections. PHP supports four main loop types.

Types of Loops in PHP

Loop Type Purpose Key Characteristic
**`for` Loop** Fixed Iterations Runs a specified, predetermined number of times.
**`foreach` Loop** Array/Iterable Iteration Runs once for each element in an array or object.
**`while` Loop** Condition-Controlled (Entry-Controlled) Repeats code **as long as** the condition is true. The condition is checked **before** the first execution.
**`do-while` Loop** Condition-Controlled (Exit-Controlled) Executes the code block **at least once**, then repeats as long as the condition is true (checked at the end).

Detailed Loop Syntax and Examples

1. `for` Loop

for (initialization; condition; increment) { code to be executed; }

The loop runs as long as the `condition` is `true`. The `increment` is executed after each iteration.

Example: Calculate cumulative sums over 5 iterations.

Output: At the end of the loop a = 50 and b = 25

2. `foreach` Loop

foreach (array as $value) { code to be executed; }

Easily iterates over array elements. In each pass, the current element's value is copied into `$value`.

Example: Print each value from an array of `[1, 2, 3, 4, 5]`.

Output: Value is 1 \n Value is 2 \n ...

3. `while` Loop

while (condition) { code to be executed; }

The condition is checked at the start of every iteration. If it's initially `false`, the code block is never executed.

Example: Loop continues as long as `$i < 10`.

Output: Loop stopped at i = 10 and num = 40

4. `do-while` Loop

do { code to be executed; } while (condition);

Guarantees execution of the code block **at least once**, because the `while` condition is only checked at the end of the first iteration.

Example: The loop body runs once, then the condition `$i < 10` is checked.

Output: Loop stopped at i = 10

Loop Control Statements

These statements give fine-grained control over the loop execution flow.

`break` Statement

The **`break`** keyword immediately terminates the execution of the current loop (or `switch` statement). Program control moves to the statement immediately following the loop.

Example: `while` loop terminates when `$i` reaches 3, even though the condition is `$i < 10`.

Output: Loop stopped at i = 3

`continue` Statement

The **`continue`** keyword halts the current iteration of the loop. It skips the remaining code within the loop's body for that iteration and moves immediately to the next iteration.

Example: The value `3` is skipped, and the loop moves to the next value (`4`).

Output: Value is 1 \n Value is 2 \n Value is 4 \n Value is 5

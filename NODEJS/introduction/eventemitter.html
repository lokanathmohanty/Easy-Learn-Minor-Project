Node.js - Event Emitter

Node.js API is built on an event-driven architecture. Its core events module provides the EventEmitter class which allows creating and handling custom events. Objects emitting events, such as net.Server or fs.ReadStream, are instances of EventEmitter.

Using EventEmitter

To use, first import the events module and create an instance of EventEmitter:

var events = require('events');
var eventEmitter = new events.EventEmitter();

Important EventEmitter Events

EventDescription
newListenerEmitted when a new listener is added.
removeListenerEmitted when a listener is removed.

Commonly Used Methods

  • addListener(event, listener): Add a listener to the end of the listeners array.
  • on(event, listener): Alias for addListener.
  • once(event, listener): Adds a one-time listener.
  • removeListener(event, listener): Removes specified listener.
  • removeAllListeners([event]): Removes all listeners of specified event or all events.
  • listeners(event): Returns array of listeners for event.
  • emit(event, [...args]): Executes all listeners in order, passing arguments.

Example

var events = require('events');
var eventEmitter = new events.EventEmitter();

var listener1 = function() {
  console.log('listener1 executed.');
};

var listener2 = function() {
  console.log('listener2 executed.');
};

eventEmitter.addListener('connection', listener1);
eventEmitter.on('connection', listener2);

eventEmitter.emit('connection');

eventEmitter.removeListener('connection', listener1);
console.log('listener1 will not listen now.');

eventEmitter.emit('connection');

console.log('Number of listeners:', eventEmitter.listenerCount('connection'));

Output

listener1 executed.
listener2 executed.
listener1 will not listen now.
listener2 executed.
Number of listeners: 1

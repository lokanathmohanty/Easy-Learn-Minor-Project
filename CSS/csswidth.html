CSS - Width Property

The width property in CSS is used to set the width of an element’s content area. If the box-sizing property is set to border-box, then the width will include the element’s borders and padding. The final width is also constrained by min-width and max-width properties, which serve as lower and upper bounds respectively.

Syntax

width: auto | <length> | <percentage> | max-content | min-content | fit-content;

Possible Values

  • <length> → A fixed length such as px, cm, or in.
  • <percentage> → A percentage of the width of the containing element.
  • auto → The browser calculates the width automatically based on content (default).
  • max-content → Expands the width to fit the longest unbreakable content.
  • min-content → Shrinks the width to the smallest possible size without overflowing content.
  • fit-content → Uses the formula min(max-content, max(min-content, <length-percentage>)) to adjust width.

DOM Syntax

object.style.width = "100px";

Example 1: Width with Length Units

You can set width using length units like px and em.

div.a {
  width: 100px;
}

div.b {
  width: 5em;
}

Example 2: Width with Percentage

Width can be defined as a percentage of the parent container.

div.a {
  width: 120%;
}

div.b {
  width: 20%;
}

Example 3: Width with Auto

When set to auto, the width is calculated by the browser based on the content or available space.

div.auto {
  width: auto;
}

Example 4: Width with max-content and min-content

The width can be set to match either the maximum intrinsic content size or the minimum intrinsic content size.

div.c {
  width: max-content;
}

div.d {
  width: min-content;
}

Example 5: Width Applied to Images

You can control the size of images using the width property.

img.demoImg {
  width: 300px;
  margin-right: 0.5in;
}

Example 6: Width with fit-content

The fit-content value allows content to fit within available space, but not exceed max-content.

ul {
  width: fit-content;
  padding: 1.5em;
}

li {
  display: inline-flex;
  padding: 0.5em;
}

Practical Example: Responsive Layout

Developers often use percentages and auto values for responsive designs where elements adapt to screen size.

.container {
  width: 90%;
  max-width: 1200px;
  margin: auto;
}

Related Properties

  • max-width → Sets the maximum width an element can expand to.
  • min-width → Sets the minimum width an element can shrink to.
  • min-content → Minimum intrinsic width.
  • max-content → Maximum intrinsic width.
  • fit-content → Fits content within available space.
  • fit-content() → Uses the formula min(max-content, max(min-content, argument)).

Use Cases

  • Setting fixed widths for consistent layouts (e.g., cards, buttons).
  • Using percentages for responsive web design.
  • Defining flexible image widths for scaling in different viewports.
  • Applying intrinsic values (min-content, max-content) for text-heavy layouts.
  • Combining width with max-width and min-width for fully adaptive designs.

CSS - min-inline-size Property

The CSS min-inline-size property sets the minimum inline size of an element. The direction of the inline is determined by the writing-mode property. If the content fits well within the inline size of the element, this property has no effect.

Syntax

min-inline-size: auto | length | percentage | initial | inherit;

Property Values

  • auto – No width limit is set with this value. This is the default.
  • length – Sets the min-inline-size of the element using length units (e.g. px, em, rem).
  • percentage – Sets the min-inline-size of the element relative to the size of its containing element.
  • initial – Sets the property to its default value.
  • inherit – Inherits the property value from the parent element.

Min Inline Size Property with Auto Value

To not set any specific limit on the inline-size of an element, we use the auto value. The size of the element will depend on the length of the content.

Example

.container {
   min-inline-size: auto;
   display: inline-block;
}

Min Inline Size Property with Length Values

To set the inline size of an element, we can specify the size using length units (e.g. px, em, rem). If the content is greater than the size of the element, the element will grow to accommodate it.

Example

.container {
   min-inline-size: 400px;
}

.container {
   min-inline-size: 30em;
}

Min Inline Size Property with Percentage Values

We can also use percentage values relative to the size of the containing element. This ensures the inline size grows proportionally.

Example

.container {
   min-inline-size: 50%;
}

.container {
   min-inline-size: 75%;
}

Min Inline Size Property with Writing Mode

The property can be used in combination with writing-mode, which defines the inline direction. In horizontal mode, the inline size grows from left to right, and in vertical mode, it grows from top to bottom.

Example

.container {
   min-inline-size: 55%;
   writing-mode: horizontal-lr;
}

.container {
   min-inline-size: 55%;
   writing-mode: vertical-lr;
}

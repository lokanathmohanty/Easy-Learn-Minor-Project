JavaScript - SQL CRUD Operations

Introduction

CRUD stands for Create, Read, Update, and Delete. These are the four fundamental operations in permanent storage systems such as relational databases, but they can also be demonstrated in JavaScript objects. A JavaScript object is a collection of keys and values (properties), and each CRUD operation can be performed on it.

In SQL:

  • CREATE → INSERT statement
  • READ → SELECT statement
  • UPDATE → UPDATE statement
  • DELETE → DELETE statement

CRUD Syntax in JavaScript


// Creating an Object
const circle = {
   radius: 10,
   area: function() {
       return Math.PI * this.radius * this.radius;
   }
};

Create Operation

The create operation initializes new objects or adds properties to existing objects. It can be done using object literals or the Object constructor. 


// Using Object Constructor
const obj = new Object();

// Using Object Literals
const obj = {
   key1 : value1
}

Example: Create Operation


const box = { 
   height: 25, 
   breadth: 20, 
   volume: function () { 
       return this.height * this.breadth;
   } 
}; 

const cube = new Object(); 
cube.edge = 10; 
cube.volume = function () { 
   return this.edge * this.edge;
}; 

cube.edge = 15; 
console.log(box, "Volume of the box: " + box.volume()); 
console.log(cube, "Volume of the cube: " + cube.volume());

Output:


{ height: 25, breadth: 20, volume: [Function: volume] } Volume of the box: 500
{ edge: 15, volume: [Function (anonymous)] } Volume of the cube: 225

Read Operation

The read operation is used to access object properties. It can be done with dot notation, bracket notation, or object destructuring. 


// Dot notation
console.log(obj.prop1);

// Nested object
console.log(obj.prop1.subProperty);

// Bracket notation
console.log(obj['prop2']);

// Object destructuring
const { key1 } = obj1;
console.log(key1);

Example: Read Operation


const box = { 
   height: 25, 
   width: 20, 
   volume: function () { 
      return this.height * this.width;
   } 
}; 

const { height } = box; 
console.log("Box height: " + height); 
console.log("Box width: " + box['width']); 
console.log("Box volume: " + box.volume());

Output:


Box height: 25
Box width: 20
Box volume: 500

Update Operation

Update modifies existing object properties. This can be done with dot notation or bracket notation. 


// Dot notation
obj.prop1 = "newValue";

// Bracket notation
obj['prop2'] = "value2";

Example: Update Operation


const box = { 
   height: 25, 
   depth: 20, 
   volume: function () { 
      return this.height * this.depth; 
   } 
}; 

console.log("Initial Volume: " + box.volume()); 

// Update using dot notation
box.height = 50;              

// Update using brackets
box['depth'] = 40;             

console.log("Updated Volume: " + box.volume());

Output:


Initial Volume: 500
Updated Volume: 2000

Delete Operation

Delete removes properties from objects. This can be done with the delete operator or via object destructuring. 


// Using delete operator
delete obj.property;

// Using destructuring
const { prop1, ...newObj } = oldObj;

Example: Delete Operation


const person = { 
   firstName: 'Amit', 
   yearsOld: 52, 
   location: 'mumbai'
}; 

console.log("Initial person object: ", person); 

// Using destructuring
const { yearsOld, ...updatedPerson } = person; 
console.log("New person object without yearsOld attribute: ", updatedPerson); 

// Using delete operator
delete person.location; 
console.log("Person object after removing location: ", person);

Output:


Initial person object:  { firstName: 'Amit', yearsOld: 52, location: 'mumbai' }
New person object without yearsOld attribute:  { firstName: 'Amit', location: 'mumbai' }
Person object after removing location:  { firstName: 'Amit', yearsOld: 52 }

Summary

  • Create → Add new object or property.
  • Read → Access properties using dot, bracket, or destructuring.
  • Update → Modify existing properties with dot or bracket notation.
  • Delete → Remove object properties using delete or destructuring.

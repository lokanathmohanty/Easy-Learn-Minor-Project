ReactJS - Lists

In React, the most common pattern is to convert a collection of items into React elements. JavaScript provides many ways to manipulate collections. One simple way is using a for loop to generate React elements.

For Loop

The for loop can be used to iterate through an array of items and return a list of JSX elements. Let’s create a component that displays expense items inside a table.

ExpenseListUsingForLoop Component

A simple table with headers and a footer for showing the sum of expenses.

The getTotalExpenses() method loops over the expenses array and calculates the total amount. Inside render(), the for loop generates a list of rows and displays them in the table.

Using the Component

The component can be included in App.js and passed an expenses array as props. The table will render each expense and display the total in the footer.

Styling

Basic table styling can be applied through App.css to make the output cleaner.

ECMAScript 6 for..of Loop

Instead of the traditional for loop, we can use the modern for..of loop introduced in ES6.

  • entries() provides index and value pairs for iteration.
  • If index is not needed, for..of can directly loop through the array values.

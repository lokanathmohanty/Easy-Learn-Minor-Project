JavaScript - JSON

What is JSON?

JSON (JavaScript Object Notation) is a text-based data format used to represent objects and data structures. It is language-independent and is often used to exchange data between a server and a web application or between different applications.

JSON Features

  • Language-independent data storage format
  • Can represent objects and data structures
  • Can be exchanged between different programming languages
  • Supports nested objects
  • Can contain multiple data types

JSON Syntax

JSON data is represented as key-value pairs inside curly braces. Keys are always written in double quotes.

{
   "key1": value1,
   "key2": value2
}

Values can be of the following data types:

  • String − Characters enclosed in double quotes
  • Number − Integers or floating-point numbers
  • Boolean − true or false
  • Array − Ordered list of values
  • Object − Unordered collection of key-value pairs
  • null − Represents no value

JSON Data

JSON data example:

"name":"John Doe"

Difference: JSON keys must always be in double quotes, but JavaScript object properties do not require quotes.

JSON Objects

{"name": "John Doe", "age": 30, "isStudent": false}

In JavaScript, this can be parsed into a variable:

let person = {"name": "John Doe", "age": 30, "isStudent": false};

JSON Arrays

[
   {
      "name": "John Doe",
      "age": 30,
      "occupation": "Software Engineer"
   },
   {
      "name": "Jane Doe",
      "age": 25,
      "occupation": "Doctor"
   }
]

This is a JSON array containing two JSON objects.

Accessing JSON Data

We can access JSON data using dot or bracket notation.

Example

<html>
<body>
   <div>Accessing JSON data</div>
   <div id="demo"></div>
   <script>
      const person = {
         "name": "John Doe",
         "age": 30,
         "occupation": "Software Engineer"
      }
      document.getElementById("demo").innerHTML = 
      "Name: " + person.name + "<br>" +
      "Age: " + person["age"] + "<br>" +
      "Occupation: " + person.occupation;
   </script>
</body>
</html>

Output:

Accessing JSON data
Name: John Doe
Age: 30
Occupation: Software Engineer

JSON Methods

  • JSON.parse() − Converts JSON string into a JavaScript object.
  • JSON.stringify() − Converts a JavaScript object into a JSON string.

JSON vs. JavaScript Object

  • JSON is language-independent; JavaScript objects work only in JS.
  • JSON cannot contain functions; JavaScript objects can.
  • JSON keys must be in double quotes; JavaScript object keys do not require quotes.

Converting JSON String to JavaScript Object

let jsonString = '{"name": "John Doe", "age": 30, "isStudent": false}';
const jsonObject = JSON.parse(jsonString);

Example

<html>
<body>
   <div>Converting JSON string to JavaScript object</div>
   <div id="demo"></div>
   <script>
      let jsonString = '{"name": "John Doe", "age": 30, "isStudent": false}';
      const jsonObject = JSON.parse(jsonString);
      document.getElementById("demo").innerHTML = jsonObject.name;
   </script>
</body>
</html>

Output: John Doe

Converting JavaScript Object to JSON

const person = { name: "John Doe", age: 30, isStudent: false };
const jsonString = JSON.stringify(person);

Example

<html>
<body>
   <div>Converting JavaScript object to JSON string</div>
   <div id="demo"></div>
   <script>
      const person = {
         name: "John Doe",
         age: 30,
         isStudent: false
      };
      const jsonString = JSON.stringify(person);
      document.getElementById("demo").innerHTML = jsonString;
   </script>
</body>
</html>

Output: {"name":"John Doe","age":30,"isStudent":false}

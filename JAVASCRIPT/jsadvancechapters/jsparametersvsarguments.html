JavaScript - Parameters vs Arguments

Parameters and arguments are terms related to functions in JavaScript. They are often confused with each other, but they have distinct meanings. In this tutorial, we will learn the difference between parameters and arguments.

Parameters

Parameters are variable names that are used in the function definition. They hold the values of the arguments that are passed to the function when it is called.

Arguments

Arguments are used in the function call. These are the actual values passed to the function when it is invoked.

We can pass any number of arguments to a function, but:

  • If the number of arguments is less than the number of parameters, the remaining parameters will be undefined.
  • If the number of arguments is more than the number of parameters, the extra arguments will be ignored.

Parameters vs Arguments

  • Parameters are the variable names used in the function definition.
  • Arguments are the actual values passed to the function when it is called.
  • Parameters hold the values of the arguments inside the function.
  • Parameters appear in the function definition, while arguments appear in the function call.

Example

<html>
<body>
  <script>
    function add(a, b){
       return a + b;
    }
    document.write(add(10, 20));
  </script>
</body>
</html>

Output

30

Explanation

In the above example, there is a function called add() that adds two numbers. In the function definition, a and b are the parameters. When the function is called, the values 10 and 20 are passed as arguments. These values are stored in the parameters a and b, and the function returns their sum.

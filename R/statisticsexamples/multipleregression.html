R - Multiple Regression

Multiple regression extends linear regression to model the relationship between one response variable and multiple predictor variables. The model is expressed as \[ y = a + b_1 x_1 + b_2 x_2 + \dots + b_n x_n \] where \(y\) is the response, the \(x_i\) are predictors, and \(a, b_i\) are coefficients.

lm() Function Syntax

lm(y ~ x1 + x2 + x3 + ..., data)

- formula: Relationship between response and predictors.
- data: Data frame containing the variables.

Example Input Data

input <- mtcars[, c("mpg", "disp", "hp", "wt")]
print(head(input))

Create Relationship Model & Get Coefficients

# Create model
model <- lm(mpg ~ disp + hp + wt, data = input)

# Print model
print(model)

# Extract coefficients
cat("# # # # The Coefficient Values # # # \n")
a <- coef(model)[1]        # Intercept
Xdisp <- coef(model)[2]    # disp coefficient
Xhp <- coef(model)[3]      # hp coefficient
Xwt <- coef(model)[4]      # wt coefficient

print(a)
print(Xdisp)
print(Xhp)
print(Xwt)

Regression Equation

Using the coefficients, the regression equation is: 

Y = 37.15 + (-0.000937)*x1 + (-0.0311)*x2 + (-3.8008)*x3
where:
x1 = disp, x2 = hp, x3 = wt

Predict New Values

# Predict mileage given new predictors
newdata <- data.frame(disp = 221, hp = 102, wt = 2.91)
predicted_mpg <- predict(model, newdata)

R - Linear Regression

Linear regression models the relationship between two variables by fitting a straight line. One variable is the predictor (independent), and the other is the response (dependent). It assumes a linear relation expressed as \( y = a x + b \), where \(a\) and \(b\) are coefficients.

Steps for Linear Regression

  1. Gather observed values of predictor and response variables.
  2. Create a regression model using lm() in R.
  3. Extract coefficients to form the mathematical equation.
  4. Summarize the model to understand prediction errors (residuals).
  5. Use predict() to predict values for new data.

Input Data

# Predictor (height)
x <- c(151, 174, 138, 186, 128, 136, 179, 163, 152, 131)
# Response (weight)
y <- c(63, 81, 56, 91, 47, 57, 76, 72, 62, 48)

Create Regression Model

relation <- lm(y ~ x)
print(relation)

Output:

Coefficients:

Summary of the Model

summary(relation)

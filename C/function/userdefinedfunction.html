User-defined Functions in C

A function in C is a block of organized, reusable code that performs a single related action. Functions in C are classified into two types:

  • Library functions
  • User-defined functions

C compilers come with precompiled header files like stdio.h and math.h containing predefined library functions (e.g., printf(), scanf(), pow(), sqrt()).

If no suitable library function exists, you can define your own custom functions to modularize and reuse code.

The main() function itself is a user-defined function and serves as the program entry point.

What is a User-Defined Function?

A user-defined function is created by the programmer to perform a specific task, promoting code reusability and modularity. These can be defined in the same program or a user-created header file.

Creating a User-Defined Function

To create a user-defined function, understand what the function should do and follow these parts:

  1. Function declaration (prototype)
  2. Function definition
  3. Function calling

Function Declaration

The prototype declares the function signature before use. For example, a function add() that adds two integers:

int add(int, int);

Function Definition

The function definition consists of the header matching the prototype and the function body:

return_type function_name(arg1, arg2, ...) {
    // function body
    return value;
}

Example:

int add(int a, int b) {
    int c = a + b;
    return c;
}

The order of function definitions in a program doesn’t matter, but the prototype must be declared before function calls.

Calling a User-Defined Function

Call a function by passing the exact number and type of arguments as declared:

int result = add(10, 20);

Example: Addition and Subtraction Functions

// C program demonstrating user-defined functions
#include <stdio.h>

// Function declarations
int add(int, int);
int sub(int, int);

// Function definitions
int add(int a, int b) {
  return a + b;
}

int sub(int a, int b) {
  return a - b;
}

int main() {
  int num1 = 36, num2 = 24;
  int res_add, res_sub;

  // Calling the functions
  res_add = add(num1, num2);
  res_sub = sub(num1, num2);

  // Printing the results
  printf("Addition is : %d\n", res_add);
  printf("Subtraction is : %d\n", res_sub);

  return 0;
}

Output:

Addition is : 60
Subtraction is : 12

Formal and Actual Arguments

When defining a function, the parameters in parentheses are called formal arguments. When calling a function, the values passed are the actual arguments.

Example:

int x = 10, y = 20;
int result = add(x, y);

Formal arguments can be of any data type including arrays, pointers, structs, etc.

Return Types of Functions

A function can return any data type: primitive types, arrays, pointers, structs, or void if no return value is needed.

Example: Mismatched Function Declaration and Definition

#include <stdio.h>

float divide(int, int);

int main() {
  int x = 15, y = 5;
  float z = divide(x, y);
  printf("%f", z);
  return 0;
}

int divide(int a, int b) {
  int c = a / b;
  return c;
}

Output (Error):

The compiler reports a conflicting types error because the prototype returns float but the definition returns int.

Recursive Functions

Functions in C can call other functions or themselves. A function calling itself is called a recursive function.

Example of infinite recursion (not recommended):

#include <stdio.h>

int main() {
  printf("Hello");
  main();  // Recursive call
  return 0;
}

This program runs infinitely. Practical recursion must have a terminating condition to avoid infinite loops.

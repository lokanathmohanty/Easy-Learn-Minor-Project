Power BI: DAX Date Functions

DAX Date functions facilitate working with date and time data in Power BI reports, enabling creation, manipulation, and analysis of date/time values within tables and measures.

These functions are essential for building complex data models supporting time-based calculations such as duration, periods, and comparisons.

Common DAX Date Functions with Examples

  • DATE(year, month, day): Creates a date value from year, month, and day inputs.
    Example: d1 = DATE(2024, 9, 24)
  • HOUR(datetime): Extracts the hour (0-23) from a date/time value.
    Example: emp_hr = HOUR("February 22, 2024 7:00 pm") returns 19.
  • WEEKDAY(date): Returns a number 1 (Sunday) to 7 (Saturday) representing the day of the week.
    Example: Id_day = WEEKDAY("March 04, 2024") returns 2 (Monday).
  • WEEKNUM(date, [return_type]): Returns the week number of the year for a given date.
    Example: week_nm = WEEKNUM("September 01, 2010")
  • NOW(): Returns the current date and time.
    Example: current_time = NOW()
  • EOMONTH(start_date, months): Returns the last day of the month before or after a specified number of months.
    Example: bill_py = EOMONTH("November 12, 2023", 2) returns end of January 2024.
  • YEAR(date): Extracts the year from a date.
    Example: yt = YEAR("Mar 01, 2010")
  • YEARFRAC(start_date, end_date): Calculates the fractional number of years between two dates.
    Example: yt = YEARFRAC("September 23, 2007", "November 23, 2008")
  • CALENDAR(start_date, end_date): Creates a table with a continuous range of dates.
    Example: cal = CALENDAR("March 10, 2024", "March 30, 2024")
  • DATEVALUE(text_date): Converts a date in text format to a date/time value.
    Example: d_value = DATEVALUE("11 02 2010")
  • DATEDIFF(start_date, end_date, interval): Calculates the difference between two dates in a specified interval (e.g., DAY, MONTH, YEAR).
    Example: d_value = DATEDIFF(DATE(2020, 6, 20), DATE(2020, 11, 27), MINUTE)

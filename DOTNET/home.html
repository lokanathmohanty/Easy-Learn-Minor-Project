What is .NET Core?

**Content: Overview and Purpose**

**.NET Core** (now simply referred to as **.NET**) is a **free, open-source, and cross-platform** development platform maintained by Microsoft and the larger .NET community on GitHub. It was redesigned to be a fast, flexible, and modern platform to replace the older, Windows-only .NET Framework.

Its primary goal is to provide a single, unified framework for building all types of modern applications, including cloud-native apps, microservices, and high-performance services.

Key Characteristics

  • **Cross-Platform:** Allows developers to build and run applications on **Windows, macOS, and Linux**.
  • **Open-Source:** The entire platform, including the runtime and libraries, is open-source and community-driven.
  • **Modular:** Uses the **NuGet** package manager to allow developers to include only the components (libraries) they need, resulting in lightweight and faster applications.
  • **High Performance:** Optimized for speed and scalability, often outperforming other popular web frameworks.
  • **Multiple Languages:** Supports C#, F#, and Visual Basic.

Example: What You Can Build with .NET Core

The versatility of .NET Core allows a single development team to create solutions across various environments:

  • **Web Applications & APIs:** Using **ASP.NET Core** to build dynamic web apps, RESTful services, and modern microservices.
  • **Cloud-Native Apps:** Optimized for deployment in containers like **Docker** and orchestration systems like **Kubernetes** on cloud platforms (Azure, AWS, GCP).
  • **Mobile Apps:** Using **.NET MAUI** (Multi-platform App UI) to create native mobile and desktop applications from a single codebase (for iOS, Android, macOS, and Windows).
  • **Desktop Applications:** Supports building traditional Windows desktop apps using **WPF** (Windows Presentation Foundation) and **Windows Forms**.

Audience & Prerequisites

This tutorial is designed for software programmers who want to learn the basics of .NET Core. A basic understanding of general computer programming concepts and at least one programming language is highly recommended.

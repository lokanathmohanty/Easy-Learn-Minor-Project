Java - JVM Shutdown Hook

JVM Shutdown

The JVM can shut down in two ways:

  • Controlled process: When System.exit() is called, CTRL+C is pressed, or the last non-daemon thread finishes.
  • Abrupt manner: When the JVM receives a kill signal, Runtime.getRuntime().halt() is called, or there is an OS panic.

JVM Shutdown Hook

A shutdown hook is a thread that is registered to run when the JVM is shutting down. These hooks are started when the shutdown begins and run concurrently. Daemon threads continue running during shutdown, and if System.exit() was used, non-daemon threads may run too.

addShutdownHook(Thread hook) Method

The addShutdownHook method registers a shutdown hook thread.

public void addShutdownHook(Thread hook)

Parameter: hook – An initialized but unstarted thread.

Exceptions:

  • IllegalArgumentException – If the hook is already registered or running.
  • IllegalStateException – If the JVM is already shutting down.
  • SecurityException – If the security manager denies shutdown hook registration.

Example: Using a Shutdown Hook with Thread


class CustomThread extends Thread {
   public void run() {
      System.out.println("JVM is shutting down.");
   }
}

public class TestThread {
   public static void main(String args[]) throws InterruptedException {
      try {
         Runtime.getRuntime().addShutdownHook(new CustomThread());
         System.out.println("Program is starting...");
         System.out.println("Waiting for 3 seconds...");
         Thread.sleep(3000);
         System.out.println("Program is closing...");
      } catch (Exception e) {
         e.printStackTrace();
      }
   }
}

Output:


Program is starting...
Waiting for 3 seconds...
Program is closing...
JVM is shutting down.

Example 1: Shutdown Hook with Runnable

Example 2: Removing a Shutdown Hook


class CustomThread implements Runnable {
   public void run() {
      System.out.println("JVM is shutting down.");
   }
}

public class TestThread {
   public static void main(String args[]) throws InterruptedException {
      try {
         Thread hook = new Thread(new CustomThread());
         Runtime.getRuntime().addShutdownHook(hook);
         System.out.println("Program is starting...");
         System.out.println("Waiting for 3 seconds...");
         Thread.sleep(3000);
         System.out.println("Program is closing...");
         Runtime.getRuntime().removeShutdownHook(hook);
      } catch (Exception e) {
         e.printStackTrace();
      }
   }
}

Output:


Program is starting...
Waiting for 3 seconds...
Program is closing...

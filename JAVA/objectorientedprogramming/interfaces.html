Java Programming: Abstraction and Contracts

Session: Interfaces

What is a Java Interface?

A Java **Interface** is a blueprint or a contract that defines a set of behaviors that any class implementing it must adhere to. It is primarily a collection of **abstract methods** used to achieve **100% abstraction**.

An interface is a **reference type** and is similar to a class but with strict restrictions:

  • You **cannot instantiate** an interface.
  • Methods are implicitly **public** and **abstract** (no body), unless declared as **default** or **static**.
  • Fields are implicitly **public**, **static**, and **final** (constants).

Implementing Interfaces with implements

A class uses the **implements** keyword to adopt an interface. By implementing an interface, the class signs a contract to provide a concrete definition (body) for every abstract method declared in that interface (unless the class itself is declared abstract).

interface Animal {
   void eat(); // implicitly public abstract
}

public class MammalInt implements Animal {
   // Must provide implementation for all abstract methods
   public void eat() {
      System.out.println("Mammal eats");
   }
}

Key Rules for Interfaces and Inheritance

  • **Class-Interface Relationship:** A class **implements** an interface. A class can implement **multiple interfaces** (solving the multiple inheritance problem for behavior).
  • **Interface-Interface Relationship:** An interface **extends** another interface. An interface can extend **multiple parent interfaces**.
  • **Overriding Methods:** When implementing interface methods, the overriding method must maintain the exact same signature and cannot have a more restrictive access level (they must be public).

Extending Multiple Interfaces

Java supports a single class extending one class but allows it to implement multiple interfaces, or for one interface to extend multiple interfaces:

// Interface extends multiple parent interfaces
public interface Hockey extends Sports, Event { ... }

// Class implements multiple interfaces
public class HockeyDemo implements Hockey, Event {
    // Must implement all methods from Hockey AND Event
}

Tagging Interfaces (Marker Interfaces)

A **Tagging Interface** (or Marker Interface) is an interface that contains **no methods** (e.g., java.util.EventListener). Its purpose is solely to:

  1. **Create a Common Parent:** Establish a common base type for a group of related interfaces or classes.
  2. **Add a Data Type:** Allow a class implementing it to be identified as a specific type at runtime (via polymorphism and the instanceof operator), allowing the JVM or other code to apply special handling (e.g., Serialization, Cloning).

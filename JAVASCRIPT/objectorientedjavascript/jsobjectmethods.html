JavaScript - Object Methods

In JavaScript, object methods are properties that contain function definitions. An object is a collection of properties, and a property can hold any value, including a function. When a property’s value is a function, it is called a method.

Object methods allow you to encapsulate logic within objects, making code reusable, organized, and easier to maintain. You can define methods directly inside objects, invoke them with parentheses, and even add or update them dynamically.

Syntax

Defining a method inside an object: 

const obj = {
  sum: function () {
    // method body
  }
}
obj.sum();

In the above example, sum is a method inside the obj object. You access and invoke it with obj.sum().

Example: Adding a Method

Here, the company object contains a method getInfo() that uses the this keyword to access object properties. 

const company = {
  companyName: "Tutorials Point",
  companyWebsite: "www.tutorialspoint.com",
  getInfo: function () {
    return "Company Name: " + this.companyName + 
           "
Website: " + this.companyWebsite;
  }
}
document.getElementById("output").innerHTML = company.getInfo();

Output:

Company Name: Tutorials Point
Website: www.tutorialspoint.com

Object Method Shorthand

ES6 introduced a shorthand way to define methods in objects without the function keyword. 

const employee = {
  name: "John Doe",
  age: 32,
  getInfo() {
    return "The employee name is " + this.name + 
           " and his age is " + this.age + " Years.";
  }
}
document.getElementById("output").innerHTML = employee.getInfo();

Output: The employee name is John Doe and his age is 32 Years.

Example: Method with Parameters

Methods can take arguments and return results just like normal functions. 

const nums = {
  getSum(a, b) {
    return a + b;
  }
}
document.getElementById("output").innerHTML = nums.getSum(2, 3);

Output: 5

Adding or Updating Methods

You can add or update methods dynamically using dot or square bracket notation. 

const nums = {
  getSum(a, b) {
    return a + b;
  }
}
nums.getMul = function(a, b) {
  return a * b;
}
document.getElementById("output").innerHTML = nums.getMul(2, 3);

Output: 6

Using Built-in Methods

JavaScript objects also have built-in methods. For example, numbers have toString(), strings have toUpperCase(), etc. 

const num = new Number(20);
let str = num.toString();
document.getElementById("output").innerHTML = 
  "After converting: " + str + "
Type: " + typeof str;

Output:

After converting: 20
Type: string

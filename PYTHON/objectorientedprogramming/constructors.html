Python - Constructors

A constructor in Python is an instance method that is automatically called when a new object of the class is created. Its main role is to assign values to instance variables as soon as the object is declared.

Python uses the special method __init__() as a constructor to initialize instance variables. This method always takes a mandatory first parameter named self, which refers to the instance itself.

Creating a Constructor in Python

Define the __init__() method inside the class and initialize instance variables:

def __init__(self, parameters):
    # initialize instance variables

You can name the first parameter anything, but it is conventionally named self.

Types of Constructors

  • Default Constructor: Constructor with only the self parameter.
  • Parameterized Constructor: Constructor with additional parameters to initialize object with different values.

Default Constructor Example

class Employee:
    'Common base class for all employees'
    def __init__(self):
        self.name = "Bhavana"
        self.age = 24

e1 = Employee()
print("Name: {}".format(e1.name))
print("age: {}".format(e1.age))

Output:
Name: Bhavana
age: 24

Parameterized Constructor Example

class Employee:
    'Common base class for all employees'
    def __init__(self, name, age):
        self.name = name
        self.age = age

e1 = Employee("Bhavana", 24)
e2 = Employee("Bharat", 25)

print("Name: {}".format(e1.name))
print("age: {}".format(e1.age))
print("Name: {}".format(e2.name))
print("age: {}".format(e2.age))

Output:
Name: Bhavana
age: 24
Name: Bharat
age: 25

Default Values in Constructor

You can assign default values to constructor parameters so the object can be created with or without passing arguments:

class Employee:
    'Common base class for all employees'
    def __init__(self, name="Bhavana", age=24):
        self.name = name
        self.age = age

e1 = Employee()
e2 = Employee("Bharat", 25)

print("Name: {}".format(e1.name))
print("age: {}".format(e1.age))
print("Name: {}".format(e2.name))
print("age: {}".format(e2.age))

Output:
Name: Bhavana
age: 24
Name: Bharat
age: 25

Instance Methods

Besides the constructor, classes can have other instance methods that operate on instance variables. These methods take self as a parameter.

Example

class Employee:
    def __init__(self, name="Bhavana", age=24):
        self.name = name
        self.age = age
        
    def displayEmployee(self):
        print("Name : ", self.name, ", age: ", self.age)

e1 = Employee()
e2 = Employee("Bharat", 25)

e1.displayEmployee()
e2.displayEmployee()

Output:
Name : Bhavana , age: 24
Name : Bharat , age: 25

Adding, Modifying or Deleting Attributes Dynamically

You can add, modify, or delete attributes on object instances at runtime:

# Add a 'salary' attribute
emp1.salary = 7000 
# Modify 'name' attribute
emp1.name = 'xyz'
# Delete 'salary' attribute
del emp1.salary

Using Built-in Functions for Attribute Access

  • getattr(obj, name[, default]) - Access an attribute of an object.
  • hasattr(obj, name) - Check if an attribute exists.
  • setattr(obj, name, value) - Set an attribute value; creates if it doesn't exist.
  • delattr(obj, name) - Delete an attribute.
print(hasattr(e1, 'salary'))  # False
print(getattr(e1, 'name'))      # Bhavana
setattr(e1, 'salary', 7000)    
delattr(e1, 'age')

Output:
False
Bhavana

Multiple Constructors in Python

Python does not support multiple constructors directly. The last __init__() definition overrides previous ones.

However, you can achieve similar functionality by using variable arguments to handle different initialization scenarios.

Example Using *args

class Student:
    def __init__(self, *args):
        if len(args) == 1:
            self.name = args[0]
        elif len(args) == 2:
            self.name = args[0]
            self.age = args[1]
        elif len(args) == 3:
            self.name = args[0]
            self.age = args[1]
            self.gender = args[2]

st1 = Student("Shrey")
print("Name:", st1.name)
st2 = Student("Ram", 25)
print(f"Name: {st2.name} and Age: {st2.age}")
st3 = Student("Shyam", 26, "M")
print(f"Name: {st3.name}, Age: {st3.age} and Gender: {st3.gender}")

Output:
Name: Shrey
Name: Ram and Age: 25
Name: Shyam, Age: 26 and Gender: M

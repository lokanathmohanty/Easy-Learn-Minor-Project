HTML - Web Slide Desk

A slide is a single page of a presentation. Collectively, a group of slides may be known as a slide desk.

In this example, we will create a simple HTML web slide desk where you can navigate between slides using "Previous" and "Next" buttons.

Example: Web Slide Desk

<!DOCTYPE html>
<html>
<head>
   <title>Web Slide Desk</title>
</head>
<body>
   <div class="slide active">
      <h1>SLIDE 1</h1>
      <p>HELLO</p>
   </div>

   <div class="slide">
      <h1>SLIDE 2</h1>
      <p>WELCOME</p>
   </div>

   <div class="slide">
      <h1>SLIDE 3</h1>
      <p>THANK YOU!</p>
   </div>

   <button class="prev" onclick="prevSlide()">Previous</button>
   <button class="next" onclick="nextSlide()">Next</button>

   <script>
      let index = 0;
      const slides = document.querySelectorAll('.slide');

      function showSlide(n) {
         slides[index].classList.remove('active');
         index = (n + slides.length) % slides.length;
         slides[index].classList.add('active');
      }

      function prevSlide() {
         showSlide(index - 1);
      }

      function nextSlide() {
         showSlide(index + 1);
      }

      showSlide(index);
   </script>
</body>
</html>

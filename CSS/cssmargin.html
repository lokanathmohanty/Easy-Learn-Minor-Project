CSS Margins

CSS margins are used to create space around the outer part of an element. Margins help in controlling the spacing and alignment of elements within a webpage layout.

What is CSS Margin?

  • A margin in CSS adds extra space around elements, outside their border.
  • You can set margins individually for each side of an element: margin-top, margin-right, margin-bottom, margin-left.
  • Margins can accept positive or negative values. Negative margins cause elements to overlap.

CSS Margins Example

margin: 1em;
margin: 10px 0;
margin: 10px 50px 20px;
margin: 10px 50px 20px 40px;
margin: 30px;

Define Margin

The margin property is a shorthand property of the individual sides. A single value applies to all four sides.

Syntax

margin: value;

Example

<div style="margin: 20px;">CSS Margin 20px all sides</div>
<div style="margin: 10px;">CSS Margin 10px all sides</div>

CSS Individual Margin Properties

You can set margin values for each side separately:

  • margin-top: sets the top margin.
  • margin-right: sets the right margin.
  • margin-bottom: sets the bottom margin.
  • margin-left: sets the left margin.

Syntax

margin-top: value;
margin-right: value;
margin-bottom: value;
margin-left: value;

Example

<p style="margin-top: 20px;">Margin Top</p>
<p style="margin-right: 30px;">Margin Right</p>
<p style="margin-bottom: 30px;">Margin Bottom</p>
<p style="margin-left: 15px;">Margin Left</p>

CSS Margin Shorthand Property

The margin shorthand property allows specifying up to four values:

  • One Value: applies to all sides.
  • Two Values: first for top & bottom, second for left & right.
  • Three Values: first for top, second for left & right, third for bottom.
  • Four Values: top, right, bottom, left (clockwise).

Syntax

margin: value;                /* single */
margin: value1 value2;        /* double */
margin: value1 value2 value3; /* triple */
margin: value1 value2 value3 value4; /* four */

Example

<p style="margin: 20px;">Single Value</p>
<p style="margin: 10px 20px;">Two Values</p>
<p style="margin: 10px 15px 20px;">Three Values</p>
<p style="margin: 5px 10px 15px 20px;">Four Values</p>

Margin Mix-up Units

You can use different units in shorthand margin values.

Syntax

margin: 20px 4ex .5in 3em;

Example

<h2 style="margin: 20px 4ex .5in 3em;">
  Mixed units applied as margin
</h2>

Using Margin with Percentage Value

Percentage margins are calculated relative to the width of the parent element.

Example

<div style="width:300px;">
  <p style="margin:10%;">
    This margin is 10% of 300px = 30px
  </p>
</div>

Centering Elements with CSS Margin

To center an element, set margin: auto along with a defined width.

Example

<div style="width:200px; margin:auto;">
  Centered element using margin:auto
</div>

Margin Properties Reference

  • margin — shorthand property for all margins.
  • margin-top — sets top margin.
  • margin-right — sets right margin.
  • margin-bottom — sets bottom margin.
  • margin-left — sets left margin.

JavaScript - Comparison Operators

The comparison operators in JavaScript compare two variables or values and return a boolean value (true or false) based on the comparison result. They are used in logical expressions to test equality or relational conditions.

All comparison operators are binary operators because they perform operations on two operands, which can be numbers, strings, booleans, or objects.

Operators Overview

  • == → Equal
  • != → Not Equal
  • === → Strict Equality (value + type)
  • !== → Strict Inequality (value + type)
  • > → Greater Than
  • < → Less Than
  • >= → Greater Than or Equal To
  • <= → Less Than or Equal To

How Comparison is Done

If both operands are of the same type, values are compared directly. If not, JavaScript performs type coercion before comparing.

  • Numeric strings → converted to numbers.
  • Non-numeric strings → converted to NaN.
  • Empty strings → converted to 0.

Strict operators (===, !==) do not perform type coercion.

Falsy Values

These are treated as false in comparisons:

  • 0
  • false
  • "" (empty string)
  • null
  • undefined
  • NaN

Equality (==) Operator

Checks if values are equal, with type conversion if needed.


const a = 10, b = 20;
a == 10;      // true
a == b;       // false
"Hello" == "Hello"; // true
5 == '5';     // true
0 == false;   // true
0 == '';      // true

Inequality (!=) Operator

Checks if values are not equal, with type conversion if needed.


10 != 10;   // false
10 != 20;   // true
"Hello" != "Hello"; // false
10 != '10'; // false
0 != false; // false

Strict Equality (===) Operator

Checks if values and types are strictly equal (no type conversion).


10 === 10;      // true
10 === 20;      // false
'Hello' === 'Hello'; // true
10 === '10';    // false
0 === false;    // false

Strict Inequality (!==) Operator

Checks if values or types are different (no type conversion).


10 !== 10;   // false
10 !== 20;   // true
'Hello' !== 'Hello'; // false
10 !== '10'; // true
0 !== false; // true

Greater Than (>) Operator

Returns true if left operand is greater than right.


20 > 10;     // true
10 > 10;     // false
"ab" > "aa"; // true
10 > '5';    // true

Greater Than or Equal To (>=)

Returns true if left operand is greater than or equal to right.


10 >= 5;    // true
5 >= 5;     // true
"ab" >= "aa"; // true
10 >= '5';  // true

Less Than (<) Operator

Returns true if left operand is less than right.


10 < 20;     // true
5 < 5;       // false
"ab" < "aa"; // true
10 < '5';    // false

Less Than or Equal To (<=)

Returns true if left operand is less than or equal to right.


10 <= 20;    // true
5 <= 5;      // true
"ab" <= "aa"; // false
10 <= '5';   // false

Comparing null, undefined, and NaN


0 == null;       // false
0 == undefined;  // false
0 == NaN;        // false
null == undefined;  // true
null === undefined; // false
NaN == NaN;      // false

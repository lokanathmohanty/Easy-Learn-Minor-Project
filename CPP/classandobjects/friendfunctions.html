C++ Friend Functions and Classes (Trusted Access) 🤝

A **friend function** is a function that is **defined outside a class's scope** but is granted special permission to access all of that class's **private** and **protected** members. Although its prototype appears in the class definition, a friend function is **not a member function** of the class.

Declaring a Friend Function

To establish a function as a friend, its prototype must be placed inside the class definition, preceded by the keyword **friend**.

class Box {
   private:
      double width;
   public:
      // Declares printWidth as a friend function
      friend void printWidth(Box box); 
      void setWidth(double wid);
};

// Definition is outside the class scope
void printWidth(Box box) {
   // This function can now access box.width directly
   cout << "Width: " << box.width << endl; 
}

The friend function must accept the class object as a parameter (by value or reference) to access its members.

Friend Functions vs. Member Functions

FeatureFriend FunctionMember Function
Membership **Non-member** function. **Member** of the class.
Access to this **No** access to the implicit this pointer. **Has** access to the implicit this pointer.
Call Site Called like a normal function: functionName(object). Called using the object: object.functionName().
Inheritance Cannot be inherited by derived classes. Can be inherited by derived classes.

Friend Classes

If an entire class is declared as a friend, it is known as a **friend class**. This grants **all member functions** of the friend class the ability to access the private and protected members of the class that declared it as a friend.

class ClassA {
   private:
      int dataA;
   public:
      // Declare ClassB as a friend of ClassA
      friend class ClassB; 
};

class ClassB {
   public:
      void showDataFromA(const ClassA& objA) {
         // ClassB can access ClassA's private dataA
         cout << objA.dataA << endl; 
      }
};

A **forward declaration** (`class ClassB;`) is often required if the friend class is referenced before its definition.

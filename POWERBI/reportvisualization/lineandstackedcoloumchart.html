Power BI: Line and Stacked Column Chart

The Line and Stacked Column Chart is a combination chart that merges a stacked column chart and a line chart. It is useful for comparing different measures over time or categories, such as tracking net sales revenue alongside gross sales.

The main components are the X-axis (categories), Column Y-axis (values for stacked columns), and Line Y-axis (values for the line).

How to Build Line and Stacked Column Chart

  • Import the dataset into Power BI Desktop.
  • Select the "Line and Stacked Column Chart" from the Visualization pane.
  • Add the Year field to the X-axis.
  • Place the Net Sales field in the Column Y-axis section.
  • Add the Gross Sales field to the Line Y-axis section.
  • Optionally, add a categorical field like Name to the Column Legend for color coding.
  • Use the Small Multiples feature to divide the chart by a field such as Region, creating separate smaller charts.
  • Add extra fields like Designation and Region into Tooltips to show detailed info on hover.
  • Use Drill Through on fields like Net Sales to filter and explore data effectively.

Customization Options

  • X-axis: Set type to "Categorical", change font style (e.g., Georgia), size, color, and apply italics. Enable title and customize text and style.
  • Y-axis: Adjust minimum and maximum values, font style (e.g., Segoe UI Bold), color (e.g., red), and toggle title display with customization.
  • Secondary Y-axis: Configure range, font style (e.g., Symbol), font size, color, and visibility of values and title.
  • Legend: Position (e.g., Center right), font style (e.g., Constantia, Italic), and color customization.
  • Gridlines: Enable horizontal gridlines, choose style (solid), color, and line thickness.
  • Zoom Slider: Enable zoom sliders for both Y-axes for detailed examination.
  • Columns: Adjust column color transparency, enable and customize borders.
  • Lines: Change line style (e.g., dashed) and type (e.g., smooth).
  • Markers: Enable and change shape (e.g., triangle) for data points on the line chart.
  • Data Labels and Series Labels: Toggle on to show labels on chart and series.
  • Total Labels: Enable total labels with customizable fonts and background.

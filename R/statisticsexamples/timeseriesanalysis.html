R - Time Series Analysis

Time series analysis deals with data points ordered in time, such as stock prices or monthly rainfall. R handles time series data using specialized objects created with the ts() function, which can store numeric data with associated timestamps and frequency.

ts() Function Syntax

timeseries.object.name <- ts(data, start, end, frequency)
  • data: Numeric vector or matrix of observations
  • start: Start time of series (optional)
  • end: End time of series (optional)
  • frequency: Number of observations per unit time (e.g., 12 for monthly)

Example: Single Time Series

# Monthly rainfall data starting Jan 2012
rainfall <- c(799, 1174.8, 865.1, 1334.6, 635.4, 918.5, 685.5,
               998.6, 784.2, 985, 882.8, 1071)

# Create time series object
rainfall.timeseries <- ts(rainfall, start = c(2012, 1), frequency = 12)

# Print the time series
print(rainfall.timeseries)

# Save the plot
png(file = "rainfall.png")

# Plot the time series
plot(rainfall.timeseries)

# Close device
dev.off()

Frequency Values

  • frequency = 12: Monthly data per year
  • frequency = 4: Quarterly data
  • frequency = 6: Data every 10 minutes in an hour
  • frequency = 24*6: Data every 10 minutes in a day

Example: Multiple Time Series

# Two rainfall series
rainfall1 <- c(799, 1174.8, 865.1, 1334.6, 635.4, 918.5, 685.5,
                998.6, 784.2, 985, 882.8, 1071)
rainfall2 <- c(655, 1306.9, 1323.4, 1172.2, 562.2, 824, 822.4,
                1265.5, 799.6, 1105.6, 1106.7, 1337.8)

# Combine into matrix
combined.rainfall <- matrix(c(rainfall1, rainfall2), nrow = 12)

# Create time series object with two series
rainfall.timeseries <- ts(combined.rainfall, start = c(2012, 1), frequency = 12)

# Print the time series matrix
print(rainfall.timeseries)

# Save the plot
png(file = "rainfall_combined.png")

# Plot multiple time series
plot(rainfall.timeseries, main = "Multiple Time Series")

# Close device
dev.off()

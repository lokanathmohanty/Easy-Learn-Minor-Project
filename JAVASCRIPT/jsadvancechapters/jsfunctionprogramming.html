JavaScript - Functional Programming

There are mainly two programming paradigms: the imperative programming paradigm and the declarative programming paradigm. Functional programming is a subtype of the declarative paradigm. The term paradigm refers to the approach to solving a particular problem.

Functional programming has been in use for the last decades but came into trend after 2015 when the last main revised version of JavaScript was released. There are many benefits to using functional programming, which we will discuss in this tutorial.

Characteristics of Functional Programming

Functional programming works as mathematical functions work. It allows developers to develop software based on function evaluation. Programmers can break the code into small parts (functions), making it easier to evaluate and test code. The following concepts are covered in this tutorial:

  • Pure Functions
  • Code Readability
  • Immutability
  • Higher-Order Functions

Pure Functions

In JavaScript, we can write pure functions. A pure function takes values as parameters, performs some operations, and returns the output. It never shares variables with other functions or uses global variables.

Properties of a pure function:

  • Always returns the same output for the same input.
  • Does not depend on any external state or variables that are not passed as arguments.
  • Does not produce side effects such as modifying global variables or changing the state of external objects.

Example: Pure Function

In the example below, pure_func() takes a value as a parameter and multiplies it by 2. It does not rely on or modify any global variables.

<html>
<body>
  <h2>Pure Function Example</h2>
  <div id="result"></div>
  <script>
    let result = document.getElementById('result');
    let global_var = 10;
    function pure_func(value){
       return value * 2;
    }
    result.innerHTML = pure_func(5);
  </script>
</body>
</html>

Immutability in JavaScript

Immutability means that once a value is declared, it cannot be changed. In JavaScript, immutability can be achieved with the const keyword.

Example: Immutability

<html>
<body>
  <h2>Immutability Example</h2>
  <div id="result"></div>
  <script>
    let result = document.getElementById('result');
    const value = 10;
    value = 20; // ❌ Error
    result.innerHTML = value;
  </script>
</body>
</html>

Output: TypeError: Assignment to constant variable.

Code Readability

Since functional programming relies heavily on functions, it makes code more readable. Instead of manual loops, methods like for-of, filter(), and map() clearly express the intent of the operation.

For example, filtering values from an array is easier with filter() compared to writing a manual loop.

Higher-Order Functions

A higher-order function is a function that takes another function as an argument or returns one. For example, the reduce() method accepts a callback function to reduce an array into a single value.

Example: Higher-Order Function

<html>
<body>
  <h2>Higher Order Function Example</h2>
  <div id="result"></div>
  <script>
    let result = document.getElementById('result');
    let arr = [1, 2, 3, 4, 5];
    let sum = arr.reduce((acc, val) => acc + val);
    result.innerHTML = sum;
  </script>
</body>
</html>

Conclusion

We learned that functional programming in JavaScript helps write maintainable and readable code with fewer bugs by focusing on pure functions, immutability, and higher-order functions.

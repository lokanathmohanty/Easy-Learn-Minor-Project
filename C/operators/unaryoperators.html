Unary Operators in C

While most operators in C are binary (require two operands), there are several unary operators that operate on only one operand. Examples include ++, --, !, ~, etc.

The Increment Operator (++)

The increment operator ++ adds 1 to its operand. For example, a++ is equivalent to a = a + 1.

It can be used as:

  • prefix (++a): increments before use
  • postfix (a++): uses value, then increments

Example:

b = a++; // assigns a to b, then increments a
b = ++a; // increments a, then assigns it to b

The Decrement Operator (--)

The decrement operator -- subtracts 1 from its operand. a-- is equivalent to a = a - 1.

It also has prefix and postfix forms:

b = a--; // assigns a to b, then decrements a
b = --a; // decrements a, then assigns it to b

The Unary "+" Operator

The + operator can be used as a unary operator, though it has no visible effect. For example, +5 is the same as 5.

Example:

#include <stdio.h>

int main(){
   char x = 'A';
   char y = +x;

   float a = 1.55;
   float b = +a;

   printf ("x: %c y: %c\n", x, y);
   printf ("a: %f b: %f\n", a, b);

   return 0;
}

Output:

x: A y: A
a: 1.550000 b: 1.550000

The Unary "−" Operator

The unary minus operator - negates the value of its operand.

#include <stdio.h>

int main(){
   int x = 5;
   int y = -x;

   printf("x: %d y: %d\n", x, y);

   return 0;
}

Output:

x: 5 y: -5

The Address-of Operator (&)

The & operator, when used as a unary operator, returns the memory address of a variable.

#include <stdio.h>

int main(){
   char x = 'A';
   printf ("Address of x: %p\n", &x);
   return 0;
}

Output:

Address of x: 0x61fe1f

Note: The address may vary every time you run the program.

The Dereference Operator (*)

The * operator is used to access the value at a memory address (dereferencing a pointer).

Example 1:

#include <stdio.h>

int main(){
   int x = 10;
   int *y = &x;

   printf ("x: %d Address of x: %p\n", x, &x);
   printf("Value at x with Dereference: %d\n", *y);

   return 0;
}

Output:

x: 10 Address of x: 0x61fe1f
Value at x with Dereference: 10

Example 2: Modifying Value via Pointer

#include <stdio.h>

int main(){
   int x = 10;
   int *y = &x;

   *y = 20;

   printf("x: %d with Dereference: %d\n", x, *y);

   return 0;
}

Output:

x: 20 with Dereference: 20

The Logical NOT Operator (!)

The logical NOT operator ! inverts a Boolean value: true becomes false and vice versa.

Example 1:

#include <stdio.h>

int main(){
   int a = 0;
   int b = 20;

   if (!(a && b)){
      printf("Line 1 - Condition is true\n");
   }

   return 0;
}

Output:

Line 1 - Condition is true

Example 2:

#include <stdio.h>

int main(){
   int i = 0;

   while (!(i > 5)){
      printf("i = %d\n", i);
      i++;
   }

   return 0;
}

Output:

i = 0
i = 1
i = 2
i = 3
i = 4
i = 5

The 1's Complement Operator (~)

The ~ operator flips all the bits in the binary representation of an integer (1's become 0's, and vice versa).

Example: If a = 60 (binary: 0011 1100), then ~a becomes 1100 0011, which is -61 in two's complement form.

#include <stdio.h>

int main(){
   int a = 60;   // 0011 1100
   int c = ~a;   // 1100 0011 (binary), -61 in decimal

   printf("Value of c is %d \n", c);

   return 0;
}

Output:

Value of c is -61

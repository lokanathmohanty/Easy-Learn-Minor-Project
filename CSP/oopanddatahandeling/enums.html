C# Enums (Enumerations)

What is an Enumeration?

An **enumeration (enum)** is a **special value type** that defines a set of **named integer constants**. It provides a way to assign meaningful names to integral values, making code easier to read and maintain by limiting variables to a discrete, known set of values.

Enums are ideal for representing related, mutually exclusive values such as days of the week, error codes, directions, or states.

Declaring and Using Enums

Declaration Syntax:

An enumerated type is declared using the **`enum`** keyword.

enum <enum_name> {
   enumeration list 
};

Default Values:

By default, the underlying type of an enum is **`int`**. The first member is assigned the value **0**, and each subsequent member is incremented by 1.

enum Days { Sun, Mon, Tue, Wed, Thu, Fri, Sat }; 
// Sun = 0, Mon = 1, Tue = 2, and so on.

You can explicitly cast an enum member to its integer value:

int WeekdayStart = (int)Days.Mon; // WeekdayStart is 1

Specifying Custom Values:

You can assign explicit, custom integer values to enum members, which is common for status or error codes:

enum StatusCode {
   Success = 200,
   NotFound = 404,
   ServerError = 500
}

Advanced Enum Usage

1. Enums with `switch` Statements

Enums naturally integrate with `switch` statements, improving readability by using constants instead of hard-coded integers:

Weekday today = Weekday.Wednesday;

switch (today) {
    case Weekday.Wednesday:
        Console.WriteLine("It's Wednesday.");
        break;
    // ... other cases
}

2. Enum Flags for Combined Values

The **`[Flags]`** attribute allows an enum to represent a combination of values, typically for permissions or settings. Each value should be a power of 2 (1, 2, 4, 8, etc.) to allow for bitwise combination using the OR operator (`|`).

[Flags]
enum Permissions {
    None = 0,
    Read = 1,    // 001
    Write = 2,   // 010
    Execute = 4, // 100
}

Permissions userPermissions = Permissions.Read | Permissions.Write;
// userPermissions now holds the combined value (3)

3. Parsing Enums (String to Enum)

The static **`Enum.Parse()`** method is used to convert a string representation back into an enum value:

enum OrderStatus { Pending = 0, Processing = 1 }

string input = "Processing";
OrderStatus status = (OrderStatus)Enum.Parse(typeof(OrderStatus), input);
// status is now OrderStatus.Processing

JavaScript - Date

The Date object is a datatype built into the JavaScript language. Date objects are created with new Date().

Once a Date object is created, a number of methods allow you to operate on it. Most methods allow you to get and set the year, month, day, hour, minute, second, and millisecond fields of the object using either local time or UTC time.

The ECMAScript standard requires the Date object to represent any date and time, to millisecond precision, within 100 million days before or after 1/1/1970.

Syntax

  • new Date()
  • new Date(milliseconds)
  • new Date(datestring)
  • new Date(year, month, date[, hour, minute, second, millisecond])

Note: Parameters in brackets are optional.

Parameters

  • No Argument − Creates a Date object with the current date and time.
  • milliseconds − Numeric value of milliseconds since 1/1/1970.
  • datestring − String representation of a date accepted by Date.parse().
  • 7 arguments − year, month, date, hour, minute, second, millisecond.

Return Value

It returns the date string containing day, month, date, year, hours, minutes, seconds, and timezone.

JavaScript Date Reference

The Date object provides methods for creating, manipulating, and formatting dates and times.

Date Static Methods

  • Date.parse() − Parses a string and returns milliseconds.
  • Date.UTC() − Returns the milliseconds for a given UTC date.

Date Methods

  • getDate() − Returns day of the month.
  • getDay() − Returns day of the week.
  • getFullYear() − Returns the year.
  • getHours() − Returns the hours.
  • getMilliseconds() − Returns the milliseconds.
  • getMinutes() − Returns the minutes.
  • getMonth() − Returns the month.
  • getSeconds() − Returns the seconds.
  • getTime() − Returns milliseconds since Jan 1, 1970.
  • toDateString() − Returns date as a human-readable string.
  • toISOString() − Returns ISO format string.
  • toLocaleDateString() − Returns date in locale format.
  • toUTCString() − Returns date in UTC string format.

Examples

Creating JavaScript Date Object

<script>
const date = new Date();
document.getElementById("output").innerHTML = "Today's date is: " + date;
</script>

Setting a Custom Date

<script>
const date = new Date("August 19, 2024 09:30:54");
document.getElementById("output").innerHTML = "The custom date is: " + date;
</script>

Using Milliseconds

<script>
let date = new Date(999999999999);
console.log(date);
date = new Date(-999999999999);
console.log(date);
</script>

Constructing a Date with 7 Arguments

<script>
const date = new Date(2001, 5, 14, 6, 43, 58, 342);
console.log(date);
</script>

Formatting Dates

<script>
const date = new Date(999999999999);
console.log(date.toDateString());
console.log(date.toISOString());
console.log(date.toUTCString());
</script>

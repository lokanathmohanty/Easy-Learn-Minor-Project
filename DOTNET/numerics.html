.NET Core Numerics: Primitive and Advanced Data Types

.NET Core provides support for **standard numeric primitives** (integral and floating-point) as well as several **advanced numeric types** in the System.Numerics namespace for large integers, complex math, and high-performance vector processing.

Integral Types (Integers)

These are **value types** that support signed and unsigned integers ranging from one byte to eight bytes in length. All integral types support standard arithmetic, comparison, equality, and conversion operators. The System.BitConverter class can be used to work with individual bits.

Type Signed/Unsigned Size (bytes) Minimum Value Maximum Value
**Byte** Unsigned 1 0 255
**SByte** Signed 1 -128 127
**Int16** Signed 2 -32,768 32,767
**UInt16** Unsigned 2 0 65,535
**Int32** Signed 4 -2,147,483,648 2,147,483,647
**UInt32** Unsigned 4 0 4,294,967,295
**Int64** Signed 8 -9,223,372,036,854,775,808 9,223,372,036,854,775,807
**UInt64** Unsigned 8 0 18,446,744,073,709,551,615

Floating-Point Types

.NET Core provides three primitive types for working with floating-point numbers. They support standard arithmetic and conversion operators. The Decimal type includes specialized methods (Decimal.GetBits) for bit-level operations.

Type Size (bytes) Minimum Value Maximum Value
**Single** 4 -3.402823e38 3.402823e38
**Double** 8 -1.79769313486232e308 1.79769313486232e308
**Decimal** 16 -79,228,162,514,264,337,593,543,950,335 79,228,162,514,264,337,593,543,950,335

Advanced Numeric Types in System.Numerics

The System.Numerics namespace introduces types for advanced mathematical and high-performance computing:

  • **System.Numerics.BigInteger**: An **immutable integral type** that can represent integers of **arbitrarily large size**, having no upper or lower bound in theory (limited only by memory). Its methods parallel those of standard integral types.
  • **System.Numerics.Complex**: A type used to represent **complex numbers**, consisting of a real number part and an imaginary number part. It supports a comprehensive set of arithmetic, algebraic, and trigonometric methods.

SIMD-Enabled Vector Types (Performance)

SIMD (**Single Instruction Multiple Data**) types are included for huge performance gains in mathematical, scientific, and graphics applications by enabling parallel operations at the hardware level. Key SIMD types include:

  • **Vectors (Single)**: Vector2, Vector3, and Vector4 (2, 3, and 4-dimensional vectors of type Single).
  • **Generic Vectors**: The Vector<T> structure, which can be a vector of any primitive numeric type (excluding Decimal).
  • **Matrices**: Matrix3x2 (3x2 matrix) and Matrix4x4 (4x4 matrix).
  • **3D Math**: Plane (three-dimensional plane) and Quaternion (vector used for 3D physical rotations).

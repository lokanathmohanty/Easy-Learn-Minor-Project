CSS - place-self Property

The CSS place-self property is a shorthand property used to align individual items within a grid or flex container. It combines two properties:

  • align-self – controls alignment in the block (vertical) direction.
  • justify-self – controls alignment in the inline (horizontal) direction.

By using place-self, you can set both values in a single line. If only one value is provided, it applies to align-self, while justify-self defaults to auto.

Possible Values

  • auto – Uses the parent’s align-self value.
  • normal – Acts differently depending on layout mode:
    • Behaves like start on replaced absolutely positioned boxes.
    • Behaves like stretch in most other contexts.
  • self-start – Aligns item to the start edge of its alignment container.
  • self-end – Aligns item to the end edge of its alignment container.
  • flex-start – Aligns item to the start of the cross-axis.
  • flex-end – Aligns item to the end of the cross-axis.
  • center – Centers the item within its container.
  • baseline / first baseline / last baseline – Aligns item with baseline rules.
  • stretch – Stretches the item to fill available space.

Syntax

Examples of valid syntax:

  • place-self: auto center;
  • place-self: normal start;
  • place-self: center normal;
  • place-self: self-start auto;
  • place-self: flex-end normal;
  • place-self: stretch auto;

Applies To

This property applies to block-level boxes, absolutely positioned boxes, flex items, and grid items.

Examples

Example 1: place-self: normal start

In this example, Item 2 is aligned to the start of its grid cell. 

.container {
  display: grid;
  grid-template-columns: 1fr 1fr;
  grid-auto-rows: 100px;
}
.item2 {
  place-self: normal start;
}

Example 2: place-self: auto center

In this example, Item 2 is centered inside its grid cell. 

.container {
  display: grid;
  grid-template-columns: 1fr 1fr;
  grid-auto-rows: 100px;
}
.item2 {
  place-self: auto center;
}

Example 3: place-self: center normal

In this case, Item 2 is aligned both horizontally and vertically in the center. 

.container {
  display: grid;
  grid-template-columns: 1fr 1fr;
  grid-auto-rows: 100px;
}
.item2 {
  place-self: center normal;
}

Example 4: place-self: end normal

Here, Item 2 is aligned to the end of its grid cell. 

.item2 {
  place-self: end normal;
}

Example 5: place-self: self-start auto

Item 2 is aligned to the start of the row vertically, with automatic horizontal positioning. 

.item2 {
  place-self: self-start auto;
}

Example 6: place-self: flex-end normal

Aligns Item 2 to the right edge of its container. 

.item2 {
  place-self: flex-end normal;
}

Example 7: place-self: baseline normal

Aligns Item 2 to the baseline of the row. 

.item2 {
  place-self: baseline normal;
}

Example 8: place-self: stretch auto

This makes Item 2 stretch to fill its grid cell horizontally. 

.item2 {
  place-self: stretch auto;
}

Summary

The place-self property is a powerful shorthand for aligning items in grid and flexbox layouts. It allows developers to control both vertical and horizontal alignment with a single declaration. This makes layouts more concise and easier to manage compared to setting align-self and justify-self separately.

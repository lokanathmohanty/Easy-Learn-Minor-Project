JavaScript - Strings

The String object in JavaScript lets you work with a series of characters; it wraps JavaScript's string primitive data type with a number of helper methods.

As JavaScript automatically converts between string primitives and String objects, you can call any of the helper methods of the String object on a string primitive.

The string is a sequence of characters containing 0 or more characters. For example, 'Hello' is a string.

Syntax

JavaScript strings can be created as objects using the String() constructor or as primitives using string literals.

var val = new String(value);

The String parameter, value is a series of characters that has been properly encoded.

We can also create string primitives:


str1 = 'Hello World!'; // single quote
str2 = "Hello World!"; // double quote
str3 = `Hello World`;  // back ticks
str4 = String('Hello World!'); // String() function

String Object Properties

  • constructor - Returns a reference to the String function that created the object.
  • length - Returns the length of the string.
  • prototype - Allows you to add properties and methods to an object.

String Object Methods

Static Methods

  • fromCharCode() - Converts UTF-16 code units into a string.
  • fromCodePoint() - Creates a string from ASCII values.

Instance Methods

  • at() - Returns character from specified index.
  • charAt() - Returns the character at the specified index.
  • charCodeAt() - Returns Unicode value of character at given index.
  • codePointAt() - Returns Unicode value at index.
  • concat() - Combines two strings.
  • endsWith() - Checks if string ends with substring.
  • includes() - Checks if one string exists in another.
  • indexOf() - Returns first index of occurrence.
  • lastIndexOf() - Returns last index of occurrence.
  • localeCompare() - Compares two strings in sort order.
  • match() - Matches regex against a string.
  • matchAll() - Matches all regex patterns.
  • normalize() - Returns Unicode normalization.
  • padEnd() - Pads string at end.
  • padStart() - Pads string at start.
  • raw() - Returns raw string from template literal.
  • repeat() - Repeats string N times.
  • replace() - Replaces first match with new substring.
  • replaceAll() - Replaces all matches with new substring.
  • search() - Searches for regex match.
  • slice() - Extracts part of string.
  • split() - Splits string into array.
  • substr() - Returns substring from location with length.
  • substring() - Returns substring between indexes.
  • toLocaleLowerCase() - Lowercase respecting locale.
  • toLocaleUpperCase() - Uppercase respecting locale.
  • toLowerCase() - Converts to lowercase.
  • toString() - Returns string representation.
  • toUpperCase() - Converts to uppercase.
  • toWellFormed() - Returns well-formed copy.
  • trim() - Removes whitespace from both ends.
  • trimEnd() - Removes whitespace at end.
  • trimStart() - Removes whitespace at start.
  • valueOf() - Returns primitive value of string.

String Constructor

String() - Creates a string object and initializes it with provided value.

Examples

Creating JavaScript String Objects


const str = new String("Hello World!");
console.log(str);       // Hello World!
console.log(typeof str); // object

Accessing a String


let str1 = new String("Welcome!");
let str2 = "Welcome!";
console.log(str1[0]); // W
console.log(str2[4]); // o

Case Sensitivity


let char1 = 'S';
let char2 = 's';
console.log(char1 == char2); // false

Strings Are Immutable


let str = "Animal";
str[0] = 'j';
console.log(str); // Animal
str = "Hi!";
console.log(str); // Hi!

Escape Characters

  • \" - Double quote
  • \' - Single quote
  • \\ - Backslash
  • \n - New line
  • \t - Tab
  • \b - Backspace
  • \f - Form feed
  • \v - Vertical tab
  • \r - Carriage return
  • \uXXXX - Unicode escape

let str1 = "Your\'s welcome!";
let str2 = "Backslash \\";
console.log(str1); // Your's welcome!
console.log(str2); // Backslash \

String HTML Wrappers

  • anchor() - Creates an HTML anchor.
  • big() - Displays string in big font.
  • blink() - Makes string blink.
  • bold() - Displays string in bold.
  • fixed() - Displays string in fixed-pitch font.
  • fontcolor() - Sets font color.
  • fontsize() - Sets font size.
  • italics() - Displays string in italics.
  • link() - Creates hyperlink.
  • small() - Displays string in small font.
  • strike() - Struck-out text.
  • sub() - Subscript text.
  • sup() - Superscript text.

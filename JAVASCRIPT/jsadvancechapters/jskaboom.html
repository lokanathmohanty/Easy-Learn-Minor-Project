JavaScript - Kaboom.js

Kaboom.js makes it easy to create JavaScript games. You can add physics, detect collisions, and use sprites in different scenes. Kaboom helps developers focus on creativity instead of complex coding. Features like backgrounds, power-ups, and scoring can be added to enhance gameplay.

Getting Started with Kaboom

To initialize Kaboom, call the kaboom() function to set up the context: 

kaboom({
   global: true,
});

When building in your editor, include both your JS file and the Kaboom.js library in your HTML file: 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Simple Kaboom Game</title>
    <script src="https://kaboomjs.com/lib/0.5.0/kaboom.js"></script>
</head>
<body>
    <script src="example.js"></script>
</body>
</html>

Create a Scene

A scene defines how the game will look, behave, and play out: 

kaboom({
   global: true,
});

scene("main", () => {
   //...
});

start("main");

Load Sprites and Create Player

Sprites are images used in your game. Use loadSprite() to load them and add() to display: 

kaboom({
  global: true,
});

loadRoot('https://i.imgur.com/');
loadSprite('yeti', 'OqVwAm6.png');

scene('main', () => {
  const yeti = add([
    sprite('yeti'),
    pos(80, 80),
    color(255, 188, 0),
  ]);
});

start('main');

This will display the yeti sprite in your game window.

Add Physics (Body and Ground)

The body() component gives your sprite gravity. Add a ground to stop the sprite from falling: 

kaboom({
  global: true,
});

loadRoot('https://i.imgur.com/');
loadSprite('yeti', 'OqVwAm6.png');

scene('main', () => {
  const yeti = add([
    sprite('yeti'),
    pos(80, 80),
    color(255, 188, 0),
    body(),
  ]);

  // Add the ground
  add([
    rect(width(), 12),
    pos(0, 280),
    origin('topleft'),
    solid(),
  ]);
});

start('main');

Kaboom Key Events

Add movement and jumping to your sprite with key events: 

kaboom({
  global: true,
});

loadRoot('https://i.imgur.com/');
loadSprite('yeti', 'OqVwAm6.png');

scene('main', () => {
  const yeti = add([
    sprite('yeti'),
    pos(80, 80),
    color(255, 188, 0),
    body(),
  ]);

  add([
    rect(width(), 12),
    pos(0, 280),
    origin('topleft'),
    solid(),
  ]);

  // Controls
  const JUMP_FORCE = 320;
  const MOVE_SPEED = 120;

  keyPress("space", () => {
    yeti.jump(JUMP_FORCE);
  });

  keyDown("left", () => {
    yeti.move(-MOVE_SPEED, 0);
  });

  keyDown("right", () => {
    yeti.move(MOVE_SPEED, 0);
  });
});

start('main');

Add a Background Image

You can also add a background sprite to your game: 

kaboom({
   global: true,
});

loadSprite("yeti", "https://i.imgur.com/OqVwAm6.png");
loadSprite("bg", "/Users/abc/Downloads/image.jpg");

scene("main", () => {
   // Add background
   add([
      sprite("bg"),
      scale(width() / 240, height() / 240),
      origin("topleft"),
   ]);

   const yeti = add([
      sprite("yeti"),
      pos(80, 80),
      color(255, 188, 0),
      body(),
   ]);

   add([
      rect(width(), 12),
      pos(0, 280),
      origin("topleft"),
      solid(),
   ]);

   const JUMP_FORCE = 320;
   const MOVE_SPEED = 120;

   keyPress("space", () => {
      yeti.jump(JUMP_FORCE);
   });

   keyDown("left", () => {
      yeti.move(-MOVE_SPEED, 0);
   });

   keyDown("right", () => {
      yeti.move(MOVE_SPEED, 0);
   });
});

start("main");

Summary

Kaboom.js is a beginner-friendly library for building JavaScript games. You can initialize contexts, create scenes, add sprites, apply physics, handle events, and include backgrounds. With Kaboom, game development becomes easier and more fun.

ReactJS - Using useContext

Context provides a way to share values like configuration, theme, or user data across components without passing props manually at every level. It improves readability and simplifies global state management.

Use Cases

  • Application configuration
  • Current authenticated user information
  • User settings (language, preferences)
  • Theme or design configuration

How Context Works

Context consists of four parts:

  • Creating a new context
  • Providing context in the root component
  • Consuming context in a child component
  • Accessing values using useContext

Example: Creating Context

import React from 'react';

const ThemeContext = React.createContext({
   color: 'black',
   backgroundColor: 'white'
});

export default ThemeContext;

Example: Providing Context

import ThemeContext from './ThemeContext';

function App() {
   return (
      <ThemeContext.Provider value={{
         color: 'white',
         backgroundColor: 'green'
      }}>
         <HelloWorld />
      </ThemeContext.Provider>
   );
}

export default App;

Example: Consuming with useContext

import React, { useContext } from "react";
import ThemeContext from "../ThemeContext";

function HelloWorld() {
   const theme = useContext(ThemeContext);

   return (
      <div style={{
         color: theme.color,
         backgroundColor: theme.backgroundColor
      }}>
         Hello World
      </div>
   );
}

export default HelloWorld;

Updating Context

You can combine useState with useContext to allow updating context values dynamically (e.g., switching themes). 

import { useState } from 'react';
import ThemeContext from './ThemeContext';
import HelloWorld from './HelloWorld';

function App() {
   const [theme, setTheme] = useState({
      color: 'white',
      backgroundColor: 'green'
   });

   return (
      <ThemeContext.Provider value={{ theme, setTheme }}>
         <HelloWorld />
      </ThemeContext.Provider>
   );
}

export default App;

Example: Changing Theme

import React, { useContext } from "react";
import ThemeContext from "../ThemeContext";

function HelloWorld() {
   const { theme, setTheme } = useContext(ThemeContext);

   return (
      <div style={{
         color: theme.color,
         backgroundColor: theme.backgroundColor
      }}>
         <select
            value={theme.backgroundColor}
            onChange={(e) => setTheme({
               ...theme,
               backgroundColor: e.target.value
            })}
         >
            <option value="green">Green</option>
            <option value="red">Red</option>
         </select>

         <div>Hello World</div>
      </div>
   );
}

export default HelloWorld;

Summary

Context simplifies sharing global data in React applications. The useContext hook makes consuming and updating context values easier, especially when combined with useState.

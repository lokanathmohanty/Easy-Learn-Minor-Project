Python Date and Time

Python provides several standard library modules to handle date and time operations including datetime, time, and calendar. These modules facilitate tasks such as converting date formats, performing date arithmetic, and generating calendars.

Time intervals are represented as floating-point numbers in seconds since the UNIX epoch: January 1, 1970, 00:00:00 UTC. Python's time module offers functions to work with these values including time.time() which returns the current ticks since the epoch.

The time Tuple and Tick Intervals

Many time-related functions return or accept a time tuple with 9 elements such as year, month, day, hour, minute, second, weekday, yearday, and daylight savings flag. For example, time.localtime() returns the current local time as a time tuple. 

import time
local_time = time.localtime()
print(local_time)

The elements can be accessed by their names like tm_year, tm_mon, tm_mday, etc.

Popular Time Functions

  • time.time() - Returns current time in seconds since epoch.
  • time.localtime() - Converts seconds to local time tuple.
  • time.asctime() - Converts time tuple to readable string.
  • time.sleep(secs) - Sleeps for the specified number of seconds.
  • time.strftime(format, time_tuple) - Formats a time tuple as a string.
  • time.strptime(string, format) - Parses a string to time tuple.

Calendar Module

The calendar module supplies functions for working with calendars including printing formatted monthly and yearly calendars. You can set the week start day, generate lists of weeks for a month, check for leap years, and more. 

import calendar
print(calendar.month(2023, 4))

datetime Module - Date Object

The datetime module provides classes to manipulate dates and times. The date class represents calendar dates (year, month, day). You can create dates, access date attributes, perform arithmetic, and format dates. 

from datetime import date

d = date(2023, 4, 20)
print(d.year, d.month, d.day)

Note: Invalid dates raise a ValueError.

datetime Module - time and datetime Objects

The time class represents time independent of date, including hour, minute, second, and microsecond. The datetime class combines both date and time. Both support attributes for their components and methods for formatting and arithmetic. 

from datetime import time, datetime

t = time(8, 15, 30)
dt = datetime(2023, 4, 20, 8, 15, 30)
print(t, dt)

Timedelta Object

The timedelta object represents a duration or difference between dates and times. You can add or subtract timedeltas to datetime objects to perform date arithmetic. 

from datetime import timedelta, datetime

now = datetime.now()
future_date = now + timedelta(days=5)
print(future_date)

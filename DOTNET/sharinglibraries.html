.NET Core - Sharing Libraries as NuGet Packages

To share a library for use in other projects, it must be packaged into a **NuGet package** (a .nupkg file). NuGet is the package manager for .NET, and the resulting package can be published to a public feed (nuget.org) or a private feed.

Creating the NuGet Package (dotnet pack)

The **.NET Core CLI** (Command Line Interface) is used to generate the NuGet package file from the library project:

  1. Open the command prompt and navigate to the folder containing the library's **project.json** file.
  2. Execute the **dotnet pack** command: 
    dotnet pack
  3. The command compiles the library and produces the NuGet package files in the **bin\Debug** folder.
  4. Two package files are generated:
    • **StringLibrary.1.0.0.nupkg**: Contains the compiled library (StringLibrary.dll) and package metadata/dependencies.
    • **StringLibrary.1.0.0.symbols.nupkg**: Contains source files (.cs files) and program database files (.pdb) necessary for debugging.

Configuring Package Metadata

The package metadata, such as the author, description, and version, is configured within the **project.json** file:

  1. Open the project.json file of your library project.
  2. Add or update metadata fields outside of the supports, dependencies, and frameworks sections.

Example of updated metadata in project.json:

{ 
   "authors": [ "Mark Junior" ], 
   "description": "String Library API", 
   "version" : "1.0.1-*", 
   "supports": {}, 
   
   "dependencies": { 
      // ... dependencies listed here ...
   }, 
   "frameworks": { 
      "netstandard1.3": {} 
   } 
}

After updating the version to 1.0.1-*, running **dotnet pack** again will generate a new package named **StringLibrary.1.0.1.nupkg** with the updated metadata.

Publishing the Package to a Private Feed

To consume the library in another project, it must be published to a NuGet feed (either public or private). Using a private feed is often simpler for internal sharing:

  1. **Install NuGet Commandline Utility**: This utility is required to push packages to a feed. It can be installed via the NuGet Package Manager UI (**nuget.commandline**) or downloaded manually.
  2. **Push the Package**: Open the command prompt, navigate to the **bin\Debug** folder, and use the nuget add command to copy the package to your private feed directory: 
    nuget add StringLibrary.1.0.1.nupkg -Source D:\PrivateNugetPackages

    The -Source argument specifies the local path of your private package feed.

  3. **Verification**: The NuGet package is installed into the private feed location, typically creating a folder structure like D:\PrivateNugetPackages\stringlibrary\1.0.1\StringLibrary.1.0.1.nupkg. The package is now ready to be consumed by other projects that reference this private source.

JavaScript - Object Properties

Introduction

An object property in JavaScript is a key: value pair, where the key is a string (also called the property name) and the value can be of any data type. Objects are essentially collections of such properties. These properties are not stored in a specific order.

Properties can be added, updated, or deleted dynamically in JavaScript objects.

Syntax

const fruit = {
  name: "Apple",
  price: 100,
}

In this example, fruit is an object with two properties: name and price.

Accessing Object Properties

There are three ways to access object properties:

  • Using dot notation
  • Using square bracket notation
  • Using an expression inside brackets

The Dot Notation

obj.prop

Example

const fruit = {
  name: "Banana",
  price: 20,
}
console.log("The price of the " + fruit.name + " is " + fruit.price);

Output

The price of the Banana is 20

The Square Bracket Notation

obj["prop"]

Square brackets are required when using keys that are invalid identifiers (for example, keys with spaces, numbers, or special characters).

Example

const fruit = {
  name: "Banana",
  price: 20,
}
console.log("The price of the " + fruit["name"] + " is " + fruit["price"]);

Output

The price of the Banana is 20

Using Expressions Inside Brackets

obj[expression]

Example

const num = {
  10: "Ten",
  20: "Twenty",
}
const x = 10;
console.log(num[x + 10]);

Output

Twenty

Accessing Nested Object Properties

Obj.prop.nestedProp
// OR
Obj["prop"]["nestedProp"];

Example

const cars = {
  audi: {
    model: "Q7",
    price: 10000000,
  },
  bmw: {
    model: "S20D",
    price: 8000000,
  }
}
console.log("Audi Model: " + cars.audi.model + " Price: " + cars.audi.price);
console.log("BMW Model: " + cars["bmw"]["model"] + " Price: " + cars["bmw"]["price"]);

Output

Audi Model: Q7 Price: 10000000
BMW Model: S20D Price: 8000000

Adding or Updating Object Properties

obj.prop = newValue;
obj["prop"] = newValue;

Example

const fruit = {
  name: "Watermelon",
  price: 150,
}
fruit.name = "Apple";
fruit["price"] = 200;
fruit.expiry = "5 days";
console.log(fruit);

Output

{ name: "Apple", price: 200, expiry: "5 days" }

Deleting Object Properties

delete obj.prop;

Example

const fruit = {
  name: "Watermelon",
  price: 150,
}
delete fruit.name;
console.log(fruit);

Output

{ "price": 150 }

Enumerating Object Properties

You can use for...in loop or Object.keys() to enumerate object properties.

for (let key in table) {
  console.log(key + ": " + table[key]);
}

Example

const table = {
  color: "brown",
  shape: "round",
  price: 10000,
}

for (let key in table) {
  console.log(key + ": " + table[key]);
}

Output

color: brown
shape: round
price: 10000

Property Attributes

Each object property has four attributes:

  • value – the property's value
  • enumerable – whether the property can be iterated
  • configurable – whether the property can be reconfigured
  • writable – whether the property can be modified

By default, only the value attribute can be directly changed. To modify other attributes, you need Object.defineProperty() or Object.defineProperties().

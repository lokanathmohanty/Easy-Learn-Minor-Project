ReactJS - Web Components

React and Web Components can work together in the same application. A React component can render Web Components, and a Web Component can use React to manage its content. This makes it possible to combine the strengths of both approaches.

Concept

A Web Component is a reusable custom element built with standard browser APIs. React can integrate with Web Components by treating them like any other DOM element. Data can be passed through attributes and events can be listened to directly.

Example

The following example creates a simple Web Component (<hello-message>) and uses it inside a React component:

// Web Component
class HelloMessage extends HTMLElement {
   constructor() {
      super();
      this.name = 'Folks';
   }
   static get observedAttributes() { return ['name']; }
   attributeChangedCallback(prop, oldVal, newVal) {
      if (oldVal !== newVal) this[prop] = newVal;
   }
   connectedCallback() {
      this.textContent = `Hello ${this.name}!`;
   }
}
customElements.define('hello-message', HelloMessage);

// React Component
import React from "react";
class SimpleWebComponent extends React.Component {
   render() {
      return <hello-message name="Peter"></hello-message>;
   }
}
export default SimpleWebComponent;

Steps to Integrate

  • Create a Web Component by extending HTMLElement.
  • Register the component with customElements.define.
  • Include the Web Component script in public/index.html.
  • Use the custom element directly inside React JSX.

Summary

React and Web Components complement each other well. By combining them, developers can leverage React’s declarative UI with the reusability of Web Components, depending on the needs of the application.

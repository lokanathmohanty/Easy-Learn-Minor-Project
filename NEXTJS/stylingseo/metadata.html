Next.js - Metadata

**Metadata** of a webpage stores important information like webpage title, description, title card images, etc. Proper metadata is essential for better search engine results (**SEO**). In this chapter, we will explain the metadata object in Next.js, how to define static and dynamic metadata, and how to generate a metadata image using CSS.

Metadata Object in Next.js

In Next.js, the **`metadata` object** is part of the **App Router** used to define metadata for each route. With the `metadata` object, we can define the **title**, **description**, and other SEO components even for dynamically generated routes.

Syntax of Metadata Object

export const metadata = {
    title: "Title of Webpage",
    description: "Description of Webpage"
}

Title Attribute

The `title` attribute is used to set the title of the document. It can be defined as a simple string or an optional **template object**.

Title Template Object Structure

import type { Metadata } from 'next'

export const metadata: Metadata = {
  title: {
    default: '...',
    template: '...',
    absolute: '...',
  },
}

  • **`default`**: Defines a fallback title for child routes.
  • **`template`**: Used to add a prefix or a suffix to titles defined in child routes (e.g., `%s | My App`).
  • **`absolute`**: Used to provide a title that ignores `title.template` set in the parent route.

Declare a Static Metadata

**Static metadata** does not depend on data from external sources and remains the same for all users.

In the App Router, you define static metadata by exporting a **`Metadata` object** from a **`layout.tsx`** or static **`page.tsx`** file.

  • Metadata in `layout.tsx` is accessible to all components within that layout.
  • Metadata in `page.tsx` is specific to that component and can **override** metadata from the layout.

Example of Metadata in Layout Component (`layout.tsx`)

// app/layout.tsx file

import { ReactNode } from 'react';
import type { Metadata } from 'next'

export const metadata: Metadata = {
  title: 'Next JS Tutorial',
  description: 'We provide simple and easy to learn tutorial on Next JS',
}
// ... RootLayout component definition ...

The title defined here will be the default for all pages unless overridden.

Example of Metadata for a Specific Component (`page.tsx`)

This example shows how to override the layout metadata specifically for the **About page**.

// app/about/page.tsx file

import type { Metadata } from 'next';

export const metadata: Metadata = {
  title: 'Next JS About Page',
  description: 'We provide simple and easy to learn tutorial on Next JS',
}
// ... About component definition ...

When accessing the `/about` route, this metadata will take precedence.

Declare a Dynamic Metadata

**Dynamic metadata** depends on dynamic information, such as the current **route parameters**, external data, or parent metadata. It is set by exporting a **`generateMetadata()` function** that returns a `Metadata` object.

Example of Dynamic Title Based on Route Parameter

This example generates a dynamic title for a product page based on the `[id]` route parameter.

// app/products/[id]/page.tsx

import { Metadata } from "next";

type Props ={
  params: {
    id: string;
  };
}

// Dynamic Metadata function
export const generateMetadata = ({ params }: Props): Metadata => {
  return {
    title: `Product ${params.id} - My Store`,
  };
}
// ... ProductPage component definition ...

Metadata Image Generation

**Metadata images** are used for creating social media images such as **Open Graph images** and **Twitter cards**. This image is displayed when the webpage link is shared on platforms like WhatsApp or Twitter.

Example: Simple "Hello world!" Image Generation

The example below uses the **`ImageResponse` constructor** to generate dynamic images using JSX and CSS.

// app/api/og/route.js

import { ImageResponse } from 'next/og';

export async function GET() {
  return new ImageResponse(
    (
      <div
        style={{
          /* ... CSS styles ... */
        }}
      >
        Hello world!
      </div>
    ),
    {
      width: 300,
      height: 100,
    }
  );
}

// The image is then referenced in another page:
// app/contacts/page.js
// <...>
//     <img src="/api/og" alt="Generated Image" />
// <...>

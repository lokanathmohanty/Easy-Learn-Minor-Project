HTML Attributes

HTML attributes are keywords found in an opening element tag to give more details about that particular element. CSS is needed to manage how HTML elements behave, look and function. Every attribute takes the form name="value" and should always be put inside the start tag. Nearly every HTML element can use attributes to let us style, link, add tooltips or include images and videos.

Every attribute increases the accuracy of both the interpretation and presentation of the element by the browser. While the names and values in attributes can differ greatly based on case, it is recommended by W3C that you use small letters. Several attributes can be put on one tag by inserting a space between them.

Syntax

<element attribute_name="value">content</element>

Example

<!DOCTYPE html>
<html>
<head>
</head>
<body>
  <h1> This is Style attribute</h1>
  <p style="height: 50px; color: blue">It will add style property in element</p>
  <p style="color: red">It will change the colour of content</p>
</body>
</html>

Output:

<p style="height: 50px; color: blue">It will add style property in element</p>
We have marked the paragraphs above by giving them style attributes using tags. The style attribute is utilised to set CSS styles on any HTML tag. It adds a height of 50px and turns the paragraph colour into blue.

<p style="color: red">It will change the color of content</p>
We have added a style attribute to the paragraph again to change its colour to red.
Note: There are some commonly used attributes given below, and the complete list and explanation of all attributes are provided in HTML Attributes List.

The Title Attribute

The title attribute is used as text tooltip in most browsers. It displays text when the user hovers the cursor over a link or any element. You can use it with text or links to show extra descriptions.

Syntax

<h1 title="This is heading tag">Example of title attribute</h1>
<p title="This is paragraph tag">Move the cursor over the heading and paragraph, and you will see a description as a tooltip</p>

Example

<!DOCTYPE html>
<html>
<head></head>
<body>
  <h1 title="This is heading tag">Example of title attribute</h1>
  <p title="This is paragraph tag">Move the cursor over the heading and paragraph, and you will see a description as a tooltip</p>
</body>
</html>

Output:

The title attribute is commonly used to display additional info via tooltips, enhancing user guidance without cluttering the interface.

The href Attribute

The href attribute is the main attribute of the <a> tag. It provides the hyperlink reference. If left blank, the page will not redirect.

Syntax

<a href="https://www.tpointtech.com/html-anchor">This is a link</a>
<a href="">This is a link</a>
The href attribute is used for making links. A missing value will stop a redirect.

src, width, and height Attributes

The src attribute is required in the <img> element. It specifies the image source. Width and height define the image size, and alt provides alternative text.

Example 1

<img src="whitepeacock.jpg" height="400" width="600">
The above example shows an image sized 400x600 pixels. The src defines the image source, width/height specify its size, and alt provides accessibility text.

Example 2 (Absolute URL)

<img src="https://tpointtech.com/images/img10" alt="TPointTech banner logo">
This example loads an image from an external source.

The alt Attribute

The alt attribute provides alternative text if an image doesn’t load. It is important for accessibility and SEO.

Example

<img src="img_typo.jpg" alt="Girl with a jacket">
If the image doesn’t load, "Girl with a jacket" will be displayed. Screen readers also read this text aloud for accessibility.

Quotes in HTML Attributes

You can use single or double quotes for attribute values. Always quoting values ensures consistency.

Example with Double Quotes

<a href="https://www.tpointtech.com/">A link to HTML.</a>

Example with Single Quotes

<a href='https://www.tpointtech.com/'>A link to HTML.</a>

Example Without Quotes (Not Recommended)

<a href=https://www.tpointtech.com/>A link to HTML.</a>
All render correctly, but the last one may break if the value contains spaces.

The lang Attribute

The lang attribute sets the language of the document for better SEO and accessibility.

Example

<!DOCTYPE html>
<html lang="en-US">
<body>
  ...
</body>
</html>
This indicates the page language is English (U.S.).

Conclusion

HTML attributes improve how content operates, looks, and is used. They allow links (href), images (src, alt, width, height), styles (style), tooltips (title), and language settings (lang). While lowercase and quotes aren’t mandatory, they are best practices for clean and consistent code.

Pointer to an Array in C

Introduction

An array name is a constant pointer to the first element of the array. For example, in the declaration:

int balance[5];

balance is a pointer to &balance[0], which is the address of the first element.

Example: Pointer to Array

#include <stdio.h>

int main() {
  int *ptr;
  int balance[5] = {1, 2, 3, 4, 5};

  ptr = balance;

  printf("Pointer 'ptr' points to the address: %d", ptr);
  printf("\nAddress of the first element: %d", balance);
  printf("\nAddress of the first element: %d", &balance[0]);

  return 0;
}

All three printf statements will output the same address, since ptr, balance, and &balance[0] refer to the same location.

Dereferencing *ptr returns the value 1, which is the first element of the array.

Array Names as Constant Pointers

It is valid to use array names as constant pointers. For example, *(balance + 4) accesses balance[4].

After assigning balance to ptr, array elements can be accessed using pointer arithmetic such as *ptr, *(ptr + 1), and so on.

Example: Accessing Array Elements Using Pointers

#include <stdio.h>

int main() {
  double balance[5] = {1000.0, 2.0, 3.4, 17.0, 50.0};
  double *ptr;
  int i;

  ptr = balance;

  printf("Array values using pointer:\n");
  for (i = 0; i < 5; i++) {
    printf("*(ptr + %d): %f\n", i, *(ptr + i));
  }

  printf("\nArray values using balance as address:\n");
  for (i = 0; i < 5; i++) {
    printf("*(balance + %d): %f\n", i, *(balance + i));
  }

  return 0;
}

Output

  • *(ptr + 0): 1000.000000
  • *(ptr + 1): 2.000000
  • *(ptr + 2): 3.400000
  • *(ptr + 3): 17.000000
  • *(ptr + 4): 50.000000
  • *(balance + 0): 1000.000000
  • *(balance + 1): 2.000000
  • *(balance + 2): 3.400000
  • *(balance + 3): 17.000000
  • *(balance + 4): 50.000000

The pointer ptr stores the address of a double type variable. Once it holds the address of the array, *ptr gives the value at that address.

C - Scope Rules

In C programming, a scope defines the region in a program where a variable is accessible. Outside its scope, the variable cannot be accessed.

There are three main types of variable scopes in C:

  • Local variables: Declared inside a function or block.
  • Global variables: Declared outside all functions.
  • Formal parameters: Declared in function definitions.

Local Variables

Variables declared inside a function or block are called local variables. They can only be accessed within that specific function or block.

Example

#include <stdio.h>

int main() {
    int a, b;
    int c;

    a = 10;
    b = 20;
    c = a + b;

    printf("value of a = %d, b = %d and c = %d\n", a, b, c);
    return 0;
}

Global Variables

Global variables are declared outside all functions. They retain their value throughout the program and can be accessed by any function.

Example

#include <stdio.h>

/* global variable */
int g;

int main() {
    int a, b;

    a = 10;
    b = 20;
    g = a + b;

    printf("value of a = %d, b = %d and g = %d\n", a, b, g);
    return 0;
}

Local and Global Variables with Same Name

A local variable with the same name as a global variable will override it within the function scope.

Example

#include <stdio.h>

/* global variable */
int g = 20;

int main() {
    /* local variable */
    int g = 10;
    printf("value of g = %d\n", g);
    return 0;
}

Output:

value of g = 10

Formal Parameters

Formal parameters are variables declared in function definitions. They act as local variables and override global variables with the same name.

Example

#include <stdio.h>

int a = 20;

int sum(int a, int b) {
    printf("value of a in sum() = %d\n", a);
    printf("value of b in sum() = %d\n", b);
    return a + b;
}

int main() {
    int a = 10;
    int b = 20;
    int c;

    printf("value of a in main() = %d\n", a);
    c = sum(a, b);
    printf("value of c in main() = %d\n", c);

    return 0;
}

Output:

value of a in main() = 10
value of a in sum() = 10
value of b in sum() = 20
value of c in main() = 30

Initializing Local and Global Variables

Local variables are not automatically initialized — they contain garbage values unless explicitly assigned.

Global variables are automatically initialized by the system with default values based on their data type:

  • int: 0
  • char: '\0'
  • float: 0
  • double: 0
  • pointer: NULL

Always initialize variables explicitly to avoid unpredictable behavior.

JavaScript - Memoization

As our systems grow and start doing more complex calculations, the need for speed grows and process optimization becomes necessary. Ignoring this issue results in applications that use a lot of system resources and operate slowly.

In this chapter, we will discuss memoization, a technique that can significantly reduce processing time when used properly.

What is Memoization?

Memoization is a technique for speeding up applications by storing the results of expensive function calls and providing them when the same inputs are used again.

  • Expensive Function Calls: Functions that consume a lot of time or memory.
  • Cache: A temporary storage mechanism to store results for future reuse.

Benefits of Memoization

After receiving input, a function does the necessary computation, caches the result, and then returns the value. If the same input is received again in the future, the process will not need to be repeated.

When to Use Memoization?

  • When a function calls itself (recursive functions).
  • When the function is pure (always returns the same output for the same input).
  • When the function has high time complexity.

Memoization in JavaScript

Memoization in JavaScript is an optimization technique used to minimize runtime and memory usage. It reduces redundant computations by caching previous results.

How Does Memoization Work?

JavaScript memoization is based on two core concepts:

  • Closures
  • Higher-order functions

Closures

A closure is a function that has access to its own scope, the outer function's scope, and the global scope. Let's see an example: 

let greeting = "Welcome";
function welcomeMessage() { 
   let user = "Rahul"; 
   console.log(`${greeting} to the program, ${user}!`); 
}
welcomeMessage();

Output: Welcome to the program, Rahul!

Now, using lexical scoping and returning a nested function:

function welcomeMessage() { 
   let user = "Rahul";
   function welcome() {
      console.log(`Greetings, ${user}!`);
   }
   return welcome;
}
let greet = welcomeMessage();
greet();

Output: Greetings Rahul!

Higher-Order Functions

Higher-order functions take other functions as arguments or return them. In our closure example, welcomeMessage() is a higher-order function.

Example: Fibonacci Sequence

The Fibonacci sequence is a series of numbers where each number is the sum of the two preceding ones:

1, 1, 2, 3, 5, 8, 13, ...

Naive Recursive Function

function fibonacciSeq(n) {
   if (n < 2)
      return 1;
   return fibonacciSeq(n - 1) + fibonacciSeq(n - 2);
}

Optimized with Memoization

function memoizedFibSeq(num, memo) {
   memo = memo || [1, 1];  
   if (num <= 1) return memo[num];
   if (memo[num]) return memo[num];
   memo[num] = memoizedFibSeq(num - 1, memo) + memoizedFibSeq(num - 2, memo);
   return memo[num];
}

console.log(memoizedFibSeq(10));

Output: 89

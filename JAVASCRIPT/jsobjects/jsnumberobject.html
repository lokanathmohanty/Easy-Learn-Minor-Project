JavaScript - The Number Object

The JavaScript Number object represents numerical data as floating-point numbers. It provides different properties (constants) and methods for working with numbers. In practice, you rarely need to explicitly create Number objects, because the browser automatically wraps number literals as Number objects when needed.

You can create a Number object using the Number constructor, or convert other types (such as strings) to numbers using the Number() function.

JavaScript numbers are always stored as floating-point values (64-bit IEEE 754 format). JavaScript does not distinguish between integers and floating-point values.

Syntax

const val = new Number(number);

If a non-number argument is provided and cannot be converted, it returns NaN (Not-a-Number).

We can also create number primitives directly:

let num1 = 24;
let num2 = 35.65;

JavaScript automatically treats primitives like Number objects when needed, so you can access Number methods and properties on them.

Number Properties

  • EPSILON – Difference between 1 and the smallest floating-point number greater than 1.
  • MAX_SAFE_INTEGER – Maximum safe integer value.
  • MAX_VALUE – Largest possible number (1.7976931348623157E+308).
  • MIN_SAFE_INTEGER – Minimum safe integer value.
  • MIN_VALUE – Smallest possible number (5E-324).
  • NaN – Represents a “Not-a-Number” value.
  • NEGATIVE_INFINITY – Value less than MIN_VALUE.
  • POSITIVE_INFINITY – Value greater than MAX_VALUE.
  • prototype – Allows extending Number with custom properties/methods.
  • constructor – Refers to the function that created the object (Number by default).

Number Methods

Instance Methods

  • toExponential() – Displays number in exponential notation.
  • toFixed() – Formats with fixed decimal digits.
  • toLocaleString() – Converts number to a locale-sensitive string.
  • toPrecision() – Formats number with specified total digits.
  • toString() – Converts number to string.
  • valueOf() – Returns primitive value of the number.

Static Methods

  • isNaN() – Checks if a value is NaN.
  • isFinite() – Checks if value is finite.
  • isInteger() – Checks if value is an integer.
  • isSafeInteger() – Checks if value is a safe integer.
  • parseFloat() – Parses a float from a string.
  • parseInt() – Parses an integer from a string.

Examples

Creating Number Object

<script>
const num = new Number(20);
document.getElementById("output").innerHTML =
   "num = " + num + "<br>" +
   "typeof num : " + typeof num;
</script>

Output:

  • num = 20
  • typeof num : object

Using Number Properties

<script>
document.getElementById("output").innerHTML =
   "Max Value : " + Number.MAX_VALUE + "<br>" +
   "Min Value : " + Number.MIN_VALUE + "<br>" +
   "Positive Infinity : " + Number.POSITIVE_INFINITY + "<br>" +
   "Negative Infinity : " + Number.NEGATIVE_INFINITY + "<br>" +
   "NaN : " + Number.NaN;
</script>

Output:

  • Max Value : 1.7976931348623157e+308
  • Min Value : 5e-324
  • Positive Infinity : Infinity
  • Negative Infinity : -Infinity
  • NaN : NaN

Using Number Methods

<script>
const num = 877.5312;
document.getElementById("output").innerHTML =
   "num.toExponential() : " + num.toExponential() + "<br>" +
   "num.toFixed() : " + num.toFixed() + "<br>" +
   "num.toPrecision(2) : " + num.toPrecision(2);
</script>

Output:

  • num.toExponential() : 8.775312e+2
  • num.toFixed() : 878
  • num.toPrecision(2) : 8.8e+2

JavaScript Number() Function

The Number() function converts a value into a number primitive. Unlike the Number constructor, it does not create a Number object.

let num = Number(val);

Example

<script>
let num = Number(10);
document.getElementById("output").innerHTML =
   "num = " + num + "<br>" +
   "typeof num = " + typeof num;
</script>

Output:

  • num = 10
  • typeof num = number

Converting Numeric Strings

<script>
let str = "102.34";
let num = Number(str);
document.getElementById("output").innerHTML =
   "num = " + num + "<br>" +
   "typeof num = " + typeof num;
</script>

Output:

  • num = 102.34
  • typeof num = number

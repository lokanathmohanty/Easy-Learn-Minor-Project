Power BI: Scatter Chart

The Scatter Chart plots data points representing different groups over X- and Y-axes for selected variables. It can render up to 10,000 points. It includes three main sections: Values, X-axis, and Y-axis. X-axis can be numeric or categorical, Y-axis is numeric, and Values designate the data points.

How to Create a Scatter Chart

  • Import your dataset into Power BI Desktop.
  • Select the Scatter Chart visual.
  • Add the Year field into the Values section and Gross Sales to the X-axis.
  • Add Net Sales to the Y-axis to complete the chart showing sums by year.
  • Add Name to Legend to color data points by category.
  • Use the Size section to assign bubble size (e.g., Sum of Gross Sales) indicating relative magnitude.
  • Add fields like Designation to Tooltips for detailed info on hover.
  • Use Drill Through to filter data (e.g., specific region).

Customizing Scatter Chart

  • X-axis: Options include Range (log scale, invert), Values (font style, size, color), and Title (toggle visibility, style changes).
  • Y-axis: Similar options as X-axis for range, values, and title customization.
  • Legend: Configure placement (e.g., top right stacked), text style, font size, color, and title text.
  • Gridlines: Enable horizontal and vertical gridlines, customize style (e.g., dashed), and colors.
  • Zoom Slider: Enable sliders to zoom in/out on data points for focus.
  • Markers: Change bubble shape symbols (e.g., triangle) for distinct visualization.

C - The If Statement

Conditional execution of instructions is the basic requirement of a computer program. The if statement in C is the primary conditional statement. C allows an optional else keyword to specify the statements to be executed if the if condition is false.

Syntax of if Statement

The if statement is written with the following syntax:

if (boolean_expression) {
   /* statement(s) will execute if the boolean expression is true */
}

How if Statement Works?

If the Boolean expression evaluates to true, then the block of code inside the if statement will be executed. If the expression evaluates to false, the program continues after the if block.

Example: Simple If Statement

This example checks if a variable is less than 20 and displays a message accordingly.

#include <stdio.h>

int main() {
   int a;
   a = 12;  // change to 40 and run again
   printf("Value of a is : %d\n", a);

   if (a < 20) {
      printf("a is less than 20\n");
   }

   return 0;
}

Output

  • Value of a is: 12
    a is less than 20
  • Value of a is: 40

If Statement with Logical Operations

You can use logical operators like && or || within an if condition to check compound expressions.

#include <stdio.h>

int main() {
   int a = 10, b = 5, c = 7;

   if (a >= b && a >= c) {
      printf("a is greater than b and c\n");
   }

   printf("a: %d b: %d c: %d", a, b, c);
   return 0;
}

Output

  • a is greater than b and c
    a: 10 b: 5 c: 7
  • a: 10 b: 20 c: 15

Multiple If Statements

Use multiple if statements to handle various conditions.

#include <stdio.h>

int main() {
   int amount;
   float discount, net;

   amount = 500;  // try 2250 or 5200

   if (amount < 1000) {
      discount = 0;
   }
   if (amount >= 1000 && amount < 5000) {
      discount = 5;
   }
   if (amount >= 5000) {
      discount = 10;
   }

   net = amount - amount * discount / 100;
   printf("Amount: %d Discount: %f Net payable: %f", amount, discount, net);

   return 0;
}

Output

  • Amount: 500 Discount: 0.000000 Net payable: 500.000000
  • Amount: 2250 Discount: 5.000000 Net payable: 2137.500000
  • Amount: 5200 Discount: 10.000000 Net payable: 4680.000000

Checking Multiple Conditions

You can use logical operators to check multiple conditions in one if statement.

#include <stdio.h>

int main() {
   int phy = 50, maths = 50;
   float avg;

   avg = (float)(phy + maths) / 2;
   printf("Phy: %d Maths: %d Avg: %f\n", phy, maths, avg);

   if (avg >= 50 && (maths >= 35 && phy >= 35)) {
      printf("Result: Pass");
   }

   if (avg < 50) {
      printf("Result: Fail\n");
   }

   return 0;
}

Output

  • Phy: 50 Maths: 50 Avg: 50.000000
    Result: Pass
  • Phy: 40 Maths: 40 Avg: 40.000000
    Result: Fail
  • Phy: 80 Maths: 40 Avg: 60.000000
    Result: Pass

JavaScript - Undefined Check

In JavaScript, undefined is one of the primitive data types. It represents the absence of a value. A variable becomes undefined when it is declared but not assigned any value.

How to Check if a Variable is Undefined?

There are multiple ways to check if a variable is undefined:

  • Using typeof operator
  • Using strict equality operator (===)
  • Using void operator

Using typeof Operator

The typeof operator returns "undefined" when a variable has not been assigned a value. It can even be used on undeclared variables.

Syntax:

typeof variable_name === 'undefined'

Example:

var a;
if (typeof a === 'undefined') {
  document.write('a is undefined');
}

Output:
a is undefined

Using Strict Equality Operator

We can also check undefined variables using the strict equality operator (===). If a variable has not been assigned any value, it will be strictly equal to undefined.

Syntax:

variable_name === undefined

Example:

var a;
if (a === undefined) {
  document.write('a is undefined');
}

Output:
a is undefined

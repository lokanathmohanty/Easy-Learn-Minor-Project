HTML - Style Guide

A style guide in HTML is a set of rules and conventions that define how to write and format code. It ensures readability, maintainability, and consistency across projects, while also reducing bugs and errors.

Start with HTML5 Doctype

Always begin HTML documents with the <!DOCTYPE html> declaration. It ensures the browser renders the page in standard mode.

Example

<!DOCTYPE html>
<html>
<head>
   <!-- Content inside head tag -->
</head>
<body>
   Hello, Welcome to Tutorialspoint
</body>
</html>

Specify Document Language

Use the lang attribute in the opening <html> tag to define the document’s language.

Example

<!DOCTYPE html>
<html lang="en">
<head></head>
<body>
   Hello, Welcome to Tutorialspoint
</body>
</html>

Define Charset

Declare the character encoding explicitly with UTF-8 for wider support.

Example

<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
</head>
<body>
   Hello, Welcome to Tutorialspoint
</body>
</html>

Use Lowercase for Elements and Attributes

Always write element names, attributes, and attribute values in lowercase for clarity and consistency.

Example

<body>
   <h1>Heading</h1>
   <p style="font-size: 25px;">Hello, Welcome to Tutorialspoint</p>
</body>

Quote Attribute Values

Enclose attribute values in double quotes, especially when they contain spaces.

Example

<p style="font-size: 25px;">Paragraph text</p>

Use Closing Tags

Close all HTML elements properly. Even optional tags should be closed for cleaner code.

Example

<!DOCTYPE html>
<html>
<head></head>
<body>
   <h1>Heading</h1>
   <p>Paragraph</p>
   <br>
   <p>Another paragraph</p>
</body>
</html>

Use Proper Indentation

Indent code with consistent spaces (2 or 3) to show hierarchy. Use blank lines to separate large blocks.

Example

<!DOCTYPE html>
<html>
<head>
   <!-- Head content -->
</head>
<body>
   <h1>Heading</h1>
   <p>Paragraph</p>
</body>
</html>

Set the Viewport

Control how web pages are displayed on different devices with the viewport meta tag.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Add Comments

Use comments <!-- --> to explain code. Avoid using comments for styling or scripting.

Example

<!DOCTYPE html>
<html lang="en">
<head>
   <!-- Head content -->
</head>
<body>
   <h1>Heading</h1>
   <p>Hello, Welcome to Tutorialspoint</p>
</body>
</html>

JavaScript - Fetch API

What is Fetch API?

The JavaScript Fetch API is a web API that allows a web browser to make HTTP requests to a web server. It was introduced in ES6 as an alternative to the XMLHttpRequest (XHR) object, and it can handle GET, POST, PUT, and DELETE requests.

The fetch() method is available by default in the browser’s window object. It returns a promise that resolves to the response object.

Syntax

fetch(URL, [options]);
  • URL − API endpoint to make a request.
  • [options] − Optional object containing method, headers, body, etc.

Return Value

The fetch() method returns a promise, which can be handled using then...catch or with async/await.

Handling with then...catch

fetch(URL)
  .then(res => res.json())
  .then(data => {
    // Handle data
  })
  .catch(err => {
    // Handle error
  });

Example (then...catch)

<html>
<body>
  <div id="output"></div>
  <script>
    const output = document.getElementById('output');
    const URL = 'https://jsonplaceholder.typicode.com/todos/5';
    fetch(URL)
      .then(res => res.json())
      .then(data => {
        output.innerHTML += "The data from the API is: <br>";
        output.innerHTML += JSON.stringify(data);
      });
  </script>
</body>
</html>

Handling with async/await

async function getData() {
  let response = await fetch(URL);
  let data = await response.json();
  console.log(data);
}
getData();

Options with Fetch API

You can pass an object with options such as method, headers, body, etc.

fetch(URL, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(data)
});

Examples

GET Request

let options = { method: "GET" };
fetch("https://dummy.restapiexample.com/api/v1/employee/2", options)
  .then(res => res.json())
  .then(res => console.log(res));

POST Request

let employee = { emp_name: "Sachin", emp_age: "30" };
let options = {
  method: "POST",
  headers: { "Content-Type": "application/json;charset=utf-8" },
  body: JSON.stringify(employee)
};
fetch("https://dummy.restapiexample.com/api/v1/create", options)
  .then(res => res.json())
  .then(res => console.log(res));

PUT Request

let animal = { name: "Lion", color: "Yellow", age: 10 };
let options = {
  method: "PUT",
  headers: { "Content-Type": "application/json;charset=utf-8" },
  body: JSON.stringify(animal)
};
fetch("https://dummy.restapiexample.com/api/v1/update/3", options)
  .then(res => res.json())
  .then(res => console.log(res));

DELETE Request

let options = { method: "DELETE" };
fetch("https://dummy.restapiexample.com/api/v1/delete/2", options)
  .then(res => res.json())
  .then(res => console.log(res));

Advantages of Fetch API

  • Easy syntax for making requests
  • Promise-based handling
  • Built-in JSON conversion
  • Supports multiple request options

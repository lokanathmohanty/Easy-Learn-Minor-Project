Python - Loop Dictionaries

Overview

Looping through dictionaries in Python refers to iterating over key-value pairs within the dictionary and performing operations on each pair. This allows you to access both keys and their corresponding values.

There are several methods for looping through dictionaries:

  • Using a for loop
  • Using dict.items() method
  • Using dict.keys() method
  • Using dict.values() method

Method 1: Basic For Loop

A for loop iterates over the keys of the dictionary by default. You can access the corresponding values using dictionary indexing.

Example - Iterating over Keys:

student = {"name": "Alice", "age": 21, "major": "Computer Science"}
for key in student:
    print(key, student[key])

Output:

name Alice
age 21
major Computer Science

Method 2: Using dict.items()

The dict.items() method returns a view object that displays key-value pairs in the dictionary. This method provides direct access to both keys and values simultaneously.

Example:

student = {"name": "Alice", "age": 21, "major": "Computer Science"}
for key, value in student.items():
    print(key, value)

Output:

name Alice
age 21
major Computer Science

Method 3: Using dict.keys()

The dict.keys() method returns a view object containing all the keys in the dictionary. This method is useful when you only need to iterate over the keys.

Example:

student = {"name": "Alice", "age": 21, "major": "Computer Science"}
for key in student.keys():
    print(key)

Output:

name
age
major

Method 4: Using dict.values()

The dict.values() method returns a view object containing all the values in the dictionary. This method is useful when you only need to iterate over the values.

Example:

student = {"name": "Alice", "age": 21, "major": "Computer Science"}
for value in student.values():
    print(value)

Output:

Alice
21
Computer Science

Practical Applications

Dictionary looping is commonly used for:

  • Data processing and transformation
  • Filtering dictionary contents based on conditions
  • Creating new dictionaries with modified data
  • Searching for specific keys or values
  • Counting or aggregating dictionary elements

Best Practices

  • Use dict.items() when you need both keys and values
  • Use dict.keys() when you only need keys
  • Use dict.values() when you only need values
  • Basic for loop is equivalent to dict.keys() but more concise
  • Choose the method that best fits your specific use case for cleaner, more readable code

Key Points

Remember that all dictionary methods return view objects, which provide a dynamic view of the dictionary's contents. This means changes to the original dictionary will be reflected in the view objects.

Dictionary iteration order is guaranteed to be insertion order in Python 3.7 and later versions, making your loops predictable and consistent.

C# `if...else` Statement

Introduction to `if...else`

The **`if...else` statement** is a conditional construct that ensures one of two distinct code blocks will be executed, depending on the outcome of a **Boolean expression**.

  • If the condition is **true**, the code inside the **`if` block** executes.
  • If the condition is **false**, the code inside the **`else` block** executes.

Unlike the simple `if` statement, `if...else` guarantees that the program takes one of two paths.

Syntax

if(boolean_expression) {
   /* statement(s) will execute if the boolean expression is true */
} else {
   /* statement(s) will execute if the boolean expression is false 
   */
}

Example: Simple `if...else`

This example demonstrates how the flow is diverted to the `else` block when the initial condition is false:

using System;

class Program {
    static void Main(string[] args) {
        int a = 100;
         
        /* check the boolean condition: (100 < 20) is FALSE */
        if (a < 20) {
            Console.WriteLine("a is less than 20");
        } else {
            // This block executes
            Console.WriteLine("a is not less than 20");
        }
        Console.WriteLine("value of a is : {0}", a);
    }
}

Output:

a is not less than 20;
value of a is : 100

The `if...else if...else` Chain

This structure allows you to test **multiple conditions sequentially** using a single statement. Once an `if` or `else if` condition succeeds (evaluates to true), the corresponding block is executed, and **none of the remaining `else if` or `else` blocks are tested or executed**.

Syntax:

if(boolean_expression 1) {
   /* Executes if condition 1 is true */
} else if( boolean_expression 2) {
   /* Executes if condition 1 is false AND condition 2 is true */
} else {
   /* executes if all preceding conditions are false */
}

Example: `if...else if...else` Chain

This demonstrates testing for specific values in a sequence:

using System;

class Program {
    static void Main(string[] args) {
        int a = 100;
         
        if (a == 10) { /* False */ } 
        else if (a == 20) { /* False */ } 
        else if (a == 30) { /* False */ } 
        else {
            // None of the above were true, this block executes
            Console.WriteLine("None of the values is matching");
        }
    }
}

Output:

None of the values is matching

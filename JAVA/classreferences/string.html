Java String Class Summary 📝

In Java, **Strings** are **objects** that represent a sequence of characters. The core class for handling text is **java.lang.String**.

I. Immutability: The Most Important Concept 🔒

  • The **String** class is **immutable**. Once a String object is created, its value cannot be changed.
  • Any method that appears to "modify" a string (like concat(), substring(), or toUpperCase()) actually creates and returns a **new String object**. The original object remains unchanged.
  • **Alternatives:** For scenarios requiring frequent text modifications, the mutable classes **StringBuilder** (faster, not thread-safe) or **StringBuffer** (thread-safe, slower) should be used.

II. Creation and Concatenation

  • Literal Creation: The most common and memory-efficient way is using a string literal: String s = "Hello";. The compiler uses the **String Pool** to reuse identical literals.
  • Constructor Creation: You can create a new object using the new keyword, often from a character array: String s = new String(charArray);.
  • Concatenation:
    • The **`+` operator** is the most common way and is optimized by the compiler (often internally using StringBuilder for efficiency).
    • The **concat(String str)** method explicitly returns a new concatenated string.

III. Essential Accessor and Utility Methods

Category Method Examples Description
Accessors int length(), char charAt(int index), int indexOf(String str) Retrieving information about the string (size, specific character, location of substring).
Comparison boolean equals(Object obj), boolean equalsIgnoreCase(String str), int compareTo(String str) Checking equality or lexicographical order. Note that == checks object reference equality, not content equality.
Modification (New String) String substring(int begin), String replace(char old, char new), String trim(), String toUpperCase() Methods that generate and return a new string with the specified change.
Parsing/Splitting String[] split(String regex) Divides the string into an array of strings based on a regular expression delimiter.
Formatting static String format(String format, Object... args) Returns a formatted string, similar to printf(), allowing reuse of the formatted text.

IV. Unicode and Code Points

Java strings are Unicode sequences. Methods using the term "Code Point" (like codePointAt() and codePointCount()) are available to correctly handle characters outside of the Basic Multilingual Plane (BMP), which require two char values (surrogate pairs) to represent a single character.

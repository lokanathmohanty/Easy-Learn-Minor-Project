The C++ return Statement ↩️

The **return statement** is used to immediately **exit a function** and optionally **send a value back** to the function's caller. It is vital for controlling program flow and ensuring functions deliver their computed results to other parts of the code.

The basic syntax is return [expression];, where the expression is optional.

Key Aspects of return

  • Function Termination: When return is executed, the function stops immediately, and program control transfers back to the point where the function was called. This allows for **early exit** to handle error conditions or special cases (e.g., division by zero).
  • Value Transfer: For functions with a non-void return type, the `expression` specifies the value sent back to the caller. This returned value is then typically stored in a variable by the caller.
  • void Functions: For functions declared with **void** (meaning they return no value), the return statement is optional but can be used without an expression (`return;`) to force an early exit from the function.
  • Multiple Returns: A function can contain multiple return statements, usually nested within conditional structures (`if`/`else`), but only **one** will ever be executed during a single function call.

Example: Early Exit

The return is used here to prevent division by zero and indicate an error with a sentinel value (-1):

int divideInteger(int a, int b) {
   if (b == 0) {
      // Early exit on error
      return -1; 
   }
   return a / b;
}

Return Types and Value Handling

C++ functions can return virtually any data type, including primitive types, user-defined types, pointers, and references.

1. Primitive and User-Defined Types (Return by Value)

When returning a primitive type (`int`, `char`, `double`) or a class/struct object, the return value is typically a **copy** of the data. This is simple and safe.

struct Point { int x, y; };
Point createPoint(int x, int y) {
   // Returns a copy of the Point object
   return {x, y}; 
}

2. Returning References (T&)

Returning a **reference** (int& or Point&) allows the function to provide direct access to an existing object outside the function. This is highly efficient as it avoids copying, but it must **never** be used to return a reference to a local variable (which is destroyed upon function exit).

int globalValue = 100;
int& getGlobalValue() {
   // Returns a reference to the global variable
   return globalValue; 
}
// Caller can modify the global variable: getGlobalValue() = 200;

3. Returning Pointers (T*)

A function can return a **pointer** to dynamically allocated memory or to an existing object. When returning dynamically allocated memory, the caller assumes responsibility for managing and eventually freeing that memory using `delete` or `delete[]`.

int* createArray(int size) {
   // Returns a pointer to memory allocated on the heap
   return new int[size]; 
}

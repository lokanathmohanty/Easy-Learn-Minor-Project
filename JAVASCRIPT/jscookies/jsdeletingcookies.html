JavaScript - Deleting Cookies

In order to delete cookies with JavaScript, we can set the expires date to a past date. We can also delete a cookie using the max-age attribute. Additionally, cookies can be deleted explicitly from the browser.

Deleting cookies with JavaScript removes small bits of data that websites store on a user's computer. Cookies are used to track a user's browsing activity and preferences.

It is important to note that deleting cookies can have unintended consequences. For example, if you delete a cookie that is used to authenticate you to a website, you will be logged out. You should only delete cookies if you are sure you want to do so.

Different Ways to Delete the Cookies

  • Set the past expiry date using the expires attribute.
  • Use the max-age attribute.
  • Delete cookies explicitly from the browser.

Delete Cookies using expires Attribute

When you set a past expiry date as the value of the expires attribute, the browser automatically deletes the cookie.

Syntax

document.cookie = "data1=test1;expires=Tue, 22 Aug 2023 12:00:00 UTC;";

Example

<html>
<body>  
  <button onclick="setCookies()"> Set Cookie </button>
  <button onclick="deleteCookies()"> Delete Cookie </button>
  <button onclick="readCookies()"> Read Cookies </button>
  <p id="output"></p>

  <script>
    let output = document.getElementById("output");
    function setCookies() {
      document.cookie = "data1=test1;";
      document.cookie = "data2=test2;";
    }
    function deleteCookies() {
      document.cookie = "data1=test1;expires=Tue, 22 Aug 2023 12:00:00 UTC;";
      document.cookie = "data2=test2;expires=Mon, 22 Aug 2050 12:00:00 UTC;";
    }
    function readCookies() {
      const allCookies = document.cookie.split("; ");
      output.innerHTML = "The cookie is : <br>";
      for (const cookie of allCookies) {
        const [key, value] = cookie.split("=");
        if (key == "data1" || key == "data2") {
          output.innerHTML += `${key} : ${decodeURIComponent(value)} <br>`;
        }
      }
    }
  </script>
</body>
</html>

Delete Cookies using max-age Attribute

The browser automatically deletes the cookie when you assign 0 or a negative value to the max-age attribute.

Syntax

document.cookie = "user1=sam;max-age=-60;";

Example

<html>
<body>    
  <button onclick="setCookies()"> Set Cookie </button>
  <button onclick="deleteCookies()"> Delete Cookie </button>
  <button onclick="readCookies()"> Read Cookies </button>
  <p id="output"></p>

  <script>
    let output = document.getElementById("output");
    function setCookies() {
      document.cookie = "user1=sam;";
      document.cookie = "user2=virat;";
    }
    function deleteCookies() {
      document.cookie = "user1=sam;max-age=-60;";
      document.cookie = "user2=virat;max-age=5000;";
    }
    function readCookies() {
      const allCookies = document.cookie.split("; ");
      output.innerHTML = "The cookie is : <br>";
      for (const cookie of allCookies) {
        const [key, value] = cookie.split("=");
        if (key == "user1" || key == "user2") {
          output.innerHTML += `${key} : ${decodeURIComponent(value)} <br>`;
        }
      }
    }
  </script>
</body>
</html>

Delete Cookies Explicitly from the Browser

You can manually delete cookies from the browser by following the steps below.

  1. In your browser, click the three vertical dots (menu) at the top right corner.
  2. Hover over History and click on History.
  3. Click on the Clear browsing data tab.
  4. Check the cookies and other site data checkbox, then click the Clear data button.

Note: The exact steps may vary depending on which browser you are using.

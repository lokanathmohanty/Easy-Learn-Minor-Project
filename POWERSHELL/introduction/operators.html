PowerShell: Operators

PowerShell provides a rich set of operators to manipulate variables and expressions. These operators are grouped into several categories.

Arithmetic Operators

  • + Addition (e.g., A + B = 30)
  • - Subtraction (e.g., A - B = -10)
  • * Multiplication (e.g., A * B = 200)
  • / Division (e.g., B / A = 2)
  • % Modulus (e.g., B % A = 0)

Comparison Operators

  • -eq Equals (e.g., A -eq B yields False)
  • -ne Not Equals (e.g., A -ne B yields True)
  • -gt Greater Than (e.g., B -gt A yields True)
  • -ge Greater Than or Equals (B -ge A equals True)
  • -lt Less Than (B -lt A yields False)
  • -le Less Than or Equals (B -le A yields False)

Assignment Operators

  • = Simple assignment (e.g., C = A + B)
  • += Add and assign (e.g., C += A is C = C + A)
  • -= Subtract and assign (C -= A is C = C - A)

Logical Operators

  • -AND Logical AND (True if both operands true; (A -AND B) is False when B is False)
  • -OR Logical OR (True if either operand is true; (A -OR B) is True if A is True)
  • -NOT Logical NOT (Reverses operand state; -NOT (A -AND B) is True if condition is False)

Miscellaneous Operators

  • > Redirection operator - redirects output to file or device. Example: dir > test.log writes directory listing to test.log.

User-Defined Exceptions in Python

User-defined exceptions in Python are custom error classes that you create to handle specific error conditions in your code. They inherit from the built-in Exception class or its subclasses, allowing precise control over error handling.

Benefits include clarity with specific error messages, granularity to handle different errors separately, and maintainability by centralizing error handling logic.

How to Create a User-Defined Exception

Step 1 - Define the Exception Class

class MyCustomError(Exception):
   pass

Inherit from Exception to get standard behavior. For simple exceptions, an empty class body with pass is enough.

Step 2 - Initialize the Exception

class InvalidAgeError(Exception):
   def __init__(self, age, message="Age must be between 18 and 100"):
      self.age = age
      self.message = message
      super().__init__(self.message)

Initialize attributes to store additional error information. The super() call initializes the base exception class properly.

Step 3 - Optionally Override __str__ or __repr__

class InvalidAgeError(Exception):
   def __init__(self, age, message="Age must be between 18 and 100"):
      self.age = age
      self.message = message
      super().__init__(self.message)

   def __str__(self):
      return f"{self.message}. Provided age: {self.age}"

Customize string representation for clearer error messages during printing or logging.

Raising User-Defined Exceptions

Use the raise statement with your custom exception:

def set_age(age):
   if age < 18 or age > 100:
      raise InvalidAgeError(age)
   print(f"Age is set to {age}")

Handling User-Defined Exceptions

Catch user-defined exceptions with try-except blocks and respond accordingly. 

try:
   set_age(150)
except InvalidAgeError as e:
   print(f"Invalid age: {e.age}. {e.message}")

Complete Example

class InvalidAgeError(Exception):
   def __init__(self, age, message="Age must be between 18 and 100"):
      self.age = age
      self.message = message
      super().__init__(self.message)

   def __str__(self):
      return f"{self.message}. Provided age: {self.age}"

def set_age(age):
   if age < 18 or age > 100:
      raise InvalidAgeError(age)
   print(f"Age is set to {age}")

try:
   set_age(150)
except InvalidAgeError as e:
   print(f"Invalid age: {e.age}. {e.message}")

Output:

Invalid age: 150. Age must be between 18 and 100

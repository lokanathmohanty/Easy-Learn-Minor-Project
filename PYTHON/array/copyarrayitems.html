Copy Arrays in Python

Copying an array in Python means creating a new array object with the same elements as the original. This can be done using the assignment operator or the deepcopy() function from the copy module.

Copy Arrays Using Assignment Operator

Assigning one array to another with the = operator creates a new reference, not a copy. Both variables point to the same array object.

import array as arr
a = arr.array('i', [110, 220, 330, 440, 550])
b = a
print("Copied array:", b)
print(id(a), id(b))

a[2] = 10
print(a, b)
# Output:
# Copied array: array('i', [110, 220, 330, 440, 550])
# 134485392383792 134485392383792
# array('i', [110, 220, 10, 440, 550]) array('i', [110, 220, 10, 440, 550])

Copy Arrays Using Deep Copy

deepcopy() creates a completely new array object, independent of the original.

import array as arr
import copy
a = arr.array('i', [110, 220, 330, 440, 550])
b = copy.deepcopy(a)
print("Copied array:", b)
print(id(a), id(b))

a[2] = 10
print(a, b)
# Output:
# Copied array: array('i', [110, 220, 330, 440, 550])
# 2771967069936 2771967068976
# array('i', [110, 220, 10, 440, 550]) array('i', [110, 220, 330, 440, 550])

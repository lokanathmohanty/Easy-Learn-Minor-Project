Java - Naming a Thread with Examples

Name a Thread while Implementing a Runnable Interface

If your class implements the Runnable interface, you can name a thread by creating a Thread object using the constructor:

Thread(Runnable threadObj, String threadName);

Here, threadObj is the instance of your Runnable implementation and threadName is the thread's name.

After creating the thread, you start it by calling start(), which invokes the run() method.

void start();

Example: Naming a Thread using Runnable Interface

In this example, the class RunnableDemo implements Runnable. We create threads with names "Thread-1" and "Thread-2".

package com.tutorialspoint;
class RunnableDemo implements Runnable {
   private String threadName;
   RunnableDemo(String name) {
      threadName = name;
      System.out.println("Thread: " + threadName + ", State: New");
   }
   public void run() {
      System.out.println("Thread: " + threadName + ", State: Running");
      for(int i = 4; i > 0; i--) {
         System.out.println("Thread: " + threadName + ", " + i);         
      }
      System.out.println("Thread: " + threadName + ", State: Dead");
   }
}
public class TestThread {
   public static void main(String args[]) {
      RunnableDemo runnableDemo1 = new RunnableDemo("Thread-1");
      RunnableDemo runnableDemo2 = new RunnableDemo("Thread-2");

      Thread thread1 = new Thread(runnableDemo1);
      Thread thread2 = new Thread(runnableDemo2);

      thread1.start();
      thread2.start();
   }
}

Naming a Thread while Extending the Thread Class

The other approach to naming threads is by extending the Thread class and passing the thread name to the superclass constructor using super(name).

Example 1: Naming Thread by Extending Thread Class

In this example, the ThreadDemo class extends Thread, names the thread in the constructor, and overrides the start() method.

package com.tutorialspoint;
class ThreadDemo extends Thread {
   ThreadDemo(String name) {
      super(name);
      System.out.println("Thread: " + name + ", State: New");
   }
   public void run() {
      System.out.println("Thread: " + getName() + ", State: Running");
      for(int i = 4; i > 0; i--) {
         System.out.println("Thread: " + getName() + ", " + i); 
      }
      System.out.println("Thread: " + getName() + ", State: Dead");
   }
   public void start() {
      System.out.println("Thread: " + getName() + ", State: Start");
      super.start();
   }
}
public class TestThread {
   public static void main(String args[]) {
      ThreadDemo thread1 = new ThreadDemo("Thread-1");
      ThreadDemo thread2 = new ThreadDemo("Thread-2");
      thread1.start();
      thread2.start();
   }
}

Example 2: Default Thread Names when Extending Thread Class

This example shows how threads are named by default if you do not explicitly provide names.

package com.tutorialspoint;
class ThreadDemo extends Thread {
   ThreadDemo() {
      System.out.println("Thread: " + Thread.currentThread().getName() + ", State: New");
   }
   public void run() {
      System.out.println("Thread: " + Thread.currentThread().getName() + ", State: Running");
      for(int i = 4; i > 0; i--) {
         System.out.println("Thread: " + Thread.currentThread().getName() + ", " + i); 
      }
      System.out.println("Thread: " + Thread.currentThread().getName() + ", State: Dead");
   }
   public void start() {
      System.out.println("Thread: " + Thread.currentThread().getName() + ", State: Start");
      super.start();
   }
}

public class TestThread {
   public static void main(String args[]) {
      ThreadDemo thread1 = new ThreadDemo();
      ThreadDemo thread2 = new ThreadDemo();
      thread1.start();
      thread2.start();
   }
}

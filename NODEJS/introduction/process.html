Node.js - Process

The process object in Node.js is a global object representing the current Node.js process. It is an instance of the EventEmitter class and provides methods and properties to interact with the runtime process.

Process Events

Event Description
exitEmitted when the process is about to exit.
beforeExitEmitted when Node.js empties its event loop but still has pending asynchronous calls.
uncaughtExceptionEmitted when an exception bubbles up to the event loop.
warningEmitted when warnings occur.
Signal EventsEmitted upon receiving signals like SIGINT, SIGHUP.

Example: Handling Process Events

process.on('beforeExit', (code) => {
  console.log('A beforeExit event occurred with code:', code);
});

process.on('exit', (code) => {
  console.log('Process exit event with code:', code);
});

console.log('This message is displayed first.');

Output:

This message is displayed first.
A beforeExit event occurred with code: 0
Process exit event with code: 0

Process Methods

  • abort(): Immediately terminate process and create a core dump.
  • chdir(path): Change current working directory.
  • cwd(): Return current working directory.
  • exit([code]): Synchronously terminate process with exit code.
  • kill(pid, [signal]): Send a signal to the specified process.
  • memoryUsage(): Returns an object describing memory usage.
  • nextTick(callback): Defers callback execution until next event loop iteration.

Additional Properties

  • argv: Array of command-line arguments.
  • env: Object containing environment variables.
  • pid: Process ID.
  • platform: Operating system platform.
  • version: Node.js version string.
  • arch: CPU architecture.

Example: Accessing Command-line Arguments

const args = process.argv;
console.log(args);
const name = args[2];
console.log("Hello,", name);

Run with:

node hello.js Tutorials

Output:

[ 'node', 'hello.js', 'Tutorials' ]
Hello, Tutorials

Example: Environment Variables

const envVars = Object.keys(process.env);
envVars.forEach(key => {
  console.log(key + ': ' + process.env[key]);
});

Environment variables can also be set via command line:

USER_ID=101 USER_NAME=admin node app.js

Accessed in script as:

process.env.USER_ID; // "101"
process.env.USER_NAME; // "admin"

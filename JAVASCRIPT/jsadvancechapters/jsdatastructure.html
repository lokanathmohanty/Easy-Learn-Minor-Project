JavaScript - Data Structures

Data Structures are programming constructs used to store and organize data efficiently. With proper use of data structures, we can write effective programs for performing different operations. JavaScript provides several built-in data structures that serve various use cases.

Data Structures in JavaScript

Common data structures available in JavaScript include:

  • Array
  • Object
  • Map
  • Set
  • WeakMap
  • WeakSet
  • Stack
  • Queue
  • Linked List

Arrays

An array is the most commonly used data structure in JavaScript. It can store multiple values, even of different types such as numbers, strings, booleans, objects, or other arrays.

Example


var arr = [1, 'John', true, {name: 'John', age: 25}, [1, 2, 3]];
console.log(arr);

Output


1, John, true, [object Object], 1, 2, 3

Objects

Objects store data as key-value pairs. Keys are strings, and values can be of any data type, including nested objects.

Example


var obj = {
   name: 'John',
   age: 25,
   isMarried: true,
   address: { city: 'New York', country: 'USA' }
};
console.log(obj);

Output


{"name":"John","age":25,"isMarried":true,"address":{"city":"New York","country":"USA"}}

Map

A Map stores data as key-value pairs. Unlike objects, keys in a Map can be of any type and maintain insertion order.

Example


var map = new Map();
map.set('name', 'John');
map.set('age', 25);
map.set('isMarried', true);
map.set('address', {city: 'New York', country: 'USA'});
map.forEach((value, key) => console.log(key + " : " + value));

Output


name : John
age : 25
isMarried : true
address : {"city":"New York","country":"USA"}

Set

A Set stores unique values, meaning no duplicates are allowed.

Example


var set = new Set();
set.add(1);
set.add('John');
set.add(true);
set.forEach(value => console.log(value));

Output


1
John
true

WeakMap

A WeakMap is similar to a Map, but its keys are weakly held. If there are no other references to the key, it will be garbage-collected.

Example


var weakMap = new WeakMap();
var key = {name: 'John'};
weakMap.set(key, 25);
console.log(weakMap.get(key));

Output


25

WeakSet

A WeakSet is similar to a Set, but only stores objects and allows garbage collection if the objects are no longer referenced elsewhere.

Example


var weakSet = new WeakSet();
var obj = {name: 'John'};
weakSet.add(obj);
console.log(weakSet.has(obj));

Output


true

Stack

A Stack follows the LIFO (Last In First Out) principle. The last inserted element is the first to be removed.

Example


class Stack {
   constructor() {
      this.items = [];
   }
   push(element) {
      this.items.push(element);
   }
   pop() {
      if (this.items.length === 0) return 'Underflow';
      return this.items.pop();
   }
}
var stack = new Stack();
stack.push(1);
stack.push(2);
stack.push(3);
console.log(stack.pop()); 
console.log(stack.pop()); 
console.log(stack.pop());

Output


3
2
1

Queue

A Queue follows the FIFO (First In First Out) principle. The first inserted element is the first to be removed.

Example


class Queue {
   constructor() {
      this.items = [];
   }
   enqueue(element) {
      this.items.push(element);
   }
   dequeue() {
      if (this.items.length === 0) return 'Underflow';
      return this.items.shift();
   }
}
var queue = new Queue();
queue.enqueue(1);
queue.enqueue(2);
queue.enqueue(3);
console.log(queue.dequeue()); 
console.log(queue.dequeue()); 
console.log(queue.dequeue());

Output


1
2
3

Linked List

A Linked List stores elements as nodes. Each node contains data and a reference (pointer) to the next node.

Example


class Node {
   constructor(element) {
      this.element = element;
      this.next = null;
   }
}
class LinkedList {
   constructor() {
      this.head = null;
      this.size = 0;
   }
   add(element) {
      var node = new Node(element);
      var current;
      if (this.head === null) {
         this.head = node;
      } else {
         current = this.head;
         while (current.next) {
            current = current.next;
         }
         current.next = node;
      }
      this.size++;
   }
   printList() {
      var current = this.head;
      var str = '';
      while (current) {
         str += current.element + ' ';
         current = current.next;
      }
      console.log(str);
   }
}
var linkedList = new LinkedList();
linkedList.add(1);
linkedList.add(2);
linkedList.add(3);
linkedList.printList();

Output


1 2 3

Conclusion

JavaScript offers a wide variety of data structures that can be used depending on the problem. Arrays and objects are the most commonly used, but for performance and efficiency, structures like Maps, Sets, Stacks, Queues, and Linked Lists provide powerful alternatives.

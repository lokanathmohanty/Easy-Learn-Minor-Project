Node.js - Debugger

Overview

Debugging is an essential process in software development to identify and fix issues. Node.js includes a built-in debugger to pause script execution and inspect variables and expressions, improving application reliability and quality.

What is Node.js Debugger?

The Node.js debugger is a command-line tool that works interactively to pause code execution, step through lines, and inspect program state. It can integrate with tools like Chrome DevTools and Visual Studio Code for visual debugging.

Starting the Debugger

Use the following commands in your terminal:

  • Interactive mode: node inspect test.js (pauses execution allowing step-through debugging)
  • Chrome DevTools mode: node --inspect test.js (starts debugger and provides WebSocket URL for Chrome)
  • Pause on first line: node --inspect-brk test.js (halts execution on the first line ready for user breakpoints)

Debugger Commands

CommandDescription
cont (or c)Continue execution until next breakpoint or program end.
next (or n)Move to the next line of code.
step (or s)Step into a function to inspect.",
out (or o)Step out of the current function.
pausePause execution manually.
watch('var')Watch a variable for changes.
replOpen a debugging REPL to execute JavaScript commands interactively.

Debugging with Chrome DevTools

  1. Run your script with node --inspect-brk test.js.
  2. Open Chrome browser and navigate to chrome://inspect.
  3. Click "Open dedicated DevTools for Node" to find your running script under Remote Target.
  4. Set breakpoints, inspect variables, and step through execution using DevTools interface just like debugging client-side JavaScript.

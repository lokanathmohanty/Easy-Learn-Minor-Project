PHP - Sending Email

The Built-in $\text{mail()}$ Function

PHP includes a native function, **$\text{mail()}$**, for sending email directly from a web application. However, it requires proper configuration of the $\text{php.ini}$ file to work correctly, especially regarding the underlying Mail Transfer Agent (MTA).

Configuration

  • Windows: Requires setting the $\text{SMTP}$ directive (e.g., $\text{smtp.secureserver.net}$) and the $\text{sendmail\_from}$ directive (your sender email address) within the $\text{[mail function]}$ section of $\text{php.ini}$.
  • Linux: Simply requires setting the **$\text{sendmail\_path}$** directive to the location of the $\text{sendmail}$ application (e.g., $\text{/usr/sbin/sendmail -t -i}$).

$\text{mail()}$ Function Syntax and Parameters

mail( to, subject, message, headers, parameters );
  • $\text{to}$ (Required): The recipient(s) address(es).
  • $\text{subject}$ (Required): The email subject (must not contain newline characters).
  • $\text{message}$ (Required): The body of the email. Lines should be separated by $\text{\n}$ and ideally not exceed $\text{70}$ characters.
  • $\text{headers}$ (Optional): Additional headers like $\text{From}$, $\text{Cc}$, $\text{Bcc}$, and MIME version settings for HTML email. Headers are separated by $\text{\r\n}$ (CRLF).

Sending HTML Email

To send an email with HTML formatting, you must specify the appropriate headers to inform the client's mail program that the content is HTML:

  • $\text{MIME-Version: 1.0}$
  • $\text{Content-type: text/html}$ (or $\text{multipart/mixed}$ for attachments)

Example: Sending HTML Email with Headers

This example demonstrates setting up the required headers for HTML content, along with $\text{From}$ and $\text{Cc}$ fields:

<?php
   $to = "xyz@somedomain.com";
   $subject = "HTML Message Test";
   $message = "<b>This is HTML message.</b><h1>This is headline.</h1>";

   $header = "From: abc@somedomain.com \r\n";
   $header .= "Cc: afgh@somedomain.com \r\n";
   $header .= "MIME-Version: 1.0\r\n";
   $header .= "Content-type: text/html\r\n"; // Crucial for HTML formatting

   $retval = mail ($to, $subject, $message, $header);

   if( $retval == true ) {
      echo "Message sent successfully...";
   } else {
      echo "Message could not be sent...";
   }
?>

Advanced Mail: Using PHPMailer

The $\text{mail()}$ function often fails on local development environments (localhost) and lacks advanced features like native SMTP authentication. For reliable and complex email sending, external libraries like **PHPMailer** are recommended. PHPMailer allows you to send emails using an external SMTP server (e.g., $\text{smtp.gmail.com}$) by handling connection, authentication, and encryption ($\text{TLS}$/$\text{SSL}$) internally.

Key PHPMailer Setup Steps

  • Set $\text{isSMTP()}$ to $\text{true}$.
  • Configure the $\text{Host}$ (SMTP server address), $\text{Port}$ (e.g., $\text{587}$ for $\text{TLS}$), and $\text{SMTPSecure}$.
  • Set $\text{SMTPAuth}$ to $\text{true}$ and provide $\text{Username}$ and $\text{Password}$.
  • Use $\text{setFrom()}$ for the sender and $\text{addAddress()}$ for recipients.
  • Use $\text{isHTML(true)}$ and set the message body.
  • For attachments, the $\text{mail()}$ function requires manually constructing complex $\text{multipart/mixed}$ MIME headers and $\text{base64}$ encoding the file content. PHPMailer handles this complexity via methods like $\text{addAttachment()}$ (not explicitly shown in the provided example, but a core feature).

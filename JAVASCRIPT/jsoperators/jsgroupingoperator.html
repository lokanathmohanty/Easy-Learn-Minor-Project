JavaScript - Grouping Operator

The grouping operator in JavaScript controls the precedence of the evaluation in expressions. It is denoted by parentheses (), and you can put the expression inside that to change the expression evaluation order. It helps to evaluate an expression with lower precedence before an expression with higher precedence.

Syntax

You can follow the syntax below to use the grouping operator:

( exp )

In the above syntax, the exp is an expression to change the precedence of evaluation.

let res1 = 4 + 5 * 6; // 4 + 30
let res2 = (4 + 5) * 6; // 9 * 6

The multiplication (*) operator in JavaScript has higher precedence than the addition (+) operator. So, in the first expression it multiplies 5 and 6 first, and then adds 4.

In the second expression, we grouped (4 + 5) using the grouping operator, so it is evaluated first, then multiplied by 6.

Example

Example: Using grouping operator with arithmetic

Code:

let res1 = 4 + 5 * 6;
let res2 = (4 + 5) * 6;
console.log(res1); // 34
console.log(res2); // 54

Immediately Invoked Function Expressions (IIFEs)

To define an immediately invoked function in JavaScript, we use the grouping operator. The anonymous function definition is put inside the grouping operator. These are also called self-executing functions.

(function () { return 5; })();

Here, the function definition is put inside the grouping operator and executes immediately.

Example

Example: Using grouping operator with IIFE

Code:

let ans1 = 5 + 10 / (function () { return 5; })();
let ans2 = (5 + 10) / (function () { return 5; })();
console.log(ans1); // 7
console.log(ans2); // 3

Grouping Operator with Logical Operators

The grouping operator in JavaScript can also be used to group expressions with logical operators. For example, the && operator has a higher precedence than the || operator.

false && false || true; // true

However, if we add parentheses:

false && (false || true); // false

Example

Example: Using grouping operator with logical operators

Code:

let res1 = false && false || true;
let res2 = false && (false || true);
console.log(res1); // true
console.log(res2); // false

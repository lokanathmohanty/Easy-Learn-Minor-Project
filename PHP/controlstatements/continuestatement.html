PHP `continue` Statement

The **`continue`** statement is a **loop control statement** that is used to **skip the remaining code** in the current iteration of a loop and immediately proceed to the **next iteration**. It can be used within `for`, `foreach`, `while`, and `do...while` loops.

Basic Functionality and Flow

When PHP encounters the `continue` keyword, it immediately stops executing the rest of the statements in the loop body for that iteration and jumps to the expression evaluation phase (the condition check) of the next cycle.

for (init; condition; increment) {
   if (specific_condition) {
      **continue;** // Skip to increment and next condition check
   }
   // Code here is skipped if 'continue' runs
}

Example: Skipping Even Numbers in a `for` Loop

The `continue` statement skips the `echo` line whenever `$x` is evenly divisible by 2.

for ($x=1; $x<=10; $x++) { if ($x%2==0) { **continue;** } echo "x = $x \n"; }

Output: x = 1 \n x = 3 \n x = 5 \n x = 7 \n x = 9

Example: Skipping Elements in a `foreach` Loop

This is useful for filtering out specific items during array iteration.

$fruits = ["Apple", "Mango", "Orange"];
foreach ($fruits as $fruit) { if ($fruit == "Mango") { **continue;** } echo "Fruit: $fruit\n"; }

Output: Fruit: Apple \n Fruit: Orange

Skipping Multiple Loops (Numeric Argument)

Like `break`, the `continue` statement accepts an optional numeric argument to specify how many levels of enclosing loops should be skipped to the end of. The default is 1, which skips to the next iteration of the immediate loop.

continue [level];

If you use **`continue 2;`** inside a deeply nested loop, execution jumps to the condition check/increment of the loop that is **two levels above** the current one.

Django Template Inheritance: Adding a Master Template 🖼️

Django supports **template inheritance**, an essential feature that ensures a uniform look and structure across all pages of a web application. It works similarly to object-oriented inheritance, where a **master template** (or base template) provides the overall skeleton, and **child templates** fill in the variable content.

The Master Template (base.html)

The master template defines the common structure, such as the page header, footer, and sidebar. Crucially, it uses the **{% block %} and {% endblock %}** template tags to mark the areas meant to be overridden by child templates. Each block must have a unique identifier (block_name).

The provided **base.html** template establishes the consistent layout with a header, a sidebar containing links (home, register, login), a content area, and a footer:

{% block block_name %}
   ...
   ...{% endblock %}

In this example, the main content area is designated by {% block contents %}.

The Child Template (index.html)

A child template inherits the structure of the master template and overrides the content blocks. It achieves this using two steps:

  1. **Inheritance:** The **{% extends "base.html" %}** tag is the first line in the child template, declaring which master template it inherits from.
  2. **Content Population:** It uses the same **{% block contents %}** tag to insert its specific HTML content, thereby replacing the dummy block content in the base template.

The provided **index.html** overrides the contents block to display its unique "Home page" message, while automatically receiving the header, sidebar, and footer defined in base.html.

Implementation (View and URL)

The view function simply renders the child template:

from django.shortcuts import render

def index(request):
   return render(request, "index.html", {})

When the view is registered with the URL dispatcher (e.g., path('home/', views.index, name='home')) and accessed, Django first processes the index.html template. It sees the {% extends %} tag, incorporates the base.html structure, and inserts the content between the {% block contents %} tags into the correct location, rendering the complete, uniform page.

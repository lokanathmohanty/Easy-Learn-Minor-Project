PowerShell: Aliases

An alias in PowerShell is a shorthand or alternate name for a cmdlet, function, script, or executable file. Aliases help users save time by typing shorter names instead of full cmdlet names.

Creating Aliases

Use the New-Alias cmdlet to create an alias. For example, the alias help for Get-Help cmdlet:

New-Alias -Name help -Value Get-Help
help Get-WmiObject -Detailed

This executes Get-Help via the alias help.

Viewing Aliases

Use Get-Alias to list all aliases in the current session:

Get-Alias

Sample output:

CommandType     Name                     Definition
-----------     ----                     ----------
Alias           %                        ForEach-Object
Alias           ?                        Where-Object
Alias           ac                       Add-Content
Alias           asnp                     Add-PSSnapIn
...

Additional Notes

Aliases cannot include parameters. To alias a command with specific parameters, define a function instead.

Aliases can be made permanent by adding New-Alias or Set-Alias commands to your PowerShell profile script.

JavaScript - Event Bubbling

Content

Event bubbling is the process by which an event triggered on a DOM element propagates upward through its ancestors. When an event occurs on a target element, event handlers on parent elements may also run as the event "bubbles" up the DOM tree.

Event Bubbling Steps

  • Event triggering — the event originates on a target element.
  • Capturing phase (optional) — the event travels from the document root down to the target (handlers registered for capture run here).
  • Target phase — the event reaches the target element.
  • Bubbling phase — the event bubbles from the target up through ancestor elements (handlers registered without capture run here).

When to use bubbling

  • When you want a single handler on a parent to manage many child elements.
  • To handle dynamically added elements without attaching handlers to each new element.
  • To implement centralized logging or analytics for user interactions.

How to stop bubbling

Inside an event handler you can prevent further propagation by calling event.stopPropagation() or stop all default behavior and propagation with event.stopImmediatePropagation().

Example

Example — Two nested <div> elements (description)

This example demonstrates two nested elements. A click on the inner (child) element triggers its handler and then the parent's handler due to bubbling.

HTML structure shown (escaped):

<div id="parent">

<div id="child">Click me</div>

</div>

JavaScript description:

  • Attach a "click" listener to the parent: parent.addEventListener('click', parentHandler)
  • Attach a "click" listener to the child: child.addEventListener('click', childHandler)
  • Clicking the child runs childHandler then parentHandler unless propagation is stopped.

Example — Three nested levels (description)

This example shows three nested levels. Clicking the innermost element triggers handlers on level 3, then level 2, then level 1 as the event bubbles up.

HTML structure shown (escaped):

<div id="level1">

<div id="level2">

<div id="level3">Click here</div>

</div>

</div>

Behavior notes:

  • Use event.target inside handlers to detect the original target element.
  • Use event.currentTarget to refer to the element whose handler is currently executing.
  • To prevent parent handlers from running, call event.stopPropagation() inside the child handler.

Quick Reference

  • event.target — original element that initiated the event.
  • event.currentTarget — element whose event listener is executing.
  • stopPropagation() — stops bubbling to ancestor handlers.
  • stopImmediatePropagation() — stops other listeners on the same element and further propagation.

Tip: favor event delegation (a single handler on an ancestor) when managing many similar child elements.

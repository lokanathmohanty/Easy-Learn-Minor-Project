Python - Nested if Statement

Python supports nested if statements, meaning you can place an if or if...else construct inside another if statement.

This is useful when additional conditions must be checked only after the first condition evaluates to True. You can also use an if...elif...else block inside another if...elif...else block.

Syntax of Nested if Statement

if boolean_expression1:
    statement(s)
    if boolean_expression2:
        statement(s)

Example of Nested if Statement

The following example checks divisibility of a number:

num = 36
print("num =", num)
if num % 2 == 0:
    if num % 3 == 0:
        print("Divisible by 3 and 2")
print("....execution ends....")

Output:

num = 36
Divisible by 3 and 2
....execution ends....

Nested if Statement with else Condition

We can also include else inside nested if blocks. Depending on which conditions evaluate to True, the appropriate branch executes.

Syntax

if expression1:
    statement(s)
    if expression2:
        statement(s)
    else:
        statement(s)
else:
    if expression3:
        statement(s)
    else:
        statement(s)

Example

num = 8
print("num =", num)

if num % 2 == 0:
    if num % 3 == 0:
        print("Divisible by 3 and 2")
    else:
        print("Divisible by 2 not divisible by 3")
else:
    if num % 3 == 0:
        print("Divisible by 3 not divisible by 2")
    else:
        print("Not divisible by 2 not divisible by 3")

Sample Outputs

num = 8
Divisible by 2 not divisible by 3

num = 15
Divisible by 3 not divisible by 2

num = 12
Divisible by 3 and 2

num = 5
Not divisible by 2 not divisible by 3

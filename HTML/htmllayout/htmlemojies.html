HTML - Emojis

Emojis are used in webpages to represent emotions in plain text. They are widely used in social media, messaging apps, and websites to add humor and feelings. For example: 😈, 😁, 😉

What are Emojis?

Emojis are small graphical symbols or icons representing emotions, objects, animals, flags, food items, nature, and more. Though they look like graphical symbols, emojis are characters from the UTF-8 character set.

UTF-8 Emojis

How to Add Emojis in HTML

To add emojis, always define character encoding in the <head> section using UTF-8:

<meta charset="UTF-8">

You can then use emojis in two ways:

  • Using Decimal Code → Format: &#code;
  • Using Hexadecimal Code → Format: &#xcode;

Example: Using Decimal Code

Devil Emoji: 😈

Tears of Joy Emoji: 😂

Thumbs Up Emoji: 👍

Example: Using Hexadecimal Code

Devil Emoji: 😈

Tears of Joy Emoji: 😂

Thumbs Up Emoji: 👍

Drawbacks of Using HTML Emojis

  • Emojis are not directly available on computer keyboards.
  • Users must remember or look up their Unicode codes.

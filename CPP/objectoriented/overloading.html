C++ Overloading (Operator and Function) 🎭

**Overloading** is a core C++ feature that allows the reuse of a name (for a function or an operator) to perform different operations depending on the types or number of arguments involved. The compiler resolves which specific definition to use through a process called **overload resolution**.

1. Function Overloading

**Function overloading** allows multiple functions in the same scope to share the same name. They must be distinguished by either:

  • The **number of arguments**.
  • The **type of arguments**.

Crucially, you **cannot** overload functions that differ only by their return type.

Example

The print() function is overloaded to handle different data types:

void print(int i);       // Prints an integer
void print(double f);    // Prints a double
void print(char* c);     // Prints a C-style string

When you call `pd.print(500.263);`, the compiler automatically selects the `void print(double f)` definition.

2. Operator Overloading

**Operator overloading** allows you to redefine the behavior of most C++ built-in operators (like `+`, `-`, `*`, `==`, etc.) when applied to **user-defined types** (objects). This makes working with custom objects more intuitive.

Syntax

An overloaded operator is a function defined using the keyword **operator** followed by the operator symbol.

// Member function declaration for overloading '+'
Box operator+(const Box&);

Example: Overloading the Addition Operator (`+`)

The example shows the `+` operator being overloaded to define the "addition" of two `Box` objects (summing their respective dimensions).

// Defined as a member function of Box
Box Box::operator+(const Box& b) {
   Box box;
   // 'this' refers to the object on the left of the '+' (Box1)
   // 'b' refers to the object on the right of the '+' (Box2)
   box.length = this->length + b.length;
   // ...
   return box;
}

This allows the natural syntax: `Box3 = Box1 + Box2;`

Overloadable Operators (Partial List)

Most common operators are overloadable, including: `+`, `-`, `*`, `/`, `=`, `==`, `!=`, `<`, `>`, `<<`, `>>`, `[]`, `()`, and `new`/`delete`.

Non-Overloadable Operators

A few operators cannot be overloaded to preserve language consistency: **Scope Resolution** (`::`), **Member Selection** (`.`), **Pointer to Member Selection** (`.*`), and the **Ternary Conditional** (`?:`).

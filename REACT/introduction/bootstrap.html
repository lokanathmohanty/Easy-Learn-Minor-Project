ReactJS - Bootstrap

Bootstrap is a popular CSS framework used by front-end developers around the world. It provides excellent support for designing responsive, high-performance web pages using utility classes and components. Bootstrap also offers a large collection of jQuery-based UI components.

By integrating Bootstrap with React, developers can enjoy the benefits of both frameworks for building beautiful, responsive web applications.

Integrating Bootstrap

Bootstrap can be integrated into React applications in multiple ways:

  • Link tag (CSS only)
  • Import feature (CSS only)
  • Link tag (Bootstrap + jQuery UI)
  • Wrapper React component
  • Native React Bootstrap component

Link tag (CSS only)

To include Bootstrap CSS only, create a new React application and add the link tag in public/index.html.

<!-- CSS only -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.2.2/dist/css/bootstrap.min.css"
rel="stylesheet" integrity="sha384-Zenh87qX5JnK2Jl0vWa8Ck2rdkQ2Bzep5IDxbcnCeuOxjzrPF/et3URy9Bv1WTRi"
crossorigin="anonymous">

Example App component:

import './App.css'
function App() {
  return (
    <div className="container">
      <button type="button" class="btn btn-primary">Primary</button>
      <button type="button" class="btn btn-secondary">Secondary</button>
      <button type="button" class="btn btn-success">Success</button>
      <button type="button" class="btn btn-danger">Danger</button>
      <button type="button" class="btn btn-warning">Warning</button>
      <button type="button" class="btn btn-info">Info</button>
      <button type="button" class="btn btn-light">Light</button>
      <button type="button" class="btn btn-dark">Dark</button>
      <button type="button" class="btn btn-link">Link</button>
    </div>
  );
}
export default App;

Import feature (CSS only)

Another way is to install Bootstrap as a dependency and import it in your React project.

npm install --save bootstrap

Example App component:

// Bootstrap CSS
import "bootstrap/dist/css/bootstrap.min.css";
// Bootstrap Bundle JS
import "bootstrap/dist/js/bootstrap.bundle.min";
import './App.css'

function App() {
  return (
    <div className="container">
      <button type="button" class="btn btn-primary">Primary</button>
      <button type="button" class="btn btn-secondary">Secondary</button>
      <button type="button" class="btn btn-success">Success</button>
      <button type="button" class="btn btn-danger">Danger</button>
      <button type="button" class="btn btn-warning">Warning</button>
      <button type="button" class="btn btn-info">Info</button>
      <button type="button" class="btn btn-light">Light</button>
      <button type="button" class="btn btn-dark">Dark</button>
      <button type="button" class="btn btn-link">Link</button>
    </div>
  );
}
export default App;

Link tag (Bootstrap + jQuery UI)

This option allows developers to use Bootstrap and jQuery UI components together on the same page with React. It is a simple option suitable for small projects.

Wrapper React Component

Developers can create wrapper React components for Bootstrap components and reuse them in their applications. This approach is useful for moderate to complex applications.

Native React Bootstrap Component

React also has dedicated Bootstrap component libraries:

  • React-Bootstrap
  • Bootstrap 4 React
  • Reactstrap
  • CoreUI Bootstrap React

Example: React-Bootstrap

npm install --save react-bootstrap bootstrap
        
// Bootstrap CSS
import "bootstrap/dist/css/bootstrap.min.css";
// Bootstrap Bundle JS
import "bootstrap/dist/js/bootstrap.bundle.min";
import './App.css'
import { Button } from 'react-bootstrap';

function App() {
  return (
    <div className="container">
      <Button variant="primary">Primary</Button>{' '}
      <Button variant="secondary">Secondary</Button>{' '}
      <Button variant="success">Success</Button>{' '}
      <Button variant="warning">Warning</Button>{' '}
      <Button variant="danger">Danger</Button>{' '}
      <Button variant="info">Info</Button>{' '}
      <Button variant="light">Light</Button>{' '}
      <Button variant="dark">Dark</Button>{' '}
      <Button variant="link">Link</Button>
    </div>
  );
}
export default App;

Summary

React provides multiple ways to integrate with the Bootstrap library. Developers can start with simple CSS imports or link tags and progressively adopt native React-Bootstrap components. This flexibility enables smooth migration and the ability to leverage rich third-party Bootstrap components for better UI/UX.

JavaScript - Data Types

Data types in JavaScript refer to the types of the values that we are storing or working with. One of the most fundamental characteristics of a programming language is the set of data types it supports.

JavaScript data types can be categorized as primitive and non-primitive (object). JavaScript (ES6 and higher) allows you to work with seven primitive data types:

  • String
  • Number
  • Boolean
  • null
  • undefined
  • BigInt
  • Symbol

In addition to these, JavaScript supports a composite type called object, which includes:

  • Object
  • Array
  • Date

JavaScript String

A string is a sequence of characters. It can be created using single quotes, double quotes, or backticks.

let str1 = "Hello World!";
let str2 = 'Hello World!';
let str3 = `Hello World!`;

JavaScript Number

Numbers in JavaScript are always floating-point values (64-bit IEEE 754 standard).

let num1 = 10;       // Integer
let num2 = 10.22;    // Floating point
let num3 = 98e4;     // Exponential notation (980000)

JavaScript Boolean

A Boolean represents logical values: true or false.

let bool1 = true;
let bool2 = false;

JavaScript Undefined

Variables declared but not initialized contain undefined.

let houseNo; // undefined
let apartment = undefined;

JavaScript Null

null is used to represent an intentional absence of value.

let houseNo = null;

JavaScript BigInt

BigInt is used to store very large integers.

let big = 1245646564515635412348923448234842842343546576876789n;

JavaScript Symbol

Symbols are unique and immutable values introduced in ES6.

let sym1 = Symbol("id");
let sym2 = Symbol("id"); // sym1 !== sym2

JavaScript Object

Objects store data in key-value pairs.

let obj = { animal: "Horse", legs: 4 };

JavaScript Array

Arrays store lists of values.

const colors = ["Brown", "Red", "Blue"];

JavaScript Date

The Date object allows working with dates and times.

let today = new Date();

Dynamic Types

JavaScript is dynamically typed, meaning variables can hold different types at different times.

let value = "One"; 
value = 1; 
value = true;

typeof Operator

The typeof operator checks the type of a variable.

typeof 30;       // "number"
typeof "Hello";  // "string"
typeof true;     // "boolean"

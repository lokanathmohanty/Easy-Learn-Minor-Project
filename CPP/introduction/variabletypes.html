C++ Variables: Naming, Definition, and Declaration

A **variable** provides a named storage location that a program can manipulate. Every variable has a **type** that determines its memory size, the range of values it can store, and the operations that can be applied to it.

Variable Naming Conventions 🏷️

Variable names must adhere to specific rules in C++, which is a **case-sensitive** language:

  • Must begin with a **letter** (A-Z, a-z) or an **underscore** (_).
  • Subsequent characters can be **letters**, **digits** (0-9), or **underscores**.
  • **Cannot** be a C++ **keyword** (e.g., int, float).
  • **Cannot** contain spaces or hyphens (-).

Variable Definition and Initialization

Variable Definition tells the compiler how much and where to create storage for the variable. It specifies the **data type** and a list of variable names.

Syntax: type variable_list;

Example: int i, j, k; (Declares and defines three integer variables)

Variable Initialization means assigning an initial value at the time of definition.

Syntax: type variable_name = value;

Example: char x = 'x';

Variable Declaration vs. Definition

While a definition allocates storage, a **declaration** assures the compiler that a variable exists with a given type and name, allowing compilation to proceed without the full storage details.

  • A variable can be **declared multiple times** but **defined only once**.
  • The extern keyword is used to declare a variable that is defined elsewhere (often in another file), postponing the allocation of memory until the linking stage.

Declaration Syntax: extern type variable_name;

Lvalues and Rvalues

Expressions in C++ are categorized based on their ability to represent a memory location:

  • Lvalue (Left-hand side value): Refers to a **memory location**. It can appear on either the left or right side of an assignment operator. **Variables** are Lvalues.

    Valid: int g = 20;

  • Rvalue (Right-hand side value): Refers to a **data value** stored at some memory address. It can only appear on the right side of an assignment. **Numeric literals** are Rvalues.

    Invalid: 10 = 20; (Rvalue cannot be assigned a value)

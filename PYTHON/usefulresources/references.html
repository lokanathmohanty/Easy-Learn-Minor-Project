Python Reference

This reference section provides an overview of Python's built-in functions, methods, keywords, modules, and additional libraries. It acts as a quick guide for developers and learners to recall Python features during programming and interview preparation.

Python Built-in Functions

  • Common Functions: print(), len(), type(), id(), help()
  • Type Conversion: int(), float(), str(), list(), dict(), set()
  • Mathematical: abs(), min(), max(), pow(), sum()
  • Iterables: range(), enumerate(), zip(), map(), filter()
  • Input/Output: input(), open()
  • Others: any(), all(), sorted(), reversed()

String Methods

  • upper(), lower(), title()
  • strip(), replace(), split(), join()
  • find(), startswith(), endswith()
  • isalpha(), isdigit(), isspace()

List Methods

  • append(), extend(), insert()
  • remove(), pop(), clear()
  • sort(), reverse(), index(), count()

Dictionary Methods

  • keys(), values(), items()
  • get(), update(), pop(), popitem()
  • clear(), copy()

Tuple Methods

  • count(), index()

Set Methods

  • add(), remove(), discard(), pop()
  • union(), intersection(), difference(), symmetric_difference()
  • issubset(), issuperset()

File Methods

  • open(), read(), readline(), readlines()
  • write(), writelines(), close()

Python Keywords

Some commonly used Python keywords are:

  • and, or, not, if, else, elif
  • for, while, break, continue, pass
  • def, class, return, yield
  • try, except, finally, raise, assert
  • import, from, as, with
  • True, False, None

Built-in Module Reference

  • random: Generate random numbers.
  • sys: Access system-specific parameters and functions.
  • requests: HTTP requests handling.
  • re: Regular expressions.
  • math: Mathematical operations.
  • cmath: Complex number math functions.
  • time: Time access and conversions.
  • sqlite3: Database operations with SQLite.
  • functools: Higher-order functions, caching, partials.
  • statistics: Mathematical statistics functions.
  • collections: Specialized data structures like deque, Counter, defaultdict.

Additional Libraries

  • pyforest: Lazy import of common Python libraries.
  • randfacts: Generates random fun facts.
  • faker: Generates fake data (names, addresses, emails, etc.).
  • holidays: Provides holiday dates for different countries.
  • pyperclip: Clipboard handling for copy-paste operations.
  • rarfile: Work with RAR compressed files.

Next Steps

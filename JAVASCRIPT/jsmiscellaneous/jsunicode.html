JavaScript - Unicode

What is Unicode?

Unicode is a universal set of characters that contains a list of characters from the majority of languages, writing systems, etc. It provides a unique number for every character without focusing on programming language, platform, operating system, etc. Furthermore, it also includes punctuation, emojis, special characters, etc.

In short, the Unicode set contains unique numbers, each referring to a unique character, having the same meaning regardless of platform, operating system, etc.

Intuition behind Unicode

Before understanding Unicode, let's understand the idea behind it. You can read this tutorial because you know the meaning of the letters written. A reader and writer both have the same comprehension of the English alphabet, which enables communication.

Similarly, computers don't understand letters. For computers, letters are sequences of bits, and each sequence is mapped to a unique character — that mapping is called Unicode.

Unicode in JavaScript

JavaScript allows developers to use Unicode characters in string literals and source code. Developers need to use the escape notation (\u) to use Unicode characters in JavaScript code.

Syntax

const char = '\uxxxx';

Here, xxxx represents hexadecimal characters, and \u represents the escape notation.

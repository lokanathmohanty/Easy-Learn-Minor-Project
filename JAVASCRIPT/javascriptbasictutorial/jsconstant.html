JavaScript - Constants

JavaScript constants are the variables whose values remain unchanged throughout the execution of the program. You can declare constants using the const keyword.

JavaScript const Keyword

The const keyword is introduced in the ES6 version of JavaScript with the let keyword. The const keyword is used to define variables having constant reference.

A variable defined with const can't be re-declared or reassigned. The const declaration has block as well as function scope.

Declaring JavaScript Constants

You always need to assign a value at the time of declaration if the variable is declared using the const keyword.

const x = 10; // Correct Way

You can't declare variables with the const keyword without initialization.

const y; // Incorrect way
y = 20;

Can't be Reassigned

You can't update the value of the variables declared with the const keyword.

const y = 20;
y = 40; // Not possible

Block Scope

A variable declared with const has block-scope. This means the same variable is treated as different outside the block.

Example:

{ const x = "john"; }
const x = "Doe"

But we can't re-declare the const variable within the same block:

{ const x = "john"; const x = "Doe"; // Incorrect }

Constant Arrays and Objects in JavaScript

We can declare arrays and objects using the const keyword, but only the reference is constant, not the value. You can update elements/properties, but you can't reassign a new array or object.

Example (Constant Arrays)

Updating elements and pushing new values is allowed:


const arr = ["door", "window", "roof", "wall"];
arr[0] = "gate";
arr.push("fence");
// arr = ["table", "chair"] // Error
document.write(arr);

Output: gate,window,roof,wall,fence

Example (Constant Objects)


const obj = { animal: "Lion", color: "Yellow" };
obj.animal = "Tiger";
obj.legs = 4;
document.write(JSON.stringify(obj));
// obj = { name: "cow" } // Error

Output: {"animal":"Tiger","color":"Yellow","legs":4}

So, we can't change the reference to variables declared with const, but we can update their contents.

No Const Hoisting

Variables defined with const are not hoisted. Accessing before declaration will cause an error.


document.write(x);
const x = 10; // Error

Key Properties of const

  • Block scope
  • Can't be re-declared in the same scope
  • Not hoisted
  • Holds a constant reference

Which should you use?

  • Use let for block scope variables.
  • Use const for constant references.
  • Use var if you need function scope, but avoid re-declaring variables when possible.

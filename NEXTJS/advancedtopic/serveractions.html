Next.js Server Actions

Overview of Server Actions

Server Actions are asynchronous functions in Next.js that execute exclusively on the server side. They are essential for performing server-side operations such as:

  • Data fetching and mutations.
  • Authentication logic.
  • Handling form submissions.

A function is designated as a Server Action by using the "use server" directive. This directive can be placed in two locations:

  • At the top of an async function to make only that function a Server Action.
  • At the top of a separate file to make all exports in that file Server Actions.

Server Action in a Client Component

Server Actions can be imported and called directly from a **Client Component** (which is marked with 'use client'). This allows client-side events, like a button click, to safely trigger server-side code without needing to build an explicit API endpoint.

Example Server Action (app/actions.ts):

'use server'

export async function create() {
    // Logic for creating data and revalidating cache
    return true;
}

Example Client Component (app/page.tsx):

'use client'
import { create } from './actions'

export function Button() {
    return <button onClick={() => create()}>
        Create
    </button>
}

Server Actions in Form Handling

Next.js integrates Server Actions seamlessly with the standard HTML **<form>** element. By passing a Server Action function to the action prop of the form, the framework automatically handles the form submission, serializes the data into a **FormData** object, and invokes the server function.

Example Form Submission:

export default function Page() {
  async function createInvoice(formData: FormData) {
    'use server'

    const rawFormData = {
      customerId: formData.get('customerId'),
      amount: formData.get('amount'),
      status: formData.get('status'),
    }
 
    // Perform data mutation and cache revalidation
  }

  return (
    <form action={createInvoice}>
        {/* Form fields here... */}
        <button type="submit">Submit Invoice</button>
    </form>
  )
}

Programmatic Form Submission

You can trigger a form submission programmatically using the **requestSubmit()** method available on the HTML form element. This is often used to implement custom submission shortcuts, such as the Ctrl/Cmd + Enter shortcut commonly used in text areas.

Example Programmatic Submission:

'use client'
 export function Entry() {
  const handleKeyDown = (e: React.KeyboardEvent<HTMLTextAreaElement>) => {
    if (
      (e.ctrlKey || e.metaKey) &&
      (e.key === 'Enter' || e.key === 'NumpadEnter')
    ) {
      e.preventDefault()
      // Triggers the form's action prop
      e.currentTarget.form?.requestSubmit() 
    }
  }
 
  return (
    <div>
      <textarea name="entry" rows={20} required onKeyDown={handleKeyDown} />
    </div>
  )}

CSS - Combinators

CSS combinators are used to specify the relationship between selectors so that styling can be applied based on the position and hierarchy of elements in an HTML structure. They are especially useful for targeting elements depending on whether they are children, descendants, or siblings of another element.

For example, using a combinator, you can style a <p> element that is placed immediately after a <div> element.

Types of Combinators

  • Descendant Combinator (whitespace)
  • Child Combinator (>)
  • Adjacent Sibling Combinator (+)
  • General Sibling Combinator (~)

CSS Descendant Combinator

The descendant combinator is represented by a single space. It selects elements that are nested within another element, no matter how deep the nesting goes.

Syntax:

div p {
   /* CSS styles for all p elements inside div */
}

Example:

.parent p {
   color: red;
   font-weight: bold;
}
      
<div class="parent">
   <h3>This is h3 inside parent</h3>
   <p>Paragraph inside parent</p>
   <p>Another paragraph inside parent</p>
</div>
<div>
   <p>Paragraph outside parent</p>
</div>

CSS Child Combinator

The child combinator (>) selects only the direct children of a specified element. It will not select deeper nested elements.

Syntax:

div > p {
   /* CSS styles for all direct p children of div */
}

Example:

.parent > p {
   color: blue;
   font-weight: bold;
}
      
<div class="parent">
   <h3>Heading inside parent</h3>
   <p>Direct child paragraph</p>
   <div>
      <p>Nested paragraph (not selected)</p>
   </div>
</div>

CSS Adjacent Sibling Combinator

The adjacent sibling combinator (+) selects an element that is immediately preceded by a specified element. Only the first sibling that comes directly after is selected.

Syntax:

h3 + p {
   /* CSS styles for the p element immediately after h3 */
}

Example:

h3 + p {
   color: purple;
   font-style: italic;
}
      
<h3>Heading</h3>
<p>Paragraph immediately after h3 (styled)</p>
<p>Second paragraph (not styled)</p>

CSS General Sibling Combinator

The general sibling combinator (~) selects all siblings of a specified element that appear after it. Unlike the adjacent sibling combinator, it applies to multiple following elements.

Syntax:

h3 ~ p {
   /* CSS styles for all p elements after h3 */
}

Example:

h3 ~ p {
   color: darkorange;
   text-decoration: underline;
}
      
<p>Paragraph before h3 (not styled)</p>
<h3>Heading</h3>
<p>Paragraph after h3 (styled)</p>
<p>Another paragraph after h3 (styled)</p>

Combining Multiple Combinators

CSS also allows combining multiple combinators to create complex rules. For example, you can target a <p> that is a direct child of a <div> and also immediately follows an <h3>.

Syntax:

div > h3 + p {
   /* CSS styles for p directly inside div and immediately after h3 */
}

Example:

ul > li + a {
   color: red;
   text-decoration: underline;
}
ul > li > a {
   color: blue;
   text-decoration: none;
}
      
<nav>
   <ul>
      <li><a href="#">Home</a></li>
      <li><a href="#">About</a></li>
      <li><a href="#">Services</a></li>
      <a href="#">Contact</a>
   </ul>
</nav>

Conclusion

CSS combinators add precision and flexibility when styling elements based on their structural relationship. Whether it's nested elements, direct children, or siblings, combinators help developers apply styles without adding extra classes or IDs.

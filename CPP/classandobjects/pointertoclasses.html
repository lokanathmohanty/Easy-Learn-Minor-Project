Pointer to C++ Classes ➡️📦

A **pointer to a C++ class** works exactly like a pointer to a C structure: it is a variable that stores the **memory address** of an object (an instance of the class).

Declaration and Assignment

To declare a pointer to a class, you use the class name followed by the dereference operator (`*`). You assign the address of an object using the **address-of operator** (`&`).

Box Box1(3.3, 1.2, 1.5); // Object declaration
Box *ptrBox;             // Declare pointer to a Box class

ptrBox = &Box1;        // Save the address of Box1 in ptrBox

Accessing Members with a Pointer

To access the members (data or functions) of an object via a pointer to that object, you use the **member access operator** (or **arrow operator**): **->**.

The expression `ptrBox->Volume()` is shorthand for `(*ptrBox).Volume()`, which first dereferences the pointer to get the object, and then calls the member function.

// Accessing the Volume() method using the arrow operator
cout << "Volume of Box1: " << ptrBox->Volume() << endl;

Pointers are essential for working with polymorphism, linked data structures, and dynamic memory allocation in C++.

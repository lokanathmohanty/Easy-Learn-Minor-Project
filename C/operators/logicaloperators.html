Logical Operators in C

Logical operators in C evaluate to either True or False and are typically used with Boolean operands.

The logical AND operator (&&) and the logical OR operator (||) are binary operators requiring two operands, while the logical NOT operator (!) is unary.

Since C treats 0 as False and any non-zero number as True, operands to logical operators are implicitly converted to Boolean values.

Logical Operators

  • && (Logical AND): True if both operands are non-zero.
  • || (Logical OR): True if either operand is non-zero.
  • ! (Logical NOT): Unary operator that reverses logical state.

Truth Tables

Logical AND (&&)

  • true && true = true
  • true && false = false
  • false && true = false
  • false && false = false

Logical OR (||)

  • true || true = true
  • true || false = true
  • false || true = true
  • false || false = false

Logical NOT (!)

  • !true = false
  • !false = true

Examples

Example 1: Basic logical operators usage in C

#include <stdio.h>

int main(){
   int a = 5;
   int b = 20;

   if (a && b){
      printf("Line 1 - Condition is true\n");
   }

   if (a || b){
      printf("Line 2 - Condition is true\n");
   }

   a = 0;
   b = 10;

   if (a && b){
      printf("Line 3 - Condition is true\n");
   } else {
      printf("Line 3 - Condition is not true\n");
   }

   if (!(a && b)){
      printf("Line 4 - Condition is true\n");
   }
   return 0;
}

Output:

Line 1 - Condition is true
Line 2 - Condition is true
Line 3 - Condition is not true
Line 4 - Condition is true

Example 2: Logical operators with char type

#include <stdio.h>

int main(){
   char a = 'a';
   char b = '\0'; // Null character

   if (a && b){
      printf("Line 1 - Condition is true\n");
   }

   if (a || b){
      printf("Line 2 - Condition is true\n");
   }
   return 0;
}

Output:

Line 2 - Condition is true

Example 3: Compound Boolean expression using logical OR

#include <stdio.h>

int main(){
   int phy = 50;
   int maths = 60;

   if (phy < 50 || maths < 50){
      printf("Result:Fail");
   } else {
      printf("Result:Pass");
   }
   return 0;
}

Output: Result:Pass

Example 4: Compound Boolean expression using logical AND

#include <stdio.h>

int main(){
   int phy = 50;
   int maths = 60;

   if (phy >= 50 && maths >= 50){
      printf("Result: Pass");
   } else {
      printf("Result: Fail");
   }
   return 0;
}

Output: Result: Pass

Example 5: Using logical NOT operator in a while loop

#include <stdio.h>

int main(){
   int i = 0;

   while (!(i > 5)){
      printf("i = %d\n", i);
      i++;
   }
   return 0;
}

Output:

i = 0
i = 1
i = 2
i = 3
i = 4
i = 5

Logical operators are commonly used to build complex boolean expressions and control program flow.

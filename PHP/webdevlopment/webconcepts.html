PHP: Web Concepts and Dynamic Content

PHP is a **server-side scripting language** used to generate **dynamic webpages**. It operates on a Web server with an installed PHP module, communicating with the client browser via the **HTTP protocol**.

Adding Dynamic Content

Dynamic content can be added on both the client and server side:

  • Client-Side: **JavaScript** runs in the browser, manipulating the HTML Document Object Model (DOM) to render dynamic content based on the client's environment (e.g., local time).
  • Server-Side: **PHP** runs on the server, processing requests, interacting with databases, and generating the final HTML/data before sending it to the client (e.g., server time, user-specific data).

Core Web Application Capabilities with PHP

PHP is instrumental in enabling essential web features:

  • **Form Handling:** PHP intercepts and processes data submitted from HTML forms using methods like **HTTP GET** and **POST**.
  • **Database Interaction:** PHP interacts with databases (like MySQL) using extensions like `mysqli` or `PDO` to store, retrieve, and dynamically populate web pages.
  • **State Management:** It creates and manages **Sessions** (server-side tracking of user activity) and **Cookies** (client-side data storage) to maintain state across the stateless HTTP protocol.
  • **File Management:** It supports uploading files to the web server (images, documents, etc.).
  • **Security/Authentication:** It is used to implement login pages, check user credentials against a database, and manage user authentication.

Identifying Client Details

PHP utilizes server environment variables to gather information about the client making the request. The **$_SERVER['HTTP_USER_AGENT']** variable is particularly useful as it contains a string identifying the user's browser, version, and operating system platform.

Browser Redirection

PHP's **header()** function is used to send raw HTTP headers to the browser, which is commonly used to redirect the user to a different URL. The redirection must be done using the Location: header and must occur **before** any other output is sent to the browser.

header("Location: http://www.example.com/new_page.php");
exit(); // Essential to stop further script execution

Example Session: Form Submission Basics

This demonstrates a simple HTML form submission and how PHP processes the data using the **$_POST** superglobal array.


<?php
   // Check if form has been submitted
   if( $_POST["name"] || $_POST["age"] ) {
      echo "Welcome ". $_POST['name']. "<br />";
      echo "You are ". $_POST['age']. " years old.";
      exit();
   }
?>
<form action = "<?php echo $_SERVER['PHP_SELF']; ?>" method = "POST">
   Name: <input type = "text" name = "name" />
   Age: <input type = "text" name = "age" />
   <input type = "submit" />
</form>

The action attribute points back to the same script (using $_SERVER['PHP_SELF']) for processing, and the user's input is found in $_POST['name'] and $_POST['age'].

Python - NamedTuple

In Python, namedtuple is a subclass of tuple that allows you to create tuples with named fields. You can access elements using field names, making code more readable and maintainable. NamedTuples are part of the collections module.

Creating a NamedTuple

from collections import namedtuple

# Define a namedtuple with field names
Vertex = namedtuple('Vertex', ['x', 'y'])

# Create an instance of Vertex
v = Vertex(10, 20)

# Access fields
print(v.x)  # 10
print(v.y)  # 20

Accessing NamedTuple Fields

You can access fields using:

  • Indexing: v[0], v[1]
  • Field names: v.x, v.y
  • getattr() function: getattr(v, 'x')
print(v[0])         # 10
print(v.x)          # 10
print(getattr(v, 'x')) # 10

NamedTuple Methods

NamedTuples have useful built-in methods:

  • _fields: returns a tuple of field names
  • _replace(**kwargs): returns a new namedtuple replacing specified fields
  • _asdict(): returns an OrderedDict of field names and values
  • _make(iterable): creates a new instance from an iterable
# Example: _replace, _asdict, _fields, _make

print(v._fields)                  # ('x', 'y')

v2 = v._replace(x=30)
print(v2)                        # Vertex(x=30, y=20)

print(v._asdict())               # OrderedDict([('x', 10), ('y', 20)])

v3 = Vertex._make([40, 50])
print(v3)                       # Vertex(x=40, y=50)

Unpacking NamedTuples with ** Operator

data = {'x': 100, 'y': 200}
v4 = Vertex(**data)
print(v4)  # Vertex(x=100, y=200)

Summary

NamedTuples provide immutable, memory-efficient data structures with readable field names. They combine benefits of tuples and dictionaries, suitable when you want immutable objects with named fields.

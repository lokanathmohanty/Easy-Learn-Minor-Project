Next.js Environment Variables 🔒

What are Environment Variables?

**Environment variables** are key-value pairs used to store configuration data, such as **API keys**, **database connection strings**, and other secrets, outside of your source code. Next.js has built-in support for automatically loading these variables from **`.env`** files into the standard Node.js **`process.env`** object.

Loading and Priority of .env Files

Next.js loads variables from specific files in your project root, with a defined priority (highest to lowest):

File Name Purpose Priority
`.env.local` Local, sensitive secrets. **NEVER commit to git** (add to `.gitignore`). Highest (Overrides all others)
`.env.development` Variables specific to the development environment. High
`.env.production` Variables specific to the production environment. High
`.env` Common project environment variables. Lowest 
// Example file: /.env
API_KEY=djcjcwj-wcdkjcnw

Accessing Environment Variables

1. Server-Side Access (Default)

All variables loaded from `.env` files are available in the **server environment** (e.g., API Routes, Middleware, Server Components). This is the intended use for sensitive information.

// Accessing API_KEY in server-side logic (e.g., Middleware)
const secretKey = process.env.API_KEY;

if (clientKey !== secretKey) {
  return res.status(401).json({ message: 'Unauthorized' });
}

2. Client-Side Access (Publicly Exposed)

For **security reasons**, environment variables are **not exposed** to the client (browser) by default. To expose a variable to the client side for general-purpose, non-sensitive data (like an analytics ID), you must prefix it with **`NEXT_PUBLIC_`**.

// File: /.env.local
API_KEY=SECRET_SERVER_ONLY_KEY
NEXT_PUBLIC_ANALYTICS_ID=123 ← PUBLICLY EXPOSED
// Client Component (e.g., page.tsx)
"use client"
export default function Home() {
    return (
        <div>
            <p>API Key: {process.env.API_KEY}</p> <!-- WILL BE UNDEFINED -->
            <p>Analytics ID: {process.env.NEXT_PUBLIC_ANALYTICS_ID}</p> <!-- WILL BE 123 -->
        </div>
    );
}

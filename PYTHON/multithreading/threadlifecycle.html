Python Thread Life Cycle

A thread object goes through different stages during its life cycle. After creation, a thread must be started by calling its start() method, which invokes the run() method containing the thread's task logic. Once the run() method completes, the thread finishes and merges with the main thread.

During execution, a thread can be paused for a specific duration or until an event occurs, after which it resumes.

States of a Thread Life Cycle in Python

  • Creating a Thread: Use the Thread class from the threading module to create a new thread.
  • Starting a Thread: Call the thread's start() method to begin execution, which runs the run() method in a new thread.
  • Paused/Blocked State: Threads can be paused or blocked, often by calling join(), which waits for the thread to finish.
  • Synchronizing Threads: Use synchronization primitives like locks or semaphores to coordinate thread operations.
  • Termination: The thread terminates when the run() method completes or an exception occurs.

Example: Python Thread Life Cycle Demonstration

import threading

def func(x):
   print('Current Thread Details:', threading.current_thread())
   for n in range(x):
      print('{} Running'.format(threading.current_thread().name), n)
   print('Internal Thread Finished...')

# Create thread objects
t1 = threading.Thread(target=func, args=(2,))
t2 = threading.Thread(target=func, args=(3,))

# Start the threads
print('Thread State: CREATED')
t1.start()
t2.start()

# Wait for threads to complete
t1.join()
t2.join()
print('Threads State: FINISHED')

# Simulate main thread work
for i in range(3):
   print('Main Thread Running', i)

print("Main Thread Finished...")

Example: Using a Synchronization Primitive (Semaphore)

import threading
import time

# Create a semaphore 
semaphore = threading.Semaphore(2)

def worker():
   with semaphore:
      print('{} has started working'.format(threading.current_thread().name))
      time.sleep(2)
      print('{} has finished working'.format(threading.current_thread().name))

# Keep track of threads
threads = []

# Create and start 5 threads
for i in range(5):
   t = threading.Thread(target=worker, name='Thread-{}'.format(i+1))
   threads.append(t)
   print('{} has been created'.format(t.name))
   t.start()

# Wait for all threads to complete
for t in threads:
   t.join()
   print('{} has terminated'.format(t.name))

print('Threads State: All are FINISHED')
print("Main Thread Finished...")

CSS - Animations

CSS animations allow the creation of smooth transitions between different styles without using JavaScript.

What is CSS Animation?

In CSS, we can dynamically change styles of elements based on time duration, user interaction, or state changes. This is called CSS animations. It is implemented using the @keyframes rule and the animation property.

CSS @keyframes Rule

The @keyframes rule defines keyframes for animation, specifying how an element looks at various stages of animation.

.box {
    animation: colorChange 5s infinite;
}

@keyframes colorChange {
    0% { background-color: red; }
    50% { background-color: green; }
    100% { background-color: blue; }
}

Animation Delay Property

Use animation-delay to set a delay before an animation starts. Negative values allow animations to start mid-way.

Set Animation Iteration Count

Use animation-iteration-count to specify how many times an animation should repeat. Values can be a number or infinite.

Animation Direction Property

The animation-direction property defines the direction in which animation runs:

  • normal – plays forward (default).
  • reverse – plays backward.
  • alternate – plays forward, then backward.
  • alternate-reverse – plays backward, then forward.

Animation Timing Function

Defines the speed curve of animation. Common values:

  • ease – starts slow, speeds up, ends slow (default).
  • linear – constant speed.
  • ease-in – slow start.
  • ease-out – slow end.
  • ease-in-out – slow start and end.
  • cubic-bezier() – custom curve.

Set Animation Fill Modes

The animation-fill-mode property specifies styles before and after animation:

  • none – no style applied (default).
  • forwards – keeps last keyframe style.
  • backwards – applies first keyframe style before animation starts.
  • both – applies both forwards and backwards rules.

Animation Shorthand Property

The animation shorthand allows multiple properties to be written in one line:

animation: name duration timing-function delay iteration-count direction fill-mode;

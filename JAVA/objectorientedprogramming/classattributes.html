Java - Class Attributes

Java class attributes are variables bound in a class, used to define its state. These attributes are accessible within class methods by default.

For example, in a Student class, variables like roll_no, age, and name are class attributes.

Creating (Declaring) Java Class Attributes

Syntax:

access_modifier data_type attribute_name;

Example:

public class Dog {
  String breed;
  int age;
  String color;

  void barking() {}
  void hungry() {}
  void sleeping() {}
}

Here, breed, age, and color are class attributes.

Accessing Java Class Attributes

To access class attributes, create an object and use the dot . operator.

Syntax:

object_name.attribute_name;

Example:

class Dog {
  String breed = "German Shepherd";
  int age = 2;
  String color = "Black";
}

public class Main {
  public static void main(String[] args) {
    Dog obj = new Dog();
    System.out.println(obj.breed);
    System.out.println(obj.age);
    System.out.println(obj.color);
  }
}

Output:

  • German Shepherd
  • 2
  • Black

Modifying Java Class Attributes

Modify class attributes by assigning new values using the = operator.

Syntax:

object_name.attribute_name = new_value;

Example:

class Dog {
  String breed = "German Shepherd";
  int age = 2;
  String color = "Black";
}

public class Main {
  public static void main(String[] args) {
    Dog obj = new Dog();

    System.out.println("Before modifying:");
    System.out.println(obj.breed);
    System.out.println(obj.age);
    System.out.println(obj.color);

    obj.breed = "Golden Retriever";
    obj.age = 3;
    obj.color = "Golden";

    System.out.println("\nAfter modifying:");
    System.out.println(obj.breed);
    System.out.println(obj.age);
    System.out.println(obj.color);
  }
}

Output:

  • Before modifying:
  • German Shepherd
  • 2
  • Black

  • After modifying:
  • Golden Retriever
  • 3
  • Golden

Making Java Class Attributes Read Only

Use the final keyword to make an attribute read-only. Once assigned, it cannot be modified.

Syntax:

access_modifier final data_type attribute_name;

Example:

package com.tutorialspoint;

class Dog {
  final String name = "Tommy";
}

public class Tester {
  public static void main(String[] args) {
    Dog dog = new Dog();
    dog.name = "Tommy"; // Error: Cannot assign a value to final variable
    System.out.println(dog.name);
  }
}

Output:

  • Exception in thread "main" java.lang.Error: Unresolved compilation problem:
  • The final field Dog.name cannot be assigned

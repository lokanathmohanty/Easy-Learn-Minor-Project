C++ Classes and Objects (User-Defined Types) 📦

**Classes** are the central feature of C++ that support Object-Oriented Programming (OOP). A class is a **user-defined type** that serves as a **blueprint** for creating **objects**. It neatly combines **data representation** and **methods** (functions) for manipulating that data into a single package.

  • The data and functions inside a class are called **members**.

C++ Class Definition

A class definition starts with the keyword **class**, followed by the class name, and a body enclosed in curly braces, ending with a semicolon.

class Box {
   public:
      double length;   // Data member (property)
      double breadth;  // Data member (property)
      double height;   // Data member (property)
      // Member functions go here
}; // Semicolon is mandatory!

The keyword **public** is an **access modifier** that specifies that the members following it can be accessed from outside the class.

Defining and Accessing Objects

Defining Objects

An **object** is an instance of a class. Declaring an object is done just like declaring a variable of a basic type:

Box Box1; // Declares Box1, an object of type Box
Box Box2; // Declares Box2, another object of type Box

Each object (Box1 and Box2) will have its own independent copy of the class's data members (length, breadth, height).

Accessing Members

To access the **public** members of an object, you use the **direct member access operator** (a period: **.**).

// Setting data members for Box1
Box1.height = 5.0; 
Box1.length = 6.0; 

// Calculating volume using accessed members
double volume = Box1.height * Box1.length * Box1.breadth;

Note: **Private** and **protected** members cannot be accessed directly using the . operator and require special member functions.

Further Class and Object Concepts

  • Class Member Functions: Functions defined within a class to manipulate the class's data.
  • Access Modifiers: Keywords (public, private, protected) that control visibility and access to class members.
  • Constructor & Destructor: Special methods automatically called when an object is created (constructor) and destroyed (destructor).
  • this Pointer: A special, implicit pointer available inside every non-static member function that points to the object itself.
  • Static Members: Data or function members that belong to the class as a whole, rather than to any specific object instance.

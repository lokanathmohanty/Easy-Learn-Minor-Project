Python - While Loops

A while loop in Python repeatedly executes a target statement as long as the specified boolean expression evaluates to True. It begins with the while keyword, followed by a condition and a colon. The indented block of code beneath executes until the condition becomes False.

If the condition never evaluates to False, the loop runs infinitely, which is often undesired in most programs unless explicitly intended.

Syntax of while Loop

while expression:
   statement(s)

Example 1

count = 0
while count < 5:
   count += 1
   print("Iteration no. {}".format(count))

print("End of while loop")

Example 2: User Input

The isnumeric() method can be used to repeat a loop until non-numeric input is given. 

var = '0'
while var.isnumeric() == True:
   var = input("Enter a number: ")
   if var.isnumeric() == True:
      print("Your input", var)
print("End of while loop")

Python Infinite while Loop

A loop becomes infinite if its condition never evaluates to False. Infinite loops are sometimes used in server programs to keep them running continuously. 

var = 1
while var == 1:  # This constructs an infinite loop
   num = int(input("Enter a number: "))
   print("You entered:", num)

print("Good bye!")

Python while-else Loop

An else clause can be associated with a while loop. It executes when the condition becomes False. 

count = 0
while count < 5:
   count += 1
   print("Iteration no. {}".format(count))
else:
   print("While loop over. Now in else block")

print("End of while loop")

Single Statement Suites

If the while loop contains only a single statement, it can be placed on the same line as the loop header. 

flag = 0
while (flag): print("Given flag is really true!")
print("Good bye!")

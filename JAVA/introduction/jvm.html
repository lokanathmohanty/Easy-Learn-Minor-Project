What is JVM (Java Virtual Machine)?

The JVM (Java Virtual Machine) is a virtual machine, an abstract computer that has its own instruction set, memory, stack, heap, etc. It runs on the host OS and requests resources from it.

JVM is a specification and can have different implementations as long as they adhere to the specs.

  • Oracle HotSpot JVM
  • IBM J9 JVM

JVM Architecture Overview

The JVM comes in client and server versions, supports 32-bit and 64-bit modes, and consists of several main components:

  • Class Loader
  • Linking and Initialization
  • Runtime Data Areas
  • Execution Engine
  • Java Native Interface (JNI)
  • Native Method Libraries

1. Class Loader

The JVM manages loading, linking, and initialization of classes dynamically.

  • Bootstrap Class Loader: Loads core JDK classes.
  • Extension Class Loader: Loads extension classes.
  • Application Class Loader: Loads user classes and jars.

2. Linking and Initialization

Linking consists of verification, preparation, and resolution of classes, followed by initialization where static variables and blocks are executed.

3. Runtime Data Areas

  • PC Register: Stores the address of the current instruction per thread.
  • Stack: Stores method parameters, local variables, return addresses per thread.
  • Heap: Shared memory for objects, arrays, metadata.
  • Method Area: Shared area for class-level info.
  • Native Method Stacks: For native method execution.

4. Execution Engine

  • Garbage Collector: Automatically manages memory by removing unreachable objects.
  • Interpreter: Executes bytecode instructions.
  • JIT Compiler: Compiles bytecode to machine code at runtime.

5. Java Native Interface (JNI)

Allows Java to interact with native code written in other languages like C and C++.

6. Native Method Libraries

Collections of native platform-dependent libraries essential for JVM execution.

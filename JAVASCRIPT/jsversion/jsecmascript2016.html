JavaScript - ECMAScript 2016

Overview

The ECMAScript 2016 version of JavaScript was released in 2016. Earlier versions were named by numbers (e.g., ES5, ES6). From 2016 onwards, versions are named by the release year (e.g., ECMAScript 2016, ECMAScript 2017, etc.).

This version introduced a few but important new features:

  • Array includes() method
  • Exponentiation Operator (**)
  • Exponentiation Assignment Operator (**=)

Array includes() Method

The includes() method checks whether an array contains a particular element.

Syntax:

arr.includes(searchElement, fromIndex);

- searchElement: The element to search for.
- fromIndex: Optional starting index for the search.

Example 1

const watches = ["Titan", "Rolex", "Noise", "Fastrack", "Casio"];
console.log(watches.includes("Noise"));

Output: true

Example 2

const subjects = ["Java", "JavaScript", "Python", "C", "C++"];
console.log(subjects.includes("Python", 1));

Output: true

Exponentiation Operator (**)

The exponentiation operator raises the first operand to the power of the second operand.

Syntax:

x ** y;

Example

console.log(2 ** 2);

Output: 4

Exponentiation Assignment Operator (**=)

The exponentiation assignment operator raises the value of a variable to the power of another and reassigns it.

Syntax:

x **= y;

Example

let num = 10;
num **= 2;
console.log(num);

Output: 100

Java Programming: Enum Customization

Session: Enum String Representation

Default String Representation 🏷️

By default, the **string representation** of an enum constant is simply its declared name. This default behavior is consistent whether you print the enum directly, use the **toString()** method, or use the **name()** method.

System.out.println(WEEKDAY.MONDAY);       // Output: MONDAY
System.out.println(WEEKDAY.MONDAY.toString());  // Output: MONDAY
System.out.println(WEEKDAY.MONDAY.name());    // Output: MONDAY

The key distinction is that the **name()** method is **final** and **cannot be overridden**, ensuring you can always retrieve the original, declared name of the constant.

Overriding the toString() Method

To provide a **custom string representation** (like a description or friendly name) for an enum constant, you must **override the toString() method**. The toString() method can be overridden in two main ways:

1. Per Enum (Using a Switch Expression)

You can override toString() once within the enum body and use a switch expression or statement to return a custom string based on the current constant.

enum WEEKDAY { 
   MONDAY, TUESDAY, WEDNESDAY, ... ;

   @Override
   public String toString() {
      return switch(this) {
         case MONDAY: yield "Day 1";
         case TUESDAY: yield "Day 2";
         // ...
      };
   }	
}

2. Per Constant (Constant-Specific Class Body)

Because each enum constant implicitly defines an anonymous subclass of the enum, you can provide a unique implementation of toString() for each constant using a constant-specific class body (the curly braces {} following the constant).

enum WEEKDAY {
   MONDAY {
      @Override
      public String toString() {
         return "Day 1 of the Week";
      }
   },
   TUESDAY {
      @Override
      public String toString() {
         return "Day 2 of the Week";
      }		
   };	
}

Demonstrating Custom vs. Default Names

When toString() is overridden, it affects the direct print statement, but the name() method is always reliable for the declared name.

WEEKDAY day = WEEKDAY.MONDAY;
System.out.println(day);             // Calls overridden toString() -> Day 1 of the Week
System.out.println(day.toString());  // Calls overridden toString() -> Day 1 of the Week
System.out.println(day.name());      // Calls final name() method -> MONDAY

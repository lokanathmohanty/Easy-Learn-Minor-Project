C++ String Concatenation Methods ➕🔗

String concatenation is the process of joining two or more strings together end-to-end to form a single, longer string. C++ provides several methods for this, categorized by whether they apply to modern std::string objects or legacy C-style character arrays (`char[]`).

I. std::string Concatenation (Modern C++)

These methods are generally preferred for safety and flexibility, as std::string objects handle memory allocation automatically.

1. Using the `+` Operator or `+=` Operator

The **`+` operator** is overloaded for std::string objects, making it the simplest and most readable way to concatenate strings.

string strA = "Hello";
string strB = "World";
string strC = strA + strB; // Creates a new string: "HelloWorld"

strA += strB; // In-place modification: strA becomes "HelloWorld"

2. Using the string::append() Function

This is a member function of the std::string class, used to append one string (or a portion of one) to the end of another. It modifies the initial string in place.

string initial("I Love TP.");
string new_str(" I am new here.");

initial.append(new_str); // initial becomes "I Love TP. I am new here."

3. Using Iterative Methods (for/while/Range-Based Loop)

While generally less efficient and verbose than the `+` or `append()` methods, concatenation can be performed character by character by iterating over the source string and appending each character to the destination string using the `+=` operator.

string initial("I Love TP.");
string new_str(" Now.");

// Range-based loop example:
for(char c: new_str){
   initial += c; // Appends one character at a time
}
// initial becomes "I Love TP. Now."

II. C-Style String Concatenation

4. Using the strcat() Function

The **`strcat()`** function (from <cstring>) is used exclusively for **C-style character arrays** (`char[]`).

char s1[30] = "I love "; // Destination array MUST have enough space
char s2[] = "TP.";
strcat(s1, s2); // s1 becomes "I love TP."

⚠️ **Warning:** The destination array (`s1` in the example) **must** be large enough to hold the combined string, including the null terminator. Failure to ensure sufficient space leads to a **buffer overflow**, a critical security and stability risk.

III. OOPS and Advanced Methods

Concatenation logic can be encapsulated within classes using Object-Oriented Programming (OOPS) concepts for cleaner design:

  • **Inheritance/Virtual Methods:** A base class can define a virtual `concatenate` method, and a derived class can implement the logic (often using the simple `+` or `+=` operator) to perform the actual join.
  • **Friend Functions:** A **friend function** can be declared to access private members of a class (typically C-style character arrays) and use functions like `strcat()` on them, allowing external functions to perform operations that would otherwise be restricted.

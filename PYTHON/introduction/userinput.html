Python - User Input

Python allows programs to accept input from the user during execution, making them interactive. Input is usually taken from the console using built-in functions and displayed back using the print() function.

Python User Input Functions

  • input() - available in Python 3.x
  • raw_input() - available in Python 2.x (renamed to input() in Python 3)

Using Variables Without User Input

Example program with static values:

#! /usr/bin/python3.11

name = "Kiran"
city = "Hyderabad"

print("Hello My name is", name)
print("I am from", city)

Output:

Hello My name is Kiran
I am from Hyderabad

This program prints the same output each time, requiring manual edits to change values.

The input() Function

The input() function reads input from the user as a string. The program waits for the user to press Enter before continuing.

Example:

name = input("Enter your name: ")
city = input("Enter your city: ")

print("Hello My name is", name)
print("I am from", city)

Sample Run:

Enter your name: Praveen
Enter your city: Bengaluru
Hello My name is Praveen
I am from Bengaluru

The raw_input() Function

In Python 2.x, raw_input() was used to take input as string. In Python 3, input() performs this task.

name = raw_input("Enter your name: ")
city = raw_input("Enter your city: ")

print("Hello My name is", name)
print("I am from", city)

Taking Numeric Input

Since input() always returns a string, numeric input must be converted to int or float before performing arithmetic operations.

Example: Calculating Area of a Rectangle

width = int(input("Enter width: "))
height = int(input("Enter height: "))

area = width * height
print("Area of rectangle =", area)

Sample Run:

Enter width: 20
Enter height: 30
Area of rectangle = 600

Example: Using float()

amount = float(input("Enter Amount: "))
rate = float(input("Enter rate of interest: "))

interest = amount * rate / 100
print("Amount:", amount, "Interest:", interest)

Sample Run:

Enter Amount: 12500
Enter rate of interest: 6.5
Amount: 12500.0 Interest: 812.5

The print() Function

The print() function is used to display values and expressions. Multiple items can be printed, separated by commas.

Example:

a = "Hello World"
b = 100
c = 25.50
d = 5+6j

print("Message:", a)
print(b, c, b-c)
print(pow(100, 0.5), pow(c, 2))

Output:

Message: Hello World
100 25.5 74.5
10.0 650.25

The sep parameter changes the separator, and the end parameter customizes what follows the output.

Example: Using sep

city = "Hyderabad"
state = "Telangana"
country = "India"

print(city, state, country, sep=",")

Output:

Hyderabad,Telangana,India

Example: Using end

city = "Hyderabad"
state = "Telangana"

print("City:", city, end=" ")
print("State:", state)

Output:

City: Hyderabad State: Telangana

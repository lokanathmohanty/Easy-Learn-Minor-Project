R - Survival Analysis

Survival analysis predicts the time until a specific event occurs, such as the survival time of a patient or failure time of a machine. In R, survival analysis is conducted using the survival package.

Key functions are Surv() to create a survival object from time and event data, and survfit() to fit a survival curve and plot it.

Installation

install.packages("survival")

Usage

library(survival)

Syntax

Surv(time, event)
survfit(formula)

- time: Follow-up time until event or censoring
- event: Indicator whether event occurred (1) or censored (0)
- formula: Model formula specifying response and predictors

Example

The built-in dataset pbc records survival data on patients with primary biliary cirrhosis. 

library(survival)

# View data
print(head(pbc))

# Fit survival curve with time and status (event of interest: status==2)
surv_obj <- Surv(pbc$time, pbc$status == 2)
fit <- survfit(surv_obj ~ 1)

# Save plot to file
png("survival.png")
plot(fit)
dev.off()

# Print summary
print(fit)

Sample Output

Call: survfit(formula = Surv(pbc$time, pbc$status == 2) ~ 1)

      n  events  median 0.95LCL 0.95UCL 
    418    161    3395   3090   3853

The survival curve shows survival probability over time, useful for estimating survival rates and median survival time.

Python - For Else Loop

Python supports an optional else block to be associated with a for loop. If an else block is used with a for loop, it executes only when the loop terminates normally.

A for loop terminates normally when it completes all its iterations without encountering a break statement, which is typically used to exit the loop when a certain condition is met.

Syntax of For Else Loop

for variable_name in iterable:
   # statements in the loop
   ...
else:
   # statements in else clause
   ...

Example of For Else Loop

for count in range(6):
   print("Iteration no. {}".format(count))
else:
   print("for loop over. Now in else block")
print("End of for loop")

For-Else Construct without break statement

The else block executes only when the loop terminates normally, i.e. without a break. 

for i in ['T','P']:
   print(i)
else:
   # No break used, so else executes
   print("ForLoop-else statement successfully executed")

For-Else Construct with break statement

If the loop is forcefully terminated with a break, the else block is skipped. 

for i in ['T','P']:
   print(i)
   break
else:
   # Will not execute due to break
   print("Loop-else statement successfully executed")

For-Else with break statement and if conditions

You can use a for-else loop with conditions. If the loop completes without break, the else block is executed. 

# Function to check positive or negative numbers
def positive_or_negative():
   for i in [5,6,7]:
      if i >= 0:
         print("Positive number")
      else:
         print("Negative number")
         break
   else:
      print("Loop-else Executed")

CSS - Cursor Property

The CSS cursor property determines the appearance of the mouse cursor when hovering over an element to which this property is applied. Its main purpose is to improve usability by visually representing certain functions. For example, a pointer cursor indicates a clickable link, while a text cursor indicates text selection.

Syntax

cursor: value;

Property Values

  • auto – Browser decides the cursor style based on the context (default).
  • alias – Indicates creating an alias or shortcut.
  • all-scroll – Indicates scrolling in any direction.
  • cell – Indicates selecting table cells.
  • col-resize – Indicates column resizing horizontally.
  • copy – Indicates something will be copied.
  • crosshair – Displays a crosshair for selections.
  • default – Default arrow cursor.
  • e-resize, w-resize, n-resize, s-resize – Indicate directional resizing.
  • ew-resize, ns-resize, nesw-resize, nwse-resize – Indicate diagonal or bidirectional resizing.
  • grab – Indicates draggable content.
  • grabbing – Indicates active dragging.
  • help – Indicates help is available.
  • move – Indicates something can be moved.
  • no-drop – Indicates dropping is not allowed.
  • not-allowed – Indicates an action is forbidden.
  • pointer – Indicates a link or clickable item.
  • progress – Indicates a process is running but interaction is possible.
  • row-resize – Indicates vertical resizing of rows.
  • text – Text selection cursor (I-beam).
  • url() – Custom cursor image.
  • wait – Indicates the program is busy.
  • zoom-in – Indicates zoom in is available.
  • zoom-out – Indicates zoom out is available.

Example: Demonstration of Cursors

The following code shows different cursor styles applied to elements:

<div class="box" style="cursor: pointer;">Pointer Cursor</div>
<div class="box" style="cursor: text;">Text Cursor</div>
<div class="box" style="cursor: wait;">Wait Cursor</div>
<div class="box" style="cursor: move;">Move Cursor</div>
<div class="box" style="cursor: crosshair;">Crosshair Cursor</div>

Example: Using an Image as a Cursor

You can also specify an image as a custom cursor using url(). A generic cursor type should be provided as a fallback in case the image fails to load.

<div class="box" style="cursor: url('custom-cursor.png'), pointer;">
  Image Cursor Example
</div>

Summary

The CSS cursor property is a powerful way to improve user interaction by providing visual cues. It supports many values, from default system cursors to custom images, allowing developers to enhance the usability and accessibility of web applications.

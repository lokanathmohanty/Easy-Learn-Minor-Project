R - Data Reshaping

Data reshaping in R involves changing the organization of data into rows and columns. While most data processing uses data frames, sometimes you need to convert them into different formats. R offers various functions to split, merge, transpose rows and columns, and more.

Joining Columns and Rows in a Data Frame

We can combine vectors into a data frame using cbind(), and merge two data frames using rbind().

# Create vectors
city <- c("Tampa", "Seattle", "Hartford", "Denver")
state <- c("FL", "WA", "CT", "CO")
zipcode <- c(33602, 98104, 6161, 80294)

# Combine into one data frame
addresses <- cbind(city, state, zipcode)

cat("# # # # The First data frame\n")
print(addresses)

# Another data frame
new.address <- data.frame(
  city = c("Lowry", "Charlotte"),
  state = c("CO", "FL"),
  zipcode = c("80230", "33949"),
  stringsAsFactors = FALSE
)

cat("# # # The Second data frame\n")
print(new.address)

# Combine rows from both data frames
all.addresses <- rbind(addresses, new.address)

cat("# # # The combined data frame\n")
print(all.addresses)

Merging Data Frames

Use the merge() function to merge two data frames by matching columns with the same names. 

library(MASS)
merged.Pima <- merge(x = Pima.te, y = Pima.tr,
  by.x = c("bp", "bmi"),
  by.y = c("bp", "bmi")
)
print(merged.Pima)
nrow(merged.Pima)

This merges rows with matching bp and bmi values from Pima.te and Pima.tr datasets.

Melting and Casting

Reshaping data from wide to long format can be done using melt(), and from long back to wide using cast(). This helps in data aggregation and reorganization. 

library(MASS)
print(ships)

molten.ships <- melt(ships, id = c("type","year"))
print(molten.ships)

recasted.ship <- cast(molten.ships, type + year ~ variable, sum)
print(recasted.ship)

The library MASS contains the ships dataset. Melting converts columns (other than type, year) to rows, and casting aggregates values back by type and year.

Python - Templating

Templating in Python is a technique for generating dynamic content, typically HTML, by combining static templates with data.

Python provides simple string templates and powerful templating engines like Jinja2.

String Templates using string.Template

Use the Template class from the string module for simple and safe placeholder substitution.

Creating Template

from string import Template
template = Template("Hello, $name!")

Substituting Values

tempStr = Template('Hello. My name is $name and my age is $age')
newStr = tempStr.substitute(name='Pushpa', age=26)
print(newStr)

Output: Hello. My name is Pushpa and my age is 26

Using Dictionary

dct = {'name': 'Pushpalata', 'age': 25}
newStr = tempStr.substitute(dct)
print(newStr)

Handling Missing Keys

Using substitute() with missing keys raises KeyError.

Use safe_substitute() to avoid this, leaving placeholders unchanged.

newStr = tempStr.safe_substitute({'name': 'Pushpalata'})
print(newStr)

Output: Hello. My name is Pushpalata and my age is $age

Using Jinja2 Templating Engine

Jinja2 is a powerful, feature-rich templating engine popular in web development.

Installing Jinja2

pip install jinja2

Creating a Template (template.html)

<!DOCTYPE html>
<html>
<head>
    <title>Hello, {{ name }}!</title>
</head>
<body>
    <h1>Hello, {{ name }}!</h1>
    <p>Welcome to our site.</p>
</body>
</html>

Rendering the Template

from jinja2 import Template, FileSystemLoader, Environment

file_loader = FileSystemLoader('.')
env = Environment(loader=file_loader)
template = env.get_template('template.html')

output = template.render(name='Alice')
print(output)

This outputs HTML with placeholders replaced by data.

Advanced Jinja2 Features

Template Inheritance

<!-- base.html -->
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>{% block title %}Default Title{% endblock %}</title>
</head>
<body>
    {% block content %}{% endblock %}
</body>
</html>

<!-- child.html -->
{% extends "base.html" %}

{% block title %}Child Page{% endblock %}
{% block content %}
<h1>Child Page Content</h1>
{% endblock %}

Loops

<ul>
{% for item in items %}
    <li>{{ item }}</li>
{% endfor %}
</ul>

Conditionals

{% if user %}
    <p>Welcome, {{ user }}!</p>
{% else %}
    <p>Please log in.</p>
{% endif %}

Custom Filters

# Define a custom filter function
def reverse_string(s):
    return s[::-1]

# Register the filter
env.filters['reverse'] = reverse_string

# Use in template:
{{ "hello" | reverse }}

Output: olleh

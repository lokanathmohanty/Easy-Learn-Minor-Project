JavaScript - Modules

What is a Module?

A module in JavaScript is a single file containing JavaScript code. Rather than adding the code for the whole application in a single file, we can break down the code and create separate files for the code having the same functionalities.

In short, the module contains the code to perform a specific task. It can contain variables, functions, classes, etc. As applications grow larger, organizing code into modules helps improve manageability and maintainability.

Syntax

export function func_name(parameters) {
   // function code
}

import { func_name } from './filename.js';

The export keyword is used to export a function, class, or variable from a module, and the import keyword is used to import it into another file.

Example: Exporting a Function

File: mul.js

// exporting mul() function
export function mul(a, b) {
   return a * b;
}

File: test.html

<html>
<body>
   <div>JavaScript - Modules</div>
   <div id="output"></div>

   <script type="module">
      import { mul } from './mul.js';
      document.getElementById('output').innerHTML = 
         "The multiplication of 2 and 3 is " + mul(2, 3);
   </script>
</body>
</html>

Output:

  • JavaScript - Modules
  • The multiplication of 2 and 3 is 6

Export Multiple Objects from a Single Module

File: math.js

// exporting mul() function
export function mul(a, b) {
   return a * b;
}
// exporting sum() function
export function sum(a, b) {
   return a + b;
}
// exporting PI constant
export let PI = Math.PI;

File: test.html

<html>
<body>
   <div>Exporting Multiple Objects from a Single Module</div>
   <div id="output"></div>

   <script type="module">
      import { mul, sum, PI } from './math.js';
      document.getElementById('output').innerHTML =
         "The multiplication of 2 and 3 is " + mul(2, 3) + 
         "<br>The addition of 2 and 3 is " + sum(2, 3) + 
         "<br>The value of PI is " + PI;
   </script>
</body>
</html>

Default Exports

The default keyword allows you to define a default export in a module. If you import something not explicitly exported, the default export is used.

File: test.js

const v1 = "Version 1";
// default export
export default v1;
// other export
export const v2 = "Version 2";

File: test.html

<html>
<body>
   <div>Default Export</div>
   <div id="output"></div>

   <script type="module">
      // v3 is not defined, so it imports default (v1)
      import v3, { v2 } from './test.js';

      document.getElementById('output').innerHTML =
         "The value of v3 is: " + v3 + "<br>" +
         "The value of v2 is: " + v2;
   </script>
</body>
</html>

Output:

  • The value of v3 is: Version 1
  • The value of v2 is: Version 2

Rename Import and Export

To avoid conflicts, we can rename functions, variables, or classes when exporting or importing them using the as keyword.

Syntax to Rename Exports

export {
   func1 as N1,
   func2 as N2
};
// import in another file
import { N1, N2 } from './module.js';

Syntax to Rename Imports

export {
   func1,
   func2
};
// import in another file
import { func1 as N1, func2 as N2 } from './module.js';

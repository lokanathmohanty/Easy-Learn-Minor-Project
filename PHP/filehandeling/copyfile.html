PHP File Copying

Copying files in PHP is a common task used for creating backups, duplicating resources, or moving files to a new location while preserving the original. PHP offers several ways to perform file copying, ranging from a dedicated built-in function to manual I/O operations.

The Dedicated `copy()` Function (Recommended) ⭐

The simplest and most efficient way to duplicate a file in PHP is using the **`copy()`** function. It handles the entire process internally, requiring only the source and destination paths.

**Syntax:**
copy(string $source, string $destination): bool

**Example:**
$sFile = "original.txt";
$dFile = "backup/original_backup.txt"; // Copies to a new folder

if (copy($sFile, $dFile)) {
   echo "File copied successfully!";
}

Alternative Methods for Copying

1. Using `file_get_contents()` and `file_put_contents()` 📝

This method is fast and concise for smaller files. It reads the entire source file into a single string in memory, and then writes that string to the destination file.

$source = "hello.txt";
$target = "test.txt";

$data = **file_get_contents**($source); // Read all into memory
**file_put_contents**($target, $data); // Write from memory

2. Manual Read/Write Loop (for Large Files) 🔄

For very large files, manual I/O using `fopen()`, `fgets()`, and `fputs()` is more memory-efficient. It processes the file line by line (or in chunks), preventing the entire file from being loaded into the server's RAM.

$src = fopen("hello.txt", "r");
$dest = fopen("new.txt", "w");

while(! feof($src)) {
   $str = fgets($src);
   fputs($dest, $str);
}
fclose($src);
fclose($dest);

Error Prevention and Best Practices ⚠️

Before attempting to copy, it's crucial to check that the source file exists and that the destination directory has the appropriate write permissions.

$sFile = "data.txt";
if (**file_exists**($sFile) && **is_writable**('backup/')) {
   // Proceed with copy()
} else {
   echo "Check file existence or write permissions.";
}

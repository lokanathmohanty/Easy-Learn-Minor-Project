Django: Sending E-mails 📧

Django provides a lightweight, easy-to-use mail engine via the **django.core.mail** module. Before sending emails, you must configure your project's SMTP settings in settings.py:

  • EMAIL_HOST: SMTP server address.
  • EMAIL_HOST_USER: Login username for the SMTP server.
  • EMAIL_HOST_PASSWORD: Password for the SMTP server.
  • EMAIL_PORT: SMTP server port (often 587 or 465).
  • EMAIL_USE_TLS / _SSL: Set to True for a secure connection.

Sending a Simple E-mail (send_mail)

The **send_mail** shortcut is the simplest way to send a single email. It returns the number of successfully delivered messages (usually 1 or 0).

from django.core.mail import send_mail

def sendSimpleEmail(request, emailto):
   res = send_mail(
      "Hello Paul",                 # subject
      "Comment tu vas?",            # message (body)
      "paul@polo.com",              # from_email
      [emailto],                    # recipient_list
      fail_silently=False           # raise exception on error
   )
   return HttpResponse(f'{res}')

Sending Multiple E-mails (send_mass_mail)

To send multiple distinct messages efficiently in a single connection, use **send_mass_mail**. This method takes a single tuple, where each element is a tuple representing a message (subject, message, from\_email, recipient\_list).

from django.core.mail import send_mass_mail

def sendMassEmail(request, emailto1, emailto2):
   msg1 = ('subject 1', 'message 1', 'polo@polo.com', [emailto1])
   msg2 = ('subject 2', 'message 2', 'polo@polo.com', [emailto2])
   datatuples = (msg1, msg2)
   
   res = send_mass_mail(datatuples, fail_silently=False)
   return HttpResponse(f'{res}')

Mailing Admins and Managers

Django provides specialized functions to quickly email site administrators or managers defined in settings.py:

  • mail_admins(subject, message): Sends email to addresses listed in the **ADMINS** setting.
  • mail_managers(subject, message): Sends email to addresses listed in the **MANAGERS** setting.
from django.core.mail import mail_admins
def sendAdminsEmail(request):
   res = mail_admins('my subject', 'site is going down.')
   return HttpResponse(f'{res}')

Sending HTML E-mail and Attachments (EmailMessage)

For more complex needs, like sending HTML content or attachments, use the **EmailMessage** class.

HTML Content

For Django versions < 1.7, you must manually set email.content_subtype = "html". For Django ≥ 1.7, you can pass the html_message parameter to send_mail to create a multipart/alternative email.

from django.core.mail import EmailMessage

def sendHTMLEmail(request, emailto):
   html_content = "Comment tu vas?"
   email = EmailMessage("my subject", html_content, "paul@polo.com", [emailto])
   
   # Required for older Django versions (< 1.7)
   email.content_subtype = "html" 
   
   res = email.send()
   return HttpResponse(f'{res}')

With Attachment

Use the **.attach()** method on the EmailMessage object before sending. It requires the filename, the file content (as a string/bytes), and the MIME type.

from django.core.mail import EmailMessage

def sendEmailWithAttach(request, emailto):
   # ... EmailMessage object setup ...
   
   fd = open('manage.py', 'r')
   email.attach('manage.py', fd.read(), 'text/plain')
   
   res = email.send()
   return HttpResponse(f'{res}')

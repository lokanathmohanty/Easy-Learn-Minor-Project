JavaScript - Cookie Attributes

Cookie Attributes

The JavaScript cookie attributes are used to set additional information about a cookie such as path, domain, expiry date, etc. In JavaScript, you can specify the cookie attributes while setting up a new cookie or updating the cookie. For example, you can set the cookie's expiry date using the expires attribute.

In simple terms, cookie attributes are used to control the behavior of the cookies and how the cookie is used in the browser.

List of Cookie Attributes

Here, we have listed all cookie attributes in the table below with their description and default values.

Attribute Description Default Value
Name/Value It is used to store the cookies in the browser. -
Domain To specify the domain for whose cookie is valid. Website of domain (e.g. tutorialspoint.com)
Path The path to the directory or web page that sets the cookie. / (entire domain)
Expires Specifies the date and time when the cookie should expire. Current session
Max-Age Specifies the time limit after which cookie should expire. Current session
Secure Restricts cookies to secure connections if set. false
HttpOnly Prevents accessing the cookies via JavaScript to make cookies secure. false
SameSite Specifies how third-party cookies should be handled. Lax
Priority Defines the priority of the cookies. 1000
Site/Service Gets information about the origin site of the cookie. -
SourcePort Gets the port of the source for the cookie. -
StoragePartition Defines which storage partition is used to store cookies. -
Size Represents the size of the cookies. Depends on text length

However, above all, attributes are optional. Also, you can't manipulate all attributes of the cookies. The browser sets some attributes.

Check the Attribute Value in the Browser

You can set the attributes to the cookie, but you can't access the attributes directly in JavaScript. To check whether the attribute is set, you can use the browser console.

  1. Right click in the browser and select Inspect to open the developer tools.
  2. Go to the Application / Storage tab.
  3. In the sidebar, select Cookies.
  4. Click on any cookie to check its name, value, and other attribute values.

The above steps are for Chrome. Steps may vary in other browsers.

Cookie's Name/Value Attribute

The Name attribute is used to store the cookie data. It takes the data as a value. If you want to use special characters in the value, you need to encode the text using encodeURIComponent().

Syntax

let value = encodeURIComponent(cookieValue);
document.cookie = "name=" + value + ";";

Example

<script>
let output = document.getElementById("output");
function setCookies() {
  document.cookie = "subscribed=false"; // name-value pair
  output.innerHTML = "Cookie setting successful!";
}
function readCookies() {
  const allCookies = document.cookie.split("; ");
  output.innerHTML = "The subscribed cookie is - <br>";
  for (const cookie of allCookies) {
    const [name, value] = cookie.split("=");
    if (name == "subscribed") {
      output.innerHTML += name + " : " + decodeURIComponent(value) + "<br>";
    }
  }
}
</script>

Cookie's Path Attribute

The Path attribute sets the scope of the cookie. It defines where cookies should be accessible on the website.

Syntax

document.cookie = "name=value;path=pathStr";

Example

<script>
let output = document.getElementById("output");
function setCookies() {
  document.cookie = "signIn=true; path=/";
  output.innerHTML = "Cookie set successful!";
}
function readCookies() {
  const allCookies = document.cookie.split("; ");
  output.innerHTML = "The cookie is : <br>";
  for (const cookie of allCookies) {
    const [key, value] = cookie.split("=");
    if (key == "signIn") {
      output.innerHTML += key + " : " + decodeURIComponent(value) + "<br>";
    }
  }
}
</script>

Cookie Expires Attribute

The expires attribute sets the expiry date of the cookie. It takes a date string as value.

Syntax

document.cookie = "name=value;expires=dateStr";

Example

<script>
let output = document.getElementById("output");
function setCookies() {
  document.cookie = "product=mobile;expires=12 Jan 2050 12:00:00 UTC";
  output.innerHTML = "Cookie Set Successful!";
}
function readCookies() {
  const allCookies = document.cookie.split("; ");
  output.innerHTML = "The cookie is : <br>";
  for (const cookie of allCookies) {
    const [key, value] = cookie.split("=");
    if (key == "product") {
      output.innerHTML += key + " : " + decodeURIComponent(value) + "<br>";
    }
  }
}
</script>

Cookie's maxAge Attribute

The maxAge attribute is an alternative to expires. It specifies the lifetime of the cookie in seconds.

Syntax

document.cookie = "name=value;max-age=age";

Example

<script>
const output = document.getElementById("output");
function setCookies() {
  document.cookie = "token=1234wfijdn;max-age=864000";
}
function readCookies() {
  const allCookies = document.cookie.split("; ");
  output.innerHTML = "The cookie is : <br>";
  for (const cookie of allCookies) {
    const [key, value] = cookie.split("=");
    if (key == "token") {
      output.innerHTML += key + " : " + decodeURIComponent(value) + "<br>";
    }
  }
}
</script>

Cookie Domain Attribute

The domain attribute specifies the domain for which the cookie is valid. By default, it uses the domain from which the request is made. It can also include subdomains.

Syntax

document.cookie = "name=value;domain=domain_name";

Example

<script>
const output = document.getElementById("output");
function setCookies() {
  document.cookie = "username=abcd;domain=tutorialspoint.com";
}
function readCookies() {
  const allCookies = document.cookie.split("; ");
  output.innerHTML = "The cookie is : <br>";
  for (const cookie of allCookies) {
    const [key, value] = cookie.split("=");
    if (key == "username") {
      output.innerHTML += key + " : " + decodeURIComponent(value) + "<br>";
    }
  }
}
</script>

Similarly, you can update the attribute values. For example, you can extend the expiry time of the cookie.

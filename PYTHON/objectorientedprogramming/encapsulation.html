Python - Encapsulation

Encapsulation is the object-oriented programming practice of bundling data (attributes) and methods (functions) into a single unit—the class. It protects sensitive data by restricting direct access and only allowing controlled interaction via methods.

Python uses naming conventions to achieve encapsulation: a single underscore for protected members and double underscores for private members.

Encapsulation Example: Public vs Private Attributes

class Student:
    def __init__(self, name="Rajaram", marks=50):
        self.name = name               # public attribute
        self.__marks = marks           # private attribute

    def studentdata(self):
        print(f"Name: {self.name} marks: {self.__marks}")

s1 = Student()
s1.studentdata()                      # OK: uses method to access private
print(s1.name)                        # OK: public attribute
print(s1.__marks)                     # Error: AttributeError, private

Attempting to access __marks directly from outside the class raises an error, demonstrating encapsulation at work. Public members can be accessed directly, but private members are accessible only via class methods.

Name Mangling for Private Access

print(s1._Student__marks)  # Works but not recommended; outputs 50

Encapsulation with Getter and Setter Methods

Encapsulation is commonly implemented by exposing getter and setter methods that allow controlled access and validation of private data.

Encapsulation with Getters and Setters

class User:
    def __init__(self, name):
        self.__name = name

    def get_name(self):
        return self.__name

    def set_name(self, name):
        if name:
            self.__name = name

user = User("Alice")
print(user.get_name())    # Output: Alice
user.set_name("Bob")
print(user.get_name())    # Output: Bob
  • Single underscore (_var): Indicates protected attribute, meant for internal/internal subclass use.
  • Double underscores (__var): Indicates private attribute, triggers name mangling.
  • Encapsulation lets you validate and control data changes, improve code organization, and support safer maintenance and extension of your codebase.

Quick Guide to C Language

Introduction

C is a general-purpose programming language developed in the early 1970s. It is widely used for system programming, embedded systems, and application development. C provides low-level access to memory and requires manual management of resources.

Basic Syntax

A simple C program includes the main() function, where execution starts. Statements end with a semicolon (;). Comments are written with /* ... */ for multi-line or // for single-line.

Data Types

C supports basic data types like int (integer), float (floating-point), char (character), and double (double-precision floating-point).

Variables and Constants

Variables must be declared with a data type before use. Constants are declared with the const keyword or using #define.

Control Structures

C supports conditional statements like if, else, and loops such as for, while, and do-while.

Functions

Functions allow modular programming. Every C program must have a main() function. Other functions can be declared and defined to perform specific tasks.

Example: Hello World Program

Below is a simple program to print “Hello, World!” to the console:

#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}

Example: Simple Addition

This example reads two integers from the user and prints their sum:

#include <stdio.h>

int main() {
    int a, b, sum;
    printf("Enter two integers: ");
    scanf("%d %d", &a, &b);
    sum = a + b;
    printf("Sum: %d\n", sum);
    return 0;
}

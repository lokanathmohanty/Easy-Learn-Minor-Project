ReactJS - React Without JSX

What is JSX?

JSX is a JavaScript extension that lets developers write HTML-like code inside JavaScript. It makes the code easier to read and understand. Under the hood, JSX is compiled into JavaScript React.createElement calls before execution.

Example: 

<h1>Hello World</h1>

gets converted into: 

React.createElement('h1', null, 'Hello World')

What is createElement?

React.createElement is the core API of React that creates React elements. It accepts three arguments:

  1. Type – HTML tag or React component (e.g., 'div', 'h1')
  2. Props – JavaScript object containing attributes (can be null)
  3. Children – Content or nested elements inside the component

Elements can be nested to any depth using createElement.

Working Example

Let's build a BookListUsingCreateElement component without JSX.

Step 1: Create a new app

create-react-app myapp
cd myapp
npm start

Step 2: Create the component

import React from 'react';

class BookListUsingCreateElement extends React.Component {
   constructor(props) {
      super(props);
      this.state = {
         list: ['C++ Programming', 'Java Programming', 'JavaScript Programming']
      };
   }
   render() {
      let content = React.createElement(
         'ol',
         null,
         this.state.list.map(
            (item) => React.createElement('li', null, item)
         )
      );
      return content;
   }
}
export default BookListUsingCreateElement;

Explanation:

  • React.createElement('ol') creates the ordered list container.
  • map() loops through each book and returns React.createElement('li', null, item) for each.
  • No JSX is used—only pure createElement.

Step 3: Use the Component in App.js

import BookListUsingCreateElement 
   from "./components/CreateElement/BookListUsingCreateElement";

function App() {
   return (
      <div>
         <BookListUsingCreateElement />
      </div>
   );
}
export default App;

Final Output

When running npm start, the app will display: 

1. C++ Programming
2. Java Programming
3. JavaScript Programming

Summary

  • JSX simplifies writing React elements but is not mandatory.
  • React.createElement provides full control over component creation.
  • Useful in environments where JSX cannot be used or when dynamic element creation is required.

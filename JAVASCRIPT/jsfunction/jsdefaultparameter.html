JavaScript - Default Parameters

The default parameters in JavaScript allow you to specify a default value for a function parameter. This feature was introduced in ES6. If a function is called with missing arguments or with undefined, it uses the default value.

By default, function parameters are undefined in JavaScript. Before ES6, developers had to check and manually assign values if parameters were undefined.

Example Without Default Parameters


function sum(p, q) {
  return p + q;
}
sum(10, 20); // 30
sum(10);     // NaN
sum();       // NaN

- sum(10, 20) → 30 - sum(10) → NaN - sum() → NaN

Default Parameters Syntax


function functName(param1 = defaultValue1, param2 = defaultValue2) {
  // Use parameters here
}

Example With Default Parameters


function sum(p = 30, q = 40) {
  return p + q;
}
sum(10, 20); // 30
sum(10);     // 50
sum();       // 70

- sum(10, 20) → 30 - sum(10) → 50 - sum() → 70

Passing Expressions as Default Values


function sum(p = 2, q = p * 2, r = p * q * 2) {
  return p + q + r;
}
sum(5, 10, 15); // 30
sum(5, 10);     // 115
sum();          // 22

Default values can be expressions that reference earlier parameters.

Passing Undefined Argument


function sum(p = 24, q = 26) {
  return p + q;
}
sum(5, undefined); // 31
sum(undefined);    // 50

Using Functions as Default Parameters


function getNum() {
  return 5;
}
function mul(p = 5, q = getNum()) {
  return p * q;
}
mul(10); // 50
mul();   // 25

Optional Parameters

Default parameters are also known as optional parameters. Required parameters should come first, and optional parameters should be last. 


function func(p, q = 10) {
  return p + q;
}
func(10, 20); // 30

If you place an optional parameter first, it can cause errors: 


function sum(p = 10, q) {
  return p + q;
}
sum(, 10); // Error
sum(10);   // NaN

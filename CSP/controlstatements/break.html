C# `break` Statement

Purpose of the `break` Statement

The **`break` statement** in C# is a control flow mechanism used to **immediately terminate** the execution of the nearest enclosing loop (for, while, or do...while) or the **`switch`** statement.

  • When encountered inside a loop, program control instantly resumes at the statement following the loop's block.
  • In **nested loops**, `break` only terminates the **innermost** loop in which it appears.

Syntax

break;

Example: Using `break` with a `while` Loop

This example shows how `break` stops a while loop prematurely based on a conditional check **inside** the loop body:

using System;
class Program {
    static void Main(string[] args) {
        int a = 10;
         
        while (a < 20) {
            Console.WriteLine("value of a: {0}", a);
            a++; // a becomes 11, 12, 13, 14, 15, 16...
            
            if (a > 15) {
               /* break terminates the loop when a reaches 16 */
               break;
            }
        }
        // Execution resumes here after the break
    }
}

Output: The loop prints values of a from 10 up to 15, stopping before reaching 20.

value of a: 10
value of a: 11
value of a: 12
value of a: 13
value of a: 14
value of a: 15

Example: Using `break` for Searching in a `for` Loop

Using `break` is efficient for searching, as it prevents unnecessary iterations once the target is found:

using System;
class BreakExample {
   static void Main() {
      for (int i = 1; i <= 10; i++) {
         if (i % 2 == 0) {
            Console.WriteLine("First even number found: " + i);
            break; // Loop stops immediately here (at i=2)
         }
         Console.WriteLine("Checking number: " + i);
      }
      Console.WriteLine("Loop terminated after finding the first even number.");
   }
}

Output:

Checking number: 1
First even number found: 2
Loop terminated after finding the first even number.

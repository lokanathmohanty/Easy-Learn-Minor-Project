Next.js Built-in Components 🧱

Overview of Next.js Components

**Next.js components** are specialized React components that extend standard HTML elements (`<img>`, `<a>`, `<form>`, etc.) to inject advanced features like **performance optimization**, automatic **client-side routing**, and **data management**. They are core to building efficient Next.js applications, especially within the App Router structure.

Next.js Component Reference

Component Standard HTML Element Key Functionality
`<Image>` `<img>` **Automatic image optimization** (resizing, format conversion, compression), **lazy loading**, and layout shift prevention.
`<Link>` `<a>` **Client-side navigation** (fast page transitions) and **automatic prefetching** of linked pages.
`<Script>` `<script>` **Optimized loading strategies** for third-party scripts (e.g., Google Analytics) like lazy loading and execution control.
`<Form>` `<form>` **Enhanced form handling** in the App Router, including client-side navigation on submission and integration with Server Actions.
`<Head>` `<head>` (Pages Router only) Used to dynamically modify the document's head (title, meta tags). Replaced by `generateMetadata` in the App Router.
`@next/font` — Used for **loading and optimizing fonts** (Google and local) with zero layout shift and improved performance (no component name, but often referred to as the Font system).

Example: Using `<Link>` for Navigation

The `<Link>` component is essential for client-side routing. When a user hovers over a `<Link>`, Next.js typically preloads the necessary code for the target page, resulting in instant navigation.

// app/layout.tsx (Used for a persistent navigation bar)
import Link from 'next/link';

export default function RootLayout({ children }: RootLayoutProps) {
    return (
        <body>
            <header>
                <ul> 
                    <li><Link href="/">Home</Link></li> 
                    <li><Link href="/products">Products</Link></li>
                </ul>
            </header>
            <main>{children}</main> 
        </body>
    );
}

Example: Styling the `<Image>` Component

The `<Image>` component allows standard styling methods, including inline styles, which are applied to the underlying `<img>` element after Next.js handles optimization.

import Image from 'next/image'

export default function Page() {
    const imageStyle = {
        borderRadius: '50%',
        border: '5px solid black',
    }

    return (
        <Image
            src="/profile.jpg"
            width={200}
            height={100}
            alt="Flower Image"
            style={imageStyle} // Apply inline JavaScript style object
        />
    )
}

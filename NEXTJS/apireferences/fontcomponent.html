Next.js Font Optimization (`@next/font`) 🖋️

Introduction to Next.js Font Optimization

The **`@next/font`** module is the recommended way to handle external and custom fonts in Next.js applications. It provides built-in utilities to ensure that fonts are automatically **preloaded**, optimized, and self-hosted (in the case of Google Fonts), which significantly improves loading performance and reduces the chance of **Cumulative Layout Shift (CLS)**.

Key Optimization Features:

  • **Zero CLS:** Automatically handles font loading to prevent the content from jumping when the font loads.
  • **Automatic Self-Hosting:** Google Fonts are downloaded and served from your origin, reducing external requests.
  • **Minimizing File Sizes:** Removes unused characters (**sub-setting**) to ensure only necessary glyphs are loaded.
  • **Fallback:** Ensures content remains visible using system fonts while the custom font loads.

1. Using Google Fonts (`next/font/google`)

To use a Google Font, you import it directly from the **`next/font/google`** package and call the function with configuration options (e.g., subsets and weights).

import { Inter } from 'next/font/google';

// Configure the Inter font
const inter = Inter({
  subsets: ['latin'],  // Required to subset the font for size
  weight: '400',       // Specifies font weight
});

export default function Home() {
  return (
    // Apply the font by referencing its generated CSS class name
    <div className={inter.className}>
      <h1>Hello, Next.js with Inter font!</h1>
    </div>
  );
}

2. Using Local/Custom Fonts (`next/font/local`)

To use fonts hosted within your project, you import **`localFont`** and provide the path to your font file(s) using the **`src`** argument. This ensures the font is self-hosted with the same optimization benefits.

import localFont from 'next/font/local';

// Configure the local font
const myFont = localFont({
  src: './path/to/font.woff2',  // Path relative to the file where localFont is called
  weight: '400',
  style: 'normal',
});

export default function Home() {
  return (
    <div className={myFont.className}>
      <h1>Hello, Next.js custom font!</h1>
    </div>
  );
}

Key Arguments for Font Configuration

Argument Purpose
`src` (Local Fonts) Specifies the relative path to the font file(s).
`subsets` (Google Fonts) An array specifying which character subsets (e.g., `'latin'`) to include for file size reduction.
`weight` / `style` Defines the weight (e.g., `'400'`, `'700'`) or style (e.g., `'italic'`) of the font variant to load.
`variable` A CSS variable name (e.g., `'--font-inter'`) to make the font globally available via CSS.
`fallback` An array of system font names to use while the custom font is loading.
`display` The CSS `font-display` strategy (e.g., `'swap'`, `'fallback'`) to control font loading behavior.

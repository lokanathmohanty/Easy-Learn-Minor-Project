R - Data Types

Generally, in programming, variables reserve memory locations to store values and can hold various data types such as character, integer, floating-point, Boolean, etc. In R, variables are not declared with a data type; instead, they are assigned R-Objects, and the data type of these objects is the variable's type.

The frequently used R-Objects include:

  • Vectors
  • Lists
  • Matrices
  • Arrays
  • Factors
  • Data Frames

Atomic Vectors and Data Types

The simplest R-objects are vectors which come in six atomic data types (also called classes):

Data Type Example Verification
Logical TRUE, FALSE v <- TRUE
print(class(v)) → [1] "logical"
Numeric 12.3, 5, 999 v <- 23.5
print(class(v)) → [1] "numeric"
Integer 2L, 34L, 0L v <- 2L
print(class(v)) → [1] "integer"
Complex 3 + 2i v <- 2+5i
print(class(v)) → [1] "complex"
Character 'a', "good", "TRUE", '23.4' v <- "TRUE"
print(class(v)) → [1] "character"
Raw "Hello" stored as 48 65 6c 6c 6f v <- charToRaw("Hello")
print(class(v)) → [1] "raw"

Vectors

To create a vector with multiple elements, use the c() function to combine elements: 

# Create a vector
apple <- c('red','green',"yellow")

print(apple)         # Outputs: "red" "green" "yellow"
print(class(apple))  # Outputs: "character"

Lists

A list can contain multiple types of elements including vectors, functions, and even other lists: 

# Create a list
list1 <- list(c(2,5,3), 21.3, sin)

print(list1)

The output:

[[1]]
[1] 2 5 3

[[2]]
[1] 21.3

[[3]]
function (x)  .Primitive("sin")

Matrices

A matrix is a two-dimensional rectangular data set created from vectors: 

# Create a matrix
M = matrix(c('a','a','b','c','b','a'), nrow = 2, ncol = 3, byrow = TRUE)
print(M)

The output:

     [,1] [,2] [,3]
[1,] "a"  "a"  "b" 
[2,] "c"  "b"  "a"

Arrays

Arrays can have any number of dimensions and are created using the array() function with a dimension attribute: 

# Create an array with two 3x3 matrices
a <- array(c('green','yellow'), dim = c(3,3,2))
print(a)

The output shows the two matrices:

, , 1

     [,1]     [,2]     [,3]    
[1,] "green"  "yellow" "green" 
[2,] "yellow" "green"  "yellow"
[3,] "green"  "yellow" "green" 

, , 2

     [,1]     [,2]     [,3]    
[1,] "yellow" "green"  "yellow"
[2,] "green"  "yellow" "green" 
[3,] "yellow" "green"  "yellow"

Factors

Factors are created from vectors and store distinct values as character labels. They are useful in statistical modeling. Create a factor with the factor() function and find the number of levels with nlevels(): 

# Create a vector
apple_colors <- c('green','green','yellow','red','red','red','green')

# Create a factor object
factor_apple <- factor(apple_colors)

# Print the factor and number of levels
print(factor_apple)
print(nlevels(factor_apple))

The output:

[1] green  green  yellow red    red    red    green 
Levels: green red yellow
[1] 3

Data Frames

Data frames are tabular data objects where each column can have a different mode (numeric, character, logical). They are lists of vectors of equal length, created using data.frame(): 

# Create a data frame
BMI <- data.frame(
  gender = c("Male", "Male","Female"), 
  height = c(152, 171.5, 165), 
  weight = c(81, 93, 78),
  Age = c(42, 38, 26)
)
print(BMI)

The output:

  gender height weight Age
1   Male  152.0     81  42
2   Male  171.5     93  38
3 Female  165.0     78  26

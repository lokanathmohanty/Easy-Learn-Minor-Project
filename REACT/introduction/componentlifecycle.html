ReactJS - Component Life Cycle

In React, the life cycle of a component represents the different stages during its existence. React provides several callback methods (Life Cycle APIs) to attach functionality at each stage.

Life Cycle Stages

  • Mounting – When a component is inserted into the DOM.
  • Updating – When a component is re-rendered due to changes in props or state.
  • Unmounting – When a component is removed from the DOM.

Important Life Cycle Methods

  • constructor() – Initializes state and props.
  • render() – Renders the component to the virtual DOM.
  • componentDidMount() – Called after the component is mounted; good for API calls and timers.
  • componentDidUpdate(prevProps, prevState, snapshot) – Invoked after an update. Useful for reacting to changes.
  • componentWillUnmount() – Cleanup phase (remove timers, listeners, etc.).
  • shouldComponentUpdate(nextProps, nextState) – Determines whether the component should re-render.
  • static getDerivedStateFromProps(props, state) – Updates state based on props; rarely used.
  • getSnapshotBeforeUpdate(prevProps, prevState) – Captures info (like scroll position) before updates.

Example: Clock Component

import React from 'react';

class Clock extends React.Component {
   constructor(props) {
      super(props);
      this.state = { date: new Date() };
   }

   componentDidMount() {
      this.setTimeRef = setInterval(() => this.setTime(), 1000);
   }

   componentWillUnmount() {
      clearInterval(this.setTimeRef);
   }

   setTime() {
      this.setState({ date: new Date() });
   }

   render() {
      return (
         <div>
            <p>The current time is {this.state.date.toString()}</p>
         </div>
      );
   }
}
export default Clock;

Using the Clock Component

import React from 'react';
import ReactDOM from 'react-dom';
import Clock from './components/Clock';

ReactDOM.render(
   <React.StrictMode>
      <Clock />
   </React.StrictMode>,
   document.getElementById('root')
);

// Remove after 5 seconds
setTimeout(() => {
   ReactDOM.render(
      <React.StrictMode>
         <div><p>Clock is removed from the DOM.</p></div>
      </React.StrictMode>,
      document.getElementById('root')
   );
}, 5000);

In this example, the clock shows the time for 5 seconds and is then unmounted. The componentWillUnmount() method ensures cleanup by clearing the interval.

Summary

Life cycle methods help React developers attach behavior at different stages of a component’s life. They are extremely useful for tasks such as API calls, DOM manipulation, and cleanup. Use them only when necessary, as overusing them may impact performance.

Python - Access Modifiers

In Python, access modifiers are used to restrict access to class members (variables and methods) from outside the class. The three types of access modifiers in Python are:

  • Public: Members accessible from anywhere.
  • Protected: Members accessible within the class and derived classes.
  • Private: Members accessible only within the class.

Unlike languages like C++ or Java, Python doesn’t enforce strict access modifiers but follows naming conventions:

  • Public: no underscore prefix.
  • Protected: single underscore prefix, e.g., _salary.
  • Private: double underscore prefix, e.g., __age.

Example: Access Modifiers

class Employee:
    def __init__(self, name, age, salary):
        self.name = name          # public
        self.__age = age          # private
        self._salary = salary     # protected

    def displayEmployee(self):
        print("Name: ", self.name, ", Age: ", self.__age, ", Salary: ", self._salary)

emp = Employee("Bhavana", 24, 10000)

print(emp.name)        # Works, public
print(emp._salary)     # Works, protected (convention)
print(emp.__age)       # Raises AttributeError, private

Output:

Bhavana
10000
AttributeError: 'Employee' object has no attribute '__age'

Name Mangling for Private Members

Python internally changes (mangles) the name of private members by prefixing their names with _ClassName. For example, __age becomes _Employee__age, allowing access if needed (though discouraged).

print(emp._Employee__age)  # Access private attribute via mangled name

Property Object and Encapsulation

Python provides the property() function to create managed attributes, supporting getter, setter, and deleter methods to enforce encapsulation.

Using Getter and Setter Methods

class Employee:
    def __init__(self, name, age):
        self.__name = name
        self.__age = age

    def get_name(self):
        return self.__name

    def set_name(self, value):
        self.__name = value

    def get_age(self):
        return self.__age

    def set_age(self, value):
        self.__age = value

    name = property(get_name, set_name, "Name property")
    age = property(get_age, set_age, "Age property")

emp = Employee("Bhavana", 24)
print(emp.name, emp.age)    # Access via property

emp.name = "Archana"         # Set via property
emp.age = 23
print(emp.name, emp.age)

Output:

Bhavana 24
Archana 23

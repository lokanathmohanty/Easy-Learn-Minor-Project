PHP File Reading Functions

**File Reading** is the process of extracting data from a file on the server for use within a PHP program. PHP provides several built-in functions to perform this operation, often utilizing a file pointer (handle) obtained from `fopen()`.

Methods for Reading Files

1. Reading the Entire File into a String: `file_get_contents()` 📝

This is the simplest way to read a file. It reads the entire content of a file directly into a single string. It handles opening, reading, and closing the file automatically, making it ideal for smaller files like configuration settings.

$content = **file_get_contents**('myfile.txt');
if ($content !== false) { /* use $content */ }

2. Reading Line by Line: `fgets()` 📏

The `fgets()` function reads a single line from an already opened file pointer (`$stream`). The read operation stops at a newline character, a specified length, or the End Of File (EOF). It is often used within a `while` loop that checks for EOF using **`feof()`**.

$file = fopen("hello.txt", "r");
while( ! feof($file) ) {
   echo **fgets**($file) . "<br>";
}
fclose($file);

3. Reading Character by Character: `fgetc()` 🔍

The `fgetc()` function reads and returns a **single character** from the current position of the file pointer. It is the most granular reading method.

$file = fopen("hello.txt", "r");
$char = **fgetc**($file); // Reads the first character
fclose($file);

4. Reading a Specified Number of Bytes: `fread()` 📦

The `fread()` function reads a specified number of bytes (`$length`) from the file pointer. This function is **binary-safe**, making it suitable for reading non-text files like images or archives (when opened in binary mode, e.g., `rb`).

$filename = "welcome.png";
$file = fopen($filename, "rb"); // Open in binary read mode
$data = **fread**($file, **filesize($filename)**); // Reads all bytes
fclose($file);

5. Reading and Parsing Formatted Data: `fscanf()` ⚙️

The `fscanf()` function reads a line from the file stream and attempts to **parse** its contents according to a specified format string (similar to C's `sscanf`). It's useful for structured files where data fields are separated by delimiters.

// Reads name (%s), email (%s), and salary (%d) separated by tabs (\t)
while ($data = **fscanf**($fp, "%s\t%s\t%s\t%d\n")) {
   list ($name, $email, $post, $salary) = $data;
   // ... process data ...
}

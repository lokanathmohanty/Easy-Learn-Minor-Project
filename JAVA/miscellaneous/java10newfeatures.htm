Java 10 - New Features (APIs & Options)

Overview and Release Cadence Changes 🔄

**Java 10**, released on **March 20, 2018**, marked a significant shift in the Java release strategy. Oracle adopted a new **6-month rapid release cadence** (non-LTS) and introduced a Long-Term Support (LTS) model for specific releases (e.g., Java 11). This ensures features are shipped faster using a "release train" concept.

Java 10 is a **non-LTS** release. Notably, Oracle also began promoting **OpenJDK** as the primary, freely distributable JDK, making Java much friendlier for cloud and container deployment.

Key New Features (JEPs)

While Java 10 introduced many features, the most impactful for day-to-day coding and performance are:

  • JEP 286: Local Variable Type Inference (var) ✨: Allowed the use of the reserved type name **var** for local variable declarations. The compiler infers the actual type, reducing boilerplate code while maintaining strong static typing.
  • JEP 307: Parallel Full GC for G1: Improved the performance of the **G1 Garbage Collector** by introducing a parallel full garbage collection phase, aiming to reduce latency and improve throughput.
  • JEP 304: Garbage-Collector Interface: Provided a clean interface for GCs to plug into the JDK, improving modularity and maintenance.
  • JEP 310: Application Class-Data Sharing (CDS): Extended CDS to allow sharing of archives of loaded classes for application-specific classes, which significantly improves startup time and reduces memory footprint, especially in multiple JVMs on the same machine.

New APIs and Utility Methods

Over 70 new APIs and options were added, focusing on collection management and defensive coding:

1. Unmodifiable Collections Creation

New methods were introduced for defensive copying of collections, resulting in **immutable** collections:

  • List.copyOf(Collection), Set.copyOf(Collection), Map.copyOf(Map): These methods create an unmodifiable copy of an existing collection. Attempts to modify the resulting collection will throw an UnsupportedOperationException.
  • Stream Collectors: New static methods in the Collectors class create immutable collections directly from a stream pipeline: toUnmodifiableList(), **toUnmodifiableSet()**, and **toUnmodifiableMap()**.

2. Optional Class Enhancement

The **java.util.Optional** class gained a clear method for retrieving the value or throwing an exception:

  • Optional.orElseThrow(): This method is now the preferred, cleaner alternative to the older get() method. If the Optional is empty, it throws NoSuchElementException.

3. Javadoc Enhancements

The javadoc tool received new options for richer documentation:

  • **--add-stylesheet:** Allows the use of multiple CSS stylesheets.
  • **--overridden-methods=value:** Simplifies documentation by allowing inherited and overridden methods to be grouped together.
  • **{@summary ...}:** A new inline tag to explicitly specify the short summary text for an API description.

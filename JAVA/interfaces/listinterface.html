List Interface in Java

Content

The List interface extends the Collection interface and represents an ordered collection that stores elements in a sequence.

Elements in a list can be accessed or inserted by their zero-based index. Lists allow duplicate elements.

Some key methods defined by the List interface include:

  • void add(int index, Object obj) - Inserts an element at a specific position.
  • boolean addAll(int index, Collection c) - Inserts all elements of a collection starting at a specified position.
  • Object get(int index) - Retrieves the element at a specified index.
  • int indexOf(Object obj) - Returns the first occurrence index of an element.
  • int lastIndexOf(Object obj) - Returns the last occurrence index of an element.
  • Object remove(int index) - Removes the element at the specified position.
  • Object set(int index, Object obj) - Replaces the element at the specified position.
  • List subList(int start, int end) - Returns a view of the portion of the list between start (inclusive) and end (exclusive).

List implementations include ArrayList and LinkedList, each with different performance characteristics.

Example

The following Java example demonstrates common List interface operations:


import java.util.*;

public class Main {
  public static void main(String[] args) {
    List list1 = new ArrayList<>();
    List list2 = new ArrayList<>();

    list1.add(0, 10);
    list1.add(1, 20);

    System.out.println("list1 : " + list1);

    list2.add(10);
    list2.add(20);
    list2.add(30);

    list1.addAll(1, list2);

    System.out.println("list2 : " + list2);

    list1.remove(1);

    System.out.println("list1 after removing an element: " + list1);

    System.out.println("list1 using get() : " + list1.get(2));

    list1.set(0, 50);

    System.out.println("list1 : " + list1);
  }
}

C++ Dereferencing (The Indirection Operator *) 🎯

**Dereferencing** is the process of accessing or modifying the **value** stored at the memory address held by a **pointer**. It is the inverse operation of taking a variable's address with `&`.

The **dereference operator**, denoted by the asterisk (*****), is also known as the **indirection operator**.

How Dereferencing Works

The `*` operator performs two main functions on a pointer:

1. Reading a Value

It accesses the value stored at the pointer's address, allowing you to read it.

int* ptr = &number;
int value = *ptr; // Reads the value at the address held by ptr

2. Modifying a Value

It accesses the memory location itself, allowing you to assign a new value to the original variable.

int* ptr = &number;
*ptr = 100; // Modifies the value of 'number' to 100

Example: Reading and Modifying

int number = 42;      
int* ptr = &number;   

cout << "Original: " << *ptr << endl;  // Output: 42

*ptr = 100; // Changes 'number' via the pointer

cout << "Modified: " << number << endl; // Output: 100

Dereferencing vs. References

Both pointers (with dereferencing) and references allow indirect access to a variable, but they function differently:

FeatureDereferencing (*)Reference (& in declaration)
Purpose Accessing the **value** stored at a pointer's **address**. Creating a permanent **alias** (another name) for an existing variable.
Usage Symbol ***** (used in an expression) No special symbol needed after declaration.
Reassignment Pointers can be reassigned to point to different variables. References **cannot** be reassigned after initialization.
Nullability Pointers can be set to **nullptr**. References **must** be initialized and cannot be null.

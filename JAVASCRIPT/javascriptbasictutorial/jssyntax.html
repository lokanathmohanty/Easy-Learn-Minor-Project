JavaScript Syntax

Introduction

JavaScript syntax is the set of rules that defines how JavaScript programs are constructed. These rules guide how statements, variables, operators, and other language features are written.

Embedding JavaScript in HTML

You can embed JavaScript using the <script> tag. It can be placed in the head, body, or linked externally.

  • Inside the <head> section.
  • Inside the <body> section.
  • In an external file using <script src="file.js"></script>.

Example

Here is a simple JavaScript example:

<script>
  document.write("Hello World!");
</script>

Variables

Variables are used to store values. JavaScript supports var, let, and const.

let a = 5;
const b = "One";

Comments

  • Single-line: // comment
  • Multi-line: /* comment */

Operators

JavaScript supports arithmetic, comparison, and logical operators.

  • Arithmetic: + - * / %
  • Comparison: == === != !==
  • Logical: && || !

Expressions

Expressions combine values and operators to produce a result.

let x = 10;
let y = x + 5;
let z = y * 2;

Character Set

JavaScript uses Unicode, which allows symbols and special characters.

  • &larr; → ←
  • &#8360; → ₹

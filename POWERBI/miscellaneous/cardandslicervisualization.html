Power BI: Card and Slicer Visualization

Power BI offers powerful visual tools to create interactive reports and easily model data. The Card visual highlights a single aggregated value, such as an average salary, maximum salary, or total production, making key metrics clearly visible at a glance.

The Slicer visual enables interactive filtering of data. It gives users a simple way to narrow down data displayed in other visuals by selecting values from lists, numeric ranges, dates, or hierarchies. Together, these tools enhance report interactivity and usability.

Creating a Card Visual: Average Monthly Salary Example

  1. Open Power BI Desktop and use the "Get Data" option to load an Excel workbook such as Employee.xls.
  2. Select the appropriate worksheet (e.g., Sheet1) and load it to Power BI.
  3. Navigate to the Report view and select the "Salary" column.
  4. Click on the Card visual icon. By default, it displays the sum of salaries.
  5. Change the aggregation by clicking the arrow next to "Sum of Salary" and select "Average".
  6. The Card visual now displays the average employee salary clearly and prominently.

Using Slicer Visual for Data Filtering

  1. Select the "Slicer (New)" visual from the Visualizations pane and add it to the report canvas.
  2. Drag a column like "Name" to the Field textbox. This populates the slicer with all employee names.
  3. Drag a related column such as "Job Role" into the Drill Through fields and set it as a category filter.
  4. Use the slicer checkboxes to filter employee names by their job roles, e.g., selecting "Cyber Security Analyst" filters the list to relevant employees.

Slicers allow fast and user-friendly filtering on numeric values, dates, and hierarchies, improving report interactivity and making it easy for users to find specific information.

Benefits and Tips

  • Cards provide quick, unambiguous display of key metrics without complexity.
  • Slicers foster dynamic data interaction and easy filtering across reports.
  • These visuals can help beginners navigate complex datasets efficiently and improve data analytics outcomes.
  • Practicing with these features builds strong report-building skills in Power BI.

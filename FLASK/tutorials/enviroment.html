Setting Up the Flask Development Environment 🛠️

Setting up an isolated environment is the best practice for Flask development. This ensures that different projects can use different versions of Python libraries without conflicts.

Prerequisite and Python Version Recommendation

Flask requires **Python 2.6 or higher**. Although Flask and its core dependencies support **Python 3.3 onwards**, it is generally recommended to use **Python 2.7** for broader compatibility, as many Flask extensions historically lacked proper support for Python 3. *Note: Modern development is rapidly shifting to Python 3.*

Virtual Environment Setup

The key tool for creating an isolated environment is **virtualenv**, which allows you to create multiple, side-by-side Python environments to manage library versions and avoid compatibility issues.

1. Install virtualenv

The simplest way to install the tool is via **pip**. You may need administrator privileges to run this command.

pip install virtualenv

Alternatively, on Ubuntu, you can use the package manager:

sudo apt-get install virtualenv

2. Create a New Virtual Environment

First, create and navigate into your project folder, then run the **virtualenv** command, specifying a name for your environment folder (commonly venv).

  • mkdir newproj
  • cd newproj
  • virtualenv venv

3. Activate the Environment

You must activate the environment to start using it. Once active, any packages installed will only be placed inside the venv folder, not system-wide.

  • **On Linux/OS X:** venv/bin/activate
  • **On Windows:** venv\scripts\activate

Installing Flask

Once the virtual environment is activated, you can install the Flask framework using pip. The framework will be installed only within your isolated venv.

pip install Flask

*(To install Flask system-wide, simply run the above command without activating a virtual environment.)*

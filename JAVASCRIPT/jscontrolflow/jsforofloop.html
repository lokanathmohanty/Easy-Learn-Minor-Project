JavaScript for...of Loop — E-Learning Session

Overview

The for...of loop is used to iterate over the values of iterable objects such as arrays, strings, maps, sets, and generators. Unlike for...in, which iterates over property names (keys), for...of directly gives you the values, making it more efficient and readable for iterables.

Syntax

for (element of iterable) { // loop body }

Parameters

  • element — the current value from the iterable.

  • of — the operator indicating iteration over values.

  • iterable — an iterable object such as an array, string, map, or set.

Examples

For...of Loop with Arrays

Iterating over an array of strings:

const arr = ["JavaScript", "Python", "C", "C++", "HTML", "CSS"]

for (let ele of arr) { /* use ele */ }

Output:

  • JavaScript
  • Python
  • C
  • C++
  • HTML
  • CSS

For...of Loop with Strings

Strings are iterable character by character:

let str = "JavaScript"

for (let char of str) { /* use char */ }

Output:

  • J
  • a
  • v
  • a
  • S
  • c
  • r
  • i
  • p
  • t

For...of Loop with Set

A Set stores unique values. The loop iterates through them once:

const nums = new Set([10, 20, 30, 30, 40, 50])

for (let num of nums) { /* use num */ }

Output: 10, 20, 30, 40, 50

For...of Loop with Map

A Map stores key-value pairs. Using array destructuring inside the loop, you can access both keys and values:

const map = new Map(); map.set("one", 1); map.set("second", 2);

for (let [k, v] of map) { /* use k and v */ }

Output:

  • one -> 1
  • second -> 2
  • third -> 3

Comparison with for...in

  • for...in iterates over keys (property names).

  • for...of iterates over values of iterables.

  • Use for...of for arrays, strings, sets, and maps where values are needed.

Common Pitfalls

  • Using for...of on non-iterable objects (like plain objects) will throw an error.

  • Confusing for...in with for...of may cause bugs since they operate differently.

Practice Tasks

  • Write a for...of loop that sums all numbers in an array.

  • Use for...of to iterate over a string and count the vowels.

  • Create a map of countries and capitals and print them using for...of.

Summary

The for...of loop provides a clean and efficient way to iterate over iterable objects. Use it for arrays, strings, sets, maps, and generators when you need values instead of property names.

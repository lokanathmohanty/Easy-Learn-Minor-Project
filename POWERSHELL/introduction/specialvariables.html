PowerShell: Special Variables

PowerShell special variables, also known as automatic variables, store information about the current state of the PowerShell session or pipeline. These variables are predefined and update automatically as you use PowerShell.

Key PowerShell Special Variables

  • $$ - Contains the last token in the previous command line.
  • $? - Indicates success (True) or failure (False) of the last operation.
  • $^ - Contains the first token in the previous command line.
  • $_ or $PSItem - Represents the current object in the pipeline.
  • $ARGS - An array of undeclared parameters passed to script or function.
  • $ERROR - Collection of error objects from recent errors.
  • $LASTEXITCODE - Exit code of the last Windows-based program run.
  • $HOME - Path of the current user's home directory.
  • $PID - Process ID of the current PowerShell session.
  • $PROFILE - Path to the user's PowerShell profile script.
  • $PSVersionTable - Displays properties about the PowerShell version in use.
  • $TRUE / $FALSE - Built-in boolean constants for true and false.

Usage Examples

Example: Using the pipeline item variable $_

Get-Process | Where-Object { $_.CPU -gt 100 }

This selects processes where the CPU usage is greater than 100.

Example: Checking command success with $?

Get-ChildItem "C:\NonExistentFolder"
echo $?

This outputs False because the folder does not exist.

HTML - Symbols

In HTML, you can embed the symbols and special characters that are not available on the keyboard using HTML entities.

What are HTML Symbols?

HTML symbols are characters that hold a special meaning and are difficult to type directly on the keyboard. For example, other than the dollar symbol, we can’t find currency symbols like rupees and euros on normal keyboards. HTML provides entities to insert such symbols into webpages.

Entities start with an ampersand (&) and end with a semicolon (;). They can be named (e.g., ©) or numeric (e.g., ©).

Inserting Symbols in HTML Document

To insert symbols, we use either named entities or numeric entities:

  • Named entities use a descriptive name (e.g., ©).
  • Numeric entities use decimal or hexadecimal numbers (e.g., ©).

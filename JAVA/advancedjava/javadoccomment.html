Java Documentation Using Javadoc Tool

Javadoc is a tool included with the JDK for generating HTML documentation from Java source code. It produces documentation pages based on special comments that follow a predefined format embedded in your Java code.

From Java 9 onwards, Javadoc supports generating docs in HTML5 format using the -html5 option.

What is Javadoc?

Javadoc comments start with /** and are placed before class, method, or field declarations. Comments can contain HTML tags like <h1> and <p> for formatting.

/**
 * 
Hello, World!

 * The HelloWorld program implements an application that
 * simply displays "Hello World!" to the standard output.
 * 

 * Proper comments make your program more user friendly and high quality.
 *
 * @author  Zara Ali
 * @version 1.0
 * @since   2014-03-31
 */
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello World!");
    }
}

Common Javadoc Tags

  • @author - Specifies author of the code
  • @version - Version info
  • @since - Since which version
  • @param - Describes method parameter
  • @return - Describes return value
  • @throws - Describes exceptions thrown
  • {@link} - Creates hyperlink to other documented items

Example: Documenting AddNum Class

import java.io.*;

/**
 * 
Add Two Numbers!

 * This class adds two integers and prints the result.
 * 

 * Note: Proper comments produce user friendly and high-quality code.
 * 
 * @author Zara Ali
 * @version 1.0
 * @since 2014-03-31
 */
public class AddNum {
    /**
     * Adds two integers.
     * @param numA first number
     * @param numB second number
     * @return the sum of numA and numB
     */
    public int addNum(int numA, int numB) {
        return numA + numB;
    }

    /**
     * Main method which uses addNum.
     * @param args Unused.
     * @throws IOException on input error.
     * @see IOException
     */
    public static void main(String args[]) throws IOException {
        AddNum obj = new AddNum();
        int sum = obj.addNum(10, 20);
        System.out.println("Sum of 10 and 20 is :" + sum);
    }
}

Running javadoc AddNum.java generates HTML documentation of the class and methods.

Using Javadoc with HTML5

From Java 9 onward, running javadoc -html5 AddNum.java generates documentation in modern HTML5 format ensuring better compatibility and styling options.

Be aware of tag correctness; e.g., avoid using @return in methods with void return type to prevent errors.

C - User Input

Need for User Input in C

Every computer application accepts data from the user and processes it to produce output. C has no built-in keywords for user input, but provides the scanf() function from the stdio.h header to handle user input from the standard input stream.

Example

#include <stdio.h>

int main(){
   int price, qty, ttl;

   price = 100;
   qty = 5;
   ttl = price * qty;

   printf("Total: %d", ttl);

   return 0;
}

C User Input Function: The scanf()

The scanf() function reads formatted input from the keyboard. It requires a format string and the addresses of variables to store the input values.

Syntax of scanf()

int scanf(const char *format, &var1, &var2, ...);

User Input Format Specifiers

  • %c – Character
  • %d – Signed integer
  • %f – Float
  • %i – Unsigned integer
  • %lf – Double
  • %s – String
  • %ld, %lli, %llu – Long and unsigned variants

Example

#include <stdio.h>

int main(){
   int price, qty, ttl;

   printf("Enter price and quantity: ");
   scanf("%d %d", &price, &qty);

   ttl = price * qty;

   printf("Total : %d", ttl);

   return 0;
}

Integer Input

Example: Integer Input in C

#include <stdio.h>

int main(){
   int num;
   printf("Enter an integer: ");
   scanf("%d", &num);
   printf("You entered an integer: %d", num);
   return 0;
}

Multiple Integer Inputs

Example: Multiple Integer Inputs in C

#include <stdio.h>

int main(){
   int num1, num2;
   printf("Enter two integers: ");
   scanf("%d %d", &num1, &num2);
   printf("You entered two integers: %d and %d", num1, num2);
   return 0;
}

Float Input

Example: Float Input in C

#include <stdio.h>

int main(){
   float num1;
   printf("Enter a number: ");
   scanf("%f", &num1);
   printf("You entered a floating-point number: %f", num1);
   return 0;
}

Integer and Float Input

Example: Integer and Float Inputs in C

#include <stdio.h>

int main(){
   int num1;
   float num2;
   printf("Enter two numbers: ");
   scanf("%d %f", &num1, &num2);
   printf("You entered an integer: %d a floating-point number: %6.2f", num1, num2);
   return 0;
}

Character Input

For character input, use the %c specifier. Include a space before %c to skip any leftover whitespace.

Example: Character Input in C

#include <stdio.h>

int main(){
   char ch;
   printf("Enter a single character: ");
   scanf(" %c", &ch);
   printf("You entered character: %c", ch);
   return 0;
}

Multiple Characters Input

Example: Multiple Character Inputs in C

#include <stdio.h>

int main(){
   char ch1, ch2;
   printf("Enter two characters: ");
   scanf("%c %c", &ch1, &ch2);
   printf("You entered characters: %c and %c", ch1, ch2);
   return 0;
}

Character Input Using getchar()

The getchar() function reads a single character without requiring Enter.

Example: Using getchar()

#include <stdio.h>

int main(){
   char ch;
   printf("Enter a character: ");
   ch = getchar();
   puts("You entered: ");
   putchar(ch);
   return 0;
}

Reading a Character Sequence

Example: Reading Until Enter Key

#include <stdio.h>

int main(){
   char ch;
   char word[10];
   int i = 0;

   printf("Enter characters. End by pressing the Enter key: ");
   while(1){
      ch = getchar();
      word[i] = ch;
      if (ch == '\n')
         break;
      i++;
   }
   printf("\nYou entered the word: %s", word);
   return 0;
}

String Input Using scanf()

Example: String Input Using scanf()

#include <stdio.h>

int main(){
   char name[20];
   printf("Enter your name: ");
   scanf("%s", name);
   printf("You entered the name: %s", name);
   return 0;
}

String Input Using gets()

Example: String Input Using gets()

#include <stdio.h>

int main(){
   char name[20];
   printf("Enter your name: ");
   gets(name);
   printf("You entered the name: %s", name);
   return 0;
}

User input is an essential part of interactive programs. In this session, we've covered both formatted (scanf) and unformatted (getchar, gets) input methods in C.

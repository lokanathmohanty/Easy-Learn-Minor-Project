Python - Join Sets

Common methods to join sets include union, update, set comprehension, unpacking, and iterative addition.

Join Python Sets Using "|" Operator

The "|" operator is the union operator that returns a new set containing all unique elements from both sets. 


s1 = {1,2,3,4,5}
s2 = {4,5,6,7,8}
s3 = s1 | s2
print(s3)

Output: {1, 2, 3, 4, 5, 6, 7, 8}

Join Python Sets Using union() Method

The union() method returns a new set with elements from both sets, removing duplicates. 


s1 = {1,2,3,4,5}
s2 = {4,5,6,7,8}
s3 = s1.union(s2)
print(s3)

Output: {1, 2, 3, 4, 5, 6, 7, 8}

Join Python Sets Using update() Method

The update() method adds elements from the second set into the first set, modifying it in place. 


s1 = {1,2,3,4,5}
s2 = {4,5,6,7,8}
s1.update(s2)
print(s1)

Output: {1, 2, 3, 4, 5, 6, 7, 8}

Join Python Sets Using Unpacking Operator

The unpacking operator (*) allows merging multiple sets into a new set by unpacking their elements. 


s1 = {1,2,3,4,5}
s2 = {4,5,6,7,8}
s3 = {*s1, *s2}
print(s3)

Output: {1, 2, 3, 4, 5, 6, 7, 8}

Join Python Sets Using Set Comprehension

Set comprehension creates a new set by iterating over multiple sets and collecting all elements. 


set1 = {1, 2, 3}
set2 = {3, 4, 5}

joined_set = {x for s in [set1, set2] for x in s}
print(joined_set)

Output: {1, 2, 3, 4, 5}

Join Python Sets Using Iterative Addition

Elements from multiple sets can be added one by one to a new set using loops and the add() method. 


set1 = {1, 2, 3}
set2 = {3, 4, 5}

joined_set = set()

for element in set1:
   joined_set.add(element)

for element in set2:
   joined_set.add(element)

print(joined_set)

Output: {1, 2, 3, 4, 5}

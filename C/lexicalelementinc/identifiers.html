Identifiers in C

Identifiers are user-defined names used to identify variables, constants, functions, arrays, and other programming elements. They help programmers refer to memory locations by name rather than by numeric address.

Rules for Naming Identifiers

  • Identifiers must start with an alphabet (A-Z or a-z) or an underscore (_).
  • Subsequent characters can be alphabets, digits (0-9), or underscores.
  • Keywords (reserved words) cannot be used as identifiers.
  • Identifiers are case-sensitive (e.g., age and Age are different).
  • Identifiers cannot contain special characters or spaces.
  • An identifier can only be used once within the same scope.

Valid and Invalid Identifiers

Valid: age, Age, AGE, average_age, __temp, address1, phone_no_personal, _my_name

Invalid: Average-age, my name, $age, #phone, 1mg, phy+maths

Examples


#include <stdio.h>

int main() {
   int marks = 50;
   float marks = 65.50;  // Error: duplicate identifier with different type
   printf("%d %f", marks, marks);
   return 0;
}

This code produces a compilation error because marks is declared twice with different types.

Scope of Identifiers

Global Identifiers: Declared outside all functions; accessible throughout the program.


int marks = 100;  // Global identifier

int main() {
   printf("The value of marks is %d\n", marks);
}

Local Identifiers: Declared within functions; accessible only within that function.


int main() {
   int marks = 100;  // Local identifier
   printf("The value of marks is %d\n", marks);
}

Types of Identifiers

  • Variable identifiers
  • Function identifiers
  • User-defined type identifiers (e.g., struct)
  • Typedef identifiers
  • Label identifiers (used with goto)
  • Enum identifiers

Examples of Different Identifier Types


// Variable identifier
int marks1 = 50, marks2 = 60;
float avg = (float)(marks1 + marks2) / 2;

// Function identifier
int average(int marks1, int marks2) {
   return (marks1 + marks2) / 2;
}

// User-defined type identifier
struct student {
   int rollno;
   char *name;
   int m1, m2, m3;
   float percent;
};
struct student s1 = {1, "Raju", 50, 60, 70, 60.00};

// Typedef identifier
typedef struct student STUDENT;
STUDENT s1 = {1, "Raju", 50, 60, 70, 60.00};

// Label identifier
int x = 0;
begin:
x++;
if (x >= 10)
  goto end;
printf("%d\n", x);
goto begin;
end:

// Enum identifier
enum week { Mon=10, Tue, Wed, Thur, Fri=10, Sat=16, Sun };
printf("Value of enum week: %d\n", Mon);

Object Oriented Programming in PHP

**Object-Oriented Programming (OOP)** is a paradigm that models the world using **objects**, which are instances of **classes**. OOP is built on several key concepts:

  • Class: A blueprint or template for creating objects, defining their properties (member variables) and behaviors (member functions).
  • Object (Instance): An individual instance of a class. You can create many objects from a single class definition.
  • Encapsulation: The bundling of data (variables) and the methods (functions) that operate on that data into a single unit (the class), restricting direct access to some of the object's components.
  • Inheritance: A mechanism where a new class (**Child Class** or subclass) is created by inheriting properties and methods from an existing class (**Parent Class** or base class). This promotes code reuse.
  • Polymorphism: The ability of a function or method to take on multiple forms, such as when a child class overrides a parent class method (Function Overriding).
  • Data Abstraction: Hiding the complex implementation details and showing only the essential information to the user.

Defining and Using PHP Classes

A class is defined using the class keyword. Member variables are traditionally declared with var (though modern practice favors visibility keywords like **public**), and member functions define the class's behavior. 

<?php
   class Books {
      /* Member variables */
      var $price; // Property
      var $title; // Property
      
      /* Member function (Method) */
      function setTitle($par){
         // $this refers to the current object instance
         $this->title = $par;
      }
      
      function getTitle(){
         echo $this->title . " <br/>";
      }
   }
?>

Creating Objects

Objects are created using the new operator. Each object is independent. 

$physics = new Books();
$maths = new Books();

Calling Member Functions

Methods are called using the -> operator on an object instance. 

$physics->setTitle( "Physics for High School" );
$physics->setPrice( 10 );
$physics->getTitle();

Constructors and Destructors

  • Constructor (__construct()): A special method that is automatically called when a new object is created. It's used to initialize member variables. 
    function __construct( $par1, $par2 ) {
   $this->title = $par1;
   $this->price = $par2;
}

// Object creation with initialization
$book = new Books( "The Martian", 20 );
  • Destructor (__destruct()): A special method automatically called when an object is destroyed or goes out of scope, often used to release resources.

Inheritance and Access Modifiers

Inheritance

A class inherits from a parent using the extends keyword, gaining all the parent's public and protected members. 

class Novel extends Books {
   var $publisher;
   // Additional methods or overridden methods...
}

To call a parent's method from an overridden child method, you use parent::methodName() or ParentClassName::methodName() (e.g., when calling the parent constructor).

Access Modifiers

Keywords control the visibility and accessibility of properties and methods:

  • public: Accessible from anywhere (inside the class, by inherited classes, and from outside via the object). This is the default.
  • protected: Accessible within the class itself and by all classes that inherit from it (child classes). Not accessible from outside.
  • private: Accessible **only** within the class in which it is declared. Not visible or accessible even by child classes.

Advanced OOP Concepts

  • Abstract Classes (abstract): A class that cannot be instantiated on its own, only inherited. It may contain abstract methods (which have no body) that **must** be implemented by any non-abstract child class.
  • Interfaces (interface): Define a contract of public methods that an implementing class must define. A class uses the implements keyword to adopt an interface. 
    interface Mail { public function sendMail(); }
class Report implements Mail { /* implementation here */ }
  • Static Members (static): Members (properties or methods) declared as static belong to the class itself, not to any specific object instance. They are accessed using the scope resolution operator (::). 
    class Foo { public static $my_static = 'foo'; }
print Foo::$my_static;
  • Final Keyword (final):
    • If prefixed to a **method**, it prevents child classes from overriding that method.
    • If prefixed to a **class**, it prevents the class from being extended (inherited).
  • Constants (const): Declared inside a class, they hold an immutable value that cannot be changed once declared. They don't use the $ prefix. 
    class MyClass { const requiredMargin = 1.7; }

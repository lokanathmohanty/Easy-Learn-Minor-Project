HTML - Velocity Draw

Introduction

Velocity Draw is a tool for creating and manipulating animations and visual graphics on a web page. It exposes properties such as opacity, size, and position that control animation behaviour. In this session learners will see how cursor position, opacity, and density influence the drawing output.

Tool Overview

The demo allows freehand drawing affected by velocity and density. Controls are provided to adjust opacity and density interactively.

On-screen Controls & Status

  • opacity: 25%
  • density: 422
  • point cache: 0
  • pan: space + drag
  • lock opacity: hold Shift
  • clear cache: Ctrl + Del
  • save: Ctrl + Shift + S
  • velocity skewing: disabled

Interaction Tips

  • Drag the small control circle (left corner) up or down to change opacity and density.
  • Move the cursor faster to create longer, sparser strokes; move slowly for denser strokes.
  • Use space + drag to pan the canvas while drawing.
  • Hold Shift while drawing to lock the current opacity.

Accessibility & Shortcuts

Keyboard shortcuts and modifier keys allow quick control without reaching for UI sliders:

  • Ctrl + Del — Clear the point cache.
  • Ctrl + Shift + S — Save the current canvas state.

Example: Minimal Markup Structure

Use this skeleton to embed a Velocity Draw canvas and controls (behaviour implemented via JavaScript):

<div class="velocity-draw-session">
  <div class="vd-toolbar">
    <button class="vd-btn" data-action="clear">Clear</button>
    <button class="vd-btn" data-action="save">Save</button>
    <div class="vd-control" data-control="opacity">Opacity: <span class="vd-value">25%</span></div>
    <div class="vd-control" data-control="density">Density: <span class="vd-value">422</span></div>
  </div>

  <div class="vd-canvas-wrap">
    <canvas class="vd-canvas" width="800" height="600"></canvas>
  </div>

  <div class="vd-help">
    <p>Pan: space + drag · Lock opacity: shift · Clear cache: ctrl + del · Save: ctrl + shift + s</p>
  </div>
</div>

Learning Activities

  • Experiment with different densities and observe how stroke appearance changes.
  • Toggle velocity skewing (if available) and compare results with skewing disabled.
  • Record and save a sequence of frames to study animation artifacts at different frame rates.

Further Notes

Implementations typically rely on the Canvas API and a small physics/velocity model to map cursor movement into stroke width, spacing, and opacity. For teaching purposes, consider exposing the velocity-to-size mapping as a visible graph so learners can correlate input speed with visual output.

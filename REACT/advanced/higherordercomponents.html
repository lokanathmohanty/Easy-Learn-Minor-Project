ReactJS - Higher-Order Components

In React, components are composed together rather than extended through inheritance. This makes logic sharing a challenge. A Higher-Order Component (HOC) is a design pattern (not a React API) that provides a way to share logic between components without side effects.

How to use Higher-Order Components

A HOC is a function that takes a React component as input and returns a new component with enhanced functionality.

For example, a HOC can receive a rendering component as input and return a new component with data-fetching capabilities wrapped around the input component.

General Signature

function createHOC(WrappedComponent, url) {
   // returns a new component
}

Data Fetching Example

HOC function with primary logic (fetching data) and wrapped component:

function createFetchHOC(WrappedComponent, url) {
   class DataFetcher extends React.Component {
      componentDidMount() {
         fetch(url)
            .then((response) => response.json())
            .then((data) => {
               this.setState({ data: data });
            });
      }
      render() {
         return (
            <WrappedComponent data={this.state.data} {...this.props} />
         )
      }
   }
   return DataFetcher;
}

Using the HOC

Create a new component by combining the wrapped component and HOC:

const UserListWithFetch = createFetchHOC(
   UserList,
   "users.json"
);

<UserListWithFetch />

Applying HOC in an Application

Steps to create and use the HOC:

  • Create a React app with create-react-app.
  • Create the HOC function createFetchHOC.
  • Create sample data files: users.json and todo_list.json.
  • Create components UserList and TodoList to render data.
  • Wrap them using createFetchHOC to create fetch-enabled components.
  • Use them in a parent component (SimpleHOC) and render in App.js.

Example HOC Function

import React from 'react';

function createFetchHOC(WrappedComponent, url) {
   class DataFetcher extends React.Component {
      constructor(props) {
         super(props);
         this.state = { data: [] };
      }

      componentDidMount() {
         fetch(url)
            .then((response) => response.json())
            .then((data) => {
               this.setState({ data: data });
            });
      }

      render() {
         return (
            <WrappedComponent data={this.state.data} {...this.props} />
         )
      }
   }
   return DataFetcher;
}

export default createFetchHOC;

UserList Component

import React from "react";

class UserList extends React.Component {
   render() {
      return (
         <ul>
            {this.props.data && this.props.data.map(
               (item) => <li key={item.id}>{item.name}</li>
            )}
         </ul>
      )
   }
}
export default UserList;

TodoList Component

import React from "react";

class TodoList extends React.Component {
   render() {
      return (
         <ul>
            {this.props.data && this.props.data.map(
               (item) =>
                  <li key={item.id}>
                     {item.title} {item.is_done && <strong>Done</strong>}
                  </li>
            )}
         </ul>
      )
   }
}
export default TodoList;

SimpleHOC Component

import React from "react";
import UserList from "./UserList";
import TodoList from "./TodoList";
import createFetchHOC from "./createFetchHOC";

const UserListWithFetch = createFetchHOC(UserList, "users.json");
const TodoListWithFetch = createFetchHOC(TodoList, "todo_list.json");

class SimpleHOC extends React.Component {
   render() {
      return (
         <>
            <UserListWithFetch />
            <TodoListWithFetch />
         </>
      )
   }
}
export default SimpleHOC;

App.js

import './App.css';
import React from 'react';
import SimpleHOC from './Components/SimpleHOC';

function App() {
   return (
      <div className="container">
         <SimpleHOC />
      </div>
   );
}

export default App;

Summary

Higher-Order Components (HOCs) provide an efficient and reusable way to share logic between components. They are widely used in React applications and third-party libraries, making them a reliable and time-tested design pattern.

Pandas - Removing Duplicates

Duplicate rows are records that appear more than once in a dataset. These duplicates can lead to incorrect analysis or inflated results.

In the dataset below, we can observe that row 11 and row 12 contain the exact same values:


  11  60  '2020/12/12'  100  120  250.7
  12  60  '2020/12/12'  100  120  250.7

To find duplicates, we can use the duplicated() method, which returns a Boolean Series where duplicate rows are marked as True.

Example: Discovering Duplicates

This example prints whether each row in the DataFrame is a duplicate:


print(df.duplicated())

Rows marked as True are duplicates of previous rows.

Example: Removing Duplicates

To remove all duplicate rows from the DataFrame, use the drop_duplicates() method.


df.drop_duplicates(inplace=True)

Using inplace=True ensures that the changes are made directly to the existing DataFrame without needing to assign the result to a new variable.

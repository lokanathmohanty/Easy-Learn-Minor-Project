HTML - Color Names

HTML color names are predefined names that can be used directly in CSS or HTML attributes to style elements. These names represent specific colors without requiring RGB or hexadecimal values.

There are 16 standard color names introduced in HTML 3.2, and modern browsers also support many extended color names.

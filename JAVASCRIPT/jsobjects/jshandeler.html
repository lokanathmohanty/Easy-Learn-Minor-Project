JavaScript - Handler

The JavaScript Proxy Handlers are used to define custom behavior for fundamental operations performed on objects. By defining handlers, you can override the default behavior of these operations.

Common proxy handler methods include apply(), construct(), get(), has(), and more.

JavaScript Handlers

Following are the methods of JavaScript Handler −

  • apply() − Allows you to call a function with particular arguments and context.
  • construct() − Allows you to define custom behavior for fundamental operations on an object.
  • defineProperty() − Used to define new properties or modify existing ones on an object.
  • deleteProperty() − Used as a trap for the delete operator.
  • get() − A trap for getting a property value.
  • getOwnPropertyDescriptor() − A trap for the [[GetOwnProperty]] object internal method.
  • getPrototypeOf() − A trap for the internal method.
  • has() − Used to hide any property that you want.
  • isExtensible() − Determines whether a new property can be added to the target object.
  • ownKeys() − A trap for the [[OwnPropertyKeys]] object internal method.
  • set() − A trap for the [[Set]] object internal method.
  • setPrototypeOf() − Allows you to set the prototype of a specified object to another object.

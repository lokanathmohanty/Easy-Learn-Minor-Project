JSON in Python

JSON (JavaScript Object Notation) is a lightweight, text-based data format used for data exchange between systems. It is easy to read and write for humans, and easy to parse and generate by machines.

Python provides the json module to serialize Python objects to JSON and deserialize JSON strings to Python objects.

  • Supported types for serialization include: dict, list, tuple, str, int, float, bool, and None.
  • JSON strings use double quotes for keys and string values.

Serialization example (Python object to JSON string):

import json

data = {"name": "Alice", "age": 30, "city": "New York"}

json_string = json.dumps(data)
print(json_string)

Output:

{"name": "Alice", "age": 30, "city": "New York"}

JSON Deserialization

Deserialization converts a JSON string or file content back into Python objects.

You can deserialize from strings using json.loads() or from files using json.load().

Deserialize JSON string to object example:

import json

json_string = '{"name": "John", "age": 30, "is_student": false, "courses": ["Math", "Science"]}'

obj = json.loads(json_string)
print(obj)

Output:

{'name': 'John', 'age': 30, 'is_student': False, 'courses': ['Math', 'Science']}

Deserialize JSON from file example:

import json

with open("data.json", "r") as f:
    obj = json.load(f)
print(obj)

Advanced JSON Handling

For JSON data containing custom objects, use the object_hook parameter to provide a function that converts decoded dictionaries into Python objects.

Example with custom deserialization:

import json
from datetime import datetime

def custom_deserializer(dct):
    if 'joined' in dct:
        dct['joined'] = datetime.fromisoformat(dct['joined'])
    return dct

json_str = '{"name": "John", "joined": "2021-05-17T10:15:00"}'

obj = json.loads(json_str, object_hook=custom_deserializer)
print(obj)

Output:

{'name': 'John', 'joined': datetime.datetime(2021, 5, 17, 10, 15)}

JSONEncoder and JSONDecoder Classes

The JSONEncoder class serializes Python objects to JSON-formatted strings, supporting types as shown below:

  • Python dict → JSON object
  • Python list, tuple → JSON array
  • Python str → JSON string
  • Python int, float → JSON number
  • Python True → JSON true
  • Python False → JSON false
  • Python None → JSON null

Main methods include encode() and iterencode(), and options to control indentation and sorting keys.

Example using iterencode():

import json

data = ['Rakesh', {'marks': (50, 60, 70)}]
encoder = json.JSONEncoder()

for chunk in encoder.iterencode(data):
    print(chunk)

Output:

["Rakesh", { "marks" : [50, 60, 70]}]

JSONDecoder

The JSONDecoder class decodes JSON strings into Python objects. Main method is decode().

Example:

import json

data = ['Rakesh', {'marks': (50, 60, 70)}]
encoder = json.JSONEncoder()
json_str = encoder.encode(data)

decoder = json.JSONDecoder()
py_obj = decoder.decode(json_str)
print(py_obj, type(py_obj))

Output:

['Rakesh', {'marks': [50, 60, 70]}] <class 'list'>

Core Functions in json Module

  • json.dump(): Serialize Python object to a file-like object.
  • json.dumps(): Serialize to JSON string.
  • json.load(): Deserialize JSON from a file-like object.
  • json.loads(): Deserialize JSON string.

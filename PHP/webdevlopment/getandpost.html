PHP: GET and POST Methods

PHP handles client data submitted via web forms using the HTTP **GET** and **POST** request methods. These methods populate specific **superglobal arrays** in PHP, allowing server-side scripts to access user input.

The GET Method

The GET method sends encoded data appended to the page request URL as a **query string**. The data is visible in the browser's address bar.

  • Access in PHP: Data is accessed via the **$_GET** associative array.
  • Visibility: Data is exposed in the URL (e.g., page.php?name=value).
  • Restrictions: Limited data size (typically under 2048 characters) and cannot be used for binary data.
  • Use Case: Suitable for non-sensitive data, search queries, or bookmarkable links. **Never use for passwords.**

The POST Method

The POST method transfers data via **HTTP headers** in the request body, making the data invisible in the URL. It is the standard method for sending form data.

  • Access in PHP: Data is accessed via the **$_POST** associative array.
  • Restrictions: No practical limit on data size (though server configuration, like post_max_size in `php.ini`, imposes one).
  • Capability: Can send both ASCII and **binary data** (e.g., file uploads).
  • Use Case: Mandatory for sensitive data (passwords, payment info) and when submitting large amounts of data or files.

The $_REQUEST Superglobal

The **$_REQUEST** superglobal is an associative array that contains the contents of $_GET, $_POST, and $_COOKIE. While convenient, it is generally recommended to use $_GET or $_POST directly to explicitly know where the data originated, improving code clarity and security.

File Uploads with POST

To upload files, the form's method must be **POST** and its **enctype** attribute must be set to **multipart/form-data**. File details are accessed via the separate **$_FILES** superglobal array.

Example Session: Accessing POST Data

This example demonstrates how the HTML form's method="POST" populates the PHP $_POST array.


<!-- HTML Form (e.g., hello.html) -->
<form action="hello.php" method="POST">
   First Name: <input type="text" name="first_name"/> <br/>
   Age: <input type="text" name="age" />
   <input type="submit" value="Submit" />
</form>

<?php
   // PHP Script (e.g., hello.php)
   if( isset($_POST["first_name"]) || isset($_POST["age"]) ) {
      $name = htmlspecialchars($_POST['first_name']);
      $age = htmlspecialchars($_POST['age']);
      
      echo "Welcome ". $name. "<br />";
      echo "You are ". $age. " years old.";
   }
?>

JavaScript — Function Parameters

Function Parameters and Arguments

Function parameters in JavaScript are variables listed inside the parentheses of a function definition. Function arguments are the values passed to the function when it is called. A function can have multiple parameters separated by commas.

The number of arguments passed must match the number of parameters, otherwise unexpected results may occur. 

function functionName(parameter1, parameter2, parameter3) {
  // statements
}

Example function call with arguments: 

functionName(10, b, "Hello");

Parameter Rules

  • JavaScript functions don't check the number of arguments.
  • No need to specify data types for parameters.
  • No type-checking is performed on arguments.
  • Arguments can be of any type: numbers, strings, objects, variables.

Example: Function Parameters and Arguments

function mult(a, b, c) {
  let res = a * b * c;
  return res;
}
let ans = mult(2, 3, 4);
document.getElementById("output").innerHTML =
  "The multiplication of 2, 3, and 4 is " + ans;

Output: The multiplication of 2, 3, and 4 is 24

Argument Object

Every JavaScript function has an arguments object, which stores all arguments in an array-like format. This allows access to arguments even if they were not explicitly defined as parameters. 

function merge() {
  let final = "";
  for (let p = 0; p < arguments.length; p++) {
    final += arguments[p] + " ";
  }
  return final;
}
let ans = merge("Hi", "I", "am", "John!");
document.getElementById("output").innerHTML =
  "The merged string is: " + ans;

Output: The merged string is: Hi I am John!

Passing Arguments by Value

When passing arguments by value, the value is copied into the function’s parameter. Changing the parameter does not affect the original argument. 

function update(val1, val2) {
  val1 = 20;
  val2 = 30;
}

var val1 = "Hello";
var val2 = "World";

console.log("Before: val1 = " + val1 + ", val2 = " + val2);
update(val1, val2);
console.log("After: val1 = " + val1 + ", val2 = " + val2);

Output:
Before calling the function: val1 = Hello, val2 = World
After calling the function: val1 = Hello, val2 = World

Passing Arguments by Reference

When passing objects as arguments, the function receives the reference (memory address) of the object. Modifying the object inside the function will also affect it outside the function. 

function update(obj) {
  obj.domain = "www.tutorialspoint.com";
}

var obj = { domain: "www.google.com" };

console.log("Before: domain = " + obj.domain);
update(obj);
console.log("After: domain = " + obj.domain);

Output:
Before calling the function: domain = www.google.com
After calling the function: domain = www.tutorialspoint.com

Key Points

  • Parameters are variables listed in function definitions.
  • Arguments are values passed when calling functions.
  • The arguments object holds all passed arguments.
  • Arguments can be passed by value (primitive types) or reference (objects).

Practice Tasks

  • Create a function with 3 parameters and return their sum.
  • Use the arguments object to find the largest number passed.
  • Demonstrate passing by reference with an object that stores user details.

Summary

JavaScript functions can accept parameters and arguments of any type. They can be handled via explicit parameters or the arguments object. Primitive values are passed by value, while objects are passed by reference, allowing modifications inside functions to persist outside them.

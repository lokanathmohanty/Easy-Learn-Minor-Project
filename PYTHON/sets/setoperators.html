Python - Set Operators

Set operators in Python are symbols and functions that allow performing operations such as union, intersection, difference, and symmetric difference on sets. These operators help combine, compare, and modify sets easily.

Set Union Operator (|)

The union of two sets contains all distinct elements present in either set or both. It can be performed using the | operator or the union() method. 


set1 = {1, 2, 3}
set2 = {3, 4, 5}
set3 = {6, 8, 9}
set4 = {9, 45, 73}

union_set1 = set1.union(set2)
union_set2 = set3 | set4

print('The union of set1 and set2 is', union_set1)
print('The union of set3 and set4 is', union_set2)

Output:

{1, 2, 3, 4, 5}

{73, 6, 8, 9, 45}

Set Intersection Operator (&)

The intersection of two sets contains only the elements common to both sets. It can be performed using the & operator or the intersection() method. 


set1 = {1, 2, 3}
set2 = {3, 4, 5}
set3 = {6, 8, 9}
set4 = {9, 8, 73}

intersection_set1 = set1.intersection(set2)
intersection_set2 = set3 & set4

print('The intersection of set1 and set2 is', intersection_set1)
print('The intersection of set3 and set4 is', intersection_set2)

Output:

{3}

{8, 9}

Set Difference Operator (-)

The difference of two sets contains elements in the first set that are not in the second set. It can be performed using the - operator or the difference() method. 


set1 = {1, 2, 3}
set2 = {3, 4, 5}
set3 = {6, 8, 9}
set4 = {9, 8, 73}

difference_set1 = set1.difference(set2)
difference_set2 = set3 - set4

print('The difference between set1 and set2 is', difference_set1)
print('The difference between set3 and set4 is', difference_set2)

Output:

{1, 2}

{6}

Note: Difference is not commutative, i.e., s1 - s2 is different from s2 - s1.

Set Symmetric Difference Operator (^)

The symmetric difference contains elements that are in either set but not in both. It can be performed using the ^ operator or the symmetric_difference() method. 


set1 = {1, 2, 3}
set2 = {3, 4, 5}
set3 = {6, 8, 9}
set4 = {9, 8, 73}

symmetric_difference_set1 = set1.symmetric_difference(set2)
symmetric_difference_set2 = set3 ^ set4

print('The symmetric difference of set1 and set2 is', symmetric_difference_set1)
print('The symmetric difference of set3 and set4 is', symmetric_difference_set2)

Output:

{1, 2, 4, 5}

{73, 6}

Subset Testing Operation

To check if one set is a subset of another (all elements of the first set present in the second), use the issubset() method or the <= operator. 


set1 = {1, 2}
set2 = {1, 2, 3, 4}
set3 = {64, 47, 245, 48}
set4 = {64, 47, 3}

is_subset1 = set1.issubset(set2)
is_subset2 = set3 <= set4

print('set1 is a subset of set2:', is_subset1)
print('set3 is a subset of set4:', is_subset2)

Output:

set1 is a subset of set2: True

set3 is a subset of set4: False

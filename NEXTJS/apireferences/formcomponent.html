Next.js `<Form>` Component (App Router) 📝

Overview and Purpose

The **`

` component** is an enhanced element in the Next.js **App Router** that wraps the standard HTML ``. It provides advanced features for handling form submissions, particularly those involving **URL search parameters** or **Server Actions**. Its main benefits are: client-side navigation on submission, prefetching the target route, and providing progressive enhancement for form handling.

Basic Syntax

import Form from 'next/form' // Note: Ensure this import is correct based on your Next.js version (usually imported from 'next/experimental/form-actions' or similar experimental path if not natively exposed)

export default function Page() {
  return (
    <Form action="/submit-page"> 
        <!-- Form Elements -->
        <input type="text" name="name" />
        <button type="submit">Submit</button>
    </Form>
  )}

Key Props and Behavior

Prop Type Description
`action` `string` or `function` The URL to **navigate** to, or the **Server Action** function to execute upon submission. If a string, form data is encoded as URL search parameters (GET method).
`replace` `boolean` If `true`, the new submission URL **replaces** the current history entry, preventing the user from navigating back to the form page. (Valid when `action` is a string/URL).
`scroll` `boolean` If `false`, it **prevents the page from scrolling to the top** after a successful form submission and client-side navigation.
`prefetch` `boolean` If `true`, the target submission route is **prefetched** when the form comes into the viewport, making the subsequent navigation nearly instantaneous. (Valid when `action` is a string/URL).

Example: Using `action` for Navigation

Submitting this form navigates to the `/form-submission` route with the form data appended as query parameters (e.g., `/form-submission?name=...`).

<Form action="/form-submission" > 
    <input type="text" name="name" />
    <button type="submit">Submit</button>
</Form>

Example: Preventing History Back with `replace`

Using `replace` set to `true` ensures that the browser history stack is overwritten, effectively preventing the "back" button from returning to the form page after submission.

<Form action="/form-submission" replace>
    ...
</Form>

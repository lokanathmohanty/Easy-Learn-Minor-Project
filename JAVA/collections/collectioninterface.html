Collection Interface in Java

Content

The Collection interface is the root interface in the Java Collections Framework. It defines core methods that all collections implement for managing groups of objects.

Key methods include adding and removing elements, checking if elements exist, obtaining the size, and clearing the collection.

  • add(Object obj) - Adds an element to the collection.
  • remove(Object obj) - Removes an element from the collection.
  • contains(Object obj) - Checks if an element exists in the collection.
  • size() - Returns the number of elements.
  • clear() - Removes all elements.
  • iterator() - Returns an iterator over the elements.

These methods provide a unified way to interact with different types of collections like lists, sets, and queues.

Example

Here is a simple Java example demonstrating the use of the Collection interface methods with an ArrayList:


import java.util.*;

public class CollectionExample {
    public static void main(String[] args) {
        Collection collection = new ArrayList<>();
        collection.add("Apple");
        collection.add("Banana");
        collection.add("Cherry");

        System.out.println("Size: " + collection.size());
        System.out.println("Contains 'Banana': " + collection.contains("Banana"));

        collection.remove("Banana");
        System.out.println("After removal: " + collection);

        collection.clear();
        System.out.println("Is empty: " + collection.isEmpty());
    }
}

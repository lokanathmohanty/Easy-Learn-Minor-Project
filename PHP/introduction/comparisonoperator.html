PHP Comparison Operators Examples

**Comparison Operators** in PHP are used to compare two operands and determine their relationship. They always return a **Boolean** value (`true` or `false`). These operators are essential for conditional statements and decision-making logic.

Standard Comparison Operators

Operator Name Description
== Equal Checks for **equal value** (Type coercion is allowed).
!= or <> Not Equal Checks for **unequal value** (Type coercion is allowed).
> Greater Than Left operand is strictly greater than right.
< Less Than Left operand is strictly less than right.
>= Greater Than or Equal To Checks if the left operand is greater than or equal to the right.
<= Less Than or Equal To Checks if the left operand is less than or equal to the right.

Strict vs. Loose Comparison

PHP provides "strict" comparison operators that check both **value AND data type**, preventing PHP's automatic type coercion.

1. Equality (`==`) vs. Identity (`===`)

  • **`==` (Equal):** Checks only if the **values** are the same. If types differ, PHP converts one to match the other before comparing.
    $x = 15; $y = "15";
    $x == $y $\rightarrow$ true (Value is equal)
  • **`===` (Identical):** Checks if both the **value** AND the **data type** are the same. No type conversion occurs.
    $x = 15; $y = "15";
    $x === $y $\rightarrow$ false (Integer is not identical to String)

2. Inequality (`!=`) vs. Non-Identity (`!==`)

The same principle applies to negative comparisons. `!==` is generally safer for robust type checking.

$p = 50; $q = "50";
$p != $q $\rightarrow$ false (Value is equal)
$p !== $q $\rightarrow$ true (Types are different)

The Spaceship Operator (`<=>`)

Introduced in PHP 7, the **Spaceship Operator** is a three-way comparison operator that returns an integer indicating the relationship between the two operands.

  • **Returns `-1`:** If the left operand is **less than** the right.
  • **Returns `0`:** If the operands are **equal**.
  • **Returns `1`:** If the left operand is **greater than** the right.
5 <=> 10 $\rightarrow$ -1
20 <=> 10 $\rightarrow$ 1
10 <=> 10 $\rightarrow$ 0

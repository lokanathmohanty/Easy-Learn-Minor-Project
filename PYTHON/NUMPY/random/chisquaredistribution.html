Chi Square Distribution

The Chi Square Distribution is commonly used as a basis to verify hypotheses in statistics.

Parameters:

  • df — Degrees of freedom.
  • size — The shape of the returned array.

Example: Generating Chi Square Distribution Samples

Generate a 2x3 sample from a chi square distribution with 2 degrees of freedom:

from numpy import random

x = random.chisquare(df=2, size=(2, 3))

print(x)

Visualization of Chi Square Distribution

Visualize 1000 samples from a chi square distribution with 1 degree of freedom using Seaborn:

from numpy import random
import matplotlib.pyplot as plt
import seaborn as sns

sns.displot(random.chisquare(df=1, size=1000), kind="kde")

plt.show()

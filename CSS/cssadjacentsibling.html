Introduction to HTML

What is HTML?

HTML (HyperText Markup Language) is the standard language used to create and structure content on the web. It provides the foundation for web pages by defining elements such as headings, paragraphs, lists, links, images, and more.

Browsers read HTML documents and render them into visible or audible web pages. HTML elements are represented by tags, and these tags tell the browser how to display the content.

Basic Structure of an HTML Document

Every HTML document follows a basic structure which includes the document type declaration, the <html> element, a head section, and a body section.

Example

The following code shows a simple HTML document with a heading and a paragraph:

<!DOCTYPE html>

<html lang="en">

<head>

  <title>My First Page</title>

</head>

<body>

  <h1>Hello, World!</h1>

  <p>This is my first web page.</p>

</body>

</html>

Key Features of HTML

  • HTML is platform-independent and works on all browsers.
  • It provides a way to structure and present content on the web.
  • HTML is often used with CSS and JavaScript to create dynamic, interactive websites.
  • It supports multimedia elements like images, audio, and video.

Practice

  • Add a list of your three favorite hobbies using the <ul> tag.
  • Insert a link to your favorite website using the <a> tag.

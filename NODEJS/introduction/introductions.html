Node.js: Introduction and Features

What is Node.js?

Node.js is a cross-platform, open-source JavaScript runtime environment built on Chrome's V8 engine. It enables developers to execute JavaScript code outside of a browser, primarily for server-side development.

  • Event-driven and non-blocking I/O model
  • High scalability with single-threaded architecture
  • Fast execution powered by the V8 engine
  • Open-source and supported by a large community

Typical Node.js Use Cases

  • I/O bound applications
  • Streaming applications
  • Real-time chat and data applications
  • JSON API-based applications
  • Single Page Applications (SPAs)

Example: Basic HTTP Server in Node.js

Below is an example showing how to create a simple HTTP server using Node.js. The server will respond with a "Hello, world!" message when accessed. 


const http = require('http');

const server = http.createServer((req, res) => {
  res.writeHead(200, {'Content-Type': 'text/plain'});
  res.end('Hello, world!');
});

server.listen(3000, () => {
  console.log('Server is running on port 3000');
});
  • Save the code in a file named server.js.
  • Run it using node server.js from your command line.
  • Access http://localhost:3000/ in your browser to view the output.

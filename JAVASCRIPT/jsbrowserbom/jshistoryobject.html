JavaScript - History Object

Window History Object

In JavaScript, the history object contains information about the browser's session history. It keeps track of the array of visited URLs in the current session.

The history object is a property of the window object and can be accessed with or without referencing window.

History Object Methods

The history object provides useful methods that allow us to navigate back and forth in the browser’s session history.

Syntax:

  • window.history.methodName();
  • history.methodName();

JavaScript back() Method

The back() method loads the previous URL in the session history.

Syntax:

history.back();

Example:

<html>
<body>
   <p>Click "Go Back" button to load previous URL</p>
   <button onclick="goback()">Go Back</button>
   <p id="output"></p>
   <script>
      function goback() {
         history.back();
         document.getElementById("output").innerHTML +=
            "You will have gone to previous URL if it exists";
      }
   </script>
</body>
</html>

JavaScript forward() Method

The forward() method loads the next URL in the session history.

Syntax:

history.forward();

Example:

<html>
<body>
   <p>Click "Go Forward" button to load next URL</p>    
   <button onclick="goforward()">Go Forward</button>
   <p id="output"></p>
   <script>
      function goforward() {
         history.forward();
         document.getElementById("output").innerHTML =
            "You will have forwarded to next URL if it exists.";
      }
   </script>
</body>
</html>

JavaScript go() Method

The go() method loads a specific URL from the session history. The count parameter is a numeric value that represents which page to visit.

Syntax:

history.go(count);

Example 1: Move to 2nd previous page

<html>
<body>
   <p>Click the button to load 2nd previous URL</p>
   <button onclick="moveTo()">Move at 2nd previous URL</button>
   <p id="output"></p>
   <script>
      function moveTo() {
         history.go(-2);
         document.getElementById("output").innerHTML =
            "You will have moved to 2nd previous URL if it exists.";
      }
   </script>
</body>
</html>

Example 2: Move to 2nd next page

<html>
<body>
   <p>Click the button to load 2nd next URL</p>    
   <button onclick="moveTo()">Move at 2nd next URL</button>
   <p id="output"></p>
   <script>
      function moveTo() {
         history.go(2);
         document.getElementById("output").innerHTML =
            "You will have moved to 2nd next URL if it exists.";
      }
   </script>
</body>
</html>

History Object Properties

  • length – Returns the number of URLs in the session history list.

History Object Methods

  • back() – Takes you to the previous page.
  • forward() – Takes you to the next page.
  • go() – Takes you to a specific page in history.

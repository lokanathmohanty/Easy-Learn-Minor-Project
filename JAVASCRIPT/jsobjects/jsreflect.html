JavaScript - The Reflect Object

In JavaScript, Reflect is a global object introduced in ES6. It contains static methods that provide a cleaner and safer way to interact with objects at runtime.

Unlike most global objects, Reflect is not a constructor. You cannot use it with new or call it as a function. All methods are static, similar to the Math object.

Reflect methods allow you to access, update, and delete properties of objects at runtime.

Key Features

  • Object construction – create objects dynamically using Reflect.construct().
  • Function invocation – invoke functions with Reflect.apply().
  • Property manipulation – get, set, update, or delete properties safely.

Syntax

Reflect.method()

Replace method with any Reflect method, such as get, set, apply, construct, has, etc.

Reflect Methods

  • apply() – invokes a function.
  • construct() – creates an object with a specific prototype.
  • defineProperty() – adds or edits a property.
  • deleteProperty() – deletes a property.
  • get() – retrieves a property value.
  • getOwnPropertyDescriptor() – gets a property descriptor.
  • getPrototypeOf() – retrieves the prototype of an object.
  • has() – checks if a property exists.
  • isExtensible() – checks if an object is extensible.
  • ownKeys() – returns an object’s own keys (ignores inherited).
  • preventExtensions() – prevents object extension.
  • set() – sets a property value.
  • setPrototypeOf() – sets or removes an object’s prototype.

Examples

Example 1: Using Reflect.get()

<html>
<body>
   <div id="output">The model of the car is: </div>
   <script>
      const car = { name: "Audi", model: "Q6", price: 7000000 };
      let prop = "model";
      let model = Reflect.get(car, prop);
      document.getElementById("output").innerHTML += model;
   </script>
</body>
</html>

Output: The model of the car is: Q6

Example 2: Using Reflect.set()

<html>
<body>
   <div id="output">The total doors in the Audi Q6 is: </div>
   <script>
      const car = { name: "Audi", model: "Q6", price: 7000000 };
      Reflect.set(car, "doors", 4);
      document.getElementById("output").innerHTML += car.doors;
   </script>
</body>
</html>

Output: The total doors in the Audi Q6 is: 4

Example 3: Using Reflect.has()

<html>
<body>
   <p id="output"></p>
   <script>
      const car = { name: "Audi", model: "Q6", price: 7000000 };
      const isName = Reflect.has(car, "name");
      if (isName) {
         document.getElementById("output").innerHTML =
           "The Car object contains the name.";
      }
   </script>
</body>
</html>

Output: The Car object contains the name.

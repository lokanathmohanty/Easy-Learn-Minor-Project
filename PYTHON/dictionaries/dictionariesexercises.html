Python Dictionary Exercises

Exercise 1: Create New Dictionary from Keys

d1 = {"one":11, "two":22, "three":33, "four":44, "five":55}
keys = ['two', 'five']
d2 = {}
for k in keys:
  d2[k] = d1[k]
print(d2)

Output:

{'two': 22, 'five': 55}

Exercise 2: Convert Dictionary to List of (key, value) Tuples

d1 = {"one":11, "two":22, "three":33, "four":44, "five":55}
L1 = list(d1.items())
print(L1)

Output:

[('one', 11), ('two', 22), ('three', 33), ('four', 44), ('five', 55)]

Exercise 3: Remove Keys with Duplicate Values

d1 = {"one":"eleven", "2":2, "three":3, "11":"eleven", "four":44, "two":2}
vals = list(d1.values())  # all values
uvals = [v for v in vals if vals.count(v) == 1]  # unique values
d2 = {}
for k, v in d1.items():
  if v in uvals:
    d2[k] = v
print("dict with unique value:", d2)

Output:

dict with unique value: {'three': 3, 'four': 44}

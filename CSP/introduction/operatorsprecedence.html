C# Operator Precedence and Associativity

Understanding Operator Precedence

Operator Precedence determines the **grouping of terms** in an expression, which directly affects the order in which operations are evaluated. Operators with a **higher precedence** are always evaluated before operators with a lower precedence.

For example, in the expression x = 7 + 3 * 2, multiplication (*) has higher precedence than addition (+), so (3 * 2) is calculated first, resulting in $7 + 6 = 13$.

Key Precedence Levels:

  • Highest: Parentheses (()), Indexing ([]), Member Access (.)
  • High: Unary Operators (++, --, !)
  • Medium: Multiplicative (*, /, %)
  • Lower Medium: Additive (+, -)
  • Low: Relational/Equality (<, >, ==, !=)
  • Lowest: Assignment (=, +=, -=, etc.) and Comma (,)

Operator Associativity

Associativity defines the execution order when an expression contains **multiple operators of the same precedence**.

  • Left to Right: Operations are grouped from the left. Most arithmetic, relational, and logical operators (e.g., *, /, +, -) are left-associative. Example: a - b + c is evaluated as (a - b) + c.
  • Right to Left: Operations are grouped from the right. Unary, assignment (=, +=), and the conditional (? :) operators are right-associative. Example: a = b = c is evaluated as a = (b = c).

Example: Using Parentheses to Control Order

Parentheses **override** default operator precedence, ensuring the enclosed expression is evaluated first.

Default Precedence:

int result = 10 + 5 * 2; // (5 * 2) is done first.
Console.WriteLine("Result: " + result); // Output: 20

Overriding with Parentheses:

int result = (10 + 5) * 2; // (10 + 5) is done first.
Console.WriteLine("Result: " + result); // Output: 30

Assignment Associativity:

int a, b, c;
a = b = c = 10; // Evaluated as a = (b = (c = 10)); Right-to-Left

Console.WriteLine("a: 10, b: 10, c: 10");

HTML - Drag and Drop API

The Drag and Drop (DnD) API provides native support for dragging elements with the mouse and dropping them into targets. This makes it easier to copy, reorder, or delete items without complex JavaScript or external libraries.

Most modern browsers support the HTML5 Drag and Drop API, including Chrome, Firefox, and Safari.

Creating a Draggable Element

To make an element draggable, set the draggable attribute to true:

<div draggable="true"> ... </div>

Drag and Drop Events

  • dragstart – Fires when the user starts dragging an element.
  • dragenter – Fires when the mouse enters a valid drop target.
  • dragover – Fires repeatedly as the element is dragged over a drop target.
  • dragleave – Fires when the mouse leaves a drop target.
  • drag – Fires continuously while dragging.
  • drop – Fires when the element is dropped.
  • dragend – Fires when the drag operation is finished.

Note: Only drag events fire during a drag operation, not regular mouse events.

The DataTransfer Object

The dataTransfer object is used to hold data about the drag-and-drop operation. It can set, retrieve, and clear data:

  • dataTransfer.setData(format, data) – Stores data in a given format.
  • dataTransfer.getData(format) – Retrieves stored data.
  • dataTransfer.clearData() – Clears stored data.
  • dataTransfer.dropEffect – Defines the type of drop (copy, move, link, none).
  • dataTransfer.effectAllowed – Defines allowed drag operations.
  • dataTransfer.files – Accesses files being dragged.
  • dataTransfer.setDragImage() – Sets a custom drag image.

Drag and Drop Process

The process of drag and drop typically includes:

  • Make an element draggable with draggable="true".
  • Use dragstart to store the data being dragged.
  • Set listeners for dragenter, dragover, and drop on the drop target.

Example – Making an Object Draggable

This example shows how to drag a purple box:

<div id="boxA" draggable="true" ondragstart="return dragStart(event)">Drag Me</div>

function dragStart(ev) {
  ev.dataTransfer.effectAllowed = 'move';
  ev.dataTransfer.setData("Text", ev.target.id);
  return true;
}

Example – Dropping the Object

This example shows dropping the purple box into the pink box:

<div id="boxB" ondragenter="return dragEnter(event)"
  ondragover="return dragOver(event)"
  ondrop="return dragDrop(event)">Drop Here</div>

function dragEnter(ev) {
  ev.preventDefault();
  return true;
}

function dragOver(ev) {
  return false;
}

function dragDrop(ev) {
  var src = ev.dataTransfer.getData("Text");
  ev.target.appendChild(document.getElementById(src));
  ev.stopPropagation();
  return false;
}

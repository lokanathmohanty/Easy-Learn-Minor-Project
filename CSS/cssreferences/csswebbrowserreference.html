CSS Browser Support Reference

This session provides a reference for CSS properties and their browser support across Chrome, Edge, Firefox, Safari, and Opera. It helps developers check compatibility before using a property in their projects.

Why Browser Support Matters?

Different browsers may implement CSS properties at different times. Knowing the support level ensures consistent design and avoids unexpected issues.

Examples of Property Support

  • aspect-ratio: Supported from Chrome 88, Edge 89, Firefox 88, Safari 15, Opera 74.
  • backdrop-filter: Supported from Chrome 79, Edge 103, Firefox 76, Safari 9, Opera 63.
  • text-decoration-thickness: Supported from Chrome 89, Edge 70, Firefox 89, Safari 12.1, Opera 75.

Best Practices

  • Check your target audience’s browsers before using advanced properties.
  • Use progressive enhancement to ensure fallback designs work in older browsers.
  • Apply @supports rules to conditionally use modern features.

Example with @supports

Below is an example of using @supports to safely apply a new property:

Example

@supports (aspect-ratio: 1/1) {
  .box {
    aspect-ratio: 1/1;
  }
}

Miscellaneous Operators in C

C includes several other important operators besides the main categories like arithmetic, logical, and assignment. These include the address-of operator (&), dereference operator (*), sizeof, conditional (ternary) operator (?:), member access operator (.), and struct pointer operator (->).

sizeof Operator

This compile-time unary operator returns the size in bytes of a data type or variable. It varies by machine architecture.

#include <stdio.h>

int main(){
   int a = 16;
   printf("Size of variable a : %d\n", sizeof(a));
   printf("Size of int data type : %d\n", sizeof(int));
   printf("Size of char data type : %d\n", sizeof(char));
   printf("Size of float data type : %d\n", sizeof(float));
   printf("Size of double data type : %d\n", sizeof(double));   
   return 0;
}

Output example:

Size of variable a: 4
Size of int data type: 4
Size of char data type: 1
Size of float data type: 4
Size of double data type: 8

Address-of Operator (&)

Returns the memory address of a variable, which can be assigned to a pointer.

#include <stdio.h>

int main(){
   int var = 100;
   printf("var: %d address: %d", var, &var);
   return 0;
}

Dereference Operator (*)

Declares pointers and accesses the value stored in the address they point to. Pointer and variable types must match.

#include <stdio.h>

int main(){
   float var1 = 10.55;
   float *floatptr = &var1;

   printf("var1: %f\naddress of var1: %d\n\nfloatptr: %d\naddress of floatptr: %d", var1, &var1, floatptr, &floatptr);

   printf("Value at floatptr: %f", *floatptr);
   return 0;
}

Ternary Operator (?:)

A conditional operator with three operands, condenses if-else conditions.

#include <stdio.h>

int main(){
   int a = 10;
   (a % 2 == 0) ? printf("%d is Even\n", a) : printf("%d is Odd\n", a);
   return 0;
}

Member Access Operator (.)

Used to access members of a struct or union variable.

#include <stdio.h>

struct book {
   char title[10];
   double price;
   int pages;
};

int main(){
   struct book b1 = {"Learn C", 675.50, 325};
   printf("Title: %s\n", b1.title);
   printf("Price: %lf\n", b1.price);
   printf("No of Pages: %d\n", b1.pages);
   return 0;
}

Indirection Operator (->)

Used to access members of a struct through a pointer.

#include <stdio.h>

struct book {
   char title[10];
   double price;
   int pages;
};

int main(){
   struct book b1 = {"Learn C", 675.50, 325};
   struct book *strptr = &b1;
   printf("Title: %s\n", strptr->title);
   printf("Price: %lf\n", strptr->price);
   printf("No of Pages: %d\n", strptr->pages);
   return 0;
}

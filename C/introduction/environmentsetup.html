C - Environment Setup

To begin programming in C, you need an environment where you can write, compile, and run your C programs. This includes:

  • A C Compiler
  • A Text Editor

The C Compiler

C source code is human-readable, but it must be compiled into machine language before it can be executed by your CPU. Popular C compilers include:

  • GCC (GNU Compiler Collection): Open-source and supports many platforms (Windows, macOS, Linux).
  • Clang: Part of the LLVM project, known for speed and optimizations.
  • Microsoft Visual C++: Proprietary compiler for Windows, integrated with Visual Studio.
  • Turbo C: Discontinued, once popular in the 1990s.

This tutorial uses the GCC compiler, which works for both C and C++ programming languages.

Installing GCC

On UNIX/Linux

Check if GCC is installed:

$ gcc -v

If installed, you'll see output similar to:

gcc version 11.3.0 (Ubuntu 11.3.0-1ubuntu1~22.04)

If not installed, visit https://gcc.gnu.org/install/ for instructions.

On macOS

Install Xcode from Apple’s developer website. Xcode includes GCC and other development tools.

Download from: developer.apple.com/technologies/tools/

On Windows

Install MinGW:

  1. Go to MinGW Downloads.
  2. Download mingw-w64-install.exe.
  3. During setup, install at minimum:
    • gcc-core
    • gcc-g++
    • binutils
    • MinGW runtime
  4. Add the bin folder of MinGW to your PATH environment variable.

After installation, you can run tools like gcc, g++, ar, etc., from the command line.

Text Editor

To write C code, use any text editor such as:

  • Notepad (Windows)
  • vi or vim (Linux/UNIX/Windows)
  • EMACS, Brief, Epsilon

Source files should be saved with a .c extension (e.g., hello.c).

Using the Command Line

After writing your code, you can compile and run it from the terminal or command prompt. Example:

gcc -c hello.c -o hello.o
gcc -o hello.exe hello.o
./hello.exe

If your code has errors, you'll need to go back and edit, then compile again.

Using an IDE

To avoid the repetitive edit-compile-run cycle manually, use an IDE (Integrated Development Environment). IDEs allow you to:

  • Edit, compile, debug, and run code in one interface
  • Get real-time syntax highlighting and error detection

Popular IDEs for C include:

  • Code::Blocks
  • NetBeans
  • VS Code

Installing Code::Blocks on Windows

  1. Download codeblocks-20.03mingw-setup.exe from: Code::Blocks Binaries
  2. During installation, select MinGW as the compiler.
  3. Launch Code::Blocks and create a new project or file.

Example Program

#include <stdio.h>

int main() {
   /* my first program in C */
   printf("Hello, World! \n");

   return 0;
}

Output:

Hello, World!

Build and run the code using the Build menu or F9 shortcut. The output will appear in the terminal window.

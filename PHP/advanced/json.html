PHP JSON Processing

**JSON (JavaScript Object Notation)** is a lightweight, text-based, language-independent data interchange format. PHP includes native support for JSON through the built-in **JSON extension** (enabled by default since PHP 5.2), providing functions to efficiently convert between PHP values and JSON strings.

PHP JSON Encoding and Decoding Functions

1. $\text{json\_encode()}$

Converts a **PHP value** (e.g., array, object) into its **JSON string representation**. It serializes arrays and objects recursively.

json_encode(mixed $value, int $flags = 0, int $depth = 512): string|false

Example: An associative array $\text{array('a' => 1, 'b' => 2)}$ becomes the JSON string $\text{"\{\"a\":1,\"b\":2\}"}$.

2. $\text{json\_decode()}$

Takes a **JSON encoded string** and converts it into a **PHP value** (an array or a generic object).

json_decode(string $json, ?bool $associative = null, int $depth = 512, int $flags = 0): mixed
  • If the optional $\text{\$associative}$ parameter is set to **$\text{true}$**, JSON objects are returned as **associative arrays** ($\text{array}$).
  • If $\text{\$associative}$ is set to **$\text{false}$** (the default behavior), JSON objects are returned as **objects** ($\text{stdClass}$).

JSON Error Handling

After calling $\text{json\_encode()}$ or $\text{json\_decode()}$, it is crucial to check for errors, especially when decoding external data.

$\text{json\_last\_error()}$

Returns an **integer** constant indicating the type of error that occurred during the last JSON operation. $\text{JSON\_ERROR\_NONE}$ (0) indicates success.

$\text{json\_last\_error\_msg()}$

Returns the corresponding **string message** for the last error (e.g., "No error", "Syntax error", "Malformed UTF-8 characters").

Common Error Constants:

  • $\text{JSON\_ERROR\_NONE}$: No error.
  • $\text{JSON\_ERROR\_SYNTAX}$: Invalid JSON format.
  • $\text{JSON\_ERROR\_CTRL\_CHAR}$: Control character error.
  • $\text{JSON\_ERROR\_RECURSION}$: Found one or more recursive references during encoding.

JSON Flags ($\text{\$flags}$)

Flags are optional bitmasks that modify the behavior of $\text{json\_encode()}$ or $\text{json\_decode()}$.

Constant Description Use
$\text{JSON\_PRETTY\_PRINT}$ Formats the JSON string with indentation and newlines, making it human-readable. $\text{json\_encode()}$
$\text{JSON\_UNESCAPED\_SLASHES}$ Prevents forward slashes ($\text{/}$) from being escaped ($\text{\/}$). Useful for URLs. $\text{json\_encode()}$
$\text{JSON\_FORCE\_OBJECT}$ Ensures that an empty array or numerically indexed non-empty array is encoded as a JSON object ($\text{\{\}}$), not a JSON array ($\text{[]}$). $\text{json\_encode()}$
$\text{JSON\_HEX\_TAG}$ Encodes HTML tags ($\text{<}$ and $\text{>}$) to their hexadecimal representations. $\text{json\_encode()}$

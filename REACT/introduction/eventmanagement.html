ReactJS - Event Management

Events are actions performed by a user to interact with an application. They can be small actions like hovering a mouse pointer on an element, resizing an application window, or dragging and dropping elements to upload files. Events in React are divided into three categories:

  • Mouse Events − onClick, onDrag, onDoubleClick
  • Keyboard Events − onKeyDown, onKeyPress, onKeyUp
  • Focus Events − onFocus, onBlur

For each event, JavaScript provides responses using Event Handlers. Event Management is the process of working with events using these handlers.

Event Management in ReactJS

Event management enables the user to interact with a web application. React supports all events available in web applications, and event handling is similar to DOM events with small changes. Some examples include:

  • Clicking on a component
  • Scrolling the page
  • Hovering over elements
  • Submitting a form
  • Redirecting to another page
  • Loading images

Synthetic React Events

React uses SyntheticEvent, a cross-browser wrapper for native events. This ensures events work identically across all browsers. Each synthetic event has attributes like:

  • bubbles, cancelable, isTrusted
  • currentTarget, target, nativeEvent
  • preventDefault(), stopPropagation(), persist()
  • timeStamp, type

Since synthetic events are reused, their properties become null after the event callback is executed.

Adding an Event

React events are defined using camelCase and written inside curly braces. The syntax differs for functional and class components:

  • Functional Component: onClick = {"{action}"}
  • Class Component: onClick = {"{this.action}"}

Handling an Event

Steps to handle an event:

  • Define an event handler method.
  • Use console.log() or any action inside the handler.

Example handler:

log() { console.log("Event is fired"); }

Or with lambda syntax:

log = () => { console.log("Event is fired"); }

Passing Arguments to Event Handler

Two methods are available:

  • Arrow Method: Pass e for event target details or add extra arguments before e.
  • Bind Method: Bind the event handler in the constructor to ensure this is available.

Example using bind in constructor:

this.logContent = this.logContent.bind(this);

Setting handler in JSX:

  • <div onClick={"{this.log}"}> ... </div>
  • <div onClick={"{this.log.bind(this, extra)}"}> ... </div>

Summary

  • Events allow users to interact with React apps.
  • React uses SyntheticEvent for cross-browser compatibility.
  • Event handlers can be written with arrow functions or bound in the constructor.
  • Arguments can be passed using arrow or bind methods.

ReactJS - Map

JavaScript Array datatype provides a range of easy-to-use functions to manipulate arrays. One of them is the map() function, which accepts a transform function and creates a new array by applying the transform to each element.

map() Function

The signature of the map function is:

array.map(function(item, index, items), thisValue)

Where:

  • currentValue – the current element’s value
  • index – the index of the current element
  • items – the whole array
  • thisValue – optional value to use as this

Example

Doubling each number in an array using map():

var numbers = [2, 4, 6]
var transformed = numbers.map((val) => val + val)
for (var item of transformed) { console.log(item) }

Output:

4
8
12

React Example

Let us create a React component to display expenses using map().

ExpenseListUsingForLoop.js

import React from 'react'
class ExpenseListUsingForLoop extends React.Component {
   getTotalExpenses() {
      var items = this.props['expenses'];
      var total = 0;
      for (let i = 0; i < items.length; i++) {
         total += parseInt(items[i]);
      }
      return total;
   }
   render() {
      var items = this.props['expenses'];
      var expenses = items.map((item, idx) => 
         <tr><td>item {idx + 1}</td><td>{item}</td></tr>
      );
      var total = this.getTotalExpenses();
      return <table>
         <thead>
            <tr><th>Item</th><th>Amount</th></tr>
         </thead>
         <tbody>{expenses}</tbody>
         <tfoot>
            <tr><th>Sum</th><th>{total}</th></tr>
         </tfoot>
      </table>
   }
}
export default ExpenseListUsingForLoop

App.js

import ExpenseListUsingForLoop from './components/ExpenseListUsingForLoop';
import './App.css';

function App() {
   var expenses = [100, 200, 300]
   return (
      <div>
         <ExpenseListUsingForLoop expenses={expenses} />
      </div>
   );
}
export default App;

Map in JSX

Since map() is a JavaScript expression, it can be used directly inside JSX:

render() {
   var items = this.props['expenses'];
   var total = this.getTotalExpenses();
   return <table>
      <thead>
         <tr><th>Item</th><th>Amount</th></tr>
      </thead>
      <tbody>
         {items.map((item, idx) => 
            <tr><td>item {idx + 1}</td><td>{item}</td></tr>
         )}
      </tbody>
      <tfoot>
         <tr><th>Sum</th><th>{total}</th></tr>
      </tfoot>
   </table>
}

Summary

The map() function is a concise and powerful way to transform arrays in JavaScript and React. In JSX, map() can be directly embedded to dynamically render elements, such as lists or tables.

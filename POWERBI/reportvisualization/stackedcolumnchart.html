A Stacked Column Chart displays data values as vertically stacked rectangles, where each segment represents a part of the whole. It helps distinguish portions of totals across categories.

How to Generate a Stacked Column Chart?

  1. Import the dataset from D:\Dataset_excel\sl.xlsx into Power BI Desktop. Select the Stacked Column Chart from the Visualizations pane.
  2. Place the Country field in the X-axis and the remaining fields in the Y-axis.
  3. To split the visual into smaller charts for each country, add the Country field to the Small multiples section.
  4. To display detailed information (e.g., Sum of Sales Production in 2023) when hovering, add the field to the Tooltips section.

How to Format a Stacked Column Chart?

Click on Format Visual to enhance the chart appearance. Below are various formatting options:

Step 1: Format X-axis

  • Expand the X-axis section.
  • Under Values, set Font to Tahoma, Font size to 16, style to Italic, and choose a color.

Step 2: Format Y-axis

  • Expand the Y-axis section and set the Range with Minimum and Maximum values.
  • Enable Logarithmic scale and Invert range.
  • Under Values, set Font to Georgia, Font size to 17, and apply styling and color.

Step 3: Modify Y-axis Title

  • Expand the Title subsection.
  • Change Style to Show unit only.
  • Set Font to Courier New, Font size to 14, and apply pink color.

Step 4: Customize Legend

  • To hide the legend, turn off the Legend toggle.
  • Expand Options to change position (e.g., Top right Stacked).
  • Modify legend text font, size, and color.

Step 5: Adjust Gridlines

  • Expand Gridlines.
  • Choose Solid for Horizontal lines, set color, and width to 2px.

Step 6: Change Column Colors

  • Expand the Columns section.
  • Select a field (e.g., Sum of Sales Production in 2021) and choose a new color.

Step 7: Enable Data Labels

  • Turn on Data labels and select All under Series.
  • Change orientation to Vertical to avoid overlap.

Step 8: Show Total Labels

  • Enable Total labels.
  • Customize font and background color under Values and Background sections.

Step 9: Adjust Visual Size

  • Go to the General tab to set height and width of the visual.

Step 10: Hide Title

  • Turn off the Title toggle to remove the chart title.
  • Expand Title section to adjust settings like Subtitle, Divider, and Spacing.

Step 11: Change Canvas Background

  • Expand the Effects section.
  • Under Background, select a new background color for the canvas.

Step 12: Format Tooltips

  • Tooltips include Options, Text, and Background.
  • To change tooltip background, expand Background and choose a color.

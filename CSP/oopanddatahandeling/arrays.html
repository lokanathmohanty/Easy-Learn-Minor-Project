C# Arrays

Introduction to Arrays

An **array** is a data structure that stores a **fixed-size sequential collection of elements of the same data type**. Arrays allow you to group related variables under a single name, accessing individual elements using an **index**.

  • Arrays are stored at **contiguous memory locations**.
  • In C#, arrays are **reference types** (objects), even when they hold value types like integers.
  • Array indexing starts at **0** (the first element).

Declaration and Initialization

Declaration Syntax:

Specify the data type, followed by square brackets, and the array name:

datatype[] arrayName; 
// Example: double[] balance;

Initialization (Memory Allocation):

Since arrays are reference types, the new keyword is used to allocate memory based on the specified size.

double[] balance = new double[10]; // Allocates memory for 10 doubles

Initialization with Values:

You can initialize and assign values during declaration:

// Declare size implicitly based on initializer list
int[] marks = new int[] { 99, 98, 92, 97, 95 }; 

// Simplest form of declaration and initialization
double[] balance = { 2340.0, 4523.69, 3421.0 };

Accessing and Iterating Elements

Accessing by Index:

Access individual elements using the array name and the index enclosed in square brackets.

// Accessing the element at index 9 (the 10th element)
double salary = balance[9];

Iterating with `for` Loop:

The `for` loop is commonly used when you need access to the index:

for (int j = 0; j < n.Length; j++) {
   Console.WriteLine("Element[{0}] = {1}", j, n[j]);
}

Iterating with `foreach` Loop:

The `foreach` loop provides a simpler, read-only iteration over all elements without manual index management:

foreach (int value in n) {
   Console.WriteLine("Value: {0}", value);
}

Array Properties and Methods

`Length` Property:

Returns the total number of elements in the array (read-only).

int[] numbers = { 10, 20, 30, 40, 50 };
int length = numbers.Length; // length will be 5

Sorting an Array (`Array.Sort`):

The static Array.Sort() method sorts array elements in **ascending** order in-place.

int[] numbers = { 50, 20, 40, 10, 30 };
Array.Sort(numbers); 
// numbers is now: { 10, 20, 30, 40, 50 }

Descending Sort:

Achieved by sorting first, then reversing the order.

Array.Sort(numbers);
Array.Reverse(numbers);
// numbers is now: { 50, 40, 30, 20, 10 }

Copying an Array:

Copying an array variable (e.g., int[] score = marks;) only copies the reference, meaning both variables point to the same memory. To create a true, independent copy:

  • `Array.Copy()`: Copies a range of elements to another array.
  • `Array.Clone()`: Creates a shallow copy of the entire array. 
    int[] clonedArray = (int[])sourceArray.Clone();

Advanced Array Concepts

  • Multi-dimensional arrays: Arrays with more than one dimension, typically used for tables or grids (e.g., int[,] matrix;).
  • Jagged arrays: Arrays of arrays, where the length of each inner array can be different (e.g., int[][] jagged;).
  • Param arrays (`params` keyword): Used in method signatures to allow passing an unknown number of arguments as a single array.

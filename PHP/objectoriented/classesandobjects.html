PHP - Classes and Objects

**Classes** and **Objects** form the foundation of PHP's Object-Oriented Programming (OOP). A **class** acts as a blueprint or a template, describing the structure (properties) and behavior (methods) common to a set of entities. An **object** is a unique, specific instance of that class.

Defining a Class in PHP

A class is defined using the class keyword, followed by its name, and an enclosed body containing **properties** (variables) and **methods** (functions). 

<?php
   class Book {
      /* Member variables (Properties) */
      var $price; // Traditional way to declare a public property
      var $title;

      /* Member functions (Methods) */
      function setPrice($par){
         // $this refers to the current object instance
         $this->price = $par;
      }

      function getTitle(){
         echo $this->title ."\n";
      }
   }
?>
  • **Properties (Member Variables)**: Variables defined within the class (e.g., $price, $title). They hold the data that characterizes an object.
  • **Methods (Member Functions)**: Functions defined within the class (e.g., setPrice(), getTitle()). They define the actions or behaviors of an object.
  • **The $this Pseudo-variable**: Used inside a method to refer to the object itself, allowing access to its own properties and methods (e.g., $this->price).

Defining and Using an Object

An object, an instance of a class, is created using the new keyword. The new operator allocates memory for the object's properties and methods. 

$b1 = new Book; // $b1 is an object (instance) of the Book class
$b2 = new Book; // $b2 is a separate, independent object

Accessing Object Members

You access an object's properties and methods using the **object operator** (->).

  • Setting Properties via Methods: 
    $b1->setTitle("PHP Programming");
$b1->setPrice(450);
  • Retrieving Data via Methods: 
    $b1->getTitle();
$b1->getPrice();

Example: Complete Class and Object Interaction

This script defines the Book class, creates two objects ($b1 and $b2), sets their unique properties, and then retrieves them. 

<?php
   class Book {
      var $price;
      var $title;

      function setPrice($par){ $this->price = $par; }
      function getPrice(){ echo $this->price ."\n"; }
      function setTitle($par){ $this->title = $par; }
      function getTitle(){ echo $this->title ."\n"; }
   }

   $b1 = new Book;
   $b2 = new Book;

   // Object $b1 properties
   $b1->setTitle("PHP Programming");
   $b1->setPrice(450);
   
   // Object $b2 properties
   $b2->setTitle("PHP Fundamentals");
   $b2->setPrice(275);
   
   // Output
   $b1->getTitle(); // PHP Programming
   $b1->getPrice(); // 450
   $b2->getTitle(); // PHP Fundamentals
   $b2->getPrice(); // 275
?>

Benefits of Using Classes and Objects

Adopting OOP principles with classes and objects provides key advantages:

  • **Code Organization**: Related data and functionality are logically grouped together, making the code easier to manage and understand.
  • **Code Reusability**: A single class definition can be used to create multiple objects, eliminating the need to rewrite the same logic.
  • **Encapsulation**: Classes help in the process of **Encapsulation**, which is keeping properties and methods secure and defining a clear interface for interacting with the object's internal state.

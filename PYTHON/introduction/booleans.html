Python - Booleans

In Python, bool is a sub-type of int type. A bool object has two possible values, True and False, which are initialized using Python keywords.

Example

>>> a=True
>>> b=False
>>> type(a), type(b)
(<class 'bool'>, <class 'bool'>)

A bool object can be passed as an argument to type conversion functions:

  • int(True) returns 1, int(False) returns 0.
  • float(True) returns 1.0, float(False) returns 0.0.
  • complex(True) returns (1+0j).

Example

a=int(True)
print ("bool to int:", a)

a=float(False)
print ("bool to float:", a)

a=complex(True)
print ("bool to complex:", a)

Output:

bool to int: 1
bool to float: 0.0
bool to complex: (1+0j)

Python Boolean Expressions

A Boolean expression is an expression that evaluates to True or False. They usually involve comparison operators. The bool() function can also be used to evaluate truth values.

Syntax: bool([x])

  • Returns True if x evaluates to true, else False.
  • If called without parameters, it returns False.

Example

# Check true
a = True
print(bool(a))

# Check false
a = False
print(bool(a))

# Check 0
a = 0.0
print(bool(a))

# Check 1
a = 1.0
print(bool(a))

# Check Equality
a = 5
b = 10
print(bool(a==b))

# Check None
a = None
print(bool(a))

# Check an empty sequence
a = ()
print(bool(a))

# Check an empty mapping
a = {}
print(bool(a))

# Check a non-empty string
a = 'Tutorialspoint'
print(bool(a))

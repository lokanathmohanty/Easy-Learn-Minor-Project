JavaScript - Template Literals

In JavaScript, the template literals were introduced in ES6 to customize strings dynamically. They allow you to add variables or expressions into a string, and the string updates automatically based on the variable or expression values.

Template literals are also known as template strings, string templates, or back-tick syntax.

Syntax

let str = `Hi ${name}`;

Strings are written between back-ticks (` `). Variables or expressions can be inserted using ${}. Template literals also remove the need for escape characters to add quotes inside strings.

Examples

Creating Strings with Template Literals


let str1 = `Hello Users!`;
let str2 = `'Tutorialspoint' is a good website`;

Output:

  • Hello Users!
  • 'Tutorialspoint' is a good website

Variables with Template Literals


let car = "BMW";
let model = "X5";
const price = 5000000;
const carStr = `The price of the ${car} ${model} is ${price}.`;

Output:

The price of the BMW X5 is 5000000.

Expressions with Template Literals


function func() {
  return 10;
}

const str1 = `The sum of 2 and 3 is ${2 + 3}.`;
const str2 = `The return value from the function is ${func()}`;

Output:

  • The sum of 2 and 3 is 5.
  • The return value from the function is 10

Nested Template Literals

JavaScript allows template literals inside other template literals, known as nested template literals. 


const nested = `The subtraction result is: ${2 < 3 ? `${3 - 2}` : `${2 - 3}`}`;

Output: The subtraction result is: 1

Multiline String Using Template Literal


function func() {
  return 10;
}

const str1 = `The sum of 2 and 3 is ${2 + 3}. 
The return value from the function is ${func()}`;

Output:

  • The sum of 2 and 3 is 5.
  • The return value from the function is 10

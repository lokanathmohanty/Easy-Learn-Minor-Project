PHP Global Variables

A **Global Variable** is any variable declared **outside of all functions or classes** in a PHP script. It can be accessed directly anywhere outside of a function. However, due to PHP's scoping rules, global variables are **not automatically accessible inside a function's local scope**.

Accessing Global Variables Inside Functions

There are two primary methods to access and modify a global variable from within a function: the `global` keyword and the `$GLOBALS` superglobal array.

1. Using the `global` Keyword

The `global` keyword is used inside a function to explicitly declare that the variable being used is the one from the global scope. This creates a reference (alias) to the global variable. Any changes made to the variable inside the function are reflected globally.

$name = "Amar"; // Global variable
function sayhello() {
   **GLOBAL $name;** // Explicitly declare global access
   echo "Hello " . $name . PHP_EOL;
   $name = "Amarjyot"; // Modifies the global $name
}
sayhello();
echo $name; // Output: Amarjyot (The change persists)

2. Using the `$GLOBALS` Superglobal Array

**`$GLOBALS`** is an **associative array** that holds all variables defined in the global scope. It is a superglobal, meaning it is available in all scopes without needing the `global` keyword. You access variables by using their name as the array key (e.g., `$GLOBALS['name']`).

$x = 10;
$y = 20;
function addition() {
   $z = **$GLOBALS['x'] + $GLOBALS['y']**;
   **$GLOBALS['z'] = $z;** // Adds $z to the global scope
}
addition();
echo "Addition: $z"; // Output: Addition: 30

**Note:** Using `$GLOBALS` is generally considered a cleaner way to access and modify global variables within a function, as it is self-documenting and doesn't rely on the `global` keyword reference mechanism.

Variables in Included Scripts

Variables defined in a PHP script that is included using `include` or `require` statements are also added to the **global scope** of the main script and can be accessed using the methods above.

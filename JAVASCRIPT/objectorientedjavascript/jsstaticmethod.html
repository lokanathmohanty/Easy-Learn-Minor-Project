JavaScript - Static Methods

What are Static Methods?

A static method in JavaScript is defined using the static keyword followed by the method name. You can execute the static method by taking the class name as a reference rather than an instance of the class.

The main benefit of the static method is that it can be used to create a utility function that doesn't require the instance of the class for execution. For example, a Math object contains various static methods, which we can invoke directly through the Math class.

Also, you can use static methods to add all related methods under a single namespace. Furthermore, static methods give better performance than the regular class methods due to memory optimization.

Syntax

In the following syntax, we define a static method called getSize() in the class Table:

class Table {
  static getSize() { // Static method
    return "10 x 10";
  }
}
Table.getSize(); // Static method invocation

In the above syntax, getSize() is a static method. We used the class name to execute the getSize() method.

Examples

Example: Static Method

In the example below, printSize() is a static method, and getColor() is a regular method in the Table class. The printSize() method is invoked using the class name, and the getColor() method is executed using the class instance.

So, the class can contain both static and non-static methods.

class Table {
  static printSize() {
    return "The size of the table is: 20 x 20";
  }
  getColor() {
    return "Black";
  }
}

Table.printSize(); // Static method execution
const tableObj = new Table();
tableObj.getColor(); // Regular method execution

Output:

  • The size of the table is: 20 x 20
  • The color of the table is: Black

Example: Multiple Static Methods

In the below code, the Table class contains the printSize() and getColor() static methods. Both methods are executed by taking the class name as a reference. 

class Table {
  static printSize() {
    return "The size of the table is 20 x 20";
  }
  static getColor() {
    return "The color of the table is Pink";
  }
}

Table.printSize();
Table.getColor();

Output:

  • The size of the table is 20 x 20
  • The color of the table is Pink

Example: Static Methods with the Same Name

A single class can contain multiple static methods with the same name. When you execute the static method with the same name, it executes the last method. 

class Table {
  static printSize() {
    return "The size of the table is: 20 x 20";
  }
  static printSize() {
    return "The size of the table is: 30 x 30";
  }
}

Table.printSize();

Output: The size of the table is: 30 x 30

Example: Static Method Execution in the Constructor

You can also execute the static method of the class in the constructor using this.constructor followed by the static method name.

In the example below, the Num class contains the getSqrt() static method. It is executed in the constructor and stored in the sqrt property. 

class Num {
  constructor(a) {
    this.sqrt = this.constructor.getSqrt(a);
  }
  static getSqrt(a) {
    return a * a;
  }
}
const num1 = new Num(10);
num1.sqrt; // 100

Output: The square root of 10 is: 100

Example: Static Method Execution in Non-Static Method

You can also execute the static method inside a non-static method using the class name as a reference. 

class Num {
  static getSqr(a) {
    return a * a;
  }
  printSqr(a) {
    return "The square of " + a + " is: " + Num.getSqr(a);
  }
}
const num1 = new Num();
num1.printSqr(6); // The square of 6 is: 36

Output: The square of 6 is: 36

In this chapter, let us create a sample Expense Manager application by applying the concepts we have learned in this tutorial. Some of the concepts used include:

  • React basics (components, JSX, props, and state)
  • Routing using react-router
  • HTTP client programming (Web API)
  • Form programming using Formik
  • Advanced state management using Redux
  • Async / Await programming

Features

Some of the key features of our sample Expense Manager application are:

  • Listing all expenses from the server
  • Adding an expense item
  • Deleting an expense item

Steps

The main steps in building this application are as follows:

  • Expense Manager API
  • Installing necessary modules
  • State management
  • Listing expenses
  • Adding expenses

CSS - height Property

The height property in CSS specifies the height of an element. It determines how tall an element will be, directly affecting its layout and positioning within the document. This property can be applied to block-level elements, inline-block elements, and replaced elements like images.

Syntax

height: auto | length | percentage | min-content | max-content | initial | inherit;

Property Values

  • auto → The element expands or contracts based on its content. Default value.
  • length → Sets a fixed height using units like px, em, rem, etc.
  • percentage → Sets the height relative to the height of the containing block.
  • min-content → Fits the minimum height required by the content without overflow.
  • max-content → Expands height to fit the tallest content.
  • initial → Sets the property to its default value.
  • inherit → Inherits the property from the parent element.

Example 1: height with auto

The element height adjusts automatically based on content.

.outer {
  height: 200px;
  padding: 10px;
  box-sizing: border-box;
}

.inner {
  height: auto;
  border: 2px solid;
}

Example 2: height with length values

Height is fixed with length units like px or em. If the content is larger, overflow occurs.

.inner1 {
  height: 40px;
}

.inner2 {
  height: 90px;
}

Example 3: height with percentage values

Height is relative to the parent container.

.outer {
  height: 300px;
}

.inner1 {
  height: 30%;
}

.inner2 {
  height: 50%;
}

Example 4: height with min-content

The element height fits the smallest size needed to contain the content.

.inner {
  height: min-content;
}

Example 5: height with max-content

The element height grows to fit the tallest content.

.inner {
  height: max-content;
}

Example 6: Using inherit

Child element inherits height from the parent element.

.parent {
  height: 150px;
}

.child {
  height: inherit;
}

Example 7: height with initial

Resets height to the browser default value (auto).

.box {
  height: initial;
}

Real-World Example: Fixed Height Card

A card with a fixed height forces content overflow handling.

.card {
  height: 250px;
  overflow: auto;
  border: 1px solid black;
}

Supported Browsers

  • Chrome → 1.0+
  • Edge → 4.0+
  • Firefox → 1.0+
  • Safari → 1.0+
  • Opera → 7.0+

Practical Use Cases

  • Defining consistent sizes for cards, modals, and containers.
  • Ensuring elements scale correctly inside flex and grid layouts.
  • Preventing overflow in UI components like chat boxes or lists.
  • Maintaining aspect ratio of media elements with controlled height.

JavaScript - Local Storage

This chapter will show you how to use JavaScript's localStorage to save data for several browser sessions. We will demonstrate how to use this method using the Window.localStorage property, as well as go over the principles of web storage in JavaScript.

What is localStorage in JavaScript?

The localStorage feature allows JavaScript apps and websites to save key-value pairs in a web browser with no expiration date. This means that the stored data remains even if the user closes the browser or restarts the computer.

localStorage is a window object property, so it can interact with and manipulate the browser window.

Syntax


myStorage = window.localStorage;

What is Window.localStorage?

The localStorage method is accessible via the Window.localStorage property. It is a read-only property that returns a reference to a local storage object which is intended to store data that can only be accessed by the origin that created it.

When to use localStorage

You can use localStorage to store small amounts of data such as:

  • User preferences like language or theme
  • Form data, so it is not lost when closing the browser
  • Session data, to keep users logged in after closing/reopening the browser
  • Data cache for frequently used values

How does localStorage work?

  • setItem(): Adds a key and value to localStorage
  • getItem(): Retrieves items from localStorage
  • removeItem(): Removes an item from localStorage
  • clear(): Erases all data from localStorage
  • key(): Returns a key name by its index

Usage of setItem() Method


localStorage.setItem('name', 'Ankit Sharma');

Since localStorage can only store strings, objects and arrays must be converted using JSON.stringify(): 


const userArr = ["Ankit", 25];
localStorage.setItem('user', JSON.stringify(userArr));

Usage of getItem() Method


localStorage.getItem('name'); // "Ankit Sharma"

const userData = JSON.parse(localStorage.getItem('user'));
console.log(userData); // ["Ankit", 25]

Usage of removeItem() Method


localStorage.removeItem('name');

Usage of clear() Method


localStorage.clear();

Usage of key() Method


localStorage.key(index);

Advantages of LocalStorage

  • Saved data never expires
  • Data is available offline
  • More secure and controlled than cookies
  • Greater storage capacity (up to 5MB vs. cookies’ 4KB)

Disadvantages of LocalStorage

  • Operations are synchronous and may slow performance with large datasets
  • Not secure for sensitive data (accessible to anyone using the device)
  • Can only store strings (other types must be stringified)
  • Storing too much data may slow applications

C# Indexers: Virtual Array Access

What is an Indexer? 🔢

An **indexer** allows an object of a class or structure to be indexed in the same way an array is indexed. When an indexer is defined, the class behaves like a **"virtual array,"** allowing its instances to be accessed using the array access operator (`[ ]`).

Indexers are conceptually similar to properties but, instead of returning or setting a single named field, they enable accessing specific parts of the object's internal data using an index.

Indexer Syntax and Structure

Indexers are defined using the **`this`** keyword, followed by the index parameter(s) inside square brackets.

Basic Syntax

element-type this[index-type index] {
   // The get accessor (for reading)
   get {
      // Logic to retrieve the value at the given index
      return internal_data[index];
   }
   
   // The set accessor (for writing)
   set {
      // Logic to assign the 'value' to the internal data at the given index
      internal_data[index] = value;
   }
}

Key Differences from Properties

  • **Naming:** Indexers are defined using the keyword **`this`**, not a user-defined name.
  • **Parameters:** Indexers **must** take one or more parameters inside the square brackets, which acts as the index. Properties have no parameters.

Versatility of Indexers

1. Non-Integer Indexes (Dictionary-Style) 💡

The index parameter does **not** have to be an integer. This allows you to create dictionary-like access where a string or other custom type is used as the key.

// Indexer using a string key to access an internal Dictionary
public string this[string name]
{
    get { return phoneBook.ContainsKey(name) ? phoneBook[name] : "Not Found"; }
    set { phoneBook[name] = value; }
}

This allows instances of the class to be accessed like: `contacts["Aman"] = "1234..."`

2. Overloaded Indexers

Indexers can be overloaded, meaning you can define multiple indexers within the same class as long as their parameter signatures are different (e.g., one taking an `int` and one taking a `string`). This allows the class to be accessed in multiple ways.

3. Access Modifiers on Accessors

Similar to properties, you can apply access modifiers (`private`, `protected`) to the individual `get` or `set` accessors, providing granular control over how the internal data can be read or written from outside the class.

public string this[int index]
{
    get { return items[index]; }
    private set { items[index] = value; } // Cannot be set externally
}

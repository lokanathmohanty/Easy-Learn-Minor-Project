JavaScript - Document Object

Introduction

The document object is a JavaScript object that provides access to all elements of an HTML document. When the HTML document is loaded in the web browser, it creates a document object. It is the root of the HTML document.

The document object contains various properties and methods you can use to get details about HTML elements and customize them. It is a property of the window object and can be accessed using window.document or directly as document.

Document Object Properties

  • document.title − Gets or sets the title of the document.
  • document.URL − Returns the URL of the document.
  • document.body − Returns the <body> element.
  • document.head − Returns the <head> element.
  • document.documentElement − Returns the <html> element.
  • document.doctype − Returns the Document Type Declaration.

Example: Accessing the Document Title

<html>
<head>
   <title> JavaScript - DOM Object </title>
</head>
<body>
   <div id="output">The title of the document is: </div>
   <script>
      document.getElementById("output").innerHTML += document.title;
   </script>
</body>
</html>

Output: The title of the document is: JavaScript - DOM Object

Document Object Methods

  • getElementById(id) − Returns the element with the specified ID.
  • getElementsByClassName(className) − Returns a collection of elements by class name.
  • getElementsByTagName(tagName) − Returns a collection of elements by tag name.
  • createElement(tagName) − Creates a new HTML element.
  • createTextNode(text) − Creates a new text node.
  • appendChild(node) − Appends a node as the last child of a node.
  • removeChild(node) − Removes a child node from the DOM.
  • setAttribute(name, value) − Sets an attribute on the specified element.
  • getAttribute(name) − Returns the value of an attribute.

Example: Accessing HTML Element by ID

<html>
<body>
   <div id="result"></div>
   <script>
      document.getElementById("result").innerHTML += 
      "Hello User! You have accessed the DIV element using its id.";
   </script>
</body>
</html>

Output: Hello User! You have accessed the DIV element using its id.

Example: Adding an Event to the Document

<html>
<body>
   <div id="result">
       <h2> Mouseover Event </h2>
       <p> Hover over here to change background color </p>
   </div>
   <script>
      document.addEventListener('mouseover', function () {
         document.getElementById("result").innerHTML = "Mouseover event occurred.";
      });
   </script>
</body>
</html>

Output: Mouseover event occurred.

Document Object Properties List

Here are some additional properties of the document object:

  • document.activeElement – Returns the currently focused element.
  • document.baseURI – Returns the base URI of the document.
  • document.cookie – Gets the cookies related to the document.
  • document.forms – Returns all <form> elements.
  • document.images – Returns all <img> elements.
  • document.lastModified – Returns the last modified date/time.
  • document.readyState – Returns the current state of the document.
  • document.scripts – Returns all <script> elements.
  • document.title – Gets/sets the title of the document.
  • document.URL – Returns the full URL of the document.

Document Object Methods List

Here are some more commonly used methods:

  • addEventListener() – Adds an event listener to the document.
  • createComment() – Creates a new comment node.
  • createDocumentFragment() – Creates a lightweight container for DOM nodes.
  • elementFromPoint(x, y) – Returns the top element at given coordinates.
  • querySelector() – Returns the first element matching a CSS selector.
  • querySelectorAll() – Returns all elements matching a CSS selector.
  • removeEventListener() – Removes an event listener.
  • write() – Writes text or HTML into the document.
  • writeln() – Writes text/HTML with a newline.

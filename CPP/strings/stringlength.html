C++ String Length Methods 📏

The **length of a string** is the number of characters it contains. C++ supports two string types, offering different ways to determine their length:

  • **C-Style Character Arrays** (`char[]`)
  • **std::string Objects** (from the <string> class)

The length calculation always **stops** at the first occurrence of the **null terminating character** (`'\0'`), if present.

I. std::string Member Methods (Preferred)

These methods are built into the std::string class and are the standard, safe way to get the length of a string object.

1. string::length() and string::size()

These two member functions are **functionally identical** and return the number of characters in the string object.

std::string s = "I love TP !!!";
// Both length() and size() return 13
int len1 = s.length(); 
int len2 = s.size();

Note: When an std::string is initialized with an explicit null character (e.g., `"I love TP !!!\0 and others"`), its length() and size() methods will correctly report the length up to the actual null character found during initialization, which is 13 in the examples.

II. C-Style Function

2. strlen() Method

This function, found in the <cstring> header (or <string.h>), is designed for **C-style character arrays** (`char[]`). It takes the string array name (which decays to a pointer) and counts characters until it encounters the `'\0'` terminator.

char s[] = "I love TP !!!";
size_t len = strlen(s); // Returns 13

III. Iterative Methods (Manual Counting)

These methods manually reproduce the behavior of strlen() by looping through the string character by character and incrementing a counter until the `'\0'` is reached.

3. Using an Iterative for Loop

std::string s = "I love TP !!!";
int count = 0;
for(int i = 0; s[i] != '\0'; i++) 
   count++; // count will be 13

4. Using an Iterative while Loop

std::string s = "I love TP !!!";
int count = 0, i = 0;
while(s[i] != '\0') {
   count++; 
   i++;
}
// count will be 13

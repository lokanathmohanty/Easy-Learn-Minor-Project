Node.js - Command Line Options

Overview

Node.js provides several command-line options to configure and control the runtime environment. These options assist with debugging, performance tuning, running scripts, and syntax checking.

Running a Node.js Script

Execute a JavaScript file by running: 

node filename.js

Commonly Used Command-Line Options

--help

Displays a list of all available command-line flags and their descriptions.

node --help

--version or -v

Shows the installed Node.js version.

node --version
or
node -v

Output example: v22.13.1

-e or --eval

Executes JavaScript code directly from the command line without creating a file. Useful for quick testing of code snippets or calculations.

node -e "console.log('Welcome to TutorialsPoint!')"

Output: Welcome to TutorialsPoint!

Supports multi-line code by separating lines with semicolons:

node -e "let x=112; let a=234; console.log(x+a);"

Output: 346

-p or --print

Evaluates and prints the result of a JavaScript expression without needing an explicit console.log().

node -p "112 - 321"

Output: -209

Can print function call results:

node -p "Math.sqrt(121)"

Output: 11

--check or -c

Checks the syntax of a JavaScript file without executing it. Shows error messages if syntax errors are found.

Example with a correct file (no output):

node --check test.js

Example with syntax error in file:


C:\Users\Lenovo\test.js:1
console.log("Welcome To, TP.!";
            ^^^^^^^^^^^^^^^^^^

Python - Type Casting

Type casting refers to converting an object of one type into another. Python supports two types of casting: implicit and explicit. It allows us to convert between numbers, sequences, mappings, and more.

1. Implicit Casting

Also called type coercion, implicit casting happens automatically when Python converts a smaller data type into a larger one (e.g., int → float) during operations.

Example

a = 10     # int
b = 10.5   # float
c = a + b
print(c)   # 20.5

Booleans are also implicitly converted to numbers before arithmetic.

a = True
b = 10.5
c = a + b
print(c)   # 11.5

2. Explicit Casting

Explicit casting is done using built-in functions like int(), float(), str(), etc. It allows conversions not handled automatically by Python.

Python int() Function

Converts values to integers. Works with numbers, booleans, and valid strings.

a = int(10.5)     # 10
b = int(True)     # 1
c = int("100")    # 100

It can also convert binary, octal, and hexadecimal strings by providing a base:

print(int("110011", 2))   # 51
print(int("20", 8))       # 16
print(int("2A9", 16))     # 681

Python float() Function

Converts values to floating-point numbers. Works with integers, strings, and scientific notation.

print(float(100))       # 100.0
print(float("9.99"))    # 9.99
print(float("1.00E4"))  # 10000.0

Python str() Function

Converts objects into strings, including numbers, booleans, lists, tuples, and dictionaries.

print(str(10))       # '10'
print(str(11.10))    # '11.1'
print(str([1,2,3]))  # '[1, 2, 3]'

Conversion of Sequence Types

Lists, tuples, and strings can be interconverted using list(), tuple(), and str().

a = [1,2,3,4,5]
b = (1,2,3,4,5)
c = "Hello"

print(list(c))   # ['H', 'e', 'l', 'l', 'o']
print(tuple(a))  # (1, 2, 3, 4, 5)
print(str(b))    # '(1, 2, 3, 4, 5)'

Data Type Conversion Functions

  • int(x) − Converts x to integer.
  • float(x) − Converts x to float.
  • complex(x, y) − Creates a complex number.
  • str(x) − Converts object to string.
  • repr(x) − Converts object to expression string.
  • eval(x) − Evaluates string and returns object.
  • tuple(s) − Converts s to tuple.
  • list(s) − Converts s to list.
  • set(s) − Converts s to set.
  • dict(d) − Creates dictionary from (key,value) pairs.
  • frozenset(s) − Converts s to immutable set.
  • chr(i) − Converts integer to character.
  • ord(c) − Converts character to integer.
  • hex(x) − Converts integer to hexadecimal string.
  • oct(x) − Converts integer to octal string.

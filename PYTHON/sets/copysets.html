Python - Copy Sets

Different methods to copy a set in Python include using the copy() method, the set() function, or set comprehension.

Copy Sets Using the copy() Method

The copy() method creates a shallow copy of a set object. It returns a new set but does not create copies of mutable objects inside the set. 


lang1 = {"C", "C++", "Java", "Python"}
print("lang1: ", lang1, "id(lang1): ", id(lang1))

lang2 = lang1.copy()
print("lang2: ", lang2, "id(lang2): ", id(lang2))

lang1.add("PHP")
print("After updating lang1")
print("lang1: ", lang1, "id(lang1): ", id(lang1))
print("lang2: ", lang2, "id(lang2): ", id(lang2))

Output:

{'Python', 'Java', 'C', 'C++'} id(lang1): 2451578196864
{'Python', 'Java', 'C', 'C++'} id(lang2): 2451578197312
After updating lang1
{'Python', 'C', 'C++', 'PHP', 'Java'} id(lang1): 2451578196864
{'Python', 'Java', 'C', 'C++'} id(lang2): 2451578197312

Copy Sets Using the set() Function

The set() function can create a new set from an iterable. Passing the original set to set() returns a copy where modifications to the copy do not affect the original. 


original_set = {1, 2, 3, 4}
copied_set = set(original_set)
print("copied set:", copied_set)

copied_set.add(5)
print("copied set:", copied_set)
print("original set:", original_set)

Output:

{1, 2, 3, 4}
{1, 2, 3, 4, 5}
{1, 2, 3, 4}

Copy Sets Using Set Comprehension

Set comprehension creates a new set by iterating over an original set. It offers a concise way to copy sets. 


original_set = {1, 2, 3, 4, 5}
copied_set = {x for x in original_set}
print("Copied set:", copied_set)

Output:

{1, 2, 3, 4, 5}

Python Interpreter and Its Modes

Python Interpreter

Python is an interpreter-based language. In Linux, the executable is usually installed in /usr/bin/. On Windows, it is found in the installation folder such as C:\python311.

The Python interpreter executes code one statement at a time. It first checks syntax, then generates intermediate byte code, and finally the Python Virtual Machine converts it into native binary for execution.

Interactive Mode

When launched without arguments, Python starts in interactive mode with a >>> prompt, working on the REPL (Read, Evaluate, Print, Loop) principle.

>>> price = 100
>>> qty = 5
>>> total = price * qty
>>> total
500
>>> print("Total = ", total)
Total = 500

Exit using ctrl+D (Linux), ctrl+Z (Windows), or quit().

Advanced alternatives like IPython and bpython provide features such as auto-completion, syntax highlighting, and command history.

Scripting Mode

Python programs can be written in a text file with .py extension and executed with the Python command.

# prog.py
print("My first program")
price = 100
qty = 5
total = price * qty
print("Total = ", total)

Run the script:

C:\> python prog.py

Output:

My first program
Total = 500

If an error occurs, execution stops at that point, but earlier statements are still executed.

Using Shebang in Linux

Python scripts can be made self-executable in Linux with a shebang line:

#! /usr/bin/python3.11

print("My first program")
price = 100
qty = 5
total = price * qty
print("Total = ", total)

Mark the file executable:

$ chmod +x prog.py

Run directly:

$ ./prog.py

Interactive Python - IPython

IPython is an enhanced interactive Python shell with features like introspection, history, syntax highlighting, tab completion, and magic commands. It was created by Fernando Perez in 2001 and serves as the kernel for Jupyter Notebook.

Install IPython:

pip3 install ipython

Launch:

C:\> ipython

Example session:

In [1]: price = 100
In [2]: quantity = 5
In [3]: total = price * quantity
In [4]: total
Out[4]: 500

Key Features

  • Tab completion of variables, functions, and keywords
  • Object introspection with ?
  • History of commands stored and retrievable
  • Magic commands for environment control and OS tasks

Example of introspection:

In [5]: var = "Hello World"
In [6]: var?
Type: str
String form: Hello World
Length: 11
Docstring:
str(object='') -> str
...

Example of magic command to run OS command:

In [8]: !dir *.exe
07-02-2023 16:55            103,192 python.exe
07-02-2023 16:55            101,656 pythonw.exe

Jupyter Notebook

Jupyter Notebook is a web-based environment that uses IPython as its kernel for Python. It also supports other languages like R and Julia.

JavaScript - Debugging

What is Debugging?

Debugging in JavaScript is a process of examining JavaScript code, finding errors, and fixing them. Errors may be logical, syntax, or runtime. An error in a program is called a bug, and the process of finding and fixing bugs is called debugging.

This section covers tools and techniques that can help with debugging tasks.

Use a JavaScript Debugger

A debugger is a tool that lets programmers control script execution, examine values, and watch variables. Modern browsers include built-in debuggers in the developer tools console.

How to Open Console in the Browser?

Below are steps for opening the console in different browsers:

Open Console in Chrome

  • Windows/Linux: Ctrl + Shift + I or Ctrl + Shift + J
  • macOS: Cmd + Option + I or Cmd + Option + J

Alternatively: Right-click → Inspect → Console tab.

Open Console in Firefox

  • Windows/Linux: Ctrl + Shift + I or Ctrl + Shift + J
  • macOS: Cmd + Option + I or Cmd + Option + J

Alternatively: Right-click → Inspect(Q) → Console tab.

Open Console in Microsoft Edge

Similar steps as Chrome. Right-click → Inspect → Console tab.

Open Console in Safari

Enable "Show Develop Menu" in Preferences → Advanced, then use Develop → Show Error Console.

Open Console in Opera

Use Menu → Developer → Developer Tools → Console.

Using the console.log() Method

The console.log() method prints messages in the browser console. It can display values, objects, and expressions.

Syntax:

console.log(val1, val2, ...);

Example: Debugging Variable Types

<html>
<body>
   <div id="output"></div>
   <p>Note: To see the result, open the console before running the code.</p>
   <script>
      let num1 = "3";
      let num2 = 2;
      let sum = num1 + num2;
      document.getElementById("output").innerHTML = "The sum is: " + sum;
      console.log("typeof num1 is " + typeof num1);
      console.log("typeof num2 is " + typeof num2);
   </script>
</body>
</html>

Output: The sum is: 32

Console result:

  • typeof num1 is string
  • typeof num2 is number

Example: Debugging Objects

<html>
<body>
   <div id="demo"></div>
   <p>Note: To see the result, open the console before running the code.</p>
   <script>
      let output = document.getElementById("demo");
      let person = {
         name: "John",
         age: 25,
         city: "New York"
      }
      output.innerHTML = "The name of the person is: " + person.name + "<br>";
      output.innerHTML += "The city of the person is: " + person.city + "<br>";
      console.log(person);
   </script>
</body>
</html>

Output: The name of the person is: John. The city of the person is: New York.

Console result: {name: "John", age: 25, city: "New York"}

Using the debugger Keyword

The debugger keyword pauses execution in the browser so you can inspect values before continuing.

Example: Using debugger

<html>
<body>
   <div id="demo"></div>
   <script>
      const output = document.getElementById("demo");
      const person = { name: "John", age: 25, city: "New York" };
      debugger;
      output.innerHTML = "The name of the person is: " + person.name + "<br>";
      output.innerHTML += "The city of the person is: " + person.city;
   </script>
</body>
</html>

Setting Breakpoints

You can set breakpoints in the browser's Sources panel to pause execution on a specific line, similar to using debugger.

Example: Breakpoints

<html>
<body>
   <div id="output">The resultant string after appending str2 to str1 is: </div>
   <script>
      function test() {
         let str1 = "Hi";
         let str2 = "";
         let res = str1.concat(str2);
         document.getElementById("output").innerHTML += res;
      }
      test();
   </script>
</body>
</html>

Output: The resultant string after appending str2 to str1 is: Hi

Useful Tips for Developers

  • Use comments to explain code logic.
  • Indent your code for readability.
  • Write modular functions for reusability.
  • Use consistent and descriptive variable/function names.
  • Test long scripts in smaller sections.
  • Be careful with quotation marks and equality operators.
  • Always declare variables explicitly.

R - Overview

R is a programming language and software environment for statistical analysis, graphics representation, and reporting. It was created by Ross Ihaka and Robert Gentleman at the University of Auckland, New Zealand. The language is currently developed by the R Development Core Team.

The core of R is an interpreted language that allows branching and looping, as well as modular programming using functions. R also supports integration with procedures written in C, C++, .Net, Python, or FORTRAN for efficiency.

R is freely available under the GNU General Public License, with pre-compiled binary versions provided for major operating systems such as Linux, Windows, and Mac. It is part of the GNU project called GNU S.

Evolution of R

R was initially authored by Ross Ihaka and Robert Gentleman at the Department of Statistics, University of Auckland. The first public release was in 1993. Since mid-1997, the "R Core Team" has maintained and modified the source code.

Over the years, many contributors have sent code and bug reports, shaping the language to what it is today. The name "R" is derived from the first letters of the authors' first names, as well as marking its heritage as a successor to the S language.

Features of R

  • Well-developed, simple, and effective language with conditionals, loops, recursion, and input/output facilities.
  • Effective data handling and storage facilities.
  • Operators for calculations on arrays, lists, vectors, and matrices.
  • Large collection of integrated tools for data analysis.
  • Graphical facilities for data analysis and display, either on-screen or in print.

R is the world's most widely used statistics programming language, favored by data scientists and supported by a vibrant community. It is actively taught in universities and used in critical business applications globally.

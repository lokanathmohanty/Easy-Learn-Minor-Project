CSS - Quotes

The CSS quotes property allows the browser to render quotation marks around text content. It is usually used in combination with pseudo-elements ::before and ::after along with the content property. Using this property, you can define how open and close quotation marks appear for different levels of nested quotations.

Syntax

quotes: none | auto | <string>+ | initial;

Possible Values

  • none − No quotation marks are generated when open-quote and close-quote are used.
  • auto − Browser automatically decides appropriate quotes depending on the language (lang attribute).
  • string,string,+ − One or more pairs of strings are used to represent quotation marks. The first pair is used for outermost quotes, the second pair for nested quotes, and so on.
  • initial − Resets the quotes property to its default (user agent defined) value.

Quotation Characters

Some common quotation entities:

  • " (double quotes) → \0022
  • ' (single quote) → \0027
  • < and > (single angle quotes) → \2039, \203A
  • « and » (double angle quotes) → \00AB, \00BB
  • ‘ ’ (curly single quotes) → \2018, \2019
  • “ ” (curly double quotes) → \201C, \201D

Examples

1. quotes: none

This removes quotation marks completely:

p {
   quotes: none;
}
p::before {
   content: open-quote;
}
p::after {
   content: close-quote;
}

This text has no quotes rendered.

2. quotes with string values

We can define different quotation marks for different nesting levels:

#quote1 { quotes: '«' '»'; }
#quote2 { quotes: '[' ']'; }
#quote3 { quotes: "<<" ">>" "<" ">"; }

3. quotes: initial

Restores browser default quotes:

q {
   quotes: initial;
}

Browser decides default quotation style.

4. quotes: auto

Automatically sets quotation marks based on language:

q {
   quotes: auto;
}

5. Using :lang pseudo-class

Different quotes for different languages:

:lang(en) {
   quotes: '"' '"' "<<" ">>";
}
:lang(fr) {
   quotes: '\2039' '\203A';
}

Key Takeaways

  • The quotes property works best with q elements or pseudo-elements using open-quote and close-quote.
  • It provides great flexibility for localization and custom styles.
  • Different languages may have different default quotation marks, so auto and :lang selectors are very useful.

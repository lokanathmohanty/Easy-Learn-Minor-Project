Python - History and Versions

History of Python

Python was developed by Guido van Rossum (a Dutch programmer) in the late 1980s and early nineties at the National Research Institute for Mathematics and Computer Science in the Netherlands.

Python is derived from many other languages, including ABC, Modula-3, C, C++, Algol-68, SmallTalk, and Unix shell and other scripting languages. Guido van Rossum wanted Python to be a high-level language that was powerful yet readable and easy to use.

Python is copyrighted. Like Perl, Python source code is now available under the GNU General Public License (GPL).

For many uninitiated people, the word Python is related to a species of snake. Rossum though attributes the choice of the name Python to a popular comedy series Monty Python's Flying Circus on BBC.

Being the principal architect of Python, the developer community conferred upon him the title of Benevolent Dictator for Life (BDFL). However, in 2018, Rossum relinquished the title. Thereafter, the development and distribution of the reference implementation of Python is handled by a nonprofit organization Python Software Foundation.

Who Invented Python?

Python was invented by a Dutch Programmer Guido Van Rossum in the late 1980s. He began working on Python in December 1989 as a hobby project while working at the Centrum Wiskunde & Informatica (CWI) in the Netherlands. Python's first version (0.9.0) was released in 1991.

Evolution of Python - The Major Versions

  • Python 0.9.0 − Released in February 1991. Included classes with inheritance, exception handling, and core data types like lists and dictionaries.
  • Python 1.0 − Released in January 1994. Introduced functional programming tools, support for complex numbers, and a module system for better code organization.
  • Python 2.0 − Released in October 2000. Added list comprehension, garbage collection, and Unicode support. Widely adopted with libraries like NumPy, SciPy, and Django.
  • Python 3.0 − Released in December 2008. A major revamp fixing discrepancies in Python 2.x. Introduced unicode by default, improved integer division, and the python2to3 utility for migration.
  • EOL for Python 2.x − Python 2 support officially ended in 2020, with version 2.7.17 as its last release.

Current Version of Python

As of February 2023, the latest stable release is Python 3.11.2.

What's New in Python 3.11?

  • Up to 60% faster execution compared to Python 3.10.
  • Improved exception messages with more precise error locations.
  • add_note() method added to BaseException (PEP 678).
  • math.cbroot() function introduced to compute cube roots.
  • New tomllib module for parsing TOML files.

Python in the Future

Python continues to evolve with regular updates to the 3.x branch. Developers are focusing on improving performance while keeping its simplicity. Its use in AI, machine learning, and data science ensures a bright future. Python is also increasingly becoming the first programming language taught in schools and universities worldwide.

Java - Files and I/O

The java.io package contains nearly every class needed to perform input and output (I/O) in Java. Streams in this package support various data types including primitives, objects, and localized characters.

Stream

A stream is a sequence of data. Java has two main types of streams:

  • InputStream – used to read data from a source.
  • OutputStream – used to write data to a destination.

Byte Streams

Used to perform input and output of 8-bit bytes. Commonly used classes include FileInputStream and FileOutputStream.

Example: Copy file using Byte Streams

import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.IOException;

public class CopyFile {
   public static void main(String args[]) throws IOException {  
      FileInputStream in = null;
      FileOutputStream out = null;

      try {
         in = new FileInputStream("input.txt");
         out = new FileOutputStream("output.txt");

         int c;
         while ((c = in.read()) != -1) {
            out.write(c);
         }
      } finally {
         if (in != null) in.close();
         if (out != null) out.close();
      }
   }
}

Input file: input.txt

This is test for copy file.

Output: File output.txt will contain the same content.

Character Streams

Used for 16-bit Unicode character data. FileReader and FileWriter are most commonly used. They handle two bytes at a time.

Example: Copy file using Character Streams

import java.io.FileReader;
import java.io.FileWriter;
import java.io.IOException;

public class CopyFile {
   public static void main(String args[]) throws IOException {
      FileReader in = null;
      FileWriter out = null;

      try {
         in = new FileReader("input.txt");
         out = new FileWriter("output.txt");

         int c;
         while ((c = in.read()) != -1) {
            out.write(c);
         }
      } finally {
         if (in != null) in.close();
         if (out != null) out.close();
      }
   }
}

Standard Streams

Java provides three standard streams:

  • System.in – Standard Input (keyboard)
  • System.out – Standard Output (screen)
  • System.err – Standard Error (screen)

Example: Read from console using InputStreamReader

import java.io.InputStreamReader;
import java.io.IOException;

public class ReadConsole {
   public static void main(String args[]) throws IOException {
      InputStreamReader cin = null;

      try {
         cin = new InputStreamReader(System.in);
         System.out.println("Enter characters, 'q' to quit.");
         char c;
         do {
            c = (char) cin.read();
            System.out.print(c);
         } while(c != 'q');
      } finally {
         if (cin != null) cin.close();
      }
   }
}

FileInputStream

Used to read data from a file. Common constructors:

InputStream f = new FileInputStream("C:/java/hello");
File f = new File("C:/java/hello");
InputStream f = new FileInputStream(f);

Useful methods:

  • close() – Closes the stream
  • read() – Reads a byte
  • read(byte[]) – Reads into an array
  • available() – Returns available bytes

FileOutputStream

Used to write data to a file. Common constructors:

OutputStream f = new FileOutputStream("C:/java/hello");
File f = new File("C:/java/hello");
OutputStream f = new FileOutputStream(f);

Useful methods:

  • close() – Closes the stream
  • write(int) – Writes one byte
  • write(byte[]) – Writes array of bytes

Example: File Stream Read/Write

import java.io.*;

public class fileStreamTest {
   public static void main(String args[]) {
      try {
         byte bWrite[] = {11, 21, 3, 40, 5};
         OutputStream os = new FileOutputStream("test.txt");
         for (int x = 0; x < bWrite.length; x++) {
            os.write(bWrite[x]);
         }
         os.close();

         InputStream is = new FileInputStream("test.txt");
         int size = is.available();

         for (int i = 0; i < size; i++) {
            System.out.print((char)is.read() + "  ");
         }
         is.close();
      } catch (IOException e) {
         System.out.print("Exception");
      }
   }
}

Directories in Java

A directory is a File that contains other files or directories.

Example: Creating Directories

import java.io.File;

public class CreateDir {
   public static void main(String args[]) {
      String dirname = "/tmp/user/java/bin";
      File d = new File(dirname);
      d.mkdirs();
   }
}

Note: Java handles path separators automatically for Windows and UNIX.

Example: Listing Directory Contents

import java.io.File;

public class ReadDir {
   public static void main(String[] args) {
      File file = null;
      String[] paths;

      try {
         file = new File("/tmp");
         paths = file.list();

         for (String path : paths) {
            System.out.println(path);
         }
      } catch (Exception e) {
         e.printStackTrace();
      }
   }
}

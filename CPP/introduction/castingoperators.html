C++ Casting Operators 🔄

A **cast** is a special **unary operator** that explicitly forces one data type to be converted into another. While C++ supports the traditional C-style cast (type) expression, it strongly encourages the use of **C++-specific type casting operators** for safety, clarity, and specific functionality.

C++ Named Casting Operators

C++ provides four specialized casting operators, each with a defined purpose, improving code readability and making it easier to search for potentially risky casts.

OperatorPurposeUse Case
static_cast<T>(expr) Performs a **non-polymorphic** cast. Casting between related types (e.g., int to float, base class pointer to derived class pointer without runtime check). It is the standard replacement for most C-style casts.
dynamic_cast<T>(expr) Performs a **runtime-checked** cast. Used exclusively on **polymorphic types** (classes with virtual functions) to safely cast a base class pointer/reference to a derived class pointer/reference. Returns nullptr or throws an exception on failure.
const_cast<T>(expr) Manipulates the **const** or **volatile** attributes. Used to add or remove const/volatile modifiers from a variable or object. This should be used sparingly as it can violate const-correctness.
reinterpret_cast<T>(expr) Performs a bitwise interpretation of the value. Used for casting between unrelated pointer types (e.g., int* to char*) or between a pointer and an integral type. This is the most dangerous cast and should only be used when low-level, implementation-dependent conversions are necessary.

Simple C-style Cast Example (Truncation)

The following example uses the C-style cast to perform a conversion from a floating-point type to an integer, which results in the **truncation** (loss) of the decimal part.

double a = 21.09399; // Floating-point value
float b = 10.20;     // Floating-point value
int c;

c = (int) a; // C-style cast: Truncates 21.09399 to 21
// Line 1 - Value of (int)a is :21
   
c = (int) b; // C-style cast: Truncates 10.20 to 10
// Line 2 - Value of (int)b is  :10

For the conversions above, the C++ standard equivalent would be: c = static_cast<int>(a); and c = static_cast<int>(b);.

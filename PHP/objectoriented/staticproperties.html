PHP: Static Properties

**Static properties** are variables that belong to the **class itself**, rather than being specific to any object instance of that class. This means all objects of the class share the *same single copy* of the static property.

Declaration and Access

  • A property is declared static using the **static** keyword, which can appear before or after the access modifier (e.g., public static $var;).
  • Static properties are **not accessible** via the object instance ($obj->var will result in a Notice).
  • They must be accessed using the **Scope Resolution Operator** (::) and the class name: MyClass::$propertyName;
  • Type hints (e.g., string, int) can be used, but the type must follow the static keyword: static private string $var1;

Accessing Static Properties Internally

To manipulate or read a static property from within the class's methods, you use special keywords:

Using self

To refer to a static property within the **current class**, use the **self** keyword, followed by the scope resolution operator and the property name (prefixed with a dollar sign):

self::$staticProperty;

Using parent

In a derived class, to access a static property defined in the **parent class**, use the **parent** keyword:

parent::$staticProperty;

Static Property vs. Constant

The key difference is **mutability** (ability to change):

  • **Constants** (const) are **immutable**; their value cannot change after declaration.
  • **Static Properties** (static) are **mutable**; their value can be changed during script execution, making them ideal for shared state like counters.

Example Session

Using a Static Property as an Object Counter

This example demonstrates how a static property ($var1) is shared across all objects of the class to maintain a running count of how many objects have been instantiated.


class myclass {
   // Shared static property, initialized to 0
   static int $var1 = 0; 

   function __construct(){
      // Increment the shared counter every time a new object is created
      self::$var1++;
      echo "object number ". self::$var1 . PHP_EOL;
   }
}

// Creating multiple objects, all sharing the same $var1 counter
$obj1 = new myclass;
$obj2 = new myclass;

// Accessing the static property outside the class
echo "Total objects created: " . myclass::$var1 . PHP_EOL; 
// Output: 
// object number 1
// object number 2
// Total objects created: 2

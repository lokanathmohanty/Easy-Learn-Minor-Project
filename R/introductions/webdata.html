R - Web Data

Many websites provide data for public consumption in formats like CSV, TXT, and XML. Using R, it is possible to programmatically extract such data by scraping websites. Common R packages for web scraping and data extraction include RCurl, XML, and stringr. These packages help connect to URLs, identify file links, and download files locally.

Install Required R Packages

install.packages("RCurl")
install.packages("XML")
install.packages("stringr")
install.packages("plyr")

Example: Download Weather Data Files

# Read the URL containing weather data files
url <- "http://www.geos.ed.ac.uk/~weather/jcmb_ws/"

# Gather all the links present on the webpage
links <- getHTMLLinks(url)

# Identify the links pointing to JCMB 2015 files
filenames <- links[str_detect(links, "JCMB_2015")]

# Store the filenames as a list
filenames_list <- as.list(filenames)

# Define a function to download files from the URL using the list of filenames
downloadcsv <- function(mainurl, filename) {
  filedetails <- str_c(mainurl, filename)
  download.file(filedetails, filename)
}

# Download all the JCMB 2015 files by applying the function over the filenames list
l_ply(filenames, downloadcsv, mainurl = "http://www.geos.ed.ac.uk/~weather/jcmb_ws/")

Verify File Download

After running the above code, the following files will be located in the current R working directory:

  • JCMB_2015.csv
  • JCMB_2015_Apr.csv
  • JCMB_2015_Feb.csv
  • JCMB_2015_Jan.csv
  • JCMB_2015_Mar.csv

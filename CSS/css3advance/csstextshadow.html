CSS - text-shadow Property

The text-shadow property is used to add a shadow effect to text. It allows you to specify the color, offset, and blur-radius of the shadow.

Possible Values

  • <color>:

    Sets the color of the shadow. It is optional and can be specified either before or after the offset values. Any value for color can be specified, such as a name, HEX, or RGB value.

  • <offset-x> <offset-y>:

    Any length value, specifying the X and Y offsets. - X value represents the shadow's horizontal distance from text. - Y value represents the shadow's vertical distance from text. If both values are 0, the shadow appears directly behind the text.

  • <blur-radius>:

    Any length value specifying the blur radius. It is optional. A higher value creates a bigger blur. If no value is provided, the default is 0.

Applies To

The text-shadow property applies to all HTML elements.

DOM Syntax

object.style.textShadow = "5px 5px 3px red";

  • The first two values (5px, 5px) specify the X and Y offsets of the shadow.
  • The third value (3px) specifies the blur radius.
  • The last value (red) specifies the shadow color.

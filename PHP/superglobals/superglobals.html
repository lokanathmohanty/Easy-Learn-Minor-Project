PHP Sessions and the `$_SESSION` Superglobal

In PHP, a **Session** is a mechanism for making data persistently accessible across multiple pages during a single user visit to a website. The primary tool for managing this data is the **`$_SESSION`** superglobal variable.

What is `$_SESSION`?

**`$_SESSION`** is an **associative superglobal array** that holds all registered session variables for the current user's session. It allows data (like user ID, preferences, or shopping cart contents) to be maintained and retrieved as the user navigates from one script to another.

How Sessions Work:

  1. The server starts a session and generates a **unique Session ID** (e.g., stored in a cookie on the user's browser).
  2. The server creates a temporary file on the server to store the session data, associated with that unique ID.
  3. All data stored in the `$_SESSION` array is written to this server-side file and is available until the session is terminated.

Managing Sessions

Starting a Session

The **`session_start()`** function must be called at the very beginning of every script that intends to use or manipulate session data. It either creates a new session or resumes the existing one using the session ID.

<?php
   **session_start();**
   // All code below can now use $_SESSION
?>

Creating and Reading Variables

Session variables are stored as key-value pairs in the `$_SESSION` array, just like any other associative array.

**Create/Set:** $_SESSION['UserID'] = $_POST['ID'];
**Read:** echo $_SESSION['Name'];

Deleting Session Data

You can remove individual variables or terminate the entire session:

  • **Remove Specific Variable:** Use **`unset()`** on the array key.
    unset($_SESSION['UserID']);
  • **Destroy All Data/Session:** Use **`session_destroy()`**. This function removes the session file from the server.
    session_destroy();

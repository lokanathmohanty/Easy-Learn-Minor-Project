HTML - Colors

HTML colors are a way of specifying the appearance of web elements. They are very important aspects of web design, as they not only enhance the visual appeal but also influence user behavior. Colors are also used to evoke emotions and highlight important content.

In HTML, colors are generally defined for backgrounds, borders, and texts. To specify the colors, the style attribute of HTML elements is used.

HTML Color Coding Methods

The following three methods are used to set colors in a web page −

  • Color names − Directly specify names like green, blue, or red.
  • Hex codes − A six-digit code representing the amount of red, green, and blue.
  • RGB values − Decimal or percentage values using the rgb() property.

HTML Color Names

W3C has listed 16 basic color names that will validate with an HTML validator, but there are over 200 different color names supported by major browsers.

W3C Standard 16 Colors

BlackGraySilverWhite
YellowLimeAquaFuchsia
RedGreenBluePurple
MaroonOliveNavyTeal

Example (Color Names)

<!DOCTYPE html>
<html>
<head>
   <title>HTML Colors by Name</title>
</head>
<body text="blue" bgcolor="green">
   <p>Use different color names for body and table and see the result.</p>
   <table bgcolor="black">
      <tr>
         <td>
            <font color="white">This text will appear white on black background.</font>
         </td>
      </tr>
   </table>
</body>
</html>

Browser Safe Colors

Web-safe colors are formed by combinations of red, green, and blue (RGB) hex values. A list of 216 colors is considered safe and consistent across all computers using a 256-color palette, ranging from #000000 (black) to #FFFFFF (white).

Setting Text Color

We use the color property in the style attribute:

<h2 style="color: Fuchsia;">Setting Text Color in HTML</h2>
<p style="color: Teal;">This line has color Teal.</p>
<p style="color: SlateBlue;">This line has color SlateBlue.</p>

Setting Background Color

We use the background-color property:

<h2 style="background-color: Fuchsia;">Setting Background Color in HTML</h2>
<p style="background-color: Teal;">This line has background color Teal.</p>
<p style="background-color: SlateBlue;">This line has background color SlateBlue.</p>

Setting Border Color

We use the border property with color:

<h2 style="border: 2.5px solid Fuchsia;">Setting Border Color in HTML</h2>
<p style="border: 2.5px dotted Teal;">This line has border color Teal.</p>
<p style="border: 2.5px dashed SlateBlue;">This line has border color SlateBlue.</p>

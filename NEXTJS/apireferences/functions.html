Next.js Function, Hook, and API Reference 📚

Next.js provides a comprehensive set of **built-in APIs, functions, and hooks** to manage data fetching, routing, and server-side operations. This reference summarizes key functions used across both the legacy Pages Router and the modern App Router.

App Router Functions & Hooks (Recommended)

These functions are primarily used in the modern **`app`** directory structure for Server and Client Components.

Function/Hook Purpose
`useParams()` Retrieves **dynamic route parameters** (e.g., `id` from `[id]`) in a **Client Component**.
`usePathname()` Provides the **current URL pathname** (e.g., `/products/123`) in a **Client Component**.
`useSearchParams()` Provides access to **URL query parameters** (e.g., `?sort=price`) in a **Client Component**.
`generateMetadata()` Generates **dynamic metadata** (title, description, SEO tags) based on route parameters or fetched data at request time.
`generateStaticParams()` Generates parameters for **dynamic routes** during **Static Site Generation (SSG)** (similar to `getStaticPaths`).
`redirect()` / `permanentRedirect()` Generates a redirection response (302 or 301 status codes) on the server.
`notFound()` Returns a **404 HTTP status** and renders the nearest `not-found.js` file.
`cookies()` / `headers()` Allows reading/manipulating **HTTP Cookies** or **Headers** in **Server Components** or Route Handlers.
`revalidatePath()` / `revalidateTag()` Manually invalidates cached data for a path or an associated fetch tag (**On-Demand Revalidation**).

Pages Router Functions & Hooks (Legacy)

These functions are specific to the legacy **`pages`** directory structure.

Function/Hook Purpose
`getStaticProps()` Fetches data at **build time** for Static Site Generation (SSG).
`getStaticPaths()` Used alongside `getStaticProps` to pre-render **dynamic routes** at build time.
`getServerSideProps()` Fetches data on the **server at request time** (Server-Side Rendering or SSR).
`getInitialProps()` Legacy method for data fetching on both server and client side.
`useRouter()` Client-side hook to access the router object for imperative navigation.
`useAmp()` Hook to detect if the current page is being rendered as an **Accelerated Mobile Page (AMP)**.

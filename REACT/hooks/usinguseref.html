ReactJS - useRef

React’s useRef hook allows direct access to DOM elements and persists values across renders without triggering re-renders. It is the function component equivalent of createRef used in class components.

Signature

const refObj = useRef(initialValue)
const domElement = refObj.current

Example: Basic Usage

import { useRef } from "react"

function Example() {
   const inputRef = useRef(null)

   return <input ref={inputRef} />
}

Example: Counter and Input

import { useState, useRef } from "react"

function RefInput() {
   const [count, setCount] = useState(0)
   const inputRef = useRef(null)
   const labelRef = useRef(null)

   const handleClick = () => setCount(count + 1)
   const handleChange = () => {
      labelRef.current.innerText =
         inputRef.current.value === "" ? "World" : inputRef.current.value
   }

   return (
      <div>
         <div>
            Counter: {count}
            <button onClick={handleClick}>+</button>
         </div>
         <div>
            <label>Enter your name:</label>
            <input type="text" ref={inputRef} onChange={handleChange} />
            <div>Hello, <span ref={labelRef}></span></div>
         </div>
      </div>
   )
}

export default RefInput

Key Points

  • useRef stores values that persist across renders.
  • Updating a ref does not trigger a re-render.
  • Refs are often used to directly interact with DOM elements.

Use Cases

  • Focusing or selecting an input element.
  • Playing or controlling audio/video with Media API.
  • Using Web Animation API for imperative animations.
  • Integrating with third-party libraries that require direct DOM access.

Summary

The useRef hook is essential when direct DOM access is required. It complements React’s declarative approach by offering a way to work with DOM APIs, animations, or third-party libraries seamlessly.

C# Quick Guide & Cheat Sheet

I. Basic Structure & Entry Point

The core structure of a C# console application:

using System; // Imports the System namespace

namespace MyApp
{
    class Program
    {
        // Entry point for all C# applications
        static void Main(string[] args)
        {
            /* Code execution starts here */
            Console.WriteLine("Hello World"); // Output to console
            Console.ReadKey();               // Waits for a key press (VS.NET only)
        }
    }
}

Case Sensitivity: C# is **case sensitive**. All statements must end with a semicolon (;).

Comments:

  • // Single-line comment
  • /* Multi-line comment */

II. Data Types

C# is strongly typed. Data types are categorized as Value Types (stored on the stack) and Reference Types (stored on the heap).

Value Types (Basic)

Type Represents Size Example Literal
int 32-bit signed integer 4 bytes 100
bool Boolean value (True/False) 1 bit true, false
char 16-bit Unicode character 2 bytes 'A'
float 32-bit floating point 4 bytes 10.5f (requires f)
double 64-bit floating point 8 bytes 10.5 (default)
decimal 128-bit precise decimal (for money) 16 bytes 10.5m (requires m)

Reference Types (Basic)

  • **string**: Sequence of Unicode characters. Alias for System.String.
    Example: string name = "Planetary Science";
  • **object**: The ultimate base class for all types.
    Example: object obj = 100; (This is **boxing**.)
  • **dynamic**: Type checking takes place at run-time, bypassing compile-time checks.

Variable Declaration

Variables must be declared before use. The **var** keyword can be used for implicitly typed local variables (type inferred by the compiler).

int age = 25;
const double Pi = 3.14159; // Constant (value cannot change)
var message = "Hello";    // Compiler knows 'message' is a string

III. Control Flow (Conditionals & Loops)

Conditional Statements

// IF-ELSE IF-ELSE
if (score >= 90) {
    Console.WriteLine("A");
} else if (score >= 80) {
    Console.WriteLine("B");
} else {
    Console.WriteLine("C");
}

// SWITCH STATEMENT
switch (day) {
    case 1:
        Console.WriteLine("Monday");
        break; // Required to exit the switch block
    case 7:
        Console.WriteLine("Sunday");
        break;
    default:
        Console.WriteLine("Other");
        break;
}

Loops (Iteration)

// FOR Loop (Known number of iterations)
for (int i = 0; i < 5; i++) {
    Console.Write(i + " "); // Output: 0 1 2 3 4
}

// FOREACH Loop (Iterating collections/arrays)
int[] numbers = {10, 20, 30};
foreach (int num in numbers) {
    Console.WriteLine(num);
}

// WHILE Loop (Condition checked before each iteration)
int j = 0;
while (j < 3) {
    Console.WriteLine(j);
    j++;
}

// DO-WHILE Loop (Executes code block at least once)
do {
    // ...
} while (condition);

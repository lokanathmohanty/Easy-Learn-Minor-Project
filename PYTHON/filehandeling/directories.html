Python - Directories

Directories, or folders, in Python are locations on the filesystem used to store files and other directories, helping organize data hierarchically. Python provides the os and os.path modules, along with shutil, for working with directories.

Checking if a Directory Exists

You can check whether a directory exists using os.path.exists(). It accepts relative or absolute path strings.

import os

directory_path = "D:\\Test\\MyFolder\\"

if os.path.exists(directory_path):
   print(f"The directory '{directory_path}' exists.")
else:
   print(f"The directory '{directory_path}' does not exist.")

Output:

The directory 'D:\Test\MyFolder\' exists.

Creating a Directory

Use os.makedirs() to create a directory, including intermediate directories if needed. You may specify permissions using the optional "mode" parameter. 

import os

new_directory = "new_dir.txt"

try:
   os.makedirs(new_directory)
   print(f"Directory '{new_directory}' created successfully.")
except OSError as e:
   print(f"Error: Failed to create directory '{new_directory}'. {e}")

Output:

Directory 'new_dir.txt' created successfully.

The mkdir() Method

Creates a directory in the current working directory.

import os

os.mkdir("test")
print("Directory created successfully")

Output:

Directory created successfully

Get Current Working Directory

Retrieve the current directory Python is operating in using os.getcwd().

import os

current_directory = os.getcwd()
print(f"Current working directory: {current_directory}")

Output:

Current working directory: /home/cg/root/667ba7570a5b7

Listing Files and Directories

List contents of a directory using os.listdir().

import os

directory_path = r"D:\MyFolder\Pictures"

try:
   contents = os.listdir(directory_path)
   print(f"Contents of '{directory_path}':")
   for item in contents:
      print(item)
except OSError as e:
   print(f"Error: Failed to list contents of directory '{directory_path}'. {e}")

Output:

Contents of 'D:\MyFolder\Pictures':
Camera Roll
desktop.ini
Saved Pictures
Screenshots

Changing the Current Working Directory

Change the current directory using os.chdir().

import os

new_directory = r"D:\MyFolder\Pictures"

try:
    os.chdir(new_directory)
    print(f"Current working directory changed to '{new_directory}'.")
except OSError as e:
    print(f"Error: Failed to change working directory to '{new_directory}'. {e}")

Output:

Current working directory changed to 'D:\MyFolder\Pictures'.

Removing a Directory

Remove an empty directory with os.rmdir(). To delete non-empty directories recursively, use shutil.rmtree().

import os
directory_path = r"D:\MyFolder\new_dir"

try:
   os.rmdir(directory_path)
   print(f"Directory '{directory_path}' successfully removed.")
except OSError as e:
   print(f"Error: Failed to remove directory '{directory_path}'. {e}")

Output:

Directory 'D:\MyFolder\new_dir' successfully removed.

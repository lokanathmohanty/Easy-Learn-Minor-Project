JavaScript Window Object

Introduction

The JavaScript window object represents the browser's window. It is a global object that contains methods and properties to access and manipulate the browser window. All global variables and functions become properties and methods of the window object.

Window Object as a Global Object

Since window is global, you can access global variables, functions, and objects using the window object anywhere in your code.

Example: Global vs Local Variables

In the example below, the global variable is accessed using window while the local one is not.

Example Code

<html>
<body>
  <div id="output1">Global num: </div>
  <div id="output2">Local num: </div>
  <div id="output3">Car brand: </div>
  <script>
    var num = 100;
    const car = { brand: "Honda", model: "City" };
    
    function test() {
      let num = 300;
      document.getElementById("output1").innerHTML += window.num;
      document.getElementById("output2").innerHTML += num;
      document.getElementById("output3").innerHTML += car.brand;
    }
    test();
  </script>
</body>
</html>

Output

  • Global num: 100
  • Local num: 300
  • Car brand: Honda

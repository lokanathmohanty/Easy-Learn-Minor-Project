ReactJS - Architecture

React is built on a simple, flexible, and extensible foundation. Its primary purpose is to let developers build user interfaces using pure JavaScript without introducing a new template language. Instead of templates, React relies on three core concepts:

  • React Elements – JavaScript representation of the HTML DOM, created using React.createElement.
  • JSX – A JavaScript extension with HTML-like syntax, compiled into React elements.
  • React Components – The primary building blocks of a React app, written as JavaScript classes or functions with properties, state, and lifecycle methods.

Architecture of a React Application

React is just a UI library and does not enforce strict design patterns. Developers are free to adopt their own architectures, but the community often recommends patterns like Flux. React also supports concepts such as Higher Order Components, Context, Render Props, Refs, and Hooks for state management in larger projects.

The high-level architecture of a React application is:

  • A React app starts with a single root component.
  • The root component is composed of multiple nested components.
  • Components are composed, not inherited, and can be reused at different levels.
  • Most components focus on UI, but third-party libraries can be integrated for routing, animations, and state management.

Workflow of a React Application

To better understand React's workflow, let's consider a simple example:

Example using React.createElement

<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8" />
    <title>React Application</title>
  </head>
  <body>
    <div id="react-app"></div>
    <script src="https://unpkg.com/react@17/umd/react.development.js"></script>
    <script src="https://unpkg.com/react-dom@17/umd/react-dom.development.js"></script>
    <script>
      element = React.createElement('h1', {}, 'Hello React!');
      ReactDOM.render(element, document.getElementById('react-app'));
    </script>
  </body>
</html>

Here, React.createElement creates elements, and ReactDOM.render renders them into the root container.

Nested Elements

<script>
  element = React.createElement('div', {},
    React.createElement('h1', {}, 'Hello React!')
  );
  ReactDOM.render(element, document.getElementById('react-app'));
</script>

Using JSX

<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8" />
    <title>React Application</title>
  </head>
  <body>
    <div id="react-app"></div>
    <script src="https://unpkg.com/react@17/umd/react.development.js"></script>
    <script src="https://unpkg.com/react-dom@17/umd/react-dom.development.js"></script>
    <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
    <script type="text/babel">
      ReactDOM.render(
        <div><h1>Hello React!</h1></div>,
        document.getElementById('react-app')
      );
    </script>
  </body>
</html>

Component Example

<script type="text/babel">
  function Greeting() {
    return <div><h1>Hello JSX!</h1></div>;
  }
  ReactDOM.render(<Greeting />, document.getElementById('react-app'));
</script>

React Application Workflow

  1. React components (JSX or elements) are passed to ReactDOM.render along with the root container.
  2. React converts JSX into elements and builds a Virtual DOM.
  3. The Virtual DOM is compared to the previous state and merged with the real DOM efficiently.
  4. The browser displays the updated UI with minimal re-rendering.

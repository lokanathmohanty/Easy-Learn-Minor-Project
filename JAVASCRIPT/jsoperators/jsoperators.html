JavaScript - Operators

What is an Operator?

In JavaScript, an operator is a symbol that performs an operation on one or more operands, such as variables or values, and returns a result. For example, in the expression 4 + 5, the numbers 4 and 5 are operands, while + is the operator.

JavaScript supports the following types of operators:

  • Arithmetic Operators
  • Comparison Operators
  • Logical (or Relational) Operators
  • Bitwise Operators
  • Assignment Operators
  • Miscellaneous Operators

JavaScript Arithmetic Operators

Arithmetic operators are used to perform mathematical calculations such as addition, subtraction, multiplication, division, etc.

Assume variable x = 10 and y = 20:

  • + (Addition): x + y → 30
  • - (Subtraction): x - y → -10
  • * (Multiplication): x * y → 200
  • / (Division): y / x → 2
  • % (Modulus): y % x → 0
  • ++ (Increment): x++ → 11
  • -- (Decrement): x-- → 9

Addition also works on strings, e.g., "a" + 10 → "a10".

JavaScript Comparison Operators

Comparison operators compare two values and return a boolean result (true or false).

Assume x = 10 and y = 20:

  • == (Equal): (x == y) → false
  • != (Not Equal): (x != y) → true
  • === (Strict Equality): (x === y) → false
  • !== (Strict Inequality): (x !== y) → true
  • > (Greater Than): (x > y) → false
  • < (Less Than): (x < y) → true
  • >= (Greater Than or Equal): (x >= y) → false
  • <= (Less Than or Equal): (x <= y) → true

JavaScript Logical Operators

Logical operators are used to perform logical operations on boolean values. Assume x = 10 and y = 0:

  • && (Logical AND): (x && y) → false
  • || (Logical OR): (x || y) → true
  • ! (Logical NOT): !x → false

JavaScript Bitwise Operators

Bitwise operators perform operations at the binary level. Assume x = 2 and y = 3:

  • & (AND): (x & y) → 2
  • | (OR): (x | y) → 3
  • ^ (XOR): (x ^ y) → 1
  • ~ (NOT): (~y) → -4
  • << (Left Shift): (x << 1) → 4
  • >> (Right Shift): (x >> 1) → 1
  • >>> (Zero Fill Right Shift): (x >>> 1) → 1

JavaScript Assignment Operators

Assignment operators are used to assign values to variables:

  • = (Simple Assignment): z = x + y
  • += (Add and Assign): z += x → z = z + x
  • -= (Subtract and Assign): z -= x → z = z - x
  • *= (Multiply and Assign): z *= x → z = z * x
  • /= (Divide and Assign): z /= x → z = z / x
  • %= (Modulus and Assign): z %= x → z = z % x
  • Also applies to bitwise: <<=, >>=, &=, |=, ^=

JavaScript Miscellaneous Operators

  • ? : (Conditional): condition ? value1 : value2
  • typeof: returns data type
  • ?? (Nullish Coalescing): returns right-hand side if left is null/undefined
  • delete: removes a property from an object
  • , (Comma): evaluates multiple expressions and returns last
  • () (Grouping): changes precedence
  • yield: pauses/resumes a generator
  • ... (Spread): expands iterables like arrays or strings
  • ** (Exponentiation): raises to a power (x ** y)

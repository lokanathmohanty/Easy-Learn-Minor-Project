Flask Overview and Core Components

What is a Web Framework?

A **Web Application Framework** (or simply Web Framework) is a collection of libraries and modules that allows developers to write web applications without having to manage **low-level details** like network protocols and thread management. It abstracts away common boilerplate tasks, letting you focus on the application's unique logic.

What is Flask?

Flask is a web application framework written in **Python**. It was developed by **Armin Ronacher** of the international Python group **Pocco** (now the Pallets Project).

The "Microframework" Concept

Flask is known as a **microframework** because its core is designed to be **simple and extensible**. It intentionally omits built-in features for certain functionalities, such as:

  • Database abstraction layers (ORM)
  • Form validation support

Instead, Flask encourages the use of **extensions** to add these capabilities, giving developers full control over their architectural choices.

Flask's Core Bases

Flask is built upon two essential Pocco projects that handle the communication and presentation layers:

  • WSGI (Web Server Gateway Interface): This is a specification that defines a **universal interface** for communication between web servers and Python web applications.
  • Werkzeug: This is the **WSGI toolkit** that Flask uses. It implements core features like handling HTTP **request and response objects** and other utility functions, forming a basis for the framework.
  • Jinja2: This is a popular **templating engine** for Python. It allows developers to combine a template (HTML structure) with a data source (Python variables) to render **dynamic web pages**.

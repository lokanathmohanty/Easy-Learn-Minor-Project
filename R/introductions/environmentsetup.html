R - Environment Setup

If you are still willing to set up your environment for R, you can follow the steps given below.

Windows Installation

You can download the Windows installer version of R from R-4.5.1 for Windows (32/64 bit) and save it in a local directory.

As it is a Windows installer (.exe) with the name "R-version-win.exe", you can just double click and run the installer accepting the default settings. If your Windows is 32-bit version, it installs the 32-bit version. But if your Windows is 64-bit, then it installs both the 32-bit and 64-bit versions.

After installation, you can locate the icon to run the program in the directory structure R\R4.5.1\bin\i386\Rgui.exe under the Windows Program Files. Clicking this icon brings up the R-GUI which is the R console to do R Programming.

Linux Installation

R is available as a binary for many versions of Linux at the location R Binaries.

The instruction to install Linux varies from flavor to flavor. These steps are mentioned under each type of Linux version at the aforementioned link. However, if you are in a hurry, then you can use yum command to install R as follows: 

$ yum install R

The above command will install the core functionality of R programming along with standard packages. Still, if you need additional packages, then you can launch R prompt as follows: 

$ R

Now you can use install command at R prompt to install the required package. For example, the following command will install the plotrix package which is required for 3D charts: 

> install.packages("plotrix")

Example: Installing plotrix Package in R

To install the plotrix package in R, after launching R prompt, type the command: 

> install.packages("plotrix")

This command downloads and installs the package required for creating 3D charts in R.

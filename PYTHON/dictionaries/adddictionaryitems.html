Python - Add Dictionary Items

Adding dictionary items in Python means inserting new key-value pairs into an existing dictionary. Dictionaries are mutable, so their contents can be dynamically updated.

Common ways to add items include using square brackets, update(), unpacking, union operators, setdefault(), and collections.defaultdict().

Add Item Using Square Brackets []


marks = {"Savita": 67, "Imtiaz": 88, "Laxman": 91, "David": 49}
print("Initial dictionary:", marks)

marks["Kavya"] = 58    # Add new key-value pair
print("Dictionary after new addition:", marks)

Output:

Initial dictionary: {'Savita': 67, 'Imtiaz': 88, 'Laxman': 91, 'David': 49}
Dictionary after new addition: {'Savita': 67, 'Imtiaz': 88, 'Laxman': 91, 'David': 49, 'Kavya': 58}

Add Multiple Items Using update() Method


marks = {"Savita": 67, "Imtiaz": 88}
print("Initial dictionary:", marks)

marks.update({'Kavya': 58, 'Mohan': 98})    # Add multiple pairs
print("Dictionary after new addition:", marks)

Output:

Initial dictionary: {'Savita': 67, 'Imtiaz': 88}
Dictionary after new addition: {'Savita': 67, 'Imtiaz': 88, 'Kavya': 58, 'Mohan': 98}

Add Items Using Unpacking Operator


marks = {"Savita": 67, "Imtiaz": 88, "Laxman": 91, "David": 49}
marks1 = {"Sharad": 51, "Mushtaq": 61, "Laxman": 89}

newmarks = {**marks, **marks1}   # Combining dictionaries
print("Marks after update:")
print(newmarks)

Output:

Marks after update:
{'Savita': 67, 'Imtiaz': 88, 'Laxman': 89, 'David': 49, 'Sharad': 51, 'Mushtaq': 61}

Add Items Using Union Operator |


marks = {"Savita": 67, "Imtiaz": 88, "Laxman": 91, "David": 49}
marks1 = {"Sharad": 51, "Mushtaq": 61, "Laxman": 89}

newmarks = marks | marks1    # Merge dictionaries
print("Marks after update:")
print(newmarks)

Output:

Marks after update:
{'Savita': 67, 'Imtiaz': 88, 'Laxman': 89, 'David': 49, 'Sharad': 51, 'Mushtaq': 61}

Add Items Using |= Operator


marks = {"Savita": 67, "Imtiaz": 88, "Laxman": 91, "David": 49}
marks1 = {"Sharad": 51, "Mushtaq": 61, "Laxman": 89}

marks |= marks1     # Update marks in-place
print("Marks after update:")
print(marks)

Output:

Marks after update:
{'Savita': 67, 'Imtiaz': 88, 'Laxman': 89, 'David': 49, 'Sharad': 51, 'Mushtaq': 61}

Add Item Using setdefault() Method


student = {"name": "Alice", "age": 21}

# Adds "major":"Computer Science" only if key is absent
major = student.setdefault("major", "Computer Science")
print(student)

Output:

{'name': 'Alice', 'age': 21, 'major': 'Computer Science'}

Add Items Using collections.defaultdict() Method


from collections import defaultdict

# Default value 0 for missing keys
d = defaultdict(int)
d["a"] += 1
print(d)

# Default empty list for missing keys
d = defaultdict(list)
d["b"].append(1)
print(d)

# Using custom default factory function
def default_value():
    return "N/A"

d = defaultdict(default_value)
print(d["c"])

Output:

defaultdict(, {'a': 1})
defaultdict(, {'b': [1]})
N/A

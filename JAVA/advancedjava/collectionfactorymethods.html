Java Collection Factory Methods (Java 9+)

Introduction to Collection Factory Methods

In **Java 9**, static **factory methods** were added to the **List**, **Set**, and **Map** interfaces. These methods provide a concise and less verbose way to create **immutable** (unmodifiable) instances of these collections.

The primary benefit is developer convenience, as they eliminate the multi-step process previously required to create and then wrap a mutable collection using Collections.unmodifiableList/Set/Map().

Factory Methods for List and Set

The **List** and **Set** interfaces gained overloaded static of() methods:

  • **static <E> List<E> of(E... elements)**
  • **static <E> Set<E> of(E... elements)**

There are also several overloaded methods (up to 10 elements) for performance reasons, but the variadic (...) version handles any number of elements.

Key Features of List.of() and Set.of()

  • They return an **immutable** collection. Any attempt to add, remove, or modify an element will result in an UnsupportedOperationException.
  • They **do not allow null elements**. Passing a null element will immediately throw a NullPointerException.
  • For Set.of(), passing **duplicate elements** in the input will throw an IllegalArgumentException.

List and Set Syntax Comparison

Pre-Java 9 (Verbose, Multi-Step)

// List Example
List<String> list = new ArrayList<>();
list.add("A");
list.add("B");
list = Collections.unmodifiableList(list);

// Set Example
Set<String> set = new HashSet<>();
set.add("A");
set.add("B");
set = Collections.unmodifiableSet(set);

Java 9+ (Concise, Single-Step)

// List Example
List<String> list = List.of("A", "B", "C");

// Set Example
Set<String> set = Set.of("A", "B", "C");

Factory Methods for Map

The **Map** interface was also enhanced with static factory methods. Since maps require both keys and values, the of() methods take them in pairs:

  • **static <K, V> Map<K, V> of(K k1, V v1, K k2, V v2, ...)** (Up to 10 key-value pairs)
  • **static <K, V> Map<K, V> ofEntries(Map.Entry<? extends K, ? extends V>... entries)** (For more than 10 pairs or dynamically created entries)

Key Features of Map.of()

  • It returns an **immutable** map.
  • It **does not allow null keys or null values**.
  • It **does not allow duplicate keys**. Passing duplicate keys will result in an IllegalArgumentException.
  • The map's iteration order is typically unspecified.

Map Syntax Comparison

Pre-Java 9 (Verbose, Multi-Step)

Map<String, String> map = new HashMap<>();
map.put("A", "Apple");
map.put("B", "Boy");
map = Collections.unmodifiableMap(map);

Java 9+ (Concise, Single-Step)

Map<String, String> map = Map.of("A", "Apple", "B", "Boy", "C", "Cat");

Python - Tools/Utilities

The Python standard library comes with a number of modules that can be used both as modules and as command-line utilities. These tools help with debugging, profiling, disassembling, and checking code formatting.

The dis Module

The dis module is the Python disassembler. It converts byte codes into a human-readable format. You can run the disassembler from the command line, or as a module in your code.

Example:

import dis
def sum():
   vara = 10
   varb = 20

   sum = vara + varb
   print("vara + varb = %d" % sum)

# Call dis function for the function.
dis.dis(sum)

The pdb Module

The pdb module is the standard Python debugger. It is based on the bdb debugger framework. You can step through code line by line and inspect values at runtime.

Example:

$pdb.py sum.py
> /test/sum.py(3)()
-> import dis
(Pdb) n
> /test/sum.py(5)()
-> def sum():
(Pdb) n
>/test/sum.py(14)()
-> dis.dis(sum)
(Pdb) n
...

The profile Module

The profile module is the standard Python profiler. It measures performance and reports how much time each function takes.

Example:

vara = 10
varb = 20
sum = vara + varb
print("vara + varb = %d" % sum)

Run profiler:

$cProfile.py sum.py
vara + varb = 30
   4 function calls in 0.000 CPU seconds
   Ordered by: standard name
ncalls   tottime  percall  cumtime  percall filename:lineno
 1       0.000    0.000    0.000    0.000 :1()
 1       0.000    0.000    0.000    0.000 sum.py:3()
...

The tabnanny Module

The tabnanny module checks Python source files for ambiguous indentation. If a file mixes tabs and spaces inconsistently, it reports an error.

Example:

vara = 10
varb = 20

sum = vara + varb
print("vara + varb = %d" % sum)

Run tabnanny:

$tabnanny.py -v sum.py
'sum.py': Clean bill of health.

Django: Asynchronous JavaScript and XML (AJAX) 🌐

AJAX is a technology that allows web applications to send and retrieve data from a server asynchronously (in the background) without interfering with the display and behavior of the existing page. This greatly enhances the end-user experience by reducing full page loads.

Two Ways to Use AJAX in Django:

  1. **Direct Use:** Manually implement AJAX using a JavaScript library like **jQuery** or Axios to handle the client-side requests, and then write a standard Django function-based view to handle the request and return JSON/HTML data.
  2. **Django Frameworks:** Use specialized Django packages like **django-dajax** (now largely obsolete, but featured in the source text) which abstracts much of the JavaScript code, allowing the developer to write asynchronous presentation logic almost entirely in Python.

Using the Django-Dajax Framework (Conceptual Example)

The django-dajax framework simplifies the AJAX workflow by linking Python functions directly to client-side calls.

Setup and Configuration (settings.py)

After installing django-dajax and its dependency django-dajaxice, both must be added to INSTALLED_APPS, and specific configuration options for static files and template processors must be set to ensure Dajax can find its necessary JavaScript files and function mappings:

INSTALLED_APPS += ('dajaxice', 'dajax')

STATICFILES_FINDERS = (
   # ... default finders ...
   'dajaxice.finders.DajaxiceFinder',
)
DAJAXICE_MEDIA_PREFIX = 'dajaxice'

Defining the AJAX Function (ajax.py)

The server-side logic that runs asynchronously is defined in a separate ajax.py file within the app. The **@dajaxice_register** decorator exposes the Python function to be called from the client side.

from dajax.core import Dajax
from dajaxice.utils import deserialize_form
from myapp.form import DreamrealForm

@dajaxice_register
def send_form(request, form):
   dajax = Dajax()
   form = DreamrealForm(deserialize_form(form))
   
   if form.is_valid():
      # Server-side logic to save the data...
      dr.save()
      
      # Client-side command: Show an alert popup
      dajax.alert("Dreamreal Entry %s was successfully saved." % 
         form.cleaned_data.get('name'))
   else:
      # Client-side command: Add an 'error' CSS class to fields
      for error in form.errors:
         dajax.add_css_class('#id_%s' % error, 'error')
			
   return dajax.json() # Return JSON response containing client commands

Client-Side Template (dreamreal.html)

The template must load the necessary JavaScript files (jQuery and Dajax's core file). The form submission is tied to a JavaScript function that uses the Dajaxice utility to call the corresponding Python function:

<!-- Load tags and Dajax/jQuery scripts -->
{% load static %}{% load dajaxice_templatetags %}
<script src = "path/to/jquery.js"></script>
<script src = "path/to/dajax.core.js"></script>
{% dajaxice_js_import %}

<script>
   function send_form(){
      // Call the Python function, passing the serialized form data
      Dajaxice.myapp.send_form(Dajax.process,{'form':$('#my_form').serialize(true)});
   }
</script>

<form id = "my_form" ... >
   {{ form.as_p }}
   <input type = "button" value = "Send" onclick = "send_form();"> <!-- Triggers AJAX function -->
</form>

The Dajax framework handles packaging the client-side request and interpreting the Python function's dajax.json() output to execute JavaScript commands in the browser.

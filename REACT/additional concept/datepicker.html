ReactJS - Date Picker

React provides form components through third-party UI libraries. One popular option is React Bootstrap, which offers a date picker component built on top of Bootstrap styles and components.

What is a Date Picker?

A date picker allows users to easily select a date instead of typing it manually. The HTML <input type="date"> enables this feature natively.

<input type="date">

In React Bootstrap, the Form.Control component is used to render input elements, including a date picker.

Useful Props

  • ref − Ref to access the underlying DOM node.
  • as − Specify a different element instead of input.
  • disabled − Enable or disable the control.
  • id − Identifier for the control element.
  • isInvalid / isValid − Mark input as invalid or valid.
  • plaintext − Render as plain text (with readOnly).
  • readOnly − Make the input read-only.
  • size − Control size (sm or lg).
  • type − Input type (e.g., date, text).
  • value − Current value, updated via onChange.
  • onChange − Callback when the value changes.

Example

A simple form using a date picker in React Bootstrap:

import { Form, Button } from 'react-bootstrap';

function SimpleDatePicker() {
   return (
      <Form>
         <Form.Group className="mb-3" controlId="name">
            <Form.Label>Name</Form.Label>
            <Form.Control type="name" placeholder="Enter your name" />
         </Form.Group>
         
         <Form.Group className="mb-3" controlId="dob">
            <Form.Label>Date of birth</Form.Label>
            <Form.Control type="date" />
         </Form.Group>

         <Button variant="primary" type="submit">
            Submit
         </Button>
      </Form>
   );
}

export default SimpleDatePicker;

This example demonstrates using Form.Control with type="date" inside a form component.

Summary

The React Bootstrap date picker simplifies handling date input in forms. It leverages Form.Control with type="date" and integrates seamlessly with other Bootstrap form elements.

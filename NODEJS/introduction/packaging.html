Node.js - Packaging

Overview

Large Node.js projects with many dependencies and assets require packaging for easy distribution and deployment across environments. Packaging bundles the code, dependencies, and assets into a single executable or deployable package.

Nexe Packaging Tool

Nexe is a CLI utility that compiles Node.js applications into single executable files, including all dependencies and assets.

Installing Nexe on Windows

  • Install globally using: npm install nexe -g
  • Install NASM tool from www.nasm.us
  • Python version 3.7 to 3.11 required
  • Install Visual Studio 2022 Desktop Development with C++ workload

Building Executable

Run this command from project directory:

nexe index.js --build windows-x64-20.9.0 verbose

Compiles your Node.js app into self-contained expressApp.exe, including source, dependencies, and assets.

Other Packaging Tools

pkg Tool

CLI tool to create executables for Windows, macOS, and Linux from Node.js projects without requiring Node.js on target machines. 

npm install -g pkg
pkg myapp.js

JXCore

An open-source project to package and encrypt source files and assets into JX packages for deployment. 

jx package index.js index
// produces index.jxp and index.jx files
jx index.jx command_line_arguments

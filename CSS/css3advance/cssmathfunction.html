CSS - Math Functions

CSS math functions allow you to perform mathematical calculations directly in your CSS stylesheets. These functions can be used to manipulate values such as lengths, angles, colors, and more.

Types of Mathematical Functions in CSS

There are several types of math functions that can be used in CSS. They include:

  • Basic Arithmetic Functions: Includes the calc() function for performing calculations on numerical values.
  • Comparison Functions: Includes functions like min(), max(), and clamp() for comparing variables.
  • Stepped Value Functions: Includes the round() function for calculating a rounded number based on a rounding strategy.
  • Trigonometric Functions: Functions such as sin(), cos(), and tan() introduce mathematical calculations into stylesheets.

The calc() Function

The calc() function allows you to perform calculations on numerical values. It can be used to dynamically modify property values by carrying out addition, subtraction, multiplication, and division.

Example

Here’s an example demonstrating the usage of the calc() function:

.box {
    width: calc(100% - 40px); 
    height: calc(100% - 20px); 
}

The max() Function

The max() function determines the maximum value from a given list of values. It helps apply conditional styling by choosing the larger value.

Example

.box {
    width: max(200px, 50%);
}

The min() Function

The min() function determines the minimum value from a given list of values. It helps apply conditional styling by choosing the smaller value.

Example

.box {
    width: min(200px, 50%);
}

Comparison Functions

CSS comparison functions make it easier to assess values and apply conditional styling.

  • min(): Determines the minimum value from a set of values.
  • max(): Determines the maximum value from a set of values.
  • clamp(): Calculates the central value between a minimum, preferred, and maximum value.

Stepped Value Functions

These functions allow precise control with discrete jumps in property values.

  • round(): Calculates a rounded number based on a specified rounding strategy.

Trigonometric Functions

CSS trigonometric functions allow complex design alterations by using mathematical sine, cosine, and tangent calculations.

  • sin(): Calculates the sine of a number.
  • cos(): Calculates the cosine of a number.
  • tan(): Calculates the tangent of a number.
  • asin(): Calculates the inverse sine of a number.
  • acos(): Calculates the inverse cosine of a number.
  • atan(): Calculates the inverse tangent of a number.
  • atan2(): Calculates the inverse tangent of two numbers in a plane.

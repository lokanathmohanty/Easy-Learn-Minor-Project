R - Pie Charts

R provides several libraries to create charts and graphs. A pie chart represents data as slices of a circle, with each slice corresponding to a category or value. The pie() function in R creates pie charts with options for adding labels, titles, colors, and legends.

Basic Syntax

pie(x, labels, radius, main, col, clockwise)
  • x: Vector of numeric values for slices
  • labels: Descriptions for each slice
  • radius: Radius of the pie chart (between -1 and +1)
  • main: Title of the chart
  • col: Color palette for slices
  • clockwise: Draw slices clockwise/anticlockwise

Simple Pie Chart Example

# Create data and labels
x <- c(21, 62, 10, 53)
labels <- c("London", "New York", "Singapore", "Mumbai")

# Save file
png(file = "city.png")

# Create pie chart
pie(x, labels)

# Save file
dev.off()

Pie Chart with Title and Colors

x <- c(21, 62, 10, 53)
labels <- c("London", "New York", "Singapore", "Mumbai")

png(file = "city_title_colours.jpg")
pie(x, labels, main = "City pie chart", col = rainbow(length(x)))
dev.off()

Slice Percentages and Chart Legend

x <- c(21, 62, 10, 53)
labels <- c("London", "New York", "Singapore", "Mumbai")
piepercent <- round(100*x/sum(x), 1)

png(file = "city_percentage_legends.jpg")
pie(x, labels = piepercent, main = "City pie chart", col = rainbow(length(x)))
legend("topright", c("London","New York","Singapore","Mumbai"), cex = 0.8, fill = rainbow(length(x)))
dev.off()

3D Pie Chart

# Load package
library(plotrix)

# Data and labels
x <- c(21, 62, 10, 53)
lbl <- c("London","New York","Singapore","Mumbai")

png(file = "3d_pie_chart.jpg")
pie3D(x, labels = lbl, explode = 0.1, main = "Pie Chart of Countries")
dev.off()

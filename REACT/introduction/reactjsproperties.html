ReactJS - Properties (props)

React enables developers to create dynamic and advanced components using properties (props). Every component can have attributes similar to HTML attributes, and each attribute's value can be accessed inside the component using this.props.

For example, in the Hello component with a name attribute: 

<Hello name="React" />
// Accessed inside component as this.props.name

React properties support attribute values of different types:

  • String
  • Number
  • Datetime
  • Array
  • List
  • Objects

Using Props

When we need immutable data in a component, we can pass it as props through the ReactDOM.render() function and use it inside the component. 

// App.jsx
import React from 'react';

class App extends React.Component {
   render() {
      return (
         <div>
            <h1>{this.props.headerProp}</h1>
            <h2>{this.props.contentProp}</h2>
         </div>
      );
   }
}
export default App;

// main.js
import React from 'react';
import ReactDOM from 'react-dom';
import App from './App.jsx';

ReactDOM.render(
   <App headerProp="Header from props..." contentProp="Content from props..."/>, 
   document.getElementById('app')
);

Output: Displays the header and content passed as props.

Default Props

You can also set default property values directly on the component using defaultProps instead of passing them through ReactDOM.render(). 

// App.jsx
import React from 'react';

class App extends React.Component {
   render() {
      return (
         <div>
            <h1>{this.props.headerProp}</h1>
            <h2>{this.props.contentProp}</h2>
         </div>
      );
   }
}

App.defaultProps = {
   headerProp: "Header from props...",
   contentProp: "Content from props..."
}
export default App;

// main.js
import React from 'react';
import ReactDOM from 'react-dom';
import App from './App.jsx';

ReactDOM.render(<App/>, document.getElementById('app'));

Output: Same as before, but now using default props.

State vs Props

The following example shows how to combine state and props. The parent component sets the state and passes it down to child components as props. 

// App.jsx
import React from 'react';

class App extends React.Component {
   constructor(props) {
      super(props);
      this.state = {
         header: "Header from props...",
         content: "Content from props..."
      }
   }
   render() {
      return (
         <div>
            <Header headerProp={this.state.header}/>
            <Content contentProp={this.state.content}/>
         </div>
      );
   }
}

class Header extends React.Component {
   render() {
      return (
         <div>
            <h1>{this.props.headerProp}</h1>
         </div>
      );
   }
}

class Content extends React.Component {
   render() {
      return (
         <div>
            <h2>{this.props.contentProp}</h2>
         </div>
      );
   }
}
export default App;

// main.js
import React from 'react';
import ReactDOM from 'react-dom';
import App from './App.jsx';

ReactDOM.render(<App/>, document.getElementById('app'));

Output: Same as previous examples. The difference is that the data now comes from the component's state. Updating the state automatically updates all child components.

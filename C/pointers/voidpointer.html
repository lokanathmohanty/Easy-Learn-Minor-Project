void Pointer in C

What Is a void Pointer?

A void pointer (written void *) is a special pointer type that is not associated with any specific data type. It is a generic pointer that can hold the address of any data type (except function types in a portable manner). :contentReference[oaicite:0]{index=0}

Declaring a void Pointer

Syntax:

void *ptr;

Example of void Pointer Usage

#include <stdio.h>

int main() {
  int a = 10;
  char b = 'x';

  // void pointer holds address of int a
  void *ptr = &a;
  printf("Address of 'a': %p\n", &a);
  printf("Void pointer points to: %p\n", ptr);

  // now assign it to point to char b
  ptr = &b;
  printf("Address of 'b': %p\n", &b);
  printf("Void pointer points to: %p\n", ptr);

  return 0;
}

Output will show the addresses (in pointer form) of a and b and how ptr can point to both.

Array of void Pointers

You can create an array of void * pointers to hold addresses of different types:

#include <stdio.h>

int main() {
  void *arr[3];
  int a = 100;
  float b = 20.5;
  char *c = "Hello";

  arr[0] = &a;
  arr[1] = &b;
  arr[2] = &c;

  printf("Integer: %d\n", *((int *)arr[0]));
  printf("Float: %f\n", *((float *)arr[1]));
  printf("String: %s\n", *((char **)arr[2]));

  return 0;
}

Applications of void Pointers

  • The malloc() and calloc() functions return void * so they can allocate memory for any data type. :contentReference[oaicite:1]{index=1}
  • Used in writing generic functions (e.g. library routines) that need to handle different data types. :contentReference[oaicite:2]{index=2}
  • Implementing flexible data structures (linked lists, trees) with generic payload types. :contentReference[oaicite:3]{index=3}

Limitations of void Pointers

  • You cannot dereference a void * directly because its pointed-to type is unknown. You must cast it back to a concrete pointer type first. :contentReference[oaicite:4]{index=4}
  • Pointer arithmetic (e.g. ptr + 1) is not allowed on void * because the size of the underlying type is unknown. :contentReference[oaicite:5]{index=5}

CSS Interview Questions

CSS stands for Cascading Style Sheets and is used to define the visual appearance and layout of web pages. CSS was first introduced by Håkon Wium Lie in 1996 to separate content structure from presentation for making it easier to style web pages.

This article presents a list of commonly asked CSS questions, categorized into beginner, intermediate, and advanced levels. Questions often start with basics and progress based on your answers.

Basic CSS Questions and Answers

1. What is CSS?

CSS (Cascading Style Sheets) is a language used to style and format the layout of web pages written in HTML. It allows customization of colors, fonts, spacing, and page layout.

2. What are the advantages of using CSS?

  • Pages load faster due to reduced code repetition.
  • Easy maintenance with global style changes.
  • Provides more styling options compared to HTML.
  • Supports multiple device compatibility with responsive design.
  • Follows global web standards as HTML attributes are deprecated.

3. What are the drawbacks of CSS?

  • Browser compatibility issues across different versions.
  • Complexity in managing large projects.
  • No built-in security.
  • Global scope may lead to unintended styling conflicts.

4. What is the difference between CSS and CSS3?

CSS3 introduces advanced features like selectors, media queries, animations, and gradients, which were not supported in earlier versions of CSS.

5. What is the syntax for CSS Style?


selector {
    property: value;
}

The selector targets elements, and the declaration block contains one or more property-value pairs.

6. How to add CSS to an HTML page?

  • Internal CSS – inside a <style> tag within HTML.
  • External CSS – linked via an external stylesheet.
  • Inline CSS – applied directly using the "style" attribute.

7. Which type of CSS has the highest priority?

Inline CSS has the highest priority, followed by internal CSS, then external CSS.

8. What are selectors in CSS?

Selectors define which HTML elements to style. Examples: class selectors, ID selectors, element selectors, attribute selectors, and pseudo-classes.

9. What is a universal selector?


* {
    margin: 0;
    padding: 0;
}

It applies styles to all elements in the document.

10. What is a class selector?


.black {
    color: #000000;
}

Targets elements with a specific class attribute.

11. What is an ID selector?


#main-heading {
    color: #333333;
}

Targets a unique element with a given ID.

12. What is an element selector?


p {
    font-size: 16px;
}

Applies style to all elements of the specified type.

13. What is an attribute selector?


a[target="_blank"] {
    color: blue;
    text-decoration: underline;
}

Targets elements based on attribute values.

14. How to add comments in CSS?


/* This is a comment */
p {
    color: red; /* Inline comment */
}

15. How to set color in CSS?


p {
    color: red;
    color: #ff0000;
    color: rgb(255, 0, 0);
    color: rgba(255, 0, 0, 0.5);
    color: hsl(0, 100%, 50%);
    color: hsla(0, 100%, 50%, 0.5);
}

16. What are CSS background properties?

  • background-color
  • background-image
  • background-position
  • background-size

17. What is transition in CSS?


.button {
    background-color: lightblue;
    transition: background-color 0.3s ease;
}
.button:hover {
    background-color: deepskyblue;
}

18. How to hide an element in CSS?


.hidden {
    display: none;
}
.invisible {
    visibility: hidden;
}

19. Difference between margin and padding

Margin is space outside the element. Padding is space inside the element, between content and border.

20. Explain CSS Box Model

The box model consists of content, padding, border, and margin. It defines how elements are sized and spaced in a layout.

C# Namespaces

Purpose of Namespaces

A **namespace** is designed to provide a way to keep one set of names separate from another. Its primary function is to organize code and prevent naming conflicts between classes, structs, enums, and other types, particularly in large applications or when using external libraries.

For example, you can declare a class named Logger in two different namespaces (e.g., App.Utilities and App.Services) without conflict.

Defining and Accessing a Namespace

Declaration Syntax:

A namespace definition begins with the keyword **`namespace`** followed by the chosen name and enclosed in curly braces.

namespace MyCompanyName.ProjectName {
   // All code declarations (classes, interfaces, etc.) here
}

Fully Qualified Name:

To access a member (like a class) that belongs to a namespace, you use the **fully qualified name** by prepending the namespace name and using the dot (`.`) operator.

// Example using System namespace
System.Console.WriteLine("Hello there"); 

// Example using a custom namespace
first_space.namespace_cl fc = new first_space.namespace_cl();
fc.func();

The `using` Keyword

The **`using`** keyword is a directive that imports the names from a specified namespace, allowing you to use the members of that namespace directly without needing to prepend the fully qualified name.

using System;      // Allows direct use of Console, String, etc.
using first_space; // Allows direct use of 'namespace_cl' within the program

class TestClass {
   static void Main(string[] args) {
      // Direct use of Console due to 'using System;'
      Console.WriteLine("Starting program..."); 
   }
}

If two imported namespaces contain classes with the same name, a conflict occurs, and you must revert to using the fully qualified name or use a **`using alias`** (e.g., using FC = first_space.namespace_cl;).

Nested Namespaces

Namespaces can be defined inside other namespaces to create a hierarchical structure, commonly reflecting the project's folder structure or logical organization.

Declaration:

namespace first_space {
   class abc { /* ... */ }
   
   namespace second_space { // Nested Namespace
      class efg { /* ... */ }
   }
}

Accessing Nested Members:

Members of a nested namespace are accessed by chaining the names with the dot operator.

// Using directive to import the nested namespace
using first_space.second_space; 

class TestClass {
   static void Main(string[] args) {
      efg sc = new efg(); // Accessing the class directly after using directive
      sc.func();
   }
}

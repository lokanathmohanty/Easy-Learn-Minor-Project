Next.js Parallel Routing 🧩

What is Parallel Routing?

**Parallel Routing** is an advanced routing method in Next.js (App Router) that enables you to **simultaneously render one or more pages (or views) within the same layout**. This is particularly useful for creating complex dashboards, social media feeds, or split views where different sections of the UI should load and navigate independently.

A key feature is the ability to render these sections **conditionally**, allowing you to control which view appears based on the current URL or user state.

Example Use Case:

Displaying a user's **Feed** on the left side and their **Profile** details on the right side, all within a single persistent layout.

Setting Up Parallel Routing

Parallel routing uses **named slots** defined in the file system.

Step 1 & 2: Create Named Slots (The `@folder` Convention)

Slots are defined by creating directories prefixed with the **`@`** symbol. These folders represent the parallel segments of the route.

app/
  layout.tsx
  page.tsx        // Default page content (if present)
  @sidebar/       // ← Slot 1
      page.tsx
  @content/       // ← Slot 2
      page.tsx

Step 3: Define the Layout and Slots

The parent **`layout.tsx`** file must receive the slots as **props** and render them in the desired location in the UI. The prop names must match the slot folder names (e.g., `@sidebar` becomes the `sidebar` prop).

// File: app/layout.tsx
export default function RootLayout({ children, sidebar, content }) {
    return (
      <html>
        <body>
          <div style={{ display: "flex" }}>
            <aside>{sidebar}</aside> <!-- Renders @sidebar/page.tsx -->
            <main>{content}</main> <!-- Renders @content/page.tsx -->
          </div>
          {children} <!-- Renders app/page.tsx (the default page content) -->
        </body>
      </html>
    );
}

Step 4: Create Parallel Route Segments

Each slot folder contains its own route segment file, which is an independent component.

// File: @sidebar/page.tsx
export default function Sidebar() {
  return <nav>Sidebar Content</nav>;
}

// File: @content/page.tsx
export default function Content() {
  return <section>Main Content</section>;
}

PHP Files and I/O (Input/Output)

**PHP Files and I/O** refers to the process of managing files—reading, writing, creating, and deleting—using built-in PHP functions. File management is crucial for storing and retrieving persistent data in web applications.

1. Opening and Closing Files

Opening a File: `fopen()`

The `fopen()` function opens a file and is mandatory before any read or write operation. It requires two arguments: the **file name** and the **mode**. It returns a **file pointer** resource on success, or `false` on failure.

$file = fopen( "data.txt", "r" );

File Modes (`fopen`):

The mode specifies the intended operation and pointer placement:

  • **`r`**: **Read** only. Pointer at the beginning.
  • **`r+`**: **Read and Write**. Pointer at the beginning.
  • **`w`**: **Write** only. Creates file if it doesn't exist, **truncates** file to zero length if it does. Pointer at the beginning.
  • **`w+`**: **Read and Write**. Creates file if it doesn't exist, **truncates** file to zero length if it does. Pointer at the beginning.
  • **`a`**: **Append** (Write only). Creates file if it doesn't exist. Pointer at the **end** of the file.
  • **`a+`**: **Append and Read**. Creates file if it doesn't exist. Pointer at the **end** of the file.

Closing a File: `fclose()`

The `fclose()` function closes an open file resource. It takes the **file pointer** as its argument and is critical for freeing up system resources.

fclose( $file );

2. Reading a File

The primary function for reading content from an open file is `fread()`.

`fread()` Function

Reads data from the file pointer. It requires two arguments: the **file pointer** and the **length in bytes** to read.

`filesize()` Function

Used to determine the total size of the file in bytes, which is often passed to `fread()` to read the entire file content. It takes the **file name** as an argument.

Reading Steps:

  1. Open the file (`fopen($filename, "r")`).
  2. Get the file size (`filesize($filename)`).
  3. Read the content (`fread($file_pointer, $filesize)`).
  4. Close the file (`fclose($file_pointer)`).

3. Writing a File

The `fwrite()` function is used to write or append data to an open file.

`fwrite()` Function

Writes the contents of a string to a file. It requires the **file pointer** and the **string of data** to be written. An optional third argument can limit the length of the data written.

$file = fopen( "log.txt", "w" ); // Opens for writing, truncates if exists
fwrite( $file, "This is a new log entry.\n" );
fclose( $file );

The **`file_exists()`** function can be used to check if a file has been successfully created or exists on the file system.

Rounding Decimals

There are primarily five ways of rounding off decimals in NumPy:

  • truncation
  • fix
  • rounding
  • floor
  • ceil

Truncation

Removes the decimals and returns the float number closest to zero. Use the trunc() and fix() functions.

Example: Using trunc()

import numpy as np

arr = np.trunc([-3.1666, 3.6667])

print(arr)

Example: Using fix()

import numpy as np

arr = np.fix([-3.1666, 3.6667])

print(arr)

Rounding

The around() function increments the preceding digit or decimal by 1 if it is >= 5, otherwise does nothing.

Example: Round off 3.1666 to 2 decimal places:

import numpy as np

arr = np.around(3.1666, 2)

print(arr)

Floor

The floor() function rounds decimals down to the nearest lower integer.

Example: Floor the elements of the following array:

import numpy as np

arr = np.floor([-3.1666, 3.6667])

print(arr)

Ceil

The ceil() function rounds decimals up to the nearest upper integer.

Example: Ceil the elements of the following array:

import numpy as np

arr = np.ceil([-3.1666, 3.6667])

print(arr)

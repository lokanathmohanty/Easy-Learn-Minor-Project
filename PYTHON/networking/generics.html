Python Generics

Generics in Python allow definition of functions and classes that operate on multiple types while maintaining type safety and promoting code reuse.

Introduced with type hints (PEP 484) in Python 3.5, generics add flexibility and correctness by specifying type parameters.

Defining a Generic Function

from typing import List, TypeVar

T = TypeVar('T')

def reverse(items: List[T]) -> List[T]:
    return items[::-1]

This function reverses a list of any type T. Type T is a placeholder replaced by the actual list element type when the function is used.

Example usage:

numbers = [1, 2, 3, 4, 5]
print(reverse(numbers))  # Output: [5, 4, 3, 2, 1]

fruits = ['apple', 'banana', 'cherry']
print(reverse(fruits))  # Output: ['cherry', 'banana', 'apple']

Defining a Generic Class

from typing import TypeVar, Generic

T = TypeVar('T')

class Box(Generic[T]):
    def __init__(self, item: T) -> None:
        self.item = item

    def get_item(self) -> T:
        return self.item

Create instances specifying the type:

box1 = Box[int](42)
print(box1.get_item())  # Output: 42

box2 = Box[str]("Hello")
print(box2.get_item())  # Output: Hello

Type checking tools like mypy will verify type correctness based on these annotations.

Summary

  • Generics enable writing reusable, type-safe code in Python.
  • Type variables (TypeVar) are placeholders for generic types.
  • Generic functions and classes can operate on any type specified by the user.
  • Type hints help static type checkers catch type errors before runtime.

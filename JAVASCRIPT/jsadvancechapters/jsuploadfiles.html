JavaScript - Upload Files

Uploading files is a common task in web development. While forms are the most widely used method, JavaScript offers several ways to upload files directly to the server. In this session, we will explore three main approaches:

  • Using FormData with fetch or $.ajax
  • Using XMLHttpRequest
  • Using a Plugin for Simplified Upload

Using FormData with Fetch or $.ajax

The FormData object lets you create key-value pairs for file uploads. It can be used with fetch or $.ajax to send data without a traditional HTML form. 


// Create a new FormData object
var formData = new FormData();

// Append the file to the FormData object
formData.append('pictureFile', pictureInput.files[0]);

// Use $.ajax to send the file
$.ajax({
   url: 'upload.php',        
   type: 'POST',
   processData: false,       
   contentType: false,
   dataType: 'json',         
   data: formData            
});

Example Success Response:


{
   "status": "success",
   "message": "File uploaded successfully.",
   "filePath": "uploads/picture.jpg"   
}

Example Error Response:


{
   "status": "error",
   "message": "File upload failed. Please try again."
}

Using XMLHttpRequest

Another way to upload files is with XMLHttpRequest. This approach gives you more control over the upload process. 


// Get the form element 
var form = document.getElementById('the-form');

form.onsubmit = function () {
   var formData = new FormData(form);
   formData.append('file', file); 
   var xhr = new XMLHttpRequest();
   
   xhr.open('POST', form.getAttribute('action'), true);
   xhr.send(formData);
   return false; // Prevent actual form submission
}

Example Success Response:


{
   "status": "success",
   "message": "File uploaded successfully.",
   "filePath": "/uploads/myfile.jpg" 
}

Example Error Response:


{
   "status": "error",
   "message": "File upload failed. Please try again."
}

Using a Simple Upload Plugin

Plugins like simpleUpload simplify file uploading using jQuery. They abstract the setup and let you focus on server-side handling. 


<input type="file" name="file" id="simpleUpload" multiple>
<button type="button" id="upload">Upload</button>

<script>
   $(document).ready(function() {
      $('#simpleUpload').simpleUpload({
         url: 'upload.php',
         trigger: '#upload',
         success: function (data) {
            alert('Successfully Uploaded');
         },
         error: function (error) {
            alert('Upload failed. Please try again.');
         }
      });
   });
</script>

Output on Success: "Successfully Uploaded"

Output on Failure: "Upload failed. Please try again."

Summary

Each method provides a different level of flexibility:

  • FormData with fetch or $.ajax is simple and modern.
  • XMLHttpRequest gives more control but requires extra setup.
  • Plugins like simpleUpload make implementation quick and easy.

Choose the approach that best fits your project’s needs.

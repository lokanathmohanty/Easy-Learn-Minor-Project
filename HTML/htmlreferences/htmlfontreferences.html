HTML - Fonts Reference

Fonts are platform-specific, meaning the look and feel of a web page can vary across different operating systems such as Windows, Linux, or macOS. The HTML <font> tag is deprecated in HTML 4.0 onwards, and fonts should now be set using CSS.

Syntax

To set fonts using CSS class:


body {
   font-family: "new century schoolbook";
}

To set font using inline CSS within an HTML tag:


<body style="font-family:new century schoolbook;">

HTML <font> Tag

The <font> tag was used in older versions of HTML to specify font size, color, and face. It has been deprecated in favor of CSS. A <basefont> tag could be used to set default text properties. The <font> tag supported three attributes:

  • size
  • color
  • face

Web Safe Fonts

CSS3 supports font combinations, where the browser will try the next available font if the first one is not supported. These are known as web safe fonts.

Example of HTML Fonts


<!DOCTYPE html>
<html>
<head>
   <title>Font Setting Using CSS</title>
</head>
<body>
   <p>Change any of the style and try it.</p>

   <div style="font-family:verdana;">
      This is demo for font family
   </div>

   <br />

   <div style="font-size:120%;">
      This is demo for font size
   </div>

   <br />

   <div style="font-size:14pt;">
      This is demo for font size
   </div>
</body>
</html>

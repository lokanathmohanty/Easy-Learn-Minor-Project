Java BitSet Class Summary 🔢🗜️

The **java.util.BitSet** class implements a special, highly efficient data structure—a **vector of bits** that grows as needed. It's used to represent a set of non-negative integers as individual binary flags (true/false) in a compact, dynamic array.

I. Core Characteristics and Efficiency

BitSet excels at representing a large number of boolean flags efficiently, allowing for fast set algebra operations.

  • **Space Efficiency:** It stores each boolean value using a single bit. This is extremely memory-efficient, especially when dealing with large, sparse sets of flags.
  • **Dynamic Size:** The array of bits automatically grows as needed to accommodate a set bit at a higher index, similar to a `Vector` or `ArrayList`.
  • **Initial State:** All bits in a new `BitSet` initially have the value **`false`** (or 0).
  • **Indexing:** The index of a bit corresponds to the integer value it represents. For example, setting the bit at index 10 means the number 10 is in the set.
  • **Non-Synchronized:** It is **not thread-safe** and requires external synchronization for concurrent modification.

II. Bitwise and Set Operations

The primary utility of `BitSet` lies in its ability to perform highly optimized set algebra (intersection, union, difference) using bitwise logic:

Method Set Algebra Equivalent Action
void **and**(BitSet set) Intersection ($\cap$) Keeps bits set to `true` **only** if they are `true` in **both** `BitSet` objects.
void **or**(BitSet set) Union ($\cup$) Sets bits to `true` if they are `true` in **either** `BitSet` object.
void **xor**(BitSet set) Symmetric Difference ($\triangle$) Sets bits to `true` if they are `true` in **one but not both** `BitSet` objects.
void **andNot**(BitSet set) Difference ($\setminus$) Clears bits in the target `BitSet` if the corresponding bit is set in the argument `BitSet`. (i.e., this $\setminus$ set)

III. Key Access and Utility Methods

Other essential methods for managing and querying the bit vector:

  • **void set(int bitIndex):** Sets the bit at the specified index to `true`.
  • **boolean get(int bitIndex):** Returns the value (`true` or `false`) of the bit at the specified index.
  • **int cardinality():** Returns the **number of bits set to `true`** (the size of the represented set).
  • **int length():** Returns the "logical size," which is the index of the highest set bit **plus one**.
  • **int nextSetBit(int fromIndex):** Efficiently finds the index of the next `true` bit starting from a given index.

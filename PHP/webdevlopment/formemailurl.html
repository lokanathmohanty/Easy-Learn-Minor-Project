PHP: Form Email/URL Validation

Validating that user input adheres to the strict format of an email address or a URL is a crucial part of server-side form handling. PHP provides two primary methods for this: using **Regular Expressions (Regex)** or the dedicated **filter_var()** function.

Validation with filter_var() (Recommended)

The **filter_var()** function is the simplest and most robust way to validate common data types like emails and URLs, as it uses PHP's standardized, pre-compiled validation rules.

filter_var(mixed $value, int $filter, array|int $options = 0): mixed
  • For Email Validation: Use the filter constant **FILTER_VALIDATE_EMAIL**. It returns the email string if valid, or FALSE if the format is incorrect.
  • For URL Validation: Use the filter constant **FILTER_VALIDATE_URL**. It returns the URL string if valid, or FALSE if the format is incorrect.

Validation with Regular Expressions (Regex)

The **preg_match()** function can be used to compare the input string against a complex Regular Expression pattern that defines the valid structure of an email or URL. While powerful, writing and maintaining correct regular expressions for these complex formats is difficult and error-prone. The filter_var() approach is generally preferred.

Security Considerations

Validation ensures the *format* is correct. However, always use **htmlspecialchars()** when displaying the validated email/URL back to the user to prevent XSS (Cross-Site Scripting) vulnerabilities, even after passing validation.

Example Session: Using filter_var()

This example demonstrates how to validate both an email and a URL submitted via a POST request using the built-in filtering constants.


<?php
   if ($_SERVER["REQUEST_METHOD"] == "POST") {
      $email = $_POST['email'];
      $url = $_POST['url'];

      // --- Email Validation ---
      if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
         echo "Error: Invalid email format. Please re-enter.\n"; 
      } else {
         echo "Email is valid: " . htmlspecialchars($email) . "\n";
      }

      // --- URL Validation ---
      if (!filter_var($url, FILTER_VALIDATE_URL)) {
         echo "Error: Invalid URL format. Please re-enter.\n"; 
      } else {
         echo "URL is valid: " . htmlspecialchars($url) . "\n";
      }
   }
?>

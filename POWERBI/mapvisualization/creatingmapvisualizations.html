Power BI: Creating Map Visualizations

Map visualizations in Power BI display geographical data using colorful bubbles that represent numerical values on locations. They help discover data point identities, patterns, and trends using Location, Legend, Latitude, Longitude, Bubble size, and Tooltips.

Precise data point locations are provided by Latitude and Longitude fields, and Microsoft Bing Maps powers the Map visual.

Types of Map Visuals

  • Map Visual: Displays data point bubbles on geographic locations with size representing a measure like sales.
  • Filled Map: Shows geographic areas filled with colors representing data categories or values.
  • Azure Map: Provides advanced map capabilities integrated with Azure services.
  • ArcGIS Map: A powerful mapping tool with rich spatial analytics embedded in Power BI.

Creating a Map Visual Example

  • Switch to Report View and select the Map visual.
  • Drag the Region field to Location to plot points geographically.
  • Add Gross Sales to Legend to differentiate points by color.
  • Drag Latitude and Longitude fields into their respective sections for precise locations.
  • Place Gross Sales into Bubble size to scale bubble size by sales value.
  • Use Tooltips to add extra data fields like Name so details appear when hovering over points.

Creating a Filled Map Visual Example

  • Select the Filled Map visual from Visualizations.
  • Add States to Location and Name to Legend to color regions based on categories.
  • Latitude and Longitude are optional and not used in Filled Map.
  • Hovering over regions reveals detailed tooltips including names and other info like Gross Sales.

Additional Map Visualization: Treemap

Treemaps show hierarchical data using nested rectangles sized and colored by values. For example, visualizing sales production by country, with larger rectangles for higher sales.

Drag Country to Category and Sales Production in 2023 to Values. Customize fonts and colors to enhance readability. Tooltips show detailed info on hovering rectangles.

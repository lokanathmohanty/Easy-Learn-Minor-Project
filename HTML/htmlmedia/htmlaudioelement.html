HTML <audio> Element

Overview

The HTML <audio> element embeds an audio file inside a web page. Similar to the <video> element, it supports multiple audio formats (such as MP3, WAV, and OGG) and provides built-in playback features like play, pause, and volume control.

Common Attributes

Attribute Description
controls Adds built-in controls (play, pause, volume).
autoplay Plays the audio automatically when the page loads.
loop Replays the audio after it ends.
muted Starts the audio in muted mode.
preload Specifies how the audio should be preloaded by the browser.
src Specifies the path to the audio file.

Basic Syntax

<audio controls>
  <source src="file_path" type="audio/mpeg">
  Your browser does not support the audio element.
</audio>

Example: Multiple Sources

This example provides MP3, WAV, and OGG sources so the browser can select the most suitable format.

<!DOCTYPE html>
<html>
<body>
  <p>Working with audio element</p>
  <audio controls>
    <source src="/html/media/audio/sample_3sec_audio.mp3" type="audio/mp3">
    <source src="/html/media/audio/sample_3sec_audio.wav" type="audio/wav">
    <source src="/html/media/audio/sample_3sec_audio.ogg" type="audio/ogg">
    Your browser does not support the <audio> element.
  </audio>
</body>
</html>

Autoplay, Muted, and Loop

Use the autoplay, muted, and loop attributes to play the audio automatically, start it muted, and replay it continuously. Autoplay often requires the muted attribute to work in modern browsers. 

<audio controls autoplay muted loop>
  <source src="/html/media/audio/sample_3sec_audio.mp3" type="audio/mp3">
  <source src="/html/media/audio/sample_3sec_audio.wav" type="audio/wav">
  <source src="/html/media/audio/sample_3sec_audio.ogg" type="audio/ogg">
  Your browser does not support the <audio> element.
</audio>

Best Practices

  • Provide multiple formats for maximum browser compatibility.
  • Always include fallback text for unsupported browsers.
  • Use autoplay with muted to prevent unwanted sound on load.
  • Consider accessibility by providing transcripts or captions where necessary.

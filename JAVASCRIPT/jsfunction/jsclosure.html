JavaScript - Closures

What is a Closure?

A closure in JavaScript is the combination of a function and its lexical environment. It allows an inner function to access variables from its parent function, even after the parent function has finished executing.

Closures are commonly used to create private variables and maintain state between function calls.

Prerequisites

Before diving into closures, let’s review a few key concepts:

1. Lexical Scoping

Lexical scoping means that the scope of variables is determined by the structure of the code at compile time. Nested functions can access variables defined in their parent function.

2. Nested Functions


function outer() {
  console.log("The outer function is executed!");
  function inner() {
    console.log("The inner function is executed!");
  }
  inner();
}
outer();

Output:

  • The outer function is executed!
  • The inner function is executed!

3. Returning Functions


function outer() {
  console.log("The outer function is executed!");
  return function inner() {
    console.log("The inner function is executed!");
  }
}

const func = outer();
func();
func();

Output:

  • The outer function is executed!
  • The inner function is executed!
  • The inner function is executed!

A Counter Dilemma

Without closures, we might use a global variable for a counter:


var cnt = 100;

function decrement() {
  cnt = cnt - 1;
  console.log("The value of cnt is: " + cnt);
}

decrement(); // 99
decrement(); // 98
decrement(); // 97

This works, but the problem is that cnt is a global variable. Any part of the program can change its value.

Closures to the Rescue

We can solve this by using a closure to encapsulate cnt inside a function.


function counter() {
  let cnt = 100; 
  return function decrement() {
    cnt = cnt - 1;
    console.log("The value of cnt is: " + cnt);
  }
}

const func = counter(); 
func(); // 99
func(); // 98
func(); // 97

Here, counter() has already finished execution, but the inner function still remembers and accesses cnt. That’s a closure!

Another Example


function name() {
  let firstName = "John";
  return function getFullName() {
    return firstName + " Doe";
  }
}

const fullName = name();
console.log("The full name is " + fullName());

Output: The full name is John Doe

Benefits of Closures

  • Encapsulation: Closures allow data hiding by making variables private.
  • Preserving State: Functions remember their environment, allowing state persistence across calls.
  • Improved Memory Efficiency: Only necessary variables are retained, reducing global memory usage.

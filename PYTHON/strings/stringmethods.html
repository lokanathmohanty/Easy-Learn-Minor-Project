Python - String Methods

Python's built-in str class defines various methods to manipulate strings. Since strings are immutable, these methods return a new copy of the string with the applied transformation.

Case Conversion Methods

  • capitalize() – Capitalizes first letter of string
  • casefold() – Converts all characters to lowercase (works on UNICODE too)
  • lower() – Converts all uppercase letters to lowercase
  • swapcase() – Inverts the case of all letters
  • title() – Converts to title case (each word starts with uppercase)
  • upper() – Converts lowercase letters to uppercase

Alignment Methods

  • center(width, fillchar) – Centers string within given width using fillchar
  • ljust(width, fillchar) – Left-justifies string to given width
  • rjust(width, fillchar) – Right-justifies string to given width
  • expandtabs(tabsize=8) – Expands tabs into spaces (default 8)
  • zfill(width) – Left-pads string with zeros to match given width

Split and Join Methods

  • lstrip() – Removes leading whitespace
  • rstrip() – Removes trailing whitespace
  • strip() – Removes leading and trailing whitespace
  • rsplit() – Splits from the right
  • split() – Splits by delimiter (default: space)
  • splitlines() – Splits at newline characters
  • partition() – Splits at first occurrence of separator into 3 parts
  • rpartition() – Splits at last occurrence of separator into 3 parts
  • join() – Joins elements of a sequence into a string with a separator
  • removeprefix() – Removes given prefix from string
  • removesuffix() – Removes given suffix from string

Boolean String Methods

  • isalnum() – True if all characters are alphanumeric
  • isalpha() – True if all characters are alphabetic
  • isdigit() – True if all characters are digits
  • islower() – True if all cased characters are lowercase
  • isnumeric() – True if all characters are numeric
  • isspace() – True if all characters are whitespace
  • istitle() – True if string is titlecased
  • isupper() – True if all cased characters are uppercase
  • isascii() – True if all characters are ASCII
  • isdecimal() – True if all characters are decimal numbers
  • isidentifier() – True if string is a valid Python identifier
  • isprintable() – True if all characters are printable

Find and Replace Methods

  • count(sub, beg, end) – Counts occurrences of substring
  • find(sub, beg, end) – Returns index of first occurrence (or -1)
  • index(sub, beg, end) – Same as find(), but raises exception if not found
  • replace(old, new, max) – Replaces old with new (max times if provided)
  • rfind(sub, beg, end) – Finds last occurrence of substring
  • rindex(sub, beg, end) – Same as rfind(), but raises exception if not found
  • startswith(sub, beg, end) – Checks if string starts with substring
  • endswith(suffix, beg, end) – Checks if string ends with suffix

Translation Methods

  • maketrans() – Returns a translation table for use in translate()
  • translate(table, deletechars) – Translates string using given table

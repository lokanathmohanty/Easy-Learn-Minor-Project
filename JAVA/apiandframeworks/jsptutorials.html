Java Server Pages (JSP) Summary 📄💻

Java Server Pages (JSP) is a server-side programming technology that simplifies the process of creating **dynamic web content** by allowing developers to embed Java code directly into HTML, XML, or other document types.

I. Core Role and Relationship with Servlets

JSP is built directly on top of the **Java Servlets API** and is designed to address the complexity of writing presentation code (HTML markup) directly in Java code (using `out.println()` statements in a Servlet).

  • **Simplified Presentation:** JSP's primary goal is to provide a **view layer** where the static HTML structure dominates, and the dynamic content is inserted using special tags and scriptlets.
  • **The Translation Phase:** The key to JSP performance is its compilation process:
    1. The JSP file (`.jsp`) is requested for the first time.
    2. The Servlet Container **translates** the JSP into a standard Java **Servlet** source file.
    3. The Servlet is **compiled** into a class file (`.class`).
    4. The compiled Servlet is executed to handle the request.
    The compilation only happens once, making subsequent requests very fast.
  • **Enterprise Access:** Like Servlets, JSPs have access to the entire **Java EE** ecosystem, including JDBC, JNDI, and EJBs.

II. Advantages over Alternatives

JSP is superior to many older technologies for creating dynamic web pages:

  • **vs. Pure Servlets:** It is far more convenient to write regular HTML and embed small pieces of Java code than to generate all HTML using `response.getWriter().println()` calls. JSP acts as the **View** layer, while Servlets handle the **Controller/Business Logic** (Model-View-Controller or MVC).
  • **vs. CGI/Perl:** Performance is significantly better because JSPs are **compiled** once, whereas CGI typically requires the server to load an interpreter and script for every request.
  • **vs. ASP (Microsoft):** JSP is **platform-portable** (can run on Linux, Windows, etc., with any web server/container), and its dynamic logic is written in the powerful Java language.

III. JSP Scripting Elements

JSP provides three main ways to embed Java logic into the markup:

  1. **Scriptlets (`<% Java code %>`):** Used for embedding arbitrary Java code (like conditional statements, loops, or method calls). *Example: `<% if (user.isLoggedIn()) { %>`*
  2. **Expressions (`<%= Java expression %>`):** Used to evaluate a Java expression and output the result directly into the page content. This is a shorthand for `out.println()`. *Example: `<%= request.getRemoteAddr() %>`*
  3. **Declarations (`<%! Java declaration %>`):** Used to declare instance variables or methods that will be part of the translated Servlet class.

JSP also provides **Standard Actions (``, ``)** and the **JSTL (JSP Standard Tag Library)** to perform common tasks without using Java scriptlets.

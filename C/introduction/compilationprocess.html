Compilation Process in C

C is a compiled language, which means the source code you write must be transformed into machine code that the computer's CPU can execute directly. This transformation is performed by a compiler and involves multiple stages.

Common C compilers include GCC, Clang, and MSVC, each translating C code into platform-specific executables.

Stages of the Compilation Process

  • Preprocessing: The compiler handles directives like #include and #define. It expands macros, includes header files, and removes comments. The output is an expanded source file with an ".i" extension.
  • Compilation: The preprocessed file is translated into assembly language, producing a ".s" file.
  • Assembly: The assembler converts the assembly code into machine code, creating an object file with a ".o" extension.
  • Linking: The linker combines object files and libraries to produce the final executable program.

Example: Hello World Program

#include <stdio.h>

int main() {
   /* my first program in C */
   printf("Hello World! \n");
   return 0;
}

Compile and build this program using GCC with the following commands:

gcc -c hello.c -o hello.o
gcc -o hello.exe hello.o

After building, run the program:

./hello.exe    (Windows)
./hello.out    (Linux)

Output:

Hello World!

Common Compilation Commands

  • gcc -E main.c: Stops after preprocessing, outputs main.i.
  • gcc -S main.c: Stops after compilation, outputs assembly main.s.
  • gcc -c main.c: Stops after assembly, outputs object file main.o.
  • gcc main.c -o executable: Full build, produces executable named executable.

Notes

• Machine code is platform-specific; executables built on one OS may not run on another.

• Errors in the source code will stop compilation and show error messages.

• IDEs like CodeBlocks can automate compiling and running C programs conveniently.

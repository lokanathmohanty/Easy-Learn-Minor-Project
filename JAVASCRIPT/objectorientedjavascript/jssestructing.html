JavaScript - Destructuring

Introduction

Destructuring is a JavaScript expression that allows you to extract values from arrays or properties from objects and assign them to variables in a concise way.

Think of it like a box that contains multiple items. Normally, if you want a specific item, you’d have to search through the whole box. With destructuring, you can directly unpack and retrieve the exact item you need in one step.

When to Use Destructuring?

  • When you need more than one property from an object or multiple values from an array.
  • When assigning multiple values to variables in a single step.
  • When passing an object as a function parameter and needing specific properties.
  • When returning multiple values from a function as an object.
  • To make working with arrays and objects simpler and more readable.

Types of Destructuring

There are two main types of destructuring in JavaScript:

  • Object Destructuring − Extracts properties from an object.
  • Array Destructuring − Extracts elements from an array.

Object Destructuring

Object destructuring means extracting properties from an object and assigning them to variables. It helps in writing shorter and more readable code.

<script>
   const person = { name: "Alice", age: 25, city: "New York" };

   // Destructuring
   const { name, age } = person;

   console.log(name); // Alice
   console.log(age);  // 25
</script>

Array Destructuring

Array destructuring allows you to extract elements from an array and assign them to variables directly.

<script>
   const numbers = [10, 20, 30, 40];

   // Destructuring
   const [first, second] = numbers;

   console.log(first);  // 10
   console.log(second); // 20
</script>

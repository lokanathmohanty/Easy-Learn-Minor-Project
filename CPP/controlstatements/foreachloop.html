C++ Range-Based for Loop (Foreach) 📚

The **range-based `for` loop**, often called the **Foreach loop** in other languages, is a C++11 feature that provides a concise and readable way to iterate over all elements in a container (like arrays, vectors, lists, etc.) or any object that meets the requirements of an iterable type.

It eliminates the boilerplate code (initialization, condition, increment) associated with traditional for loops for simple iteration.

Syntax and Mechanism

Syntax:

for ( data_type  element_variable_name : container_name ) {
   // code to be executed for each element
}

The loop automatically obtains the beginning and end iterators of the container and proceeds sequentially:

  1. The loop starts at the first element of the container_name.
  2. The element's value is copied to element_variable_name (unless a reference is used).
  3. The loop body executes.
  4. The process repeats until all elements are traversed.

Modifying Elements with References

To **modify** the elements of the container directly, you must use a **reference** (&) in the loop variable declaration:

for (int& num : digits) {
   num *= 2; // num is a reference, so the original element is changed.
}
// Output: 20 40 60 80 100

Advantages and Considerations

AdvantagesLimitations
**Simplicity & Readability:** Reduces boilerplate code and is straightforward to read. **Forward Traversal Only:** Cannot easily iterate in reverse order.
**Safety:** Eliminates common errors related to manual index management (off-by-one errors). **No Direct Index Access:** The current element's index or position is not directly available during iteration.
**Works with Iterables:** Works on any container or custom type that implements begin() and end() methods. **Non-interruptible Iteration:** Designed for full traversal; skipping elements or breaking the loop early must use continue or break statements, respectively.

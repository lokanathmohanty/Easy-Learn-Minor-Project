JavaScript - Rest Parameter

Rest Parameter

The rest parameter in JavaScript allows a function to accept a variable number of arguments as an array. When the number of arguments is not fixed, you can use the rest parameters.

The rest parameter is represented with three dots (...) followed by a parameter name. This parameter name is the array that contains all the remaining arguments.

Rest Parameter Syntax

function functionName(para1, para2, ...theArgs) {
   // function body
}

Here, para1 and para2 are ordinary parameters while theArgs is a rest parameter. The rest parameter collects the remaining arguments and assigns them to an array.

Important Rules:

  • The rest parameter should always be the last parameter in the function definition.
  • A function can have only one rest parameter.

Example: Variable Length Parameter List

<script>
function sum(...nums) {
  let totalSum = 0;
  for (let num of nums) {
    totalSum += num;
  }
  return totalSum;
}
console.log(sum(10, 20, 30, 40)); // 100
console.log(sum(10, 20));         // 30
console.log(sum());               // 0
</script>

Example: Finding the Maximum Number

The rest parameter simplifies the process of finding the maximum number among a set of given numbers.

<script>
function getMax(...args) {
  return Math.max(...args);
}
console.log(getMax(10, 20, 30, 40)); // 40
console.log(getMax(10, 20, 30));     // 30
</script>

Spread Operator and Rest Parameters

The spread operator (...) is closely related to rest parameters. While the rest parameter collects function arguments into an array, the spread operator spreads array elements into individual arguments.

<script>
function multiply(a, b, c) {
  return a * b * c;
}
const numbers = [2, 3, 4];
console.log(multiply(...numbers)); // 24
</script>

Rest Parameter vs. Arguments Object

Both can handle variable-length parameter lists, but rest parameters are more concise and modern.

Using Rest Parameters

<script>
function sum(...numbers) {
  return numbers.reduce((total, num) => total + num, 0);
}
console.log(sum(1, 2, 3, 4, 5)); // 15
</script>

Using Arguments Object

<script>
function sum() {
  const argsArray = Array.from(arguments);
  return argsArray.reduce((total, num) => total + num, 0);
}
console.log(sum(1, 2, 3, 4, 5)); // 15
</script>

Destructuring with Rest Parameter

The destructuring assignment can be used with rest parameters to extract values from the array of arguments.

<script>
function getFirstTwo(...numbers) {
  const [first, second] = numbers;
  return `First: ${first}, Second: ${second}`;
}
console.log(getFirstTwo(1, 2, 3, 4, 5));
// Output: First: 1, Second: 2
</script>

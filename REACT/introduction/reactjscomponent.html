ReactJS - Component

React components are the building blocks of React applications. A component represents a small chunk of the user interface in a webpage.

Its main role is to render the UI, manage events, and update the UI whenever the internal state changes.

  • Initial rendering of the user interface
  • Management and handling of events
  • Updating UI when the internal state changes

Key Concepts in React Components

  • Properties − Receive input from outside.
  • Events − Manage DOM events and user interactions.
  • State − Make a component stateful and update UI accordingly.

Types of Components

  • Function Components − Defined as JavaScript functions, return React elements.
  • Class Components − Extend React.Component and support state and lifecycle methods.

Example: Function Component

function Hello() { 
  return <div>Hello</div> 
}

Example: Class Component

class ExpenseEntryItem extends React.Component {
  render() {
    return (
      <div>Hello</div>
    );
  }
}

Creating a Class Component

Let us create a new component ExpenseEntryItem to showcase an expense entry item with details such as name, amount, date, and category.

Example: ExpenseEntryItem Class Component

class ExpenseEntryItem extends React.Component {
  render() {
    return (
      <div>
        <div><b>Item:</b> <em>Mango Juice</em></div>
        <div><b>Amount:</b> <em>30.00</em></div>
        <div><b>Spend Date:</b> <em>2020-10-10</em></div>
        <div><b>Category:</b> <em>Food</em></div>
      </div>
    );
  }
}
export default ExpenseEntryItem;

Example: Using Component in index.js

import React from 'react';
import ReactDOM from 'react-dom';
import ExpenseEntryItem from './components/ExpenseEntryItem';

ReactDOM.render(
  <React.StrictMode>
    <ExpenseEntryItem />
  </React.StrictMode>,
  document.getElementById('root')
);

Creating a Function Component

The same ExpenseEntryItem can also be created as a function component for simpler use cases.

Example: Function Component

function ExpenseEntryItem() {
  return (
    <div>
      <div><b>Item:</b> <em>Mango Juice</em></div>
      <div><b>Amount:</b> <em>30.00</em></div>
      <div><b>Spend Date:</b> <em>2020-10-10</em></div>
      <div><b>Category:</b> <em>Food</em></div>
    </div>
  );
}

Splitting Components

Large applications can become complex with many classes and dependencies. Code splitting helps by loading only the required components on demand, improving performance. This is also called lazy loading.

Example: Before and After Code Splitting

// Before
import { sub } from './math';
console.log(sub(23, 14));

// After
import("./math").then(math => {
  console.log(math.sub(23, 14));
});

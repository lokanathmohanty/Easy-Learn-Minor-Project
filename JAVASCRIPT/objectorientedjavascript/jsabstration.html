JavaScript - Abstraction

Abstraction in JavaScript

The abstraction in JavaScript can be achieved using the abstract class. In object-oriented programming, the abstraction concept allows you to hide the implementation details and expose features only to the users.

For example, you can execute the Math object methods in JavaScript by accessing the method using its name but cannot see how it is implemented. Similarly, array methods like push(), pop(), etc., can be executed without knowing their internal implementation.

So, abstraction makes code cleaner by exposing the required features and hiding the internal implementation details.

How to Achieve Abstraction in JavaScript?

In most programming languages, you can achieve abstraction using the abstract class. The abstract class contains only method declaration but not implementation. Furthermore, you need to implement the methods declared in the abstract class into the child class. Also, you cannot create an instance of the abstract class.

JavaScript does not allow creating an abstract class like Java or C++ natively, but you can achieve the same functionality using the object constructor function.

Creating the Abstract Class

In the example below, the fruit() function initializes the name property. When anyone creates an instance of fruit(), the constructor property becomes equal to fruit. To prevent creating an instance, we throw an error.

We also add the getName() method to the prototype. After that, creating an instance of fruit() will throw an error.

Example

<html>
<body>
   <div id="output"></div>
   <script>
      try {
         function fruit() {
            this.name = "Fruit";
            if (this.constructor === fruit) {
               throw new Error("You can't create the instance of the fruit.");
            }
         }
         fruit.prototype.getName = function () {
            return this.name;
         }
         const apple = new fruit();
      } catch (error) {
         document.getElementById("output").innerHTML = error;
      }
   </script>
</body>
</html>

Output

Error: You can't create the instance of the fruit.

Extending the Abstract Class

In this example, the fruit() constructor is similar to the above example. We implement the Apple() constructor, initializing the name property.

We then assign the prototype of fruit() to Apple() using the Object.create() method. This allows Apple() to inherit the properties and methods of fruit.

Example

<html>
<body>
   <div id="output">The name of the fruit is: </div>
   <script>
      function fruit() {
         this.name = "Fruit";
         if (this.constructor === fruit) {
            throw new Error("You can't create the instance of the fruit.");
         }
      }
      fruit.prototype.getName = function () {
         return this.name;
      }
      function Apple(fruitname) {
         this.name = fruitname;
      }
      Apple.prototype = Object.create(fruit.prototype);
      const apple = new Apple("Apple");
      document.getElementById("output").innerHTML += apple.getName();
   </script>
</body>
</html>

Output

The name of the fruit is: Apple

Conclusion

The prototype implements the getName() method in the above code, so the implementation is hidden.

This way, you can use an object constructor to achieve abstraction in JavaScript.

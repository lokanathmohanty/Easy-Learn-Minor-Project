Python - Output Formatting

Output formatting makes code output readable and user-friendly. Python offers multiple methods:

  • String modulo operator (%)
  • format() method
  • F-strings (formatted string literals)
  • Template strings

Advanced formatting includes text wrapping and pretty-printing with modules like textwrap and pprint.

String Modulo Operator (%)

print("My name is %s and weight is %d kg!" % ('Zara', 21))

Output: My name is Zara and weight is 21 kg!

Supports placeholders like %d (integer), %f (float), %s (string).

format() Method

name = "Rajesh"
age = 23
print("my name is {} and my age is {} years".format(name, age))
print("my name is {name} and my age is {age} years".format(name="Rajesh", age=23))

Output:

my name is Rajesh and my age is 23 years

More elegant than % operator, supports positional and keyword arguments.

F-Strings (Formatted String Literals)

name = 'Rajesh'
age = 23
fstring = f'My name is {name} and I am {age} years old'
print(fstring)

Output: My name is Rajesh and I am 23 years old

Fast, readable, allows inline expressions, requires Python 3.6+

Template Strings

from string import Template

temp_str = "My name is $name and I am $age years old"
tempobj = Template(temp_str)
ret = tempobj.substitute(name='Rajesh', age=23)
print(ret)

Output: My name is Rajesh and I am 23 years old

Provides customizable and safe string substitution using $ placeholders.

Text Wrapping with textwrap Module

import textwrap
text = '''Python is a high-level, general-purpose programming language. Its design philosophy emphasizes code readability with the use of significant indentation...'''
wrapper = textwrap.TextWrapper(width=40)
wrapped = wrapper.wrap(text=text)
for line in wrapped:
    print(line)

Wraps text to specified width to make output more readable.

Pretty Printing with pprint Module

import pprint
students = {
    "Dilip": ["English", "Maths", "Science"],
    "Raju": {"English": 50, "Maths": 60, "Science": 70},
    "Kalpana": (50, 60, 70)
}
pp = pprint.PrettyPrinter()
print("normal print output")
print(students)
print("----")
print("pprint output")
pp.pprint(students)

Pretty printer formats complex data structures in a readable way with indentation and sorting.

Custom HTML Video Player

We can create a custom HTML video player using the <video> tag, along with CSS and JavaScript for enhanced features. HTML provides native video support without requiring Flash.

In this tutorial, you will learn how to build a video player where users can upload and play local video files directly in the browser.

We also recommend reviewing the basics of embedding video in HTML to understand the <video> tag.

Complete Code Example: Custom HTML Video Player

The following example demonstrates how to create a simple custom video player that allows users to upload and play their local video file: 

<!DOCTYPE html>
<html>
<head>
   <title>Custom Video Player</title>
</head>
<body>
   <input type="file" accept="video/*">
   <br>
   <video controls height="300" width="500"></video>

   <script>
      (function localFileVideoPlayer() {
         var handleFile = function(event) {
            var file = this.files[0];
            var url = window.URL || window.webkitURL;
            var fileURL = url.createObjectURL(file);
            var videoNode = document.querySelector('video');
            videoNode.src = fileURL;
         }
         var inputNode = document.querySelector('input');
         inputNode.addEventListener('change', handleFile, false);
      })()
   </script>
</body>
</html>

Capture and Play Video Using Camera

We can also capture video directly from the user’s camera using the Media Devices API. The following example demonstrates how to stream camera input into a video element and capture an image using a canvas: 

<!DOCTYPE html>
<html>
<head>
   <title>Camera Capture</title>
</head>
<body>
   <video id="vid" controls autoplay></video>
   <canvas id="mytutorial" width="600" height="300"></canvas>
   <button id="snapshot">Take Picture</button>

   <script>
      const video = document.getElementById('vid');
      const canvas = document.getElementById('mytutorial');
      const context = canvas.getContext('2d');
      const button = document.getElementById('snapshot');

      button.addEventListener('click', () => {
         context.drawImage(video, 0, 0, canvas.width, canvas.height);
      });

      navigator.mediaDevices.getUserMedia({ video: true })
         .then((stream) => {
            video.srcObject = stream;
         });
   </script>
</body>
</html>

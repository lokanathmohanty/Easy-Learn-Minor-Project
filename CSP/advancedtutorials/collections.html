C# Collections: Specialized Data Structures

Overview of Collection Classes 🗃️

**Collection classes** are specialized classes in C# designed for efficient data storage and retrieval. They provide support for dynamic data structures like stacks, queues, lists, and hash tables.

A key characteristic of the older (non-generic) collection classes, such as those in the **`System.Collections`** namespace, is that they store elements as objects of the **`Object`** class (the base class for all C# types), allowing them to hold elements of **any data type**.

Common Non-Generic Collection Types

1. ArrayList

The **`ArrayList`** is a dynamic, non-generic collection that can store elements of different data types. It acts as a flexible alternative to a fixed-size array, automatically resizing as elements are added or removed.

  • **Access:** By zero-based **index**.
  • **Key Feature:** Dynamic resizing, allowing insertion/removal at specified positions.

2. Hashtable

The **`Hashtable`** stores data as **key-value pairs**.

  • **Access:** By a unique **key**.
  • **Key Feature:** Highly efficient element access based on the key's hash code. Keys must be unique.

3. SortedList

The **`SortedList`** also stores key-value pairs, but with the added feature that the elements are **automatically sorted** based on their keys.

  • **Access:** By both a unique **key** (like a Hashtable) or an **index** (like an ArrayList).
  • **Key Feature:** Maintains elements in key-sorted order at all times.

Stack and Queue (LIFO and FIFO)

4. Stack 🧱

The **`Stack`** collection implements a **Last-In, First-Out (LIFO)** data structure. Elements are added and removed from the *top*.

  • **Adding:** **`Push`**
  • **Removing:** **`Pop`** (removes and returns the item)

5. Queue 〰️

The **`Queue`** collection implements a **First-In, First-Out (FIFO)** data structure. Elements are added at the *end* and removed from the *front*.

  • **Adding:** **`Enqueue`**
  • **Removing:** **`Dequeue`** (removes and returns the item)

6. BitArray

A **`BitArray`** represents an array of binary values (bits, 1 and 0). It is used for storing collections of booleans or binary data where the number of bits may not be known initially.

  • **Access:** By integer **index**.
  • **Key Feature:** Efficient storage and manipulation of individual bits.

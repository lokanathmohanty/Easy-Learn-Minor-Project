PowerShell - Quick Guide

Windows PowerShell is a powerful command-line shell and scripting language designed for system administration. It allows you to automate tasks and manage Windows operating systems and applications efficiently.

Key Concepts

  • Cmdlets: Lightweight commands in PowerShell used for various tasks (e.g., Get-Help, Get-Process).
  • Pipeline: Output of one cmdlet can be passed as input to another using the pipe | operator.
  • Objects: PowerShell works with objects, not just text, allowing richer manipulation of data.
  • Scripts: You can write and run PowerShell scripts (.ps1 files) to automate complex tasks.

Basic Commands

  • Get-Help <cmdlet-name>: Get help about a cmdlet.
  • Get-Command: List all available cmdlets and functions.
  • Get-Service: View running services.
  • Get-Process: List running processes.
  • Set-ExecutionPolicy: Manage script execution policies.

Running Scripts

To run a script, you can type its path in PowerShell, for example:

.\myscript.ps1

If you get an execution policy error, run PowerShell as Administrator and set the policy:

Set-ExecutionPolicy RemoteSigned

Useful Tips

  • Use Tab for command auto-completion.
  • Use Get-Help Update-Help to download the latest help files.
  • Use variables by prefixing with $ (e.g., $name = "User").
  • Use comments in scripts with #.

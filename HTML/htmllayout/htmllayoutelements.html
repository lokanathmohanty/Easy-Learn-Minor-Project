HTML - Layout Elements

HTML layout elements are special semantic elements that define the structure and layout of a web page. These elements divide the content into logical sections, improving readability, accessibility, and SEO performance.

Common layout parts of a web page include a header, navigation bar, content sections, articles, sidebars, and a footer.

Key HTML Layout Elements

  • <header> − Defines the header section of a page (title, intro, navigation).
  • <nav> − Contains navigation links to other pages or sections.
  • <section> − Defines major parts of a webpage (main content blocks).
  • <footer> − Displays copyright, contact info, and links at the bottom.
  • <article> − Represents independent content like blog posts or news.
  • <aside> − Represents related or sidebar content (ads, links, etc.).

HTML <header> Element

The <header> element acts as a container for introductory and navigational content, usually placed at the top of a page.

Example

<header>
  <h1>Tutorialspoint</h1>
  <h3>Simply easy learning!</h3>
</header>

HTML <nav> Element

The <nav> element represents a navigation menu with hyperlinks to sections of the same page or other pages.

Example

<nav>
  <ul>
    <li><a href="#">Home</a></li>
    <li><a href="#">HTML</a></li>
    <li><a href="#">CSS</a></li>
    <li><a href="#">JavaScript</a></li>
  </ul>
</nav>

HTML <section> Element

The <section> element defines a major content area. A webpage can have multiple sections.

Example

<section>Section 1</section>
<section>Section 2</section>

HTML <footer> Element

The <footer> element defines the bottom section of a page, often containing copyright information, policies, and links.

Example

<footer>
  <p>© 2024 Tutorialspoint. All rights reserved.</p>
  <a href="#">Privacy Policy</a> | 
  <a href="#">Contact</a>
</footer>

HTML <article> Element

The <article> element specifies self-contained content such as a blog post, news article, or forum entry.

Example

<article>
  <h2>Understanding the Article Tag</h2>
  <p>Posted on June 20, 2024 by Admin</p>
  <p>The article tag is used for posts, news, or comments.</p>
</article>

HTML <aside> Element

The <aside> element defines optional or related content such as sidebars, advertisements, or links.

Example

<aside>
  <h3>Related Links</h3>
  <ul>
    <li><a href="#">HTML Tutorial</a></li>
    <li><a href="#">CSS Tutorial</a></li>
  </ul>
</aside>

Creating Layout with Semantic Elements

By combining the above semantic tags, you can create a structured and accessible webpage layout.

Example

<header>
  <h1>My Website</h1>
  <nav>Menu Links</nav>
</header>

<section>
  <article>
    <h2>Main Content</h2>
    <p>This is the article section.</p>
  </article>

  <aside>
    <h3>Sidebar</h3>
    <p>Related links go here.</p>
  </aside>
</section>

<footer>
  <p>Copyright © 2024</p>
</footer>

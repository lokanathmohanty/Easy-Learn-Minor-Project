PHP `$_GET` Superglobal

The **`$_GET`** is a **superglobal associative array** in PHP used to collect data passed to the current script via the **URL query string**. This data is visible in the browser's address bar and is typically associated with the HTTP **GET** request method, though it is populated anytime a query string is present.

How `$_GET` is Populated

Data is passed to `$_GET` in two main ways:

1. Direct URL Access (Query String)

Key-value pairs are appended to the URL after a question mark (`?`), separated by ampersands (`&`).

**URL:** http://server/script.php?**name=Amit&age=22**

**PHP Access:**
echo $_GET['name']; // Amit
echo $_GET['age']; // 22

2. HTML Form Submission (method="get")

If an HTML form uses the `method="get"` attribute, the field names and values are automatically appended to the action URL as a query string when the form is submitted.

**HTML:** <form action="hello.php" **method="get"**>
   <input type="text" **name="first_name"** />
</form>

**PHP:** echo $_GET['first_name'];

Security and Best Practices ⚠️

  • **Visibility & Limits:** Data sent via `GET` is visible in the URL, browser history, and server logs, making it **unsuitable for sensitive data** like passwords. Additionally, URLs have length restrictions, limiting the data volume.
  • **Sanitization is Critical:** Since data comes directly from the URL, it is easily manipulated by users. To prevent Cross-Site Scripting (XSS) and other vulnerabilities, always sanitize and validate all input from `$_GET`.

    Use `htmlspecialchars()` to convert special characters (like `<`, `>`, `&`) into their HTML entity equivalents before echoing them to the browser:

    echo htmlspecialchars($_GET["name"]);

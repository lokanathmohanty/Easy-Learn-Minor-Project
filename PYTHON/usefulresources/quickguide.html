Python Quick Guide

Python is a high-level, interpreted, and object-oriented programming language known for its simplicity and readability. It supports multiple programming paradigms including procedural, functional, and object-oriented styles. This quick guide gives you a solid foundation to get started with Python.

Getting Started

  • Python can be installed from python.org.
  • Run Python in interactive mode using python or execute scripts using python filename.py.
  • Python files use the .py extension.

Basic Syntax

# Printing
print("Hello, World!")

# Variables
x = 10
y = 20.5
name = "Python"

# Comments
# This is a single-line comment
""" This is a
multi-line comment """

Data Types

  • Numbers: int, float, complex
  • Sequence: list, tuple, range
  • Text: str
  • Mapping: dict
  • Set: set, frozenset
  • Boolean: True, False

Control Structures

# If-Else
age = 18
if age >= 18:
    print("Adult")
else:
    print("Minor")

# Loops
for i in range(5):
    print(i)

count = 0
while count < 5:
    print(count)
    count += 1

Functions

def greet(name):
    return "Hello, " + name

print(greet("Python"))

Collections

# List
fruits = ["apple", "banana", "cherry"]

# Tuple
coordinates = (10, 20)

# Dictionary
person = {"name": "John", "age": 25}

# Set
unique_nums = {1, 2, 3, 3}

Object-Oriented Programming

class Person:
    def __init__(self, name):
        self.name = name

    def greet(self):
        print("Hello, my name is " + self.name)

p = Person("Alice")
p.greet()

Modules and Packages

# Importing a module
import math
print(math.sqrt(16))

# Creating your own module
# Save code in mymodule.py and import it
import mymodule

File Handling

# Writing to a file
with open("test.txt", "w") as f:
    f.write("Hello World")

# Reading a file
with open("test.txt", "r") as f:
    content = f.read()
    print(content)

Exceptions

try:
    num = int("abc")
except ValueError:
    print("Invalid conversion")
finally:
    print("End of block")

Virtual Environments

  • Create: python -m venv myenv
  • Activate: myenv\Scripts\activate (Windows) or source myenv/bin/activate (Linux/Mac)
  • Deactivate: deactivate

Popular Libraries

  • NumPy: Numerical computations
  • Pandas: Data analysis
  • Matplotlib / Seaborn: Visualization
  • Flask / Django: Web development
  • TensorFlow / PyTorch: Machine learning

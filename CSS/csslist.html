CSS - Styling Lists

Lists are essential in web development because they help organize information in a structured and easy-to-read manner. CSS provides various properties to control the appearance of lists, including the style of markers, position, images as markers, and shorthand notations.

Types of Lists

HTML supports three primary types of lists:

  • Ordered List (<ol>): Displays items in a specific order, such as steps or procedures.
  • Unordered List (<ul>): Displays items without a required sequence, commonly shown with bullets.
  • Definition List (<dl>): Displays terms with their corresponding descriptions.

List Style Type Property

The list-style-type property defines the type of marker used for lists.

Example

<ul style="list-style-type: circle;">
  <li>Circle bullet</li>
  <li>Circle bullet</li>
</ul>

<ol style="list-style-type: upper-roman;">
  <li>Roman numeral</li>
  <li>Roman numeral</li>
</ol>

List Style Image Property

The list-style-image property allows using an image as a custom list marker.

Example

<ul style="list-style-image: url('smiley.png');">
  <li>Custom bullet 1</li>
  <li>Custom bullet 2</li>
</ul>

List Style Position Property

The list-style-position property controls whether the marker appears inside or outside the list item box.

  • inside: The marker is inside the content flow.
  • outside: The marker is outside the content area (default).

Example

<ul style="list-style-position: inside;">
  <li>Marker inside</li>
</ul>

<ul style="list-style-position: outside;">
  <li>Marker outside</li>
</ul>

List Style Shorthand Property

The list-style property is a shorthand for setting list-style-type, list-style-image, and list-style-position in one line.

Example

<ul style="list-style: square inside;">
  <li>Shorthand style 1</li>
  <li>Shorthand style 2</li>
</ul>

Styling Unordered List

You can enhance unordered lists with background, hover effects, and spacing.

Example

<ul style="list-style-type: none;">
  <li>Styled item 1</li>
  <li>Styled item 2</li>
  <li>Styled item 3</li>
</ul>

Styling Definition List

Definition lists (<dl>) are useful for displaying key-value pairs like glossaries or FAQs. They can be styled to highlight terms and provide emphasis on descriptions.

Example

<dl>
  <dt>HTML</dt>
  <dd>A markup language for structuring web pages.</dd>

  <dt>CSS</dt>
  <dd>A language for styling web documents.</dd>

  <dt>JavaScript</dt>
  <dd>A language for making web pages interactive.</dd>
</dl>

List Style Type Reference

The following values can be applied with list-style-type:

  • none: No marker
  • disc: Default filled circle
  • circle: Empty circle
  • square: Filled square
  • decimal: Numbers (1, 2, 3…)
  • decimal-leading-zero: Numbers with leading zero (01, 02…)
  • lower-alpha: Lowercase letters (a, b, c…)
  • upper-alpha: Uppercase letters (A, B, C…)
  • lower-roman: Lowercase Roman numerals (i, ii, iii…)
  • upper-roman: Uppercase Roman numerals (I, II, III…)
  • lower-greek: Greek alphabet (alpha, beta…)
  • armenian: Armenian numbering
  • georgian: Georgian numbering
  • cjk-ideographic: Ideographic numbers
  • hiragana, katakana: Japanese numbering
  • hiragana-iroha, katakana-iroha: Japanese iroha ordering

Python - Class Methods

Methods belong to objects of a class and perform specific operations. Python methods fall into three categories: class methods, instance methods, and static methods.

A class method is bound to the class itself rather than an instance, and it can be called on the class directly. Class methods receive the class as the first parameter, conventionally named cls. This is different from instance methods which receive the instance (self) as the first parameter.

Creating Class Methods in Python

There are two main ways to create class methods:

  • Using the built-in classmethod() function
  • Using the @classmethod decorator

Using classmethod() Function

The classmethod() function transforms an instance method into a class method that can only be called on the class.

class Employee:
    empCount = 0

    def __init__(self, name, age):
        self.__name = name
        self.__age = age
        Employee.empCount += 1

    def showcount(self):
        print(self.empCount)

    counter = classmethod(showcount)

e1 = Employee("Bhavana", 24)
e2 = Employee("Rajesh", 26)
e3 = Employee("John", 27)

e1.showcount()
Employee.counter()

Output:
3
3

Using @classmethod Decorator

The @classmethod decorator is the preferred and more readable way to define class methods.

class Employee:
    empCount = 0

    def __init__(self, name, age):
        self.name = name
        self.age = age
        Employee.empCount += 1

    @classmethod
    def showcount(cls):
        print(cls.empCount)

    @classmethod
    def newemployee(cls, name, age):
        return cls(name, age)

e1 = Employee("Bhavana", 24)
e2 = Employee("Rajesh", 26)
e3 = Employee("John", 27)
e4 = Employee.newemployee("Anil", 21)

Employee.showcount()

Output:
4

Accessing Class Attributes in Class Methods

Class methods can access class attributes using the cls parameter and dot notation.

class Cloth:
    price = 4000  # Class attribute

    @classmethod
    def showPrice(cls):
        return cls.price

print(Cloth.showPrice())

Output:
4000

Dynamically Adding and Deleting Class Methods

You can dynamically add a class method to a class using setattr():

class Cloth:
    pass

@classmethod
def brandName(cls):
    print("Name of the brand is Raymond")

setattr(Cloth, "brand_name", brandName)
newObj = Cloth()
newObj.brand_name()

Output:
Name of the brand is Raymond

To delete a dynamically added class method, use the del operator:

class Cloth:
    @classmethod
    def brandName(cls):
        print("Name of the brand is Raymond")

del Cloth.brandName
print("Method deleted")

Output:
Method deleted

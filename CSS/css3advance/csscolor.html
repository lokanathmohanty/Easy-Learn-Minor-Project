Overview

CSS colors are used to set the foreground (text), background, borders, shadows and many decorative effects. Colors can be expressed in multiple formats — keywords, hex, rgb/rgba, hsl/hsla, functions, and special keywords such as currentcolor. Understanding these formats helps you pick the right representation for readability, accessibility and performance.

Common Color Formats

  • Keyword — named colors such as red, blue, aqua.
  • Hexadecimal — 6-digit hex: #RRGGBB (example: #FF0000).
  • Short hex — 3-digit shorthand: #RGB (example: #F00 → #FF0000).
  • RGB — rgb(r, g, b) where values are 0–255 or percentages.
  • RGBA — rgba(r, g, b, a) with alpha 0–1 for transparency.
  • HSL — hsl(h, s%, l%) uses hue (0–360), saturation and lightness.
  • HSLA — hsla(h, s%, l%, a) with alpha transparency.
  • currentcolor — keyword referring to the element's current color value, usable in borders and shadows.
  • System colors — OS/browser defined tokens (older usage).

Why choose one format over another?

  • Keywords are readable and quick for common colors, but limited in variety.
  • Hex is compact and widely supported; great for static palettes.
  • RGB/RGBA allow precise channel control and alpha transparency.
  • HSL/HSLA are easier to reason about when adjusting hue, saturation or lightness programmatically.
  • currentcolor makes components inherit color for consistent theming.

Examples (CSS written as escaped text for clarity)

1. Keyword

Example CSS (text):

p { color: red; background-color: aqua; }

2. Hexadecimal

Example CSS (text):

div { background-color: #00FF00; }

3. Short Hex

Example CSS (text):

div { background-color: #00F; /* equivalent to #0000FF */ }

4. RGB

Example CSS (text):

div { background-color: rgb(255, 0, 255); }

5. RGBA (with transparency)

Example CSS (text):

div { background-color: rgba(255, 0, 255, 0.2); }

6. HSL

Example CSS (text):

div { background-color: hsl(120, 100%, 50%); /* pure green */ }

7. HSLA

Example CSS (text):

div { background-color: hsla(355, 70%, 50%, 0.4); }

8. currentcolor

Example CSS (text):

h2 { color: red; } h2::after { border-left: 4px solid currentcolor; }

Practical Patterns and Tips

  • Theme variables: use CSS custom properties to centralize palette: --primary, --accent, etc., then use color: var(--primary).
  • Contrast & accessibility: ensure text and background color combinations pass contrast checks (WCAG) for readability.
  • Alpha overlays: use rgba/hsla for overlays and subtle tints.
  • Programmatic adjustments: prefer HSL when you need systematic lightening/darkening via saturation/lightness edits.
  • Consistent component colors: use currentcolor inside components so borders/shadows follow the component text color automatically.

Browser Support and Notes

  • All modern browsers support hex, rgb(a) and hsl(a).
  • Keywords are widely supported but limited to the predefined list.
  • Use fallbacks if you rely on newer color formats in older target environments.
  • System colors and legacy color keywords are rarely required today.

Large Example: Using Variables and Formats (as text)

Below is a multi-line example shown as plain text so you can paste it into your stylesheet. It uses variables, hex, rgba and currentcolor patterns.

/* CSS example (text) */

:root { --primary: #1a73e8; --muted: rgba(0,0,0,0.6); }

.btn { color: var(--primary); border: 2px solid currentcolor; }

.card { background: hsl(210, 40%, 98%); box-shadow: 0 4px 8px rgba(0,0,0,0.08); }

.overlay { background: rgba(0, 0, 0, 0.5); }

Cheatsheet: When to Use Which Format

  • Hex — simple palettes, copy/paste from design tools.
  • RGB(A) — precise channel control, alpha transparency.
  • HSL(A) — easy programmatic hue/saturation/lightness adjustments.
  • Keywords — semantic quick use for common colors.
  • currentcolor — build components that adapt to text color.

Summary

CSS provides many ways to express color. Choose the format that best matches your needs: hex for static palettes, rgba/hsla for transparency, hsl for programmatic tweaks, and currentcolor for adaptive components. Always check accessibility and keep a consistent design token strategy for maintainable color systems.

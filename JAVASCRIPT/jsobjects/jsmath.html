JavaScript - Math

The JavaScript Math object provides properties and methods for mathematical constants and functions. Unlike other global objects, Math is not a constructor. All the properties and methods of Math are static and can be called directly without creating an instance.

For example, you refer to the constant pi as Math.PI and call the sine function as Math.sin(x), where x is the argument.

Syntax

var pi_val = Math.PI;   // Property
var sine_val = Math.sin(30); // Method

JavaScript Math Properties

  • E − Euler's constant (≈ 2.718).
  • LN2 − Natural logarithm of 2 (≈ 0.693).
  • LN10 − Natural logarithm of 10 (≈ 2.302).
  • LOG2E − Base 2 logarithm of E (≈ 1.442).
  • LOG10E − Base 10 logarithm of E (≈ 0.434).
  • PI − The ratio of circumference to diameter (≈ 3.14159).
  • SQRT1_2 − Square root of 1/2 (≈ 0.707).
  • SQRT2 − Square root of 2 (≈ 1.414).

JavaScript Math Methods

  • abs() − Returns the absolute value of a number.
  • acos() − Returns the arccosine (in radians) of a number.
  • acosh() − Returns the inverse hyperbolic cosine of a number.
  • asin() − Returns the arcsine (in radians) of a number.
  • asinh() − Returns the inverse hyperbolic sine of a number.
  • atan() − Returns the arctangent (in radians) of a number.
  • atan2() − Returns the arctangent of the quotient of its arguments.
  • atanh() − Returns the inverse hyperbolic tangent of a number.
  • cbrt() − Returns the cube root of a number.
  • ceil() − Returns the smallest integer greater than or equal to a number.
  • clz32() − Returns the number of leading zeros in a 32-bit binary representation.
  • cos() − Returns the cosine of a number.
  • cosh() − Returns the hyperbolic cosine of a number.
  • exp() − Returns EN, where N is the argument.
  • expm1() − Returns EN - 1.
  • floor() − Returns the largest integer less than or equal to a number.
  • fround() − Returns the nearest 32-bit float representation.
  • hypot() − Returns the square root of the sum of squares of arguments.
  • imul() − Performs 32-bit multiplication.
  • log() − Returns the natural logarithm (base E).
  • log10() − Returns the base 10 logarithm.
  • log1p() − Returns the natural logarithm of (1 + N).
  • log2() − Returns the base 2 logarithm.
  • max() − Returns the largest number among arguments.
  • min() − Returns the smallest number among arguments.
  • pow() − Returns base raised to the exponent power.
  • random() − Returns a pseudo-random number between 0 and 1.
  • round() − Returns a number rounded to the nearest integer.
  • sign() − Returns -1, 0, or 1 indicating the sign of the number.
  • sin() − Returns the sine of a number.
  • sinh() − Returns the hyperbolic sine.
  • sqrt() − Returns the square root of a number.
  • tan() − Returns the tangent of a number.
  • tanh() − Returns the hyperbolic tangent of a number.
  • trunc() − Returns the integer part of a number.

Examples

Example: Math Properties

document.write("Math.E == " + Math.E + "<br>" +
               "Math.LN2 == " + Math.LN2 + "<br>" +
               "Math.LN10 == " + Math.LN10 + "<br>" +
               "Math.PI == " + Math.PI);

Output: Displays values of Math constants.

Example: Math.ceil()

let ans = Math.ceil(5.9);
document.write("Math.ceil(5.9) = " + ans);

Output: Returns 6.

Example: Math.max()

let ans = Math.max(100, 10, -5, 89, 201, 300);
document.write("Math.max(...) = " + ans);

Output: Returns 300.

Example: Math.cos()

let ans = Math.cos(0);
document.write("Math.cos(0) = " + ans);

Output: Returns 1.

R - Analysis of Covariance (Poisson Regression)

Poisson regression models count data (non-fractional values), assuming the response variable follows a Poisson distribution. It models the log of the expected count as a linear combination of predictor variables:

Model: \( \log(y) = a + b_1 x_1 + b_2 x_2 + \dots + b_n x_n \)

where \(y\) is the count response, \(a, b_i\) are numeric coefficients, and \(x_i\) are predictor variables.

The glm() function with family set to poisson is used.

Syntax

glm(formula, data, family = poisson)

Example

Use the built-in "warpbreaks" dataset relating wool type and tension to number of warp breaks:

# Load data
input <- warpbreaks
print(head(input))

# Create Poisson regression model
output <- glm(formula = breaks ~ wool + tension, data = warpbreaks, family = poisson)
print(summary(output))

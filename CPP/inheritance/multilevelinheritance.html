C++ Multilevel Inheritance (Inheritance Chain) 🪜

**Multilevel inheritance** is a type of inheritance where a class is derived from another class that is itself a derived class. This creates a **chain of inheritance** that allows properties and behaviors to be passed down through multiple generations of classes, establishing a transitive "is-a" relationship (e.g., a Triangle is-a Polygon, and a Polygon is-a Shape).

Syntax

class Base { /* ... */ }; 
class Derived1 : public Base { /* ... */ }; 
class Derived2 : public Derived1 { /* ... */ }; // Derived2 inherits from Derived1

  • Base is the grandparent.
  • Derived1 inherits from Base (Parent $\rightarrow$ Child).
  • Derived2 inherits from Derived1 (Grandchild $\rightarrow$ Parent).

Example and Mechanism

In the example provided:

  1. The **Shape** class is the **Base** class.
  2. The **Polygon** class inherits from **Shape**. It gains access to Shape's members (like display()).
  3. The **Triangle** class inherits from **Polygon**. It gains access to Polygon's members (like sides()) AND, through Polygon, it gains access to Shape's members (like display()).

When an object of the deepest derived class, Triangle, is created, it possesses the characteristics of all its predecessors:

Triangle myTriangle;
myTriangle.display(); // Calls Shape::display()
myTriangle.sides();   // Calls Polygon::sides()
myTriangle.type();    // Calls Triangle::type()

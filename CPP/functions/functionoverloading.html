C++ Function Overloading (Compile-Time Polymorphism) 🔄

Function Overloading is a powerful feature in C++ that allows you to define **multiple functions** with the **same name** within the same scope. The key is that each overloaded function must have a distinct **function signature**, achieved by varying the type, order, or number of its parameters.

This is a form of **compile-time polymorphism**, enabling a single function name to be used for a set of related operations, making the code more readable and intuitive.

How Overloading Works (The Function Signature)

When the compiler encounters a function call, it determines which version of the overloaded function to execute by examining the **function signature** of the call and matching it against the defined signatures. The signature includes:

  1. The **Number** of parameters.
  2. The **Type** of each parameter.
  3. The **Order** of the parameters.

The **return type** alone is **not** part of the function signature and cannot be used to differentiate overloaded functions.

Example: Multiple Definitions for addition

// Signature 1: (int, int)
int addition(int a, int b) { ... } 

// Signature 2: (int, int, int)
int addition(int a, int b, int c) { ... } 

// Signature 3: (float, float) - Different parameter types
float addition(float a, float b) { ... }

When calling addition(10.5f, 20.3f), the compiler matches the call to the function that takes two `float` arguments (Signature 3).

Overloading Criteria

1. Based on Number of Parameters

The functions have the same name but accept a different count of arguments.

void display(int a);           // Call: display(10);
void display(int a, double b); // Call: display(10, 3.14);

2. Based on Different Parameter Types

The functions have the same name and number of arguments, but the types are different.

void show(int a);    // Call: show(10);
void show(double a); // Call: show(3.14);

3. Based on Different Parameter Order

The functions have the same name, the same number of arguments, and the same *types*, but their **sequence** is different.

void display(int a, double b);    // Call: display(10, 3.14);
void display(double a, int b);    // Call: display(3.14, 10);

Common Use Cases

Function overloading is crucial for creating intuitive APIs:

  • **Handling Different Data Types:** Implementing the same core logic (e.g., `max`, `add`, `print`) for various data types (`int`, `float`, `string`) under a single, unified function name.
  • **Providing Optional Parameters:** Using different overloads to handle cases where a user might or might not supply certain parameters (though **default parameters** are often an alternative for this).
  • **Different Contexts:** Providing variations of a function to suit specific requirements, such as a function that saves data requiring only the file name, and another overload requiring the file name and encryption key.

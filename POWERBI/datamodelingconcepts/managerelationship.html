Once datasets are uploaded into Power BI Desktop, it automatically detects relationships between them.

To modify or manage these relationships, Power BI provides the Manage relationships feature. This allows users to add, edit, or delete existing relationships between tables.

Handle Relationship in Data Modeling

Follow these steps to manage relationships in your data model:

Step 1

Go to the Model View and click on Manage relationships under the Home tab.

You will see existing relationships such as many-to-one between dt and Sheet1.

Step 2

In the Manage relationships dialog, you can add, edit, or delete a relationship. To delete, select a relationship and click Delete.

Step 3

Confirm the deletion in the Delete relationship dialog box.

Step 4

After deletion, the connection between the two tables (e.g., dt and Sheet1) will be removed in the Model View.

Step 5

Click on New in the Manage relationships dialog to create a new relationship.

  • First Table: Sheet1
  • Second Table: dt
  • Cardinality: One to many (1:*)

Click OK and then Close.

This creates a one-to-many relationship where the arrow goes from Sheet1 to dt, showing a single cross-filter direction.

Step 6

In the Properties pane, set the cross-filter direction to Both and click Apply changes. This makes the relationship bidirectional, which can help when dealing with multiple datasets.

Strong vs Weak Relationships

  • Strong Relationship: Represented by a solid line.
  • Weak Relationship: Represented by a dotted line.

Types of Keys in Data Modeling

  • Primary Key: Contains unique, non-null values.
  • Foreign Key: A field in another table that refers to the primary key.
  • Composite Key: Combines multiple fields to ensure uniqueness. Duplicate or empty values should be removed first.

Key Points While Managing Relationships

  • Only one active relationship can exist between two tables.
  • You can set Single or Both for cross-filter direction.
  • Too many relationships can create confusion and complexity.
  • Circular relationships are not allowed.
  • Proper relationships reduce model size and increase performance.

Role-Playing Dimensions

If a table has multiple one-to-many relationships with another, only one can be active. The inactive relationships can still be used via DAX expressions.

Table Configuration and Column Properties

In the Model View, selecting a table opens the Properties pane with two sections: General and Advanced.

General Section

  • Rename the table under Name.
  • Write a description under Description.
  • Set the Row label (e.g., "Yr").
  • Select a Key column (e.g., "ky_id").

Advanced Section

Here, you can change the Storage mode from Import to Direct Query. Sometimes this may be disabled due to configuration issues.

Formatting Options

When selecting a numeric column (e.g., ky_id), you will see formatting options:

  • Data type
  • Format
  • Percent format
  • Thousand separator

You can choose Fixed decimal number and adjust formatting accordingly. Use Table View to preview the formatted fields.

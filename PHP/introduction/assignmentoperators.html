PHP Assignment Operators Examples

**Assignment Operators** in PHP are used to assign a value to a variable. The most basic is the simple assignment operator (`=`). PHP also provides **Compound Assignment Operators**, which are a shorthand notation for performing an operation on a variable and then re-assigning the result back to that same variable.

Arithmetic Compound Assignment Operators

These operators combine an arithmetic operation with assignment, offering a concise way to update a variable's value.

Operator Description Equivalent to Example ($c=62, $a=42) New Value of $c
+= Add AND assignment $c = $c + $a $c += $a $62 + 42 = 104
-= Subtract AND assignment $c = $c - $a $c -= $a $62 - 42 = 20
*= Multiply AND assignment $c = $c * $a $c *= $a $62 * 42 = 2604
/= Divide AND assignment $c = $c / $a $c /= $a $62 / 42 \approx 1.476$
%= Modulus AND assignment $c = $c % $a $c %= $a $62 \% 42 = 20$

Bitwise and Other Assignment Operators

PHP also supports compound assignment for **Bitwise** operations and **String concatenation**.

Bitwise Assignment Operators (Example with $a = $a \texttt{ operator } $b$)

  • **`&=`**: Bitwise AND assignment (e.g., `$a &= $b`)
  • **`|=`**: Bitwise OR assignment (e.g., `$a |= $b`)
  • **`^=`**: Bitwise XOR assignment (e.g., `$a ^= $b`)
  • **`<<=`**: Left Shift AND assignment (e.g., `$a <<= 2$)
  • **`>>=`**: Right Shift AND assignment (e.g., `$a >>= 2$)

String Concatenation Assignment Operator

  • **`.=`**: Concatenation AND assignment. Appends the right operand's string value to the left operand's string value.
    $s = "Hello"; $s .= " World"; $\rightarrow$ $s is now "Hello World"

Practical Use in Loops

Assignment operators, especially `+=`, are commonly used to update loop counters or totals in a single, clean statement.

This loop uses $num += 2; to increment the loop variable by 2 in each iteration, printing odd numbers.

<?php
$num = 1;
while ($num <= 10) {
   echo "$num ";
   $num += 2; // Shorthand for $num = $num + 2;
}
?>

Output: 1 3 5 7 9

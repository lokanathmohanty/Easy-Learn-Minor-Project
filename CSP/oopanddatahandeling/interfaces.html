C# Interfaces

Defining the Contract

An **Interface** defines a **syntactical contract** that specifies a set of members (methods, properties, events) that a class or struct must implement. It defines the **'what'** (the contract) but not the **'how'** (the implementation).

  • Interfaces contain **only declarations**; they cannot contain fields or implementation logic.
  • All interface members are **implicitly public** and **abstract**.
  • A key use is to achieve **polymorphism** and allow a class to inherit common behavior from multiple sources (since C# doesn't support multiple class inheritance).

Declaration Syntax:

Interfaces are declared using the **`interface`** keyword, conventionally prefixed with an I (e.g., ITransactions).

public interface ITransactions {
   // Method declaration (no body)
   void showTransaction();
   
   // Property declaration
   double getAmount();
}

Implementing Interfaces

A class or struct uses the colon (:) notation to implement an interface. It must provide a **public implementation** for every member declared in the interface.

// Implement the interface in a class
public class Transaction : ITransactions {
   private double amount;
   
   // Providing the implementation for the interface method
   public void showTransaction() {
      Console.WriteLine("Amount: {0}", getAmount());
   }
   
   // Providing the implementation for the interface method
   public double getAmount() {
      return amount;
   }
}

Multiple Interface Implementation

Unlike classes, a class can implement multiple interfaces, separating them by commas. This is how C# achieves the flexibility of **multiple inheritance** of behavior.

class MyClass : IInterfaceA, IInterfaceB {
    // ... must implement all members from A and B
}

Common .NET Interfaces

Many core C# behaviors are defined through standard interfaces, enforcing consistency across collections and data types.

1. `IEnumerable` (for Iteration)

This interface defines the **iterator pattern**. Any class implementing IEnumerable can be iterated over using a **`foreach`** loop. It exposes the GetEnumerator() method, which is the key to iteration.

class Demo : IEnumerable, IEnumerator { /* ... implementation ... */ }
// Allows: foreach (var number in demo) { ... }

2. `IList` (for List-like Collections)

A generic interface implemented by arrays and List. It defines methods for sequential collections, including indexed access, addition, removal, and counting.

IList<int> numbers = new List<int> { 1, 2, 3 };
// Features: numbers[index], numbers.Add(), numbers.Remove()

3. `IDictionary` (for Key/Value Collections)

A generic interface defining the contract for collections of key/value pairs, implemented by Dictionary. Keys must be unique.

IDictionary<string, int> ages = new Dictionary<string, int>();
ages.Add("Sudhir", 27);
// Features: ages["Sudhir"], ages.ContainsKey(), ages.Remove()

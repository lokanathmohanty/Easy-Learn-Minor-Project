Next.js `<Link>` Component 🔗

Overview and Key Features

The **`` component** is a built-in Next.js feature that extends the standard HTML `` tag. It is essential for **client-side navigation** (making page transitions faster and smoother) and automatically handles **route prefetching** for optimized performance.

Any attributes from the standard `` tag (like `className`, `target="_blank"`, or `rel="noopener noreferrer"`) can be passed directly as props to `` and will be applied to the underlying `` element.

Basic Syntax:

import Link from 'next/link' 

export default function Page() {
    // The 'href' prop is the only required prop for navigation
    return <Link href="/about">About Page</Link>
}

Primary Props of the `<Link>` Component

Prop Description Effect
`href` **Required** URL or route path to navigate to. Defines the destination page.
`prefetch` A boolean to control route preloading. (Defaults to `true` when link is visible.) When `true`, the target page's JavaScript is loaded in the background for near-instant navigation.
`replace` If `true`, replaces the current URL entry in the browser history stack. **Prevents** the user from navigating back to the previous page.
`scroll` If `false`, prevents the page from automatically scrolling to the top upon navigation. Maintains the current scroll position on the new page.

Examples of Advanced `<Link>` Behavior

1. Preventing History Back (`replace`)

Setting `replace` to `true` is useful for actions like logging out or completing a workflow where returning to the previous page is not desired.

import Link from 'next/link'
// Navigates to /dashboard and removes the current page from history
<Link href="/dashboard" replace>Dashboard</Link>

2. Maintaining Scroll Position (`scroll`)

Setting `scroll` to `false` prevents the default browser behavior of scrolling to the top of the new page, which is helpful when navigating between content on long pages or partial views.

import Link from 'next/link'
// Navigates without scrolling to the top
<Link href="/about" scroll={false}>About Page</Link>

3. Creating a Persistent Navigation Bar

The `` component is commonly used within a **Layout Component** (like `app/layout.tsx` in the App Router) to create a navigation bar that appears across all routes, leveraging prefetching for fast access.

// app/layout.tsx file excerpt
import Link from 'next/link' 
// ...

<header>
    <h1>Header Element</h1>
    <ul> 
        <li><Link href="/">Home</Link></li> 
        <li><Link href="/products">Products</Link></li>
    </ul>
</header>
<main>{children}</main>

CSS - tab-size Property

The tab-size property in CSS is used to control the width of tab characters (U+0009) within an element. By default, browsers usually render tabs as the width of 8 spaces. With this property, developers can adjust how many spaces a tab should occupy or even set a specific length value in units like px or em.

This property is especially useful when displaying formatted text, such as programming code, where indentation matters. Without proper tab control, code alignment can break and reduce readability.

Key Points

  • Integer values: Set tab width as multiples of a space character (e.g., tab-size: 4; makes tabs equal to four spaces).
  • Length values: Set a fixed measurement (e.g., tab-size: 12px;).
  • Default: Most browsers use tab-size: 8; if not explicitly defined.
  • Applies to block containers such as <pre> and <p> with white-space: pre;.

Syntax

Integer syntax:

  • tab-size: 4;
  • tab-size: 2;

Length syntax:

  • tab-size: 16px;
  • tab-size: 2em;

Supported Browsers

The tab-size property is widely supported across major browsers, including Chrome, Edge, Firefox, Safari, and Opera.

Content Summary

The tab-size property allows developers to adjust the spacing of tab characters within block containers. It accepts integer and length values, and is useful in code formatting and text alignment. Default behavior is usually 8 spaces. Browser support is broad, making it reliable for practical use.

Example: Tab-size with Different Values

.tab1 {
   tab-size: 8;
}
.tab2 {
   tab-size: 12;
}

<pre class="tab1">
CSS	 tab-size with    8.
</pre>

<pre class="tab2">

</pre>

Example: Comparing Default and Custom Tab Size

p {
   white-space: pre;
}
.tab1 {
   tab-size: 3;
}

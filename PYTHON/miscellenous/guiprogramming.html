Python - GUI Programming

Python offers several GUI frameworks:

  • Tkinter: Standard Python interface to the Tk GUI toolkit.
  • wxPython: Python bindings for wxWidgets (cross-platform).
  • PyQt: Bindings for the Qt application framework.
  • PyGTK: Python bindings for GTK.
  • PySimpleGUI: Simplified GUI based on Tkinter, Qt, and wxPython.
  • Pygame: Library targeted at game development (SDL wrapper).
  • Jython: Python running on Java platform with access to Java libraries.

Tkinter Basics

Tkinter is Python’s built-in GUI library and provides many widgets:

  • Buttons, Labels, Entries, Frames, Listboxes, Menus, Scrollbars, Text widgets, and more.

Basic window creation:

import tkinter as tk
root = tk.Tk()
root.mainloop()

For complex apps, use OOP approach:

class App(tk.Tk):
    def __init__(self):
        super().__init__()
app = App()
app.mainloop()

Geometry Managers

Tkinter uses three geometry managers for layout:

  • pack: Organizes widgets in blocks.
  • grid: Organizes widgets in a table format.
  • place: Places widgets at specific positions.

Dialogs and Color Chooser

Modules provided include:

  • simpledialog: Prompts to get integer, float, or string input.
  • colorchooser: Dialog for selecting colors.
  • filedialog: Dialogs for open/save file and directory selection.
from tkinter import *
from tkinter import simpledialog, colorchooser, filedialog

root = Tk()
def get_integer():
    num = simpledialog.askinteger("Input", "Enter an integer")
    print(num)

def pick_color():
    color = colorchooser.askcolor()
    print(color)

def open_file():
    file = filedialog.askopenfile()
    print(file)

# Add buttons and mainloop here
root.mainloop()

Ttk Widgets

The ttk module provides themed versions of Tk widgets with modern look-and-feel, and new widgets such as:

  • Notebook (tabbed interface)
  • ProgressBar
  • Separator
  • Treeview
  • Combobox
  • Sizegrip

To use ttk, import as:

from tkinter import *
from tkinter import ttk

Example: ttk Combobox

from tkinter import *
from tkinter import ttk

root = Tk()
langs = ["C", "C++", "Java", "Python", "PHP"]

combo = ttk.Combobox(root, values=langs)
combo.set("Pick an Option")
combo.pack()

root.mainloop()

Example: ttk ProgressBar

import tkinter as tk
from tkinter import ttk

root = tk.Tk()

def increment():
    progress.step(20)

def decrement():
    progress.step(-20)

def show_value():
    print(progress["value"])

progress = ttk.Progressbar(root, mode='determinate')
progress.pack(padx=10, pady=10)

tk.Button(root, text="Increase", command=increment).pack(side=tk.LEFT)
tk.Button(root, text="Decrease", command=decrement).pack(side=tk.LEFT)
tk.Button(root, text="Show", command=show_value).pack(side=tk.LEFT)

root.mainloop()

Example: ttk Notebook (Tabbed Interface)

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
notebook = ttk.Notebook(root)

frame1 = ttk.Frame(notebook)
ttk.Label(frame1, text="Page 1").pack(padx=20, pady=20)
frame2 = ttk.Frame(notebook)
ttk.Label(frame2, text="Page 2").pack(padx=20, pady=20)

notebook.add(frame1, text="Tab 1")
notebook.add(frame2, text="Tab 2")
notebook.pack(expand=True, fill="both")

root.mainloop()

Example: ttk Treeview

import tkinter as tk
from tkinter import ttk

data = [
    ("Bobby", 26, 20000),
    ("Harish", 31, 23000),
    ("Jaya", 18, 19000),
    ("Mark", 22, 20500)
]

root = tk.Tk()
columns = ("age", "salary")
tree = ttk.Treeview(root, columns=columns, show="headings")

tree.heading("age", text="Age")
tree.heading("salary", text="Salary")

for person in data:
    tree.insert("", tk.END, values=person)

tree.pack()
root.mainloop()

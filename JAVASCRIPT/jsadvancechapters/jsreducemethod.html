JavaScript - Reduce Method

What is Reduce Method?

In JavaScript, the reduce() method is used to manipulate arrays. It executes a reducer function on each element of the array (from left to right) and returns a single value as a result.

It accepts an optional parameter named initialValue. If not provided, the first array element (arr[0]) is used as the initial value. The method does not execute the reducer on empty array elements and does not modify the original array.

Note: If the array is empty and no initialValue is provided, this method throws a TypeError.

Syntax

array.reduce(callbackFn(accumulator, currentValue, currentIndex, array), initialValue)

Parameters

  • initialValue (optional): Value used as the first accumulator when the function is first called.
  • callbackFn: Function that runs for each element in the array.

The callbackFn itself takes four arguments:

  • accumulator: Stores the accumulated result of previous operations.
  • currentValue: The current element being processed.
  • currentIndex (optional): Index of the current element.
  • array (optional): The array on which reduce was called.

Return Value

The reduce() method returns a single value, which is the accumulated result after processing the entire array.

Example 1: Sum of Array Elements

<script>
const numbers = [10, 20, 30, 40, 50];
const sum = numbers.reduce((accumulator, currentValue) => accumulator + currentValue, 0);
document.write(sum);
</script>

Output: 150

Example 2: Empty Array Without Initial Value

<script>
const numbers = [];
try {
   numbers.reduce((accumulator, currentValue) => accumulator * currentValue);
} catch (error) {
   document.write(error);
}
</script>

Output: TypeError: Reduce of empty array with no initial value

Reduce Method on TypedArray

reduce() can also be used with TypedArrays in the same way as with normal arrays. 

<script>
// function
function multi(accumulator, currentValue) {
   return accumulator * currentValue;
}

const T_array = new Uint16Array([1, 2, 3, 4, 5]);
document.write("Typed array: ", T_array);
document.write("<br>The product: ", T_array.reduce(multi));
</script>

Output:
Typed array: 1,2,3,4,5
The product: 120

Example: Empty TypedArray

<script>
const T2_array = new Uint16Array([]);
document.write("Length: ", T2_array.length);

try {
   T2_array.reduce((a, b) => a + b);
} catch (error) {
   document.write("<br>", error);
}
</script>

Output:
Length: 0
TypeError: Reduce of empty array with no initial value

Reduce Method on Map

We can apply reduce() on Map values by spreading them into an array using [...map.values()]. 

<script>
// function
function add(accumulator, currentValue) {
   return accumulator + currentValue;
}

const map = new Map([[1, 2], [3, 4], [5, 6]]);
document.write("Map: ", map);
document.write("<br>The sum: ", [...map.values()].reduce(add));
</script>

Output:
Map: 1 => 2, 3 => 4, 5 => 6
The sum: 12

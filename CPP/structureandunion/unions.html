C++ Unions (union) 🎁

A C++ **union** is a user-defined data type that allows **multiple members** (variables) of different types to share the **same memory location**. This is a memory-saving technique, but with a critical constraint:

  • A union can hold a valid value for **only one** of its members at any given time.
  • Assigning a value to one member **overwrites** the value previously held by any other member, as they all share the same storage.
  • The **size of the union** is determined by the size of its **largest member**.

Union Declaration and Size

union Data {
  int intValue;      // e.g., 4 bytes
  float floatValue;  // e.g., 4 bytes
  char strValue[50]; // e.g., 50 bytes (Largest member)
};

In this example, the size of the Data union would be 50 bytes (or slightly more due to padding), regardless of which member you are currently using.

Accessing Union Members and Undefined Behavior

Union members are accessed using the **dot operator** (`.`).

The main risk with unions is reading from a member that was not the last one written to. This results in **undefined behavior**, as demonstrated in the provided example:

Data data;

data.intValue = 2006;       // intValue is valid (2006)

data.floatValue = 5.75f;    // Overwrites intValue's memory. floatValue is valid (5.75).

// Undefined Behavior: Reading intValue when memory holds a float's bit pattern
cout << data.intValue;

The program will simply output the raw memory bits interpreted as an integer, which is rarely the intended value.

Anonymous Unions and Union-like Classes

Anonymous Unions

An anonymous union is declared without a name. Its members are treated as if they are direct members of the scope in which the union is declared, simplifying access by removing the need for the union variable name.

// Anonymous union declared in main()
union {
  int intValue;
  float floatValue;
};

// Direct access to members without a variable name
intValue = 10;

Union-like Classes (The Need for Type Safety)

In modern C++, raw unions are often wrapped in classes (sometimes called "union-like classes") to add **type safety**. This involves using an additional member (often an `enum`) to explicitly track which union member is currently active, preventing accidental reads that cause undefined behavior.

This concept has led to the development of the standard library type **std::variant** (C++17), which provides a type-safe modern alternative to raw unions.

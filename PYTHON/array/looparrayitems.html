Loop Arrays in Python

Loops allow repeated execution of code blocks. Python provides for and while loops that can iterate over array elements since arrays behave like sequences. Looping enables operations like accessing, modifying, searching, or aggregating array elements.

Python For Loop with Array

The for loop executes when the number of iterations is known. It iterates over each element in the array.

import array as arr
newArray = arr.array('i', [56, 42, 23, 85, 45])
for iterate in newArray:
    print(iterate)
# Output:
# 56
# 42
# 23
# 85
# 45

Python While Loop with Array

A while loop continues based on a condition. When looping an array, an index variable is managed manually.

import array as arr
a = arr.array('i', [96, 26, 56, 76, 46])
l = len(a)
idx = 0
while idx < l:
    print(a[idx])
    idx += 1
# Output:
# 96
# 26
# 56
# 76
# 46

Python For Loop with Array Index

You can use the array length and range() to loop through indices.

import array as arr
a = arr.array('d', [56, 42, 23, 85, 45])
l = len(a)
for x in range(l):
    print(a[x])
# Output:
# 56.0
# 42.0
# 23.0
# 85.0
# 45.0

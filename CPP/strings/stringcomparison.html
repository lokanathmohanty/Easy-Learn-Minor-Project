C++ String Comparison: C-Style vs. std::string 🟰🆚

C++ string comparison is the process of evaluating two strings to determine their **equality** or their **lexicographical order**. By default, all comparisons in C++ are **case-sensitive**, meaning the ASCII values of the characters (e.g., 'A' vs. 'a') determine the result.

I. Comparing C-Style Strings (char[])

C-style strings, which are null-terminated character arrays, **cannot** be compared directly using standard operators (like `==` or `<`). You must use functions from the <cstring> library.

1. strcmp(str1, str2)

This is the primary function for comparing two C-style strings lexicographically (based on ASCII values).

  • Returns **0** if strings are equal.
  • Returns a **negative value** if `str1` is lexicographically less than `str2`.
  • Returns a **positive value** if `str1` is lexicographically greater than `str2`.

Lexicographical Order Example: In `strcmp("hello", "Tutorialspoint")`, the comparison is: 'h' (ASCII 104) vs. 'T' (ASCII 84). Since $104 > 84$, the result is a positive number, indicating "hello" is greater.

2. strcoll(str1, str2)

Compares two C-style strings based on the **current locale** settings, which is essential for proper sorting and internationalization (handling language-specific character ordering rules).

II. Comparing std::string Objects (Modern C++)

std::string objects can be compared using two convenient methods.

1. Comparison Operators (`==`, `!=`, `<`, `>`, etc.)

The standard C++ comparison operators are overloaded for std::string, allowing for direct, readable comparison that works lexicographically.

std::string str1 = "Allen";
std::string str2 = "allen";

// Result: 0 (false) because 'A' (65) != 'a' (97)
str1 == str2

// Result: 1 (true) because 'A' (65) < 'a' (97)
str1 < str2

2. std::string::compare() Method

This member function performs a lexicographical comparison and is similar to `strcmp()` but designed for std::string. It is often preferred when comparing a substring or a segment of a string.

  • Returns **0** if the strings are equal.
  • Returns a **positive value** if the calling string is greater.
  • Returns a **negative value** if the calling string is lesser.
std::string str1 = "apple";
std::string str2 = "banana";

// Result: negative (e.g., -1) because 'a' < 'b'
str1.compare(str2) 

// Result: 0
str1.compare("apple")

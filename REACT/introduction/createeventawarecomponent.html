ReactJS - Create an Event-Aware Component

Event management is one of the important features in a web application. It enables the user to interact with the application. React supports all events available in a web application. React event handling is very similar to DOM events with little changes. For example, clicking on a component is one of the common events observed in React-based websites.

An event-aware component in React is a component that contains an event handler method within it. The component can either be a class component or a functional component.

How to create an Event-Aware Component?

Let us create a new component, MessageWithEvent, and handle events in the component to understand event management in React.

  • Step 1 − Open the expense-manager application and create a file MessageWithEvent.js inside src/components.
  • Step 2 − Create a class MessageWithEvent with a constructor.
  • Step 3 − Define an event handler method logEventToConsole to log event details.
  • Step 4 − Implement render() to return a greeting message.
  • Step 5 − Attach logEventToConsole as a click event handler.
  • Step 6 − Bind the event handler inside the constructor.

Complete Code: MessageWithEvent Component

The complete code of the MessageWithEvent component is shown below:

import React from 'react';

class MessageWithEvent extends React.Component {
  constructor(props) {
    super(props);
    this.logEventToConsole = this.logEventToConsole.bind();
  }

  logEventToConsole(e) {
    console.log(e.target.innerHTML);
  }

  render() {
    return (
      <div onClick={this.logEventToConsole}>
        <p>Hello {this.props.name}!</p>
      </div>
    );
  }
}
export default MessageWithEvent;

Using the Component

Update index.js to use the MessageWithEvent component:

import React from 'react';
import ReactDOM from 'react-dom';
import MessageWithEvent from './components/MessageWithEvent';

ReactDOM.render(
  <React.StrictMode>
    <div>
      <MessageWithEvent name="React" />
      <MessageWithEvent name="React developer" />
    </div>
  </React.StrictMode>,
  document.getElementById('root')
);

Run npm start and open http://localhost:3000. Clicking the component will log messages to the console.

Passing Extra Information to Event Handler

We can pass additional information (for example, msgid) to the event handler.

  • Step 1 − Update the event handler to accept msgid.
  • Step 2 − Bind msgid in the render() method.

class MessageWithEvent extends React.Component {
  constructor(props) {
    super(props);
    this.logEventToConsole = this.logEventToConsole.bind();
  }

  logEventToConsole(msgid, e) {
    console.log(e.target.innerHTML);
    console.log(msgid);
  }

  render() {
    return (
      <div onClick={this.logEventToConsole.bind(this, Math.floor(Math.random() * 10))}>
        <p>Hello {this.props.name}!</p>
      </div>
    );
  }
}
export default MessageWithEvent;

Now, when you click on the component, it will log both the message text and the msgid to the console.

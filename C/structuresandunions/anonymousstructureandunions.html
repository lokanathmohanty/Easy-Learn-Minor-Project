Anonymous Structures and Unions in C

Overview

Anonymous structures and unions, introduced in C11, allow defining struct or union members without a name. Their members can be accessed directly from the parent structure, improving code readability and flexibility.

Anonymous Structure Syntax

An anonymous struct is defined within another struct without a tag or variable name:


struct employee {
  char name[10];
  float salary;
  struct {
    int d, m, y;
  };
};

Accessing Members

Members of the anonymous struct can be accessed directly as if they belong to the parent struct: 


e1.d = 12;
e1.m = 5;
e1.y = 1990;

Anonymous Union Syntax

Anonymous unions work similarly; members share the same memory location and can be accessed directly: 


struct mystruct {
  int var;
  union {
    int var1;
    float var2;
    char var3;
  };
};

Advantages

  • Direct access without naming inner struct/union improves readability.
  • Memory-efficient for unions, as members share storage.
  • Useful for complex data structures and hardware register mappings.

Compatibility Note

Anonymous structs and unions require a C11 compliant compiler. Use cautiously if backward compatibility is needed.

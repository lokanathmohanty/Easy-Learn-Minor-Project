ReactJS - Props Validation

Debugging is one of the most time-consuming tasks in development. In React, props are widely used, and they can originate from different sources: static values, or dynamic values passed from parent components.

A common source of bugs is when the type of the prop does not match what the developer expected. React provides a solution through PropTypes, which helps validate props and catch issues early during development.

What are PropTypes?

The prop-types package allows you to specify expected types for props. For example: 

Sum.propTypes = {
   num1: PropTypes.number,
   num2: PropTypes.number
}

If the props passed do not match these types, React will throw a warning (in development mode only).

Setup

  • Create a new React app: create-react-app myapp
  • Start the app: npm start
  • Install prop-types: npm i prop-types --save

Example Component with PropTypes

// Sum.js
import React from 'react'
import PropTypes from 'prop-types'

class Sum extends React.Component {
   render() {
      return <p>The sum of {this.props.num1} and {this.props.num2}
      is {parseInt(this.props.num1) + parseInt(this.props.num2)}</p>
   }
}

Sum.propTypes = {
   num1: PropTypes.number,
   num2: PropTypes.number
}

export default Sum

Using the Component

// App.js
import './App.css'
import Sum from './Components/Sum'

function App() {
   return (
      <div className="container">
         <div style={{ padding: "10px" }}>
            <Sum num1="10" num2="John" />
         </div>
      </div>
   );
}
export default App

When running this, the console will show warnings because "10" is a string and "John" is not a number.

Available Validators

  • PropTypes.array
  • PropTypes.bigint
  • PropTypes.bool
  • PropTypes.func
  • PropTypes.number
  • PropTypes.object
  • PropTypes.string
  • PropTypes.symbol
  • PropTypes.node – anything that can be rendered
  • PropTypes.element – React element
  • PropTypes.elementType – type of React component
  • PropTypes.instanceOf(Class)
  • PropTypes.oneOf(['A', 'B'])
  • PropTypes.oneOfType([PropTypes.number, PropTypes.string])
  • PropTypes.arrayOf(PropTypes.number)
  • PropTypes.objectOf(PropTypes.string)
  • PropTypes.func.isRequired
  • PropTypes.any.isRequired

Custom Validator

You can also write your own validator. For example, checking if a prop is a valid email: 

Sum.propTypes = {
   num1: PropTypes.number,
   num2: PropTypes.number,
   email: function(myProps, myPropName, myComponentName) {
      if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(myProps[myPropName])) {
         return new Error(
            'Invalid prop `' + myProps[myPropName] + '` supplied to ' +
            myComponentName + '/' + myPropName + '. Validation failed.'
         );
      }
   }
}

Function parameters in custom validators:

  • myProps – all props
  • myPropName – current property being validated
  • myComponentName – component name

Similarly, custom validators can be created for arrayOf and objectOf.

Summary

PropTypes is a useful tool for developers to catch bugs early, enforce correct data types, and build reliable applications. It only runs in development mode, ensuring no performance impact in production.

Java - How to Use Comparable?

The Comparable interface allows Java Collections to sort custom objects. By implementing this interface, objects can define their natural ordering through the compareTo() method.

This is useful when you want custom objects to be sorted just like strings or wrapper classes using collection utility methods such as Collections.sort().

Comparable Interface Methods

  • int compareTo(Object obj) – Compares the current object with the specified object. Returns:
    • 0 if equal
    • Positive value if current object is greater
    • Negative value if current object is lesser
  • boolean equals(Object obj) – Tests equality between two comparator objects. Overriding this is optional.

Examples of Using Comparable

Example 1: Sort Custom Objects by Name

class Dog implements Comparable<Dog> {
  private String name;
  private int age;

  Dog(String n, int a) {
    name = n;
    age = a;
  }

  public int compareTo(Dog d) {
    return this.name.compareTo(d.name);
  }

  public String toString() {
    return this.name + "," + this.age;
  }
}

Output:

Sorted by name:
[Lacy,2, Roger,10, Shaggy,3, Tammy,1, Tommy,4]

Example 2: Sort in Reverse Order Using Collections.reverseOrder()

Collections.sort(list, Collections.reverseOrder());

Output:

Sorted by name in reverse order:
[Tommy,4, Tammy,1, Shaggy,3, Roger,10, Lacy,2]

Example 3: Sort by Age

public int compareTo(Dog d) {
  return this.age - d.age;
}

Output:

Sorted by age:
[Tammy,1, Lacy,2, Shaggy,3, Tommy,4, Roger,10]

Applications of Pointers in C

One of the most important features of C is that it provides low-level memory access with the concept of pointers. A pointer is a variable that stores the address of another variable in the memory.

The provision of pointers has many applications such as passing arrays and struct types to functions, dynamic memory allocation, etc. In this chapter, we will explain some important applications of pointers in C.

To Access Array Elements

Array elements can be accessed through pointers by declaring and initializing a pointer to an array. Incrementing the pointer moves it to the next element.

#include <stdio.h>

int main() {
   int arr[] = {1,2,3,4,5};
   int *ptr = arr;

   for(int i = 0; i <= 4; i++){
      printf("arr[%d]: %d\n", i, *ptr);
      ptr++;
   }
   
   return 0;
}

Output:

arr[0]: 1
arr[1]: 2
arr[2]: 3
arr[3]: 4
arr[4]: 5

For Allocating Memory Dynamically

Pointers play a key role in dynamic memory allocation. Functions like malloc(), calloc(), and realloc() are used to allocate and manage memory during runtime.

1. The malloc() Function

malloc() allocates a block of memory of the specified size (in bytes) and returns a void pointer. Example:

int *ptr;
ptr = (int *) malloc(sizeof(int));

Example of allocating memory for a string:

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main() {
   char *name;
   name = (char *) malloc(strlen("TutorialsPoint") + 1);

   if(name == NULL) {
      fprintf(stderr, "Error - unable to allocate required memory\n");
   } else {
      strcpy(name, "TutorialsPoint");
      printf("Name = %s\n", name);
   }
   free(name);
}

Output:

Name = TutorialsPoint

2. The calloc() Function

calloc() allocates memory for an array of elements and initializes all bytes to zero.

int *ptr;
ptr = (int *) calloc(25, sizeof(int));

3. The realloc() Function

realloc() changes the size of a previously allocated memory block.

ptr = (int *) realloc(ptr, new_size);

For Passing Arguments as Reference

Passing pointers to functions allows functions to modify variables in the caller’s scope and to return multiple values indirectly.

Example: Swap Two Variables

int swap(int *x, int *y) {
   int z = *x;
   *x = *y;
   *y = z;
   return 0;
}

#include <stdio.h>

int swap(int *x, int *y);

int main() {
   int a = 10, b = 20;
   printf("Before swap, a = %d, b = %d\n", a, b);
   swap(&a, &b);
   printf("After swap, a = %d, b = %d\n", a, b);
   return 0;
}

Output:

Before swap, a = 10, b = 20
After swap, a = 20, b = 10

For Passing an Array to Function

Arrays are passed by reference by passing the pointer to the first element. The function can then access and manipulate the array elements.

#include <stdio.h>

int max(int *arr, int length);

int main() {
   int arr[] = {10, 34, 21, 78, 5};
   int length = sizeof(arr)/sizeof(arr[0]);
   int maxnum = max(arr, length);
   printf("max: %d\n", maxnum);
   return 0;
}

int max(int *arr, int length) {
   int max = *arr;
   for(int i = 0; i < length; i++) {
      printf("arr[%d]: %d\n", i, *arr);
      if(*arr > max)
         max = *arr;
      arr++;
   }
   return max;
}

Output:

arr[0]: 10
arr[1]: 34
arr[2]: 21
arr[3]: 78
arr[4]: 5
max: 78

For Returning Multiple Values from a Function

Since functions can only return one value, pointers allow returning multiple values by modifying variables through their addresses.

#include <stdio.h>

void funAddSub(int a, int b, int* add, int* sub) {
  *add = a + b;
  *sub = a - b;
}

int main() {
  int num1 = 10, num2 = 3;
  int res1, res2;

  funAddSub(num1, num2, &res1, &res2);
  printf("Addition is %d and subtraction is %d\n", res1, res2);

  return 0;
}

Output:

Addition is 13 and subtraction is 7

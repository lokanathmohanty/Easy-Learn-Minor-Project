JavaScript - tRPC Library

tRPC is a type-safe TypeScript module that uses the RPC (Remote Procedure Call) API design to process API requests and return results. Unlike REST APIs, tRPC has no request types such as GET or POST. Instead, every request passes through a query system that returns responses based on input and query.

What is tRPC?

tRPC adds a type-safe layer to the RPC architectural framework. While RESTful APIs rely on request types, tRPC simplifies the process by using built-in functions and react-query for handling requests. With tRPC:

  • No need for a dedicated /API folder with multiple routes.
  • Requests are described using URLs to represent queries.
  • Type safety ensures only valid data is sent between client and server.

Need of tRPC

The main benefit of tRPC is type safety. This ensures:

  • Clients cannot send invalid data to the server.
  • Errors such as assigning strings to number properties are immediately caught.
  • Both IDEs and browsers alert developers about type mismatches.

tRPC uses Zod to construct data schemas. For example, if an API route requires user information, you can define an object with Zod on the server side, and tRPC will ensure the client sends data in the correct format.

Usage of tRPC

It only takes a few seconds to launch an Express server and start creating tRPC routes and queries. Typically, the client-side (React) and server-side (Express) remain separate, connected via CORS.

Folder Structure

Start by creating a directory named tRPC-Demo. Inside, create a folder trpclibrary to hold both the server and client projects: 


tRPC-Demo
 └── trpclibrary
      ├── client-side (React App Folder)
      ├── server-side (Express Server Folder)
 package.json

Root package.json

Add a package.json file in the root directory: 


{
  "name": "trpclibrary",
  "version": "1.0.0",
  "main": "index.js",
  "license": "MIT",
  "private": true,
  "scripts": {
    "start": "concurrently \"wsrun --parallel start\""
  },
  "workspaces": [
    "trpclibrary/*"
  ],
  "devDependencies": {
    "concurrently": "^5.2.0",
    "wsrun": "^5.2.0"
  }
}

Setting up the Server

Navigate into the trpclibrary folder and create the server with: 


npx create-mf-app
? Pick the name of your app: server-side
? Project Type: API Server
? Port number: 3005
? Template: express

Install dependencies and start the server: 


cd server-side
npm install
npm start

Setting up the Client

Next, create the client-side project: 


npx create-mf-app
? Pick the name of your app: client-side
? Project Type: Application
? Port number: 3000
? Framework: react
? Language: typescript
? CSS: Tailwind
? Bundler: Webpack

Install dependencies and start the client: 


cd client-side
npm install
npm start

Configuring TypeScript

In both the server and client directories, initialize TypeScript configuration: 


npx tsc --init

Installing Required Libraries

On the server side, install tRPC, CORS, and Zod: 


yarn add @trpc/server zod cors

On the client side, install: 


yarn add @trpc/client @trpc/react-query @tanstack/react-query zod

Summary

tRPC simplifies API development by removing the need for traditional REST routes while ensuring type safety using TypeScript and Zod. It enables seamless integration between client and server, making development faster and less error-prone.

R Programming Cheat Sheet

1. Basics

  • Assignment: x <- 10 or x = 10
  • Comment: # This is a comment
  • Print: print(x)
  • Help: ?mean or help(mean)

2. Data Types

  • numeric: x <- 3.14
  • integer: x <- 2L
  • character: x <- "hello"
  • logical: x <- TRUE
  • complex: x <- 1+2i

3. Data Structures

  • Vector: c(1, 2, 3)
  • Matrix: matrix(1:6, nrow=2)
  • List: list(name="Tom", age=25)
  • Data Frame: data.frame(a=1:3, b=c("x", "y", "z"))
  • Factor: factor(c("high", "low", "medium"))

4. Control Structures

  • if (x > 0) {...}
  • for (i in 1:5) {...}
  • while (x < 10) {...}
  • repeat {...; if (x > 10) break}

5. Functions

add <- function(a, b) {
  return(a + b)
}

6. File I/O

  • Read CSV: read.csv("file.csv")
  • Write CSV: write.csv(data, "file.csv")

7. Packages

  • Install: install.packages("ggplot2")
  • Load: library(ggplot2)

8. Useful Functions

  • mean(x), median(x), sd(x)
  • summary(data), str(data)
  • length(x), class(x), typeof(x)

9. Data Manipulation

  • subset(data, condition)
  • merge(df1, df2)
  • rbind(df1, df2), cbind(df1, df2)
  • apply(m, 1, sum)

10. Plotting

  • plot(x, y)
  • hist(x)
  • boxplot(x)
  • barplot(x)

11. Logical Operations

  • &, |, !, ==, !=, <, >
  • any(x > 5), all(x > 0)

12. Environment

  • getwd(), setwd("path")
  • ls(), rm(x)
  • save(x, file="x.RData"), load("x.RData")

13. Random Numbers

  • runif(n): Uniform distribution
  • rnorm(n): Normal distribution
  • sample(x, size): Random sampling

14. Data Cleaning

  • na.omit(x)
  • is.na(x), anyNA(x)
  • replace(x, is.na(x), value)

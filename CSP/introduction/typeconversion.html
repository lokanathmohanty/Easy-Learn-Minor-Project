C# Type Conversion (Type Casting)

Forms of Type Conversion

Type conversion, or **Type Casting**, is the process of converting data from one type to another. In C#, this process occurs in two primary forms:

1. Implicit Type Conversion (Automatic)

These conversions are performed automatically by the C# compiler because they are **type-safe** and there is **no risk of data loss**. This usually happens when converting from a **smaller-sized type to a larger-sized type** (e.g., int to double, or a derived class to a base class).

2. Explicit Type Conversion (Manual)

These conversions must be done explicitly by the user using a **cast operator** (e.g., (int)). This is required when converting between types where there is a **risk of data loss** or incompatibility (e.g., double to int).

Conversion Methods (Example)

C# provides dedicated methods for robust explicit conversion, especially when dealing with strings and user input.

Using the Cast Operator (Explicit)

double d = 5673.74; 
int i;

// Cast operator: (int)
i = (int)d; // Result: 5673 (decimal part truncated)

Using the Convert Class

The Convert class provides methods like Convert.ToInt32() for explicit, defined conversions.

string str = "123";
int num = Convert.ToInt32(str); // Result: 123

Using Parse() and TryParse()

  • Parse(): Converts a string representation of a number to its respective type (e.g., int.Parse(str)). Throws an exception if the string is invalid.
  • TryParse(): The **safest** way to convert a string. It returns a **boolean** (success/failure) and uses an **out** parameter to store the result, thus avoiding exceptions for invalid input.
// TryParse() example
string str = "789";
if (int.TryParse(str, out int result)) 
{
    // Conversion succeeded
}

Built-in Conversion Methods

The Convert class provides numerous methods, usually named To[TypeName], to handle various conversions:

  • ToBoolean: Converts a type to a boolean value.
  • ToByte, ToInt16, ToInt32, ToInt64: Convert a type to a specific integer size.
  • ToDecimal, ToDouble, ToSingle: Convert to different floating-point types.
  • ToString: Converts any type to its string representation (e.g., i.ToString()).
  • ToDateTime: Converts appropriate types to date-time structures.

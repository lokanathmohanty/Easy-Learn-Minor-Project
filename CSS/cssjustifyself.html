CSS justify-self Property

The CSS justify-self property defines how a grid item is aligned within its grid cell along the inline (row) axis. This property only applies to elements that are direct children of a grid container. It overrides the justify-items value set on the container for that specific item.

It is very useful when you want to control the alignment of an individual grid item without changing the alignment of all other items inside the container.

Syntax

The basic syntax of the property is:

  • justify-self: auto | normal | stretch | start | end | left | right | center | baseline | initial | inherit;

Property Values

  • auto: Inherits the grid container’s justify-items value. This is the default.
  • normal: Depends on the layout mode. In a grid layout, it behaves like stretch.
  • stretch: The grid item expands to fill the grid cell, if no width is set.
  • start: Aligns the item to the start edge of the grid cell (left in LTR languages).
  • end: Aligns the item to the end edge of the grid cell (right in LTR languages).
  • left: Aligns the item explicitly to the left edge.
  • right: Aligns the item explicitly to the right edge.
  • center: Centers the item horizontally inside the grid cell.
  • baseline: Aligns the item to the baseline of the grid cell’s row.
  • initial: Resets the property to its default value.
  • inherit: Inherits the value from the parent element.

Examples

Below are some examples showing different uses of the justify-self property. In these examples, we imagine a grid container with three columns and three items, where the alignment of the second item is controlled using different values.

Example 1: justify-self with auto

The item will follow the container’s justify-items value. 

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  justify-items: stretch;
}
.item {
  justify-self: auto;
}

Example 2: justify-self with center

The grid item is placed at the center of its grid cell. 

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}
.item {
  justify-self: center;
}

Example 3: justify-self with start and end

This aligns the grid item to the start or end of the grid cell, depending on writing direction. 

.item-start {
  justify-self: start;
}
.item-end {
  justify-self: end;
}

Example 4: justify-self with stretch

The grid item will expand to fill the width of its grid cell. 

.item {
  justify-self: stretch;
}

Supported Browsers

The justify-self property is widely supported in modern browsers. Below is a compatibility table:

  • Chrome: 57+
  • Edge: 16+
  • Firefox: 45+
  • Safari: 10.1+
  • Opera: 44+

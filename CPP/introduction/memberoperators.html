C++ Member Access Operators (Dot . & Arrow ->)

The **dot (.)** and **arrow (->)** operators are used to **reference individual members** (variables or functions) within classes, structures, and unions. They are essential for accessing the data and behavior encapsulated by these user-defined types.

1. The Dot Operator (.)

The dot operator is used when accessing a member directly through the **object (or instance) name** itself. It operates on the actual object stored in memory.

Syntax

object.member_name

Example

If you have an Employee variable named emp, you use the dot operator to access its members:

struct Employee { char first_name[20]; };
Employee emp;

// Accessing the member via the object name
strcpy(emp.first_name, "zara");

2. The Arrow Operator (->)

The arrow operator is used when accessing a member through a **pointer to an object**. It automatically dereferences the pointer and then accesses the member.

Syntax

pointer_to_object->member_name

Equivalence

The expression p_emp->first_name is functionally equivalent to using the dot operator combined with the dereference operator (*):

(*p_emp).first_name

The arrow operator is a shorthand convenience that simplifies code when dealing with pointers.

Example

If p_emp is a pointer pointing to the emp object:

Employee emp;
Employee* p_emp = &emp; // p_emp holds the address of emp

// Accessing the member via the pointer
strcpy(p_emp->first_name, "zara");

.NET Core - Creating a .NET Standard Library

A class library provides reusable types and methods that can be called from different applications. By developing a class library using **.NET Core**, it targets the **.NET Standard Library**. This allows the library to be consumed by any .NET platform (like .NET Framework, .NET Core, or Xamarin) that supports that specific version of .NET Standard.

Adding the Class Library Project

To begin, we will add a new class library project to our existing solution:

  1. In Solution Explorer, right-click on the src folder (or the solution node) and select Add → New Project.
  2. In the Add New Project dialog, choose the .NET Core node.
  3. Select the **Class Library (.NET Core)** project template.
  4. Enter the name "UtilityLibrary" for the project and click OK.

Once the project is created, we will add a new class to house our utility methods.

  1. Right-click on the new UtilityLibrary project in Solution Explorer and select Add → Class...
  2. Name the class file StringLib.cs and click Add.

Implementing the String Library Class (StringLib.cs)

Replace the content of the newly created StringLib.cs file with the following code. This static class contains extension methods for the String type to check the case or numeric value of the first character.

using System; 
using System.Collections.Generic; 
using System.Linq; 
using System.Threading.Tasks; 
  
namespace UtilityLibrary { 
   public static class StringLib { 
      // Checks if the string starts with an uppercase letter
      public static bool StartsWithUpper(this String str) { 
         if (String.IsNullOrWhiteSpace(str)) 
            return false; 
         Char ch = str[0]; 
         return Char.IsUpper(ch); 
      } 
      
      // Checks if the string starts with a lowercase letter
      public static bool StartsWithLower(this String str) { 
         if (String.IsNullOrWhiteSpace(str)) 
            return false; 
         Char ch = str[0]; 
         return Char.IsLower(ch); 
      } 
      
      // Checks if the string starts with a number
      public static bool StartsWithNumber(this String str) { 
         if (String.IsNullOrWhiteSpace(str)) 
            return false;  
         Char ch = str[0]; 
         return Char.IsNumber(ch); 
      } 
   } 
}

After saving the file, choose **Build → Build Solution** from the menu bar to ensure the new class library compiles successfully.

Consuming the Library (Adding Reference)

To use the StringLib extension methods in our existing console application (FirstApp), we must add a project reference:

  1. Expand the **FirstApp** project in Solution Explorer.
  2. Right-click on **References** and select **Add Reference**.
  3. In the Reference Manager dialog box, find and select the **UtilityLibrary** project.
  4. Click **OK**.

The console project now has access to the public types and methods defined in the UtilityLibrary.

Using the Extension Methods in FirstApp (Program.cs)

Open the Program.cs file in the FirstApp project and replace the existing code with the following implementation, which uses the StartsWithUpper extension method:

using System; 
using System.Collections.Generic; 
using System.Linq; 
using System.Threading.Tasks; 
using UtilityLibrary; 

namespace FirstApp { 
   public class Program { 
      public static void Main(string[] args) { 
         int rows = Console.WindowHeight; 
         Console.Clear(); 
         
         do { 
            if (Console.CursorTop >= rows || Console.CursorTop == 0) { 
               Console.Clear(); 
               Console.WriteLine("\nPress <Enter> only to exit; otherwise, enter a string and press <Enter>:\n"); 
            } 
            
            string input = Console.ReadLine(); 
            
            if (String.IsNullOrEmpty(input)) break; 
            
            Console.WriteLine("Input: {0} {1,30}: {2}\n", input, "Begins with uppercase? ", 
            input.StartsWithUpper() ? "Yes" : "No"); 
            
         } while (true); 
      } 
   } 
}

Run the application. When you type a string and press Enter, the console output will indicate whether the input string begins with an uppercase character by calling the extension method from your newly created UtilityLibrary.

You can further enhance this console application by using the other extension methods (`StartsWithLower` and `StartsWithNumber`) in a similar fashion.

C# Miscellaneous Operators

Overview of Special Operators

Miscellaneous Operators are specialized operators that do not fit into the standard arithmetic, relational, or logical categories. They perform functions related to **type handling**, **null checking**, and **memory information**.

Key Operator Groups:

  • Conditional: ?: (Ternary)
  • Null Handling: ?? (Null-Coalescing), ??= (Null-Coalescing Assignment)
  • Type Checking/Casting: is, as, typeof()
  • Memory/Size: sizeof()

Conditional and Null Handling Operators

Ternary Operator (? :)

This operator is a concise shorthand for a simple if-else statement. It requires three operands: (Condition ? Value if True : Value if False).

int age = 20;
string result = (age >= 18) ? "Adult" : "Minor";

Console.WriteLine(result); // Output: Adult

Null-Coalescing Operator (??)

Returns the left operand if it is **not** null; otherwise, it returns the right operand (the default value).

int? number = null;
int result = number ?? 100; // If number is null, result is 100

Console.WriteLine(result); // Output: 100

Null-Coalescing Assignment (??=)

Assigns a value to the left operand **only if** the left operand is currently null.

string message = null;
message ??= "Default Message"; 

// If message was null, it now holds "Default Message".

Type Checking and Information Operators

Type Checking (is)

The is operator checks if an object is compatible with a given type. It can also be used for **pattern matching** to check and extract a value simultaneously (C# 7.0+).

object obj = 42;

// Check if obj is an int AND assign its value to the new variable 'number'
if (obj is int number) 
{
    Console.WriteLine("obj is an integer: " + number);
}

Safe Type Casting (as)

The as operator attempts to cast an expression to a specified reference type or nullable value type. Unlike a direct cast, it returns **null** on failure instead of throwing an exception, making the code safer.

object obj = "Hello, C#";
string str = obj as string; // str now holds "Hello, C#"

object num = 42;
string badCast = num as string; // badCast now holds null (no exception)

Size and Type Info (sizeof and typeof)

  • sizeof(T): Returns the size in bytes of a value type (e.g., sizeof(int) returns 4). Requires an unsafe context.
  • typeof(T): Returns the **System.Type** object for the specified type.

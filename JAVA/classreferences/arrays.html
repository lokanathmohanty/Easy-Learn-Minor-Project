Java Arrays Class Summary 🛠️

The **java.util.Arrays** class is a static utility class that contains a vast collection of static methods for efficiently **manipulating**, **searching**, **sorting**, and **comparing** both primitive type arrays and object arrays.

I. Core Utility Functions

These methods are the backbone of array management in Java:

  • Sorting (sort() / parallelSort()): Sorts the array into ascending order. parallelSort() uses the Fork/Join framework to leverage multiple processors for large arrays, making it faster than sort() in those scenarios.
  • Searching (binarySearch()): Searches a sorted array for a specified value. **Crucially, the array must be sorted first** for this method to work correctly; otherwise, the result is undefined.
  • Comparison (equals() / compare() / mismatch()):
    • equals(): Checks if two arrays contain the same elements in the same order.
    • deepEquals(): Performs a deep comparison for nested arrays (arrays of arrays).
    • compare(): Compares two arrays lexicographically (like dictionary order).
    • mismatch(): Finds the index of the first differing element between two arrays.
  • Filling (fill()): Assigns a specified value to every element in the array.

II. Copying and Array-to-Collection Conversion

The Arrays class provides methods to create copies and bridge the gap between arrays and the Collections Framework:

  • copyOf() / copyOfRange(): Creates a **new array** by copying all or a portion of the original array. This is the preferred way to resize or safely copy an array.
  • <T> List<T> asList(T... a): Returns a **fixed-size List** backed by the specified array.

    Note: Since the returned list is backed by the original array, modifying an element in the list **will modify the array**, and vice-versa. Attempting to add or remove elements (which would change the size) will throw an UnsupportedOperationException.

III. Streaming and Functional Programming

The Arrays class includes methods that integrate arrays with modern Java 8+ features:

  • stream(...): Returns a sequential **Stream** (or specialized primitive streams like IntStream) using the array as its source, enabling functional operations like filtering and mapping.
  • setAll() / parallelSetAll(): Fills all elements of an array using a **generator function** (lambda expression), calculating each element's value based on its index.
  • parallelPrefix(): Applies a given function cumulatively to the elements of the array in parallel.

Next.js - Fast Refresh

Introduction to Fast Refresh

Fast Refresh is a core **React feature** that is integrated into Next.js. Its primary function is to allow developers to see code changes reflected in the application in **real-time** without losing the component's state or forcing a full page reload.

This feature significantly improves the development experience by providing immediate feedback, making it highly valuable for working on applications of any size.

How Fast Refresh Works

Fast Refresh operates based on the type of file that is edited, determining the scope of the update:

  • Editing a React Component File: If a file only exports **React component(s)**, Next.js performs a targeted update, re-rendering only that component while attempting to preserve its local state.
  • Editing a Non-Component File (with React dependents): If you edit a file that contains exports that **aren't React components** (e.g., a theme or utility file), Next.js will re-run the edited file and all other files that import it. This ensures dependent components are updated.
  • Editing a Non-React Dependency: If a file is edited and is imported by code **outside of the React tree** (e.g., a file used by both a React component and a non-React component utility), Fast Refresh falls back to performing a **full application reload**.

Key Features

Fast Refresh provides several key benefits:

  • Real-Time Updates: Changes to components or styles are applied instantly.
  • State Preservation: It retains the internal **component state** across most updates, drastically reducing the need to manually reproduce application state after every code change.
  • Automatic Activation: It is **enabled by default** in development mode in Next.js (version 9 onwards) and requires no extra configuration.

Example of Default Behavior

Since Next.js 9, Fast Refresh is automatically active. If you modify the content of a component file, the changes will appear instantly without a full page refresh.

Example Component (app/page.tsx):

// File: app/page.tsx
export default function Home() {
    return (
        <div>
            <h1>Home Page</h1>
            <p>This is the home page.</p>
        </div>
    );
}

Disable Fast Refresh

While generally beneficial, you can disable Fast Refresh in development mode if necessary by modifying the **next.config.js** file:

// File: next.config.js

module.exports = {
    experimental: {
      reactRefresh: false,
    },
  };

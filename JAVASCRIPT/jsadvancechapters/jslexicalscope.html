JavaScript - Lexical Scope

What is Lexical Scope?

Lexical scope refers to an expression's definition area. In other words, an item's lexical scope is the context in which it was created.

Lexical scope is sometimes known as static scope. It is determined by where the code is written, not by where it is invoked.

Types of Scope

  • Global Scope: Variables defined outside of any function or block are accessible throughout the program.
  • Local Scope: Variables defined within a function or block can only be accessed there.
  • Nested Scope: Inner functions can access variables in their parent functions.
  • Block Scope: Variables defined with let and const are only valid in the block where they are declared.

Example 1: Global Scope


// Define a variable in the global scope
const myName = "Shwetaa";

// Call myName variable from a function
function getName() {
   return myName;
}

Here, myName is defined in the global scope. Its lexical scope is global, even though it is accessed inside a function.

Example 2: Local Scope


function getName() {
   const myName = "Swati";
   return myName;
}

In this case, myName is defined and used inside the function, so its lexical scope is the local environment of getName().

How Does Lexical Scope Work?

The code that can access a JavaScript expression is determined by the environment in which it was defined. Only code within an item's lexical scope can access it.

Example with ReferenceError


// Define a function
function myLastName() {
   const lastName = "Sharma";
   return lastName;
}

// Define another function
function showFullName() {
   const fullName = "Swati " + lastName;
   return fullName;
}

// Invoke showFullName():
console.log(showFullName());

Output:


Uncaught ReferenceError: lastName is not defined

The error occurs because lastName is not in the lexical scope of showFullName().

Example with Proper Scope


function showLastName() {
   const lastName = "Sharma";
   return lastName;
}

// Define another function
function displayFullName() {
   const fullName = "Swati " + showLastName();
   return fullName;
}

// Invoke displayFullName():
console.log(displayFullName());

Output:


Swati Sharma

Because showLastName() and displayFullName() are defined in the same lexical (global) scope, they can work together properly.

Summary

Understanding lexical scope in JavaScript is important for creating clean, maintainable code. By properly scoping variables and functions, you can minimize naming conflicts, improve readability, and prevent errors. Lexical scope ensures more organized and efficient programs.

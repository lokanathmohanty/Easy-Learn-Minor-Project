JavaScript - Browser Object Model

The Browser Object Model (BOM) in JavaScript refers to the objects provided by the browsers to interact with them. By using these objects, you can manipulate the browser's functionality such as history, window size, navigation, and more.

The Browser Object Model is not standardized and may differ across browsers.

Objects of the BOM

  • Window – Represents the current browser window.
  • Document – Represents the current web page (HTML DOM).
  • Screen – Provides information about the user’s screen.
  • History – Accesses browser session history.
  • Navigator – Provides information about the browser.
  • Location – Provides information about the current URL.
  • Console – Provides access to the browser’s debugging console.

JavaScript Window Object

The window object represents the browser's window and is the global object in JavaScript. All global variables and functions are its properties and methods. 

window.document.write("Hello World");
document.write("Hello World"); // without window

Properties such as innerHeight and innerWidth return the browser window dimensions.

JavaScript Document Object

The document object represents the HTML document and forms the root of the DOM. It provides methods to access and manipulate elements. 

<div id="text">This will be changed</div>

const textDiv = document.getElementById("text");
textDiv.innerHTML = "The text of this DIV is changed.";

JavaScript Screen Object

The screen object provides information about the user’s display screen dimensions. 

document.write("Width: " + screen.width);
document.write("Height: " + screen.height);

JavaScript History Object

The history object gives access to the browser’s session history. You can navigate using methods like history.back() and history.forward().

JavaScript Navigator Object

The navigator object provides information about the browser, such as version, language, and whether cookies are enabled.

JavaScript Location Object

The location object provides information about the current page URL and allows redirection. 

document.write("Host: " + location.host);

JavaScript Console Object

The console object allows developers to log debugging messages in the browser console. 

console.log("Hello from console!");

Conclusion

The Browser Object Model (BOM) provides JavaScript with the ability to interact with the browser beyond the web page. Mastering BOM objects like window, document, history, and location is crucial for web development.

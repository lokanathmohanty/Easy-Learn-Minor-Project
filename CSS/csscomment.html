CSS - Comments

In CSS, comments are useful for adding explanatory notes or annotations within your stylesheet. These comments are ignored by the browser when rendering a webpage, but they are extremely valuable for developers when it comes to documentation, debugging, and improving the readability of code.

Syntax

CSS comments are written inside /* */ symbols. Anything between these markers will not be executed by the browser.

Example:

  • /* This is a comment */
  • p { color: red; /* Set text color to red */ }

Why Use Comments?

  • They provide documentation inside stylesheets for future developers.
  • They help in debugging by allowing parts of code to be "disabled".
  • They explain complex styling rules.
  • They improve readability of long CSS files.

Types of CSS Comments

There are generally two ways comments are used in CSS:

1. Single-line Comments

Single-line comments are written between /* and */ on one line.

Example:

  • /* Single line Comment */

2. Multi-line Comments

Multi-line comments span across multiple lines, still enclosed within /* and */.

Example:

  • /* Comment which stretches over multiple lines */

HTML and CSS Comments

In HTML, comments are different. They are defined between <!-- and -->. Whereas in CSS, comments always use /* */.

Syntax:

  • <!-- This is an HTML comment -->
  • /* This is a CSS comment */

Full Example

Here is an example showing both HTML and CSS comments in action:

  • <html>
    <head>
    <style>
    /* Target all div elements */
    div {
    background-color: red; /* Set background color */
    height: 50px; /* Set the height */
    width: 200px; /* Set the width */
    padding: 5px; /* Set the padding */
    border: 5px solid black; /* Set the border */
    }
    </style>
    </head>

    <body>
    <!-- This is an HTML comment format -->
    <div>
    Styles Applied
    </div>
    </body>
    </html>

Practice Task

Try creating your own HTML file with CSS comments. For example:

  • Add a CSS comment above a rule to describe what it does.
  • Use HTML comments to mark sections of your webpage (like header, footer, sidebar).

Real-World Use Case

In large projects, CSS files can be thousands of lines long. Developers often use comments to divide sections like:

  • /* ===== HEADER STYLES ===== */
  • /* ===== FOOTER STYLES ===== */
  • /* ===== GRID SYSTEM ===== */

This helps organize the stylesheet and makes collaboration easier in a team environment.

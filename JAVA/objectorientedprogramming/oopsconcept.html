Java - OOPs (Object-Oriented Programming) Concepts

OOPs (Object-Oriented Programming System)

Object means a real-world entity such as a mobile, book, table, computer, watch, etc. Object-Oriented Programming is a methodology or paradigm to design a program using classes and objects. It simplifies software development and maintenance by providing some concepts.

In this tutorial, we will learn about the concepts of Java (OOPs) object-oriented programming systems.

Java OOPs Concepts

  • Class
  • Object
  • Inheritance
  • Polymorphism
  • Abstraction
  • Encapsulation

Class

In object-oriented programming, a class is a blueprint from which individual objects are created. A class defines attributes and methods that the objects will have.

Example:

public class Student {
   String name;
   int rollNo;
   String section;

   Student(String name, int rollNo, String section){
      this.name = name;
      this.rollNo = rollNo;
      this.section = section;
   }

   public void printDetails() {
      System.out.println("Student Details:");
      System.out.println(this.name + ", " + this.rollNo + ", " + section);
   }
}

Object

An object is an instance of a class and represents an entity with state and behavior.

Example:

public class Student {
   String name;
   int rollNo;
   String section;

   Student(String name, int rollNo, String section){
      this.name = name;
      this.rollNo = rollNo;
      this.section = section;
   }

   public void printDetails() {
      System.out.print("Student Details: ");
      System.out.println(this.name + ", " + this.rollNo + ", " + section);
   }

   public static void main(String[] args) {
      Student student1 = new Student("Robert", 1, "IX Blue");
      Student student2 = new Student("Adam", 2, "IX Red");
      Student student3 = new Student("Julie", 3, "IX Blue");

      student1.printDetails();
      student2.printDetails();
      student3.printDetails();
   }
}

Output:

  • Student Details: Robert, 1, IX Blue
  • Student Details: Adam, 2, IX Red
  • Student Details: Julie, 3, IX Blue

Inheritance

Inheritance is the process of one class acquiring the properties and behaviors of another class. The class being inherited from is called the parent (or base) class, and the class inheriting is the child (or derived) class.

Example:

class Person {
   String name;

   Person(String name){
      this.name = name;
   }
}

public class Student extends Person {
   int rollNo;
   String section;

   Student(String name, int rollNo, String section){
      super(name);
      this.rollNo = rollNo;
      this.section = section;
   }

   public void printDetails() {
      System.out.print("Student Details: ");
      System.out.println(this.name + ", " + this.rollNo + ", " + section);
   }

   public static void main(String[] args) {
      Student student1 = new Student("Robert", 1, "IX Blue");
      Student student2 = new Student("Adam", 2, "IX Red");
      Student student3 = new Student("Julie", 3, "IX Blue");

      student1.printDetails();
      student2.printDetails();
      student3.printDetails();
   }
}

Polymorphism

Polymorphism allows methods to have the same name but different behaviors. It is implemented through method overloading and method overriding.

Example (Method Overloading):

public class Student {
   String name;
   int rollNo;
   String section;

   Student(String name, int rollNo, String section){
      this.name = name;
      this.rollNo = rollNo;
      this.section = section;
   }

   public void printDetails() {
      System.out.print("Student Details: ");
      System.out.println(this.name + ", " + this.rollNo + ", " + section);
   }

   public void printDetails(boolean hideSection) {
      System.out.print("Student Details: ");
      System.out.println(this.name + ", " + this.rollNo + ", " + (hideSection ? "" : section));
   }

   public static void main(String[] args) {
      Student student1 = new Student("Robert", 1, "IX Blue");
      Student student2 = new Student("Adam", 2, "IX Red");
      Student student3 = new Student("Julie", 3, "IX Blue");

      student1.printDetails();
      student2.printDetails(true);
      student3.printDetails(false);
   }
}

Output:

  • Student Details: Robert, 1, IX Blue
  • Student Details: Adam, 2,
  • Student Details: Julie, 3, IX Blue

Abstraction

Abstraction hides the internal implementation and only shows the necessary features. In Java, it's implemented using abstract classes or interfaces.

Example:

abstract class Vehicle {
   public void startEngine() {
      System.out.println("Engine Started");
   }
}

public class Car extends Vehicle {
   private String color;

   public Car(String color) {
      this.color = color;
   }

   public void printDetails() {
      System.out.println("Car color: " + this.color);
   }

   public static void main(String[] args) {
      Car car = new Car("White");
      car.printDetails();
      car.startEngine();
   }
}

Output:

  • Car color: White
  • Engine Started

Encapsulation

Encapsulation is the process of binding data and methods together and restricting direct access to some components. It’s usually implemented by using private fields and public methods.

Example:

public class Student {
   private String name;
   private int rollNo;
   private String section;

   Student(String name, int rollNo, String section){
      this.name = name;
      this.rollNo = rollNo;
      this.section = section;
   }

   public void printDetails() {
      System.out.print("Student Details: ");
      System.out.println(this.name + ", " + this.rollNo + ", " + section);
   }

   public static void main(String[] args) {
      Student student1 = new Student("Robert", 1, "IX Blue");
      Student student2 = new Student("Adam", 2, "IX Red");
      Student student3 = new Student("Julie", 3, "IX Blue");

      student1.printDetails();
      student2.printDetails();
      student3.printDetails();
   }
}

Output:

  • Student Details: Robert, 1, IX Blue
  • Student Details: Adam, 2, IX Red
  • Student Details: Julie, 3, IX Blue

Advantages of Java OOPs

  • OOPs concepts are easier to implement and understand.
  • Faster execution than procedural programming in large systems.
  • Supports code reusability through inheritance.
  • Encapsulation helps to protect sensitive data.

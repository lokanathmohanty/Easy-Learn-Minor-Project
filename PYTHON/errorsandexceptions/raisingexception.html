Python - Raising Exceptions

In Python, you can raise exceptions explicitly using the raise statement. Raising exceptions allows you to indicate that an error has occurred and to control the flow of your program by handling these exceptions appropriately.

Raising an exception means explicitly triggering an error condition in your program. This can be useful when the normal flow of your program cannot continue due to an error or unexpected condition.

Raising Built-in Exceptions

You can raise any built-in exception by creating an instance of the exception class and using the raise statement. The syntax is: 

raise Exception("This is a general exception")

Example

def divide(a, b):
   if b == 0:
      raise ValueError("Cannot divide by zero")
   return a / b

try:
   result = divide(10, 0)
except ValueError as e:
   print(e)

Output:

Cannot divide by zero

Raising Custom Exceptions

You can define and raise custom exceptions by creating a new exception class that inherits from Exception or its subclasses.

Example

class MyCustomError(Exception):
   pass

def risky_function():
   raise MyCustomError("Something went wrong in risky_function")

try:
   risky_function()
except MyCustomError as e:
   print(e)

Output:

Something went wrong in risky_function

Creating Custom Exceptions with Arguments

Custom exceptions can include additional attributes and methods to provide more detailed context about the error condition.

Example

class InvalidAgeError(Exception):
   def __init__(self, age, message="Age must be between 18 and 100"):
      self.age = age
      self.message = message
      super().__init__(self.message)

def set_age(age):
   if age < 18 or age > 100:
      raise InvalidAgeError(age)
   print(f"Age is set to {age}")

try:
   set_age(150)
except InvalidAgeError as e:
   print(f"Invalid age: {e.age}. {e.message}")

Output:

Invalid age: 150. Age must be between 18 and 100

Re-Raising Exceptions

Sometimes you may want to catch an exception, perform actions like logging or cleanup, and then re-raise the same exception for further handling up the call stack. Use raise without arguments to re-raise.

Example

def process_file(filename):
   try:
      with open(filename, "r") as file:
         data = file.read()
         # process data
   except FileNotFoundError as e:
      print(f"File not found: {filename}")
      raise  # Re-raise the exception

try:
   process_file("nonexistentfile.txt")
except FileNotFoundError:
   print("Handling the exception at a higher level")

Output:

File not found: nonexistentfile.txt
Handling the exception at a higher level

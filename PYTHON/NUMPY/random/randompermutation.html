NumPy: Random Permutations

A permutation is a rearrangement of elements in a particular order. For example, [3, 2, 1] is a permutation of [1, 2, 3].

NumPy provides two methods for random permutations: shuffle() and permutation().

Shuffling Arrays

"Shuffle" means rearranging elements *in place* within the original array.

Using shuffle() modifies the original array directly.

from numpy import random
import numpy as np

arr = np.array([1, 2, 3, 4, 5])
random.shuffle(arr)
print(arr)  # Output: array with elements shuffled

Generating Permutations

permutation() returns a *new* array with elements randomly rearranged, leaving the original array unchanged.

from numpy import random
import numpy as np

arr = np.array([1, 2, 3, 4, 5])
print(random.permutation(arr))  # New shuffled array
print(arr)                     # Original array remains unaltered

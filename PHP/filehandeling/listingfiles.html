PHP - Listing Files

Listing files within a directory is a common task in PHP, useful for building **dynamic galleries**, **managing user uploads**, or **displaying available resources**. PHP offers two main approaches for this: the **stream-based** readdir() approach and the **array-based** scandir() approach.

The readdir() Function (Stream-Based Listing)

The readdir() function provides a stream-based way to read directory contents one entry at a time, similar to how file contents are read line by line. This method involves three steps:

  • opendir(): Opens a directory stream handle. 
    opendir(string $directory): resource|false
  • readdir(): Reads the **next available entry** (file or subdirectory name) from the handle. It returns false when there are no more entries. 
    readdir(?resource $dir_handle = null): string|false
  • closedir(): Closes the directory stream handle. 
    closedir(?resource $dir_handle = null): void

Example: Using opendir() and readdir()

This code iterates through all files and directories in the current working directory, printing each name. 

<?php
   $dir = getcwd(); // Get current directory path
   
   // Check if it is a valid directory
   if (is_dir($dir)) {
      // Open the directory handle
      if ($dh = opendir($dir)) {
         // Loop through all entries until readdir returns false
         while (($file = readdir($dh)) !== false) {
            echo "filename: " . $file . "<br>";
         }
         // Close the directory handle
         closedir($dh);
      }
   }
?>

The scandir() Function (Array-Based Listing)

The scandir() function reads the entire contents of a directory into an **indexed array**. This is often the simplest method for listing files. 

scandir(string $directory, int $sorting_order = SCANDIR_SORT_ASCENDING): array|false
  • $directory: The path of the directory to scan.
  • $sorting_order: Optional parameter. By default, it's SCANDIR_SORT_ASCENDING (alphabetical). Can be set to SCANDIR_SORT_DESCENDING or SCANDIR_SORT_NONE.

Note: Both readdir() and scandir() will typically include the special directory entries . (current directory) and .. (parent directory) in their results.

Example: Using scandir()

This example scans a directory and then uses a foreach loop to iterate and display the contents of the returned array. 

<?php
   $dir = "c:/xampp/php/mydir/";

   $files = scandir($dir);
   
   // Loop through the array returned by scandir()
   foreach ($files as $file) {
      echo $file . PHP_EOL; // PHP_EOL is a platform-independent newline
   }

   // Example of descending sort
   $files_desc = scandir($dir, SCANDIR_SORT_DESCENDING);
   // ... can now loop through $files_desc
?>

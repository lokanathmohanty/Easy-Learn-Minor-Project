Python - Escape Characters

Escape Character

An escape character is a character followed by a backslash (\). It signals the interpreter that the following character or sequence has a special meaning. For example, \n represents a newline character.

Unless an r or R prefix is used, escape sequences in strings are interpreted according to rules similar to those used in C. Strings prefixed with r or R are considered raw strings, where escape characters are not processed.

Example: Normal vs Raw String

# normal string
normal = "Hello"
print(normal)

# raw string
raw = r"Hello"
print(raw)

Output:

Hello
Hello

Example with Escape Character

normal = "Hello\nWorld"
print(normal)

raw = r"Hello\nWorld"
print(raw)

Output:

Hello
World
Hello\nWorld

Escape Characters in Python

  • \ → Backslash and newline ignored
  • \\ → Backslash
  • \' → Single quote
  • \" → Double quote
  • \a → ASCII Bell
  • \b → ASCII Backspace
  • \f → ASCII Formfeed
  • \n → Newline
  • \r → Carriage Return
  • \t → Horizontal Tab
  • \v → Vertical Tab
  • \ooo → Character with octal value
  • \xhh → Character with hexadecimal value

Escape Characters Example

# ignore \
s = 'This string will not include \
backslashes or newline characters.'
print(s)

# escape backslash
s = 'The \\character is called backslash'
print(s)

# escape single quote
s = 'Hello \'Python\''
print(s)

# escape double quote
s = "Hello \"Python\""
print(s)

# escape \b to generate ASCII backspace
s = 'Hel\blo'
print(s)

# ASCII Bell character
s = 'Hello\a'
print(s)

# newline
s = 'Hello\nPython'
print(s)

# Horizontal tab
s = 'Hello\tPython'
print(s)

# form feed
s = "hello\fworld"
print(s)

# Octal notation
s = "\101"
print(s)

# Hexadecimal notation
s = "\x41"
print(s)

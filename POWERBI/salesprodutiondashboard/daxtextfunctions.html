Introduction to Power BI DAX Text Functions

DAX Text functions in Power BI allow you to manipulate and format text data within your reports. These functions help in extracting parts of text, combining strings, finding specific values, and cleaning up text data to improve report clarity and usability.

By integrating text functions into measures and calculated columns, users can enhance data presentation and provide meaningful insights from textual data fields.

Examples of Common DAX Text Functions

  • LEFT(): Extracts characters from the left side of a string.
    Example: LEFT("Subscription", 4) returns "Subs".
  • RIGHT(): Extracts characters from the right side of a string.
    Example: RIGHT("clothing", 5) returns "thing".
  • UPPER(): Converts text to uppercase.
    Example: UPPER("annual rate") returns "ANNUAL RATE".
  • LOWER(): Converts text to lowercase.
    Example: LOWER("PARTITION") returns "partition".
  • FORMAT(): Formats values as text using a specified format.
    Example: FORMAT(Sheet1[CSAT], "Percent").
  • FIND(): Finds the position of a substring within a string.
    Example: FIND("Happy", "Living Happy life").
  • CONCATENATE(): Joins two text strings.
    Example: CONCATENATE("California", " US") returns "California US".
  • CONCATENATEX(): Concatenates values from a column with a delimiter.
    Example: CONCATENATEX(Sheet1, Sheet1[Data Resources], " ").
  • MID(): Extracts a substring starting at a specified position.
    Example: MID(Sheet1[Data Resources], 2, 4).
  • TRIM(): Removes extra spaces from text.
    Example: TRIM(" sabn ") returns "sabn".
  • REPLACE(): Replaces part of a string with new text.
    Example: REPLACE(Sheet1[Customer_id], 1, 1, "5").
  • EXACT(): Compares two strings for exact match.
    Example: EXACT("Energetic", "Hectic") returns FALSE.
  • SUBSTITUTE(): Substitutes new text for old text in a string.
    Example: SUBSTITUTE(Sheet1[Resources popularity], "High", "Very High").

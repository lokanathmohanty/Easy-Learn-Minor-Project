C++ if...else and if...else if...else Statements ⚖️

The **if...else statement** provides a way to execute one of two distinct code blocks based on the evaluation of a single Boolean expression. It ensures that exactly one path is taken.

1. The if...else Statement

Syntax:

if (boolean_expression) {
   // Executes if the expression is TRUE (non-zero)
} else {
  // Executes if the expression is FALSE (zero)
}

In the example provided, a is 100:

if ( a < 20 ) { // 100 < 20 is FALSE
    // This block is skipped
} else {
    // This block executes
    cout << "a is not less than 20;" << endl;
}
// Output: a is not less than 20;

2. The if...else if...else Statement

This structure is used to test a **sequence of multiple conditions**. The conditions are checked in order, and the code block associated with the **first true condition** is executed. Once a condition succeeds, the remaining else if and else blocks are completely skipped.

Syntax:

if (expression 1) {
   // Executes if expression 1 is TRUE
} else if (expression 2) {
   // Executes if expression 1 was FALSE, but expression 2 is TRUE
} else if (expression 3) {
   // ... and so on ...
} else {
   // Executes only if ALL preceding expressions were FALSE
}

Example Analysis:

With a = 100, the conditions are checked sequentially:

if (a == 10)      // FALSE
else if (a == 20) // FALSE
else if (a == 30) // FALSE
else {
    // All conditions failed, this block executes
    cout << "Value of a is not matching" << endl;
}
// Output: Value of a is not matching
//         Exact value of a is : 100

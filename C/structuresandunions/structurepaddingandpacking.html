Structure Padding and Packing in C

What is Structure Padding in C?

Structure padding in C is the process handled by the CPU architecture. It adds empty bytes within a structure to align data members naturally in memory. Alignment requirements depend on the processor architecture, such as data bus size, not on the language itself.

Understanding Structure Padding with Examples

Consider the following struct definition:

struct struct1 {
  char x;
  int y;
  char z;
};

Example 1

Check the size of this struct:

#include <stdio.h>

struct struct1 {
  char a;
  char b;
  int c;
};

int main() {
  printf("Size: %d", sizeof(struct struct1));
  return 0;
}

Output:

Size: 8

This is unexpected because char is 1 byte and int is 4 bytes, so we might expect 6 bytes total.

Explanation of Structure Padding

On a 32-bit processor (4 bytes per word), the CPU accesses memory in 4-byte chunks. To optimize access, padding bytes are inserted to align the int member on a 4-byte boundary. Thus, two empty bytes are added after the two char members, increasing total size to 8 bytes.

Example 2

Changing member order and types:

#include <stdio.h>

struct struct1 {
  char a;
  int b;
  char c;
};

int main() {
  printf("size: %d", sizeof(struct struct1));
  return 0;
}

Output:

size: 12

Explanation: - char a occupies 1 byte, followed by 3 padding bytes. - int b occupies next 4 bytes. - char c occupies 1 byte, followed by 3 padding bytes. - Total size becomes 12 bytes due to padding for alignment.

What is Structure Packing in C?

Structure packing reduces the padding by minimizing or eliminating the empty bytes added for alignment, thus saving memory.

Understanding Structure Packing with Examples

There are two common ways to enforce packing:

  • Using #pragma pack(1) directive
  • Using __attribute__((packed)) GCC attribute

Using #pragma pack(1) Directive

This directive forces the compiler to pack the structure members without padding.

#include <stdio.h>
#pragma pack(1)

struct struct1 {
  char a;
  int b;
  char c;
};

int main() {
  printf("size: %d", sizeof(struct struct1));
  return 0;
}

Output:

size: 6

This shows that padding is avoided and memory is saved.

Using __attribute__((packed))

This GCC-specific attribute achieves the same packing effect by applying it to the struct definition.

#include <stdio.h>

struct __attribute__((packed)) struct1 {
  char a;
  int b;
  char c;
};

int main() {
  printf("size: %d", sizeof(struct struct1));
  return 0;
}

Output:

size: 6

This method also avoids padding and saves memory.

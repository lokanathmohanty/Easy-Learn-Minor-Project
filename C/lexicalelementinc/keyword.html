Keywords in C

Keywords are predefined reserved words in C that have special meanings to the compiler. According to the C99 standard, there are 32 keywords, and they cannot be used for variable names or identifiers.

Example of Using a Keyword as an Identifier (Error)


#include <stdio.h>

void register(int, int);
int main() {
    int a=5, b=7;
    register(a, b);
    return 0;
}
void register(int a, int b) {
    printf("%d", a+b);
}

This code causes compilation errors because register is a reserved keyword and cannot be used as a function name or identifier.

Categories of C Keywords

Keywords can be broadly classified into categories, such as:

  • Primary Data Types: int, char, float, double, etc.
  • User-defined Types: struct, union, enum
  • Storage Classes: auto, extern, static, register
  • Conditionals: if, else, switch, case
  • Loops: for, while, do
  • Others: break, continue, return, sizeof

Notes on Keywords

Keywords in C are case-sensitive and are always written in lowercase. New keywords introduced after C99 start with an underscore. They are reserved for implementation purposes and should not be used as identifiers.

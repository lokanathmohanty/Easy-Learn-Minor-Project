Next.js Route Handlers (App Router) ⚙️

What are Route Handlers?

**Route Handlers** are the equivalent of API Routes for the modern Next.js **App Router** architecture. They are used to create custom **server-side API endpoints** that can be consumed by the frontend (Client Components) or any external client. They define server-side logic for HTTP requests, such as fetching data, handling form submissions, or interacting with a database.

How They Work:

  • **Creation:** A Route Handler is created by adding a file named **`route.js`** or **`route.ts`** inside a folder within the `app` directory (e.g., `app/api/hello/route.js`).
  • **Endpoint Mapping:** The file path defines the API endpoint (e.g., `/api/hello`).
  • **Coexistence:** A `route.js` file **cannot** exist at the same folder level as a `page.js` file, as they both map to the same URL segment.

Setting Up a Basic Route Handler

A basic handler exports a function named after the HTTP method it handles. It receives a `Request` object and must return a `Response` object, typically using **`NextResponse.json()`** for convenience.

Example (GET Request):

// File: app/api/hello/route.js
import { NextResponse } from 'next/server';

export async function GET() {
  // Returns a JSON response with status 200 (OK)
  return NextResponse.json({ message: 'Hello from Route Handler!' });
}

Handling Multiple HTTP Methods

You can handle different HTTP verbs by exporting separate functions named `GET`, `POST`, `PUT`, `DELETE`, etc., from the same `route.ts` file.

// File: app/api/users/route.ts

// Handles GET requests to /api/users
export async function GET() {
  return NextResponse.json(
    { message: 'Fetching users' },
    { status: 200 }
  );
}

// Handles POST requests to /api/users (e.g., for creating a new user)
export async function POST(request: Request) {
  // Access the request body via the Request object
  const data = await request.json(); 
  return NextResponse.json(
    { message: 'Creating user', data },
    { status: 201 } // 201 Created
  );
}

// Handles DELETE requests to /api/users
export async function DELETE(request: Request) {
  // Access query parameters from the request URL
  const { searchParams } = new URL(request.url);
  const id = searchParams.get('id');
  return NextResponse.json(
    { message: 'Deleting user', id },
    { status: 200 }
  );
}

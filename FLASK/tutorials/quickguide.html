Flask Quick Guide: Overview and Environment Setup 🐍

Flask Overview

**Flask** is a **micro web application framework** written in Python, developed by **Armin Ronacher** and the Pocco group. As a framework, it provides a collection of libraries and modules that handle low-level details (like protocols and thread management), allowing developers to focus on application logic.

Flask is based on two core components, both Pocco projects:

  • **Werkzeug:** A **WSGI** (Web Server Gateway Interface) toolkit that implements request and response objects. WSGI is the standard universal interface between Python web applications and web servers.
  • **Jinja2:** A powerful and popular **templating engine** used to render dynamic HTML pages by combining templates with data sources.

Flask is classified as "micro" because it keeps the core simple and does not include built-in abstraction layers for components like database handling or form validation; these functionalities are added via **extensions**.

Flask Environment Setup

While Flask works with Python 3.3+, it's best practice to use a **virtual environment** for development to manage dependencies and avoid compatibility issues.

1. Install virtualenv

pip install virtualenv (Requires administrator privileges)

2. Create and Activate the Environment

A virtual environment (e.g., named venv) is created within your project directory and then activated:

  • **Create:** virtualenv venv
  • **Activate (Linux/OS X):** venv/bin/activate
  • **Activate (Windows):** venv\scripts\activate

3. Install Flask

Once the environment is active, install Flask:

pip install Flask

A Minimal Flask Application (Hello.py)

A basic Flask application demonstrates the essential components:

from flask import Flask
app = Flask(__name__)

@app.route('/')
def hello_world():
   return 'Hello World'

if __name__ == '__main__':
   app.run()

Key Concepts:

  • **Flask Object:** app = Flask(__name__) creates the **WSGI application instance**. The argument __name__ is the name of the current module.
  • **Routing:** The **@app.route(rule, options)** decorator binds a **URL rule** (e.g., '/' for the home page) to an **associated function** (hello_world()).
  • **Running the App:** The **app.run()** method starts the local development server.

app.run() Parameters (Optional):

  • **host:** Defaults to 127.0.0.1 (localhost). Set to **0.0.0.0** to make the server accessible externally.
  • **port:** Defaults to **5000**.
  • **debug:** Defaults to False. If set to **True**, it provides debug information (like an interactive debugger) and enables the reloader.

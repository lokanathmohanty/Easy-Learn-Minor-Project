Quick Guide to R Programming

What is R?

R is a language and environment for statistical computing and graphics. It is widely used among statisticians, data scientists, and researchers for data analysis, visualization, and machine learning.

Basic Syntax

  • Comments start with #
  • Assignment is done with <- or =
  • Statements are typically separated by new lines

Data Types

  • Numeric: e.g., 3.14, 42
  • Integer: e.g., 2L
  • Character: e.g., "hello"
  • Logical: TRUE, FALSE
  • Complex: e.g., 1+2i

Common Data Structures

  • Vector: c(1, 2, 3)
  • Matrix: matrix(1:6, nrow=2)
  • List: list(name="Tom", age=25)
  • Data Frame: data.frame(id=1:3, name=c("A", "B", "C"))
  • Factor: factor(c("male", "female", "male"))

Control Structures

  • if, else
  • for loops
  • while loops
  • repeat loops with break

Functions

Functions are created using the function() keyword.

Example:

add <- function(a, b) {
  return(a + b)
}

Packages

  • Install: install.packages("ggplot2")
  • Load: library(ggplot2)

Reading and Writing Data

  • CSV: read.csv("file.csv")
  • Write CSV: write.csv(data, "file.csv")

Basic Plotting

  • plot(x, y)
  • hist(x)
  • boxplot(x)

Useful Functions

  • mean(x), median(x), sd(x)
  • summary(data)
  • str(data)
  • head(data), tail(data)

Getting Help

  • ?mean or help(mean)
  • help.search("regression")

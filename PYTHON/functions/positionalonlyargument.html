Python - Positional-Only Arguments

In Python, you can define functions where one or more arguments cannot accept values using keywords. Such arguments are called positional-only arguments.

To make an argument positional-only, use the / symbol in the function definition. All arguments before / are treated as positional-only.

For example, Python’s built-in input() function is positional-only. Its syntax is: 

input(prompt = "")

The argument prompt is an explanatory string for the user. However, you cannot pass it as a keyword.

Example: Using Keyword for input()

name = input(prompt="Enter your name ")

Error:

TypeError: input() takes no keyword arguments

Positional-Only Arguments Examples

Example 1

Making both arguments positional-only using /:

def intr(amt, rate, /):
    val = amt * rate / 100
    return val

print(intr(316200, 4))

Output:

12648.0

Example 2

If you try to pass positional-only arguments as keywords, Python raises an error:

def intr(amt, rate, /):
    val = amt * rate / 100
    return val

print(intr(amt=1000, rate=10))

Error:

TypeError: intr() got some positional-only arguments 
passed as keyword arguments: 'amt, rate'

Example 3

A function may have positional-only, regular, and keyword-only arguments together: 

def myfunction(x, /, y, *, z):
    print(x, y, z)

myfunction(10, y=20, z=30)
myfunction(10, 20, z=30)

Output:

10 20 30
10 20 30

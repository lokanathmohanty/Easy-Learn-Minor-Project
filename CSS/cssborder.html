CSS - Borders

The border property creates a border around an HTML element, such as a div, image, or text. You can customize the border by changing its style, width, radius, and color. Borders improve readability, separate content, and can highlight important sections of a webpage.

CSS Border Shorthand Property

The shorthand border property allows you to set the width, style, and color in a single declaration.

Syntax:

border: border-width border-style border-color;

Example:

<p style="border: solid 4px grey;">Paragraph with border</p>
<div style="border: darkred solid 5px;">Div with border</div>

Types of Border Properties

  • border-style: sets border type (solid, dashed, dotted, etc.)
  • border-width: sets thickness of border
  • border-color: sets color of border

CSS border-style Property

Specifies the type of line drawn for the border.

Example:

<p style="border-style: dotted;">Dotted border</p>
<p style="border-style: dashed;">Dashed border</p>
<p style="border-style: double;">Double border</p>
<p style="border-style: groove;">Groove border</p>

Border Style for Individual Sides

You can apply different styles to each side:

<p style="
  border-top-style: dotted; 
  border-right-style: solid; 
  border-bottom-style: dashed; 
  border-left-style: double;">
Different border styles on all sides.
</p>

CSS border-width Property

Specifies the thickness of a border.

<p style="border: solid thin;">Thin border</p>
<p style="border: solid medium;">Medium border</p>
<p style="border: solid thick;">Thick border</p>
<p style="border: solid 10px;">10px border</p>

CSS border-color Property

Sets the color of a border.

<p style="border: dashed red;">Red border</p>
<p style="border: solid #00ff00;">Green border</p>

Borders for Individual Sides

Each side can have different color, width, and style.

<p style="
  border-top: red dashed thick;
  border-right: solid blue medium;
  border-bottom: dotted green thin;
  border-left: double orange 15px;">
Different borders for each side
</p>

Overriding Shorthand

You can override a shorthand border by specifying individual side properties.

<div style="
  border: 5px solid gray; 
  border-bottom-width: 15px;">
Overridden bottom border
</div>

Borders on Inline Elements

Borders can also be applied to inline elements like span.

<p>
This is <span style="border: 2px solid black;">inline</span> with border.
</p>

CSS border-image Property

Allows using an image as the border of an element.

<div style="
  border: 20px solid transparent; 
  border-image: url('border.png') 40;">
Border image example
</div>

CSS border-radius Property

Rounds the corners of borders.

<div style="border: 2px solid black; border-radius: 20px;">
Rounded box
</div>

<div style="border: 2px solid black; border-radius: 50%;">
Circle
</div>

CSS Borders Properties Reference

  • border – shorthand for all border properties
  • border-style – style of border
  • border-width – thickness of border
  • border-color – color of border
  • border-top, border-right, border-bottom, border-left – shorthand for sides
  • border-image – set image as border
  • border-radius – round corners

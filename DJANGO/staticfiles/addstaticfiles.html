Django: Adding and Serving Static Files 🖼️

Static files are the resources a web application needs to render a complete web page, separate from dynamic data. These typically include **images**, **JavaScript code** (JS), and **Cascading Style Sheets** (CSS).

The Staticfiles App and Configuration

Django manages static files using the **django.contrib.staticfiles** app, which is installed by default in INSTALLED_APPS. This app automatically searches for static assets in a specific location:

  • **Storage Location:** Django looks for static files within a folder named **static** inside each application's package folder (e.g., myapp/static/).
  • **Settings:** The **STATIC_URL** parameter in settings.py must be correctly configured. By default, it is often set to 'static/': 
    STATIC_URL = 'static/'

Usage in Templates (.html files)

To use static files in a Django template, you must follow two steps:

  1. **Load the Tag:** Use the **{% load static %}** template tag at the top of the HTML file.
  2. **Reference the File:** Use the **{% static 'file_path' %}** tag to generate the correct, absolute URL path to the file. The path is relative to the app's static/ folder.

Example for an Image (django.png):

<html><body>
   {% load static %}
   <img src="{% static 'django.png' %}" alt="My image">
</body></html>

Example for CSS File (style.css):

<link rel="stylesheet" type="text/css" href="{% static 'style.css' %}">

Example for JavaScript File (script.js):

<head>
   {% load static %}
   <script src = "{% static 'script.js' %}"></script>
</head>

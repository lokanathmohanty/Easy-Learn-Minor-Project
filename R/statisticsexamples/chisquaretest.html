R - Chi Square Test

Chi-Square test is a statistical method to determine if two categorical variables have a significant correlation between them. Both variables should be from the same population and categorical like Yes/No, Male/Female, Red/Green, etc.

For example, we can analyze people's ice-cream buying patterns to correlate gender with preferred ice-cream flavor. If a correlation is found, appropriate stocks can be planned accordingly.

Syntax

The function used for performing chi-Square test is chisq.test().

Basic syntax:

chisq.test(data)

Where data is a table containing the count values of the observed variables.

Example

Using the Cars93 dataset from the MASS library representing sales of different car models in 1993, we test the correlation between types of cars and their airbags.

library("MASS")
car.data <- data.frame(Cars93$AirBags, Cars93$Type)
car.data = table(Cars93$AirBags, Cars93$Type)
print(car.data)
print(chisq.test(car.data))

Output of the table:

             Compact Large Midsize Small Sporty Van
Driver & Passenger   2    4      7     0      3   0
Driver only          9    7     11     5      8   3
None                 5    0      4    16      3   6

Chi-Square test results:

Pearson's Chi-squared test

data:  car.data
X-squared = 33.001, df = 10, p-value = 0.0002723

Warning message:
In chisq.test(car.data) : Chi-squared approximation may be incorrect

Conclusion

The p-value < 0.05 indicates a strong correlation between car types and airbag types in this dataset.

C++ Identifiers: Naming Rules and Types

C++ Identifiers are unique names used to identify user-defined items in a program, such as **variables**, **functions**, **classes**, and **arrays**.

Examples: In int number = 10; and string name = "John";, number and name are identifiers.

Rules for Creating Identifiers

To be valid, an identifier must adhere to the following rules:

  • It must begin with a **letter** (A-Z, a-z) or an **underscore** (_). It **cannot** start with a digit (0-9).
  • Subsequent characters can be **letters**, **digits** (0-9), or **underscores**.
  • Identifiers are **case-sensitive** (e.g., myVar is different from myvar).
  • It **cannot** be a **C++ keyword** (e.g., int, while, return).
  • It must be **unique** within its namespace.

Common Practices

While not strict rules, these practices improve code readability:

  • Use **meaningful names** that reflect the identifier's purpose (e.g., totalCount, calculateArea).
  • Commonly use **camelCase** (e.g., firstName) or **snake_case** (e.g., first_name).
  • Avoid overly long names, as they can reduce readability.

Types of Identifiers

Identifiers are used to name various programming elements:

  • Variable Identifiers: Names for variables storing data (e.g., age, salary, initial_alpha).
  • Constant Identifiers: Names for fixed values (e.g., MAX_SIZE for const int MAX_SIZE = 100;).
  • Function Identifiers: Names for reusable blocks of code (e.g., calculateSum(), getValue()).
  • Class Identifiers: Names for user-defined data types in OOP (e.g., Person for class Person {...};).

Examples of Invalid Identifiers

  • 2ndValue (Starts with a digit)
  • first-name (Contains a hyphen -)
  • @username (Begins with a special character)
  • my variable (Contains a space)
  • float (Uses a reserved keyword)

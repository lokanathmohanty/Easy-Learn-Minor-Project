C# Relational Operators

What Are Relational Operators?

Relational Operators (or **Comparison Operators**) are used to **compare two operands** and determine the relationship between them. The result of a relational operation is always a **Boolean value** (either true or false).

These operators are fundamental for **decision-making**, creating **conditional statements** (if/else), controlling **loops**, and **data validation**.

Relational Operators List:

  • Equal to: ==
  • Not equal to: !=
  • Greater than: >
  • Less than: <
  • Greater than or equal to: >=
  • Less than or equal to: <=

Usage in Conditional Logic (Example)

Relational operators are most commonly found in if statements to control program flow based on conditions.

Temperature Check Example

int temperature = 25; // Current temperature

if (temperature > 30) // Checks if 25 is greater than 30 (False)
{
    Console.WriteLine("It's a hot day!");
}
else
{
    Console.WriteLine("The weather is pleasant."); // This line executes
}

Loop Control Example

The relational operator defines the loop's continuation condition:

// The loop continues as long as i is less than or equal to 5 (i <= 5)
for (int i = 1; i <= 5; i++)
{
    Console.WriteLine("Iteration: " + i);
}

Real-World Application

Relational operators are critical for implementing business rules and constraints:

  • Age Validation: if (age >= 18) (Check voting eligibility).
  • Fund Checks: if (withdrawal <= balance) (Check if sufficient funds exist).
  • Pass/Fail Grades: if (marks >= 50) (Determine exam result).

Best Practices:

  • **ALWAYS** use the double equals sign (==) for comparison, and the single equals sign (=) for assignment. Mixing these up is a very common error.
  • To combine multiple comparisons, use **Logical Operators** (&& or ||), for instance: if (x > 5 && x < 10).

Python - List Exercises

Exercise 1: Find Unique Numbers in a List

L1 = [1, 9, 1, 6, 3, 4, 5, 1, 1, 2, 5, 6, 7, 8, 9, 2]
L2 = []
for x in L1:
   if x not in L2:
      L2.append(x)
print(L2)

Output:

[1, 9, 6, 3, 4, 5, 2, 7, 8]

Exercise 2: Sum of All Numbers in a List

L1 = [1, 9, 1, 6, 3, 4]
ttl = 0
for x in L1:
   ttl += x
print("Sum of all numbers Using loop:", ttl)

ttl = sum(L1)
print("Sum of all numbers sum() function:", ttl)

Output:

Sum of all numbers Using loop: 24
Sum of all numbers sum() function: 24

Exercise 3: Create List of 5 Random Integers

import random
L1 = []
for i in range(5):
   x = random.randint(0, 100)
   L1.append(x)
print(L1)

Sample Output:

[77, 3, 20, 91, 85]

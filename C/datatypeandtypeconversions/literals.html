C - Literals

Literals in C represent fixed values used directly in source code for initializing variables or constants. They represent data of specific types such as integers, floating points, characters, and strings.

Types of Literals

  • Integer Literals
  • Floating Point Literals
  • Character Literals
  • Escape Sequences
  • String Literals
  • Array and Struct Literals

Integer Literals

Represent whole numbers without fractional parts. Can be:

  • Decimal: e.g., 10, -50
  • Octal: prefixed with 0, e.g., 025
  • Hexadecimal: prefixed with 0x or 0X, e.g., 0xa1
  • Binary (in modern compilers): prefixed with 0b, e.g., 0b1010

May include suffixes: U (unsigned), L (long), combinations like UL.

Floating Point Literals

Represent real numbers expressed with decimal points and optional exponent notation:

  • Examples: 10.55, -1.333, 100E+4, -1.3E-03
  • Suffixes like L for long double

Used to initialize float or double variables.

Character Literals

Single characters enclosed in single quotes, e.g., 'A'.

Represented as their ASCII integer values internally.

Escape sequences represent special characters, e.g., '\n' is newline.

Unicode characters can be represented as '\uXXXX'.

Escape Sequences

Special characters beginning with backslash \, representing characters like newline, tab, quote, etc.

  • \n - Newline
  • \t - Horizontal Tab
  • \\ - Backslash
  • \" - Double Quote

String Literals

Sequences of characters enclosed in double quotes, e.g., "Hello World".

Stored as arrays of chars terminated by a null character '\0'.

Can include escape sequences and extend across lines with backslash.

Examples


#include <stdio.h>

int main() {
    int decimal = 10;
    int octal = 025;            // octal literal
    int hex = 0xa1;             // hexadecimal literal
    int binary = 0b1010;        // binary literal (compiler support required)
    
    float pi = 3.14159;         // floating point literal
    float sci = 1.23E4;         // scientific notation
    
    char ch = 'A';              // character literal
    char newline = '\n';        // escape sequence
    
    char str[] = "Hello, C!";   // string literal
    
    printf("decimal = %d\n", decimal);
    printf("octal (025) = %d\n", octal);
    printf("hex (0xa1) = %d\n", hex);
    printf("binary (0b1010) = %d\n", binary);
    printf("pi = %f\n", pi);
    printf("sci = %f\n", sci);
    printf("character = %c (ASCII %d)\n", ch, ch);
    printf("string = %s\n", str);
    
    return 0;
}

Django Admin: Customizing List Display and Search ⚙️

The Django Admin interface is highly customizable, allowing you to control how model objects are represented in lists and forms. Customization is managed using the **admin.ModelAdmin** class.

1. Improving Object Representation (__str__)

By default, Django displays generic names like "Employee object (1)". To make the objects more user-friendly in the Admin and other places, you must **override the __str__() method** in your model class. This method defines the string representation of an object:

class Employee(models.Model):
   # ... fields ...
   
   def __str__(self):
      return "Name: {}, Contact: {}".format(self.empname, self.contact)

After this change, the list view will show the descriptive string, e.g., "Name: John Doe, Contact: 555-1234".

2. Customizing List Columns (list_display)

The **"change list page"** (the page listing all objects for a model) can be customized using the **list_display** attribute of a **ModelAdmin** class. This attribute takes a **tuple** of field names to be displayed as columns.

The **EmployeeAdmin** class inherits from admin.ModelAdmin and is registered with the Employee model. This registration can be done via the standard function or the decorator:

Defining and Registering the Admin Class (admin.py)

from django.contrib import admin
from .models import Employee

# Use the @admin.register decorator for clean registration
@admin.register(Employee) 
class EmployeeAdmin(admin.ModelAdmin):
   list_display = ("empname", "contact", "joined_date")

This configuration replaces the default single column with columns for Name, Contact, and Joined Date.

3. Adding Search Functionality (search_fields)

You can add a search box to the change list page using the **search_fields** attribute. This attribute takes a tuple of field names upon which the search will be performed. You can use field lookup types (like __startswith) to refine the search behavior.

@admin.register(Employee)
class EmployeeAdmin(admin.ModelAdmin):
   list_display = ("empname", "contact", "joined_date")
   search_fields = ("empname__startswith", ) # Search based on the start of the employee's name

By adding this, a search field appears on the top of the Employee list page, restricting results to names beginning with the entered text.

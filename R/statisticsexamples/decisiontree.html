R - Decision Tree

Decision trees represent decisions and their possible consequences as a tree structure. Nodes indicate decision points/events, and edges represent rules or conditions. Widely used in machine learning and data mining, decision trees support classification tasks like spam detection or credit risk assessment.

The R package party provides tools to build and visualize decision trees via the ctree() function.

Installation

install.packages("party")

Usage

library(party)

Basic Syntax

ctree(formula, data)

- formula: Defines predictor and response variables (e.g., nativeSpeaker ~ age + shoeSize + score)

- data: Dataset to fit the tree.

Example

# Load package
library(party)

# View sample data
print(head(readingSkills))

# Use first 105 rows as training data
input.dat <- readingSkills[1:105, ]

# Create decision tree
output.tree <- ctree(nativeSpeaker ~ age + shoeSize + score, data = input.dat)

# Plot and save the tree
png(file = "decision_tree.png")
plot(output.tree)
dev.off()

The resulting tree shows, for example, that individuals with reading scores below 38.3 and age over 6 are likely non-native speakers.

This output is generated after loading necessary dependencies like mvtnorm and grid automatically.

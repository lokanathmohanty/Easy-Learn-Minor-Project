CSS border-inline Property

The border-inline property is a shorthand CSS property that allows developers to set values for logical inline borders, namely border-inline-width, border-inline-style, and border-inline-color, in one single declaration. The border-style is mandatory, while color and width will default if not specified.

Unlike physical properties such as border-left or border-right, border-inline is logical and adapts to different writing modes, text orientation, and direction of content.

Syntax

border-inline: border-inline-width border-inline-style border-inline-color | initial | inherit;

Property Values

  • border-inline-width: Specifies the width of element borders in the inline direction. Default: medium.
  • border-inline-style: Specifies the style of element borders in the inline direction. Default: none.
  • border-inline-color: Specifies the color of element borders in the inline direction. Default: same as text color.
  • initial: Sets the property to its default value.
  • inherit: Inherits the property value from its parent element.

Defining All Values of Border Inline Property

To define all three values (width, style, and color) at once, the border-inline property can be used in a single declaration.

Example

<p style="border-inline: 4px solid red;">Solid red inline border 4px</p>
<p style="border-inline: 6px dashed blue;">Dashed blue inline border 6px</p>
<p style="border-inline: 8px dotted yellow;">Dotted yellow inline border 8px</p>
<p style="border-inline: 8px double brown;">Double brown inline border 8px</p>

Constituent Properties

The shorthand border-inline is made up of three separate properties:

  • border-inline-width
  • border-inline-style
  • border-inline-color

Example

<p style="border-inline-width:4px; border-inline-style:solid; border-inline-color:red;">
  Inline border: solid red, 4px
</p>

<p style="border-inline-width:6px; border-inline-style:dashed; border-inline-color:blue;">
  Inline border: dashed blue, 6px
</p>

Border Inline with Writing Mode

The effect of border-inline depends on the writing-mode. In horizontal writing mode, it applies to the left and right borders, while in vertical writing mode, it applies to the top and bottom borders.

Example

<p style="border-inline: 4px solid red; writing-mode: horizontal-rl;">
  Horizontal inline border
</p>

<p style="border-inline: 6px dashed blue; writing-mode: vertical-rl;">
  Vertical inline border
</p>

Supported Browsers

  • Chrome: 87.0+
  • Edge: 87.0+
  • Firefox: 66.0+
  • Safari: 14.1+
  • Opera: 73.0+

Summary

The border-inline property is a powerful shorthand for logical inline borders in CSS. It ensures that designs adapt well to international writing systems by applying borders relative to text flow, rather than fixed physical sides. Using this property makes layouts more responsive to languages that use different orientations such as vertical text.

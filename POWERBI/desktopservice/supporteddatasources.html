Power BI Supported Data Sources

Power BI supports a wide range of data sources that can be connected and used to build datasets for analysis and reporting.

Major Categories of Data Sources

  • Flat Files: Excel workbooks, CSV, Text, XML, JSON, PDF, Folder, and others.
  • Databases: SQL Server, Access, Oracle, MySQL, PostgreSQL, SAP, IBM DB2, Amazon Redshift, Google BigQuery, Snowflake, Vertica, Azure SQL Database, and many more.
  • Cloud Services: Azure Data Lake, Azure Blob Storage, Azure Synapse Analytics, and cloud-hosted databases.
  • Online Services: Salesforce, Google Analytics, Facebook, Dynamics 365, Zendesk, Adobe Analytics, Mailchimp, and other SaaS platforms.
  • Other Data Sources: SharePoint Lists, OData feeds, Active Directory, Hive, Hadoop, Web APIs, R and Python scripts, ODBC connections.

Connection Modes

For supported database sources, users can select between Import and DirectQuery connection modes:

  • Import: Data is loaded into Power BI’s in-memory engine, enabling fast interactions but limited to dataset size.
  • DirectQuery: Queries are sent live to the database at run-time, allowing larger datasets and up-to-date data but with some limitations.

Security and Authentication

Power BI requires authenticated dataset connections to ensure data security. Data sources often require user credentials or gateway configurations to access on-premises data.

Usage Tips

  • Users typically start with flat files and familiar databases for testing.
  • Enterprise environments leverage cloud and on-premises database connectors.
  • Ensuring data source permissions and gateway setups is critical for reliable refreshes and report functioning.

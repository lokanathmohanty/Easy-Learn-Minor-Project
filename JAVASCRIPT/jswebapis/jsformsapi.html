JavaScript - Forms API

Web Forms API

JavaScript Forms API is a web API that allows us to interact with and manipulate HTML forms. It provides a set of methods and properties that are used to perform client-side form validation. It also helps ensure data integrity before form submission. The Forms API is also referred to as the Form Validation API or Constraint Validation API.

Here, we will discuss how to use various methods and properties to validate the form data using JavaScript.

Constraint Validation DOM Methods

The constraint validation DOM methods validate the input value by referencing the input fields. They return a boolean value that represents whether the input value is valid.

  • checkValidity() - Returns a boolean value based on whether the input element contains a valid value.
  • setCustomValidity() - Used to set a custom message to the validationMessage property.

Syntax

You can use these methods as follows:

element.checkValidity()
OR
element.setCustomValidity(message);

Example: Using the checkValidity() Method

We created a number input with a min attribute. The validateInput() function validates the value entered.

<html>
<body>
   <input type="number" min="10" id="num" required>
   <p id="output"></p>
   <button onclick="validateInput()"> Validate Number </button>
   <script>
      const output = document.getElementById("output");
      function validateInput() {
         let num = document.getElementById("num");
         if (num.checkValidity() == false) {
            output.innerHTML = "Please enter a number greater than 10";
         } else {
            output.innerHTML = "Your number is " + num.value;
         }
      }
   </script>
</body>
</html>

Example: Using the setCustomValidity() Method

Here, the validateAge() function applies custom validation to ensure the user enters an age of at least 18.

<html>
<body>
   <form>
      <label> Enter your age: </label>
      <input type="number" id="age" required> <br><br>
      <button type="button" onclick="validateAge()"> Validate Age </button>
   </form>
   <div id="message"></div>
   <script>
      function validateAge() {
         const ageInp = document.getElementById("age");
         const output = document.getElementById("message");
         const age = parseInt(ageInp.value);
         if (isNaN(age)) {
            ageInp.setCustomValidity("Please enter a valid number.");
         } else if (age < 18) {
            ageInp.setCustomValidity("You must be at least 18 years old.");
         } else {
            ageInp.setCustomValidity("");
            output.innerHTML = "Age is valid!";
         }
         ageInp.reportValidity();
      }
   </script>
</body>
</html>

Constraint Validation DOM Properties

JavaScript also contains DOM properties for constraint validation. These help check specific validations of input values.

  • validity - Contains multiple properties to perform validations.
  • validationMessage - Holds the validation message if the input is invalid.
  • willValidate - Represents whether the input will be validated.

Properties of the validity Property

The validity object contains several properties:

  • customError - True if a custom validity message is set.
  • patternMismatch - True if the value doesn’t match the pattern.
  • rangeOverflow - True if the value exceeds the max attribute.
  • rangeUnderflow - True if the value is below the min attribute.
  • stepMismatch - True if the value doesn’t align with the step.
  • tooLong - True if the value exceeds the maxLength attribute.
  • typeMismatch - True if the value doesn’t match the input type.
  • valueMissing - True if the required input is empty.
  • valid - True if the input value is valid.

Syntax

element.validity.property;

Example: Using rangeOverflow Property

<html>
<body>
   <form>
      <label> Enter Any Number: </label>
      <input type="number" id="num" max="300" required> <br><br>
      <button type="button" onclick="validateNumber()"> Validate Number </button>
   </form>
   <div id="output"></div>
   <script>
      const output = document.getElementById('output');
      function validateNumber() {
         const numInput = document.getElementById('num');
         if (numInput.validity.rangeOverflow) {
            output.innerHTML = "Number is too large";
         } else {
            output.innerHTML = "Number is valid";
         }
      }
   </script>
</body>
</html>

Example: Using valueMissing Property

<html>
<body>
   <form>
      <label> Enter any text: </label>
      <input type="text" id="str" required> <br><br>
      <button type="button" onclick="validateText()"> Validate Text </button>
   </form>
   <div id="output"></div>
   <script>
      const output = document.getElementById('output');
      function validateText() {
         const strInput = document.getElementById('str');
         if (strInput.validity.valueMissing) {
            output.innerHTML = "Please enter a value.";
         } else {
            output.innerHTML = "You have entered " + strInput.value + ".";
         }
      }
   </script>
</body>
</html>

You can also use other properties of the validity property to validate form input data and show custom error messages.

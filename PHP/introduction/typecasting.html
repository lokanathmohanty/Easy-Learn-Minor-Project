PHP Type Casting: Conversion of Data Types

**Type Casting** refers to the conversion of one data type into another. Since PHP is a **weakly typed language**, this conversion happens in two ways: **Implicitly** (coercion by the parser) and **Explicitly** (using casting operators or built-in functions).

1. Implicit Type Casting (Coercion)

PHP automatically converts types when a certain operation requires it.

  • **Numeric Operation:** A string containing digits is converted to a number if used in an arithmetic operation.
    $a = 10; $b = '20'; $c = $a + $b; $\rightarrow$ `c = 30` (String '20' cast to integer 20)
  • **Concatenation:** A number is converted to a string if used in the string concatenation operation (using the `.` operator).
    $a = 10; $b = '20'; $c = $a . $b; $\rightarrow$ `c = 1020` (Integer 10 cast to string '10')

2. Explicit Type Casting (Operators)

Explicit casting forces a conversion by placing the target type in parentheses before the expression: **`$var = (type)expr;`**.

Common Casting Operators:

  • **`(int)`** or **`(integer)`**
  • **`(float)`**, **`(double)`**, or **`(real)`**
  • **`(bool)`** or **`(boolean)`**
  • **`(string)`**
  • **`(array)`**
  • **`(object)`**

Casting to Integer (`(int)`):

  • **Float to Int:** The fractional part is **discarded** (not rounded).
    $a = 9.99; $b = (int)$a; $\rightarrow$ `int(9)`
  • **String to Int:**
    • If the string starts with digits, only those digits are kept (e.g., `"10 Rs."` $\rightarrow$ `int(10)`).
    • If the string starts with non-numeric characters, the result is `0` (e.g., `"$100"` $\rightarrow$ `int(0)`).

Casting to Boolean (`(bool)`):

An expression is cast to `true` or `false` based on its "truthiness":

  • **`true`** for any **non-zero** number (integer or float), and for most non-empty strings (even `"Hello"`).
  • **`false`** for `0` (integer), `0.0` (float), empty string `""`, string `"0"`, `NULL`, and empty arrays.
    $a = 100; $b = (bool)$a; $\rightarrow$ `bool(true)`
    $x = 0; $y = (bool)$x; $\rightarrow$ `bool(false)`

3. Type Casting Functions

PHP provides dedicated built-in functions for casting, which are sometimes preferred for clarity.

  • **`intval(mixed $value, int $base = 10)`:** Gets the **integer** value of a variable. Useful for specifying a base (e.g., 8 for octal) for string-to-integer conversion.
  • **`floatval(mixed $value)`** (Alias: `doubleval()`): Gets the **float** value of a variable.
    floatval('99.90 Rs') $\rightarrow$ `99.9` (Discards non-numeric suffix)
  • **`strval(mixed $value)`:** Gets the **string** value of a variable.
    strval(4.2E5) $\rightarrow$ `'420000'`

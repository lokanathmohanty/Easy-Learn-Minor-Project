Python - Access Tuple Items

The most common way to access values within a Python tuple is using indexing. We specify the index of the element we want inside square brackets [].

Tuples are immutable ordered collections in Python, useful for grouping related data.

Accessing Tuple Items with Indexing

Each element has an index starting at 0 for the first element and ends at length - 1. Access the element by referencing the index:

tuple[3]

Example:

tuple1 = ("Rohan", "Physics", 21, 69.75)
tuple2 = (1, 2, 3, 4, 5)

print("Item at 0th index in tuple1:", tuple1[0])
print("Item at index 2 in tuple2:", tuple2[2])

Output:

Item at 0th index in tuple1: Rohan
Item at index 2 in tuple2: 3

Accessing Tuple Items with Negative Indexing

Negative indexes start from -1 for the last element and decrease towards the first element.

tup1 = ("a", "b", "c", "d")
tup2 = (25.50, True, -55, 1+2j)

print("Item at last index in tup1:", tup1[-1])
print("Item at third last index in tup2:", tup2[-3])

Output:

Item at last index in tup1: d
Item at third last index in tup2: True

Accessing Range of Tuple Items (Slicing)

Use slicing to access subsets of tuples: tuple[start:stop].

tup1 = ("a", "b", "c", "d")
tup2 = (1, 2, 3, 4, 5)

print("Items from index 1 to last in tup1:", tup1[1:])
print("Items from index 2 to second last in tup2:", tup2[2:-1])

Output:

Items from index 1 to last in tup1: ('b', 'c', 'd')
Items from index 2 to second last in tup2: (3, 4)

Accessing Sub Tuples

Fetch consecutive elements using slicing with start and stop indices:

tuple1 = ("a", "b", "c", "d")
tuple2 = (25.50, True, -55, 1+2j)

print("Items from index 1 to 2 in tuple1:", tuple1[1:3])
print("Items from index 0 to 1 in tuple2:", tuple2[0:2])

Output:

Items from index 1 to 2 in tuple1: ('b', 'c')
Items from index 0 to 1 in tuple2: (25.5, True)

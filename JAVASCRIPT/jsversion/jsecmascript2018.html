JavaScript - ECMAScript 2018

The ECMAScript 2018 version of JavaScript was released in 2018. ECMAScript 2017 introduced significant enhancement to the language. Two important features introduced in this version are asynchronous iteration for improved handling of asynchronous operations, and Promise.finally() to execute code regardless of promise resolution. This chapter will discuss all the new added features in ECMAScript 2018.

New Added Features in ECMAScript 2018

  • Asynchronous iteration
  • New features of the RegExp() Object
  • Promise.finally()
  • Rest object properties

JavaScript Asynchronous Iteration

You can also use the await keyword with the for loop to make asynchronous iterations.

For example, you are iterating multiple promises, and in each iteration, you need to stop the code execution until the current promise gets resolved or rejected.

Example

async function* gen_function() {
   for (let p = 0; p < 5; p++) {
      await new Promise(res => setTimeout(res, 500));
      yield p;
   }
}

async function test() {
   for await (const ele of gen_function()) {
      console.log("Returned element is:", ele);
   }
}
test();

Output:

  • Returned element is: 0
  • Returned element is: 1
  • Returned element is: 2
  • Returned element is: 3
  • Returned element is: 4

New features of the RegExp() object

In ECMAScript 2018, the following four new regular expression features were introduced:

  • Unicode Property Escapes (\p{...})
  • Lookbehind Assertions (?<=) and (?<!)
  • Named Capture Groups
  • s (dotAll) Flag

Unicode Property Escapes (\p{...})

Allows you to match Unicode characters using properties.

const regex = /\p{Letter}/u;
console.log(regex.test('Y')); // true
console.log(regex.test('6')); // false

Lookbehind Assertions (?<= and ?<!)

const lookBehind = /(?<=@)\w+/;
console.log(lookBehind.exec('abcd@tutorialspoint.com')[0]); // tutorialspoint

Named Capture Groups

const datePattern = /(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/;
const match = datePattern.exec('2023-08-22');
console.log(match.groups.year); // 2023

s (dotAll) Flag

const strRegex = /Hello.programmers/s;
console.log(strRegex.test('Hello\nprogrammers')); // true

JavaScript Promise finally()

You can use the finally() block with promises to execute particular code after the promise gets resolved or rejected.

const getData = new Promise((res, rej) => {
   setTimeout(() => {
      res("Promise resolved!");
   }, 1000);
});

getData
   .then(result => {
      console.log(result);
   })
   .finally(() => {
      console.log("In the finally block!");
   });

Output:

  • Promise resolved!
  • In the finally block!

JavaScript Rest Object Properties

The spread operator can be used while destructuring objects to collect remaining properties into a single variable.

const numbers = {
   num1: 40,
   num2: 50,
   num3: 80,
   num4: 90,
}

const { num1, ...nums } = numbers;
console.log(num1); // 40
console.log(nums); // { num2: 50, num3: 80, num4: 90 }

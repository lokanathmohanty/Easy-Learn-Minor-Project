Power BI: 100% Stacked Chart

The 100% stacked chart in Power BI is a visualization tool used to show the proportional contribution of different categories to a whole, using either horizontal bars or vertical columns, with each bar or column representing 100% length.

There are two main types:

  • 100% Stacked Bar Chart: Horizontal bars represent aggregated values, showing percentage contributions of different fields per category on the Y-axis.
  • 100% Stacked Column Chart: Vertical bars represent aggregated values proportionally stacked to 100%, categorizing data on the X-axis.

Creating a 100% Stacked Bar Chart

Steps to create a 100% stacked bar chart:

  • Load the dataset (e.g., Diabetes1.xlsx) in Power BI Desktop.
  • In Report View, select the 100% stacked bar chart visual.
  • Drag a categorical field like EmployeeName to the Y-axis.
  • Drag multiple numerical fields like bl_gl_level, BMI, and Stage_HbA1c to the X-axis.
  • Use the Small Multiples feature to subdivide the chart by an additional field (e.g., Age), producing smaller charts.
  • Enhance tooltips with additional fields (e.g., Age) for detailed information on hover.
  • Apply filter or drill-through features (e.g., by Gender) to view data for specific groups like Male or Female employees.
  • Customize appearance via the Format Visual panel, including toggling data labels.

Creating a 100% Stacked Column Chart

Steps to create a 100% stacked column chart:

  • Use the same dataset and switch to Report View.
  • Select the 100% stacked column chart visual.
  • Add a categorical field like EmployeeName to the X-axis.
  • Add multiple numerical fields such as Age, BP, BMI, and bl_gl_level to the Y-axis.
  • Use Small Multiples to split charts by a category field such as Diabetes.
  • Enhance the tooltips to show extra information like "Sum of Diabetes" when hovering on bars.
  • Use Drill Through to filter and explore data by specific categories (e.g., employees with heart disease or diabetes).
  • Customize the chart's visual elements in Format Visual menu (background, fonts, colors, etc.).

C++ do...while Loop (Exit-Controlled) 🔁

The **do...while loop** is an **exit-controlled** loop, meaning its condition is tested **after** the loop body has executed. Its defining characteristic is the guarantee that the statements within the loop will execute **at least once**, regardless of whether the condition is initially true or false.

Syntax and Mechanism

The loop starts with the do keyword, executes the body, and then checks the while condition at the end. Note the semicolon after the while(condition) part.

do {
   // Statement(s) to execute repeatedly
   // This code runs at least one time.
} while (condition); // Semicolon is required here!

The flow of control is:

  1. The code block after do executes.
  2. The condition is tested.
  3. If the condition is **true**, control jumps back to do to repeat the process.
  4. If the condition is **false**, the loop terminates.

Example Analysis (a starts at 10)

The example demonstrates the loop iterating while a is less than 20. The variable a is initialized, and then the do block executes immediately.

int a = 10;

do {
   cout << "value of a: " << a << endl;
   a = a + 1; // Crucial step to ensure termination
} while ( a < 20 ); // Condition checked after execution

The loop prints the value of a from 10 up to 19. When a becomes 20, the condition ($20 < 20$) fails, and the loop terminates. The output is identical to the for and while examples because the condition was true from the start:

value of a: 10
value of a: 11
...
value of a: 18
value of a: 19

If a were initialized to 20 or greater, the do...while loop would still execute once, printing the initial value, whereas a while loop would skip entirely.

JavaScript - Debouncing

What is Debouncing?

Debouncing is a programming technique that helps in limiting the function calls. It delays the execution of a function until a certain amount of time has passed since the last execution. This prevents unnecessary repeated calls and acts as a rate-limiter.

For example, when you press an elevator button multiple times, the elevator won’t come faster — only the first press matters. Similarly, debouncing ensures extra calls are ignored.

How to Implement Debouncing in JavaScript?

One common way to implement debouncing is using the setTimeout() method. The debounce function takes a callback and a delay. Every time the event occurs, it clears the previous timer and sets a new one. Only after the delay passes without new calls, the function executes.

Example

<html>
<body>
   <h2> JavaScript - Debouncing </h2>
   <div id="output"></div>
   <button id="btn">Debounce</button>

   <script>
      var output = document.getElementById("output");
      var btn = document.getElementById("btn");

      // Add event listener with debounce
      btn.addEventListener("click", debounce(function () {
         output.innerHTML = "Hello " + new Date().toLocaleTimeString();
      }, 2000));

      // Debounce function
      function debounce(func, wait) {
         var timeout;
         return function () {
            var context = this, args = arguments;
            clearTimeout(timeout);
            timeout = setTimeout(function () {
               func.apply(context, args);
            }, wait);
         };
      }
   </script>
</body>
</html>

Output: If you click the button multiple times within 2 seconds, only one function call will be executed after the delay.

Benefits of Debouncing

  • Improves performance by limiting function calls.
  • Reduces server load by minimizing requests.
  • Enhances user experience with smoother interactions.
  • Prevents unnecessary API calls and reduces cost.

Real-world Use Cases

  • Search boxes: Send requests only when the user pauses typing.
  • Infinite scroll / Lazy loading: Detect when users stop scrolling to fetch data efficiently.
  • Gaming controls: Prevent accidental multiple clicks or actions.

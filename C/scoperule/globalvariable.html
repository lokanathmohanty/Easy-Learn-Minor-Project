Global Variables in C

In C programming, global variables are defined outside all functions, usually at the top of the program. They hold their value throughout the lifetime of the program and can be accessed inside any function.

If a function modifies a global variable, the updated value is visible to all other functions.

Global variables can also be accessed across different files using the extern keyword.

Declaring Global Variables

Global variables are declared similarly to local variables, but they are placed outside any function block.

Syntax:

data_type variable_name;

Example: Simple Global Variable

Example

#include <stdio.h>

/* global variable declaration */
int g = 10;

int main() {
    int a;
    a = g * 2;
    printf("Value of a = %d, and g = %d\n", a, g);
    return 0;
}

Output:

Value of a = 20, and g = 10

Accessing and Updating Global Variables

Global variables can be accessed and updated from any function within the same file. Once updated, their new value is reflected across all functions.

Example

#include <stdio.h>

int g = 10;

int function1();
int function2();

int main() {
    printf("Value of Global variable g = %d\n", g);
    function1();
    printf("Updated value of Global variable g = %d\n", g);
    function2();
    printf("Updated value of Global variable g = %d\n", g);
    return 0;
}

int function1() {
    g = g + 10;
    printf("New value of g in function1(): %d\n", g);
    return 0;
}

int function2() {
    printf("The value of g in function2(): %d\n", g);
    g = g + 10;
    return 0;
}

Output:

Value of Global variable g = 10
New value of g in function1(): 20
Updated value of Global variable g = 20
The value of g in function2(): 20
Updated value of Global variable g = 30

Scope and Accessibility of Global Variables

Global variables can only be accessed in functions defined after their declaration. If a global variable is declared after main(), it cannot be used inside it, leading to a compilation error.

Example

#include <stdio.h>

/* global variable */
int x = 10;

int function1();

int main() {
    printf("value of Global variable x = %d y = %d\n", x, y);
    function1();
    return 0;
}

int y = 20;

int function1() {
    printf("Value of Global variable x = %d y = %d\n", x, y);
}

Output: Compilation Error

error: 'y' undeclared (first use in this function)

Accessing Global Variables Using extern

If a global and a local variable have the same name, use the extern keyword to access the global one within the local scope.

Example

#include <stdio.h>

/* Global variable */
int x = 50;

int main() {
    /* Local variable */
    int x = 10;
    {
        extern int x;
        printf("Value of global x is %d\n", x);
    }

    printf("Value of local x is %d\n", x);

    return 0;
}

Output:

Value of global x is 50
Value of local x is 10

Avoid Using Too Many Global Variables

While global variables make it easier to share data between functions, they come with drawbacks:

  • They remain in memory until the program ends.
  • They reduce modularity and can be accessed or modified from anywhere.
  • They make debugging, testing, and maintaining the program harder.
  • They pose potential security risks due to unrestricted access.

Therefore, limit their use and prefer local variables or parameter passing for better program structure.

Java Programming: Object-Oriented Concepts

Session: Java Constructors

What are Java Constructors?

Java **constructors** are special methods used to **initialize an object** immediately after it is created. They have the same name as their class and, unlike standard methods, **do not have an explicit return type** (not even void).

Constructors are typically used to assign initial values to **instance variables** or perform necessary setup procedures for a complete object.

Rules for Creating Constructors

  • The constructor's name **must** be the same as the class name.
  • Constructors **must not** have a return type.
  • Access modifiers (public, private, etc.) can be used to control visibility.
  • **Constructor Overloading** (multiple constructors with different parameters) is allowed.

The Default Constructor

If you **do not** define any constructor in a class, Java automatically provides a **default constructor**. This default constructor initializes all member variables to their default values (e.g., int to 0, object references to null).

However, **once you define any constructor**, the Java-provided default constructor is no longer available.

Types of Java Constructors

Java constructors are categorized primarily by the arguments they accept:

  1. **No-Args Constructor:** A constructor explicitly defined by the user that accepts no arguments. It's often used to set explicit default values.
  2. **Parameterized Constructor:** A constructor that accepts one or more arguments to initialize the instance variables with specific values provided during object creation.

Example: No-Args vs. Parameterized Constructor

This demonstrates how different constructors initialize the object's state:

class Student {
  String name;
  int age;

  // 1. No-args constructor (sets custom defaults)
  Student() {
    this.name = "Unknown";
    this.age = 0;
  }

  // 2. Parameterized constructor
  Student(String name, int age) {
    this.name = name;
    this.age = age;
  }
}

public class Main {
  public static void main(String[] args) {
    Student std1 = new Student();           // Invokes No-Args
    Student std2 = new Student("Paxton", 25); // Invokes Parameterized

    // Output will show different initial states
  }
}

Constructor Overloading

**Constructor Overloading** is the process of having multiple constructors in a single class, provided each one has a unique parameter list (different number or type of arguments). This allows objects to be initialized in different ways.

Example: Constructor Overloading

The Student class above demonstrates overloading by providing three constructors: one with no arguments, one with one argument (name), and one with two arguments (name and age).

public class Main {
  public static void main(String[] args) {
    Student std1 = new Student();              // Uses no-args
    Student std2 = new Student("Jordan");      // Uses 1-parameter
    Student std3 = new Student("Paxton", 25);  // Uses 2-parameters
    
    // Each object is initialized differently based on the call.
    // ... code to print details ...
  }
}

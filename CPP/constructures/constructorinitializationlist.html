C++ Constructor Initialization List ✨

A **Constructor Initialization List** is a mechanism used to initialize member variables of a class **before** the execution of the constructor's body. It is an efficient and sometimes compulsory way to ensure members are properly set up as soon as the object memory is allocated.

Syntax

The list is placed after the constructor's parameter list, separated by a colon (`:`). Each member to be initialized is followed by its initial value in parentheses, separated by commas.

ClassName(type1 param1, type2 param2) 
   : member1(param1), member2(param2) // Initialization List
{
   // Constructor body (runs after initialization list)
}

Why Use Initialization Lists?

  1. Efficiency (Direct Initialization): Using an initialization list performs **direct initialization**. If you use assignment (`member = param;`) inside the constructor body, the member is first initialized using its default constructor (if it's a class type like `std::string`), and then assigned a new value. The list skips this redundant two-step process.
  2. Mandatory Initialization (Special Cases): Initialization lists are **compulsory** for three main types of members:
    • **Const Member Variables:** Must be initialized immediately, not assigned later.
    • **Reference Members:** Must be bound to an object upon creation.
    • **Base Class Members:** Required to call a specific base class constructor.

Special Case: Base Class Initialization

When creating a derived class object, the base class's constructor must be called. This is done through the initialization list:

class Derived : public Base {
   public:
      // Calls Base(value) before Derived's body runs
      Derived(int value, int extra) : **Base(value)**, extraValue(extra) {}
   //...
};

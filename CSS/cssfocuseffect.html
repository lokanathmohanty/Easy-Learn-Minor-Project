CSS - Focus Effects

CSS focus effects are used to make form elements like input fields, buttons, and links more dynamic and engaging for users interacting with a webpage. They help users identify which element is currently active or selected, improving both usability and accessibility.

The :focus pseudo-class in CSS is applied to an element when it receives focus either by clicking on it or by navigating to it using the keyboard (commonly via the Tab key). Its purpose is to apply specific styles that indicate the current point of interaction.

What is Focus Pseudo-Class?

The :focus pseudo-class is a type of CSS selector that targets an element when it becomes active or focused. It is most commonly used with interactive elements such as:

  • Form input fields (text boxes, checkboxes, etc.)
  • Buttons
  • Links and navigation items
  • Custom interactive components with tabindex

Focus effects are vital for accessibility, as they allow users navigating via keyboard or screen readers to see which element they are currently interacting with.

CSS Focus Effect on Input Field

One of the most common uses of :focus is in form input fields. This helps users clearly see which field they are typing in.

Example: Highlighting a text input field by changing its border when focused.

<input type="text" placeholder="Enter your name">

When focused, the input box border might turn blue and expand slightly to make it stand out.

CSS Button With Focus Effect

Buttons can also be styled to provide visual feedback when they receive focus. This makes them more interactive and accessible for users who navigate without a mouse.

Example: A button changes its background color and size when focused.

<button>Focus on me!</button>

On focus, the button might enlarge slightly and change to a contrasting color.

CSS Border With Focus Effect

You can adjust border styles of elements on focus to visually highlight the active element. This is useful for form components or clickable div elements with tabindex enabled.

Example: A div element gets rounded corners when focused.

<div tabindex="0">Focus on me!</div>

CSS Box-Shadow With Focus Effect

Adding a box-shadow on focus gives depth to the element, making it stand out from the background.

Example: A box or button displays a grey shadow when focused.

<div tabindex="0">Focus on me!</div>

CSS Styling on Focusing

More advanced effects can also be applied on focus, such as animations or glowing effects. These effects not only highlight the active element but also enhance the overall user experience.

Example: A glowing button that activates its gradient glow when focused.

<button tabindex="0">FOCUS ON ME!</button>

Key Points to Remember

  • Always use :focus effects to improve accessibility, especially for keyboard users.
  • Ensure focus effects are visible enough for people with visual impairments.
  • Combine :hover and :focus for consistent user experience across mouse and keyboard interactions.
  • Do not remove focus outlines unless you replace them with an equally visible alternative.

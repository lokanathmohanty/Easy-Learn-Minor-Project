JavaScript - Changing HTML

Changing HTML with JavaScript

The HTML DOM allows us to change the HTML elements with JavaScript. You can customize or dynamically update the HTML elements using the various methods and properties. For example, you can change the content of the HTML element, remove or add new HTML elements to the web page, or change a particular element's attribute's value.

In JavaScript, we can access the HTML elements using id, attribute, tag name, class name, etc. After accessing the elements, we can change and manipulate them using properties such as innerHTML, outerHTML and methods such as replaceWith(), appendChild() etc.

Changing HTML Using innerHTML Property

The innerHTML property is used to replace the HTML content of the element or add new HTML elements as children.

Syntax

element.innerHTML = HTML_str;

Example

<div id="text">
   <p>One</p>
   <p>Two</p>
</div>
<button onclick="changeHTML()">Change HTML</button>

<script>
  function changeHTML() {
    let text = document.getElementById('text');
    text.innerHTML = `<div> JavaScript </div> <div> HTML </div> <div> CSS </div>`;
  }
</script>

Changing HTML Using outerHTML Property

The outerHTML property replaces the HTML of the element, including the tags.

Syntax

element.outerHTML = HTML_str;

Example

<div id="text">
   <p>Paragraph One</p>
   <p>Paragraph Two</p>
</div>
<button onclick="changeHTML()">Change HTML</button>

<script>
  function changeHTML() {
    let text = document.getElementById('text');
    text.outerHTML = `<img src="logo.png" alt="Logo">`;
  }
</script>

Replacing HTML Element Using replaceWith()

The replaceWith() method replaces a particular HTML element with a new element.

Syntax

old_element.replaceWith(new_element);

Example

<div id="text">Hello World!</div>
<button onclick="changeHTML()">Change HTML</button>

<script>
  function changeHTML() {
    const text = document.getElementById('text');
    const textNode = document.createElement('p');
    textNode.innerHTML = "Welcome to the Tutorial!";
    text.replaceWith(textNode);
  }
</script>

Changing Value of an Attribute

You can access the HTML element and set its attribute value in JavaScript.

Syntax

element.attribute = new_value;

Example

<img src="logo.png" id="logoImg" width="300px">
<button onclick="changeURL()">Change URL</button>

<script>
  function changeURL() {
    document.getElementById('logoImg').src = "new-logo.png";
  }
</script>

Adding a New Element Using appendChild()

The appendChild() method adds a new HTML child to a parent element.

Syntax

element.appendChild(new_element);

Example

<div id="fruits">
  <p>Banana</p>
  <p>Watermelon</p>
</div>
<button onclick="AddFruit()">Add Apple</button>

<script>
  function AddFruit() {
    const fruits = document.getElementById("fruits");
    const p = document.createElement("p");
    p.innerHTML = "Apple";
    fruits.appendChild(p);
  }
</script>

Removing a Child Element Using removeChild()

The removeChild() method removes a child element from its parent.

Syntax

element.removeChild(child_element);

Example

<div id="fruits">
  <p>Banana</p>
  <p>Watermelon</p>
  <p>Apple</p>
</div>
<button onclick="removeFruit()">Remove Apple</button>

<script>
  function removeFruit() {
    const fruits = document.getElementById("fruits");
    const apple = fruits.children[2];
    fruits.removeChild(apple);
  }
</script>

Using document.write()

The document.write() method replaces the entire content of the webpage.

Syntax

document.write(HTML);

Example

<button onclick="replaceContent()">Replace Content</button>

<script>
  function replaceContent() {
    document.write("Hello World");
  }
</script>

For more practice, you may try changing the first child element, last child element, and other attributes of HTML elements.

PHP - Handle CSV File

CSV (Comma Separated Values) is a plain text file format used by popular spreadsheet programs to export worksheet data. Each line in the file represents a row, with column values separated by commas.

Why Use CSV Files?

CSV files are widely used in PHP due to their simplicity, compatibility with tools like **Excel**, and smaller file size compared to other formats.

PHP Functions to Handle CSV Files

PHP provides two primary filesystem functions for CSV handling:

  • fgetcsv(): Reads a line from a file pointer and parses the CSV fields into an **indexed array**. 
    fgetcsv(resource $stream, ?int $length = null, string $separator = ",", string $enclosure = "\"", string $escape = "\\"): array|false
    The $stream parameter is a file handle opened in read mode ('r').
  • fputcsv(): Writes an **indexed array** as a row of comma-separated values to the file pointer. 
    fputcsv(resource $stream, array $fields, string $separator = ",", string $enclosure = "\"", string $escape = "\\", string $eol = "\n"): int|false
    The target file must be opened in write ('w') or append ('a') mode.

Example: Reading a CSV File (fgetcsv)

This example demonstrates using fgetcsv() to read a CSV file named 'hello.csv' and output the data in an HTML table. 

<?php
   $filename = 'hello.csv';
   $data = [];

   // Open the file in read mode
   $f = fopen($filename, 'r');

   if ($f === false) {
      die('Cannot open the file ' . $filename);
   }

   // Read each line and store the resulting array in $data
   while (($row = fgetcsv($f)) !== false) {
      $data[] = $row;
   }

   // Close the file
   fclose($f);

   // Render the data in an HTML table
   echo "<table border=1>";
   foreach ($data as $row) {
      echo "<tr>";
      foreach($row as $val) {
         // Output each field as a table cell
         echo "<td>$val</td>"; 
      }
      echo "</tr>";
   }
   echo "</table>";
?>

Example: Writing a CSV File (fputcsv)

This code uses fputcsv() to write a two-dimensional array into a new file named 'employee.csv'. The file is opened in write mode ('w'). 

<?php
   $data = [
      ["Name", "Email", "Post", "Salary"],
      ["Ravishankar", "ravi@gmail.com", "Manager", "40000"],
      ["Kavita", "kavita@hotmail.com", "Assistant", "25000"],
      ["Nandkumar", "nandu@example.com", "Programmer", "30000"],
   ];
   $filename = 'employee.csv';

   // Open csv file for writing. This will create the file if it doesn't exist.
   $f = fopen($filename, 'w');

   if ($f === false) {
      die('Error opening the file ' . $filename);
   }

   // Write each row array to the file
   foreach ($data as $row) {
      fputcsv($f, $row);
   }

   // Close the file
   fclose($f);
?>

Append and Delete Operations

To **append** new data without overwriting the file, open the file using the **append mode** ("a") with fopen() before using fputcsv().

To **delete** or **unlink** a CSV file, use the unlink() function, often preceded by file_exists() for safety. 

<?php
   $fileToDelete = "old_data.csv";

   if (file_exists($fileToDelete)) {
      // Delete the file
      unlink($fileToDelete); 
      echo "File deleted successfully!";
   } else {
      echo "File not found!";
   }
?>

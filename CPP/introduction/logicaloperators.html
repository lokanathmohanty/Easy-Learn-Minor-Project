C++ Logical Operators (&&, ||, !) 🧠

**Logical operators** in C++ are used to combine multiple conditions or negate a single condition. They perform logical operations on **Boolean values** (true/false) or expressions, where any **non-zero value is treated as true** and **zero is treated as false**.

Types of Logical Operators

1. Logical AND (&&)

The result is **true (non-zero)** only if **both** operands are true. If either operand is false (zero), the result is false.

It uses **short-circuit evaluation**: if the first operand is false, the second operand is not evaluated.

2. Logical OR (||)

The result is **true (non-zero)** if **at least one** of the operands is true. The result is false only if both operands are false.

It also uses **short-circuit evaluation**: if the first operand is true, the second operand is not evaluated.

3. Logical NOT (!)

This is a unary operator that negates the logical state of its operand. If the condition is true, it returns false (0), and if the condition is false, it returns true (1).

Example Walkthrough

The provided code demonstrates how the operators work with integer values:

int a = 5;  // Treated as true
int b = 20; // Treated as true

// Line 1: if(a && b) 
// (5 && 20) -> true && true = true
// Output: Line 1 - Condition is true

// Line 2: if(a || b)
// (5 || 20) -> true || true = true
// Output: Line 2 - Condition is true

// --- Change values ---
a = 0;  // Treated as false
b = 10; // Treated as true

// Line 3/4: if(a && b)
// (0 && 10) -> false && true = false
// Output: Line 4 - Condition is not true

// Line 5: if(!(a && b))
// !(0 && 10) -> !(false) = true
// Output: Line 5 - Condition is true

The final output is:

Line 1 - Condition is true
Line 2 - Condition is true
Line 4 - Condition is not true
Line 5 - Condition is true

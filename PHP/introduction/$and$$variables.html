PHP Variables: Single (`$`) vs. Dynamic (`$$`)

PHP is unique in its use of variables, which always begin with a **single dollar sign (`$`)**. The **double dollar sign (`$$`)** introduces a feature called **dynamic variables** or **variable variables**, where the value of one variable is used as the name of a second variable.

The `$ Variable` (Normal Variable)

A normal PHP variable, `$variable`, stores a value directly (e.g., number, string, array).

<?php
   $name = "Akshita"; // The variable name is 'name'
   echo $name; // Output: Akshita
?>

The `$$ Variable` (Dynamic Variable)

A dynamic variable uses the **value** stored in the first variable as the **name** for the second variable.

How it Works:

  1. **`$a = 'good';`** $\rightarrow$ Creates a variable named `$a` with the string value `"good"`.
  2. **`$$a = 'morning';`** $\rightarrow$ PHP reads `$$a` as `$($a)`. Since `$a`'s value is `"good"`, this statement is equivalent to declaring **`$good = 'morning';`**.

Example: Dynamic Variable Usage

<?php
   $x = "foo";
   $$x = "bar"; // Equivalent to $foo = "bar";
   echo 'Value of x = ' . $x . "\n";
   echo 'Value of $$x = ' . $$x . "\n";
   echo 'Value of foo = ' . $foo;
?>

Output:
Value of x = foo
Value of $$x = bar
Value of foo = bar

Multiple `$` Symbols

The use of the dollar sign is not restricted to two. Each preceding `$` resolves the value of the variable to its right as the name for the next variable.

Given: `$Hello = "World";` and `$a = "Hello";`
* `$a` $\rightarrow$ `"Hello"` * `$$a` $\rightarrow$ `$($a)` $\rightarrow$ `$Hello` $\rightarrow$ `"World"`

Output for a chain of variables:
$$$$$a= a

Handling Ambiguity with Arrays

When using dynamic variables with arrays, curly braces (`{}`) must be used to clarify the parser's intent:

  • **`${$a[1]}`:** Treats the element `$a[1]` as a normal string, and uses its **value** as the dynamic variable name.
  • **`${$a}[1]`:** Treats `$$a` as the dynamic variable name, and then accesses the **index `[1]`** of that resulting variable (which must be an array).

**Important Restrictions:** This dynamic variable technique **cannot** be used with PHP's super-global arrays (e.g., `$_GET`, `$_POST`) within functions or class methods. Also, the special class variable `$this` cannot be referenced dynamically.

Java Logical Operators - Flashcards

Flashcard 1

Question: What does the logical AND operator (&&) do in Java?

Answer: Returns true if both operands are true, otherwise false.

Flashcard 2

Question: What is the result of the expression (A || B) if A is true and B is false?

Answer: True, because logical OR (||) returns true if at least one operand is true.

Flashcard 3

Question: What does the logical NOT operator (!) do to a boolean value?

Answer: It reverses the logical state; !A is true if A is false, and false if A is true.

Flashcard 4

Question: What will be the result of (true && false) in Java?

Answer: False

Flashcard 5

Question: What will be the result of (true || false) in Java?

Answer: True

Flashcard 6

Question: What is the result of !(true && false) in Java?

Answer: True

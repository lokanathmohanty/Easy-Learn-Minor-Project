PHP: Form Handling

**Form Handling** is the process where a PHP script receives, validates, and processes data submitted by a user through an HTML form. This is crucial for creating interactive and dynamic web applications.

HTML Form Structure and Attributes

An HTML form is defined by the <form> element and its attributes, which dictate how data is transmitted:

  • action: Specifies the URL (the PHP script) that will process the form submission. Using <?php echo $_SERVER['PHP_SELF'];?> submits the data back to the same file.
  • method: Defines the HTTP method used for submission. The primary values are:
    • POST: Sends data in the HTTP request body. Preferred for sensitive data (like passwords) or large amounts of data, as it's not visible in the URL.
    • GET (default): Appends data to the `action` URL as query parameters. Suitable for non-sensitive data or search forms.
  • enctype: Defines how form data is encoded. Must be set to multipart/form-data if the form includes file uploads (<input type="file">).

Accessing Form Data in PHP

PHP uses two primary **superglobal arrays** to access submitted form data. The choice depends on the form's method attribute:

  • **$_POST**: An associative array used to collect data submitted via the **POST** method.
  • **$_GET**: An associative array used to collect data submitted via the **GET** method.

In both cases, data is accessed using the **name attribute** of the HTML form control as the array key (e.g., $_POST["username"]).

Form Validation and Security

Before using submitted data, it is critical for security and reliability to:

  1. Check Submission: Use if ($_SERVER["REQUEST_METHOD"] == "POST") to ensure the script only processes data after a form submission.
  2. Clean Data: Use functions like **htmlspecialchars()** to convert special characters to HTML entities, preventing Cross-Site Scripting (XSS) attacks if the data is echoed back to the user.

Example Session: Retrieving POST Data

This script handles a submission, retrieves the name and email using $_POST, and echoes the sanitized results.


<?php
   $name = $email = "";

   if ($_SERVER["REQUEST_METHOD"] == "POST") {
      // 1. Retrieve and sanitize the data
      $name = htmlspecialchars($_POST["name"]);
      $email = htmlspecialchars($_POST["email"]);

      echo "<h2>Thank you!</h2>";
      echo "Name Received: " . $name . "<br>";
      echo "Email Received: " . $email . "<br>";
   }
?>

   <input type = "submit" value = "Send Data">

C# Anonymous Methods: Inline Code Blocks 👻

What are Anonymous Methods?

An **anonymous method** is a block of code that is used as a **delegate parameter** and is defined *inline* where the delegate instance is created. Crucially, it is a method **without a name**—it only has a body and a parameter list (if any).

Anonymous methods were introduced in C# to provide a simple way to pass a code block to a delegate without needing to write a separate, named method.

Anonymous Method Declaration

Anonymous methods are declared by assigning the code block directly to a delegate instance using the **`delegate`** keyword.

Syntax:

DelegateType delegateInstance = delegate([parameters]) {
   // body of the method 
   // return type is inferred from the return statement (if present)
};

Example:

delegate void NumberChanger(int n); // Delegate signature
...
NumberChanger nc = delegate(int x) { // x is the parameter
   Console.WriteLine("Anonymous Method: {0}", x);
};

nc(10); // Calling the delegate executes the anonymous code block

Usage and Evolution (Lambda Expressions)

Usage with Delegates

Anonymous methods can be used with both custom delegates (like `NumberChanger`) and built-in generic delegates like **`Action`** (returns `void`) and **`Func`** (returns a value).

// Anonymous method used with the built-in Action delegate
Action<string> greet = delegate(string name) {
   Console.WriteLine("Hello, " + name + "!");
};

Conversion to Lambda Expressions ➡️

In modern C# (version 3.0 and later), anonymous methods have been largely superseded by the more concise **Lambda Expressions**. Lambda expressions use the **`=>`** operator to achieve the same result with significantly less boilerplate code.

Syntax Code Example
Anonymous Method 
delegate(string name) { Console.WriteLine(name); }
Lambda Expression 
(name) => { Console.WriteLine(name); }

PHP Date & Time Functions

PHP provides a rich set of built-in functions and the **DateTime class** for handling and manipulating date and time information. Internally, date and time data is often managed using the **UNIX timestamp**, which is the number of seconds elapsed since the **UNIX epoch** (midnight GMT on January 1, 1970).

Getting and Converting Time Stamps

1. `time()`: Getting the Current Time Stamp

The `time()` function returns the current UNIX timestamp as an integer.

print time(); $\rightarrow$ 1739750400 (Example output)

2. `getdate()`: Converting Timestamp to Associative Array

The `getdate()` function accepts an optional timestamp (defaults to current time) and returns an **associative array** containing detailed information about the date (e.g., seconds, minutes, hours, day of the month (`mday`), day of the week (`weekday`), month name, and year).

$date_array = getdate();
print $date_array['mday']; $\rightarrow$ 8 (Example output for Nov 8)

Formatting Dates and Times: `date()`

The **`date()`** function is the primary tool for converting a timestamp into a human-readable, formatted string. It takes a **format string** as its first argument and an optional timestamp as the second.

date(string $format, ?int $timestamp = null): string

Common Format Codes:

  • **Date:** **`d`** (Day with leading zero), **`m`** (Month with leading zero), **`Y`** (Four-digit year), **`j`** (Day without leading zero).
  • **Day/Month Names:** **`D`** (Three-letter day, e.g., Thu), **`l`** (Full day name, e.g., Thursday), **`F`** (Full month name).
  • **Time:** **`H`** (24-hour format), **`h`** (12-hour format), **`i`** (Minutes), **`s`** (Seconds), **`a`** (am/pm lowercase), **`A`** (AM/PM uppercase).
date("l, F j, Y"); $\rightarrow$ Monday, February 17, 2025 (Example)

Converting Strings to Time Stamps: `strtotime()`

The **`strtotime()`** function converts a string representation of a date and time into a UNIX timestamp. This is extremely useful for date manipulation and calculations.

$date = "2025-02-17";
$timestamp = strtotime($date); $\rightarrow$ 1739750400

strtotime() is highly flexible and can parse many human-readable formats, including relative formats like `"tomorrow"`, `"next Monday"`, or `"+1 week"`.

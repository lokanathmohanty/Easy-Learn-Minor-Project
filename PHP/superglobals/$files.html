PHP `$_FILES` Superglobal for File Uploads

The **`$_FILES`** is a **superglobal associative array** in PHP used to collect and manage files uploaded to the server via an HTTP POST request. It contains critical metadata about the file, its temporary location, and any upload errors.

Client-Side Requirements for File Upload ⚙️

For `$_FILES` to be populated, the HTML form must meet three specific requirements:

  1. The form method must be **`POST`**: method="POST"
  2. The encoding type must be **`multipart/form-data`**: enctype="multipart/form-data"
  3. It must contain an input field of type **`file`**: <input type="file" name="file">

Structure and Properties of `$_FILES`

`$_FILES` is a two-dimensional associative array. The first key is the `name` attribute of the HTML input field (e.g., `$_FILES['file']`), and the second keys are the file properties:

  • **`['name']`**: The **original filename** on the user's computer (e.g., `image.jpg`).
  • **`['type']`**: The file's MIME type (e.g., `image/jpeg`). *Note: This is supplied by the browser and should not be trusted for validation.*
  • **`['size']`**: The size of the file in **bytes**.
  • **`['tmp_name']`**: The **full path** to the temporary file stored on the server (e.g., `/tmp/phpXyZ.tmp`). This is the file you must move to its permanent location.
  • **`['error']`**: The error code associated with the upload (0 means success).

Handling Uploaded Files

The file is initially stored in the temporary location (`tmp_name`). To make the file permanent, you must use the PHP function **`move_uploaded_file()`** to move it from the temporary location to a secure, permanent directory on the server.

File Upload Error Codes

The `$_FILES['file']['error']` property provides a numeric code indicating the success or failure of the upload process.

Code Constant Description
**0** `UPLOAD_ERR_OK` The file was uploaded successfully.
1 `UPLOAD_ERR_INI_SIZE` File exceeds the `upload_max_filesize` setting in `php.ini`.
4 `UPLOAD_ERR_NO_FILE` No file was uploaded (user submitted the form without selecting a file).

Multiple File Uploads

To allow a user to select multiple files, you must append `[]` to the input element's name, turning the property into an array:

*HTML:* <input type="file" **name="files[]"**>

*PHP Access:* You must loop through the nested arrays (e.g., `$_FILES["files"]["name"]`) to process each uploaded file individually.

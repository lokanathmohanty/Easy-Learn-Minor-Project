JavaScript — Functions

Introduction

A function in JavaScript is a group of reusable code that can be called anywhere in your program. Functions eliminate the need to rewrite code repeatedly and help in writing modular and manageable code.

JavaScript provides built-in functions like alert() and document.write(), but also allows you to create your own functions.

Function Definition

The most common way to define a function is by using the function keyword, followed by:

  • A unique function name
  • A list of parameters (optional)
  • A block of code inside curly braces {}
function functionName(parameter-list) {
  // statements
}

Example — a simple function definition:

function sayHello() {
  alert("Hello there!");
}

Function Expression

Functions can also be defined as expressions and stored in variables. These are called function expressions. 

const myFunc = function (x, y) {
  return x + y;
};

Function expressions can be anonymous (without a name) and are often used when passing functions as values.

Calling a Function

To execute a function, simply use its name followed by parentheses (). If parameters are required, provide them inside the parentheses. 

function sayHello() {
  alert("Hello there!");
}

sayHello(); // calling the function

Example with a button click:

<input type="button" onclick="sayHello()" value="Say Hello">

Function Parameters

Functions can accept parameters, allowing values to be passed into the function during the call. 

function sayHello(name, age) {
  document.write(name + " is " + age + " years old.");
}

sayHello("Zara", 7);

The return Statement

Functions may return values using the return statement. If omitted, the function returns undefined. 

function concatenate(first, last) {
  return first + last;
}

function secondFunction() {
  const result = concatenate("Zara ", "Ali");
  alert(result);
}

Functions as Variable Values

Functions in JavaScript are first-class citizens. They can be stored in variables, passed as arguments, or returned from other functions. 

const myFunc = function() {
  return "Hello ";
};

document.getElementById("output").innerHTML = myFunc() + "Users.";

Key Points

  • Functions can be declared or defined as expressions.
  • Parameters allow passing values into functions.
  • return allows sending results back to the caller.
  • Functions are first-class values in JavaScript.

Practice Tasks

  • Create a function that calculates the square of a number.
  • Write a function that takes two numbers and returns their product.
  • Define a function expression that returns today’s date as a string.

Summary

JavaScript functions allow modular, reusable, and organized code. They can be declared, expressed, or used as variable values. Functions may accept parameters, return values, and even be passed around like any other variable.

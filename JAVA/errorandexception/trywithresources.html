Java Try with Resources

The try-with-resources statement in Java is designed for automatic resource management. It ensures that resources such as files, streams, and connections are properly closed after their use, reducing the risk of resource leaks.

Syntax Overview

In try-with-resources, each resource is declared within the parentheses of the try statement. These resources are automatically closed at the end of the block by the Java runtime.

try (ResourceType resource = new ResourceType()) {
    // use resource
} catch (ExceptionType e) {
    // exception handling
}

Example: Reading From a File

import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class TryWithResourcesExample {
    public static void main(String[] args) {
        try (BufferedReader reader = new BufferedReader(new FileReader("sample.txt"))) {
            String line = reader.readLine();
            System.out.println("File content: " + line);
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}

This code demonstrates reading from a file using try-with-resources, ensuring the BufferedReader is always closed properly.

Multiple Resources Example

import java.io.*;

public class CopyFileExample {
    public static void main(String[] args) {
        try (
            FileReader in = new FileReader("input.txt");
            FileWriter out = new FileWriter("output.txt")
        ) {
            int c;
            while ((c = in.read()) != -1) {
                out.write(c);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}

When multiple resources are declared, each one is closed in reverse order after the try block completes or if an exception occurs.

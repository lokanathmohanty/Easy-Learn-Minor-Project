JavaScript - Page Printing

Many times, you may want to place a button on your webpage to print its content using an actual printer. JavaScript provides this functionality through the window.print() method.

The window.print() method prints the current web page when executed. You can call this function directly with the onclick event, as shown below:

Example 1: Simple Print Button

<html>
<head>      
  <script type="text/javascript">
    <!--
    //-->
  </script>
</head>   
<body>      
  <form>
    <input type="button" value="Print" onclick="window.print()" />
  </form>   
</body>
</html>

Although this works, it is not always recommended. A printer-friendly page usually removes images, ads, and unnecessary graphics, keeping only the essential text.

Making a Page Printer Friendly

  • Create a separate copy of the page without unnecessary content and link to it from the main page.
  • Mark printable text using comments like <!-- PRINT STARTS HERE --> and <!-- PRINT ENDS HERE -->, then use a backend script (like PERL) to filter only the printable content.

Example 2: Using a Custom Print Function

You can attach a printpage() function to a button to trigger printing:

<html>
<head>
  <title>Print Page</title>
  <script>
    function printpage() {
      window.print();
    }
  </script>
</head>
<body>
  <h2>This is a sample page to print</h2>
  <button onclick="printpage()">Print Page</button>
</body>
</html>

When the user clicks the button, the browser's print dialog will open, allowing them to print the page as displayed.

Important Notes About window.print()

  • It only prints the content of the current window.
  • Hidden elements (e.g., with display: none) will not be printed.
  • Dynamically loaded content (e.g., images added after load) may not appear in print.
  • For complex printouts (tables, forms, multiple pages), consider generating a PDF or using a third-party printing library.

How to Print Without JavaScript?

If no print button is available, you can always use the browser's built-in menu:

File → Print → OK

Simple Arithmetic

You could use arithmetic operators + - * / directly between NumPy arrays, but this section discusses an extension of the same where we have functions that can take any array-like objects (e.g. lists, tuples) and perform arithmetic conditionally.

Arithmetic Conditionally: means that we can define conditions where the arithmetic operation should happen. All arithmetic functions take a where parameter specifying that condition.

Addition

The add() function sums the content of two arrays and returns the results in a new array.

Example

import numpy as np

arr1 = np.array([10, 11, 12, 13, 14, 15])
arr2 = np.array([20, 21, 22, 23, 24, 25])

newarr = np.add(arr1, arr2)

print(newarr)

Returns: [30 32 34 36 38 40]

Subtraction

The subtract() function subtracts values from one array by another and returns the result in a new array.

Example

import numpy as np

arr1 = np.array([10, 20, 30, 40, 50, 60])
arr2 = np.array([20, 21, 22, 23, 24, 25])

newarr = np.subtract(arr1, arr2)

print(newarr)

Returns: [-10 -1 8 17 26 35]

Multiplication

The multiply() function multiplies values from one array by another and returns the result in a new array.

Example

import numpy as np

arr1 = np.array([10, 20, 30, 40, 50, 60])
arr2 = np.array([20, 21, 22, 23, 24, 25])

newarr = np.multiply(arr1, arr2)

print(newarr)

Returns: [200 420 660 920 1200 1500]

Division

The divide() function divides values from one array by another and returns the result in a new array.

Example

import numpy as np

arr1 = np.array([10, 20, 30, 40, 50, 60])
arr2 = np.array([3, 5, 10, 8, 2, 33])

newarr = np.divide(arr1, arr2)

print(newarr)

Returns: [3.33333333 4. 3. 5. 25. 1.81818182]

Power

The power() function raises values from the first array to the powers of values from the second array and returns the results.

Example

import numpy as np

arr1 = np.array([10, 20, 30, 40, 50, 60])
arr2 = np.array([3, 5, 6, 8, 2, 33])

newarr = np.power(arr1, arr2)

print(newarr)

Returns: [1000 3200000 729000000 6553600000000 2500 0]

Remainder

Both mod() and remainder() functions return the remainder when dividing the first array by the second.

Example: Using mod()

import numpy as np

arr1 = np.array([10, 20, 30, 40, 50, 60])
arr2 = np.array([3, 7, 9, 8, 2, 33])

newarr = np.mod(arr1, arr2)

print(newarr)

Returns: [1 6 3 0 0 27]

Example: Using remainder()

import numpy as np

arr1 = np.array([10, 20, 30, 40, 50, 60])
arr2 = np.array([3, 7, 9, 8, 2, 33])

newarr = np.remainder(arr1, arr2)

print(newarr)

Quotient and Mod

The divmod() function returns both quotient and remainder arrays.

Example

import numpy as np

arr1 = np.array([10, 20, 30, 40, 50, 60])
arr2 = np.array([3, 7, 9, 8, 2, 33])

newarr = np.divmod(arr1, arr2)

print(newarr)

Returns:
(array([3, 2, 3, 5, 25, 1]), array([1, 6, 3, 0, 0, 27]))

The first array contains quotients, the second array contains remainders.

Absolute Values

Both absolute() and abs() return element-wise absolute values, but absolute() is preferred to avoid confusion with Python's built-in abs().

Example

import numpy as np

arr = np.array([-1, -2, 1, 2, 3, -4])

newarr = np.absolute(arr)

print(newarr)

Returns: [1 2 1 2 3 4]

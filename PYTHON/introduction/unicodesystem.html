Python - Unicode System

What is Unicode System?

Python uses the Unicode standard to represent characters, which allows applications to work with multiple languages such as English, French, Japanese, Hebrew, or Hindi. A character is the smallest component of text (e.g., 'A', 'B', 'C'). Unicode assigns each character a unique code point (from 0 to 0x10FFFF).

Character Encoding

Unicode code points are represented in memory as code units, which are mapped to bytes. The process of converting characters into bytes is called encoding, while converting bytes back into characters is called decoding.

Python supports the following common encodings:

  • UTF-8
  • UTF-16
  • UTF-32

Python's Unicode Support

Since Python 3, all strings are Unicode by default. Any string created with quotes (', ", ''', """) is stored as Unicode. Python source code files are encoded in UTF-8 by default.

Strings can contain either literal characters or Unicode escape sequences (e.g., "¾" or "\u00BE").

Example

var = "3/4"
print(var)

var = "\u00BE"
print(var)

Output:

3/4
¾

Example - Storing Digits Using Unicode

var = "\u0031\u0030"
print(var)

Output:

10

Encoding and Decoding

- encode() → Converts string (Unicode) into bytes.
- decode() → Converts bytes back into string (Unicode).

Example - Encode and Decode ASCII String

string = "Hello"
tobytes = string.encode('utf-8')
print(tobytes)

string = tobytes.decode('utf-8')
print(string)

Output:

b'Hello'
Hello

Example - Using Rupee Symbol

string = "\u20B9"
print(string)

tobytes = string.encode('utf-8')
print(tobytes)

string = tobytes.decode('utf-8')
print(string)

Output:

₹
b'\xe2\x82\xb9'
₹

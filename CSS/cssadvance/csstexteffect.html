CSS - Text Effects

Introduction

CSS text effects are used to enhance the presentation of text by controlling overflow, wrapping, line-breaking, and writing directions. These properties help ensure that text remains readable and properly formatted across different devices and screen sizes.

The most commonly used text effect properties in CSS are:

  • text-overflow: Controls how text is displayed when it overflows its container.
  • word-wrap: Allows long words to break and wrap onto the next line.
  • word-break: Defines how words should break when reaching the container edge.
  • writing-mode: Defines the horizontal or vertical direction of text flow.

Text Overflow

The text-overflow property specifies how overflowing text should be handled. Common values include clip, which cuts off the text, and ellipsis, which adds "..." to indicate more content.

Example - Text Overflow

A paragraph with text-overflow: clip; will hide the extra text beyond its container. A paragraph with text-overflow: ellipsis; will show an ellipsis (...) instead of the extra text.

Word Wrap

The word-wrap property allows long words to be wrapped onto the next line to prevent overflowing. It supports two values:

  • normal: Default, long words will overflow.
  • break-word: Forces words to break to fit within the container.

Example - Word Wrap

Using word-wrap: break-word; ensures that long words such as ThisIsAVeryLongWordThatWillBreak are wrapped properly within the container.

Word Break

The word-break property specifies how words should be broken at line breaks. It is particularly useful for handling long words or URLs.

  • normal: Uses the default line break rules.
  • break-all: Breaks words at arbitrary points.
  • keep-all: Prevents word breaks for non-CJK text.

Example - Word Break

With word-break: break-all;, a word like This-paragraph-contains-some-text can break in the middle. With keep-all;, it will only break at natural break points.

Writing Mode

The writing-mode property defines the direction of text flow. It is commonly used to support vertical languages or to create rotated text.

  • horizontal-tb: Default, left-to-right, top-to-bottom.
  • vertical-rl: Vertical writing from top-to-bottom, right-to-left.
  • vertical-lr: Vertical writing from top-to-bottom, left-to-right.

Example - Writing Mode

A paragraph with writing-mode: vertical-rl; will display text stacked vertically, starting from the right side. With vertical-lr;, it will start from the left side.

Summary of CSS Text Effect Properties

  • text-overflow: Manages overflowing text (clip or ellipsis).
  • word-wrap: Breaks long words to fit the container.
  • word-break: Controls how words break at line endings.
  • writing-mode: Sets horizontal or vertical text flow.
  • text-justify: Controls justification when text-align is set to justify.

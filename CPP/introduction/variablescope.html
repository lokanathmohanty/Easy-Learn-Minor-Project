Variable Scope in C++: Local and Global

Scope refers to the region of a program where a variable is accessible. In C++, variables are primarily categorized into two main scopes based on where they're declared:

  • **Local Variables** (Inside a function or block)
  • **Global Variables** (Outside all functions)
  • Formal Parameters (In a function's parameter definition, which act like local variables)

Local Variables 🏠

**Local variables** are declared **inside a function or a block of code** (e.g., inside main() or an if statement). They can only be used by statements within that specific function or block. They are **not known** outside their own scope.

  • Initialization: Local variables are **not initialized** by the system and contain garbage values until explicitly initialized by the programmer.
  • Life-time: They exist only while the function/block is executing.

Example: In the following code, a, b, and c are local to the main function.

int main () {
   int a, b; // Local variable declaration
   // ...
   return 0;
}

Global Variables 🌎

**Global variables** are defined **outside of all functions**, usually at the beginning of the program file. They are accessible by **any function** in the program after their declaration.

  • Initialization: Global variables are **automatically initialized** to zero (or NULL for pointers, '\0' for char, etc.) by the system if they aren't explicitly initialized.
  • Life-time: They hold their value throughout the entire life-time of the program.

Example:

int g; // Global variable declaration

int main () {
   // g can be accessed and modified here
   g = 30; 
   return 0;
}

Scope Resolution Operator (SRO) ::

If a program has a **local variable and a global variable with the same name**, the **local variable takes precedence** within its function/block. This is known as **shadowing**.

To explicitly access the global variable when it is shadowed by a local one, you must use the **Scope Resolution Operator (SRO)**, ::, placed before the variable's name.

Example:

int g = 20; // Global g

int main () {
   int g = 10; // Local g
   
   cout << g;     // Prints Local value: 10
   cout << ::g;  // Prints Global value: 20
   return 0;
}

Next.js Command Line Interface (CLI) 💻

Next.js CLI Syntax

The Next.js **Command Line Interface (CLI)** is the built-in tool used to manage the lifecycle of your application (development, building, and starting). Its general syntax is composed of a command and optional flags or arguments (options):

npx next [command] [options]
  • `npx next`: Executes the Next.js CLI tool.
  • `[command]`: The action to perform (e.g., `dev`, `build`).
  • `[options]`: Arguments that modify the command's behavior (e.g., `-p 4000`).

Next.js CLI Commands

Here are the essential commands used in the Next.js CLI:

Command Description
`dev` Starts the application in **development mode**, featuring **Hot Module Reloading (HMR)** and detailed error reporting.
`build` Creates an **optimized production build** (minified code, optimized routing, etc.) in the `.next` folder.
`start` Starts the Next.js server in **production mode** to serve the previously built application (requires running `next build` first).
`lint` Runs **ESLint** across the configured source directories of the application, helping to identify code quality and style issues.
`info` Prints relevant system information (Node.js version, Next.js version, OS, etc.), useful for debugging and reporting bugs.
`telemetry` Used to enable or disable the sharing of anonymous general usage data with Next.js.

CLI Options and Examples

Changing the Default Port

By default, Next.js runs on port **3000**. To run it on a specific port, use the `-p` (or `--port`) option with the `dev` command:

npx next dev -p 4000

The application will now be accessible at `http://localhost:4000/`.

Using HTTPS in Development Mode

To enable a secure connection (HTTPS) for local development—essential for testing features like service workers or certain OAuth flows—use the `--experimental-https` flag:

npx next dev --experimental-https

This command automatically uses tools like `mkcert` to generate a self-signed certificate, making the application available over `https://localhost:3000/` (or the specified port).

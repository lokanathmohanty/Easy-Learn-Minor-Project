Java 11 - Major New Features Summary (LTS Release)

Overview and LTS Status 🛡️

**Java 11**, released in **September 2018**, is the first **LTS (Long-Term Support)** feature release since Java 8, making it a critical version for enterprise deployments. Following the 6-month release cadence established by Java 10, Java 11 focused on stabilizing new features and removing legacy components.

Key API and Language Enhancements

1. HTTP Client API Standardized (JEP 321)

The new, modern HTTP Client API (for HTTP/2, WebSockets, etc.) introduced in Java 9 as an incubator module is now officially part of the Java SE standard. It provides a fluent, synchronous, and asynchronous way to handle HTTP requests and responses.

2. Launch Single-File Source-Code Programs (JEP 330)

This allows running a single Java source code file directly from the command line using the java launcher **without explicit compilation** using javac. This greatly simplifies learning, testing, and scripting for simple applications.

// Command Line Usage
$ java HelloWorld.java

3. Local-Variable Syntax for Lambda Parameters (JEP 323)

Enables the use of the **var** keyword (Local Variable Type Inference from Java 10) in **lambda expression parameters**. This is particularly useful when applying annotations to the parameters, as the type must be explicitly written out otherwise.

// Using 'var' in a lambda parameter for annotation
(var list) -> list.add("item")

// Annotated parameter
(@NonNull var list) -> list.add("item")

Core Library Updates

String API Enhancements

Several useful utility methods were added to the **String** class:

  • isBlank(): Returns true if the string is empty or contains only whitespace.
  • lines(): Returns a Stream of lines extracted from the string.
  • repeat(int count): Returns a string whose value is the concatenation of the original string repeated count times.
  • strip(), stripLeading(), stripTrailing(): Improved methods for removing whitespace (based on Unicode character properties) compared to the older trim().

New File I/O Methods

Simplifies reading and writing entire files as a single string:

  • Files.readString(Path path): Reads all content from a file into a string.
  • Files.writeString(Path path, CharSequence content): Writes a string to a file, creating or overwriting it.

Other API Updates

  • Optional.isEmpty(): A straightforward method that returns the inverse of isPresent().
  • Collection.toArray(IntFunction): A new default method that allows array creation with the specified size and type, simplifying collection-to-array conversions.
  • Predicate.not(Predicate): A static method that negates an existing Predicate, commonly used in stream filter operations (e.g., .filter(Predicate.not(String::isBlank))).

Performance and Garbage Collectors

Java 11 introduced two experimental and one no-op garbage collector option, giving users more flexibility for low-latency or specific testing environments:

  • ZGC (JEP 333): A **Scalable Low-Latency Garbage Collector** designed for systems with massive heaps (multiterabytes) where pause times must be minimal (less than 10 milliseconds).
  • Epsilon GC (JEP 318): A **No-Op Garbage Collector** that handles allocation but implements no actual memory reclamation. Useful for performance testing where GC overhead needs to be isolated, or for extremely short-lived jobs.

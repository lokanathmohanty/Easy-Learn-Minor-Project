Python - Immutable Data Structures

Immutable data structures in Python are those that cannot be changed once created. Any modification results in the creation of a new instance, ensuring data stability and making programs easier to maintain and less prone to bugs.

Data structures organize, process, and store data efficiently; immutable ones ensure values remain constant throughout program execution.

Common Immutable Data Structures

  • Tuples: Ordered, fixed collections of items. Defined with parentheses ().
  • Strings: Sequences of characters enclosed in single, double, or triple quotes.
  • Frozensets: Immutable versions of sets with no modification allowed after creation.
  • Named Tuples: Subclass of tuples with named fields to improve readability. They are immutable.

Tuples

# Creating tuples
empty_tuple = ()
single_element_tuple = (5,)  # Note trailing comma
multi_element_tuple = (1, 2, 'Tutorialspoint', 3.14)
nested_tuple = (1, (2, 3), 'Learning')

print("Single element tuple:", single_element_tuple)
print("Multi elements tuple:", multi_element_tuple)
print("Nested tuple:", nested_tuple)

# Immutability demonstration
my_tuple = (1, 2, 3, 'hello')
try:
    my_tuple[0] = 10
except TypeError as e:
    print(f"Error: {e}")
print("Original tuple:", my_tuple)

Output:

Single element tuple: (5,)
Multi elements tuple: (1, 2, 'Tutorialspoint', 3.14)
Nested tuple: (1, (2, 3), 'Learning')
Error: 'tuple' object does not support item assignment
Original tuple: (1, 2, 3, 'hello')

Strings

# Creating strings
single_quoted = 'Hello, Welcome to Tutorialspoint'
double_quoted = "Python Programming"
multi_line = """This is a 
multi-line 
string"""

print(single_quoted)
print(double_quoted)
print(multi_line)

# Immutability demonstration
my_str = "Hello"
modified_str = my_str + " Learners"
print(modified_str)

try:
    my_str[0] = 'h'
except TypeError as e:
    print(f"Error: {e}")

Output:

Hello, Welcome to Tutorialspoint
Python Programming
This is a
multi-line
string
Hello Learners
Error: 'str' object does not support item assignment

Frozensets

# Creating a frozenset
fset = frozenset([1, 2, 3, 4])
print(fset)

# Immutability demonstration
try:
    fset.add(5)
except AttributeError as e:
    print(f"Error: {e}")

try:
    fset.remove(2)
except AttributeError as e:
    print(f"Error: {e}")
print("Original frozenset:", fset)

Output:

frozenset({1, 2, 3, 4})
Error: 'frozenset' object has no attribute 'add'
Error: 'frozenset' object has no attribute 'remove'
Original frozenset: frozenset({1, 2, 3, 4})

Named Tuples

from collections import namedtuple

# Define named tuple
Point = namedtuple('Point', ['x', 'y'])

# Create instance
p = Point(1, 2)
print(p)
print(p.x)
print(p.y)

# Immutability demonstration
try:
    p.x = 10
except AttributeError as e:
    print(f"Error occurred: {e}")

Output:

Point(x=1, y=2)
1
2
Error occurred: can't set attribute

Immutable data structures in Python are critical for creating stable, thread-safe, and maintainable programs by preventing unintended modifications.

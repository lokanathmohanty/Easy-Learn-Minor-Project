PHP Syntax and Structure Fundamentals

PHP is a **server-side scripting language** whose syntax is highly similar to the **C language**. PHP code is stored in text files with the **`.php`** extension, often mixed with HTML, CSS, and JavaScript.

Running PHP Code

A `.php` file must be executed by a web server with an installed PHP interpreter.

  • **Correct (HTTP Protocol):** Open the file via a web server URL (e.g., `http://localhost/index.php`). The PHP code is processed, and the resulting HTML is displayed.
  • **Incorrect (File Protocol):** Double-clicking the file opens it locally with the `file://` protocol. The browser will likely display the raw PHP code as text, as the interpreter is never engaged.

PHP Tags and Escaping from HTML

The PHP parser ignores everything outside its opening and closing tags, allowing PHP code to be seamlessly embedded within HTML.

Canonical PHP Tags (Recommended)

This is the most reliable method, as it works on all servers without needing extra configuration.

<?php
   echo "Hello World!";
?>

Short-Open (SGML-style) Tags

These are shorter but require the `short_open_tag=on` setting in the `php.ini` configuration file. They are generally discouraged as they conflict with XML syntax.

<?
   echo "Hello Everyone!";
?>

Escaping for Conditionals

PHP can drop out of its parsing mode to output large blocks of text, often combined with control structures:

<?php if ($is_valid == true): ?>
   This HTML statement will be rendered only if the condition is true.
<?php endif; ?>

Statements and Case Sensitivity

Statements

A statement in PHP is an expression followed by a **semicolon (`;`)**. The semicolon is the statement terminator.

$greeting = "Welcome to PHP!";

A single physical line can contain multiple statements, and a single statement can span multiple lines. Multiple statements can be grouped into a single block using **curly braces (`{}`)**.

Case Sensitivity

PHP is generally a **case-sensitive** language for its **identifiers** (names).

  • **Variables** are **case-sensitive**. E.g., `$age` and `$Age` are treated as two different variables.
  • **Keywords** (e.g., `if`, `else`, `while`), **language constructs** (e.g., `echo`, `print`), and most **user-defined functions** are generally **case-insensitive** (though using the proper casing is a strong best practice).

Python - Keyword Arguments

Python allows passing function arguments in the form of keywords, also called named arguments. Variables defined in the function signature can be explicitly assigned values during the function call using their names.

Calling Function with Keyword Arguments

# Function definition
def printinfo(name, age):
    print("Name:", name)
    print("Age", age)

# Function calls
printinfo("Naveen", 29)              # positional arguments
printinfo(name="miki", age=30)       # keyword arguments

Output:

Name: Naveen
Age 29
Name: miki
Age 30

Order of Keyword Arguments

Normally, arguments are assigned in the order of appearance. But when using keyword arguments, order does not matter.

Example with Positional Arguments

def division(num, den):
    quotient = num / den
    print("num:{} den:{} quotient:{}".format(num, den, quotient))

division(10, 5)
division(5, 10)

Output:

num:10 den:5 quotient:2.0
num:5 den:10 quotient:0.5

Example with Keyword Arguments

def division(num, den):
    quotient = num / den
    print("num:{} den:{} quotient:{}".format(num, den, quotient))

division(num=10, den=5)
division(den=5, num=10)

Output:

num:10 den:5 quotient:2.0
num:10 den:5 quotient:2.0

Mixing Positional and Keyword Arguments

You can mix positional and keyword arguments. But positional arguments must always come first. 

def division(num, den):
    quotient = num / den
    print("num:{} den:{} quotient:{}".format(num, den, quotient))

division(num=5, 10)   # ❌ Invalid

Error:

SyntaxError: non-keyword arg after keyword arg

Quick Comparison

Type Example Notes
Positional printinfo("Naveen", 29) Values assigned by order
Keyword printinfo(name="miki", age=30) Order doesn’t matter
Mixed printinfo("Naveen", age=29) Positional must come first

DAX Introduction

DAX (Data Analysis Expressions) is a formula expression language used in Power BI and other BI tools. It is often referred to as a function language, where the code is encapsulated inside functions.

DAX formulas support two data types:

  • Numeric: Includes integers, currency, decimals
  • Other: Includes strings and binary objects

Example DAX formula:


Product_C = RIGHT(Sheet1[Prod_Id], 3)

DAX formulas can include functions, conditional logic, and value references.

DAX Functions

Power BI provides a wide variety of DAX functions used to analyze data and create new columns or measures. As you type in the formula bar, a list of functions will appear for easy access.

Categories of DAX Functions

  • Aggregate
  • Text
  • Date
  • Logical
  • Counting
  • Information

Aggregate Functions

  • MIN, MINA, MINX
  • MAX, MAXA, MAXX
  • AVERAGE, AVERAGEA, AVERAGEX
  • SUM, SUMX
  • PRODUCT, PRODUCTX

Text Functions

  • LEFT, RIGHT, MID
  • UPPER, LOWER, TRIM
  • FORMAT, LEN, FIND, EXACT
  • CONCATENATE, CONCATENATEX, SUBSTITUTE, REPLACE
  • BLANK

Date Functions

  • DATE, DATEDIFF, DATEVALUE
  • CALENDAR, YEAR, YEARFRAC
  • HOUR, NOW, EOMONTH
  • WEEKDAY, WEEKNUM

Logical Functions

  • AND, OR, NOT
  • IF, IFERROR, COALESCE
  • SWITCH, TRUE, FALSE
  • BITXOR, BITAND, BITLSHIFT

Counting Functions

  • DISTINCTCOUNT
  • COUNT, COUNTA
  • COUNTROWS, COUNTBLANK

Information Functions

  • CONTAINS, CONTAINSSTRING, CONTAINSROW
  • COLUMNSTATISTICS, CONTAINSSTRINGEXACT
  • HASONEFILTER, HASONEVALUE
  • ISBLANK, ISNUMBER, ISLOGICAL
  • ISTEXT, ISNONTEXT, ISERROR, ISAFTER, ISSUBTOTAL
  • SELECTEDMEASURE, NONVALUE

DAX Calculation Types

DAX in Power BI allows the creation of two main types of calculations:

  • Calculated Columns
  • Calculated Measures

Creating a Calculated Column

  1. Navigate to the Modeling tab.
  2. Click New Column.
  3. Enter the DAX formula in the formula bar.

Example: Creating a new column called Product_C from the last 3 characters of Prod_Id: 

Product_C = RIGHT(Sheet1[Prod_Id], 3)

You can rename the column by editing its name in the formula bar.

Creating a Calculated Measure

  1. Go to the Modeling tab.
  2. Select New Measure.
  3. Write your DAX formula in the formula bar.

A new measure object will appear in the Fields pane, and the measure can be used in visualizations.

Java Programming: Special Types

Session: Enum Class (Enumerations)

What is a Java Enum? 🔢

An **Enum** (short for **Enumeration**) is a special kind of **class** in Java that defines a fixed group of **constants**. It is used to group related values under a single type, ensuring **type safety** by allowing only predefined, valid values to be assigned.

Enums are declared using the **enum** keyword, and the constants are typically written in **uppercase** and separated by commas.

Why Use Enums Over Constants?

Traditionally, fixed constants were defined using `public static final int` variables. The problem with this approach is a lack of type safety, as any `int` value (even invalid ones) could be assigned. Enums solve this by strictly limiting variables to the defined set of constants.

Enums are ideal for representing fixed sets like:

  • Days of the week (`SUNDAY`, `MONDAY`, etc.)
  • Directions (`NORTH`, `SOUTH`, `EAST`, `WEST`)
  • Status Codes (`RUNNING`, `STOPPED`, `PAUSED`)

Declaration and Usage

Declaration Syntax

Enums can be declared outside a class (public) or inside a class (nested), but not inside a method.

public enum Day {
   SUNDAY, MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY;
}

Enum in a Switch Statement

Enums work seamlessly with **switch** statements, providing clean and readable conditional logic:

Mobile mobile = Mobile.Samsung;

switch(mobile) {
   case Samsung:
      System.out.println("Samsung");
      break;
   case Nokia:
      System.out.println("Nokia");
      break;
   // ... other cases
}

Built-in Enum Methods

Since enums are a special kind of class, they inherit methods from **java.lang.Enum**:

  • **name()**: Returns the exact constant name as declared (e.g., "SUNDAY").
  • **toString()**: By default, returns the same as name().
  • **ordinal()**: Returns the position of the constant in its declaration, starting from 0 (e.g., `SUNDAY` is 0, `MONDAY` is 1).
  • **compareTo(E o)**: Compares the ordinal values of two enum constants.
  • **valueOf(Class<T> enumType, String name)**: Static method that returns the enum constant matching the specified string name.

Key Takeaways

Unlike normal classes where you create objects, an enum **automatically creates its objects**, which are the constants themselves. Enums always implicitly extend **java.lang.Enum** and their constructors are always private, meaning they cannot be explicitly subclassed or instantiated with `new`.

PHP: Abstract Classes

An **abstract class** is a class that cannot be instantiated on its own; you cannot create objects directly from it. It is intended to be a **blueprint** for other classes, defining common methods and properties that inheriting classes must implement.

Key Rules for Abstract Classes

  • The class must be declared with the **abstract** keyword: abstract class MyClass {...}.
  • An abstract class **cannot be instantiated** (e.g., $obj = new MyClass; will cause a Fatal Error).
  • If a class contains even one **abstract method**, the class itself **must** be declared abstract.
  • Abstract classes can contain properties, constants, and methods (public, private, or protected), including non-abstract ("normal") methods.
  • An abstract method is defined with the abstract keyword and **has no body** (only the signature).

Inheritance and Implementation

An abstract class is **extended** by a child class. If a child class is not abstract, it **must** provide a concrete implementation (a method body) for *every* abstract method defined in the parent abstract class. Failure to do so results in a fatal error, forcing the child class to either implement the method or also be declared abstract.

Why Use Abstract Classes?

The primary benefits are:

  1. Enforcing Structure: They require child classes to implement specific methods, ensuring a consistent structure across a set of related classes.
  2. Code Reusability: Common attributes and non-abstract methods can be defined once in the abstract parent class, reducing duplication.

Example Session

Calculating Student Percentage

Consider an abstract class marks that enforces that any derived class must implement a percent() method to calculate a student's score, but also provides the common properties ($m1, $m2, $m3) needed for the calculation.


abstract class marks {
   protected int $m1, $m2, $m3;
   // Abstract method: MUST be implemented by children
   abstract public function percent(): float; 
}

class student extends marks {
   public function __construct($x, $y, $z) {
      $this->m1 = $x; $this->m2 = $y; $this->m3 = $z;
   }
   // Concrete implementation of the abstract method
   public function percent(): float { 
      return ($this->m1 + $this->m2 + $this->m3) * 100 / 300;
   }
}

$s1 = new student(50, 60, 70);
echo "Percentage: " . $s1->percent(); // Output: Percentage: 60

The student class is forced to implement percent(), ensuring all student-type objects can report their scores reliably.

Java 13 - Major New Features Summary (Non-LTS Release)

Overview of Java 13

**Java 13**, released in **September 2019**, continued the 6-month rapid release cycle and is a **non-LTS (Long-Term Support)** release. The main highlights were the second preview of Switch Expressions and the introduction of Text Blocks, both aimed at improving the conciseness and expressiveness of the Java language.

Language and API Enhancements

1. Switch Expressions (Second Preview) (JEP 354)

The enhanced switch feature, introduced in Java 12, was iterated upon. The major change was the replacement of the reserved keyword **break** for returning a value with the new keyword **yield**.

  • Purpose of yield: When switch is used as a statement (not an expression), break is still used to terminate the switch. However, when switch is used as an **expression** to produce a value, **yield** is used to yield the result of that case to the surrounding context.
String result = switch (day) {
    case MONDAY, FRIDAY: yield "Short Day";
    default: yield "Long Day";
};

2. Text Blocks (First Preview) (JEP 355)

Text blocks provide a new way to handle **multi-line string literals** in Java, primarily to simplify working with code that contains snippets of other languages, such as HTML, JSON, or SQL.

  • Syntax: Defined using three double-quote characters (""") to open and close the block.
  • Advantages: Eliminates the need for explicit line breaks (\n) and concatenation, and handles most indentation automatically.
String json = """
{
    "name": "Gemini",
    "version": 13
}""";

3. New String Methods for Text Blocks

To support text blocks, new instance methods were added to the String class to manage indentation and formatting:

  • String.stripIndent(): Removes incidental white space from the string that was added by the Java compiler during text block processing.
  • String.translateEscapes(): Processes escape sequences (like \n or \t) that may be present within a text block.
  • String.formatted(Object... args): A convenience instance method that simplifies formatting compared to the static String.format().

Performance and JVM Enhancements

ZGC Enhancements: Unused Heap Memory Return (JEP 351)

The Z Garbage Collector (ZGC) was enhanced to **uncommit unused heap memory** back to the operating system. This is crucial for environments where resources are pooled or elastic (like containers or microservices), allowing the JVM to reduce its memory footprint when idle. Previously, ZGC would rarely return unused memory to the OS.

Dynamic CDS Archive (JEP 350)

This allows the **Class Data Sharing (CDS)** feature to be dynamically archived after application classes have loaded. This simplifies the creation and deployment of CDS archives, further improving application startup time and memory footprint.

Socket API Reimplementation (JEP 353)

The underlying implementation of the Legacy Socket API (java.net.Socket and java.net.ServerSocket) was rewritten using the more modern and easier-to-maintain APIs from Java 8. This improves performance, scalability, and maintainability, especially on the Windows platform.

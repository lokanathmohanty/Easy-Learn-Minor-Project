C++ Lambda Expressions (Anonymous Functions) 🛠️

A **Lambda Expression** is a powerful feature in Modern C++ (C++11 and later) that allows you to define an **anonymous function object** (a function without a name) **inline**. They are essential for functional programming tasks like callbacks, algorithms, and simplifying code.

Core Syntax

The lambda expression is structured into four main parts:

[ capture ] (parameters) -> return_type { function_body }
  • **[ capture ]**: Specifies how variables from the surrounding scope are accessed.
  • **(parameters)**: The input arguments for the lambda.
  • **-> return_type**: Explicitly defines the return type (optional if the compiler can deduce it).
  • **{ body }**: The logic of the function.

Capturing Variables

The **capture clause** (`[]`) determines which variables from the outer scope the lambda can access and how (by value or by reference).

Capture ClauseDescription
**[x]**Capture variable `x` by **value** (read-only copy).
**[&x]**Capture variable `x` by **reference** (read and modify the original).
**[=]**Capture **all** surrounding variables by **value**.
**[&]**Capture **all** surrounding variables by **reference**.
**[=, &x]**Mixed: Capture all by value, except `x` by reference.
**[&, x]**Mixed: Capture all by reference, except `x` by value.
**[this]**Capture the `this` pointer by value, allowing access to class members inside a class method.

Return Type Deduction

The compiler is often able to determine the return type automatically, which simplifies the syntax (Implicit Deduction):

// Implicit return type (compiler sees 'return a + b;' and deduces 'int')
auto add = [](int a, int b) { return a + b; };

// Explicit return type (required for complex types or multiple return paths)
auto complex_op = [](double x) -> double { return x * 2.0; };

Recursive Lambdas

Since a lambda is anonymous, it cannot call itself directly by name. To make a lambda recursive, you must assign it to an **std::function** object, which provides the necessary named reference for the recursive call.

// std::function gives the lambda a name ('factorial') and type signature
std::function<int(int)> factorial = [&](int n) -> int {
    if (n <= 1) return 1;
    return n * factorial(n - 1); // Uses the named std::function object
};

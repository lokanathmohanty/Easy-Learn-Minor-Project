HTML - SSE API (Server-Sent Events)

Server-Sent Events (SSE API)

Server-sent events are a way of sending data from a server to a web page without requiring the page to refresh or make repeated requests. These events are useful for creating real-time applications, such as chat systems, news feeds, or notifications.

Using SSE, a persistent connection is opened to the server, allowing the server to continuously push data to the browser. This eliminates the need for continuous polling and standardizes how we stream data from the server to the client.

How to Use SSE in a Web Application?

To use Server-Sent Events in a web application, we need to add an <eventsource> element. Its src attribute should point to a URL that provides a persistent HTTP connection which streams events. The URL usually points to a PHP, PERL, or Python script that sends event data consistently.

Instance

The following is a sample HTML code of a web application that would expect server time:

<!DOCTYPE html>
<html>
<head>
   <script type="text/javascript">
      /* Define event handling logic here */
   </script>
</head>
<body>
   <div id="sse">
      <eventsource src="/cgi-bin/ticker.cgi" />
   </div>
   <div id="ticker">
      <TIME>
   </div>
</body>
</html>

Server-side Script for SSE

The following are the steps for sending server-sent events from a server-side script:

  • Set the Content-Type Header
    print "Content-Type: text/event-stream\n\n";
  • Send an Event Name
    print "Event: server-time\n";
  • Send Event Data
    print "Data: $time\n";

Finally, here is a complete example of a ticker.cgi script written in Perl:

#!/usr/bin/perl
print "Content-Type: text/event-stream\n\n";
while(true){
   print "Event: server-time\n";
   $time = localtime();
   print "Data: $time\n";
   sleep(5);
}

Handle Server-Sent Events

We can also modify the client-side web application to listen for and process server-sent events using an eventsource object.

Example

<!DOCTYPE html>
<html>
  <head>
    <script type="text/javascript">
      document.getElementsByTagName("eventsource")[0].addEventListener("server-time", eventHandler, false);
      function eventHandler(event) {
         // Display time sent by the server
         document.querySelector('#ticker').innerHTML = event.data;
      }
    </script>
  </head>
  <body>
    <div id="sse">
      <eventsource src="/cgi-bin/ticker.cgi" />
    </div>
    <div id="ticker" name="ticker"> [TIME] </div>
  </body>
</html>

Note: Before testing Server-Sent Events, make sure your web browser supports this feature.

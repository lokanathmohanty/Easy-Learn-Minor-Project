C++ Functions (Modular Programming) 🧩

A **function** is a self-contained block of statements designed to perform a specific, well-defined task. Every C++ program starts execution in the required **main()** function, which can then call other functions. Breaking code into functions promotes reusability, modularity, and better organization.

A function is defined by two main parts: the **Declaration** (what the function looks like) and the **Definition** (what the function does).

Defining a Function (The Body)

The **function definition** provides the actual instructions the function executes. It includes a header and a body:

return_type function_name( parameter list ) {
   // body of the function (statements)
}
  • **Return Type:** The data type of the value the function sends back to the caller (e.g., `int`, `double`, `string`). If the function returns nothing, the type is **void**.
  • **Function Name:** The unique identifier for the function.
  • **Parameters (Formal Parameters):** Placeholders that receive values (arguments) when the function is called. They define the type, order, and number of inputs.
  • **Function Body:** The block of statements enclosed in braces `{}` that performs the task.

Function Declaration (The Signature)

A **function declaration** (or prototype) informs the compiler about the function's existence, its name, its return type, and its parameter types. This allows the function to be called before its full definition appears in the code.

return_type function_name( parameter list ); // Note the semicolon

For the function `int max(int num1, int num2)`, a valid declaration is:

int max(int, int); // Parameter names are optional in the declaration

A declaration is necessary when functions are defined in separate files or when the definition appears *after* the first call to that function (e.g., `main()` calls a function defined below it).

Calling a Function

To execute a function, you **call** (or invoke) it by using its name and providing the necessary arguments. Program control transfers to the called function and returns when the function executes a `return` statement or reaches its closing brace.

int a = 100;
int b = 200;
int ret = max(a, b); // Calling the max() function
// Program control returns here.

Function Arguments and Passing Methods

Passing Methods

The way arguments are passed determines whether the function can modify the original variable:

Call TypeMechanismEffect on Original Argument
**Call by Value (Default)** Copies the argument's **value** to the formal parameter. **None.** Changes inside the function are isolated.
**Call by Pointer** Copies the argument's **address** (pointer) to the formal parameter. **Yes.** Changes made via the address affect the original data.
**Call by Reference** Copies the argument's **reference** (alias) to the formal parameter. **Yes.** Changes made affect the original variable (most common in modern C++).

Default Parameter Values

You can provide **default values** for parameters (starting from the rightmost parameter). These values are used if the corresponding argument is omitted in the function call.

// Function definition: b defaults to 20
int sum(int a, int b = 20) { ... } 

// Call 1: value of 200 is used for b (Result: 300)
result = sum(100, 200);

// Call 2: default value of 20 is used for b (Result: 120)
result = sum(100);

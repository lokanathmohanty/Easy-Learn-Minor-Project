JavaScript - Versions

JavaScript was developed by Brendan Eich in 1995. It was standardized in 1997 by the European Computer Manufacturers Association (ECMA) and officially known as ECMAScript. The first version of the language is known as ECMAScript 1 (ES1). The first three versions (ES1, ES2, and ES3) laid the foundation of the language. The fourth version, ES4, was abandoned. The first major revision was ES5 (2009), followed by the second major revision ES6 (2015). After 2015, versions are named by the year of release.

The latest version of JavaScript is ECMAScript 2023.

JavaScript Versions

The table below lists the official versions of JavaScript and their major features.

Version Official Name Release Year Features Added
ES1 ECMAScript 1 1997 First release
ES2 ECMAScript 2 1998 Minor changes
ES3 ECMAScript 3 1999
  • Regular expressions
  • do-while
  • switch
  • try/catch
ES4 ECMAScript 4 - Never released
ES5 ECMAScript 5 2009
  • Strict mode
  • Multiline strings
  • String.trim()
  • Array & Object methods
  • Getters and setters
  • Trailing commas
ES6 ECMAScript 2015 2015
  • let and const
  • Map and Set
  • Arrow functions
  • for/of loop
  • Classes
  • Promises
  • Modules
  • Spread operator
  • Symbols
ES7 ECMAScript 2016 2016
  • Exponential (**) operator
  • Array.includes()
ES8 ECMAScript 2017 2017
  • Async/await
  • Object.entries(), Object.values()
  • Object.getOwnPropertyDescriptor()
  • String padding
ES9 ECMAScript 2018 2018
  • Rest/spread for objects
  • Shared memory
  • Promise.finally()
  • New RegExp features
ES10 ECMAScript 2019 2019
  • String.trimStart(), String.trimEnd()
  • Array.flat()
  • Revised Array.sort()
  • Object.fromEntries()
ES11 ECMAScript 2020 2020
  • Nullish Coalescing (??)
  • BigInt
ES12 ECMAScript 2021 2021
  • String.replaceAll()
  • Promise.any()
ES13 ECMAScript 2022 2022
  • Static blocks in classes
  • New class features
  • Top-level await
ES14 ECMAScript 2023 2023
  • Array.findLast(), Array.findLastIndex()
  • Hashbang grammar
  • Symbols as WeakMap keys

Browser Support

All modern browsers fully support ES1 to ES6. For later versions, you may use polyfills for compatibility.

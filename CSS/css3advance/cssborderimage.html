CSS - Border Images

CSS border-image properties are used to create custom borders by setting an image as the border around any element.

The border-image property takes the image and slices it into nine sections (3x3). It then places the corners at the corners of the border, and the edges are repeated or stretched as specified. The middle part of the image will be ignored.

Example of Image as Border

The following code shows a basic example of how to set an image as a border.

Example

div {
  background-color: #f0f0f0;
  border: 20px solid transparent;
  border-image: url(/css/images/border.png) 40;
  padding: 20px;
}

CSS Border Image Source

The border-image-source property specifies the source (URL) of an image to be used as a border.

Example

div {
  background-color: #f0f0f0;
  border: 20px solid transparent;
  border-image-source: url(/css/images/border.png);
  padding: 20px;
}

CSS Border Image Slice

The border-image-slice property defines how the image is sliced into regions, which are then used to draw the borders.

The image is divided into 9 sections: four corners, four edges, and the center.

The value specifies how far inward from the edges the slicing should occur. Percentages are commonly recommended.

Example

div {
  background-color: #f0f0f0;
  border: 20px solid transparent;
  border-image-source: url(/css/images/scenery2.jpg);
  border-image-slice: 25%;
  padding: 15px;
  width: 50%;
}

CSS Border Image Width

The border-image-width property specifies the width of the image border.

Example

div {
  background-color: #f0f0f0;
  border: 20px solid transparent;
  border-image-source: url(/css/images/border.png);
  border-image-width: 5px;
  border-image-slice: 25%;
  padding: 5px;
  margin: 20px;
}

CSS Border Image Outset

The border-image-outset property specifies the gap between the element and the border image, pushing the border outward.

Example

div {
  background-color: grey;
  border: 20px solid transparent;
  border-image-source: url(/css/images/border.png);
  border-image-width: 10px;
  border-image-slice: 25%;
  border-image-outset: 0px;
  padding: 5px;
  width: 80%;
  margin: 10px 15px 60px;
}

CSS Border Image Repeat

The border-image-repeat property defines whether the image is stretched, repeated, or rounded along the border edges.

Example

div {
  background-color: #f0f0f0;
  border: 20px solid transparent;
  border-image-source: url(/css/images/border.png);
  border-image-slice: 25%;
  border-image-repeat: repeat;
  padding: 20px;
  width: 80%;
  margin: 10px 15px 60px;
}

Border Image Shorthand Property

The border-image shorthand property allows setting all border-image properties in one declaration.

Syntax: border-image: image-source | image-slice | image-repeat;

Example

div {
  background-color: #f0f0f0;
  border: 20px solid transparent;
  border-image: url('/css/images/border.png') 30 round;
  padding: 20px;
}

CSS Gradient as Border Images

CSS gradients (linear, radial, conic) can also be used as border images.

Example

div {
  background-color: #f0f0f0;
  border: 20px solid transparent;
  border-image: linear-gradient(45deg, green, yellow) 1;
  padding: 20px;
  margin: 20px;
}

CSS Border Images All Properties

  • border-image – Shorthand for setting border image.
  • border-image-outset – Sets how much the border image extends beyond the border box.
  • border-image-repeat – Defines if the border image should repeat, round, or stretch.
  • border-image-source – Defines the image source.
  • border-image-slice – Defines how to slice the image into border regions.
  • border-image-width – Defines the width of the image border.

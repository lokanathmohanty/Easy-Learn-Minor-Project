Java Stack Class Summary (LIFO) 📚🔄

The **java.util.Stack** class represents a standard **Last-In, First-Out (LIFO)** stack of objects. It is a **legacy** class that **extends Vector** (meaning it is an array-based implementation and is **synchronized** / thread-safe), but it should be noted that modern Java development typically uses **ArrayDeque** or a **LinkedList** implementing the Deque interface for stack functionality due to better performance.

I. Stack Principle (LIFO)

The LIFO principle dictates that the element most recently added to the stack is the first one to be removed.

II. Essential Stack Methods

The Stack class adds five specific operations on top of the methods inherited from Vector:

Method Action LIFO Operation
E push(E item) Adds an item to the **top** of the stack. **Insert**
E pop() Removes and returns the object at the **top** of the stack. **Delete**
E peek() Returns the object at the **top** without removing it. **Examine**
boolean empty() Tests if the stack contains no items. **Check State**
int search(Object o) Returns the 1-based position (distance from the top) where the object is found. **Search**

III. Exception Handling and Example Flow

  • The **pop()** and **peek()** methods throw an **EmptyStackException** (an unchecked exception) if they are called on a stack that contains no elements.
  • The provided example correctly demonstrates this behavior by wrapping the final, failed showpop(st) call in a `try-catch` block.

Example Flow:

// Push: [42] -> [42, 66] -> [42, 66, 99]
push(99) is the last element inserted.

// Pop -> 99 (Last-In)
// Stack is now: [42, 66]

// Pop -> 66
// Stack is now: [42]

// Pop -> 42 (First-In, Last-Out)
// Stack is now: [ ]

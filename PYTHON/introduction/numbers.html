Python - Numbers

Python provides built-in support to store and process numeric data. Numbers are widely used in almost every Python application. Python supports multiple number types and offers many functions for mathematical operations.

Number Types in Python

  • int – Integer numbers
  • float – Floating point numbers
  • complex – Complex numbers
  • bool – Boolean values (subclass of int: True=1, False=0)

Integers

Integers are whole numbers without a fractional part. Examples: 1234, -55, 0.

They can be created using literals, expressions, or the int() function.

a = 10
b = 20
c = a + b
print("a:", a, "type:", type(a))
print("c:", c, "type:", type(c))

Output:

a: 10 type: <class 'int'>
c: 30 type: <class 'int'>

Binary, Octal, and Hexadecimal

Binary

a = 0b101
print("a:", a, "type:", type(a))

b = int("0b101011", 2)
print("b:", b, "type:", type(b))

Octal

a = 0O107
print(a, type(a))   # Output: 71 <class 'int'>

b = int("20", 8)
print(b, type(b))   # Output: 16 <class 'int'>

Hexadecimal

a = 0XA2
print(a, type(a))   # Output: 162 <class 'int'>

num_string = "A1"
number = int(num_string, 16)
print("Hexadecimal:", num_string, "Integer:", number)

Floating Point Numbers

Floats have integer and fractional parts separated by a decimal point. They can also be written in scientific notation.

a = 9.99
b = -0.999
c = 1.23E3
print(a, b, c)

Output:

9.99 -0.999 1230.0

Floats can also represent inf (infinity) and nan (Not a Number).

Complex Numbers

A complex number is represented as x+yj, where x is real and y is imaginary part.

a = 5+6j
print(a, type(a))

b = complex(5.3, 6)
print(b, type(b))

Attributes and methods:

a = 5+6j
print("Real part:", a.real)
print("Imag part:", a.imag)
print("Conjugate:", a.conjugate())

Type Conversion

  • int(x) → Convert to integer
  • float(x) → Convert to float
  • complex(x) → Complex with real part x
  • complex(x, y) → Complex with real part x and imaginary part y

Math Module Functions

Python’s math module provides many functions:

  • Theoretic Functions: ceil(), floor(), factorial(), gcd(), isqrt(), etc.
  • Power & Log: pow(), sqrt(), log(), log10(), exp()
  • Trigonometric: sin(), cos(), tan(), asin(), acos(), atan()
  • Conversions: degrees(), radians()
  • Constants: math.pi, math.e, math.tau, math.inf, math.nan
  • Hyperbolic: sinh(), cosh(), tanh(), asinh(), etc.
  • Special: gamma(), lgamma(), erf(), erfc()

Random Numbers

The random module provides random number generation functions:

  • random() → Random float in [0,1)
  • randrange(start, stop, step) → Random number from range
  • choice(seq) → Random item from sequence
  • shuffle(seq) → Shuffle sequence
  • uniform(a, b) → Random float between a and b

Built-in Mathematical Functions

  • abs(x) → Absolute value
  • max(iterable) → Maximum value
  • min(iterable) → Minimum value
  • pow(x, y) → x raised to y
  • round(x, n) → Round to n digits
  • sum(iterable) → Sum of elements

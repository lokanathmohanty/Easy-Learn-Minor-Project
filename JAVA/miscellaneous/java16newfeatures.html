Java 16 - Major New Features Summary (Non-LTS Release)

Overview of Java 16

**Java 16**, released in **March 2021**, maintained the 6-month rapid release cycle and is a **non-LTS (Long-Term Support)** release. This version was significant for graduating several key language preview features to **standard status**, providing major stability to the platform, and introducing powerful low-level APIs.

Language Features Standardized ✨

Java 16 permanently integrated major language features that had previously been in preview:

  • Records (JEP 395): The concise syntax for creating immutable data classes is now a **standard feature**. Records automatically generate the constructor, accessors, equals(), hashCode(), and toString() methods.
  • Pattern Matching for instanceof (JEP 394): The enhancement to the instanceof operator that automatically casts the object to a new, local pattern variable upon a successful check is now a **standard feature**.

Other Language & Tooling Updates

  • Sealed Classes (Second Preview) (JEP 397): Continued its preview phase with minor enhancements. This feature allows a class or interface to explicitly declare which classes are permitted to extend or implement it.
  • Packaging Tool (jpackage) (JEP 392): The tool for packaging self-contained Java applications (including a private JRE) into native installation formats (like .msi, .dmg, .deb) is now a **standard feature**.

JVM, Concurrency, and Low-Level APIs

Advanced APIs (Incubator)

Java 16 introduced new, low-level APIs intended to improve performance and native interoperability:

  • Vector API (Incubator) (JEP 338): Provides an API for performing vector computations that compile down to optimal vector instructions on supported CPU architectures (SIMD). This can lead to dramatic performance improvements in relevant mathematical and processing tasks.
  • Foreign Linker API (Incubator) (JEP 389): A replacement for the complex and brittle JNI (Java Native Interface), allowing Java programs to naturally and efficiently call native libraries (C/C++) and vice versa.
  • Foreign-Memory Access API (Third Incubator) (JEP 393): Continued development of the API for safe access to foreign memory (outside the Java heap).

Platform and Performance

  • Strongly Encapsulate JDK Internals by Default (JEP 396): A crucial security update. The default access mode for the illegal access command-line option (--illegal-access) was switched from permit to **deny**, meaning reflection access to internal JDK APIs is now blocked by default, improving modularity and security.
  • ZGC: Concurrent Thread-Stack Processing (JEP 376): The Z Garbage Collector was improved by moving its thread-stack processing from the JVM's stop-the-world **safepoints** into a concurrent phase, further **reducing GC pause times**.
  • Elastic Metaspace (JEP 387): Improved the management of class-metadata memory (Metaspace) by enabling the HotSpot VM to quickly return unused Metaspace memory to the operating system, reducing the memory footprint.
  • New Ports (JEP 386 & 388): Official JDK builds were added for **Alpine Linux** (using musl libc) and **Windows/AArch64** (ARM server/laptops).

Next.js Imperative Routing (Programmatic Navigation) ⚙️

What is Imperative Routing?

**Imperative routing** is a method of navigating between pages programmatically, typically based on a **user action** (like submitting a form) or a **dynamic condition** (like checking authentication status). Unlike **declarative routing** (using the `<Link>` component), this approach uses custom logic to determine *when* and *where* to navigate.

Implementing Imperative Routing with `useRouter`

To perform programmatic navigation on the client side, Next.js provides the **`useRouter`** hook from **`next/navigation`** (for the App Router). Since it's a hook, it must be used within a **Client Component** (files marked with `"use client"`).

Key Router Methods:

  • `router.push(path)`: Navigates to a new path and adds a new entry to the browser history stack (allows the user to go back).
  • `router.replace(path)`: Navigates to a new path and replaces the current entry in the history stack (the user **cannot** go back to the previous page).

Example: Navigating After a User Action (Order Placement)

In this example, after a button click, an alert is shown, and the user is programmatically redirected to the home page using `router.push("/")`.

"use client";
import { useRouter } from "next/navigation";

export default function ProductPage({ params }) {
    const router = useRouter();

    const handleClick = () => {
        alert("Order Placed...");
        router.push("/"); // ← Imperative navigation
    };
    // ... returns component with <button onClick={handleClick}>
}

Routing Based on Conditions (Authentication)

Imperative routing is crucial for logic that requires redirection. A common use case is checking user authentication status and redirecting unauthenticated users to a login page.

// app/protected-page/page.tsx file
"use client";
import { useEffect } from 'react';
import { useRouter } from 'next/navigation';

export default function ProtectedPage() {
  const router = useRouter();

  useEffect(() => {
    const userAuthenticated = false; 
    
    if (!userAuthenticated) {
      // Redirects to /login page and prevents the user from navigating back here
      router.replace('/login'); 
    }
  }, [router]);

  return <div> Welcome to the Protected Page </div>;
}

In the scenario above, if a user tries to access the `/protected-page` while not authenticated, the `useEffect` hook runs on the client, detects the unauthenticated status, and immediately performs an imperative redirect to the `/login` route.

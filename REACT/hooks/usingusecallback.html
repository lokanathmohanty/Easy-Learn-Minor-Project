ReactJS — useCallback

Overview

useCallback is a React hook that returns a memoized version of a callback function. It is similar to useMemo, but specifically intended for memoizing functions (callbacks) instead of values. Because functions in JavaScript are passed by reference, memoizing callbacks prevents unnecessary re-creations and can reduce re-renders when functions are passed as props.

Signature

The hook signature is:

  • const <memoized_callback_fn> = useCallback(<callback_fn>, <dependency_array>);

  • callback_fn — the function to memoize.
    dependency_array — variables the callback depends on.

  • Note: useCallback(fn, deps) is equivalent to useMemo(() => fn, deps).

When to use useCallback

  • When passing function props to pure (memoized) child components.
  • When a function is included in a hook dependency array (e.g., useEffect).
  • When a function participates in debouncing, throttling, or other performance-sensitive patterns.

Applying useCallback — Step-by-step example

Create a React app (create-react-app) and add a memoized list component that receives:

  • an items prop — array to display
  • a handleClick prop — callback to call on click

PureListComponent (concept)

The child component reads props and is wrapped with React.memo to become a pure component:

  • Uses items to render a list (map over array).
  • Uses handleClick as click handler for items.
  • Because props include references (array, function), these must be stable to avoid re-renders.

Problem demonstration

If the parent component updates state frequently (for example, updating the current time every second), the parent re-renders each second. If the array and callback props are recreated on every render, React.memo in the child won't help — the child still receives new references and re-renders.

Solution using useMemo and useCallback

Preserve the items array and the callback function in the parent:

  • const listOfNumbers = useMemo(() => [...Array(100).keys()], []);
  • const handleCallbackFn = useCallback((e) => console.log(e.target.innerText), []);

With those memoized, the child receives stable references and React.memo prevents unnecessary re-renders even when the parent updates a state like currentTime.

Example structure (files)

  • src/components/PureListComponent.js — a memoized component that maps items and attaches handleClick to each item.

  • src/App.js — parent that demonstrates frequent re-render (time state) and then uses useMemo and useCallback to stabilize props.

Key code lines (conceptual)

  • const listOfNumbers = useMemo(() => [...Array(100).keys()], []);

  • const handleCallbackFn = useCallback((e) => console.log(e.target.innerText), []);

  • Wrap child export as: export default React.memo(PureListComponent)

Use cases

  • Pure functional components that accept functions as props.
  • Hooks that list functions in their dependency arrays (to avoid recreating effects on each render).
  • When using debounce/throttle utilities that require stable function references.

Advantages

  • Simple API and easy to apply.
  • Can improve application performance by preventing unnecessary re-renders.

Disadvantages / caveats

  • Overuse can reduce code readability and make debugging harder.
  • Developers must understand closures and dependencies well to avoid bugs.
  • Only use when there's measurable benefit — premature optimization is discouraged.

Summary

useCallback is a helpful hook to memoize functions and prevent needless re-creations. Use it selectively when it helps with performance (for example, stabilizing props passed to memoized children). If there is no measurable performance issue, allowing React to manage re-renders is often simpler and clearer.

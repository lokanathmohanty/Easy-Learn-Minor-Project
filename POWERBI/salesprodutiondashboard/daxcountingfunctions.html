Steps to Execute DAX Counting Functions

  1. Import the dataset into Power BI Desktop.
  2. Select New measure from the Table tools tab.
  3. Specify a valid expression in the formula bar for each counting function.
  4. Navigate to the Report View and choose any visual (Table, Matrix, Scorecard) to display the result.

Dataset: D:\Employee12.xlsx

1. DISTINCTCOUNT Function

Returns the number of distinct values in a column (including null values).

n1 = DISTINCTCOUNT('Electronic company'[Name])

Output: 9 distinct names

2. DISTINCTCOUNTNOBLANK Function

Same as DISTINCTCOUNT, but null values are ignored.

r1 = DISTINCTCOUNTNOBLANK('Electronic Company'[Quantity])

3. COUNT Function

Counts numeric, text, and date values, excluding null values.

Quantity_count = COUNT('Electronic company'[Quantity])

Scenario: Boolean Values

Using COUNT with Boolean values like TRUE/FALSE:

dt = COUNT(Dessert[Like Dessert])

Note: COUNT will not return results for Boolean fields.

4. COUNTA Function

Counts all non-blank values including TRUE/FALSE.

count_cost = COUNTA('Electronic Company'[Quantity])

Example with Boolean Values:

dt_count = COUNTA(Dessert[Like Dessert])

5. COUNTX Function

Counts non-blank results of an expression across a table (excludes TRUE/FALSE).

cnx = COUNTX(Dessert, Dessert[Name])

6. COUNTAX Function

Like COUNTX but includes all data types (text, numbers, booleans).

widgets_count = COUNTAX(Widgets, Widgets[Cost])

7. COUNTROWS Function

Returns the total number of rows in a table.

r1 = COUNTROWS('Electronic Company')

Output: 14 rows

8. COUNTBLANK Function

Returns the number of null/blank values in a column.

cnt_blank = COUNTBLANK('Electronic Company'[Cost])

Output: 2 blank values

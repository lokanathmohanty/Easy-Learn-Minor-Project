CSS - Gradients

CSS gradients allow you to design custom colors for HTML elements by creating a smooth transition between two or more colors.

What is CSS Gradient?

In CSS, gradient is a special type of user-defined image that can be used for background or borders of an element. Gradients are resolution-independent and do not lose quality when zoomed.

Types of CSS Gradients

CSS defines three main types of gradients:

  • Linear Gradient: Goes from left to right, top to bottom, or diagonally.
  • Radial Gradient: Starts from a center point and radiates outward.
  • Conic Gradient: Colors revolve around a central point.

Linear Gradients

The linear gradient creates a color band flowing in a single direction.

linear-gradient(direction, color1, color2, ...);

Radial Gradients

A radial gradient consists of colors radiating outward from a central point.

radial-gradient(shape size position, color1, color2...);

Conic Gradients

A conic gradient arranges colors in a circular or conical pattern around a center point.

conic-gradient(from angle at position, color-list)

Gradients for Borders

CSS gradients can be used to create fancy borders.

border-image: linear-gradient(color-list)

Positioning Color Stops

Color stops define where each color transition begins and ends in a gradient.

linear-gradient(to right, red 10%, pink 30%, blue 60%)

Creating Hard Lines

Hard lines can be created by setting two color stops at the same position.

Color Bands Using Gradients

Striped effects can be created by repeating colors with adjacent stops.

Stacked Gradients

Multiple gradients can be layered to create complex effects.

Related Functions

  • linear-gradient() - Colors transition in a straight line.
  • radial-gradient() - Colors radiate outward from a center.
  • conic-gradient() - Colors arranged in a circular pattern.
  • repeating-linear-gradient() - Creates a repeating linear pattern.
  • repeating-radial-gradient() - Creates a repeating radial pattern.
  • repeating-conic-gradient() - Creates a repeating conic pattern.

Python - Function Annotations

Function annotations in Python allow adding explanatory metadata about function arguments and return types. They are ignored by the interpreter during execution but useful for IDEs and static type checkers (e.g., mypy).

Unlike docstrings, annotations stay tied to the function signature and help maintain up-to-date documentation even when the prototype changes (PEP 3107).

Example: Simple Annotations

def myfunction(a: int, b: int):
    c = a + b
    return c

print(myfunction(10, 20))
print(myfunction("Hello ", "Python"))

Output:

30
Hello Python

Function Annotations with Return Type

You can also annotate the return type using ->. 

def myfunction(a: int, b: int) -> int:
    c = a + b
    return c

print(myfunction(56, 88))
print(myfunction.__annotations__)

Output:

144
{'a': <class 'int'>, 'b': <class 'int'>, 'return': <class 'int'>}

Annotations with Expressions

Instead of types, you may use any valid Python expression as annotation metadata. 

def total(x: "marks in Physics", y: "marks in Chemistry"):
    return x + y

print(total(86, 88))
print(total.__annotations__)

Output:

174
{'x': 'marks in Physics', 'y': 'marks in Chemistry'}

Annotations with Default Arguments

Annotations can be combined with default values. Default arguments must appear after required ones. 

def myfunction(a: "physics", b: "Maths" = 20) -> int:
    c = a + b
    return c

print(myfunction(10))
print(myfunction.__annotations__)

Output:

30
{'a': 'physics', 'b': 'Maths', 'return': <class 'int'>}

Annotations for Arbitrary Arguments

You can annotate *args and **kwargs as well. 

def myfunction(*args: "arbitrary args", **kwargs: "arbitrary keyword args") -> int:
    pass

print(myfunction.__annotations__)

Output:

{'args': 'arbitrary args', 'kwargs': 'arbitrary keyword args', 'return': <class 'int'>}

Multiple Annotations per Argument

You can provide multiple annotations using a dictionary as metadata. 

def division(
    num: dict(type=float, msg="numerator"),
    den: dict(type=float, msg="denominator")
) -> float:
    return num / den

print(division.__annotations__)

Output:

{'num': {'type': <class 'float'>, 'msg': 'numerator'}, 
 'den': {'type': <class 'float'>, 'msg': 'denominator'}, 
 'return': <class 'float'>}

Node.js - Callbacks Concept

What is a Callback?

In Node.js, a callback is a special asynchronous function passed as an argument to another function. It enables Node.js to perform tasks asynchronously, letting other operations run while waiting for a lengthy process to complete. Callbacks are essential for non-blocking operations.

Callback Syntax

function function_name(argument, function (callback_argument) {
  // callback body
})

Example: setTimeout Callback

setTimeout(function () {
  console.log('This prints after 1000 ms');
}, 1000);

console.log("Hello World");

Output:

Hello World

This prints after 1000 ms

Blocking Code Example

This example reads a file synchronously, blocking further execution until complete.

var fs = require("fs");
var data = fs.readFileSync('input.txt');
console.log(data.toString());

let i = 1;
while (i <= 5) {
  console.log("The number is " + i);
  i++;
}

Non-Blocking Code Example Using Callback

This example reads a file asynchronously and uses a callback function to handle results without blocking.

var fs = require("fs");
fs.readFile('input.txt', function (err, data) {
  if (err) return console.error(err);
  console.log(data.toString());
});

let i = 1;
while (i <= 5) {
  console.log("The number is " + i);
  i++;
}

Output:

The numbers 1 through 5 will print before the file contents, showing non-blocking behavior.

Callback as Arrow Function

Using ES6 arrow functions simplifies callback syntax:

var fs = require("fs");
fs.readFile('input.txt', (err, data) => {
  if (err) return console.error(err);
  console.log(data.toString());
});

let i = 1;
while (i <= 5) {
  console.log("The number is " + i);
  i++;
}

R - XML Files

XML (Extensible Markup Language) is a file format that stores data using markup tags to describe the meaning of data, unlike HTML which focuses on page structure. R can read XML files using the XML package.

Input Data

Create an XML file (e.g., input.xml) with employee data structured inside <RECORDS> and <EMPLOYEE> tags containing child elements like ID, NAME, SALARY, STARTDATE, and DEPT.

Reading XML File

# Load required packages
library("XML")
library("methods")

# Parse the XML file
result <- xmlParse(file = "input.xml")

# Print parsed result
print(result)

Output snippet:

1
Rick
623.3
1/1/2012
IT
2
Dan
515.2
9/23/2013
Operations
...

Number of Nodes in XML File

# Extract root node
rootnode <- xmlRoot(result)

# Count number of nodes
rootsize <- xmlSize(rootnode)

print(rootsize)

Output:

[1] 8

Details of the First Node

# Print first node in root
print(rootnode[1])

Output:

$EMPLOYEE
   1
   Rick
   623.3
   1/1/2012
   IT

attr(,"class")
[1] "XMLInternalNodeList" "XMLNodeList"

Accessing Different Elements of a Node

# Access specific node elements
print(rootnode[[1]][[1]]) # ID of 1st EMPLOYEE
print(rootnode[[1]][[5]]) # DEPT of 1st EMPLOYEE
print(rootnode[[3]][[2]]) # NAME of 3rd EMPLOYEE

Output:

1
IT
Michelle

Convert XML to Data Frame

# Convert XML file to data frame for analysis
xmldataframe <- xmlToDataFrame("input.xml")
print(xmldataframe)

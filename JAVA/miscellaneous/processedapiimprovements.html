Java - Process API Improvements (Java 9+)

Overview of the Enhanced Process API ⚙️

The **Java Process API** received substantial improvements in **Java 9**, making it much easier to control and manage operating system processes. The key addition is the **ProcessHandle** interface, which provides comprehensive information about native OS processes.

Key Features of ProcessHandle

The ProcessHandle class provides access to critical OS-level process data and functionality:

  • Process ID (PID): Accessible via pid().
  • Detailed Info: Accessed through the nested **ProcessHandle.Info** interface, providing:
    • Start time (startInstant())
    • Accumulated CPU time
    • Command and command line
    • User and arguments
  • Hierarchy: Methods to get the **parent process** and a stream of **descendant processes** (parent() and descendants()).
  • Lifecycle Control: Methods to check liveness (isAlive()) and to terminate/destroy processes (destroy()).
  • Asynchronous Action: The **onExit()** method returns a CompletableFuture, allowing non-blocking, asynchronous actions to be performed when a process exits.

Example: Accessing Current Process Information

The static ProcessHandle.current() method is used to get information about the Java process executing the code.

ProcessHandle currentProcess = ProcessHandle.current();
ProcessHandle.Info info = currentProcess.info();

System.out.printf("Process ID : %s%n", currentProcess.pid());
System.out.printf("Command name : %s%n", info.command().orElse("N/A"));
System.out.printf("Start time: %s%n", info.startInstant().map(i -> i.toString()).orElse("N/A"));

Example: Finding Child Processes

The children() method returns a Stream of ProcessHandle objects for the direct child processes.

// Get a stream of child processes
Stream<ProcessHandle> childProcesses = ProcessHandle.current().children();

// Filter for currently running children and print their details
childProcesses
    .filter(ProcessHandle::isAlive)
    .forEach(childProcess -> {
        System.out.printf("Child PID: %s, Command: %s%n", 
            childProcess.pid(), 
            childProcess.info().command().orElse("N/A")
        );
    });

Python - Dictionaries

In Python, a dictionary is a built-in data type that stores data in key-value pairs. It is an unordered, mutable, and indexed collection where each unique key maps to a value. Dictionaries are widely used to store related data accessible via keys.

Dictionaries are a type of mapping, associating keys and values with a colon (:), with pairs separated by commas and enclosed in curly braces {}.

Key Features of Dictionaries

  • Unordered (before Python 3.7) but maintain insertion order in Python 3.7 and later.
  • Mutable: items can be added, changed, or removed.
  • Indexed by unique keys (not by positions).
  • Keys must be immutable types like strings, numbers, or tuples.
  • Values can be any data type, including mutable types.

Examples of Dictionaries


capitals = {
  "Maharashtra": "Mumbai",
  "Gujarat": "Gandhinagar",
  "Telangana": "Hyderabad",
  "Karnataka": "Bengaluru"
}

numbers = {
  10: "Ten",

  30: "Thirty",
  40: "Forty"
}

marks = {
  "Savita": 67,
  "Imtiaz": 88,
  "Laxman": 91,

}

Dictionary Creation

Create dictionaries by enclosing comma-separated key:value pairs in curly braces { }. Alternatively, use the dict() function.


# Using curly braces
sports_player = {
  "Name": "Sachin Tendulkar",
  "Age": 48,
  "Sport": "Cricket"
}

# Using dict() function
student_info = dict(name="Alice", age=21, major="Computer Science")

print("Dictionary using curly braces:", sports_player)
print("Dictionary using dict():", student_info)

Accessing Dictionary Items

You can access values by keys using square brackets [] or the get() method.


student_info = {
  "name": "Alice",
  "age": 21,
  "major": "Computer Science"
}

name = student_info["name"]
print("Name:", name)

age = student_info.get("age")
print("Age:", age)

Modifying Dictionary Items

You can change values or add new key-value pairs by assignment.


student_info["age"] = 22           # Modify existing key
student_info["graduation_year"] = 2023  # Add new key-value pair

print("The modified dictionary is:", student_info)

Removing Dictionary Items

You can remove items using del, pop(), or popitem() methods.


del student_info["major"]            # Remove by key
graduation_year = student_info.pop("graduation_year")  # Remove and return value

print(student_info)

Iterating Through a Dictionary

Loop through keys, values, or key-value pairs using:


# Iterating through keys
for key in student_info:
  print("Keys:", key, student_info[key])

# Iterating through values
for value in student_info.values():
  print("Values:", value)

# Iterating through key-value pairs
for key, value in student_info.items():
  print("Key:Value:", key, value)

Properties of Dictionary Keys

  • Keys must be unique; duplicate keys overwrite previous values.
  • Keys must be immutable types such as strings, numbers, or tuples.
  • Using mutable types (e.g., lists) as keys raises TypeError.

dict = {'Name': 'Zara', 'Age': 7, 'Name': 'Manni'}
print("dict['Name']: ", dict['Name'])

# Output: dict['Name']: Manni

# Using a list as key (TypeError)
dict = {['Name']: 'Zara', 'Age': 7}
print(dict['Name'])  # Raises TypeError: unhashable type: 'list'

Dictionary Operators

Python defines various operators to use with dictionaries:

Operator Description Example
dict[key] Extract or assign the value mapped with key. print(d1['b']) retrieves value 4;
d1['b'] = 'Z' assigns new value.
dict1 | dict2 Union of two dictionaries returning a new object. d3 = d1 | d2, combines keys and values from both.
dict1 |= dict2 Augmented dictionary union operator; updates dict1 with dict2’s items. d1 |= d2

Dictionary Methods

  • dict.clear(): Removes all items.
  • dict.copy(): Returns shallow copy.
  • dict.fromkeys(): Creates new dictionary from sequence of keys.
  • dict.get(key, default): Gets value for key or default.
  • dict.items(): Returns view of (key, value) pairs.
  • dict.keys(): Returns view of keys.
  • dict.setdefault(key, default): Like get, but sets key to default if missing.
  • dict.update(): Updates with another dict's items.
  • dict.values(): Returns view of values.

Built-in Functions With Dictionaries

  • cmp(dict1, dict2): Compares elements of both dictionaries (Python 2 only).
  • len(dict): Returns number of items.
  • str(dict): Returns string representation of dictionary.
  • type(variable): Returns type of variable; dictionary type for dict objects.

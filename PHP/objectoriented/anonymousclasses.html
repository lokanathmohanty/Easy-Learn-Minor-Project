PHP: Anonymous Classes

**Anonymous Classes** (introduced in PHP 7.0) are classes that are instantiated and defined simultaneously, and they do not have a programmer-declared name. They are designed for **one-time use** when you need a simple, single-use object without the overhead of defining a full, named class.

Creating an Anonymous Class

An anonymous class is created using the new class() syntax, where the entire class body immediately follows:

$obj = new class() {
   // properties and methods
};

Key Features and Usage

  • One-Time Use: Ideal for simple, disposable objects, such as mocks for testing or implementing an interface for a single service call.
  • **Functionality:** They are functionally identical to named classes; they can have constructors, properties, methods, and access modifiers.
  • **OOP Support:** An anonymous class can **extend** a named class, **implement** an interface, or **use** a trait.
  • **Internal Name:** While they lack a declared name, the PHP parser assigns them an internal name (e.g., class@anonymous...), which can be retrieved using get_class($obj).

Dependencies

Dependencies (such as objects or services) must be passed to the anonymous class via its **constructor** to be available internally, just like a named class.

Example Session

Anonymous Class Extending a Parent

This example shows an anonymous class extending myclass to reuse the hello() method while adding its own constructor and methods.


class myclass {
   public function hello() {
      echo "Base: Hello World!" . PHP_EOL;
   }
}

// Anonymous class is instantiated and extends 'myclass'
$obj = new class("Neena") extends myclass {
   private string $nm;
   
   function __construct($x) {
      $this->nm = $x;
   }
   
   public function greeting() {
      // Calls method from the parent class
      parent::hello(); 
      echo "Welcome " . $this->nm . "!" . PHP_EOL;
   }
};

$obj->greeting();
// Output:
// Base: Hello World!
// Welcome Neena!

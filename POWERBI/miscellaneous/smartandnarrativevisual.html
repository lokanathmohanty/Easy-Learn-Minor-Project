Power BI: Smart Narrative Visual

The Smart Narrative visual in Power BI helps non-technical users understand complex data stories by summarizing key insights from multiple visuals on the report canvas. It automatically generates textual summaries explaining the main trends, comparisons, and values, enriching business reporting and analysis.

This visual is particularly useful for business users who want to grasp important findings without deep data expertise, enabling them to communicate insights clearly and make informed decisions.

Generating a Smart Narrative

There are two primary ways to generate a Smart Narrative visual:

  • Summarize Option: Right-click a visual (e.g., a Pie Chart) and select "Summarize". This creates a smart narrative reflecting the visual's data.
  • Smart Narrative Visual: Add the Smart Narrative visual from the Visualizations pane, which generates key points for selected visuals on the report.

Users can expand summaries with "+ Value" buttons to add further dynamic calculations, assign names to dynamic queries, and save customized narratives.

Using and Customizing the Smart Narrative

Smart Narrative visuals aggregate insights from related charts, such as pie charts and column charts, into text summaries displayed on the report canvas. Users can manually add new insights or dynamic values for more detailed stories.

Formatting options in the Format pane include:

  • Properties: Adjust size, position, padding, and advanced layout options.
  • Title: Enable and customize title text, font style (e.g., Comic Sans MS), size, text color, background color, and headings.
  • Effects: Apply background colors, visual borders, and shadows to enhance appearance.
  • Header Icons: Customize header icon colors including background and border for a polished look.
  • Alt Text: Add descriptive alt text for accessibility; screen readers will read this description aloud.

What is a Paginated Report?

Paginated reports are pixel-perfect reports designed for printing or sharing large datasets without loss of data. They maintain the original page format and are ideal for scenarios with millions of rows, such as bank statements, invoices, and card bills.

The Power BI Report Builder is a free tool from Microsoft used to create paginated reports. It supports multiple data sources and allows publishing and sharing reports within an organization.

Users with PPU or Pro licenses can broadcast paginated reports to other business users.

Generating a Paginated Report in the Report Builder Tool

  1. Open the Report Builder tool.
  2. Navigate to the File tab and click Open.
  3. Select the .rdl file from This PC.
  4. The report design view opens with formatting options such as Font, Paragraph, Border, Number, and Layout.
  5. Click Publish to connect to the Power BI service and broadcast the report to users.

Rendering a Report with Field Values and Column Headings

  1. Sign in to your Microsoft account.
  2. Click Run under the Views tab to generate the paginated report.
  3. Print the report using options like Print, Page Setup, and Print Layout.
  4. Export the report into various formats: XML, Word, TIFF, PDF, PowerPoint, etc.

Developing a Paginated Report in Power BI Desktop

  1. Open Power BI Desktop and select Paginated Report from Visualizations.
  2. Choose either Create paginated report or Connect to report.
  3. Click Create paginated report, which connects to Power BI service after sign-in.
  4. Select the aq database and click Create paginated report.
  5. Choose a worksheet, e.g., Sheet1, from the Data pane to develop the report.

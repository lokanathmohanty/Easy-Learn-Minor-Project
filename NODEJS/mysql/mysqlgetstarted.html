Node.js - MySQL Integration

Overview

Node.js applications commonly interface with backend databases for persistent data storage and retrieval. MySQL is a widely used open-source relational database management system (RDBMS).

MySQL uses SQL to manage data, control user access and perform tasks such as data creation, modification, and backup.

MySQL Installation

On Ubuntu (Linux)

  • Update package info: sudo apt-get update
  • Install MySQL server: sudo apt-get install mysql-server
  • Configure root user password during installation
  • Install MySQL Workbench: sudo apt-get install mysql-workbench
  • Manage MySQL with systemctl status mysql

On Windows

  • Download installer from MySQL official site
  • Run the MSI installer and choose "Full" setup
  • Set a strong root password during installation
  • Use MySQL Workbench GUI or MySQL command-line client for managing databases

Connecting Node.js to MySQL

Use the mysql module from npm, which is simple to use and MIT licensed.

Install the module:

npm install mysql

Sample Connection Code

var mysql = require('mysql');

var con = mysql.createConnection({
  host: "localhost",
  user: "root",
  password: "your_password"
});

con.connect(function(err) {
  if (err) throw err;
  console.log("Connected!");
});

After connecting, you can use standard SQL queries and the connection object's methods to interact with MySQL databases.

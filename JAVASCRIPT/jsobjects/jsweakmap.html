JavaScript - The WeakMap Object

A WeakMap object in JavaScript is a collection of key-value pairs where the keys are weakly referenced. The keys must be objects or non-registered symbols, while values can be of any arbitrary JavaScript type.

The difference between WeakMap and Map is that:

  • Map can use any type of value as a key.
  • WeakMap keys must be objects.
If you try to use a non-object key in a WeakMap, a TypeError occurs.

Syntax

const weak_map = new WeakMap();

The new keyword with WeakMap() creates a new WeakMap instance.

WeakMap Properties

  • constructor – returns the constructor function of a WeakMap.

WeakMap Methods

  • delete() – deletes a single key-value pair.
  • get() – retrieves the value for a given key.
  • has() – checks whether a key exists.
  • set() – inserts a new key-value pair.

WeakMap Constructor()

  • WeakMap() – creates a new WeakMap object.

Examples

Example: Inserting key-value pair

<html>
<body>
   <p id="output">The laptop price is: </p>
   <script>
      const wm = new WeakMap();
      const laptop = { brand: "HP", model: "Pavilion" };

      wm.set(laptop, 100000);
      document.getElementById("output").innerHTML += wm.get(laptop);
   </script>
</body>
</html>

Output: The laptop price is: 100000

Example: Deleting key-value pair

<html>
<body>
   <div id="output1">The laptop price is: </div>
   <div id="output2">The laptop price after deletion is: </div>
   <script>
      const wm = new WeakMap();
      const laptop = { brand: "HP", model: "Pavilion" };

      wm.set(laptop, 100000);
      document.getElementById("output1").innerHTML += wm.get(laptop);

      wm.delete(laptop);
      document.getElementById("output2").innerHTML += wm.get(laptop);
   </script>
</body>
</html>

Output:
The laptop price is: 100000
The laptop price after deletion is: undefined

Note

WeakMaps are not iterable in JavaScript.

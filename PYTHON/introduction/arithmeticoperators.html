Python - Arithmetic Operators

Introduction

Python arithmetic operators are used to perform mathematical operations such as addition, subtraction, multiplication, division, and more on numbers. These are binary operators as they operate on two operands. Python also supports mixed arithmetic, allowing operands of different types.

Types of Arithmetic Operators

  • + → Addition
  • - → Subtraction
  • * → Multiplication
  • / → Division
  • % → Modulus
  • ** → Exponent
  • // → Floor Division

Addition Operator

Represents by +. Adds two operands and returns the result.

a=10
b=20
print("Addition of two integers:", a+b)

a=10
b=20.5
print("Addition of integer and float:", a+b)

a=10+5j
b=20.5
print("Addition of complex and float:", a+b)

Subtraction Operator

Represents by -. Subtracts right operand from left operand.

a=10
b=20
print("a-b =", a-b, " b-a =", b-a)

a=10
b=20.5
print("a-b =", a-b, " b-a =", b-a)

a=10+5j
b=20.5
print("a-b =", a-b, " b-a =", b-a)

Multiplication Operator

Represents by *. Returns the product of operands.

a=10
b=20
print("a*b =", a*b)

a=10
b=20.5
print("a*b =", a*b)

a=-5.55
b=6.75E-3
print("a*b =", a*b)

a=10+5j
b=20.5
print("a*b =", a*b)

Division Operator

Represents by /. Returns the quotient as float.

a=10
b=20
print("a/b =", a/b, " b/a =", b/a)

a=10
b=-20.5
print("a/b =", a/b)

a=7.5+7.5j
b=2.5
print("a/b =", a/b, " b/a =", b/a)

Modulus Operator

Represents by %. Returns remainder after division.

a=10
b=2
print("a%b =", a%b)

a=10
b=4
print("a%b =", a%b, " b%a =", b%a)

a=10
b=2.5
print("a%b =", a%b)

Exponent Operator

Represents by **. Returns power of operand.

a=10
b=2
print("a**b =", a**b)

a=10
b=1.5
print("a**b =", a**b)

a=1+2j
b=4
print("a**b =", a**b)

Floor Division Operator

Represents by //. Returns quotient without fractional part.

a=9
b=2
print("a//b =", a//b)

a=9
b=-2
print("a//b =", a//b)

a=10
b=1.5
print("a//b =", a//b)

Precedence & Associativity

Operator(s)DescriptionAssociativity
**ExponentRight to Left
%, *, /, //Modulus, Multiplication, Division, Floor DivisionLeft to Right
+, -Addition, SubtractionLeft to Right

Arithmetic with Complex Numbers

Addition & Subtraction

a=2.5+3.4j
b=-3+1j
print("a+b =", a+b)
print("a-b =", a-b)

Multiplication

a=6+4j
b=3+2j
print("a*b =", a*b)

Division

a=6+4j
b=3+2j
print("a/b =", a/b)

Note: Complex class in Python does not support % and // operators.

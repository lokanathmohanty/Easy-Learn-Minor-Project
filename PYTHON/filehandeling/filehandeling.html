Introduction

File handling in Python involves interacting with files to read or write data. Python provides built-in functions and methods for opening, reading, writing, and closing files safely and efficiently.

Opening a File

The open() function is used to open files with specified modes:

  • r: Read only (default)
  • w: Write only (overwrites or creates new file)
  • a: Append (adds to end or creates new file)
  • r+: Read/write
  • b: Binary mode (used with other modes)
  • x: Create new file, fail if exists

Reading from a File

Common methods for reading file data:

  • read(): Reads entire file as string
  • readline(): Reads one line at a time
  • readlines(): Reads all lines into a list

Writing to a File

Writing methods include:

  • write(): Writes a string to the file
  • writelines(): Writes sequence of strings

Closing a File

It is important to close files after operations to release resources. Use close() explicitly or (preferably) use a with block that auto-closes the file.

Exception Handling for File Closing

Use try...finally construct to ensure files are closed even if exceptions occur during file operations.

Example: Open and Read a File

with open("example.txt", "r") as file:
content = file.read()
print(content)

Example: Write to a File

with open("example.txt", "w") as file:
file.write("Hello, World!\n")
file.write("This is a new line.\n")

Example: Append to an Existing File

with open("example.txt", "a") as file:
file.write("Adding a new line.\n")

Example: Manual File Open and Close

file = open("example.txt", "w")

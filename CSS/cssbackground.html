CSS Backgrounds

CSS backgrounds define the background colors and images of HTML elements. They allow you to use different colors, gradients, or images behind the content. In this chapter, we will learn about various CSS background properties, including how to set background colors, apply images, adjust their size and position, control repetition, and more.

CSS Background Shorthand Property

The background shorthand property allows you to specify all background properties in a single declaration. The correct order when using the shorthand is:

  • background-color
  • background-image
  • background-position
  • background-size (must be used with /)
  • background-repeat
  • background-origin
  • background-attachment
  • background-clip

Syntax:

background: bg-color bg-image bg-position bg-size bg-repeat bg-origin bg-clip bg-attachment | initial | inherit;

Example:

background: green url('image.jpg') top/20% no-repeat border-box content-box fixed;

Note: If you include background-size it must follow background-position separated by / (e.g. left/50%).

Setting Background Color

You can set the background color for elements like div, span, body, p using background-color.

Example (various color value formats):

<!DOCTYPE html>
<html>
<head>
  <style>
    body { background-color: lightgray; }
    .firstDiv { background-color: rgb(255, 215, 0); }
    .secondDiv { background-color: #f0f0f0; }
    .thirdDiv { background-color: hsl(120, 100%, 75%); }
  </style>
</head>
<body>
  <h2>CSS Background Colors</h2>
  <div class="firstDiv">Color: rgb(255, 215, 0)</div>
  <div class="secondDiv">Color: #f0f0f0</div>
  <div class="thirdDiv">Color: hsl(120, 100%, 75%)</div>
</body>
</html>

Setting Images in Background

Use background-image to set one or more images. Multiple images are separated by commas.

Example:

<!DOCTYPE html>
<html lang="en">
<head>
  <style>
    body { background-image: url('/css/images/logo.png'); height: 350px; }
    div { background-color: rgba(255,255,255,0.7); padding: 20px; }
  </style>
</head>
<body>
  <div>
    <h1>Welcome to My Website</h1>
    <p>This is an example of setting a background image using CSS</p>
  </div>
</body>
</html>

Define Background Position

background-position sets the initial position of the background image. It is relative to background-origin.

Example (position to the right):

<!DOCTYPE html>
<html>
<head>
  <style>
    .position-right {
      background-image: url('/css/images/logo.png');
      background-position: right;
      background-repeat: no-repeat;
      width: 100%;
      height: 300px;
      border: 3px solid black;
    }
  </style>
</head>
<body>
  <div class="position-right"></div>
</body>
</html>

Setting Background Size

background-size controls how the background image is scaled (e.g. contain, cover, explicit sizes).

Example (contain):

<!DOCTYPE html>
<html>
<head>
  <style>
    .size-contain {
      background-image: url('/css/images/pink-flower.jpg');
      background-size: contain;
      width: 300px;
      height: 300px;
    }
  </style>
</head>
<body>
  <h2>CSS background-size property</h2>
  <div class="size-contain"></div>
</body>
</html>

Repeating Background Image

background-repeat controls repetition (e.g. repeat, no-repeat, repeat-x, repeat-y).

Example (repeat):

<!DOCTYPE html>
<html>
<head>
  <style>
    .repeat {
      background-image: url('/css/images/logo.png');
      background-repeat: repeat;
      width: 800px;
      height: 400px;
    }
  </style>
</head>
<body>
  <h2>CSS background-repeat property</h2>
  <div class="repeat"></div>
</body>
</html>

Defining Background Origin

background-origin sets the origin area used to position the background: border-box, padding-box, or content-box.

Example (content-box):

<!DOCTYPE html>
<html>
<head>
  <style>
    div {
      border: 10px dashed rgb(13,7,190);
      margin: 5px;
      padding: 1cm;
      display: inline-block;
      background-image: url('/css/images/yellow-flower.jpg');
      height: 200px;
      width: 200px;
      background-size: contain;
    }
    .content-box { background-origin: content-box; }
  </style>
</head>
<body>
  <div class="content-box"></div>
  <p>This image background starts from the content box of the div element.</p>
</body>
</html>

Controlling Background Scrolling

background-attachment determines whether the background is fixed within the viewport (fixed) or scrolls with its container (scroll).

Example (fixed):

<!DOCTYPE html>
<html>
<head>
  <style>
    .fixed {
      background-image: url('images/logo.png');
      background-repeat: no-repeat;
      background-attachment: fixed;
      background-position: left top;
      background-size: 40% 30%;
      width: 250px;
      height: 500px;
      padding: 5rem;
    }
  </style>
</head>
<body>
  <h2>CSS background-attachment Property</h2>
  <div class="fixed">
    <p>Lorem Ipsum sample text...</p>
  </div>
</body>
</html>

Controlling Background Display

background-clip specifies the painting area of the background: border-box, padding-box, or content-box.

Example:

<!DOCTYPE html>
<html>
<head>
  <style>
    p { border: 10px dotted black; padding: 15px; background: green; color: white; }
    .border-area { background-clip: border-box; }
    .padding-area { background-clip: padding-box; }
  </style>
</head>
<body>
  <h2>CSS background-clip property</h2>
  <p class="border-area">Background applied to the entire element.</p>
  <p class="padding-area">Background applied to the content & padding area.</p>
</body>
</html>

CSS Background Properties (Overview)

  • background — shorthand for background-related properties.
  • background-attachment — fixed or scrollable relative to viewport.
  • background-clip — how far the background extends (border/padding/content).
  • background-color — sets background color.
  • background-image — sets one or more background images.
  • background-origin — sets the origin area for positioning.
  • background-position — sets initial position of each background image.
  • background-position-x — horizontal position of the background image.
  • background-position-y — vertical position of the background image.
  • background-repeat — controls repetition of the background image.
  • background-size — controls scaling of the background image.
  • background-blend-mode — determines how background images blend with each other.

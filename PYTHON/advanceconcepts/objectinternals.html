Python - Object Internals

Understanding Python's object internals gives insight into how Python manages and manipulates data. This includes the object's structure, identity, type, value, memory management, and attributes/methods.

Such knowledge is crucial for writing efficient code and debugging effectively.

Object Structure

Every Python object consists of two main parts:

  • Object Header: Contains essential information for the interpreter like reference count and type pointer.
  • Object Data: Holds the actual data, differing per object type (e.g., numeric value for int, list references for lists).

Object Identity

Object identity is a unique integer representing the object’s memory address and remains constant during its lifetime. Use id() to get this value. 

a = "Tutorialspoint"
print(id(a))  # Example of getting the id of a string object

Note: The memory address can change on each run.

Object Type

The type defines what operations an object supports, accessed by the type() function. 

a = "Tutorialspoint"
print(type(a))

Output example:

<class 'str'>

Object Value

The value represents the actual data held by an object, such as primitive values or complex data structures. 

b = "Welcome to Tutorialspoint"
print(b)

Output:

Welcome to Tutorialspoint

Memory Management

Python manages memory using reference counting and garbage collection. Each object tracks how many references point to it; when none remain, the memory is freed. 

import sys
c = [1, 2, 3]
print(sys.getrefcount(c))  # Shows the reference count

An example output could be:

2

The count is 2 because the argument to getrefcount() temporarily increases the count.

Attributes and Methods

Python objects have attributes (data) and methods (functions) accessed via dot notation. 

class MyClass:
   def __init__(self, value):
      self.value = value

   def display(self):
      print(self.value)

obj = MyClass(10)
obj.display()

Output:

10

Join Arrays in Python

Joining two arrays in Python (merging or concatenating) requires both arrays to have the same data type. Python provides several ways to join arrays using the array module.

Using append() Method

Append each element of the second array to the first using a loop and the append() method.

import array as arr

# creating two arrays
a = arr.array('i', [10, 5, 15, 4, 6, 20, 9])
b = arr.array('i', [2, 7, 8, 11, 3, 10])

# merging arrays
for i in range(len(b)):
    a.append(b[i])

print(a)
# Output: array('i', [10, 5, 15, 4, 6, 20, 9, 2, 7, 8, 11, 3, 10])

Using + Operator

Convert arrays to lists, concatenate with +, then convert back to an array.

import array as arr

a = arr.array('i', [10, 5, 15, 4, 6, 20, 9])
b = arr.array('i', [2, 7, 8, 11, 3, 10])

x = a.tolist()
y = b.tolist()

a = arr.array('i', x + y)
print(a)
# Output: array('i', [10, 5, 15, 4, 6, 20, 9, 2, 7, 8, 11, 3, 10])

Using extend() Method

Extend the first array by appending all elements from the second array using the extend() method after converting to a list.

import array as arr

a = arr.array('i', [88, 99, 77, 66, 44, 22])
b = arr.array('i', [12, 17, 18, 11, 13, 10])

a.extend(b)
print(a)
# Output: array('i', [88, 99, 77, 66, 44, 22, 12, 17, 18, 11, 13, 10])

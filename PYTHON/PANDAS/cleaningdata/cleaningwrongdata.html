Pandas - Fixing Wrong Data

Wrong data is not limited to empty cells or incorrect formats. It can simply be values that don’t make sense in the context of your dataset. For example, if a workout session shows a duration of 450 minutes while all others are between 30 and 60, it’s likely an error.

When analyzing data, spotting outliers or inconsistencies like this is important, especially when you have an idea of what the data should generally look like.

There are a couple of common strategies to deal with such issues: replacing the wrong values or removing the affected rows.

Example: Replacing a Specific Wrong Value

In this example, we assume that the Duration value of 450 is a typo and should be 45 instead. We can manually replace the value using the row index.


df.loc[7, 'Duration'] = 45

Example: Replacing Values Based on a Rule

For larger datasets, we can define rules to clean the data. For example, we might assume any workout longer than 120 minutes is invalid and set it to 120:


for x in df.index:
    if df.loc[x, "Duration"] > 120:
        df.loc[x, "Duration"] = 120

Example: Removing Rows with Wrong Data

If you prefer to remove problematic data instead of replacing it, you can drop the rows that contain suspicious values. Here’s how to delete rows where Duration is greater than 120:


for x in df.index:
    if df.loc[x, "Duration"] > 120:
        df.drop(x, inplace=True)

Node.js - Upload Files

Overview

Node.js is an excellent choice for handling file uploads due to its non-blocking architecture and ability to efficiently manage concurrent requests.

File uploading consists of sending files from the client browser to a server over HTTP, which processes and stores the files or performs actions based on them.

Tools Used

  • Express: Minimal web framework to handle HTTP requests and responses.
  • Multer: Middleware for handling file uploads in Express.

Setting Up the Project

  1. Create a project folder and navigate to it: 
    mkdir file-test
cd file-test
  2. Initialize Node.js application with default configs: 
    npm init -y
  3. Install dependencies Express and Multer: 
    npm install express multer

Project Structure & Code

Import dependencies:

const express = require('express');
const multer = require('multer');
const path = require('path');
const fs = require('fs');

Set up Multer storage configuration:

const storage = multer.diskStorage({
  destination: (req, file, cb) => {
    cb(null, './test');
  },
  filename: (req, file, cb) => {
    cb(null, Date.now() + path.extname(file.originalname));
  },
});

Initialize Multer with the storage config:

const upload = multer({ storage: storage });

Create the 'test' folder if it does not exist:

if (!fs.existsSync('./test')) {
  fs.mkdirSync('./test');
}

Routes

POST route to handle single file upload:

app.post('/upload', upload.single('file'), (req, res) => {
  if (!req.file) {
    return res.status(400).send('No file uploaded');
  }
  res.send(`File uploaded successfully: ${req.file.filename}`);
});

Example: Complete 'tp.js' File

const express = require('express');
const multer = require('multer');
const path = require('path');
const fs = require('fs');

const app = express();
const port = 1121;

const storage = multer.diskStorage({
  destination: (req, file, cb) => {
    cb(null, './test');
  },
  filename: (req, file, cb) => {
    cb(null, Date.now() + path.extname(file.originalname));
  },
});

const upload = multer({ storage: storage });

if (!fs.existsSync('./test')) {
  fs.mkdirSync('./test');
}

app.post('/upload', upload.single('file'), (req, res) => {
  if (!req.file) {
    return res.status(400).send('No file uploaded');
  }
  res.send(`File uploaded successfully: ${req.file.filename}`);
});

app.get('/', (req, res) => {
  res.send(\`
    
Upload a File

    

      
      
    

  \`);
});

app.listen(port, () => {
  console.log(\`Server is running at http://localhost:\${port}\`);
});

Running the Server

Use the command:

node tp.js

Access http://localhost:1121 in your browser to upload files via the form.

Additional Features

File Size Limit

const upload = multer({
  storage: storage,
  limits: { fileSize: 10 * 1024 * 1024 }
});

Limits upload size to 10MB and rejects larger files.

Multiple File Uploads

app.post('/upload', upload.array('x', 4), (req, res) => {
  if (!req.x) {
    return res.status(400).send('No files uploaded');
  }
  res.send(`Successfully uploaded ${req.x.length} files`);
});

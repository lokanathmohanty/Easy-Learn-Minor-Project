ReactJS - Pagination

Introduction

React provides pagination components through third-party UI libraries. One of the most popular is React Bootstrap, which ports almost all Bootstrap components, including a fully featured Pagination component.

Pagination Component

The Pagination component allows creating simple pagination with Bootstrap styling. It includes the following subcomponents:

  • Pagination.Item
  • Pagination.First
  • Pagination.Last
  • Pagination.Previous
  • Pagination.Next

Props for Pagination

  • size (sm | lg) – Set the size of the pagination buttons
  • bsPrefix (string) – Change the underlying component CSS

Props for Pagination.Item

  • active (boolean) – Marks the item as active
  • activeLabel (string) – Label for active state
  • disabled (boolean) – Disables the item
  • href (string) – Link for the pagination item
  • onClick (function) – Callback on click

Applying Pagination

  1. Create a new React app:

create-react-app myapp
cd myapp
npm start
  1. Install Bootstrap and React Bootstrap:

npm install --save bootstrap react-bootstrap
  1. Create SimplePagination component:

import React from 'react';
import { Table, Pagination } from 'react-bootstrap';

class SimplePagination extends React.Component {
   render() {
      return <div>Pagination component</div>
   }
}

export default SimplePagination;
  1. Add users.json in public folder with sample data.
  2. Initialize state in the constructor with users, usersToBeShown, and currentPage.
  3. Fetch users in componentDidMount and prepare pagination details.
  4. Implement calculatePaginationDetails method to compute pages and visible users.
  5. Add handlePagination event handler.

Rendering Table with Pagination

The render method includes a Table for user data and a Pagination component for navigation:


<Table bordered hover striped>
   <thead>
      <tr>
         <th>#</th>
         <th>Name</th>
         <th>Age</th>
         <th>Email</th>
      </tr>
   </thead>
   <tbody>
      {this.state.usersToBeShown.map(item => (
         <tr key={item.id}>
            <td>{item.id}</td>
            <td>{item.name}</td>
            <td>{item.age}</td>
            <td>{item.name.toLowerCase()}.example@tutorialspoint.com</td>
         </tr>
      ))}
   </tbody>
</Table>

<Pagination>
   <Pagination.First onClick={this.handlePagination} />
   <Pagination.Prev onClick={this.handlePagination} />
   {this.state.pageArray.map(item => (
      <Pagination.Item 
         key={item} 
         onClick={this.handlePagination}
         active={this.state.currentPage === item}
      >{item}</Pagination.Item>
   ))}
   <Pagination.Next onClick={this.handlePagination} />
   <Pagination.Last onClick={this.handlePagination} />
</Pagination>

Using the Component

Update App.js to use SimplePagination:


import './App.css'
import "bootstrap/dist/css/bootstrap.min.css";
import SimplePagination from './Components/SimplePagination';

function App() {
   return (
      <div className="container">
         <SimplePagination />
      </div>
   );
}

export default App;

Summary

React Bootstrap’s Pagination component provides flexible APIs for rendering simple or complex pagination designs in React applications.

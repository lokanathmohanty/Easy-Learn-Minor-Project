.NET Core - SDK (Focusing on Tooling and CLI Updates)

Previous | Quiz | Next

This chapter explores the updates and new features being introduced in the **.NET Core SDK**, particularly focusing on the evolution of the **.NET Command Line Interface (CLI)** tools.

Exploring the .NET CLI

Information regarding the .NET CLI development progress and source code can be found on GitHub: https://github.com/dotnet/cli

Checking the Current Tooling Version

To view the currently installed version of the .NET Command Line Tools on your system, execute the following command in the command prompt:

Command

dotnet --info

Initially, the system had **preview 2 tooling** installed.

Initial dotnet new Command Help

To get information about the available templates for creating new projects, the dotnet help new command is used. This command outlines how to select the language (like C# or F#) and the type of project to be created.

Command

dotnet help new

Upgrading and Verifying the SDK

To explore the latest features, the newest version of the **.NET Core SDK preview tools** is downloaded and installed. This process involves:

  1. Downloading the installer from the **Installer and Binaries** section (e.g., selecting the installer for .NET Core 2.0 preview 1).
  2. Running the installer and clicking **Install** to start the process.
  3. Once installation is finished, closing the dialog.

Verifying the New Tooling Version

After the installation is complete, running the dotnet --info command again shows the updated version:

Command and Result

dotnet --info

The output now shows that the system has **preview1 tooling of .NET Core 2** installed.

New Features in dotnet new (Preview 1, .NET Core 2)

Running dotnet help new after the update reveals new and improved functionality for project creation. The new tooling is capable of downloading packages to the package cache and offers significantly more templates.

With the updated **.NET Core 2 preview1** tools, developers can now create .NET Core applications using new templates directly from the command line, including:

  • **mstest** (MSTest Unit Test Project)
  • **web** (Basic Web Application)
  • **mvc** (Model-View-Controller Web Application)
  • **webapi** (Web API Project)

This expansion provides greater flexibility and speed for scaffolding different types of .NET Core applications using the command line.

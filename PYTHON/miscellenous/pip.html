Python - PIP (Package Installer)

pip is the standard package management system in Python used to install and manage software packages from the Python Package Index (PyPI). Starting from Python 3.4, pip is bundled with the language for easy package management.

Installing pip

For Python 3.4+, pip is pre-installed. If missing, install pip via the following steps:

  • Download get-pip.py script: curl https://bootstrap.pypa.io/get-pip.py -o get-pip.py
  • Run the script: python get-pip.py

Installing Packages with pip

Use pip to install packages from the official repository PyPI.

pip install package_name

Example: To install the requests library:

pip install requests

To install a specific version:

pip install requests==2.25.1

Install multiple packages at once:

pip install numpy pandas matplotlib

Upgrading Packages

Upgrade an installed package to the latest version with:

pip install --upgrade package_name

Example: Upgrade requests:

pip install --upgrade requests

Listing Installed Packages

List all installed packages and their versions with:

pip list

Get detailed info about a package:

pip show requests

List outdated packages available for upgrade:

pip list --outdated

Uninstalling Packages

Uninstall packages when no longer needed:

pip uninstall package_name

You can uninstall multiple packages at once by listing them:

pip uninstall numpy pandas

Freezing Installed Packages

Generate a requirements.txt file listing all installed packages with versions to recreate environments: 

pip freeze > requirements.txt

Install packages from this file in another environment:

pip install -r requirements.txt

Using Virtual Environments

Virtual environments isolate dependencies per project, avoiding conflicts:

  • Create a virtual environment: python -m venv myenv
  • Activate on Windows: myenv\Scripts\activate
  • Activate on macOS/Linux: source myenv/bin/activate
  • Deactivate: deactivate
  • Delete virtual environment by deleting its directory.

Python - Modify Strings

String modification refers to the process of changing the characters of a string. In Python, modifying a string actually means creating a new string that is a variation of the original one.

Immutability of Strings

A string in Python (an object of the str class) is immutable. This means once it is created in memory, it cannot be modified in place. Unlike a list, you cannot overwrite, insert, or append characters directly. To modify a string, we use certain methods or workarounds that return a new string, while the original remains unchanged.

Workarounds to Modify Strings

1. Converting a String to a List

Since both strings and lists are sequence types, we can cast a string into a list, modify the list, and then convert it back into a string using join().

Example:

s1 = "WORD"
print("original string:", s1)
l1 = list(s1)

l1.insert(3, "L")
print(l1)

s1 = ''.join(l1)
print("Modified string:", s1)

Output:

original string: WORD
['W', 'O', 'R', 'L', 'D']
Modified string: WORLD

2. Using the Array Module

The array module from Python’s standard library can construct an array of Unicode characters from a string. You can then insert or modify elements and convert it back to a string.

Example:

import array as ar

s1 = "WORD"
print("original string:", s1)

sar = ar.array('u', s1)
sar.insert(3, "L")

s1 = sar.tounicode()
print("Modified string:", s1)

Output:

original string: WORD
Modified string: WORLD

3. Using the StringIO Class

The io module provides the StringIO class, which creates an in-memory text stream. It behaves like a file object, allowing read/write operations. The getvalue() method retrieves the modified string.

Example:

import io

s1 = "WORD"
print("original string:", s1)

sio = io.StringIO(s1)
sio.seek(3)
sio.write("LD")
s1 = sio.getvalue()

print("Modified string:", s1)

Output:

original string: WORD
Modified string: WORLD

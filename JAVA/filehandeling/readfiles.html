Java - Reading File

Reading a file is a fundamental task in Java, and several classes and methods in the Java API make this process efficient and flexible. The three most common approaches are using FileInputStream, FileReader, and Files.readAllLines(). Each provides different capabilities for reading file data as bytes, characters, or a list of lines.

Reading File Using FileInputStream

FileInputStream is used for reading file content as bytes. It is suitable for working with binary files or when low-level data access is necessary.

InputStream f = new FileInputStream("C:/java/hello.txt");

Alternatively, construct using a File object:

File file = new File("C:/java/hello.txt");
InputStream f = new FileInputStream(file);

Example:

byte bWrite[] = {65, 66, 67, 68, 69};
OutputStream os = new FileOutputStream("test.txt");
for(int x = 0; x < bWrite.length ; x++) {
   os.write( bWrite[x] );
}
os.close();

InputStream is = new FileInputStream("test.txt");
int size = is.available();
for(int i = 0; i < size; i++) {
   System.out.print((char)is.read() + "  ");
}
is.close();

This code writes bytes to test.txt and reads them back, displaying characters: A B C D E

Reading File Using FileReader.read()

FileReader reads files as character streams, making it suitable for text files.

File file = new File("d://test//testFile1.txt");
FileReader reader = new FileReader(file);
int c;
while ((c = reader.read()) != -1) {
   char ch = (char) c;
   System.out.print(ch);
}
reader.close();

This example creates or opens a file, writes a string, and reads the content character by character.

Reading File Using Files.readAllLines()

The Files.readAllLines() method (Java NIO) reads all lines from a file into a List<String>, making it convenient for processing large text files or configuration files.

List<String> content = Files.readAllLines(Paths.get("d://test/testFile3.txt"));

Example:

String data = "Test data";
Files.write(Paths.get("d://test/testFile3.txt"), data.getBytes());
List<String> content = Files.readAllLines(Paths.get("d://test/testFile3.txt"));
System.out.println(content); // Output: [Test data]

Working with multiple files or appending lines is also straightforward with this approach, as the content is managed as a list of strings.

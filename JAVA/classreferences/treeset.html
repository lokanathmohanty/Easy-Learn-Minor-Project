Java TreeSet Class Summary 🌳🗂️

The **java.util.TreeSet** class is an implementation of the **Set** interface that guarantees elements are always stored and retrieved in **sorted (ascending)** order. It is backed internally by a **TreeMap**, which uses a **Red-Black Tree** structure to maintain this sorted order efficiently.

I. Core Characteristics and Ordering

  • Sorted Order: Elements are always arranged and iterated based on their sort order, not insertion order. This order is enforced either by the element's **natural ordering** or by a **Comparator** provided at construction.
  • Uniqueness: Like all Sets, it does not permit duplicate elements. Uniqueness is determined by the sorting mechanism (i.e., if two elements compare as equal, only one is stored).
  • Implementation: It is backed by a `TreeMap`. Elements added to the `TreeSet` become the **keys** of the internal map, and the values are dummy objects.
  • Non-Synchronized: It is **not thread-safe**.

II. Performance and Requirements

  • **Time Complexity:** Basic operations like **add()**, **remove()**, and **contains()** run in **$O(\log n)$ (logarithmic time)**. This is slower than the constant time ($O(1)$) of a `HashSet`, but the trade-off is the guaranteed sorting.
  • **Element Requirement:** Elements inserted into a `TreeSet` **must be mutually comparable**. They must either:
    1. Implement the **Comparable** interface (for natural ordering).
    2. Have their ordering defined by a **Comparator** supplied to the `TreeSet` constructor.

III. NavigableSet Functionality

TreeSet implements the **NavigableSet** interface, which adds powerful methods for efficiently querying and navigating the sorted data:

Method Action
E **first()** / E **last()** Returns the lowest/highest element.
E **pollFirst()** / E **pollLast()** Retrieves and removes the lowest/highest element.
E **floor(E e)** / E **ceiling(E e)** Returns the greatest element $\le e$ (floor) or the least element $\ge e$ (ceiling).
SortedSet<E> **subSet(...)** Returns a view of a specific range of the set.
Iterator<E> **descendingIterator()** Provides an iterator that traverses the set from highest to lowest element.

The example confirms that even though the elements were added in no particular order, the output (iteration) is sorted:

// Insertion Order: 12, 13, 14, 15 (Already sorted in this case)

// Output (TreeSet always guarantees sorted order):
Tree set : [12, 13, 14, 15]

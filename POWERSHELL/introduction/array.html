PowerShell: Arrays

PowerShell arrays are fixed-size collections that store elements of any type in sequential order. They allow you to manage multiple related values under a single variable name, accessible by zero-based indices.

Arrays simplify handling bulk data compared to declaring many individual variables.

Declaring Arrays

Arrays can be declared by listing elements separated by commas or using range notation:

$A = 1, 2, 3, 4
$B = 1..4

You may specify element data type, e.g., [int[]]$A = 1, 2, 3, 4.

Accessing Array Elements

Use zero-based indices to retrieve or assign array values:

$A[0]  # First element
$A[3]  # Fourth element
$A[1] = 10  # Assign new value

Get total elements using $A.Length.

Processing Arrays

Typical methods to loop through arrays include:

  • For Loop: Index-controlled iteration.
  • ForEach Loop: Iteration over elements directly.
  • While Loop: Conditional iteration with manual index control.

Example:

for ($i = 0; $i -lt $A.Length; $i++) { $A[$i] }
foreach ($item in $A) { $item }
$i = 0; while ($i -lt $A.Length) { $A[$i]; $i++ }

Array Manipulation

You can modify elements by index assignment and utilize array methods for adding, removing, or sorting items.

Example:

$A[1] = 100   # Change second element
$A.Sort()       # Sort array in place

Power BI - Data Modeling

Introduction to Data Modeling

Data modeling in Power BI helps connect multiple data sources using relationships. Relationships define how data tables relate and enable building comprehensive visualizations across datasets.

Core Features

  • Create custom calculations on existing tables, which can be directly used in visualizations.
  • Define new metrics using Data Analysis Expressions (DAX).
  • Build and view relationships by dragging lines between common columns on the model view.

Working with Data Sources

Add data sources in Power BI using the Get Data option. Imported tables appear in the right sidebar and can be managed in the Report, Data, and Relationships tabs:

  • Report Tab: Build dashboards and choose visualization types.
  • Data Tab: View all data according to defined relationships.
  • Relationships Tab: View and create relationships between tables. You can add, edit, or delete relationships.

Managing Relationships

Delete or create relationships by right-clicking columns or dragging fields to link them. Use "Hide in report view" to hide unwanted columns from reports.

Creating Calculated Columns

Calculated columns combine or transform data to create new metrics. Add them via the Data View and Modeling tab by writing DAX formulas. Example: extracting the last three characters from a product ID:

Product_C = RIGHT(Sheet1[Prod_Id], 3)

Creating Calculated Tables

Calculated tables are new tables created using DAX formulas. These tables appear in the Fields pane and can participate in relationships and visualizations.

Time-Based Data Handling

Power BI supports drill-down on time hierarchies automatically. For example, users can explore data from years, to quarters, to months by enabling drill in visuals.

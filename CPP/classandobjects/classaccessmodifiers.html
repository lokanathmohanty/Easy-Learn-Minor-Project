C++ Class Access Modifiers 🔑

C++ **access modifiers** (or **access specifiers**) control the visibility and accessibility of a class's members (data and functions). They are fundamental to implementing **data hiding** and **encapsulation**—core principles of Object-Oriented Programming.

A class can have multiple `public`, `private`, or `protected` sections. The default access level for members in a C++ `class` is **private**.

The Three Access Specifiers

1. public (Accessible Everywhere) 🌐

Public members are accessible from **anywhere** outside the class, within the program's scope.

  • Usage: Typically used for member functions (methods) that form the public interface of the class, and occasionally for data members when direct external access is intended.
class Line {
   public:
      double length; // Accessible directly via line.length
      void setLength(double len);
};

2. private (Internal Use Only) 🔒

Private members **cannot be accessed or viewed** from outside the class. Only the **member functions** of that same class (and any declared `friend` functions) can access them.

  • Usage: Standard practice is to define **data members** (attributes) as private to enforce encapsulation. External access to this data is then restricted and must be mediated through public member functions (like getters and setters).
class Box {
   public:
      void setWidth(double wid);
   private:
      double width; // Cannot be accessed as box.width from main()
};

3. protected (Inheritance Access) 🛡️

Protected members are similar to private members in that they are inaccessible from outside the class, **but** they provide one crucial exception: they **can be accessed** by member functions of **derived classes** (child classes) during inheritance.

  • Usage: Used for members that should be hidden from the general public but still accessible to subsequent generations of classes in an inheritance hierarchy.
class Box {
   protected:
      double width; // Accessible by SmallBox's methods
};

class SmallBox : public Box {
   public:
      // Can access 'width' inherited from Box
      void setSmallWidth(double wid) {
         width = wid; 
      }
};

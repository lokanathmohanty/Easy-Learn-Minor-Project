PHP Functions for File Existence and Permissions

In PHP, checking for the existence and accessibility of a file or directory is a critical step to prevent runtime exceptions and ensure robust file operations. This is done using a set of built-in filesystem utility functions.

Core Functions for File Validation

These functions all take a string `$filename` (which can be a file or directory path, relative or absolute) and return a boolean (`true` or `false`).

`file_exists()`: Check Existence (File or Directory)

This is the most general check. It determines if the specified path points to an existing file **or** directory.

if (file_exists('data/config.ini')) { /* ... proceed ... */ }

*Note: This returns `true` for both files and directories.*

`is_file()`: Check if the Path is Specifically a File

Used to differentiate between a file and a directory. It returns `true` **only if** the path exists and is a regular file.

$filename = 'hello.txt';
if (is_file($filename)) {
   echo "$filename is a file";
}

Functions for Permission Checks

Before attempting I/O (Input/Output) operations, these functions verify that the script has the necessary operating system permissions.

`is_readable()`: Check Read Permission 📖

Tests whether the file or directory exists and has permissions that allow the current PHP script to **read** from it.

if (is_readable('data.log')) {
   // OK to use file_get_contents() or fopen('r')
}

`is_writable()`: Check Write Permission ✍️

Tests whether the file or directory exists and has permissions that allow the current PHP script to **write** to it. This is crucial before using functions like `file_put_contents()` or `fopen('w')`.

if (is_writable('temp/cache')) {
   // OK to create or modify files inside this folder
}

Java - continue Statement

Introduction

The continue statement can be used in any loop control structure to skip the current iteration and jump to the next one. In a for loop, it immediately transfers control to the update statement, while in a while or do-while loop, it jumps directly to the Boolean expression for the next iteration.

Syntax of continue Statement

continue;

Using continue with while Loop

This example shows how continue skips the number 15 while printing values from 10 to 20:

public class Test {
   public static void main(String args[]) {
      int x = 10;
      while(x < 20) {
         x++;
         if(x == 15){
            continue;		 
         }   
         System.out.print("value of x : " + x );
         System.out.print("\n");
      }
   }
}

Output:

  • value of x : 11
  • value of x : 12
  • value of x : 13
  • value of x : 14
  • value of x : 16
  • value of x : 17
  • value of x : 18
  • value of x : 19
  • value of x : 20

Using continue with for Loop

This example skips the value 30 from an array:

public class Test {
   public static void main(String args[]) {
      int [] numbers = {10, 20, 30, 40, 50};

      for(int index = 0; index < numbers.length; index++) {
         if(numbers[index] == 30){
            continue;
         }
         System.out.print("value of item : " + numbers[index] );         
         System.out.print("\n");
      }
   }
}

Output:

  • value of item : 10
  • value of item : 20
  • value of item : 40
  • value of item : 50

Using continue with do-while Loop

This example shows how the number 15 is skipped in a do-while loop:

public class Test {
   public static void main(String args[]) {
      int x = 10;

      do {
         x++;
         if(x == 15){
            continue;		 
         }   
         System.out.print("value of x : " + x );
         System.out.print("\n");
      } while( x < 20 );
   }
}

Output:

  • value of x : 11
  • value of x : 12
  • value of x : 13
  • value of x : 14
  • value of x : 16
  • value of x : 17
  • value of x : 18
  • value of x : 19
  • value of x : 20

Use Cases of continue Statement

1. Skipping Specific Values in a Loop

Example: Skipping even numbers in a for loop.

for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue;
    }
    System.out.println(i);
}

2. Ignoring Specific Input in User Input Loops

Example: Skipping negative numbers entered by the user.

Scanner scanner = new Scanner(System.in);
for (int i = 0; i < 5; i++) {
    System.out.print("Enter a positive number: ");
    int num = scanner.nextInt();

    if (num < 0) {
        System.out.println("Negative numbers are not allowed, skipping...");
        continue;
    }

    System.out.println("You entered: " + num);
}

3. Skipping Iteration in Nested Loops

Example: Skip when row index equals column index in a nested loop.

for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (i == j) {
            continue;
        }
        System.out.println("i: " + i + ", j: " + j);
    }
}

4. Skipping Blank Lines While Processing Files

Example: Skip empty lines from a file.

BufferedReader reader = new BufferedReader(new FileReader("data.txt"));
String line;
while ((line = reader.readLine()) != null) {
    if (line.trim().isEmpty()) {
        continue;
    }
    System.out.println(line);
}
reader.close();

5. Filtering Specific Characters in a String

Example: Skipping vowels when processing a string.

String str = "hello world";
for (char ch : str.toCharArray()) {
    if ("aeiou".indexOf(ch) != -1) {
        continue;
    }
    System.out.print(ch);
}

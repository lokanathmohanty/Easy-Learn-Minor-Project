Understanding Semantic HTML

Semantic HTML refers to the use of HTML tags that convey meaning about the type of content they contain. Instead of using generic tags like <div>, semantic tags such as <header>, <article>, and <footer> describe the structure and purpose of different sections on a web page.

This approach improves accessibility, SEO, and the overall readability of code, making it easier for developers and browsers to understand the page structure.

  • Improves accessibility for assistive technologies.
  • Enhances search engine optimization (SEO).
  • Creates cleaner, more maintainable code.

Example: Applying Semantic Structure

Below is an example of a simple web page structured with semantic HTML elements:

<header>
  <h1>My Web Page</h1>
  <nav>
    <a href="#">Home</a>
    <a href="#">About</a>
    <a href="#">Contact</a>
  </nav>
</header>
<main>
  <article>
    <h2>Introduction to Semantic HTML</h2>
    <p>Semantic HTML uses meaningful tags to improve structure and accessibility.</p>
  </article>
  <aside>
    <p>Related links and resources.</p>
  </aside>
</main>
<footer>
  <p>Copyright © 2025 Web Academy</p>
</footer>

This layout defines clear sections like header, navigation, content area, and footer, making the document easily understood by both humans and machines.

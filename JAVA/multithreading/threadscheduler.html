Java - Scheduling Threads

Java is a multi-threaded programming language which means we can develop multi-threaded programs using Java. A multi-threaded program contains two or more parts that can run concurrently, each handling a different task at the same time. This makes optimal use of available resources, especially on computers with multiple CPUs.

Multitasking means multiple processes share common processing resources like a CPU. Multi-threading extends this idea by subdividing operations within a single application into individual threads that can run in parallel. The OS allocates processing time among applications and their threads.

Multi-threading enables multiple activities to proceed concurrently within the same program.

ScheduledExecutorService Interface

Java provides the java.util.concurrent.ScheduledExecutorService interface, a subinterface of ExecutorService, supporting future and/or periodic execution of tasks or threads.

Key Methods

  • <V> ScheduledFuture<V> schedule(Callable<V> callable, long delay, TimeUnit unit): Schedules a task to execute after a delay.
  • ScheduledFuture<?> schedule(Runnable command, long delay, TimeUnit unit): Schedules a one-time action after a delay.
  • ScheduledFuture<?> scheduleAtFixedRate(Runnable command, long initialDelay, long period, TimeUnit unit): Schedules periodic execution starting after an initial delay, then repeatedly at fixed intervals.
  • ScheduledFuture<?> scheduleWithFixedDelay(Runnable command, long initialDelay, long delay, TimeUnit unit): Schedules periodic execution starting after an initial delay, with a fixed delay between the end of one execution and the start of the next.

Example 1: scheduleAtFixedRate() and schedule()

This example schedules a task to run every 2 seconds after an initial delay of 2 seconds, stopping after 10 seconds.

package com.tutorialspoint;

import java.util.concurrent.Executors;
import java.util.concurrent.ScheduledExecutorService;
import java.util.concurrent.ScheduledFuture;
import java.util.concurrent.TimeUnit;

public class TestThread {
   public static void main(final String[] arguments) throws InterruptedException {
      final ScheduledExecutorService scheduler = Executors.newScheduledThreadPool(1);

      final ScheduledFuture<?> beepHandler = 
         scheduler.scheduleAtFixedRate(new BeepTask(), 2, 2, TimeUnit.SECONDS);

      scheduler.schedule(new Runnable() {
         @Override
         public void run() {
            beepHandler.cancel(true);
            scheduler.shutdown();			
         }
      }, 10, TimeUnit.SECONDS);
   }

   static class BeepTask implements Runnable {
      public void run() {
         System.out.println("beep");      
      }
   }
}

Python os.path Methods Overview

The os.path module in Python provides many useful methods to manipulate and obtain information about file and directory paths. These methods help in path normalization, joining, existence checks, and more.

  • abspath(path): Returns an absolute normalized version of the path.
  • basename(path): Returns the last component of a path.
  • commonprefix(list): Returns longest common prefix from a list of paths.
  • dirname(path): Returns the directory portion of the path.
  • exists(path): Checks if a path exists (False for broken symlinks).
  • lexists(path): Checks if a path exists (True even for broken symlinks).
  • expanduser(path): Expands ~ or ~user to home directory.
  • expandvars(path): Expands environment variables in the path.
  • getatime(path): Returns last access time.
  • getmtime(path): Returns last modification time.
  • getctime(path): Returns creation time (platform dependent).
  • getsize(path): Returns file size in bytes.
  • isabs(path): Checks if path is absolute.
  • isfile(path): Checks if path is a file.
  • isdir(path): Checks if path is a directory.
  • islink(path): Checks if path is a symbolic link.
  • ismount(path): Checks if path is a mount point.
  • join(path1, ...): Joins multiple path components intelligently.
  • normcase(path): Normalizes case of the path.
  • normpath(path): Normalizes path by collapsing redundant separators.
  • realpath(path): Returns canonical path by resolving symbolic links.
  • relpath(path, start): Returns relative filepath to path from start.
  • samefile(path1, path2): Checks if two paths refer to the same file.
  • sameopenfile(fp1, fp2): Checks if two file descriptors refer to same open file.
  • samestat(stat1, stat2): Checks if two stat tuples refer to the same file.
  • split(path): Splits path into (head, tail) at last separator.
  • splitdrive(path): Splits path into (drive, tail) on Windows.
  • splitext(path): Splits path into (root, extension).
  • walk(path, visit, arg): Calls function for each directory in tree (deprecated in Python 3).

Example: Using os.path.join and os.path.exists

The following example joins directory and filename into a full path and checks if it exists:

import os.path
dir = "/home/user/docs"
filename = "example.txt"
full_path = os.path.join(dir, filename)
if os.path.exists(full_path):
  print(f"File found at: {full_path}")
else:
  print("File not found")

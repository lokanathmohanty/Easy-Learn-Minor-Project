Nested try Block in Python

In a Python program, if there is another try-except construct either inside a try block or inside its except block, it is known as a nested try block. Nested try blocks are useful when different blocks like outer and inner may cause different errors and need different error handling.

Example 1

A single try-except-finally block handling division by zero with a generic exception.

a=10
b=0
try:
   print(a/b)
except Exception:
   print("General Exception")
finally:
   print("inside outer finally block")

Output:

General Exception
inside outer finally block

Example 2

Nested try-except-finally within an outer try. Outer except handles ZeroDivisionError, inner handles generic exceptions.

a=10
b=0
try:
   print(a/b)
   try:
      print("This is inner try block")
   except Exception:
      print("General exception")
   finally:
      print("inside inner finally block")
except ZeroDivisionError:
   print("Division by 0")
finally:
   print("inside outer finally block")

Output:

Division by 0
inside outer finally block

Example 3

Inner try causes division by zero, handled by inner except. Outer except not triggered.

a=10
b=0
try:
   print("This is outer try block")
   try:
      print(a/b)
   except ZeroDivisionError:
      print("Division by 0")
   finally:
      print("inside inner finally block")
except Exception:
   print("General Exception")
finally:
   print("inside outer finally block")

Output:

This is outer try block
Division by 0
inside inner finally block
inside outer finally block

Example 4

Inner try raises ZeroDivisionError, but inner except looks for KeyError. Exception propagates to outer except which handles it.

a=10
b=0
try:
   print("This is outer try block")
   try:
      print(a/b)
   except KeyError:
      print("Key Error")
   finally:
      print("inside inner finally block")
except ZeroDivisionError:
   print("Division by 0")
finally:
   print("inside outer finally block")

Output:

This is outer try block
inside inner finally block
Division by 0
inside outer finally block

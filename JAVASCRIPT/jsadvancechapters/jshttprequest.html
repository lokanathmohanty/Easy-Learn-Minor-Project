JavaScript - HTTP Requests

HTTP (Hypertext Transfer Protocol) is the foundation of communication on the web. HTTP requests allow us to interact with web servers by sending and receiving data. They can be used to fetch information, submit forms, upload files, and more.

HTTP Methods

  • GET: Used to retrieve data from a server without sending additional information.
  • POST: Used to send data to a server, often when submitting a form.
  • PUT: Used to update existing data on a server.
  • DELETE: Used to remove data from a server.
  • PATCH: Used to update partial data, such as fixing a typo in stored information.

Ways to Make HTTP Requests in JavaScript

In JavaScript, there are two common ways to make HTTP requests:

  • Using XMLHttpRequest (XHR)
  • Using Fetch API

Using XMLHttpRequest (XHR)

XMLHttpRequest is a built-in browser object that provides a way to make HTTP requests. Although it is older, it is still supported in all browsers. 


// Create a new XMLHttpRequest object
var xhr = new XMLHttpRequest();

// Configure it: GET-request for the URL
xhr.open('GET', '/article/.../load', true);

// Send the request over the network
xhr.send();

Using Fetch API

The Fetch API is a modern and simpler way to make HTTP requests. It returns promises, making it easier to handle asynchronous operations. 


// Make a request using Fetch API
fetch('/article/.../load')
  .then(response => response.json())
  .then(data => alert(data.title))
  .catch(error => alert(error));

Conclusion

HTTP requests are essential for client-server communication in web applications. Developers can use different HTTP methods to fetch, update, delete, or send data. In JavaScript, requests can be made using both XMLHttpRequest and the modern Fetch API.

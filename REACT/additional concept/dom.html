ReactJS - DOM

To run a react application, it needs to be attached itself to the main document of the web application. React provides a module to access and attach the application to the DOM of the document and the module is ReactDOM (react-dom).

Let us learn how to create a simple react component and attach the component into the document using ReactDOM module in this chapter.

ReactDOM usage

react-dom is the core package used to manipulate the DOM of the document. It allows one or more react applications to be attached to the document.

The react-dom should be imported into the application as shown below −

import * as ReactDOM from 'react-dom';

The react-dom provides two methods to manipulate the DOM:

  • createPortal() − Creates a portal in the react application.
  • flushSync() − Flushes the state changes immediately and updates the DOM.

The react-dom provides two submodules:

  • react-dom/server
  • react-dom/client

ReactDOMServer

The server module is used to render a react component in the server:

import * as ReactDOMServer from 'react-dom/server';

Some methods of ReactDOMServer:

  • renderToPipeableStream()
  • renderToReadableStream()
  • renderToStaticNodeStream()
  • renderToString()
  • renderToStaticMarkup()

ReactDOMClient

The client module is used in front-end development:

import * as ReactDOM from 'react-dom/client';

Some methods of ReactDOMClient:

  • createRoot() − Creates a root element to render a react component.
  • hydrateRoot() − Same as createRoot() but used with server-side rendering.

Example: Applying ReactDOMClient

Create a new react application:

create-react-app myapp
cd myapp
npm start

Example component (Hello.js):

import React from "react";
class Hello extends React.Component {
  render() {
    return (<div>Hello, {this.props.name}</div>);
  }
}
export default Hello;

Example HTML (index.html):

<div id="root"></div>
<div id="root2"></div>

Example JavaScript (index.js):

import React from 'react';
import ReactDOM from 'react-dom/client';
import Hello from './Components/Hello';

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(<Hello name="Main root container" />);

const root2 = ReactDOM.createRoot(document.getElementById('root2'));
root2.render(<Hello name="Another root container" />);

Summary

ReactDOM provides the ability to create the entry point for the react application by attaching the react component into the HTML document in both client and server environments.

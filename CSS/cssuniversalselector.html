CSS - Universal Selectors

The CSS universal selector (*) is a special selector that targets all elements in an HTML document. It is commonly used to apply a common style rule to the entire page, such as resetting margins, setting a default font, or applying a global background.

Syntax

* {
  margin: 0;
  padding: 0;
}

In this example, the universal selector removes all default margins and padding from all elements, creating a consistent baseline across browsers.

Using Universal Selector to Set Background and Text Color

You can use the universal selector to set a common background color and text color for the entire web page. 

* {
  background-color: #04af2f;
  color: white;
}

Example Output: All elements on the page will have a green background and white text.

<p>Welcome to Tutorials Point</p>

Using Universal Selector to Set Border

The universal selector can be used to apply a border to every element on the page. 

* {
  border: 2px solid #04af2f;
}

Example Output: Every element in the HTML document will be outlined with a green border.

<p>Welcome to Tutorials Point</p>

Using Universal Selector to Set Font

The universal selector is also useful for applying a consistent font style across the document. 

* {
  font-size: 16px;
  font-family: Verdana, sans-serif;
}

Example Output: All text in the document will be displayed in 16px Verdana (or sans-serif fallback).

<p>Welcome to Tutorials Point</p>

When to Use Universal Selector

  • To reset browser default styles (e.g., margin and padding).
  • To enforce a global font or color scheme.
  • To apply a debugging outline or border to all elements.

Important Note

While powerful, the universal selector can be costly in performance when applied to large documents because it targets every element. Use it carefully for resets or global styles, but avoid overusing it in complex projects.

Example: Universal Selector in Action

* {
  margin: 0;
  padding: 0;
  font-family: Arial, sans-serif;
  background-color: #f0f0f0;
  color: black;
}

<p>This paragraph inherits all universal styles.</p>
<h1>This heading also inherits the same font and background.</h1>

Tokens in C

What is a Token?

A token is the smallest unit in the source code of a programming language like C. Just like sentences are formed from words in natural languages, C programs are formed using tokens such as keywords, identifiers, symbols, and literals.

In the compilation process, the tokenizer is the first stage that splits the source code into tokens and identifies their type. These tokens are passed to the parser, which understands grammar rules, checks syntax, and converts error-free code into machine instructions.

Types of Tokens in C

  • Character set
  • Keyword tokens
  • Literal tokens
  • Identifier tokens
  • Operator tokens
  • Special symbol tokens

C Character Set

The C character set includes English letters, digits, and special symbols. It also supports escape sequences like \n for newline.

Character Categories

  • Uppercase: A to Z
  • Lowercase: a to z
  • Digits: 0 to 9
  • Special characters: ! " # $ % & ' ( ) * + - . : , ; ` ~ = < > { } [ ] ^ _ \ /

Special usage includes:

  • Double quotes " " for string literals
  • Square brackets [ ] for arrays
  • Curly brackets { } for code blocks
  • Backslash \ for escape sequences

C Keywords

Keywords are reserved words in C with predefined meanings. All keywords are in lowercase and follow specific syntax rules. For example: int, for, return.

The compiler ensures keywords are used correctly and compiles the code accordingly.

C Literals

Literals are fixed values assigned to variables directly in the source code.

Types of Literals

  • Numeric literals: Digits, decimal points, or scientific notation (e.g. 3.14, 2E3)
  • String literals: Characters inside double quotes (e.g. "Hello")
  • Character literals: A single character in single quotes (e.g. 'A')
  • Array literals: A list of values in square brackets (e.g. {1, 2, 3})
  • Escape sequences: Characters starting with backslash (e.g. '\n')

C Identifiers

Identifiers are names given by the programmer to variables, functions, constants, etc. They must follow specific rules:

  • Must start with a letter (A–Z or a–z) or underscore (_)
  • Can contain digits after the first character
  • Cannot be a keyword (e.g. for cannot be used as an identifier)

C Operators

Operators perform operations on data. They are built from special characters in C's character set.

Common Operators

  • Arithmetic: +, -, *, /
  • Comparison: <, >, ==, !=
  • Assignment: =
  • Logical: &&, ||, !

C Special Symbols

Special symbols are non-alphanumeric characters used in various parts of C syntax.

Examples

  • ; – Statement terminator
  • , – Separator
  • : – Used in labels (e.g. in switch)
  • ( ) – Used in function calls and expressions
  • { } – Define blocks of code
  • [ ] – Define arrays

These symbols play a crucial role in defining structure, logic, and flow in a C program.

C++ Loop Through a String 🚶‍♀️

Looping through a C++ **std::string**—an object array of characters—is the process of iterating over each character to access, modify, or analyze its contents. This can be achieved using various loop structures:

1. Using the Traditional for Loop

This method uses an **index variable** (typically i or size_t i) to traverse the string from the first character (index 0) up to (but not including) the string's length, accessing each character via array notation (str[i]).

std::string str = "TutorialsPoint";
for (size_t i = 0; i < str.length(); ++i) {
   std::cout << str[i] <<" ";
}

This approach gives **direct control** over the index, which is useful if you need to access adjacent elements or the character's position.

2. Using the while Loop

The while loop also relies on an **external counter** (index) to manage iteration. The condition checks the index against the string's length before each execution, and the counter must be manually incremented within the loop body.

std::string str = "TutorialsPoint";
size_t i = 0;
while (i < str.length()) {
   std::cout << str[i] << " ";
   ++i; // Must remember to increment!
}

Like the for loop, this allows index access but requires careful initialization and manual update of the counter.

3. Using the Range-Based for Loop (Foreach)

Introduced in C++11, this is the **most idiomatic and cleanest way** to iterate over containers like std::string. It automatically handles the iteration without explicit indexing or managing loop termination.

std::string str = "TutorialsPoint";
for (char c : str) { // 'c' is a copy of the character
   std::cout << c << " ";
}

To **modify** the string's characters, you must use a **reference** (char& c : str). This method is preferred for its simplicity and safety, as it eliminates potential index errors.

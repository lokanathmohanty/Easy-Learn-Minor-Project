Python - Packages

A Python package is a directory containing one or more module files and a special __init__.py file. Packages organize modules into namespaces and support modular program development.

Modules are individual Python files (.py) with classes or functions, while packages are folders grouping related modules. The __init__.py file marks the directory as a package and can expose selected functions or resources.

Creating a Python Package

  • Create an outer folder (e.g. packagedemo).
  • Inside, make a folder named mypackage.
  • Add modules (e.g. areafunctions.py, mathfunctions.py).
  • Add an empty or populated __init__.py file to mark mypackage as a package.

Sample Package Structure and Module Code

# mypackage/mathfunctions.py
def sum(x,y):
    return x + y

def average(x,y):
    return (x + y) / 2

def power(x,y):
    return x ** y

# mypackage/areafunctions.py
def rectangle(w,h):
    return w * h

def circle(r):
    import math
    return math.pi * math.pow(r, 2)

Testing the Package

# example.py (above the mypackage folder)
from mypackage.areafunctions import rectangle
print("Area :", rectangle(10, 20))

from mypackage.mathfunctions import average
print("average:", average(10, 20))
# Output:
# Area : 200
# average: 15.0

Using __init__.py to Expose Selected Functions

# mypackage/__init__.py
from .areafunctions import circle
from .mathfunctions import sum, power

This allows you to import these functions directly from the package name.

Direct Import Example

# testpackage.py
from mypackage import power, circle

print("Area of circle:", circle(5))
print("10 raised to 2:", power(10, 2))
# Output:
# Area of circle: 78.53981633974483
# 10 raised to 2: 100

Installing the Package Using PIP

# setup.py
from setuptools import setup
setup(
    name='mypackage',
    version='0.1',
    description='Package setup script',
    url='#',
    author='anonymous',
    author_email='test@gmail.com',
    license='MIT',
    packages=['mypackage'],
    zip_safe=False
)

Run pip3 install . from the parent folder to install the package system-wide.

  • After installation, you can import and use your package from anywhere in your system as a standard Python library.
  • Packages help keep code organized, reusable, and easy to distribute in Python projects.

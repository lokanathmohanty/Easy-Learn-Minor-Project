PHP - Create Directory

PHP provides several functions for **directory management** (folder operations), allowing you to create, change, retrieve, and remove directories programmatically. These functions are crucial for file organization within an application.

The mkdir() Function (Create Directory)

The mkdir() function creates a new directory specified by the given path. 

mkdir(
   string $directory,
   int $permissions = 0777,
   bool $recursive = false,
   ?resource $context = null
): bool
  • $directory: The absolute or relative path of the new directory to create.
  • $permissions: An **octal number** specifying permissions (e.g., 0777 for full read/write/execute access). This is generally ignored on Windows OS.
  • $recursive: If set to true, PHP will create any necessary parent directories that don't already exist.

Example: Using mkdir()

Examples of creating directories, including nested structures: 

<?php
   // Creates 'mydir' in the current working directory
   $dir1 = "./mydir/";
   mkdir($dir1);

   // Creates 'dir1' -> 'dir2' -> 'dir3' only because the recursive flag is TRUE
   $dirs2 = "./dir1/dir2/dir3/";
   mkdir($dirs2, 0777, true); 

   // Creates a directory with read/write access for the owner (0600)
   $dir3 = "c:/safe_storage/";
   mkdir($dir3, 0600);
?>

Directory Navigation and Retrieval

  • The chdir() Function (Change Directory)

    Corresponds to the cd command, changing the **current working directory** for the script. 

    chdir(string $directory): bool

  • The getcwd() Function (Get Current Working Directory)

    Works like the pwd command, returning the **absolute path** to the current working directory. 

    getcwd(): string|false

Example: Navigation and Retrieval

Demonstrates retrieving the current directory, changing it, and then listing files in the new directory using scandir(). 

<?php
   echo "Initial directory: " . getcwd() . PHP_EOL;

   // Change the current directory to 'mydir'
   $dir = "./mydir";
   chdir($dir);

   echo "Directory changed to: " . getcwd() . PHP_EOL;

   // This file 'a.txt' will be created INSIDE 'mydir'
   $fp = fopen("a.txt", "w");
   fwrite($fp, "Hello World");
   fclose($fp);

   // List files in the new current directory
   foreach(scandir(getcwd()) as $file) {
      echo $file . PHP_EOL;
   }
?>

The rmdir() Function (Remove Directory)

The rmdir() function removes the directory specified by the path. 

rmdir(string $directory, ?resource $context = null): bool

Important Note: The directory to be removed **must be empty**. To delete a directory with files inside, you must recursively remove all contents first. 

<?php
   $dir_to_remove = "./empty_folder/";
   
   if (rmdir($dir_to_remove)) {
      echo "Directory '$dir_to_remove' removed successfully.";
   } else {
      die("The directory is not present or not empty.");
   }
?>

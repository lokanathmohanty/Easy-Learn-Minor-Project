C# Nested Loops

Definition of Nested Loops

A **nested loop** in C# is a programming construct where one loop (the **inner loop**) is placed entirely inside the body of another loop (the **outer loop**). The inner loop executes all its iterations completely for every single iteration of the outer loop.

The flexibility of C# allows you to nest **any type of loop** inside any other type of loop (e.g., a `for` loop inside a `while` loop, or a `do...while` inside a `for` loop).

Execution Flow

To understand the execution, consider an outer loop running 3 times and an inner loop running 5 times:

  • **Outer Loop** Iteration 1 starts.
  •   **Inner Loop** runs 5 times (Iterations 1 through 5).
  • **Outer Loop** Iteration 2 starts.
  •   **Inner Loop** runs 5 times (Iterations 1 through 5).
  • **Outer Loop** Iteration 3 starts.
  •   **Inner Loop** runs 5 times (Iterations 1 through 5).

The total number of executions for the inner loop body is $3 \times 5 = 15$ times.

Example: Prime Number Detection (Nested `for` Loops)

Nested loops are often used to check complex conditions across a range of values. This classic example finds prime numbers from 2 to 100:

using System;
class Program {
    static void Main(string[] args) {
        int i, j;
         
        // Outer loop iterates through numbers 2 to 99
        for (i = 2; i < 100; i++) {
            
            // Inner loop checks for factors (j) up to the square root of i
            for (j = 2; j <= (i / j); j++)
                if ((i % j) == 0) break; // Not prime, exit inner loop

            // If the inner loop completed without finding a factor, it is prime
            if (j > (i / j)) 
               Console.WriteLine("{0} is prime", i);
        }
    }
}

Output (Partial):

2 is prime
3 is prime
5 is prime
...

Syntax Examples

Nested `while` Loop Syntax:

while(outer_condition) {
   // Outer loop statements
   while(inner_condition) {
      // Inner loop statements
   }
   // Continue outer loop statements
}

Nested `do...while` Loop Syntax:

do {
   // Outer loop statements
   do {
      // Inner loop statements
   } while( inner_condition );
} while( outer_condition );

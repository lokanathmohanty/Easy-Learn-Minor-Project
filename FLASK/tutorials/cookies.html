Flask Cookies: Setting and Retrieving Client Data 🍪

A **cookie** is a small text file stored on a client's computer by a web browser. Its main purpose is to **remember and track data** related to a user's session, which helps personalize the visitor experience and gather site statistics.

Setting a Cookie

In Flask, cookies are attached to the **response object**. Since view functions normally return strings or templates, you must first convert the return value into a response object using **make_response()**. After that, the cookie can be set:

  1. **Create the Response:** Use make_response(render_template('template_name.html')).
  2. **Set the Cookie:** Use the response object's **set_cookie()** method: resp.set_cookie('key', 'value').

The **/setcookie** route in the example demonstrates this: the user ID from the form is used as the value for the userID cookie.

resp = make_response(render_template('readcookie.html'))

resp.set_cookie('userID', user)

Other attributes like cookie expiry time, path, and domain are also stored.

Reading a Cookie

When a client makes a subsequent request, the browser automatically sends all relevant cookies back to the server. This data is accessed via the global **request object**, specifically its **cookies** attribute.

  • **request.cookies:** A dictionary-like object containing all cookie names and their corresponding values transmitted by the client.
  • **Retrieval:** The **get()** method of this dictionary is used to safely read a specific cookie's value.

Example: The getcookie() Function

The **/getcookie** route demonstrates retrieving and displaying the stored userID:

def getcookie():

name = request.cookies.get('userID')

return '<h1>welcome ' + name + '</h1>'

The code retrieves the value of the cookie named 'userID' and displays a welcome message using that value.

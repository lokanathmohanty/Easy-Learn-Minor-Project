Python - Main Thread

The main thread is the initial thread that starts when the Python interpreter runs. It manages the program and creates additional threads. Every Python program has at least one thread: the main thread.

By default, the main thread is non-daemon and will exit when the main program's execution ends, but other threads will keep running until they finish.

Accessing the Main Thread

Python's threading module provides:

  • threading.current_thread(): Returns the current thread object.
  • threading.main_thread(): Returns the main thread object.

Example:

import threading

print('Main Thread:', threading.main_thread())
print('Current Thread:', threading.current_thread())

Output example:

Main Thread: <_MainThread(MainThread, started 123456789)>
Current Thread: <_MainThread(MainThread, started 123456789)>

Main Thread Behavior

The main thread continues to run until all non-daemon threads have finished or the script ends. Starting additional threads does not stop the main thread from running its code.

Example:

import threading
import time

def worker():
    for i in range(6):
        print(f'{threading.current_thread().name} running {i}')
        time.sleep(0.5)

t = threading.Thread(target=worker)
t.start()

for i in range(3):
    print(f'Main Thread running {i}')
    time.sleep(0.5)

print('Main Thread finished')

Possible output:

Main Thread running 0
Main Thread running 1
Main Thread running 2
Main Thread finished
Thread-1 running 0
Thread-1 running 1
Thread-1 running 2
Thread-1 running 3
Thread-1 running 4
Thread-1 running 5

Main Thread Waiting for Other Threads

To ensure the main thread waits for other threads to complete before exiting, use the join() method on threads.

Example:

from threading import Thread
from time import sleep

def worker_1():
    print("Worker 1 started")
    sleep(1)
    print("Worker 1 done")

def worker_2(t):
    print("Worker 2 waiting for Worker 1")
    t.join()
    print("Worker 2 started")
    sleep(1)
    print("Worker 2 done")

t1 = Thread(target=worker_1)
t2 = Thread(target=worker_2, args=(t1,))

t1.start()
t2.start()

for i in range(6):
    print(f"Main thread working on task {i}")
    sleep(0.6)

t1.join()
print("Main thread completed")

Output example:

Worker 1 started
Worker 2 waiting for Worker 1
Main thread working on task 0
Main thread working on task 1
Worker 1 done
Worker 2 started
Main thread working on task 2
Worker 2 done
Main thread working on task 3
Main thread working on task 4
Main thread working on task 5
Main thread completed

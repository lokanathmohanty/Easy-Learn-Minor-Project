CSS - user-select Property

The CSS user-select property controls whether users can select text on a webpage. It does not affect text inside form elements like input fields or textareas. This property is useful for preventing unwanted text selection or enhancing user experience.

Syntax

user-select: none | auto | text | contain | all;

Possible Values

  • none – Text cannot be selected.
  • auto – Default behavior. Selection rules depend on the browser and parent elements.
  • text – Allows text selection.
  • contain – Selection can start within the element but is restricted to its boundaries.
  • all – If any part of the element is selected, the entire element content is selected automatically.

Example 1: user-select - none

Prevents the user from selecting text.

.text-none {
  -webkit-user-select: none;
  user-select: none;
}

Example 2: user-select - auto

Uses the default browser behavior for text selection.

p {
  -webkit-user-select: auto;
  user-select: auto;
}

Example 3: user-select - text

Explicitly allows text selection.

p {
  -webkit-user-select: text;
  user-select: text;
}

Example 4: user-select - all

Ensures the entire content is selected in one click.

p {
  -webkit-user-select: all;
  user-select: all;
}

Example 5: user-select - contain

Allows selection only within the element’s boundaries.

p {
  -webkit-user-select: contain;
  user-select: contain;
}

Applies To

The user-select property applies to all elements. However, its effect may differ depending on the browser implementation.

Summary

The user-select property is useful for customizing text selection behavior. For instance, setting it to none prevents copying sensitive UI text, while all makes selecting full blocks of text easier.

Example

Here is a practical usage example:

.button-text {
  user-select: none; /* Prevents accidental selection on button labels */
}

.article-content {
  user-select: text; /* Allows normal text selection */
}

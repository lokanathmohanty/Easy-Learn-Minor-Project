Java Assignment Operators

Session Content

Java assignment operators are used to assign or modify values of variables. The simple assignment operator is '=', which assigns the right operand's value to the left operand. Compound assignment operators combine an arithmetic or bitwise operation with assignment, providing shorthand syntax.

  • = : Assigns right operand to left operand
  • += : Adds right operand to left and assigns result to left
  • -= : Subtracts right operand from left and assigns result
  • *= : Multiplies left operand by right and assigns result
  • /= : Divides left operand by right and assigns result
  • %= : Takes modulus and assigns result
  • <<= : Left shift and assign
  • >>= : Right shift and assign
  • &= : Bitwise AND and assign
  • ^= : Bitwise XOR and assign
  • |= : Bitwise OR and assign

Example 1: Basic Assignment Operations

This program uses simple assignment, addition assignment, subtraction assignment, and multiplication assignment: 

public class Test {
   public static void main(String args[]) {
      int a = 10;
      int b = 20;
      int c = 0;

      c = a + b;
      System.out.println("c = a + b = " + c);

      c += a;
      System.out.println("c += a = " + c);

      c -= a;
      System.out.println("c -= a = " + c);

      c *= a;
      System.out.println("c *= a = " + c);
   }
}
  • c = a + b = 30
  • c += a = 40
  • c -= a = 30
  • c *= a = 300

Example 2: Division, Modulus, and Bitwise Assignments

This program demonstrates divide, modulus, bitwise AND, bitwise XOR, and bitwise OR assignments: 

public class Test {
   public static void main(String args[]) {
      int a = 10;
      int c = 15;

      c /= a;
      System.out.println("c /= a = " + c);

      c = 15;
      c %= a;
      System.out.println("c %= a = " + c);

      c = 15;
      c &= a;
      System.out.println("c &= a = " + c);

      c = 15;
      c ^= a;
      System.out.println("c ^= a = " + c);

      c = 15;
      c |= a;
      System.out.println("c |= a = " + c);
   }
}
  • c /= a = 1
  • c %= a = 5
  • c &= a = 10
  • c ^= a = 5
  • c |= a = 15

Example 3: Bit Shift Assignments

This example shows left shift and right shift assignment operators: 

public class Test {
   public static void main(String args[]) {
      int a = 10;
      int c = 0;

      c <<= 2;
      System.out.println("c <<= 2 = " + c);

      c = 15;
      c >>= 2;
      System.out.println("c >>= 2 = " + c);
   }
}
  • c <<= 2 = 0
  • c >>= 2 = 3

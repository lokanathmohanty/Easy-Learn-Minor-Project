JavaScript - Ajax

Asynchronous JavaScript and XML (Ajax) is a web development technique that enables dynamic, interactive communication between server and webpage without requiring a full page reload. Ajax allows data exchanges in the background, making web applications seamless and responsive.

How Ajax Works?

Ajax relies on the XMLHttpRequest object to send requests and receive responses asynchronously from a server. The server typically returns data in JSON or XML format, and JavaScript updates parts of the webpage without refreshing the entire page.

This background communication ensures that user interaction is not interrupted, enabling real-time updates and smoother web experiences.

Approaches to Implement Ajax

There are four common ways to implement Ajax in JavaScript:

  • XMLHttpRequest (Older Approach)
  • Fetch API (Modern Approach)
  • Axios (Promise-based HTTP library)
  • jQuery Ajax (Legacy approach with jQuery)

In the following examples, we use JSONPlaceholder, a free REST API that provides dummy data for testing.

Using XMLHttpRequest

The native JavaScript XMLHttpRequest object was the earliest way to make asynchronous requests. It requires handling request states manually. 

function nativeAjax() {
  var xhr = new XMLHttpRequest();
  xhr.open('GET', 'https://jsonplaceholder.typicode.com/users/2', true);
  xhr.onreadystatechange = function () {
    if (xhr.readyState == 4 && xhr.status == 200) {
      console.log(JSON.parse(xhr.responseText));
    }
  };
  xhr.send();
}

Using Fetch API

The Fetch API provides a cleaner, Promise-based syntax for making HTTP requests. It is widely used in modern JavaScript. 

function fetchApi() {
  fetch('https://jsonplaceholder.typicode.com/users/3')
    .then(response => response.json())
    .then(data => console.log(data))
    .catch(error => console.error('Fetch Error:', error));
}

Using Axios

Axios is a popular library built on Promises. It simplifies HTTP requests and automatically transforms JSON responses. 

function axiosExample() {
  axios.get('https://jsonplaceholder.typicode.com/users/5')
    .then(response => console.log(response.data))
    .catch(error => console.error('Axios Error:', error));
}

Using jQuery Ajax

jQuery’s $.ajax method simplifies Ajax requests and ensures cross-browser compatibility. Although less common in modern apps, it remains useful in legacy projects. 

function jqueryAjax() {
  $.ajax({
    url: 'https://jsonplaceholder.typicode.com/users/7',
    method: 'GET',
    dataType: 'json',
    success: function (data) {
      console.log(data);
    },
    error: function (xhr, status, error) {
      console.error('jQuery Ajax Error:', error);
    }
  });
}

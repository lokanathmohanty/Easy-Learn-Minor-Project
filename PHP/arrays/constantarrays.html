PHP Constant Arrays

A **Constant Array** in PHP is an array whose values, once defined, **cannot be altered** (modified, added to, or removed) during the script's execution. They are useful for storing fixed configuration values or immutable lists.

Constant arrays were introduced in PHP 5.6 and newer versions. Unlike regular variables, their identifiers **do not** start with the dollar sign (`$`).

Defining Constant Arrays

Constant arrays can be declared using two methods:

1. Using the `const` Keyword (Global Scope)

The `const` keyword is used to declare constants at the top level of a script or inside a class.

**Syntax:** const ARRAY_NAME = ["val1", "val2", "val3"];

**Example:** const FRUITS = ["Watermelon", "Strawberries", "Pomegranate"];

The `FRUITS` array is fixed and cannot be changed.

2. Using the `define()` Function (PHP 7+)

The `define()` function allows for defining constants, including constant arrays, and can be used in the global scope.

**Syntax:** define('ARRAY_NAME', ["val1", "val2", "val3"]);

**Example (Associative Array):** define ('CAPITALS', array(
   "Maharashtra" => "Mumbai",
   "Telangana" => "Hyderabad"
));

Output: Array ( [Maharashtra] => Mumbai [Telangana] => Hyderabad )

Immutability (The Fatal Error)

Any attempt to change, add, or remove an element from a constant array will result in a fatal error, confirming its immutable nature.

const FRUITS = ["Apple", "Banana"];
FRUITS[1] = "Mango"; // Attempts to modify the element

$\rightarrow$ **PHP Fatal error:** Cannot use temporary expression in write context

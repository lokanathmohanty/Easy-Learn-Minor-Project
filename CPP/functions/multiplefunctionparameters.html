C++ Functions with Multiple Parameters 🔢

C++ functions can accept **multiple parameters** (arguments), enabling them to perform complex operations that require several inputs. This feature is fundamental to modular design, allowing functions to work with various subsets of data simultaneously.

Syntax and Data Types

Multiple parameters are defined in the function signature by listing them separated by commas, each with its own specific **data type** and **name**.

return_type function_name(param1_type param1_name, param2_type param2_name, ...);

Functions can accept parameters of a **single data type** (e.g., three ints for a sum) or **multiple different data types** (e.g., a string name, an int age, and a double height), allowing for flexible input handling.

Parameter Passing Techniques

The technique used to pass multiple arguments determines how the data is transferred and whether the function can modify the original variables:

  • Pass by Value (Default): A **copy** of the actual argument's value is passed. Changes inside the function **do not** affect the original variable. This is simple and safe but can be inefficient for large objects.
  • Pass by Reference (using &): A **reference (alias)** to the original variable is passed. The function works directly with the original data, meaning changes **do** affect the original variable. This is highly efficient as it avoids copying.
  • Pass by Constant Reference (using const &): The address is passed for efficiency, but the const keyword ensures the function **cannot modify** the original data. This is the best practice for passing large immutable types like std::string.

Types of Multiple Parameters

1. Fixed Number of Parameters

The standard function type where the exact number of parameters is specified in the declaration and remains constant for every call.

2. Default Parameters

Parameters assigned a default value in the function declaration. If the argument is omitted during the function call, the default value is used. Default parameters must be placed at the **end** of the parameter list.

// If no name or age is provided, defaults are used.
void greet(const string& name = "Guest", int age = 0);

3. Variable Number of Parameters (Variadic)

Functions that can accept an arbitrary, unspecified number of arguments. In modern C++ (since C++11), this is accomplished using **variadic templates** (template<typename... Args>).

4. Parameter Objects and Named Parameters

While C++ doesn't have native **named parameters**, a clean, object-oriented approach is to group related values into a **struct** or **class** (a **Parameter Object**). The function then takes a single parameter of that complex type, improving readability and organization.

struct Person { string name; int age; };

// Function takes one Person object, containing multiple data points.
void printPerson(const Person& p) { ... }

Python Closures

A Python closure is a nested function which captures and retains variables from its enclosing function's scope even after the outer function has finished execution. This allows the inner function to remember and access those variables later. To modify immutable outer variables within a closure, the nonlocal keyword is used.

Closures help avoid using global variables and provide data hiding, and are often used in decorators.

Nested Functions

Nested functions are functions defined inside other functions. The inner function can be invoked within the outer function's scope.

def functionA():
    print("Outer function")
    def functionB():
        print("Inner function")
    functionB()

functionA()

Output:

Outer function
Inner function

The outer function can pass arguments to the inner function:

def functionA(name):
    print("Outer function")
    def functionB():
        print("Inner function")
        print("Hi {}".format(name))
    functionB()

functionA("Python")

Output:

Outer function
Inner function
Hi Python

Variable Scope and Closures

Closures retain access to variables from their enclosing scopes even after those scopes have finished execution. 

def outer_function(x):
    y = 10
    def inner_function(z):
        return x + y + z  # x and y captured
    return inner_function

closure = outer_function(5)
result = closure(3)
print(result)  # Output: 18

Creating a Closure

A closure is created by returning a nested function from an outer function, thereby capturing the variables in that outer scope. 

def functionA(name):
    name = "New name"
    def functionB():
        print(name)
    return functionB

myfunction = functionA("My name")
myfunction()  # Output: New name

Using the nonlocal Keyword

The nonlocal keyword allows modifying an outer, but non-global, variable inside a nested function: 

def functionA():
    counter = 0
    def functionB():
        nonlocal counter
        counter += 1
        return counter
    return functionB

myfunction = functionA()

print("Counter:", myfunction())  # Counter: 1
print("Counter:", myfunction())  # Counter: 2
print("Counter:", myfunction())  # Counter: 3

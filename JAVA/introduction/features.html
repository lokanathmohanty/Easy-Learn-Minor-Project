Java - Features

Java programming language was initially developed to work on embedded systems, set-top boxes, television. So by requirements, it was initially designed to work on varied platforms. Over the period of multiple years, Java evolved to become one of the most popular languages used to develop internet-based applications.

Java is a feature-rich language and with every new version, it is continuously evolving. It is widely used across billions of devices. Following are the main features of the Java language:

  • Object Oriented
  • Platform Independent
  • Simple
  • Secure
  • Architecture-neutral
  • Portable
  • Robust
  • Multithreaded
  • Interpreted
  • High Performance
  • Distributed
  • Dynamic

Object Oriented

In Java, everything is an object. Java can be easily extended since it is based on the object model. As a language that has the Object-Oriented feature, Java supports the following fundamental concepts of OOPs:

  • Polymorphism
  • Inheritance
  • Encapsulation
  • Abstraction
  • Classes
  • Objects
  • Instance
  • Method
  • Message Passing

Platform Independent

Unlike many other programming languages including C and C++, when Java is compiled, it is not compiled into platform-specific machine code, but into platform-independent byte code. This byte code is distributed over the web and interpreted by the Java Virtual Machine (JVM) on whichever platform it is being run on.

Java is designed in Write Once, Run Anywhere (WORA) way. Code written in Java is not directly dependent on the type of machine it is running. It is compiled into ByteCode which is platform independent. Platform-specific JVMs interpret the bytecode, allowing Java code to run on Windows, Linux, Unix, Mac, etc., without modification.

Simple

Java is designed to be easy to learn. If you understand the basic concept of OOP, Java would be easy to master.

It inherits features from C and C++ but removes complex ones like pointers, operator overloading, multiple inheritance, and explicit memory allocation. Java includes automatic garbage collection and a rich set of libraries that simplify development.

Secure

With Java's secure features, it enables development of virus-free, tamper-free systems. Authentication techniques are based on public-key encryption.

Java avoids direct interaction with system memory, preventing issues like buffer overflows. Exception handling and garbage collection enhance security and stability.

Architecture-neutral

Java compiler generates an architecture-neutral object file format, making compiled code executable on many processors with a JVM present.

JVMs can be implemented for different architectures, so a Java program compiled on Windows can run on Linux or Mac without changes.

Portable

Java's architecture-neutral nature and lack of platform-specific features make it highly portable. Java programs can run on various systems without modification.

The compiler is written in ANSI C with a POSIX subset for clean portability.

Robust

Java emphasizes error checking at compile time and runtime. Features like garbage collection, strong memory management, and exception handling make Java a robust language.

Multithreaded

Java supports multithreaded programming, allowing multiple tasks to run concurrently within a single program. This improves efficiency and user experience, especially on multi-core systems.

Multithreading enables programs to make better use of CPU resources and handle multiple operations smoothly.

Interpreted

Java bytecode is interpreted on the fly by the JVM using Just-In-Time (JIT) compilation. This improves development speed and enables dynamic linking.

The JVM sits between the compiled bytecode and hardware, translating bytecode into native instructions during execution.

High Performance

Java achieves high performance through JIT compilers. JIT optimizes bytecode execution by applying techniques like:

  • Method inlining
  • Dead code elimination
  • Heuristics for optimizing call sites
  • Constant folding

Distributed

Java is designed for the distributed environment of the internet, making it suitable for applications that run across multiple systems and communicate over networks.

Dynamic

Java is dynamic and adaptable to an evolving environment. It carries run-time type information to verify and resolve object access during execution.

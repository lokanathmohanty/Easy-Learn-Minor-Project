Java - SortedSet Interface

The SortedSet interface extends Set and models a set sorted in ascending order.

It adds several methods beyond those of Set. Exceptions such as NoSuchElementException, ClassCastException, and NullPointerException may be thrown in certain conditions.

SortedSet Interface Methods

  • comparator(): Returns the comparator used, or null if natural ordering is used.
  • first(): Returns the first (lowest) element.
  • headSet(Object end): Returns a view of elements less than end.
  • last(): Returns the last (highest) element.
  • subSet(Object start, Object end): Returns elements between start (inclusive) and end (exclusive).
  • tailSet(Object start): Returns elements greater than or equal to start.

Operations on SortedSet Interface

Creating a SortedSet: Use the TreeSet class, e.g.:

SortedSet<String> set = new TreeSet<>();

Adding Values: The add() method adds elements if not already present.

set.add("b");
set.add("c");
set.add("a");

Getting Values: Use an iterator:

Iterator it = set.iterator();
while (it.hasNext()) {
  Object element = it.next();
  System.out.println(element.toString());
}

Deleting Values: Use remove() method:

set.remove("a");

Iterating SortedSet: The iterator() method provides traversal over the set elements.

Example 1: Adding Elements to a SortedSet

import java.util.Iterator;
import java.util.SortedSet;
import java.util.TreeSet;

public class SortedSetDemo {
  public static void main(String[] args) {
    SortedSet<String> set = new TreeSet<>();
    set.add("b");
    set.add("c");
    set.add("a");
    Iterator it = set.iterator();
    while (it.hasNext()) {
      Object element = it.next();
      System.out.println(element.toString());
    }
  }
}

Output:

a
b
c

Example 2: Removing Elements from a SortedSet

import java.util.Iterator;
import java.util.SortedSet;
import java.util.TreeSet;

public class SortedSetDemo {
  public static void main(String[] args) {
    SortedSet<String> set = new TreeSet<>();
    set.add("b");
    set.add("c");
    set.add("a");
    set.add("d");
    set.add("e");
    set.add("f");
    set.remove("c");
    set.remove("f");
    Iterator it = set.iterator();
    while (it.hasNext()) {
      Object element = it.next();
      System.out.println(element.toString());
    }
  }
}

Output:

a
b
d
e

Example 3: Clearing a SortedSet

import java.util.Iterator;
import java.util.SortedSet;
import java.util.TreeSet;

public class SortedSetDemo {
  public static void main(String[] args) {
    SortedSet<String> set = new TreeSet<>();
    set.add("b");
    set.add("c");
    set.add("a");
    set.add("d");
    set.add("e");
    set.add("f");
    System.out.println(set);
    set.clear();
    System.out.println(set);
  }
}

Output:

[a, b, c, d, e, f]
[]

Advantages of SortedSet Interface

  • Maintains elements in ascending sorted order.
  • Efficient searches due to sorting and uniqueness.
  • Supports custom sorting using a comparator.

Disadvantages of SortedSet Interface

  • Performance overhead due to sorting on every modification.
  • Does not support duplicate elements.

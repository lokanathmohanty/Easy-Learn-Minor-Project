C# Classes and Objects

C# Classes (The Blueprint)

A **class** is the fundamental construct of Object-Oriented Programming (OOP) in C#. It serves as a **blueprint** or **template** for creating objects. A class encapsulates related **data (fields)** and **behavior (methods)** together, helping to achieve **encapsulation** and code organization.

Declaration Syntax:

<access specifier> class ClassName {
   // Member Variables (Fields)
   <access specifier> <data type> variable1;
   
   // Member Methods (Functions)
   <access specifier> <return type> method1(parameter_list) {
      // method body
   }
}

Note: The default access specifier for a class itself is `internal`. The default access specifier for class members (fields, methods) is `private`.

C# Objects (The Instance)

An **object** is an **instance** of a class. It is a concrete entity created from the class blueprint. An object stores specific data (its state) and can access the methods defined in its class (its behavior).

Object Instantiation:

Objects are created using the **`new`** keyword, which allocates memory for the object on the **Heap**.

class_name object_name = new class_name();

// Example:
Box Box1 = new Box(); // Box1 is an object (instance) of the Box class

Accessing Members:

Class members are accessed using the **dot (`.`) operator** linked to the object name.

Box1.height = 5.0; // Accessing a field (data)
double vol = Box1.getVolume(); // Calling a method (behavior)

Constructors and Destructors

Constructors

A **constructor** is a special method with the **same name as the class** and no return type. It is executed automatically when an object is created using the `new` keyword. Its purpose is to initialize the object's fields.

  • Default Constructor: Has no parameters.
  • Parameterized Constructor: Takes arguments, allowing you to set initial field values at creation.
class Line {
   // Default Constructor
   public Line() { Console.WriteLine("Object is being created"); } 
   
   // Parameterized Constructor
   public Line(double len) { this.length = len; }
}

Destructors

A **destructor** is a special method prefixed with a tilde (`~`) and also has the same name as the class. It is used to perform any necessary cleanup before the garbage collector reclaims the object's memory. Destructors cannot be called explicitly, cannot have parameters, and cannot be overloaded.

~Line() { 
    Console.WriteLine("Object is being deleted"); 
}

Access Modifiers and Encapsulation

Access modifiers define visibility. Good practice dictates using **`private`** for fields (data) to achieve **encapsulation**, forcing interaction via public methods or properties to control data manipulation.

Modifier Scope
public Accessible from **anywhere**.
private Accessible **only within the same class**. (Default for members)
protected Accessible within the same class and **derived classes**.
internal Accessible within the **current assembly** (project). (Default for class type)

Example of Encapsulation:

class Box {
   private double length; // Data is hidden

   public void setLength(double len) { // Controlled access via public method
      length = len;
   }
   public double getVolume() { // Method to access computed value
      return length * ...;
   }
}

Static Members

The **`static`** keyword is used to declare members that belong to the **class itself**, rather than to any specific instance (object) of the class. Only a single copy of a static member exists, regardless of how many objects are created.

  • **Static Variables:** Used for values shared by all instances, like counters or global constants. They are accessed via the class name: StaticVar.num.
  • **Static Methods:** Can only access other static members. They are often used for utility functions that don't need object-specific data (e.g., Main() method).

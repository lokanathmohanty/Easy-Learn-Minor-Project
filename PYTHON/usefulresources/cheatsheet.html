Python Cheatsheet

This Python cheatsheet provides a quick reference to Python basics, syntax, functions, methods, operators, and useful libraries.

1. Variables & Data Types

  • x = 10 → Integer
  • y = 3.14 → Float
  • name = "Python" → String
  • is_true = True → Boolean
  • nums = [1,2,3] → List
  • t = (1,2,3) → Tuple
  • s = {1,2,3} → Set
  • d = {"a":1, "b":2} → Dictionary

2. Operators

  • Arithmetic: +, -, *, /, //, %, **
  • Comparison: ==, !=, >, <, >=, <=
  • Logical: and, or, not
  • Membership: in, not in
  • Identity: is, is not

3. Strings

  • s = "Hello World"
  • s.lower(), s.upper(), s.title()
  • s.strip(), s.replace("World","Python")
  • s.split(), "-".join(["a","b","c"])
  • s.find("o"), s.startswith("He"), s.endswith("ld")

4. Lists

  • nums = [1,2,3]
  • nums.append(4), nums.extend([5,6])
  • nums.insert(1,99), nums.remove(3), nums.pop()
  • nums.sort(), nums.reverse()
  • nums[0], nums[-1], nums[1:3]

5. Dictionaries

  • d = {"a":1, "b":2}
  • d["a"], d.get("b")
  • d.keys(), d.values(), d.items()
  • d.update({"c":3}), d.pop("a")

6. Sets

  • s = {1,2,3}
  • s.add(4), s.remove(2), s.discard(5)
  • {1,2} | {2,3} → Union
  • {1,2} & {2,3} → Intersection
  • {1,2} - {2,3} → Difference

7. Conditionals

  • if x > 0:
    print("Positive")
elif x == 0:
    print("Zero")
else:
    print("Negative")

8. Loops

  • for i in range(5):
    print(i)
          
  • while x > 0:
    x -= 1

9. Functions

  • def add(a, b=0):
    return a + b

print(add(2, 3))

10. Classes

  • class Person:
    def __init__(self, name):
        self.name = name

    def greet(self):
        return f"Hello {self.name}"

p = Person("Alice")
print(p.greet())

11. Exceptions

  • try:
    x = 10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero")
finally:
    print("Done")

12. File Handling

  • with open("file.txt", "r") as f:
    content = f.read()
          
  • with open("file.txt", "w") as f:
    f.write("Hello")

13. Common Modules

  • import math → math.sqrt(16), math.pi
  • import random → random.randint(1,10)
  • import datetime → datetime.datetime.now()
  • import os → os.getcwd(), os.listdir()

14. List Comprehension

  • [x**2 for x in range(5)] → [0,1,4,9,16]

15. Lambda & Map/Filter/Reduce

  • f = lambda x: x*2
  • list(map(lambda x: x+1, [1,2,3]))
  • list(filter(lambda x: x%2==0, [1,2,3,4]))
  • from functools import reduce → reduce(lambda x,y:x+y, [1,2,3])

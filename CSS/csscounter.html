CSS Counters

CSS counters act as variables that are used for numbering purposes. They can be increased or decreased by CSS rules and allow automatic numbering of content such as headings, paragraphs, and list items. This makes them very useful for creating structured, automatically numbered documents.

How to Implement Counters in CSS?

To use counters in CSS, follow three main steps:

  • Initialize the Counter using counter-reset.
  • Increment the Counter using counter-increment.
  • Display the Counter using counter() or counters().

Example: Initializing a Counter

The following example initializes a counter named section and increments it every time a heading appears: 

body {
  counter-reset: section;
}

h2::before {
  counter-increment: section;
  content: "Section " counter(section) ": ";
}

Automatic Numbering with Counters

The below example demonstrates automatic numbering for headings: 

<!DOCTYPE html>
<html>
<head>
  <style>
    body {
      counter-reset: section;
    }
    h2::before {
      counter-increment: section;
      content: "Section " counter(section) ": ";
    }
  </style>
</head>
<body>
  <h1>CSS Counters</h1>
  <h2>SQL Tutorial</h2>
  <h2>JavaScript Tutorial</h2>
  <h2>Python Tutorial</h2>
  <h2>HTML Tutorial</h2>
  <h2>CSS Tutorial</h2>
</body>
</html>

Nesting Counters

CSS counters can also be nested to create hierarchical numbering, such as sections and subsections. 

ol {
  counter-reset: section;
  list-style-type: none;
}

li::before {
  counter-increment: section;
  content: counters(section, ".") " ";
}

Example: Nested Counters

<ol>
  <li>Section 1
    <ol>
      <li>Subsection 1.1</li>
      <li>Subsection 1.2</li>
    </ol>
  </li>
  <li>Section 2
    <ol>
      <li>Subsection 2.1</li>
      <li>Subsection 2.2</li>
    </ol>
  </li>
</ol>

Reversed Counters

A reversed counter counts backwards instead of forwards. This is supported only in Firefox using counter-reset: reversed(). 

body {
  counter-reset: reversed(section);
}

p::before {
  counter-increment: section -1;
  content: "Section " counter(section) ": ";
}

CSS Counter Related Properties

  • counter-reset – Creates or resets a counter.
  • counter-set – Sets a counter to a specific value.
  • counter-increment – Increments a counter value.
  • counter() – Displays the current value of a counter.
  • counters() – Displays nested counter values.
  • @counter-style – Defines custom counter styles.

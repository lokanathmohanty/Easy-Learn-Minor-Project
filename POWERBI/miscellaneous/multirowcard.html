Power BI: Multi-row Card Visualization

The Multi-row Card visual in Power BI displays multiple rows of data fields within a single card, making it ideal for showing grouped and related data such as employee details together. This contrasts with a single-row card, which highlights only one computed value.

How to Create a Multi-row Card Visualization

  1. Select a sample dataset and choose the Multi-row Card visual from the Visualizations pane; an empty multi-row card will appear.
  2. Add fields such as Name, Designation, Salary, and Incentive to the Fields section.
  3. The card will display a list of these fields grouped by records (e.g., different employees with their details).
  4. Use the Drill Through feature for filtering, for instance, add Gender to Drill Through and filter for female employees by checking the "F" checkbox.

Customizing the Multi-row Card Visual

  1. Click on Format Visual; the pane contains two tabs: Visual and General.
  2. Under Visual, customize:
    • Callout Values: Change font style (e.g., Times New Roman), size (e.g., 16), italicize text, and set font color.
    • Category Labels: Adjust font style (e.g., Georgia), size (e.g., 10), italics, and font color.
    • Cards: Set border styles by selecting Top, Bottom, Left, and Right checkboxes under Style.
    • Accent Bar: Change color (e.g., #ad5129) and increase width (e.g., 2px) for visual emphasis.
  3. Under General, modify:
    • Properties: Adjust Size (height, width), Position, Padding, and Advanced options.
    • Title: Turn on the title, enter text (e.g., "Employee Details"), set heading level, choose font (e.g., Calibri), size (e.g., 17), italics, text color (e.g., #d64550), background color (e.g., #f5c4af), and alignment (Center).
    • Subtitle: Turn on subtitle, set text (e.g., "Multiple rows"), heading level, font (e.g., Tahoma), size, italics, and text color, aligned centrally.
    • Divider: Enable, select color (e.g., #73361c), style (Dashed), and width (e.g., 7px) to separate header and rows visually.
    • Effects: Enable background colors (e.g., light pink), visual borders, and shadows to enhance appearance.
    • Header Icons: Change header icon colors including background, border, and icon color for a polished look.
  4. Use the Alt Text section to provide descriptive text for accessibility; this text is read by screen readers when enabled on the system.

HTML - SVG

HTML SVG (Scalable Vector Graphics) is used to define vector graphics in XML format that can be embedded into HTML pages. Unlike bitmap images, SVG retains its quality even when zoomed.

  • SVG stands for Scalable Vector Graphics.
  • It is written in XML and allows drawing shapes, charts, and graphs.
  • Vector images do not lose quality on zoom.
  • SVG became a W3C Recommendation on 14 January 2003.

Bitmap vs Scalable Vector Graphics

PNG, GIF, and JPG are bitmap graphics, while SVG is vector graphics. Bitmap graphics are made of pixels, but vector graphics are defined by code, so they do not lose quality after zooming.

How to Use SVG in HTML?

  • Using <img> tag: Embed SVG as an image file.
  • Using <svg> tag: Write SVG code directly inside HTML.

Example: Using <img> Tag

<img src="svg_file_name.svg" alt="Alternate Text">

Syntax: Using <svg> Tag

<svg>
   <!-- code to create graphics -->
</svg>

Predefined SVG Elements

  • <rect> - Rectangle
  • <circle> - Circle
  • <ellipse> - Ellipse
  • <line> - Line
  • <polyline> - Polyline
  • <polygon> - Polygon

Common Attributes

  • x, y: Top-left coordinates.
  • width, height: Dimensions of rectangle or shape.
  • rx, ry: Roundness of ellipse.
  • style: Inline style.

Examples of Drawing Shapes

Circle

<svg height="500">
   <circle cx="50" cy="50" r="50" fill="red"></circle>
</svg>

Rectangle

<svg height="200">
   <rect width="300" height="100" fill="red"></rect>
</svg>

Line

<svg height="200">
   <line x1="0" y1="0" x2="200" y2="100" 
         style="stroke:red;stroke-width:2"></line>
</svg>

Ellipse

<svg height="200">
   <ellipse cx="100" cy="50" rx="100" ry="50" fill="red"></ellipse>
</svg>

Polygon

<svg height="200">
   <polygon points="20,10 300,20 170,50 130,70" fill="red"></polygon>
</svg>

Polyline

<svg height="200">
   <polyline points="0,0 0,30 30,30 30,60 60,60" fill="red"></polyline>
</svg>

Applying Gradient

You can apply gradients using <linearGradient> or <radialGradient>.

Example

<svg height="200">
   <defs>
      <radialGradient id="gradient" cx="50%" cy="50%" r="50%" fx="50%" fy="50%">
         <stop offset="0%" style="stop-color:rgb(200,200,200);" />
         <stop offset="100%" style="stop-color:rgb(0,0,255);" />
      </radialGradient>
   </defs>
   <ellipse cx="100" cy="50" rx="100" ry="50" style="fill:url(#gradient)"></ellipse>
</svg>

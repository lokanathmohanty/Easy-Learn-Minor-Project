Python - Join Lists

Joining lists in Python refers to combining the elements of multiple lists into a single list. This can be achieved using various methods, such as concatenation, list comprehension, or using built-in functions like extend() or the + operator.

Joining lists does not modify the original lists but creates a new list containing the combined elements.

Joining Lists Using Concatenation Operator

The concatenation operator + joins lists and creates a new list with all elements from both lists.

Example: Using + Operator

# Two lists to be joined
L1 = [10, 20, 30, 40]
L2 = ['one', 'two', 'three', 'four']
# Joining the lists
joined_list = L1 + L2
print("Joined List:", joined_list)

Output:

Joined List: [10, 20, 30, 40, 'one', 'two', 'three', 'four']

Joining Lists Using List Comprehension

List comprehension can join lists by iterating over multiple lists and combining their elements into a new list.

Example: List Comprehension

L1 = [36, 24, 3]
L2 = [84, 5, 81]
# Joining using list comprehension
joined_list = [item for sublist in [L1, L2] for item in sublist]
print("Joined List:", joined_list)

Output:

Joined List: [36, 24, 3, 84, 5, 81]

Joining Lists Using append() Function

The append() function adds a single element to the end of a list. By iterating over a second list and appending each element, two lists can be joined.

Example: Using append()

list1 = ['Fruit', 'Number', 'Animal']
list2 = ['Apple', 5, 'Dog']
for element in list2:
    list1.append(element)
print("Joined List:", list1)

Output:

Joined List: ['Fruit', 'Number', 'Animal', 'Apple', 5, 'Dog']

Joining Lists Using extend() Function

The extend() function appends all elements of another list (or iterable) to the end of the current list.

Example: Using extend()

list1 = [10, 15, 20]
list2 = [25, 30, 35]
list1.extend(list2)
print("Extended List:", list1)

Output:

Extended List: [10, 15, 20, 25, 30, 35]

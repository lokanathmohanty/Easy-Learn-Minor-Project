Django: Adding CSS Files as Static Assets 🎨

CSS (Cascading Style Sheets) is the language used to specify the presentation and styling of an HTML document. In Django, CSS files are treated as **static assets** and managed by the django.contrib.staticfiles application.

To include a CSS file in a template, it must be stored in the **static folder** inside your app's package directory.

Steps to Include CSS in a Template

To ensure Django can correctly locate and serve the CSS file (e.g., style.css) within your HTML template, use the following two steps:

1. Load the Static Template Tag

Add the {% load static %} tag at the beginning of your HTML template to enable Django's static file functionality:

{% load static %}

2. Link the CSS File

Use the **{% static 'file_path' %}** template tag within the href attribute of the <link> tag. This dynamically generates the correct path to the static asset.

<link rel="stylesheet" type="text/css" href="{% static 'style.css' %}">

Application Example (cities.html)

The following template loads the CSS file in the <head> section and then iterates through a list of cities passed from the view to display them in an unordered list:

<html><head>
   {% load static %}
   <link rel="stylesheet" type="text/css" href="{% static 'style.css' %}">
</head><body>
   <h2>List of Cities</h2>
   <ul>
      {% for city in cities %}
         <li>{{ city }} </li>
      {% endfor %}
   </ul>
</body></html>

View and Styling

The view simply fetches the data and renders the template:

def index(request):
   cities = ['Mumbai', 'New Delhi', 'Kolkata', 'Bengaluru', 'Chennai', 'Hyderabad']
   return render(request, "cities.html", {"cities":cities})

The **style.css** file placed in the static folder contains the actual styling rules that are then applied to the rendered page (e.g., setting the background color, font sizes, and text color).

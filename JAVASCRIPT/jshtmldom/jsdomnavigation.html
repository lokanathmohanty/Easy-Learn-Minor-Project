JavaScript - DOM Navigation

Introduction

In JavaScript, with the HTML DOM we can navigate the tree nodes using their relationships. Every HTML document forms a DOM tree with the document object as the root.

Each element, text, and comment in the HTML is represented as a node.

Types of Nodes

  • Root Node − The document object.
  • Parent Node − A node that contains other nodes.
  • Child Node − A node inside another node.
  • Sibling Node − Nodes at the same level with the same parent.

Example DOM Structure


<html>
  <head>
    <title> JavaScript - DOM Navigation </title>
  </head>
  <body>
    <div>
      <h3> Hi Users! </h3>
      <p> Hello World! </p>
    </div>
  </body>
</html>

Here:

  • <html> → root node (no parent).
  • <head> and <body> → children of <html>.
  • <title> → child of <head>.
  • <div> → child of <body>.
  • <h3> and <p> → siblings inside <div>.

DOM Navigation Properties

PropertyDescription
firstChildReturns the first child (can be text, comment, etc.)
firstElementChildReturns the first element child (e.g., <p>, <div>)
lastChildReturns the last child node
lastElementChildReturns the last element child
childNodesReturns all child nodes (including text, comments)
childrenReturns only element children
parentNodeReturns the parent node
parentElementReturns the parent element node
nextSiblingReturns the next sibling node
nextElementSiblingReturns the next sibling element
previousSiblingReturns the previous sibling node
previousElementSiblingReturns the previous sibling element

Examples

Accessing the First Child


const numbers = document.getElementById("num");
console.log(numbers.firstChild.textContent);        // text node
console.log(numbers.firstElementChild.textContent); // <p> element

Accessing the Last Child


const langs = document.getElementById("lang");
console.log(langs.lastChild.textContent.trim());       // text node
console.log(langs.lastElementChild.textContent);       // <p> element

Accessing All Children


let children = langs.childNodes;   // includes text
let elements = langs.children;     // only elements

Accessing Parent Node


const blue = document.getElementById("blue");
console.log(blue.parentNode.nodeName);  // UL

Accessing Sibling Nodes


apple.nextElementSibling.textContent;    // Banana
banana.previousElementSibling.textContent; // Apple

DOM Root Nodes

  • document.body → returns the <body> element.
  • document.documentElement → returns the full <html> element.

Node Properties

  • nodeName → name of the node (UPPERCASE for tags, #text for text, #document for document).
  • nodeValue → returns the value of the node (null for elements, text content for text nodes).
  • nodeType → returns the type of node (1 = Element, 3 = Text, 8 = Comment, 9 = Document, 10 = Doctype).

Example: Node Type


const div = document.getElementById("output");
console.log(div.nodeName);  // DIV
console.log(div.nodeType);  // 1

Conclusion

DOM Navigation lets you move up, down, and across the DOM tree (parents, children, siblings). Mastering these properties is essential for manipulating web pages dynamically with JavaScript.

Java ArrayDeque Class Summary ↔️💨

The **java.util.ArrayDeque** class is the preferred, high-performance implementation of the **Deque** (Double-Ended Queue) interface. It is implemented using a resizable array and is optimized for insertions and deletions at **both the front and the back**.

I. Core Characteristics and Performance

ArrayDeque offers efficient, dynamically growing storage, making it the modern replacement for the legacy Stack and often a high-performance alternative to LinkedList for pure Queue/Stack use cases.

  • **Double-Ended:** It implements the Deque interface, supporting element insertion and removal at both ends: head (first) and tail (last).
  • **Resizable Array:** It is array-backed, but the array automatically resizes as needed (no capacity restrictions).
  • **High Performance:** It is **generally faster** than both the synchronized **Stack** and the node-traversing **LinkedList** for LIFO (stack) and FIFO (queue) operations.
  • **Non-Synchronized:** It is **not thread-safe**. External synchronization is required for concurrent access.
  • **Null Prohibition:** **Null elements are explicitly prohibited** in an `ArrayDeque`.

II. Dual Role as Queue and Stack

Because it's a Deque, ArrayDeque can efficiently be used as both a Queue (FIFO) and a Stack (LIFO).

Role Mechanism Primary Methods (Constant Time $O(1)$)
Queue (FIFO) Elements added to the tail, removed from the head. offerLast(E e) / pollFirst()
Stack (LIFO) Elements added to the head, removed from the head. push(E e) / pop()

III. Essential Deque Methods (Insertion/Removal)

The methods ensure consistent access to both ends of the queue. Methods starting with `add` or `remove` throw an exception on failure, while methods starting with `offer` or `poll` return a boolean or null.

  • **Head Operations (First Element):**
    • **Insert:** addFirst(E e), offerFirst(E e), push(E e)
    • **Remove:** removeFirst(), pollFirst(), pop()
  • **Tail Operations (Last Element):**
    • **Insert:** addLast(E e), offerLast(E e)
    • **Remove:** removeLast(), pollLast()

The example demonstrates the symmetrical use of the Deque at both ends:

// Add to head and tail
objDeque.addFirst(15);
objDeque.addLast(28); // Deque is now: [15, 28]

// Remove from head and tail
int ele1 = objDeque.removeFirst(); // 15
int ele2 = objDeque.removeLast();  // 28

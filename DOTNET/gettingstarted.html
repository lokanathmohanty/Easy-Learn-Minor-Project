.NET Core - Getting Started (Creating a Console App)

This session describes how to create your first **.NET Core application** within the **Visual Studio 2015** development environment, assuming the necessary tooling has been installed.

Creating a New .NET Core Project

To begin a new project, navigate to the **New Project** dialog box in Visual Studio and follow these steps:

  1. In the **Templates** list, expand the **Visual C#** node.
  2. Select **.NET Core**. You will see the following project templates:
    • Class Library (.NET Core)
    • Console Application (.NET Core)
    • ASP.NET Core Web Application (.NET Core)
  3. Select **Console Application (.NET Core)**.
  4. Name the project **"FirstApp"** and click **OK**.

Visual Studio will generate the project structure, which you can view in the **Solution Explorer** window.

Testing the Console Application

To test the functionality of the new **Console Application** project, use the following C# code. This code simply prints a greeting message to the console.

using System;
using System.Collections.Generic;
using System.Linq;
using System.Threading.Tasks; 

namespace FirstApp { 
   public class Program { 
      public static void Main(string[] args) { 
         Console.WriteLine("Hello guys, welcome to .NET Core world!"); 
      } 
   } 
}

After running the application (usually by pressing F5 or clicking the 'Start' button), you should see the following output:

Hello guys, welcome to .NET Core world!

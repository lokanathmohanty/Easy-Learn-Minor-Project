Java - ThreadGroup Class

ThreadGroup Class

The Java ThreadGroup class represents a set of threads. It can also include other thread groups, forming a tree structure. Each group (except the initial group) has a parent group.

ThreadGroup Class Declaration


public class ThreadGroup
   extends Object
   implements Thread.UncaughtExceptionHandler

Constructors

  • ThreadGroup(String name) – Constructs a new thread group.
  • ThreadGroup(ThreadGroup parent, String name) – Creates a new thread group with a parent.

Methods

  • int activeCount() – Returns the number of active threads.
  • int activeGroupCount() – Returns the number of active groups.
  • void checkAccess() – Checks if the current thread can access this group.
  • void destroy() – Destroys this thread group and all subgroups.
  • int enumerate(Thread[] list) – Copies active threads into the array.
  • int enumerate(Thread[] list, boolean recurse) – Copies active threads, with optional recursion.
  • int enumerate(ThreadGroup[] list) – Copies active subgroups into the array.
  • int enumerate(ThreadGroup[] list, boolean recurse) – Copies active subgroups, with optional recursion.
  • int getMaxPriority() – Returns the group’s max priority.
  • String getName() – Returns the group’s name.
  • ThreadGroup getParent() – Returns the parent group.
  • void interrupt() – Interrupts all threads in the group.
  • boolean isDaemon() – Tests if the group is a daemon group.
  • boolean isDestroyed() – Checks if the group is destroyed.
  • void list() – Prints info about this group.
  • boolean parentOf(ThreadGroup g) – Tests if this group is the parent or ancestor of another group.
  • void setDaemon(boolean daemon) – Sets the daemon status.
  • void setMaxPriority(int pri) – Sets the max priority for the group.
  • String toString() – Returns a string representation.
  • void uncaughtException(Thread t, Throwable e) – Called by JVM when a thread has an uncaught exception.

Inherited Methods

This class inherits methods from java.lang.Object.

Example: Using ThreadGroup in Java

This example demonstrates creating a parent and child thread group and launching threads within them.


public class ThreadGroupDemo implements Runnable {
   public static void main(String[] args) {
      ThreadGroupDemo tg = new ThreadGroupDemo();
      tg.func();
   }

   public void func() {
      try {
         ThreadGroup pGroup = new ThreadGroup("Parent ThreadGroup");
         ThreadGroup cGroup = new ThreadGroup(pGroup, "Child ThreadGroup");

         Thread t1 = new Thread(pGroup, this);
         System.out.println("Starting " + t1.getName() + "...");
         t1.start();

         Thread t2 = new Thread(cGroup, this);
         System.out.println("Starting " + t2.getName() + "...");
         t2.start();

         System.out.println("Active threads in \"" + pGroup.getName() + 
            "\" = " + pGroup.activeCount());

         t1.join();
         t2.join();
      } catch (InterruptedException ex) {
         System.out.println(ex.toString());
      }
   }

   public void run() {
      for (int i = 0; i < 1000; i++) {
         i++;
      }
      System.out.println(Thread.currentThread().getName() + " finished executing.");
   }
}

Output:


Starting Thread-0...
Starting Thread-1...
Thread-0 finished executing.
Active threads in "Parent ThreadGroup" = 1
Thread-1 finished executing.

Return Statement in C

The return statement terminates the execution of a function and returns control to the calling function. Every function should have a return statement as its last statement. The return type and returned value (expression) must match.

Syntax of return Statement

return value_or_expression;

Example with main() function returning 0 to indicate successful completion:

int main(){
   // function body;
   return 0;
}

Returning non-zero indicates failure.

The void return Statement

Functions with void return type may omit the return statement or use return; without any expression.

#include <stdio.h>

/* function declaration */
void test() {
   return;
}

int main() {
   test();
   printf("end");
   return 0;
}

Return Type Mismatch Error

If the function prototype and definition have conflicting return types, the compiler throws an error.

int main() {
   test(5);
   printf("end");
   return 0;
}

float test(int a) {
   return 1.1;
}

Error: conflicting types for 'test'

This happens because without a prototype, functions are assumed to return int by default.

Return Type Mismatch in Prototype vs Definition

float test(int);

int main() {
   test(5);
   printf("end");
   return 0;
}

float test(float a) {
   return 1.1;
}

Prototype and definition mismatch causes a compile error.

Multiple Return Statements

A function can have multiple conditional return statements but can return only a single value per call.

int test(int);

int main() {
   test(5);
   printf("end");
   return 0;
}

int test(int a) {
   if (a < 3)
      return 1;
   else
      return 0;
}

Function Returning an Array (Using Pointer)

Functions cannot return entire arrays, but they can return pointers to arrays.

#include <stdio.h>

int* test(int *);

int main() {
   int a[] = {1, 2, 3, 4};
   int i;
   int *b = test(a);

   for (i = 0; i < 4; i++) {
      printf("%d\n", b[i]);
   }
   return 0;
}

int* test(int *a) {
   int i;
   for (i = 0; i < 4; i++) {
      a[i] = 2 * a[i];
   }
   return a;
}

Output:

2
4
6
8

To return multiple values, use pointers or structures.

exit() Instead of return Statement

The exit() function terminates program execution immediately without returning control to the calling function. It is useful for unrecoverable errors or normal termination.

exit() is declared in the <stdlib.h> header.

void exit(int status);

The status is an integer indicating success or failure, passed back to the operating system.

Unlike return, exit() does not return to the caller but ends the program entirely.

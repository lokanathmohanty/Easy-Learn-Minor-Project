JavaScript - Conditional Operators

Introduction

The conditional operator in JavaScript first evaluates an expression for a true or false value and then executes one of the two given statements depending upon the result of the evaluation. The conditional operator is also known as the ternary operator.

The JavaScript conditional (ternary) operator is the only operator that takes three operands: a condition followed by a question mark (?), then the first expression to be executed if the condition is truthy, followed by a colon (:), and finally the second expression to be executed if the condition is falsy.

There are six falsy values in JavaScript. These are:

  • 0 (zero)
  • false
  • empty string ('' or "")
  • null
  • undefined
  • NaN

All other values are treated as truthy in JavaScript.

Syntax

The syntax of the conditional (ternary) operator in JavaScript is:

var variable = condition ? exp1 : exp2;

Parameters

  • condition − A conditional statement.
  • exp1 − Executed if the conditional statement evaluates truthy.
  • exp2 − Executed if the conditional statement evaluates falsy.

If the value of the condition is any falsy value, the result will be exp2; otherwise, it will be exp1.

Examples

Example 1: Basic Comparison

In this example, we compare the values of num1 and num2 using the conditional operator.

<script>
var num1 = 90;
var num2 = 67;
var res = num1 > num2 ? "num1 is greater than num2" : "num2 is greater than num1";
document.getElementById("output").innerHTML = res;
</script>

Output: num1 is greater than num2

Example 2: Assigning Object Properties

Here, we assign a value to the object property conditionally using the ternary operator.

<script>
const year = 2004;
const obj = {
  name: "John",
  age: year < 2005 ? "adult" : "minor",
  city: "New York"
};
document.getElementById("output").innerHTML = 
  obj.name + " is " + obj.age + " and lives in " + obj.city;
</script>

Output: John is adult and lives in New York

Example 3: Using Expressions

We can also use expressions instead of values inside the ternary operator.

<script>
let operator = '-';
let res = operator == '+' ? 10 + 20 : 10 - 20;
document.getElementById("output").innerHTML = "The result is: " + res;
</script>

Output: The result is: -10

Example 4: Handling Null Values

The conditional operator can handle null values by setting a default value.

<script>
const greet = (user) => {
  const name = user ? user.name : "stranger";
  return `Hello, ${name}`;
};
document.getElementById("output").innerHTML =
  greet({ name: "John" }) + "<br>" +
  greet(null);
</script>

Output:

  • Hello, John
  • Hello, stranger

Conclusion

The ternary or conditional operator allows you to shorten your code by replacing traditional if-else statements with a more concise expression.

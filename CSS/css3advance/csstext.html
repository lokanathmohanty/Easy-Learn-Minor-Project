CSS - Styling Text

CSS Styling Text involves modifying the appearance of text content by setting properties like color, alignment, letter-spacing, and indentation to make it more visually appealing. This session demonstrates how to style text on web pages using CSS properties.

How to Style Text in CSS?

  • Change Color: Use the color property to set text color.
  • Set Alignment: Use the text-align property to align text (left, right, center, justify).
  • Text Decoration: Use the text-decoration property to underline, overline, or strike-through text.
  • Shadow Effect: Use the text-shadow property to add shadows to text.
  • Change Font Style: Use the font-style property to make text normal, italic, or oblique.

Properties for Styling Text

  • color - Sets the color of the text.
  • text-align - Sets horizontal alignment.
  • text-align-last - Sets alignment of the last line.
  • direction - Sets text direction (ltr or rtl).
  • text-indent - Sets indentation of the first line.
  • letter-spacing - Controls spacing between letters.
  • word-spacing - Controls spacing between words.
  • white-space - Controls handling of whitespace.
  • text-decoration - Shorthand for adding decorations.
  • text-transform - Transforms text (uppercase, lowercase, capitalize).
  • line-height - Controls spacing between lines.
  • text-emphasis - Adds emphasis marks.
  • text-shadow - Adds shadows to text.
  • line-break - Controls line breaking rules.
  • word-break - Controls word wrapping.
  • text-orientation - Sets orientation in vertical writing.
  • text-underline-offset - Adjusts underline position.
  • text-overflow - Controls how hidden overflow text is displayed.

Example: Setting Text Color

color: blueviolet;

color: #ff00ff;

color: rgb(255,124,100);

color: rgba(255,124,100,0.5);

color: hsl(7, 98%, 50%);

Example: Text Alignment

Example: Text Decoration

text-decoration: overline solid red 5px;

text-decoration: line-through solid green 1px;

text-decoration: underline dashed blue 2pt;

Example: Text Transform

text-transform: capitalize; → Capitalizes first letter of each word.

text-transform: uppercase; → ALL UPPERCASE.

text-transform: lowercase; → all lowercase.

Example: Text Indentation

Python Command Line Arguments

Python allows programs to accept input parameters from the command line, useful when running scripts with variable values.

The command line arguments after the script name are accessible via sys.argv, a list of strings:

import sys
print(sys.argv)  # argv[0] is script name, argv[1:] are arguments

Simple Example: Using sys.argv

import sys
name = sys.argv[1]
print(f"Hello {name}, how are you?")

Run:

python script.py Alice

Output:

Hello Alice, how are you?

Parsing Numeric Arguments

import sys
a = int(sys.argv[1])
b = int(sys.argv[2])
print(f"Sum: {a + b}")

Arguments are strings; explicit conversion is required for numeric use.

Option Parsing: getopt Module

Provides C-style option parsing, handling short and long options.

import sys, getopt

def main(argv):
    input_file = ''
    output_file = ''
    try:
        opts, args = getopt.getopt(argv, "hi:o:", ["ifile=", "ofile="])
    except getopt.GetoptError:
        print('Usage: script.py -i  -o ')
        sys.exit(2)
    for opt, arg in opts:
        if opt == '-h':
            print('Usage: script.py -i  -o ')
            sys.exit()
        elif opt in ("-i", "--ifile"):
            input_file = arg
        elif opt in ("-o", "--ofile"):
            output_file = arg

    print(f"Input file: {input_file}")
    print(f"Output file: {output_file}")

if __name__ == "__main__":
    main(sys.argv[1:])

Advanced Argument Parsing: argparse Module

Higher-level parsing with support for positional, optional arguments, help messages, type enforcement, and choices.

import argparse

parser = argparse.ArgumentParser(description="Sample argument parser")
parser.add_argument("name", help="your name")
parser.add_argument("--age", type=int, help="your age", default=20)
parser.add_argument("--language", choices=["Python", "Java", "C"], help="favorite language")

args = parser.parse_args()

print(f"Hello {args.name}, age {args.age}")
if args.language:
    print(f"You prefer {args.language}")

Run with:

python script.py Alice --age 30 --language Python

Argument Details

  • Positional arguments: Required arguments identified by position.
  • Optional arguments: Usually prefixed with -, -- and can have default values.
  • Type: Converts argument value to specified type (int, float, etc.).
  • Choices: Restricts argument to given set of values.
  • Help: Automatically generated usage docs with -h or --help.

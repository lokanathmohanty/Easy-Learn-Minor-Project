Python Descriptors

Python Descriptors provide a powerful way to customize attribute access, assignment, and deletion in classes. They are objects that implement one or more of the special methods: __get__, __set__, and __delete__.

When a descriptor is used as a class attribute, Python automatically invokes these methods during attribute access or modification, enabling custom behavior like validation, logging, or computed properties.

Descriptor Methods and Examples

1. The __get__ Method

class Descriptor:
    def __get__(self, instance, owner):
        if instance is None:
            return self
        return instance._value

class MyClass:
    attr = Descriptor()

    def __init__(self, value):
        self._value = value

obj = MyClass(42)
print(obj.attr)  # Outputs: 42

2. The __set__ Method

class Descriptor:
    def __set__(self, instance, value):
        if not isinstance(value, int):
            raise TypeError("Value must be an integer")
        instance._value = value

class MyClass:
    attr = Descriptor()

    def __init__(self, value):
        self.attr = value

obj = MyClass(42)
print(obj.attr)

obj.attr = 100
print(obj.attr)

3. The __delete__ Method

class LoggedDescriptor:
    def __init__(self, name):
        self.name = name

    def __get__(self, instance, owner):
        return instance.__dict__.get(self.name)

    def __set__(self, instance, value):
        instance.__dict__[self.name] = value

    def __delete__(self, instance):
        if self.name in instance.__dict__:
            print(f"Deleting {self.name} from {instance}")
            del instance.__dict__[self.name]
        else:
            raise AttributeError(f"{self.name} not found")

class Person:
    name = LoggedDescriptor("name")
    age = LoggedDescriptor("age")

    def __init__(self, name, age):
        self.name = name
        self.age = age

p = Person("Tutorialspoint", 30)
print(p.name)  # Outputs: Tutorialspoint
print(p.age)   # Outputs: 30
del p.name     # Prints deletion message
print(p.name)  # Outputs: None
del p.age      # Prints deletion message
print(p.age)   # Outputs: None

Types of Descriptors

Criteria Data Descriptors Non-Data Descriptors
Methods Implemented __get__ and __set__ (optional __delete__) Only __get__
Precedence Overrides instance attributes Can be overridden by instance attributes
Use Cases Validation, managed attributes, logging, enforcement Method binding, caching, default values

Data descriptors take precedence over instance attributes during attribute lookup, while non-data descriptors do not.

Descriptors form the foundation for Python features such as properties, methods, static methods, and class methods. They enable advanced capabilities like lazy evaluation, data validation, attribute management, and more, making them essential for fine-grained control over attribute behavior in object-oriented programming.

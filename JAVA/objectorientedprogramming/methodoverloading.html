Java Programming: Polymorphism Concepts

Session: Method Overloading (Compile-Time Polymorphism)

What is Method Overloading?

**Method Overloading** is a feature in Java where a single class has two or more **methods** with the **same name** but **different parameters**. When the method is called, the compiler resolves which specific method body to use based on the arguments passed.

This mechanism is key to achieving **compile-time polymorphism** (or static binding), as the method call is determined at compile time.

Advantage and Rules

The main advantage of method overloading is that it greatly **improves code readability** and **reduces code redundancy**. Developers can use one logical name (like `add`) for operations that perform the same function on different data inputs.

Method overloading is achieved by changing the method's **parameter list** in one of two ways:

  • **Different number of arguments.**
  • **Different type of arguments.**

What Cannot Be Overloaded

A method **cannot** be successfully overloaded just by changing the return type or the access modifier. If two methods have the same name and the exact same parameter list, the compiler will report a duplicate method error, regardless of the return type or whether one is static and the other is not.

Example: Overloading by Number of Arguments

The add method is overloaded to handle different quantities of input values:

class Calculator {
   // 1. Two arguments
   public static int add(int a, int b){
      return a + b;
   }
   // 2. Three arguments
   public static int add(int a, int b, int c){
      return a + b + c;
   }
}

public class Tester {
   public static void main(String args[]){
      System.out.println(Calculator.add(20, 40));     // Calls (1), Output: 60
      System.out.println(Calculator.add(40, 50, 60)); // Calls (2), Output: 150
   }
}

Example: Overloading by Type of Arguments

The add method is overloaded to handle different data types (integers and doubles):

class Calculator {
   // 1. Accepts two integers
   public int add(int a, int b){
      return a + b;
   }
   // 2. Accepts two doubles
   public double add(double a, double b){
      return a + b;
   }
}

public class Tester {
   public static void main(String args[]){
      Calculator calculator = new Calculator();   
      System.out.println(calculator.add(20, 40));   // Calls (1), Output: 60
      System.out.println(calculator.add(20.0, 40.0)); // Calls (2), Output: 60.0
   }
}

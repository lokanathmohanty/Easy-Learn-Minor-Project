R - Poisson Regression

Poisson regression models count data, where the response variable represents the number of times an event occurs within a fixed interval. It assumes the response variable follows a Poisson distribution. The model relates predictors to the logarithm of the expected counts:

Model: \( \log(y) = a + b_1 x_1 + b_2 x_2 + \cdots + b_n x_n \)

Parameters:

  • \( y \): Response count variable
  • \( a, b_i \): Numeric coefficients
  • \( x_i \): Predictor variables

The glm() function with family set to poisson performs Poisson regression in R.

Syntax

glm(formula, data, family = poisson)

Example

Analyze the warpbreaks dataset describing counts of loom breaks affected by wool type and tension level.

# Load data
input <- warpbreaks
print(head(input))

# Create Poisson regression model
output <- glm(formula = breaks ~ wool + tension, data = warpbreaks, family = poisson)
print(summary(output))

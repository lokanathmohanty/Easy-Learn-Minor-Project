PHP - SAX Parser (Event-Based XML) Example

SAX Parser: Event-Based XML Processing

The **SAX (Simple API for XML)** parser in PHP is an **event-based** parsing mechanism. Unlike tree-based parsers ($\text{SimpleXML}$, $\text{DOM}$), SAX does **not load the entire XML document** into memory. Instead, it processes the document sequentially, triggering custom handler functions whenever it encounters specific "events" (like a start tag, end tag, or text data). This makes it significantly **faster and more memory-efficient** for handling large XML documents.

Core SAX Functions

  • $\text{xml\_parser\_create()}$: Creates a new $\text{XMLParser}$ resource object.
  • $\text{xml\_set\_element\_handler()}$: Associates custom functions (callbacks) to handle **start tags** and **end tags**.
  • $\text{xml\_set\_character\_data\_handler()}$: Associates a custom function to handle the **text content** found between tags.
  • $\text{xml\_parse()}$: Starts the parsing process, reading the XML data chunk by chunk and calling the configured handler functions as events are encountered.
  • $\text{xml\_parser\_free()}$: Frees the memory allocated for the $\text{XMLParser}$ resource.

Example: SAX Parsing XML Data

The XML Data ($\text{sax.xml}$)

The XML document contains a list of $\text{}$ elements, each with structured child elements like $\text{}$, $\text{}$, etc.

<tutors>
   <course>
      <name>Android</name>
      ...
   </course>
   ...
</tutors>

PHP Handler Functions and Logic

The logic relies on global variables ($\text{\$tutors}$ to store the final data, $\text{\$elements}$ to track the currently open tag) and three custom handlers:

<?php
   $tutors   = array();
   $elements   = null;

   // 1. Called when a new tag is opened
   function startElements($parser, $name, $attrs) {
      global $tutors, $elements;
      if ($name == 'COURSE') {
         // Start a new array entry for a new course
         $tutors []= array(); 
      }
      $elements = $name; // Store the current tag name
   }

   // 2. Called on the text between the start and end of the tags
   function characterData($parser, $data) {
      global $tutors, $elements;
      // Only process data if it belongs to one of the target elements
      if(!empty($data) && $elements) {
         if (in_array($elements, ['NAME', 'COUNTRY', 'EMAIL', 'PHONE'])) {
            // Assign the data to the latest course array entry, using the element name as the key
            $tutors[count($tutors)-1][$elements] = trim($data);
         }
      }
   }

   // 3. Called when a tag is closed (resets the current element tracker)
   function endElements($parser, $name) {
      global $elements;
      if(!empty($name)) {
         $elements = null;
      }
   }
   
   // --- Main Execution ---
   $parser = xml_parser_create();
   xml_set_element_handler($parser, "startElements", "endElements");
   xml_set_character_data_handler($parser, "characterData");

   // Open and read the XML file chunk by chunk
   if ($handle = fopen('sax.xml', "r")) {
      while($data = fread($handle, 4096)) {
         xml_parse($parser, $data);  // Call handlers for each event in the chunk
      }
      fclose($handle);
   }

   xml_parser_free($parser); 
   // Display the processed data stored in the $tutors array...
?>

This approach successfully parses the XML by reacting to events, building the $\text{\$tutors}$ array incrementally without holding the entire document's $\text{DOM}$ tree in memory.

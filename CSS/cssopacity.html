CSS - Opacity Property

The CSS opacity property controls the transparency of an element. It determines how much of an element is visible or hidden. This property can be applied to text, images, or background elements. The lower the opacity value, the more transparent the element becomes.

Syntax

The general syntax of the opacity property is:

opacity: number | percentage | initial | inherit;

Property Values

  • number – A numeric value between 0 (fully transparent) and 1 (fully visible).
  • percentage – A percentage value between 0% and 100%.
  • initial – Resets the property to its default value.
  • inherit – Inherits the property value from the parent element.

Example: Numeric Values

In this example, different numeric values are applied to div elements using the opacity property. 

div {
   height: 50px;
   padding: 20px;
   text-align: center;
   font-weight: bold;
   font-size: 20px;
   background-color: lightgreen;
}

.first { opacity: 0.3; }
.second { opacity: 0.6; }
.third { opacity: 1; }

Explanation: The first div is partially transparent, the second is more visible, and the third is fully visible.

Example: Percentage Values

Opacity can also be defined using percentage values. 

.first { opacity: 30%; }
.second { opacity: 60%; }
.third { opacity: 100%; }

Explanation: Similar to numeric values, but expressed in percentages for readability.

Example: Opacity with Images

The opacity property can also be used on images to create transparency effects such as overlays. 

img.first-img { opacity: 0.1; }
img.second-img { opacity: 50%; }
img.third-img { opacity: 1; }

Explanation: The first image is almost invisible, the second is semi-transparent, and the third is fully visible.

Example: Using RGBA for Transparency

One limitation of opacity is that it affects both the element and its children. If you only want the background to be transparent, you can use rgba() colors instead. 

.decimal-opacity1 { opacity: 0.1; }
.decimal-opacity2 { opacity: 0.3; }
.decimal-opacity3 { opacity: 0.6; }
.decimal-opacity4 { opacity: 0.9; }

.rgba-opacity1 { background-color: rgba(77, 77, 255, 0.1); }
.rgba-opacity2 { background-color: rgba(77, 77, 255, 0.3); }
.rgba-opacity3 { background-color: rgba(77, 77, 255, 0.6); }
.rgba-opacity4 { background-color: rgba(77, 77, 255, 0.9); }

Explanation: Opacity applies transparency to the entire element including its content, but rgba() allows background-only transparency, leaving the text unaffected.

Supported Browsers

  • Chrome: Supported from version 4.0
  • Edge: Supported from version 9.0
  • Firefox: Supported from version 2.0
  • Safari: Supported from version 3.1
  • Opera: Supported from version 9.0

Key Notes

  • Use opacity for general transparency of an element and its children.
  • Use rgba() when you want only the background color to be transparent, not the text.
  • Values range from 0 (fully invisible) to 1 (fully visible).
  • Opacity can enhance UI design by creating overlays, faded effects, or hover transitions.

Python Socket Programming

Socket programming allows communication between two nodes in a network, where one acts as a server listening for incoming requests and the other as a client sending requests.

Python's socket module provides access to BSD sockets, enabling communication over TCP (connection-oriented) and UDP (connection-less) protocols.

Socket Creation:

socket.socket(family=AF_INET, type=SOCK_STREAM, protocol=0)

Where, AF_INET is the IP address family for IPv4, SOCK_STREAM is for TCP.

Servers use bind(), listen(), and accept() to handle connections. Clients use connect() to connect to the server.

Server Example

import socket

host = "127.0.0.1"
port = 5000
server = socket.socket()
server.bind((host, port))
server.listen()

print("Server listening...")

conn, addr = server.accept()
print(f"Connection from {addr}")

while True:
    data = conn.recv(1024).decode()
    if not data:
        break
    print("From client:", data)
    data = data.upper()
    conn.send(data.encode())

conn.close()
server.close()

Client Example

import socket

host = "127.0.0.1"
port = 5000

client = socket.socket()
client.connect((host, port))

while True:
    msg = input("Enter message (q to quit): ")
    if msg.lower() == 'q':
        break
    client.send(msg.encode())
    data = client.recv(1024).decode()
    print("Received from server:", data)

client.close()

File Transfer Example

Server sends a file, and client receives it and writes to a local file.

# Server side
import socket

server = socket.socket()
server.bind(("127.0.0.1", 5001))
server.listen()
conn, addr = server.accept()
print("Connected by", addr)

with open('test.txt', 'rb') as f:
    while True:
        bytes_read = f.read(1024)
        if not bytes_read:
            break
        conn.sendall(bytes_read)

conn.close()
server.close()
      
# Client side
import socket

client = socket.socket()
client.connect(("127.0.0.1", 5001))

with open('received.txt', 'wb') as f:
    while True:
        bytes_read = client.recv(1024)
        if not bytes_read:
            break
        f.write(bytes_read)

client.close()
print("File received successfully.")

Python Socketserver Module

The socketserver module provides a framework for writing network servers. It supports TCP and UDP servers and offers request handler classes to process incoming client requests.

import socketserver

class MyTCPHandler(socketserver.BaseRequestHandler):
    def handle(self):
        data = self.request.recv(1024).strip()
        print(f"Received from {self.client_address}: {data.decode()}")
        response = input("Send response: ")
        self.request.sendall(response.encode())

if __name__ == "__main__":
    HOST, PORT = "localhost", 9999
    with socketserver.TCPServer((HOST, PORT), MyTCPHandler) as server:
        print("Server started")
        server.serve_forever()

Clients connect normally using sockets and communicate with the server.

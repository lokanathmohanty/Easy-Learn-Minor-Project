CSS clip Property

The clip property in CSS is used to define a clipping region for an element, which controls which portion of the element is visible. Anything outside the clipping region will be hidden. This property only applies to elements with position: absolute or position: fixed.

Syntax

clip: auto | rect(top, right, bottom, left) | initial | inherit;

Property Values

  • auto – No clipping is applied (default value).
  • rect(top, right, bottom, left) – Defines a rectangular clipping region.
  • initial – Sets the property to its default value.
  • inherit – Inherits the property value from the parent element.

Example: clip with auto Value

Using clip: auto; ensures no clipping is applied, so the element remains fully visible. 

.sample {
  width: 200px;
  background-color: lightblue;
  padding: 10px;
}

.clip-rect {
  position: absolute;
  width: 200px;
  background-color: lightblue;
  padding: 10px;
  clip: auto;
}
        
<div class="sample">
  This is an example of full visible content without clipping.
</div>

<div class="clip-rect">
  This content also remains fully visible since clip is set to auto.
</div>

Example: clip with rect() Value

The rect() function defines a rectangular area by specifying top, right, bottom, and left offsets. 

.sample {
  width: 200px;
  background-color: lightgreen;
  padding: 10px;
}

.clip-rect {
  position: absolute;
  width: 200px;
  background-color: lightgreen;
  padding: 10px;
  clip: rect(0px, 170px, 140px, 0px);
}
        
<div class="sample">
  This is the original content displayed without clipping.
</div>

<div class="clip-rect">
  This content is clipped using rect(0px, 170px, 140px, 0px).
</div>

Example: clip Property with Images

The clip property can also be applied to absolutely positioned images. 

img {
  width: 300px;
  height: 200px;
}

.clip-auto {
  position: absolute;
  clip: auto;
}

.clip-rect {
  position: absolute;
  clip: rect(0px, 140px, 170px, 0px);
}
        
<img src="flower.jpg" alt="original image">

<img src="flower.jpg" class="clip-auto" alt="auto clipped image">

<img src="flower.jpg" class="clip-rect" alt="rect clipped image">

Important Notes

  • The clip property is deprecated and replaced by clip-path.
  • It will not work if overflow: visible is applied to the element.

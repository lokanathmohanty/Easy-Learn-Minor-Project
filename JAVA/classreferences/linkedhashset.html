Java LinkedHashSet Class Summary 🔗🧩

The **java.util.LinkedHashSet** class is an implementation of the **Set** interface that combines the fast performance of a **hash table** (like HashSet) with the element ordering of a **doubly-linked list**. It is essentially a subclass of HashSet that guarantees a **predictable iteration order**.

I. Core Feature: Insertion Order Preservation

The defining characteristic of LinkedHashSet is its ability to maintain the order in which elements were inserted into the set (Insertion Order).

  • **Predictable Iteration:** When you iterate over the set (using an Iterator, `forEach`, or `Spliterator`), elements are returned in the **exact order they were added**.
  • **Uniqueness:** Like all `Set` implementations, it enforces element uniqueness based on object equality (`equals()` and `hashCode()`). If an element is added twice, the second operation returns `false`, and the element's position in the insertion order remains unchanged.

II. Performance and Internal Structure

LinkedHashSet achieves its dual functionality by being backed by a **LinkedHashMap** internally, similar to how HashSet is backed by a HashMap:

  • **Speed:** Fundamental operations like **add()**, **remove()**, and **contains()** remain **constant time ($O(1)$)**, just like in HashSet, because the core structure is still a hash table.
  • **Iteration:** Iteration is generally slightly **more efficient** than HashSet because it only follows the linked list of entries, avoiding the traversal of potentially empty hash table buckets.
  • **Overhead:** The cost of maintaining the insertion order is a **slightly higher memory overhead** compared to a regular HashSet, due to the maintenance of the doubly-linked list pointers.
  • **Nulls and Synchronization:** It **permits a single `null` element** and is **not synchronized** (not thread-safe).

III. Example of Insertion Order

The example demonstrates that the output order perfectly matches the insertion order:

// Insertion Order: 1, 2, 3
newset.add(1); 
newset.add(2);
newset.add(3);  

// Output (Spliterator Iteration Order):
1
2
3

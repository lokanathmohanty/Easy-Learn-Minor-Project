Add Set Items

Items can be added using methods like add(), update(), set union (|), or set comprehension.

Add Set Items Using add() Method

The add() method adds a single element to the set if it is not already present.

Example: Using add() Method

language = set()
language.add("C")
language.add("C++")
language.add("Java")
language.add("Python")

print("Updated Set:", language)

Output example: {'Python', 'Java', 'C++', 'C'}

Add Set Items Using update() Method

The update() method adds multiple elements from an iterable (list, tuple, set, string) to the set.

Example: Using update() Method

my_set = {1, 2, 3}
my_set.update([4])
print("Updated Set:", my_set)

lang1 = {"C", "C++", "Java", "Python"}
lang2 = {"PHP", "C#", "Perl"}
lang1.update(lang2)
print(lang1)

set1 = set("Hello")
set1.update("World")
print(set1)

Output examples:
{1, 2, 3, 4}
{'Python', 'C++', 'C#', 'C', 'Java', 'PHP', 'Perl'}
{'H', 'r', 'o', 'd', 'W', 'l', 'e'}

Add Set Items Using Union Operator (|)

Use the union operator | or the union() method to combine sets, resulting in a new set with all unique elements.

Example: Using Union

lang1 = {"C", "C++", "Java", "Python"}
lang2 = {"PHP", "C#", "Perl"}
lang3 = {"SQL", "C#"}

combined_set1 = lang1.union(lang2)
combined_set2 = lang2 | lang3

print("Combined Set1:", combined_set1)
print("Combined Set2:", combined_set2)

Example Output:
{'C#', 'Perl', 'C++', 'Java', 'PHP', 'Python', 'C'}
{'C#', 'Perl', 'PHP', 'SQL'}

Add Set Items Using Set Comprehension

Set comprehensions create a new set by applying an expression to each item in an iterable.

Example: Using Set Comprehension

numbers = [1, 2, 3, 4, 5]
squares_set = {num ** 2 for num in numbers}
print("Squares Set:", squares_set)

Output example: {1, 4, 9, 16, 25}

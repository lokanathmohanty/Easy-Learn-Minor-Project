Pointer Arithmetic in C

A pointer variable in C stores the address of another variable. The address is always an integer. Pointer arithmetic allows incrementing, decrementing, adding or subtracting integers, subtracting pointers, and comparing pointers. These operations are different from general integer arithmetic because the pointer arithmetic takes into account the size of the data type the pointer points to.

Increment and Decrement of a Pointer

The increment (++) and decrement (--) operators move the pointer to the next or previous element in memory, respectively, taking into account the size of the data type.

Addition and Subtraction of Integer to Pointer

You can add or subtract an integer to/from a pointer, which moves the pointer by that integer times the size of the data type.

Subtraction of Pointers

Subtracting two pointers returns the number of elements between them (assuming they point to the same array).

Comparison of Pointers

Pointers can be compared using relational operators if they point to elements within the same array or memory block.

Example: Traversing an Array with Pointer Arithmetic

The following example demonstrates how you can traverse an integer array by incrementing a pointer:


#include <stdio.h>

int main() {
  int a[] = {10, 20, 30, 40, 50};
  int *ptr = a;
  int length = sizeof(a) / sizeof(int);

  for (int i = 0; i < length; i++) {
    printf("Address of a[%d] = %p, Value = %d\n", i, (void*)ptr, *ptr);
    ptr++;
  }

  return 0;
}

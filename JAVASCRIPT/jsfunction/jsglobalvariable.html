JavaScript - Global Variables

Global variables in JavaScript are variables that are defined outside of any function or block. They are accessible from anywhere in the code. All scripts and functions can access global variables.

You can define global variables using the var, let, or const keywords. If you declare a variable without using any of these keywords, it automatically becomes a global variable.

JavaScript Global Scope

The global variables have global scope. A variable declared outside a function or block has global scope and is accessible in all other scopes.

In client-side JavaScript, the global scope is the web page where the code runs. A global variable declared with var belongs to the window object.

var x = 10; // Global Scope
let y = 20; // Global Scope
const z = 30; // Global Scope

Here, the variables x, y, and z are declared outside any function or block, so they have global scope.

Global Variable Examples

Example 1

<script>
var x = 10;
let y = 20;
const z = 30;
document.getElementById("output").innerHTML =
   "x = " + x + "<br>" +
   "y = " + y + "<br>" +
   "z = " + z;
</script>

Output:

  • x = 10
  • y = 20
  • z = 30

Example 2

<script>
var a = 10;
let b = 20;
function test() {
   document.getElementById("demo").innerHTML += 
      "a -> Inside function = " + a + "<br>" +
      "b -> Inside function = " + b + "<br>";
}
test();
document.getElementById("demo").innerHTML += 
   "a -> Outside function = " + a + "<br>" +
   "b -> Outside function = " + b + "<br>";
</script>

Output:

  • a → Inside function = 10
  • b → Inside function = 20
  • a → Outside function = 10
  • b → Outside function = 20

Automatic Global Variables

If you define a variable without var, let, or const, it automatically becomes global—even if defined inside a function.

Example

<script>
function test() {
   a = 90; // no keyword used, becomes global
   document.getElementById("demo").innerHTML += 
      "a -> Inside function = " + a + "<br>";
}
test();
document.getElementById("demo").innerHTML += 
   "a -> Outside function = " + a + "<br>";
</script>

Output:

  • a → Inside function = 90
  • a → Outside function = 90

Note: Defining global variables inside functions or blocks is not good practice, as it may cause naming conflicts.

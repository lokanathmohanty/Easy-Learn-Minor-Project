C++ Structures (struct) 🧱

A C++ **structure** (or **struct**) is a **user-defined data type** that allows you to group related variables of **different data types** under a single name. Structures are commonly used to represent a record or a composite entity.

Defining a Structure

You use the `struct` keyword to define a new data type with multiple members (variables) inside it.

struct [structure tag] {
   member definition; // e.g., int id;
   member definition; // e.g., char name[50];
   ...
} [optional variables];

The **structure tag** (like `Books` in the example below) is the name of the new data type.

struct Books {
   char  title[50];
   char  author[50];
   char  subject[100];
   int   book_id;
}; // Semicolon is mandatory!

Accessing Structure Members

To access the individual variables (members) within a structure, you use the **member access operator** (a period: **.**).

struct Books Book1; // Declare a variable of type Books

// Accessing and setting members
strcpy(Book1.title, "Learn C++");
Book1.book_id = 6495407; 

// Accessing and printing members
cout << "Book title: " << Book1.title << endl;

Structures with Functions and Pointers

Structures as Function Arguments

Structures can be passed to functions just like any other variable. By default, they are passed **by value** (a copy is created), which can be inefficient for large structures.

// Function declaration: passes the structure by value (creates a copy)
void printBook(struct Books book);

// Call:
printBook(Book1);

Pointers to Structures

To avoid copying large structures, or to allow the function to modify the original structure, you pass the structure's **address** (a pointer).

// Declaration of a pointer to a Books structure
struct Books *struct_pointer;

// Storing the address of Book1
struct_pointer = &Book1;

To access members using a structure pointer, you must use the **structure dereference operator** (**->**), which is shorthand for `(*struct_pointer).member`.

// Accessing members using the pointer operator ->
void printBook(struct Books *book_ptr) {
   cout << "Title: " << book_ptr->title << endl;
}

// Call:
printBook(&Book1); // Pass the address

The typedef Keyword

The **typedef** keyword provides a convenient way to create an **alias** (a new name) for an existing data type. When used with structures, it allows you to define structure variables without repeatedly using the `struct` keyword.

typedef struct {
   char  title[50];
   int   book_id;
} Books; // 'Books' is now an alias for the structure type

int main() {
   // No need to use 'struct Books'
   Books Book1, Book2; 
   // ...
}

PHP `while` Loop

The **`while`** loop is the simplest **entry-controlled** looping construct in PHP. It repeatedly executes a block of code as long as a specified **Boolean expression** remains `true`. The condition is checked **before** the execution of the loop body in every iteration.

`while` Loop Syntax and Flow

The loop consists of the `while` keyword, a condition, and the statements to be executed.

while (expr) { statements }
  • **Entry-Controlled:** If the expression evaluates to `false` initially, the loop body is **never executed**.
  • **Termination:** It is crucial that the loop body contains code that eventually makes the `expr` false, or the loop will become infinite.

Simple `while` Loop Examples

Incrementing Loop

A variable `$x` is initialized to 1. The loop continues as long as `$x` is less than or equal to 10. The value of `$x` is incremented inside the loop to ensure termination.

$x = 1;
while ($x<=10) { echo "Iteration No. $x \n"; $x++; }

Output (Partial): Iteration No. 1 ... Iteration No. 10

Decrementing Loop

The loop variable is initialized to a large value and decremented until the condition is no longer true.

$x = 5;
while ($x>0) { echo "Iteration No. $x \n"; $x--; }

Output: Iteration No. 5 \n ... \n Iteration No. 1

Practical Applications

Iterating Indexed Arrays

The `while` loop can traverse an indexed array by using a counter variable (`$x`) to access elements by index until the counter reaches the array's size (`count($numbers)`).

$numbers = array(10, 20, 30);
$size = count($numbers); $x=0;
while ($x<$size) { echo "Number at index $x is $numbers[$x] \n"; $x++; }

Output: Number at index 0 is 10 ...

Nested `while` Loops

Using one `while` loop inside another allows for processing two-dimensional data or executing repetitive tasks for each outer loop iteration. The inner loop's counter must be **re-initialized** for each new iteration of the outer loop.

$i=1; $j=1;
while ($i<=3){ while ($j<=3){ /* ... */ $j++; } $j=1; $i++; }

Alternative Syntax (`while: endwhile;`)

PHP provides an alternative syntax for the `while` loop, typically used when intermixing PHP with large HTML blocks. It uses a **colon (`:`)** to open the body and the **`endwhile;`** keyword to close it.

while ($x<=10): echo "Iteration No. $x \n"; $x++; endwhile;

Power Query Editor - Merge Queries (Part 1)

Right Outer Join

When two tables need to be merged based on a common column, a right outer join extracts all records from the second table, along with matching records from the first table. This is opposite to the left outer join.

Example Scenario

Suppose two tables exist: Employee (with columns Employee ID, Name, Designation, Salary, Age) and Department (with Employee ID and Department). A right outer join combines these tables showing all department entries and matching employee details.

Steps to Perform Right Outer Join in Power BI Desktop

  1. Open Power BI Desktop, click the Home tab, select Get Data, and load the Employee and Department Excel workbooks separately.
  2. Select the relevant sheet and load each table into Power BI.
  3. Click Home > Transform Data to open Power Query Editor.
  4. Choose Combine > Merge Queries > Merge Queries.
  5. In the Merge dialog, select the common column Employee ID in both tables.
  6. Under Join Kind, select "Right Outer (all from second, matching from first)".
  7. Click OK to execute the join and view the combined table.

Left Anti Join and Right Anti Join

The left anti join retrieves unmatched records from the first table, and the right anti join retrieves unmatched records from the second table.

Example to Retrieve Unmatched Records

  1. Load the two tables into Power BI Desktop as before.
  2. Open Power Query Editor.
  3. Choose Merge Queries; select Employee ID columns from both tables.
  4. Select "Left Anti (rows only in first)" to get unmatched records from the first table, or "Right Anti (rows only in second)" to get unmatched records from the second table.
  5. Click OK to see results with unmatched rows displayed (null for missing department if applicable).

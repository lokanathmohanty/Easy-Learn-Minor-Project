Java - Streams (Java 8+)

The Need for Streams and Declarative Programming 💡

The **Stream API**, introduced in **Java 8**, is a new abstract layer that allows developers to process sequences of objects in a **declarative way**. Before streams, aggregate operations on collections required verbose, error-prone code using loops and explicit checks.

Streams solve two major problems:

  • Verbosity: Replaces boilerplate loop-based code (the "how") with high-level descriptions of the desired outcome (the "what"), similar to SQL.
  • Parallelism: Enables easy and efficient **parallel processing** of data, automatically leveraging multi-core architectures without complex, manual thread management.

What is a Stream?

A stream represents a **sequence of elements from a source** (like a Collection or Array) that supports **aggregate operations** but **never stores the elements** itself. Elements are computed or retrieved on demand.

Stream Characteristics and Operations

The Stream Pipeline

Stream operations are executed in a pipeline structure:

  1. Source: The origin of the elements (e.g., List.stream()).
  2. Intermediate Operations: Operations that process the input and return another stream itself, allowing for **pipelining**. They are lazily executed (only when a terminal operation is called). Examples: filter(), map(), sorted(), limit().
  3. Terminal Operation: The final operation that consumes the stream and produces a result (or a side effect). After a terminal operation, the stream cannot be reused. Examples: collect(), forEach(), count(), reduce().

Generating Streams

  • Sequential Stream: collection.stream()
  • Parallel Stream: collection.parallelStream() (leveraging multiple CPU cores)
  • Random Data Stream: new Random().ints().limit(10)

Key Intermediate Stream Methods

  • filter(Predicate): Selects elements based on a condition, eliminating elements that don't match. 
    strings.stream().filter(s -> s.isEmpty()).count();
  • map(Function): Transforms each element into a new element or value of a potentially different type. 
    numbers.stream().map(i -> i * i); // Converts Integer to its square
  • distinct(): Returns a stream with unique elements, based on the object's equals() and hashCode() methods.
  • limit(long maxSize): Truncates the stream, ensuring the result contains no more than the specified number of elements.
  • sorted(): Returns a stream sorted according to natural order (or a custom Comparator).

Key Terminal Stream Methods

  • forEach(Consumer): Performs an action for each element. This is a terminal operation used for side effects (like printing).
  • collect(Collector): Performs a mutable reduction operation, accumulating the stream elements into a container like a List, Set, or Map. The Collectors class provides many predefined methods:
    • Collectors.toList(): Accumulates elements into a List.
    • Collectors.joining(delimiter): Concatenates elements into a single String.
  • summaryStatistics(): Used with mapToInt(), mapToLong(), or mapToDouble() to efficiently compute basic statistics (min, max, sum, average, count) in a single pass. 
    IntSummaryStatistics stats = numbers.stream().mapToInt(x -> x).summaryStatistics();

Introduction to ES6

Overview

ES6, or ECMAScript 2015, is the 6th version of the ECMAScript programming language. It is the standardization of JavaScript, released in 2015, and brought many improvements such as new syntax, keywords, and advanced features for better development practices.

New Features in ES6

1. The let Keyword

The let variables are mutable and block-scoped. It prevents variable leakage outside of the intended scope. 

let n = 10;
{
    let n = 2; // Block-scoped variable
    console.log(n);
}
console.log(n);

Output:

  • 2
  • 10

2. The const Keyword

const is used to declare variables with a constant value. Once assigned, it cannot be reassigned. 

const PI = 3.14159;
PI = 3; // Error: Assignment to constant variable

3. Arrow Functions

Arrow functions provide a shorter syntax for writing functions and automatically bind this to the surrounding context. 

// Traditional function
function add(a, b) { return a + b; }

// Arrow function
const add = (a, b) => a + b;

4. Destructuring Assignment

Destructuring allows breaking complex structures like objects or arrays into simpler parts.

Object Destructuring

const obj = { name: "Raj", age: 25 };
const { name, age } = obj;
console.log(name, age);

Output: Raj 25

Array Destructuring

const a = ["red", "blue", "green"];
const [first, second] = a;
console.log(first, second);

Output: red blue

5. The Spread (...) Operator

Expands arrays or objects into individual elements or properties. 

const n1 = [1, 2, 3];
const n2 = [...n1, 4, 5];
console.log(n2);

Output: [1, 2, 3, 4, 5]

6. The for/of Loop

Iterates over arrays, strings, Maps, and Sets.

const a = ["apple", "banana", "cherry"];
for (const fruit of a) {
    console.log(fruit);
}

Output: apple, banana, cherry

7. Maps and Sets

Map: Stores key-value pairs.

const map = new Map();
map.set("a", 1);
map.set("b", 2);
console.log(map.get("a"));

Output: 1

Set: Stores unique values.

const set = new Set([1, 2, 3, 3]);
console.log(set);

Output: Set(3) {1, 2, 3}

8. Classes

class Animal {
    speak() { console.log("The animal makes a sound"); }
}

const dog = new Animal();
dog.speak();

Output: The animal makes a sound

9. Promises

Simplifies asynchronous handling with .then and .catch.

const fetch = () => {
    return new Promise((resolve) => {
        setTimeout(() => resolve("Data fetched"), 2000);
    });
};

fetch().then(data => console.log(data));

10. Default Parameters

Functions can have default values for parameters.

function greet(name = "Guest") {
    return `Hello, ${name}!`;
}
console.log(greet());

Output: Hello, Guest!

Additional Enhancements

  • includes(), startsWith(), endsWith()
  • find(), findIndex(), from()
  • Template Literals
  • Modules (import, export)
  • Rest Parameters (...args)
  • Generators and Iterators
  • Binary (0b) and Octal (0o) Literals
  • Enhanced Object Literals
  • WeakMap and WeakSet
  • Proxy and Reflect
  • Symbol primitive type
  • Block-scoped Functions

Browser Support

ES6 is fully supported in all modern browsers since June 2017:

  • Chrome 51 (May 2016)
  • Edge 15 (Apr 2017)
  • Firefox 54 (Jun 2017)
  • Safari 10 (Sep 2016)
  • Opera 38 (Jun 2016)

Note: ES6 is not supported in Internet Explorer.

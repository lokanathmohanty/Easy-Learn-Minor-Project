ReactJS - Render Props

Since react components are interconnected by composition (having one component inside another) rather than by inheritance, logic used in a react component will not be shared to another component directly. React provides multiple options to share the logic between components and one such option is Render Props. Render props is basically passing a function with necessary rendering logic to a component having core functionality through its props. Hence, it is termed as render props.

How to use render props

Let us see how to use render props and share logic between two components in a step-by-step manner. Consider the scenario of fetching and rendering the data from an external URL.

  • Create a component, FetcherComponent with data fetching logic for the given props.url.
  • Update FetcherComponent so that the core rendering logic will be delegated to this.props.render.
  • Create a FetcherConsumerComponent that consumes FetcherComponent and provides the rendering logic.

Example Code

FetcherComponent with data fetching logic

componentDidMount() {
   fetch(this.props.url)
   .then((response) => response.json())
   .then((data) => {
      this.setState({
         data: data
      });
   });
}

Updated FetcherComponent with render props

render() {
   return (
      <div>
         <h2>Fetch react component</h2>
         {this.state.data && this.props.render(this.state.data)}
      </div>
   )
}

Here, this.props.render is the function with rendering logic and is passed into FetcherComponent through props.

FetcherConsumerComponent Example

render() {
   return (
      <FetcherComponent url="users.json" render={(items) => (
         <ul>
            {items && items.length && items.map((item) =>
               <li key={item.id}>{item.name}</li>
            )}
         </ul>
      )} />
   )
}

Applying render props

First of all, create a new react application:

create-react-app myapp
cd myapp
npm start

Create a component FetchRenderProps with data fetching logic.

FetchRenderProps.js

import React from "react";
class FetchRenderProps extends React.Component {
   constructor(props) {
      super(props);
      this.state = { data: [] }
   }
   componentDidMount() {
      fetch(this.props.url)
      .then((response) => response.json())
      .then((data) => {
         this.setState({ data: data });
      });
   }
   render() {
      return (
         <div>
            <h2>Fetch react component</h2>
            {this.state.data && this.props.render(this.state.data)}
         </div>
      )
   }
}
export default FetchRenderProps;

SimpleRenderProps.js

import React from "react";
import FetchRenderProps from "./FetchRenderProps";
class SimpleRenderProps extends React.Component {
   render() {
      return (
         <>
            <FetchRenderProps url="users.json" render={(items) => (
               <ul>
                  {items && items.length && items.map((item) =>
                     <li key={item.id}>{item.name}</li>
                  )}
               </ul>
            )} />

            <FetchRenderProps url="todo_list.json" render={(items) => (
               <ul>
                  {items && items.length && items.map((item) =>
                     <li key={item.id}>
                        {item.title} {item.is_done && <strong>Done</strong>}
                     </li>
                  )}
               </ul>
            )} />
         </>
      )
   }
}
export default SimpleRenderProps;

App.js

import './App.css'
import React from 'react';
import SimpleRenderProps from './Components/SimpleRenderProps'
function App() {
   return (
      <div className="container">
         <div style={{ padding: "10px" }}>
            <SimpleRenderProps />
         </div>
      </div>
   );
}
export default App;

Summary

Render props is an efficient method to share logic between components. It is extensively used in many third-party components with good success rate and is a time-tested method to share logic in the React domain.

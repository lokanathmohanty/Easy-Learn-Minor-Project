Power BI: Ribbon Chart

A Ribbon Chart visualizes the relationship between categorical and numeric fields using colorful ribbons stacked over each other. The width of each ribbon represents the relative size of a category's value along the X-axis, such as sales production by country and year.

How to Create a Ribbon Chart

  • Load the data workbook into Power BI Desktop.
  • In Report View, select the Ribbon Chart visual from the Visualizations pane.
  • Add the Country field to the X-axis.
  • Add sales production fields like Sales Production in 1990, Sales Production in 1991, and Sales Production in 1992 to the Y-axis.
  • Use Small Multiples by adding the Country field to see separate visuals for each country’s sales production by year.
  • Enhance Tooltips by adding additional fields (e.g., Sales Production in 1993) to show detailed data on hover.

Formatting the Ribbon Chart

  • General: Adjust report page size (height and width) in Properties.
  • Title: Enable and customize with text (e.g., "Ribbon Chart"), font style (Comic Sans MS), size (29), and color.
  • Subtitle: Enable, choose heading type and style (Italic), and set color (e.g., blue).
  • Divider: Enable to add delimiter below title; customize color and style (solid).
  • Spacing: Add space below title (e.g., 10px).
  • Effects: Customize background color, visual borders, and shadows.
  • Header Icons: Enable and set colors for background, border, and icons.
  • Tooltips: Customize font style (Georgia), size (9), label color (#a8337d), and value color (#D9B300).
  • X-axis: Format font (Times New Roman), size (11), and color (blue). Optionally toggle axis title.
  • Y-axis: Format font (Tahoma), size (12), and color.
  • Legend: Position at top right stacked, customize font and style.
  • Gridlines: Enable horizontal gridlines, select dashed style, blue color, and set width (4px).
  • Ribbon: Adjust ribbon colors, transparency, and border.
  • Data Labels: Enable to display data values on each ribbon segment.

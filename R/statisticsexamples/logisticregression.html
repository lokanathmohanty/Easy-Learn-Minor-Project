R - Logistic Regression

Logistic regression models the probability of a binary response (e.g., True/False, 0/1) based on predictor variables using a logistic function: \[ y = \frac{1}{1 + e^{-(a + b_1 x_1 + b_2 x_2 + b_3 x_3 + \dots)}} \] where \(y\) is the response variable, \(x_i\) are predictors, and \(a, b_i\) are coefficients.

glm() Function Syntax

glm(formula, data, family)
  • formula: Relationship between response and predictors (e.g., am ~ cyl + hp + wt)
  • data: Data frame containing variables
  • family: Model family; use binomial for logistic regression

Example: Data Preparation

# Select relevant columns from mtcars
input <- mtcars[, c("am", "cyl", "hp", "wt")]
print(head(input))

Create Logistic Regression Model

print(summary(am.data))

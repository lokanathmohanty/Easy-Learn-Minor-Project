PHP Decision Making (Conditional Statements)

**Decision making** in programming allows the sequential flow of execution to be altered based on specific conditions. PHP supports several conditional statements to implement this logic.

Decision Making Statements in PHP

PHP offers three main constructs for decision control:

1. `if...else` Statement

This is the most fundamental conditional structure. A **Boolean expression** is evaluated; if it is **`true`**, the code block immediately following the `if` is executed. If it is **`false`**, the code block following the optional `else` is executed.

if (expr) { statement1 } else { statement2 }

Any expression involving comparison operators (`<`, `>`, `==`, etc.) or logical operators (`&&`, `||`, `!`) is a Boolean expression.

2. `elseif` Statement

The `elseif` statement is used with `if` to check **multiple, distinct conditions** sequentially. As soon as one condition evaluates to `TRUE`, its corresponding code block is executed, and the entire structure is exited.

if (cond1) { /* code A */ } elseif (cond2) { /* code B */ } else { /* code C */ }

3. `switch` Statement

The `switch` statement is used to perform a specific action based on the value of a **single variable or expression**. It is generally preferred over a long series of `if..elseif..else` statements when checking one variable against many possible discrete values, improving readability.

Advanced Conditional Usage

Nested `if` Statements

An `if` statement can be placed within the block of another `if` or `else` statement to handle **sequential dependencies** or more complex logic.

if ($age >= 18) { /* outer condition true */
   if ($age < 60) { echo "Adult"; } // inner condition
   else { echo "Senior"; }
} else { echo "Minor"; }

`break` and `continue` (Context within Control Flow)

While primarily used in loops, `break` is essential in `switch` statements to prevent **fall-through** (execution of code in subsequent `case` blocks). `continue` is used in loops to skip the rest of the current iteration and move to the next.

switch ($day) {
   case "Monday": echo "Start"; **break;** // Prevents fall-through
   case "Friday": echo "Weekend"; break;
}

Format Specifiers in C

Format specifiers are special symbols used in formatted input/output functions such as printf() and scanf(), as well as file IO functions like fprintf() and fscanf(). They specify the type of data to be printed or read, guiding the compiler for proper interpretation.

Why Use Format Specifiers?

Input/output devices communicate via streams of textual data. Format specifiers let the program interpret this text correctly as integers, floats, strings, etc., and convert variables into text for output.

Common Format Specifiers

  • %c: Character
  • %d: Signed integer
  • %i: Signed integer (alternate)
  • %f: Float
  • %e or %E: Scientific notation (float)
  • %g or %G: Automatically select %f or %e
  • %hi: Short signed integer
  • %hu: Short unsigned integer
  • %ld or %li: Long integer
  • %lf: Double
  • %Lf: Long double
  • %lu: Unsigned long
  • %lli or %lld: Long long integer
  • %llu: Unsigned long long
  • %o: Octal number
  • %p: Pointer (memory address)
  • %s: String
  • %u: Unsigned integer
  • %x or %X: Hexadecimal (lowercase / uppercase)
  • %%: Prints the percent sign

Integer Format Specifiers Example


#include <stdio.h>

int main() {
   int num = 20;
   printf("Signed integer: %d\n", num);
   printf("Unsigned integer: %i\n", num);
   printf("Long integer: %ld\n", num);
   printf("Octal integer: %o\n", num);
   printf("Hexadecimal integer: %x\n", num);
   return 0;
}

Floating-point Format Specifiers

C uses %f for single precision floats, %lf for double precision, and %Lf for long double. You can specify precision and width, for example %4.2f prints a number in a width of 4 characters with 2 decimals.

Floating-point Format Example


#include <stdio.h>

int main() {
   float num = 5.347;
   printf("float: %f\n", num);
   printf("double: %lf\n", num);
   printf("Scientific notation: %e\n", num);
   printf("Width and precision: %4.2f\n", num);
   return 0;
}

String Format Specifiers

The %c specifier prints a single character; using %d with a char prints its ASCII value. The %s specifier prints a string (array of chars).

String Example


#include <stdio.h>

int main() {
   char ch = 'D';
   char word[] = "Hello World";

   printf("As character: %c\n", ch);
   printf("As ASCII value: %d\n", ch);
   printf("String: %s\n", word);
   return 0;
}

Use in File IO

Format specifiers are also used in fprintf() and fscanf() for formatted reading and writing from/to files.

File IO Example


#include <stdio.h>

int main() {
   int x, y, z;
   FILE *fp = fopen("test.txt", "w");
   x = 10; y = 20; z = 30;
   fprintf(fp, "%d, %d, %d", x, y, z);
   fclose(fp);

   fp = fopen("test.txt", "r");
   fscanf(fp, "%d, %d, %d", &x, &y, &z);
   printf("%d, %d, %d\n", x, y, z);
   fclose(fp);

   return 0;
}

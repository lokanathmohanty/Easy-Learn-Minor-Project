Type Conversion in C

In C programming, type conversion is the process of converting a value from one data type to another to ensure compatibility in expressions. This happens either implicitly by the compiler or explicitly by the programmer.

Implicit Type Conversion

Also known as automatic type conversion, it occurs when the compiler converts types on its own, typically promoting smaller data types to larger ones to maintain precision and consistency.

Rules include:

  • Byte and short values are promoted to int.
  • If one operand is long, the expression is promoted to long.
  • If one operand is float, promote expression to float.
  • If any operand is double, promote expression to double.

Example: Implicit Type Conversion


#include <stdio.h>

int main() {
  int  i = 17;
  char c = 'c'; // ASCII value 99

  int sum = i + c;

  printf("Value of sum: %d\n", sum);
  return 0;
}

Output:


Value of sum: 116

The char c is promoted to int using its ASCII value 99 before addition.

Usual Arithmetic Conversion

When operands have different types, both are converted to a common type following this hierarchy:

  1. double
  2. float
  3. unsigned long
  4. long
  5. unsigned int
  6. int

Example: Usual Arithmetic Conversion


#include <stdio.h>

int main() {
  char a = 'A';   // ASCII 65
  float b = a + 5.5;

  printf("%f\n", b);
  return 0;
}

Output:


70.500000

Here, a is promoted to float to match the other operand.

Explicit Type Conversion (Typecasting)

Typecasting is when the programmer explicitly converts a value from one type to another using the cast operator (type). It is required when converting from a larger to a smaller type or between unrelated types (e.g., float to int).

Example: Without Typecasting


#include <stdio.h>

int main() {
  int x = 10, y = 4;
  float z = x / y;

  printf("%f\n", z);
  return 0;
}

Output:


2.000000

Result is 2 because both operands are int and integer division truncates decimals.

Example: With Explicit Typecasting


#include <stdio.h>

int main() {
  int x = 10, y = 4;
  float z = (float) x / y;

  printf("%f\n", z);
  return 0;
}

Output:


2.500000

Now the division occurs in floating-point arithmetic producing the correct result.

Typecasting Functions in C

  • atoi(): Converts string to integer.
  • itoa(): Converts integer to string.
  • malloc(): Often used with explicit cast for pointer type.

Example: Using atoi()


#include <stdio.h>
#include <stdlib.h>

int main() {
  char str[] = "123";
  int num = atoi(str);

  printf("%d\n", num);
  return 0;
}

Output:


123

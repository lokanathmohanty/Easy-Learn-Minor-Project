JavaScript Loop Control — E-Learning Session

Overview

JavaScript provides control statements to manage how loops execute. With break, continue, and labels, developers can stop a loop, skip iterations, or control nested loops more precisely.

Loop Control Keywords

  • break — exits the loop immediately.

  • continue — skips the current iteration and continues with the next.

  • label — an identifier applied to a loop or block, used with break or continue to control nested loops.

The break Statement

The break statement exits a loop completely, regardless of whether the condition has finished.

Example: breaking a while loop when x == 5

Output:

  • Entering the loop
  • 2
  • 3
  • 4
  • 5
  • Exiting the loop!

The continue Statement

The continue statement skips the rest of the current iteration and moves directly to the loop’s condition check. If true, the loop continues with the next iteration.

Example: skipping when x == 5

Output:

  • Entering the loop
  • 2
  • 3
  • 4
  • 6
  • 7
  • 8
  • 9
  • 10
  • Exiting the loop!

Using Labels to Control Flow

A label is an identifier followed by a colon (:) placed before a loop. It allows break and continue to target specific loops, which is useful in nested loop situations.

Example 1: break with labels

In nested loops, using break innerloop or break outerloop can control which loop is exited.

Output:

  • Entering the loop!
  • Outerloop: 0
  • Innerloop: 0
  • Innerloop: 1
  • Innerloop: 2
  • Innerloop: 3
  • Outerloop: 1
  • Innerloop: 0
  • Innerloop: 1
  • Innerloop: 2
  • Innerloop: 3
  • Outerloop: 2
  • Outerloop: 3
  • Innerloop: 0
  • Innerloop: 1
  • Innerloop: 2
  • Innerloop: 3
  • Outerloop: 4
  • Exiting the loop!

Example 2: continue with labels

Using continue outerloop skips the current iteration of the outer loop when a condition is met.

Output:

  • Entering the loop!
  • Outerloop: 0
  • Innerloop: 0
  • Innerloop: 1
  • Innerloop: 2
  • Outerloop: 1
  • Innerloop: 0
  • Innerloop: 1
  • Innerloop: 2
  • Outerloop: 2
  • Innerloop: 0
  • Innerloop: 1
  • Innerloop: 2
  • Exiting the loop!

Summary

Loop control statements allow fine-grained management of loop execution:

  • Use break to exit loops early.

  • Use continue to skip an iteration.

  • Use labels to control nested loops with precision.

Java Base64 Encoding and Decoding (Java 8+)

The Base64 Utility Class

The **java.util.Base64** utility class was introduced in **Java 8** to provide built-in support for Base64 encoding and decoding operations. This eliminates the need for third-party libraries for these common operations.

Base64 is a scheme that represents binary data in an ASCII string format by translating it into a radix-64 representation. It is typically used to ensure that binary data remains intact when transferred over mediums that are not 8-bit clean (e.g., email via MIME).

Three Types of Base64 Schemes

The Base64 class provides access to separate **Encoders** and **Decoders** for three distinct use cases:

  1. Basic: The standard Base64 encoding (A-Za-z0-9+/). The encoder **does not add line feeds**, and the decoder strictly rejects any non-standard characters.

    Access via: Base64.getEncoder() and Base64.getDecoder()

  2. URL and Filename Safe: Used for data that will be transmitted in URLs or used in filenames. It replaces the standard + and / characters with URL-safe characters (typically - and _) to prevent issues with URL parsing.

    Access via: Base64.getUrlEncoder() and Base64.getUrlDecoder()

  3. MIME: Used for compatibility with the **MIME** standard (e.g., email attachments). The encoder formats the output into lines of no more than **76 characters** each, separated by a carriage return and line feed (\r\n).

    Access via: Base64.getMimeEncoder() and Base64.getMimeDecoder()

Example: Basic Base64 Encoding and Decoding

The process always involves converting the input string to a byte array before encoding, and then converting the resulting byte array back to a string after decoding, typically using "utf-8".

import java.util.Base64;
import java.nio.charset.StandardCharsets;

String stringToEncode = "Hello World! Java 8";

// --- Encoding (String -> Bytes -> Base64 String) ---
String base64encodedString = Base64.getEncoder().encodeToString(
    stringToEncode.getBytes(StandardCharsets.UTF_8)
);
System.out.println("Encoded: " + base64encodedString);

// --- Decoding (Base64 String -> Bytes -> Original String) ---
byte[] base64decodedBytes = Base64.getDecoder().decode(base64encodedString);
String decodedString = new String(base64decodedBytes, StandardCharsets.UTF_8);
System.out.println("Decoded: " + decodedString);

C# Operator Overloading

Concept and Purpose

**Operator Overloading** is a form of **static polymorphism** that allows you to redefine the behavior of C# operators (like `+`, `-`, `==`, `>`) when they are applied to **user-defined types** (classes or structs).

This allows programmers to use intuitive operator syntax with their custom objects, making the code more readable and closer to mathematical notation (e.g., adding two custom Box objects simply by using Box3 = Box1 + Box2;).

Implementing Operator Overloading

Overloaded operators are implemented as **public static methods** within the class or struct they operate on. The method name is formed by the keyword **`operator`** followed by the symbol of the operator being overloaded.

Syntax for Binary Operator Overloading:

Binary operators (like `+`) take two operands, so the overloaded method must accept two parameters.

public static <return type> operator<operator symbol> (<type> param1, <type> param2) {
   // Implementation to define the operation
   // Must return a value of the specified return type
}

// Example for Box addition:
public static Box operator+ (Box b, Box c) {
   Box box = new Box();
   box.length = b.length + c.length; // Defines the logic for Box + Box
   // ...
   return box; // Returns a new Box object
}

Rules for Overloading:

  • The method must be **`public`** and **`static`**.
  • At least **one operand** must be of the containing class or struct type.
  • If you overload `==`, you must also overload **`!=`**, and it's highly recommended to override **`Equals()`** and **`GetHashCode()`**.
  • If you overload `<` or `>`, you must overload the **other one** (e.g., overload both `<` and `>`). The same applies to `<=`, and `>=`.

Overloadable Operators in C#

While most operators can be overloaded, certain ones are non-overloadable.

Overloadable Operators (Common Examples):

Type Operators
Unary +, -, !, ~, ++, --, true, false
Binary +, -, *, /, %, &, |, ^, <<, >>
Comparison ==, !=, <, >, <=, >=

Non-Overloadable Operators:

The following cannot be redefined:

  • **Assignment Operators:** =, +=, -=, *=, etc. (They automatically use the overloaded arithmetic operators if available).
  • **Access/Member Operators:** ., ?:, new, is, as, sizeof, typeof, checked, unchecked.
  • **Conditional Logical Operators:** &&, || (However, overloading `&` and `|` allows C# to implicitly support `&&` and `||`).

Example: Overloading Comparison Operators

Overloading the comparison operators (`<`, `>`) for the Box class requires defining a custom logic, such as comparing all dimensions, or perhaps just comparing the volumes.

// Must be static and public
public static bool operator >(Box lhs, Box rhs) {
    // Custom logic: return true only if ALL dimensions are greater
    if (lhs.length > rhs.length && lhs.height > rhs.height 
        && lhs.breadth > rhs.breadth) {
        return true;
    }
    return false;
}

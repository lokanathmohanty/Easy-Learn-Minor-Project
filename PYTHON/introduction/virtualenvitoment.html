Python - Virtual Environment

Introduction

Python virtual environments create a virtual installation of Python inside a project directory. This allows installing and managing packages separately for each project without affecting other environments.

What is Virtual Environment in Python?

A virtual environment is:

  • Considered disposable.
  • Contains a specific Python interpreter, libraries, and binaries.
  • Usually located in a directory named venv or .venv.
  • Not movable or copyable.

Virtual environments avoid conflicts when different projects require different versions of the same library. Each environment has its own isolated Python interpreter and modules.

Creating Virtual Environments with venv

The venv module is included in the standard Python distribution. Example:

C:\Users\Acer>md \pythonapp
C:\Users\Acer>cd \pythonapp
C:\pythonapp>python -m venv myvenv

This creates a myvenv folder with the following structure:

Include/
Lib/
Scripts/
pyvenv.cfg

Scripts Folder

The Scripts folder contains activation utilities, pip, and a local copy of Python:

  • activate, activate.bat, Activate.ps1
  • deactivate.bat
  • pip.exe, pip3.exe
  • python.exe, pythonw.exe

Activating Virtual Environment

Run the activate script:

C:\pythonapp>myvenv\scripts\activate
(myvenv) C:\pythonapp>

The environment name appears in parentheses. You can now run Python within this environment.

Checking Virtual Environment

To verify, check sys.path inside Python:

>>> import sys
>>> sys.path
['', 'C:\\Python310\\lib', 'C:\\pythonapp\\myvenv', 
'C:\\pythonapp\\myvenv\\lib\\site-packages']

Installed packages are limited to this environment only.

Deactivating Virtual Environment

To exit the environment, run:

(myvenv) C:\pythonapp>deactivate

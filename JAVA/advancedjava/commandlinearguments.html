Java - Command Line Arguments

In Java, command line arguments are a way to pass inputs to a program during execution. These inputs are captured in the main() method as a string array named args[].

This allows dynamic behavior of the application without changing the code. The arguments are passed through the terminal when running the compiled Java program.

Passing & Accessing Command Line Arguments

Command line arguments are passed using this syntax:

javac Tester.java
java Tester arg1 arg2 arg3

The JVM stores these arguments in the args[] array, starting at args[0]. The number of arguments is determined using args.length.

Each element in args[] is a string, regardless of whether it looks like a number or not.

Benefits of Command Line Arguments

  • Used to configure application behavior at runtime
  • Useful in automation and batch processing
  • Allow parameterized execution without changing code
  • Facilitate user input in console-based applications

Code Examples

Example 1: Single Command Line Argument

This example expects exactly one argument — the user's name.

public class Tester {
  public static void main(String[] args) {
    if(args.length == 1) {
      String name = args[0];
      System.out.println("Welcome " + name + "!");
    } else {
      System.out.println("Invalid Command line argument(s) passed.");
    }
  }
}

Output:

D:\test>javac Tester.java
D:\test>java Tester
Invalid Command line argument(s) passed.

D:\test>java Tester Mahesh
Welcome Mahesh!

Example 2: Multiple Command Line Arguments

This example expects two arguments — name and age.

public class Tester {
  public static void main(String[] args) {
    if(args.length == 2) {
      String name = args[0];
      int age = Integer.parseInt(args[1]);
      System.out.println("Name: " + name + ", age: " + age);
    } else {
      System.out.println("Invalid Command line argument(s) passed.");
    }
  }
}

Output:

D:\test>javac Tester.java
D:\test>java Tester
Invalid Command line argument(s) passed.

D:\test>java Tester Mahesh 40
Name: Mahesh, age: 40

Conclusion

Command line arguments provide flexibility and allow programs to accept user inputs at runtime. They are especially useful for tools, automation, and scripts where behavior can be changed without editing the source code.

Most IDEs also allow setting command line arguments through configuration, making this feature both powerful and accessible.

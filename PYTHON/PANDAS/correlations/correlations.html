Pandas - Data Correlations

One of the powerful features of the Pandas module is the corr() method, which is used to calculate the correlation (relationship) between numerical columns in a dataset.

The correlation value ranges from -1 to 1:

  • 1: Perfect positive correlation
  • 0: No correlation
  • -1: Perfect negative correlation

The examples on this page use a CSV file named data.csv.

Example: Finding Relationships

Calculate the correlation between numeric columns using:


import pandas as pd

df = pd.read_csv("data.csv")
print(df.corr())

Sample result:


             Duration     Pulse  Maxpulse  Calories
Duration  1.000000 -0.155408  0.009403  0.922721
Pulse    -0.155408  1.000000  0.786535  0.025120
Maxpulse  0.009403  0.786535  1.000000  0.203814
Calories  0.922721  0.025120  0.203814  1.000000

Note: The corr() method ignores non-numeric columns like "Date".

Result Explained

The resulting table shows the correlation between all numeric columns. Here's how to interpret the values:

  • 1.0 → Perfect correlation (a column compared to itself)
  • 0.9 → Very strong positive correlation
  • 0.2 → Weak correlation
  • -0.9 → Very strong negative correlation

What is considered a "good" correlation depends on the context, but typically a value of at least ±0.6 is seen as a strong correlation.

Examples of Correlation

  • Perfect Correlation: "Duration" and "Duration" have a correlation of 1.000000.
  • Good Correlation: "Duration" and "Calories" have a correlation of 0.922721. This suggests that longer workouts burn more calories.
  • Poor Correlation: "Duration" and "Maxpulse" have a correlation of 0.009403, meaning no meaningful relationship between workout length and max pulse.

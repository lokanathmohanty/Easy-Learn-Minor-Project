C++ Multiple Inheritance 🔗🔗

**Multiple inheritance** is a C++ feature that allows a **derived class** to inherit attributes and behaviors from **more than one base class**. This is used to combine the functionalities of several parent classes into a single child class, modeling real-world entities that possess multiple characteristics (e.g., a DualModeVehicle is both a Car and a Boat).

Implementation Syntax

Multiple base classes are specified in the derived class declaration using a **comma-separated list** with their respective access specifiers:

class Derived : public Base1, public Base2 {
   // Derived class inherits members from both Base1 and Base2
};

Challenges and Solutions

While powerful, multiple inheritance introduces two main challenges:

1. Ambiguity

Ambiguity occurs when two or more base classes have members (functions or variables) with the **exact same name**, and the derived class tries to access one without specifying which one.

// Base1::show() and Base2::show() both exist.
// Calling obj.show() is ambiguous.

// Resolution: Use **Scope Resolution Operator (::)**
void Derived::show() {
    Base1::show(); // Explicitly call Base1's version
    Base2::show(); // Explicitly call Base2's version
}

2. The Diamond Problem 💎

This arises when a class inherits from two classes, which themselves both inherit from a common grandparent class. This structure forms a "diamond" shape in the inheritance graph. The derived class ends up with **two copies** of the common grandparent's members, leading to ambiguity.

Solution: Virtual Inheritance

The **virtual** keyword is used when declaring the base classes in the intermediate derived classes to ensure that **only a single instance** of the common grandparent base class exists in the final derived object.

class Derived1 : **virtual** public Base {}; 
class Derived2 : **virtual** public Base {}; 

class Final : public Derived1, public Derived2 {}; 
// Final object now has only one Base instance, resolving ambiguity.

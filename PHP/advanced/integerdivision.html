PHP $\text{intdiv()}$ Function for Integer Division ➗

The $\text{intdiv()}$ function, introduced in PHP 7, performs **integer division** on two integer operands, returning only the integer quotient of the division. This function is valuable because standard PHP division ($\text{/}$) returns a floating-point number ($\text{float}$), even if the result is an integer.

Syntax and Behavior

int intdiv ( int $x , int $y )

The function returns the mathematical integer part of $\text{x/y}$. Its behavior is defined by the relationship: $\text{x} = \text{y} \times \text{quotient} + \text{remainder}$, where the result is the $\text{quotient}$.

Sign Rules:

  • If both $\text{x}$ and $\text{y}$ have the same sign (both positive or both negative), the result is **positive**.
  • If $\text{x}$ and $\text{y}$ have different signs (one positive, one negative), the result is **negative**.
  • The result is always an **integer**.

Examples of $\text{intdiv()}$

Case 1: Standard Division

When the numerator is greater than the denominator:

<?php
   echo intdiv(10, 3); // Output: 3 (10 / 3 = 3.33, integer part is 3)
?>

When the numerator is less than the denominator:

<?php
   echo intdiv(3, 10); // Output: 0 (3 / 10 = 0.3, integer part is 0)
?>

Case 2: Handling Negative Numbers

The result truncates toward zero, consistent with the sign rules above:

<?php
   echo intdiv(10, -3);  // Output: -3
   echo intdiv(-10, 3);  // Output: -3
   echo intdiv(-10, -3); // Output: 3
?>

Error Handling: Division by Zero

Unlike standard division, which returns $\text{INF}$ (Infinity) when dividing by zero, $\text{intdiv()}$ throws an exception.

<?php
   // Throws a fatal error
   intdiv(10, 0); 
?>

This operation results in a **$\text{DivisionByZeroError}$** exception.

C# `while` Loop

Introduction to the `while` Loop

The **`while` loop** is a fundamental control flow statement in C# that allows a block of code to be executed **repeatedly as long as a specified Boolean condition remains true**. It is best suited for scenarios where the **number of iterations is not known** ahead of time.

A key characteristic is that it is a **pre-test loop**: the condition is evaluated **before** the loop body executes. If the condition is initially false, the loop body will **never run**.

Syntax and Components

Syntax:

while(condition) {
   statement(s);
}

Three Main Parts:

  • Initialization: Declaring and setting the initial value of the loop control variable (must be done **before** the loop).
  • Condition: The Boolean expression that is tested before each iteration. The loop runs as long as this is true.
  • Update (Increment/Decrement): A statement **inside the loop body** that changes the loop control variable, moving it closer to satisfying the termination condition. **Failing to include the update creates an infinite loop.**

Example: Simple Iteration (10 to 20)

This demonstrates the standard structure, with initialization before the loop and the update inside the loop body:

using System;
class Program {
    static void Main(string[] args) {
        /* Initialization */
        int a = 10;

        /* Condition: Loop runs while a <= 20 */
        while (a <= 20) {
            Console.WriteLine("value of a: {0}", a);
            /* Update */
            a++; 
        }
    }
}

Output: Values 10 through 20 are printed.

Common Use Cases

The `while` loop is highly effective for tasks where the stopping point is dynamic:

  • **Input Validation:** Looping until a user enters a valid or correctly formatted piece of data (e.g., a positive number).
  • **File Processing:** Reading data line by line from a file stream (or network socket) until the **End-of-File** (EOF) condition is reached.
  • **Algorithmic Tasks:** Reversing a number, counting digits, or calculating sums where the condition is based on the evolving state of the variable (e.g., while (num != 0)).
  • **Continuous Tasks:** Running background threads or simulation tasks until an external flag or system condition changes.

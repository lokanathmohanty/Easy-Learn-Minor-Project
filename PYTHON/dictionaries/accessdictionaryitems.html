Python - Access Dictionary Items

Accessing dictionary items in Python means retrieving values associated with specific keys in a dictionary. Dictionaries store data as unique key-value pairs.

You can access these values using square brackets [], the get() method, looping, or dedicated methods like keys(), values(), and items().

Using Square Brackets []


capitals = {
  "Maharashtra": "Mumbai",
  "Gujarat": "Gandhinagar",
  "Telangana": "Hyderabad",
  "Karnataka": "Bengaluru"
}

print("Capital of Gujarat is:", capitals["Gujarat"])
print("Capital of Karnataka is:", capitals["Karnataka"])

Output:

Capital of Gujarat is: Gandhinagar
Capital of Karnataka is: Bengaluru

Note: Using a key that does not exist causes a KeyError.

Using get() Method

The get() method returns the value for a key or a default (usually None) if the key is missing, without raising an error. 


print("Capital of Gujarat is:", capitals.get("Gujarat"))
print("Capital of Karnataka is:", capitals.get("Karnataka"))
print("Capital of Haryana is:", capitals.get("Haryana"))
print("Capital of Haryana is:", capitals.get("Haryana", "Not found"))

Output:

Capital of Gujarat is: Gandhinagar
Capital of Karnataka is: Bengaluru
Capital of Haryana is: None
Capital of Haryana is: Not found

Accessing Keys with keys()


student_info = {
  "name": "Alice",
  "age": 21,
  "major": "Computer Science"
}

all_keys = student_info.keys()
print("Keys:", all_keys)

Output:

Keys: dict_keys(['name', 'age', 'major'])

Accessing Values with values() and by Key


name = student_info["name"]
age = student_info.get("age")
major = student_info.get("major")
grad_year = student_info.get("graduation_year", "2023")

print("Name:", name)
print("Age:", age)
print("Major:", major)
print("Graduation Year:", grad_year)

all_values = student_info.values()
print("Values:", all_values)

Output:

Name: Alice
Age: 21
Major: Computer Science
Graduation Year: 2023
Values: dict_values(['Alice', 21, 'Computer Science'])

Accessing Key-Value Pairs with items()


all_items = student_info.items()
print("Items:", all_items)

for key, value in all_items:
    print(f"{key}: {value}")

Output:

Items: dict_items([('name', 'Alice'), ('age', 21), ('major', 'Computer Science')])
name: Alice
age: 21
major: Computer Science

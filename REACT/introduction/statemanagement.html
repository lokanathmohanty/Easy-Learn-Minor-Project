ReactJS - State Management

State management is one of the important and unavoidable features of any dynamic application. React provides a simple and flexible API to support state management in a React component.

In this chapter, we will learn how to maintain state in a React application.

What is State?

State represents the value of dynamic properties of a React component at a given instance. React provides a dynamic data store for each component. This internal data, known as state, can be accessed using the this.state member variable.

Whenever the state of the component changes, the component will automatically re-render by calling its render() method with the updated state.

For example, a clock component needs to maintain the current date and time in its state. Since time changes every second, the component updates its state every second, which re-renders the UI accordingly.

A simple representation of state could be:

{ date: '2020-10-10 10:10:10' }

Defining a State

State can be used in both class and functional components. To work with state in a class component, we define the initial state in the constructor.

Syntax to define state in a class component:

state = { attribute: "value" };

Example:

class SampleClass extends React.Component {
  constructor(props) {
    super(props);
    this.state = { name: "John Doe" };
  }
}

Creating a State Object

React components have a built-in state object. The state object is used to store all property values that belong to the component. When the state object changes, the component re-renders automatically.

Example:

class BookClass extends React.Component {
  constructor(props) {
    super(props);
    this.state = { name: "John Doe" };
  }

  render() {
    return (
      <div>
        <h1>Name of the Author</h1>
      </div>
    );
  }
}

Python - Membership Operators

The membership operators in Python help us determine whether an item is present in a given container type object, or in other words, whether an item is a member of the given container type object.

Python has two membership operators: in and not in. Both return a Boolean result. The result of in operator is opposite to that of not in operator.

The "in" Operator

The in operator is used to check whether a substring is present in a bigger string, an item is present in a list or tuple, or a sub-list/sub-tuple is included in a list or tuple.

var = "TutorialsPoint"
a = "P"
b = "tor"
c = "in"
d = "To"
print(a, "in", var, ":", a in var)
print(b, "in", var, ":", b in var)
print(c, "in", var, ":", c in var)
print(d, "in", var, ":", d in var)

Output:

  • P in TutorialsPoint : True
  • tor in TutorialsPoint : True
  • in in TutorialsPoint : True
  • To in TutorialsPoint : False

The "not in" Operator

The not in operator is used to check if a sequence with the given value is not present in the object like string, list, or tuple.

var = "TutorialsPoint"
a = "P"
b = "tor"
c = "in"
d = "To"
print(a, "not in", var, ":", a not in var)
print(b, "not in", var, ":", b not in var)
print(c, "not in", var, ":", c not in var)
print(d, "not in", var, ":", d not in var)

Output:

  • P not in TutorialsPoint : False
  • tor not in TutorialsPoint : False
  • in not in TutorialsPoint : False
  • To not in TutorialsPoint : True

Membership Operators with Lists and Tuples

var = [10,20,30,40]
a = 20
b = 10
c = a-b
d = a/2
print(a, "in", var, ":", a in var)
print(b, "not in", var, ":", b not in var)
print(c, "in", var, ":", c in var)
print(d, "not in", var, ":", d not in var)

Output:

  • 20 in [10, 20, 30, 40] : True
  • 10 not in [10, 20, 30, 40] : False
  • 10 in [10, 20, 30, 40] : True
  • 10.0 not in [10, 20, 30, 40] : False

Note: Even if a number is expressed in another format (binary, octal, hexadecimal), membership operators correctly check presence inside the sequence.

>>> 0x14 in [10, 20, 30, 40]
True

If you check two successive numbers, in returns False unless they are grouped together as a sequence inside the list/tuple.

var = (10,20,30,40)
a = 10
b = 20
print((a,b), "in", var, ":", (a,b) in var)

var = ((10,20),30,40)
a = 10
b = 20
print((a,b), "in", var, ":", (a,b) in var)

Output:

  • (10, 20) in (10, 20, 30, 40) : False
  • (10, 20) in ((10, 20), 30, 40) : True

Membership Operators with Sets

var = {10,20,30,40}
a = 10
b = 20
print(b, "in", var, ":", b in var)

var = {(10,20),30,40}
a = 10
b = 20
print((a,b), "in", var, ":", (a,b) in var)

Output:

  • 20 in {40, 10, 20, 30} : True
  • (10, 20) in {40, 30, (10, 20)} : True

Membership Operators with Dictionaries

When used with dictionaries, in and not in operators check only the keys, not the values.

var = {1:10, 2:20, 3:30}
a = 2
b = 20
print(a, "in", var, ":", a in var)
print(b, "in", var, ":", b in var)

Output:

  • 2 in {1: 10, 2: 20, 3: 30} : True
  • 20 in {1: 10, 2: 20, 3: 30} : False

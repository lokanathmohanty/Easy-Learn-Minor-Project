CSS max-inline-size Property

The max-inline-size property in CSS sets the maximum inline size of an element. The inline direction is determined by the writing-mode property. If the content fits within the element's inline size, the property has no effect. This property is especially useful in responsive design where you want to control the growth of inline elements without fixing their size.

Syntax

max-inline-size: auto | length | percentage | initial | inherit;

Property Values

  • auto – Default. No inline-size limit is applied.
  • length – Defines the maximum inline size in absolute or relative length units (px, em, rem, etc.).
  • percentage – Defines the maximum inline size as a percentage of the containing element.
  • initial – Resets the property to its default value.
  • inherit – Inherits the value from the parent element.

Examples

Max Inline Size with Auto Value

When set to auto, the element does not have a maximum inline size restriction, and its size depends solely on its content. 

<div class="container">
  <div style="max-inline-size: auto; display: inline-block;">
    <p>
      This paragraph expands based on content without any restriction
      from max-inline-size because the value is set to auto.
    </p>
  </div>
</div>

Max Inline Size with Length Values

You can use specific length units to set the maximum inline size of an element. If the content overflows, it will either wrap or extend depending on other CSS rules. 

<div class="container">
  <div style="max-inline-size: 160px; display: inline-block;">
    <p>This element has a maximum inline size of 160px.</p>
  </div>

  <div style="max-inline-size: 6.5em; display: inline-block;">
    <p>This element has a maximum inline size of 6.5em.</p>
  </div>
</div>

Max Inline Size with Percentage Values

Using percentage values makes the element’s size responsive to its parent container. For example, 50% means the element can grow up to half of its container’s inline size. 

<div class="container" style="width: 500px;">
  <div style="max-inline-size: 45%; display: inline-block;">
    <p>This box takes up to 45% of its parent container.</p>
  </div>

  <div style="max-inline-size: 55%; display: inline-block;">
    <p>This box takes up to 55% of its parent container.</p>
  </div>
</div>

Max Inline Size with Writing Mode

The max-inline-size property works in combination with the writing-mode property. In horizontal writing mode, inline-size grows left to right. In vertical writing mode, it grows top to bottom. 

<div class="container">
  <div style="max-inline-size: 65%; writing-mode: horizontal-tb; display: inline-block;">
    <p>This uses horizontal writing mode with max-inline-size of 65%.</p>
  </div>

  <div style="max-inline-size: 65%; writing-mode: vertical-rl; display: inline-block;">
    <p>This uses vertical writing mode with max-inline-size of 65%.</p>
  </div>
</div>

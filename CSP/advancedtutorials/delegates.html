C# Delegates: Method References 🔗

What is a Delegate?

A **delegate** is a **reference type** variable that holds the reference (or address) of a **method**. They are essentially C#'s version of function pointers, but they are object-oriented, type-safe, and secure.

Delegates are crucial for:

  • **Implementing Events:** The foundation of event handling in C#.
  • **Call-back Methods:** Allowing a method to be passed as an argument to another method, which can then execute (call back) the referenced method.
  • **Generic Programming:** Using built-in delegates like `Action` and `Func`.

All delegates implicitly derive from the **`System.Delegate`** class.

Declaring and Instantiating Delegates

Declaration (Defining the Signature)

A delegate declaration defines the signature (return type and parameter list) of the methods it can reference.

delegate <return type> <delegate-name> <parameter list>

Example: `delegate int NumberChanger(int n);`

Instantiation (Referencing a Method)

A delegate object is created using the **`new`** keyword and associating it with a specific method that matches the delegate's signature.

// Method must match signature: int (int)
NumberChanger nc1 = new NumberChanger(AddNum); 

// The delegate object can be invoked like the method itself
nc1(25);

Multicast Delegates (Invocation List)

Delegate objects can be combined using the **`+`** operator and removed using the **`-`** operator. This creates an **invocation list** of multiple methods that will be called sequentially when the delegate is invoked. This is called **multicasting**.

NumberChanger nc;
NumberChanger nc1 = new NumberChanger(AddNum);
NumberChanger nc2 = new NumberChanger(MultNum);
         
nc = nc1; // nc now references AddNum
nc += nc2; // nc now references both AddNum AND MultNum
         
nc(5); // Both AddNum(5) and MultNum(5) are called

Built-in Generic Delegates

C# provides generic delegates in the **`System`** namespace that cover most common method signatures, making custom delegate declarations often unnecessary.

Delegate Purpose Example
`Action<T...>` References a method that **returns `void`** (takes 0 to 16 input parameters). `Action<string> greet = name => Console.WriteLine(name);`
`Func<T..., TResult>` References a method that **returns a value** of type `TResult` (takes 0 to 16 input parameters `T...`). `Func<int, int, int> add = (a, b) => a + b;`
`Predicate<T>` References a method that **returns a `bool`** and takes exactly **one** input parameter of type `T`. `Predicate<int> isEven = n => n % 2 == 0;`

Python - Wrapper Classes

In Python, wrapper classes are used to modify or extend the behavior of other classes or functions without changing their original code. This is often achieved by using decorators that wrap a class inside another class.

Wrapping helps in managing or augmenting class behavior after instantiation by adding extra functionality.

Example: Creating a Wrapper Class Using a Decorator

def decorator_function(Wrapped):
    class Wrapper:
        def __init__(self, x):
            self.wrap = Wrapped(x)
        def print_name(self):
            return self.wrap.name
    return Wrapper

@decorator_function
class Wrapped:
    def __init__(self, x):
        self.name = x

obj = Wrapped('TutorialsPoint')
print(obj.print_name())

Output:

TutorialsPoint

How the Wrapper Works

- The class Wrapped is passed as an argument to the decorator_function.
- The decorator_function defines an inner class Wrapper that holds an instance of Wrapped.
- The Wrapper class exposes methods that interact with the wrapped instance.
- When Wrapped is instantiated, actually Wrapper is created, which internally manages the original class.

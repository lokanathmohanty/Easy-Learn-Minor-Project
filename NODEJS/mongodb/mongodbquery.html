Node.js - MongoDB Query

Overview

The find() and findOne() methods in MongoDB driver allow querying documents in a collection using JSON-style filters. MongoDB uses its own query operators prefixed with $ for comparisons and logical expressions.

Common MongoDB Operators

OperatorDescription
$eqEqual to (==)
$gtGreater than (>)
$gteGreater than or equal to (>=)
$inMatch any value in an array
$ltLess than (<)
$lteLess than or equal to (<=)
$neNot equal to (!=)
$ninNot in array

Example: Find Documents With Price > 10000

async function fetchDocs(client, dbname, colname) {
  const result = await client.db(dbname).collection(colname)
    .find({ price: { $gt: 10000 } }).toArray();
  console.log(JSON.stringify(result));
}

Compound Logical Expressions

Use $and and $or for compound filters:

await client.db(dbname).collection(colname)
  .find({ $and: [ { price: { $gt: 1000 } }, { price: { $lt: 10000 } } ] }).toArray();

Using Regex Filters

Match by patterns using $regex in queries.

Example: Names Starting with "P"

await client.db(dbname).collection(colname)
  .find({ Name: { $regex: "^P" } }).toArray();

Example: Names Containing "Ro"

await client.db(dbname).collection(colname)
  .find({ Name: /Ro/ }).toArray();

Example: Names Ending with "er"

await client.db(dbname).collection(colname)
  .find({ Name: /er$/ }).toArray();

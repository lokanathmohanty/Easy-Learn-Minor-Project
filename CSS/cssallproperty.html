CSS - all Property

The CSS all property is a powerful shorthand property that resets all CSS properties of an element, except for unicode-bidi, direction, and custom properties (CSS variables). It can reset properties to their initial, inherited, or unset values, depending on the specified keyword.

Syntax

all: initial | inherit | unset;

Property Values

  • initial – Resets all properties to their default initial values as defined by the browser.
  • inherit – Forces all properties to inherit values from the element’s parent.
  • unset – Acts like inherit for inheritable properties and initial for non-inheritable properties.

Examples of CSS All Property

1. Using all: initial;

When the value initial is applied, the element’s properties are reset to the browser’s default values. It will not inherit styles from parent elements. 

<html>
  <head>
    <style>
      html {
        font-size: 25px;
        color: lightcoral;
        font-style: italic;
      }
      #custom1 {
        background-color: #ecf0f1;
        color: #e74c3c;
      }
      #custom2 {
        all: initial;
      }
    </style>
  </head>
  <body>
    <h2>CSS all property</h2>
    <div id="custom1">
      Reference sentence with custom styles.
    </div>
    <div id="custom2">
      This sentence uses all: initial, so it resets to default browser styling.
    </div>
  </body>
</html>

2. Using all: inherit;

When the value inherit is applied, the element inherits all properties from its parent or, if not available, from the root <html> element. 

<html>
  <head>
    <style>
      html {
        font-size: 25px;
        color: lightcoral;
        font-style: italic;
      }
      #custom1 {
        background-color: lightgreen;
        font-weight: bold;
        padding: 10px;
        color: #e74c3c;
      }
      #custom2 {
        all: inherit;
      }
    </style>
  </head>
  <body>
    <h2>CSS all property</h2>
    <div id="custom1">
      Reference sentence with custom styles.
    </div>
    <div id="custom2">
      This sentence uses all: inherit and inherits values from its parent.
    </div>
  </body>
</html>

3. Using all: unset;

The unset value behaves like inherit for inheritable properties (e.g., color, font-size) and like initial for non-inheritable properties (e.g., margin, padding). 

<html>
  <head>
    <style>
      .parent {
        color: purple;
        font-weight: bold;
        font-size: 20px;
        text-align: center;
        background-color: lightgrey;
      }
      .custom1 {
        font-weight: bold;
        padding: 10px;
      }
      .custom2 {
        all: unset;
      }
    </style>
  </head>
  <body>
    <h2>CSS all property</h2>
    <div class="parent">
      <div class="custom1">
        This element inherits from parent when using all: unset.
      </div>
    </div>
    <div class="custom2">
      This element has no parent with styles, so it falls back to browser defaults.
    </div>
  </body>
</html>

Supported Browsers

  • Chrome: 37+
  • Edge: 79+
  • Firefox: 27+
  • Safari: 9.1+
  • Opera: 24+

In summary, the all property is useful when you want to completely reset styles for an element, ensuring consistent presentation across different cascade layers. It is often applied in components or reset utilities in modern CSS.

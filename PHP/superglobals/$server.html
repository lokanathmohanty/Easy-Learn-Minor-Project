PHP `$_SERVER` Superglobal

The **`$_SERVER`** is a **superglobal associative array** in PHP that contains information about the web server, the execution environment, and the current request headers. Because this information is supplied by the web server, its content can vary widely depending on the server software (e.g., Apache, Nginx) and how the script is being run (e.g., web access vs. command line).

Key Information Stored in `$_SERVER`

The array holds essential data about the script, the request, and the client/server environment.

Variable Description
**`PHP_SELF`** The filename of the currently executing script, relative to the document root.
**`REQUEST_METHOD`** The HTTP method used to access the page (e.g., `GET`, `POST`, `PUT`).
**`QUERY_STRING`** The raw query string (key=value&key2=value2) appended to the URL after the `?`.
**`REQUEST_URI`** The full URI used to access the page, including the query string (e.g., `/path/script.php?id=1`).
**`DOCUMENT_ROOT`** The directory path on the server configured as the web root (e.g., `C:/xampp/htdocs`).
**`REMOTE_ADDR`** The IP address of the machine viewing the current page (the client).
**`SERVER_NAME`** The host name of the server (e.g., `localhost` or `www.example.com`).
**`SERVER_PORT`** The port on which the web server is listening (usually `80` or `443`).

HTTP Request Headers

PHP automatically includes all incoming **HTTP Request Headers** into the `$_SERVER` array. These entries are prefixed with **`HTTP_`** followed by the capitalized header name (with hyphens replaced by underscores).

The HTTP header **`Accept-Language`** becomes the `$_SERVER` entry: **`$_SERVER['HTTP_ACCEPT_LANGUAGE']`**.
The HTTP header **`Host`** becomes the `$_SERVER` entry: **`$_SERVER['HTTP_HOST']`**.

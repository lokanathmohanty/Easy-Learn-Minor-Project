C Operators Overview

An operator in C is a symbol that the compiler uses to perform specific mathematical or logical operations on operands. Operands are the values or variables on which the operations are performed.

Depending on the number of operands, operators are classified as:

  • Unary Operators: Require one operand (e.g., ++, --, !, ~, &, *)
  • Binary Operators: Require two operands (e.g., arithmetic, logical, relational operators)
  • Unary Operators: Require three operands (ternary operator)

C provides a rich set of operators categorized as arithmetic, relational, logical, bitwise, assignment, and miscellaneous operators.

Arithmetic Operators

  • + Addition: Adds two operands
  • - Subtraction: Subtracts second operand from first
  • * Multiplication
  • / Division
  • % Modulus: Remainder of integer division
  • ++ Increment: Increases operand by 1
  • -- Decrement: Decreases operand by 1

Relational Operators

  • == Equal to
  • != Not equal to
  • < Less than
  • <= Less than or equal to
  • > Greater than
  • >= Greater than or equal to

Logical Operators

  • && Logical AND: True if both operands are true
  • || Logical OR: True if at least one operand is true
  • ! Logical NOT: Inverts truth value

Bitwise Operators

  • & Bitwise AND
  • | Bitwise OR
  • ^ Bitwise XOR
  • ~ Bitwise Complement
  • << Left Shift
  • >> Right Shift

Assignment Operators

  • = Assignment
  • += Add and assign
  • -= Subtract and assign
  • *= Multiply and assign
  • /= Divide and assign
  • %= Modulus and assign
  • <<= Left shift and assign
  • >>= Right shift and assign
  • &= Bitwise AND and assign
  • ^= Bitwise XOR and assign
  • |= Bitwise OR and assign

Miscellaneous Operators

  • sizeof() Returns size of variable or type in bytes
  • & Returns address of variable
  • * Pointer dereference operator
  • ?: Ternary conditional operator

Operator Precedence and Associativity

Operators have precedence which determines the order in which parts of expressions are evaluated. Higher precedence operators are evaluated before lower precedence operators.

Operators also have associativity which defines the order of evaluation for operators of the same precedence - either left to right or right to left.

Example:

int x = 7 + 3 * 2; is evaluated as 7 + (3 * 2) = 13 because multiplication (*) has higher precedence than addition (+).

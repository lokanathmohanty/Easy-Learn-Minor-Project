Python - Classes and Objects

Python is an object-oriented programming language, meaning it is based on the OOP concept. Every entity in a Python program like numbers, strings, lists, and dictionaries are objects of corresponding built-in classes. The base class for all classes in Python is Object.

What is a Class in Python?

A class is a user-defined data type that defines the type of data an object can contain and the actions it can perform. It acts as a template for creating objects. For example, a class Smartphone could define attributes like RAM, ROM, screen size, and methods like call and message.

Creating Classes in Python

Use the class keyword followed by the class name and a colon to declare a class:

class ClassName:
    'Optional class documentation string'
    class_suite

The documentation string can be accessed via ClassName.__doc__. The class suite contains member variables and methods.

Example

class Employee:
    'Common base class for all employees'
    empCount = 0

    def __init__(self, name, salary):
        self.name = name
        self.salary = salary
        Employee.empCount += 1
    
    def displayCount(self):
        print("Total Employee %d" % Employee.empCount)

    def displayEmployee(self):
        print("Name : ", self.name, ", Salary: ", self.salary)

What is an Object?

An object is an instance of a class with its own attributes and methods, defined by the class. Memory is allocated when objects are instantiated from the class.

Creating Objects of Classes in Python

Create instances by calling the class with the arguments required by its constructor __init__ method:

emp1 = Employee("Zara", 2000)
emp2 = Employee("Manni", 5000)

Accessing Attributes of Objects

Access attributes and methods using the dot . operator:

emp1.displayEmployee()
emp2.displayEmployee()
print("Total Employee %d" % Employee.empCount)

Built-in Class Attributes

Python classes keep built-in attributes accessible via dot notation:

  • __dict__: Dictionary containing class namespace.
  • __doc__: Class documentation string.
  • __name__: Class name.
  • __module__: Module name where class is defined.
  • __bases__: Tuple of base classes.

Example of Built-In Class Attributes

print("Employee.__doc__:", Employee.__doc__)
print("Employee.__name__:", Employee.__name__)
print("Employee.__module__:", Employee.__module__)
print("Employee.__bases__:", Employee.__bases__)
print("Employee.__dict__:", Employee.__dict__)

Garbage Collection (Destroying Objects)

Python automatically deletes objects to free memory when their reference count reaches zero. You can define a destructor __del__() called when an object is destroyed.

Example of Destructor

class Point:
    def __init__(self, x=0, y=0):
        self.x = x
        self.y = y
    def __del__(self):
        class_name = self.__class__.__name__
        print(class_name, "destroyed")

pt1 = Point()
pt2 = pt1
pt3 = pt1
print(id(pt1), id(pt2), id(pt3))
del pt1
del pt2
del pt3

Data Hiding in Python

To hide object attributes from outside access, prefix names with double underscores. Such attributes are name-mangled and can be accessed as object._className__attrName.

Example of Data Hiding

class JustCounter:
    __secretCount = 0
   
    def count(self):
        self.__secretCount += 1
        print(self.__secretCount)

counter = JustCounter()
counter.count()
counter.count()
# print(counter.__secretCount)  # Raises AttributeError
print(counter._JustCounter__secretCount)

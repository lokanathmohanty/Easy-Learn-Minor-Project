Multi-dimensional Arrays in C

A one-dimensional array uses a single index. When arrays have more than one index, they are called multi-dimensional arrays. In C, you can declare two-dimensional or even higher-dimensional arrays by adding additional index brackets.

Multi-dimensional arrays are essentially arrays of arrays, allowing data to be stored in structured layouts like tables, matrices, or grids.

Declaration of Multidimensional Arrays

Syntax:

type name[size1][size2]...[sizeN];

Example (3D Array):

int threedim[3][3][3];

You can create arrays with as many dimensions as needed, though 2D and 3D are the most common in practice.

Two-dimensional Array in C

A 2D array is an array of 1D arrays. Think of it as a matrix with rows and columns.

Example Declaration and Initialization:

int arr[3][5] = {
   {1,2,3,4,5},
   {10,20,30,40,50},
   {5,10,15,20,25}
};

This forms a matrix:

1    2    3    4    5
10   20   30   40   50
5    10   15   20   25

The element at row index 1 and column index 2 is 30.

Example: Print Elements of a 2D Array

#include <stdio.h>
int main() {
   int a[5][2] = { {0,0}, {1,2}, {2,4}, {3,6}, {4,8}};
   int i, j;
   for (i = 0; i < 5; i++) {
      for (j = 0; j < 2; j++) {
         printf("a[%d][%d] = %d\n", i, j, a[i][j]);
      }
   }
   return 0;
}

Output:

a[0][0] = 0
a[0][1] = 0
a[1][0] = 1
a[1][1] = 2
...
a[4][1] = 8

Example: Print 2D Array as Matrix

#include <stdio.h>

int main() {
   int arr[3][5] = {
      {1,2,3,4,5},
      {10,20,30,40,50},
      {5,10,15,20,25}
   };
   int i, j;
   for (i = 0; i < 3; i++) {
      for (j = 0; j < 5; j++) {
         printf("%4d", arr[i][j]);
      }
      printf("\n");
   }
   return 0;
}

Output:

   1   2   3   4   5
  10  20  30  40  50
   5  10  15  20  25

Three-dimensional Array in C

A 3D array is an array of 2D arrays. Each element of a 3D array is accessed using three indices: arr[depth][row][column].

Example scenario: student seating across 5 halls, each with 20 rows and 5 columns.

Example: Print 3D Array

#include <stdio.h>

int main() {
   int i, j, k;
   int arr[3][3][3] = {
      {
         {11,12,13},
         {14,15,16},
         {17,18,19}
      },
      {
         {21,22,23},
         {24,25,26},
         {27,28,29}
      },
      {
         {31,32,33},
         {34,35,36},
         {37,38,39}
      }
   };

   printf("Printing 3D Array Elements\n");
   for(i=0; i<3; i++) {
      for(j=0; j<3; j++) {
         for(k=0; k<3; k++) {
            printf("%4d", arr[i][j][k]);
         }
         printf("\n");
      }
      printf("\n");
   }
   return 0;
}

Output:

  11  12  13
  14  15  16
  17  18  19

  21  22  23
  24  25  26
  27  28  29

  31  32  33
  34  35  36
  37  38  39

Row-wise Sum of a 2D Array

#include <stdio.h>

int main() {
   int arr[3][5] = {
      {1, 2, 3, 4, 5},
      {10, 20, 30, 40, 50},
      {5, 10, 15, 20, 25}
   };
   int i, j, sum;

   for (i = 0; i < 3; i++) {
      sum = 0;
      for (j = 0; j < 5; j++) {
         sum += arr[i][j];
      }
      printf("Sum of row %d: %d\n", i, sum);
   }

   return 0;
}

Output:

Sum of row 0: 15
Sum of row 1: 150
Sum of row 2: 75

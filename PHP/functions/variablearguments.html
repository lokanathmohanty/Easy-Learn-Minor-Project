PHP Variable Arguments (Variadic Functions)

A **Variable Argument** list, or **Variadic Function**, in PHP is a function capable of accepting a dynamic, **variable number of arguments**. This functionality can be implemented using the **splat operator (`...`)** (PHP 5.6+) or older built-in functions.

1. Using the Splat Operator (`...`) - Recommended

The most modern and recommended way is to prepend the parameter name with the **three dots (`...`)** operator. This automatically collects all the passed arguments into a single **indexed array**.

Syntax and Example

**Syntax:**
function myfunction(**...$arg**) { /* $arg is an array */ }

**Example: Calculating Average**
function myfunction(**...$numbers**) {
   $avg = array_sum($numbers) / count($numbers);
   return $avg;
}
myfunction(5, 12, 9, 23, 8); $\rightarrow$ **11.4**

Combining Positional and Variable Arguments

The variable argument must be the **last** parameter in the function definition. Any arguments passed before it are treated as normal **positional arguments**.

function myfunction($x, **...$numbers**) { /* ... */ }
myfunction(**5**, 12, 9, 23, 8, 41);

Here, $x$ gets the value 5, and $numbers$ is an array: [12, 9, 23, 8, 41].

2. Using Built-in Functions (Legacy)

Prior to PHP 5.6, the following built-in functions were used to manually access the argument list. They are still available but less clean than the `...` operator.

Function Description
**`func_num_args()`** Returns the total number of arguments passed to the function.
**`func_get_arg($index)`** Returns the value of a single argument at the specified zero-based index.
**`func_get_args()`** Returns an **indexed array** containing all the arguments passed to the function.

Example using `func_get_args()`

function myfunction() {
   $sum = 0;
   foreach (func_get_args() as $n) {
      $sum += $n;
   }
   return $sum;
}
echo myfunction(5, 12, 9, 23, 8, 41); $\rightarrow$ **98**

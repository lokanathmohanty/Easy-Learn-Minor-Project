Java Teeing Collectors (Java 12+)

The Collectors.teeing() Method

The static **Collectors.teeing()** method, introduced in **Java 12**, is a powerful collector that allows you to perform **two independent downstream collection operations** on the same stream elements and then combine their results using a third function.

The term "teeing" is inspired by a T-junction pipe, where the stream of elements is split into two separate paths (downstream collectors) and the final results are merged back together.

Syntax and Components

public static <T, R1, R2, R> Collector<T, ?, R> teeing(
   Collector<? super T, ?, R1> downstream1, 
   Collector<? super T, ?, R2> downstream2, 
   BiFunction<? super R1, ? super R2, R> merger)
  1. downstream1 (Collector $\rightarrow$ $R1$): The first collector applied to the stream elements. It processes the elements and produces an intermediate result $R1$.
  2. downstream2 (Collector $\rightarrow$ $R2$): The second collector, applied independently to the same stream elements, producing an intermediate result $R2$.
  3. merger (BiFunction $R1, R2 \rightarrow R$): A **BiFunction** that takes the two results ($R1$ and $R2$) from the downstream collectors and combines, processes, or merges them into the final desired result $R$.

Example: Calculating the Mean (Average)

A classic use case for teeing() is calculating the mean of a stream, which requires finding both the sum and the count in a single pass.

The downstream1 computes the sum, downstream2 computes the count, and the merger computes the division.

double mean = Stream.of(1, 2, 3, 4, 5, 6, 7)
    .collect(Collectors.teeing(
       // Downstream 1: Calculates the sum (R1 is Double)
       Collectors.summingDouble(i -> i), 

       // Downstream 2: Calculates the count (R2 is Long)
       Collectors.counting(), 

       // Merger Function: Takes (sum, count) and returns (sum / count)
       (sum, n) -> sum / n
    ));

System.out.println(mean); // Output: 4.0

Example: Finding Min and Max in a Single Pass

This demonstrates using teeing() to find two distinct values (Min and Max Student objects) and mapping them into a HashMap as the final result.

// ... list of Student objects ...

HashMap<String, Student> result = students.stream().collect(
    Collectors.teeing(
        // Downstream 1: Finds the Student with the highest marks (R1 is Optional)
        Collectors.maxBy(Comparator.comparing(Student::getMarks)),

        // Downstream 2: Finds the Student with the lowest marks (R2 is Optional)
        Collectors.minBy(Comparator.comparing(Student::getMarks)),

        // Merger Function: Maps both Optional results into a HashMap (R is HashMap)
        (s1, s2) -> {
            HashMap<String, Student> map = new HashMap<>();
            // Optional.get() is safe here because maxBy/minBy only return Optional.empty() for an empty stream.
            map.put("Highest", s1.get()); 
            map.put("Lowest", s2.get());
            return map;
        }
    )
);

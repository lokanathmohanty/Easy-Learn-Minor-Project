PHP Sessions and the `$_SESSION` Superglobal

A **Session** in PHP is a mechanism to make data persistently available across multiple pages during a single user visit (a "session"). Because the HTTP protocol is **stateless**, sessions overcome this limitation by storing data server-side and linking it to the user via a unique **Session ID**. The primary interface for this data is the **`$_SESSION`** superglobal associative array.

How to Use PHP Sessions

1. Start or Resume the Session 🚀

The **`session_start()`** function is mandatory and must be called at the very beginning of every script that intends to use `$_SESSION`. This function either creates a new session file on the server or resumes the existing one using the user's Session ID (usually sent via a cookie).

<?php
   **session_start();**
   // All code below can now access $_SESSION
?>

2. Create and Access Session Variables

Session data is stored as key-value pairs in the `$_SESSION` array, similar to any other associative array. This data is stored in a temporary file on the server.

**Create/Set:**
$_SESSION['UserID'] = $user_id;
$_SESSION['CartCount'] = 5;

**Read/Use (on any subsequent page):**
echo "Welcome back, User ID: " . **$_SESSION['UserID']**;

3. Delete Session Variables

You have two options for clearing session data:

  • **Remove Specific Variable:** Use **`unset()`** to remove a single variable from the array.
    unset($_SESSION['UserID']);
  • **Destroy the Entire Session:** Use **`session_destroy()`** to destroy all data registered to the current session and remove the session file from the server.
    session_destroy();

*Note: The session ends when the user's connection terminates, the session times out, or when `session_destroy()` is manually called.*

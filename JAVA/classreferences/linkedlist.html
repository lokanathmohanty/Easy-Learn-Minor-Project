Java LinkedList Class Summary 🔗🔗

The **java.util.LinkedList** class is an implementation of the **List** and **Deque** interfaces. It uses a **doubly-linked list** data structure, where each element (node) stores a reference to both the **next** element and the **previous** element.

I. Core Characteristics and Roles

LinkedList's structure allows it to efficiently fulfill three primary roles in the Collections Framework:

  • List (Sequence): Allows access by index and maintains insertion order.
  • Queue (FIFO): Supports First-In, First-Out operations via methods like offer() and poll().
  • Deque (Double-Ended Queue): Supports element insertion and removal at **both the beginning and the end**, making it suitable for both FIFO queues and LIFO stacks.

II. Performance and Big O Notation

The linked structure dictates its performance profile, contrasting sharply with `ArrayList`:

Operation Complexity Reason
**Insertion/Deletion (at ends)** (addFirst, addLast, removeFirst, removeLast) $O(1)$ Only requires updating the head/tail reference pointers.
**Random Access** (get(int index)) $O(n)$ The list must be traversed from the closest end (head or tail) to reach the $n^{th}$ element.
**Insertion/Deletion (in middle)** (add(index, E), remove(index)) $O(n)$ Requires $O(n)$ time to first find the element by index, followed by $O(1)$ time to update the pointers.

III. Deque and Stack/Queue Methods

The LinkedList provides a comprehensive set of methods to serve as a queue or a stack, often using method aliases for clarity:

Queue / Deque Role Stack Role (LIFO) General Access
offer(E e) / addLast(E e) (Insert to tail) push(E e) (Insert to head) add(E e) (Appends to end)
poll() / removeFirst() (Remove from head) pop() (Remove from head) get(int index)
peek() / peekFirst() (Examine head) — getFirst() / getLast()

Conclusion on Usage

Choose **LinkedList** when you anticipate frequent element **insertions or deletions at the beginning or end** of the list (e.g., when implementing a queue, stack, or stream processing). Choose **ArrayList** when you anticipate frequent **random access** (getting elements by index).

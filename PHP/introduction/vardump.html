PHP Variable Handling: The `var_dump()` Function

The **`var_dump()`** function is a key debugging tool in PHP used to display **structured information** about one or more expressions or variables. It shows the **data type** and **value** in detail.

Key Features and Syntax

  • **Purpose:** To output detailed, human-readable information about a variable's structure, including its type, value, length (for strings), and recursive structure (for arrays and objects).
  • **Return Value:** It returns **nothing** (`void`); it simply prints the information directly to the output stream.
  • **Object/Array Handling:** It properly **indents** the output to show the recursive structure of arrays and objects, including the visibility of object properties (public, private, protected).
  • **Syntax:**
    void var_dump ( mixed $value, mixed ...$values )

Examples of `var_dump()` Output

1. Basic Types (Integer, Float, String)

For built-in scalar types, it shows the type name and value. For strings, it also shows the length.

<?php $x = 10; var_dump($x); ?>
Output: int(10)

<?php $x = "Hello World"; var_dump($x); ?>
Output: string(11) "Hello World"

2. Arrays (Indexed and Associative)

It displays the array size and the detailed information for each element, including its index/key, type, and value.

<?php $x = array("Hello", false, 99.99, array(10, 20)); var_dump($x); ?>

array(4) {
  [0]=>
  string(5) "Hello"
  [1]=>
  bool(false)
  [3]=>
  array(2) {
    [0]=>
    int(10)
  }
}

3. Objects

It shows the object's class name, a unique object handle (`#1`), the number of properties, and detailed information about each property, including its access modifier (e.g., `private`).

// Assuming $p is an instance of class Point with private properties $x=4, $y=5
var_dump($p);

object(Point)#1 (2) {
  ["x":"Point":private]=>
  int(4)
  ["y":"Point":private]=>
  int(5)
}

Java Programming: Inner Class Specialization

Session: Anonymous Inner Classes

What is an Anonymous Inner Class? 👻

An **Anonymous Inner Class** is a **nameless inner class** that is declared and instantiated at the same time. Since it has no name, it **cannot have a constructor**.

Anonymous classes are used to create a simple class that is required only **once** for a specific, immediate purpose, such as overriding a method or implementing an interface.

Syntax and Declaration

The syntax uses the new operator followed by the name of the class or interface it is extending/implementing, immediately followed by the class body {}:

new ClassOrInterfaceName(argument-list) {
   // Anonymous class body: 
   // - Overridden methods
   // - Fields (if any)
}

The type of the resulting object is typically a subtype of the `ClassOrInterfaceName`.

Types and Usage

1. Anonymous Class that Extends a Class

Used to quickly extend a concrete or abstract class and override one or more of its methods on-the-fly. The reference type is the **parent class**.

class Car { public void engineType() { ... } }
// Create an object of an anonymous subclass of Car
Car c2 = new Car() {
   @Override
   public void engineType() {
      System.out.println("V2 Engine"); // Provides a unique, one-off implementation
   }
};

2. Anonymous Class that Implements an Interface

Used to provide a quick, single-use implementation of an interface, often for a functional task (before Java 8 Lambda expressions). The reference type is the **interface**.

interface Software { public void develop(); }

Software s = new Software() {
   @Override
   public void develop() {
      System.out.println("Software Developed in Java");
   }
};

3. Anonymous Class as a Method Argument

This is a very common use case, where the entire anonymous class declaration is passed directly into a method call that requires an interface or abstract class object. It keeps the code extremely concise.

class Vehicle {
   public void transport(Engine e) { // Accepts an Engine abstract object
      e.engineType();
   }
}

// Pass an anonymous subclass of Engine directly to the method:
v.transport(new Engine() {
   @Override
   public void engineType() {
      System.out.println("Turbo Engine");
   }
});

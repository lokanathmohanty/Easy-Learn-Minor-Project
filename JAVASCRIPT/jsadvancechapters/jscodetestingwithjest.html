JavaScript - Code Testing with Jest

Overview

Testing your code ensures better reliability and maintainability. Jest is a popular testing framework that helps identify errors early. It is widely used in applications built with Node.js, React, Angular, and Vue.js. In this session, you will explore Jest’s features, setup, and examples of writing different types of tests.

Learning Objectives

  • Understand what Jest is and its role in JavaScript testing.
  • Identify the key features that make Jest powerful and efficient.
  • Set up Jest in a Node.js project.
  • Write synchronous, asynchronous, and mock tests using Jest.

What is Jest?

The Jest framework was created by Facebook to simplify testing in JavaScript and TypeScript projects. It integrates seamlessly with popular frameworks like React, Angular, and Vue.js. Jest focuses on speed, adaptability, and providing built-in tools to make testing easier. Key strengths include zero configuration, mocking support, and snapshot testing.

Features of Jest

  • Zero Config: Minimal setup required to start testing. A configuration file can be added for customization.
  • Snapshots: Capture and compare saved snapshots to verify functionality consistency.
  • Isolated Testing: Tests run in parallel to save time and reduce conflicts.
  • Mocking Support: Easily create mock functions to test how code interacts with other components.

Setting Up Jest

  • Step 1: Initialize a project

    Navigate to your project folder and run:

    npm init -y

  • Step 2: Install Jest

    Run the following command:

    npm install --save-dev jest

  • Step 3: Configure package.json

    Add the following line in the scripts section:

    "scripts": { "test": "jest" }

  • Step 4: Run tests

    Use the command:

    npm test

Example 1 — Synchronous Test

Create a simple function and test it.

sum.js

function sum(a, b) { return a + b; } module.exports = sum;

sum.test.js

const sum = require('./sum'); test('adds 1 + 2 to equal 3', () => { expect(sum(1, 2)).toBe(3); });

Running npm test will confirm the function returns the correct result.

Example 2 — Asynchronous Test

Jest supports asynchronous code using async/await.

fetchData.js

async function fetchData() { return 'freeCodeCamp'; } module.exports = fetchData;

fetchData.test.js

const fetchData = require('./fetchData'); test('the data is freeCodeCamp', async () => { const data = await fetchData(); expect(data).toBe('freeCodeCamp'); });

Here, Jest waits for the promise to resolve before checking the result.

Example 3 — Mock Function

Mock functions simulate code behavior without using real implementations.

const myMockFunction = jest.fn(x => x + 42); test('mock function test', () => { expect(myMockFunction(0)).toBe(42); });

In this example, jest.fn() creates a function that always adds 42 to its input, making testing predictable.

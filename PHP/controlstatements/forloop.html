PHP `for` Loop

The **`for`** statement is a fundamental control flow construct in PHP used to execute a statement or block of statements a **specified number of times**. It is ideal when the number of iterations is known before the loop begins.

`for` Loop Syntax and Components

The `for` loop is defined by three expressions separated by semicolons, followed by the loop body:

for (expr1; expr2; expr3) { code to be executed; }
  1. **`expr1` (Initialization):** Executed **once** at the very start of the loop. Typically used to initialize the loop counter (e.g., `$i = 1`).
  2. **`expr2` (Condition):** Evaluated at the **beginning** of *each* iteration. If it evaluates to `true`, the loop continues; if `false`, the loop terminates.
  3. **`expr3` (Increment/Decrement):** Executed at the **end** of *each* iteration. Typically used to update the counter variable (e.g., `$i++` or `$i--`).

Basic `for` Loop Examples

Simple Incrementing Loop

This loop runs 10 times, incrementing `$i` from 1 to 10.

for ($i=1; $i<=10; $i++) { echo "Iteration No: $i \n"; }

Output (Partial): Iteration No: 1 ... Iteration No: 10

Decrementing Loop

The loop counter is initialized to a large value and decremented until the condition fails.

for ($i=10; $i>=1; $i--) { echo "Iteration No: $i \n"; }

Output: Iteration No: 10 ... Iteration No: 1

Alternative Syntax (`for: endfor;`)

Similar to `if/else`, the `for` loop supports an alternative syntax using a colon (`:`) to open the block and the `endfor;` keyword to close it.

for ($i=1; $i<=10; $i++): echo "Iteration No: $i \n"; endfor;

Iterating Over Arrays and Strings

Iterating Indexed Arrays

The `for` loop is the traditional method for accessing indexed array elements by their numerical position, often using the `count()` function to determine the loop limit.

$numbers = array(10, 20, 30, 40, 50);
for ($i=0; $i<count($numbers); $i++) { echo "numbers[$i] = $numbers[$i] \n"; }

Output: numbers[0] = 10 ...

Iterating Strings

A PHP string can be treated as an array of characters, allowing the `for` loop and `strlen()` to iterate through its characters.

$str = "Hello";
for ($i=0; $i<strlen($str); $i++) { echo "$str[$i]"; } $\rightarrow$ H e l l o

Nested `for` Loops

When one `for` loop is placed inside another, they are **nested**. The inner loop completes all its iterations for every single iteration of the outer loop. This is commonly used for grid, table, or pattern generation.

for ($i=1; $i<=2; $i++) {
   for ($j=1; $j<=2; $j++) {
      echo "i= $i j= $j \n";
   }
}

Output: i= 1 j= 1 \n i= 1 j= 2 \n i= 2 j= 1 \n i= 2 j= 2

R - Histograms

A histogram displays the frequencies of values of a variable grouped into continuous ranges (or bins). Each bar represents the number of data points that fall within that range. Unlike bar charts, histograms show distribution by ranges rather than individual categories.

Basic Syntax

hist(v, main, xlab, xlim, ylim, breaks, col, border)
  • v: Numeric vector for histogram values
  • main: Title of the chart
  • xlab: X-axis label
  • xlim: Range on X-axis
  • ylim: Range on Y-axis
  • breaks: Number or width of bins
  • col: Color of bars
  • border: Border color for bars

Simple Histogram Example

# Create data vector
v <- c(9, 13, 21, 8, 36, 22, 12, 41, 31, 33, 19)

png(file = "histogram.png")
hist(v, xlab = "Weight", col = "yellow", border = "blue")
dev.off()

Setting Range and Breaks

# More control over X/Y axis and bins
v <- c(9, 13, 21, 8, 36, 22, 12, 41, 31, 33, 19)

png(file = "histogram_lim_breaks.png")
hist(v, xlab = "Weight", col = "green", border = "red", xlim = c(0, 40), ylim = c(0, 5), breaks = 5)
dev.off()

These examples show how to make and customize histograms, set color and axis ranges, and define bin widths in R.

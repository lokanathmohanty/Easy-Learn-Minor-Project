ReactJS - Component Collection

In modern applications, developers often need to render a list of items (e.g., todos, orders, invoices) in tabular or gallery format. React provides clear and simple techniques to build list-based UIs using two main features:

  • JavaScript's built-in map() method
  • React expressions in JSX

Map Method

The map() function accepts a collection and applies a mapping function to each item, returning a new list.

Example: Doubling Numbers

let list = [10, 30, 45, 12, 24];
let result = list.map((input) => input * 2);
console.log(result); // [20, 60, 90, 24, 48]

Example: React Expression

var hello = <h1>Hello!</h1> 
var final = <div>{hello}</div>

// Output: <div><h1>Hello!</h1></div>

ExpenseEntryItemList Component

Let’s apply the map() function to build a component that renders a collection of expense entry items in a table format.

Example: ExpenseEntryItemList.js

import React from 'react';
import './ExpenseEntryItemList.css';

class ExpenseEntryItemList extends React.Component {
  constructor(props) {
    super(props);
  }
  render() {
    const lists = this.props.items.map((item) =>
      <tr key={item.id}>
        <td>{item.name}</td>
        <td>{item.amount}</td>
        <td>{new Date(item.spendDate).toDateString()}</td>
        <td>{item.category}</td>
      </tr>
    );

    return (
      <table>
        <thead>
          <tr>
            <th>Item</th>
            <th>Amount</th>
            <th>Date</th>
            <th>Category</th>
          </tr>
        </thead>
        <tbody>
          {lists}
        </tbody>
      </table>
    );
  }
}

export default ExpenseEntryItemList;

CSS - Multiple Column Layout

CSS provides several properties to design multiple column layouts for webpages. The multiple column layout is commonly used in newspapers, online blogs, books, etc. In this session, we will discuss how to create and style multiple column layouts using HTML and CSS.

CSS Column Rules

In multiple column layouts, we can add rules (lines) between columns using column rule properties:

  • column-rule-style: Defines the style of the line between columns (e.g., solid, dashed).
  • column-rule-color: Sets the color of the line between columns.
  • column-rule-width: Specifies the width (thickness) of the line between columns.
  • column-rule: A shorthand property to set style, color, and width together.

CSS Spanning Columns in Multiple Column Layout

If you want an element, like a heading, to span across all columns, use the column-span property.

  • column-span: all - The element spans over all columns.
  • column-span: none - The element will be placed as part of a single column.

Multiple Column Layout Related Properties

The following table shows all the CSS properties used in multiple column layouts:

  • column-count: Specifies the number of columns.
  • column-fill: Specifies how to fill columns.
  • column-gap: Sets the size of the gap between columns.
  • column-width: Sets the column width.
  • column-rule: Shorthand property for style, color, and width of the rule between columns.
  • column-rule-color: Sets the rule color.
  • column-rule-style: Sets the rule style.
  • column-rule-width: Sets the rule thickness.
  • column-span: Defines if an element spans across all columns or not.

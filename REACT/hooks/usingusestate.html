ReactJS - Using useState

useState is a basic React hook that allows a function component to maintain its own state and re-render when the state changes.

Syntax

const [state, setState] = useState(initialValue)
  • initialValue − Initial value of the state (number, string, array, or object).
  • state − Variable representing the current state value.
  • setState − Function to update the state.

setState Function

setState(valueToBeUpdated)

Example:

// initialize
const [name, setName] = useState('John')

// update
setName('Peter')

Features of useState

  • Function Parameter − Accepts a function to compute the initial state (runs only once). 
    const [val, setVal] = useState(() => {
   let initialValue = null
   // expensive calculation here
   return initialValue
})
  • Verifies Previous Values − Only re-renders if state changes. 
    setName('John') // renders
setName('John') // no re-render (same value)
  • Batched Updates − React batches multiple state updates internally. Use flushSync for immediate updates. 
    flushSync(() => setName('Peter'))

Applying useState

Let’s create a login form with username and password state variables.

LoginForm Component

import { useState } from 'react';

export default function LoginForm() {
   const [username, setUsername] = useState('')
   const [password, setPassword] = useState('')

   let isEmpty = (val) => !val

   let validate = (e) => {
      e.preventDefault()
      if(!isEmpty(username) && !isEmpty(password)) {
         alert(JSON.stringify({ username, password }))
      } else {
         alert("Please enter username / password")
      }
   }

   return (
      <div>
         <form name="loginForm">
            <label htmlFor="username">Username: </label>
            <input 
               id="username" 
               name="username" 
               type="text"
               value={username}
               onChange={(e) => setUsername(e.target.value)} />
            <br />

            <label htmlFor="password">Password: </label>
            <input 
               id="password" 
               name="password" 
               type="password"
               value={password}
               onChange={(e) => setPassword(e.target.value)} />
            <br />

            <button type="submit" onClick={(e) => validate(e)}>Submit</button>
         </form>
      </div>
   )
}

App Component

import './App.css';
import LoginForm from './components/LoginForm';

function App() {
   return (
      <LoginForm />
   );
}

export default App;

Object as State

Unlike class components, hooks replace the entire state object on update. Use the spread operator to preserve other fields. 

// state as object
const [data, setData] = useState({
   username: 'John',
   password: 'secret'
})

// ❌ wrong - overwrites password
setData({ username: 'Peter' })

// ✅ correct - preserve password
setData({ ...data, username: 'Peter' })

LoginFormObject Component

import { useState } from 'react';

export default function LoginFormObject() {
   const [data, setData] = useState({})

   let isEmpty = (val) => !val

   let validate = (e) => {
      e.preventDefault()
      if(!isEmpty(data.username) && !isEmpty(data.password)) {
         alert(JSON.stringify(data))
      } else {
         alert("Please enter username / password")
      }
   }

   return (
      <div>
         <form name="loginForm">
            <label htmlFor="username">Username: </label>
            <input 
               id="username" 
               name="username" 
               type="text"
               value={data.username}
               onChange={(e) => setData({ ...data, username: e.target.value })} />
            <br />

            <label htmlFor="password">Password: </label>
            <input 
               id="password" 
               name="password" 
               type="password"
               value={data.password}
               onChange={(e) => setData({ ...data, password: e.target.value })} />
            <br />

            <button type="submit" onClick={(e) => validate(e)}>Submit</button>
         </form>
      </div>
   )
}

Summary

The useState hook makes it easy to manage state in function components. It works with simple values or complex objects and allows multiple state variables. Updates are batched internally, making state management efficient in React.

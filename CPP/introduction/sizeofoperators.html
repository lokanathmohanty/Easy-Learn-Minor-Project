C++ sizeof Operator 📏

The **sizeof** is a **compile-time unary operator** that determines and returns the size, in **bytes**, of a variable, a data type, or any user-defined type (like a class or structure).

Syntax and Basic Types

The operator can be used in two forms:

sizeof (data type); // Parentheses are required for data types
sizeof variable_name; // Parentheses are optional for variable names

The memory size returned by sizeof is **platform-dependent**, meaning it can vary based on the compiler and operating system architecture. A typical output for fundamental types might look like this:

Data TypeTypical Size (bytes)
char1
short int2
int4
long int4 or 8
float4
double8
wchar_t2 or 4

Advanced Use Cases

1. Finding Array Length

The sizeof operator is commonly used to dynamically determine the number of elements in a locally defined array without hardcoding the count. This is a crucial technique for arrays passed to functions, as sizeof returns the size of the pointer, not the array itself.

int scores[] = {85, 90, 78, 92, 88}; // Total size: 20 bytes (5 elements * 4 bytes/int)

int totalSize = sizeof(scores);
int elementSize = sizeof(scores[0]);

// Length is calculated by dividing the total array size by the size of one element.
int length = totalSize / elementSize; // 20 / 4 = 5

2. Size of Classes/Structs

When applied to a class or structure, sizeof returns the total memory occupied by an object of that type. This size may be greater than the sum of its member variables due to **memory padding** (or *alignment*), which the compiler adds to optimize access speeds.

class Student {
    int rollNumber; // 4 bytes
    double marks;   // 8 bytes
    // Total may be 16 bytes due to padding for the double alignment.
};

// Output: Size of Student class: 16 bytes

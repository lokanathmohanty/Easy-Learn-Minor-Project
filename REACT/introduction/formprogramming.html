ReactJS - Form Programming

Forms are a common part of web applications which are mainly used to allow users to interact with the application. These forms may be included on the web page to gather user information, to let the user search a website, to make payments, etc. The basic elements a form can contain are input fields, buttons, checklists, drop-down menus and so on. The data obtained from these forms is usually handled by components in React.

To learn how to use forms in React, let us look at some examples.

Form Programming

Unlike HTML where forms get updated based on user input data, React updates the form with the help of its state. The mutable state is typically specified in the state property of components, and is only updated using setState().

The nature of form programming needs the state to be maintained because the input field information will change as the user interacts with the form. React library does not store or maintain any state information by itself and the component has to use state management API to manage state.

Considering this, React provides two types of components to support form programming:

  • Controlled component − React provides a special attribute value for all input elements and controls the input elements. The value attribute can be used to get and set the value of the input element. It must be in sync with state of the component.
  • Uncontrolled component − React provides minimal support for form programming. It has to use Ref concept (another React concept to get a DOM element in the React component during runtime) to handle form programming.

Let us learn form programming using both controlled and uncontrolled components in this chapter.

Controlled Component

In controlled components, the form data is handled by the React component state. Input values are always driven by this.state, and updated through setState(). This ensures React is the single source of truth for the form data.

Uncontrolled Component

In uncontrolled components, form data is handled by the DOM itself rather than React state. To access the values, Refs are used. This approach is simpler but less powerful compared to controlled components.

Formik

Formik is a popular third-party library for building and managing forms in React. It simplifies handling form state, validation, and submission, making it easier to implement both controlled and uncontrolled form behaviors with less boilerplate code.

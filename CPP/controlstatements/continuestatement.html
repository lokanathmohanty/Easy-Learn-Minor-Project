C++ continue Statement (Skip Current Iteration) ⏭️

The **continue statement** is a loop control statement that forces the current iteration of a loop to stop and immediately jumps to the next iteration, skipping any remaining code within the loop body for that iteration.

Mechanism by Loop Type

When continue is executed, control flow is altered as follows:

  • **for Loop:** Control immediately jumps to the **increment/decrement** step, followed by the conditional test.
  • **while and do...while Loops:** Control immediately jumps to the **conditional test** at the end (for do...while) or beginning (for while) of the loop.

Example Analysis: Skipping 15

In the provided do...while example, the loop iterates from $a=10$ up to $a=19$. The continue statement ensures that the value 15 is skipped:

do {
    if( a == 15) { 
        a = a + 1; // Crucial: 'a' is incremented to 16 here.
        continue; // Skips the 'cout' line below for a=15.
    }
    cout << "value of a: " << a << endl; // This line is skipped when a=15.
    a = a + 1;
} while( a < 20 );

When $a=15$, the if condition is true. $a$ is incremented to **16**, and continue is hit, skipping the `cout` statement. The loop then checks the condition $16 < 20$ and proceeds to the next iteration, where $16$ is printed.

continue vs. break

These two control statements serve fundamentally different purposes:

  • **continue:** **Skips** the remainder of the **current iteration** and proceeds to the next iteration of the loop. It does **not** terminate the loop.
  • **break:** **Immediately terminates** the entire loop (or switch) and transfers control to the statement immediately following the loop.

Use Cases for continue

The continue statement is useful for:

  • **Data Filtering:** Skipping invalid or unwanted data records during processing.
  • **Optimizing Calculations:** Avoiding complex or redundant computations when a simple check determines they are unnecessary for the current iteration.
  • **Handling Special Cases:** Bypassing standard processing logic for specific, non-critical values within a loop.

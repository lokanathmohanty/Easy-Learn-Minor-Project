JavaScript - Type Conversions

Type Conversions in JavaScript refer to the automatic or explicit process of converting data from one data type to another. These conversions are essential for JavaScript to perform operations and comparisons effectively, as JavaScript is a weakly typed language.

There are two types of type conversion in JavaScript:

  • Implicit Type Conversion (Coercion)
  • Explicit Type Conversion

Implicit Type Conversion

When type conversion is done automatically by JavaScript, it is called implicit type conversion. For example, when using the + operator with a string and a number, JavaScript converts the number to a string and concatenates.

Converting to String (Implicit)

"100" + 24;      // "10024"
"100" + false;   // "100false"
"100" + null;    // "100null"
"100" + undefined; // "100undefined"

Converting to Number (Implicit)

'100' / 50;     // 2
'100' - '50';   // 50
'100' * true;   // 100
'100' - false;  // 100
'tp' / 50;      // NaN

Converting to Boolean (Implicit)

!!0;       // false
!!1;       // true
!!"";      // false
!!"Hello"; // true

Null to Number (Implicit)

100 + null; // 100
100 * null; // 0

Undefined with Number/Boolean (Implicit)

100 + undefined;   // NaN
false * undefined; // NaN

Explicit Type Conversion

When a programmer manually converts values between types using built-in functions or methods, it is called explicit type conversion.

Converting to String (Explicit)

String(100);   // "100"
String(null);  // "null"
String(true);  // "true"

const num = 100;
num.toString(); // "100"

Converting to Number (Explicit)

Number("200");     // 200
Number("1000e-2"); // 10
Number(false);     // 0
Number(null);      // 0
Number(undefined); // NaN
+"200";            // 200

parseInt("42");    // 42
parseFloat("3.14");// 3.14

Converting to Boolean (Explicit)

Boolean(100);  // true
Boolean(0);    // false
Boolean("");   // false
Boolean("Hi"); // true
Boolean(null); // false

Converting Date to String/Number

let date = new Date();

Number(date);      // Numeric timestamp
date.getTime();    // Numeric timestamp

String(date);      // String date
date.toString();   // String date

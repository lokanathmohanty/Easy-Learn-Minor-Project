Python - CGI Programming

CGI (Common Gateway Interface) defines how web servers communicate with external programs like Python scripts.

CGI scripts generate dynamic web content and interact with web servers via standard input/output.

Web servers execute CGI scripts typically placed in a special cgi-bin directory.

Basic CGI Script Example

#!/usr/bin/python3
print("Content-type:text/html\r\n\r\n")
print("<html>")
print("<head><title>Hello World</title></head>")
print("<body>")
print("<h2>Hello World! This is my first CGI program</h2>")
print("</body>")
print("</html>")

Make the script executable with chmod 755 hello.py. Access via http://localhost/cgi-bin/hello.py.

HTTP Headers in CGI

CGI scripts must first output HTTP headers before content, commonly:

Content-type: text/html\r\n\r\n

Other headers include “Expires”, “Location”, “Set-Cookie”, etc.

Common CGI Environment Variables

  • QUERY_STRING: URL-encoded data from GET request
  • REQUEST_METHOD: HTTP method used (GET or POST)
  • CONTENT_TYPE: Type of data sent by client
  • REMOTE_ADDR: Client’s IP address
  • HTTP_COOKIE: Cookies from client
  • ... and more variables useful for request handling and server info

Handling Form Data with cgi Module

Using the cgi module to access GET or POST data via FieldStorage.

import cgi, cgitb
form = cgi.FieldStorage()
first_name = form.getvalue('first_name')
last_name = form.getvalue('last_name')

print("Content-type:text/html\r\n\r\n")
print("<html><body>")
print(f"<h2>Hello {first_name} {last_name}</h2>")
print("</body></html>")

Supports both GET and POST methods.

Handling Checkboxes, Radio Buttons, Textarea, and Drop-downs

  • Checkboxes: Use form.getvalue('checkbox_name') to check if selected (value or None).
  • Radio Buttons: Retrieve selected option via form.getvalue('radio_name').
  • Text Area: Multi-line text retrieved with form.getvalue('textarea_name').
  • Drop-down Box: Selected option via form.getvalue('select_name').

Using Cookies in CGI

Cookies are key-value pairs stored on the client to maintain state between requests.

Set cookies via HTTP header before content:

print("Set-Cookie: UserID=XYZ;\r\n")
print("Content-type:text/html\r\n\r\n")

Retrieve cookies from HTTP_COOKIE environment variable.

File Upload via CGI

Use HTML form with enctype="multipart/form-data" and input type file:

<form enctype="multipart/form-data" action="/cgi-bin/save_file.py" method="post">
  <input type="file" name="filename" />
  <input type="submit" value="Upload" />
</form>

In CGI script, handle upload:

import cgi, os
form = cgi.FieldStorage()
fileitem = form['filename']

if fileitem.filename:
    fn = os.path.basename(fileitem.filename)
    with open('/tmp/' + fn, 'wb') as f:
        f.write(fileitem.file.read())
    message = f'The file "{fn}" was uploaded successfully'
else:
    message = 'No file was uploaded'

print("Content-Type: text/html\n")
print(f"<html><body><p>{message}</p></body></html>")

Forcing File Download via CGI

To prompt file download dialog, use the following HTTP headers:

print("Content-Type: application/octet-stream; name=\"FileName\"\r\n")
print("Content-Disposition: attachment; filename=\"FileName\"\r\n\n")

with open("foo.txt", "rb") as fo:
    data = fo.read()
    print(data)

Send file content after headers to trigger download.

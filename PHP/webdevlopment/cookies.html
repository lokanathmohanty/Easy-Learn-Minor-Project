PHP - Managing HTTP Cookies

Cookies: A Mechanism for State Management

The HTTP protocol is **stateless**, meaning it doesn't inherently remember past requests. **Cookies** are small pieces of data included by the server in its response to the client. The client (browser) stores this data (typically as text files) and includes it in subsequent requests to the server, allowing the application to maintain a sense of a user's prior activity or identity.

Setting Cookies with $\text{setcookie()}$

PHP uses the **$\text{setcookie()}$** function to send a $\text{Set-Cookie}$ HTTP header to the client. This function *must* be called before any actual HTML output is sent to the browser.

Syntax and Parameters

setcookie(name, value, expire, path, domain, security);
  • $\text{name}$ and $\text{value}$: The required key-value pair of the cookie.
  • $\text{expire}$: A future Unix timestamp (seconds since $\text{1970-01-01}$). If omitted, the cookie is a "session cookie" and expires when the browser closes.
  • $\text{path}$: The server path for which the cookie is valid. $\text{/}$ makes it valid for the entire domain.
  • $\text{security}$ (or $\text{secure}$): If set to $\text{1}$ (or $\text{true}$), the cookie is only sent over $\text{HTTPS}$.

Example: Accessing, Setting, and Deleting Cookies

Accessing Cookies

Cookies sent by the client are populated into the PHP superglobal array **$\text{\$_COOKIE}$**. You can also use the older $\text{\$HTTP\_COOKIE\_VARS}$ array.

<?php
    if (isset($_COOKIE["username"])) {
        echo "Welcome back, " . $_COOKIE["username"] . "!";
    } else {
        echo "Sorry... Not recognized";
    }
?>

Setting a Simple Cookie

The following PHP snippet sets a cookie named "$\text{username}$" with the value "$\text{MohanKumar}$".

<?php
    if (!isset($_COOKIE['username'])) {
        // Sets a cookie that expires when the browser is closed (session cookie)
        setcookie("username", "MohanKumar");
        echo "<h3>Cookie username is now set</h3>";
    } else {
        echo "<h3>Cookie username already set: " . $_COOKIE['username'] . "</h3>";
    }
?>

Deleting Cookies

To delete a cookie, call $\text{setcookie()}$ with the same name, but set the $\text{expire}$ time to a point in the **past**.

<?php
    // Sets the cookie expiration to one hour ago (3600 seconds)
    setcookie("username", "", time() - 3600);
    echo "<h3>Cookie username is now removed</h3>";
?>

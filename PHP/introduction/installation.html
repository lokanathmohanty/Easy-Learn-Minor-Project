PHP Installation Methods Summary

To fully develop **PHP applications** (especially those involving web servers and databases), installing a local PHP environment is necessary. While **online PHP compilers** are useful for learning the basics, advanced features require a full setup.

The Three Vital Components (Manual Installation)

To run PHP web pages, you must install and configure three components:

  • **Web Server:** Processes requests. Most common is the free **Apache Server**.
  • **Database:** Stores and retrieves data. The most commonly used free option is **MySQL** (or its fork, **MariaDB**).
  • **PHP Parser:** The engine that executes PHP script instructions and generates HTML output.

**Note:** Manually installing and configuring these components is complex, especially for beginners.

Recommended Method: All-in-One Packages (XAMPP)

The easiest way to install a full PHP environment is by using an **all-in-one packaged distribution** that contains precompiled binaries for Apache, MySQL, and PHP.

XAMPP Overview (Cross-Platform)

**XAMPP** is the most popular package, created by Apache Friends. The acronym stands for:

  • **X** - Cross-platform (Windows, Linux, OS X)
  • **A** - Apache
  • **M** - MariaDB (a functional equivalent of MySQL)
  • **P** - PHP
  • **P** - Perl

Installation and Management (Linux Example)

The installation is wizard-based on Windows and uses simple command-line steps on Linux:

  1. **Install:** Change permissions (`chmod 755`) and run the installer (`sudo ./xampp-linux-*-installer.run`). XAMPP is installed in the `/opt/lampp` directory.
  2. **Start:** Use the command `sudo /opt/lampp/lampp start`.
  3. **Stop:** Use the command `sudo /opt/lampp/lampp stop`.

A **Control Panel** (GUI tool) is also available on all platforms (e.g., `manager-linux.run` or `manager-osx`) to easily start and stop the Apache and MySQL servers.

Manual Installation Steps (Windows Example)

For a more controlled installation, the following steps detail the process for Windows using the Apache module:

  1. **Download PHP Files:** Get the most recent **PHP x64 Thread Safe ZIP** package.
  2. **Extract Files:** Extract the contents to a folder like `C:\php`.
  3. **Configure `php.ini`:** Copy `php.ini-development` to `php.ini`. Uncomment and set extensions (e.g., `extension=pdo_mysql`) and configure the `[mail function]` section if needed.
  4. **Add to PATH:** Add the `C:\php` directory to the Windows **PATH environment variable** so the PHP executable can be found from any location.
  5. **Configure Apache:** Edit `C:\Apache24\conf\httpd.conf` to load PHP as an Apache module using:

    PHPIniDir "C:/php"
    LoadModule php_module "C:/php/php8apache2_4.dll"
    AddType application/x-httpd-php .php

    Optionally, change `DirectoryIndex` to include `index.php`.
  6. **Test:** Create an `index.php` file in the web root (`C:\Apache24\htdocs`) containing `<?php phpinfo();?>` and access it via the browser (`http://127.0.0.1/index.php`) to confirm the installation.

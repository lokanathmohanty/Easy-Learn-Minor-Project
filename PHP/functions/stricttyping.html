PHP Strict Typing

By default, PHP is a **weakly typed** language, meaning it performs **automatic type casting** (type juggling) on variables whenever possible to match the context of an operation. **Strict Typing** is a feature that overrides this default behavior to prevent implicit type conversion, enforcing that passed values strictly match the declared **Type Hints**.

Enabling Strict Typing

To enable strict typing for a specific file, you must add the following directive as the very first statement in the PHP file (immediately after the `<?php` tag):

<?php
   **declare (strict_types=1);**

Note that the `declare(strict_types=1)` setting only affects function calls made from **within that specific file** and does not apply globally across the application.

Impact of Strict Typing vs. Weak Typing

Weak Typing (Default Behavior)

Without strict typing, PHP attempts to convert argument types to match the **Type Hints** on the function parameters.

*Function defined with type hints:* function addition(int $x, int $y) { /* ... */ }
*Function called with a string:* addition("10", 20);

$\rightarrow$ **Result:** PHP converts `"10"` to `10` and executes successfully, resulting in an addition of 30.

Strict Typing (Forced Type Checking)

When `declare(strict_types=1)` is active, PHP will **not** perform implicit casting. If the type of the argument does not exactly match the declared type hint, a fatal `TypeError` is immediately thrown.

*With strict\_types=1:* addition("10", 20);

$\rightarrow$ **Fatal Error:** Uncaught TypeError: addition(): Argument #1 ($x) must be of type int, string given.

Strict Return Type Checking

Since PHP 7, **Return Type Declarations** can also be added using a colon (`:`) after the parameter list (e.g., `: int`). In strict mode, if a function returns a value that doesn't match the declared return type, a fatal `TypeError` is thrown.

*Return type declared as `int` but returns `float`:*
function division(int $x, int $y) : **int** { return $x/$y; }
division(10, 20); // Returns 0.5 (float)

$\rightarrow$ **Fatal Error:** Uncaught TypeError: division(): Return value must be of type int, float returned.

Benefits of Strict Typing

  • **Code Reliability:** Increases type safety and significantly reduces the risk of subtle runtime bugs caused by unexpected implicit type conversions.
  • **Readability & Maintainability:** Explicit type definitions make the function's expectations clearer to other developers, improving long-term code maintenance.

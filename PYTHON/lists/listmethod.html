Python - List Methods

The Python list data structure provides several built-in methods for efficiently adding, updating, accessing, and removing elements. These methods make lists highly flexible and powerful for managing collections of items in Python[2][1].

Printing All List Methods

print(dir([]))
print(help([].append))

Use dir() to display all available list methods and help() for detailed documentation about any method[1].

Methods to Add Elements

  • list.append(obj): Appends an element to the end of the list.
  • list.extend(seq): Appends all elements from another iterable to the end of the list.
  • list.insert(index, obj): Inserts an element at the specified index in the list.

Methods to Remove Elements

  • list.clear(): Removes all elements from the list.
  • list.pop([index]): Removes and returns the element at the specified position (or the last element if index is omitted).
  • list.remove(obj): Removes the first occurrence of an element with the specified value.

Methods to Access Elements

  • list.index(obj): Returns the index of the first appearance of an element with the specified value.
  • list.count(obj): Returns the number of times an element appears in the list.

Copying and Ordering Methods

  • list.copy(): Returns a shallow copy of the list.
  • list.sort([key][, reverse]): Sorts the list in ascending order by default; accepts optional parameters for custom sorting.
  • list.reverse(): Reverses the elements of the list in place.

Example: Append and Sort

a = [2, 4, 1]
a.append(3)
a.sort()
print(a)   # Output: [1, 2, 3, 4]

PHP: Static Methods

The **static** keyword is used to define methods and properties that belong to the **class itself**, rather than to any specific object instance of that class.

Creating and Calling Static Methods

  • A method is declared static using the static keyword: public static function myStaticMethod() {...}.
  • Static methods are called directly on the class using the **Scope Resolution Operator** (::): MyClass::myStaticMethod();
  • You **do not need** to create an instance of the class to call a static method.
  • Because static methods are not tied to an object, the pseudo-variable **$this is not available** inside them. They can only access static properties (e.g., self::$var1).

Accessing Static Methods

Static methods can be called from various contexts using special keywords:

Within the Same Class

To call a static method from another method (either static or instance) within the same class, use the **self** keyword:

self::myStaticMethod();

In Inheritance (Derived Class)

To call a static method defined in a parent class from within a derived class, use the **parent** keyword:

parent::myStaticMethod();

From an Unrelated Class

A static method can be called from any other class by simply prefixing the method name with its class name and the scope resolution operator:

OtherClass::otherStaticMethod();

Example Session

Tracking Object Count with a Static Method

A common use for static members is to track class-level information, such as the number of objects created from that class. A static method can access a static property to report this count.


class myclass {
   // Static property to track the count, shared by all objects
   static int $objectCount = 0; 

   function __construct() {
      // Increment the static property upon object creation
      self::$objectCount++; 
   }

   // Static method to report the shared count
   public static function getCount() { 
      echo "Number of objects created: " . self::$objectCount . PHP_EOL;
   }
}

$obj1 = new myclass;
$obj2 = new myclass;
myclass::getCount(); // Calls the static method without an object
// Output: Number of objects created: 2

PHP Type Hints and Strict Typing

**Type Hints** (or **Type Declarations**) allow you to explicitly declare the expected data type for function parameters, return values, and class properties (PHP 7.4+). Since PHP is typically a **weakly typed** language that performs automatic type casting, type hints help in writing more reliable, robust, and self-documenting code.

Function Type Hints

1. Parameter and Return Type Declarations (PHP 7+)

You can specify the expected type for arguments and the type of the value a function must return.

function addition(**int** $x, **int** $y) : **int** {
   return $x + $y;
}

2. Strict Type Checking

By default, PHP attempts to coerce (cast) values to match the declared type (e.g., automatically converting the string `"10"` to the integer `10`). To prevent this and enforce strict type matching, you must enable **strict mode** by placing the following declaration at the top of the file:

<?php
   **declare (strict_types=1);**
   function addition(int $x, int $y) : int { /* ... */ }
   $x="10"; // Will now cause a Fatal TypeError
   addition($x, 20);
?>

If strict mode is not set, `"10"` would be implicitly cast to `10`.

Advanced Type Hints (PHP 7.1+)

1. Nullable Types (`?`)

Prefixing a type with a question mark (`?`) means the parameter or return value can be either the specified type **or `null`**.

function greet(**?string** $name) { /* ... */ }
greet("Jatin"); // Valid
greet(null); // Valid

2. Union Types (`|`) (PHP 8.0+)

Allows you to specify that a parameter or return value can be one of several types, separated by the pipe symbol (`|`).

function addition(**int|float** $x, int|float $y) : **float** {
   return $x + $y;
}

3. Mixed Type (PHP 8.0+)

The `mixed` pseudo-type can be used to indicate that an argument or return value accepts **any type** (int, string, array, object, null, etc.). It is equivalent to using a large union of all possible types.

function display(**mixed** $value) { var_dump($value); }

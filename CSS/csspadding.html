CSS - Paddings

CSS padding is used to create extra space between the border of the element and its contents. In this chapter, we will learn about different types of padding and properties associated with it.

What is CSS Padding?

In CSS, padding is a property used to create additional spacing inside the boundary of an element. The default value for padding is 0. When padding is 0, the content of the element starts directly from its border.

CSS Padding Example

You can try different ways to apply padding in the examples below:

  • padding: 1em;
  • padding: 10px 0;
  • padding: 10px 50px 20px;
  • padding: 10px 50px 20px 40px;
  • padding: 30px;

Syntax

padding: value;

Example

<div>
  <p style="padding: 5px;">
    CSS Padding Applied on Paragraph Element
  </p>
</div>

CSS Individual Padding Properties

The padding property is a shorthand for four individual properties:

  • padding-top: Sets the top padding of an element.
  • padding-right: Sets the right padding of an element.
  • padding-bottom: Sets the bottom padding of an element.
  • padding-left: Sets the left padding of an element.

Syntax

padding-top: value;
padding-right: value;
padding-bottom: value;
padding-left: value;

Example

<div>
  <p style="padding-top: 20px;">Padding Top</p>
  <p style="padding-right: 30px;">Padding Right</p>
  <p style="padding-bottom: 30px;">Padding Bottom</p>
  <p style="padding-left: 15px;">Padding Left</p>
</div>

⚠ Note: Negative values are not allowed for padding in CSS.

CSS Padding Shorthand Property

You can set padding with one, two, three, or four values:

  • Single Value: Applies the same padding to all sides. (padding: 20px;)
  • Two Values: First value = top & bottom, second = left & right. (padding: 10px 20px;)
  • Three Values: First = top, second = left & right, third = bottom. (padding: 10px 15px 20px;)
  • Four Values: Top, right, bottom, left in clockwise order. (padding: 5px 10px 15px 20px;)

Syntax

padding: value;               /* Single Value */
padding: value value;         /* Two Values */
padding: value value value;   /* Three Values */
padding: value value value value; /* Four Values */

Example

<div>
  <p style="padding: 20px;">Single Value</p>
  <p style="padding: 10px 20px;">Two Values</p>
  <p style="padding: 10px 15px 20px;">Three Values</p>
  <p style="padding: 5px 10px 15px 20px;">Four Values</p>
</div>

Padding with Mixed Units

You can mix different CSS units (px, em, %, in, etc.) while defining padding values.

Example

<h2 style="padding: 20px 4ex .5in 3em;">
  Padding with Mixed Units
</h2>

Padding with Percentage Value

The percentage value is calculated relative to the width of the parent element.

Example

<div style="width: 300px;">
  <p style="padding: 10%;">
    Padding of 10% means 30px (10% of 300px).
  </p>
</div>

Padding Properties Reference

Property Description
padding Shorthand property for setting all padding sides in one declaration.
padding-top Sets the top padding of an element.
padding-right Sets the right padding of an element.
padding-bottom Sets the bottom padding of an element.
padding-left Sets the left padding of an element.

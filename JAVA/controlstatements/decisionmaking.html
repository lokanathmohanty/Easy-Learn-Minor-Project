Java Decision Making

Session Content

Decision making structures in Java evaluate one or more conditions to control program flow. If a condition is true, a set of statements executes; if false, optionally different statements can run. Java supports various decision-making statements for effective control flow.

  • if statement: executes when a boolean expression is true
  • if...else statement: provides an alternative block if the condition is false
  • nested if statement: allows if or else if inside another if or else if
  • switch statement: tests variables against a list of values for equality

Additionally, the conditional operator ?: can replace simpler if...else statements with a more concise expression form.

Example: Conditional Operator (Ternary Operator)

This example uses the ternary operator to assign a value to b based on the condition involving a. 

public class Test {
   public static void main(String args[]) {
      int a, b;
      a = 10;
      b = (a == 1) ? 20 : 30;
      System.out.println("Value of b is : " + b);

      b = (a == 10) ? 20 : 30;
      System.out.println("Value of b is : " + b);
   }
}
  • Output:
  • Value of b is : 30
  • Value of b is : 20

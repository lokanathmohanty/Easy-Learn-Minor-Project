Python - Functions

A Python function is a block of organized, reusable code that performs a single, related action. Functions help in modular programming and code reuse.

Types of Functions

  • Built-in functions – Already available in Python (e.g., print(), len(), sum()).
  • Functions in built-in modules – Provided by standard libraries, must be imported.
  • User-defined functions – Written by the programmer.

Defining a Function

def function_name(parameters):
    "optional docstring"
    function_body
    return [expression]

Example

def greetings():
    "This is docstring of greetings function"
    print("Hello World")
    return

greetings()

Output:

Hello World

Calling a Function

def printme(str):
    "This prints a passed string"
    print(str)

printme("I'm first call to user-defined function!")
printme("Again second call")

Output:

I'm first call to user-defined function!
Again second call

Pass by Reference vs Value

Python passes references to objects. Whether changes reflect outside depends on mutability:

  • Immutable (numbers, strings, tuples): function creates new objects → original unchanged.
  • Mutable (lists, dicts): modifications inside function affect the original object.

Example with Immutable

def testfunction(arg):
    print("ID inside:", id(arg))
    arg = arg + 1
    print("new object:", arg, id(arg))

var = 10
print("ID before:", id(var))
testfunction(var)
print("value after:", var)

Output:

ID before: 140719550297160
ID inside: 140719550297160
new object: 11 140719550297192
value after: 10

Example with Mutable

def testfunction(arg):
    arg.append(100)

var = [10, 20, 30]
testfunction(var)
print("list after:", var)

Output:

list after: [10, 20, 30, 100]

Function Arguments

  • Positional – must be passed in correct order.
  • Keyword – specify with name.
  • Default – parameters with default values.
  • Positional-only (after /).
  • Keyword-only (after *).
  • Variable-length – *args and **kwargs.

Example: Keyword Argument

def printinfo(name, age):
    print("Name:", name)
    print("Age:", age)

printinfo(age=50, name="Miki")

Output:

Name: Miki
Age: 50

Return Statement

def add(x, y):
    return x + y

result = add(10, 20)
print("Sum:", result)

Output:

Sum: 30

Lambda (Anonymous) Functions

sum = lambda a, b: a + b
print(sum(10, 20))
print(sum(20, 20))

Output:

30
40

Scope of Variables

total = 0  # global

def sum(a, b):
    total = a + b  # local
    print("Inside function total:", total)
    return total

sum(10, 20)
print("Outside function total:", total)

Output:

Inside function total: 30
Outside function total: 0

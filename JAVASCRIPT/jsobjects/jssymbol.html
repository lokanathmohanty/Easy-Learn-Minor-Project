JavaScript - The Symbol Object

JavaScript Symbol

In JavaScript, Symbol is a primitive data type introduced in ECMAScript 6 (ES6). It can be created using the Symbol constructor.

Symbols are immutable and unique. They are especially helpful when a unique identifier is required, as they can be used to create private object properties and avoid naming conflicts.

Key Points

  • Each symbol contains unique values.
  • Symbols are immutable.
  • Symbols are used to define unique object properties.
  • The type of a symbol cannot be changed.

Syntax

const sym = Symbol([description]);

description is an optional parameter. It specifies the symbol description, which you can access using the description property.

Symbol Properties

  • description − Get an optional description of the symbol.
  • asyncIterator − Makes the object async iterable.
  • hasInstance − Checks if a constructor object counts the object as its instance.
  • isConcatSpreadable − Determines array concatenation behavior.
  • iterator − Returns an iterator.
  • match − Matches regex with string.
  • matchAll − Returns all regex matches.
  • replace − Replaces a substring.
  • search − Returns index of match.
  • species − Creates a derived object.
  • split − Splits string where regex matches.
  • toStringTag − Creates a default string description.

Symbol Methods

  • for() − Searches for a given symbol.
  • keyFor() − Retrieves a key from the global symbol registry.
  • toString() − Converts symbol to string.
  • valueOf() − Gets primitive value of the symbol.

Examples

Creating a Symbol

<html>
<body>
  <p id="output"></p>
  <script>
    const sym1 = Symbol();
    document.getElementById("output").innerHTML =
      "The sym1 is: " + sym1.toString() + "<br>" +
      "The type of sym1 is: " + typeof sym1 + "<br>";

    const sym2 = Symbol("description");
    document.getElementById("output").innerHTML += "The sym2 is: " + sym2.toString();
  </script>
</body>
</html>

Output:

  • The sym1 is: Symbol()
  • The type of sym1 is: symbol
  • The sym2 is: Symbol(description)

Accessing Symbol Description

<html>
<body>
  <p id="output"></p>
  <script>
    const sym = Symbol("Welcome to Tutorials Point...");
    document.getElementById("output").innerHTML =
      "The sym description of the symbol is : " + sym.description;
  </script>
</body>
</html>

Output: The sym description of the symbol is : Welcome to Tutorials Point...

Each Symbol is Unique

<html>
<body>
  <p id="output"></p>
  <script>
    const sym1 = Symbol();
    const sym2 = Symbol();

    if (sym1 == sym2) {
      document.getElementById("output").innerHTML = "Sym1 and Sym2 are equal.";
    } else {
      document.getElementById("output").innerHTML = "Sym1 and Sym2 are not equal.";
    }
  </script>
</body>
</html>

Output: Sym1 and Sym2 are not equal.

Using Symbol as an Object Key

<html>
<body>
  <p id="output">The object is: </p>
  <script>
    const objId = Symbol();
    const person = {
      name: "John Doe",
      age: 30,
      [objId]: "abcd123",
    }
    document.getElementById("output").innerHTML += JSON.stringify(person);
  </script>
</body>
</html>

Output: The object is: {"name":"John Doe","age":30}

Benefits of Using Symbols

  • Unique property keys − Each symbol is unique, useful to avoid collisions.
  • Non-iterable properties − Symbol keys are not traversed in for...in loops.
  • Private Members − Can be used as private properties in classes.
  • Avoid overwriting − Ensures no accidental overwriting of properties.

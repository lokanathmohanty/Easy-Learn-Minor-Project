Python OS File/Directory Methods

The os module of Python provides a wide range of useful methods to manage files and directories. These built-in methods help in interacting with operating systems. Most of the useful methods are listed here −

OS File/Directory Methods

  • os.access(path, mode) − Test for access to path using real uid/gid.
  • os.chdir(path) − Change the current working directory to path.
  • os.chflags(path, flags) − Set the flags of path to the numeric flags.
  • os.chmod(path, mode) − Change the mode of path.
  • os.chown(path, uid, gid) − Change the owner and group id of path.
  • os.chroot(path) − Change the root directory of the current process.
  • os.close(fd) − Close file descriptor.
  • os.closerange(fd_low, fd_high) − Close all file descriptors in range.
  • os.dup(fd) − Return a duplicate of file descriptor.
  • os.dup2(fd, fd2) − Duplicate file descriptor fd to fd2.
  • os.fchdir(fd) − Change current working directory to one represented by fd.
  • os.fchmod(fd, mode) − Change mode of file given by fd.
  • os.fchown(fd, uid, gid) − Change owner and group id of file given by fd.
  • os.fdatasync(fd) − Force write of file with fd to disk.
  • os.fdopen(fd[, mode[, bufsize]]) − Return open file object connected to fd.
  • os.fpathconf(fd, name) − Return system configuration info relevant to an open file.
  • os.fstat(fd) − Return status for file descriptor fd.
  • os.fstatvfs(fd) − Return filesystem info for file associated with fd.
  • os.fsync(fd) − Force write of file with fd to disk.
  • os.ftruncate(fd, length) − Truncate file corresponding to fd.
  • os.getcwd() − Return current working directory.
  • os.getcwdu() − Return Unicode object of current working directory. (Removed in Python 3)
  • os.isatty(fd) − Return True if fd is open and connected to a tty device.
  • os.lchflags(path, flags) − Set flags, not following symbolic links.
  • os.lchmod(path, mode) − Change mode, not following symbolic links.
  • os.lchown(path, uid, gid) − Change owner/group id, not following symbolic links.
  • os.link(src, dst) − Create a hard link pointing to src named dst.
  • os.listdir(path) − Return a list of entries in the directory.
  • os.lseek(fd, pos, how) − Set current position of fd.
  • os.lstat(path) − Like stat(), but no symbolic link following.
  • os.major(device) − Extract major device number.
  • os.makedev(major, minor) − Compose raw device number from major/minor.
  • os.makedirs(path[, mode]) − Recursive directory creation.
  • os.minor(device) − Extract minor device number.
  • os.mkdir(path[, mode]) − Create a directory.
  • os.mkfifo(path[, mode]) − Create a FIFO (named pipe).
  • os.mknod(filename[, mode, device]) − Create a filesystem node.
  • os.open(file, flags[, mode]) − Open file with given flags and mode.
  • os.openpty() − Open new pseudo-terminal pair.
  • os.pathconf(path, name) − Return system config info for a named file.
  • os.pipe() − Create a pipe (r, w file descriptors).
  • os.popen(command[, mode[, bufsize]]) − Open a pipe to/from command.
  • os.read(fd, n) − Read at most n bytes from fd.
  • os.readlink(path) − Return the path to which a symlink points.
  • os.remove(path) − Remove a file.
  • os.removedirs(path) − Remove directories recursively.
  • os.rename(src, dst) − Rename file or directory.
  • os.renames(old, new) − Recursive directory/file renaming.
  • os.rmdir(path) − Remove directory.
  • os.stat(path) − Perform a stat system call on path.
  • os.stat_float_times([newvalue]) − Control timestamp float behavior.
  • os.statvfs(path) − Perform statvfs system call on path.
  • os.symlink(src, dst) − Create a symbolic link.
  • os.tcgetpgrp(fd) − Get process group of terminal.
  • os.tcsetpgrp(fd, pg) − Set process group of terminal.
  • os.tempnam([dir[, prefix]]) − Return a unique path name for temporary file. (Deprecated)
  • os.tmpfile() − Return new file object in update mode. (Deprecated in Python 3)
  • os.tmpnam() − Return unique path name for temporary file. (Deprecated)
  • os.ttyname(fd) − Return terminal device name associated with fd.
  • os.unlink(path) − Remove file path.
  • os.utime(path, times) − Set access and modified times.
  • os.walk(top[, topdown, onerror, followlinks]) − Generate file names in directory tree.
  • os.write(fd, str) − Write string to fd, return number of bytes written.

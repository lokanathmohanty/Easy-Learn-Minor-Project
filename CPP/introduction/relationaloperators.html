C++ Relational Operators ⚖️

**Relational operators** in C++ are used to compare two values or expressions, checking the relationship between them. The result of a relational operation is always a **Boolean value** (true or false, which C++ often represents as 1 or 0, respectively).

List of Relational Operators

These operators are fundamental for control flow and decision-making (e.g., in if statements and loops).

OperatorMeaningExample
==Equal toa == b
!=Not equal toa != b
>Greater thana > b
<Less thana < b
>=Greater than or equal toa >= b
<=Less than or equal toa <= b

Usage and Contexts

Relational operators can be used with various data types, but with some considerations:

  • Numeric Types (Integers, Floats): Standard comparison of magnitude.
  • Characters: Comparison is based on their underlying **ASCII** values.
  • Strings: Comparison is **lexicographical** (alphabetical order).
  • Custom Objects: Comparison requires **operator overloading**, where the programmer defines what it means for one object to be "greater than" or "equal to" another (e.g., comparing two Point objects based on their distance from the origin).

Floating-Point Caution ⚠️

Due to potential **precision issues** (rounding errors) in floating-point arithmetic (float, double), direct equality comparison (x == y) is often unreliable. Instead, it is safer to check if the absolute difference between the two numbers is less than a very small threshold (epsilon, e.g., $10^{-6}$):

if (fabs(x - y) < 1e-6) // x and y are considered equal

Combining with Logical Operators

Relational expressions are frequently combined with **Logical Operators** (&&, ||, !) to create complex conditions that must all be true, any can be true, or a condition is negated.

if (age >= 18 && height > 170) {
    // Both relational conditions must be true
}

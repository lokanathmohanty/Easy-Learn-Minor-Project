CSS - Forms

Forms are essential in web development when you want to collect data from users. They typically contain input fields for users to enter information, labels to describe the fields, and buttons to submit or reset the form.

Using CSS, we can enhance the appearance of forms by styling text fields, checkboxes, radio buttons, dropdown menus, and submit buttons to improve usability and aesthetics.

HTML Form Structure

An HTML form is created using the <form> element. It may include various input controls like text fields, password fields, checkboxes, radio buttons, select menus, and buttons.

  • Text fields allow users to type input.
  • Labels describe the purpose of each input.
  • Select menus let users choose from a list of options.
  • Buttons are used to submit or reset the form.

HTML Form Example

Below is a simple form that accepts a user's first and last name along with a tutorial selection. Upon submitting, it can redirect to a course page or process the data as required.

Example

<form action="/courses" method="post">
  <label for="fname">First Name:</label><br>
  <input type="text" id="fname" name="fname"><br><br>

  <label for="lname">Last Name:</label><br>
  <input type="text" id="lname" name="lname"><br><br>

  <label for="tutorial">Tutorial:</label><br>
  <select id="tutorial" name="tutorial">
    <option value="html">HTML</option>
    <option value="css">CSS</option>
    <option value="javascript">JavaScript</option>
  </select><br><br>

  <input type="submit" value="Submit">
</form>

Explanation

  • The <label> tag defines text for the input field, improving accessibility.
  • The <input type="text"> creates a text box for user input.
  • The <select> element provides a dropdown list of tutorials.
  • The <input type="submit"> creates a button that sends form data to the server.

Styling Forms with CSS

CSS can be applied to enhance user experience, such as adding padding, borders, focus effects, and hover states. For example, you can style input fields to expand when focused or give buttons hover animations.

Well-styled forms improve readability, accessibility, and encourage users to complete them.

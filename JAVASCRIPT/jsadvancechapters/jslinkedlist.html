JavaScript - Linked List

A Linked List is an ordered collection of data elements represented using nodes. Each node has two parts:

  • Data: The actual value stored in the node.
  • Next: A reference (pointer) to the next node in the list.

The Head is a reference to the first node in the list. Nodes are connected sequentially, allowing efficient insertion and deletion.

Types of Linked List

  • Singly Linked List: Each node points only to the next node.
  • Doubly Linked List: Each node points to both the next and previous nodes.
  • Circular Linked List: The last node points back to the first node.

Implementation

To implement a linked list in JavaScript, we define two classes:

  • Node class: Represents a node containing data and a pointer.
  • LinkedList class: Represents the list with methods to insert, search, delete, and print nodes.

Node Class

class Node {
  constructor(data) {
    this.data = data;
    this.next = null;
  }
}

LinkedList Class

class LinkedList {
  constructor() {
    this.head = null;
    this.tail = null;
    this.length = 0;
  }
}

Operations on Linked List

Insert a Node

insert(data) {
  let node = new Node(data);
  if (!this.head) {
    this.head = node;
    this.tail = this.head;
  } else {
    this.tail.next = node;
    this.tail = node;
  }
  this.length++;
  return this;
}

Search a Node

search(data) {
  let current = this.head;
  while (current) {
    if (current.data === data) {
      return current;
    }
    current = current.next;
  }
  return null;
}

Delete a Node

delete(data) {
  if (!this.head) return null;
  if (this.head.data === data) {
    this.head = this.head.next;
    this.length--;
    return this;
  }
  let current = this.head;
  let prev = null;
  while (current) {
    if (current.data === data) {
      prev.next = current.next;
      this.length--;
      return this;
    }
    prev = current;
    current = current.next;
  }
  return null;
}

Print Linked List

print() {
  let current = this.head;
  while (current) {
    console.log(current.data);
    current = current.next;
  }
}

          this.head = null;
          this.tail = null;
          this.length = 0;

          let node = new Node(data);
          if (!this.head) {
            this.head = node;

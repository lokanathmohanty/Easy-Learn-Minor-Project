Python - Anonymous Class and Objects

Python's built-in type() function returns the class that an object belongs to. In Python, a class—built-in or user-defined—is an object of type class.

Example

class myclass:
   def __init__(self):
      self.myvar = 10
      return

obj = myclass()

print('class of int', type(int))
print('class of list', type(list))
print('class of dict', type(dict))
print('class of myclass', type(myclass))
print('class of obj', type(obj))

Output:

class of int <class 'type'>
class of list <class 'type'>
class of dict <class 'type'>
class of myclass <class 'type'>

Three-Argument Version of type()

The function type() also has a three-argument version used to dynamically create a class:

  • name – the name of the class, which becomes the __name__ attribute
  • bases – a tuple of base classes (can be empty if no inheritance)
  • dict – a dictionary containing attributes and methods for the class
newclass = type(name, bases, dict)

Create an Anonymous Class

Using the three-argument form, an anonymous class can be created by passing an empty string as the name, inheriting from object, and an empty dictionary for attributes: 

anon = type('', (object,), {})

Create an Anonymous Object

obj = anon()
print("type of obj:", type(obj))

The output shows the object is of an anonymous class:

type of obj: <class '__main__.'>

Anonymous Class with Dynamic Attributes and Methods

def getA(self):
   return self.a

obj = type('', (object,), {
   'a': 5,
   'b': 6,
   'c': 7,
   'getA': getA,
   'getB': lambda self: self.b
})()

print(obj.getA(), obj.getB())

Output:

5 6

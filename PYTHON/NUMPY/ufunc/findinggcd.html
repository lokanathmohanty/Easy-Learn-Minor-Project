NumPy GCD (Greatest Common Divisor)

The GCD (Greatest Common Divisor), also known as HCF (Highest Common Factor), is the largest number that is a common factor of both numbers.

Example 1: Find GCD of Two Numbers

Find the HCF of the following two numbers:

import numpy as np

num1 = 6
num2 = 9

x = np.gcd(num1, num2)

print(x)

Returns: 3 because 3 is the highest number both can be divided by (6÷3=2 and 9÷3=3).

Example 2: Find GCD of an Array

To find the Highest Common Factor of all values in an array, use the reduce() method with the np.gcd ufunc.

This method applies the GCD operation cumulatively on the elements of the array.

import numpy as np

arr = np.array([20, 8, 32, 36, 16])

x = np.gcd.reduce(arr)

print(x)

Returns: 4 because 4 is the highest number all values can be divided by.

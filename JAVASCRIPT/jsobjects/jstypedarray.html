JavaScript - The TypedArray Object

What is a TypedArray?

A JavaScript TypedArray is an array-like object used to store binary data. Unlike normal arrays, the size of a TypedArray cannot be dynamic, and it can’t hold values of different data types. This improves performance when working with binary data.

TypedArrays are commonly used in audio processing, graphics rendering, and networking.

Why TypedArray?

In languages like C++, arrays can contain elements of only one data type. JavaScript arrays are more flexible but less efficient for binary data. TypedArray was introduced in JavaScript to handle binary data efficiently while maintaining memory.

TypedArray Objects

Here are the types of TypedArray objects available for different data sizes:

  • Int8Array – 8-bit signed integer
  • Uint8Array – 8-bit unsigned integer
  • Uint8ClampedArray – 8-bit unsigned clamped integer
  • Int16Array – 16-bit signed integer
  • Uint16Array – 16-bit unsigned integer
  • Int32Array – 32-bit signed integer
  • Uint32Array – 32-bit unsigned integer
  • Float32Array – 32-bit floating point
  • Float64Array – 64-bit floating point
  • BigInt64Array – 64-bit signed big integer
  • BigUint64Array – 64-bit unsigned big integer

TypedArray Properties

  • constructor – Returns the array buffer constructor.
  • byteLength – Returns the byte length of the TypedArray.
  • maxByteLength – Maximum expandable byte length.
  • resizable – Checks if the TypedArray is resizable.

TypedArray Static Methods

  • from() – Creates a new TypedArray instance.
  • of() – Creates a new TypedArray instance.

TypedArray Instance Methods

Some commonly used instance methods include:

  • at() – Returns element at the given index.
  • copyWithin() – Copies elements within the same TypedArray.
  • find() – Finds the first matching element.
  • map() – Creates a new TypedArray by applying a function.
  • reduce() – Reduces all elements to a single value.
  • slice() – Extracts a portion of the array.
  • sort() – Sorts the TypedArray in place.
  • values() – Returns an iterable of array values.

Examples

Example 1: Using Int8Array

Creating a TypedArray with Int8Array. Numbers exceeding 8-bit range are automatically converted. 

<html>
<body>
  <p id="output"></p>
  <script>
    const array = new Int8Array([1000, 200, 30, 40]);
    document.getElementById("output").innerHTML = "The array is: " + array;
  </script>
</body>
</html>

Output: The array is: -24,-56,30,40

Example 2: Using Float32Array

Creating a TypedArray with Float32Array and updating values. 

<html>
<body>
  <p id="output"></p>
  <script>
    const array = new Float32Array([100.212, 907.54, 90, 14562547356342.3454]);
    array[2] = 23.65; 
    document.getElementById("output").innerHTML = "The array is: " + array;
  </script>
</body>
</html>

Output: The array is: 100.21199798583984,907.5399780273438,23.649999618530273,14562546941952

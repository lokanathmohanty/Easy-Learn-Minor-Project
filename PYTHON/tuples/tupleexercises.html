Python Tuple Exercises

Exercise 1: Find Unique Numbers in a Tuple

Write a program to find unique numbers in a given tuple.

T1 = (1, 9, 1, 6, 3, 4, 5, 1, 1, 2, 5, 6, 7, 8, 9, 2)
T2 = ()
for x in T1:
    if x not in T2:
        T2 += (x,)

print("original tuple:", T1)
print("Unique numbers:", T2)

Output:

original tuple: (1, 9, 1, 6, 3, 4, 5, 1, 1, 2, 5, 6, 7, 8, 9, 2)
Unique numbers: (1, 9, 6, 3, 4, 5, 2, 7, 8)

Exercise 2: Sum of All Numbers in a Tuple

Calculate the sum of all numbers in a tuple using both a loop and the built-in sum() function.

T1 = (1, 9, 1, 6, 3, 4)
ttl = 0
for x in T1:
    ttl += x
print("Sum of all numbers Using loop:", ttl)

ttl = sum(T1)
print("Sum of all numbers sum() function:", ttl)

Output:

Sum of all numbers Using loop: 24
Sum of all numbers sum() function: 24

Exercise 3: Create a Tuple of 5 Random Integers

Generate a tuple consisting of 5 random integers.

import random
t1 = ()
for i in range(5):
    t1 += (random.randint(0, 100),)

print(t1)

Sample Output:

(64, 21, 68, 6, 12)

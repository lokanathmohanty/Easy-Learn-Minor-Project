Command Line Arguments in C

In any C program, execution starts from the main() function. While other functions may accept arguments and return values, the main() function typically has no arguments and returns 0.

int main() { 
   ...
   return 0;
}

You can accept input using scanf() inside main() like this:

#include <stdio.h>

int main() {
   int a;
   scanf("%d", &a);
   printf("%d", a);
   return 0;
}

What are Command Line Arguments?

Instead of taking input from within the program, we can pass input at runtime via the command line. These values are called command line arguments.

This is useful when you want to pass parameters to control the behavior of your program externally, such as:

C:\users\user>hello Prakash

The above command would pass "Prakash" as a command-line argument to your program.

argc and argv

To receive command line arguments, the main() function must be defined with two parameters:

int main(int argc, char *argv[])
  • argc: Argument count — number of command line arguments
  • argv: Argument vector — array of character pointers to the arguments

argv[0] is the name of the program itself, and the remaining arguments are the values passed by the user.

Simple Example

Save the following code as hello.c:

#include <stdio.h>

int main (int argc, char * argv[]) {
   printf("Hello %s", argv[1]);
   return 0;
}

Compile and Run

C:\Users\user>gcc -c hello.c -o hello.o
C:\Users\user>gcc -o hello.exe hello.o
C:\Users\user>hello Prakash

Output

Hello Prakash

On Linux:

$ gcc hello.c
$ ./a.out Prakash

Example: Argument Count Check

This program checks how many arguments were passed:

#include <stdio.h>

int main (int argc, char *argv[]) {
   if (argc == 2) {
      printf("The argument supplied is %s\n", argv[1]);
   } else if (argc > 2) {
      printf("Too many arguments supplied.\n");
   } else {
      printf("One argument expected.\n");
   }
}

Output

$ ./a.out testing
The argument supplied is testing.

$ ./a.out testing1 testing2
Too many arguments supplied.

$ ./a.out
One argument expected.

Notes on argc and argv

  • argv[0] → Name of the executable
  • argv[1] → First argument
  • argc is always at least 1 (because argv[0] is always present)

Passing Numbers via Command Line

The following program adds two numbers passed as arguments:

#include <stdio.h>

int main (int argc, char * argv[]) {
   int c = argv[1] + argv[2]; // Incorrect
   printf("addition: %d", c);
   return 0;
}

Compilation Error

You'll get an error because argv[1] and argv[2] are strings (char pointers).

error: invalid operands to binary + (have 'char *' and 'char *')

Using atoi()

Use the atoi() function to convert string arguments to integers:

#include <stdio.h>
#include <stdlib.h>

int main (int argc, char * argv[]) {
   int c = atoi(argv[1]) + atoi(argv[2]);
   printf("addition: %d", c);
   return 0;
}

Run

C:\Users\user>add 10 20
addition: 30

Arguments with Spaces

If an argument has spaces, wrap it in quotes:

$ ./a.out "testing1 testing2"
        
#include <stdio.h>

int main(int argc, char *argv[]) {
   printf("Program name %s\n", argv[0]);

   if(argc == 2) {
      printf("The argument supplied is %s\n", argv[1]);
   }
   else if(argc > 2) {
      printf("Too many arguments supplied.\n");
   }
   else {
      printf("One argument expected.\n");
   }
}

Output

Program name ./a.out
The argument supplied is testing1 testing2

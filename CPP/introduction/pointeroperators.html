C++ Pointer Operators (& and *)

C++ uses two fundamental **pointer operators** to manage memory addresses and the values stored at those addresses:

  • **Address-of Operator** (&)
  • **Indirection/Dereference Operator** (*)

A **pointer** is a variable that stores the memory address of another variable.

1. Address-of Operator (&)

The **Address-of Operator** (&) is a unary operator that returns the **memory address** of its operand (variable). It is used to initialize a pointer variable.

  • **Read as:** "the address of"
  • **Example:** If var is a variable, &var gives the memory location where var's value is stored.

2. Indirection/Dereference Operator (*)

The **Indirection Operator** (*) is the complement of &. It is a unary operator that performs **dereferencing**, returning the **value** of the variable located at the address specified by its operand (the pointer).

  • **Read as:** "the value at the address contained in"
  • **Example:** If ptr holds a memory address, *ptr retrieves the actual data stored at that address.

Example Walkthrough

The provided code demonstrates the relationship between the variable, its address, and the dereferenced value:

int var = 3000; // var holds the value 3000
int *ptr;       // ptr is a pointer to an integer
int val;        // val will hold the retrieved value

// 1. Address of Operator (&)
ptr = &var; // ptr now stores the memory address of var

// 2. Indirection Operator (*)
val = *ptr; // val is assigned the value found at the address stored in ptr (which is 3000)

Output Analysis:

Value of var :3000       // The direct value of the variable
Value of ptr :0xbff64494 // The memory address stored in the pointer (var's address)
Value of val :3000       // The value retrieved by dereferencing the pointer

*Note: The address value (0xbff64494) will vary each time the program runs.*

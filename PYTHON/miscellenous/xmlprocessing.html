Python - XML Processing

XML (Extensible Markup Language) is a markup language that is portable, open, and readable by different applications regardless of the platform or language.

Python provides multiple APIs for XML processing within the xml package:

  • xml.sax: Event-driven SAX API for streaming parsing, memory-efficient for large files.
  • xml.dom: DOM API for loading whole XML as tree structure, allowing random access and modification.
  • xml.etree.ElementTree: Lightweight tree API for easy creation, parsing, and modification of XML data.

Parsing XML using SAX

Create a class inheriting from xml.sax.ContentHandler and override methods:

  • startElement(tag, attributes)
  • endElement(tag)
  • characters(content)

Example: Parse movies.xml displaying movie details as tags are processed.

Parsing XML using DOM

Load entire XML file into memory as tree using xml.dom.minidom.parse(file).

Access and modify nodes easily:

DOMTree = xml.dom.minidom.parse("movies.xml")
collection = DOMTree.documentElement
movies = collection.getElementsByTagName("movie")
for movie in movies:
    title = movie.getAttribute("title")
    print("Title:", title)

DOM allows random access but uses more memory, suitable for smaller XML files.

ElementTree API for XML

ElementTree treats XML as nested tree elements, providing a simple API to create, parse, and modify XML.

Create elements and children using Element() and SubElement(), write to file with ElementTree.write().

import xml.etree.ElementTree as et
root = et.Element("employees")
child = et.Element("employee")
root.append(child)
nm = et.SubElement(child, "name")
nm.text = "Alice"
tree = et.ElementTree(root)
tree.write("employees.xml")

Parsing and Modifying XML File with ElementTree

Read XML file with ElementTree(file=filename) and get root element with getroot().

Iterate over child elements for processing and modifications.

tree = et.ElementTree(file='employees.xml')
root = tree.getroot()
for employee in root:
    name = employee.find("name").text
    print(name)
# Modify values example:
for sal in root.iter('sal'):
    sal.text = str(int(sal.text) + 100)
tree.write('employees.xml')

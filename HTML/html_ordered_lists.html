HTML - Ordered Lists

An ordered list is defined by the <ol> tag where all list items are marked in an ordered sequence.

Ordered HTML Lists

An ordered list is a collection of items that have a specific order or sequence. Each list item is defined by the <li> tag inside the <ol> element.

This type of list is useful when the sequence matters, such as steps in a recipe, rankings, or chronological events.

Creating Ordered Lists

To create an ordered list in HTML, we use the <ol> tag and nest <li> elements inside it.

Example:

<ol>
  <li>Beetroot</li>
  <li>Ginger</li>
  <li>Potato</li>
  <li>Radish</li>
</ol>

The type Attribute

The type attribute specifies the numbering style for ordered lists. Options include:

  • 1 – Default numbers (1, 2, 3)
  • I – Uppercase Roman numerals
  • i – Lowercase Roman numerals
  • A – Uppercase alphabets
  • a – Lowercase alphabets

Examples

Numbers:

<ol type="1">
  <li>Beetroot</li>
  <li>Ginger</li>
</ol>

Uppercase Roman:

<ol type="I">
  <li>Aman</li>
  <li>Vivek</li>
</ol>

Lowercase Roman:

<ol type="i">
  <li>Aman</li>
  <li>Vivek</li>
</ol>

Uppercase Alphabets:

<ol type="A">
  <li>Bus</li>
  <li>Train</li>
</ol>

Lowercase Alphabets:

<ol type="a">
  <li>Bus</li>
  <li>Train</li>
</ol>

The start Attribute

The start attribute defines the starting number of the list.

<ol type="i" start="4">
  <li>Beetroot</li>
  <li>Ginger</li>
</ol>

Styling Ordered Lists

CSS can be used to style ordered lists, change numbering styles, add counters, and customize spacing. Example classes may include .roman, .letters, or .counter-list.

Nested Ordered Lists

You can nest ordered lists inside other list items. Example:

<ol>
  <li>Fruits
    <ol>
      <li>Apple</li>
      <li>Banana</li>
    </ol>
  </li>
  <li>Vegetables
    <ol type="i">
      <li>Carrot</li>
      <li>Spinach</li>
    </ol>
  </li>
</ol>

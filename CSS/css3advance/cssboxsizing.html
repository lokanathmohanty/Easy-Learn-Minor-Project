CSS - Box Sizing

The box-sizing property in CSS is used to define how the total width and height of an element is calculated. By default, the width and height of an element include its content, padding, and border. With the box-sizing property, you can alter this behavior to include or exclude the padding and border from the width and height calculation.

In older versions of CSS (CSS2), the default box model behavior often made the element look bigger than the dimensions specified:

  • width + padding + border = actual visible/rendered width
  • height + padding + border = actual visible/rendered height

CSS box-sizing Property

The CSS box-sizing property is useful for adjusting how element sizes are calculated, making layouts more predictable.

Possible Values

  • content-box: This is the default value. Padding and border are added to the total width and height of the element.
  • border-box: Padding and border are included in the specified width and height, shrinking the content area.
  • padding-box: Not supported by browsers and cannot be used.

Applies to

All HTML elements that accept width or height.

DOM Syntax

object.style.boxSizing = "content-box | border-box";

Example

The following example demonstrates the difference between content-box and border-box:

Example Code

<div class="with-content-box">CONTENT BOX</div>
<div class="with-border-box">BORDER BOX</div>

In this example, content-box includes padding in the calculation of width and height, while border-box does not. This makes border-box very useful for responsive designs.

Universal Box-Sizing Reset

For a smooth and fluid responsive design, many developers reset box-sizing for all elements: 

* {
   box-sizing: border-box;
}

A more complete syntax also applies to pseudo-elements: 

*, *:before, *:after {
   box-sizing: border-box;
}

Another flexible approach is to inherit box-sizing: 

html {
   box-sizing: border-box;
}
*, *:before, *:after {
   box-sizing: inherit;
}

Browser Support

Modern browsers support box-sizing: border-box without prefixes. Older browsers may require -webkit- or -moz- prefixes: 

html {
   -webkit-box-sizing: border-box;
   -moz-box-sizing: border-box;
   box-sizing: border-box;
}
*, *:before, *:after {
   -webkit-box-sizing: inherit;
   -moz-box-sizing: inherit;
   box-sizing: inherit;
}

Summary

  • content-box (default): Adds padding and border to the element size.
  • border-box: Keeps total size fixed, includes padding and border inside dimensions.
  • Preferred for responsive design: border-box.

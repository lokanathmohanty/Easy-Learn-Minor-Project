Java Try Catch Block

In Java, the try-catch block is a core component for handling exceptions and ensuring your program does not terminate unexpectedly when an error or exceptional event occurs during runtime. It enables safer execution and better user experiences in your software applications.

Purpose of Try-Catch

  • Safely handle code that might generate exceptions.
  • Allow custom logic or fallback actions when an error happens.
  • Avoid abrupt program termination and make applications robust.

Syntax and Basic Usage

The basic try-catch syntax:

try {
    // code that may throw an exception
} catch (ExceptionType e) {
    // code to handle the exception
}

All risky code goes inside the try block, and exceptions are matched to the nearest appropriate catch block.

Example: Handling Array Exception

public class ExcepTest {
    public static void main(String args[]) {
        try {
            int[] a = new int[2];
            System.out.println("Access element three :" + a[3]);
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Exception thrown  :" + e);
        }
        System.out.println("Out of the block");
    }
}
// Output:
// Exception thrown  :java.lang.ArrayIndexOutOfBoundsException: 3
// Out of the block

This example attempts to access an invalid array index. The error is caught and handled by the catch block, and the program continues running.

Node.js Built-in Modules

Node.js provides a rich set of built-in modules that are compiled into the runtime and help perform essential server-side tasks such as event management, file operations, network communication, and cryptography.

The following is a list of important built-in modules commonly used in Node.js development:

  • assert - Provides assertion functions for verifying conditions.
  • buffer - Handles fixed-length sequences of bytes for binary data.
  • http - Creates HTTP servers and manages HTTP requests.
  • fs - File system utilities for reading, writing, and managing files.
  • path - Utilities for transforming and working with file paths.
  • url - Parses and builds URLs.
  • util - Provides utility functions for debugging and data manipulation.
  • crypto - Cryptographic functions and secure data hashing.
  • process - Accesses and controls Node.js process information and environment.
  • net - Networking capabilities for creating clients and servers.
  • stream - Framework for stream-based data handling.
  • events - Event-driven programming with the EventEmitter class.
  • console - Console I/O functions for logging and output.
  • readline - Reads streams line-by-line for input processing.
  • querystring - Parsing and formatting URL query strings.
  • v8 - Interfaces with V8 JavaScript engine specifics.
  • os - Operating system-related utilities.

These modules can be imported in a Node.js application using the require() function. For example: 

const fs = require('fs');
const http = require('http');
const path = require('path');

They collectively empower Node.js to handle a wide range of development needs natively without extra libraries.

PHP Arithmetic Operators Examples

**Arithmetic Operators** in PHP are used to perform mathematical calculations on numeric operands (integers or floats).

Core Arithmetic Operators

Operator Description Example ($a=42, $b=20) Result
+ Addition $a + $b 62
- Subtraction $a - $b 22
* Multiplication $a * $b 840
/ Division $a / $b 2.1 (Result is a float)
% Modulus (Remainder) $a % $b 2
** Exponentiation (Power of) 2 ** 3 8

Increment and Decrement Operators

The increment (`++`) and decrement (`--`) operators are used to increase or decrease a variable's value by one. Their placement (before or after the variable) determines when the operation takes effect in an expression.

Pre-Increment/Decrement (`++$a`, `--$a`)

The value is **changed first**, then the result is used in the expression.

$count = 10;

echo ++$count; $\rightarrow$ 11 ($count is now 11)

Post-Increment/Decrement (`$a++`, `$a--`)

The **original value is used first** in the expression, then the value is changed.

$count = 10;

echo $count++; $\rightarrow$ 10 ($count is now 11)

echo $count; $\rightarrow$ 11

Behavior with Data Types

Division (`/`) and Modulus (`%`)

  • **Division** (`/`) always returns a **float** unless the result is exactly an integer (e.g., $4/2 = 2$). For integer division, use the `intdiv()` function.
  • **Modulus** (`%`) returns the remainder of integer division. The sign of the result is always the same as the **dividend** (the first operand).
    -10 % 5 $\rightarrow$ 0 (Since -10 is a multiple of 5)
    -10 % 3 $\rightarrow$ -1

Floating-Point Arithmetic

Arithmetic operations on **float** numbers generally result in a float. Be aware of standard floating-point precision issues common across all programming languages.

5.5 + 2.2 $\rightarrow$ 7.7
5.5 / 2.2 $\rightarrow$ 2.5

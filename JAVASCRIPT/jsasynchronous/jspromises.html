What is a Promise?

A Promise is an object that represents the eventual completion (or failure) of an asynchronous operation and its resulting value. Promises make async code easier to read and manage compared with deeply nested callbacks.

Producing a Promise

Create a promise with the Promise constructor. The executor receives two functions: resolve and reject.

Syntax:

let promise = new Promise(function(resolve, reject) { /* producing code */ });

Example (producing):

let promise = new Promise(function(resolve, reject) {

if (someCondition) resolve('success value');

else reject(new Error('failure reason'));

});

States of a Promise

  • Pending — initial state, neither fulfilled nor rejected.
  • Fulfilled — operation completed successfully; promise has a value.
  • Rejected — operation failed; promise has a reason (error).
  • Settled — either fulfilled or rejected.

Consuming Promises

Use instance methods to consume promises: then(), catch(), finally().

then()

Attach handlers for fulfilled and optionally rejected cases.

Syntax:

promise.then(onFulfilled, onRejected);

Example:

const num = 10;

const p = new Promise((resolve, reject) => {

if (num === 10) resolve('Number is 10');

else reject('Number is not 10');

});

p.then(function(message) { /* handle success */ }, function(err) { /* handle error */ });

catch()

Handle rejections; typically chained after then().

Syntax:

promise.then(onFulfilled).catch(onRejected);

Example:

const p = new Promise((resolve, reject) => reject('fail'));

p.then(msg => console.log(msg)).catch(err => console.log('Caught:', err));

finally()

Runs a callback when the promise is settled (fulfilled or rejected). Useful for cleanup tasks.

Syntax:

promise.then(onFulfilled).catch(onRejected).finally(() => { /* always runs */ });

Examples

Basic resolve / consume example:

let promise1 = new Promise((resolve, reject) => {

if (10 === 10) resolve('The value is 10');

else reject('Not 10');

});

promise1.then(msg => console.log(msg), err => console.log(err));

Delayed rejection example:

let promise2 = new Promise((resolve, reject) => {

setTimeout(() => reject('timed out'), 2000);

});

console.log('Waiting...');

promise2.then(msg => console.log(msg)).catch(err => console.log('Error:', err));

finally() example:

let p = Promise.resolve('ok');

p.then(msg => console.log('then:', msg))

.catch(err => console.log('catch:', err))

.finally(() => console.log('clean up / always run'));

Promise Static Methods (overview)

  • Promise.all(iterable) — fulfills when all input promises fulfill; rejects on first rejection.
  • Promise.allSettled(iterable) — waits until all have settled and returns their outcomes.
  • Promise.any(iterable) — fulfills when any promise fulfills; rejects if all reject.
  • Promise.race(iterable) — settles as soon as any promise settles (fulfill or reject).
  • Promise.resolve(value) — returns a resolved promise for the value.
  • Promise.reject(reason) — returns a rejected promise for the reason.

Best Practices

  • Avoid passing two callbacks to then(); prefer then(...).catch(...) for readability.
  • Use finally for cleanup (UI hide loader, closing resources).
  • Prefer Promise.allSettled or Promise.any when combining many independent operations with mixed outcomes.
  • Convert callback-based APIs to promises (wrapping) for consistent async flow and easier composition.

Reference Summary

  • Constructor: Promise()
  • Instance methods: then(), catch(), finally()
  • Static methods: all(), allSettled(), any(), race(), resolve(), reject()

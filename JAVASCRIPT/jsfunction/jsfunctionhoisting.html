JavaScript - Function Hoisting

Function hoisting in JavaScript is the default behavior where function declarations are moved to the top of their local scope before code execution. This means you can call a function in its scope before it is declared.

Only declarations are hoisted, not initializations. The same applies to variable hoisting, where variable declarations are moved to the top of their scope.

Example: Function Declaration Hoisting


add(5, 10); // 15
function add(x, y) {
  return x + y;
}

Equivalent to: 


function add(x, y) {
  return x + y;
}
add(5, 10); // 15

Function hoisting only works with function declarations, not with function expressions. 


add(5, 10); // ReferenceError
const add = function(x, y) {
  return x + y;
};

Example: Function Hoisting in Scope


printMessage("Top");

function printMessage(pos) {
  console.log("The function is called from the " + pos);
}

printMessage("Bottom");

The function is called from the Top

The function is called from the Bottom

Example: Function Inside Block


if (1) {
  test("Top");
  function test(pos) {
    console.log("The function is called from the " + pos);
  }
  test("Bottom");
}

The function is called from the Top

The function is called from the Bottom

Although hoisting allows flexibility, it is always recommended to declare functions and variables at the top of their scope for clarity.

JavaScript Variable Hoisting

Variables declared with var are hoisted, but variables declared with let and const are not hoisted to the top of their scope.

Example: Variable Hoisting


y = 10;
console.log("The value of y is: " + y);
var y;

The value of y is : 10

Example: Variable Hoisting inside Function


function printNum() {
  y = 20;
  console.log("The value of y is: " + y);
  var y; // function scope
}
printNum();

The value of the variable y is : 20

Example: Initialization is not Hoisted


var x;
console.log("x is -> " + x);
x = 10;

x is -> undefined

Example: let and const


try {
  x = 10;
  console.log("The value of x is -> " + x);
  let x;
} catch (error) {
  console.log(error.message);
}

Cannot access 'x' before initialization

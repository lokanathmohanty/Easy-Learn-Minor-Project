JavaScript - Variable Scope

The variable scope in JavaScript determines the accessibility and visibility of a variable in different parts of the code. The scope is the current context of the code execution. This means variable scope is determined by where it is executed, not by where it is declared.

In JavaScript, objects and functions are also variables. So variable scope also determines the accessibility or visibility of objects and functions in a program.

It is essential to learn variable scope to write clear code and avoid naming conflicts.

Types of variable scope in JavaScript:

  • Block scope
  • Function scope
  • Local scope
  • Global scope

Here, we will cover block, function, and local scope. Global scope is discussed in detail in the JavaScript Global Variable chapter.

JavaScript Block Scope

Before ES6, there were only global and function scopes. ES6 introduced the let and const keywords, which provide block scope in JavaScript.

Variables defined using let and const inside a { } block can only be accessed inside that block.

{
   let x = 10; // x is accessible here
}
// x is not accessible here

{
   var x = 10; // x is accessible here
}
// x is still accessible here

Example 1

<script>
if (true) {
   let a = 10;
   document.getElementById("output").innerHTML = "a = " + a;
}
// a can't be accessed here
</script>

Output: a = 10

Example 2

<script>
function test() {
   {
      let x = 30;
      document.getElementById("demo").innerHTML = "x = " + x;
   }
   // x is not accessible here
}
test();
</script>

Output: x = 30

Whenever you define a variable with let or const inside a block (loop, if-else, etc.), it cannot be accessed outside that block.

JavaScript Function Scope

Each function creates its own scope. Variables defined inside a function have function scope and are only accessible within that function. They cannot be accessed outside the function.

Variables declared with var are function-scoped, even if declared inside a block. By contrast, let and const remain block-scoped inside the function.

function func() {
   {
      var x;    // function scope
      let y;    // block scope
      const z = 20; // block scope
   }
   // x is accessible here, but y and z are not
}

Example

<script>
function func() {
   {
      var x = 30;
      let y = 20;
      const z = 10;
      document.write("x inside block = " + x + "<br>");
      document.write("y inside block = " + y + "<br>");
      document.write("z inside block = " + z + "<br>");
   }
   document.write("x outside block = " + x + "<br>");
   // y and z not accessible here
}
func();
</script>

Output:

  • x → Inside the block = 30
  • y → Inside the block = 20
  • z → Inside the block = 10
  • x → Outside the block = 30

JavaScript Local Scope

Local scope is created whenever a function is invoked. The variables defined inside the function exist only during its execution and are destroyed after the function ends.

Variables defined inside a function (using var, let, or const) are local to that function. Similarly, variables declared in a block are local to that block.

Example

<script>
function func() {
   let first = 34;
   var second = 45;
   const third = 60;

   document.write("First = " + first + "<br>");
   document.write("Second = " + second + "<br>");
   document.write("Third = " + third + "<br>");
}
func();
</script>

Output:

  • First → 34
  • Second → 45
  • Third → 60

C++ Operators Precedence and Evaluation Order 🪜

**Operator precedence** determines the order in which operators are evaluated in a single expression. Operators with a **higher precedence** are performed before those with a lower precedence.

Associativity (Left-to-Right or Right-to-Left) determines the order of evaluation when operators have the same precedence (e.g., in A + B - C, the evaluation goes left-to-right).

Precedence Rules Summary

Operators are evaluated in descending order of precedence (top to bottom):

  • Highest Precedence: Scope (::), Postfix/Unary (++, --, (), ., ->, sizeof, Unary !, ~, +, -).
  • Multiplicative: *, /, % (Left-to-Right).
  • Additive: +, - (Left-to-Right).
  • Relational and Equality: <, <=, >, >=, ==, != (Left-to-Right).
  • Logical: &&, || (Left-to-Right).
  • Conditional: ?: (Right-to-Left).
  • Lowest Precedence: Assignment (=, +=, etc., Right-to-Left) and Comma (,).

To explicitly override precedence, use **parentheses (())**, which are the highest precedence group.

Example Walkthrough (a=20, b=10, c=15, d=5)

Case 1: e = (a + b) * c / d;

  1. **Parentheses:** (a + b) is evaluated first: $20 + 10 = 30$. Expression becomes: e = 30 * c / d;
  2. **Multiplication/Division:** These have the same precedence, so they are evaluated Left-to-Right.
    • $30 * 15 = 450$. Expression becomes: e = 450 / d;
    • $450 / 5 = 90$.
Value of (a + b) * c / d is :90

Case 2: e = ((a + b) * c) / d; and e = (a + b) * (c / d);

These two expressions yield the same result (90), showing how parentheses group the elements differently but lead to the same mathematical outcome.

  • ((a + b) * c) / d: $((30) * 15) / 5 \rightarrow 450 / 5 = 90$
  • (a + b) * (c / d): $(30) * (3) \rightarrow 90$

Case 3: e = a + (b * c) / d;

  1. **Parentheses:** (b * c) is evaluated first: $10 * 15 = 150$. Expression becomes: e = a + 150 / d;
  2. **Multiplication/Division** (Higher Precedence): $150 / 5 = 30$. Expression becomes: e = a + 30;
  3. **Addition:** $20 + 30 = 50$.

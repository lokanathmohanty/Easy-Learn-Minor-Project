CSS - Media Queries

Media queries in CSS are used to apply different styles depending on the screen size, resolution, orientation, or other characteristics of the device. They use the @media rule and are essential for responsive design, making websites adapt to mobile, tablet, and desktop devices.

Syntax

@media not|only mediatype and (media feature) and (media feature) {
   /* CSS styles */
}

- media-type examples: screen, print, speech.
- media-feature examples: width, height, orientation.

Media Types

  • all: Applies to all devices.
  • print: Applies only when printing.
  • screen: Applies to device screens like mobiles, tablets, and desktops.

CSS Media Type Print

Print styles are optimized for paper, usually removing dark backgrounds and using simple colors to save ink. 

@media print {
  body {
    background-color: white;
    color: black;
  }
}

CSS Media Type All

The all keyword applies styles across all devices including screen and print. 

@media all {
  body {
    font-size: 16px;
  }
}

CSS Media Type Screen

Used for devices with screens. Often combined with screen width checks for responsiveness. 

@media screen and (max-width: 500px) {
  .container {
    flex-direction: column;
  }
}

Width Ranges for Media Queries

You can set rules for specific screen width ranges. 

@media (min-width: 600px) and (max-width: 800px) {
  p {
    background-color: yellow;
    color: red;
  }
}

Combining Media Queries

Multiple queries can be combined using a comma, which acts like an OR operator. 

@media (min-width: 500px), print {
  body {
    background-color: black;
    color: white;
  }
}

CSS Media Type With Only

Using only ensures that the rule applies only if the entire media query matches. 

@media only screen and (min-width: 500px) and (max-width: 700px) {
  body {
    background-color: pink;
    color: blue;
  }
}

CSS Media Queries AND Operator

The and operator lets you combine multiple conditions. All must be true for the styles to apply. 

@media (min-width: 500px) and (max-width: 700px) {
  body {
    background-color: lightgreen;
    color: blue;
  }
}

Media Queries NOT Operator

The not operator negates the condition and applies styles only if the query does not match. 

@media not screen and (max-width: 700px) {
  body {
    background-color: orange;
    color: white;
  }
}

Creating Complex Media Queries

You can use and, not, and only operators together to create advanced queries. 

@media only screen and (min-width: 500px) and (max-width: 700px) {
  body {
    background-color: pink;
    color: blue;
  }
}
@media not screen and (max-width: 700px) {
  body {
    background-color: orange;
    color: white;
  }
}

Media Queries for Screen Orientation

You can apply styles based on whether the device is in portrait or landscape orientation. 

@media (min-width: 500px) and (orientation: landscape) {
  body {
    color: blue;
  }
}

List of Media Queries Features

Common media features include:

  • width - viewport width
  • height - viewport height
  • orientation - portrait or landscape
  • aspect-ratio - width to height ratio
  • hover - checks if device supports hover
  • pointer - checks pointer type (mouse, touch)
  • prefers-color-scheme - light or dark mode preference
  • prefers-reduced-motion - user preference to reduce animations
  • resolution - screen resolution in dpi

Practice Task

  • Create a responsive layout that changes from 2-column to 1-column below 600px.
  • Add print-specific styles that remove background colors.
  • Use orientation queries to style differently in landscape mode.
  • Experiment with prefers-color-scheme to create light/dark themes.

C# Basic Syntax: Rules and Structure

The Object-Oriented Foundation

C# is an **Object-Oriented Programming (OOP)** language. A program consists of **objects** that interact via **methods** (actions). Objects of the same kind are grouped into a **class**.

The basic structure includes: using statements, a **namespace**, at least one **class**, and the **Main()** method as the program's entry point.

Fundamental Syntax Rules

  • Case Sensitivity: C# treats names with different capitalization as separate identifiers (e.g., Age is different from age).
  • Statement Termination: Every statement must end with a **semicolon (;)**.
  • Code Blocks: **Curly braces ({})** are used to group statements together in classes, methods, loops, and conditional statements.
  • Whitespace: Extra spaces and newlines are ignored, but proper indentation is vital for readability.

Key Structural Components

  • The using Keyword: Includes necessary **namespaces** (like System) in the program.
  • The class Keyword: Declares a class, which holds member variables (attributes/data) and member functions (methods/behavior).
  • Identifiers: Names for classes, variables, and functions. They must begin with a letter or underscore, and cannot be a C# keyword.
  • Comments: Used to explain code. Single-line: //. Multi-line: /* ... */.

Example: Conditional Statement and Input/Output

Control Flow (If-Else)

int age = 18;
if (age >= 18)
{
    Console.WriteLine("You are eligible to vote.");
}

Data Input and Output

Output: Use Console.WriteLine() to print text.

Input: Use Console.ReadLine() to accept user input (e.g., a name).

Error Handling

Errors can be managed using a try-catch block to prevent program crashes:

try
{
    // Code that might cause an error
}
catch (Exception ex)
{
    Console.WriteLine("Error: " + ex.Message);
}

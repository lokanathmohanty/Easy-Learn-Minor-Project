CSS - Layers

CSS Layers are a concept used to control the stacking order of different DOM elements on a webpage. The z-index property determines the stacking order of elements within a stacking context.

Elements with a higher z-index value appear above those with a lower value. If elements share the same z-index, they stack according to their order in the DOM. This tutorial explores CSS layering in detail with examples.

CSS Layering With z-index Property

The z-index property is used to decide the stacking order of elements on a webpage. Elements with higher z-index values are placed above elements with lower values.

Example
<div class="box1">z-index: 1</div>
<div class="box2">z-index: 2</div>
<div class="box3">z-index: 3</div>
Layer Text Above Image

Using CSS position property, you can place text at different locations above an image. Set the image container to position: relative and text elements to position: absolute. Then, use inset properties like top, bottom, left, and right to control the text position.

Example
<div class="container">
   <img src="image.jpg" alt="sample image">
   <h3 class="center">Text at Center</h3>
   <h3 class="top-left">Text at Top Left</h3>
   <h3 class="top-right">Text at Top Right</h3>
   <h3 class="bottom-left">Text at Bottom Left</h3>
   <h3 class="bottom-right">Text at Bottom Right</h3>
</div>
Positioning Without z-index Property

It is possible to create layers without explicitly using the z-index property. Elements positioned absolutely can overlap naturally, depending on their DOM order.

Example
<div class="box1">Box 1</div>
<div class="box2">Box 2</div>
<div class="box3">Box 3</div>

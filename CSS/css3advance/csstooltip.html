CSS - Tooltips

CSS Tooltips are small pop-up boxes that appear when a user hovers over an element, providing additional information or context. Tooltips are styled and positioned using CSS properties like inset, translateX, translateY, etc.

How to Create Tooltips in CSS?

  1. Setting Up the Element: Add a button, image, or any element to trigger the tooltip.
  2. Create the Tooltip Text: Use a <span> to hold tooltip text and hide it initially with visibility: hidden.
  3. Position the Tooltip: Use position: absolute on tooltip, position: relative on container.
  4. Style the Tooltip: Add background, text color, padding, etc.
  5. Display on Hover: Use the :hover effect to show tooltip when user hovers.

Basic Tooltip

This example shows how to create a simple tooltip that displays when hovered: 

<div class="tooltip">
  Hover over this text
  <span class="tooltiptext">This is a tooltip</span>
</div>

Positioning Tooltips

Tooltips can be positioned around the container (top, bottom, left, right). The container is set to position: relative, while the tooltip is set to position: absolute. Example: 

.element {
   position: relative;
}
.tooltip {
   position: absolute;
   top: 50px;
   left: 50px;
}

Tooltip Arrows

Tooltip arrows are created using ::after pseudo-element with empty content and styled with border to create triangles. 

.tooltip-text::after {
    content: "";
    position: absolute;
    border-width: 5px;
    border-style: solid;
    border-color: black transparent transparent transparent;
}

Fade In Tooltips

By setting initial opacity: 0 and using transition, tooltips can fade in smoothly. 

.tooltip .tooltiptext {
   opacity: 0;
   transition: opacity 2s;
}
.tooltip:hover .tooltiptext {
   opacity: 1;
}

Advantages of Tooltips

  • Provide extra info without cluttering the webpage.
  • Help users understand elements better.
  • Highly customizable (colors, fonts, animations).
  • Easy to implement without complex JavaScript.

PHP Arrow Functions (PHP 7.4+)

**Arrow Functions** (introduced in PHP 7.4) provide a concise, single-expression syntax for writing **Anonymous Functions** (Closures). They are designed for simplicity, making short, one-line callback functions much cleaner and more readable.

Syntax and Core Features

Arrow functions replace the `function` keyword with **`fn`** and automatically handle the return value.

1. Implicit Return

There is only one expression after the `=>` operator, and its calculated value is **automatically returned** without the need for an explicit `return` statement.

**Syntax:** fn (argument_list) **=> expr**

**Example:**
$add = **fn** ($a, $b) **=>** $a + $b;

2. Automatic Scope Access (Implicit `use`)

Unlike traditional anonymous functions (which require the `use` keyword), arrow functions **automatically capture variables by value** from the parent scope, allowing them to act as closures without the verbose syntax.

$maxmarks = 300;
$percent = fn ($marks) => $marks * 100 / **$maxmarks**;

**Implicit Capture:** The `$maxmarks` variable is accessed directly from the parent scope.

Usage as Callback Functions

Arrow functions are perfectly suited for quick, inline callbacks used in array functions.

Filtering an Array (`array_filter`)

$numbers = [1, 2, 3, 4, 5];
$evenNumbers = **array_filter**($numbers, **fn($n) => $n % 2 === 0**);

The result is `[2, 4]`.

Transforming an Array (`array_map`)

$nums = [1, 2, 3];
$squared = **array_map**(**fn($n) => $n * $n**, $nums);

The result is `[1, 4, 9]`.

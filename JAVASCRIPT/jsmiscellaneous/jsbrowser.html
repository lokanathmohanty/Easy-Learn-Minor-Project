JavaScript - Browsers Compatibility

It is important to understand the differences between different browsers in order to handle each in the way it is expected. To know which browser your web page is running in, you can use the built-in navigator object.

Navigator Properties

The following are commonly used navigator-related properties:

  • appCodeName − Contains the code name of the browser.
  • appVersion − Contains the version of the browser and other useful details.
  • language − Two-letter abbreviation for the language used by the browser (Netscape only).
  • mimeTypes[] − Array of MIME types supported by the client (Netscape only).
  • platform − Contains the platform for which the browser was compiled, e.g. "Win32".
  • plugins[] − Array of plug-ins installed on the client (Netscape only).
  • userAgent − String with the code name and version of the browser, sent to the server for identification.

Navigator Methods

Navigator also provides some methods:

  • javaEnabled() − Returns true if Java is enabled in the browser.
  • plugins.refresh − Refreshes the plugins array after new plug-ins are installed (Netscape only).
  • preference(name, value) − Gets or sets Netscape browser preferences (Netscape only).
  • taintEnabled() − Returns true if data tainting is enabled.

Browser Detection

You can use JavaScript to detect the browser name and serve content accordingly.

Example

<html>   
   <head>
      <title>Browser Detection Example</title>
   </head>
   
   <body>      
      <script type = "text/javascript">
         var userAgent   = navigator.userAgent;
         var opera       = (userAgent.indexOf('Opera') != -1);
         var ie          = (userAgent.indexOf('MSIE') != -1);
         var gecko       = (userAgent.indexOf('Gecko') != -1);
         var netscape    = (userAgent.indexOf('Mozilla') != -1);
         var version     = navigator.appVersion;
            
         if (opera) {
            document.write("Opera based browser");
         } else if (gecko) {
            document.write("Mozilla based browser");
         } else if (ie) {
            document.write("IE based browser");
         } else if (netscape) {
            document.write("Netscape based browser");
         } else {
            document.write("Unknown browser");
         }
          
         document.write("<br /> Browser version info : " + version );
      </script>      
   </body>
</html>

Output

When executed, the script displays the detected browser type and version information.

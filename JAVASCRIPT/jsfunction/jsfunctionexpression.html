JavaScript — Function Expressions

Introduction

A function expression allows us to define a JavaScript function inside an expression. Unlike function declarations, the function name can be omitted, making it possible to create anonymous functions.

Function expressions can be stored in variables and invoked using the variable name.

Syntax

function (parameter-list) {
  statements
};

Typically, we store a function expression in a variable: 

const varName = function (parameter-list) {
  statements
};

Example: 

const sum = function (x, y) {
  return x + y;
};
let z = sum(2, 3);

In the above code, the function expression is assigned to the variable sum, which is then used to invoke the function.

Named Function Expression

Function expressions can also be named, though they are still invoked using the variable reference. 

const sum = function addNumbers(x, y) {
  return x + y;
};
let z = sum(2, 3);

Note: The function name addNumbers cannot be used directly to invoke the function — only sum can be used.

Immediately Invoked Function Expression (IIFE)

Function expressions can be executed immediately after definition using parentheses. This is known as an Immediately Invoked Function Expression (IIFE). 

(function greet() {
  alert("Hello World");
})();

Examples

Example: Function Expression

const sum = function () {
  let a = 10;
  let b = 20;
  document.getElementById("output").innerHTML =
    "The sum of " + a + " and " + b + " is " + (a + b);
};
sum();

Output: The sum of 10 and 20 is 30

Example: The return Statement

const mul = function (a, b) {
  return a * b;
};
let result = mul(4, 5);
document.getElementById("output").innerHTML =
  "The returned value from the function is " + result;

Output: The returned value from the function is 20

Example: Function Expression as a Value

const num = function () {
  return 2;
};
let result = num() * 3;
document.getElementById("output").innerHTML =
  "The multiplication value is " + result;

Output: The multiplication value is 6

Example: Nested Function Expression

const num = function () {
  const decimal = function () {
    return 5;
  };
  return decimal();
};
document.getElementById("output").innerHTML =
  "The returned value from the function is " + num();

Output: The returned value from the function is 5

Key Points

  • Function expressions can be anonymous or named.
  • They must be stored in a variable or passed as a value.
  • IIFE allows executing functions immediately after definition.
  • Functions in expressions can return values like normal functions.
  • Function expressions can be nested inside other functions.

Practice Tasks

  • Write an anonymous function expression that squares a number.
  • Create an IIFE that prints “Welcome to JavaScript”.
  • Write a nested function expression that returns the cube of a number.

Summary

Function expressions provide flexibility in defining functions as variables, anonymous functions, or even immediate executions (IIFE). They are widely used in modern JavaScript to create concise, reusable, and modular code.

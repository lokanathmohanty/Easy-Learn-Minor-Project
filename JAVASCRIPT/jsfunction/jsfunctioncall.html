JavaScript - Function call() Method

The Function call() method allows us to invoke a function with a specific value for this and arguments provided individually.

When a normal function is called, the value of this inside the function is the object that the function was accessed on. By using call(), we can manipulate the this value and assign an arbitrary object as its context.

In other words, we can call an existing function as a method of an object without attaching it as a property.

Every function in JavaScript is a Function object. The Function object provides properties and methods such as call(), apply(), and bind() that are shared by all functions.

Syntax

funcName.call(thisArg, arg1, arg2, ... argN);

  • funcName − The name of the function to invoke.
  • thisArg − The context object whose properties or methods can be accessed using this.
  • arg1, arg2, ... argN − Optional arguments passed individually.

By default, the function context is the global object (window in browsers).

Return value: The result returned by the function.

Examples

Function call() method without specifying arguments


function test() {
  return "The function is invoked!";
}
test();
test.call();

Output:

  • The function is invoked!
  • The function is invoked!

Function call() method with this argument only


function printMessage() {
  return "The age of the " + this.name + " is " + this.age;
}

const person1 = { name: "John Doe", age: 22 };
const person2 = { name: "Jane Doe", age: 40 };

printMessage.call(person1);
printMessage.call(person2);

Output:

  • The age of the John Doe is 22
  • The age of the Jane Doe is 40

Function call() method with multiple arguments


function printSum(p1, p2) {
  return this.num1 + this.num2 + p1 + p2;
}

const nums = { num1: 5, num2: 10 };

printSum.call(nums, 40, 32);

Output: Total sum is 87

Using a method of a different object


const student = {
  getAge: function() {
    return this.age;
  }
};

const student1 = { name: "John", age: 22 };
const student2 = { name: "Doe", age: 18 };

student.getAge.call(student1);
student.getAge.call(student2);

Output:

  • 22
  • 18

The call() and apply() methods are similar, with the key difference being:

  • call() accepts arguments individually.
  • apply() accepts arguments as an array.

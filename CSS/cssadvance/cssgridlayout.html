CSS - Grid Layout

CSS Grid Layout is a two-dimensional layout system for developing responsive webpages. In this tutorial, we will learn how to design a webpage layout using grid systems.

What is a Grid Layout?

Grid Layout enhances user experience across devices by providing a responsive and flexible arrangement of HTML components on a webpage.

Grid is ideal for creating the overall layout of a webpage, while flexbox is mostly used to align items inside a container.

Grid Elements

In a grid layout system, we have two elements: Grid Container and Grid Items.

Grid Container defines the outer element of a grid, where all child elements are present. It is defined by setting display: grid or display: inline-grid.

Grid Items are all the direct children inside the grid container. These items can be arranged vertically and horizontally based on the grid definitions.

Display Grid Property

An HTML element becomes a grid container if we set its display property to grid or inline-grid. All direct children of the grid container automatically become grid items.

  • grid: Defines a block-level grid container (like a div).
  • inline-grid: Defines an inline-level grid container (like a span).

Example: Grid vs Inline-Grid

<!DOCTYPE html>
<html lang="en">
<head>
   <style>
      .grid-container {
         display: grid;
         grid-template-columns: 1fr 1fr 1fr;
         gap: 10px;
         width: 100%;
         background-color: lightblue;
      }
      .inline-grid-container {
         display: inline-grid;
         grid-template-columns: 1fr 1fr 1fr;
         gap: 10px;
         background-color: lightgreen;
      }
      .grid-item {
         background-color: lightcoral;
         padding: 20px;
         text-align: center;
      }
   </style>
</head>
<body>
   <h3>Inline Grid Example</h3>
   <p>
      Here is an example of 
      <span class="inline-grid-container">
         <span class="grid-item">1</span>
         <span class="grid-item">2</span>
         <span class="grid-item">3</span>
      </span> 
      inline grid.
   </p>
   
   <h3>Grid Example</h3>
   <div class="grid-container">
      <div class="grid-item">1</div>
      <div class="grid-item">2</div>
      <div class="grid-item">3</div>
   </div>
</body>
</html>

Grid Rows and Columns

In CSS, we can define the number of rows and columns required in a layout. Each cell represents a grid item. Below is an example showing separate row and column definitions.

Example: Rows and Columns

<!DOCTYPE html>
<html lang="en">
<head>
    <style>
        .grid-container {
            display: grid;
            gap: 10px;
            padding: 10px;
            width: 75%;
        }
        .grid-item {
            background-color: #4CAF50;
            border: 1px solid #ddd;
            padding: 20px;
            text-align: center;
            font-size: 1.2em;
            color: white;
        }
        .row{
            grid-template-columns: 1fr;
            grid-template-rows: repeat(3, 1fr);
        }
        .column{
            grid-template-columns: repeat(3, 1fr);
            grid-template-rows: 1fr;
        }
    </style>
</head>
<body>
    <h1>Grid Layout Example</h1>
    <h3>Grid Rows - 3 Rows X 1 Column</h3>
    <div class="grid-container row">
      <div class="grid-item">Item 1</div>
      <div class="grid-item">Item 2</div>
      <div class="grid-item">Item 3</div>
    </div>
    
    <h3>Grid Columns - 1 Row X 3 Columns</h3>
    <div class="grid-container column">
      <div class="grid-item">Item 1</div>
      <div class="grid-item">Item 2</div>
      <div class="grid-item">Item 3</div>
    </div>
</body>
</html>

Grid Gap

The gap properties add space between rows and columns of grid items.

  • gap: sets equal gaps for both rows and columns.
  • row-gap: sets the vertical gap (overrides gap).
  • column-gap: sets the horizontal gap (overrides gap).

Example: Grid Gap

<!DOCTYPE html>
<html lang="en">
<head>
   <style>
      .grid-container {
         display: grid;
         grid-template-columns: 1fr 1fr 1fr;
         grid-template-rows: 100px 100px 100px;

         /* Sets both row and column gaps to 20px */
         gap: 20px; 
         /* Overrides with row and column gaps */
         row-gap: 10px; 
         column-gap: 5px; 
      }
      .grid-item {
         background-color: #4CAF50;
         border: 1px solid #ddd;
         padding: 20px;
         text-align: center;
         font-size: 1.2em;
         color: white;
      }
   </style>
</head>

<body>
    <h1>Grid Gap Example</h1>
    <div class="grid-container">
      <div class="grid-item">Item 1</div>
      <div class="grid-item">Item 2</div>
      <div class="grid-item">Item 3</div>
      <div class="grid-item">Item 4</div>
      <div class="grid-item">Item 5</div>
      <div class="grid-item">Item 6</div>
    </div>
</body>
</html>

CSS Grid Lines

Grid items can be placed according to the imaginary lines between grid cells called grid lines. The lines between columns are called column lines, and the lines between rows are called row lines.

CSS Grid Properties Reference

  • display – Defines whether an element is a grid container or inline grid container.
  • gap – Defines the gap between rows and columns.
  • grid-area – Defines the location and size of a grid item.
  • grid-column – Controls placement in the column direction.
  • grid-row – Controls placement in the row direction.
  • grid-template – Specifies grid columns, rows, and areas.
  • grid-auto-columns – Determines size of automatically generated columns.
  • grid-auto-rows – Determines size of automatically generated rows.
  • grid-auto-flow – Specifies arrangement of auto-placed items.

Python - Higher Order Functions

Higher-order functions in Python either take one or more functions as arguments or return a function as their result. This feature enhances flexibility and reusability in code by allowing functions to be treated like any other object.

Functions can be stored in variables, passed as parameters, stored in data structures, or returned from other functions. Higher-order functions can be created using nested scopes or callable objects. The functools module also offers utilities to work with them.

Creating Higher Order Function with Nested Scopes

def multiplier(a):
   def multiply(b):
      return a * b
   return multiply

multiply_second_number = multiplier(5)
Result = multiply_second_number(10)
print("Multiplication of Two numbers is: ", Result)

This example defines a function that returns another function, capturing the variable a in its closure. Calling multiplier(5) returns a function that multiplies its argument by 5.

Creating Higher-Order Functions with Callable Objects

class Multiplier:
   def __init__(self, factor):
      self.factor = factor

   def __call__(self, x):
      return self.factor * x

multiply_second_number = Multiplier(2)
Result = multiply_second_number(100)
print("Multiplication of Two numbers is: ", Result)

Here, the class Multiplier is a callable object because it implements the __call__ method, allowing instances to act like functions that multiply input by a factor.

Using Higher-Order Functions: functools.wraps()

import functools

def my_decorator(f):
   @functools.wraps(f)
   def wrapper(*args, **kwargs):
      print("Calling", f.__name__)
      return f(*args, **kwargs)
   return wrapper

@my_decorator
def invite(name):
   print(f"Welcome to, {name}!")

invite("Tutorialspoint")

This example demonstrates a higher-order decorator function that wraps another function, preserving its metadata using functools.wraps.

Using functools.partial()

import functools

def myfunction(a, b):
   return a * b

partfunction = functools.partial(myfunction, b=10)
print(partfunction(10))

The partial() function creates a new function by freezing some arguments of an existing one, simplifying call signatures for reuse.

Using functools.reduce()

import functools

def mult(x, y):
   return x * y

n = 4
num = functools.reduce(mult, range(1, n+1))
print(f'Factorial of {n}: ', num)

The reduce() function applies a binary function cumulatively to the items in an iterable, for example calculating the factorial of a number.

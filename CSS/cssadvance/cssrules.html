CSS - @ Rules

CSS at-rules are special instructions or statements beginning with the "@" symbol. They control or modify the behavior of the stylesheet and extend CSS capabilities beyond basic selectors and property-value pairs. They can define external stylesheets, apply styles conditionally, manage fonts, animations, and more.

An at-rule begins with an at (@) sign, followed by an identifier, and includes everything up to the next semicolon or CSS block.

Syntax

General structure of an at-rule:

@identifier (RULE);

Types of @ Rules

Regular At-Rules

  • @charset: Specifies the character encoding of an external stylesheet.
  • @import: Imports an external CSS file into the current stylesheet.
  • @namespace: Declares and defines XML namespaces within a CSS stylesheet.

Nested At-Rules

  • @media: Applies styles if the device meets defined conditions.
  • @supports: Applies styles if the browser supports the given condition.
  • @page: Defines the layout of printed pages.
  • @font-face: Defines custom fonts to be used in a webpage.
  • @keyframes: Defines steps for CSS animations.
  • @counter-style: Defines custom counter styles.
  • @font-feature-values: Handles alternate glyphs in OpenType fonts.
  • @property: Defines custom properties and variables.
  • @layer: Creates cascade layers with precedence order.

Example: @page

This example demonstrates the usage of the @page rule to control printing layout:

@page :first {
   margin-left: 80%;
   margin-top: 80%;
}

p {
   page-break-after: always;
}

Example: @keyframes

This example shows how to use @keyframes for animation:

p {
   animation-duration: 3s;
   animation-name: slidein;
}

@keyframes slidein {
   from {
      margin-left: 100%;
      width: 300%;
   }
   to {
      margin-left: 0%;
      width: 100%;
   }
}

Example: @property

This example shows defining and using a custom property with @property:

@property --item-size {
   syntax: "<percentage>";
   inherits: true;
   initial-value: 40%;
}

.container {
   display: flex;
   height: 100px;
   --item-size: 50%;
   --item-color: tomato;
   --item-border: 5px solid green;
}

.item {
   width: var(--item-size);
   height: var(--item-size);
   border: var(--item-border);
   background-color: var(--item-color);
}

List of CSS @ Rules

  • @charset "UTF-8";
  • @container (width > 400px) { h1 { font-size: 2em; } }
  • @counter-style sample {}
  • @font-face { font-family: "CustomFont"; src: url("customfont.woff2") format("woff2"); }
  • @font-feature-values "CustomFont" { @swash { fancy: 2; } }
  • @font-palette-values One { font-family: "Bungee Spice"; }
  • @import url("style.css");
  • @keyframes sample-slide { from { transform: translateY(100%); } }
  • @layer sample-layer { .margin-lg { margin: 5px; } }
  • @media screen and (max-width: 600px) {}
  • @namespace svg url();
  • @page { size: 5in 6in; margin-left: 4in; }
  • @property sample-property { rules }
  • @supports (transform-origin: 10% 10%) {}

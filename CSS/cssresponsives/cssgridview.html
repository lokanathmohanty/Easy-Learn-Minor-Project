CSS - RWD Grid View

A responsive webpage always uses a grid layout structure, as it can be easily adapted to different screen sizes and devices. In this session, we will discuss grid view in responsive web development and how to design a grid-based responsive website.

What is Grid View?

In responsive web design, a grid view is a layout structure that uses a grid-based system to arrange layout elements in rows and columns. A typical grid view may have 12 columns, and has a total width of 100%. The grid will shrink and expand as the size of the browser changes.

Building a Responsive Grid View

  • Set Border Box: Use box-sizing: border-box; so that padding and border are included in the total width and height of elements.
  • Set Width of Column: Decide the number of columns. For example, in a 3-column layout, each column width would be 100% / 3 = 33.33%.
  • Use Media Queries: Add breakpoints for different screen widths to ensure responsiveness.

Grid Rows and Columns

In CSS, we can define the number of rows and columns required in our layout. Each cell will represent a grid item.

Example: Grid Layout

In this example, we create one grid layout for rows and another for columns:

<h1>Grid Layout Example</h1>

<h3>Grid Rows</h3>
<div class="grid-container row">
   <div class="grid-item">Item 1</div>
   <div class="grid-item">Item 2</div>
   <div class="grid-item">Item 3</div>
</div>

<h3>Grid Columns</h3>
<div class="grid-container column">
   <div class="grid-item">Item 1</div>
   <div class="grid-item">Item 2</div>
   <div class="grid-item">Item 3</div>
</div>

12 Column Layout

The 12-column layout structure involves dividing the container into 12 equal-width columns, so that elements can span across a specified number of columns to create flexible sections.

Example: 12 Column Grid

Here’s an example of a 12-column responsive layout:

<div class="grid-container">
   <div class="col-span-12">Header (12 columns)</div>

   <div class="col-span-8">Main Content (8 columns)</div>
   <div class="col-span-4">Sidebar (4 columns)</div>

   <div class="col-span-3">Footer Link 1 (3 columns)</div>
   <div class="col-span-3">Footer Link 2 (3 columns)</div>
   <div class="col-span-3">Footer Link 3 (3 columns)</div>
   <div class="col-span-3">Footer Link 4 (3 columns)</div>
</div>

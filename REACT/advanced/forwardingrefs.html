ReactJS - Forwarding Refs

Refs allow direct manipulation of DOM elements, bypassing state updates. However, when a ref needs to be applied to a React component and passed down to a deeper DOM element, we use Forwarding Refs. This enables parent components to access and control child DOM nodes directly.

Signature of forwardRef()

const NewComponent = React.forwardRef((props, ref) => {
   // return JSX and attach the ref
});

Example of forwarding a ref: 

const MyInput = React.forwardRef((props, ref) => (
   <input type="text" ref={ref} value={props.value} />
));

const myRef = React.createRef();

<MyInput ref={myRef} value="Hi" />
  • MyInput receives the ref from the parent and attaches it to <input>.
  • myRef is created in the parent using React.createRef().
  • myRef.current points directly to the underlying DOM input element.

Applying Forwarding Ref in a Component

Create a new React app and add the following component:

SimpleForwardRef.js

import React from "react";

const SimpleForwardRef = React.forwardRef((props, ref) => (
   <input type="text" ref={ref} value={props.value} />
));

export default SimpleForwardRef;
  • Uses forwardRef to pass ref down to the input element.
  • Input element receives the ref via ref prop.

App.js

import './App.css'
import React, { useEffect } from 'react';
import SimpleForwardRef from './Components/SimpleForwardRef';

function App() {
   const myRef = React.createRef();

   useEffect(() => {
      setTimeout(() => {
         myRef.current.value = "Hello";
      }, 5000);
   });

   return (
      <div className="container">
         <div style={{ padding: "10px" }}>
            <SimpleForwardRef ref={myRef} value="Hi" />
         </div>
      </div>
   );
}

export default App;
  • myRef is created in the App component.
  • myRef is passed into SimpleForwardRef.
  • useEffect changes the input value from Hi to Hello after 5 seconds.

Summary

Forwarding Refs extends React’s ref mechanism, allowing DOM elements deep in the component tree to be accessed and manipulated directly. This is useful for forms, animations, or integrating with third-party libraries that require direct DOM access.

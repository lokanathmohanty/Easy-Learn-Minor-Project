JavaScript - Async Iteration

Asynchronous Iteration

In JavaScript, asynchronous iteration refers to the ability to iterate over asynchronous sequences or collections, such as those returned by asynchronous functions or generators. It is useful when working with tasks like fetching remote data, reading files, or handling streams.

Understanding Asynchronous Operations

Asynchronous operations are tasks that do not block program execution while they are pending. Instead of pausing for each task to finish, the program continues executing other tasks, while waiting for asynchronous tasks to resolve.

Using the for await...of Loop

The for await...of loop is used for asynchronous iteration. It works like a regular for...of loop, but it supports asynchronous iterators. An async iterator defines an async next() method that returns a promise for the next value in the sequence.

Example 1: Using Promises

function asyncOperation(value) {
  return new Promise(resolve => {
    setTimeout(() => {
      console.log("Processed:", value);
      resolve(value);
    }, 1000);
  });
}

const asyncIterable = {
  async *[Symbol.asyncIterator]() {
    for (let i = 1; i <= 3; i++) {
      yield await asyncOperation(i);
    }
  }
};

async function processAsyncIterable() {
  for await (const result of asyncIterable) {
    console.log("Received:", result);
  }
}

processAsyncIterable();

Example 2: Using Fetch API

const url = 'https://jsonplaceholder.typicode.com/todos/';

const asyncIterable = {
  async *[Symbol.asyncIterator]() {
    for (let i = 1; i <= 3; i++) {
      const response = await fetch(`${url}${i}`);
      const data = await response.json();
      console.log("Received:", data);
      yield data;
    }
  }
};

async function processAsyncIterable() {
  for await (const result of asyncIterable) {
    // Each result is logged above.
  }
}

processAsyncIterable();

Example 3: Using Callbacks

function asyncOperation(value, callback) {
  setTimeout(() => {
    console.log("Processed:", value);
    callback(value);
  }, 1000);
}

function processAsyncIterable(iterable, callback) {
  const iterator = iterable[Symbol.iterator]();
  function iterate() {
    const next = iterator.next();
    if (next.done) return;
    asyncOperation(next.value, result => {
      console.log("Received:", result);
      iterate();
    });
  }
  iterate();
}

const asyncIterable = [5, 6, 7, 8, 9, 10];
processAsyncIterable(asyncIterable, result => {
  // Handle final result if needed.
});

Example 4: Promise with Error Handling

function delay(ms) {
  return new Promise(resolve => setTimeout(resolve, ms));
}

function fetchData(index) {
  return new Promise((resolve, reject) => {
    if (index < 5) {
      delay(1000).then(() => resolve(`Data ${index}`));
    } else {
      reject(new Error("Error fetching data for index 5"));
    }
  });
}

function startAsyncIteration() {
  let index = 0;
  function iterate() {
    fetchData(index)
      .then(data => {
        console.log("Data received:", data);
        index++;
        if (index < 6) iterate();
      })
      .catch(error => {
        console.error("Error:", error.message);
      });
  }
  iterate();
}

startAsyncIteration();

Real World Use Cases

Async iteration is useful in many scenarios, such as:

  • Fetching data concurrently from multiple APIs
  • Processing real-time updates (e.g., chat systems)
  • Handling batch or parallel tasks efficiently
  • Managing file operations and streams
  • Processing IoT device data
  • Dynamically loading web content
  • Synchronizing data in offline-first applications

NumPy Trigonometric Functions

NumPy provides the ufuncs sin(), cos(), and tan() that take values in radians and return the corresponding sine, cosine, and tangent values.

Example: Find sine value of PI/2

import numpy as np

x = np.sin(np.pi/2)

print(x)

Example: Find sine values for an array

import numpy as np

arr = np.array([np.pi/2, np.pi/3, np.pi/4, np.pi/5])

x = np.sin(arr)

print(x)

Convert Degrees Into Radians

All trigonometric functions take radians as input by default. You can convert degrees to radians using deg2rad().

Note: radians = (π / 180) * degree_values

Example: Convert degrees to radians

import numpy as np

arr = np.array([90, 180, 270, 360])

x = np.deg2rad(arr)

print(x)

Convert Radians Into Degrees

Convert radians to degrees using rad2deg().

Example: Convert radians to degrees

import numpy as np

arr = np.array([np.pi/2, np.pi, 1.5*np.pi, 2*np.pi])

x = np.rad2deg(arr)

print(x)

Finding Angles from Sine, Cosine, and Tangent Values

NumPy provides the inverse functions arcsin(), arccos(), and arctan() that return angles in radians for given sine, cosine, or tangent values.

Example: Find angle of 1.0 using arcsin()

import numpy as np

x = np.arcsin(1.0)

print(x)

Example: Find angles for an array of sine values

import numpy as np

arr = np.array([1, -1, 0.1])

x = np.arcsin(arr)

print(x)

Finding Hypotenuse Using Pythagoras Theorem

NumPy provides the hypot() function which calculates the hypotenuse given base and perpendicular lengths.

Example: Find hypotenuse for base=3 and perpendicular=4

import numpy as np

base = 3
perp = 4

x = np.hypot(base, perp)

print(x)

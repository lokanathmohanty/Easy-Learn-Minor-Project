JavaScript - this Keyword

What is 'this' keyword?

In JavaScript, the this keyword contains the reference to the object. It represents the context of the function or current code. It is used to access the properties and methods of the current object.

When this is used inside a function, it refers to the object that the function is called with. Since functions are also objects in JavaScript, you can also use this with them.

Which object does 'this' refer to?

  • In the global scope, this refers to the window object.
  • Inside a function, it usually represents the window object.
  • In strict mode functions, it becomes undefined.
  • In object methods, it refers to the object itself.
  • In event handlers, it refers to the element where the event occurred.
  • With call(), apply(), or bind(), you can explicitly set it.

Syntax

this.property
this.method();

Examples

'this' in the Global Scope

var num = 10;
function printNum() {
   console.log(this.num);
}
this.printNum(); // 10

'this' in a Function

var message = "Hello World!";
function printMessage() {
   var message = "Hi!";
   console.log(this.message);
}
printMessage(); // "Hello World!"

'this' in Strict Mode

"use strict";
function test() {
   console.log(this); 
}
test(); // undefined

'this' in a Constructor Function

function Animal() {
   this.name = "Lion";
   this.age = 3;
}
const newAnimal = new Animal();
console.log(newAnimal.name); // Lion

'this' in an Arrow Function

const wall = {
  size: "10",
  color: "blue",
  getDetails() {
    const getInnerDetails = () => {
      console.log(this); // wall object
    }
    getInnerDetails();
  }
};
wall.getDetails();

'this' in an Object Method

const fruit = {
   name: "Apple",
   color: "Red",
   printDetails() {
      console.log(this.name, this.color);
   }
}
fruit.printDetails(); // Apple Red

'this' in a Child Function of an Object Method

const person = {
   name: "Salman",
   printDetails() {
      function inner() {
         console.log(this); // Window
      }
      inner();
   }
}
person.printDetails();

'this' in Event Handlers

<div onclick="this.style.display='none'">Click me</div>

Explicit Function Binding

Using call():

const lion = {
   color: "Yellow",
   age: 10,
   printDetails() {
      console.log(this.color, this.age);
   }
}
const tiger = { color: "Orange", age: 15 };
lion.printDetails.call(tiger); // Orange 15

Using bind():

const tigerDetails = lion.printDetails.bind(tiger);
tigerDetails(); // Orange 15

'this' Precedence

  1. bind() method
  2. call() and apply() methods
  3. Object method
  4. Global scope

C++ Default Constructors ⚙️

A **default constructor** is a special member function of a class that is executed automatically when an object is created **without any arguments**. It is primarily used for setting initial, sensible values for the object's data members.

  • It has the **same name** as the class.
  • It takes **no parameters**.
  • It has **no return type** (not even `void`).

Syntax

class MyClass {
   public:
      MyClass() {
         // Initialization code
      }
};

Implicit vs. Explicit Default Constructors

  • Implicit Default Constructor (Compiler-Generated): If a class does not define **any** constructors, the C++ compiler automatically provides a public, inline, and trivial default constructor. This constructor performs no action (but zero-initializes members if the object is initialized with empty braces: `MyClass obj{};`). 
    class MyClass { // No constructor defined
   int x;
}; 
// Compiler generates MyClass::MyClass()
  • Explicit Default Constructor (User-Defined): This is a constructor you write yourself. If you write one, the compiler **will not** generate the implicit one. You can use it to set custom initial values. 
    class MyClass {
   public:
      MyClass() { // Explicitly defined by programmer
         num1 = 10;
      }
};

When is a Default Constructor Called?

The default constructor is invoked in several situations:

  • When an object is created without arguments: `DemoDC obj;`
  • When dynamically allocating an object without parentheses: `DemoDC* ptr = new DemoDC;`
  • When creating an array of objects: `DemoDC objArray[5];` (The default constructor is called 5 times).

Overloading the Default Constructor

**Constructor Overloading** is the ability to have multiple constructors in a single class, as long as each has a unique parameter list (different number or types of parameters).

In this context, a "default constructor" can be considered any constructor that can be called without providing arguments. This includes:

  1. The constructor with an **empty parameter list**.
  2. Any **parameterized constructor** where **all parameters have default values**.
class MyClass {
   public:
      // 1. True Default constructor
      MyClass() { /* a=0, b=0 */ } 

      // 2. Overloaded constructor (can also act as default if called without args)
      MyClass(int x, int y = 0) { /* ... */ } 
};

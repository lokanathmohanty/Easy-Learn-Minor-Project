JavaScript - Execution Context

What is Execution Context?

The execution context is a term that describes the internal workings of code. The JavaScript Execution Context describes the environment in which JavaScript code can be run. The execution context specifies which code sections have access to the functions, variables and objects used in the code.

During the execution context, the given code is parsed line by line, with variables and functions kept in memory. An execution context is similar to a container for storing variables; code is evaluated and then executed.

Types of Execution Context

  • Global Execution Context (GEC)
  • Functional Execution Context (FEC)
  • Eval Execution Context

Global Execution Context (GEC)

The GEC is the base or default execution. Any JavaScript code that does not occur inside a function is found here. It creates the global object (window in browsers, global in Node.js), binds this to it, and stores all variable/function declarations in memory.

Functional Execution Context (FEC)

A new FEC is created whenever a function is called. Each function has its own execution context but also has access to the GEC. Multiple FECs can exist at the same time while the GEC remains single.

Eval Execution Context

Any code executed inside eval() creates its own execution context. However, eval is rarely used in practice.

Phases of the Execution Context

  • Creation Phase: Memory allocation for variables and functions, scope chain setup.
  • Execution Phase: Code runs line by line, function calls are executed.

Example: Creation Phase

var n = 6;

function square(n) {
   var ans = n * n;
   return ans;
}
var sqr1 = square(n);
var sqr2 = square(8);

console.log(sqr1);
console.log(sqr2);

Output:

36
64

Execution Stack

The JavaScript engine uses a call stack to manage execution contexts. It follows the LIFO (Last-In-First-Out) principle. Each function call is pushed to the stack, and once completed, it is popped out.

Example: Execution Stack

function firstFunc(m,n) {
   return m * n;
}
function secondFunc(m,n) {
   return firstFunc(m,n);
}
function getResult(num1, num2) {
   return secondFunc(num1, num2);
}
var res = getResult(6,7);
console.log("The result is:", res);

Output:

The result is: 42

Stack Overflow Example

function display() {
   display();
}
display();

Output:

RangeError: Maximum call stack size exceeded

Summary

The execution context defines the environment in which JavaScript code runs. Understanding its creation and execution phases, as well as how the call stack works, is crucial to mastering JavaScript’s behavior behind the scenes.

Quick Guide to PHP 🐘

**PHP (Hypertext Preprocessor)** is a widely used, open-source scripting language especially suited for web development and can be embedded into HTML. It is executed on the server, generating HTML that is sent to the client's web browser.

Core Syntax

PHP Tags

PHP code is enclosed within standard tags:

<?php // PHP code here ?>

Use the short echo tag for quick output:

<?= $variable; ?>

Statements and Variables

All statements are terminated with a semicolon ($\text{;}$). Variables are declared using the dollar sign ($\text{\$}$):

<?php
   $message = "Hello, PHP!"; // Variable declaration
   echo $message;            // Output statement
?>

PHP is **case-sensitive** for variables, but generally **case-insensitive** for function and class names.

Data Types and Operators

Basic Data Types

  • **Scalar:** $\text{String}$, $\text{Integer}$, $\text{Float}$ ($\text{Double}$), $\text{Boolean}$.
  • **Compound:** $\text{Array}$ (indexed or associative), $\text{Object}$.

Concatenation

The dot ($\text{.}$) operator is used to join strings:

$full = "First" . " " . "Last";

Comparison

The **double equals ($\text{==}$)** compares values (loose), while the **triple equals ($\text{===}$)** compares both value and type (strict).

$a = 10;
$b = "10";
var_dump($a == $b);  // true (value is same)
var_dump($a === $b); // false (type is different)

The **spaceship operator ($\text{<=>}$)** returns -1, 0, or 1 for less than, equal to, or greater than, respectively.

Control Structures

Conditional Statements

if ($condition) {
    // code
} elseif ($other_condition) {
    // code
} else {
    // code
}

Loops

The $\text{foreach}$ loop is most common for iterating over arrays:

$colors = ['red', 'green', 'blue'];
foreach ($colors as $color) {
    echo $color;
}

Functions and Arrays

User-Defined Functions

function greet($name) {
    return "Hello, " . $name;
}
echo greet("Alice");

Arrays

Arrays can be indexed (numeric keys) or associative (string keys).

// Indexed
$names = ['Bob', 'Charlie'];

// Associative
$person = [
    'name' => 'Dave',
    'age' => 30
];
echo $person['name']; // Output: Dave

Superglobals

Built-in arrays available in all scopes, used for environmental and request data:

  • $\text{\$\_GET}$: Variables passed via $\text{URL}$ parameters.
  • $\text{\$\_POST}$: Variables passed via $\text{HTTP}$ $\text{POST}$ method.
  • $\text{\$\_SESSION}$: Session variables.
  • $\text{\$\_SERVER}$: Server and execution environment information.

Object-Oriented Programming (OOP)

PHP fully supports $\text{OOP}$ concepts including $\text{Classes}$, $\text{Objects}$, $\text{Inheritance}$, $\text{Interfaces}$, and $\text{Traits}$.

class Car {
    public $color;
    public function __construct($c) {
        $this->color = $c;
    }
}
$myCar = new Car("Red");

PHP - Constructor and Destructor

In PHP, the **Constructor** and **Destructor** are special methods used for object lifecycle management. The constructor initializes a new object upon creation, while the destructor automatically runs when an object is no longer referenced and is about to be destroyed.

The __construct() Function (Constructor)

The __construct() method is automatically called immediately after an object is created with the new operator. Its main purpose is to **initialize** the object's properties. 

__construct(mixed ...$values = ""): void
  • It is **not mandatory** to define a constructor.
  • It accepts any number of arguments (for initialization).
  • It does **not** return a value (void).

Default Constructor Example

A simple constructor initializes properties with fixed values. 

<?php
   class Book {
      var $title;
      var $price;
      
      function __construct(){
         $this->title = "PHP Fundamentals";
         $this->price = 275;
      }
      // ... getTitle() and getPrice() methods
   }

   $b1 = new Book; // __construct() is automatically called
   // Output: Title: PHP Fundamentals, Price: 275
?>

Parameterized Constructor

To initialize objects with unique values, the constructor should accept parameters. 

function __construct($param1, $param2) {
   $this->title = $param1;
   $this->price = $param2;
}

// Initialization with parameters
$b1 = new Book("PHP Programming", 450);

Simulating Constructor Overloading

PHP does not support method overloading (multiple constructors with the same name but different arguments). This is typically overcome by providing **default values** for constructor arguments. 

function __construct($param1="PHP Basics", $param2=380) {
   $this->title = $param1;
   $this->price = $param2;
}

// Will use default values
$b1 = new Book(); 

// Will use passed values
$b2 = new Book("Advanced PHP", 500);

The __destruct() Function (Destructor)

The __destruct() method is automatically called when an object is about to be destroyed. This happens when the object goes **out of scope** or when its last reference is explicitly removed (e.g., set to null). It is typically used for cleanup operations, like closing database connections or releasing resources. 

__destruct(): void
  • It takes **no parameters**.
  • It does **not** return a value (void).

Example: Using __destruct()

<?php
   class ResourceHandler {
      function __destruct() {
         echo "Object destroyed and resources released.\n";
      }
   }
   
   $obj = new ResourceHandler;
   // When the script ends (or $obj is set to null), __destruct() is called.
?>

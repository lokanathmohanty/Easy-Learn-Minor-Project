Arrays in Python

Python does not have a built-in array type like C++ or Java. Instead, the array module allows for the creation of arrays, which store elements of the same type at contiguous memory locations. Lists and tuples are often used as flexible arrays, but the array module is used for actual type-restricted arrays.

Creating an Array

import array as arr

# Integer array
a = arr.array('i', [1, 2, 3])
print(type(a), a)

# Character array
a = arr.array('u', 'BAT')
print(type(a), a)

# Float array
a = arr.array('d', [1.1, 2.2, 3.3])
print(type(a), a)

Output:

<class 'array.array'> array('i', [1, 2, 3])
<class 'array.array'> array('u', 'BAT')
<class 'array.array'> array('d', [1.1, 2.2, 3.3])

Array Typecodes

  • 'b' — signed integer (1 byte)
  • 'B' — unsigned integer (1 byte)
  • 'u' — Unicode character (2 bytes)
  • 'h' — signed integer (2 bytes)
  • 'H' — unsigned integer (2 bytes)
  • 'i' — signed integer (2 bytes)
  • 'I' — unsigned integer (2 bytes)
  • 'l' — signed integer (4 bytes)
  • 'L' — unsigned integer (4 bytes)
  • 'q' — signed integer (8 bytes)
  • 'Q' — unsigned integer (8 bytes)
  • 'f' — floating point (4 bytes)
  • 'd' — floating point (8 bytes)

Basic Array Operations

  • Traverse: Print all elements one by one.
  • Insertion: Add an element at a given index.
  • Deletion: Remove an element at a given index.
  • Search: Find an element by its value or index.
  • Update: Change the value at a given index.

Example: Basic Operations

Accessing Array Elements

from array import *
array1 = array('i', [10,20,30,40,50])
print(array1[0])
print(array1[2])
# Output:
# 10
# 30

Insertion

array1.insert(1, 60)
for x in array1:
    print(x)
# Output:
# 10
# 60
# 20
# 30
# 40
# 50

Deletion

array1.remove(40)
for x in array1:
    print(x)
# Output:
# 10
# 60
# 20
# 30
# 50

Search

print(array1.index(30))
# Output:
# 3

Update

array1[2] = 80
for x in array1:
    print(x)
# Output:
# 10
# 60
# 80
# 30
# 50

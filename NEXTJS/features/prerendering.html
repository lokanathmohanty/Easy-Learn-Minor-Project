Next.js Pre-Rendering: Static vs. Server-Side 🚀

What is Pre-Rendering?

**Pre-rendering** is a core technique in Next.js where the application generates the **HTML page in advance** on the server, rather than sending a blank page and waiting for client-side JavaScript to fetch data and build the content. By default, Next.js pre-renders every page.

The subsequent process where the client-side JavaScript loads and connects to the pre-rendered HTML (making it interactive) is called **hydration**.

Why Use Pre-Rendering?

  • **Improved Performance:** Delivers a ready-to-use HTML page, significantly reducing the **Time to Interactive (TTI)**.
  • **Better SEO:** Search engines (crawlers) can easily read the fully formed HTML content, improving page ranking.
  • **Superior User Experience:** Users see the content faster, preventing the "blank screen" effect.

Types of Pre-Rendering

Next.js offers two distinct forms of pre-rendering, chosen based on data freshness requirements:

1. Static Site Generation (SSG) 🏗️

SSG generates the HTML pages **once at build time** (`next build`). This static HTML file is then cached and reused for every user request until the next deployment/rebuild or revalidation. It is the **default** strategy for pages without external data fetching.

Implementation (Page Router):

Use the **`getStaticProps()`** function to fetch data exclusively during the build process.

// Data is fetched and rendered once at build time
export async function getStaticProps() {
    const data = await fetch('...').then( res => res.json() );
    return { props: { data } };
}

2. Server-Side Rendering (SSR) 💻

SSR generates the HTML page **on every request** to the server. This ensures the user always sees the most dynamic and up-to-date content, as the data is fetched just moments before the HTML is sent.

Implementation (Page Router):

Use the **`getServerSideProps()`** function, which executes on the server for every incoming request.

// Data is fetched and rendered on every client request
export async function getServerSideProps() {
    const response = await fetch('https://link/to/api');
    const data = await response.json();
    return { props: { data } };
}

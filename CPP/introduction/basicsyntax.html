C++ Basic Syntax and Program Structure

The basic structure of a C++ program is built around the concepts of **Object-Oriented Programming (OOP)**, where a program is viewed as a collection of **objects** interacting via **methods**.

I. Core OOP Terminology

These terms define the fundamental elements of an OOP program in C++:

  • Object: An **instance** of a class. It has both **state** (values of instance variables) and **behaviors** (methods).
  • Class: A **template** or **blueprint** that describes the structure (instance variables) and capability (methods) that all objects of its type will possess.
  • Method (Member Function): A behavior defined within a class. It contains the logic for manipulating the object's data.
  • Instance Variables (Data Members): Variables declared within a class that define the object's state. Each object has its own unique set of values for these variables.

II. Basic Program Structure (Procedural Approach)

A simple C++ program typically contains the following sections:

  1. Header File Inclusion: Includes required libraries (e.g., #include <iostream> for input/output).
  2. Namespace Section: Specifies which namespaces to use (e.g., using namespace std; to avoid prefixing standard library elements with std::).
  3. main() Section: The entry point of execution. Program execution always begins here.

Example Explanation:

  • #include <iostream>: Includes the library for standard I/O streams.
  • int main(): The function that returns an integer (usually 0 for success) and is the starting point.
  • cout << "Hello World";: Uses the standard output stream (`cout`) and the insertion operator (`<<`) to display text.
  • return 0;: Terminates the main() function.

III. Syntax Rules: Terminators, Blocks, and Identifiers

  • Semicolons (;): The semicolon is a **statement terminator**. Every individual logical statement must end with a semicolon. C++ is free-form, so line breaks don't matter; only the semicolon determines the end of a statement.
  • Blocks: A set of logically connected statements enclosed by **curly braces {}**. Blocks define scope, typically for function bodies or control structures (like `if` statements or loops).
  • Identifiers: Names used for variables, functions, classes, etc.
    • Must start with a **letter** (A-Z or a-z) or an **underscore** (_).
    • Can be followed by letters, underscores, and digits (0-9).
    • C++ is case-sensitive (MyVar is different from myvar).
    • Cannot be C++ reserved **keywords** (e.g., class, if, int).
  • Whitespace: Blanks, tabs, and newlines are used to separate elements (like a type from a variable name: `int age;`). Whitespace is otherwise ignored by the compiler for readability.

IV. C++ Program Structure (Object-Oriented Approach)

OOP programs center on the **Class Declaration** and **Object Creation**:

  1. Class Declaration:
    • Defines the structure using the class keyword.
    • Contains **Data Members** (instance variables) and **Member Functions** (methods).
    • Uses **Access Modifiers** (private, public, protected) to control visibility and access to its members.
  2. Object Creation:
    • An object is instantiated using the class name, similar to declaring a variable of a built-in type (e.g., Numbers num;).
    • Methods (like `num.setValues(10, 20)`) are then invoked on the object.

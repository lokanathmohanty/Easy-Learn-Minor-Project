JavaScript - Base64 Encoding

Encoding is the process of converting data from one format into another. In computer science, encoding often means converting text or binary data into a different representation. It is different from encryption, as encoding does not aim to secure the data, only to represent it in another form.

Base64 encoding is commonly used to encode binary data (such as images, audio, or video) into text format. It represents binary data as an ASCII string using a radix-64 representation.

Base64 is widely used in applications like email (via MIME), and for storing complex data inside XML or JSON.

String to Base64 Encoding using btoa()

The btoa() method encodes a string into a Base64-encoded ASCII string.

Syntax:


btoa(string)

The string parameter is the input string to be encoded, and the return value is the Base64-encoded string.

Example


var str = "Tutorials point";
var encoded = window.btoa(str);
console.log('The encoded string for "Tutorials point" is ' + encoded);

Output


The encoded string for "Tutorials point" is VHJ1c3Rpb25zIHBvaW50

Base64 Decoding using atob()

Decoding converts the encoded string back into the original string. The atob() method is used to decode a Base64 string.

Syntax:


atob(encodedString)

The encodedString parameter is the Base64 input string to decode, and the return value is the original string.

Example


var str = "VHV0b3JpYWxzIHBvaW50";
var decoded = window.atob(str);
console.log('The decoded string for "' + str + '" is ' + decoded);

Output


The decoded string for "VHV0b3JpYWxzIHBvaW50" is Tutorials point

Conclusion

JavaScript provides simple methods for Base64 encoding (btoa()) and decoding (atob()). These methods are helpful when working with data transfer, embedding binary files in text formats, or handling data inside JSON/XML safely.

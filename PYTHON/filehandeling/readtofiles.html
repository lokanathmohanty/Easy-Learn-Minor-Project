Python - Read Files

Reading from a file involves opening the file, reading its contents, and then closing the file to free up system resources. Python provides several methods to read from a file, each suited for different use cases.

Opening a File for Reading

Use the open() function with mode 'r' (default) to open a file for reading.

Reading a File Using read() Method

This method reads the entire file content as a single string.

# Open the file in read mode
file = open('example.txt', 'r')

# Read the entire content
content = file.read()

# Print the content
print(content)

# Close the file
file.close()

Output:

welcome to Tutorialspoint.

Reading a File Using readline() Method

This method reads one line at a time, useful for large files.

# Open the file in read mode
file = open('example.txt', 'r')

# Read the first line
line = file.readline()

# Print the line
print(line)

# Close the file
file.close()

Output:

welcome to Tutorialspoint.

Reading a File Using readlines() Method

Reads all lines into a list of strings.

# Open the file in read mode
file = open('example.txt', 'r')

# Read all lines
lines = file.readlines()

# Print lines
for line in lines:
   print(line, end='')

# Close the file
file.close()

Output:

welcome to Tutorialspoint.
Hi Surya.
How are you?.

Using with Statement

The with statement ensures automatic closing of the file even if an exception occurs.

with open('example.txt', 'r') as file:
   content = file.read()
   print(content)

Output:

welcome to Tutorialspoint.
Hi Surya.
How are you?.

Reading a File in Binary Mode

Use mode 'rb' for reading binary files like images, audio, or executables.

with open('test.bin', 'rb') as f:
   data = f.read()
   print(data.decode('utf-8'))

Output:

Hello World

Reading Integer Data from a Binary File

n = 25
data = n.to_bytes(8, 'big')

with open('test.bin', 'wb') as f:
   f.write(data)

with open('test.bin', 'rb') as f:
   data = f.read()
   n = int.from_bytes(data, 'big')
   print(n)

Output:

25

Reading Float Data from a Binary File

import struct

x = 23.50
data = struct.pack('f', x)

with open('test.bin', 'wb') as f:
   f.write(data)

with open('test.bin', 'rb') as f:
   data = f.read()
   x = struct.unpack('f', data)[0]
   print(x)

Output:

23.5

Reading and Writing Using 'r+' Mode

Using modes like 'r+' or 'w+' enables reading and writing without closing the file.

with open("foo.txt", "r+") as fo:
   fo.seek(10, 0)
   data = fo.read(3)
   print(data)

Output:

rat

Simultaneous Reading and Writing

with open("foo.txt", "r+") as fo:
   fo.write("This is a rat race")
   fo.seek(0)
   data = fo.read()
   print(data)

Output:

This is a rat race

Reading File from Specific Offset

fo = open("foo.txt", "w+")
fo.write("This is a rat race")
fo.seek(10, 0)
data = fo.read(3)
print("Data read from position 10:", data)
fo.seek(10, 0)
fo.write("cat")
fo.seek(0, 0)
data = fo.read()
print("Updated file content:", data)
fo.close()

Output:

Data read from position 10: rat
Updated file content: This is a cat race

In this chapter, we explore various DAX Aggregate functions in Power BI with examples. These functions return a single value from a column and can work with numeric, text, and Boolean values.

Start by loading your dataset, go to Table Tools → New Measure to write these expressions.

MIN Function

Returns the smallest numeric value in a column.

min_salary = MIN(Sheet1[Salary])

MINA Function

Returns the smallest value including Boolean and text values.

min_a = MINA(Sheet1[Name])

MINX Function

Returns the smallest value over an expression evaluated across a table.

min_x = MINX(Sheet1, Sheet1[Name])

MAX Function

Returns the largest numeric value from a column.

max_salary = MAX(Sheet1[Salary])

MAXA Function

Returns the largest value including Boolean and numeric values.
Note: FALSE = 0, TRUE = 1, NULL is ignored. 

max_a = MAXA(Sheet1[Age])

MAXX Function

Evaluates an expression over a table and returns the maximum value.

max_x = MAXX(Sheet1, Sheet1[Name])

AVERAGE Function

Returns the arithmetic mean of a column.

aver = AVERAGE(Sheet1[Salary])

AVERAGEA Function

Returns the average including Boolean and text values.
Notes:

  • Strings and NULL = 0
  • FALSE = 0, TRUE = 1

aver = AVERAGEA(Sheet1[Name])

AVERAGEX Function

Calculates the average of an expression evaluated across a table.

avg = AVERAGEX(Sheet1, Sheet1[Salary] + Sheet1[Incentive])

SUM Function

Returns the sum of numeric values in a column.

sum = SUM(Sheet1[Salary])

SUMX Function

Returns the sum of an expression evaluated across a table.

sum = SUMX(Sheet1, Sheet1[Salary] - Sheet1[Penality])

PRODUCT Function

Returns the product (multiplication) of values in a column.

pw = PRODUCT(Sheet1[Incentive])

PRODUCTX Function

Returns the product of an expression evaluated across a table.


product = PRODUCTX(
  Student_details,
  Student_details[Theory Marks] + Student_details[Practical Marks]
)

PHP: The Final Keyword

The **final** keyword is used in PHP to prevent inheritance or overriding of certain class members. Its purpose is to lock down important parts of your code, ensuring their stability and guaranteeing that their behavior will not be altered by child classes.

Using final with Classes and Methods

  • For Classes: Declaring a class as final (e.g., final class MyClass {}) **prevents it from being extended** (inherited). Any attempt by another class to extend a final class will result in a fatal error.
  • For Methods: Declaring a method as final (e.g., final public function hello() {}) **prevents that specific method from being overridden** in any child class. The class itself can still be extended.

Using final with Constants (PHP 8.1+)

Since PHP 8.1.0, the final keyword can also be applied to class constants (e.g., final public const NAME = "Value";). This prevents child classes from overriding the value of the constant.

Important Restriction

The final keyword **cannot be used** on class properties (member variables).

Example Session

Preventing Method Overriding

This example demonstrates how final ensures that a critical method's logic (in this case, an area calculation base) cannot be modified by any subclass.


class BaseGeometry {
   // This formula is considered fundamental and must not change.
   final public function getFormulaName() {
      return "Area is PI * A * B";
   }
}

class Ellipse extends BaseGeometry {
   // This is fine: The class is not final, and this is a new method.
   public function calculate(float $a, float $b) {
      // ... calculation logic ...
      echo $this->getFormulaName(); // Uses the final method
   }
   
   // public function getFormulaName() { /* Fatal Error if uncommented! */ }
}

$e = new Ellipse();
$e->calculate(5, 4);
// Output will include: Area is PI * A * B

Fatal Error Scenario (Class)

If the BaseGeometry class above was declared as final class BaseGeometry {...}, the line class Ellipse extends BaseGeometry {...} would immediately trigger a fatal error.

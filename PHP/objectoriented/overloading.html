PHP: Overloading

In PHP, **overloading** (unlike in C++ or Java) is the ability to create properties and methods dynamically. This feature is implemented using special **magic methods** (names starting with double underscore, e.g., __set, __call) that are automatically invoked when interacting with properties or methods that are **inaccessible** or **undeclared**.

Property Overloading

Property overloading handles interactions with properties that are either not declared or are inaccessible (due to private or protected visibility) in the current scope. These methods only work in an **object context** (not static).

  • __set($name, $value): Runs when you try to **write data** to an inaccessible property.
  • __get($name): Runs when you try to **read data** from an inaccessible property.
  • __isset($name): Runs when isset() or empty() is called on an inaccessible property.
  • __unset($name): Runs when unset() is called on an inaccessible property.

Method Overloading

Method overloading handles invocations of methods that are either not defined in the class or are inaccessible in the current scope.

  • __call($name, $arguments): Triggered when invoking an inaccessible method in an **object context** (e.g., $obj->myMethod()).
  • __callStatic($name, $arguments): Triggered when invoking an inaccessible method in a **static context** (e.g., MyClass::myMethod()).

Security Note on Encapsulation

Implementing __get and __set can potentially bypass encapsulation by allowing controlled access to private or protected properties. Developers must implement proper access control and validation logic within these magic methods to maintain data integrity.

Example Session

Dynamic Property Handling

This demonstrates how __set() and __get() allow a class to handle a property (myproperty) that was never explicitly declared in the class definition.


class DynamicProps {
   // This method is triggered when setting an undeclared property
   public function __set($name, $value) {
      echo "Setting property '$name' to '$value'\n";
      // Dynamically create the property
      $this->$name = $value;
   }

   // This method is triggered when getting an undeclared property
   public function __get($name) {
      echo "Retrieving property '$name': ";
      return $this->$name;
   }
}

$obj = new DynamicProps();
// Calls __set()
$obj->myProperty = "Hello Dynamic!"; 
// Calls __get()
echo $obj->myProperty . PHP_EOL;
// Output: 
// Setting property 'myProperty' to 'Hello Dynamic!'
// Retrieving property 'myProperty': Hello Dynamic!

Docstrings in Python

In Python, docstrings are used to document modules, classes, functions, and methods. They are enclosed within triple quotes (""" """) and can span multiple lines.

Docstrings provide a convenient way to associate documentation with Python code and are accessible via the __doc__ attribute.

Types of Docstrings

  • Single-Line Docstrings: Brief descriptions fitting on one line, ending with a period.
  • Multi-Line Docstrings: Detailed explanations including parameters, return values, and more.
  • Module Docstrings: Located at the top of the module, providing an overview.
  • Class Docstrings: Describe purpose and usage of classes and their methods.

Best Practices

  • Be clear and concise.
  • Use proper grammar and spelling.
  • Follow consistent formatting conventions (Google, NumPy, or Sphinx styles).
  • Include examples wherever helpful.

Example

Below are examples of different docstring styles.

Google Style

def divide(dividend, divisor):
    """
    Divide two numbers and return the result.

    Args:
        dividend (float): The number to be divided.
        divisor (float): The number to divide by.

    Returns:
        float: The result of the division.

    Raises:
        ValueError: If divisor is zero.
    """
    if divisor == 0:
        raise ValueError("Cannot divide by zero")
    return dividend / divisor

NumPy/SciPy Style

def fibonacci(n):
    """
    Compute the nth Fibonacci number.

    Parameters
    ----------
    n : int
        The index of the Fibonacci number to compute.

    Returns
    -------
    int
        The nth Fibonacci number.

    Examples
    --------
    >>> fibonacci(0)
    0
    >>> fibonacci(5)
    5
    >>> fibonacci(10)
    55
    """
    if n == 0:
        return 0
    elif n == 1:
        return 1
    else:
        return fibonacci(n-1) + fibonacci(n-2)

Sphinx Style (reStructuredText)

def divide(dividend, divisor):
    """
    Divide two numbers and return the result.

    :param float dividend: The number to be divided.
    :param float divisor: The number to divide by.
    :return: The result of the division.
    :rtype: float
    :raises ValueError: If divisor is zero.
    """
    if divisor == 0:
        raise ValueError("Cannot divide by zero")
    return dividend / divisor

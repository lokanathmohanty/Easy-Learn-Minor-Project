JavaScript - ECMAScript 2017

Overview

The ECMAScript 2017 version of JavaScript was released in 2017. This version introduced several new features. One of the most notable is the async/await syntax, which allows writing asynchronous operations in a synchronous style. It also introduced shared memory and atomics, enhancing support for concurrent programming.

New features include:

  • padStart() and padEnd() methods
  • Object.entries() method
  • Object.values() method
  • async and await
  • Object.getOwnPropertyDescriptors() method
  • Shared Memory and Atomics

String Padding: padStart() and padEnd()

These methods allow adding padding to a string at the beginning or the end until the desired length is achieved.

Example

let base = "TutorialsPoint";
let start_updated = base.padStart(18, "@");
let end_updated = base.padEnd(18, "*");

console.log(start_updated); // @@@@TutorialsPoint
console.log(end_updated);   // TutorialsPoint****

The Object.entries() Method

Returns an array of a given object's own enumerable string-keyed property [key, value] pairs.

Example

const employee = {
  Company: "TutorialsPoint",
  Ex_company: "TCS",
  Experience: 4,
};

for (let pair of Object.entries(employee)) {
  console.log(pair);
}

Output:

["Company","TutorialsPoint"]
["Ex_company","TCS"]
["Experience",4]

The Object.values() Method

Returns an array of the object's own enumerable property values.

Example

const wall = {
  color: "blue",
  size: "15x12",
  paintBrand: "Asian paints"
};

console.log(Object.values(wall));

Output: ["blue","15x12","Asian paints"]

Async and Await

The async keyword is used to define asynchronous functions, and the await keyword pauses execution until a promise resolves.

Example

async function printMessage() {
  let getData = new Promise((res) => {
    setTimeout(() => { res("Promise resolved !!"); }, 500);
  });
  console.log(await getData);
}

printMessage();

Output: Promise resolved !!

The Object.getOwnPropertyDescriptors() Method

Returns all property descriptors for an object, including metadata such as writable, enumerable, configurable, and value.

Example

const wall = {
  color: "blue",
  thickness: 10,
};

console.log(Object.getOwnPropertyDescriptors(wall));

Output:

{
  color: { value: "blue", writable: true, enumerable: true, configurable: true },
  thickness: { value: 10, writable: true, enumerable: true, configurable: true }
}

Shared Memory and Atomics

Shared memory allows multiple threads to share a memory space, enabling efficient communication. JavaScript is single-threaded, but with Web Workers and SharedArrayBuffer, memory can be shared, and atomic operations can be performed.

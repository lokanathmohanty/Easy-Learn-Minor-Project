JavaScript - Form Validation

Originally, form validation happened only on the server after submission. If the user entered invalid or missing data, the server had to send the form back for correction. This process was slow and put extra load on the server.

JavaScript allows validation on the client-side before sending data to the server. Form validation usually includes two parts:

  • Basic Validation – Checks that all required fields are filled in.
  • Data Format Validation – Ensures that entered data is in the correct format (e.g., email, numbers).

Example: HTML Form

<html>   
<head>
  <title>Form Validation</title>      
  <script type="text/javascript">
    // Form validation code will come here.
  </script>

<body>

Basic Form Validation

The validate() function checks that the required fields are filled and that data is in the expected format.

<script type="text/javascript">
function validate() {
  if (document.myForm.Name.value == "") {
    alert("Please provide your name!");
    document.myForm.Name.focus();
    return false;
  }
  if (document.myForm.EMail.value == "") {
    alert("Please provide your Email!");
    document.myForm.EMail.focus();
    return false;
  }
  if (document.myForm.Zip.value == "" || isNaN(document.myForm.Zip.value) ||
      document.myForm.Zip.value.length != 5) {
    alert("Please provide a zip in the format #####.");
    document.myForm.Zip.focus();
    return false;
  }
  if (document.myForm.Country.value == "-1") {
    alert("Please provide your country!");
    return false;
  }
  return true;
}
</script>

Data Format Validation (Email)

We can also check that the entered email follows a proper structure using string checks.

<script type="text/javascript">
function validateEmail() {
  var emailID = document.myForm.EMail.value;
  atpos = emailID.indexOf("@");
  dotpos = emailID.lastIndexOf(".");

  if (atpos < 1 || (dotpos - atpos < 2)) {
    alert("Please enter correct email ID");
    document.myForm.EMail.focus();
    return false;
  }
  return true;
}
</script>

This ensures the email contains an @ and a . in the correct positions.

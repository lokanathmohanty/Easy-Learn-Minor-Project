Bitwise Operators in C

Bitwise operators in C allow low-level manipulation of data stored in computer memory. Unlike logical operators that work on Boolean expressions, bitwise operators perform operations on individual bits of integer operands.

The common bitwise operators include:

  • & (AND) - Copies a bit if it exists in both operands.
  • | (OR) - Copies a bit if it exists in either operand.
  • ^ (XOR) - Copies the bit if it is set in one operand but not both.
  • ~ (One's Complement) - Flips bits (unary operator).
  • << (Left Shift) - Shifts bits left by the number of positions.
  • >> (Right Shift) - Shifts bits right by the number of positions.

For example, given two variables a = 60 (binary 0011 1100) and b = 13 (binary 0000 1101):

  • a & b results in 12 (0000 1100)
  • a | b results in 61 (0011 1101)
  • a ^ b results in 49 (0011 0001)
  • ~a results in -61 (binary 1100 0011, two's complement)
  • a << 2 results in 240 (1111 0000)
  • a >> 2 results in 15 (0000 1111)

These operators are useful for efficient data processing at the bit level.

Example code demonstrating all the operators:

#include <stdio.h>

int main(){
   unsigned int a = 60;  /* 0011 1100 */  
   unsigned int b = 13;  /* 0000 1101 */
   int c = 0;           

   c = a & b;
   printf("Line 1 - Value of c is %d\n", c);

   c = a | b;
   printf("Line 2 - Value of c is %d\n", c);

   c = a ^ b;
   printf("Line 3 - Value of c is %d\n", c);

   c = ~a;
   printf("Line 4 - Value of c is %d\n", c);

   c = a << 2;
   printf("Line 5 - Value of c is %d\n", c);

   c = a >> 2;
   printf("Line 6 - Value of c is %d\n", c);

   return 0;
}

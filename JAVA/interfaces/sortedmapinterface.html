SortedMap Interface in Java

The SortedMap interface extends Map and ensures that entries are maintained in ascending key order.

It supports methods like:

  • comparator() - Returns the comparator used or null for natural ordering.
  • firstKey() - Returns the first key in the map.
  • lastKey() - Returns the last key in the map.
  • headMap(end) - Returns a map with keys less than end.
  • tailMap(start) - Returns a map with keys greater than or equal to start.
  • subMap(start, end) - Returns a map with keys from start (inclusive) to end (exclusive).

The TreeMap class implements this interface, automatically sorting keys upon insertion.

Example 1: Iterating Through a SortedMap

This example demonstrates how to add entries to a SortedMap and iterate through them in sorted order:

SortedMap map = new TreeMap<>();
map.put("Zara", 3434.34);
map.put("Mahnaz", 123.22);
map.put("Ayan", 1378.00);

for (Map.Entry entry : map.entrySet()) {
    System.out.println(entry.getKey() + ": " + entry.getValue());
}

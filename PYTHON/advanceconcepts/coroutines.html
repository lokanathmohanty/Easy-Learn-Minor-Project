Python - Coroutines

Coroutines in Python are advanced functions that extend traditional functions by allowing multiple entry points and the ability to pause and resume execution. They are highly suitable for asynchronous programming and building data processing pipelines.

Unlike subroutines which have a single entry and exit, coroutines enable cooperative multitasking by letting programmers control when execution switches between tasks.

Key Characteristics of Coroutines

  • Multiple Entry Points: Coroutines can pause at yield points and resume later.
  • No Central Coordinator: Coroutines operate independently and can interact in pipeline fashion.
  • Cooperative Multitasking: Programmer controls when coroutines yield and resume.

Coroutines vs Subroutines

CriteriaSubroutinesCoroutines
DefinitionFunctions with single entry and exit.Functions with multiple entry points and suspension.

Basic Coroutine Example

def print_name(prefix):
    print(f"Searching prefix: {prefix}")
    while True:
        name = (yield)
        if prefix in name:
            print(name)

corou = print_name("Welcome to")
corou.__next__()
corou.send("Tutorialspoint")
corou.send("Welcome to Tutorialspoint")

Output:

Searching prefix: Welcome to
Welcome to Tutorialspoint

Closing a Coroutine

def print_name(prefix):
    print(f"Searching prefix: {prefix}")
    try:
        while True:
            name = (yield)
            if prefix in name:
                print(name)
    except GeneratorExit:
        print("Closing coroutine!!")

corou = print_name("Come")
corou.__next__()
corou.send("Come back Thank You")
corou.send("Thank you")
corou.close()

Output:

Searching prefix: Come
Come back Thank You
Closing coroutine!!

Chaining Coroutines for Pipelines

def producer(sentence, next_coroutine):
    tokens = sentence.split(" ")
    for token in tokens:
        next_coroutine.send(token)
    next_coroutine.close()

def pattern_filter(pattern="ing", next_coroutine=None):
    print(f"Searching for {pattern}")
    try:
        while True:
            token = (yield)
            if pattern in token:
                next_coroutine.send(token)
    except GeneratorExit:
        print("Done with filtering!!")
        next_coroutine.close()

def print_token():
    print("I'm the sink, I'll print tokens")
    try:
        while True:
            token = (yield)
            print(token)
    except GeneratorExit:
        print("Done with printing!")

pt = print_token()
pt.__next__()
pf = pattern_filter(next_coroutine=pt)
pf.__next__()
sentence = "Tutorialspoint is welcoming you to learn and succeed in Career!!!"
producer(sentence, pf)

Output:

I'm the sink, I'll print tokens
Searching for ing
welcoming
Done with filtering!!
Done with printing!

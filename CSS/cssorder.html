CSS - Order Property

The CSS order property is used with flexbox layouts to control the order in which flex items appear inside a flex container. By default, flex items are displayed in the source order (the order in which they appear in the HTML). However, with the order property, you can rearrange items without changing the HTML structure.

Syntax

The syntax of the order property is:

order: number | initial | inherit;

Property Values

  • number − Defines the position of the item in the flex container. Items with smaller values are displayed first.
  • initial − Resets the property to its default value (which is 0).
  • inherit − Inherits the value from its parent.

Default Behavior

All flex items have a default order value of 0. If no order is specified, items appear in the order they are written in the HTML.

Examples of CSS Order Property

1. Order Property with Positive Numeric Values

When positive values are used, items with smaller numbers appear first. This allows you to rearrange items easily.

Example: If four boxes have order values 2, 4, 1, and 3, they will be arranged in the order: 1 → 2 → 3 → 4 (based on values).

  • Box1 → order: 2
  • Box2 → order: 4
  • Box3 → order: 1
  • Box4 → order: 3

Result: Box3 will appear first, followed by Box1, Box4, and Box2.

2. Order Property with Negative Numeric Values

The order property also accepts negative numbers. Items with smaller negative values are displayed before larger ones. This is useful when you want certain items to always appear at the beginning.

Example: If boxes have order values -2, -1, -3, -4, they will be arranged as -4 → -3 → -2 → -1.

  • Box1 → order: -2
  • Box2 → order: -1
  • Box3 → order: -3
  • Box4 → order: -4

Result: Box4 will appear first, followed by Box3, Box1, and Box2.

3. Order Property with Images

The order property is not limited to divs; it can also be applied to images or any flex items. By changing the order values, you can rearrange image positions dynamically without modifying the HTML structure.

  • Image1 → order: 4
  • Image2 → order: 2
  • Image3 → order: 1
  • Image4 → order: 3

Result: Image3 will be displayed first, followed by Image2, Image4, and finally Image1.

Real-World Use Cases

  • Responsive Design: On smaller screens, you may want a navigation bar to appear at the top, but on larger screens, it could be at the side. Order property helps achieve this without restructuring HTML.
  • Content Prioritization: Important messages or alerts can be ordered to appear first on mobile devices, improving accessibility and UX.
  • Dynamic Layouts: Developers can use order in combination with media queries to reorder items based on device type.

Default vs Custom Order Example

Suppose you have three boxes: A, B, C. By default, they appear as A → B → C. If you apply:

  • A → order: 3
  • B → order: 1
  • C → order: 2

Then the new order will be: B → C → A.

Browser Support

The order property is supported in all major browsers. The following versions are the minimum required:

  • Chrome: 29+
  • Edge: 12+
  • Firefox: 28+
  • Safari: 9.0+
  • Opera: 12.1+

Key Notes

  • Default value is 0.
  • Negative values are allowed.
  • Does not affect non-flexbox elements.
  • Order should not be misused for accessibility, as screen readers may still read items in DOM order.

In summary, the CSS order property is a powerful tool for rearranging elements within a flex container without modifying the HTML source code. It helps developers create flexible, responsive layouts and makes it easier to prioritize content on different devices.

ReactJS - Reference API

React JS is a JavaScript library for building user interfaces. React allows developers to create interactive UI components efficiently. This reference attempts to document every built-in function, hook, component, and other essential functionality provided by React JS. In this tutorial we will use the React@18 version.

In React JS, functions are organized into sections based on their usage. Below are the main references.

Built-in Hooks

  • use() − Lets us read the value of a resource.
  • useDebugValue() − Add a label to a custom Hook.
  • useDeferredValue() − Lets us defer updating a portion of the UI.
  • useId() − Generates unique IDs.
  • useImperativeHandle() − Helps us connect with a child component.
  • useInsertionEffect() − Allows inserting elements into the DOM.
  • useLayoutEffect() − Perform layout measurements.
  • useSyncExternalStore() − Subscribe to an external store.
  • useTransition() − Update state without blocking the UI.

Built-in Component

  • <Suspense> − Display a fallback until its children have finished loading.

Built-in React APIs

  • cache() − Cache the result of a data fetch.
  • createContext() − Creates a context that components can provide.
  • lazy() − Delay loading a component’s code.
  • startTransition() − Update state without blocking the UI.

Directives

  • use client − Marks code that runs on the client.
  • use server − Marks server-side functions.

Built-in React DOM Hooks

  • useFormState() − Update state as per the result of a form action.
  • useFormStatus() − Provides status of the last form submission.

Event Handling Functions

  • event object − Link between code and browser events.
  • AnimationEvent handler − Handles CSS animation events.
  • ClipboardEvent handler − Handles Clipboard API events.
  • CompositionEvent handler − Handles input method editor events.
  • DragEvent handler − Handles HTML Drag and Drop API events.
  • FocusEvent handler − Handles focus events.
  • InputEvent handler − Handles onBeforeInput events.
  • KeyboardEvent handler − Handles keyboard events.
  • MouseEvent handler − Handles mouse events.
  • PointerEvent handler − Handles pointer events.
  • TouchEvent handler − Handles touch events.
  • TransitionEvent handler − Handles CSS transition events.
  • UIEvent handler − Handles generic UI events.
  • WheelEvent handler − Handles onWheel events.

React DOM APIs

  • createPortal() − Create a portal to render children into a DOM node.
  • flushSync() − Flush state updates synchronously.
  • findDOMNode() − Access underlying DOM node.
  • createRoot() − Create a root to render UI.
  • hydrateRoot() − Hydrate a server-rendered container.
  • renderToReadableStream() − Render to a readable stream (SSR).
  • renderToString() − Render a component to HTML string.
  • renderToStaticMarkup() − Render static HTML without React IDs.
  • cloneElement() − Clone and return a React element.
  • isValidElement() − Verify if an object is a valid React element.
  • PureComponent − Enhanced version of regular Component.

Other Class Components

  • componentDidCatch() − Called when a child throws an error.
  • componentDidUpdate() − Called after re-render.
  • componentWillUnmount() − Called before component is removed.
  • forceUpdate() − Forces a re-render.
  • getChildContext() − Specify values for legacy context.
  • getSnapshotBeforeUpdate() − Capture info before DOM changes.
  • static contextType − Consumes legacy context.
  • static defaultProps − Set default props.
  • static propTypes − Declare prop types.
  • static getDerivedStateFromError() − Called on error during render.
  • static getDerivedStateFromProps() − Called before render with new props.
  • UNSAFE_componentWillMount() − Legacy lifecycle method.
  • UNSAFE_componentWillReceiveProps() − Legacy method for new props.
  • UNSAFE_componentWillUpdate() − Legacy method before update.
  • createElement() − Create React element without JSX.
  • createRef() − Create a ref object.

Test Utilities

  • act() − Wrap code interacting with components.
  • mockComponent() − Create mock version of a component.
  • isElement() − Check if object is a React element.
  • isElementOfType() − Check if object is of specific type.
  • isDOMComponent() − Check if object is a DOM component.
  • isCompositeComponent() − Check if object is a composite component.
  • findAllInRenderedTree() − Find all rendered instances in tree.
  • scryRenderedDOMComponentsWithClass() − Find DOM components by class.
  • findRenderedDOMComponentWithClass() − Find first DOM component by class.
  • scryRenderedDOMComponentsWithTag() − Find DOM components by tag.
  • findRenderedDOMComponentWithTag() − Find first DOM component by tag.
  • scryRenderedComponentsWithType() − Find all components of specific type.
  • findRenderedComponentWithType() − Find first component of specific type.
  • renderIntoDocument() − Render a component into the DOM.
  • Simulate() − Simulate user interactions.

Test Renderer

  • TestRenderer.create() − Render component in test instance.
  • TestRenderer.act() − Execute interactions in test renderer.
  • testRenderer.toJSON() − JSON representation of tree.
  • testRenderer.toTree() − Tree structure of rendered component.
  • testRenderer.update() − Trigger an update manually.
  • testRenderer.unmount() − Unmount the component.
  • testRenderer.getInstance() − Get root component instance.
  • testRenderer.root() − Access root node of tree.
  • testInstance.find() − Find nodes in component tree.
  • testInstance.findByType() − Find nodes by type.
  • testInstance.findByProps() − Find nodes by props.
  • testInstance.findAll() − Find all nodes in tree.
  • testInstance.findAllByType() − Find all nodes by type.
  • testInstance.findAllByProps() − Find all nodes by props.
  • testInstance.instance − Actual component instance.
  • testInstance.type − Type of component.
  • testInstance.props − Props of component.
  • testInstance.parent − Parent node in tree.
  • testInstance.children − Children nodes in tree.

JavaScript - Truthy and Falsy Values

Truthy & Falsy Values

In JavaScript, every value has an inherent boolean "truthiness" or "falsiness." This determines whether the value is treated as true or false in conditional expressions and logical operations.

  • Truthy Values: Values that evaluate to true when converted to a boolean. Examples include non-empty strings, non-zero numbers, arrays, objects, and functions.
  • Falsy Values: Values that evaluate to false when converted to a boolean. Examples include 0, null, undefined, NaN, false, and empty strings ("").

Example

Consider a scenario where we want to check if a user has an active subscription: 


// old user without subscriptionDays
const userOld = {
   name: "Alisha",
   email: "alisha@example.com"
}; 
 
// new user with active subscription
const userNewWithSubscription = {
   name: "Shital",
   email: "shital@example.com",
   subscriptionDays: 30
}; 
 
// new user with expired subscription
const userNewWithoutSubscription = {
   name: "Chetan",
   email: "chetan@example.com",
   subscriptionDays: 0
}; 
 
function displaySubscriptionStatus(user) {
   if (user.subscriptionDays !== undefined) {
      if (user.subscriptionDays > 0) {
         console.log(`User has ${user.subscriptionDays} days of subscription left.`);
      } else {
         console.log("User's subscription has expired.");
      }
   } else {
      console.log("User does not have a subscription.");
   }
} 

displaySubscriptionStatus(userOld);
displaySubscriptionStatus(userNewWithSubscription); 
displaySubscriptionStatus(userNewWithoutSubscription);

Output

  • User does not have a subscription.
  • User has 30 days of subscription left.
  • User's subscription has expired.

Truthy vs Falsy in JavaScript

Besides types, each value has an underlying boolean evaluation. Some values are always falsy, while everything else is considered truthy.

Always Falsy Values

  • false
  • 0, -0, 0n
  • '', "", `` (empty strings)
  • null
  • undefined
  • NaN

Examples of Truthy Values

  • '0' (a string containing zero)
  • 'false' (a string containing text)
  • [] (an empty array)
  • {} (an empty object)
  • function(){} (an empty function)

Dealing with Truthy and Falsy Values

Avoid Direct Comparisons


// Instead of
if (x == false)

// Use
if (!x)

Use Strict Equality (===)


// Instead of
if (a == b)

// Use
if (a === b)

Convert to Boolean Explicitly


if (Boolean(x) === Boolean(y))
// or
if (!!x === !!y)

Filtering Truthy Values

You can use Boolean or !! to filter truthy values from an array: 


const truthy_values = [false,0,``,'',"",null,undefined,NaN,'0','false',[],{},function() {}].filter(Boolean);

console.log(truthy_values);

Summary

Understanding truthy and falsy values in JavaScript is essential for writing reliable conditional statements. Pay attention to edge cases such as [] and NaN, which may cause unexpected results.

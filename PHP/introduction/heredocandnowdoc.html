PHP Heredoc and Nowdoc Syntax

**Heredoc** and **Nowdoc** are special syntaxes in PHP that provide convenient ways to define multi-line strings without needing to escape quotes or newlines. They are particularly useful for embedding large blocks of text, code, or XML/HTML.

Heredoc (`<<

Heredoc strings are conceptually similar to **double-quoted strings** (`""`): they support **variable expansion** and **interpretation of escape sequences** (like `\n`). The syntax uses a starting identifier preceded by `<<<`.

Heredoc Syntax Rules:

  1. **Start:** Begin with `<<<` followed immediately by a custom, chosen **IDENTIFIER**.
  2. **Content:** The string content follows on the next line and can span multiple lines. Quotes (`'` and `"`) do not need to be escaped.
  3. **End:** The string ends with the **same IDENTIFIER** on a new line.
  4. **Termination:** The closing IDENTIFIER must be followed immediately by a semicolon (`;`).
  5. **Indentation:** The closing identifier may be indented, and that indentation will be stripped from all lines of the string.

Heredoc Example (Supports Interpolation):

<?php
$lang="PHP";
echo <<<EOS
   Heredoc strings in **$lang** expand variables.
EOS;
?>

Output: Heredoc strings in **PHP** expand variables.

Nowdoc (`<<<'IDENTIFIER'`)

Nowdoc strings are conceptually similar to **single-quoted strings** (`''`): they represent the literal text. They **do not support variable expansion** and **do not interpret escape sequences**. They provide the raw, unparsed text.

Nowdoc Syntax Rules:

The syntax is exactly the same as Heredoc, except the starting **IDENTIFIER MUST be enclosed in single quotes** (`'`).

Nowdoc Example (Raw Text):

<?php
$lang="PHP";
$str = <<<'RAWTEXT'
   IT doesn't expand the value of **$lang** variable.
RAWTEXT;
echo $str;
?>

Output: IT doesn't expand the value of **$lang** variable.

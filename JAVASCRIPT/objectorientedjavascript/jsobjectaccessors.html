JavaScript - Object Accessors

The object accessor properties in JavaScript are methods that get or set the value of an object. They are defined using the get and set keywords. Accessor properties are a powerful way to control how your objects are accessed and modified.

The JavaScript object can have two kinds of properties:

  • Data properties
  • Accessor properties

Example of data property:

const obj = {
    key: "value", // Data property
}

Object Accessor Properties

In JavaScript, you can use the getters to get the object properties and setters to set the object properties.

  • get − Used to define a method to get the object property value.
  • set − Used to define a method to update the object property value.

JavaScript Getters

The getters are used to access the object properties. To define a method as a getter, we use the get keyword followed by the method name.

get methodName() {
    // Method body
}
obj.methodName;

You can access the getter like a property without parentheses.

Example

const wall = {
  color: "brown",
  get getColor() {
    return this.color;
  }
}
console.log(wall.getColor);

Output: The color of the wall is: brown

JavaScript Setters

The setters are used to update the object properties. The setter method always takes a single parameter, and you can assign values to it just like a property.

set methodName(param) {
    this.color = param;
}
obj.methodName = "Red";

Example

const wall = {
  color: "brown",
  set setColor(color) {
    this.color = color;
  }
}
wall.setColor = "Red";

Output: The color of the wall before update is: brown
The color of the wall after update is: Red

Object Methods vs Getters/Setters

Getters and setters provide a simpler syntax compared to defining methods. Both can achieve the same results, but getters and setters offer cleaner code.

const wall = {
  color: "brown",
  get getColor() {
    return this.color;
  },
  colorMethod: function () {
    return this.color;
  }
}

Output:
Getting the color using the getters: brown
Getting the color using the object method: brown

Data Quality and Security

Getters and setters improve data quality by validation and also allow encapsulation or abstraction (data hiding).

Example

const wall = {
  color: "Brown",
  get getColor() {
    return this.color.toUpperCase();
  }
}
console.log(wall.getColor);

Output: BROWN

Defining Getters/Setters using Object.defineProperty()

You can also add getters or setters into an object using Object.defineProperty().

Object.defineProperty(object, "methodName", {
  get: function () { ... },
  set: function (value) { ... }
});

Example

const door = { size: 20 };

Object.defineProperty(door, "getSize", {
  get: function () {
    return this.size;
  }
});

Object.defineProperty(door, "setSize", {
  set: function (value) {
    this.size = value;
  }
});

console.log(door.getSize); // 20
door.setSize = 30;
console.log(door.getSize); // 30

Reasons to Use Getters and Setters

  • They provide simpler syntax than object methods.
  • Improve data quality by validating input.
  • Enable encapsulation and secure the object data.
  • Allow abstraction and data hiding.

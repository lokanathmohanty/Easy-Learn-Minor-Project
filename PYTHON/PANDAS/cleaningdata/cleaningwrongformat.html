Pandas - Cleaning Data of Wrong Format

Cells with data in the wrong format can make it difficult or even impossible to analyze data properly. In such cases, you can either remove the rows with incorrect formatting or convert all cells in the column to the correct format.

For instance, in a column that is supposed to represent dates, inconsistent formats (e.g., '2020/12/01' vs 20201226) can cause parsing issues. Pandas provides a convenient method to handle this using to_datetime().

Example: Converting Column to Date Format

The following example demonstrates how to convert the Date column to proper datetime format using Pandas. Invalid or missing formats will be converted to NaT (Not a Time).

Code Example


import pandas as pd

df = pd.read_csv('data.csv')

# Convert to datetime format
df['Date'] = pd.to_datetime(df['Date'], format='mixed', errors='coerce')

# Remove rows where Date could not be converted
df.dropna(subset=['Date'], inplace=True)

print(df.to_string())

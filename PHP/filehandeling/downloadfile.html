PHP File Downloads

PHP can be used to manage file downloads safely and effectively, especially for files (like text, PDF, or images) that browsers typically open instead of downloading. By using PHP, you gain control over access, security, and tracking of files.

The Download Mechanism ⚙️

The core of forcing a file download in a browser involves sending specific **HTTP response headers** before outputting the file content.

1. Essential HTTP Headers

These headers tell the browser how to handle the data it is about to receive:

  • **`Content-Type: application/octet-stream`**: This is a generic MIME type for binary data, instructing the browser not to process or display the content but treat it as a generic data stream.
  • **`Content-Disposition: attachment; filename="file.ext"`**: This header is crucial. The `attachment` directive tells the browser to prompt the user with a "Save As" dialog, and the `filename` parameter suggests the name for the downloaded file.
  • **`Content-Length: [bytes]`**: (Optional but recommended) Specifies the size of the file in bytes, allowing the browser to display a progress bar.

2. Sending the File Content

Once the headers are sent, the PHP script reads the file content and outputs it to the response stream.

The `readfile()` Function (Recommended)

The `readfile()` function is the simplest and often the most memory-efficient way to stream a file. It reads the file and writes it directly to the output buffer.

$filePath = 'welcome.png';

// 1. Send Headers to force download
header('Content-Type: application/octet-stream');
header('Content-Disposition: attachment; filename="'. basename($filePath).'"');

// 2. Stream the file content
**readfile**($filePath);

Handling Large Files (Chunking)

For very large files, it is best practice to read and output the file in smaller chunks using functions like `fread()` within a loop. This prevents the entire file from being loaded into the server's memory at once, avoiding memory exhaustion.

Security Best Practices for Downloads 🔒

To prevent security issues (like unauthorized access or Path Traversal attacks), always implement these measures:

  • **Hide File Path:** Never directly expose the internal server path. Use a script (like `download.php?file=123`) to handle the request.
  • **File Validation:** Check that the file exists and is in a permitted directory before initiating the download.
  • **Authentication:** For private files, verify the user's login status and permissions before allowing the download.
  • **Use `basename()`:** When setting the `filename` in the `Content-Disposition` header, use `basename()` to strip any directory components from the file name, mitigating path traversal risks.

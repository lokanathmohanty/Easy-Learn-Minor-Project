PHP Array Operators

**Array Operators** in PHP are used for combining and comparing array data structures. They are unique in how they handle keys, especially when merging or checking for equality.

Array Operators Summary

Name Symbol Description
**Union** + Combines two arrays. If keys conflict, the elements from the **left-hand array** are kept.
**Equality** == Returns `true` if arrays have the **same key-value pairs**. Order and data types are **ignored**.
**Identity** === Returns `true` if arrays have the **same key-value pairs**, in the **same order**, and with the **same data types**.
**Inequality** != or <> Returns `true` if arrays are **not equal** (based on loose comparison, `==`).
**Non-identity** !== Returns `true` if arrays are **not identical** (based on strict comparison, `===`).

Combining Arrays: The Union Operator (`+`)

The `+` operator performs a **Union**. It appends the elements of the right-hand array to the left-hand array, but it **does not overwrite** existing keys. If a key from the right array already exists in the left array, the left array's value for that key is preserved.

$arr1 = ["a" => 1, "b" => 2];
$arr2 = ["b" => 5, "c" => 3];
$arr3 = $arr1 + $arr2; $\rightarrow$ $arr3 is ["a" => 1, **"b" => 2**, "c" => 3]

Comparing Arrays: Equality vs. Identity

Understanding the difference between loose equality (`==`) and strict identity (`===`) is crucial in array comparisons.

Equality (`==`) - Loose Comparison

Two arrays are equal if they contain the same key-value pairs. **Order of elements** and **data types** of values are **not checked**.

$arr1 = [0=>70, 2=>80, 1=>90]; (Indices are 0, 2, 1)
$arr2 = [70, 90, 80]; (Indices are 0, 1, 2)
$arr1 == $arr2 $\rightarrow$ bool(false) (Keys 1 and 2 don't match values, as key 1 in $arr1$ is 90 and key 1 in $arr2$ is 90). **Note:** The text example provided a conflicting result; for equality, both key and value must match, regardless of order.

Identity (`===`) - Strict Comparison

Two arrays are identical only if:

  1. They have the **same key-value pairs**.
  2. The pairs are in the **same order**.
  3. The values and keys have the **same data types**.

$arrA = [1, 2]; $arrB = ["1", 2];
$arrA == $arrB $\rightarrow$ bool(true) (Values coerced)
$arrA === $arrB $\rightarrow$ bool(false) (Types differ)

$arrC = [1=>10, 0=>20]; $arrD = [0=>20, 1=>10];
$arrC === $arrD $\rightarrow$ bool(false) (**Order** is different)

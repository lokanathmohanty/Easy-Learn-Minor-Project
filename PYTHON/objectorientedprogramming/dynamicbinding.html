Python Dynamic Binding

In object-oriented programming, dynamic binding is the process where method calls are resolved at runtime rather than compile time. It is closely tied to polymorphism and enables different objects to respond differently to the same method call.

Python's interpreter determines the actual method or attribute to invoke based on the object's type or class hierarchy dynamically during execution.

Dynamic Binding Example

class shape:
    def draw(self):
        print("draw method")

class circle(shape):
    def draw(self):
        print("Draw a circle")

class rectangle(shape):
    def draw(self):
        print("Draw a rectangle")

shapes = [circle(), rectangle()]
for shp in shapes:
    shp.draw()

# Output:
# Draw a circle
# Draw a rectangle

Duck Typing Concept

Duck typing focuses on an object's behavior rather than its actual type. If an object has the necessary methods or attributes, it can be used interchangeably—even if it is not of a specific class.

This promotes flexibility and extensibility in Python code.

Duck Typing Example

class circle:
    def draw(self):
        print("Draw a circle")

class rectangle:
    def draw(self):
        print("Draw a rectangle")

class area:
    def area(self):
        print("calculate area")

def duck_function(obj):
    obj.draw()

objects = [circle(), rectangle(), area()]
for obj in objects:
    duck_function(obj)

# Output:
# Draw a circle
# Draw a rectangle
# Traceback: 'area' object has no attribute 'draw'

Here, duck_function calls draw() on each object regardless of its class. If the method is absent, Python raises an AttributeError at runtime.

Dynamic binding and duck typing together enable powerful polymorphic behaviors in Python.

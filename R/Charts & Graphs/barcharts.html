R - Bar Charts

Bar charts represent data in rectangular bars with lengths proportional to the values. In R, bar charts are created using the barplot() function, which supports both vertical and horizontal bars. You can customize labels, colors, and subtitles for each bar.

Basic Syntax

barplot(H, xlab, ylab, main, names.arg, col)
  • H: Numeric vector or matrix for bar values
  • xlab: Label for X axis
  • ylab: Label for Y axis
  • main: Title of the bar chart
  • names.arg: Vector of names under each bar
  • col: Color(s) for bars

Simple Bar Chart Example

# Data for chart
H <- c(7, 12, 28, 3, 41)

png(file = "barchart.png")
barplot(H)
dev.off()

Adding Labels, Title, and Colors

# Data and month names
H <- c(7, 12, 28, 3, 41)
M <- c("Mar", "Apr", "May", "Jun", "Jul")

png(file = "barchart_months_revenue.png")
barplot(H, names.arg = M, xlab = "Month", ylab = "Revenue", col = "blue", main = "Revenue chart", border = "red")
dev.off()

Grouped and Stacked Bar Charts

# Input vectors and matrix for groups/stacks
colors <- c("green", "orange", "brown")
months <- c("Mar", "Apr", "May", "Jun", "Jul")
regions <- c("East", "West", "North")
Values <- matrix(c(2,9,3,11,9, 4,8,7,3,12, 5,2,8,10,11), nrow = 3, ncol = 5, byrow = TRUE)

png(file = "barchart_stacked.png")
barplot(Values, main = "total revenue", names.arg = months, xlab = "month", ylab = "revenue", col = colors)
legend("topleft", regions, cex = 1.3, fill = colors)
dev.off()

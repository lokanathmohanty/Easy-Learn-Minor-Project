CSS - hyphens Property

The CSS hyphens property controls how words are broken into lines when text is too long to fit on a single line. This is particularly useful in responsive design, where long words might otherwise overflow or create awkward spacing. The property only applies to block-level elements and improves readability by determining where line breaks may occur.

Syntax

The general syntax of the property is:

hyphens: none | manual | auto | initial | inherit;

Property Values

  • none – Disables hyphenation completely. Words will not be broken, even if they are too long.
  • manual – Default value. Hyphenation only occurs where the author manually inserts soft hyphens (&shy;).
  • auto – Enables the browser to automatically hyphenate words based on language rules.
  • initial – Resets the property to its default value (manual).
  • inherit – Inherits the hyphenation property from its parent element.

Prevent Hyphenation with hyphens: none;

If you do not want words to break or be hyphenated, set the property to none. This ensures the entire word will remain on the same line.

Example:

Consider a paragraph inside a narrow container. By setting hyphens: none;, the browser will not break the text:

  • Code Concept: p { hyphens: none; }
  • Effect: Words will overflow instead of breaking.

For example:
"ThisIsAVeryVeryVeryLongWordWithoutAnyHyphenation" would stay on one line and possibly overflow.

Manual Hyphenation with hyphens: manual;

With the manual value, the browser only hyphenates where you insert a soft hyphen (&shy;). This gives you full control of line-breaking behavior.

Example:

Text:
"This is a much­much­much larger building."

In this case, the browser will only break the line at &shy; points when needed.

Automatic Hyphenation with hyphens: auto;

The auto value allows the browser to intelligently insert hyphens at natural breakpoints according to the language's grammar rules. This is very useful for paragraphs with long words in narrow containers.

Example:

If a word like "responsiveness" cannot fit on one line, the browser may display it as:
"respon-
siveness"

This prevents overflow and maintains readability without requiring manual intervention.

Supported Browsers

Browser support for the hyphens property:

  • Chrome: Supported from version 55.0
  • Edge: Supported from version 79.0
  • Firefox: Supported from version 43.0
  • Safari: Supported from version 17.0
  • Opera: Supported from version 44.0

Summary

The hyphens property gives developers better control over how text behaves in narrow or responsive layouts. While none ensures words remain unbroken, manual gives precision with soft hyphens, and auto provides a browser-driven solution that follows language-specific rules.

Use this property thoughtfully, especially in multi-language websites, to avoid unexpected breaks and ensure the best reading experience.

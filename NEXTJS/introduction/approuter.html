Next.js App Router Setup and Usage 🛣️

Introduction to the App Router

Starting with Next.js version 13, the **App Router** is the recommended system for defining application routes. It utilizes the file structure within the **`/app`** directory, where every folder containing a special file (like `page.tsx`) automatically becomes a route.

Step 1 & 2: Project Setup and Understanding Basic Routes

Project Creation

When creating a new Next.js project, select the App Router option:

npx create-next-app@latest

File-System Routing

In the App Router, a route is defined by creating a folder and placing a **`page.tsx`** file inside it. The file structure maps directly to the URL path:

  • `app/page.tsx` → **`/`** (The default Home Route)
  • `app/about/page.tsx` → **`/about`**
  • `app/contact/page.tsx` → **`/contact`**

Step 3: Setup Nested Routes

Nested routing is achieved by creating **folders within folders** inside the `/app` directory. For example, to create the `/about` route, you create an `about` folder and add `page.tsx` inside it.

// File: app/about/page.tsx 
export default function About() {
    return (<div><h1>About Us</h1></div>);
}

Step 4: Setup Dynamic Routes

Dynamic routes are routes that accept parameters (variables) in the URL. This is done by enclosing the folder name in **square brackets** (`[paramName]`).

  • **Route:** `app/products/[id]/page.tsx` → URL will be `/products/123`.
  • **Accessing the Parameter:** The parameter is accessed using the **`useParams()`** hook (when using Client Components) or the `params` prop (when using Server Components).
// Example: app/products/[id]/page.tsx
"use client"
import { useParams } from 'next/navigation';

export default function ProductPage() {
  const { id } = useParams(); // Retrieves '123' if URL is /products/123
  return (<h1>Product {id}</h1>);
}

Step 5: API Routes (Route Handlers)

In the App Router, API endpoints are created using **Route Handlers**, which are files named **`route.ts`** (or `route.js`) inside a route folder (e.g., `app/api/hello/route.ts`). They handle specific HTTP methods (`GET`, `POST`, etc.).

  • **Path:** `app/api/hello/route.ts` → Endpoint will be **`/api/hello`**.
// Example: app/api/hello/route.js
export async function GET(request) {
  return Response.json({ message: 'Hello, Next.js API!' });

Map Interface in Java

Content

The Map interface maps unique keys to values. A key is used to retrieve the associated value later.

Values are stored in the map using keys, which must be unique within that map.

Exceptions thrown by Map methods include NoSuchElementException, ClassCastException, NullPointerException, and UnsupportedOperationException.

Map Interface Methods

  • void clear() – Removes all key/value pairs.
  • boolean containsKey(Object k) – Checks if key k exists.
  • boolean containsValue(Object v) – Checks if value v exists.
  • Set entrySet() – Returns a Set of all key-value entries.
  • boolean equals(Object obj) – Checks equality with another Map.
  • Object get(Object k) – Retrieves value for key k.
  • int hashCode() – Returns the map’s hash code.
  • boolean isEmpty() – Checks if map is empty.
  • Set keySet() – Returns a Set of all keys.
  • Object put(Object k, Object v) – Adds or replaces value for key k.
  • void putAll(Map m) – Adds all entries from another map.
  • Object remove(Object k) – Removes the entry for key k.
  • int size() – Returns number of key/value pairs.
  • Collection values() – Returns a collection of all values.

Classes That Implement Map

  • HashMap
  • EnumMap
  • LinkedHashMap
  • WeakHashMap
  • TreeMap

Interfaces That Extend Map

  • SortedMap
  • NavigableMap
  • ConcurrentMap

Example 1: HashMap Usage


import java.util.HashMap;
import java.util.Map;

public class CollectionsDemo {
   public static void main(String[] args) {
      Map<String, String> m1 = new HashMap<>();
      m1.put("Zara", "8");
      m1.put("Mahnaz", "31");
      m1.put("Ayan", "12");
      m1.put("Daisy", "14");

      System.out.println();
      System.out.println(" Map Elements");
      System.out.print("\t" + m1);
   }
}

Output:

{Daisy=14, Ayan=12, Zara=8, Mahnaz=31}

Example 3: Adding and Removing Elements


import java.util.HashMap;
import java.util.Map;

public class CollectionsDemo {
   public static void main(String[] args) {
      Map<String, String> m1 = new HashMap<>();
      m1.put("Zara", "8");
      m1.put("Mahnaz", "31");
      m1.put("Ayan", "12");
      m1.put("Daisy", "14");

      System.out.println();
      System.out.println(" Map Elements");
      System.out.print("\t" + m1);
	  
      m1.remove("Daisy");
	  
      System.out.println(" Map Elements");
      System.out.print("\t" + m1);
   }
}

Output:

{Ayan=12, Zara=8, Mahnaz=31}

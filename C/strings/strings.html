Strings in C

A string in C is a one-dimensional array of char type, with the last character in the array being a "null character" represented by '\0'. Thus, a string in C can be defined as a null-terminated sequence of char type values.

Creating a String in C

Let us create a string "Hello". It comprises five char values. In C, the literal representation of a char type uses single quote symbols such as 'H'. These five alphabets put inside single quotes, followed by a null character represented by '\0', are assigned to an array of char types. The size of the array is five characters plus the null character, six.

Example

char greeting[6] = {'H', 'e', 'l', 'l', 'o', '\0'};

Initializing String Without Specifying Size

C lets you initialize an array without declaring the size, in which case the compiler automatically determines the array size.

Example

char greeting[] = {'H', 'e', 'l', 'l', 'o', '\0'};

Loop Through a String

You can loop through a string (character array) to access and manipulate each character of the string using a for loop or other loop statements.

Example

#include <stdio.h>
#include <string.h>

int main (){
   char greeting[] = {'H', 'e', 'l', 'l', 'o', '\0'};

   for (int i = 0; i < 5; i++) {
      printf("%c", greeting[i]);
   }

   return 0;
}

Output:

Hello

Printing a String (Using %s Format Specifier)

C provides a format specifier "%s" which is used to print a string when using functions like printf() or fprintf().

The "%s" specifier tells the function to iterate through the array until it encounters the null terminator (\0) and print each character. This effectively prints the entire string without needing a loop.

Example

#include <stdio.h>

int main (){
   char greeting[] = {'H', 'e', 'l', 'l', 'o', '\0'};
   printf("Greeting message: %s\n", greeting );
   return 0;
}

Output:

Greeting message: Hello

Oversized and Undersized Array Initialization

You can declare an oversized array and assign fewer characters without issues. However, if the size is less than the number of characters in the initialization, you may get garbage values in the output.

Example

char greeting[3] = {'H', 'e', 'l', 'l', 'o', '\0'};
printf("%s", greeting);

Constructing a String using Double Quotes

Instead of constructing a char array of individual char values in single quotes and using "\0" as the last element, C lets you construct a string by enclosing the characters within double quotes. This method is more convenient as the compiler automatically adds "\0" as the last character.

Example

#include <stdio.h>

int main() {
  char greeting[] = "Hello World";
  printf("%s\n", greeting);
  return 0;
}

Output:

Hello World

String Input Using scanf()

Declaring a null-terminated string causes difficulty when asking the user to input a string. You can accept one character at a time to store in each element of an array, with the help of a for loop.

Syntax

for(i = 0; i < 6; i++){
   scanf("%c", &greeting[i]);
}
greeting[i] = '\0';

Example

printf("Starting typing... ");

for (i = 0; i < 5; i++) {
  scanf("%c", &greeting[i]);
}

greeting[i] = '\0';

printf("Value of greeting: %s\n", greeting);

Output:

Starting typing... Hello
Value of greeting: Hello

Using scanf("%s") for String Input

It is not possible to input the null character (\0) because it is non-printable. To overcome this, scanf("%s") is used to read a string until whitespace.

Example

#include <stdio.h>
#include <string.h>

int main (){
   char greeting[10];
   printf("Enter a string:\n");
   scanf("%s", greeting);
   printf("You entered:\n%s", greeting);
   return 0;
}

Output:

Enter a string:
Hello
You entered:
Hello

Note: If the array size is less than the input string length, it may cause garbage or data corruption.

String Input with Whitespace

The scanf("%s") reads characters until it encounters whitespace (space, tab, newline, etc.). Therefore, strings with multiple words will only accept characters before the first whitespace.

Example

#include <stdio.h>
#include <string.h>

int main (){
   char greeting[20];
   printf("Enter a string:\n");
   scanf("%s", greeting);
   printf("You entered:\n%s", greeting);
   return 0;
}

Output:

Enter a string:
Hello World!

You entered:
Hello

String Input Using gets() and fgets() Functions

To accept string input with whitespaces, gets() was traditionally used but is deprecated due to lack of bounds checking, leading to potential buffer overflow.

Example: Using gets()

#include <stdio.h>
#include <string.h>

int main(){
   char name[20];
   printf("Enter a name:\n");
   gets(name);
   printf("You entered:\n%s", name);
   return 0;
}

Output:

Enter a name:
Sachin Tendulkar

You entered:
Sachin Tendulkar

It is safer to use fgets(), which performs bound checking.

Example: Using fgets()

#include <stdio.h>
#include <string.h>

int main(){
   char name[20];
   printf("Enter a name:\n");
   fgets(name, sizeof(name), stdin);
   printf("You entered:\n%s", name);
   return 0;
}

Output:

Enter a name:
Virat Kohli

You entered:
Virat Kohli

Alternative String Input Using scanf("%[^\n]s")

You may use scanf("%[^\n]s") to read characters until a newline is encountered.

Example

#include <stdio.h>
#include <string.h>

int main (){
   char name[20];
   printf("Enter a name:\n");
   scanf("%[^\n]s", name);
   printf("You entered:\n%s", name);
   return 0;
}

Output:

Enter a name:
Zaheer Khan

You entered:
Zaheer Khan

JavaScript - Tagged Templates

The tagged templates in JavaScript are an advanced version of template literals. You can define a function to format a string and use it with a template literal, so the string is formatted according to the logic of the function.

The tagged template is used with a template literal by calling only the function name, without parentheses.

Syntax


function format(str, exp1, exp2, ...expN) {
    // Format the string
}

let res = format`${exp1} abcd ${exp2}`;

The format() function acts as a template tag. It takes multiple parameters:

  • str − An array of string literals.
  • exp1, exp2, ...expN − The expressions inside the template literal.

Examples

Basic Tagged Template


function format(str) {
   return str.join("").toUpperCase();
}
let res = format`Hi How are you?`;

Output: HI HOW ARE YOU?

Expression with Tagged Templates


function format(str, name) {
   return str.join(" ") + name;
}
let name = "John";
let res = format`Hi ${name}, How are you?`;

Output: Hi , How are you?John

Using Rest Parameter

You can also use the rest parameter (...values) to collect all expressions into a single array. 


function format(str, ...values) {
   console.log(values);
   return str.join(" ") + values[1];
}
const price = 100;
let name = "John";
const res = format`Hi,${name} The price is ${price}`;

Output:

  • John,100
  • Hi, The price is 100

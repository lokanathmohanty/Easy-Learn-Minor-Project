CSS - zoom Property

The CSS zoom property is used to control the magnification level of HTML elements. It allows developers to zoom in or out of an element by applying a scaling effect. However, it is important to note that zoom is a non-standard CSS property, meaning it is not part of the official CSS specification and might not work consistently across all browsers. Instead, developers are encouraged to use the transform: scale() property for better cross-browser compatibility.

Syntax

The syntax for the zoom property is:

zoom: normal | percentage | number;

Possible Values

  • normal: Renders the element at its normal size.
  • <percentage>: Zoom factor in percent. 100% is normal size, less than 100% zooms out, and more than 100% zooms in.
  • <number>: Zoom factor in numeric value. 1.0 is normal size, less than 1.0 zooms out, and more than 1.0 zooms in.

Applies To

The zoom property can be applied to all HTML elements. However, because it is non-standard, some browsers may not fully support it.

CSS zoom Property with normal Value

The default value of zoom is normal, meaning the element will appear at its regular size without any magnification applied.

Example:

<style>
  .normal {
      zoom: normal;
  }
</style>

<p class="normal">CSS zoom with normal value.</p>

CSS zoom Property with Percent Value

Using a percentage value allows zooming in or out relative to the normal size. A value greater than 100% will zoom in, and a value less than 100% will zoom out.

Example: Zoom-in effect using 200% on hover.

<style>
  .box {
      height: 50px;
      width: 200px;
      border: 1px solid black;
      text-align: center;
      transition: all 0.3s ease;
  }
  .box:hover {
      zoom: 200%;
  }
</style>

<div class="box">Hover to Zoom</div>

CSS zoom Property with Numeric Value

Instead of percentages, numeric values can also be used. A value greater than 1 zooms in, and a value less than 1 zooms out.

Example: Zoom-in effect with zoom: 2.

<style>
  .box {
      height: 50px;
      width: 200px;
      border: 1px solid black;
      text-align: center;
      transition: all 0.3s ease;
  }
  .box:hover {
      zoom: 2;
  }
</style>

<div class="box">Hover to Zoom</div>

CSS zoom Property with Transition

By combining zoom with transitions or even transform: scale(), smooth zoom animations can be created for interactive elements.

Example: Multiple boxes with different zoom levels and hover animations.

<style>
  .box {
      width: 50px;
      height: 50px;
      display: inline-block;
      margin: 10px;
      transition: transform 0.5s;
  }
  #a {
      background-color: green;
      zoom: normal;
  }
  #b {
      background-color: pink;
      zoom: 200%;
  }
  #c {
      background-color: yellow;
      zoom: 2.5;
  }
  .box:hover {
      transform: scale(1.5);
  }
</style>

<div id="a" class="box"></div>
<div id="b" class="box"></div>
<div id="c" class="box"></div>

Best Practice

While zoom can be useful, it is recommended to use transform: scale() for reliable cross-browser support. For example: 

<style>
  .box {
      width: 100px;
      height: 100px;
      background: lightblue;
      transition: transform 0.5s;
  }
  .box:hover {
      transform: scale(1.5);
  }
</style>

<div class="box"></div>

Summary

  • The zoom property adjusts the magnification of elements.
  • It supports values like normal, percentages, and numbers.
  • It is non-standard and not recommended for production use.
  • Prefer using transform: scale() for better compatibility.

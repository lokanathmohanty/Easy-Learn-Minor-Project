Nested Functions in C

Introduction

The term nesting refers to enclosing one programming element inside another of the same type, like nested loops or nested structures. A nested function describes the use of one or more functions inside another function.

What is Lexical Scoping?

In C, defining a function inside another function is not allowed. Functions may be declared (not defined) within other functions, a concept called lexical scoping. However, lexical scoping is not valid in C because the compiler cannot resolve the inner function's memory location.

Limitations of Nested Functions in C

Nested functions cannot access local variables of the enclosing functions, only global variables. C supports two scopes: local and global, which limits the practical use of nested functions.

Example: Attempting a Nested Function

#include <stdio.h>

int main(void) {
    printf("Main Function");

    int my_fun() {
        printf("my_fun function");

        // Nested Function
        int nested() {
            printf("This is a nested function.");
        }
    }
    nested();
}

Output/Error:

main.c:(.text+0x3d): undefined reference to `nested'
collect2: error: ld returned 1 exit status

Trampolines for Nested Functions (GNU C Extension)

GNU C (GCC) supports nested functions using a technique called trampolines. This happens when the address of a nested function is taken at runtime. The nested function must be declared with the auto keyword.

Example 1: Nested Function with auto Keyword

#include <stdio.h>

int main() {
    auto int nested();
    nested();

    printf("In Main Function now\n");

    int nested() {
        printf("In the nested function now\n");
    }

    printf("End of the program");
}

Output:

In the nested function now
In Main Function now
End of the program

Example 2: Nested Function Inside Another Function

#include <stdio.h>
#include <math.h>

double myfunction(double a, double b);

int main() {
    double x = 4, y = 5;
    printf("Addition of squares of %f and %f = %f", x, y, myfunction(x, y));
    return 0;
}

double myfunction(double a, double b) {
    auto double square(double c) { return pow(c, 2); }
    return square(a) + square(b);
}

Output:

Addition of squares of 4.000000 and 5.000000 = 41.000000

Points to Note About Nested Functions

  • A nested function can access all identifiers of the containing function that precede its definition.
  • A nested function must not be called after the containing function exits.
  • A nested function cannot use goto to jump to labels in the containing function.
  • Nested function definitions are permitted within any block, mixed with declarations and statements.
  • Calling a nested function through its address after the containing function exits causes an error.
  • A nested function has no linkage; declaring it with extern or static causes errors.

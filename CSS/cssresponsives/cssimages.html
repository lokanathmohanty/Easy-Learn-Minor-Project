CSS RWD Images

In responsive web design, it is important to make sure images fit well on all screen sizes and resolutions. By using properties like max-width and min-width, images can automatically resize to fit different screens.

When an image is uploaded to a webpage, it will be displayed in its default width and height. We can change these dimensions in CSS so that the image fits according to available space in our layout.

For better adaptability, we should always use relative units for the width property such as percentage, instead of absolute values like pixels. Absolute values restrict the image from being responsive.

Responsive Image Using width Property

To make an image scale according to screen size, we need to set width property of the image to 100% and height to auto.

This setup allows the image to scale with the screen size. However, on very large screens, the image may stretch beyond its natural width, making it appear distorted.

Example

The image will cover 100% width of its parent container.

img {
    width: 100%;
    height: auto;
}

Responsive Image Using max-width Property

On large screens, the image might stretch beyond its natural dimension. To prevent this, we can use max-width property instead of width.

By setting max-width: 100%, the image will scale down if necessary, but never scale up to be larger than its original size.

Example

The image will scale according to the screen size but never exceed its natural size.

img {
    max-width: 100%;
    height: auto;
}

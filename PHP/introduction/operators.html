PHP Operators Types Overview

In PHP, **Operators** are symbols or keywords that perform specific operations on one or more values, known as operands. They are fundamental for performing calculations, making comparisons, and controlling program flow.

Categories of PHP Operators

PHP supports a wide array of operators, categorized by the type of operation they perform:

  • **Arithmetic:** Used for mathematical calculations (e.g., `+`, `-`, `*`, `/`, `%`).
  • **Comparison:** Used to compare two operands, returning a Boolean (`true` or `false`) value (e.g., `==`, `>`, `<=`).
  • **Logical:** Used to combine or invert Boolean expressions (e.g., `&&`, `||`, `!`).
  • **Assignment:** Used to assign or update the value of a variable (e.g., `=`, `+=`, `*=`).
  • **String:** Used specifically for string manipulation (e.g., `.`, `.=`).
  • **Array:** Used for operations unique to arrays (e.g., `+` for union, `==` for equality).
  • **Conditional (Ternary):** A shortcut for an `if-else` statement (e.g., `? :`).

Key Operator Types and Examples

Arithmetic Operators

Perform basic mathematical functions. The increment (`++`) and decrement (`--`) operators change a variable's value by one.

  • `$a + $b` (Addition)
  • `$a / $b` (Division)
  • `$a % $b` (Modulus/Remainder)
  • `$a++` (Increment)

Comparison Operators

Compare values and data types, resulting in a Boolean value.

  • `$a == $b` (Equal value, loose comparison)
  • `$a !== $b` (Not identical, strict comparison: checks value AND type)
  • `$a < $b` (Less than)
  • `$a >= $b` (Greater than or equal to)

Logical Operators

Used to combine complex conditions. Note that `and`/`or` have lower precedence than `&&`/`||`.

  • `$A && $B` (Logical AND)
  • `$A || $B` (Logical OR)
  • `!$A` (Logical NOT)

Assignment and String Operators

Assignment operators, particularly **Compound Assignment**, perform an operation and then assign the result.

  • `$c = $a + $b` (Simple Assignment)
  • `$c += $a` (Compound: Equivalent to `$c = $c + $a`)
  • `$first . $second` (String Concatenation)
  • `$left .= $right` (String Append and Assign)

Operator Precedence and Associativity

**Precedence** dictates the order in which operators are evaluated (e.g., multiplication before addition). **Parentheses `()`** can always be used to force a specific order of execution.

**Associativity** dictates the order of execution for operators with the same precedence (e.g., left-to-right or right-to-left).

In `2 + 6 / 3`, the `/` (division) is executed first due to higher precedence, resulting in $2 + 2 = 4$.

In `(2 + 6) / 3`, the `()` forces the `+` (addition) first, resulting in $8 / 3 = 2.66...$

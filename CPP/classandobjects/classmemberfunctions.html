C++ Class Member Functions (Methods) ⚙️

A **class member function** (or **method**) is a function whose declaration or definition lies within the class body. It operates on an object of that class and has full access to **all members** (data and other functions) of that specific object.

Declaration within the Class

The prototype of the member function must be included in the class definition:

class Box {
   public:
      double length;        
      double getVolume(void); // Member function prototype
      // ...
};

Defining Member Functions

1. Definition Inside the Class (Implicitly inline)

Defining the function body directly within the class definition makes the function implicitly **inline**. This is generally suitable for short functions.

class Box {
   public:
      // ...
      double getVolume(void) {
         return length * breadth * height; // Full access to members
      }
};

2. Definition Outside the Class (Using Scope Resolution)

For longer functions, it's common practice to define them outside the class using the **scope resolution operator** (**::**). This tells the compiler that the function belongs to the specified class.

// Syntax: return_type ClassName::FunctionName(parameters)
double Box::getVolume(void) {
   return length * breadth * height;
}

Calling Member Functions

Member functions are called using the **dot operator** (**.**) on a specific object of the class.

Box myBox;          // Create an object
myBox.setLength(6.0); // Calls setLength() on the 'myBox' object

double v = myBox.getVolume(); // Calls getVolume() on 'myBox'

When myBox.getVolume() is called, the function operates on the length, breadth, and height variables that belong specifically to the myBox object.

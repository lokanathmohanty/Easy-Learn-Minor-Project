C# `continue` Statement

Purpose of the `continue` Statement

The **`continue` statement** is a control flow mechanism used within loops (for, while, or do...while) that forces the program to **skip the remainder of the code block** for the current iteration and immediately jump to the next iteration.

  • For a **`for` loop**, `continue` causes the flow of control to jump directly to the **increment/decrement** step, followed by the conditional test.
  • For **`while`** and **`do...while`** loops, `continue` causes the flow of control to jump directly to the **conditional test**.

Syntax

continue;

Example: Skipping an Iteration in a `do...while` Loop

This example demonstrates how `continue` prevents the Console.WriteLine from executing when the loop variable a is 15. Notice that the update (a = a + 1) **must** be placed before continue to avoid an infinite loop.

using System;
class Program {
    static void Main(string[] args) {
        int a = 10;
         
        do {
            if (a == 15) {
               // Must update 'a' here before continuing!
               a = a + 1; 
               continue; // Skips Console.WriteLine for a=15
            }
            Console.WriteLine("value of a: {0}", a);
            a++;
        } 
        while (a < 20);
    }
}

Output: The value 15 is missing, as its iteration was skipped.

value of a: 10
value of a: 11
value of a: 12
value of a: 13
value of a: 14
value of a: 16
value of a: 17
value of a: 18
value of a: 19

Example: Filtering with `continue` in a `for` Loop

This is a common use case: using `continue` to process only elements that meet a certain criterion (in this case, odd numbers) while ignoring others:

using System;
class ContinueExample {
   static void Main() {
      for (int i = 1; i <= 10; i++) {
         // Check for even numbers
         if (i % 2 == 0) {
            continue; // Skip the rest of the loop body; go to i++
         }
         Console.WriteLine("Odd number: " + i);
      }
      Console.WriteLine("Loop completed.");
   }
}

Output:

Odd number: 1
Odd number: 3
Odd number: 5
Odd number: 7
Odd number: 9
Loop completed.

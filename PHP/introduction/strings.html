PHP Strings: Fundamentals and Operations

A **string** is a sequence of characters. In PHP, a string is an array of bytes, and a character is equivalent to a byte, limiting native support to a **256-character set** (no native Unicode). PHP supports four ways to represent strings: **single-quoted**, **double-quoted**, **Heredoc**, and **Nowdoc**.

Single-Quoted Strings (`'`)

Single-quoted strings are treated almost **literally**. They offer the fastest execution as the parser does minimal work.

  • **Variable Expansion:** Variables (like `$x`) are **not expanded**; they are printed as literal text (e.g., `'Value of x = $x'` outputs `Value of x = $x`).
  • **Escaping:** Only two characters need escaping:
    • **`\'`** $\rightarrow$ A literal single quote.
    • **`\\`** $\rightarrow$ A literal backslash.
  • **Escape Sequences:** Sequences like `\n` or `\r` are treated as literal characters, not interpreted as newline or carriage return.

Double-Quoted Strings (`"`)

Double-quoted strings are **preprocessed** by PHP, offering two key features not found in single-quoted strings:

  • **Variable Interpolation:** Variable names are **expanded** and replaced with their string representations.
    $price = 200; echo "Price = $price"; $\rightarrow$ `Price = 200`
  • **Special Escape Sequences:** Standard C-like escape sequences are interpreted:

    `\n` (newline), `\r` (carriage return), `\t` (horizontal tab), `\\` (backslash), `\"` (double-quote), and `\$` (literal dollar sign).

  • **Character Escaping:** PHP allows escaping octal (prefix `\`) and hexadecimal (prefix `\x`) numbers to represent ASCII characters.
    $str = "\x50\x48\x50"; $\rightarrow$ `PHP` (since 50 is the hex code for 'P', 48 for 'H')

String Operators and Functions

String Concatenation Operator (`.`)

The dot (`.`) is the concatenation operator used to join two or more strings together.

$s1="Hello"; $s2="World"; echo $s1 . " " . $s2; $\rightarrow$ `Hello World`

`strlen()` Function (Get Length)

Returns the **length of a string** in bytes (which is the number of characters in a non-Unicode string).

echo strlen("Hello world!"); $\rightarrow$ `12`

`strpos()` Function (Find Position)

Searches for the first occurrence of a substring within a larger string.

  • Returns the **position** (index) of the first match, with the starting position being **0**.
  • Returns **`FALSE`** if no match is found.
echo strpos("Hello world!","world"); $\rightarrow$ `6` (since the space is at index 5, 'w' is at index 6)

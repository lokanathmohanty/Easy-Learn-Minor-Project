C++ while Loop (Entry-Controlled) 🔄

The **while loop** is an **entry-controlled** looping structure that repeatedly executes a block of code as long as a specified condition remains **true** (any non-zero value). The condition is tested at the start of each iteration.

Syntax and Mechanism

The flow involves checking the condition first. If it's true, the body executes; if it's false, the loop terminates immediately.

while (condition) {
   // Statement(s) to execute repeatedly
   // Must include code to eventually change the condition!
}
// Program control moves here when the condition is false.
  • **Key Feature:** The while loop might **not execute at all** if the initial condition is false.

Example Analysis (a starts at 10)

The loop is initialized with a = 10 and continues as long as a < 20. The increment a++ is essential to ensure the condition eventually becomes false, preventing an infinite loop.

int a = 10;
while( a < 20 ) { 
   cout << "value of a: " << a << endl; // Print current value
   a++; // Increment 'a'
} 
// Loop terminates when 'a' reaches 20.

The loop executes for values of a from 10 up to 19. When a becomes 20, the condition (20 < 20) is false, and the loop stops. The resulting output is:

value of a: 10
value of a: 11
value of a: 12
value of a: 13
value of a: 14
value of a: 15
value of a: 16
value of a: 17
value of a: 18
value of a: 19

ReactJS - Helmet

The meta information of a web document is very important for SEO purposes. The meta information is generally specified inside the head using <meta> tags. The <title> tag also plays an important role in providing meta information about a document. The head section can also have <script> and <style> tags. The Helmet component provides an easy way to manage the head section of a document by providing all valid head tags. Helmet will gather all the information specified inside it and update the head section of the document.

Installing Helmet

Use the following command to install the Helmet component:

npm install --save react-helmet

The above command will install the helmet component and make it ready to use in your application.

Concept and Usage of Helmet

Helmet accepts all valid head tags and outputs them in the head section of the document. Example:

import React from "react";
import {Helmet} from "react-helmet";

class Application extends React.Component {
   render () {
      return (
         <div className="application">
            <Helmet>
               <title>Helmet sample application</title>
               <meta charSet="utf-8" />
               <meta name="description" content="Helmet sample program to understand the working of the helmet component" />
               <meta name="keywords" content="React, Helmet, HTML, CSS, Javascript" />
               <meta name="author" content="Peter" />
               <meta name="viewport" content="width=device-width, initial-scale=1.0" />
            </Helmet>
         </div>
      );
   }
}

Helmet can also be nested. If a child component has its own Helmet, it will update the head section when the child is rendered.

Applying Helmet

Steps to apply Helmet in a React application:

  • Create a new React application: create-react-app myapp
  • Start the application: npm start
  • Remove all CSS classes from App.css
  • Create a new component SimpleHelmet and add Helmet configuration.
import React from "react";
import {Helmet} from "react-helmet";

class SimpleHelmet extends React.Component {
   render() {
      return (
         <div>
            <Helmet>
               <title>Helmet sample application</title>
               <meta charSet="utf-8" />
               <meta name="description" content="Helmet sample program to understand the working of the helmet component" />
               <meta name="keywords" content="React, Helmet, HTML, CSS, Javascript" />
               <meta name="author" content="Peter" />
               <meta name="viewport" content="width=device-width, initial-scale=1.0" />
            </Helmet>
            <p>A sample application to demonstrate helmet component.</p>
         </div>
      )
   }
}

export default SimpleHelmet;

Finally, import and use the component inside App.js.

Summary

The Helmet component is an easy-to-use utility to manage the head content of the document. It supports both server-side and client-side rendering, making it a powerful tool for SEO and document metadata management in React applications.

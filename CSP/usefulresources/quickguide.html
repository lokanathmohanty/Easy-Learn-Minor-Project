String Type

The **String Type** allows you to assign any string value to a variable. The string is an alias for the System.String class. It is derived from object type. The value of a string type can be assigned using string literals in two forms:

  • **Quoted form:** The strings are enclosed in double quotes (" ").
  • **@ quoted form (verbatim strings):** The strings are prefixed with @, allowing escape characters (like \n or \t) to be ignored and multi-line strings to be easily created.

For example:

string str = "C# is a powerful language.";
string path = @"C:\Windows\System32";

Strings are **immutable**, meaning once a string object is created, its content cannot be changed. Any operation that appears to modify a string actually creates a new string object.

Pointer Type

Pointer types hold the memory address of another type. They are similar to pointers in C or C++. However, pointer access is restricted and requires the use of the **unsafe** modifier.

  • Pointer types are only available in code blocks marked with the unsafe keyword.
  • They are primarily used for interoperability with unmanaged code or performance-critical areas.
  • A pointer is declared using the asterisk (*) symbol, such as int* p.

The use of pointers bypasses the Common Language Runtime (CLR)'s garbage collection, which is why it is considered "unsafe" and must be explicitly enabled.

Syntax Example:

class TestPointer {
   unsafe static void Main(string[] args) {
      int var = 20;
      int* p = &var; // p now holds the address of var
   }
}

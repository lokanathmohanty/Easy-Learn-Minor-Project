HTML - Character Encodings

Character encoding is a method of converting bytes into characters. To validate or display an HTML document properly, a program must choose a proper character encoding.

HTML Charset Attribute

The HTML charset attribute of the <meta> tag is used to mention character encoding of a webpage. 

<meta charset="UTF-8">

The ASCII Character Set

The most common character set or character encoding in use on computers is ASCII (The American Standard Code for Information Interchange). It consists of 128 characters (0–127).

  • English Alphabets (A–Z and a–z)
  • Numbers (0–9)
  • Special Characters (@, #, $, %, etc.)

The ANSI Character Set

ANSI character set is generally used in Windows systems, also called windows-1252.

  • From 0 to 127: ANSI follows ASCII characters.
  • From 128 to 159: Some extra special characters are added.
  • From 160 to 255: Identical to UTF-8.

The ISO-8859-1 Character Set

ISO-8859-1 was the default character set for HTML 4. It supported 256 different character codes.

  • Same as ASCII for the first 128 characters.
  • Does not use the characters from 128 to 159.
  • Same as ANSI and UTF-8 from 160 to 255.

The UTF-8 Character Set

The HTML5 specification recommends developers to use UTF-8 encodings in webpages because it covers all characters and symbols in the world.

  • Identical to ASCII for 0 to 127 characters.
  • Characters 128 to 159 are empty.
  • Uses same characters as ANSI and ISO-8859-1 from 160 to 255.
  • Supports characters from other languages (256 to 1000 and beyond).

ISO Character Sets

Here is the list of ISO character sets being used around the world:

  • ISO-8859-1 — Latin alphabet part 1 (Western Europe, Latin America, Caribbean, Africa)
  • ISO-8859-2 — Latin alphabet part 2 (Eastern Europe)
  • ISO-8859-3 — Latin alphabet part 3 (SE Europe, Esperanto, miscellaneous)
  • ISO-8859-4 — Latin alphabet part 4 (Scandinavia/Baltics)
  • ISO-8859-5 — Latin/Cyrillic alphabet
  • ISO-8859-6 — Latin/Arabic alphabet
  • ISO-8859-7 — Latin/Greek alphabet
  • ISO-8859-8 — Latin/Hebrew alphabet
  • ISO-8859-9 — Latin 5 alphabet (Turkish replaces Icelandic)
  • ISO-8859-10 — Latin 6 alphabet (Nordic, Eskimo, Lappish)
  • ISO-8859-15 — Extended Latin alphabet (more characters added)
  • ISO-2022-JP — Latin/Japanese alphabet part 1
  • ISO-2022-JP-2 — Latin/Japanese alphabet part 2
  • ISO-2022-KR — Latin/Korean alphabet

Unicode and UTF Character Sets

Unicode was developed to encompass all characters from different languages in a single encoding system. Unicode provides different formats:

  • UTF-8 — Variable-width, 1 to 4 bytes per character.
  • UTF-16 — Variable-width, 1 or 2 shorts (16-bit units).
  • UTF-32 — Fixed-width, always 1 long (32-bit unit).

The first 256 characters of Unicode correspond to ISO-8859-1. By default, HTML4 processors support UTF-8, while XML and XHTML processors support both UTF-8 and UTF-16.

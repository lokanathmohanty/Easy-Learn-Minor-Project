Power BI: DAX Depreciation Functions

DAX depreciation functions calculate the depreciation value of assets over specified periods using various accounting methods. These functions are integral for financial analysis and reporting in Power BI.

Key Depreciation Functions with Examples

  • AMORDEGRC() - Returns depreciation for each period using the French accounting system's method.
    Example: lk = AMORDEGRC(8600, DATE(1998,4,23), DATE(1999,11,30), 790, 4, 0.13)
  • AMORLINC() - Calculates linear depreciation for each accounting period.
    Example: tr = AMORLINC(8900, DATE(1999,4,23), DATE(2000,11,30), 567, 3, 0.11)
  • DB() - Computes depreciation using the fixed declining balance method over a given period.
    Example: rt = DB(76000.00, 2300.00, 3, 1)
  • DDB() - Calculates depreciation using the double declining balance method.
    Example: dpr = DDB(87000.00, 4600.00, 5, 2)
  • SLN() - Returns straight-line depreciation over the asset's lifetime.
    Example: tr = SLN(9800.00, 4900.00, 4)
  • SYD() - Computes depreciation using the sum-of-years'-digits method.
    Example: sd = SYD(65000.00, 6000.00, 5, 2)

Usage Notes

Depreciation functions require parameters like asset cost, salvage value, useful life, period for depreciation, and optionally rate or factor.

These functions calculate depreciation values for each specified period and can be used in calculated columns or measures for financial reporting.

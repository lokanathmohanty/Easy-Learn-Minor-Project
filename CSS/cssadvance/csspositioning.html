CSS - Positioning

What is CSS Position?

In CSS, the position property is used to define how an element is placed in a webpage. It allows developers to create floating layouts, sticky navigation bars, and interactive page features. The position of an element can be manipulated using top, right, bottom, and left properties, which specify the offset of the element relative to its containing block.

Syntax:

position: static | relative | absolute | fixed | sticky;

Static Positioned Element

By default, elements are positioned using position: static. Static elements remain in the normal flow of the document, and offsets such as top, left, right, and bottom have no effect on them.

Example

<div class="static-element">
   This is a static element.
</div>

Relative Positioned Elements

The position: relative property allows an element to be positioned relative to its original position in the document. The element still occupies its original space, but you can shift it using offset properties.

Example

<div class="relative-element">
   This element is shifted 20px down and 30px right.
</div>

Absolutely Positioned Elements

An element with position: absolute is removed from the normal flow and positioned relative to the nearest ancestor that has a positioning property other than static. If no such ancestor exists, it is positioned relative to the viewport.

Example

<div class="absolute-element">
   Absolutely positioned element.
</div>

Fixed Positioned Element

The position: fixed property allows an element to remain in the same position relative to the browser window, even when the page is scrolled.

Example

<p class="fixed-element">
   I stay fixed even when you scroll.
</p>

Sticky Positioned Element

The position: sticky property is a hybrid of relative and fixed positioning. A sticky element toggles between relative and fixed, depending on the user's scroll position.

Example

<h2 class="sticky-header">
   I stick to the top when scrolling.
</h2>

Positioning Text in an Image

By combining position: absolute with a relatively positioned container, you can place text on images at any location such as corners or the center.

Example

<div class="image-container">
   <img src="flower.jpg" alt="Flower">
   <h3 class="top-left">Top Left</h3>
   <h3 class="bottom-right">Bottom Right</h3>
</div>

Position Related Properties

  • top – Sets the vertical offset of an element.
  • bottom – Moves the element based on its bottom edge.
  • left – Moves the element based on its left edge.
  • right – Moves the element based on its right edge.
  • z-index – Controls the stack order of elements.
  • overflow – Determines how content is rendered if it overflows.
  • clip – Defines a clipping region for an element.
  • vertical-align – Aligns inline or table-cell elements vertically.

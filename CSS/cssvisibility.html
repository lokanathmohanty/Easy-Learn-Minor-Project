CSS - Visibility Property

The CSS visibility property allows you to control whether an element is shown or hidden, while still preserving its allocated space in the document layout. This differs from the display property, which completely removes the element from the layout when set to none.

The visibility property is especially useful when you want to hide elements temporarily without collapsing the surrounding layout. It can be applied to all HTML elements, including block elements, inline elements, and table rows or columns.

Syntax

The general syntax of the property is:

  • visibility: visible | hidden | collapse | initial | inherit;

Possible Values

  • visible: Default value. The element is visible.
  • hidden: The element is hidden but still takes up space in the layout.
  • collapse: For table rows, columns, or cells, it removes them from the table. On non-table elements, it behaves like hidden.
  • initial: Resets the property to its default value (visible).
  • inherit: Inherits the visibility value from its parent element.

CSS visibility - visible Value

By default, elements are visible. You can explicitly set visibility to make sure an element is shown.

  • Example: A heading made explicitly visible.
  • Even if previously hidden, applying visibility: visible restores the element.

CSS visibility - hidden Value

When an element is set to hidden, it disappears from view but still occupies space in the layout. Screen readers may still detect the element.

  • Use this when you want to hide content without shifting layout.
  • The element remains interactive for assistive technologies.

CSS visibility - collapse Value

The collapse value applies primarily to table elements:

  • Table rows or columns are removed completely, and the layout adjusts accordingly.
  • For non-table elements, collapse works the same as hidden.

Examples Explained

  • Visible Example: A heading displayed normally.
  • Hidden Example: A heading hidden but still taking space, while other text flows around it.
  • Collapse Example 1: In a table, cells or rows disappear completely from the structure.
  • Collapse Example 2: On a non-table element, behaves like hidden.

Comparison: visibility vs display

It is important to distinguish visibility from display:

  • visibility: hidden → element is invisible but still occupies space.
  • display: none → element is completely removed from the layout.

Browser Support

The visibility property is supported by all major browsers:

  • Chrome: Supported since version 1.0
  • Edge: Supported since version 12.0
  • Firefox: Supported since version 1.0
  • Safari: Supported since version 1.0
  • Opera: Supported since version 4.0

Key Takeaways

  • Use visibility when you want to hide an element but preserve layout flow.
  • Use display: none when you want to remove the element entirely.
  • collapse is useful for hiding table rows or columns.
  • For accessibility, remember that hidden elements may still be announced by screen readers.

With the visibility property, you gain fine control over how elements are displayed in the document flow, making it a powerful option for managing layouts, conditional content, and user interactions.

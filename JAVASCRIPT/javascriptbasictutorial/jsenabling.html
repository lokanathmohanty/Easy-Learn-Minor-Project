Enabling JavaScript in Browsers

Enabling JavaScript

All modern browsers come with built-in support for JavaScript, and it is enabled by default. Sometimes, you may need to enable or disable it manually. Below are steps for Chrome, Microsoft Edge, Firefox, Safari, Opera, and Brave.

JavaScript in Chrome

  • Click the Chrome menu at the top right-hand corner of your browser.
  • Select the Settings option.
  • Click on the Privacy and Security tab from the left sidebar.
  • Click Show advanced settings at the end of the page.
  • Click on the Site Settings tab.
  • Scroll down and find the JavaScript section.
  • Select a radio button to turn JavaScript on or off.
  • You can also add URLs to block/unblock JavaScript on specific websites.

JavaScript in Microsoft Edge

  • Click the Edge menu (three dots) at the top right-hand corner.
  • Go to More Tools → Internet Options.
  • Select the Security tab.
  • Click the Custom Level button.
  • Scroll down to the Scripting option.
  • Select Enable under Active scripting to enable JavaScript.
  • Select Disable to turn it off.

JavaScript in Firefox

  • Open a new tab and type about:config in the address bar.
  • Accept the warning: I'll be careful, I promise!
  • Search for javascript.enabled.
  • Toggle its value:
    • true → enabled
    • false → disabled

JavaScript in Safari

  • Click the Safari menu from the top-left corner.
  • Select Preferences from the dropdown.
  • Go to the Security tab.
  • Check Enable JavaScript to enable it, or uncheck to disable.
  • Close the preferences window and reload the page.

JavaScript in Opera

  • Go to Tools → Preferences.
  • Select the Advanced option.
  • Choose Content from the list.
  • Check Enable JavaScript to turn it on.
  • Uncheck to disable.

JavaScript in Brave

  • Open the website URL where you want to disable JavaScript.
  • Click the Brave Shields icon in the address bar.
  • Find the Scripts option in the Shields panel.
  • Default is Allow Scripts. Choose Block Scripts to disable for that site.

Warning for Non-JavaScript Browsers

If you need to ensure users know when JavaScript is required, you can use the <noscript> tag. Example:

Example

<html>
<head>
   <script>
      document.write("Hello World!")
   </script>

   <noscript>
      Sorry...JavaScript is needed to go ahead.
   </noscript>      
</head>
<body>
</body>
</html>

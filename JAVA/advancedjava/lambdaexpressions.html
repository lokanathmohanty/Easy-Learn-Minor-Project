Java - Lambda Expressions

Lambda expressions were introduced in Java 8 and are a major feature that simplifies functional programming. A lambda expression provides a clear and concise way to implement a functional interface — an interface with a single abstract method.

Lambdas remove boilerplate code and make programs more readable. They can infer parameter types and may omit return statements and even braces in simple cases.

Lambda Expression Syntax

parameter -> expression body

Characteristics of Java Lambda Expressions

  • Optional type declaration: Compiler infers the parameter types.
  • Optional parentheses: Not needed for single parameters.
  • Optional braces: Not required for single-statement bodies.
  • Optional return keyword: Inferred if body contains a single expression.

Example: Basic Math Operations with Lambda

MathOperation addition = (int a, int b) -> a + b;
MathOperation subtraction = (a, b) -> a - b;
MathOperation multiplication = (int a, int b) -> { return a * b; };
MathOperation division = (int a, int b) -> a / b;

System.out.println("10 + 5 = " + operate(10, 5, addition));
System.out.println("10 - 5 = " + operate(10, 5, subtraction));
System.out.println("10 x 5 = " + operate(10, 5, multiplication));
System.out.println("10 / 5 = " + operate(10, 5, division));

Output:

10 + 5 = 15
10 - 5 = 5
10 x 5 = 50
10 / 5 = 2

Example: Lambda with GreetingService

GreetingService greetService1 = message -> System.out.println("Hello " + message);
GreetingService greetService2 = (message) -> System.out.println("Hello " + message);

greetService1.sayMessage("Mahesh");
greetService2.sayMessage("Suresh");

Output:

Hello Mahesh
Hello Suresh

Using Constants in Lambda

Lambdas can access final or effectively final variables. Reassigning such variables causes a compilation error.

Example: Constant in Lambda

final static String salutation = "Hello! ";
GreetingService greetService1 = message -> System.out.println(salutation + message);

greetService1.sayMessage("Mahesh");

Output:

Hello! Mahesh

Lambda in Java Collections

Lambda expressions are commonly used in collections — for iteration, filtering, and sorting. Java 8 added many new methods to the Collection API that support lambdas.

Example: Lambda with forEach and removeIf

List<String> list = new ArrayList<>();
list.add("java");
list.add("html");
list.add("python");

list.forEach(i -> System.out.println(i));

List<Integer> numbers = new ArrayList<>();
numbers.add(1);
numbers.add(2);
numbers.add(3);
numbers.add(4);
numbers.add(5);
numbers.add(6);
numbers.add(7);
numbers.add(8);

System.out.println(numbers);
numbers.removeIf(n -> n % 2 != 0);
System.out.println(numbers);

Output:

java
html
python
[1, 2, 3, 4, 5, 6, 7, 8]
[2, 4, 6, 8]

Conclusion

Lambda expressions simplify code by removing the need for anonymous classes and boilerplate. They improve readability and enable functional-style operations, especially in collections.

Java ArrayList Class Summary 📏🔗

The **java.util.ArrayList** class is the most common implementation of the **List** interface in Java. It provides a **resizable-array** implementation, which means it behaves like a standard array but can grow or shrink dynamically as elements are added or removed.

I. Core Characteristics and Performance

ArrayList is a general-purpose, non-synchronized list with distinct performance characteristics:

  • Dynamic Array: Unlike native Java arrays (which have a fixed size), ArrayList automatically manages its internal array storage. When the internal capacity is exceeded, a new, larger array is created, and all elements are copied over—this resizing operation is expensive ($O(n)$).
  • Random Access: It implements the **RandomAccess** marker interface. Accessing an element by index using **get(index)** is extremely fast (constant time, $O(1)$).
  • Insertions/Deletions: Adding or removing an element at the **end** of the list is fast ($O(1)$ amortized). However, inserting or removing an element from the **middle** of the list requires shifting all subsequent elements, resulting in slow, linear time performance ($O(n)$).
  • Non-Synchronized: ArrayList is **not thread-safe**. If multiple threads access it concurrently, external synchronization is required. (For a thread-safe alternative, use **Vector** or **Collections.synchronizedList(new ArrayList(...))**).

II. Constructors and Capacity Management

  • **ArrayList():** Creates an empty list with a default initial capacity (usually sufficient for **10 elements**).
  • **ArrayList(int initialCapacity):** Recommended when the approximate size is known, as it avoids initial resizing costs.
  • **void ensureCapacity(int minCapacity):** Allows a developer to manually increase the internal capacity, preventing resizing overheads during batch element additions.
  • **void trimToSize():** Reduces the internal array's capacity to the list's current size, minimizing memory usage after many deletions.

III. Demonstration of Operations

The example illustrates the ease of adding and removing elements, a core feature of the dynamic nature of ArrayList.

Code Analysis:

// Initial size: 0 (capacity is 10)
ArrayList al = new ArrayList(); 

al.add("C"); 
al.add(1, "A2"); // Fast, as insertion is near the start
// Contents: [C, A2, A, E, B, D, F]

al.remove("F"); // Removes element "F"
al.remove(2);   // Removes the element at index 2 (which is "A")

// Final Contents: [C, A2, E, B, D]
// Size after deletions: 5

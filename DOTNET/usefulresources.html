Instructions for Generating Clean HTML

The user has requested the generation of **clean HTML code** suitable for an e-learning text session. This HTML must adhere to strict structural constraints to integrate correctly with an existing external CSS file.

Mandatory Constraints

  • **No CSS Styles:** Do not include any <style> tags or style="" attributes (inline styling).
  • **No Styling Tags:** Do not use tags that are primarily for styling (e.g., <b>, <i>, <font>). Use semantic alternatives where necessary (e.g., <strong> or <em>).
  • **Semantic Structure Only:** Use standard semantic HTML tags such as <div>, <h1>, <h2>, <p>, <ul>, <li>, and <a>.

Required Class Structure

The HTML must strictly employ the following classes for organizational structure:

  • container: The outermost wrapper for the entire page section.
  • session: The wrapper for the main content block.
  • title: Contains the main heading (<h1>) and navigation links.
  • content: Contains the primary text, lists, and examples.

Example Formatting Rule

When presenting examples or code blocks, the **content** section should contain a subsection where an inner <div> is used to define the example block, if no specific class for examples is provided in the prompt beyond the primary structure (container, session, title, content).

Python - Renaming and Deleting Files

In Python, files can be renamed and deleted using functions from the os module. These operations are essential for file management within a file system.

Renaming Files in Python

Use the os.rename() function to rename a file. It requires two arguments: the current file name and the new file name. 

import os

# Current file name
current_name = "oldfile.txt"

# New file name
new_name = "newfile.txt"

# Rename the file
os.rename(current_name, new_name)

print(f"File '{current_name}' renamed to '{new_name}' successfully.")

Output:

File 'oldfile.txt' renamed to 'newfile.txt' successfully.

Deleting Files in Python

Use the os.remove() function to delete a file by specifying its filename. 

import os

# File to be deleted
file_to_delete = "file_to_delete.txt"

# Delete the file
os.remove(file_to_delete)

print(f"File '{file_to_delete}' deleted successfully.")

Output:

File 'file_to_delete.txt' deleted successfully.

JavaScript - Recursion

Recursion is a programming technique where a function calls itself. It is useful when solving problems that can be broken down into smaller, similar subproblems.

What is Recursion?

The word recursion comes from "recurring," meaning happening again and again. A recursive function calls itself with a modified input until it reaches a stopping point called the base condition.

For example, when calculating the factorial of a number, the function calls itself by decreasing the input step by step until it reaches 1, which acts as the base condition.

How Recursion Works?

Recursion follows the principle of divide and conquer. The function divides the problem into smaller chunks and continues solving until the base condition is met, after which the recursive calls stop and results are returned back up the chain.

Example of Recursion: Factorial

The factorial of a positive integer n is defined as:

n! = 1 × 2 × 3 × ... × n

  • Factorial of 0 is 1.
  • Factorial of negative numbers does not exist.

Example Code


// Recursive function to find factorial
function fact(n) {
   // base condition
   if (n === 0) {
      return 1;
   } else {
      return n * fact(n - 1);
   }
}

const num = 6;
if (num >= 0) {
   let result = fact(num);
   console.log(`The factorial of ${num} is ${result}`);
}

Output


The factorial of 6 is 720

Explanation

Let’s break down the recursive process for fact(6):

  • fact(6) → 6 × fact(5)
  • fact(5) → 5 × fact(4)
  • fact(4) → 4 × fact(3)
  • fact(3) → 3 × fact(2)
  • fact(2) → 2 × fact(1)
  • fact(1) → 1 × fact(0)
  • fact(0) → 1 (base condition)

Multiplying all results together gives 720.

Advantages of Recursion

  • Simplifies code for problems like factorial, Fibonacci, and tree traversal.
  • Makes code more readable for divide-and-conquer algorithms.

Disadvantages of Recursion

  • Consumes more memory due to repeated function calls in the call stack.
  • May cause stack overflow if the base condition is missing or incorrect.

Conclusion

Recursion is a powerful tool in JavaScript. By understanding how to define a base condition and break down problems into smaller subproblems, developers can solve complex tasks elegantly. However, recursion must be used carefully to avoid performance issues.

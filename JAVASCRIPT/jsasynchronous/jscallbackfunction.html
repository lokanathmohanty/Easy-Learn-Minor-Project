JavaScript - Callback Functions

What is the Callback Function?

The callback function in JavaScript is regularly passed as an argument of another function. The callback function name can be any valid identifier.

The callback function can be called inside the parent function after completing a particular task. It is mainly used to handle asynchronous operations.

Syntax

function func_name(callback) {
   // function body
   callback();
}
func_name(callback); // Function invocation

// OR
func_name(() => {
   // Callback function body
})

You can also pass an arrow or anonymous function as a callback function.

Example

In this example, the multiply() function is passed as an argument to the sum() function. 

function multiply(a) {
   let m = a * 4;
   console.log("The result is " + m);
}

function sum(a, b, callback) {
   let c = a + b;
   callback(c);
}

sum(4, 8, multiply);

Output: The result is 48

Passing an Anonymous Function as a Callback

function mathOperation(a, b, callback) {
   let result = callback(a, b);
   console.log("The result is " + result);
}

mathOperation(10, 20, function (a, b) {
   return a + b;
});

mathOperation(20, 10, function (a, b) {
   return a - b;
});

mathOperation(10, 20, function (a, b) {
   return a * b;
});

Output:

  • The result is 30
  • The result is 10
  • The result is 200

Need for the Callback Function

JavaScript is single-threaded and executes code line-by-line. For tasks like fetching data, loading images, or API requests, callbacks prevent blocking execution.

Example with setTimeout()

console.log("Start of the program");

setTimeout(function printMessage() {
   console.log("In the printMessage() function");
}, 500);

console.log("End of the program");

Output:

  • Start of the program
  • End of the program
  • In the printMessage() function

Callbacks with Built-in Methods

array.sort()

let arr = [23, 21, 56, 11, 10, 7, 8];
console.log(arr.sort()); // Ascending

let sorted = arr.sort(function(a, b) {
   return b - a;
});
console.log(sorted); // Descending

array.filter()

let arr = [23, 21, 56, 11, 10, 7, 8];
let evenNums = arr.filter(function(element) {
   return element % 2 === 0;
});
console.log(evenNums);

Callbacks with Events

let button = document.getElementById("btn");
button.addEventListener("click", function() {
   console.log("You clicked the button");
});

Nesting Callbacks and Callback Hell

function asyncTask(taskName, duration, callback) {
   console.log("Task started " + taskName);
   setTimeout(() => {
      console.log("Completed " + taskName);
      callback();
   }, duration);
}

asyncTask("Task 1", 1000, () => {
   asyncTask("Task 2", 1500, () => {
      asyncTask("Task 3", 1000, () => {
         console.log("All tasks completed");
      });
   });
});

Nested callbacks can become complex and difficult to read. This is known as Callback Hell. In such cases, Promises or async/await should be used.

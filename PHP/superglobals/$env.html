PHP `$_ENV` Superglobal and Environment Variables

The **`$_ENV`** is a **superglobal associative array** that holds all **environment variables** available to the current PHP script. Environment variables are values (like system paths, user information, or configuration settings) provided by the operating system shell or the web server under which the PHP parser is running.

Key Features and Accessibility

  • **Superglobal:** `$_ENV` is accessible in all scopes (including functions and classes) without explicit declaration.
  • **Source:** Most variables are inherited from the operating system shell or the web server (including CGI variables). The contents vary significantly across platforms (Windows, Linux, etc.) and server configurations.
  • **Access:** You retrieve a variable's value using its name as a key: echo $_ENV['Path'];

Configuration Caveat (Important) ⚠️

The availability of variables in the `$_ENV` array depends on the **`variables_order`** directive in your `php.ini` file. If the letter **`E`** (for Environment) is not included in this setting, the `$_ENV` array will be empty.

To ensure `$_ENV` is populated, set:
variables_order = "**E**GPCS"

Related Functions for Environment Variables

1. `getenv()` (Get Environment Variable)

This function is the standard, reliable way to retrieve environment variables and is often preferred over using `$_ENV` due to the `variables_order` dependency.

  • **Get Specific Variable:** getenv("PATH")
  • **Get All Variables:** Called without arguments, it returns an array of all environment variables.

2. `putenv()` (Set Environment Variable)

This function allows you to set or change the value of an environment variable for the duration of the **current request only**.

putenv("PHP_TEMPUSER=GUEST");
echo getenv("PHP_TEMPUSER"); // Output: GUEST

*Note: Changing certain sensitive variables is restricted, often controlled by the `safe_mode_protected_env_vars` directive in `php.ini`.*

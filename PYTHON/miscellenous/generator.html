Python Generators

Generators in Python are a convenient way to create iterators that produce values on-the-fly and do not store entire sequences in memory. They are especially useful for large datasets or infinite sequences.

A generator is defined like a normal function using the def keyword but uses yield instead of return to produce a value. Each call to the generator's __next__() method resumes execution right after the last yield.

Creating Generators

Using Generator Functions

def count_up_to(max_value):
    current = 1
    while current <= max_value:
        yield current
        current += 1

counter = count_up_to(5)
for number in counter:
    print(number)

Output:

1
2
3
4
5

Using Generator Expressions

gen_expr = (x * x for x in range(1, 6))

for value in gen_expr:
    print(value)

Output:

1
4
9
16
25

Exception Handling in Generators

You can iterate a generator using a while loop with exception handling for StopIteration: 

def generator(num):
    for x in range(1, num+1):
        yield x

it = generator(5)
while True:
    try:
        print(next(it))
    except StopIteration:
        break

Output:

1
2
3
4
5

Normal Function vs Generator Function

Normal functions compute and return all values at once and then terminate, discarding local variables. Generator functions yield values one at a time, suspending state between yields and generating values lazily. 

# Normal function producing Fibonacci series
def fibonacci(n):
    fibo = []
    a, b = 0, 1
    while True:
        c = a + b
        if c >= n:
            break
        fibo.append(c)
        a, b = b, c
    return fibo

f = fibonacci(10)
for i in f:
    print(i)

Output:

1
2
3
5
8

# Generator function producing Fibonacci series
def fibonacci(n):
    a, b = 0, 1
    while True:
        c = a + b
        if c >= n:
            break
        yield c
        a, b = b, c

f = fibonacci(10)
while True:
    try:
        print(next(f))
    except StopIteration:
        break

Output:

1
2
3
5
8

Asynchronous Generators

Asynchronous generators are Python coroutines defined with async def and are used with async for loops. They yield items asynchronously and allow awaiting other coroutines during iteration. 

import asyncio

async def async_generator(x):
    for i in range(1, x+1):
        await asyncio.sleep(1)
        yield i

async def main():
    async for item in async_generator(5):
        print(item)

asyncio.run(main())

Output:

1
2
3
4
5

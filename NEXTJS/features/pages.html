Next.js Pages: The Building Blocks of Routing 📄

What Pages Are and Where They Live

In Next.js, **pages** are **React components** that define the user interface for a specific route. The framework uses a **file-based routing system**, where the file names and folder structure within the primary routing directory automatically map to URLs.

  • Recommended Directory: The **`/app`** directory (using the **App Router**) is the current standard.
  • Page File: Any file named **`page.js`** (or `page.tsx`) inside a folder in the `/app` directory becomes a public route.

Creating Different Page Types

1. Home Page (Root Route)

The home page is defined by the `page.js` file located directly inside the `/app` directory.

  • **File:** `app/page.jsx`
  • **Route:** `http://localhost:3000/`
// app/page.jsx
export default function Home() {
    return (<h1>Welcome to My Next.js App</h1>);
}

2. Nested Routing Pages

Routes with segments (e.g., `/about`) are created by adding a **folder** and placing a `page.js` file inside it.

  • **File:** `app/about/page.jsx`
  • **Route:** `http://localhost:3000/about`

3. Dynamic Routing Pages

Dynamic routes are used when the URL contains a variable (a parameter). The folder name for the dynamic segment is enclosed in **square brackets** (`[]`). Parameters are retrieved using the `useParams()` hook (for client components).

  • **File:** `app/products/[id]/page.tsx`
  • **Route:** `http://localhost:3000/products/123` (where `id` is `123`)
// Accesses the dynamic parameter 'id'
const { id } = useParams();

Layout Pages (Shared UI)

In the App Router, **Layout Pages** define the **shared UI** across multiple pages or nested routes. They are defined by the special file name **`layout.js`** (or `layout.tsx`) and are essential for maintaining persistent elements like headers and footers during navigation.

A layout component must accept and render a **`children`** prop, which will be the content of the nested `page.js` file.

// app/layout.jsx (Example)
export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>
        <header><h1>Header Element</h1></header>
        <main>{children}</main> <!-- Page content goes here -->
      </body>
    </html>
  );
}

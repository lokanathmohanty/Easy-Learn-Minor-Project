Multiple Catch Blocks in Java

What are Multiple Catch Blocks?

Multiple catch blocks in Java allow a single try block to handle different types of exceptions separately, enhancing error handling by processing specific exceptions in relevant catch blocks.

Syntax

try {
   // Protected code
} catch (ExceptionType1 e1) {
   // Handle ExceptionType1
} catch (ExceptionType2 e2) {
   // Handle ExceptionType2
} catch (ExceptionType3 e3) {
   // Handle ExceptionType3
}

Important Points

  • Only one exception is caught and handled at a time.
  • Catch blocks must be ordered from most specific exception type to most general to avoid compile-time errors.

Example 1: Multiple Catch Blocks

package com.tutorialspoint;

public class ExcepTest {
   public static void main(String args[]) {
      try {
         int a[] = new int[2];
         int b = 0;
         int c = 1 / b; // ArithmeticException here
         System.out.println("Access element three :" + a[3]);
      }
      catch (ArrayIndexOutOfBoundsException e) {
         System.out.println("ArrayIndexOutOfBoundsException thrown  :" + e);
      }
      catch (Exception e) {
         System.out.println("Exception thrown  :" + e);
      }
      System.out.println("Out of the block");
   }
}

Output:

Exception thrown :java.lang.ArithmeticException: / by zero
Out of the block

Example 2: Ordered Multiple Catch Blocks

package com.tutorialspoint;

public class ExcepTest {
   public static void main(String args[]) {
      try {
         int a[] = new int[2];
         int b = 0;
         int c = 1 / b; // ArithmeticException
         System.out.println("Access element three :" + a[3]);
      }
      catch (ArithmeticException e) {
         System.out.println("ArithmeticException thrown  :" + e);
      }
      catch (ArrayIndexOutOfBoundsException e) {
         System.out.println("ArrayIndexOutOfBoundsException thrown  :" + e);
      }
      catch (Exception e) {
         System.out.println("Exception thrown  :" + e);
      }
      System.out.println("Out of the block");
   }
}

Output:

ArithmeticException thrown :java.lang.ArithmeticException: / by zero
Out of the block

Example 3: Multi-catch Block (Java 7+)

Catch multiple exception types in a single block using pipe |:

package com.tutorialspoint;

public class ExcepTest {
   public static void main(String args[]) {
      try {
         int a[] = new int[2];
         int b = 0;
         int c = 1 / b;
         System.out.println("Access element three :" + a[3]);
      }
      catch (ArrayIndexOutOfBoundsException | ArithmeticException e) {
         System.out.println("Exception thrown  :" + e);
      }
      System.out.println("Out of the block");
   }
}

Output:

Exception thrown :java.lang.ArithmeticException: / by zero
Out of the block

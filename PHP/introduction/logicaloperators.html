PHP Logical Operators Examples

**Logical Operators** in PHP are used to combine conditional statements (Boolean expressions) to create more complex conditions. They are crucial for controlling the flow of execution in constructs like `if`, `while`, and `for` statements.

PHP Logical Operators

Operator Name Description
&& Logical AND Returns `true` if **both** operands are true.
and Logical AND (Low Precedence) Returns `true` if **both** operands are true.
|| Logical OR Returns `true` if **at least one** operand is true.
or Logical OR (Low Precedence) Returns `true` if **at least one** operand is true.
! Logical NOT Reverses the logical state; `true` becomes `false` and vice versa.

Key Concepts and Examples

Truthiness and Falsiness in PHP

When non-Boolean values are used with logical operators, PHP evaluates their **truthiness**.

  • **Falsey values** include: the integer `0`, the float `0.0`, the empty string `""`, `NULL`, and the empty array `[]`.
  • **Truthy values** include: all non-zero numbers (even negative ones) and non-empty strings.
$a = 42; // True
$b = 0; // False
if ($a && $b) { /* ... */ } else { echo "False"; } $\rightarrow$ False

Operator Precedence: `&&`/`||` vs. `and`/`or`

While `&&` and `and` perform the same logical operation, they have different levels of **precedence**, which affects complex expressions (e.g., when combined with assignment operators).

  • **High Precedence:** `&&` and `||` bind more tightly to their operands.
  • **Low Precedence:** `and` and `or` have lower precedence.

In a simple conditional statement like `if ($x > 5 and $y < 10)`, the result is the same as `&&` because the comparison operators (`>` and `<`) have even higher precedence, so they are evaluated first.

Using Logical NOT (`!`)

The Logical NOT operator is used to negate a condition.

$isMember = true;
if (! $isMember) { echo "Not a member"; } $\rightarrow$ (No output, as condition is false)

Complex Conditions in Control Flow

Logical operators are commonly used in loops to define multiple exit conditions.

The loop condition `while ($count <= 5 && $count != 3)` ensures the loop runs only if **both** conditions are met: the count is less than or equal to 5 AND the count is not 3.

Output: Current count: 1, Current count: 2 (Stops at 3 because `3 != 3` is false)

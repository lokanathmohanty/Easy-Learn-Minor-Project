C++ Data Types: Primitive, Derived, and User-Defined

Variables in C++ reserve memory locations to store values. The **data type** of a variable dictates the memory allocated and the range of values it can store.

Primitive Built-in Types ⚙️

These are the fundamental data types. Their size can vary depending on the compiler and machine.

Basic Types:

  • bool (Boolean)
  • char, wchar_t (Character/Wide character)
  • int (Integer)
  • float, double, long double (Floating point)
  • void (Valueless)

Type Modifiers:

These keywords modify the properties and size of basic types:

  • signed, unsigned (For integer/char types, specifying if negative values are allowed)
  • short, long (To define shorter or longer versions of integer types)

Checking Data Type Sizes

The sizeof() operator is used to determine the size of a data type or variable in bytes on a specific system.

#include <iostream>
using namespace std;

int main() {
   cout << "Size of int : " << sizeof(int) << " bytes" << endl;
   cout << "Size of double : " << sizeof(double) << " bytes" << endl;
   return 0;
}

Derived Data Types 🧱

These types are constructed or obtained from the primitive built-in types:

  • Function: A named, reusable block of code with a specified return_type and input parameters.
  • Array: A series of elements of the **same data type** stored in contiguous memory locations.
  • Pointer: A variable that holds the **memory address** of another variable (e.g., int *p = &a;).
  • Reference: An **alias** or another name for an existing variable, sharing the same memory location (e.g., int& refer = c;).

User-Defined Data Types 🧑‍💻

These types are defined by the user to represent custom structures and entities:

  • Class: A blueprint for creating **objects** in OOP, encapsulating data (attributes) and functions (methods).
  • Structure (struct): A collection of related variables (of potentially different types) grouped under a single name.
  • Union: Similar to a struct, but all members **share the same memory location**. Changing one member's value changes the others.
  • Enumeration (enum): A type that assigns names (identifiers) to **integer constants**, improving code readability. By default, names start at 0 and increment by 1, but values can be explicitly set.

Typedef Declarations

The typedef keyword creates a **new alias (name)** for an existing data type, making complex declarations simpler to read and use.

Syntax: typedef existing_type new_name;

Example: typedef int feet; allows you to use feet distance; instead of int distance;.

Power BI - Stacked Bar Chart

What is a Stacked Bar Chart?

A stacked bar chart displays data as horizontal stacked rectangles without overlaps. It shows how individual parts contribute to the whole for each category.

Creating a Stacked Bar Chart - Case Study

Using the dataset “sl.xlsx” containing sales production data by year and country, Richard creates stacked bar charts for:

  • Sales in 2023 by country
  • Sales in 2020 and 2021 by country (stacked)

Steps to Create the Chart

  1. Open Report View and select the stacked bar chart visual.
  2. Add "Country" to the Y-axis and "Sales production 2023" to the X-axis to see sales sums for 2023 by country.
  3. Add "Sales production 2020" and "Sales production 2021" to the X-axis to create a multi-segment stacked bar chart.
  4. Add "Country" to the Legend bucket to enable color classification by country.
  5. Use Small Multiples to partition by year or another attribute.

Interacting with the Chart

Hovering over segments shows detailed data. Adding fields to the Tooltips section reveals extra contextual information natively.

Advanced Features

Use the Drill-through feature to filter specific categories, e.g., viewing sales only for Argentina.

Formatting Options

  1. Adjust size and position under the Properties section.
  2. Toggle and customize titles, subtitles, font styles, font sizes, and colors.
  3. Set background color and effects.
  4. Configure header icons and tooltips including font and background styling.
  5. Enable gridlines, adjusting style, color, and thickness.
  6. Show data labels and total labels on bars.

These options help create an aesthetically engaging and informative stacked bar chart suited for effective storytelling.

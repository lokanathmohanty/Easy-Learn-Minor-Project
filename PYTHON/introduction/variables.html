Python - Variables

Introduction

Python variables are reserved memory locations used to store values within a program. When you create a variable, memory is reserved for it. The type of data stored determines the amount of memory allocated.

Memory Addresses

All data in Python is stored in memory locations represented internally in binary form. Python’s id() function returns the address where the object is stored.

>>> "May"
'May'
>>> id("May")
2167264641264

>>> 18
18
>>> id(18)
140714055169352

Variables act as labels (identifiers) to refer to these memory locations using the assignment operator =.

>>> month = "May"
>>> age = 18

Creating Variables

Variables in Python are created automatically when a value is assigned:

counter = 100        # integer
miles   = 1000.0     # float
name    = "Zara Ali" # string

Printing Variables

Use print() to display variable values:

counter = 100
miles   = 1000.0
name    = "Zara Ali"

print(counter)
print(miles)
print(name)
# Output:
# 100
# 1000.0
# Zara Ali

Deleting Variables

Use del to delete a variable:

counter = 100
print(counter)

del counter
print(counter)  # NameError: counter is not defined

Getting Type of Variables

Use type() to find a variable’s data type:

x = "Zara"
y = 10
z = 10.10

print(type(x))  # str
print(type(y))  # int
print(type(z))  # float

Casting Variables

You can explicitly specify the type with casting:

x = str(10)   # '10'
y = int(10)   # 10
z = float(10) # 10.0

Case Sensitivity

Variable names are case sensitive:

age = 20
Age = 30
print(age) # 20
print(Age) # 30

Multiple Assignment

Assign the same or different values to multiple variables:

a = b = c = 100
print(a, b, c)  # 100 100 100

a, b, c = 1, 2, "Zara Ali"
print(a, b, c)  # 1 2 Zara Ali

Naming Conventions

Rules for variable names:

  • Must start with a letter or underscore (_).
  • Cannot start with a number or special character.
  • Can contain letters, digits, and underscores.
  • Case-sensitive (Name ≠ NAME).
  • Cannot use reserved keywords.

Naming styles:

  • Camel Case: pricePerLitre
  • Pascal Case: PricePerLitre
  • Snake Case: price_per_litre

Examples

Valid Variable Names

counter = 100
_count = 100
name1 = "Zara"
zara_salary = 100000

Invalid Variable Names

1counter = 100     # Invalid
$_count = 100      # Invalid
zara-salary = 1000 # Invalid

Using Variables in Programs

width = 10
height = 20
area = width * height
perimeter = 2 * (width + height)

print("Area =", area)
print("Perimeter =", perimeter)
# Output:
# Area = 200
# Perimeter = 60

Local Variables

Defined inside a function and only accessible there:

def sum(x, y):
    total = x + y
    return total

print(sum(5, 10))  # 15

Global Variables

Defined outside a function and accessible everywhere:

x = 5
y = 10

def sum():
    return x + y

print(sum())  # 15

Constants

Python doesn’t have true constants but by convention we use ALL_CAPS names:

PI_VALUE = 3.14159
MAX_USERS = 100

Variables in Python vs C/C++

In C/C++, variables are memory locations. In Python, variables are references (labels) to objects in memory. Multiple variables can point to the same object. When an object is no longer referenced, Python’s garbage collector releases the memory.

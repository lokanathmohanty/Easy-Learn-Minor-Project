Visualization is an effective technique where users can showcase their data in a presentation format. Power BI provides built-in visuals like clustered charts, line charts, heat maps, funnel charts, pie charts, and more. These visuals help segregate data based on accuracy, allowing quicker identification of meaningful insights and reducing manual processing.

Clustered Bar Chart

This chart contains horizontal bars. The Y-axis shows categorical variables, and the X-axis shows summarized values. It is ideal for visualizing large datasets with long labels.

Steps to Create a Clustered Bar Chart for Gender Distribution

  1. Open Power BI Desktop and load the dataset from D:\Employee.xlsx which includes columns: Age, Designation, Employee ID, Gender, Name, and Salary.
  2. In the Report Editor, click on the Clustered Bar Chart visual.
  3. Add the Name column to the Y-axis, Salary to the X-axis, and Gender to the Legend.
  4. Replace the X-axis by dragging the Age column into the X-axis field. The chart now shows the sum of Age by Name and Gender.
  5. To count Male and Female employees, drag the Gender column to the Drill through section.
  6. Click the "F" checkbox to filter and display only Female employees.
  7. Click the "M" checkbox to display only Male employees in the visual.

Clustered Column Chart

This chart shows data as vertical bars. The X-axis represents categories, while the Y-axis shows aggregated values like Sum or Count.

Determining Company Sales Profit Using a Clustered Column Chart

  1. Select the Clustered Column Chart icon. A default chart appears on the canvas.
  2. Add the Company field to the X-axis and Yearly Sales Profit to the Y-axis.
  3. To color-code bars by a field, add Quantity to the Legend. Bars will now display in different colors.
  4. Add the Cost field to the Small multiples section to create separate visuals for each cost category.
  5. Include the Cost field in the Tooltips to show cost details when hovering over bars.
  6. Use the Drill through option to filter data. For example, drag the Company field into Drill through, select a value like "Sony," and view only that company's data.
  7. Customize the report background by selecting Format your report page and changing the color under the Color section.

This technique is simple yet effective for beginners. Make sure your dataset includes the essential fields like Gender, Name, and Salary in the employee table. Other columns are optional.

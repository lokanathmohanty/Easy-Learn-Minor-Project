JavaScript - typeof Operator

The typeof Operator

The typeof operator in JavaScript is a unary operator used to get the data type of a particular variable. It returns a string value indicating the data type of its operand. JavaScript contains primitive and non-primitive data types.

There are seven primitive data types in JavaScript: number, string, boolean, undefined, null, symbol, and bigint. There is also a composite data type called object, which includes objects, arrays, and dates.

Syntax

typeof (operand);
typeof operand;

Parameter

operand − It can be a value, variable, or expression representing the object or primitive.

Return Value

It returns a string value representing the data type of the operand.

Datatypes Returned by typeof Operator

  • Number → "number"
  • String → "string"
  • Boolean → "boolean"
  • Object → "object"
  • Function → "function"
  • Undefined → "undefined"
  • Null → "object"
  • Symbol → "symbol"
  • Bigint → "bigint"

Examples

Checking Number Type

typeof 10; // "number"
typeof -10; // "number"
typeof 0; // "number"
typeof 10.20; // "number"
typeof Infinity; // "number"
typeof NaN; // "number"

Example:

<script>
  let num = 42;
  document.getElementById("output").innerHTML = typeof num;
</script>

Checking String Type

typeof "Hello"; // "string"
typeof ""; // "string"
typeof String(10); // "string"

Checking Boolean Type

typeof true; // "boolean"
typeof false; // "boolean"

Checking Symbol Type

typeof Symbol(); // "symbol"
typeof Symbol("id"); // "symbol"

Checking Undefined and Null

typeof undefined; // "undefined"
typeof null; // "object"

Checking Object Type

typeof {age: 23}; // "object"
typeof [1,2,3]; // "object"
typeof new Date(); // "object"

Checking Function Type

const myFunc = function(){};
typeof myFunc; // "function"

class MyClass {}
typeof MyClass; // "function"

Checking BigInt Type

typeof 100n; // "bigint"

Real-Time Example

Developers often use typeof to check API responses. For example, if an API sometimes returns a single string and other times an array of strings, typeof helps handle both cases. 

<script>
  const response = ["Hello", "World"];

  if (typeof response === "string") {
    document.write("Response: " + response);
  } else {
    document.write("Response values: ");
    for (let val of response) {
      document.write(val + " ");
    }
  }
</script>

Arrays and typeof Operator

Arrays return "object" when using typeof. To check if a value is an array, use Array.isArray(). 

let numbers = [1, 2, 3];
Array.isArray(numbers); // true

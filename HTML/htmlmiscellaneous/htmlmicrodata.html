HTML - Microdata

Introduction

Microdata is a standardized way to provide additional semantics in web pages. It lets us define custom elements and embed custom properties. A microdata structure consists of groups of name-value pairs.

These groups are called items, and each name-value pair is a property. Both items and properties are represented by normal HTML elements.

Using Microdata in HTML Documents

To create an item, the itemscope attribute is used. To add a property, the itemprop attribute is used on one of the item's descendants.

Example

<div itemscope>
  <p>My name is <span itemprop="name">Zara</span>.</p>
</div>

<div itemscope>
  <p>My name is <span itemprop="name">Nuha</span>.</p>
</div>

Global Attributes in Microdata

Attribute Description
itemscope Creates an item. Boolean attribute that marks the start of microdata.
itemtype A valid URL that defines the item and provides context for its properties.
itemid A global identifier for the item.
itemprop Defines a property of the item.
itemref Lists additional elements to crawl for name-value pairs of the item.

Properties Datatypes

Properties generally have string values, but they can also represent URLs, dates, times, or even nested groups of properties.

Example: Image as a URL

<div itemscope>
  <img itemprop="image" src="tp-logo.gif" alt="TutorialsPoint">
</div>

Example: Date Property

<div itemscope>
  My birthday is −
  <time itemprop="birthday" datetime="1971-05-08">
    Aug 5th 1971
  </time>
</div>

Microdata API Support

If a browser supports the HTML5 Microdata API, it exposes a getItems() function on the document object. If not, the function will be undefined.

function supports_microdata_api() {
  return !!document.getItems;
}

The HTML5 microdata standard includes both markup (for search engines) and DOM functions (for browsers). Search engines that don’t support microdata simply ignore the attributes.

Defining Microdata Vocabulary

To define a microdata vocabulary, you need a namespace URL that points to a working web page. For example, http://data-vocabulary.org/Person can be used as the namespace for a personal microdata vocabulary with the following properties:

  • name – Person’s name as text.
  • photo – A URL to a person’s photo.
  • url – A website belonging to the person.

Example: Person Microdata

<div itemscope>
  <section itemscope itemtype="http://data-vocabulary.org/Person">
    <h1 itemprop="name">Gopal K Varma</h1>
    <p>
      <img itemprop="photo" src="http://www.tutorialspoint.com/green/images/logo.png">
    </p>
    <a itemprop="url" href="#">Site</a>
  </section>
</div>

Google and Microdata

Google supports microdata as part of its Rich Snippets program. When Google’s crawler detects valid microdata, it extracts and stores the structured properties alongside the rest of the page data.

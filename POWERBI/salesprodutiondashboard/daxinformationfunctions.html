Power BI: DAX Information Functions

DAX Information functions provide valuable feedback about the data type, presence, and state of values within your model. These functions help inspect data, handle exceptions, and conditionally respond to data characteristics to improve report reliability and interactivity.

Key DAX Information Functions with Examples

  • CONTAINS(): Returns TRUE if specified values exist in a table/column; otherwise FALSE. Example: ln = CONTAINS(Sheet1, Sheet1[CS Ticket], 13, Sheet1[CSAT], 0.11)
  • CONTAINSSTRING(): Returns TRUE if one string contains another (case-insensitive). Example: stg = CONTAINSSTRING("sunpharmacompany", "sun")
  • CONTAINSSTRINGEXACT(): Case-sensitive version of CONTAINSSTRING. Example: ck = CONTAINSSTRINGEXACT(Sheet1[Data Resources], "Hotels")
  • ISBLANK(): Returns TRUE if value is blank; otherwise FALSE. Example: bln = ISBLANK(Sheet1[Active/Inactive customers])
  • ISEVEN(): Returns TRUE if number is even. Example: az = ISEVEN(222)
  • ISODD(): Returns TRUE if number is odd. Example: ds = ISODD(33333)
  • ISNUMBER(): Returns TRUE if value is a number; otherwise FALSE. Example: IS_NUMBER = ISNUMBER(Sheet1[CSAT])
  • ISTEXT(): Returns TRUE if value is text; otherwise FALSE. Example: tx = ISTEXT(Sheet1[Customer_id])
  • ISNONTEXT(): Returns TRUE if value is not text; otherwise FALSE. Example: non_tx = ISNONTEXT(Sheet1[Resources popularity])
  • ISERROR(): Returns TRUE if expression results in error; otherwise FALSE. Example: stg = ISERROR(1 / 0)

Additional Information Functions

  • HASONEFILTER(): Checks if a single filter is applied on a column.
  • HASONEVALUE(): Checks if exactly one value is filtered or selected in a column.
  • ISSUBTOTAL(): Determines if a value is part of a subtotal.
  • NONVISUAL(): Identifies fields that appear as non-visual in summaries.
  • SELECTEDMEASURE(): References the current measure in expressions, useful for dynamic calculations.

Usage Overview

Information functions facilitate data validation, error handling, and conditional logic critical to complex data models. They enhance report robustness and enable intelligent user interactions in Power BI.

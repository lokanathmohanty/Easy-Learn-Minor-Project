ReactJS - Nested Components

A nested component in React is a component placed inside another component. This is not done through inheritance, but through composition. React components can be combined and nested to create larger, more structured components.

Proper nesting makes code more efficient and organized. However, if not done carefully, it may increase complexity and reduce efficiency.

FormattedMoney Component

The FormattedMoney component formats a number into two decimal places before rendering.

  1. Create a file FormattedMoney.js in the src/components folder.
  2. Extend React.Component and add a format() method.
  3. Use this.props.value to render formatted output.

Example: FormattedMoney.js

import React from 'react';

class FormattedMoney extends React.Component {
  constructor(props) {
    super(props);
  }
  format(amount) {
    return parseFloat(amount).toFixed(2);
  }
  render() {
    return (
      <span>{this.format(this.props.value)}</span>
    );
  }
}

export default FormattedMoney;

FormattedDate Component

The FormattedDate component formats a date into a more readable string format (e.g., 10-OCT-2020).

  1. Create a file FormattedDate.js in the src/components folder.
  2. Add a format() method to convert raw date strings.
  3. Render the formatted date using this.props.value.

Example: FormattedDate.js

import React from 'react';

class FormattedDate extends React.Component {
  constructor(props) {
    super(props);
  }
  format(val) {
    const months = [
      "JAN", "FEB", "MAR", "APR", "MAY", "JUN", 
      "JUL", "AUG", "SEP", "OCT", "NOV", "DEC"
    ];
    let parsed_date = new Date(Date.parse(val));
    let formatted_date =
      parsed_date.getDate() + "-" +
      months[parsed_date.getMonth()] + "-" +
      parsed_date.getFullYear();
    return formatted_date;
  }
  render() {
    return (
      <span>{this.format(this.props.value)}</span>
    );
  }
}

export default FormattedDate;

Python - Inner Classes

A class defined inside another class is known as an inner class in Python. Sometimes inner class is also called a nested class. If the inner class is instantiated, the object of the inner class can also be used by the parent class. Objects of an inner class automatically inherit attributes of the outer class.

Syntax

class outer:
   def __init__(self):
      pass
   class inner:
      def __init__(self):
         pass

An inner class lets you group related classes. One of the advantages of nesting classes is that it becomes easy to understand dependencies. The inner class has local scope and acts as one of the attributes of the outer class.

Example

class student:
   def __init__(self):
      self.name = "Ashish"
      self.subs = self.subjects()
   
   def show(self):
      print("Name:", self.name)
      self.subs.display()

   class subjects:
      def __init__(self):
         self.sub1 = "Phy"
         self.sub2 = "Che"
      
      def display(self):
         print("Subjects:", self.sub1, self.sub2)

s1 = student()
s1.show()

Output:

Name: Ashish
Subjects: Phy Che

It is possible to declare an object of the outer class independently and call its inner display method: 

sub = student().subjects().display()

Types of Inner Class

In Python, inner classes are mainly of two types:

  • Multiple Inner Class
  • Multilevel Inner Class

Multiple Inner Class

A single outer class can contain more than one inner class. Each functions independently but can interact with outer members. 

class Organization:
   def __init__(self):
      self.inner1 = self.Department1()
      self.inner2 = self.Department2()
        
   def showName(self):
      print("Organization Name: Tutorials Point")

   class Department1:
      def displayDepartment1(self):
         print("In Department 1")
            
   class Department2:
      def displayDepartment2(self):
         print("In Department 2")

outer = Organization() 
outer.showName()  
inner1 = outer.inner1 
inner1.displayDepartment1() 
inner2 = outer.inner2 
inner2.displayDepartment2()

Output:

Organization Name: Tutorials Point
In Department 1
In Department 2

Multilevel Inner Class

An inner class can itself contain another inner class, creating multiple levels of nesting. 

class Organization:
   def __init__(self):
      self.inner = self.Department()

   def showName(self):
      print("Organization Name: Tutorials Point")

   class Department:
      def __init__(self):
         self.innerTeam = self.Team1()

      def displayDep(self):
         print("In Department")

      class Team1:
         def displayTeam(self):
            print("Team 1 of the department")

outer = Organization()  
outer.showName()  
inner = outer.inner  
inner.displayDep()  
innerTeam = inner.innerTeam  
innerTeam.displayTeam()

Output:

Organization Name: Tutorials Point
In Department
Team 1 of the department

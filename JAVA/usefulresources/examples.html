Comprehensive Java Programming Examples Reference ☕💡

This is a categorized list of practical and ready-to-use Java programming examples that are highly beneficial for projects, learning, and reference. The examples cover core Java concepts, essential utility classes, advanced data structures, and integration with popular third-party libraries.

Core Java Environment & Compilation

These examples focus on working with the Java Development Kit (JDK) and the command line.

  • **How to compile a Java file?** (e.g., javac MyFile.java)
  • **How to run a class file?** (e.g., java MyClass)
  • **How to set classpath?** (Using -classpath or -cp flag)
  • **How to check version of Java running on your system?** (e.g., java -version)
  • **How to set classpath when class files are in .jar file?** (e.g., java -cp mylib.jar MyMainClass)

Strings Examples 💬

Fundamental examples for manipulating the immutable String class and its mutable counterparts, StringBuilder/StringBuffer.

  • **How to compare strings?** (Using .equals() vs. ==, and .compareTo())
  • **How to reverse a String?** (Using StringBuilder.reverse())
  • **How to remove a particular character from a string?** (Using .replace() or regular expressions)
  • **How to split a string into a number of substrings?** (Using .split(regex))
  • **How to concatenate two strings?** (Using + operator or .concat())
  • **How to buffer strings?** (Using StringBuffer for thread safety or StringBuilder for performance)
  • **How to format strings?** (Using String.format())

Arrays Examples 🗃️

Common tasks involving fixed-size arrays, often utilizing the java.util.Arrays utility class.

  • **How to sort an array and search an element inside it?** (Arrays.sort() and Arrays.binarySearch())
  • **How to reverse an array?** (Manual iteration or using Collections.reverse() on an array converted to a List)
  • **How to find the minimum and the maximum element in an array?** (Iterating through the array or using Collections.min/max)
  • **How to merge two arrays?** (Using System.arraycopy() or Arrays.copyOf()/stream.concat())
  • **How to check if two arrays are equal or not?** (Using Arrays.equals())

Date & Time Examples 📅🕰️

Examples primarily using the modern **java.time** package (since Java 8) for robust time handling and formatting.

  • **How to display current date and time?** (Using LocalDateTime.now() or ZonedDateTime.now())
  • **How to display time in different country's format?** (Using ZonedDateTime and ZoneId)
  • **How to format time in AM-PM format?** (Using DateTimeFormatter with pattern 'hh:mm:ss a')
  • **How to display name of a month in (MMM) format?** (Using Month.getDisplayName() or DateTimeFormatter with 'MMM')
  • **How to display date in different formats?** (Creating custom DateTimeFormatter instances)

Files and Directories Examples 📁

Essential file I/O operations using the modern java.nio.file package (NIO.2) and traditional java.io classes.

  • **How to create a new file?** (Files.createFile())
  • **How to read a file?** (Using Files.readAllLines() or BufferedReader)
  • **How to write to a file?** (Using Files.write() or FileWriter)
  • **How to delete a file or directory?** (Files.delete())
  • **How to copy one file into another file?** (Files.copy())
  • **How to search all files inside a directory?** (Using Files.walk() or Files.find())
  • **How to get the size of a directory?** (Recursively summing file sizes using Files.walk())

Methods and Control Flow Examples ⚙️

Examples covering method features, recursion, and advanced control flow.

  • **How to overload methods?** (Defining methods with the same name but different parameters)
  • **How to use method for calculating Factorial of a number?** (A classic recursive example)
  • **How to use method overloading for printing different types of array?** (Creating multiple printArray() methods)
  • **How to use method overriding in Inheritance for subclasses?** (Demonstrating polymorphism)
  • **How to make a method take variable length argument as an input?** (Using **varargs** notation: (Type... args))

Exceptions and Error Handling Examples ⚠️

Focus on structured error management using try-catch-finally blocks and custom exceptions.

  • **How to use finally block for catching exceptions?** (Ensuring cleanup code executes regardless of exception)
  • **How to use catch to handle chained exception?** (Using getCause())
  • **How to handle multiple exceptions (divide by zero / Array out of bound)?** (Using multiple catch blocks or the multi-catch feature: catch (ExceptionA | ExceptionB e))
  • **How to create user defined Exception?** (Extending Exception or RuntimeException)

Data Structures and Collections Examples 🧠

Using the **Java Collections Framework** for dynamic data management.

  • **How to implement Queue/Stack?** (Using LinkedList or ArrayDeque for Queue; Stack or ArrayDeque for Stack)
  • **How to get the first and the last element of a linked list?** (Using LinkedList.getFirst()/getLast() or peekFirst()/peekLast())
  • **How to convert an array into a collection?** (Using Arrays.asList())
  • **How to iterate through elements of HashMap?** (Using entrySet(), keySet(), or values() views)
  • **How to find min & max of a List?** (Using Collections.min() and Collections.max())
  • **How to shuffle the elements of a collection?** (Using Collections.shuffle())

Networking and Threading Examples 🌐🔗

Examples for concurrent programming and network communication.

  • **How to determine IP Address & hostname of Local Computer?** (Using InetAddress.getLocalHost())
  • **How to read and download a webpage?** (Using URL.openStream() or modern HTTP Client)
  • **How to create a multithreaded server?** (Using Sockets with a **Thread Pool Executor**)
  • **How to solve the producer consumer problem using thread?** (Classic concurrency problem using wait() and notifyAll() or **BlockingQueue**)
  • **How to check a thread is alive or not?** (Using Thread.isAlive())
  • **How to suspend a thread for a while?** (Using Thread.sleep())

GUI and JDBC Examples (Application Layer) 🖼️📊

Examples of user interface creation and database connectivity.

  • **How to display a message in a new frame?** (Simple Swing/JavaFX application structure)
  • **How to draw a polygon using GUI?** (Using the Graphics2D class)
  • **How to establishing a connection with Database?** (JDBC **Driver Manager** and **Connection** object)
  • **How to Create, edit & alter table using Java?** (Executing DDL statements via Statement object)
  • **How to use prepared statement in Java?** (Using PreparedStatement for security and performance)

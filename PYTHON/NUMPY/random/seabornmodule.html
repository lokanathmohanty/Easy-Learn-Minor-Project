Seaborn

Visualize Distributions With Seaborn

Seaborn is a library that uses Matplotlib underneath to plot graphs. It is commonly used to visualize random distributions.

Install Seaborn

If you have Python and PIP installed, install Seaborn using this command:

C:\Users\Your Name>pip install seaborn

If you use Jupyter Notebook, install Seaborn using this command:

C:\Users\Your Name>!pip install seaborn

Displots

Displot stands for distribution plot. It takes as input an array and plots a curve corresponding to the distribution of points in the array.

Import Matplotlib

Import the pyplot object of the Matplotlib module using the following statement:

import matplotlib.pyplot as plt

You can learn more about Matplotlib in the Matplotlib tutorial.

Import Seaborn

Import the Seaborn module using the following statement:

import seaborn as sns

Plotting a Displot

import matplotlib.pyplot as plt
import seaborn as sns

sns.displot([0, 1, 2, 3, 4, 5])

plt.show()

Plotting a Displot Without the Histogram

import matplotlib.pyplot as plt
import seaborn as sns

sns.displot([0, 1, 2, 3, 4, 5], kind="kde")

plt.show()

Note: We will be using sns.displot(arr, kind="kde") to visualize random distributions in this tutorial.

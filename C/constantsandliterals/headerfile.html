Header Files in C

The #include preprocessor directive is used to make the definitions of functions, constants and macros etc. from one file, usually called a header file, available for use in another C code. A header file has ".h" extension from which you can include the forward declarations of one or more predefined functions, constants, macros etc. The provision of header files in C facilitates a modular design of the program.

System Header Files

The C compiler software is bundled with many pre-compiled header files called system header files. A well-known example is stdio.h, included in almost every C program.

These header files contain utility functions often called library functions, like printf() and scanf() for IO operations.

The preprocessor statements that load one or more header files are always at the beginning of the C code.

Syntax to Include Header Files in C

A header file is loaded with the #include directive, using either:

  • #include <filename.h> for system/default directory header files.
  • #include "filename.h" for user-defined or non-standard header files in the same directory as the source file.

Standard Header Files in C

A typical C compiler includes several pre-compiled header files with predefined standard library functions.

User-defined Header Files

Functions/macros/variables of similar nature can be grouped into user-defined header files and included like standard headers. These files are usually in the same directory as the source code.

Header guards prevent multiple inclusions of the same file, avoiding compilation errors.

Computed Includes

Sometimes conditional inclusion of header files is necessary depending on the system or configuration, achieved with conditional directives or macros for header names.

Example: Using Standard Header Files


#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <math.h>

int main() {
   char s1[20] = "53875";
   char s2[10] = "Hello";
   char s3[10] = "World";

   int res;
   res = pow(8, 4);
   printf("Using math.h, The value is : %d\n", res);

   long int a = atol(s1);
   printf("Using stdlib.h, the string to long int: %d\n", a);

   strcpy(s2, s3);
   printf("Using string.h, the strings s2 and s3: %s\t%s\n", s2, s3);

   return 0;
}

Example: User-defined Header File


// myheader.h
#ifndef MYHEADER_H
#define MYHEADER_H

void sayHello();
int add(int a, int b);
double area(double radius);
int length(char *x);

#endif

      

// myheader.c
#include <stdio.h>
#include <string.h>
#include <math.h>

#define PI 3.142

void sayHello(){
   printf("Hello World\n");
}

int add(int a, int b){
   return a + b;
}

double area(double radius){
   return PI * pow(radius, 2);
}

int length(char *x){
   return strlen(x);
}

      

// main.c
#include <stdio.h>
#include "myheader.h"

int main() {
   int p = 10, q = 20;
   double x = 5.25;

   sayHello();
   printf("sum of %d and %d is %d\n", p, q, add(p,q));
   printf("Radius: %lf Area: %lf", x, area(x));

   return 0;
}

PHP Arrays

An **array** in PHP is an ordered map that stores multiple data values, often related, in a single variable. Arrays are highly flexible in PHP because they can associate **values** with **keys**, where keys can be either integers or strings.

PHP arrays can implement various data structures like lists, hash tables, dictionaries, and stacks.

Array Declaration and Syntax

There are two primary ways to define an array in PHP:

1. Using the `array()` function (Legacy)

The built-in function takes comma-separated elements as arguments.

$arr1 = array(10, "string", 1.55, true);
$arr2 = array("key" => "value", "apple" => 1);

2. Using Square Brackets `[]` (Short Syntax - Recommended)

This is the preferred, concise syntax for declaring an array, similar to JavaScript or Python.

$arr1 = [10, "string", 1.55, true];
$arr2 = ["key" => "value", "apple" => 1];

Types of Arrays in PHP

PHP uses the same internal structure (an ordered map) for all arrays, but they are categorized based on how keys are assigned and accessed:

1. Indexed Array

A collection of values where each element is accessed using a numerical, zero-based index. When keys aren't explicitly specified, PHP assigns them automatically starting from 0.

$fruits = ["Apple", "Banana", "Orange"];
Access: $fruits[0] $\rightarrow$ "Apple"

2. Associative Array

A collection of **key-value pairs**, where the keys are explicitly defined, usually as strings. This acts as a dictionary or hash map. The key is associated with its value using the **`=>`** symbol.

$marks = ["Ankit" => 85, "Eisha" => 90];
Access: $marks["Eisha"] $\rightarrow$ 90

3. Multi-Dimensional Array

An array where one or more of its elements are themselves arrays. This allows for storing complex, structured data like tables or matrices.

$students = [
   ["Ankit", 85, "A"], // Row 0 (Indexed Sub-array)
   ["Eisha", 90, "A+"] // Row 1
];
Access: $students[0][1] $\rightarrow$ 85

Accessing Array Elements

Elements are retrieved using the bracket syntax `array[key]`, regardless of whether the key is a number or a string.

$arr1 = [10, 20]; $\rightarrow$ `var_dump($arr1[1])` is `int(20)`

$arr2 = ["two"=>2]; $\rightarrow$ `var_dump($arr2["two"])` is `int(2)`

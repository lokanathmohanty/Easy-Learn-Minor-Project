JavaScript - Array

The JavaScript Array object lets you store multiple values in a single variable. Arrays are dynamic, so their size can increase or decrease after creation.

Syntax

const arr = new Array(val1, val2, val3, ..., valN)

Parameters: Takes multiple values as arguments to initialize an array.

Return value: Returns an array object.

Note: If you pass a single numeric value, it creates an array with that length filled with undefined.

Array Literals

const fruits = ["apple", "orange", "mango"];

Array elements are accessed by index:

  • fruits[0] → first element
  • fruits[1] → second element
  • fruits[2] → third element

Array Properties

  • constructor - Reference to the array function that created the object.
  • length - Number of elements in the array.

Array Methods

Static Methods

  • from() - Creates a shallow copy of the array.
  • isArray() - Checks if a value is an array.
  • of() - Creates an array from arguments.

Instance Methods

  • at() - Get element at a specific index.
  • concat() - Joins arrays/values.
  • filter() - Creates a new array with elements passing a condition.
  • find() - Finds the first matching element.
  • map() - Creates a new array with results of a function.
  • push() - Adds elements to the end.
  • pop() - Removes last element.
  • shift() - Removes first element.
  • unshift() - Adds elements to the front.
  • slice() - Extracts part of an array.
  • splice() - Adds/removes elements.
  • sort() - Sorts array elements.
  • reduce() - Reduces array to a single value.

Examples

Creating an Array using Constructor

let strs = new Array("Hello", "World!", "Tutorials Point");
let cars = new Array(20);

strs ⇒ Hello,World!,Tutorials Point

cars ⇒ ,,,,,,,,,,,,,,,,,,,

Creating Arrays using Literals

const arr1 = [10, 40, 50, 60, 80, 90];
const arr2 = ["Hello", "Hi", "How", "are", "you?"];
const arr3 = [true, false, true, true];

arr1 ⇒ 10,40,50,60,80,90

arr2 ⇒ Hello,Hi,How,are,you?

arr3 ⇒ true,false,true,true

Accessing Array Elements

const nums = [1, 5, 6, 8, 90];
nums[0] // 1
nums[2] // 6

Element at 0th index: 1

Element at 2nd index: 6

Array Length

const nums = [1, 5, 6, 8, 90];
nums.length; // 5

Array length is: 5

Adding Elements

nums.push(6);
nums[nums.length] = 7;

Updated array: 1,2,3,4,5,6

Updated array: 1,2,3,4,5,6,7

Updating Elements

nums[0] = 100;

Updated array: 100,2,3,4,5

Traversing an Array

for (let p = 0; p < nums.length; p++) {
  console.log(nums[p]);
}

nums[0] ⇒ 1

nums[1] ⇒ 2

nums[2] ⇒ 3

nums[3] ⇒ 4

nums[4] ⇒ 5

CSS - Colors

CSS uses color values to specify a color. These values are used to set colors for text, backgrounds, borders, and other decorative effects. Colors can be defined using different formats.

Color Formats

  • Keyword: Uses predefined color names. Example: red, blue.
  • Hexadecimal Code: Six-digit code in the format #RRGGBB. Example: #FF0000.
  • Short Hexadecimal Code: Shortened three-digit version #RGB. Example: #F00.
  • RGB: rgb(red, green, blue). Example: rgb(0,0,255).
  • RGBA: Adds alpha transparency. Example: rgba(0,0,255,0.5).
  • HSL: hsl(hue, saturation, lightness). Example: hsl(120, 100%, 50%).
  • HSLA: Same as HSL with transparency. Example: hsla(120, 100%, 50%, 0.5).
  • currentcolor: Uses the element’s current color property.
  • System color: Uses OS/browser-defined system colors.

Example: Color Keyword

<div class="example-keyword">
   This div element has a background color set by a keyword (aqua).
</div>

Example: Hexadecimal Code

<div class="example-hex">
   This div element has a background color set by hex code (#00ff00).
</div>

Example: Short Hexadecimal Code

<div class="example-shorthex">
   This div element has a background color set by short hex code (#00f).
</div>

Example: RGB

<div class="example-rgb">
   This div element has a background color set using rgb(255,0,255).
</div>

Example: RGBA

<div class="example-rgba">
   This div element has a background color set using rgba(255,0,255,0.2).
</div>

Example: HSLA

   This div element has a background color set using hsla(355,70%,50%,0.4).

Example: currentcolor Keyword

<div class="example-currentcolor">
   This div element has red text and border using currentcolor.
</div>

Related Properties

  • opacity – Sets transparency of an element.
  • color – Sets text color.
  • background-color – Sets background color.
  • border-color – Sets border color.
  • outline-color – Sets outline color.
  • box-shadow – Adds shadow around an element.
  • text-shadow – Adds shadow to text.

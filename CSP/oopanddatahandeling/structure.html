C# Structures (`struct`)

Introduction to Structures

A **structure** (`struct`) in C# is a **value type** that encapsulates related variables, which can be of various data types, into a single variable. Structures are primarily used to represent a **record** or a group of closely related simple data values, such as coordinates (X, Y) or details of an item (Title, ID).

Key Distinction (Value Type):

The crucial difference between a struct and a class is storage:

  • **Structs are Value Types:** Stored on the **Stack** (or inline within another object), making them generally faster and better for small data sets where they are frequently passed by value.
  • **Classes are Reference Types:** Stored on the **Heap**.

Defining and Instantiating a Structure

Definition Syntax:

Use the **`struct`** keyword to define a new data type.

struct Books {
   public string title;
   public string author;
   public string subject;
   public int book_id;
};

Instantiation (Creation):

Structs can be instantiated with or without the `new` operator. If `new` is not used, all fields must be manually initialized before the struct can be used.

  1. **Using `new` (Parameterized Constructor):** Initializes the struct and calls a custom or default constructor. 
    Person p1 = new Person("Sudhir Sharma", 27, "SEO01");
  2. **Without `new` (Manual Assignment):** Declares the variable, but the fields remain unassigned until explicitly set. 
    Person p1;
p1.name = "Sudhir Sharma";
p1.age = 27;

Example: Defining and Using a Simple Structure

This demonstrates declaring two variables of the `Books` struct type and manually assigning values.

struct Books {
   public string title;
   public int book_id;
} 

public class testStructure {
   public static void Main(string[] args) {
      Books Book1; // Declare struct variable
      Book1.title = "C Programming";
      Book1.book_id = 6495407;

      Console.WriteLine( "Book 1 title : {0}", Book1.title);
      Console.WriteLine("Book 1 book_id :{0}", Book1.book_id);
   }
}

Output:

Book 1 title : C Programming
Book 1 book_id : 6495407

Key Features and Differences from Classes

  • **Support for Members:** Structures can have methods, fields, indexers, properties, operator methods, constructors, and events.
  • **Constructors:** Structures can have parameterized constructors, but they **cannot** define a parameterless (default) constructor, as the compiler always provides one automatically.
  • **Immutability:** Structs can be made **immutable** by using the `readonly` keyword on their fields, which is often recommended for thread safety and predictable behavior.
  • **No Inheritance:** Structures **cannot inherit** from other structs or classes, and they cannot be used as a base for others. They **can, however, implement interfaces**.
  • **Passing:** When a struct is passed as an argument to a method, a **copy** of the data is created (pass-by-value).

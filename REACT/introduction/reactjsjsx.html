ReactJS - JSX

JSX is an extension to JavaScript that allows writing code resembling HTML. JSX is mainly used to describe how the user interface should look, but it is not a template language—it is a syntax extension to JavaScript.

JSX produces React elements that are rendered into the DOM. It compiles down to React.createElement() calls, so it can be used inside valid JavaScript code.

Using JSX in ReactJS

  • Assign to a variable
  • Assign to a variable based on a condition
  • Use as a return value of a function
  • Use as an argument of a function

Example: Assigning JSX

var greeting = <h1>Hello React!</h1>;

function Greeting() { 
  return <h1>Hello React!</h1> 
}

Why JSX?

  • Optimization during compilation makes JSX faster.
  • Combines markup and logic in a single file.
  • Most errors can be caught at compile time.
  • Simplifies template creation.
  • Prevents Cross Site Scripting (XSS) attacks.
  • Supports conditional statements, loops, and expressions.

Expressions in JSX

Expressions in JSX must be wrapped in curly braces { }. They can use variables, functions, and computations from the surrounding scope.

Example: Expression in JSX

<script type="text/babel">
  var cTime = new Date().toTimeString();
  ReactDOM.render(
    <div><p>The current time is {cTime}</p></div>, 
    document.getElementById('react-app')
  );
</script>

Functions in JSX

Example: Function Usage

<script type="text/babel">
  function getCurrentTime() {
    return new Date().toTimeString();
  }
  ReactDOM.render(
    <div>
      <p>The current time is {getCurrentTime()}</p>
    </div>, 
    document.getElementById('react-app')
  );
</script>

Attributes in JSX

JSX supports HTML-like attributes but uses camelCase names. For example:

  • className instead of class
  • htmlFor instead of for
  • tabIndex instead of tabindex
  • onClick instead of onclick

Example: Attribute in JSX

<script type="text/babel">
  function getCurrentTime() {
    return new Date().toTimeString();
  }
  var class_name = "red";
  ReactDOM.render(
    <div>
      <p>The current time is 
        <span className={class_name}>{getCurrentTime()}</span>
      </p>
    </div>, 
    document.getElementById('react-app')
  );
</script>

ReactJS - Testing

Testing ensures that the functionality in a React application works according to business logic and coding specifications. React recommends using the React Testing Library for testing components and Jest as the test runner. React Testing Library allows testing components in isolation.

Installing Testing Libraries

npm install --save @testing-library/react @testing-library/jest-dom

Create React App

Create React App comes with React Testing Library and Jest pre-configured. Running tests is as simple as:

cd /go/to/react/application
npm test

Once executed, Jest runs in watch mode and provides usage options:

No tests found related to files changed since last commit.
Press `a` to run all tests, or run Jest with `--watchAll`.

Watch Usage
   Press a to run all tests.
   Press f to run only failed tests.
   Press q to quit watch mode.
   Press p to filter by a filename regex pattern.
   Press t to filter by a test name regex pattern.
   Press Enter to trigger a test run.

Testing in a Custom Application

Let’s create a custom React application using Rollup bundler and test it with React Testing Library and Jest.

1. Setup Project

cd /go/to/react-test-app
npm install --save @testing-library/react @testing-library/jest-dom

2. Create Test File

Create HelloWorld.test.js under src/components folder.

3. Import Dependencies

import React from 'react';
import { render, screen } from '@testing-library/react';
import '@testing-library/jest-dom';
import HelloWorld from './HelloWorld';

4. Write a Test

test('test scenario 1', () => {
   render(<HelloWorld />);
   const element = screen.getByText(/Hello World/i);
   expect(element).toBeInTheDocument();
});

5. Complete Test File

import React from 'react';
import { render, screen } from '@testing-library/react';
import '@testing-library/jest-dom';
import HelloWorld from './HelloWorld';

test('test scenario 1', () => {
   render(<HelloWorld />);
   const element = screen.getByText(/Hello World/i);
   expect(element).toBeInTheDocument();
});

6. Install Jest (if not already)

npm install jest -g

7. Run Tests

jest

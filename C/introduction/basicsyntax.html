C - Basic Syntax

In C programming, the term "syntax" refers to the set of rules that define how programs must be written. A typical C program contains elements such as header files, the main function, statements, and optional comments.

Structure of a C Program

A C program typically consists of comments, preprocessor directives, global declarations, and a main function. The main function is the entry point of the program.

Example

/* Hello World Program */

#include <stdio.h>

int main() {
    printf("Hello World!");
    return 0;
}

Tokens in C

Tokens are the smallest individual units in a C program. They include:

  • Keywords
  • Identifiers
  • Constants
  • String Literals
  • Symbols

Example

printf("Hello, World!\n");

This line contains tokens such as printf, parentheses, and a string literal.

Identifiers

Identifiers are names given to variables, functions, arrays, etc. They must begin with a letter (A-Z or a-z) or an underscore (_), followed by letters, digits (0-9), or underscores.

Keywords

Keywords are reserved words that have special meaning in C. Examples include:

  • int
  • return
  • if
  • else
  • while

Semicolons

Each statement in C must end with a semicolon (;). It denotes the end of a statement.

Comments

Comments are used to describe the code and are ignored by the compiler. C supports:

  • Multi-line comments: /* comment */
  • Single-line comments (in C99 and later): // comment

Whitespace

Whitespace in C is used to separate tokens and improve readability. It includes spaces, tabs, and newlines, and is mostly ignored by the compiler.

Compound Statements

Multiple statements can be grouped using curly braces { } to form a compound statement.

Example

if (score >= 50) {
    printf("Pass");
    printf("Congratulations!");
}

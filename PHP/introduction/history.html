PHP History and Major Version Milestones

Early Development (1994-1997)

**PHP** started as a small open-source project by **Rasmus Lerdorf** in **1994**.

  • **Initial Name:** **"Personal Home Page"** (PHP), used to maintain his personal online resume and track visits.
  • **Evolution:** Lerdorf later added database support and called it **"Personal Home Page/Forms Interpreter" (PHP/FI)**, which became the first standalone scripting language version, **PHP 2.0 (1997)**, featuring form handling and database support.

Major Revisions and The Zend Engine

A significant shift occurred when **Zeev Suraski** and **Andi Gutmans** rewrote the parser in **1997**, leading to:

  • **PHP 3.0 (1998):** The name was officially changed to the **recursive acronym** **"PHP: Hypertext Preprocessor"**.
  • **PHP 4.0 (2000):** Powered by the first **Zend Engine**, an advanced two-stage parse/execute system.
  • **PHP 5.0 (2004):** Featured the **Zend Engine II**, greatly enhancing the object model, introducing the **PHP Data Objects (PDO)** extension, and adding extensive **OOP support**.

Modern PHP Performance and Features (PHP 7 & 8)

The move to PHP 7 and 8 focused heavily on performance and modern language standards.

PHP 7.0 (2015)

Utilized the **Zend Engine 3** to provide substantial **performance improvements**. Key features included:

  • **Scalar and Return Type Declarations** (e.g., `int`, `string`).
  • The **Null Coalesce Operator** (`??`).
  • The **Spaceship Operator** (`<=>`).
  • **Anonymous Classes**.

PHP 8.0 (2020) and Beyond

A major release bringing advanced performance and type system capabilities. Notable features include:

  • **Just-in-Time (JIT) Compilation:** Provides **substantial performance improvements**, particularly for mathematical and intensive operations.
  • **Match Expressions:** A more compact and expressive alternative to `switch` statements, capable of being assigned to a variable.
  • **Union Types:** Allows a variable or function to accept values from a collection of types (e.g., `int|string $data`).
  • **Named Arguments:** Arguments can be passed based on their name, improving readability and allowing argument order to be ignored.
  • **Attributes (Annotations):** A new, cleaner way to add metadata to code elements (classes, functions, etc.).
  • **WeakMap:** A data structure that does not prevent contained objects from being garbage collected if they are no longer referenced elsewhere.

Subsequent versions (PHP 8.1, 8.2, 8.3, etc.) continued to add features like **Enumerations (Enums)**, **Readonly Properties**, and **Typed Class Constants**.

Functions in C

A function in C is a block of organized, reusable code that performs a single related action. Every C program has at least one function, called main(), and can include additional user-defined or library functions.

Functions help break complex logic into smaller, independent, and reusable code blocks. This top-down approach improves code maintainability and readability.

Function Components

  • Declaration: Tells the compiler the function's name, return type, and parameters.
  • Definition: Contains the actual body of code executed.

Key Parts of a Function

  • Return Type: Data type of the value the function returns (or void if it doesn't return a value).
  • Function Name: Identifier for the function.
  • Parameter List: Types and order of inputs (can be none).
  • Function Body: Statements defining the function's task.

Calling a Function

To use a function, call it by name with appropriate arguments matching the declaration. Control passes to the function and returns after execution.

Example: User-Defined Function

#include <stdio.h>

int max(int num1, int num2) {
    int result;
    if(num1 > num2)
        result = num1;
    else
        result = num2;
    return result;
}

int main() {
    printf("Max of 75 and 57 is: %d", max(75, 57));
    return 0;
}

Output:

Max of 75 and 57 is: 75

The main() Function

Entry point of a C program. Can call other functions, including library and user-defined. Signature commonly int main() or with arguments for command-line inputs.

Function Arguments Passing

  • Call by Value: Copies argument values; changes inside function don't affect originals.
  • Call by Reference: Passes addresses for direct modification of original data.

Summary

Functions enable modular code design, making large programs easier to manage, test, and reuse. The main() function serves as the starting point for execution, orchestrating calls to other functions.

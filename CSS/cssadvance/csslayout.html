CSS - Layouts

CSS Layout is essential for defining the visual structure, organization, and responsiveness of a website. In this tutorial, we will explore various CSS techniques to create effective website layouts.

Structure of Webpage Layout

A webpage is made up of various sections like header, menus, content, and footer based on which there are many different layout designs available for developers.

To know how to define a webpage structure, check out our tutorial on HTML Layout. Here we explained each and every element of a webpage layout. In this tutorial we will see how to style a webpage layout using CSS.

CSS Normal Layout Flow

Normal flow is the default layout mode where elements are positioned in the order they appear in the HTML document.

  • Block level elements like <div>, <p>, and headings stack vertically and take up full width if not specified.
  • Inline elements like <span>, <strong> stack horizontally. You cannot alter height and width of these elements.
  • Inline block elements behave like both inline and block. They start from the current line but you can alter their size.

Example

<div> Block Element </div>
<span> Inline element </span>
<div class="inlineBlock"> Inline Block Element </div>

CSS Float Layout

Float Layout is used to position elements left or right in document flow. Its main use is to create two-column layouts and to wrap text around images.

.sidebar {
    float: left;
    width: 25%;
}
.main-content {
    float: right;
    width: 75%;
}

Example

<img src="logo.png" class="float-left">
<p>This text will wrap around the floated image.</p>

CSS Flex Layout

CSS Flex Layout organizes elements within a container along a single dimension, either horizontally or vertically.

Example

<div class="container">
  <div class="item">Item 1</div>
  <div class="item">Item 2</div>
  <div class="item">Item 3</div>
</div>

CSS Grid Layouts

CSS Grid Layout is a two-dimensional layout system used for organizing elements horizontally and vertically while developing responsive webpages.

Example

<div class="grid-container">
  <div class="grid-item"> Item 1 </div>
  <div class="grid-item"> Item 2 </div>
  <div class="grid-item"> Item 3 </div>
  <div class="grid-item"> Item 4 </div>
  <div class="grid-item"> Item 5 </div>
</div>

CSS Positioning

CSS Positioning helps to manipulate the position of any element in a web page. The position property along with top, bottom, left, and right properties define exact placement.

Example

<div class="container">
  <div class="static-element">This is a static element.</div>
  <div class="relative-element">This element is relatively positioned.</div>
  <div class="normal-flow">This element is in the normal flow.</div>
</div>

CSS Responsive Layout

A Responsive webpage layout looks good on all devices such as phones, tablets, and desktops. It automatically adjusts size and layout according to the user’s device.

In CSS, Media Queries are used to apply different styles based on the screen size and other device characteristics.

Example

@media (600px < width < 800px) {
  p {
    background-color: yellow;
    color: red;
  }
}

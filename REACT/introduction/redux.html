ReactJS - Redux

React redux is an advanced state management library for React. As we learned earlier, React only supports component level state management. In a big and complex application, large number of components are used. React recommends to move the state to the top level component and pass the state to the nested component using properties. It helps to some extent but it becomes complex when the components increases.

React redux chips in and helps to maintain state at the application level. React redux allows any component to access the state at any time. Also, it allows any component to change the state of the application at any time.

Concepts

React redux maintains the state of the application in a single place called Redux store. React component can get the latest state from the store as well as change the state at any time. Redux provides a simple process to get and set the current state of the application and involves below concepts.

  • Store − The central place to store the state of the application.
  • Actions − Plain objects that describe what needs to happen in the app.
  • Reducers − Pure functions that return a new state based on the current state and action.
  • Action creators − Functions that create and return action objects.
  • Component − Connects to the store, gets state, and dispatches actions.

Redux Store Workflow

  • React component subscribes to the store and gets the latest state during initialization.
  • To change the state, a component creates and dispatches an action.
  • The reducer processes the action and returns a new state.
  • The store updates itself and notifies all subscribed components.

Redux API

Redux provides a single API, connect, to link components to the store.

Provider Component

The Provider component from React Redux makes the store available to all nested components.

Working Example

Steps to implement Redux in a React application:

  • Create a new React application.
  • Install redux and react-redux.
  • Create action types, action creators, and reducers.
  • Create a Redux store using createStore.
  • Wrap the application with Provider and pass the store.
  • Connect components to the store using connect.

Advantages of Redux

  • Centralized state management for predictable behavior.
  • Any component can access and update the state.
  • Makes debugging and testing easier.
  • Provides a scalable structure for complex applications.

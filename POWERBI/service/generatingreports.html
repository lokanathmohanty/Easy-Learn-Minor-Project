Generating Reports in Power BI

Create a Report in Power BI Service

Creating reports in Power BI Service closely resembles report generation in Power BI Desktop. Reports can be created by uploading datasets, building tables, or using auto-generated reports.

Auto Create Report

Richard, a new user, logs into Power BI Service and selects the option to paste or manually enter data. After entering data with headers, he clicks "Auto-create report," which generates a ready-to-use report instantly.

The report is interactive; clicking on an individual (like "Daniel") filters related visuals to show detailed information such as designation and work satisfaction.

Create Report from Scratch

Richard decides to build a report from scratch. He selects his workspace, chooses to create a new report, and adds visuals patterned on his data fields.

For example, he adds a stacked bar chart with "Designation" on the Y-axis and "Work Satisfaction" on the X-axis to visualize employee satisfaction by role.

These reports can be saved and shared within the organization for collaborative decision-making.

Using Q&A in Power BI

Power BI offers a natural language query feature called Q&A, allowing users to type questions and get immediate visual answers.

  • Sorting tables by name
  • Counting specific roles, like the number of software engineers
  • Generating charts dynamically by specifying measures and categories
  • Filtering data based on criteria, such as showing employees with "Excellent" work satisfaction

Publishing Reports from Power BI Desktop to Service

Reports designed in Power BI Desktop can be published to the Power BI Service for wider access.

The process involves saving the report, agreeing to privacy terms, signing into a Microsoft account, and initiating the publish action.

Once published, reports appear in the user’s Power BI workspace and are accessible online for viewing, sharing, and collaboration.

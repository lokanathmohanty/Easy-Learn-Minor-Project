PHP File Deletion and Renaming

In PHP, managing files often requires the ability to remove them from the server's file system. PHP uses the **`unlink()`** function for file deletion, and the **`rename()`** function for renaming or moving files.

Deleting Files with `unlink()` 🗑️

PHP does not have a `delete()` function; instead, it uses the Unix-like **`unlink()`** function to remove a specified file from the filesystem.

**Syntax:**
unlink(string $filename): bool

**Example with Check:**
$file = "temp_data.log";
if (file_exists($file)) {
   if (**unlink**($file)) {
      echo "File was deleted successfully.";
   } else {
      echo "Error: Could not delete the file.";
   }
}

**Note on Symlinks:** The `unlink()` function can be used to delete a symbolic link (shortcut). Deleting a symlink **does not** delete the original target file, leaving it intact.

Renaming and Moving Files with `rename()` ✍️➡️📦

The **`rename()`** function is used to change the name of a file or directory. Critically, it can also be used to **move** a file from one directory to another by simply changing the target path.

**Syntax:**
rename(string $from, string $to): bool

**1. Renaming:**
**rename**("old.txt", "new.txt");

**2. Moving/Relocating:**
**rename**("upload/temp.jpg", "archive/final.jpg");

**Overwrite Rule:** If the target file (`$to`) already exists, `rename()` will **overwrite** the existing file without warning if it's a file.

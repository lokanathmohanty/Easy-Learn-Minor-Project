JavaScript - ES5 Object Methods

The ES5 Object methods in JavaScript are used to manipulate and protect objects. ECMAScript 5 (ES5), introduced in 2009, added many new object methods to JavaScript.

These methods provide efficient ways to iterate through object properties, manipulate values, and perform operations on objects. Object manipulation is a fundamental aspect of JavaScript programming.

JavaScript ES5 Object Methods

In ES5, object-related methods were added to manipulate and protect objects. Below are some important ones:

Methods to Manipulate the Object

  • create() – Create new objects with a specified prototype.
  • defineProperty() – Add or modify a single property.
  • defineProperties() – Define multiple properties at once.
  • getOwnPropertyDescriptor() – Get a property descriptor of an object property.
  • getOwnPropertyNames() – Get all property names of an object.
  • getPrototypeOf() – Get the prototype of an object.
  • keys() – Get enumerable keys of the object in array format.

Methods to Protect the Object

  • freeze() – Prevent adding or modifying properties.
  • seal() – Seal the object (no new or deleted properties).
  • isFrozen() – Check if an object is frozen.
  • isSealed() – Check if an object is sealed.
  • isExtensible() – Check if an object can be extended.
  • preventExtensions() – Prevent new properties from being added.

Object.create()

Creates a new object with the specified prototype object and properties. 

const person = { firstName: "John", lastName: "Doe" };
const student = Object.create(person);
student.age = 18;

console.log(student.firstName); // John
console.log(student.lastName);  // Doe
console.log(student.age);       // 18

Object.defineProperty()

Defines or modifies a single property in an object. 

const car = { brand: "Tata", model: "Nexon", price: 1000000 };

Object.defineProperty(car, "gears", {
  value: 6,
  writable: true,
  enumerable: true,
  configurable: true
});

console.log(car);
// { brand: "Tata", model: "Nexon", price: 1000000, gears: 6 }

Object.defineProperties()

Defines or modifies multiple properties of an object. 

const obj = {};

Object.defineProperties(obj, {
  property1: { value: 42, writable: true },
  property2: { value: "Tutorials Point", writable: false }
});

console.log(obj.property1); // 42
console.log(obj.property2); // Tutorials Point

Object.getOwnPropertyDescriptor()

Returns a property descriptor for a specific property. 

const obj = { property1: 42 };
const descriptor = Object.getOwnPropertyDescriptor(obj, 'property1');

console.log(descriptor.configurable); // true
console.log(descriptor.value);        // 42

Object.getOwnPropertyNames()

const obj = { a: 10, b: 20, c: 30 };
console.log(Object.getOwnPropertyNames(obj)); // ["a","b","c"]

Object.getPrototypeOf()

const prototype1 = { name: "John Doe" };
const obj = Object.create(prototype1);
console.log(Object.getPrototypeOf(obj)); // { name: "John Doe" }

Object.keys()

const person = { name: "John Doe", age: 20, profession: "Engineer" };
console.log(Object.keys(person)); // ["name","age","profession"]

Object.freeze()

const obj = { prop: 23 };
Object.freeze(obj);

obj.prop = 33; // Error in strict mode
console.log(obj.prop); // 23

Object.seal()

const obj = { property: 34 };
Object.seal(obj);

obj.property = 33;
delete obj.property; // Cannot delete
console.log(obj.property); // 33

Object.isFrozen()

const person = { age: 21 };

console.log(Object.isFrozen(person)); // false
Object.freeze(person);
console.log(Object.isFrozen(person)); // true

Object.isSealed()

const person = { name: "John Doe" };

console.log(Object.isSealed(person)); // false
Object.seal(person);
console.log(Object.isSealed(person)); // true

Object.preventExtensions()

const person = {};
Object.preventExtensions(person);

try {
  Object.defineProperty(person, "name", { value: "John Doe" });
} catch (e) {
  console.log(e); 
  // TypeError: Cannot define property name, object is not extensible
}

Object.isExtensible()

const person = { name: "John Doe" };

console.log(Object.isExtensible(person)); // true
Object.preventExtensions(person);
console.log(Object.isExtensible(person)); // false

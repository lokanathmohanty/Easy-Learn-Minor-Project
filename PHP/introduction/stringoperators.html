PHP String Operators

PHP provides two operators specifically for manipulating string data types: the **Concatenation Operator** (`.`) and the **Concatenation Assignment Operator** (`. =`). These operators are used to join strings together.

1. Concatenation Operator (`.`)

The dot operator (`.`) is used to **join** two or more string operands together, appending the right-hand string to the left-hand string. It returns a new, combined string.

$third = $first . $second;

$x="Hello"; $y="PHP";
$str = $x . " " . $y; $\rightarrow$ $str is "Hello PHP"

2. Concatenation Assignment Operator (`. =`)

The concatenation assignment operator (`. =`) combines concatenation and assignment into a single operation. It **appends** the right-hand string to the string stored in the variable on the left, updating the left-hand variable's value.

$leftstring .= $rightstring; (Equivalent to: $leftstring = $leftstring . $rightstring;)

$x="Hello "; $y="PHP";
$x .= $y; $\rightarrow$ $x is updated to "Hello PHP"

Practical Usage and Type Handling

Concatenation with Variables and Other Data Types

PHP's weak typing allows easy concatenation of strings with variables holding other scalar data types (like integers and floats). PHP automatically converts the numeric value to a string before performing the join.

$name = "Ankit"; $age = 25;
$sentence = "My name is " . $name . " and I am " . $age . " years old.";

Output: My name is Ankit and I am 25 years old.

Using Concatenation in Loops

The concatenation assignment operator (`. =`) is particularly useful inside loops for efficiently building up a long string (e.g., generating HTML or collecting results).

$result = "";
for ($i = 1; $i <= 5; $i++) {
   $result .= "Number " . $i . "\n";
}

Output: Number 1\nNumber 2\n...

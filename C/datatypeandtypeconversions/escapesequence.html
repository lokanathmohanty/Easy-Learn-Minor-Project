Escape Sequences in C

An escape sequence in C is a literal consisting of multiple characters enclosed in single quotes, starting with a backslash (\) that gives special meaning to the character following it. Escape sequences allow representation of characters that are difficult or impossible to express directly in strings or character literals.

For example, the escape sequence \n represents a newline (line break), equivalent to pressing the Enter key.

Escape sequences are widely used for formatting output, controlling cursor movements, and representing special characters.

Common Escape Sequences

  • \\ - Backslash character
  • \' - Single quote character
  • \" - Double quote character
  • \? - Question mark character
  • \a - Alert or bell (makes a beep sound)
  • \b - Backspace (moves cursor back)
  • \f - Form feed (page break)
  • \n - Newline (line feed)
  • \r - Carriage return (return cursor to line start)
  • \t - Horizontal tab
  • \v - Vertical tab
  • \ooo - Octal number (one to three octal digits)
  • \xhh - Hexadecimal number (one or more hex digits)

Example: Newline Escape Sequence (\n)


#include <stdio.h>

int main() {
   printf("Hello.\nGood morning.\nMy name is Ravi");
   return 0;
}

Output:


Hello.
Good morning.
My name is Ravi

Example: Tab Escape Sequence (\t)


#include <stdio.h>

int main() {
   printf("Name:\tRavi\tMarks:\t50");
   return 0;
}

Output:


Name:   Ravi    Marks:  50

Example: Backslash Escape Sequence (\\)


#include <stdio.h>

int main() {
   printf("Directory in Windows: C:\\\\users\\\\user");
   return 0;
}

Output:


Directory in Windows: C:\users\user

Example: Quotes Escape Sequences (\" and \')


#include <stdio.h>

int main() {
   printf("Welcome to \"TutorialsPoint\"\n");
   printf ("\'Welcome\' to TutorialsPoint");
   return 0;
}

Output:


Welcome to "TutorialsPoint"
'Welcome' to TutorialsPoint

Example: Backspace Escape Sequence (\b)


#include <stdio.h>

int main() {
   printf("Welcome to\b TutorialsPoint");
   return 0;
}

Output:


Welcome t TutorialsPoint

(Note: The character before the backspace disappears)

Example: Octal Escape Sequence (\ooo)


#include <stdio.h>

int main() {
   printf("%c", '\141');
   return 0;
}

Output:


a

Example: Hexadecimal Escape Sequence (\xhh)


#include <stdio.h>

int main() {
   printf("%c", '\x41');
   return 0;
}

Output:


A

Example: Alert or Bell Escape Sequence (\a)


#include <stdio.h>

int main() {
   printf("Hello \a world\n");
   return 0;
}

Output:


Hello  world

(Terminal may produce a beep or flash alert)

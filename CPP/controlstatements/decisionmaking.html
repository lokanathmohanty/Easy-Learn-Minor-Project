C++ Decision Making Statements 🎯

Decision making structures allow a C++ program to execute specific code blocks based on whether a given **Boolean condition** evaluates to **true** or **false**. This enables the program to control its flow and make logical choices.

Types of Decision Making Statements

C++ provides the following constructs for decision making:

StatementDescriptionBest Used For
**if statement** Executes a block of code if the specified condition is **true**. Simple conditional execution.
**if...else statement** Executes one block if the condition is **true** and a different block if the condition is **false**. Choosing between two alternative paths.
**if...else if...else** Allows for testing a series of conditions sequentially. Evaluating multiple mutually exclusive conditions.
**switch statement** Tests a variable for equality against a list of constant values (cases). Choosing a path based on a single integer or character value.
**Nested if / switch** Placing one decision structure inside another. Handling complex, hierarchical conditions.

The Conditional (Ternary) Operator (? :)

The conditional operator is a powerful shorthand that can replace simple if...else assignments.

General Form:

Exp1 ? Exp2 : Exp3;
  • **Exp1 (Condition):** Evaluated first.
  • **If Exp1 is true:** The result of the whole expression is **Exp2**.
  • **If Exp1 is false:** The result of the whole expression is **Exp3**.

Example:

The if-else block:

if(y < 10) { 
   var = 30;
} else {
   var = 40;
}

Is concisely rewritten using the ternary operator as:

var = (y < 10) ? 30 : 40;

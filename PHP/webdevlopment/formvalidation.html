PHP: Form Validation

**Form Validation** is the process of checking whether user-submitted data meets the required criteria before it is processed. This step is critical for maintaining **data integrity**, improving **user experience**, and ensuring **security**.

Types of Validation

  • Client-Side Validation: Occurs in the user's browser (typically using JavaScript or HTML5 input types like `type="email"`). It provides **instant feedback** but can be bypassed.
  • Server-Side Validation: Occurs after the form is submitted, using a language like PHP. It is **essential for security** because it cannot be bypassed, ensuring data is processed correctly regardless of the client-side settings.

Server-Side Validation Techniques in PHP

PHP validation focuses on cleaning data and checking content and format:

Data Cleaning and Safety

  • trim(): Removes whitespace from the beginning and end of a string.
  • htmlspecialchars(): Converts special characters (like `<`, `>`, `&`) into HTML entities. This is the **primary defense against Cross-Site Scripting (XSS)** attacks when echoing user data back to the browser.

Content Checks (Rules)

  • Required Fields: Use empty() or isset() on the $_POST or $_GET array value to ensure essential fields are not left blank.
  • Data Type: Use functions like **is_numeric()** to enforce that fields like age or phone numbers contain only digits.
  • Format/Pattern Matching: Use **Regular Expressions** (`preg_match()`) or built-in filter functions (e.g., `filter_var()` for email/URL checks) to ensure data matches a specific format.

Preventing $_SERVER["PHP_SELF"] Exploits

To safely submit a form to the same script, the action attribute must be protected. If not sanitized, a hacker could inject malicious code into the URL that would be executed when the form loads.

<form action="<?php echo htmlspecialchars($_SERVER["PHP_SELF"]); ?>" method="post">

Wrapping $_SERVER["PHP_SELF"] with htmlspecialchars() prevents any injected code from being executed, treating it as harmless plain text instead.

Example Session: Basic Server-Side Validation

This example demonstrates checking for empty fields, cleaning the data, and validating if a field is numeric.


<?php
   if ($_SERVER["REQUEST_METHOD"] == "POST") {
      $name = trim($_POST["name"]);
      $age = trim($_POST["age"]);
      
      // 1. Check for empty fields
      if (empty($name) || empty($age)) {
         echo "Error: Name and Age fields are required.";
      } 
      // 2. Validate Age is numeric
      else if (!is_numeric($age)) {
         echo "Error: Age must be a number.";
      }
      // 3. Process the clean data
      else {
         $safe_name = htmlspecialchars($name);
         echo "Submission successful for: " . $safe_name . " (" . $age . ")";
      }
   }
?>

   Age: <input type="text" name="age"><br>
   <input type="submit">
</form>

C# Loops and Control Statements

What Are Loops?

A **loop statement** allows a statement or a group of statements to be executed **multiple times**. Loops are a fundamental control structure, allowing the program to perform repetitive tasks without redundant code.

Example: Displaying Array Elements

int[] number = { 1, 2, 3, 5, 6 };
// The 'for' loop iterates over the array
for (int i = 0; i < number.Length; i++) {
   Console.WriteLine(number[i]);
}

Types of C# Loops

C# supports three primary loop types, plus the ability to nest them:

1. The `while` Loop (Pre-test Loop)

Repeats a block of code **while** a given condition is true. The condition is tested **before** the loop body executes.

int i = 1;
while (i <= 5) // Condition checked first
{
    Console.WriteLine("Number: " + i);
    i++;
}

2. The `for` Loop

A compact structure for iterating a fixed number of times, combining initialization, condition testing, and iteration (increment/decrement) into a single line.

// Initialization; Condition; Iterator
for (int i = 1; i <= 5; i++) 
{
    Console.WriteLine("Number: " + i);
}

3. The `do...while` Loop (Post-test Loop)

Similar to `while`, but it tests the condition at the **end** of the loop body. This guarantees that the body of the loop executes **at least once**, even if the condition is initially false.

int i = 1;
do
{
    Console.WriteLine("Number: " + i);
    i++;
} while (i <= 5); // Condition checked last

Loop Control Statements

Control statements allow you to alter the normal flow of execution within a loop.

  • `break` Statement: Immediately **terminates** the loop (or `switch` statement) and transfers execution to the statement immediately following the loop.
  • `continue` Statement: Causes the loop to **skip the remainder** of its current iteration and immediately retest its condition to begin the next iteration.

Example: Using `break`

int count = 10;
for (int i = 0; i < count; i++) {
    if (i == 5) {
       break; // Stops the loop entirely when i is 5
    }
    Console.WriteLine(i);
}
// Output: 0, 1, 2, 3, 4

Infinite Loops

An **infinite loop** occurs when the loop's termination condition never becomes false, causing it to execute indefinitely. This is often an error, but it is sometimes used intentionally in system services or embedded programming.

The `for` loop is often used to create an infinite loop by simply omitting the conditional expression, as the absence of a condition assumes true.

// The most common structure for an intentional infinite loop
for (; ; ) {
   Console.WriteLine("Hey! I am Trapped");
   // To stop a program in a real-world infinite loop, you need an external break condition or process termination.
}

C++ Reading From File (ifstream) 📖

**File I/O** (Input/Output) in C++ allows programs to read data from external files, enabling **data persistence** beyond the program's execution scope. The primary tool for reading is the **Input File Stream** class, **std::ifstream**, found in the <fstream> header.

Basic Reading Steps

  1. **Open the file:** Create an std::ifstream object and associate it with a file name. Always check if the file opened successfully.
  2. **Perform I/O:** Read data using extraction operators or specialized functions.
  3. **Close the file:** Call .close() to release the file handle.
std::ifstream inputFile("data.txt"); // 1. Open
if (inputFile.is_open()) {
    // 2. Perform I/O
    inputFile.close(); // 3. Close
}

Reading Text Files (Methods)

1. Reading Word by Word (>> Operator)

The stream extraction operator (>>) is the simplest method for reading **formatted data**. It automatically stops at any **whitespace** (space, newline, tab).

std::string word;
while (inputFile >> word) { // Reads and stops when whitespace is hit
    // Process 'word'
}

2. Reading Line by Line (std::getline())

To read an **entire line of text**, including spaces, you use the non-member function `std::getline()`. It reads characters until it encounters a newline character (`\n`).

std::string line;
while (std::getline(inputFile, line)) { // Reads until a newline is hit
    // Process 'line'
}

Reading Binary Files (read())

For reading **raw, unformatted binary data**, you use the read() member function, ensuring the file is opened in binary mode (std::ios::binary).

file.read(buffer, size);
  • **buffer**: A pointer to the memory location where the data should be stored.
  • **size**: The number of bytes to read.

Error and Status Handling

Checking the state of the stream is essential for robust I/O:

  • **!stream** or **stream.fail()**: Checks if a fatal or non-recoverable error occurred (e.g., file not found, bad data format).
  • **stream.eof()**: Returns true if the **End-of-File (EOF)** marker has been reached (usually checked after a failed read).
  • **stream.good()**: Returns true if no errors have occurred and the stream is ready for I/O.

Note that the `while (inputFile >> word)` or `while (std::getline(inputFile, line))` loop structures are generally preferred, as they implicitly check the success of the read operation before continuing the loop.

NumPy LCM (Lowest Common Multiple)

The Lowest Common Multiple (LCM) is the smallest number that is a common multiple of two numbers.

Example 1: Find LCM of Two Numbers

Find the LCM of the following two numbers:

import numpy as np

num1 = 4
num2 = 6

x = np.lcm(num1, num2)

print(x)

Returns: 12 because 12 is the lowest common multiple of both numbers (4×3=12 and 6×2=12).

Example 2: Find LCM of an Array

To find the Lowest Common Multiple of all values in an array, use the reduce() method with the np.lcm ufunc.

This method applies the LCM operation cumulatively on the elements of the array.

import numpy as np

arr = np.array([3, 6, 9])

x = np.lcm.reduce(arr)

print(x)

Returns: 18 because 18 is the LCM of 3, 6, and 9 (3×6=18, 6×3=18, and 9×2=18).

Example 3: Find LCM of Integers 1 to 10

Find the LCM of all integers from 1 to 10:

import numpy as np

arr = np.arange(1, 11)

x = np.lcm.reduce(arr)

print(x)

PHP $\text{PDO}$ Extension ($\text{PHP}$ Data Objects) 💾

**$\text{PDO}$ ($\text{PHP}$ Data Objects)** is a lightweight, consistent interface for accessing databases in $\text{PHP}$. It provides a vendor-neutral abstraction layer, meaning the same $\text{PDO}$ code can be used to connect to various database systems (e.g., $\text{MySQL}$, $\text{PostgreSQL}$, $\text{SQLite}$) with minimal changes, primarily just the connection details ($\text{DSN}$).

Database Connection

A connection is established by creating an instance of the $\text{PDO}$ class. The constructor requires a **$\text{DSN}$ ($\text{Data Source Name}$)** string, along with optional username and password.

$dbh = new PDO('mysql:host=localhost;dbname=test', $user, $pass);
  • $\text{DSN}$: Specifies the driver name, followed by driver-specific connection details (e.g., $\text{mysql:host=...}$).
  • Drivers: $\text{PHP}$ must have the corresponding $\text{PDO}$ driver enabled ($\text{extension=pdo\_mysql}$ in $\text{php.ini}$). You can check available drivers with $\text{PDO::getAvailableDrivers()}$.
  • Error Handling: $\text{PDO}$ throws a **$\text{PDOException}$** object on connection failure, which should be handled using a $\text{try...catch}$ block.

Core $\text{PDO}$ Connection Methods

1. $\text{PDO::exec()}$ (Non-Query Operations)

Executes an $\text{SQL}$ statement and returns the **number of rows affected** (or $\text{0}$ if none). It is typically used for $\text{DML}$ ($\text{INSERT}$, $\text{UPDATE}$, $\text{DELETE}$) and $\text{DDL}$ ($\text{CREATE}$, $\text{DROP}$) statements, but **does not return results from $\text{SELECT}$ statements**.

public PDO::exec(string $statement): int|false

Example: Creating a table

$conn->exec("CREATE TABLE IF NOT EXISTS STUDENT (...)");

2. $\text{PDO::query()}$ (Simple Queries)

Prepares and executes an $\text{SQL}$ statement in a single call, returning a **$\text{PDOStatement}$ object**. This method is suitable for $\text{SELECT}$ statements that are executed only once and do **not** use placeholders.

public PDO::query(string $query): PDOStatement|false

Example: Fetching records

$statement = $conn->query("SELECT * from student");
$rows = $statement->fetchAll(PDO::FETCH_ASSOC);

For $\text{SQL}$ statements issued multiple times or those requiring user input (to prevent $\text{SQL}$ injection), use $\text{PDO::prepare()}$ and $\text{PDOStatement::execute()}$.

Transaction Management

$\text{PDO}$ provides methods to manage database transactions, ensuring a set of operations either all succeed or all fail together. This turns off the default autocommit mode.

  • $\text{PDO::beginTransaction()}$: Initiates a transaction.
  • $\text{PDO::commit()}$: Makes all changes within the transaction permanent and returns the connection to autocommit mode.
  • $\text{PDO::rollBack()}$: Reverts all changes made since the $\text{beginTransaction()}$ call and returns the connection to autocommit mode.

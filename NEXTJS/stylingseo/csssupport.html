Next.js - CSS Support

In Next.js, you can apply styling particular to a component (scoped) or global styling that affects all components. This chapter explores the styling methods supported by Next.js, how to style a module, and how to apply global styles.

Styling Next.js App

Next.js supports different ways of styling your application, such as:

  • **CSS Modules**
  • **Tailwind CSS**
  • **SASS**
  • **CSS-in-JS**

CSS Modules in Next.js

We can use **CSS Modules** to specify styles explicitly for a particular component. The styles specified by this method will be **scoped** and will **not affect any other components**.

Styling a Next.js Module

A stylesheet defined for a Next.js module should end with the **`.module.css`** extension.

  • You **cannot use element selectors** (like `h1`, `p`) inside CSS module files; these are only allowed inside Next.js global CSS styles.
  • In a Next.js module, you use the syntax **`styles.className`** or **`styles.idName`** to reference classes or IDs from the imported CSS file.

Example of Styling a Module (`page.tsx`)

// app/about/page.tsx

// Import the CSS module
import styles from './about.module.css';

export default function About() {
  return (
    <div className={styles.div}>
      <h1 className={styles.h1}>About Us</h1>
      <h2 className={styles.h2}>
        Welcome to the Next JS About page!
      </h2>
    </div>
  );
}

Example of Module CSS File (`about.module.css`)

// app/about/about.module.css file

.div {
    font-family: Arial, sans-serif;
    padding: 20px;
    background-color: #f9f9f9;
    border: 2px solid;
    border-radius: 10px;
    max-width: 500px;
}
.h1 {
    color: #0070f3;
}
.h2 {
    color: #333;
}

**Output**: The CSS styles are only affecting the "About" module.

Setup Tailwind CSS in Next.js

**Tailwind CSS** is a utility-first CSS framework. When creating a Next.js app, you are prompted to include it. If you choose to, Next.js will automatically set it up.

Step 1: Install Tailwind CSS (Manual Setup)

Run the following commands in your project terminal:

// Install tailwind and peer dependencies

npm install -D tailwindcss postcss autoprefixer

// Initialize tailwind and generate config files

npx tailwindcss init -p

Step 2: Configure Template Paths (`tailwind.config.ts`)

Add paths to all of your template files (files that use Tailwind CSS) to the **`content`** array in the generated `tailwind.config.ts` file.

// ./tailwind.config.ts

module.exports = {
  content: [
    "./app/**/{js,ts,jsx,tsx,mdx}",
    "./pages/**/{js,ts,jsx,tsx,mdx}",
    "./components/**/{js,ts,jsx,tsx,mdx}",
    "./src/**/{js,ts,jsx,tsx,mdx}",
  ],
  theme: { /* ... */ },
  plugins: [],
}

Step 3: Add the Tailwind Directives (`globals.css`)

Add the `@tailwind` directives to your global CSS file (`globals.css`) to inject Tailwind's `base`, `components`, and `utilities` styles.

// ./global.css

@tailwind base;
@tailwind components;
@tailwind utilities;

Step 4: Start Using Tailwind

You can now use Tailwind CSS utility classes to style any component.

// app/page.tsx

export default function Home() {
  return (
    <div>
      <h1 className="text-3xl font-bold overline" >
        Welcome to My Next.js App
      </h1>
      <p className="text-base text-gray-700" >
        This is the home page.
      </p>
    </div>
  );
}

Next.js SASS Support

**SASS** is a CSS pre-processor. Next.js has **built-in support** for SASS after the package is installed, supporting both the **`.scss`** and **`.sass`** extensions.

  • You can use component-level SASS within CSS Modules by using the **`.module.scss`** or **`.module.sass`** extension.

Install SASS

Run the following code to install SASS:

npm install --save-dev sass

Customizing SASS Options

You can configure SASS options inside the **`next.config.ts`** file, for example, to set global variables or specify the implementation.

// ./next.config.ts (Example of additionalData)

const nextConfig: NextConfig = {
  sassOptions: {
    additionalData: `$var: red;`,
  },
}

// Example of specifying implementation (optional)

const nextConfig: NextConfig = {
  sassOptions: {
    implementation: 'sass-embedded', // Default is 'sass'
  },
}

Example of SASS in Next.js

SASS variables can be exported and imported into components, as shown below:

// app/variables.module.scss

$primary-color: #64ff00;

:export {
  primaryColor: $primary-color;
}

// app/page.tsx
import variables from './variables.module.scss'

export default function Page() {
  return <h1 style={{ color: variables.primaryColor }}>
            Hello, Next.js!
        </h1>
}

Next.js CSS-in-JS

**CSS-in-JS** allows you to write styles directly in JavaScript, scoped to individual components. Next.js supports libraries like **styled-components**, **Emotion**, and its built-in **styled-jsx**.

  • **Note**: CSS-in-JS libraries which require runtime JavaScript are **not supported in Server Components**. It is recommended to use CSS-in-JS only in **Client Components** (by adding `'use client'`).

Using Styled JSX

Next.js has built-in support for **styled-jsx**, allowing you to style components with scoped CSS without additional dependencies.

// /app/page.tsx

'use client';

export default function Home() {
  return (
    <div>
      <h1>Hello, Next.js!</h1>
      <p>Welcome to CSS-in-JS.</p>
      <style jsx>{`

        h1 {
          color: green;
        }
        p {
          font-size: 18px;
          color: gray;
        }

      `}</style>
    </div>
  );
}

Using Styled Components

**Styled-components** is a popular third-party library. To use it, you must first install the package and the Babel plugin:

npm install styled-components

npm install --save-dev babel-plugin-styled-components

After installation, you can use it to create styled components:

// /app/page.tsx

'use client';
import styled from 'styled-components';

const Title = styled.h1` color: green; `; // Define a styled component
const Paragraph = styled.p` font-size: 18px; color: gray; `; // Define another

export default function Home() {
  return (
    <div>
      <Title>Hello, Next.js!</Title> <!-- Use the styled component -->
      <Paragraph>Welcome to CSS-in-JS.</Paragraph>
    </div>
  );
}

JavaScript - Destructuring Assignment

Introduction

In JavaScript, the destructuring assignment is an expression that allows us to unpack values from arrays or objects and store them into individual variables. It is a technique to assign array values or object properties directly to variables.

The destructuring assignment syntax was introduced in ECMAScript 6 (ES6). Before ES6, developers had to manually extract values from arrays and objects.

Array Unpacking Before ES6

<script>
   const arr = ["Apple", "Banana", "Watermelon"];

   const fruit1 = arr[0];
   const fruit2 = arr[1];
   const fruit3 = arr[2];

   console.log("fruit1:", fruit1);
   console.log("fruit2:", fruit2);
   console.log("fruit3:", fruit3);
</script>

Output:

  • fruit1: Apple
  • fruit2: Banana
  • fruit3: Watermelon

This approach becomes inefficient when working with larger arrays.

Array Destructuring Assignment

With destructuring assignment, we can extract values in a single line.

const [var1, var2, var3] = arr;

Example

<script>
   const arr = ["Apple", "Banana", "Watermelon"];

   const [fruit1, fruit2, fruit3] = arr;

   console.log("fruit1:", fruit1);
   console.log("fruit2:", fruit2);
   console.log("fruit3:", fruit3);
</script>

Output:

  • fruit1: Apple
  • fruit2: Banana
  • fruit3: Watermelon

Nested Array Destructuring

We can also extract values from nested arrays.

<script>
   const arr = ["Apple", ["Banana", "Watermelon"]];
   const [x, [y, z]] = arr;

   console.log(x); // Apple
   console.log(y); // Banana
   console.log(z); // Watermelon
</script>

Output:

  • Apple
  • Banana
  • Watermelon

Object Destructuring Assignment

Similarly, we can destructure objects using the following syntax:

const {prop1, prop2, prop3} = obj;

Example

<script>
   const fruit = {
      name: "Apple",
      price: 100,
   }

   const {name, price} = fruit;

   console.log("fruit name:", name);
   console.log("fruit price:", price);
</script>

Output:

  • fruit name: Apple
  • fruit price: 100

Nested Object Destructuring

We can destructure nested objects to directly access deeply nested properties.

<script>
   const person = {
      age: 26,
      name: {
         fName: "John",
         lName: "Doe"
      }
   }

   const {age, name: {fName, lName}} = person;

   console.log("Person name:", fName, lName);
   console.log("Person age:", age);
</script>

Output:

  • Person name: John Doe
  • Person age: 26

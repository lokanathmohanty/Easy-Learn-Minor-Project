Python - Positional Arguments

The list of variables declared in the parentheses at the time of defining a function are the formal arguments. These are also called positional arguments. A function may be defined with any number of formal arguments.

While calling a function:

  • All the arguments are required.
  • The number of actual arguments must be equal to the number of formal arguments.
  • They pick up values in the order of definition.
  • The type of arguments must match.
  • Names of formal and actual arguments need not be same.

Positional Arguments Examples

Example 1

The following example shows the use of positional arguments:

def add(x, y):
    z = x + y
    print("x={} y={} x+y={}".format(x, y, z))

a = 10
b = 20
add(a, b)

Output:

x=10 y=20 x+y=30

Here, the add() function has two formal arguments. When integers 10 and 20 are passed, the variable a takes 10 and b takes 20 in the order of declaration.

Example 2

If the number of arguments do not match, Python raises an error:

def add(x, y):
    z = x + y
    print(z)

a = 10
add(a)

Error:

TypeError: add() missing 1 required positional argument: 'y'

Example 3

If more arguments are passed than expected:

def add(x, y):
    z = x + y
    print("x={} y={} x+y={}".format(x, y, z))

add(10, 20, 30)

Error:

TypeError: add() takes 2 positional arguments but 3 were given

Example 4

Data type of actual and formal arguments must match:

def add(x, y):
    z = x + y
    print(z)

a = "Hello"
b = 20
add(a, b)

Error:

TypeError: can only concatenate str (not "int") to str

Difference between Positional and Keyword Arguments

Positional Argument Keyword Argument
Only the names of arguments are used to pass data. Arguments are passed in name=value form.
Arguments are passed in the order defined in the function. Order does not matter when using keywords.
function(param1, param2, ...) function(param1=value1, ...)

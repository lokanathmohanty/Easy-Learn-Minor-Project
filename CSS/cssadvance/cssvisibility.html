CSS - visibility Property

The visibility Property

The CSS visibility property allows you to show or hide an element without changing the layout of a document. Hidden elements still take up space, unlike display: none which removes elements entirely from the layout.

It can be useful for hiding elements that are not yet ready to be displayed, or for selectively hiding content based on conditions.

Syntax

visibility: visible | hidden | collapse | initial | inherit;

Possible Values

  • visible: Default value. The element is visible.
  • hidden: Hides the element, but it still takes up space.
  • collapse: Removes table rows, columns, or cells. On non-table elements, it behaves like hidden.
  • initial: Sets the visibility of the element to its default value.
  • inherit: Inherits the visibility property from the parent element.

Applies to

The visibility property can be applied to all HTML elements.

CSS visibility - visible Value

By default, elements are visible. You can explicitly set visibility: visible to ensure an element is displayed.

Example

<html>
<head>
<style>
   h2 {
      visibility: visible;
   }
</style>
</head>
<body>
   <h2>Tutorials Point CSS visibility</h2>
</body>
</html>

Hide Elements with CSS visibility Property

Using visibility: hidden hides the element but does not remove it from the document flow. The element still takes up space and is accessible to screen readers.

Example

<html>
<head>
<style>
   h2 {
      visibility: hidden;
   }
</style>
</head>
<body>
   <h2>Tutorials Point CSS visibility hidden</h2>
   <p>The hidden heading still takes up space on the page.</p>
</body>
</html>

Collapse Table Cells with CSS visibility

The visibility: collapse value is mainly used with table rows, columns, and cells. It removes them without affecting the table layout. On non-table elements, it behaves like hidden.

Example 1

<html>
<head>
<style>
   .collapse {
      visibility: collapse;
   }
   table {
      border-collapse: collapse;
      width: 100%;
      border: 2px solid black;
   }
   th, td {
      border: 2px solid black;
      padding: 8px;
      text-align: left;
   }
</style>
</head>
<body>
   <table>
      <tr>
         <td>visible</td>
         <td>hidden</td>
         <td class="collapse">collapse</td>
      </tr>
      <tr>
         <td>initial</td>
         <td>inherit</td>
         <td>revert</td>
      </tr>
   </table>
</body>
</html>

Example 2

<html>
<head>
<style>
   .collapse {
      visibility: collapse;
   }
</style>
</head>
<body>
  <h2>Collapse on non-table elements</h2>
  <p class="collapse">you cant see me</p>
  <p>the above sentence is hidden</p>
</body>
</html>

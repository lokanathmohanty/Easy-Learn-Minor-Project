Java Programming: Inheritance and Polymorphism

Session: Method Overriding

What is Method Overriding?

**Method Overriding** is the ability for a **subclass** to provide a specific implementation for a method that is already defined in its **superclass**. It is a fundamental technique for achieving **run-time polymorphism**.

The primary benefit of overriding is to allow a subclass to define a behavior that is specific to its own type, implementing the parent class method based on its unique requirements.

The Overriding Rule: Same Signature

For a method to correctly override a superclass method, the declaration signature in the subclass must be the same as the superclass method, including:

  • **Method Name** must be identical.
  • **Parameter List** must be identical (same number, type, and order).
  • **Return Type** must be the same or a compatible subtype (covariant return types).

Example: Overriding move()

The Dog class overrides the move() method inherited from Animal to provide dog-specific movement.

class Animal {
   public void move() {
      System.out.println("Animals can move");
   }
}

class Dog extends Animal {
   public void move() { // Overriding the method
      System.out.println("Dogs can walk and run");
   }
}

public class TestDog {
   public static void main(String args[]) {
      Animal b = new Dog(); // Polymorphism: Parent reference, Child object
      b.move(); // **Runs the Dog's move() method at runtime**
   }
}

Output:

Dogs can walk and run

Key Rules for Overriding

  • **Access Level:** The access level cannot be **more restrictive** than the overridden method (e.g., a `public` parent method cannot be overridden as `private`).
  • **final Methods:** A method declared `final` **cannot** be overridden.
  • **static Methods:** A method declared `static` **cannot** be overridden (it can be re-declared, which is called method hiding).
  • **Constructors:** Constructors **cannot** be overridden as they do not have the same name in the inheritance chain.
  • **Exceptions:** The overriding method can throw narrower or fewer checked exceptions, but cannot throw new or broader checked exceptions.

Using super to Call the Parent Method

The **super** keyword is used within the overriding subclass method to explicitly invoke the version of the method defined in the superclass, allowing the subclass to extend, rather than completely replace, the parent's logic.

Example: Using super.move()

class Dog extends Animal {
   public void move() {
      super.move(); // Calls the Animal's move() method first
      System.out.println("Dogs can walk and run");
   }
}

Output using the above code:

Animals can move
Dogs can walk and run

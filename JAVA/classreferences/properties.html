Java Properties Class Summary ⚙️📝

The **java.util.Properties** class is a specialized, concrete subclass of **Hashtable** used to represent a **persistent set of configuration properties**. It is optimized for storing, loading, and accessing configuration data, where both keys and values are defined as strings.

I. Core Characteristics and Purpose

  • String-Only: The key distinction is that all keys and corresponding values in a `Properties` object **must be strings** (though it inherits the generic signature Hashtable<Object, Object>, the specialized methods enforce strings).
  • Persistence: It includes dedicated methods (`load`, `store`) for reading properties from and writing them to streams (either standard **`.properties` text files** or **XML files**).
  • Defaults Support: It supports a hierarchy of properties via the `defaults` field. If a key is searched for in the main list and not found, the search automatically continues in the chain of default property lists.
  • Thread-Safe: Since it extends the legacy **Hashtable**, `Properties` is inherently **thread-safe** (all core methods are synchronized).

II. Essential I/O and Access Methods

The primary value of the `Properties` class comes from its I/O and key-specific access methods:

Method Action
String **getProperty**(String key) The standard retrieval method. Searches the primary list, and if not found, checks the default property list(s).
Object **setProperty**(String key, String value) The standard insertion method, which is merely a synchronized call to the inherited put(key, value) from Hashtable.
void **load**(InputStream inStream) Reads properties from an input byte stream (for `.properties` files).
void **store**(OutputStream out, String comments) Writes properties to an output byte stream in the standard `.properties` format.
Set<String> **stringPropertyNames**() Returns a `Set` view of all keys (including defaults) guaranteed to be strings. **(Recommended over propertyNames())**

III. Hierarchy and Defaults

When you create a `Properties` object with defaults (e.g., `new Properties(defaultProps)`), retrieval follows a cascade:

  1. Check the primary `Properties` instance.
  2. If the key is missing, check the immediate `defaults` property list.
  3. If the key is still missing, check the defaults of the `defaults` list, and so on.

Java Programming: Utility Classes

Session: The Math Class

Overview of the java.lang.Math Class

The **java.lang.Math** class is a utility class that provides methods for performing basic numeric operations, including trigonometry, exponentiation, logarithms, and rounding. It is crucial to note that all members of the Math class—fields and methods—are **static**, and the class itself is **final**, meaning it cannot be instantiated or subclassed. You access its functions directly using the class name (e.g., Math.sqrt(a)).

Math Class Fields (Constants)

The class defines two widely used mathematical constants:

  • **static double E**: The base of the natural logarithms, approximately 2.71828.
  • **static double PI**: The ratio of a circle's circumference to its diameter, approximately 3.14159.

Key Static Methods

Basic Arithmetic and Comparison

These methods are overloaded to handle primitive types (int, long, float, double):

  • **abs(a)**: Returns the **absolute value** of the argument.
  • **max(a, b)**: Returns the **greater** of the two arguments.
  • **min(a, b)**: Returns the **smaller** of the two arguments.

Exponents and Logarithms

These functions operate on double values:

  • **pow(a, b)**: Returns the value of $a$ raised to the power of $b$ ($a^b$).
  • **sqrt(a)**: Returns the **positive square root** of $a$.
  • **cbrt(a)**: Returns the **cube root** of $a$.
  • **exp(a)**: Returns Euler's number $e$ raised to the power of $a$ ($e^a$).
  • **log(a)**: Returns the **natural logarithm** (base $e$) of $a$.
  • **log10(a)**: Returns the **base 10 logarithm** of $a$.

Rounding and Remainders

  • **ceil(a)**: Returns the smallest integer value greater than or equal to $a$ (rounds up).
  • **floor(a)**: Returns the largest integer value less than or equal to $a$ (rounds down).
  • **round(double a)** / **round(float a)**: Returns the closest $\text{long}$ or $\text{int}$ to the argument.

Trigonometry and Angles (Arguments/Returns in Radians)

Trigonometric functions expect their arguments to be in **radians**.

  • **sin(a)**, **cos(a)**, **tan(a)**: Basic trigonometric functions.
  • **asin(a)**, **acos(a)**, **atan(a)**: Inverse trigonometric functions.
  • **toRadians(angdeg)**: Converts an angle in degrees to radians.
  • **toDegrees(angrad)**: Converts an angle in radians to degrees.

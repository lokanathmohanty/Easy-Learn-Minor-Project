Python - GUIs

In this chapter, you will learn about some popular Python IDEs (Integrated Development Environment), and how to use them for program development.

In scripted mode, Python instructions are saved in a text file with a .py extension. Errors require editing and re-running, which can be tedious. IDEs solve this by providing typing, editing, debugging, and execution in one interface.

IDLE

Python's standard library contains the IDLE module (Integrated Development and Learning Environment). It is designed for learners and provides:

  • Python interactive shell
  • Built-in code editor
  • Syntax highlighting
  • Auto-completion
  • Customizable interface

To write a Python script in IDLE, open a new text editor window from the File menu, enter your code, save it, and run it from the Run menu.

Jupyter Notebook

Jupyter Notebook started as a web interface for IPython and now supports multiple languages (Julia, Python, R). It is a client-server application: the server runs locally, and the browser acts as the client.

Installation:

pip3 install jupyter

Run from command line:

C:\Users\Acer>jupyter notebook

The server runs on localhost:8888, and the browser displays the dashboard. Open a new Python notebook, enter code in cells, and run them interactively.

Jupyter is widely used by data scientists for inline visualizations and can export notebooks as PDF, HTML, or Markdown.

VS Code

Visual Studio Code (VS Code), developed by Microsoft, supports multiple languages including Python. Key features include:

  • Syntax highlighting
  • Autocomplete
  • Debugger
  • Version control integration

Download VS Code from https://code.visualstudio.com/.

Launching VS Code:

C:\test>code .

Install the Python extension from the Extensions Marketplace (Ctrl+Shift+X), then set the Python interpreter (Ctrl+Shift+P).

After creating a Python file, enter your code, save it, and run it from the command prompt or integrated terminal.

PyCharm

PyCharm, developed by JetBrains, is another popular IDE. It includes:

  • Code analysis
  • Graphical debugger
  • Integration with version control
  • Support for Django web development

Download PyCharm from https://www.jetbrains.com/pycharm/download.

On starting a new project, PyCharm creates a virtual environment based on chosen settings. You can add Python scripts, such as main.py, and run them from the Run menu or using Shift+F10.

Output is displayed in the console window.

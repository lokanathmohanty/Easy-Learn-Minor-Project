Next.js Nested Routing 📂➡️📄

What is Nested Routing?

**Nested routing** is the technique of defining routes that are structured hierarchically—routes existing *within* other routes. This structure mirrors the organization of your application's UI, where sections of the interface are contained within larger layouts.

Key Benefits:

  • **Hierarchical Structure:** The URL path directly reflects the organization of your content, making navigation logical.
  • **Code Reusability:** Facilitates the sharing of parent layout components (like a common sidebar or navigation) across all child routes.
  • **Seamless Experience:** Allows for smooth transitions between related pages without unnecessary page reloads, enhancing the user experience.

Implementing Nested Routing in Next.js (App Router)

In Next.js, nested routing is achieved through the **file-system structure** inside the **`/app`** directory. Every time you create a folder within an existing route folder, you create a new nested route segment.

How Folder Structure Maps to Routes:

A route is defined by the hierarchy of folders leading to a **`page.jsx`** (or `page.tsx`) file.

app/
 products/ 
     page.jsx            // Route: /products
     electronics/ 
         page.jsx        // Route: /products/electronics

Creating a Simple Nested Page Example:

To create the route `/about`, you simply create an `about` folder inside the `/app` directory and place the page component file within it.

  • **File Path:** `app/about/page.js`
  • **URL Path:** `http://localhost:3000/about`
// app/about/page.js file
export default function About() {
    return (
        <div>
            <h1>About Us</h1>
            <p>Welcome to the about page!</p>
        </div>
    );
}

Power BI: ArcGIS Map

ArcGIS Map in Power BI provides deep insights through vibrant, interactive maps to reveal patterns and trends. Users can generate maps by signing into ArcGIS Online or by adding latitude and longitude fields. It can visualize data such as population or sales profit by region or country.

Generating an ArcGIS Map

  • Load the dataset (e.g., sample "Sheet1" with columns like Designation, Gross Sales, Latitude, Longitude, Name, Net Sales, Region, Registration ID, Year).
  • Sign in to ArcGIS Online if available, or drag a location field (e.g., Region) to the Location section.
  • Drag Latitude and Longitude columns to their respective sections; set "Don't summarize" for these fields.
  • Add a numeric field like Gross Sales to the Size section to scale bubbles by value (larger bubble represents higher sales).
  • Use map tools such as expanding map controls, searching addresses, and viewing layers to interact with the map.

Customizing ArcGIS Map

  • Base Map: Change background styles (e.g., Dark Gray Canvas) for better visual context.
  • Adding Context: Use Infographics, Reference layers, Buffer/Drive time, and Find Similar features to enrich data understanding.
  • Settings: Access settings for program info, help, and community links.
  • User Account: Manage ArcGIS sign-in and profile access through Power BI interface.

Key Benefits

ArcGIS Map enables precise spatial data visualization and enhances reports and dashboards by uncovering geographic trends and relationships effectively.

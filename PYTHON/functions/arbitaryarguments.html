Python - Arbitrary or Variable-length Arguments

Arbitrary Arguments (*args)

You may want to define a function that is able to accept arbitrary or variable number of arguments. These arguments can be positional or keyword arguments.

  • An argument prefixed with a single asterisk * is used for arbitrary positional arguments.
  • An argument prefixed with two asterisks ** is used for arbitrary keyword arguments.

Arbitrary Arguments Example

# sum of numbers
def add(*args):
    s = 0
    for x in args:
        s = s + x
    return s

result = add(10,20,30,40)
print(result)

result = add(1,2,3)
print(result)

Output:

100
6

The args variable prefixed with * stores all the values passed to it as a tuple. We can loop through its items to process the values.

Required Arguments With Arbitrary Arguments

It is also possible to define functions with required arguments along with variable-length arguments.

Example

# avg of first test and best of following tests
def avg(first, *rest):
    second = max(rest)
    return (first + second) / 2

result = avg(40,30,50,25)
print(result)

Output:

45.0

Arbitrary Keyword Arguments (**kwargs)

If an argument is prefixed with two asterisks **, the function can accept arbitrary keyword arguments. Inside the function, these arguments are stored in a dictionary of key:value pairs.

Example

def addr(**kwargs):
    for k, v in kwargs.items():
        print("{}:{}".format(k, v))

print("pass two keyword args")
addr(Name="John", City="Mumbai")

print("pass four keyword args")
addr(Name="Raam", City="Mumbai", ph_no="9123134567", PIN="400001")

Output:

pass two keyword args
Name:John
City:Mumbai
pass four keyword args
Name:Raam
City:Mumbai
ph_no:9123134567
PIN:400001

Multiple Arguments With Arbitrary Keyword Arguments

When mixing different types of arguments, arbitrary keyword arguments should appear after positional, keyword, and arbitrary positional arguments.

Example

def percent(math, sci, **optional):
    print("maths:", math)
    print("sci:", sci)
    s = math + sci
    for k, v in optional.items():
        print("{}:{}".format(k, v))
        s = s + v
    return s / (len(optional) + 2)

result = percent(math=80, sci=75, Eng=70, Hist=65, Geo=72)
print("percentage:", result)

Output:

maths: 80
sci: 75
Eng:70
Hist:65
Geo:72
percentage: 72.4

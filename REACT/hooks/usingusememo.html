ReactJS - useMemo

The useMemo hook helps improve the performance of React applications by memoizing the result of expensive calculations and reusing them until dependencies change.

Signature

const result = useMemo(expensive_fn, dependency_array);
  • expensive_fn − Function that performs expensive logic and returns output.
  • dependency_array − List of dependencies that control when the calculation runs again.

Example: Summation with useMemo

const limit = 1000;
const sum = useMemo(() => {
   let total = 0;
   for(let i = 1; i <= limit; i++) {
      total += i;
   }
   return total;
}, [limit])

In this example, the summation logic executes only when limit changes. Between renders, the memoized value is reused.

Applying useMemo in a Component

import React, { useState, useEffect, useMemo } from "react";

function Sum() {
   const [currentTime, setCurrentTime] = useState(new Date());
   const [limit, setLimit] = useState(10);

   useEffect(() => {
      const interval = setInterval(() => setCurrentTime(new Date()), 1000);
      return () => clearInterval(interval);
   }, []);

   const sum = useMemo(() => {
      let total = 0;
      for (let i = 1; i <= limit; i++) {
         total += i;
      }
      return total;
   }, [limit]);

   return (
      <div>
         <input value={limit} onChange={e => setLimit(Number(e.target.value))} />
         <div>Sum from 1 to {limit}: <b>{sum}</b></div>
         <div>Time: <b>{currentTime.toLocaleTimeString()}</b></div>
      </div>
   );
}
export default Sum;

Preserving References

Reference types such as arrays, objects, and functions are recreated on each render, even if their values remain the same. useMemo can preserve them to prevent unnecessary re-renders. 

const input = useMemo(() => [1, 1000], []);

Advantages

  • Simple to use API.
  • Improves application performance.
  • Prevents unnecessary recalculations.

Disadvantages

  • Overuse decreases readability.
  • Makes debugging more complex.
  • Requires good understanding of JavaScript references.

Summary

React applications are already optimized, but in certain cases, memoization is required to boost performance. The useMemo hook is useful in those scenarios, but should only be applied when absolutely necessary.

CSS - Attribute Selector Property

CSS attribute selectors provide a powerful mechanism to select HTML elements based on the presence or value of their attributes. Unlike class or ID selectors, attribute selectors enable developers to target elements more dynamically and precisely without altering HTML structure. This is especially useful for styling form elements, links, images, or custom data attributes.

Attribute selectors are always written inside square brackets [], and depending on the operator used, they can match exact values, partial substrings, starting values, or ending values.

Basic Syntax

A simple attribute selector checks if an element contains a specific attribute. If the attribute exists, the rule applies regardless of its value.

Syntax:

[attribute]

Example: Selecting Elements with a Data Attribute

In this example, all elements that contain a data-toggle attribute will be styled, regardless of what value it holds.

Example Code:

[data-toggle] {
   background: yellow;
   color: red;
}

When applied to HTML, it highlights any element containing the attribute data-toggle: 

<div data-toggle="yes">Styled Div</div>
<p data-toggle="no">Styled Paragraph</p>

Types of Attribute Selectors

  • [attribute] – Selects elements with the given attribute.
  • [attribute="value"] – Selects elements with an exact attribute value.
  • [attribute*="value"] – Matches attribute values containing a substring.
  • [attribute^="value"] – Matches attribute values starting with a string.
  • [attribute$="value"] – Matches attribute values ending with a string.
  • [attribute|="value"] – Matches attribute values starting with value followed by a hyphen.
  • [attribute~="value"] – Matches attribute values containing a word.

Practical Example: Attribute Equals Selector

Suppose we want to style only elements where data-toggle is explicitly set to yes: 

[data-toggle="yes"] {
   background: yellow;
   color: red;
}
      
<div data-toggle="yes">Styled</div>
<div data-toggle="no">Not Styled</div>

Example: Attribute Contains Selector

The * operator is used to select elements where the attribute contains a substring. For example, images whose src contains the word images. 

[src*="images"] {
   border: 2px dashed red;
}
      
<img src="/css/images/logo.png" alt="Logo">

Example: Attribute Starts With Selector

This selector matches attribute values that begin with a specific string. It is commonly used for URLs. 

[href^="https"] {
   color: red;
   text-decoration: none;
}
      
<a href="https://example.com">Secure Link</a>
<a href="http://example.com">Non-Secure Link</a>

Example: Attribute Ends With Selector

This selector matches elements whose attribute values end with a specific string. A common use case is selecting image formats like .png. 

[src$=".png"] {
   border: 2px solid green;
}
      
<img src="logo.png" alt="PNG Logo">

Example: Attribute with Hyphen Selector

This selector is useful for language attributes where subcodes are separated by a hyphen. 

[lang|="en"] {
   color: blue;
}
      
<div lang="en-US">English Content</div>
<div lang="fr">French Content</div>

Example: Attribute Contains Word Selector

The ~ operator matches attributes that contain a given word. It is often used with class names. 

[class~="highlight"] {
   background-color: yellow;
}
      
<div class="highlight">Highlighted</div>
<div class="highlighted">Not A Match</div>

Multiple Attribute Selectors

You can also combine multiple attribute conditions to refine selections. This is useful when elements need to meet more than one criteria. 

a[href$=".htm"][target="_blank"] {
   color: purple;
}
      
<a href="page.htm" target="_blank">Styled Link</a>
<a href="page.htm">Not Styled</a>

Attribute Selectors for Form Inputs

Attribute selectors are often used in forms to apply styles based on input types, placeholders, or names. This allows consistent styling across different form fields without manually assigning classes. 

input[type="text"] {
   border: 1px solid blue;
}
input[placeholder="Password"] {
   border: 1px solid red;
}
      
<input type="text" placeholder="Username">
<input type="password" placeholder="Password">

Conclusion

CSS attribute selectors make styling more flexible and powerful by enabling developers to target elements dynamically based on attributes and their values. They are particularly useful for forms, links, localization, and when working with dynamically generated content. Combined with other CSS combinators, attribute selectors unlock advanced control over styling.

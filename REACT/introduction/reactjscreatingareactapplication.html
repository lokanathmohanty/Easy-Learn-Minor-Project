ReactJS - Creating a React Application

React library can be used in both simple and complex applications. Simple applications normally include the React library in a script section, while complex applications require splitting the code into multiple files and organizing it into a standard structure.

React toolchain provides pre-defined structure to bootstrap applications, but developers are also free to use their own project structure.

Ways to Create a React Application

  • Simple application using CDN
  • Complex application using React Create App CLI
  • Complex application using customized methods
  • Using Rollup bundler
  • Using Parcel bundler

Using Rollup Bundler

Rollup is a small and fast JavaScript bundler. Below are the steps to create a React application using Rollup:

  • Initialize a new project with npm init -y
  • Install React, ReactDOM, Babel, and Rollup dependencies
  • Create a .babelrc file for Babel configuration
  • Create a rollup.config.js file for Rollup bundler setup
  • Define entry points and scripts in package.json
  • Build source code inside src folder
  • Create a root component and render it
  • Run the application using npm start

Using Parcel Bundler

Parcel is a fast bundler with zero configuration. It only requires the entry point of the application and handles dependencies automatically.

  • Install Parcel globally with npm install -g parcel-bundler
  • Initialize project with npm init -y
  • Install React, ReactDOM, and Babel dependencies
  • Create a .babelrc configuration file
  • Update package.json with start and build scripts
  • Place source code in src folder
  • Create entry file public/index.html
  • Run the app with npm start

Python - Interrupting Threads

Interrupting a thread in Python requires coordination since Python does not provide a direct way to forcefully terminate threads. Common approaches use threading.Event or a custom flag to signal the thread to stop.

Interrupting Using Event Object

An Event object acts as a signal that, when set, instructs threads to stop their work loops gracefully.

from time import sleep
from threading import Thread, Event

class MyThread(Thread):
    def __init__(self, event):
        super().__init__()
        self.event = event

    def run(self):
        i = 0
        while not self.event.is_set():
            i += 1
            print('Child thread running...', i)
            sleep(0.5)
        print('Child Thread Interrupted')

event = Event()
thread = MyThread(event)
thread.start()

sleep(3)
print('Main thread stopping child thread')
event.set()

thread.join()

Output:

Child thread running... 1
Child thread running... 2
Child thread running... 3
Main thread stopping child thread
Child Thread Interrupted

Interrupting Using Thread Flag

A thread can monitor a custom flag attribute to decide when to stop execution.

import threading
import time

def worker():
    t = threading.current_thread()
    while getattr(t, "do_run", True):
        print("working on a task")
        time.sleep(1)
    print("Stopping the Thread")

t = threading.Thread(target=worker)
t.start()

time.sleep(5)
t.do_run = False

Output:

working on a task
working on a task
working on a task
working on a task
working on a task
Stopping the Thread

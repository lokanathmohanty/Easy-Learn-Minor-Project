ReactJS - Component Life Cycle Using React Hooks

Introduction

React Hooks provides a special Hook, useEffect(), to execute certain functionality during the life cycle of the component. useEffect() combines componentDidMount, componentDidUpdate, and componentWillUnmount into a single API.

useEffect API


useEffect(
   <executeFn>, 
   <values>
);
  • executeFn − Function to execute when an effect occurs, with an optional return function for cleanup.
  • values − Array of values the effect depends on. The function executes only when these values change.

Adding useEffect in Clock App

Steps to update the react-clock-hook-app using useEffect:

  • Open src/components/Clock.js.
  • Import useEffect along with useState.
  • Use useEffect to set an interval and return a cleanup function to clear it.

import React, { useState, useEffect } from 'react';

function Clock() {
   const [currentDateTime, setCurrentDateTime] = useState(new Date());

   useEffect(() => {
      let setTime = () => {
         console.log("setTime is called");
         setCurrentDateTime(new Date());
      }
      let interval = setInterval(setTime, 1000);
      return () => clearInterval(interval);
   }, []);

   return (
      <div>
         <p>The current time is {currentDateTime.toString()}</p>
      </div>
   );
}
export default Clock;

Removing Clock After 5 Seconds

Edit index.js to remove the Clock from the DOM using setTimeout:


import React from 'react';
import ReactDOM from 'react-dom';
import Clock from './components/Clock';

ReactDOM.render(
   <React.StrictMode>
      <Clock />
   </React.StrictMode>,
   document.getElementById('root')
);

setTimeout(() => {
   ReactDOM.render(
      <React.StrictMode>
         <div><p>Clock is removed from the DOM.</p></div>
      </React.StrictMode>,
      document.getElementById('root')
   );
}, 5000);

The clock will run for 5 seconds and then be removed from the DOM. The cleanup function ensures clearInterval() is called properly.

React Children Property (Containment)

React allows arbitrary children user interface content to be included inside a component. This is accessed via props.children. Adding children inside the component is called containment.

Example: A RichTextMessage component can render whatever children are passed to it.

RichTextMessage Component


import React from 'react';

class RichTextMessage extends React.Component {
   constructor(props) {
      super(props);
   }
   render() {
      return (
         <div>{this.props.children}</div>
      )
   }
}
export default RichTextMessage;

Using RichTextMessage


import React from 'react';
import ReactDOM from 'react-dom';
import RichTextMessage from './components/RichTextMessage';

ReactDOM.render(
   <React.StrictMode>
      <RichTextMessage>
         <h1>Containment is really a cool feature.</h1>
      </RichTextMessage>
   </React.StrictMode>,
   document.getElementById('root')
);

Browser Output


<div id="root">
   <div>
      <div>
         <h1>Containment is really a cool feature.</h1>
      </div>
   </div>
</div>

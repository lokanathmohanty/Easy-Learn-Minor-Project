R - Packages

R packages are collections of R functions, compiled code, and sample data stored under directories called "library" in the R environment. When R is installed, a set of default packages are installed and loaded automatically, while others must be installed and loaded explicitly when needed for specific tasks.

Check Available R Packages

To get library locations containing R packages:

.libPaths()

Example output:

[1] "/usr/local/lib/R/library"
[2] "C:/Program Files/R/R-x.x.x/library"

To list all installed packages:

library()

This outputs all installed packages in the default library paths.

To view all packages currently loaded in the environment:

search()

Example output snippet:

[1] ".GlobalEnv"        "package:stats"     "package:graphics" 
[4] "package:grDevices" "package:utils"     "package:datasets" 
[7] "package:methods"   "Autoloads"         "package:base"

Install a New Package

There are two ways to add new packages to R:

  1. Directly install from CRAN:
# Replace "PackageName" with the actual package name
install.packages("PackageName")

# Example installing "XML" package
install.packages("XML")
  1. Manual installation from a downloaded package file:
# Replace the file path with the actual file location
install.packages("path/to/package.zip", repos = NULL, type = "source")

# Example manual install of "XML"
install.packages("E:/XML_3.98-1.3.zip", repos = NULL, type = "source")

Load Package to Current Environment

Before using an installed package, it must be loaded:

# Load package from default library paths
library("PackageName")

# Load package from specific library path
library("PackageName", lib.loc = "path/to/library")

Example:

library("XML")

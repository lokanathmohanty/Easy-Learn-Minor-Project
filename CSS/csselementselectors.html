CSS - Element Selectors

A CSS element selector is the most basic type of selector. It targets HTML elements directly by using their tag name. This means if you write p in your CSS, it will apply styles to all <p> elements on the page.

Syntax

element_name {
  /* property: value; */
  color: red;
}

Example 1: Setting Background Color for Paragraphs

In this example, we set the background color and text color for all <p> elements in the document. 

p {
  background-color: #04af2f;
  color: white;
}

Example 2: Adding Border to Divs

Here, we apply a border and padding to all <div> elements using the element selector. 

div {
  border: 3px solid #2a9d8f;
  padding: 10px;
}

Example 3: Setting Font for List Items

The following example shows how to use the element selector to style <li> elements by changing their font size and family. 

li {
  font-size: 18px;
  font-family: Verdana, sans-serif;
}

Key Notes

  • Element selectors are simple and apply styles to all occurrences of an element.
  • They are not specific; they apply broadly across the entire document.
  • For more precise control, combine them with class, id, or pseudo-class selectors.

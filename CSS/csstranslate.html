CSS - translate Property

The translate property in CSS allows you to move an element along the X-axis (horizontal), Y-axis (vertical), and Z-axis (depth). It is very similar to the transform: translate() function, but with the difference that translate as a property directly supports the Z-axis as well.

Syntax

The basic syntax looks like this:

translate: x-axis y-axis z-axis | none;

Possible Values

  • none → No translation is applied.
  • x-axis → Moves the element horizontally. If one value is specified, it represents translation along the X-axis.
  • y-axis → Moves the element vertically. To only move on Y-axis, set the first value to 0.
  • z-axis → Moves the element closer or farther from the screen. To only move on Z-axis, set the first two values to 0.

Values can be specified in <length> units (px, em, rem, etc.) or <percentage>.

Applies To

The translate property applies to all transformable elements (elements that can be transformed using CSS).

Example 1: translate with none

In this example, the box does not move because the translate property is set to none:

<div class="box"></div>

.box:hover {
  translate: none;
}

Example 2: translate on X-axis

Using a single value moves an element horizontally.

.box1:hover {
  translate: 20px;
}

.box2:hover {
  translate: -15%;
}

Example 3: translate on Y-axis

To move only vertically, the first value (x-axis) must be 0.

.box1:hover {
  translate: 0px 30px;
}

.box2:hover {
  translate: 0 -20%;
}

Example 4: translate on Z-axis

Adding a third value moves the element closer or farther from the screen.

.box1:hover {
  translate: 0 0 15px;
}

.box2:hover {
  translate: 0 0 -10px;
}

Example 5: translate on both X and Y

You can use two values to move an element both horizontally and vertically:

.box1:hover {
  translate: 15px 15px;
}

.box2:hover {
  translate: -10% -15%;
}

Example 6: translate on Y and Z

To move along Y and Z, set the X-axis value to 0:

.box1:hover {
  translate: 0px 15px 20px;
}

.box2:hover {
  translate: 0 -10% 10px;
}

Example 7: translate on X and Z

To move along X and Z, set the Y-axis value to 0:

.box1:hover {
  translate: 20px 0 15px;
}

.box2:hover {
  translate: -15% 0 10px;
}

Example 8: translate on X, Y, and Z

To move in all directions, specify three values:

.box1:hover {
  translate: 15px 20px 15px;
}

.box2:hover {
  translate: -10% -15px 10px;
}

Supported Browsers

  • Chrome → 104+
  • Edge → 104+
  • Firefox → 72+
  • Safari → 14.1+
  • Opera → 90+

Practical Use Cases

  • Moving buttons slightly on hover for visual feedback.
  • Creating 3D card flip effects using Z-axis translation.
  • Animating modal popups by sliding them from off-screen into view.
  • Building carousel sliders with translate for smooth transitions.

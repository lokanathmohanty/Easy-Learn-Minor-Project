Java Arithmetic Operators

Session Content

Java arithmetic operators perform basic mathematical operations like addition, subtraction, multiplication, division, and modulus. These operators work with numeric types such as int, float, double, and long. Operator precedence follows standard math rules, with multiplication and division evaluated before addition and subtraction.

  • + (Addition): Adds two values
  • - (Subtraction): Subtracts the right operand from the left
  • * (Multiplication): Multiplies two values
  • / (Division): Divides the left operand by the right
  • % (Modulus): Returns the remainder of division
  • ++ (Increment): Increases the value by 1
  • -- (Decrement): Decreases the value by 1

Assuming: A = 10, B = 20

  • A + B will give 30
  • A - B will give -10
  • A * B will give 200
  • B / A will give 2
  • B % A will give 0
  • B++ gives 21
  • B-- gives 19

Example: Arithmetic Operators Usage

The following Java program demonstrates arithmetic operations:

public class Test {
   public static void main(String args[]) {
      int a = 10;
      int b = 20;
      System.out.println("a + b = " + (a + b));
      System.out.println("a - b = " + (a - b));
      System.out.println("a * b = " + (a * b));
      System.out.println("b / a = " + (b / a));
   }
}
  • a + b = 30
  • a - b = -10
  • a * b = 200
  • b / a = 2

Example: Modulus Operator

This example shows the modulus operator (%) usage with three variables:

public class Test {
   public static void main(String args[]) {
      int a = 10;
      int b = 20;
      int c = 25;
      System.out.println("b % a = " + (b % a));
      System.out.println("c % a = " + (c % a));
   }
}
  • b % a = 0
  • c % a = 5

Example: Increment and Decrement Operators

This example demonstrates post-increment, pre-increment, post-decrement, and pre-decrement operators:

public class Test {
   public static void main(String args[]) {
      int a = 10;
      int d = 25;
      System.out.println("a++ = " + (a++));
      System.out.println("a-- = " + (a--));
      System.out.println("d++ = " + (d++));
      System.out.println("++d = " + (++d));
   }
}
  • a++ = 10
  • a-- = 11
  • d++ = 25
  • ++d = 27

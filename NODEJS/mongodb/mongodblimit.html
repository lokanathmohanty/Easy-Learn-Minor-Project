Node.js - MongoDB Limit

Overview

The limit() method in MongoDB restricts the number of documents returned by a find() query. It behaves similarly to SQL’s LIMIT clause.

Basic Usage

collection.find(query).limit(number)

The number argument specifies max documents to return; omitting it means no limit.

Example: Limit Results

Retrieve documents from orders collection where numPurchased >= 10, limiting output to 1 document. 

const { MongoClient } = require('mongodb');

async function main() {
  const uri = "mongodb://localhost:27017/";
  const client = new MongoClient(uri);

  try {
    await client.connect();
    await limitDocs(client, "mydb", "orders");
  } finally {
    await client.close();
  }
}

async function limitDocs(client, dbName, collectionName) {
  const query = { numPurchased: { $gte: 10 } };
  const result = await client.db(dbName).collection(collectionName)
                            .find(query)
                            .limit(1)
                            .toArray();
  console.log(JSON.stringify(result));
}

main().catch(console.error);

Example Output

[
  {
    "_id": "...",
    "orderId": 201,
    "custid": 301,
    "prodId": 100,
    "numPurchased": 20
  }
]

Skipping Documents

Use skip() to omit a number of documents from the result set. 

collection.find(query).limit(x).skip(y)

This returns x documents starting after skipping y documents.

Example: Retrieve Second Document

async function limitDocs(client, dbName, collectionName) {
  const query = { numPurchased: { $gte: 10 } };
  const result = await client.db(dbName).collection(collectionName)
                            .find(query)
                            .limit(1)
                            .skip(1)
                            .toArray();
  console.log(JSON.stringify(result));
}

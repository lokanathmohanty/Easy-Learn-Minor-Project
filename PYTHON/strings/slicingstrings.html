Python Slicing Strings

Python String slicing is a way of creating a sub-string from a given string. In this process, we extract a portion or piece of a string. Usually, we use the slice operator [ : ] to perform slicing on a Python String. Before proceeding with string slicing let's understand string indexing.

Python String Indexing

In Python, a string is an ordered sequence of Unicode characters. Each character in the string has a unique index in the sequence. The index starts with 0. For example, if var = "HELLO PYTHON", then var[0] is H, and var[6] is P. Accessing beyond the range raises IndexError.

Python String Negative & Positive Indexing

Python allows both positive and negative indexing. Positive indexing starts from left (0 → n−1), negative indexing starts from right (−1 → −n). For example, in "HELLO PYTHON", H is at index 0 (positive) and -12 (negative).

String Immutability

Strings are immutable in Python. You can retrieve characters using their index, but you cannot modify them in-place. Attempting to do so raises TypeError.

Python String Slicing

Slicing uses the operator : with syntax:

substr = var[x:y]

This extracts characters from index x to y−1.

Slicing with Negative Indexing

You can also use negative indexes for slicing. For example, var[-9:-4] gives the same substring as var[3:8].

Default Values in Slicing

  • If the first index is omitted, it defaults to 0.
  • If the second index is omitted, it defaults to the end of the string.
  • If both are omitted, the slice returns the full string.

Example with Defaults

  • var[:5] → substring from start to index 4.
  • var[6:] → substring from index 6 to end.
  • var[:] → entire string.

Invalid Ranges

If the left operand is greater than the right operand, Python does not raise an error but returns an empty string.

Return Type of Slicing

Slicing always returns a new string. You can perform further operations like concatenation or slicing on the result.

Java - Compact Number Formatting (Java 12+)

Introduction to Compact Number Formatting

Compact Number Formatting, introduced in **Java 12**, provides a localized and concise way to format large numbers. This is extremely useful for displaying metrics in dashboards, user interfaces, or reports where space is limited and readability is prioritized (e.g., displaying **1,000 as 1K** or **1,000,000 as 1M**).

This feature leverages the **Locale** information to correctly format the suffixes (like 'K', 'M', 'B' in English, or equivalent terms in other languages).

Creating a CompactNumberFormat Instance

The formatter instance is obtained via the static getCompactNumberInstance() method of the abstract **NumberFormat** class, requiring two main arguments:

  1. Locale: Specifies the localization rules for the format.
  2. NumberFormat.Style: Defines the desired output style.

Formatting Styles

There are two primary styles available for compact formatting:

  • NumberFormat.Style.SHORT: Uses abbreviated suffixes (e.g., 1K, 1M). 
    NumberFormat formatter = NumberFormat.getCompactNumberInstance(Locale.US, NumberFormat.Style.SHORT);
  • NumberFormat.Style.LONG: Uses full, localized words (e.g., 1 thousand, 1 million). 
    NumberFormat formatter = NumberFormat.getCompactNumberInstance(Locale.US, NumberFormat.Style.LONG);

Handling Fraction Digits

By default, the compact formatter often rounds the number to an integer and suppresses fraction digits. You can control the decimal precision using standard NumberFormat methods:

// Sets the minimum number of decimal places to display
formatter.setMinimumFractionDigits(2); 

// Example: 10012 formatted with 2 fraction digits will be "10.01K"

Example: Short vs. Long Formats

Demonstration of formatting 1000, 1,000,000, and 1,000,000,000 using US Locale.

// --- Short Formats ---
formatterShort.format(1000); // 1K
formatterShort.format(1000 * 1000); // 1M
formatterShort.format(1000 * 1000 * 1000); // 1B

// --- Long Formats ---
formatterLong.format(1000); // 1 thousand
formatterLong.format(1000 * 1000); // 1 million
formatterLong.format(1000 * 1000 * 1000); // 1 billion

Python Multiple Inheritance

Multiple inheritance allows a class to inherit attributes and methods from more than one parent class. This helps combine features from multiple classes into a single child class.

The method resolution order (MRO) determines how Python resolves method names when multiple parents share the same method name.

Example

class Father:
    def skill1(self):
        print("Father's skill: Gardening")

class Mother:
    def skill2(self):
        print("Mother's skill: Cooking")

class Child(Father, Mother):
    pass

c = Child()
c.skill1()  # Father's skill: Gardening
c.skill2()  # Mother's skill: Cooking

Method Resolution Order (MRO)

MRO defines the order in which base classes are searched when executing a method. When methods have the same name in multiple parent classes, Python follows MRO to decide which method to call.

You can check MRO with ClassName.mro() or ClassName.__mro__.

MRO Example

print(Child.mro())
# Output: [Child, Father, Mother, object]

MRO in Action

If two parents have the same method name, Python uses MRO order to determine which method runs.

Method Conflict Example

class Father:
    def skill(self):
        print("Father's skill: Gardening")

class Mother:
    def skill(self):
        print("Mother's skill: Cooking")

class Child(Father, Mother):
    pass

c = Child()
c.skill()  # Output: Father's skill: Gardening

Using super() in Multiple Inheritance

super() allows child classes to call methods from parent classes following MRO. This enables method chaining across multiple inheritance.

super() Example

class A:
    def show(self):
        print("Class A")

class B(A):
    def show(self):
        print("Class B")
        super().show()

class C(A):
    def show(self):
        print("Class C")
        super().show()

class D(B, C):
    def show(self):
        print("Class D")
        super().show()

d = D()
d.show()
# Output:
# Class D
# Class B
# Class C
# Class A

Diamond Problem

This occurs when two parent classes inherit the same base class and a child class inherits both parents.

Python resolves this ambiguity using MRO.

Diamond Problem Example

class A:
    def show(self):
        print("Class A")

class B(A):
    def show(self):
        print("Class B")

class C(A):
    def show(self):
        print("Class C")

class D(B, C):
    pass

d = D()
d.show()  # Output: Class B

Pros and Cons of Multiple Inheritance

  • Pros: Code reuse, modular design, combining functionalities.
  • Cons: Complexity, ambiguity, diamond problem, difficult maintenance.

ReactJS - Managing State using Flux

Previous | Quiz | Next

One of the important features in a front-end application is state management. React has its own state management technique at the component level, but one component’s state cannot be directly accessed by another, even in parent/child relationships. To solve this, third-party libraries like Redux and MobX are commonly used.

Flux is another technique introduced by Facebook to manage application state effectively using a unidirectional data flow. Let’s explore Flux and how to use it.

Managing State Using Flux

Flux uses four distinct parts:

Store

  • Holds all business data.
  • Updates itself with data from the dispatcher.
  • Emits change events to notify views when data changes.

Action

Actions represent events with necessary data. A view creates an action and sends it to the dispatcher. Example:

{
   actionType: "add",
   data: {
      name: "Peter"
   }
}

Dispatcher

Receives actions and forwards them to all registered stores for processing.

View

Creates actions based on user interactions, sends them to the dispatcher, and listens for store updates to re-render.

Flux Workflow

  1. User interacts with the view.
  2. View creates and sends an action to the dispatcher.
  3. Dispatcher forwards the action to registered stores.
  4. Stores update their data and emit change events.
  5. Views listening for changes update themselves with new data.

Applying Flux

Steps to implement Flux in a React application:

1. Setup Project

create-react-app myapp
cd myapp
npm start
npm install flux --save

2. Create Dispatcher

// src/Flux/Dispatcher.js
import { Dispatcher } from "flux";
export default new Dispatcher();

3. Create Actions

// src/Flux/UserActions.js
import dispatcher from "./Dispatcher";

export const USER_ACTIONS = {
   ADD: 'addUser'
};

export function addUser(userName) {
   dispatcher.dispatch({
      type: USER_ACTIONS.ADD,
      value: { name: userName }
   });
}

4. Create Store

// src/Flux/UserStore.js
import dispatcher from "./Dispatcher";
import { EventEmitter } from "events";
import * as UserActions from "./UserActions";

class UserStore extends EventEmitter {
   constructor() {
      super();
      this.users = [];
   }
   handleActions(action) {
      switch (action.type) {
         case UserActions.USER_ACTIONS.ADD:
            this.users.push(action.value);
            this.emit("storeUpdated");
            break;
         default:
      }
   }
   getUsers() {
      return this.users;
   }
}

const userStore = new UserStore();
dispatcher.register(userStore.handleActions.bind(userStore));
export default userStore;

5. Create User Input Component

// src/Flux/UserInput.js
import React from "react";
import * as UserActions from "./UserActions";

export default class UserInput extends React.Component {
   constructor(props) {
      super(props);
      this.state = { username: '' };
   }
   onButtonClick = () => {
      UserActions.addUser(this.state.username);
   };
   render() {
      return (
         <div>
            <input name="username" 
               onChange={(e) => this.setState({username: e.target.value})}/>
            <button onClick={this.onButtonClick}>Add user</button>
         </div>
      );
   }
}

6. Create User List Component

// src/Flux/UserList.js
import React from "react";
import UserStore from "./UserStore";

export default class UserList extends React.Component {
   constructor(props) {
      super(props);
      this.state = { users: UserStore.getUsers() };
   }
   componentDidMount() {
      UserStore.on("storeUpdated", this.updateUserList);
   }
   componentWillUnmount() {
      UserStore.removeListener("storeUpdated", this.updateUserList);
   }
   updateUserList = () => {
      this.setState({ users: UserStore.getUsers() });
   };
   render() {
      return (
         <ul>
            {this.state.users.map((u, idx) => <li key={idx}>{u.name}</li>)}
         </ul>
      );
   }
}

7. Update App.js

// src/App.js
import './App.css'
import UserInput from './Flux/UserInput';
import UserList from './Flux/UserList';

function App() {
   return (
      <div className="container">
         <UserInput />
         <UserList />
      </div>
   );
}
export default App;

Summary

Flux provides a predictable and structured way to manage state in React applications using unidirectional data flow. With actions, dispatcher, stores, and views, data consistency and UI synchronization become much easier to maintain.

CSS - Pseudo Elements

Content

CSS pseudo-elements are used to style specific parts of an element without modifying the actual HTML structure. They allow developers to create effects like styling the first letter, the first line, placeholders, and even inserting content before or after elements.

Pseudo-elements are written with a double colon :: followed by the element name. They are extremely useful for adding decorative styles and enhancing user experience without extra HTML.

Common pseudo-elements include:

  • ::before – Inserts content before an element.
  • ::after – Inserts content after an element.
  • ::first-letter – Styles the first letter of text.
  • ::first-line – Styles the first line of text.
  • ::placeholder – Styles placeholder text in inputs.
  • ::selection – Styles user-selected text.

By combining pseudo-elements with selectors and pseudo-classes, developers can create powerful and elegant designs with minimal markup. For example, p:hover::first-letter styles the first letter only when the paragraph is hovered.

Example: ::before and ::after

The following example demonstrates how to insert text before and after a paragraph using pseudo-elements. This technique is often used to add icons, labels, or decorative elements without adding extra HTML tags. 

selector::before {
    content: "Note: ";
    font-weight: bold;
}

selector::after {
    content: " ✔";
    color: green;
}

Example: ::first-letter

The ::first-letter pseudo-element is commonly used in typography to create "drop caps" at the start of paragraphs, giving a magazine-style appearance. 

p::first-letter {
    font-size: 2em;
    color: darkred;
    font-style: italic;
}

Example: ::selection

The ::selection pseudo-element allows you to style the part of text that a user highlights with their mouse or keyboard. This enhances interactivity and improves readability. 

.highlight::selection {
    color: yellow;
    background: brown;
}

Extra Notes

Not all pseudo-elements are supported across every browser, so it’s important to check compatibility before using them in production. Also, while ::before and ::after are very versatile, they require the content property to work.

Using pseudo-elements effectively can reduce the need for extra HTML elements, keeping code clean and semantic. They also make it easier to separate design from structure, which aligns with best practices in web development.

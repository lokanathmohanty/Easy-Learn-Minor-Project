.NET Core - Portable Class Libraries (PCL) and .NET Standard

The **Portable Class Library (PCL)** project type was historically crucial for creating managed assemblies that could run across multiple **.NET Framework** platforms (e.g., Windows, Windows Phone). The need for PCL arose due to incompatibilities between different project types, specifically the difficulty in getting the **Console App's** (then .xproj) build system to reference the **UWP App's** (.csproj) system.

PCL and the modern **.NET Standard Library** address this by defining a unified set of APIs that multiple platforms can implement, allowing a single library to be shared across many projects, reducing development and testing time.

Creating and Retargeting the Portable Library

To create a shareable library that works with both the Console App and the UWP App, we replace the previous class library with a PCL project that is then converted to target the **.NET Standard**:

  1. Remove the previous class library project (UtilityLibrary) from the solution and delete its folder from the disk.
  2. Add a new project: Select **Visual C# → Windows** in the left pane, and choose **Class Library (Portable)** in the middle pane.
  3. Name the project **StringLibrary** and click **OK**.
  4. In the next dialog, select the desired **target frameworks** (e.g., Windows Universal and ASP.NET Core).
  5. To ensure maximum compatibility, right-click the **StringLibrary** project, select **Properties**, and click **Target .NET Platform Standard**. Confirm this change.

The resulting project now uses a .csproj file, making it compatible with the UWP app, while simultaneously targeting the unified **.NET Standard** API set.

Implementing and Consuming the Shared Code

StringLib.cs Implementation

Add a new class named StringLib.cs to the StringLibrary project and include the same extension methods for checking the first character of a string (uppercase, lowercase, or numeric):

using System; 
using System.Collections.Generic; 
using System.Linq; 
using System.Text; 
using System.Threading.Tasks; 
  
namespace StringLibrary { 
   public static class StringLib { 
      public static bool StartsWithUpper(this String str) { 
         if (String.IsNullOrWhiteSpace(str)) 
            return false; 
         Char ch = str[0]; 
         return Char.IsUpper(ch); 
      } 
      // ... StartsWithLower and StartsWithNumber implementations follow ...
   } 
}

Adding Reference to Console App

Once the library builds successfully, add a reference to it in your Console application (FirstApp) just as before:

  1. Right-click on **References** in the **FirstApp** project.
  2. Select **Add Reference**.
  3. Select the **StringLibrary** project and click **OK**.

The console application can now consume the portable library, and the same library can be referenced and used within your UWP application, demonstrating the cross-platform portability benefit.

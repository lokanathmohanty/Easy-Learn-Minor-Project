C - Hello World

Writing a "Hello World" program is the traditional first step for anyone learning a new programming language. In this session, you will learn how to write, compile, and run a simple Hello World program in C.

Before beginning, ensure you have a C programming environment set up with a compiler such as GCC, a text editor, and optionally an IDE like CodeBlocks.

Example: Hello World Program

Write the following code into a file named hello.c using your text editor:

#include <stdio.h>

int main() {
   /* my first program in C */
   printf("Hello World! \n");
   return 0;
}

This program prints "Hello World!" to the console.

Step-by-Step Program Execution

Step 1: The #include <stdio.h> directive imports the standard input/output library needed for printf().

Step 2: The main() function is the entry point of the program. Inside it, printf() outputs the Hello World string.

Step 3: The program ends with the return 0; statement indicating successful completion.

Compiling and Running the Program

To compile the program, open a terminal/command prompt in the folder containing hello.c and enter:

gcc -c hello.c -o hello.o
gcc -o hello.exe hello.o

This produces an executable hello.exe (Windows) or a.out (Linux).

Run the program:

hello.exe   (Windows)
./a.out      (Linux)

The output should display:

Hello World!

Using an IDE (CodeBlocks)

CodeBlocks is a popular IDE to write, build, debug, and run C programs.

After installing CodeBlocks, create a new file, enter the Hello World code, save as hello.c, then use the Build and Run command (F9) to compile and execute.

The Build Log window shows compilation status, and the output appears in a console window.

CodeBlocks helps avoid tedious command-line compiling by providing an integrated environment.

Common Errors

Missing a semicolon ; at the end of statements is a common error that leads to compilation failure with error messages indicating the location.

Always check your Build Log for errors and fix them before running the program.

JavaScript - Display Objects

Displaying Objects in JavaScript

There are different ways to display objects in JavaScript. Using the console.log() method, we can display the object in the web console. Sometimes developers require to display the object properties and their values in the HTML or for debugging the code.

When you print the object directly, it shows [object Object] instead of its properties, as demonstrated below.

Example: Printing Object Directly


const fruit = {
  name: "Banana",
  price: 100,
}
document.getElementById("output").innerHTML += fruit;

Output:

The object is: [object Object]

To properly display objects, we can use several approaches:

  • Accessing the object properties
  • Using the JSON.stringify() method
  • Using the Object.entries() method
  • Using the for...in loop

Accessing the Object Properties

You can use dot notation or square bracket notation to access and display property values individually. 


const fruit = {
  name: "Banana",
  price: 100,
}

const fruitName = fruit.name;
const fruitPrice = fruit["price"];

document.getElementById("output").innerHTML = 
  "The price of the " + fruitName + " is: " + fruitPrice;

Output:

The price of the Banana is: 100

Using the JSON.stringify() Method

The JSON.stringify() method converts an object into a string, making it easier to display dynamic or nested objects. 


const fruit = {
  name: "Banana",
  price: 100,
}

document.getElementById("output").innerHTML += JSON.stringify(fruit);

Output:

The fruit object is {"name":"Banana","price":100}

Using the Object.entries() Method

The Object.entries() method returns a 2D array of key-value pairs. You can loop through it to display each property and value. 


const numbers = {
  num1: 10,
  num2: 20,
  num3: 30,
  num4: 40,
}

for (const [key, value] of Object.entries(numbers)) {
  document.getElementById("output").innerHTML += key + ": " + value + "<br>";
}

Output:

  • num1: 10
  • num2: 20
  • num3: 30
  • num4: 40

Using the for...in Loop

The for...in loop allows you to iterate through each property of the object and print its key-value pair. 


const languages = {
  language1: "JavaScript",
  language2: "Python",
  language3: "Java",
  language4: "HTML",
}

for (const key in languages) {
  document.getElementById("output").innerHTML += 
    key + ": " + languages[key] + "<br>";
}

Output:

  • language1: JavaScript
  • language2: Python
  • language3: Java
  • language4: HTML

Conclusion

The best way to display an object is by using the JSON.stringify() method, as it converts the object into a flat string and works with nested objects. Other methods are useful for custom or detailed property display.

Python - break Statement

The break statement in Python is used to terminate the current loop and resume execution at the next statement. It is commonly used when an external condition requires an immediate exit from a loop.

The break statement can be used with both for and while loops. In the case of nested loops, it stops execution of the innermost loop.

Syntax of break Statement

looping statement:
   condition check:
      break

break Statement with for Loop

When used inside a for loop, the break statement stops the loop before it completes all iterations. 

for letter in 'Python':    
   if letter == 'h':
      break
   print("Current Letter:", letter)
print("Good bye!")

Output:

Current Letter: P
Current Letter: y
Current Letter: t
Good bye!

break Statement with while Loop

Similarly, the break statement can stop a while loop once a condition becomes true. 

var = 10                   
while var > 0:              
   print("Current variable value:", var)
   var = var - 1
   if var == 5:
      break

print("Good bye!")

Output:

Current variable value: 10
Current variable value: 9
Current variable value: 8
Current variable value: 7
Current variable value: 6
Good bye!

break Statement with Nested Loops

In nested loops, break affects only the loop where it is placed:

  • If used in the inner loop, only the inner loop terminates.
  • If used in the outer loop, both outer and inner loops terminate.
no = 33
numbers = [11, 33, 55, 39, 55, 75, 37, 21, 23, 41, 13]

for num in numbers:
   if num == no:
      print("number found in list")
      break
else:
   print("number not found in list")

Output:

number found in list

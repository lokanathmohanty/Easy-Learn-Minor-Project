Storage Classes in C

C storage classes define the scope (visibility) and lifetime of variables and/or functions within a C program. They precede the type they modify.

We have four different storage classes in a C program:

  • auto
  • register
  • static
  • extern

The auto Storage Class

The auto is a default storage class for all variables declared inside a function or block. The keyword "auto", which is optional, can be used to define local variables.

The scope and lifetime of auto variables are limited to the block in which they are declared.

The register Storage Class

The register storage class suggests storing local variables in CPU registers for faster access. It is limited to variables that require quick access, such as counters. The variable cannot have its address taken using the '&' operator.

The static Storage Class

The static storage class keeps local variables alive for the lifetime of the program, maintaining their value between function calls. When applied to global variables, it restricts their scope to the current file.

The extern Storage Class

The extern storage class provides a reference to a global variable or function defined in another file, allowing multiple files to share them.

Summary of Storage Classes

  • auto: Local scope, lifetime within block, uninitialized by default.
  • register: Local scope, stored in register if possible, fast access.
  • static: Local or file scope, lifetime of program, initialized to zero by default.
  • extern: Global scope, lifetime of program, declared but not defined.

Example: static Storage Class

The following example demonstrates the use of a static storage class in C:

#include <stdio.h>

/* function declaration */
void func(void);

static int count = 5; /* global variable */

int main() {
   while(count--) {
      func();
   }
   return 0;
}

/* function definition */
void func(void) {
   static int i = 5; /* local static variable */
   i++;
   printf("i is %d and count is %d\n", i, count);
}

Output:

i is 6 and count is 4
i is 7 and count is 3
i is 8 and count is 2
i is 9 and count is 1
i is 10 and count is 0

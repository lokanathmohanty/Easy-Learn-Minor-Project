PHP `break` Statement

The **`break`** statement is a **loop control statement** that provides a way to **immediately terminate** the execution of the current `for`, `foreach`, `while`, or `do...while` loop (or `switch` statement). When `break` is executed, program flow is abandoned for the remaining iterations and control passes to the statement immediately following the loop construct.

Basic Usage and Flow

The `break` statement is almost always used conditionally (e.g., inside an `if` block) to exit a loop early when a specific condition is met, preventing the loop from running its intended full course.

while (true) {
   if (condition_is_met) {
      **break;** // Exit the loop immediately
   }
   // remaining loop code
}

Example: Early Termination in a `do...while` Loop

The loop below is intended to run until `$num` is greater than 5, but the `break` statement forces it to exit when `$num` reaches 3.

$num = 1;
do { echo "Value: $num \n"; if ($num == 3){ **break;** } $num++; } while ($num <= 5);

Output: Value: 1 \n Value: 2 \n Value: 3

Breaking Out of Nested Loops (Numeric Argument)

By default, `break` only terminates the **immediate** enclosing loop (level 1). You can use an optional numeric argument to specify how many nested enclosing structures to break out of.

break [level];
  • **`break 1;`**: Breaks out of the immediate loop (default behavior).
  • **`break 2;`**: Breaks out of the current loop AND the loop one level outside of it.

Example: Using `break 2`

In three nested loops (`for > while > do-while`), executing `break 2` inside the innermost `do-while` loop exits the `do-while` **and** the enclosing `while` loop, transferring control directly to the outer `for` loop.

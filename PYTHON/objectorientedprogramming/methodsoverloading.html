Python Method Overloading

Method overloading is the concept of defining multiple methods with the same name but different parameters (number or type) within the same class.

Unlike languages like Java or C++, Python does not support traditional method overloading. The last defined method overrides any previous definitions.

Incorrect Overloading Example

class Example:
    def add(self, a, b):
        return a + b
    
    def add(self, a, b, c):
        return a + b + c

obj = Example()
print(obj.add(10, 20, 30))  # Works: 60
print(obj.add(10, 20))      # Fails: TypeError

Since Python only retains the last definition of add, calling it with two arguments results in an error.

You can simulate method overloading by using default parameter values or variable-length arguments.

Simulated Overloading Using Default Parameters

class Example:
    def add(self, a=None, b=None, c=None):
        if a is not None and b is not None and c is not None:
            return a + b + c
        elif a is not None and b is not None:
            return a + b
        else:
            return 0

obj = Example()
print(obj.add(10, 20, 30))  # Output: 60
print(obj.add(10, 20))      # Output: 30
print(obj.add())            # Output: 0

Alternatively, you can use the third-party multipledispatch module which allows true method overloading.

The @dispatch decorator is used to specify the parameter types for each overloaded method.

Method Overloading with MultipleDispatch Module

from multipledispatch import dispatch

class Example:
    @dispatch(int, int)
    def add(self, a, b):
        return a + b
    
    @dispatch(int, int, int)
    def add(self, a, b, c):
        return a + b + c

obj = Example()
print(obj.add(10, 20))      # Output: 30
print(obj.add(10, 20, 30))  # Output: 60

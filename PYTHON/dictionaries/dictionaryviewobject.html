Python - Dictionary View Objects

Dictionary view objects in Python provide dynamic, live views of a dictionary’s contents. The items(), keys(), and values() methods return special view objects that reflect changes to the dictionary in real time.

The items() Method

The items() method returns a dict_items view object, which is a dynamic list of tuples containing key-value pairs. 


numbers = {10: "Ten", 20: "Twenty", 30: "Thirty", 40: "Forty"}
obj = numbers.items()
print('type of obj:', type(obj))
print(obj)

numbers.update({50: "Fifty"})
print("View automatically updated")
print(obj)

Output:

type of obj: <class 'dict_items'>
dict_items([(10, 'Ten'), (20, 'Twenty'), (30, 'Thirty'), (40, 'Forty')])
View automatically updated
dict_items([(10, 'Ten'), (20, 'Twenty'), (30, 'Thirty'), (40, 'Forty'), (50, 'Fifty')])

The keys() Method

The keys() method returns a dict_keys view object containing all keys of the dictionary. It updates automatically when the dictionary changes. 


numbers = {10: "Ten", 20: "Twenty", 30: "Thirty", 40: "Forty"}
obj = numbers.keys()
print('type of obj:', type(obj))
print(obj)

numbers.update({50: "Fifty"})
print("View automatically updated")
print(obj)

Output:

type of obj: <class 'dict_keys'>
dict_keys([10, 20, 30, 40])
View automatically updated
dict_keys([10, 20, 30, 40, 50])

The values() Method

The values() method returns a dict_values view object containing all the values in the dictionary, which updates automatically on dictionary changes. 


numbers = {10: "Ten", 20: "Twenty", 30: "Thirty", 40: "Forty"}
obj = numbers.values()
print('type of obj:', type(obj))
print(obj)

numbers.update({50: "Fifty"})
print("View automatically updated")
print(obj)

Output:

type of obj: <class 'dict_values'>
dict_values(['Ten', 'Twenty', 'Thirty', 'Forty'])
View automatically updated
dict_values(['Ten', 'Twenty', 'Thirty', 'Forty', 'Fifty'])

Key Features of Dictionary View Objects

  • They provide dynamic views, automatically reflecting dictionary changes.
  • Support iteration and membership testing.
  • Allow efficient access to dictionary keys, values, or items without copying.

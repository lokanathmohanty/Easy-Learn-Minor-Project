Clickjacking Attack

Clickjacking is a cyber-attack where an attacker tricks a user into clicking on something different from what the user perceives. This is achieved by overlaying invisible elements or frames over legitimate content, camouflaging malicious intent or altering the appearance of webpage elements.

Clickjacking can cause severe risks such as unauthorized financial transactions, data breaches, and compromise of sensitive information. It impacts users and website owners alike, potentially leading to legal consequences, financial loss, and erosion of user trust.

How Clickjacking Works?

  • Overlaying Content: Attackers create or inject invisible elements (like iframes) on top of legitimate sites.
  • Deceptive Presentation: Users are enticed to interact with visible elements such as buttons or forms, which actually hide malicious content.
  • User Interaction: Clicking or typing unknowingly interacts with the hidden malicious elements.
  • Unintended Actions: Hidden elements can trigger unauthorized transactions, data submissions, or account modifications.
  • User Unawareness: The user believes they are interacting with safe content, but malicious actions occur in the background.

Examples

Example 1: Button Overlay

In this example, a button is overlaid on a hidden malicious iframe. The user thinks they are clicking a harmless button, but the action leads them to a harmful page.

<!-- home.html -->
<!DOCTYPE html>
<html>
<body>
  <h2>This is content of the home page</h2>
  <iframe src="legitimate-site.html" width="100%" height="100%"></iframe>
  <div>
    <button onclick="window.location.href='malicious-site.html'">Click Me</button>
  </div>
</body>
</html>

Example 2: Automatic Click

Here, when the page loads, it automatically triggers a click event on a button that redirects to a malicious site.

<!-- home.html -->
<!DOCTYPE html>
<html>
<head>
  <style>
    body { display: flex; align-items: center; justify-content: center; height: 100vh; margin: 0; }
    button { position: absolute; z-index: 1; background-color: transparent; border: none; font-size: 20px; cursor: pointer; }
  </style>
</head>
<body onload="myFunction()">
  <h2>Your Content Goes Here</h2>
  <button id="clickMe">Click Me</button>
  <script>
    window.onload = function() {
      var button = document.getElementById("clickMe");
      button.click();
    };
    document.getElementById("clickMe").addEventListener("click", function() {
      window.location.href = "malicious-site.html";
    });
  </script>
</body>
</html>

Real World Clickjacking Incidents

  • Facebook "Like" Button (2011): Attackers tricked users into liking malicious pages by overlaying "Like" buttons.
  • Adobe Flash Update Scam (2015): Fake Flash update buttons led to malware downloads.
  • Twitter Clickjacking: Malicious links tricked users into unintentionally retweeting harmful content.
  • LinkedIn Fake Requests: Overlays tricked users into accepting connections from fake profiles.
  • Google Play Store Deception: Malicious overlays led to unintended downloads and ad clicks.

Preventive Measures

  • X-Frame-Options Header: Use DENY or SAMEORIGIN to block iframe embedding.
  • Frame-Busting Scripts: Add scripts to prevent embedding in iframes.
  • Content Security Policy (CSP): Restrict content sources to reduce attack risks.
  • User Education: Train users to recognize suspicious content and interactions.

As cybersecurity evolves, attackers may use AI-driven methods, social engineering, and new technologies like AR and VR to launch advanced clickjacking attacks. Continuous security improvements and awareness are essential defenses.

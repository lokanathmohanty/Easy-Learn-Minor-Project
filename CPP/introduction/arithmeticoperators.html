C++ Arithmetic Operators Example Walkthrough 🧮

The provided C++ code demonstrates the use of all standard **arithmetic operators** on integer variables a (initialized to 21) and b (initialized to 10).

    • **Output:** Line 2 - Value of c is :11
  • Line 3: c = a * b;
    • **Operation:** Multiplication (21 * 10)
    • **Result:** c is 210.
    • **Output:** Line 3 - Value of c is :210
  • Line 4: c = a / b;
    • **Operation:** Integer Division (21 / 10). Since both operands are integers, the result discards the decimal part.
    • **Result:** c is 2.

  • Line 5: c = a % b;
    • **Operation:** Modulus (Remainder of 21 / 10)
    • **Result:** c is 1.
    • **Output:** Line 5 - Value of c is :1

    • **Operation:** Post-increment. The **original value of a (21) is assigned to c first**, then a is incremented.
    • **Result:** c is 21, and a becomes 22.
    • **Output:** Line 6 - Value of c is :21
  • Line 7: c = a--;
    • **Operation:** Post-decrement. The **current value of a (22) is assigned to c first**, then a is decremented.
    • **Result:** c is 22, and a becomes 21.
    • **Output:** Line 7 - Value of c is :22

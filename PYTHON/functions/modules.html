Python - Modules

The concept of module in Python further enhances the modularity. You can define more than one related functions together and load required functions. A module is a file containing definition of functions, classes, variables, constants or any other Python object. Contents of this file can be made available to any other program. Python has the import keyword for this purpose.

A function is a block of organized, reusable code that is used to perform a single, related action. Functions provide better modularity for your application and a high degree of code reusing.

Example of Python Module

import math
print("Square root of 100:", math.sqrt(100))

Output:

Square root of 100: 10.0

Python Built-in Modules

Python's standard library comes bundled with a large number of modules. They are called built-in modules. Most of these built-in modules are written in C (as the reference implementation of Python is in C), and pre-compiled into the library. These modules pack useful functionality like system-specific OS management, disk IO, networking, etc.

Here is a select list of built-in modules:

  • os — Interface to operating system functions.
  • string — String processing functions.
  • re — Regular expression support.
  • math — Mathematical operations for floating point numbers.
  • cmath — Mathematical operations for complex numbers.
  • datetime — Work with dates and times.
  • gc — Interface to garbage collector.
  • asyncio — Asynchronous processing.
  • collections — Advanced container datatypes.
  • functools — Higher-order functions and functional programming support.
  • operator — Functions corresponding to operators.
  • pickle — Object serialization.
  • socket — Networking interface.
  • sqlite3 — SQLite database support.
  • statistics — Statistical functions.
  • typing — Type hints support.
  • venv — Virtual environments.
  • json — JSON encoding and decoding.
  • wsgiref — WSGI utilities.
  • unittest — Unit testing framework.
  • random — Random number generation.
  • sys — Interpreter-related functions.
  • requests — HTTP requests.
  • itertools — Tools for iterators.
  • locale — Localization and cultural conventions.

Python User-defined Modules

Any text file with .py extension and containing Python code is basically a module. It can contain definitions of one or more functions, variables, constants as well as classes.

Example:

# mymodule.py
def SayHello(name):
    print("Hi {}! How are you?".format(name))

Now you can import and use it:

>>> import mymodule
>>> mymodule.SayHello("Harish")
Hi Harish! How are you?

The import Statement

The import keyword loads all the functions, variables, or classes defined in a module. For example:

# mymodule.py
def sum(x, y):
    return x + y

def average(x, y):
    return (x + y) / 2

def power(x, y):
    return x ** y
      
import mymodule
print("sum:", mymodule.sum(10, 20))
print("average:", mymodule.average(10, 20))
print("power:", mymodule.power(10, 2))

Output:

sum: 30
average: 15.0
power: 100

The from ... import Statement

We can import specific objects from a module:

from mymodule import sum, average
print("sum:", sum(10, 20))
print("average:", average(10, 20))

Output:

sum: 30
average: 15.0

The import ... as Statement

We can assign an alias name to a module:

import mymodule as x
print("sum:", x.sum(10, 20))
print("average:", x.average(10, 20))
print("power:", x.power(10, 2))

Namespaces and Scoping

A namespace is a mapping of variable names to objects. Functions have local namespaces, and variables defined inside them may shadow global variables.

Money = 2000
def AddMoney():
    # global Money
    Money = Money + 1
print(Money)
AddMoney()
print(Money)

This will cause an error unless the global keyword is used.

Module Attributes

  • __file__ — physical name of the module.
  • __package__ — package to which the module belongs.
  • __doc__ — docstring of the module.
  • __dict__ — namespace dictionary of the module.
  • __name__ — name of the module.
import mymodule

print("__file__:", mymodule.__file__)
print("__doc__:", mymodule.__doc__)
print("__name__:", mymodule.__name__)

The __name__ Attribute

The __name__ attribute determines if a script is being run directly or imported as a module.

# mymodule.py
def sum(x, y):
    return x + y

if __name__ == "__main__":
    print("sum:", sum(10, 20))

This prevents functions from running when imported.

The dir() Function

The dir() function returns a list of names defined in a module.

import math
print(dir(math))

The reload() Function

If a module is modified, we may need to reload it:

import imp
import test
imp.reload(test)

Packages in Python

A package is a hierarchical directory structure that groups modules together.

Phone/
   __init__.py
   Pots.py
   Isdn.py
   G3.py

Example:

# Phone/__init__.py
from Pots import Pots
from Isdn import Isdn
from G3 import G3

import Phone
Phone.Pots()
Phone.Isdn()
Phone.G3()

Output:

I'm Pots Phone
I'm 3G Phone
I'm ISDN Phone

Pandas - Plotting

Pandas uses the plot() method to create various types of plots and diagrams. To display the plots, we use pyplot, a submodule of the Matplotlib library.

To learn more about Matplotlib, refer to the Matplotlib tutorial.

Example: Basic Plot

Import pyplot from matplotlib and plot the entire DataFrame:


import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('data.csv')
df.plot()

plt.show()

Scatter Plot

A scatter plot visualizes the relationship between two variables using dots.

Set kind='scatter' and specify the x and y axis:

Example: Duration vs. Calories


import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('data.csv')

df.plot(kind='scatter', x='Duration', y='Calories')

plt.show()

This scatter plot shows a strong positive correlation between Duration and Calories. This matches the correlation coefficient of 0.92 found earlier.

Example: Duration vs. Maxpulse


import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('data.csv')

df.plot(kind='scatter', x='Duration', y='Maxpulse')

plt.show()

This scatter plot demonstrates a weak or no correlation between Duration and Maxpulse (correlation coefficient: 0.009).

Histogram

A histogram is used to visualize the frequency of values in a single column. Use kind='hist' for this plot type.

Example: Duration Histogram


df["Duration"].plot(kind='hist')
plt.show()

This histogram shows how often different workout durations occur. For example, many workouts fall in the 50–60 minute range.

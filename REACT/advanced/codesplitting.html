ReactJS - Code-Splitting

Bundling is the process of combining application code and dependencies into a single file, usually bundle.js. While this is efficient for small applications, large bundles may slow down loading. Code-splitting allows us to split the bundle into smaller chunks that load on demand.

Dynamic Import

Dynamic imports instruct the bundler to split code into separate bundles that load when required. 

// Static import
import { round } from './math';
console.log(round(67.78));

// Dynamic import
import("./math").then(math => {
   console.log(math.round(67.78));
});

React Lazy Component

React provides React.lazy() to dynamically load components. These must be wrapped in a Suspense component. 

import React, { Suspense } from 'react';

const MyComponent = React.lazy(() => import('./MyComponent'));

function App() {
   return (
      <div>
         <Suspense fallback={<div>Loading...</div>}>
            <MyComponent />
         </Suspense>
      </div>
   );
}

Error Boundaries

Errors during lazy loading can be handled using an Error Boundary. 

import React, { Suspense } from 'react';
import MyErrorBoundary from './MyErrorBoundary';

const MyComponent = React.lazy(() => import('./MyComponent'));

const AnotherComponent = () => (
   <div>
      <MyErrorBoundary>
         <Suspense fallback={<div>Loading...</div>}>
            <section>
               <MyComponent />
            </section>
         </Suspense>
      </MyErrorBoundary>
   </div>
);

Code-Splitting with Routing

Routes can be lazy-loaded, ensuring only the necessary components are loaded for each route. 

import React, { Suspense, lazy } from 'react';
import { BrowserRouter, Routes, Route } from 'react-router-dom';

const Home = lazy(() => import('./routes/Home'));
const About = lazy(() => import('./routes/About'));

const App = () => (
   <BrowserRouter>
      <Suspense fallback={<div>Loading...</div>}>
         <Routes>
            <Route path="/" element={<Home />} />
            <Route path="/about" element={<About />} />
         </Routes>
      </Suspense>
   </BrowserRouter>
);

Example: Lazy Loading

Below is an example using React.lazy() and Suspense with a simple Hello component and SimpleErrorBoundary. 

import './App.css'
import React, { Suspense, lazy } from 'react';
import SimpleErrorBoundary from './Components/SimpleErrorBoundary';

const Hello = lazy(() => import('./Components/Hello'));

function App() {
   return (
      <div className="container">
         <SimpleErrorBoundary>
            <Suspense fallback={<div>loading...</div>}>
               <Hello name="Peter" />
            </Suspense>
         </SimpleErrorBoundary>
      </div>
   );
}

export default App;

Summary

Code-splitting improves performance by loading only the components required for a given view. Using React.lazy(), Suspense, and error boundaries ensures smooth and fault-tolerant lazy loading.

Django Index Page and Multiple App Structure 🏠

The Django **index page** is the page displayed at the root URL of your project (e.g., http://localhost:8000/). After successful installation and project creation, a default "It worked!" page is shown. The key to customizing this page is to map the root URL (/) to a specific view function.

Creating the Root Index Page

To make a custom index page, the following steps were performed:

  1. **Application Creation:** An application (myapp) was created using python manage.py startapp myapp.
  2. **Registration:** The app was registered in myproject/settings.py by adding 'myapp' to INSTALLED_APPS.
  3. **View Definition:** The index() view was defined in myapp/views.py to render an HTML template (e.g., index.html) using render(request, 'index.html', {}).
  4. **App URL Mapping:** A myapp/urls.py file was created to map the empty path ('') to the index view: 
    urlpatterns = [
   path('', views.index, name='index'),
]
  5. **Root URL Inclusion:** The main myproject/urls.py was updated to include the app's URLs at the root path: 
    urlpatterns = [
   path('', include('myapp.urls')),
   path('admin/', admin.site.urls),
]

By including myapp.urls at the root path (path('', include('myapp.urls'))), the app's index view takes over the project's home page.

Structuring a Project with Multiple Applications

In a real-world scenario, a project has multiple apps (e.g., customers and products). The project's index page often serves as a navigation hub linking to the home pages of these individual apps.

1. Creating and Configuring Multiple Apps

Two new applications, customers and products, were created and registered in settings.py.

2. App URL Structure and Views

Each new app (customers and products) defines its own index() view (e.g., rendering customerindex.html) and its own urls.py file, mapping its root ('') to its respective index view function (e.g., path("", views.index, name="customer-index")).

3. Centralized Project URL Routing

The main project myproject/urls.py directs traffic to the correct application based on the URL prefix:

urlpatterns = [
   path('admin/', admin.site.urls),
   path('products/', include("products.urls")),
   path('customers/', include("customers.urls")),
   path('', views.index, name='index'), # Project index page (optional)
]
  • The URL **/customers/** directs traffic to the customers.urls, which then resolves to the **Customer App's index view**.
  • The URL **/products/** directs traffic to the products.urls, which then resolves to the **Products App's index view**.

The overall project index page (/) can now display a navigation sidebar with links like <a href="customers/">Customers</a>, allowing users to navigate the different modules of the web application.

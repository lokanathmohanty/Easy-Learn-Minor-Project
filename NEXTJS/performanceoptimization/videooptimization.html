Next.js - Video Optimization

Using Videos in Next.js

Next.js does not provide a dedicated built-in component for video, unlike images or scripts. Videos are included in a page using standard web elements:

  • Local Video Files: Use the HTML **<video>** tag for files hosted within your application.
  • External Platform Videos: Use the HTML **<iframe>** tag to embed videos hosted on platforms like YouTube or Vimeo.

Example: Embedding a Local Video

The playsInline attribute is important for mobile compatibility, particularly on iOS.

export default function Example() {
    return (
    <div>
        <h1>Video:</h1>
        <video
            src="/video.mp4"
            autoPlay
            muted
            loop
            playsInline
        />
    </div>
    )
}

Best Practices for Video Optimization

Optimizing videos focuses on accessibility, performance, and reliability:

  • Fallback Content: Always include text or links inside the <video> tag. This content is displayed if the user's browser does not support the video format.
  • Subtitles or Captions: Use the **<track>** tag within the <video> element to provide caption files. This is essential for accessibility (users who are deaf or hard of hearing).
  • Accessible Controls: Use the standard HTML5 video controls (by including the controls attribute) for basic accessibility. For complex needs, use established third-party players (like **react-player** or **video.js**) known for accessible controls and consistent behavior.

Embedding Externally Hosted Videos (Optimized)

To optimize the loading of external videos, especially those hosted on YouTube or Vimeo, a pattern involving a **Server Component** and **React Suspense** is highly recommended.

Step 1: Create a Server Component for Fetching Video Source

This component is responsible for securely fetching the final video URL (src) and rendering the <iframe>. This server-side fetching prevents unnecessary client-side logic and potential network waterfall issues.

export default async function VideoComponent() {
  const src = await getVideoSrc() // Example function to fetch the video URL
 
  return <iframe src={src} allowFullScreen />
}

Step 2: Display Video Component using React Suspense

Wrap the VideoComponent in **<Suspense>** to provide an immediate **fallback UI** (e.g., "Loading video...") while the server component is fetching the video URL and before the <iframe> is rendered. This improves perceived performance.

import { Suspense } from 'react'
import VideoComponent from '../ui/VideoComponent.jsx'

export default function Page() {
  return (
    <section>
      <Suspense fallback={<p>Loading video...</p>}>
        <VideoComponent />
      </Suspense>
      {/* Other content of the page loads immediately */}
    </section>
  )
}

PHP Function Parameters and Arguments

**Function Parameters** are variables defined in the function signature that receive data when the function is called. These values, known as **Arguments**, allow a function to produce dynamic results based on the input they receive.

Formal Parameters vs. Actual Arguments

  • **Formal Parameters:** The variables defined in the function's declaration (e.g., `$arg_1` in the syntax below).
  • **Actual Arguments:** The literal values, variables, or expressions passed to the function when it is called (e.g., `val1`, `$x`, or `10 + 20`).

**Syntax:**
function foo($arg_1, $arg_2) { /* ... */ }
foo(val1, val2);

Key Features of Parameters

1. Default Parameters (Optional Arguments)

You can assign a default value to a parameter in the function definition. If the caller does not provide an argument for that parameter, the default value is used, making the argument optional.

function greet($name = "Guest") { echo "Hello, $name!"; }
greet(); $\rightarrow$ Hello, Guest!
greet("Rashmi"); $\rightarrow$ Hello, Rashmi!

2. Variable-Length Arguments (`...`)

The **splat operator (`...`)** allows a function to accept a dynamic, unconstrained number of arguments. These arguments are then provided to the function as an indexed array.

function sumAll(...$numbers) { return array_sum($numbers); }
sumAll(1, 2, 3, 4); $\rightarrow$ **10**

Type Handling and Error Cases

Argument Count Error

The number of actual arguments passed must generally match the number of formal parameters (unless default values or variable-length arguments are used).

  • **Too Few Arguments:** PHP raises an **`ArgumentCountError`** (Fatal Error) if a required parameter is missing.
  • **Too Many Arguments:** Extra arguments are generally ignored.

Type Mismatch and Weak Typing

PHP is a **weakly typed** language. It often attempts to automatically convert (cast) argument types to match the context of the operation inside the function.

  • If you pass `"10"` (string) and `20` (integer) to an addition function, PHP will successfully cast `"10"` to an integer and return `30`.
  • If you pass `"Hello"` and `"World"`, the `+` operator fails because it cannot perform arithmetic on non-numeric strings, resulting in a **`TypeError`** (Fatal Error, in modern PHP versions when strict types are not enabled and the operation is invalid).

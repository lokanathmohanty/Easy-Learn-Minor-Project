C# Nested `switch` Statements

What Are Nested `switch` Statements?

A **nested `switch` statement** involves placing one `switch` statement entirely **inside the code block** of a case within an outer `switch` statement. This technique is highly effective for handling **multi-level decision-making**, where the outcome of the first choice (the outer `switch`) determines the set of possibilities for the second choice (the inner `switch`).

Crucially, the case constants in the inner and outer `switch` statements can have the same values without causing conflicts, as they are evaluated in separate scopes.

Rules and Structure

The core rules for a nested structure are similar to those for a single `switch`:

  • **Expression Type:** Both the inner and outer `switch` expressions must be an **integral type** (int, char, enum, etc.).
  • **Constants:** Case values must be **constants or literals**.
  • **Break Required:** Every non-empty `case` in **both** the inner and outer switches must terminate with a jump statement, usually **break**.
  • **Independence:** Both switches can include their own optional **default** case, which is independent of the other.

Simplified Syntax Flow:

switch(outer_expression) {
   case value_A: 
      // Executes if outer_expression == value_A
      
      switch(inner_expression) { // START Inner Switch
         case value_1:
            // Executes if inner_expression == value_1
            break;
         case value_2:
            // ...
      } // END Inner Switch
      break; // Breaks out of the Outer Switch
      
   case value_B: 
      // ...
}

Example: Department and Role Selection

This demonstrates using an outer `switch` to select the **Department** and an inner `switch` to define the **Role** within that department.

using System;
public class Example {
   public static void Main() {
      string department = "IT";
      string role = "Manager";

      switch (department) { // Outer Switch: Checks "IT"
      case "IT":
         // Inner Switch executes only if Department is "IT"
         switch (role) { 
         case "Developer": break;
         case "Tester": break;
         case "Manager": // Match! This code runs
            Console.WriteLine("IT - Manager: Oversees IT projects.");
            break; 
         default: break;
         }
         break; // Breaks out of the Outer Switch
      
      case "HR":
         // ... HR inner switch logic ...
         break;
      
      default:
         Console.WriteLine("Invalid Department!");
         break;
      }
   }
}

Output:

IT - Manager: Oversees IT projects.

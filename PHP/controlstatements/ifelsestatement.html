PHP `if...else` and `elseif` Statements

The **`if...else`** statement is the core construct in PHP for controlling program flow based on conditions. It allows a program to make a decision: execute one block of code if a **Boolean expression** is true, and execute another block if it is false.

Basic `if...else` Syntax

The `if` statement evaluates a condition. The `else` keyword provides an alternative path when the condition fails.

if (expression)
   code to be executed if expression is true;
else
   code to be executed if expression is false;

Example: Simple Comparison

If the condition in the parenthesis evaluates to `true`, the `if` block executes. If `false`, the `else` block executes.

$a=10; $b=20;
if ($a > $b) { echo "a is bigger"; } else { echo "a is not bigger"; }

Output: a is not bigger

The `elseif` Statement

The **`elseif`** construct is used to check **multiple conditions** sequentially. It runs its code block only if its condition is true AND all preceding `if` or `elseif` conditions were false.

`if...elseif...else` Syntax

if (expr1)
   code to be executed if expr1 is true;
elseif (expr2)
   code to be executed if expr2 is true;
else
   code to be executed if all preceding expressions are false;

The first `true` condition in the chain is executed, and the rest of the chain is skipped.

Example: Checking Multiple Days

The script checks for Friday first, then Sunday, then defaults to "other days".

$d = date("D");
if ($d == "Fri") { echo "Weekend!"; }
elseif ($d == "Sun") { echo "Sunday!"; }
else { echo "Nice day!"; }

Alternative Syntax (`if...endif;`)

PHP provides an alternative syntax that is often used when mixing PHP logic with large blocks of HTML. Instead of curly braces (`{}`), you use a **colon (`:`)** to open the block and keywords like **`endif;`**, **`else:`**, or **`elseif:`** to close or transition between blocks.

<?php if ($d == "Fri"): ?>
   <h2>Have a nice weekend!</h2>
<?php else: ?>
   <h2>Have a nice day!</h2>
<?php endif ?>

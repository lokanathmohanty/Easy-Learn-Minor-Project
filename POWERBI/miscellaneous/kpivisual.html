Power BI: KPI Visual

KPI (Key Performance Indicator) visuals in Power BI are essential for tracking employee performance against defined targets. They provide meaningful insights, allowing organizations to identify strengths and weaknesses and make informed decisions. KPIs can be used in many scenarios, such as monitoring user reviews, customer feedback, or sales achievements.

How to Develop a KPI Visual

  1. Import the dataset (e.g., sales executive.xlsx) into Power BI Desktop.
  2. Select the KPI visual from the Visualizations pane; an empty KPI visual will appear in the report canvas.
  3. Add the field representing current year target achieved to the Value section.
  4. Add the time dimension, such as Year, to the Trend Axis.
  5. Add the previous year target achieved field to the Target section for comparison.
  6. Use the Drill Through feature with an identifier like Name to view individual employee performance details.

Customizing the KPI Visual

  • Callout Value: Change font style (e.g., Calibri), increase font size (e.g., 45), and set alignment for emphasis on key numbers.
  • Icons: Enable icons, customize size and appearance to visually represent performance.
  • Trend Axis: Define period, toggle 'High is good', and apply conditional formatting with colors for good, neutral, and bad performance states.
  • Target Label: Enable and customize font settings, including style (e.g., Symbol), size, color, and label text.
  • Distance to Goal: Show numeric distance to target rather than percentage, with customizable font and color.
  • Date Display: Toggle to show the reporting period visibly on the visual.
  • General Settings: Adjust size, position, padding, and advanced options for layout control.
  • Title and Subtitle: Change titles, subtitles, fonts, colors, alignment, and spacing to brand visuals appropriately.
  • Effects and Background: Modify background color, borders, shadows, and apply theme-based colors for visual enhancement.
  • Header Icons: Customize header icons' background, border, and icon color for neat UI presentation.

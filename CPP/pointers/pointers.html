C++ Pointers (Memory Addresses) 📍

A **pointer** is a special type of variable that stores the **memory address** of another variable. Pointers are essential for dynamic memory allocation, efficient array manipulation, and achieving various C++ programming tasks.

The Address-of Operator (&)

Every variable occupies a location in memory. The **address-of operator** (`&`) is used to retrieve the memory address of a variable.

int var = 20;
cout << &var << endl; // Prints the memory address of 'var' (e.g., 0xbfc601ac)

Pointer Declaration

Pointers are declared using the **dereference/indirection operator** (`*`). The declaration specifies the **type of data** the pointer will point to (the base type), not the type of the pointer itself (which is always a memory address).

type *var_name;

int *ip;    // Pointer to an integer
double *dp; // Pointer to a double
char *ch;   // Pointer to a character

Using Pointers: The Three Steps

  1. Declaration: Declare the pointer variable (`int *ip;`).
  2. Assignment: Assign the address of a variable to the pointer (`ip = &var;`).
  3. Dereferencing: Access the value at the memory address stored in the pointer using the dereference operator (`*`).

The Dereference Operator (*)

The **dereference operator** (`*`), when placed before a pointer variable, returns the **value** stored at the address the pointer holds.

int var = 20;   // Actual variable
int *ip;        // Pointer variable

ip = &var;      // 1. Store address of var in ip

cout << ip << endl;   // Prints the address (0x...)
cout << *ip << endl;  // 2. Prints the value at that address (20)

Key Pointer Concepts

  • Null Pointers: A pointer initialized to `NULL` (or `nullptr` in modern C++) is guaranteed not to point to a valid memory location, which is used to indicate that a pointer does not point anywhere.
  • Pointer Arithmetic: Arithmetic operators (`++`, `--`, `+`, `-`) can be used on pointers. When you increment a pointer (e.g., `p++`), the address increases by the size of the base type (e.g., if `p` is an `int*`, the address jumps 4 bytes, assuming 4-byte integers).
  • Pointers vs. Arrays: The name of an array often **decays** into a constant pointer to its first element, showing a deep relationship between the two concepts.
  • Pointer to Pointer: C++ allows you to declare a pointer that stores the address of another pointer (e.g., `int **pp;`).
  • Passing Pointers to Functions: Passing arguments by address (using pointers) allows the called function to modify the original variable in the calling function (Call by Reference using Pointers).

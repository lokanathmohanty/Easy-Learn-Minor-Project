Nested Structures in C

What is a Nested Structure?

A nested structure in C is a structure that contains another structure as one of its members. This allows composite data representation.

Nested Structure Declaration

A nested structure can be declared by including a struct type as a member of another struct type.

Syntax:

struct struct1 {
  type var1;
  type var2;
  struct struct2 strvar;
};

Example: Inline Nested Structure

Defining a nested structure inline within the outer struct:

struct employee {
  char name[10];
  float salary;
  struct dob {
    int d, m, y;
  } d1;
};

Accessing Nested Structure Members

Use the dot operator (.) for each level to access members of nested structs.

Example syntax:

outer_struct_var.inner_struct_var.member_name;

Example: Accessing Members

printf("Date of Birth: %d-%d-%d\n", e1.d1.d, e1.d1.m, e1.d1.y);

Pointer to Nested Structure

Use the arrow operator (->) to access nested struct members via a pointer.

Example: Pointer Access

struct employee *ptr = &e1;
printf("Date of Birth: %d-%d-%d\n", ptr->d1.d, ptr->d1.m, ptr->d1.y);

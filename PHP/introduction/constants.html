PHP Constants: Definition, Rules, and Usage

A **constant** in PHP is a named identifier for a simple, fixed value that **cannot be changed** during the execution of a script. They are primarily used to improve code readability, maintainability, and security (by preventing key values like configuration settings from being accidentally modified).

Rules and Naming Conventions

  • **Declaration:** Constants are defined using the **`define()`** language construct, **not** simple assignment.
  • **Symbol:** Constants **do not** start with the dollar sign (`$`), unlike variables.
  • **Scope:** Constants are **global** by default and can be accessed from anywhere in the script.
  • **Case Sensitivity:** By default, constants are **case-sensitive** (i.e., `CONSTANT` is different from `Constant`).
  • **Convention:** By convention, constant identifiers are always written in **uppercase** (e.g., `MAX_SIZE`, `PHP_VERSION`).
  • **Naming:** Must start with a letter or an underscore (`_`), followed by any number of letters, digits, or underscores.

Once a constant has been set, it **cannot be redefined or undefined**.

Defining Constants using `define()`

The primary method for creating a named constant is the `define()` function:

define("CONSTANT_NAME", value);

The full syntax includes an optional third parameter: `define(string $const_name, mixed $value, bool $case = false): bool`.

  • **`$const_name`**: The constant's identifier (e.g., `"MINSIZE"`).
  • **`$value`**: The constant's value (can be a scalar type or an array).
  • **`$case`**: If set to `true`, the constant becomes **case-insensitive** (default is `false`).

Example: Case Sensitivity

<?php
   define("CONSTANT", "Hello world.");
   echo CONSTANT; // Works
   // echo Constant; // Fatal Error (Case-sensitive by default)
?>

Output:
Hello world.

Example: Array Constant

<?php
   define("LANGS", array('PHP', 'Java', 'Python'));
   var_dump(LANGS);
?>

Output (shows array structure):
array(3) { ... }

Accessing and Checking Constants

  • **Accessing by Name:** You can directly use the constant name (e.g., `echo MINSIZE;`).
  • **`constant()` function:** Use this function if the constant name itself is stored in a variable or returned by another function.
    echo constant("MINSIZE"); // Retrieves value of MINSIZE
  • **`defined()` function:** Checks whether a named constant currently exists.
    if (defined('MAX')) { echo MAX; }
  • **Predefined Constants:** PHP includes several built-in constants for system information:
    echo PHP_VERSION; // e.g., 8.3.9
    echo PHP_OS; // e.g., Linux

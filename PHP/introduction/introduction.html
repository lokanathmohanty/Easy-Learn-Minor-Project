PHP: Introduction and Functionality Summary

What is PHP?

**PHP** is the world's most popular **server-side scripting language** used for building web applications. It began as a small open-source project by **Rasmus Lerdorf** in 1994.

  • **Initial Meaning:** "Personal Home Page".
  • **Current Meaning:** The **recursive initialism** "**PHP: Hypertext Preprocessor**".
  • It started as a set of **Common Gateway Interface (CGI) programs** in C, which evolved into PHP/FI (Personal Home Page/Forms Interpreter) with database and form support.

Today, PHP is a **cross-platform language** that is **open-source and free**, compatible with major operating systems (Windows, Linux, Mac) and web servers (Apache, IIS, nginx).

How PHP Works (Server-Side Scripting)

PHP is a **server-side scripting language** that is typically **embedded in HTML** to create dynamic content. The process from a user request to a displayed page is as follows:

  1. A user requests a PHP page in their browser.
  2. The **web server** receives the request, finds the PHP file, and sends it to the **PHP interpreter** (e.g., Zend Engine).
  3. The **interpreter** executes the PHP script.
  4. The script generates pure **HTML code** as its output.
  5. The web server sends the generated HTML code back to the user's browser.
  6. The browser parses and displays the HTML. **The user never sees the PHP source code.**

Key Features and Applications

PHP is highly valued for its simplicity, cost-effectiveness, and extensive capabilities:

Core Features

  • **System Functions:** Can create, open, read, write, and close files.
  • **Form Handling:** Gathers data from files, saves data, sends data via email, and returns data to the user.
  • **Database Management:** Adds, deletes, and modifies elements within your database.
  • **Security:** Restricts user access and encrypts data.
  • **Ecosystem:** Provides access to reusable classes and libraries through **PEAR** and **Composer** (dependency management).

Application Areas

  • **Dynamic Web Content:** Managing dynamic content, databases, and session tracking.
  • **E-commerce Sites:** Building entire online stores.
  • **Versatile Output:** Not limited to HTML; can output rich file types like **Images**, **PDFs**, **JSON**, or **XML**.
  • **Command-Line Interface (CLI):** Can be used to build **desktop standalone applications** (with extensions like PHP-GTK).

PHP Version History Milestones

PHP has undergone several major revisions, primarily driven by the **Zend Engine**:

  • **PHP 3.0 (1998):** Rewritten by Zeev Suraski and Andi Gutmans; adopted the current "PHP: Hypertext Preprocessor" acronym; introduced a mature interface for multiple databases and **Object-Oriented Programming (OOP)** support.
  • **PHP 4.0 (2000):** Powered by the initial **Zend Engine**; added support for HTTP sessions and output buffering.
  • **PHP 5.0 (2004):** Driven by **Zend Engine 2.0** with a new, enhanced object model.
  • **PHP 7.0 (2015):** A major revision using **Zend Engine 3** (originally phpng); provided **significantly improved performance** and reduced memory usage; introduced Return and Scalar Type Declarations.
  • **PHP 8.0 (2020):** Introduced **Just-in-Time compilation (JIT)**, offering substantial performance improvements for certain tasks.

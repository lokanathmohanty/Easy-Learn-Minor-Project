Django: Creating and Structuring a Project 🏗️

In Django, a **project** is the container for your entire web application. A project is composed of one or more independent **applications**, where each application is a self-contained set of code files that follows the MVT (Model-View-Template) pattern (e.g., a "forum" or a "news" engine). This modular structure promotes code reusability.

Creating the Project

To create a new project, navigate to your desired directory in the command line and use the django-admin utility:

$ django-admin startproject myproject

This command creates a top-level directory named myproject, which holds the project's necessary files.

Project Structure Breakdown

The resulting directory structure contains two main elements:

myproject/
   manage.py
   myproject/
      __init__.py
      settings.py
      urls.py
      wsgi.py
  • **manage.py**

    This is your command-line utility for interacting with the project. It acts as a local django-admin for tasks like starting the development server, managing the database, and running tests. To see all available commands, use: $ python manage.py help.

  • **myproject/ (The Settings Package)**

    This is the actual Python package for your project. It contains the configuration files:

    • **settings.py:** Contains all the project's configurations (database, time zone, installed apps, etc.).
    • **urls.py:** The project's main URL configuration, acting as a table of contents that maps URLs to the appropriate application views.
    • **wsgi.py:** Used for deploying the project with WSGI-compliant web servers (e.g., Gunicorn, Apache/mod_wsgi).
    • **__init__.py:** A standard Python file indicating that the directory is a package.

Essential Project Settings (settings.py)

The following are crucial configurations within the settings.py file:

Debug Mode

DEBUG = True

Setting this to **True** provides detailed error information and enables the Django development server to serve static files. **Always set this to False for live (production) projects** for security reasons.

Database Configuration

The **DATABASES** dictionary defines the connection parameters. The example uses the default SQLite setup:

DATABASES = {
   'default': {
      'ENGINE': 'django.db.backends.sqlite3',
      'NAME': 'database.sql',
      # ... other settings for user/password/host/port
   }
}

The ENGINE parameter changes for other databases (e.g., django.db.backends.mysql, django.db.backends.postgresql_psycopg2). Ensure the necessary database driver is installed before changing the engine.

Running the Development Server

To confirm your project is set up correctly, start the built-in lightweight development server:

$ python manage.py runserver

This command starts the server, typically accessible at **http://127.0.0.1:8000/**.

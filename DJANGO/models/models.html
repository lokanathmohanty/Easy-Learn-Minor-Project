Django Models and ORM (Object-Relational Mapping) 🗄️

A **Model** in Django is a **Python class** that defines the structure of a database table or collection. It inherits from **django.db.models.Model**, where each class attribute represents a field (column) in the database.

Model Definition Example

The Dreamreal model demonstrates basic field types and table naming:

from django.db import models

class Dreamreal(models.Model):
   website = models.CharField(max_length = 50)
   mail = models.CharField(max_length = 50)
   name = models.CharField(max_length = 50)
   phonenumber = models.IntegerField()

   class Meta:
      db_table = "dreamreal" # Forces the table name instead of default: myapp_dreamreal

Basic CRUD Operations

The Django **ORM** allows developers to interact with the database using Python objects rather than raw SQL. These operations are performed on model instances or the model's manager (Model.objects):

  • **Create:** Instantiate the model and call .save(). 
    dreamreal = Dreamreal(website="...", name="sorex", ...)
dreamreal.save()
  • **Read All:** Use the manager's .all() method to retrieve a **QuerySet** of all entries. 
    objects = Dreamreal.objects.all()
  • **Read Specific:** Use .get() with filter arguments (e.g., name="sorex"). **Raises an error if zero or multiple objects are found.** 
    sorex = Dreamreal.objects.get(name = "sorex")
  • **Update:** Retrieve an object, change its attributes, and call .save(). 
    dreamreal = Dreamreal.objects.get(name = 'sorex')
dreamreal.name = 'thierry'
dreamreal.save()
  • **Delete:** Call the .delete() method on a specific instance. 
    sorex.delete()

Advanced Data Manipulation (QuerySet Methods)

These methods are primarily executed on the model's manager (Model.objects) and return a **QuerySet**, which can be chained:

  • **Filtering Data:** Use .filter() to select objects matching specific criteria. 
    qs = Dreamreal.objects.filter(name = "paul")
  • **Ordering Results:** Use .order_by() to sort the QuerySet based on a field. 
    qs = Dreamreal.objects.order_by("name")

Linking Models (Relationships)

Django supports three main types of relationships, primarily relevant for SQL databases:

  • **One-to-Many (ForeignKey):** Used when one model instance is related to multiple instances of another model (e.g., a company has multiple websites). The field is defined on the "many" side. 
    class Dreamreal(models.Model):
   online = models.ForeignKey('Online', default = 1) # One Online object can be linked to many Dreamreal objects
    • **Accessing Related Object:** online_instance.company.name
    • **Accessing Reverse Relationship:** dreamreal_instance.online_set.all()
    • **Reverse Filtering (Joins):** Queries can span across models using double underscores (__). 
      Online.objects.filter(company__name__contains = 'company')
  • **One-to-One (OneToOneField):** Guarantees that only one instance of the primary model can be linked to one instance of the related model (and vice-versa).
  • **Many-to-Many (ManyToManyField):** Allows multiple instances of one model to be linked to multiple instances of another model (e.g., a student can take many courses, and a course has many students).

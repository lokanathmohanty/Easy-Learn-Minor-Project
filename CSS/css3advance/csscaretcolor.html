CSS - caret-color Property

The CSS caret-color property specifies the color of the cursor, also known as the text input cursor. It is commonly used with editable elements such as input fields, text boxes, and textareas.

Syntax

caret-color: auto | color | transparent | initial | inherit;

Property Values

  • auto – Browser uses the currentColor for the caret (default).
  • color – Specifies caret color in different formats (color names, hex, rgb, hsl, etc.).
  • transparent – Caret will not be visible.
  • initial – Resets the property to its default value.
  • inherit – Inherits the caret-color property from the parent element.

Examples of CSS Caret Color Property

Caret Color Property with Auto Value

The auto value lets the browser decide the color of the cursor, which usually applies the current text color to the caret. 

<input type="text" value="Default cursor color." style="caret-color:auto; color:blue;">
<textarea rows="5" style="caret-color:auto; color:red;">Default caret color.</textarea>

Caret Color Property with Color Values

You can specify a color of your choice for the caret using names, hex, rgb, or hsl values. 

<input type="text" value="Orange caret." style="caret-color:orange;">
<input type="text" value="Pink caret." style="caret-color:#ff4d94;">
<input type="text" value="Cyan caret." style="caret-color:rgb(0,204,204);">
<textarea rows="5" style="caret-color:hsl(120,100%,50%);">Green caret.</textarea>

Caret Color Property with Transparent Value

The transparent value makes the caret invisible. 

<input type="text" value="Transparent caret." style="caret-color:transparent;">
<textarea rows="5" style="caret-color:transparent;">Invisible caret.</textarea>

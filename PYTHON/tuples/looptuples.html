Python - Loop Tuples

Looping through tuple items in Python means iterating over each element sequentially. This can be done using different types of loops like the for loop, while loop, and looping through indexes.

Loop Through Tuple Items with For Loop

The for loop is commonly used to iterate through each item in a tuple. You can execute a block of code repeatedly for every element in the tuple.

tup = (25, 12, 10, -21, 10, 100)
for num in tup:
    print(num, end=' ')

Output:

25 12 10 -21 10 100

Loop Through Tuple Items with While Loop

The while loop runs as long as a condition is true. You can use an index variable to access tuple items sequentially.

my_tup = (1, 2, 3, 4, 5)
index = 0
while index < len(my_tup):
    print(my_tup[index])
    index += 1

Output:

1
2
3
4
5

Loop Through Tuple Items with Index

You can loop through tuple items by their index, iterating over a range from 0 to the tuple length, and accessing elements with the index.

tup = (25, 12, 10, -21, 10, 100)
indices = range(len(tup))
for i in indices:
    print(f"tup[{i}]:", tup[i])

Output:

tup[0]: 25
tup[1]: 12
tup[2]: 10
tup[3]: -21
tup[4]: 10
tup[5]: 100

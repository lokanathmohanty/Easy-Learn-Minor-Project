C++ Inheritance (OOP Concept) 🧬

**Inheritance** is a fundamental concept in Object-Oriented Programming (OOP) that allows a new class (the **derived class**) to inherit data members and member functions from an existing class (the **base class**). This mechanism promotes **code reusability** and establishes an **"is-a" relationship** (e.g., a Rectangle **is-a** Shape).

Syntax for Derivation

To define a derived class, you use a derivation list specifying the access type for the base class(es):

class derived-class: access-specifier base-class {
   // ... members of derived-class
};

The `access-specifier` can be **public**, **protected**, or **private**.

Access Control and Inheritance Types

The `access-specifier` determines how the base class's members are treated in the derived class. Base class **private** members are **never** directly accessible to the derived class, regardless of the inheritance type.

**public** **public** **protected** **private**
**protected** **protected** **protected** **private**
**private** **Inaccessible** **Inaccessible** **Inaccessible**

Public Inheritance (Commonly Used)

When using `public` inheritance (e.g., `class Rectangle: public Shape`), the public interface of the base class remains public in the derived class, preserving the "is-a" relationship for outside users.

// Base protected members (width, height) are accessible 
// inside the derived class's methods (getArea()).
class Rectangle: public Shape {
   public:
      int getArea() { 
         return (width * height); // Accesses protected members
      } 
};

Multiple Inheritance

**Multiple inheritance** allows a derived class to inherit from **more than one** base class, acquiring the combined attributes and behaviors of all parent classes.

Syntax

class derived-class: access baseA, access baseB { /* ... */ };

In the example, Rectangle inherits from both Shape and PaintCost, giving it dimensions and a cost calculation method.

class Rectangle: public Shape, public PaintCost {
   public:
      int getArea() { /* ... */ } 
};
// Rect object can call methods from both parents:
// Rect.setHeight(7);   // From Shape
// Rect.getCost(area);  // From PaintCost

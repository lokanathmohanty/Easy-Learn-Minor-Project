main() Function in C

The main() function in C is the entry point of any program. Program execution starts with main(). It performs the main processing and cleans up any resources allocated by the program. While a C program may have many functions, it must have exactly one main() function. Regardless of its position in the code, main() executes first.

Syntax

int main(){
   // one or more statements;
   return 0;
}

The function name must follow identifier naming rules. Typically, main() has no arguments, but can accept command-line arguments.

Valid Signatures

  • int main()
  • int main(void)
  • int main(int argc, char *argv[])

Example

#include <stdio.h>

int main() {
  printf("Hello World");
  return 0;
}

Important Points

  • A C program must contain main().
  • main is a user-defined function, not a C keyword.
  • Conventionally, main() returns 0 to signal successful execution; other values indicate failure.
  • Older compilers may allow void return type, but it is non-standard and discouraged.
  • main() cannot be declared inline, static, called from the program, or have its address taken.

How main() Works

Execution starts at main(). It can call other functions, passing control and optionally arguments. Called functions return control to main() after executing. The program usually terminates when main() returns.

Using exit() in main()

The exit() function can terminate the program early. Use exit(0) for normal termination, exit(1) or other codes for error exit.

#include <stdio.h>
#include <stdlib.h>

int main() {
  for (int i = 1; i <= 5; i++) {
    if (i == 3) {
      printf("\nexiting ..");
      exit(0);
    } else {
      printf("\nNumber is %d", i);
    }
  }
  return 0;
}

Output:

Number is 1
Number is 2
exiting ..

Command-line Arguments

main() can accept arguments from the command line. The signature for this is:

int main(int argc, char *argv[]) {
  // code
  return 0;
}

Explanation:

  • argc: Number of command-line arguments (always ≥ 1)
  • argv: Array of null-terminated strings representing the arguments; argv[0] is the program name.

Example: main() with Command-line Arguments

#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[]) {
  int x, y, z;
  if (argc < 3) {
    printf("insufficient arguments");
  } else {
    x = atoi(argv[1]);
    y = atoi(argv[2]);
    z = x + y;
    printf("addition : %d", z);
  }
  return 0;
}

Run the program via command prompt:

C:\Users\mlath>test 10 20

Output:

addition : 30

This chapter covered the importance and syntax of the main() function in C. Every C program must have one main(), which typically returns 0 to indicate success. Arguments can be passed via the command line if desired.

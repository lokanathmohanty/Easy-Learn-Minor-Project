PHP Boolean (`bool`) Data Type

The **Boolean (`bool`)** data type is a fundamental type in PHP that represents a truth value. A Boolean variable can only hold one of two possible values: **`true`** or **`false`**. These values are case-insensitive (e.g., `TRUE`, `True`, and `true` are all the same). Boolean values are essential for controlling code flow using **conditional statements** and **loops**.

Declaration and Usage

A Boolean variable is declared by simply assigning it the value `true` or `false`. Logical operations and comparisons return Boolean values.

// Declaration
$is_valid = true;
$is_error = FALSE;

// Logical operation returns bool(true)
var_dump ($gender == "Male");

The primary use is in control flow:

<?php
   $is_sunny = true;
   if ($is_sunny) {
      echo "It is a sunny day!";
   }
?>

Boolean Conversion (Truthiness)

When a value of another type is used in a logical context (like an `if` statement or with the **`(bool)` casting operator**), PHP automatically converts it to a Boolean based on a simple set of rules. This is part of **type juggling**.

Values that evaluate to **`false`** (Falsy values):

  • The Boolean `false` itself.
  • The integer `0`.
  • The floating-point number `0.0` or `-0.0`.
  • The empty string `""`.
  • The string `"0"`.
  • An empty array (`array()`).
  • The special type `NULL`.

**All other values** are considered **`true`** (Truthy). This includes non-zero numbers, non-empty strings (even `"False"`), and non-empty arrays/objects.

var_dump((bool)10); $\rightarrow$ `bool(true)`
var_dump((bool)"Hello"); $\rightarrow$ `bool(true)`
var_dump((bool)0); $\rightarrow$ `bool(false)`
var_dump((bool)""); $\rightarrow$ `bool(false)`

Boolean Operators and Comparison

Logical operators are used to combine or manipulate Boolean values:

  • **AND:** `&&` or `and` (Both sides must be true)
  • **OR:** `||` or `or` (At least one side must be true)
  • **NOT:** `!` (Reverses the truth value)

Strict vs. Loose Comparison

When dealing with Booleans, the comparison operator used is crucial due to type juggling:

  • **Loose Comparison (`==`):** Only checks the **value**, allowing type juggling. For example, `true == 1` is `true`.
    var_dump(true == 1); $\rightarrow$ `bool(true)`
  • **Strict Comparison (`===`):** Checks both the **value** AND the **data type**. This is safer and prevents type juggling. For example, `true === 1` is `false`.
    var_dump(true === 1); $\rightarrow$ `bool(false)`

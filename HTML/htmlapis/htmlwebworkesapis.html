HTML - Web Workers API

The HTML Web Workers API is a JavaScript feature that allows computationally intensive tasks to run in the background on a separate thread, without blocking the user interface.

What Are Web Workers?

Web Workers enable long tasks to execute without freezing the page. They run as background scripts and cannot access the window or DOM directly. Although they don’t block the UI, they still consume CPU cycles.

Need of Web Workers

JavaScript runs in a single-threaded environment, meaning multiple tasks cannot run simultaneously. In cases of heavy computation or large API data processing, the browser may hang. Web Workers solve this by offloading heavy tasks to background threads.

Example: Without Web Workers

<script>
function bigLoop() {
  for (var i = 0; i <= 10000000000; i++) {
    var j = i;
  }
  alert("Completed " + j + " iterations");
}
function sayHello() {
  alert("Hello sir....");
}
</script>

How Web Workers Work?

A Web Worker is created using the Worker() constructor with the URL of a JavaScript file. Communication happens with postMessage() from the worker, and the main script receives messages via onmessage.

Example: With Web Worker

<script>
var worker = new Worker('bigLoop.js');
worker.onmessage = function(event) {
  alert("Completed " + event.data + " iterations");
};
function sayHello() {
  alert("Hello sir....");
}
</script>

bigLoop.js

for (var i = 0; i <= 1000000000; i++) {
  var j = i;
}
postMessage(j);

Stopping Web Workers

Use worker.terminate() to stop a running worker. Terminated workers cannot be restarted; you must create a new one.

Handling Web Worker Errors

Errors can be handled using worker.onerror on the main thread.

Example: Error Handling

worker.onerror = function(event) {
  console.error("Error in web worker: " + event.message, event);
  alert("Error occurred in the web worker.");
  event.preventDefault();
};

Checking for Browser Support

Browser support can be detected using Modernizr:

Example: Detect Support

if (Modernizr.webworkers) {
  alert("You have web workers support.");
} else {
  alert("You do not have web workers support.");
}

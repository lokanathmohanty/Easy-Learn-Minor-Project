Overview and Characteristics of .NET Core

**NET Core** is the latest **general-purpose development platform** from Microsoft, fundamentally redesigned to be fast, flexible, and modern. It enables developers to build a wide array of applications (Android, iOS, Linux, Mac, and Windows) using an **Open Source** framework.

Key Characteristics of .NET Core

The following features define the modern nature of the .NET Core platform:

  • **Open Source**: It's an open-source implementation licensed under MIT and Apache 2, available on **GitHub** as a .NET Foundation project. This promotes a transparent development process and an engaged community.
  • **Cross-platform**: Applications can be built and run on three main operating systems: **Windows**, **Linux**, and **MacOS**, ensuring code reusability regardless of the target environment.
  • **Modular**: Unlike the monolithic .NET Framework, .NET Core is released via **NuGet** in smaller, feature-centric assembly packages. This allows developers to include only the packages their app needs, which improves security, performance, and reduces size.
  • **Compatible**: It achieves compatibility with .NET Framework, Xamarin, and Mono through the **.NET Standard Library**.
  • **Command-line tools**: All product scenarios and development tasks can be executed using the command-line interface (CLI).

Flexible Deployment Methods

There are two primary ways to deploy a .NET Core application:

  • **Framework-dependent deployment (FDD)**: The application depends on a **system-wide version** of .NET Core already installed on the host machine. The deployed package is smaller, but the correct runtime version must be present on the target system.
  • **Self-contained deployment (SCD)**: The application is deployed along with the specific **.NET Core runtime** version it was built with, making it completely independent of a pre-installed framework on the host machine. This allows side-by-side execution with other .NET versions but results in a larger deployment package.

The .NET Core Platform Components

The core platform consists of three main parts, plus the host:

  1. **NET Runtime**: Provides essential services like the type system, assembly loading, garbage collector, and native interop.
  2. **Fundamental Libraries**: A collection of framework libraries that offer primitive data types, composition types, and fundamental utilities.
  3. **SDK & Compiler**: The set of tools and language compilers (e.g., C#) that enable the base developer experience.
  4. **dotnet app host**: The executable used to launch .NET Core apps, selecting and hosting the correct runtime.

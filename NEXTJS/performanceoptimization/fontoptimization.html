Next.js - Font Optimization

Font Optimization in Next.js

Next.js features a built-in library, **next/font**, designed to optimize font usage in your application. This system ensures **zero layout shift** (preventing Cumulative Layout Shift - CLS) and offers significant performance benefits through **automatic self-hosting**.

The optimization works by:

  • Self-Hosting: Next.js downloads the font files (including Google Fonts) at **build time**.
  • Local Storage: The files are stored and served alongside your other static assets.
  • Reduced Requests: The browser no longer needs to make additional, slow requests to external font services.

Using Google Fonts in Next.js

To use an external font like Google Fonts, you import the specific font function from **next/font/google**, configure it, and apply the returned **className** to the element or layout where the font should be used.

Example: Using the Inter Google Font

import { Inter } from 'next/font/google';

// Configure the font
const inter = Inter({
  subsets: ['latin'],  // Specify subsets for smaller file size
  weight: '400',       // Optional font weight
});

export default function Home() {
  return (
    <div className={inter.className}>
      <h1>Hello, Next.js with Inter font!</h1>
    </div>
  );
}

Preloading and Scope of Fonts

The scope and preloading behavior of a font depend on where it is configured:

  • In a Layout Page (/app/layout.tsx): The font will be preloaded and available across **all routes** wrapped by that layout. This is the recommended place for primary application fonts.
  • In a Component Page (/app/component/page.tsx): The font will be loaded and preloaded only for that **specific component page**.
  • In the Root Page (e.g., /app/index.tsx, or root layout): The font is available globally on all routes.

When defined in a specific component page, a new font call will be made only when navigating to that route, as the preloading is limited to that component's scope.

Using Local Fonts in Next.js

To optimize and self-host your own font files, use the **next/font/local** library and provide the relative path(s) to the font file(s) via the **src** argument.

Example: Configuring a Local Font

import localFont from 'next/font/local';

// Configure the local font
const myFont = localFont({
  src: './path/to/font.woff2',  // Path to the font file
  weight: '400',                // Optional weight
  style: 'normal',              // Optional style
});

export default function Home() {
  return (
    <div className={myFont.className}>
      <h1>Hello, Next.js with Inter font!</h1>
    </div>
  );
}

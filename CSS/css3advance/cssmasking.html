CSS - mask Property

The mask property in CSS allows you to partially or completely hide an element by applying a mask layer. This property is a shorthand for multiple properties including mask-clip, mask-composite, mask-image, mask-mode, mask-origin, mask-position, mask-repeat, and mask-size.

Syntax

mask: <mask-image> <mask-mode> <mask-composite> <mask-clip> <mask-origin> <mask-position> <mask-repeat> <mask-size> | initial | inherit;

Property Values

  • mask-image: Specifies an image for the mask layer. Default is none.
  • mask-mode: Defines whether the image acts as a luminance or alpha mask. Default is match-source.
  • mask-composite: Sets compositing operation with below mask layers. Default is add.
  • mask-clip: Defines the area affected by the mask image. Default is border-box.
  • mask-origin: Defines the origin position of the mask layer image. Default is border-box.
  • mask-position: Sets starting position of a mask image. Default is 0% 0%.
  • mask-repeat: Specifies how the mask image repeats. Default is repeat.
  • mask-size: Defines the size of the mask image. Default is auto.
  • initial: Resets the property to its default value.
  • inherit: Inherits value from parent element.

Examples of CSS Mask Property

1. Defining Multiple Values using Mask Property

The mask property can combine multiple sub-properties in a single declaration. In this example, mask-image, mask-mode, mask-repeat, mask-position, and mask-size are defined together.

Example:

mask: url("logo.png") no-repeat 45% 50%;

Explanation: Applies a mask image positioned at 45% horizontally and 50% vertically.

2. Using Constituent Properties Individually

Instead of shorthand, you can use individual properties such as mask-image, mask-mode, mask-repeat, mask-position, and mask-size.

Example:

  • mask-image: url("logo.png");
  • mask-mode: match-source;
  • mask-repeat: no-repeat;
  • mask-position: 45%;
  • mask-size: 50%;

This produces the same visual effect as the shorthand example above.

3. Mask Property with Gradients

The mask property can also be used with gradients to create advanced masking effects.

Example:

  • mask: linear-gradient(to right bottom, black, transparent);
  • mask: radial-gradient(circle, black 35%, rgba(0, 0, 0, 0.5) 60%);

These create gradient-based masks that fade out parts of the image.

Windows Runtime and Extension SDKs in UWP

Windows Runtime (WinRT) components are self-contained objects that enable UWP applications to be developed in multiple languages (C#, JavaScript, C++, etc.). UWP apps, in addition to referencing the **.NET Core metapackage**, also reference the **Universal Windows SDK**, which provides access to WinRT functionality.

API Contracts (Modularity of Windows Runtime)

The set of APIs within a device family (like Universal Windows) is broken down into modular units known as **API Contracts**. These contracts allow developers to target specific capabilities available on various devices. The majority of common WinRT APIs are part of the **Universal API Contract**.

  • For example, to access mobile-specific functionality, like battery information, a developer would need to reference the **Windows.Phone.PhoneContract**, which contains these specialized APIs.

Adding Extension SDKs in Visual Studio

To access APIs not included in the default Universal API Contract (e.g., mobile-specific features), you must manually add an **Extension SDK** reference:

  1. In Visual Studio, right-click on **References** in the Solution Explorer.
  2. Select **Add Reference**.
  3. In the Reference Manager, navigate to the **Universal Windows** category.
  4. Under Universal Windows:
    • **Core** refers to the default, foundational Universal Windows APIs.
    • **Extensions** are where you find additional SDKs to extend functionality (e.g., Mobile, Desktop, IoT).
  5. Select the required Extension SDK, such as **Windows Mobile Extensions for the UWP**, ensuring you select the latest available version for updated APIs.
  6. Click **OK**.

The selected extension (e.g., **Windows Mobile Extensions for the UWP**) is then added as a reference, granting access to the new, platform-specific APIs on top of the base UWP functionality.

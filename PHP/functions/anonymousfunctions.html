PHP Anonymous Functions (Closures / Lambda Functions)

An **Anonymous Function** (also called a **Closure** or **Lambda Function**) is a function that is defined without a specified **name**. They are often used for one-time tasks or as inline **callback functions** passed as arguments to other functions.

Definition and Basic Syntax

Anonymous functions are treated as expressions and must be terminated with a semicolon (`;`). They are typically assigned to a variable, which is then used to call the function. They are implemented using PHP's built-in **`Closure`** class.

**Syntax:**
$var = function ($arg1, $arg2) { /* statements */ return $val; **;** };

**Example:**
$add = function ($a, $b) { return $a+$b; };
echo $add(5, 10); // Output: 15

Anonymous Functions as Callbacks

Anonymous functions are excellent for providing custom logic to higher-order functions (functions that accept other functions as arguments), such as array manipulation utilities.

Using an anonymous function as the comparison logic for the `usort()` built-in function:

$arr = [10, 3, 70];
**usort** ($arr, function ($x , $y) {
   return $x > $y; // Custom sorting logic
});

The array `$arr` is sorted to: [3, 10, 70].

Anonymous Functions as Closures (`use` Keyword)

An anonymous function becomes a **Closure** when it captures variables from the scope in which it was defined. This is achieved using the **`use`** keyword. The variables must be explicitly listed in the `use` clause.

$maxmarks = 300;
$percent = function ($marks) **use ($maxmarks)** {
   return $marks * 100 / $maxmarks; // Accessing $maxmarks from outside
};
echo $percent(250); // Output: 83.333...

Static Anonymous Functions

An anonymous function can be declared with the **`static`** keyword. This prevents the function from automatically binding the current class instance (`$this`) to its context.

$myFunction = **static** function($name) { /* ... */ };

This is useful to prevent unintentional access to `$this` when the function does not need object context.

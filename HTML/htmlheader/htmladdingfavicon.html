HTML - Favicon

HTML favicon stands for "favorite icon". It is a small-sized image that displays in the browser's tab just before the page title. Favicon is defined by using the <link> tag with the rel="icon" attribute.

What is a HTML Favicon?

A favicon is a small image that represents your website and helps users identify it among multiple tabs, bookmarks, and search results. It can be in various formats, such as ICO, PNG, GIF, JPEG, or SVG, but ICO is the most widely supported format.

How To Add a Favicon in HTML

You can add a favicon to a webpage by using the <link> tag with the rel attribute set to "icon". The <link> tag must be placed within the <head> tag.

Syntax:

<head>
  <link rel="icon" href="path_to_favicon.ico" type="image/x-icon">
</head>

Steps to Add Favicon on Webpage

  • Step 1: Create or choose an image for your favicon (commonly 16x16 or 32x32 pixels).
  • Step 2: Save and upload the favicon image to the website directory.
  • Step 3: Use the <link> element inside the <head> of the HTML document.

Example

<!DOCTYPE html>
<html>
<head>
   <title>Tutorialspoint</title>
   <link rel="icon" type="image/png" href="images/faviconTP.png">
</head>
<body>
   <h1>Adding Favicon</h1>
   <p>This is an example of including favicon to the web page.</p>
   <p>Favicon will be displayed in the browser tab to the left of the page title.</p>
</body>
</html>

Different Favicons for Different Pages

You can add different favicons for different pages of a website by placing unique <link> tags inside each page’s <head>.

Example:

<head>
  <title>Page Title 1</title>
  <link rel="icon" href="favicon1.ico" type="image/x-icon">
</head>

<head>
  <title>Page Title 2</title>
  <link rel="icon" href="favicon2.ico" type="image/x-icon">
</head>

  • 192x192 − Google Developer Apps
  • 195x195 − Opera Speed Dial

  • Safari − GIF, PNG, JPEG, SVG, ICO

.NET Core - Migrations (project.json to *.csproj)

This chapter focuses on migrating an older .NET Core project that uses the **project.json** build system to the newer **MSBuild (*.csproj)** system, which is required by the **.NET Core 2.0 preview 1 tooling** and later versions.

The Need for Migration

Projects created with older tooling (e.g., **.NET Core 1.0 preview 2**) use the **project.json** file for configuration and dependencies. Since **.NET Core 2.0** no longer supports this system, attempting to build an old project with the new command-line utility will result in an error:

Build Error (Pre-Migration)

Attempting to run dotnet build on a project.json-based project with .NET Core 2.0 tooling fails because the build system is unrecognized.

To ensure compatibility and successful builds, the project must be migrated.

Running the Migration Command

The .NET Core CLI provides a dedicated command for this transition. First, confirm the command's availability:

Checking Available Commands

dotnet help

The output shows the **migrate** command, which converts a project.json-based project to an MSBuild-based project.

Execute the following command in the project root directory:

Migration Command

dotnet migrate

The utility provides a summary confirming that the project has been migrated successfully.

Post-Migration Structure

After migration, the project directory structure changes:

  • The new ***.csproj** file (e.g., **console.csproj**) is created in the project root.
  • The original **project.json** file is moved to a **backup folder** to preserve the old configuration.

The new structure can be verified using tree /f, showing the presence of the new *.csproj file.

Restoring and Building the Migrated Project

The project can now be treated as a standard MSBuild project.

1. Restoring Packages

The new *.csproj file is used to define dependencies, which must be restored:

Restoring Packages

dotnet restore

The MSBuild system successfully restores all necessary NuGet packages.

2. Building the Project

The project can now be built successfully using the .NET Core 2.0 tooling:

Building the Project

dotnet build

The project builds successfully, generating the compiled assembly (e.g., **console.dll**) in the appropriate output folder (e.g., ..\bin\Debug\netcoreapp1.0).

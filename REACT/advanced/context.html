ReactJS - Context

Context provides a way to pass information from a parent component to deeply nested children without manually passing props through each level. It improves readability and reduces complexity when managing shared data.

Common Use Cases

  • Application configuration
  • Current authenticated user information
  • Current user settings
  • Language preference
  • Theme or design configuration

How Context Works

Context involves four main steps:

  • Creating a new context
  • Wrapping the application in a Context Provider
  • Using a Context Consumer inside components
  • Accessing and rendering the context values

Example: Creating Context

import React from 'react';

const ThemeContext = React.createContext({
   color: 'black',
   backgroundColor: 'white'
});

export default ThemeContext;

Providing Context

import './App.css';
import HelloWorld from './components/HelloWorld';
import ThemeContext from './ThemeContext';

function App() {
   return (
      <ThemeContext.Provider value={{
         color: 'white',
         backgroundColor: 'green'
      }}>
         <HelloWorld />
      </ThemeContext.Provider>
   );
}

export default App;

Consuming Context

import React from "react";
import ThemeContext from "../ThemeContext";

class HelloWorld extends React.Component {
   render() {
      return (
         <ThemeContext.Consumer>
            {({ color, backgroundColor }) => (
               <div style={{ color, backgroundColor }}>
                  Hello World
               </div>
            )}
         </ThemeContext.Consumer>
      );
   }
}

export default HelloWorld;

Summary

Context simplifies sharing global data across a React application. By using providers and consumers, components can easily access shared values such as themes, user settings, or configurations without excessive prop drilling.

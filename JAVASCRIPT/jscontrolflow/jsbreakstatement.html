Overview

The break statement terminates the current loop or switch block immediately. Execution continues with the statement that follows the terminated statement. When used inside nested loops, break exits only the loop in which it appears unless used with a label.

Syntax

break;

break labelName;

The label is optional and can be used to target an outer loop.

Behavior

  • Exits the nearest enclosing loop or switch statement.

  • When used with a label, it exits the labeled statement.

  • Useful to stop processing early when a condition is met.

Example — break with a for loop

Loop example that stops when x equals 5:

for (let x = 1; x < 10; x++) { if (x == 5) { break; } /* use x */ }

Output sequence: 1, 2, 3, 4

Example — break with a while loop

Loop example that exits when x is 3 or 7:

let x = 1; while (x < 10) { if (x == 3 || x == 7) { break; } x = x + 1; /* use x */ }

Example output when condition triggers early: 2, 3

Example — break in nested loops

Inner loop break only exits the inner loop; outer loop continues unless it also executes a break:

for (let x = 1; x < 10; x++) { for (let y = 1; y < 10; y++) { if (y == 3) break; /* inner */ } if (x == 3) break; /* outer */ }

Result: pairs printed while inner < 3, stopping entirely when x == 3.

Example — break with switch

Use break to prevent fall-through in a switch:

switch (p) { case 10: /* ... */ break; case 20: /* ... */ break; default: /* ... */ }

When a case matches and runs, the following break stops execution of the switch block.

Using labels with break

You can label loops and use break labelName; to exit an outer loop from within an inner loop. Place the label immediately before the loop you want to target.

Example pattern: outerLoop: for (...) { inner: for (...) { if (condition) break outerLoop; } }

Common Pitfalls

  • Relying on break for normal loop termination can make logic harder to follow if overused.

  • Incorrect label placement or spelling prevents the labeled break from targeting the intended loop.

  • Using break inside try/finally blocks may still execute finally blocks — be mindful of side effects.

Practice Tasks

  • Write a loop that searches an array for the first negative number and breaks when found.

  • Create nested loops and use a labeled break to exit both loops when a condition is met.

  • Implement a switch with several cases and ensure each case uses break to avoid fall-through.

Summary

The break statement is a simple but powerful control tool to exit loops or switch blocks immediately. Use it to stop processing when a target condition is reached, and consider labeled breaks only when nested-loop control is necessary.

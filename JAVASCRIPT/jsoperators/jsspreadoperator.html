JavaScript - Spread Operator

What is a Spread Operator?

The JavaScript spread operator (...) allows us to spread out elements of an iterable such as an array. It was introduced in ES6. The main use cases of the spread operator are copying array elements, concatenating arrays or objects, and using with rest parameters.

Example: Expanding Array Elements

let x = ["Tutorials", "Point"];
console.log(x); // [ 'Tutorials', 'Point' ]
console.log(...x); // Tutorials Point

Spread Operator to Concatenate Arrays

The spread operator can be used to concatenate arrays.

Example

<html>
<body>
   <div id="output"></div>
   <script>
      const nums1 = [10, 20, 30];
      const nums2 = [40, 50, 60];
      const res = [...nums1, ...nums2];
      document.getElementById("output").innerHTML = res;
   </script>
</body>
</html>

Output: 10,20,30,40,50,60

Spread Operator to Clone an Array

Assigning one array to another references the same memory location. The spread operator creates an actual copy instead.

Example: Without Spread Operator

<html>
<body>
   <div id="result1"></div>
   <div id="result2"></div>
   <script>
      const nums1 = [10, 20, 30];
      const nums2 = nums1;
      document.getElementById("result1").innerHTML = nums2;
      nums1.push(40);
      document.getElementById("result2").innerHTML = nums2;
   </script>
</body>
</html>

Output:

  • 10,20,30
  • 10,20,30,40

Example: With Spread Operator

<html>
<body>
   <div id="result1"></div>
   <div id="result2"></div>
   <script>
      const nums1 = [10, 20, 30];
      const nums3 = [...nums1];
      document.getElementById("result1").innerHTML = nums3;
      nums1.push(50);
      document.getElementById("result2").innerHTML = nums1 + "<br>";
      document.getElementById("result2").innerHTML += nums3;
   </script>
</body>
</html>

Output:

  • 10,20,30
  • 10,20,30,50
  • 10,20,30

Spread Operator to Concatenate Objects

The spread operator can also copy object properties into another object.

Example

<html>
<body>
   <div id="result1"></div>
   <div id="result2"></div>
   <script>
      const car = { gears: 6, color: "Black" }
      document.getElementById("result1").innerHTML = JSON.stringify(car);

      const BMW = { model: "X5", year: 2019, ...car }
      document.getElementById("result2").innerHTML = JSON.stringify(BMW);
   </script>
</body>
</html>

Output:

  • {"gears":6,"color":"Black"}
  • {"model":"X5","year":2019,"gears":6,"color":"Black"}

Function Rest Parameters

The spread operator can also be used with rest parameters in functions.

Example

<html>
<body>
   <div id="result"></div>
   <script>
      function sum(a, ...nums) {
         let sum = a;
         for (let i = 0; i < nums.length; i++) {
            sum += nums[i];
         }
         document.getElementById("result").innerHTML = sum;
      }
      sum(3, 6, 9, 8, 6, 5, 3, 3, 2, 1);
   </script>
</body>
</html>

Output: 46

The spread operator can also expand strings into arrays of characters, clone strings, or work with iterable objects like Set and Map.

R - Loops

In many situations, a block of code needs to be executed multiple times. By default, statements are executed sequentially, but programming languages provide loop constructs for repeated execution. R offers several loop types to handle such requirements.

  • repeat loop: Executes code multiple times and simplifies loop variable handling.
  • while loop: Repeats statements while a condition is true, testing before execution.
  • for loop: Iterates over sequences, typically testing the condition at the end of the loop body.

Loop Control Statements

  • break: Terminates the loop and transfers control to the statement following the loop.
  • next: Skips to the next iteration without executing remaining statements in the current iteration.

Example: Repeat Loop

v <- LETTERS[1:4]
i <- 0
repeat {
  print(v[i])
  i <- i + 1
  if(i > 4) {
    break
  }
}

Output:

[1] "A"
[1] "B"
[1] "C"
[1] "D"

Example: While Loop

v <- LETTERS[1:4]
i <- 0
while(i < 5) {
  print(v[i])
  i <- i + 1
}

Output:

character(0)
[1] "A"
[1] "B"
[1] "C"

Example: For Loop

list1 <- list(a = 1:3, b = "hello", c = TRUE)
for (item in list1) {
  print(item)
}

Output:

[1] 1 2 3
[1] "hello"
[1] TRUE

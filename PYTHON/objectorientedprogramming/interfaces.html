Python - Interfaces

An interface in software design defines a set of method signatures that must be implemented by any class that claims to implement the interface. Python implements interfaces using abstract base classes (ABC) and the @abstractmethod decorator.

In Python, all methods in an interface must be abstract, and instantiating an interface directly is not allowed. Any concrete class must provide implementations for all abstract methods to avoid being abstract itself.

Formal Interface (with ABC)

Formal interfaces use ABC from Python's abc module and enforce method implementation.

Formal Interface Example

from abc import ABC, abstractmethod

class DemoInterface(ABC):
    @abstractmethod
    def method1(self):
        pass
    @abstractmethod
    def method2(self):
        pass

class ConcreteClass(DemoInterface):
    def method1(self):
        print("This is method1")
    def method2(self):
        print("This is method2")

obj = ConcreteClass()
obj.method1()      # Output: This is method1
obj.method2()      # Output: This is method2

Informal Interface (Duck Typing)

An informal interface just defines method signatures, but Python cannot enforce that they are implemented. This style relies on duck typing: if a class implements the required method, it can be used wherever the interface is expected.

Informal Interface Example

class DemoInterface:
    def displayMsg(self):
        pass

class NewClass(DemoInterface):
    def displayMsg(self):
        print("This is my message")

obj = NewClass()
obj.displayMsg()   # Output: This is my message
  • Python interfaces are best created using abstract base classes for strict enforcement of required methods.
  • Informal interfaces provide flexibility but rely on developer discipline and duck typing for correctness.

NumPy Hyperbolic Functions

NumPy provides the ufuncs sinh(), cosh(), and tanh() that take values in radians and produce the corresponding hyperbolic sine, cosine, and tangent values.

Example: Find sinh value of PI/2

import numpy as np

x = np.sinh(np.pi/2)

print(x)

Example: Find cosh values for an array

import numpy as np

arr = np.array([np.pi/2, np.pi/3, np.pi/4, np.pi/5])

x = np.cosh(arr)

print(x)

Finding Angles from Hyperbolic Functions

NumPy provides inverse hyperbolic functions arcsinh(), arccosh(), and arctanh() that produce radian values from given hyperbolic sine, cosine, and tangent values.

Example: Find angle of 1.0 using arcsinh()

import numpy as np

x = np.arcsinh(1.0)

print(x)

Example: Find angles for all tanh values in an array

import numpy as np

arr = np.array([0.1, 0.2, 0.5])

x = np.arctanh(arr)

print(x)

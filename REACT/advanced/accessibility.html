ReactJS - Accessibility

Accessibility (a11y) ensures web applications are usable by everyone, including those relying on assistive technologies. React supports accessibility through ARIA attributes, semantic HTML, form labeling, keyboard support, and third-party ARIA components.

ARIA (aria-*) Attributes

WAI-ARIA (Web Accessibility Initiative - Accessible Rich Internet Applications) provides attributes (aria-*) to make UI widgets accessible. React supports these attributes directly in kebab-case. 

<input
   type="text"
   aria-label={labelText}
   aria-required="true"
   name="name"
/>
  • aria-label → Specifies the label for the input element.
  • aria-required → Specifies that the input must be filled.

Semantic HTML

Semantic tags (article, section, nav, etc.) improve accessibility. React’s Fragment helps avoid unnecessary <div> wrappers. 

// Using <div> wrapper
function ShowItems({ data }) {
   return (
      <div>
         <dt>{data.title}</dt>
         <dd>{data.description}</dd>
      </div>
   );
}

// Using <Fragment>
function ShowItems({ data }) {
   return (
      <Fragment>
         <dt>{data.title}</dt>
         <dd>{data.description}</dd>
      </Fragment>
   );
}

Forms

Every input should have a descriptive label. React uses htmlFor to associate labels with form fields. 

<label htmlFor="firstName">Firstname:</label>
<input id="firstName" type="text" name="name" />

Keyboard Support

Accessible apps must work fully with keyboards:

  • Focus → Use Ref or forwardRef to manage DOM focus.
  • Skip links → Allow users to skip navigation.
<body>
   <a href="#maincontent">Skip to main content</a>
   ...
   <main id="maincontent">
      ...
   </main>
</body>

Mouse interactions should also be adapted to keyboard alternatives. React event handling makes this possible.

Aria Components

The React community provides components with built-in accessibility:

  • react-aria – complete ARIA support for many components
  • react-modal, react-aria-modal – accessible modal dialogs
  • react-select, react-dropdown-aria – accessible select/dropdowns
  • react-aria-menubutton – accessible menu buttons
  • react-aria-tabpanel – accessible tab panels

Summary

React provides strong accessibility support via ARIA attributes, semantic HTML, form labeling, keyboard navigation, and third-party libraries. With these, developers can build fully accessible, inclusive applications.

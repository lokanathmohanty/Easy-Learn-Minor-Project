NULL Pointer in C

What is a NULL Pointer?

A NULL pointer in C is a pointer that does not point to any valid memory location. The macro NULL is defined in standard headers like stdio.h, stddef.h, and stdlib.h. :contentReference[oaicite:0]{index=0}

Declare and Initialize a NULL Pointer

You can declare and initialize a NULL pointer in two common ways:

type *ptr = NULL;
type *ptr = 0;

Example of a NULL Pointer

#include <stdio.h>

int main() {
  int *p = NULL;  // initialize the pointer to NULL
  printf("The value of pointer is %u", p);
  return 0;
}

Output:

The value of pointer is 0.

Applications of NULL Pointer

  • To initialize pointers when they don’t yet point to a valid address.
  • To pass NULL to function arguments when no address is to be passed.
  • To check if a pointer is valid before dereferencing it, preventing crashes.
  • Used in data structures (linked lists, trees) to signal the end or absence of a node.

Check Whether a Pointer is NULL

Always verify a pointer is not NULL before dereferencing it:

#include <stdio.h>

int main() {
  int *ptr = NULL;  // null pointer

  if (ptr == NULL) {
    printf("Pointer is a NULL pointer");
  } else {
    printf("Value at pointer: %d", *ptr);
  }
  return 0;
}

Output:

Pointer is a NULL pointer

Using NULL Pointer to Check Allocation

Memory allocation functions like malloc() or calloc() return NULL when allocation fails. Use this to validate allocation success.

#include <stdlib.h>
#include <stdio.h>

int main() {
  int *ptr = (int *)malloc(sizeof(int));

  if (ptr == NULL) {
    printf("Memory Allocation Failed");
    exit(0);
  } else {
    printf("Memory Allocated successfully");
  }
  return 0;
}

NULL File Pointer Example

When working with files, always check if fopen() returned a NULL FILE pointer to detect errors opening the file:

#include <stdio.h>

int main() {
  FILE *fp = fopen("file3.txt", "r");

  if (fp == NULL) {
    puts("Cannot open file");
    return 0;
  }

  // proceed with reading file...
  fclose(fp);
  return 0;
}

Summary

Using NULL is a good defensive programming practice in C. Always initialize pointers to NULL when they don’t yet point to valid memory, check for NULL before dereferencing them, and handle NULL from functions (such as memory allocation) gracefully. Dereferencing a NULL pointer is undefined behavior and often causes a runtime crash (segmentation fault). :contentReference[oaicite:1]{index=1}

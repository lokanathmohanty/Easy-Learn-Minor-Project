Java - Set Interface

A Set is a Collection that cannot contain duplicate elements. It models the mathematical set abstraction.

The Set interface inherits methods from Collection but prohibits duplicate elements and enforces a stronger contract on equals and hashCode methods.

Set Interface Methods

  • add(): Adds an object to the collection.
  • clear(): Removes all objects from the collection.
  • contains(): Checks if an object exists in the collection.
  • isEmpty(): Checks if the collection is empty.
  • iterator(): Returns an Iterator to traverse the collection.
  • remove(): Removes a specified object from the collection.
  • size(): Returns the number of elements in the collection.

Example 1: Implementing Set Using HashSet

This example demonstrates using a HashSet to store unique integers:

import java.util.HashSet;
import java.util.Set;

public class SetDemo {
  public static void main(String args[]) { 
      int count[] = {34, 22, 10, 60, 30, 22};
      Set<Integer> set = new HashSet<>();
      try {
         for(int i = 0; i < 5; i++) {
            set.add(count[i]);
         }
         System.out.println(set);
      } catch(Exception e) {}
   }
}

Output: [34, 22, 10, 60, 30]

Example 2: Implementing Set Using TreeSet

This example shows how to use TreeSet to sort elements automatically:

import java.util.HashSet;
import java.util.Set;
import java.util.TreeSet;

public class SetDemo {
  public static void main(String args[]) { 
      int count[] = {34, 22, 10, 60, 30, 22};
      Set<Integer> set = new HashSet<>();
      try {
         for(int i = 0; i < 5; i++) {
            set.add(count[i]);
         }
         System.out.println(set);

         TreeSet<Integer> sortedSet = new TreeSet<>(set);
         System.out.println("The sorted list is:");
         System.out.println(sortedSet);

         System.out.println("The First element of the set is: " + sortedSet.first());
         System.out.println("The last element of the set is: " + sortedSet.last());
      } catch(Exception e) {}
   }
}

Output:

[34, 22, 10, 60, 30]

The sorted list is:

[10, 22, 30, 34, 60]

The First element of the set is: 10

The last element of the set is: 60

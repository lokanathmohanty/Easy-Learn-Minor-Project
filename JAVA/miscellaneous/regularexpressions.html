Java - Regular Expressions (java.util.regex)

Overview of Java Regular Expressions

Java provides robust support for **Regular Expressions (Regex)** through the **java.util.regex** package. Regex is a specialized syntax for describing and matching patterns within strings. Java's implementation is similar to that of Perl.

Core Regex Classes

The java.util.regex package revolves around three main classes:

  • Pattern Class: Represents the **compiled form** of a regular expression. It provides the static compile() method to create a Pattern object from a regex string.
  • Matcher Class: The **engine** that performs match operations against an input string using a Pattern object. A Matcher object is obtained by invoking matcher() on a Pattern object.
  • PatternSyntaxException: An unchecked exception thrown when a regular expression pattern has a syntax error.

Example Workflow:

String regex = "(.*)(\\d+)(.*)";
Pattern p = Pattern.compile(regex); // 1. Compile the pattern
Matcher m = p.matcher(inputString); // 2. Create the matcher engine
if (m.find()) { // 3. Execute the operation
    // ...
}

Key Regex Syntax and Metacharacters

Regex uses a specialized syntax of metacharacters and quantifiers to define patterns:

Quantifiers (Repetition)

  • re*: Matches 0 or more occurrences of re.
  • re+: Matches 1 or more occurrences of re.
  • re?: Matches 0 or 1 occurrence of re.
  • re{n}: Matches exactly $n$ occurrences.

Character Classes and Shorthands

  • .: Matches any single character except newline.
  • [...]: Matches any single character contained within the brackets.
  • [^...]: Matches any single character **not** contained within the brackets.
  • \d / \D: Matches digit / non-digit (Equivalent to [0-9] / [^0-9]).
  • \w / \W: Matches word / non-word character (alphanumeric plus underscore).
  • \s / \S: Matches whitespace / non-whitespace.

Boundaries and Grouping

  • ^ / $: Matches the beginning / end of a line.
  • \b / \B: Matches a word boundary / non-word boundary.
  • (re): **Capturing Group.** Groups expressions and remembers the matched text (numbered 1 and up).
  • (?:re): **Non-Capturing Group.** Groups expressions without remembering the matched text.

Matcher Class Key Methods

Study Methods (Matching)

These methods attempt to match the input sequence against the pattern:

  • find(): Attempts to find the **next** subsequence of the input that matches the pattern. Returns true if found.
  • matches(): Attempts to match the **entire** region against the pattern. Returns true only if the whole input string matches.
  • lookingAt(): Attempts to match the input sequence, starting **at the beginning** of the region, against the pattern. It does not require the entire input to match.

Index Methods (Match Information)

These methods are called after a successful match (e.g., after find() or matches()):

  • start() / end(): Returns the start index / (end index + 1) of the match for the entire expression (group 0).
  • start(int group) / end(int group): Returns the start index / (end index + 1) for the subsequence captured by the specified group.
  • group(int group): Returns the actual matched text captured by the specified group.

Replacement Methods

  • replaceAll(String replacement): Replaces **every** subsequence match with the given replacement string.
  • replaceFirst(String replacement): Replaces **only the first** subsequence match.
  • appendReplacement(StringBuffer sb, String replacement) / appendTail(StringBuffer sb): Methods used for implementing custom, complex replacement logic by incrementally building the result in a StringBuffer.

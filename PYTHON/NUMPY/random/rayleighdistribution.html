Rayleigh Distribution

The Rayleigh distribution is commonly used in signal processing.

Parameters:

  • scale — Standard deviation, decides how flat the distribution will be (default 1.0).
  • size — The shape of the returned array.

Example: Generating Rayleigh Distribution Samples

Generate a 2x3 sample from a Rayleigh distribution with scale 2:

from numpy import random

x = random.rayleigh(scale=2, size=(2, 3))

print(x)

Visualization of Rayleigh Distribution

Visualize 1000 samples from a Rayleigh distribution using Seaborn:

from numpy import random
import matplotlib.pyplot as plt
import seaborn as sns

sns.displot(random.rayleigh(size=1000), kind="kde")

plt.show()

Similarity Between Rayleigh and Chi Square Distribution

At unit standard deviation and 2 degrees of freedom, Rayleigh and Chi Square distributions represent the same distribution.

ReactJS - Using useEffect

React provides useEffect to perform side effects in a component. Some common side effects include:

  • Fetching data from an external source
  • Updating DOM elements after rendering
  • Managing subscriptions
  • Using timers
  • Logging

In class-based components, these were handled by lifecycle methods such as componentDidMount, componentDidUpdate, and componentWillUnmount. The useEffect hook replaces these lifecycle events in function components.

Example

Below is an example of fetching data with useEffect: 

import { useState, useEffect } from "react";

function NameList() {
   const [data, setData] = useState([]);
   const [isLoading, setLoading] = useState(true);

   useEffect(() => {
      fetch("json/names.json")
         .then(res => res.json())
         .then(json => {
            setData(json);
            setLoading(false);
         });
   }, []);

   return (
      <div>
         {isLoading && <span>Loading...</span>}
         {!isLoading && data.map(item => 
            <span key={item.id}>{item.name} </span>
         )}
      </div>
   );
}

export default NameList;

In this example, data is fetched only once after the initial render because an empty dependency array [] is passed to useEffect.

C# Operators: Types and Precedence

Operator Categories

An **operator** is a symbol that instructs the compiler to perform a specific mathematical or logical manipulation. C# includes a rich set of built-in operators categorized as follows:

  • Arithmetic Operators: For mathematical operations (e.g., +, -, *, /, %).
  • Relational Operators: For comparing two operands, returning true or false (e.g., ==, !=, >, <).
  • Logical Operators: For combining Boolean expressions (e.g., &&, ||, !).
  • Bitwise Operators: For performing bit-by-bit operations (e.g., &, |, ^, <<, >>).
  • Assignment Operators: For assigning values and combining assignment with operations (e.g., =, +=, -=).
  • Miscellaneous Operators: Special operators like the ternary operator (? :), sizeof, typeof, is, and as.

Assignment and Ternary Operators (Example)

Assignment Operators

These operators assign values, often combining an arithmetic or bitwise operation with assignment. For example, C += A is equivalent to C = C + A.

int num = 10;
num += 5;  // Equivalent to num = 15
Console.WriteLine(num); // Output: 15

Ternary Operator (Conditional Expression)

The ternary operator (? :) is a shortcut for an if-else statement that requires three operands (Condition ? Value if True : Value if False).

int age = 18;
string result = (age >= 18) ? "Eligible to vote" : "Not eligible";
Console.WriteLine(result); // Output: Eligible to vote

Miscellaneous Operators

These specialized operators are used for tasks like type checking and metadata retrieval:

  • typeof(): Returns the type of a class or data type (e.g., typeof(int)).
  • sizeof(): Returns the size in bytes of a data type (e.g., sizeof(int) returns 4).
  • is: Determines whether an object is of a certain type.
  • as: Casts without raising an exception; returns null if the cast fails.

Operator Precedence

Operator precedence dictates the order in which operators in an expression are evaluated. Operators with higher precedence (like multiplication *) are evaluated before those with lower precedence (like addition +).

Parentheses () can be used to override the default precedence. For example, in x = 7 + 3 * 2, the result is 13 because * is done before +. To get 20, you must use x = (7 + 3) * 2.

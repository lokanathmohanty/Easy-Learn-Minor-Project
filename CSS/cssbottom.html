CSS bottom Property

The CSS bottom property is used to define the bottom position of a positioned element. It specifies the distance between the bottom edge of the element and the bottom edge of its containing element. The way this property works depends on the position value (absolute, relative, fixed, sticky). For elements with static position, the bottom property has no effect.

Syntax

bottom: auto | length | percentage | initial | inherit;

Property Values

  • auto: Default value. Lets the browser calculate the position.
  • length: Sets distance in units like px, em. Negative values are valid.
  • percentage: Sets distance as a percentage of the containing element’s height. Negative values are valid.
  • initial: Resets the property to its default value.
  • inherit: Inherits the value from the parent element.

Bottom Property with Absolute Position

When used with position: absolute, the bottom property places the element relative to its first positioned ancestor (non-static). The offset is measured from the bottom edge of the parent.

Example

.container {
  position: relative;
  height: 400px;
}
.box {
  position: absolute;
  bottom: 150px;
}
.box2 {
  position: absolute;
  bottom: 10%;
}
.box3 {
  position: absolute;
  bottom: auto;
}

Here, box is placed 150px from the bottom, box2 is placed 10% above the bottom, and box3 defaults to auto (calculated by the browser).

Bottom Property with Relative Position

When used with position: relative, the bottom property shifts the element relative to its normal position in the flow.

Example

.box {
  position: relative;
  bottom: auto;
}
.box2 {
  position: relative;
  bottom: 55%;
}
.box3 {
  position: relative;
  bottom: 25px;
}

In this case, box2 moves up by 55% of its containing block, and box3 moves up by 25px, while box remains unchanged (auto).

Bottom Property with Fixed Position

With position: fixed, the element is placed relative to the viewport and stays in that position even when the page scrolls.

Example

.box {
  position: fixed;
  bottom: auto;
}
.box2 {
  position: fixed;
  bottom: 75px;
}
.box3 {
  position: fixed;
  bottom: 2%;
}

Here, box2 is always fixed 75px from the viewport bottom, and box3 is 2% above the viewport’s bottom edge.

Bottom Property with Sticky Position

With position: sticky, the element toggles between relative and fixed positioning depending on scroll position. The bottom property determines how close it can get to the container’s bottom edge before stopping.

Example

.box {
  position: sticky;
  bottom: auto;
}
.box2 {
  position: sticky;
  bottom: 10px;
}
.box3 {
  position: sticky;
  bottom: 10%;
}

Here, box2 sticks 10px from the container’s bottom, and box3 sticks 10% above the bottom.

Important Note

For elements with position: static (the default), the bottom property has no effect. The element will remain in the normal flow of the document.

Supported Browsers

  • Chrome: 1.0+
  • Edge: 5.0+
  • Firefox: 1.0+
  • Safari: 1.0+
  • Opera: 6.0+

Key Takeaways

  • bottom only works on positioned elements (relative, absolute, fixed, sticky).
  • It specifies how far an element is offset from its containing block or viewport.
  • Negative values are allowed, pushing the element outside its container.
  • static elements ignore bottom.

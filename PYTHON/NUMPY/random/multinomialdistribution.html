Multinomial Distribution

The Multinomial Distribution is a generalization of the binomial distribution.

While the binomial distribution describes the number of successes in a sequence of two possible outcomes (like heads or tails in a coin toss), the multinomial distribution describes the outcomes for experiments with multiple possible outcomes (e.g., rolling a dice, or blood types in a population).

Parameters:

  • n — Number of times to run the experiment (number of trials).
  • pvals — A list of probabilities for each possible outcome. For a fair 6-sided die, this would be [1/6, 1/6, 1/6, 1/6, 1/6, 1/6].
  • size — The shape of the output array (number of experiments to simulate).

Note that multinomial samples return counts for each possible outcome, not a single value.

With enough trials and proper parameters, the multinomial distribution approaches a normal distribution for each outcome.

Example: Dice Roll with Multinomial Distribution

Roll a dice 6 times and count the outcomes using NumPy:

from numpy import random

x = random.multinomial(n=6, pvals=[1/6]*6)

print(x)

This will output something like:

[0 1 2 1 1 1]

Meaning:

  • 0 times outcome 1
  • 1 time outcome 2
  • 2 times outcome 3
  • 1 time outcome 4
  • 1 time outcome 5
  • 1 time outcome 6

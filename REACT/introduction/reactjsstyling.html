ReactJS - Styling

In general, React allows components to be styled using CSS classes through the className attribute. Since React JSX supports JavaScript expressions, several CSS methodologies can be used. Some of the top options are:

  • CSS stylesheet − Normal CSS styles along with className.
  • Inline styling − CSS styles as JavaScript objects with camelCase properties.
  • CSS Modules − Locally scoped CSS styles.
  • Styled components − Component-level styles.
  • Sass stylesheet − Supports Sass-based CSS styles compiled to normal CSS.
  • Post-processing stylesheet − Supports post-processing styles compiled to normal CSS.

Let us learn how to apply the three important methodologies to style React components:

  • CSS Stylesheet
  • Inline Styling
  • CSS Modules

CSS Stylesheet

CSS stylesheet is the most common and time-tested methodology. Simply create a CSS file for a component and define styles. Then, in the component, use className to apply the styles.

/* ExpenseEntryItem.css */
div.itemStyle { 
   color: brown; 
   font-size: 14px; 
}

// ExpenseEntryItem.js
import React from 'react';
import './ExpenseEntryItem.css';

class ExpenseEntryItem extends React.Component {
   render() {
      return (
         <div className="itemStyle">
            <div><b>Item:</b> <em>Mango Juice</em></div>
            <div><b>Amount:</b> <em>30.00</em></div>
            <div><b>Spend Date:</b> <em>2020-10-10</em></div>
            <div><b>Category:</b> <em>Food</em></div>
         </div>
      );
   }
}
export default ExpenseEntryItem;

Note: This approach is simple but can lead to conflicts in large projects.

Inline Styling

Inline styling is one of the safest ways to style React components. It defines styles as JavaScript objects using camelCase properties and applies them via the style attribute.

// Inside ExpenseEntryItem.js
itemStyle = {
   color: 'brown', 
   fontSize: '14px' 
}

render() {
   return (
      <div style={ this.itemStyle }>
         <div><b>Item:</b> <em>Mango Juice</em></div>
         <div><b>Amount:</b> <em>30.00</em></div>
         <div><b>Spend Date:</b> <em>2020-10-10</em></div>
         <div><b>Category:</b> <em>Food</em></div>
      </div>
   );
}

Inline styles can also be defined directly within the style attribute:

<div style={{ color: 'brown', fontSize: '14px' }}>...</div>

CSS Modules

CSS Modules provide a safe and easy way to define component styles. They use normal CSS syntax but generate locally scoped class names to avoid conflicts.

/* ExpenseEntryItem.module.css */
div.itemStyle {
   color: brown; 
   font-size: 14px; 
}

File naming convention is important. Only files ending with .module.css are treated as CSS Modules.

// ExpenseEntryItem.js
import React from 'react';
import styles from './ExpenseEntryItem.module.css';

class ExpenseEntryItem extends React.Component {
   render() {
      return (
         <div className={styles.itemStyle}>
            <div><b>Item:</b> <em>Mango Juice</em></div>
            <div><b>Amount:</b> <em>30.00</em></div>
            <div><b>Spend Date:</b> <em>2020-10-10</em></div>
            <div><b>Category:</b> <em>Food</em></div>
         </div>
      );
   }
}
export default ExpenseEntryItem;

With CSS Modules, styles remain scoped to their components, preventing naming conflicts.

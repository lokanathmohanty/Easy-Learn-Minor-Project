Binomial Distribution

Binomial Distribution is a Discrete Distribution.

It describes the outcome of binary scenarios, e.g. toss of a coin, which will either be heads or tails.

Parameters:

  • n - Number of trials.
  • p - Probability of occurrence of each trial (e.g. for a coin toss, 0.5 each).
  • size - The shape of the returned array.

Discrete Distribution: The distribution is defined at a separate set of events, e.g., a coin toss's result is discrete (heads or tails), whereas height is continuous (can be 170, 170.1, 170.11, etc.).

Example: Generate 10 data points for 10 trials of a coin toss

from numpy import random

x = random.binomial(n=10, p=0.5, size=10)

print(x)

Visualization of Binomial Distribution

from numpy import random
import matplotlib.pyplot as plt
import seaborn as sns

sns.displot(random.binomial(n=10, p=0.5, size=1000))

plt.show()

Difference Between Normal and Binomial Distribution

The main difference is that the normal distribution is continuous whereas binomial is discrete. However, with enough data points, the binomial distribution will resemble the normal distribution with certain loc and scale parameters.

Example: Comparing Normal and Binomial distributions

from numpy import random
import matplotlib.pyplot as plt
import seaborn as sns

data = {
  "normal": random.normal(loc=50, scale=5, size=1000),
  "binomial": random.binomial(n=100, p=0.5, size=1000)
}

sns.displot(data, kind="kde")

plt.show()

C - The if-else Statement

The if-else statement is one of the frequently used decision-making statements in C. It provides an alternative path of execution when the condition is not met. The use of else is optional.

Syntax of if-else Statement

if (Boolean expr) {
   Expression;
   ...
}
else {
   Expression;
   ...
}

If the condition is true, the if block runs. If false, the else block runs.

Example: Tax Calculation

#include <stdio.h>

int main() {
   int income = 5000;
   float tax;
   printf("Income: %d\n", income);

   if (income < 10000) {
      tax = (float)(income * 10 / 100);
      printf("tax: %f \n", tax);
   } else {
      tax = (float)(1000 + (income - 10000) * 15 / 100);
      printf("tax: %f", tax);
   }
}

Output

  • Income: 5000
    tax: 500.000000
  • Income: 15000
    tax: 1750.000000

Example: Checking for a Digit

#include <stdio.h>

int main() {
   char ch = '7';

   if (ch >= 48 && ch <= 57) {
      printf("The character is a digit.");
   } else {
      printf("The character is not a digit.");
   }
   return 0;
}

Output

  • The character is a digit.
  • The character is not a digit. (when ch = '*')

Incorrect Use Without Braces

This code will throw a compilation error because the else is not paired properly due to missing braces:

#include <stdio.h>

int main() {
   int amount = 50;
   float discount;
   printf("Amount: %d\n", amount);

   if (amount >= 100)
      discount = amount * 10 / 100;
      printf("Discount: %f \n", discount);
   else
      printf("Discount not applicable\n");

   return 0;
}

Output

  • Error: 'else' without a previous 'if'

Incorrect Logic Without Braces

#include <stdio.h>

int main() {
   int amount = 50;
   float discount, nett;
   printf("Amount: %d\n", amount);

   if (amount < 100)
      printf("Discount not applicable\n");
   else
      printf("Discount applicable");
      discount = amount * 10 / 100;
      nett = amount - discount;
      printf("Discount: %f Net payable: %f", discount, nett);

   return 0;
}

Output

  • Amount: 50
    Discount not applicable
    Discount: 5.000000 Net payable: 45.000000

Note: The output is incorrect because only the first statement is treated as part of the else. The rest are executed unconditionally. Always use curly braces to define blocks.

Corrected Version

if (amount >= 100) {
   discount = amount * 10 / 100;
   printf("Discount: %f \n", discount);
} else {
   printf("Discount not applicable\n");
}

The else-if Statement

Use else if when there are multiple conditions to check, one after the other.

Syntax

if (condition) {
   // Code block 1
} else if (another_condition) {
   // Code block 2
} else {
   // Default code block
}

Example: Age Check

#include <stdio.h>

int main(void) {
   int age = 15;

   if (age < 18) {
      printf("You need to be over 18 years old to continue\n");
   } else if (age < 21) {
      printf("You need to be over 21\n");
   } else {
      printf("You are over 18 and older than 21 so you can continue \n");
   }
}

Output

  • You need to be over 18 years old to continue
  • You need to be over 21 (if age = 19)
  • You are over 18 and older than 21 so you can continue (if age = 25)

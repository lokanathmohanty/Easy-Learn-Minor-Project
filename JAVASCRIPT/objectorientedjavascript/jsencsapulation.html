JavaScript - Encapsulation

What is Encapsulation?

Encapsulation in JavaScript is a way to keep the related properties and methods under a single namespace by bundling them. It can be a function, a class or an object. In JavaScript, encapsulation can be implemented using closures, classes, and getters and setters.

Encapsulation is a fundamental concept in Object-oriented programming languages, along with inheritance and polymorphism. JavaScript is an object-oriented programming language.

It is used to hide the data from the outside world and give access to required data only to improve the integrity and security of the data.

What is the need for encapsulation?

Let's discuss the need for encapsulation in JavaScript via the following example. 

const car = {
   Brand: "Honda city",
   model: "sx",
   year: 2016,
}

Anyone can access the properties of the car object: 

car.Brand

Also, anyone can change the value of any property: 

car.Brand = true;

Here, the value of the Brand property is changed to a boolean. To secure original data and provide limited access, encapsulation is required.

Different Ways to Achieve Encapsulation in JavaScript

  • Using function closures
  • Using ES6 classes
  • Using getters and setters

We will learn each approach one by one.

Encapsulation Using Function Closures

A closure allows the inner function to access variables defined in the outer function even after the outer function has executed. These variables cannot be accessed outside their scope but can be accessed using the inner function. 

function shoppingCart() {
  const cartItems = [];
  function add(item) {
    cartItems.push(item);
  }
  function remove(itemName) {
    const index = cartItems.findIndex(item => item.name === itemName);
    if (index !== -1) {
      cartItems.splice(index, 1);
    }
  }
  return { add, remove };
}

In this way, no one can directly access or modify the cartItems[] array.

Encapsulation Using ES6 Classes and Private Variables

In JavaScript, classes and private fields can be used to achieve encapsulation. Private variables are defined using the # symbol. 

class Car {
  #brand = "TATA";
  #name = "Nexon";
  #milage = 16;

  getMilage() {
    return this.#milage;
  }
  setMilage(milage) {
    this.#milage = milage;
  }
}

let carobj = new Car();
console.log(carobj.getMilage()); // 16
carobj.setMilage(20);
console.log(carobj.getMilage()); // 20
// carobj.#milage; // Error

Encapsulation Using Getters and Setters

JavaScript getters and setters are defined using get and set keywords to access or update private properties. 

class User {
  #username = "Bob";
  #password = "12345678";
  #isLoggedIn = false;

  get username() {
    return this.#username;
  }
  set username(user) {
    this.#username = user;
  }
}

const user = new User();
console.log(user.username); // Bob
user.username = "Alice";
console.log(user.username); // Alice

Benefits of Encapsulation in JavaScript

  • Data protection – Control access to class data by making them private. Validate data while updating to prevent invalid states.
  • Code reusability – Classes act as templates for objects and can be reused.
  • Code maintenance – Encapsulation improves maintainability, as objects remain independent.

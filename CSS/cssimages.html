CSS - Images

In this article, we will learn about how to style an image to change its shape, size, and layout by using different CSS properties such as padding, borders, height, width, margins, etc.

Circular And Elliptical Images

By applying border-radius: 50%, we can create circle and ellipse shaped images. Equal width and height make it circular, otherwise elliptical.

Image as a Card

Images can be styled as cards (like polaroid) with shadows and captions.


<div class="polaroid-image">
  <img src="/css/images/red-flower.jpg" alt="Flower">
  <div class="box">
    <p>Tree</p>
  </div>
</div>

Center an Image

Using flexbox properties, we can center an image horizontally and vertically.

  <img src="/css/images/logo.png" alt="logo">

Text Inside Image

With position: relative for the container and absolute for the text, we can place text at any position inside an image.


<div class="image-text-container">
  <img src="/css/images/red-flower.jpg" alt="Flower">
  <h3 class="center">Text at Center</h3>
  <h3 class="top-left">Text at Top Left</h3>
  <h3 class="top-right">Text at Top Right</h3>
  <h3 class="bottom-left">Text at Bottom Left</h3>
  <h3 class="bottom-right">Text at Bottom Right</h3>
</div>

Django Quick Guide: Basics and Setup 🐍🚀

Django is a high-level, open-source **Python web framework** that promotes rapid development and clean, pragmatic design. It was created in 2003 at the Lawrence Journal-World and named after jazz guitarist Django Reinhardt.

Design Philosophies & Advantages

Django adheres to several core philosophies that streamline web development:

  • Don't Repeat Yourself (DRY): Every piece of code should be defined in exactly one place.
  • Loosely Coupled: Elements of the stack should be independent of others.
  • Fast Development & Less Coding: Facilitates hyper-fast development with minimal code required.

Key advantages include built-in support for **Object-Relational Mapping (ORM)** for database handling (MySQL, PostgreSQL, etc.), **multilingual support**, **caching**, **RSS**, and a ready-to-use **administrative GUI**.

Django Architecture: The MVT Pattern

Unlike the traditional Model-View-Controller (MVC) pattern, Django uses the **Model-View-Template (MVT)** pattern. The key difference is that **Django handles the Controller part** (the software code that mediates interactions), leaving the developer to focus on the other three components:

  • Model (M): The data structure (Python classes defining database layout and relationships).
  • View (V): The business logic that receives the HTTP request and returns an HTTP response (often rendering a template).
  • Template (T): The front-end design (an HTML file mixed with the Django Template Language or DTL).

Workflow: User Request → Django Controller → View → Model (data) → Template (display) → HTTP Response to User.

Environment Setup

Step 1 & 2: Python and Django Installation

  • Python: Django is pure Python; ensure you have a compatible version installed (e.g., Python 2.7.3+). Verify with python --version.
  • Django: Install using pip (recommended) or manually from the archive. 
    $ pip install django
    Test the installation: 
    $ django-admin --version

Step 3 & 4: Database and Web Server

  • Database: Django supports major SQL databases (**MySQL, PostgreSQL, SQLite 3, Oracle**) and some NoSQL databases via external forks (**MongoDB, GoogleAppEngine Datastore**).
  • Web Server: Django includes a **lightweight development server** for testing (run with python manage.py runserver), but for production, you need servers like **Apache** or **Nginx**.

Creating a Project Structure

A Django web application is called a **Project**, which is composed of one or more independent **Applications**. This structure allows applications to be easily reused across different projects.

To start a new project:

$ django-admin startproject myproject

This command creates a directory structure:

myproject/
   manage.py        <-- Utility for project management
   myproject/       <-- Inner project directory (the package)
      __init__.py
      settings.py   <-- Project configuration
      urls.py       <-- URL declarations/routing
      wsgi.py       <-- Entry point for WSGI-compatible web servers

Life Cycle of a Thread in Java

The life cycle of a thread in Java defines the various states a thread undergoes from its creation to termination. Understanding these states is crucial for effective multithreading and synchronization in Java applications.

States of a Thread Life Cycle in Java

Java threads are managed by the Thread class, which defines several states a thread can be in during its life cycle:

  • New (Born): A thread is in this state immediately after its creation but before the start() method is invoked.
  • Runnable: After calling start(), the thread enters the runnable state. It is ready to run and is waiting for CPU time.
  • Blocked: A thread enters the blocked state when it wants to access a synchronized block or method but cannot because another thread is holding the required lock.
  • Waiting: A thread transitions to the waiting state when it waits indefinitely for another thread to perform a particular action.
  • Timed Waiting: A thread enters this state when it waits for a specified period.
  • Terminated (Dead): A thread enters the terminated state when it completes its execution or when it is terminated by an exception or by calling the stop() method.

Example Code Demonstrating Thread States

The following Java code demonstrates the various thread states:

public class ThreadLifeCycleDemo extends Thread {
    public void run() {
        System.out.println(Thread.currentThread().getState()); // RUNNABLE
        try {
            Thread.sleep(1000);
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
        System.out.println(Thread.currentThread().getState()); // TERMINATED
    }

    public static void main(String[] args) {
        ThreadLifeCycleDemo thread = new ThreadLifeCycleDemo();
        System.out.println(thread.getState()); // NEW
        thread.start();
        System.out.println(thread.getState()); // RUNNABLE
    }
}

In this example:

  • The thread starts in the New state.
  • Upon calling start(), it enters the Runnable state.
  • After calling sleep(), it transitions to the Timed Waiting state.
  • Once the run() method completes, it enters the Terminated state.

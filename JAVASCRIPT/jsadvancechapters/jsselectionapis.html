JavaScript - Selection API

Introduction

The JavaScript Selection API allows developers to access and modify the portion of a web page selected by the user. This includes highlighting text, interacting with selections, and responding to selection events.

⚠️ The Selection API is not available in Web Workers — it only works in the main thread of a web page.

Core Interfaces

  • Selection: Represents the selected text or caret position (obtained via document.getSelection() or window.getSelection()).
  • Range: Represents a fragment of a document, typically a selection or node subset.
  • Events: Several events (like selectionchange and selectstart) allow you to track selection changes.

Selection Interface

A Selection object shows the user-selected region of text or caret. The selection has two key points:

  • Anchor: Where the selection started.
  • Focus: Where the selection ended.

Instance Properties

PropertyDescription
anchorNodeNode where the selection starts.
anchorOffsetCharacter/element offset of start.
focusNodeNode where selection ends.
focusOffsetOffset of end position.
isCollapsedtrue if start and end are same point.
rangeCountNumber of ranges in the selection.
type"None", "Caret", or "Range".

Instance Methods

  • addRange() → Adds a Range to the selection.
  • collapse() → Collapses selection to a point.
  • deleteFromDocument() → Removes selection contents.
  • removeAllRanges() → Clears selection.
  • toString() → Returns selected text.
  • selectAllChildren(node) → Selects all children of a given node.

Document.getSelection()


let selection = document.getSelection();

Returns the Selection object for the current document, or null if none exists.

Select some text and click the button.

Window.getSelection()

Similar to document.getSelection(), but called from the window object. 


let selection = window.getSelection();

Example





   
Select some text in this paragraph.

Events

selectionchange (Document event)

Triggered whenever the document’s selection changes.


document.addEventListener("selectionchange", () => {
   console.log("Selection changed:", document.getSelection().toString());
});

selectstart (Node event)

Triggered when a new selection starts.


document.addEventListener("selectstart", () => {
   console.log("Selection started");
});

Summary

  • Use document.getSelection() or window.getSelection() to get selection details.
  • Selections are defined by anchor (start) and focus (end).
  • Use selectionchange and selectstart events to track user actions.

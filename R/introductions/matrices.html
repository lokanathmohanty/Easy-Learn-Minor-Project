R - Matrices

Matrices in R are two-dimensional rectangular data objects containing elements of the same atomic type. Though matrices with only characters or logicals can be created, numeric matrices are mainly used for mathematical calculations.

Creating a Matrix

Syntax:

matrix(data, nrow, ncol, byrow, dimnames)
  • data: Input vector becoming matrix elements
  • nrow: Number of rows
  • ncol: Number of columns
  • byrow: If TRUE, fill matrix by rows; otherwise by columns
  • dimnames: Names for rows and columns (optional)

Example

# Elements arranged by row
M <- matrix(c(3:14), nrow=4, byrow=TRUE)
print(M)

# Elements arranged by column
N <- matrix(c(3:14), nrow=4, byrow=FALSE)
print(N)

# Matrix with named rows and columns
rownames = c("row1", "row2", "row3", "row4")
colnames = c("col1", "col2", "col3")
P <- matrix(c(3:14), nrow=4, byrow=TRUE, dimnames=list(rownames, colnames))
print(P)

Accessing Matrix Elements

# Access element at row 1, column 3
print(P[1,3])

# Access element at row 4, column 2
print(P[4,2])

# Access entire 2nd row
print(P[2,])

# Access entire 3rd column
print(P[,3])

Output:

[1] 5
[1] 13
col1 col2 col3 
   6    7    8 
row1 row2 row3 row4 
   5    8   11   14

Matrix Computations

Mathematical operations on matrices require the matrices to have compatible dimensions. The results of operations are also matrices.

Matrix Addition & Subtraction

# Create two 2x3 matrices
matrix1 <- matrix(c(3, 9, -1, 4, 2, 6), nrow=2)
print(matrix1)

matrix2 <- matrix(c(5, 2, 0, 9, 3, 4), nrow=2)
print(matrix2)

# Add matrices
result <- matrix1 + matrix2
cat("Result of addition\n")
print(result)

# Subtract matrices
result <- matrix1 - matrix2
cat("Result of subtraction\n")
print(result)

Output:

     [,1] [,2] [,3]
[1,]    3    9   -1
[2,]    4    2    6

     [,1] [,2] [,3]
[1,]    5    2    0
[2,]    9    3    4

Result of addition
     [,1] [,2] [,3]
[1,]    8   11   -1
[2,]   13    5   10

Result of subtraction
     [,1] [,2] [,3]
[1,]   -2    7   -1
[2,]   -5   -1    2

Matrix Multiplication & Division

# Multiply matrices
result <- matrix1 * matrix2
cat("Result of multiplication\n")
print(result)

# Divide matrices
result <- matrix1 / matrix2
cat("Result of division\n")
print(result)

Output:

     [,1] [,2] [,3]
[1,]   15    0   -2
[2,]   36    6   24

Result of division
          [,1]      [,2]       [,3]
[1,]  0.600000       Inf -0.3333333
[2,]  0.444444 0.666667  1.5000000

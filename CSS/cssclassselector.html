CSS - Class Selectors

A CSS class selector is used to select elements that have a specific class attribute. Class selectors are defined with a period (.) followed by the class name. Unlike IDs, multiple elements can share the same class, which makes class selectors very flexible and reusable.

Syntax

.classname {
  /* property: value; */
  background-color: #04af2f;
}

Basic Class Selector

The following example applies a background color and text color to all elements with the class container. 

.container {
  background-color: #04af2f;
  color: white;
}

<p class="container">This is a paragraph with class.</p>
<p>This is a paragraph without class</p>

Multiple Class Selectors

You can use multiple classes on the same element. When multiple class names are combined, the styles are applied only if all class names match. 

.bdr.bgColor {
  border: 2px solid black;
  background-color: #04af2f;
}

<div class="bdr bgColor">
  This is div with background color and a border.
</div>

<div class="bdr">
  This is div with default styles.
</div>

Combining Class Selector with Other Selectors

Class selectors can be combined with other selectors, such as element selectors, to style only specific elements. 

p.container {
  font-size: 16px;
  font-family: Verdana, sans-serif;
  color: #04af2f;
}

<p class="container">This is a styled paragraph element.</p>
<div class="container">This is a div without any style.</div>

Combining Multiple Classes

You can also apply multiple classes to a single element, each class applying its own styles. 

.bdr {
  border: 1px solid black;
  font-size: 16px;
  font-family: Verdana, sans-serif;
}

.bgColor {
  background-color: #04af2f;
  color: white;
}

<div class="bdr bgColor">
  This is a div with a border and background color.
</div>

Using Class Selectors with Media Queries

Class selectors are very useful with media queries for creating responsive designs. You can change the style based on screen size. 

.bgColor {
  background-color: rgb(96, 5, 26);
  color: white;
}

@media (max-width: 800px) {
  .bgColor {
    background-color: #04af2f;
    color: white;
  }
}

@media (max-width: 700px) {
  .bgColor {
    background-color: #031926;
    color: white;
  }
}

<p class="bgColor">
  Try different screen sizes to see change in background color.
</p>

Key Notes

  • Classes are defined with a dot (.) before the class name.
  • Multiple elements can share the same class.
  • You can combine classes for more flexible styling.
  • Classes are reusable and essential for responsive design.

PHP Multidimensional Arrays

A **Multidimensional Array** is an array where each element contains another array. This structure is used to store complex data like tables, matrices, or hierarchical data structures. A 2D array is the most common form, often representing data in rows and columns.

Syntax and Structure

Multidimensional arrays can be a mix of indexed and associative arrays at different levels (dimensions).

2D Indexed Array (Array of Arrays)

The outer array and all inner arrays use numerical indices.

$arr = [
   [1, 2, 3], // Row 0
   [4, 5, 6] // Row 1
];

2D Associative Array (Dictionary of Dictionaries)

The outer array uses string keys (e.g., "row1"), and the inner arrays also use string keys (e.g., "key11").

$arr = [
   "row1" => ["key11" => "val11"],
   "row2" => ["key21" => "val21"]
];

Accessing Elements

Elements are accessed by chaining the keys/indices, one for each dimension.

Indexed 2D Access

$tbl = [[1, 2, 3], [10, 20, 30]];
$tbl[1][2] $\rightarrow$ Gets the element in the second row (index **1**), third column (index **2**), which is **30**.

Output: Value at [2], [2] :300

Associative 2D Access

$tbl["row2"]["key22"] $\rightarrow$ Gets the value associated with "key22" inside the array keyed by "row2".

Output: value at row2 - key22 is val22

Traversing Multidimensional Arrays

1. Nested `foreach` Loops (Standard for 2D)

You need one nested `foreach` loop for each dimension. For a 2D array, the outer loop iterates over the rows, and the inner loop iterates over the elements (columns) within each row.

**Indexed 2D Traversal:**
foreach ($tbl as $row) {
   foreach ($row as $elem) { echo $elem; }
}

2. Recursive Traversal (For N-Dimensional Arrays)

For arrays with an unknown or high number of dimensions (3D, 4D, etc.), a **recursive function** is the most flexible solution. The function checks if an element is itself an array using **`is_array($v)`**. If it is, the function calls itself; otherwise, it processes the scalar value.

function showarray($arr){
   foreach ($arr as $k=>$v){
      if (is_array($v)){
         showarray($v); // Recurse
      } else {
         echo "$k => $v "; // Print scalar
      }
   }
}

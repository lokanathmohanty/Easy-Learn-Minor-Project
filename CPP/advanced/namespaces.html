C++ Namespaces (Scope Management) 🏷️

A **namespace** is a mechanism designed to prevent **name collisions** (ambiguity) when multiple libraries or parts of a program use the same names for functions, classes, or variables. Essentially, a namespace defines a distinct **scope** or context for the names declared within it.

It acts like a surname or address, providing extra information to differentiate entities with identical names (e.g., differentiating between two people named "Zara" in the same town).

Defining and Accessing a Namespace

Definition Syntax

A namespace is defined using the keyword namespace followed by a name:

namespace MyLibrary {
   int version = 1;
   void calculate() { /* ... */ }
}

Accessing Members (Scope Resolution)

To explicitly call a function or variable from a specific namespace, you must prepend the namespace name using the **Scope Resolution Operator (`::`)**:

MyLibrary::calculate(); // Calls calculate() from MyLibrary scope
std::cout << MyLibrary::version; // Accesses version variable

The using Directive

The `using` directive allows you to avoid repeatedly prepending the namespace name. It makes the names within the specified namespace available in the current scope.

1. Whole Namespace (General Access)

This imports all names from the namespace into the current scope. This is often done for convenience, but it can re-introduce ambiguity if multiple namespaces are imported this way.

using namespace std; // Makes names like cout and endl globally available

2. Single Item (Specific Access)

You can import only a specific item from a namespace, making only that name available without the prefix.

using std::cout; // Only cout is available without prefix

Discontiguous and Nested Namespaces

Discontiguous Namespaces

A namespace can be defined in multiple blocks or even spread across multiple files. The final namespace is the **sum** of all its separately defined parts. Writing a namespace definition again simply adds new elements to the existing one.

namespace App { int value = 1; }
// In a separate file:
namespace App { void printValue() { /* ... */ } } 
// 'App' now contains both 'value' and 'printValue()'

Nested Namespaces

Namespaces can be defined inside other namespaces. Members of a nested namespace are accessed by chaining the scope resolution operators:

namespace Outer {
   namespace Inner {
      void method() { /* ... */ }
   }
}
// Accessing the method:
Outer::Inner::method();

You can also use a `using` directive to access a nested namespace:

using namespace Outer::Inner;
method(); // Direct call is now possible

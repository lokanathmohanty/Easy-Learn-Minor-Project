PHP Magic Constants Summary

**Magic Constants** in PHP are special, predefined constants that change their value based on where they are used in the script. They are resolved at **compile time** (unlike regular constants resolved at runtime) and are **case-insensitive**.

File and Location Constants

These constants provide information about the script's location:

  • **`__LINE__`**: Returns the **current line number** in the file.
    echo "Line number is " . __LINE__ . ".";
  • **`__FILE__`**: Returns the **full path and filename** of the script (or the included file, if used inside an include).
    echo "Script name is " . __FILE__ . ".";
  • **`__DIR__`**: Returns the **directory** of the file. It is equivalent to `dirname(__FILE__)`. It does not have a trailing slash unless it's the root directory.
    echo "Directory is " . __DIR__ . ".";

Scope and Context Constants

These constants identify the surrounding function, class, or namespace:

  • **`__FUNCTION__`**: Returns the **name of the function** where the constant is used (or `{closure}` for anonymous functions). Returns a blank string if used outside a function.
    function hello() { echo "Function name is ". __FUNCTION__ . ""; } $\rightarrow$ hello
  • **`__CLASS__`**: Returns the **name of the class** where the constant is used, including the namespace it was declared in.
    class myclass { ... echo __CLASS__; } $\rightarrow$ myclass
  • **`__METHOD__`**: Returns the **full method name** including the class (e.g., `ClassName::MethodName`).
    function mymethod() { echo __METHOD__; } $\rightarrow$ myclass::mymethod
  • **`__TRAIT__`**: Returns the **name of the trait** where the constant is used. Traits are used for code reuse across classes.
    trait mytrait { ... echo __TRAIT__; } $\rightarrow$ mytrait
  • **`__NAMESPACE__`**: Returns the **name of the current namespace**. Namespaces help group related classes/functions and prevent naming conflicts.
    namespace myspace; echo __NAMESPACE__; $\rightarrow$ myspace

Special Class Constant: `ClassName::class`

This special constant returns the **fully qualified class name** (including the namespace). Unlike the other magic constants, it does not use double underscores.

namespace myspace;
echo myclass::class; $\rightarrow$ myspace\myclass

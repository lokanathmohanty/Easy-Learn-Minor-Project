R - Binary Files

A binary file contains information stored as bits and bytes (0s and 1s) and is not human-readable. Specific programs are needed to interpret and use binary files, as they contain more than just text, including formatting and other metadata. In R, binary files are continuous sequences of bytes, and reading or writing them requires special handling.

R Functions for Binary Files

- writeBin(object, con): Write binary data.
- readBin(con, what, n): Read binary data.

  • con: connection object for reading/writing.
  • object: data to write.
  • what: mode of data (character, integer, etc.) to read.
  • n: number of bytes to read.

Example: Writing a Binary File

Using the built-in mtcars dataset, we store selected columns as CSV, then write as a binary file.

# Write selected columns of mtcars to CSV
write.table(mtcars, file = "mtcars.csv", row.names = FALSE, na = "", col.names = TRUE, sep = ",")

# Read 5 records from CSV
new.mtcars <- read.table("mtcars.csv", sep = ",", header = TRUE, nrows = 5)

# Open binary file for writing
write.filename = file("/web/com/binmtcars.dat", "wb")

# Write column names
writeBin(colnames(new.mtcars), write.filename)

# Write column values
writeBin(c(new.mtcars$cyl, new.mtcars$am, new.mtcars$gear), write.filename)

# Close connection
close(write.filename)

Example: Reading the Binary File

# Open binary file for reading
read.filename <- file("/web/com/binmtcars.dat", "rb")

# Read column names (3 columns)
column.names <- readBin(read.filename, character(), n = 3)

# Reopen connection and read 18 values (3 columns * 5 rows + 3 column names)
read.filename <- file("/web/com/binmtcars.dat", "rb")
bindata <- readBin(read.filename, integer(), n = 18)

# Close connection may be required
close(read.filename)

# Display data
print(bindata)

# Extract values for each column
cyldata <- bindata[4:8]
amdata <- bindata[9:13]
geardata <- bindata[14:18]

print(cyldata)
print(amdata)
print(geardata)

# Combine extracted data to a data frame
finaldata <- cbind(cyldata, amdata, geardata)
colnames(finaldata) <- column.names
print(finaldata)

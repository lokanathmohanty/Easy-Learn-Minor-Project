JavaScript - Variables

JavaScript Variables

JavaScript variables are used to store data that can be changed later on. These variables are like named containers where you can place data and refer to it by name.

In JavaScript, you can declare variables in 4 ways:

  • Without using any keywords.
  • Using the var keyword.
  • Using the let keyword.
  • Using the const keyword.

The let and const keywords were introduced in ES6 (2015). Before that, only var was used.

Variable Declaration in JavaScript

Example of declaring variables without using keywords:

Example

<script>
   Money = 10;
   Name = "tutorialspoint";
</script>

Using the var keyword:

Example

<script>
   var money;
   var name;
</script>

Declaring multiple variables with the same var:

Example

<script>
   var money, name;
</script>

Variable Initialization

Storing a value in a variable is called initialization. It can be done at declaration or later.

Example

<script>
   var name = "Ali";
   var money;
   money = 2000.50;
</script>

Note: Use the var keyword only once for a variable. Do not redeclare the same variable.

JavaScript Data Types

Variables can hold values of any type dynamically, such as numbers, strings, booleans, or objects.

Example

<script>
   var num = 765; // Number
   var str = "Welcome"; // String
   var bool = false; // Boolean
</script>

JavaScript Variable Names (Identifiers)

Identifiers are names for variables. Rules:

  • Can contain letters, digits, underscores (_), and dollar signs ($).
  • Must not start with a digit.
  • Case-sensitive (e.g., Name and name are different).
  • Can contain Unicode characters.
  • Must not use reserved keywords.

Using $ and _

These characters are valid in variable names.

Example

<html>
<head>
    <title> Variables in JavaScript </title>
</head>
<body>
   <script>
        var _abc = "Hi!";
        var $abc = "Hello!";
        // var 9abc = "Bye!";  // Invalid
        document.write("_abc " + _abc + "<br>");
        document.write("$abc = " + $abc + "<br>");
   </script>
</body>
</html>

Undefined Variable Value

If a variable is declared but not initialized, it has the value undefined.

Example

<html>
<body>
   <script>
      var num;
      document.write("The value of num is: " + num + "<br/>");
   </script>
</body>
</html>

JavaScript Variable Scope

Variables can have two scopes:

  • Global: accessible throughout the program.
  • Local: accessible only inside the function where defined.

Example

<html>
<head>
   <title>JavaScript Variable Scope Example</title>
</head>
<body onload="checkscope();">   
   <script>
      var myVar = "global"; // Global variable
      function checkscope() {
         var myVar = "local"; // Local variable
         document.write(myVar);
      }
   </script>     
</body>
</html>

Variables without var

If declared without var, they are global variables.

Example

<html>
<head>
   <title> Variables without var keyword </title>
</head>
<body>
   <script>
      name = "tutorialspoint"; // String
      number = 10.25; // Number
      document.write("name = " + name + ", number = " + number + "<br>");
   </script>
</body>
</html>

Re-declaring Variables

If a variable is redeclared without initialization, it does not lose its previous value.

Example

<html>
<head>
   <title> Variables with var keyword </title>
</head>
<body>
   <script>
      var age = 10;
      var age;
      document.write("age = " + age + "<br>");
   </script>
</body>
</html>

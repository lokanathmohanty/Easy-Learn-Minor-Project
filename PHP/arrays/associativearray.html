PHP Associative Arrays

An **Associative Array** is a collection of data where each element is stored as a **key-value pair**. Unlike indexed arrays, elements are identified and accessed by their unique, usually descriptive **string keys**, rather than by sequential numerical indices. Associative arrays are analogous to dictionaries or hash maps in other languages.

Creating an Associative Array

The association between a key and its value is established using the **`=>`** symbol. Declaration can be done using the `array()` function or the preferred short array syntax `[]`.

$arr = [
   "Maharashtra" => "Mumbai",
   "Telangana" => "Hyderabad"
];

Key Types and Casting

  • Keys can be **strings** (most common) or **integers**.
  • If a **float** is used as a key, it is truncated (cast) to an integer (e.g., `5.75` becomes key `5`).
  • If a **Boolean** is used, `true` becomes key `1` and `false` becomes key `0`.
  • If the same key appears multiple times, the **last** key-value pair will overwrite any previous entry for that key.

Accessing and Manipulating Elements

Accessing Values

Values are accessed by placing the key (string or number) inside the square brackets, using the syntax **`$arr[key]`**.

$capitals["UP"] $\rightarrow$ "Lucknow"

Updating and Adding Elements

New key-value pairs can be added, and existing ones updated, using the same access syntax.

$arr["new_key"] = "new_value"; // Adds a new pair
$arr["Maharashtra"] = "Pune"; // Updates the value for "Maharashtra"

Removing Elements

The **`unset()`** function is used to remove a specific key-value pair from the array.

unset($arr["b"]); // Removes the element with key "b"

Checking Key Existence

Use **`array_key_exists('key', $arr)`** or **`isset($arr['key'])`** before accessing a key to prevent errors.

Traversing an Associative Array

1. `foreach` Loop (Ideal Method)

The `foreach` loop is the most efficient and readable way to iterate through associative arrays, unpacking both the key and the value.

foreach ($capitals as $k => $v) {
   echo "Capital of $k is $v \n";
}

2. `for` Loop (Complex Method)

To use a traditional `for` loop, you must first extract all the keys into a new indexed array using **`array_keys($arr)`**. You then loop over this indexed key array to access the keys, which are then used to look up the corresponding values in the original array.

$keys = array_keys($capitals);
for ($i=0; $i<count($keys); $i++){
   $cap = $keys[$i]; // Get the key (e.g., "Maharashtra")
   echo $capitals[$cap]; // Use the key to get the value
}

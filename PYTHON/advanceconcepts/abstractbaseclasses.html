Python - Abstract Base Classes

An Abstract Base Class (ABC) in Python is a class that cannot be instantiated directly and is intended to be subclassed. ABCs serve as blueprints for other classes by providing a common interface that all subclasses must implement.

They play a fundamental role in object-oriented programming in Python by enforcing a consistent API across related classes.

Purpose of Abstract Base Classes

  • Defining a Standard Interface: Ensures derived classes implement certain methods.
  • Enforcing Implementation: Raises errors if abstract methods are not implemented.
  • Providing a Template: Useful for large projects by reducing inconsistency and errors.
  • Facilitating Polymorphism: Allows operations across classes that follow the same interface.

Example: Defining an Abstract Class

from abc import ABC, abstractmethod

class Shape(ABC):
   @abstractmethod
   def area(self):
      pass

   @abstractmethod
   def perimeter(self):
      pass

Here, Shape acts as an abstract base class requiring subclasses to define area() and perimeter().

Example: Enforcing Implementation

class Rectangle(Shape):
   def __init__(self, width, height):
      self.width = width
      self.height = height

   def area(self):
      return self.width * self.height

   def perimeter(self):
      return 2 * (self.width + self.height)

A subclass like Rectangle must implement both the abstract methods. Otherwise, Python raises a TypeError.

Key Components

  • ABC Class: Base for creating abstract classes.
  • @abstractmethod Decorator: Marks methods as abstract.
  • ABCMeta: Metaclass that keeps track of abstract methods.
  • Concrete Methods: Optional methods with default implementations.
  • Instantiation Restrictions: Cannot create objects of ABCs with unimplemented methods.
  • Subclass Verification: Use issubclass() and isinstance() for type checks.

Example: Polymorphism with ABCs

class Circle(Shape):
   def __init__(self, radius):
      self.radius = radius

   def area(self):
      import math
      return math.pi * self.radius ** 2

   def perimeter(self):
      import math
      return 2 * math.pi * self.radius

def print_shape_info(shape):
   print(shape.description())
   print(f"Area: {shape.area()}")
   print(f"Perimeter: {shape.perimeter()}")

shapes = [Rectangle(5, 10), Circle(7)]
for shape in shapes:
   print_shape_info(shape)

This demonstrates polymorphism: both Rectangle and Circle share the same interface defined by Shape.

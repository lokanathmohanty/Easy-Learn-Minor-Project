R - Boxplots

Boxplots show the distribution of data by dividing it into quartiles. They display the minimum, maximum, median, first quartile, and third quartile, and can compare distributions across different data sets by drawing multiple boxplots.

Basic Syntax

boxplot(x, data, notch, varwidth, names, main)
  • x: Vector or formula (e.g., mpg ~ cyl)
  • data: Data frame containing values
  • notch: TRUE to draw notches indicating median confidence
  • varwidth: TRUE to vary box width by sample size
  • names: Group labels for boxplots
  • main: Title of the plot

Basic Boxplot Example

# Use mtcars data for mpg and cyl columns
input <- mtcars[, c('mpg', 'cyl')]
print(head(input))

# Save png chart file
png(file = "boxplot.png")
boxplot(mpg ~ cyl, data = mtcars, xlab = "Number of Cylinders", ylab = "Miles Per Gallon", main = "Mileage Data")
dev.off()

Boxplot with Notch and Custom Colors

png(file = "boxplot_with_notch.png")
boxplot(mpg ~ cyl, data = mtcars,
  xlab = "Number of Cylinders",
  ylab = "Miles Per Gallon",
  main = "Mileage Data",
  notch = TRUE,
  varwidth = TRUE,
  col = c("green", "yellow", "purple"),
  names = c("High", "Medium", "Low")
)
dev.off()

These scripts create and save boxplots comparing mileage against cylinder numbers, including visual features like notches, variable widths, and custom colors.

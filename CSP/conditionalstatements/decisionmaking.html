C# Decision Making Statements

Overview of Decision Making

Decision making structures allow the programmer to control the **flow of execution** by specifying conditions to be tested. Based on whether a **Boolean expression** evaluates to true or false, the program executes specific blocks of statements.

C# provides five main types of decision-making statements:

  1. if statement
  2. if...else statement
  3. nested if statements
  4. switch statement
  5. nested switch statements

if and if...else Statements (Example)

Simple if Statement

Executes a block of code only if the condition is true.

int temperature = 30;

if (temperature > 25) // Condition is true
{
    Console.WriteLine("It's a hot day.");
}

if...else Statement

Executes the first block if the condition is true, and the second block (the else part) if the condition is false.

int temperature = 21;

if (temperature > 25)
{
    Console.WriteLine("It's a hot day.");
}
else // Condition is false, this runs
{
    Console.WriteLine("The weather is pleasant.");
}

The switch Statement (Example)

The switch statement tests a variable for **equality** against a list of values (called **cases**). It is often cleaner than a long chain of if-else if statements when checking a single value against many possibilities.

  • The **break** keyword is essential to exit the switch once a case is matched.
  • The **default** case is optional and executes if no match is found.
int day = 3;
            
switch (day)
{
    case 1:
        Console.WriteLine("Sunday");
        break;
    case 3: // Match!
        Console.WriteLine("Tuesday");
        break;
    default:
        Console.WriteLine("Invalid day number!");
        break;
}

Ternary Operator (? :) - Conditional Expression

The **conditional operator** Exp1 ? Exp2 : Exp3 is a concise way to replace simple if...else statements.

Evaluation: If Exp1 is true, the result is Exp2. If Exp1 is false, the result is Exp3.

// Equivalent to: if (age >= 18) return "Adult" else return "Minor"
string status = (age >= 18) ? "Adult" : "Minor";

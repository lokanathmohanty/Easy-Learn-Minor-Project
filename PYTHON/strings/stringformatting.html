Python - String Formatting

String formatting in Python is the process of building a string dynamically by inserting values of variables or expressions into a predefined string. Since the string concatenation operator does not accept non-string operands, Python provides several formatting techniques.

String Formatting Techniques

  • Using % operator
  • Using format() method
  • Using f-strings
  • Using Template class

1. Using % Operator

The % operator, also known as the modulo operator, is often referred to as the string formatting operator. It uses format specifiers such as %s for strings.

name = "Tutorialspoint"
print("Welcome to %s!" % name)

Output:

Welcome to Tutorialspoint!

2. Using format() Method

The format() method is a built-in method of the str class. It uses curly braces {} as placeholders, which are replaced by the arguments passed into the method.

str = "Welcome to {}"
print(str.format("Tutorialspoint"))

Output:

Welcome to Tutorialspoint

3. Using f-strings

F-strings (formatted string literals) allow embedding expressions directly inside string literals using curly braces {}. They are prefixed with f.

item1_price = 2500
item2_price = 300
total = f'Total: {item1_price + item2_price}'
print(total)

Output:

Total: 2800

4. Using String Template Class

The Template class from the string module uses placeholders prefixed with $. The substitute() method replaces these placeholders with values.

from string import Template

str = "Hello and Welcome to $name !"
templateObj = Template(str)
new_str = templateObj.substitute(name="Tutorialspoint")
print(new_str)

Output:

Hello and Welcome to Tutorialspoint !

CSS inset Property

The CSS inset property is a shorthand property used to control the positioning of an element relative to its containing block. It combines the properties top, right, bottom, and left into a single declaration. In order for inset to take effect, the element must have its position property set (e.g., absolute, relative, or fixed).

Syntax

inset: auto | length | percentage | initial | inherit;

Property Values

  • auto – Lets the browser calculate the positioning automatically, often used for default alignment.
  • length – Defines the inset distance using units like px, em, or rem. Negative values are allowed.
  • percentage – Sets the inset as a percentage relative to the size of the containing block.
  • initial – Resets the inset property to its default value.
  • inherit – Inherits the inset value from its parent element.

Detailed Explanation

The inset property can accept one to four values, and each behaves differently:

  • One value: Applied equally to all four sides.
  • Two values: First applies to top and bottom, second applies to left and right.
  • Three values: First applies to top, second applies to left and right, third applies to bottom.
  • Four values: Applied individually to top, right, bottom, and left.

Examples of CSS inset Property

1. Inset Property with Auto Value

Using auto, the browser decides the element's position automatically. This is helpful when you want the default alignment based on the containing block. 

.container {
  position: relative;
  width: 300px;
  height: 150px;
  border: 2px solid black;
}
.text {
  position: absolute;
  inset: auto;
}

In this example, the element is placed using the browser's default rules because inset: auto; does not enforce a custom distance.

2. Inset Property with Length Values

Length values let you explicitly control the element’s distance from each edge. 

.box {
  position: absolute;
  inset: 20px 40px 30px 10px;
}

This means:

  • Top: 20px
  • Right: 40px
  • Bottom: 30px
  • Left: 10px

3. Inset Property with Percentage Values

Percentage values are relative to the dimensions of the parent container. 

.element {
  position: absolute;
  inset: 10% 15% 20% 5%;
}

Here the element is offset:

  • Top: 10% of parent’s height
  • Right: 15% of parent’s width
  • Bottom: 20% of parent’s height
  • Left: 5% of parent’s width

4. Inset Property with Mixed Values

You can mix units such as pixels and percentages for flexible layouts. 

.card {
  position: absolute;
  inset: 25px 10% 15px 35%;
}

Meaning:

  • Top: 25px
  • Right: 10% of parent’s width
  • Bottom: 15px
  • Left: 35% of parent’s width

Browser Support

The inset property is supported in modern browsers:

  • Chrome: 88+
  • Edge: 88+
  • Firefox: 66+
  • Safari: 14.1+
  • Opera: 73+

Practical Example

Imagine you want to center a modal box inside a container. You can use inset with equal values to achieve that easily. 

.modal {
  position: absolute;
  inset: 0;
  margin: auto;
  width: 200px;
  height: 100px;
}

Here the modal is centered because all edges are set to 0 and margins are automatically balanced.

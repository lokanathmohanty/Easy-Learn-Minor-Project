C++ Declaring and Initializing Multiple Variables

C++ allows you to declare multiple variables in a single statement, provided they all belong to the **same data type**. This is achieved by using a **comma (,)** to separate the variable names.

Declaring Multiple Variables

You can declare multiple variables of the same data_type in one line, and assign values to them later.

Syntax:

data_type var_a, var_b, var_c;

Example:

int y, z, x; // Declaration
x = 10;      // Assignment
y = 20;
z = 30;

Initializing Multiple Variables with Different Values

Variables can be initialized with different values directly within the declaration statement using the assignment operator (=) after each variable name.

Syntax:

data_type var_a = value1, var_b, var_c = value3;

Example:

int y = 10, z = 20, x; // y and z initialized, x only declared
x = 10;

Initializing Multiple Variables with the Same Value

You can initialize multiple variables to a single, common value in a single statement by chaining the assignment operator (=). This works because the assignment operation evaluates from right to left.

Syntax:

data_type var_a = var_b = var_c = [value];

Example:

int x = y = z = 10; 
// This assigns 10 to z, then z's value (10) to y, and finally y's value (10) to x.

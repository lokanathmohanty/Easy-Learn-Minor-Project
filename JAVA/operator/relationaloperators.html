Java Relational Operators

Session Content

Java relational operators compare two values and return a boolean result: true if the condition is satisfied, false otherwise. These are commonly used in decision-making like if statements and loops. They work with primitive data types such as int, float, double, and char.

  • == (equal to): Checks if two values are equal
  • != (not equal to): Checks if two values are not equal
  • > (greater than): Checks if left operand is greater
  • < (less than): Checks if left operand is smaller
  • >= (greater than or equal to): Checks if left operand is greater or equal
  • <= (less than or equal to): Checks if left operand is smaller or equal

Example 1: Equality and Inequality Checks

The following program checks equality and inequality between two variables:

public class Test {
   public static void main(String args[]) {
      int a = 10;
      int b = 20;

      System.out.println("a == b = " + (a == b));
      System.out.println("a != b = " + (a != b));
   }
}
  • a == b = false
  • a != b = true

Example 2: Greater Than and Less Than

This program demonstrates greater than and less than relational checks:

public class Test {
   public static void main(String args[]) {
      int a = 10;
      int b = 20;

      System.out.println("a > b = " + (a > b));
      System.out.println("a < b = " + (a < b));
   }
}
  • a > b = false
  • a < b = true

Example 3: Greater Than or Equal, Less Than or Equal

This example shows the use of >= and <= operators:

public class Test {
   public static void main(String args[]) {
      int a = 10;
      int b = 20;

      System.out.println("b >= a = " + (b >= a));
      System.out.println("b <= a = " + (b <= a));
   }
}
  • b >= a = true
  • b <= a = false

C# Unsafe Code and Pointers ⚠️

What is Unsafe Code?

**Unsafe code** in C# is a code block or function marked with the **`unsafe`** modifier. It is called "unsafe" because it allows the use of **pointers**, which bypass C#'s managed memory access and type safety checks. This code is often referred to as **unmanaged code**.

While unsafe code is used sparingly, it is necessary for:

  • Interacting with legacy C/C++ libraries.
  • Low-level memory operations.
  • Achieving maximum performance in critical code sections.

Pointers in C#

A **pointer** is a variable that holds the **memory address** of another variable. They function similarly to C/C++ pointers but can only be declared and used within an `unsafe` context.

Pointer Declaration and Use

The general syntax for a pointer declaration uses the asterisk (`*`) symbol:

type *var-name;
  • **Address-of operator (`&`):** Used to get the memory address of a variable.
  • **Dereference operator (`*`):** Used to retrieve the value stored at the memory address pointed to by the pointer.
  • **Member access operator (`->`):** Used to access members of a structure or class pointed to by a pointer (e.g., `p->ToString()`).
int var = 20;
int* p = &var; // p now holds the memory address of var

Console.WriteLine(*p); // Output: 20 (dereferencing p)

Declaring Unsafe Regions

You can mark an entire method or just a specific block of code as unsafe:

  • **Unsafe Method:** `static unsafe void Main() { ... }`
  • **Unsafe Block:** `public static void Main() { unsafe { ... } }`

Pointers and Arrays (The `fixed` Keyword)

C# arrays are objects managed by the Garbage Collector (GC), meaning their location in memory can change during execution. Pointers, however, require a fixed address.

To safely access array elements using a pointer, you must use the **`fixed`** statement. This keyword temporarily pins the array in memory, preventing the GC from moving it, and provides a pointer to its first element.

int[]  list = {10, 100, 200};
fixed(int *ptr = list) // Pins the 'list' array in memory
{
   // Access elements using pointer arithmetic
   Console.WriteLine(*(ptr + 1)); // Value of list[1] (100)
}

Compilation Requirement

Since unsafe code is outside the standard type-safe execution model, it must be explicitly permitted by the compiler.

  • **Command Line:** Compile with the **`/unsafe`** switch: `csc /unsafe prog1.cs`
  • **Visual Studio:** Enable the "Allow unsafe code" option in the **Project Properties > Build** tab.

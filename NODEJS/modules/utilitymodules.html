Node.js - Utility Modules

Node.js includes several utility modules that provide common and frequent functionalities to assist development of Node.js applications.

  • OS Module - Offers basic operating system-related utility functions such as system info, memory, and CPU usage.
  • Path Module - Provides utilities for handling and transforming file and directory paths in a platform-independent manner.
  • Net Module - Implements network interfaces for creating both server and client streams, acting as a wrapper around TCP/IPC sockets.
  • DNS Module - Enables DNS lookups and uses underlying OS name resolution functions.
  • Domain Module - Allows grouping multiple I/O operations for collective error handling and context management.

Java Programming: Class Structures

Session: Inner Classes (Nested Classes)

What is an Inner Class?

A **Java Inner Class** is a class defined **inside another class**, known as the **Outer Class**. Inner classes are a member of the outer class, just like variables and methods, and are part of the larger concept of **Nested Classes**.

Inner classes provide a security mechanism, improve encapsulation, and offer logical grouping of classes that are only relevant to the outer class.

Types of Nested Classes

Nested classes are broadly categorized into two types, which further break down into specific inner class types:

  • **Static Nested Classes:** Declared with the `static` keyword. They are static members of the outer class.
  • **Non-Static Nested Classes (Inner Classes):** These are the focus of the three types below and are non-static members of the outer class.

**Three Types of Inner Classes:**

  1. **Regular Inner Class** (Member Inner Class)
  2. **Method-local Inner Class**
  3. **Anonymous Inner Class**

1. Regular Inner Class (Member Class)

This class is defined directly inside the outer class, like a field or method. Its key feature is that an instance of the inner class has an implicit reference to the instance of the outer class that created it, giving it direct access to **all** private members of the outer class.

Instantiation Syntax:

Outer_Demo outer = new Outer_Demo();
Outer_Demo.Inner_Demo inner = outer.new Inner_Demo();

A regular inner class can be made `private`, `public`, `protected`, or package-private.

2. Method-local Inner Class

A class defined **inside a method**. Its scope and lifespan are strictly limited to that method. It is similar to a local variable.

  • It can only be instantiated **within the method** where it is defined.
  • It can access the outer class's members, and also the local variables of the method, provided those local variables are effectively **`final`** (either explicitly declared `final` or not reassigned).
void my_Method() {
   int num = 23; // Effectively final

   class MethodInner_Demo { // Defined inside the method
      public void print() {
         System.out.println("Inner class access: " + num);
      }
   }
   // Instantiation is allowed only here:
   MethodInner_Demo inner = new MethodInner_Demo();
   inner.print();
}

3. Anonymous Inner Class

An inner class declared and instantiated **without a name** at the same time. They are used primarily for **overriding a single method** of a class or implementing an interface when creating a single instance.

They are useful for concise, on-the-spot implementation:

abstract class AnonymousInner {
   public abstract void mymethod();
}

// Declaration and instantiation at the same time:
AnonymousInner inner = new AnonymousInner() {
   // This is the body of the anonymous class, overriding the abstract method
   public void mymethod() {
      System.out.println("Anonymous inner class example");
   }
};

Static Nested Class (Static Member Class)

Declared using the **`static`** keyword. Unlike regular inner classes, static nested classes:

  • **No Outer Instance:** They **don't** have an implicit reference to an instance of the outer class.
  • **Access:** They can only access the **static** members of the outer class.
  • **Instantiation:** They are accessed using the outer class name, without needing an outer class object: Outer.Nested_Demo nested = new Outer.Nested_Demo();
public class Outer {
   static class Nested_Demo {
      // ... methods
   }
}

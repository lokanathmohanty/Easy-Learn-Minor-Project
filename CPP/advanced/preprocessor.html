C++ Preprocessor Directives (#) ⚙️

The **C++ Preprocessor** is a tool that processes the source code **before** the actual compilation begins. It handles directives—special instructions that modify the source code based on specific rules.

All preprocessor directives start with the **pound sign (`#`)** and do **not** end with a semicolon (`;`).

The #define Preprocessor (Macros)

The `#define` directive is used to create symbolic constants or macros. When the program is preprocessed, every subsequent occurrence of the macro-name is replaced by the replacement-text.

Simple Macro

#define PI 3.14159
// The preprocessor replaces PI with 3.14159 everywhere.

Function-Like Macros

Macros can take arguments, mimicking functions. It's best practice to use plenty of parentheses to prevent operator precedence issues when the macro is expanded.

#define MIN(a,b) (((a)<(b)) ? a : b)
// MIN(x, y) is textually replaced by the conditional expression.

Conditional Compilation

These directives allow you to include or exclude specific blocks of code from compilation based on certain conditions, which is essential for managing code across different platforms or debug modes.

DirectiveDescription
**#ifdef MACRO**Compiles the following code block only if MACRO **has been defined**.
**#ifndef MACRO**Compiles the following code block only if MACRO **has NOT been defined**.
**#if condition**Compiles the code if the specified constant expression is true.
**#else / #elif**Provide alternatives for the #if, #ifdef, or #ifndef block.
**#endif**Marks the end of a conditional compilation block.

A common pattern for debugging:

#ifdef DEBUG
   cerr << "Debugging trace..." << endl; // Only compiled if DEBUG is defined
#endif

The # and ## Operators

  • **# (Stringizing Operator):** Converts a token from the macro argument into a **string literal** (surrounded by quotes). 
    #define MKSTR(x) #x
MKSTR(HELLO C++)  // Preprocessed to: "HELLO C++"
  • **## (Token Pasting Operator):** Concatenates two tokens together to form a single new token. 
    #define concat(a, b) a ## b
concat(x, y)  // Preprocessed to: xy

Predefined C++ Macros

C++ provides several built-in macros that expand to constants at compile time, often used for logging or debugging:

  • **__LINE__**: The current line number in the source file.
  • **__FILE__**: The name of the current source file (as a string literal).
  • **__DATE__**: The compilation date (as a string literal).
  • **__TIME__**: The compilation time (as a string literal).

C++ Enumeration (enum) Types 🏷️

An **enumeration (enum)** is a **user-defined data type** that consists of a set of **named integral constants**. Enums improve code readability by providing meaningful names for a fixed set of values.

Creating and Accessing Enumerations

You use the enum keyword to declare an enumeration.

Syntax:

enum enumName {
   Enumerator_Value1, // By default, 0
   Enumerator_Value2, // By default, 1
   // ...
};

Underlying Values: By default, the first enumerator is assigned the integer value **0**, and each subsequent enumerator is incremented by 1. You can **explicitly assign** a value to an enumerator, and the sequence will continue from that new value.

Example: In enum Day { Sunday, Monday, Tuesday=10, Wednesday };, the values are: Sunday=0, Monday=1, Tuesday=10, and Wednesday=11.

Types of C++ Enums

C++ offers two main types of enums, differing primarily in their scope and type safety:

1. Unscoped Enums (Traditional enum)

  • Scope: Enumerator names are directly injected into the **enclosing scope** (global or local). This can lead to **name collisions**.
  • Access: Enumerators are accessed directly (e.g., RGB myColor = Red;).
  • Conversion: Allows **implicit conversion to integers** (e.g., int value = myColor;), which reduces type safety.

2. Scoped Enums (enum class) 🛡️

Introduced in C++11, scoped enums provide improved type safety and organization.

  • Declaration: Uses enum class enumName {...}.
  • Scope: Enumerator names are strictly **scoped within the enum type**. This avoids name conflicts.
  • Access: You **must use the enum name** to access the enumerator (e.g., Color myColor = Color::Red;).
  • Conversion: **No implicit conversion to integers**. Explicit casting (static_cast<int>(myColor)) is required, enhancing type safety.

Benefits and Use Cases

Enums are powerful for:

  • Improved Readability: Using names like LogLevel::Error is clearer than using raw integers like 2.
  • State Management: Defining distinct, fixed states (e.g., GameState::Playing, GameState::Paused).
  • Clean Function Interfaces: Using enums as function parameters ensures only valid, named options are passed.
  • **Switch Statements:** Enums integrate seamlessly with switch statements for defining logical branches based on state or command type.

Content

Use this concise guide to review the essentials of modern JavaScript for web development.

  • Values & Types: Primitives (string, number, boolean, null, undefined, bigint, symbol) and reference types (objects, arrays, functions).
  • Variables: Prefer const for defaults, use let when reassignment is needed; avoid var in modern code.
  • Operators: Use strict equality === and !==; leverage nullish coalescing ?? and optional chaining ?..
  • Control Flow: if/else, switch, loops (for, for...of, while), and array iteration methods (map, filter, reduce).
  • Functions: Declarations, expressions, and arrow functions; default and rest parameters; closures for encapsulation.
  • Objects & Arrays: Destructuring, spread/rest, shorthand properties, and immutability patterns.
  • DOM & Events: Select, read, and update elements; attach listeners; prevent default behavior when needed.
  • Asynchrony: Promises and async/await; handle errors with try/catch; use Promise.all for concurrency.
  • Modules: Organize code with ES modules (export/import); one responsibility per module.
  • Errors: Throw meaningful errors; catch and surface user-friendly messages; log for diagnostics.
  • Performance: Minimize DOM thrashing; debounce/throttle event handlers; lazy-load noncritical assets.
  • Tooling: Use linters and formatters; test critical logic; consult documentation (e.g., MDN).

Examples

  • Variables & Scope

    const API_URL = '/api/items'; let count = 0;

    function increment() { count += 1; }

  • Arrow Functions & Defaults

    const greet = (name = 'World') => `Hello, ${name}!`;

  • Destructuring & Spread

    const user = { id: 1, name: 'Ada', role: 'admin' };

    const { name, role } = user; const clone = { ...user, active: true };

  • Array Methods

    const nums = [1,2,3,4]; const evens = nums.filter(n => n % 2 === 0);

    const sum = nums.reduce((a,n) => a + n, 0);

  • Optional Chaining & Nullish Coalescing

    const city = user.address?.city ?? 'Unknown';

  • DOM Query & Event Handling

    const btn = document.querySelector('#save');

    btn.addEventListener('click', (e) => { e.preventDefault(); /* save */ });

  • Async/Await with Error Handling

    async function load() {

      try { const res = await fetch(API_URL); const data = await res.json(); return data; }

      catch (err) { console.error(err); throw new Error('Failed to load'); }

    }

  • Promise Concurrency

    const [u, p] = await Promise.all([fetch('/user'), fetch('/prefs')]);

  • Modules

    // math.js — export

    export const add = (a,b) => a + b;

    // app.js — import

    import { add } from './math.js';

  • Debounce Utility (Basic)

    const debounce = (fn, wait) => { let t; return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), wait); }; };

    window.addEventListener('resize', debounce(() => console.log('resized'), 200));

  • Class Syntax

    class Counter { constructor(v=0){ this.v = v; } inc(){ this.v++; } }

    const c = new Counter(); c.inc();

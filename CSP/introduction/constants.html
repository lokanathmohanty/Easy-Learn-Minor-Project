C# Constants and Literals

Constants and Literals Overview

Constants refer to fixed values that the program cannot alter during execution. These fixed values are also known as **Literals**.

Constants are defined using the const keyword. Their values must be set during definition and cannot be modified later. They are accessed just like regular variables.

Syntax for defining a constant:

const <data_type> <constant_name> = value;

Types of Literals

Integer Literals

Can be decimal (no prefix) or hexadecimal (prefix 0x or 0X). They can also have suffixes for type:

  • U or u for **unsigned**.
  • L or l for **long**.

Examples: 212 (decimal), 215u (unsigned), 0xFeeL (hexadecimal long).

Floating-point Literals

Can be represented in decimal form (must include a decimal point or exponent) or exponential form (using e or E).

Examples: 3.14159, 314159E-5F (the F suffix indicates float type).

Character Constants

Enclosed in **single quotes** (e.g., 'x'). Can be a plain character, an **escape sequence** (like \n for newline or \t for tab), or a universal character.

String Literals

Enclosed in **double quotes** ("hello, dear") or with the **verbatim string literal** prefix @"...". Verbatim strings treat backslashes literally, making them ideal for file paths (e.g., @"C:\path\to\file").

Code Example: Class Constants

Constants declared inside a class are implicitly **static**, belonging to the class rather than an instance. They are accessed using the class name.

Access Syntax: class_name.constant_name

class MathConstants
{
    public const double Pi = 3.14159;
    public const int SpeedOfLight = 299792458;
}

class Program
{
    static void Main()
    {
        Console.WriteLine("Value of Pi: " + MathConstants.Pi);
    }
}

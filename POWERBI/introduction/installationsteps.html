In this tutorial, we will install a Power BI desktop application. To check the system requirements and installation file details, users must navigate to the official Microsoft website.

The following are the system requirements to download the Power BI tool:

Supported Operating Systems

  • Windows 10, Windows 7, Windows 8, Windows 8.1
  • Windows Server 2008 R2, 2012, and 2012 R2
  • Internet Explorer 9 or higher is required
  • Available for 32-bit (x86) and 64-bit (x64) platforms

Installing Power BI on Windows

Step 1: Search "Power BI download" in Google and click on the first link: https://powerbi.microsoft.com/en-us/downloads/. You can download Power BI from the Microsoft Store or use Advanced download options.

Step 2: Install and open Power BI Desktop from the App Store.

Step 3: Alternatively, click on "Advanced download options". Select the language (e.g., English) and click Download.

Step 4: Direct download link: https://www.microsoft.com/en-us/download/details.aspx?id=45331

Select the correct installer file for your OS (e.g., PBIDesktop_x64.msi) and click Next. Save it locally.

Step 5: Run the installer from your Downloads folder.

Step 6: Follow the on-screen wizard and click Next.

Step 7: Accept the license agreement and continue by clicking Next.

Step 8: Choose the installation folder and click Next.

Step 9: Click Install to begin the installation.

Step 10: Once completed, click Finish.

Step 11: Launch Power BI Desktop. The welcome screen appears with several options.

Power BI Welcome Screen Options

Get Data

Connect to data sources like Azure, Microsoft Fabric, Files, or Databases based on your business needs.

Recent Sources

View recently opened files without searching the file path manually.

Saved Reports

Reopen saved Power BI files (e.g., yy.pbix) for further analysis.

Open Other Reports

Select a folder to load specific files manually.

Publishing Report

Share reports within your organization using an official Power BI service login.

The welcome screen also provides links to Power BI blogs, forums, and monthly updates.

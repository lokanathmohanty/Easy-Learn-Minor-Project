Queue Interface in Java

Content

The Queue interface, part of java.util, extends the Collection interface and represents a collection designed for holding elements prior to processing.

Queues follow the FIFO (First In First Out) principle: elements added first are removed first.

Key methods in the Queue interface include:

  • boolean add(E e) - Inserts an element, throwing an exception if the queue is full.
  • E element() - Retrieves, but does not remove, the head of the queue.
  • boolean offer(E e) - Inserts an element, returning false if no space is available.
  • E peek() - Retrieves, but does not remove, the head, or returns null if empty.
  • E poll() - Retrieves and removes the head, or returns null if empty.
  • E remove() - Retrieves and removes the head, throwing an exception if empty.

Common classes implementing Queue are LinkedList, ArrayDeque, and PriorityQueue.

Interfaces extending Queue include Deque, BlockingQueue, and BlockingDeque.

Example

This example uses a LinkedList to demonstrate queue operations:


package com.tutorialspoint;

import java.util.LinkedList;
import java.util.Queue;

public class QueueDemo {
   public static void main(String[] args) {
      Queue<Integer> q = new LinkedList<>();
      q.add(6);
      q.add(1);
      q.add(8);
      q.add(4);
      q.add(7);
      System.out.println("The queue is: " + q);
      int num1 = q.remove();
      System.out.println("The element deleted from the head is: " + num1);
      System.out.println("The queue after deletion is: " + q);
      int head = q.peek();
      System.out.println("The head of the queue is: " + head);
      int size = q.size();
      System.out.println("The size of the queue is: " + size);
   }
}

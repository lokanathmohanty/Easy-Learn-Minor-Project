PHP: Encapsulation

**Encapsulation** is a core principle of Object-Oriented Programming (OOP) that involves bundling data (properties) and the methods that operate on that data into a single unit (a class). Crucially, it means keeping the data safe by restricting direct access from outside the class, allowing controlled access only through the class's public methods.

Access Modifiers (Visibility Modes)

PHP uses three keywords to implement encapsulation by controlling the visibility of class properties and methods:

  • public: Members are accessible from **anywhere**: inside the class, inside child classes, and from the object instance outside the class. (This is the default visibility if none is specified.)
  • private: Members are accessible **only within the class itself**. They cannot be accessed by child classes or from the object instance outside the class.
  • protected: Members are accessible **within the class and within any of its child (derived) classes**, but not from the object instance outside the class.

The Principle of Data Hiding

The goal of encapsulation is usually achieved by making data members **private** or **protected** (Data Hiding) and providing public methods (often called **getters** and **setters**) to manipulate that data. This ensures that data remains consistent and validates any changes made to it.

Why Use Encapsulation?

  1. Data Protection: Prevents unauthorized or unintended external modification of the object's internal state.
  2. Controlled Access: Public methods allow you to implement validation or business logic before data is set or returned.
  3. Simplifies Maintenance: Internal changes to the data structure (e.g., changing a property name) only require updating the public methods, not every piece of external code that uses the class.

Example Session

Restricting Access with private

In this example, the properties $name and $age are made private, preventing direct external access, while public methods getName() and getAge() still provide controlled access.


class Person {
   private $name;
   private $age;

   public function __construct(string $n, int $a) {
      $this->name = $n; // Accessible within the class
      $this->age = $a;
   }

   public function getName() { // Public getter method
      return $this->name;
   }
}

$b1 = new Person("Ravi", 28);

echo "Name: " . $b1->getName() . PHP_EOL; 
// echo $b1->name; // FATAL ERROR: Cannot access private property

If the Person class were extended, a child class would still **not** be able to directly access $name or $age because they are declared as private.

C# Inheritance

Concept of Inheritance

**Inheritance** is a core principle of OOP that allows a new class (the **derived class** or **child class**) to acquire the members (fields and methods) of an existing class (the **base class** or **parent class**). This mechanism promotes **code reusability** and establishes an **IS-A** relationship (e.g., a Rectangle IS-A Shape).

Syntax for Derivation:

A derived class is defined using a colon (`:`) followed by the name of the base class.

// Base Class
class Shape { /* ... members ... */ } 

// Derived Class
class Rectangle : Shape { 
   // Rectangle inherits members from Shape
}

Accessing Members in Inheritance

The visibility of base class members within the derived class is controlled by their **access specifiers**:

  • **`public`:** Fully accessible by the derived class and by objects outside the class hierarchy.
  • **`protected`:** Accessible only within the base class and any derived class (the standard choice for members intended for inheritance).
  • **`private`:** Not accessible by the derived class.

Example: Inheriting Protected Members

class Shape {
    protected int width; // Accessible in Rectangle
    public void setWidth(int w) { width = w; }
}
class Rectangle: Shape {
    public int getArea() { 
        return (width * height); // Direct access to protected members
    }
}

Initializing the Base Class (`base` Keyword)

The **`base` keyword** is used by a derived class to access members of its immediate parent class. Its most common use is to call a specific base class constructor.

Since the base class must be initialized before the derived class, the call to the base constructor must occur in the derived class's member initialization list.

Syntax for Base Constructor Initialization:

class Student : Person {
   // Calls Person(name) constructor first
   public Student(string name, int rollNo) : base(name) {
       RollNo = rollNo;
   }
}

Types of Inheritance (C# Supported)

  1. **Single Inheritance:** A class inherits from one direct base class. (Child : Parent)
  2. **Multi-Level Inheritance:** A chain of inheritance where a class inherits from a derived class. (Child : Parent : Grandparent)
  3. **Hierarchical Inheritance:** Multiple derived classes inherit from a single base class. (Car : Vehicle and Bike : Vehicle)

C# does NOT support Multiple Inheritance of classes. A class can only inherit from one class.

Method Overriding and Keywords

Method Overriding is the ability for a derived class to provide a specific implementation of a method that is already defined in its base class.

  • **`virtual`:** Used in the **base class** method declaration to indicate that the method can be overridden by a derived class.
  • **`override`:** Used in the **derived class** method declaration to indicate that it is providing a new implementation for a virtual base class method.
class Animal {
    public virtual void MakeSound() { /* ... */ } // Base: can be overridden
}
class Dog : Animal {
    public override void MakeSound() { /* Dog specific implementation */ } // Derived: provides new implementation
}

Preventing Inheritance (`sealed`)

The **`sealed` keyword** can be applied to a class to prevent it from being inherited by any other class. This is used when you want to ensure no class can extend or modify its behavior.

sealed class FinalClass { /* ... */ } 
// class CannotDerive : FinalClass {} // This line causes a compiler error

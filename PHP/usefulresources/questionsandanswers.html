PHP Cheatsheet: Core Syntax and Fundamentals 📜

This cheatsheet provides a quick reference for essential $\text{PHP}$ concepts, syntax, variables, and common functions. It's a handy tool for revision and quick lookups.

Script Syntax and Comments

Standard PHP Tags

<?php
   // Your PHP code here
?>

Short Echo Tag (For quickly outputting variables)

<?= "Hello, World!" ?>

Comments

  • Single-line: Starts with $\text{//}$ or $\text{#}$.
  • Multi-line: Enclosed within $\text{/*}$ and $\text{*/}$.
// Single-line comment
# Another single-line comment
/* Multi-line
comment */

Variables and Output

Variable Declaration

Variables start with the dollar sign ($\text{\$}):

<?php
   $age = 21; // Integer
   $name = "Kelly Hu"; // String
?>

Printing Output

Function Use Example
$\text{echo}$ Prints one or more strings; faster. $\text{echo "Hello", " World!";}$
$\text{print}$ Prints a single string; returns 1 (useful in expressions). $\text{print "Single String";}$
$\text{printf}$ Prints a formatted string (e.g., decimals, padding). $\text{printf("Hello, \%s!", "World");}$
$\text{print\_r}$ Displays human-readable information about a variable, useful for arrays/objects. $\text{print\_r(\$array);}$

Newlines and $\text{HTML}$ Embedding

  • Console Newline: Use $\text{"\n"}$ inside double quotes.
  • Browser Newline: Use the $\text{<br />}$ $\text{HTML}$ tag.
<?php
   echo "Hello, World!\n"; // Console output
   echo "<h1>Welcome, $name!</h1>"; // Embedding HTML & variables
?>

PHP Data Types

Data Type Description Example
$\text{String}$ Sequence of characters (single or double quotes). $\text{\$str = "Hello";}$
$\text{Integer}$ Non-decimal whole numbers. $\text{\$int = 42;}$
$\text{Float/Double}$ Numbers with a decimal or fractional part. $\text{\$float = 3.14;}$
$\text{Boolean}$ $\text{TRUE}$ or $\text{FALSE}$. $\text{\$is\_admin = true;}$
$\text{Array}$ Stores multiple values in a single variable (indexed or associative). $\text{\$cities = ["Hyd", "Bang"];}$
$\text{Object}$ An instance of a user-defined class. $\text{\$p = new Person("Name");}$
$\text{NULL}$ Represents a variable with no value. $\text{\$var = null;}$

String Operations

Concatenation

Uses the dot ($\text{.}$) operator.

<?php
   $greeting = "Hello" . " " . "World!"; // Output: Hello World!
?>

Key String Functions

Function Name Use Example
$\text{strlen()}$ Returns the length of a string. $\text{strlen("Hello") // 5}$
$\text{strpos()}$ Finds the position of the first occurrence of a substring. $\text{strpos("abc", "b") // 1}$
$\text{str\_replace()}$ Replaces all occurrences of a substring with a new string. $\text{str\_replace("o", "a", "Hello") // Heall}$
$\text{substr()}$ Returns a part of a string. $\text{substr("Hello", 0, 2) // He}$
$\text{strtolower()}$ Converts a string to lowercase. $\text{strtolower("HELLO") // hello}$

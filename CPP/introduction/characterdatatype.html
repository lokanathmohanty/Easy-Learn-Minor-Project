C++ Character (char) Data Type and ASCII

The **character (char) data type** is used to store a single alphanumeric value, which can be an alphabet, a number represented as a character (e.g., '1'), or a symbol (e.g., '#'). A char variable takes **1 byte (8 bits)** of memory space.

Syntax: char variable_name = 'value'; (The value must be enclosed in single quotes).

Use Cases:

  • Holding a single character without the overhead of a string.
  • Working with character arrays (C-style strings).
  • Interacting with **ASCII** values for numerical representation.

ASCII Values and Character Representation

ASCII (American Standard Code for Information Interchange) is an encoding standard that assigns a unique **numeric value** to every character. C++'s char type leverages this, allowing characters to be treated as small integers, and vice-versa.

Common ASCII Ranges:

  • Uppercase Letters ('A' to 'Z'): 65–90
  • Lowercase Letters ('a' to 'z'): 97–122
  • Digits ('0' to '9'): 48–57

Implicit Conversion (Typecasting)

The char type can be implicitly converted to an int to retrieve its ASCII value, and an int can be converted to a char to retrieve the corresponding character. This can be done explicitly using **typecasting** (e.g., int(c) or char(a)).

Example:

  • To get the ASCII value of '$': int('$') $\to$ 36.
  • To get the character for ASCII value 97: char(97) $\to$ 'a'.

Escape Sequences

Escape sequences are special character constants that begin with a **backslash (\)**, also known as the "Escape Character." They control formatting or allow the inclusion of characters that are normally difficult to type or have special meaning.

Key Escape Sequences:

  • \n: **Newline** (moves the cursor to the next line)
  • \t: **Horizontal Tab** (inserts horizontal space)
  • \\: **Backslash** (prints a literal backslash)
  • \": **Double Quote** (allows double quotes inside strings)
  • \0: **Null Character** (used to terminate C-style strings)

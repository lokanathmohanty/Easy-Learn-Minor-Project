Python - Further Extensions

Any code that you write using compiled languages like C, C++, or Java can be integrated or imported into another Python script. This code is called an extension. A Python extension module is essentially a normal C library. On Unix systems, these libraries usually end in .so (shared object), while on Windows they end in .dll (dynamically linked library).

Pre-Requisites for Writing Extensions

  • Python header files (install the Python development package on Unix).
  • Windows users get headers with the binary Python installer.
  • Good knowledge of C or C++.

Structure of a Python Extension

A Python extension module usually contains:

  • The header file Python.h.
  • C functions to be exposed to Python.
  • A method mapping table.
  • An initialization function.

The Header File Python.h

Include Python.h before any other headers to access the Python API used for integrating with the interpreter.

C Function Signatures

Functions for extensions have one of these signatures:

  • static PyObject *MyFunction(PyObject *self, PyObject *args);
  • static PyObject *MyFunctionWithKeywords(PyObject *self, PyObject *args, PyObject *kw);
  • static PyObject *MyFunctionWithNoArgs(PyObject *self);

Use Py_RETURN_NONE if no value needs to be returned.

The Method Mapping Table

Functions are linked using a PyMethodDef structure:

  • ml_name – function name as seen in Python.
  • ml_meth – pointer to the C function.
  • ml_flags – calling convention (e.g., METH_VARARGS).
  • ml_doc – function docstring, optional.

The Initialization Function

The initialization function is required when the module is loaded and is named initModule, where Module is the module name. Use PyMODINIT_FUNC for portability.

Example:

PyMODINIT_FUNC initModule() {
   Py_InitModule3(func, module_methods, "docstring...");
}

Example: Hello World Extension

#include <Python.h>
static PyObject* helloworld(PyObject* self)
{
   return Py_BuildValue("s", "Hello, Python extensions!!");
}

static char helloworld_docs[] = "helloworld(): Example docstring\n";

static PyMethodDef helloworld_funcs[] = {
   {"helloworld", (PyCFunction)helloworld, METH_NOARGS, helloworld_docs},
   {NULL}
};

void inithelloworld(void) {
   Py_InitModule3("helloworld", helloworld_funcs, "Extension module example!");
}

Save as hello.c and compile using a setup.py file with distutils. 

from distutils.core import setup, Extension
setup(name='helloworld', version='1.0',
   ext_modules=[Extension('helloworld', ['hello.c'])])

Install with:

$ python setup.py install

Use from Python:

import helloworld
print(helloworld.helloworld())

Output:

Hello, Python extensions!!

Passing Function Parameters

Use PyArg_ParseTuple to extract Python arguments in your C function. Arguments are described using a format string. 

static PyObject *module_func(PyObject *self, PyObject *args) {
   int i;
   double d;
   char *s;
   if (!PyArg_ParseTuple(args, "ids", &i, &d, &s)) {
      return NULL;
   }
   Py_RETURN_NONE;
}

Returning Values

Use Py_BuildValue to build Python objects from C values. 

static PyObject *foo_add(PyObject *self, PyObject *args) {
   int a, b;
   if (!PyArg_ParseTuple(args, "ii", &a, &b)) {
      return NULL;
   }
   return Py_BuildValue("i", a + b);
}

This works like:

def add(a, b):
   return a + b

You can also return multiple values as tuples:

return Py_BuildValue("ii", a + b, a - b);

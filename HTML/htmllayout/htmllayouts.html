HTML - Layouts

HTML Layouts specify the arrangement of components on an HTML web page. A good layout structure is important to provide a user-friendly experience on a website. It takes considerable time to design a layout with a great look and feel.

HTML Layout Elements

The below-listed elements are used to create the structure of an HTML layout:

  • header − Adds a header section at the top of the webpage.
  • nav − Represents a section with hyperlinks to other parts of the page or other pages.
  • section − Defines a major part of the web page for important content.
  • footer − Contains copyright and other details, usually at the bottom.
  • article − Represents independent self-contained content like posts or blogs.
  • aside − Represents related or sidebar content.
  • summary − Caption for the <details> element.
  • details − Holds additional information, works with <summary>.

Example of HTML Layout

The following example shows how to define a simple HTML layout using semantic elements:

Example

<!DOCTYPE html>
<html lang="en">
<head>
   <title>HTML Layout Example</title>
</head>
<body>
   <header>
      <h1>Website Title</h1>
   </header>

   <nav>
      <a href="#">Home</a>
      <a href="#">Learn HTML</a>
      <a href="#">About Us</a>
   </nav>

   <section>
      <h2>Home</h2>
      <p>This is the home page content.</p>
   </section>

   <aside>
      <p>This is sidebar content.</p>
   </aside>

   <footer>
      <p>Copyright © Example</p>
   </footer>
</body>
</html>

Different Techniques to Create Layouts

There are four common techniques to design HTML layouts:

  • CSS Float Property − Classic way to position and format content.
  • CSS Flexbox − Used for dynamic layouts that adapt to screen sizes.
  • CSS Grid − Creates complex grid-like layouts.
  • CSS Frameworks − Libraries like Bootstrap help create responsive layouts.

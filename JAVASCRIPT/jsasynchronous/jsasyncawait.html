JavaScript - Async/Await

The JavaScript functions defined with the async / await keywords can perform the same task as promises with fewer lines of code, and it makes the code readable. Since the promise syntax can be complex, async/await was introduced.

To use async/await, we define an async function first. An async function always returns a promise. The await keyword is used inside an async function and makes JavaScript wait for the promise to resolve before continuing the function.

The JavaScript async Keyword

A function defined with async is asynchronous and always returns a promise. If you return a value directly, it is wrapped in a resolved promise.

Syntax

async function func_name(parameters) { /* function body */ }

Example

async function printMessage() { return "Hello World"; }

Equivalent to:

function printMessage() { return Promise.resolve("Hello World"); }

Consuming the Promise

You can consume the returned promise with then() and catch().

Example:

async function getText() {
  return "Text from the getText() function.";
}
getText().then((text) => {
  document.getElementById('output').innerHTML = text;
}).catch((err) => {
  document.getElementById('output').innerHTML = JSON.stringify(err);
});

The JavaScript await Keyword

The await keyword can only be used inside an async function. It pauses execution until the promise settles.

Syntax

async function func_name(parameters) { await promise; }

Example

async function solvePromise() {
  const promise = new Promise((resolve) => {
    resolve('Promise is solved');
  });
  const result = await promise;
  document.getElementById('output').innerHTML += result;
}
solvePromise();

Example (Waiting for Timeout)

async function solvePromise() {
  const promise = new Promise((resolve) => {
    setTimeout(() => {
      resolve('The promise is solved after 2 seconds');
    }, 2000);
  });
  const result = await promise;
  document.getElementById('output').innerHTML += result;
}
solvePromise();

Error Handling with Async/Await

Instead of then() and catch(), you can use try...catch blocks with async functions.

Syntax

try {
  const result = await promise;
  // handle success
} catch (err) {
  // handle error
}

Example

async function solvePromise() {
  const promise = new Promise((_, reject) => {
    reject("The promise is rejected");
  });
  try {
    const result = await promise;
    console.log("Result:", result);
  } catch (err) {
    console.log("Error:", err);
  }
}
solvePromise();

Async Class Methods

Async methods can also be defined inside classes.

Syntax

async method_name() { return await promise; }

Example

class Animal {
  async getAnimalName() {
    return await "Lion";
  }
}
const lionObj = new Animal();
lionObj.getAnimalName().then((data) => {
  console.log("The animal name is:", data);
});

Real-time Example of Async/Await

Async/await is commonly used with APIs and data fetching.

Example

async function getData() {
  try {
    let response = await fetch('https://api.github.com/users');
    let data = await response.json();
    console.log("login:", data[0].login);
    console.log("id:", data[0].id);
  } catch (err) {
    console.log("Error:", err);
  }
}

Benefits of Async/Await

  • Increases code readability.
  • Reduces complexity compared to promises and callbacks.
  • Handles multiple promises easily.
  • Makes debugging simpler.
  • Replaces traditional callbacks for asynchronous code.

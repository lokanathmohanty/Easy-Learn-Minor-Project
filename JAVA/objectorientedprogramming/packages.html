Java Programming: Code Organization

Session: Packages

What are Java Packages? 📦

A **Package** in Java is a mechanism for **grouping related types** (classes, interfaces, enumerations, and annotations) together. They serve several critical purposes:

  • **Namespace Management:** They prevent **naming conflicts** by creating a unique namespace for each group of classes.
  • **Access Control:** They provide a mechanism for controlling access to classes and members.
  • **Organization:** They make it easier to search, locate, and use related types.

Types of Packages

Java packages are categorized as:

  • **Built-in Packages:** Packages that come with the Java Development Kit (JDK), such as java.lang (fundamental classes), java.io (input/output), and java.util (utility classes).
  • **User-defined Packages:** Packages created by developers to group their own related classes and interfaces.

Creating a Java Package

To create a package, use the **`package`** statement as the **first line** of the source file. It is a best practice to use all lowercase letters for package names to avoid conflicts with class names.

/* File name : Animal.java */
package animals; // Declares the package for this file

interface Animal {
   public void eat();
   public void travel();
}

To compile files with package statements, you must use the **`-d`** (directory) option to specify where the package directory structure should be created:

$ javac -d . MammalInt.java

This command creates a folder named animals (if it doesn't exist) and places the compiled .class file inside it.

Importing Java Packages

To use a class from a different package, you must make it accessible using one of three methods:

  1. **Fully Qualified Name:** Use the complete package path every time the class is referenced (e.g., `payroll.Employee e = new payroll.Employee();`).
  2. **Specific Class Import:** Import only the required class using the `import` keyword (e.g., `import payroll.Employee;`).
  3. **Wildcard Import:** Import all public types within a package using the asterisk (`*`) (e.g., `import payroll.*;`).

Import statements must appear **after the package statement** and **before the class declaration**.

Package Directory Structure

The package name must directly correspond to the directory structure on the file system. This allows the compiler and JVM to locate the compiled `.class` files.

For a class declared as `package com.apple.computers;`, the path to the source file should be:

...\com\apple\computers\Dell.java

The compiler and JVM use the **`CLASSPATH`** system variable to find the root directory where the package structure begins (e.g., `\classes`). The full path to the class file is then constructed as: **`CLASSPATH`** + **`package name`**.

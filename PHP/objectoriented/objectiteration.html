PHP: Object Iteration

**Object iteration** is the process of traversing through the properties of a PHP object, typically using a **foreach** loop. This is useful for inspecting or processing all available data in an object without accessing each property individually.

Iteration with foreach Loop

The standard foreach loop can iterate over an object instance. However, access is restricted based on the scope from which the loop is executed:

  • **Outside the Class:** Only **public** properties are visible and accessible. Private and protected properties are ignored.
  • **Inside the Class:** When the foreach loop is executed from an instance method (e.g., foreach ($this as $key => $value)), **all** properties (public, private, and protected) are accessible.

Why Use Object Iteration?

  • **Efficient Data Management:** Easily process data from multiple objects or properties.
  • **Code Simplification:** Reduces the need for repeated code to access individual members.
  • **Debugging/Inspection:** Quickly view the state (properties) of an object.

Using the Iterator Interface

For more control over the iteration process—such as defining which properties to iterate, the order, or generating dynamic keys/values—a class can implement the **Iterator** interface. This interface requires five methods to be defined:

  • **rewind():** Resets the internal pointer to the beginning (first element). Called once before the loop starts.
  • **current():** Returns the element at the current position.
  • **key():** Returns the key (index) of the current element.
  • **next():** Moves the internal pointer to the next element. Called after each iteration.
  • **valid():** Checks if the current position is valid (i.e., if there are more elements).

Example Session

Basic Iteration (Public Properties Only)

When iterating outside the class definition, only members with public visibility are included in the loop.


class Item {
   private $secret = "Hidden";
   public $name = "Widget";
   public $price = 9.99;
}

$obj = new Item();

// Only $name and $price are shown outside the class
foreach($obj as $key => $value) {
   print "$key => $value\n";
}
// Output:
// name => Widget
// price => 9.99

Iterator Implementation Example

A class implementing Iterator can customize the traversal logic, often over an internal array.

Note: The example below represents the conceptual structure.


class Book implements Iterator {
   private $properties = ['title' => 'PHP Basics', 'author' => 'Jane Doe'];
   private $position = 0;

   public function rewind(): void { $this->position = 0; }

   public function current() { 
      return array_values($this->properties)[$this->position];
   }

   public function key() { 
      return array_keys($this->properties)[$this->position]; 
   }

   public function next(): void { ++$this->position; }

   public function valid(): bool { 
      return $this->position < count($this->properties);
   }
}

$book = new Book();
foreach ($book as $k => $v) {
   print "$k: $v\n";
}
// Output:
// title: PHP Basics  
// author: Jane Doe

PHP Variable Handling: $\text{is\_null()}$ Function

The $\text{is\_null()}$ function is a core PHP variable handling function used to explicitly check if a variable's value is **$\text{NULL}$**. It is a simple, yet valuable tool for input validation and preventing errors caused by missing values.

Syntax and Parameters

The function accepts a single parameter and returns a boolean value.

bool is_null ( mixed $value )
  • $\text{\$value}$ (mixed): The variable whose value you want to check.
  • Return Value: Returns **$\text{TRUE}$** if the variable is $\text{NULL}$, and **$\text{FALSE}$** otherwise.

When $\text{is\_null()}$ Returns $\text{TRUE}$

The $\text{is\_null()}$ function returns $\text{TRUE}$ in the following scenarios:

  1. When a variable is explicitly assigned the value $\text{NULL}$.
  2. When a variable has been defined but subsequently had its value removed using the $\text{unset()}$ function.
  3. When attempting to check a variable that has **not been declared or defined** (in PHP, an undeclared variable is treated as $\text{NULL}$ when checked with $\text{is\_null()}$). This helps provide safe execution of code.

Example 1: Explicit $\text{NULL}$ Assignment

Checking a variable that was specifically set to $\text{null}$:

<?php
   // Assigning null value
   $var = null; 
   if (is_null($var)) {
      echo "Variable is null"; // Output: Variable is null
   }
?>

Example 2: Checking an Undefined Variable

Checking a variable that was never declared (this is where $\text{is\_null()}$ provides safety):

<?php
   // $undefinedVar has not been declared
   if (is_null($undefinedVar)) {
      echo "Variable is null"; // Output: Variable is null
   }
?>

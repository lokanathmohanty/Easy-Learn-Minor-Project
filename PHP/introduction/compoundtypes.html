PHP Compound Data Types

**Compound Data Types** in PHP are used to store collections of data, potentially consisting of different scalar or even other compound types. The two compound types are **Array** and **Object**.

1. Arrays in PHP

An array is an **ordered map** that associates values with keys. It can store multiple values of different data types in a single variable.

Declaration Methods

Arrays can be declared using two equivalent syntaxes:

  • **`array()` function:** The traditional method.
    $arr = array(10, "apple", 1.55);
  • **Square Brackets `[]`:** The shorter, modern syntax.
    $arr = [10, "apple", 1.55];

Types of Arrays

PHP arrays can function as three different types:

  • **Indexed Array:** A collection of values where each element is identified by a positional **integer index** starting from **0**.
    $indexed = [10, 20, 30]; // Keys are 0, 1, 2
  • **Associative Array:** A collection of **key-value pairs**, where the keys are typically **strings** (but can be integers). The association is denoted by `=>`.
    $assoc = ["one" => 1, "two" => 2];
  • **Multi-dimensional Array:** An array where the values themselves are other arrays.

Accessing and Traversal

Elements are accessed using the syntax `array[key]`:

  • **Accessing:** `var_dump($arr[1]);` or `var_dump($assoc["two"]);`
  • **Traversal:** The **`foreach`** loop is the standard method for iterating, allowing you to unpack both keys and values.
    foreach ($arr as $key => $val) {
       echo "$key : $val\n";
    }

2. Objects in PHP

An object is an **instance of a class**. It packages data (**properties**) and functions (**methods**) together.

Object Declaration

Objects are created using the **`new` operator** on a class definition (either built-in or user-defined).

class SayHello { ... }
$obj = new SayHello; // Instantiate the object

The `stdClass`

PHP provides a generic, empty class called **`stdClass`**. It is used as a base for casting and for dynamically adding properties without a formal class definition.

$obj = new stdClass;
$obj->name = "Deepak"; // Dynamically add a property

Type Casting Between Compound and Scalar Types

Array to Object Conversion

Casting an associative array to an object converts it into an instance of **`stdClass`**, where array keys become object properties.

$arr = ["name" => "Deepak"];
$obj = **(object)** $arr;
// $obj is now a stdClass object with a 'name' property

Object to Array Conversion

Casting an object to an array converts object properties into array key-value pairs.

$arr = **(array)** $obj;
// $arr is now an associative array

Scalar to Object Conversion

Casting a scalar value (like a string or integer) to an object creates an instance of **`stdClass`** with a single property named **`scalar`** holding the original value.

$name = "Deepak";
$obj1 = **(object)** $name;
// $obj1 is stdClass Object ([scalar] => Deepak)

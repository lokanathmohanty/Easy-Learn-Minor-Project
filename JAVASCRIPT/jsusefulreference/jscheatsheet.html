JavaScript Cheatsheet

Write On-page JavaScript

To add on-page JavaScript in an HTML document, use the following script tag:

Example

<script type="text/javascript">
// Write your JavaScript code here
</script>

Insert an External JavaScript File

You can insert an external JavaScript file in an HTML document using the <script> tag with the src attribute.

Example

<script src="file.js"></script>

Printing/Output

JavaScript provides three ways to print anything on the screen:

  • Console Output
  • Alert Boxes
  • Document Write

Console Output (console.log())

The console.log() method prints messages on the web console.

Example

console.log("Hello, World!");

Alert Boxes

The alert() method displays a pop-up alert box.

Example

alert("Hello World!");

document.write()

The document.write() method writes content directly to the HTML document.

Example

document.write("Hello World!");

Variables

JavaScript variables can be declared using var, let, or const.

  • var – Function-scoped, can be reassigned.
  • let – Block-scoped, can be reassigned.
  • const – Constants, cannot be reassigned.

Example

var x = 5;
let y = 10;
const z = 15;

Data Types

JavaScript data types are categorized into two types:

  • Primitive Types: String, Number, Boolean, Undefined, Null, Symbol, BigInt
  • Object Types: Objects {}, Arrays [], Functions () => {}

Example

let str = "Kelly Hu";
let num = 123;
let bool = true;
let und = undefined;
let n = null;

Operators

JavaScript operators include:

  • Arithmetic Operators
  • Assignment Operators
  • Comparison Operators
  • Logical Operators

Arithmetic Operators

Example

let a = 10;
let b = 3;
console.log(a + b);

Assignment Operators

Example

let x = 10;
x += 3;
console.log(x);

Comparison Operators

Example

let x = 5;
let y = "5";
console.log(x == y);

Logical Operators

Example

let a = true;
let b = false;
console.log(a && b);

Conditional Statements

JavaScript supports if, else if, and else statements, as well as ternary operators.

Example

if (age < 18) {
console.log("Minor");
} else {
console.log("Adult");
}

Loops

JavaScript supports different types of loops:

  • for loop
  • while loop
  • do-while loop

Example

for (let i = 0; i < 5; i++) {
console.log(i);
}

Functions

Functions are reusable blocks of code.

  • Function Declaration
  • Function Expression
  • Arrow Functions

Example

function add(a, b) {
return a + b;
}

Objects

Objects store key-value pairs.

Example

const person = { name: "Kelly", age: 27 };

Arrays

Arrays store multiple values in a single variable.

Example

let arr = [10, 20, 30];

DOM Manipulation

DOM methods allow dynamic changes to web pages.

Example

document.getElementById("id").innerHTML = "Hello";

Event Listeners

Event listeners allow execution of code when events occur.

Example

element.addEventListener("click", () => alert("Clicked!"));

Promises

Promises handle asynchronous operations.

Example

let promise = new Promise((resolve, reject) => {...});

Async/Await

Async/Await simplifies asynchronous code.

Example

async function fetchData() {
let response = await fetch("url");
}

Error Handling

JavaScript uses try, catch, and finally to handle errors.

Example

try {
throw new Error("Error!");
} catch(e) {
console.log(e.message);
}

PHP - Class Constants

A **Class Constant** is an identifier within a class that holds a constant value—a value that remains unchanged throughout the execution of the program. They are defined using the const keyword and are not prefixed with the dollar sign ($).

Key Characteristics of Class Constants

  • Immutability: Once a constant's value is set, it **cannot be modified**.
  • Static and Scope: Class constants are automatically **static**. They belong to the class itself, not a specific object instance. You don't need an object to access them.
  • Value Type: The value must be an **expression** (including global constants like M_PI or simple values), not a variable, function call, or property.
  • Visibility: The default visibility is **public**. However, as of PHP 7.1, you can use **private** and **protected** access modifiers.
  • Naming Convention: Conventionally, constant names are written in **UPPERCASE**.

Accessing Class Constants

Class constants are accessed using the **Scope Resolution Operator** (::).

  • From outside the class, use the class name: 
    echo SomeClass::CONSTANT_NAME;
  • From inside a method, use the self keyword: 
    $area = $this->side**2 * self::PI;

Example: Defining and Accessing a Constant

This example defines a constant PI and uses it within the area() method. 

<?php
   class square {
      const PI = M_PI; // Uses the built-in global constant
      var $side = 5;

      function area() {
         // Accessing the constant using self::PI
         $area = $this->side**2 * self::PI;
         return $area;
      }
   }

   $s1 = new square();
   // Accessing the constant from outside the class using ClassName::CONSTANT
   echo "PI = " . square::PI . "\n";
   echo "area = " . $s1->area();
?>

Class Constant Visibility Modifiers

Class constants can be set to **private** or **protected** to restrict access, similar to properties. Attempting to access a private constant from outside the class results in a Fatal Error. 

<?php
   class example {
      const X = 10;           // Public (default)
      private const Y = 20;   // Private
   }
   
   echo "public = " . example::X . "\n"; // Works
   // echo "private = " . example::Y . "\n"; // Causes Fatal Error
?>

Advantages of Class Constants

Using class constants improves code quality by:

  • **Readability**: Providing meaningful, descriptive names instead of using "magic numbers" (raw, unexplained values).
  • **Maintainability**: Centralizing fixed values so that if a value needs to change, it only needs to be updated in one place.

JavaScript - void Keyword

The void keyword in JavaScript is used as an operator that evaluates a given expression and returns undefined. It can be used as a unary operator that appears before its operand, which may be of any type.

Syntax

void operand;

Here, the operand can be any expression.

Return Value: It always returns undefined.

Example

The following example shows that using void 10 returns undefined.

Example Code

<html>
<body>
   <div id = "output">The value of the ans variable is:  </div>
   <script>
      let ans = void 10;
      document.getElementById("output").innerHTML += ans;
   </script>
</body>
</html>

Output: The value of the ans variable is: undefined

Importance of Precedence of void Keyword

The precedence of void is important, as shown below:

Example Code

<html>
<body>
   <div id = "output1"> </div>
   <div id = "output2"> </div>
   <script>
      let res1 = void 10 === 20;
      let res2 = void (10 === 20);
      document.getElementById("output1").innerHTML += res1;
      document.getElementById("output2").innerHTML += res2; 
   </script>
</body>
</html>

Output: false, undefined

What is javascript:void(0)?

The expression javascript:void(0) is commonly used in anchors to prevent page navigation.

Example

<html>
<body>
   <a href="javascript:document.write('Anchor text is clicked!')"> Click me! </a>
</body>
</html>

Using void(0)

<html>
<body>
   <a href="javascript:void(0)"> Click me! </a>
</body>
</html>

Example with onclick

<html>
<body>
   <a href="javascript:void(0);" onclick="document.body.style.backgroundColor='blue'">
      Change Background Color
   </a>
</body>
</html>

The void Keyword with Functions

Example

<html>
<body>
<div id="demo"> </div>
<script>
   const output = document.getElementById('demo');
   try {
      void function test() {
         output.innerHTML += "The test function is executed!";
      }
      test();
   } catch (error) {
      output.innerHTML += "The test function is undefined!";
   }
</script>
</body>
</html>

Output: The test function is undefined!

The void Keyword with Immediately Invoked Function

Example

<html>
<body>
   <div id="demo"> </div>
   <script>
      const output = document.getElementById("demo");
      void function () {
         output.innerHTML = "Unknown function is executed!";
      }();
   </script>
</body>
</html>

Output: Unknown function is executed!

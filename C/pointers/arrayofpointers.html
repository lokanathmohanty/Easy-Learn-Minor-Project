Array of Pointers in C

Just like an integer array holds a collection of integer variables, an array of pointers holds variables of pointer type. Each element in an array of pointers is a pointer pointing to another address.

The name of an array can be used as a pointer because it holds the address of the first element of the array. If we store the address of an array in another pointer, it is possible to manipulate the array using pointer arithmetic.

Create an Array of Pointers

To create an array of pointers in C, declare an array of pointers similar to a normal pointer declaration. Use the data type, followed by an asterisk (*), then the variable name with a subscript ([]), which specifies the array size.

Each element in the array of pointers contains the address of a specific type.

Example: Creating an Array of Pointers

This example declares three integer variables and an array of pointers to access and print their values.


#include <stdio.h>

int main() {
  int var1 = 1;
  int var2 = 2;
  int var3 = 3;

  int *ptr[3];

  ptr[0] = &var1;
  ptr[1] = &var2;
  ptr[2] = &var3;

  for (int i = 0; i < 3; i++) {
    printf("Value at ptr[%d] = %d\n", i, *ptr[i]);
  }

  return 0;
}

Output:

Value at ptr[0] = 1
Value at ptr[1] = 2
Value at ptr[2] = 3

An Array of Pointers to Integers

Declaration example:

int *ptr[MAX];

This declares ptr as an array of MAX integer pointers, where each element holds a pointer to an int value.

Example code:


#include <stdio.h>

const int MAX = 3;

int main() {
  int var[] = {10, 100, 200};
  int i, *ptr[MAX];

  for (i = 0; i < MAX; i++) {
    ptr[i] = &var[i];
  }

  for (i = 0; i < MAX; i++) {
    printf("Value of var[%d] = %d\n", i, *ptr[i]);
  }

  return 0;
}

Output:

Value of var[0] = 10
Value of var[1] = 100
Value of var[2] = 200

An Array of Pointers to Characters

You can use an array of pointers to characters to store a list of strings:


#include <stdio.h>

const int MAX = 4;

int main() {
  char *names[] = {
    "Zara Ali",
    "Hina Ali",
    "Nuha Ali",
    "Sara Ali"
  };

  for (int i = 0; i < MAX; i++) {
    printf("Value of names[%d] = %s\n", i, names[i]);
  }

  return 0;
}

Output:

Value of names[0] = Zara Ali
Value of names[1] = Hina Ali
Value of names[2] = Nuha Ali
Value of names[3] = Sara Ali

An Array of Pointers to Structures

This example demonstrates managing a list of structures using an array of pointers.


#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
  char title[50];
  float price;
} Book;

const int MAX = 3;

int main() {
  Book *book[MAX];

  for (int i = 0; i < MAX; i++) {
    book[i] = malloc(sizeof(Book));
    snprintf(book[i]->title, 50, "Book %d", i + 1);
    book[i]->price = 100 + i;
  }

  for (int i = 0; i < MAX; i++) {
    printf("Title: %s, Price: %.2f\n", book[i]->title, book[i]->price);
  }

  for (int i = 0; i < MAX; i++) {
    free(book[i]);
  }

  return 0;
}

Output:

Title: Book 1, Price: 100.00
Title: Book 2, Price: 101.00
Title: Book 3, Price: 102.00

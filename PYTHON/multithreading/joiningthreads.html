Python - Joining the Threads

Joining threads in Python means using the join() method to wait for a thread to finish before continuing with other threads or the main program. This ensures orderly execution in multithreaded programs.

The Thread.join() method blocks the calling thread until the thread on which join() is called terminates, either normally, due to an exception, or after an optional timeout.

If you try to join the currently running thread or a thread that hasn’t been started, a RuntimeError occurs.

Syntax:

thread.join(timeout)

The optional timeout parameter specifies the maximum wait time in seconds. If omitted, it waits indefinitely.

The method returns None. After calling join(), is_alive() can be used to check if the thread is still running (useful for detecting timeouts).

Example: Using join() to Wait for Threads

from threading import Thread
from time import sleep

def my_function_1(arg):
   for i in range(arg):
      print("Child Thread 1 running", i)
      sleep(0.5)

def my_function_2(arg):
   for i in range(arg):
      print("Child Thread 2 running", i)
      sleep(0.1)

# Create thread objects
thread1 = Thread(target=my_function_1, args=(5,))
thread2 = Thread(target=my_function_2, args=(3,))

# Start first thread and wait for completion
thread1.start()
thread1.join()

# Start second thread and wait for completion
thread2.start()
thread2.join()

print("Main thread finished...exiting")

Output:

Child Thread 1 running 0
Child Thread 1 running 1
Child Thread 1 running 2
Child Thread 1 running 3
Child Thread 1 running 4
Child Thread 2 running 0
Child Thread 2 running 1
Child Thread 2 running 2
Main thread finished...exiting

Example: Using join() with Timeout

from threading import Thread
from time import sleep

def my_function_1(arg):
   for i in range(arg):
      print("Child Thread 1 running", i)
      sleep(0.5)

def my_function_2(arg):
   for i in range(arg):
      print("Child Thread 2 running", i)
      sleep(0.1)

# Create thread objects
thread1 = Thread(target=my_function_1, args=(5,))
thread2 = Thread(target=my_function_2, args=(3,))

# Start first thread and wait for 0.2 seconds only
thread1.start()
thread1.join(timeout=0.2)

# Start second thread and wait for completion
thread2.start()
thread2.join()

print("Main thread finished...exiting")

Output:

Child Thread 1 running 0
Child Thread 2 running 0
Child Thread 2 running 1
Child Thread 2 running 2
Child Thread 1 running 1
Main thread finished...exiting
Child Thread 1 running 2
Child Thread 1 running 3
Child Thread 1 running 4

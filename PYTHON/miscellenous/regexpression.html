Python Regular Expressions (Regex)

A regular expression (regex) is a sequence of characters forming a search pattern used for matching text strings. Python supports regex through its built-in re module.

Regex patterns can validate input, perform search-and-replace, or extract information from texts.

Python supports raw string notation (r"...") to prevent escape sequences from being interpreted, ensuring patterns like \n are treated literally.

Common Metacharacters

MetacharacterDescription
[abc]Matches any character: a, b, or c
[a-c]Matches characters between a and c (a, b, c)
[a-z]Matches lowercase letters a to z
[0-9]Matches digits 0 to 9
^Negates character sets (e.g., [^a-z] matches anything but lowercase letters)
\dMatches any digit (0-9)

\SMatches non-whitespace characters
\wMatches alphanumeric characters plus underscore
\WMatches non-alphanumeric characters
.Matches any character except newline
*Matches zero or more repetitions of the preceding pattern
+Matches one or more repetitions

\\bMatches word boundary

Using the re Module

Match vs Search

re.match() attempts to match from the start of the string; re.search() scans the entire string for a match. 

import re
line = "Cats are smarter than dogs"

matchObj = re.match(r'Cats', line)
if matchObj:
    print(matchObj.group())

searchObj = re.search(r'dogs', line)
if searchObj:
    print(searchObj.group())

Output:
Cats
dogs

Findall

Returns all non-overlapping matches of the pattern in the string as a list. 

import re
string = "Simple is better than complex"
matches = re.findall(r'\b\w{2,}\b', string)
print(matches)

Output: ['Simple', 'better', 'than', 'complex']

Substitution (sub)

Substitute all occurrences of a pattern with a replacement string. 

import re
text = "Hello, this is Python. Python is great!"
new_text = re.sub(r'Python', 'Java', text)
print(new_text)

Output:
Hello, this is Java. Java is great!

Common Regex Operations

  • re.compile(): compile a regex pattern for reuse.
  • re.finditer(): returns an iterator yielding match objects for each match.
  • Flags: modifiers like re.I (ignore case), re.M (multiline), re.S (dot matches newline) enhance matching behavior.

Example: Matching Email Addresses

import re

text = "Contact: alice@example.com, bob.smith@foo.co.uk"
pattern = r'[\w\.-]+@[\w\.-]+'

emails = re.findall(pattern, text)
print(emails)

Output: ['alice@example.com', 'bob.smith@foo.co.uk']

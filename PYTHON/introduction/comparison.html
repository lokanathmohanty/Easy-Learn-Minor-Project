Python - Comparison Operators

Comparison operators in Python are used in conditional statements (if, else, elif) and looping statements (while, for). They are also called relational operators.

Some common operators are < (less than) and > (greater than). Python also supports <= (less than or equal to) and >= (greater than or equal to).

In addition, Python provides equality (==) and inequality (!=) operators. Hence, there are six comparison operators in Python:

  • < : Less than    → a < b
  • > : Greater than    → a > b
  • <= : Less than or equal to    → a <= b
  • >= : Greater than or equal to    → a >= b
  • == : Equal to    → a == b
  • != : Not equal to    → a != b

These operators are binary, requiring two operands. Expressions with comparison operators are Boolean expressions and always return True or False.

Examples with Numbers

Example with integers:

a=5
b=7
print(a > b) # False
print(a < b) # True

Detailed integer comparisons:

a=5; b=7
print("a>b is", a>b) # False
print("a<b is", a<b) # True
print("a==b is", a==b) # False
print("a!=b is", a!=b) # True

Comparison of int and float:

a=10; b=10.0
print("a==b is", a==b) # True
print("a!=b is", a!=b) # False

Comparison of Complex Numbers

Complex numbers support only equality operators (==, !=).

a=10+1j; b=10-1j
print(a==b) # False
print(a!=b) # True

Using < or > raises a TypeError.

Comparison of Booleans

Booleans are treated as integers (True=1, False=0).

a=True; b=False
print(a > b) # True
print(a < b) # False
print(a==b) # False
print(a!=b) # True

Comparison of Sequence Types

Only similar sequence types can be compared (string with string, tuple with tuple). Lists cannot be compared with tuples.

Sequences use lexicographical ordering (compared element by element).

Example with strings:

a="BAT"; b="BALL"
print(a > b) # True (T > L in Unicode order)

Example with tuples:

a=(1,2,4); b=(1,2,3)
print(a > b) # True (4 > 3 at index 2)

Comparison of Dictionaries

Python dictionaries do not support < or >. Using them raises TypeError.

Only equality (==) and inequality (!=) are supported. Equality checks whether both dictionaries have the same key-value pairs.

a={1:1,2:2}
b={2:2,1:1,3:3}
print(a==b) # False
print(a!=b) # True

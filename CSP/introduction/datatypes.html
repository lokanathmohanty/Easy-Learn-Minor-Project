C# Data Types: Value, Reference, and Pointer Types

What Are Data Types?

C# is a **strongly typed language**, meaning all variables must be declared with a **data type** before use. Data types specify the kind of data a variable can store (e.g., integer, character, boolean) and help with memory optimization and code readability.

Variables in C# are categorized into three main types:

  • Value Types: Store the actual data directly (e.g., int, char).
  • Reference Types: Store a reference (memory address) to the actual data (e.g., object, string).
  • Pointer Types: Store the memory address of another type (used in unsafe code).

1. Value Types

Value types directly contain their data and are derived from System.ValueType. Key types include:

  • Integral Types: int (4 bytes), long (8 bytes), byte (1 byte).
  • Floating-Point Types: float (4 bytes, 6-7 precision), double (8 bytes, 15-16 precision), and decimal (16 bytes, best for financial data).
  • Character Type: char (2 bytes, stores a single character).
  • Boolean Type: bool (1 byte, stores true or false).
  • User-Defined: enum (named constant values) and struct (encapsulates related data).

2. Reference Types (Example)

Reference types store a pointer to the data. Changes made through one reference variable are reflected in others. Common types are:

  • Object Type: The base class (System.Object) for all C# types. Converting a value type to an object type is **boxing**, and the reverse is **unboxing**.
  • Dynamic Type: Type checking is performed at **run-time**, allowing it to store any type of value.
  • String Type: (Alias for System.String) Used for assigning text values. Use StringBuilder for efficient string modification.
  • Array Type: Stores multiple values of the same type in a single variable.

Type Conversion

Converting data from one type to another is common:

  • Implicit Conversion: Occurs automatically when there is **no risk of data loss** (e.g., int to double).
  • Explicit Conversion (Casting): Required when converting **incompatible types** where data loss is possible (e.g., double to int using (int)).
// Implicit
int age = 18;
double preciseAge = age; 

// Explicit
double salary = 50000.75;
int roundedSalary = (int)salary;

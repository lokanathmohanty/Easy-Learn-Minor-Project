Java Programming: Wrapper Classes

Session: The Boolean Class

Introduction to the Boolean Class

The **java.lang.Boolean** class is the wrapper class for the primitive type **boolean**. It allows a primitive boolean value (true or false) to be represented as an object. This is essential for use in Java Collections and other object-oriented APIs.

The class is declared as **public final class Boolean**, meaning it cannot be subclassed.

Key Static Fields

The Boolean class provides three important static constants:

  • **static Boolean TRUE**: The Boolean object representing the primitive value `true`.
  • **static Boolean FALSE**: The Boolean object representing the primitive value `false`.
  • **static Class<Boolean> TYPE**: The Class object representing the primitive type `boolean`.

Constructors and Utility Methods

Although the constructor **Boolean(boolean value)** is available, modern practice discourages its use in favor of the static factory method **valueOf()** to take advantage of object caching (since there are only two possible Boolean instances: TRUE and FALSE).

Core Methods:

  • **boolean booleanValue()**: Returns the value of the Boolean object as a primitive `boolean`. (The explicit method for **unboxing**).
  • **static Boolean valueOf(boolean b)**: Returns a canonical `Boolean` instance (`TRUE` or `FALSE`) representing the specified primitive value.
  • **static boolean parseBoolean(String s)**: Parses a string. Returns `true` only if the string argument is not null and is equal, ignoring case, to the string "true"; otherwise, it returns `false`.

Logical Operations:

The class also includes utility methods for basic logical operations on primitives:

  • **static boolean logicalAnd(boolean a, boolean b)**
  • **static boolean logicalOr(boolean a, boolean b)**
  • **static boolean logicalXor(boolean a, boolean b)**

Comparison

The Boolean class implements the Comparable<Boolean> interface, defining a natural order where TRUE is considered greater than FALSE.

int res = b1.compareTo(b2);
  • If `b1` equals `b2`, `res` is 0.
  • If `b1` is `TRUE` and `b2` is `FALSE`, `res` is positive (> 0).
  • If `b1` is `FALSE` and `b2` is `TRUE`, `res` is negative (< 0).

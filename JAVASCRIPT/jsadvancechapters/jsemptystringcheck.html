JavaScript - Empty String Check

A string is a data type used to store text data. It is a sequence of characters enclosed inside single or double quotes. In JavaScript, there are multiple ways to check if a string is empty or not.

Using the length Property

The most common way to check if a string is empty is by checking its length property. If the length is 0, the string is empty.

Syntax:

if (string_name.length === 0) {
   // string is empty
}

Example:

var str = '';
if (str.length === 0) {
   document.write('String is empty');
}

Output:

String is empty

Using the trim() Method

The trim() method removes whitespace from both ends of a string. After trimming, if the string length is 0, then the string is considered empty.

Syntax:

if (string_name.trim() === '') {
   // string is empty
}

Example:

var str = ' ';
if (str.trim() === '') {
   document.write('String is empty');
}

Output:

String is empty

Conclusion

To check if a string is empty in JavaScript:

  • Use string.length to detect if it has no characters.
  • Use string.trim() if you also want to ignore leading and trailing spaces.

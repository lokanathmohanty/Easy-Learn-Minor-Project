C++ Conditional (Ternary) Operator (? :) 🤔

The **conditional operator** (? :) is C++'s only **ternary operator**, meaning it requires three operands. It provides a compact, single-line shorthand for a simple if-else statement that assigns one of two values to a variable based on a condition.

Syntax and Evaluation

The structure of the conditional operator is:

Exp1 ? Exp2 : Exp3;
  • **Exp1 (Condition):** This expression is evaluated first. It must yield a Boolean (or convertible to Boolean) result.
  • **If Exp1 is true:** Then **Exp2** is evaluated, and its value becomes the result of the entire expression.
  • **If Exp1 is false:** Then **Exp3** is evaluated, and its value becomes the result of the entire expression.

Equivalence to if-else

The structure below:

if(condition) {
   variable = Value_A;
} else {
   variable = Value_B;
}

is exactly equivalent to the single-line ternary expression:

variable = condition ? Value_A : Value_B;

Example Analysis

The provided example demonstrates the conditional assignment:

int x, y = 10;
x = (y < 10) ? 30 : 40;

In this code:

  1. **Condition (Exp1):** (y < 10) is evaluated. Since y is 10, the condition (10 < 10) is **false**.
  2. **Result:** Since the condition is false, **Exp3 (40)** is evaluated, and its value is assigned to x.

This results in the output:

value of x: 40

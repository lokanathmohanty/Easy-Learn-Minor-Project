PHP Spaceship Operator (`<=>`)

The **Spaceship Operator** (`<=>`), introduced in **PHP 7.0**, is a **three-way comparison operator**. It is used to quickly determine if the left operand is less than, equal to, or greater than the right operand. It can be used to compare various types, including integers, floats, strings, and arrays.

Syntax and Return Values

The operator compares two operands and returns one of three possible integer values:

$result = operand1 **<=>** operand2;
  • **Returns `-1` (Less Than):** If `operand1` is less than `operand2`.
  • **Returns `0` (Equal To):** If `operand1` is equal to `operand2`.
  • **Returns `1` (Greater Than):** If `operand1` is greater than `operand2`.

Usage Examples with Different Data Types

1. Numeric Comparison

Used for comparing numbers, including the result of calculations.

$x = 7; $y_calc = 10 / 2; // $y_calc is 5
$z = $x <=> $y_calc;

Since $7$ is greater than $5$, the result is $\mathbf{1}$.

2. String Comparison (Lexicographical)

Compares strings alphabetically (lexicographically). This comparison is similar to the result of `strcmp()`, based on character ASCII values.

"bat" <=> "ball" $\rightarrow$ **$1$** ("bat" comes after "ball")
"bat" <=> "baz" $\rightarrow$ **$-1$** ("bat" comes before "baz")
"PHP" <=> "PHP" $\rightarrow$ **$0$**

3. Boolean Comparison

The spaceship operator also works with Boolean values, where **`false` is treated as less than `true`**.

true <=> false $\rightarrow$ **$1$**
false <=> true $\rightarrow$ **$-1$**
true <=> true $\rightarrow$ **$0$**

This behavior extends to comparison of Booleans with numbers, where `false` is treated as $0$ and `true` as $1$. For instance, `10 <=> true` evaluates to $1$ because $10$ is greater than $1$.

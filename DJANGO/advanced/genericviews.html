Django: Generic Class-Based Views (CBVs) ⚙️

Django's **Generic Views** are classes that implement common web development patterns (like displaying a static page, listing data, or handling forms). They drastically reduce the amount of repetitive boilerplate code compared to traditional function-based views.

Unlike classic views, generic views are **classes** (found in django.views.generic) that you either use directly or inherit from. To use a generic view class in a URL configuration, you must call its **.as_view()** class method.

Using Generic Views for Static Pages (TemplateView)

The **TemplateView** is used to render a template without any complex logic or database interaction.

Method 1: Creating a Custom View Class

You can define a class that inherits from TemplateView and specifies the template_name attribute:

# myapp/views.py
from django.views.generic import TemplateView

class StaticView(TemplateView):
   template_name = "static.html"

Then, register the class's .as_view() method in urls.py:

# myapp/urls.py
from myapp.views import StaticView

urlpatterns = patterns("myapp.views", 
   (r'^static/$', StaticView.as_view()),)

Method 2: Configuring Directly in urls.py (No views.py Change)

For maximum simplicity, you can configure TemplateView directly in the URLconf by passing the template_name as an argument to .as_view():

# myapp/urls.py
from django.views.generic import TemplateView

urlpatterns = patterns("myapp.views",
   url(r'^static/', TemplateView.as_view(template_name = 'static.html')),)

Using Generic Views to List Data (ListView)

The **ListView** class is designed to retrieve and display a list of objects from a database model.

To use ListView, you must specify the **model** attribute and the **template_name**:

# myapp/urls.py
from django.views.generic import ListView

urlpatterns = patterns(
   "myapp.views", 
   url(r'^dreamreals/', ListView.as_view(
      model = Dreamreal, 
      template_name = "dreamreal_list.html")),
)

Context Data in ListView

By default, ListView passes the list of retrieved objects to the template using the variable name **object_list**.

If you prefer a custom variable name, you can set the **context_object_name** argument in .as_view():

# Setting context_object_name to 'dreamreals_objects'
url(r'^dreamreals/', ListView.as_view(
   template_name = "dreamreal_list.html",
   model = Dreamreal, 
   context_object_name = 'dreamreals_objects'),
)

Template Usage

The template iterates over the list (using the default object_list in this example):

{% for dr in object_list %}
   <p>{{dr.name}}</p>
{% endfor %}

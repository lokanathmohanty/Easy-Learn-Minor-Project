ReactJS - Portals

Portals provide a way for a component to render its children into a DOM node outside its own DOM hierarchy. They are useful for modal dialogs, popups, tooltips, and other UI elements where rendering outside the parent DOM structure is preferred.

Concept and Usage of Portals

Consider the following DOM structure in the main document:

<div id="root"></div>
<div id="modalRoot"></div>

The root node is attached to the main React component, while modalRoot can be used to render a modal dialog. This separation helps preserve modal styles and prevents interference from parent DOM styles.

React provides createPortal via the ReactDOM package: 

ReactDOM.createPortal(child, container)
  • child – the modal, tooltip, or other UI element
  • container – the DOM node outside the parent hierarchy
render() {
   return ReactDOM.createPortal(
      this.props.children, 
      domNode
   );
}

Applying Portals

Steps to create a React application with portals:

  • Create a new React app and start it
  • Add a modalRoot div in public/index.html
  • Create a SimplePortal component
  • Use the portal in App component

index.html

<div id="root"></div>
<div id="modalRoot"></div>

SimplePortal Component

import React from "react";
import PortalReactDOM from "react-dom";

const modalRoot = document.getElementById("modalRoot");

class SimplePortal extends React.Component {
   render() {
      return PortalReactDOM.createPortal(
         <div className="modal" onClick={this.props.onClose}>
            <div className="modalContent">
               {this.props.children}
               <hr />
               <button onClick={this.props.onClose}>Close</button>
            </div>
         </div>,
         modalRoot
      )
   }
}
export default SimplePortal;

App Component

import React from "react";
import SimplePortal from "./Components/SimplePortal";

class App extends React.Component {
   constructor(props) {
      super(props);
      this.state = { modal: false };
   }

   handleOpenModal = () => this.setState({ modal: true });
   handleCloseModal = () => this.setState({ modal: false });

   render() {
      return (
         <div className="container">
            <p>Main App</p>
            <button onClick={this.handleOpenModal}>Show Modal</button>
            { this.state.modal ? (
               <SimplePortal onClose={this.handleCloseModal}>
                  Hi, I am the modal dialog created using portal.
               </SimplePortal>
            ) : null }
         </div>
      );
   }
}
export default App;

Summary

React Portals provide an easy way to render components outside their parent DOM hierarchy. They are particularly useful for modals, tooltips, and overlays, while still maintaining proper event bubbling across different DOM nodes.

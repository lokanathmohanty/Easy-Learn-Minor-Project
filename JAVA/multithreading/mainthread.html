Java - Main Thread

Main Thread in Java

Whenever a Java program is run, the main thread is created automatically by the JVM. This thread is responsible for executing the main method of the program. All other threads (child threads) are typically spawned from this main thread.

The main thread is the first thread to start and often the last one to finish, making it useful for shutdown tasks.

How to Control the Main Thread?

The main thread can be controlled using various thread methods. Common ones include:

  • sleep() method
  • join() method
  • interrupt() method

Example 1: Simple Main Thread

This example demonstrates a basic Java program with only the main thread. It prints the thread name and priority.


public class TestThread {
   public void printName() {
      System.out.println("Thread Name: " + Thread.currentThread().getName());
      System.out.println("Thread Priority: " + Thread.currentThread().getPriority());
   }
   public static void main(String args[]) {
      TestThread thread = new TestThread();
      thread.printName();
   }
}

Output:


Thread Name: main
Thread Priority: 5

Example 2: Main Thread and Child Threads

This example creates two child threads from the main thread. The thread states are printed during execution.


class ThreadDemo extends Thread {
   ThreadDemo() {
      System.out.println("Thread: " + Thread.currentThread().getName() + ", State: New");
   }
   public void run() {
      System.out.println("Thread: " + Thread.currentThread().getName() + ", State: Running");
      for (int i = 4; i > 0; i--) {
         System.out.println("Thread: " + Thread.currentThread().getName() + ", " + i);
      }
      System.out.println("Thread: " + Thread.currentThread().getName() + ", State: Dead");
   }
   public void start() {
      System.out.println("Thread: " + Thread.currentThread().getName() + ", State: Start");
      super.start();
   }
}

public class TestThread {
   public static void main(String args[]) {
      ThreadDemo thread1 = new ThreadDemo();
      ThreadDemo thread2 = new ThreadDemo();
      thread1.start();
      thread2.start();
   }
}

Example 3: Main Thread Ends First

This example adds a final print statement to indicate that the main thread has completed while the child threads continue running.


public class TestThread {
   public static void main(String args[]) {
      ThreadDemo thread1 = new ThreadDemo();
      ThreadDemo thread2 = new ThreadDemo();
      thread1.start();
      thread2.start();
      System.out.println("Thread: " + Thread.currentThread().getName() + ", State: Dead");
   }
}

Note: The output shows that the main thread finishes early, but the child threads continue their execution independently.

JavaScript - Callback Function

In JavaScript, functions are treated as objects, which means they can be passed around just like variables. One common use case is passing a function as an argument to another function. When the passed function is later invoked inside that function, it is called a callback function.

Callback functions provide a way to control when and how a certain piece of code should run, especially for asynchronous operations like server requests or event handling.

Why do we need Callback Functions?

  • To run a piece of code after another function finishes execution.
  • To handle asynchronous operations (e.g., data loading, user input, timers).
  • To manage events such as button clicks or page loading.
  • To reuse the same logic across different situations without duplicating code.

Example of a Callback Function


var callback = function(myCallback) {
   setTimeout(function() {
      myCallback();
   }, 5000);
};

console.log("First is displayed");
console.log("Second is displayed");

callback(function() {
   console.log("This is Callback function");
});

console.log("Last is displayed");

Output


First is displayed
Second is displayed
Last is displayed
-- after 5 seconds --
This is Callback function

Callback Function with Parameters


var callback = function(myCallback) {
   setTimeout(function() {
      myCallback("Hello, World!");
   }, 5000);
};

console.log("First is displayed");
console.log("Second is displayed");

callback(function(message) {
   console.log(message);
});

console.log("Last is displayed");

Output


First is displayed
Second is displayed
Last is displayed
-- after 5 seconds --
Hello, World!

What is Callback Hell?

Callback Hell happens when too many callbacks are nested inside each other, making the code messy and difficult to read or maintain.

Example of Callback Hell


function step1(callback) {
   setTimeout(function() {
      console.log("Step 1");
      callback();
   }, 1000);
}

function step2(callback) {
   setTimeout(function() {
      console.log("Step 2");
      callback();
   }, 1000);
}

function step3(callback) {
   setTimeout(function() {
      console.log("Step 3");
      callback();
   }, 1000);
}

step1(function() {
   step2(function() {
      step3(function() {
         console.log("Done!");
      });
   });
});

Output


Step 1
Step 2
Step 3
Done!

Conclusion

Callback functions are essential for handling asynchronous behavior in JavaScript. However, excessive nesting can lead to callback hell. To solve this, modern JavaScript uses Promises and async/await for better readability and maintainability.

R - JSON Files

JSON (JavaScript Object Notation) files store data in a human-readable text format using key-value pairs. In R, JSON files can be read using the rjson package.

Install rjson Package

install.packages("rjson")

Input Data

Create a JSON file by copying the following data into a text editor and saving it as input.json:

{
  "ID": ["1","2","3","4","5","6","7","8"],
  "Name": ["Rick","Dan","Michelle","Ryan","Gary","Nina","Simon","Guru"],
  "Salary": ["623.3","515.2","611","729","843.25","578","632.8","722.5"],
  "StartDate": ["1/1/2012","9/23/2013","11/15/2014","5/11/2014","3/27/2015","5/21/2013","7/30/2013","6/17/2014"],
  "Dept": ["IT","Operations","IT","HR","Finance","IT","Operations","Finance"]
}

Read the JSON File

# Load the rjson package
library("rjson")

# Parse the JSON file into R
result <- fromJSON(file = "input.json")

# Print the result
print(result)

Output:

[1] "IT" "Operations" "IT" "HR" "Finance" "IT" "Operations" "Finance"

Convert JSON to Data Frame

# Convert the JSON list to a data frame for analysis
json_data_frame <- as.data.frame(result)

# Print the data frame
print(json_data_frame)

.NET Core - Adding References to a Library

Adding references (dependencies) to a **Portable Class Library (PCL)** or a **.NET Standard Library** is similar to adding references in your main application projects (like a Console App or UWP App). These dependencies are managed using **NuGet packages** and are configured through the project's file (project.json at the time of this documentation) or the NuGet Package Manager UI.

Default Library References (project.json)

The **PCL** (retargeted to **.NET Standard**) project file, project.json, contains default references necessary for cross-platform compatibility:

{ 
   "supports": {}, 
   "dependencies": { 
      /** Default references for .NET Standard **/
      "NETStandard.Library": "1.6.0", 
      "Microsoft.NETCore.Portable.Compatibility": "1.0.1" 
   }, 
   "frameworks": { 
      "netstandard1.3": {} 
   } 
}

Method 1: Adding Dependencies Manually (project.json)

You can add required NuGet packages directly by editing the project.json file and listing them under the **dependencies** section:

  1. Open the project.json file for your library project (e.g., StringLibrary).
  2. Add the package name and version number as a new entry in the "dependencies" object.

For example, to add serialization and database packages:

{ 
   // ... other sections ...
   "dependencies": { 
      "NETStandard.Library": "1.6.0", 
      "Microsoft.NETCore.Portable.Compatibility": "1.0.1", 
      
      /** Manually Added References **/
      "System.Runtime.Serialization.Json": "4.0.3", 
      "Microsoft.EntityFrameworkCore": "1.1.0" 
   }, 
   // ... other sections ...
}

Upon saving the file, Visual Studio automatically resolves and adds these NuGet package references to your library.

Method 2: Adding Dependencies via NuGet Package Manager

The visual method involves using the **Manage NuGet Packages** interface in Visual Studio:

  1. Right-click on your library project (**StringLibrary (Portable)**) in Solution Explorer.
  2. Select **Manage NuGet Packages**.
  3. Use the **Browse** tab to search for the desired package (e.g., System.Runtime.Serialization.Primitives).
  4. Click **Install**, review the changes, and click **OK**.
  5. Accept the license terms by clicking **I Accept** to complete the installation.

The selected NuGet package is then downloaded and added to your library's references.

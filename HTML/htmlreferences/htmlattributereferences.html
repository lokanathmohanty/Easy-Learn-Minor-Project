HTML - Attribute Reference

HTML attributes define the characteristics of an HTML element and are placed within the element’s opening tag. These attributes either change the default functionality or add extra functionalities to an element.

Local Attributes

Local attributes are element-specific; they can be used only on certain HTML elements.

Attribute Description Example
accept Specifies file types allowed in a file input dialog. 
<input type="file" accept="image/*">
action Specifies a URL that processes the form submission. 
<form action="submit.php"></form>
alt Provides alternative text for images. 
<img src="logo.png" alt="Company Logo">
checked Indicates if a checkbox or radio is selected by default. 
<input type="checkbox" checked>
href Specifies the URL that a hyperlink points to. 
<a href="https://example.com">Visit</a>
src Specifies the path to an external resource like an image or video. 
<img src="image.jpg">

Global Attributes

Global attributes can be applied to all HTML elements universally.

Attribute Description Example
id Specifies a unique identifier for the element. 
<p id="intro">Hello</p>
class Specifies one or more class names for styling. 
<div class="box highlight"></div>
style Applies inline CSS styles. 
<p style="color:red;">Alert!</p>
title Specifies extra information displayed as a tooltip. 
<abbr title="HyperText Markup Language">HTML</abbr>
lang Defines the language of the element’s content. 
<p lang="fr">Bonjour</p>

Boolean Attributes

Boolean attributes represent true/false values. They are true when present, and false when omitted.

Attribute Description Example
readonly Makes an input field uneditable. 
<input type="text" value="Hello" readonly>
required Specifies that an input must be filled before submitting. 
<input type="email" required>
checked Specifies that a checkbox/radio is selected by default. 
<input type="radio" checked>
disabled Disables an element. 
<button disabled>Click Me</button>

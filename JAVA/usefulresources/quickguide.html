Java - Quick Guide: Overview, Environment, and Syntax Essentials

I. Java Overview and Core Concepts

Java, originally developed by **James Gosling** at Sun Microsystems and released in **1995**, is known for its core philosophy: **Write Once, Run Anywhere (WORA)**. This is achieved by compiling source code into platform-independent **bytecode**, which is then executed by the **Java Virtual Machine (JVM)** on any platform.

Key Characteristics of Java 🔑

  • **Object-Oriented:** Everything is based on the Object model, making it easily extensible.
  • **Platform Independent:** Compiled to bytecode, not platform-specific machine code.
  • **Robust:** Strong compile-time and runtime error checking (e.g., no explicit memory management).
  • **Secure:** Features for developing virus-free, tamper-free systems.
  • **Multithreaded:** Supports concurrent execution of multiple tasks within a program.
  • **Dynamic:** Capable of adapting to evolving environments and carrying extensive runtime information.

II. Environment Setup (JDK 8)

To write and run Java applications locally, you need the **Java Development Kit (JDK)**.

Essential Steps:

  1. Download & Install: Obtain the compatible **Java JDK** (version 8 or later is mentioned) from Oracle or OpenJDK.
  2. Set Environment Path: Configure the system's **PATH** environment variable to include the path to the JDK's bin directory (e.g., C:\Program Files\java\jdk\bin). This allows you to run Java tools (javac, java) from any command prompt location.
  3. Tools: Use a simple text editor (like Notepad/Notepad++) or a sophisticated IDE like **Netbeans** or **Eclipse** to write code.

Compilation and Execution Example

// 1. Save code as MyFirstJavaProgram.java
public class MyFirstJavaProgram {
   public static void main(String []args) {
      System.out.println("Hello World");
   }
}
// 2. Compile:
C:\> javac MyFirstJavaProgram.java

// 3. Run:
C:\> java MyFirstJavaProgram 
// Output: Hello World

III. Java Basic Syntax Rules

Understanding these rules is fundamental to writing compilable Java code:

  • Case Sensitivity: Java is case sensitive (e.g., Hello and hello are different).
  • Class Names: Start with an **Upper Case** letter (e.g., MyFirstJavaClass).
  • Method Names: Start with a **Lower Case** letter (e.g., myMethodName()).
  • **Program File Name:** Must **exactly match** the name of the **public class** within the file, followed by the .java extension.
  • **main() Method:** The entry point for all Java program execution: public static void main(String args[]).

Identifiers (Naming Rules)

Identifiers (for classes, variables, methods) must:

  • Begin with a **letter** (A-Z or a-z), a **currency character ($)**, or an **underscore (_) **.
  • Cannot be a **reserved keyword** (see list below).

Modifiers

Used to modify classes, methods, or variables. They fall into two categories:

  • **Access Modifiers:** public, private, protected, default (no keyword).
  • **Non-Access Modifiers:** final, abstract, static, transient, etc.

IV. Variable Types and Data Types

Variable Types

There are three types of variables, defined by their location and scope:

Primitive Data Types (8 Total)

These are the basic, built-in types, each with a fixed size:

  • **Integers:** byte (8-bit), short (16-bit), int (32-bit, default), long (64-bit).
  • **Floating-Point:** float (32-bit, single-precision), double (64-bit, default).
  • **Character:** char (16-bit Unicode character).
  • **Boolean:** boolean (true or false).

Reference/Object Data Types (like **Arrays** and **Strings**) are instances of classes.

V. Java Keywords (Reserved Words)

These words have special meaning to the compiler and cannot be used as identifiers. Important ones include:

abstract, assert, boolean, break, byte, case, catch, char, class, const (reserved, not used), continue, default, do, double, else, enum, extends, final, finally, float, for, goto (reserved, not used), if, implements, import, instanceof, int, interface, long, native, new, package, private, protected, public, return, short, static, strictfp, super, switch, synchronized, this, throw, throws, transient, try, void, volatile, while.

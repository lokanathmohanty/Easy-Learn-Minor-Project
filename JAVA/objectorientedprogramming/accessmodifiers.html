Java Programming: Security and Encapsulation

Session: Understanding Java Access Modifiers

Introduction to Access Modifiers

Java **access modifiers** define the **scope** (visibility) of classes, variables, methods, and constructors. They are essential for restricting and securing access to data, which is a core tenet of **encapsulation** in OOP.

There are four types of access modifiers:

  • **Default** (No modifier)
  • **Private**
  • **Protected**
  • **Public**

Default Access Modifier (Package-Private)

When no explicit access modifier is declared, the component is assigned **default access**. This restricts visibility to the current package.

  • Scope: Accessible by any other class within the **same package**.
  • Key Fact: Class members (fields/methods) without a modifier are package-private.

Private Access Modifier

The **private** modifier is the most restrictive access level. It is the primary mechanism for achieving encapsulation, ensuring data is hidden from the outside world.

  • Scope: Accessible **only within the declared class itself**.
  • Restriction: Classes and interfaces **cannot** be declared private.
  • Access: Private variables can be accessed indirectly outside the class using public **getter/setter methods**.

Example: Private Field with Public Accessors

The private format variable is hidden, but public methods provide controlled access:

public class Logger {
   private String format; // Private variable

   public String getFormat() { // Public getter method
      return this.format;
   }

   public void setFormat(String format) { // Public setter method
      this.format = format;
   }
}

Protected Access Modifier

The **protected** modifier is primarily used for features that should be available to derived classes (subclasses) while remaining restricted to unrelated classes.

  • Scope: Accessible within the **same package** **OR** by **subclasses** (in any package).
  • Inheritance Rule: A protected method in a superclass must be declared protected or public in the subclass (cannot be private).

Public Access Modifier

The **public** modifier provides the least restriction. A public member is accessible from anywhere in the Java environment.

  • Scope: Accessible from **any other class**, in any package.
  • Requirement: If the public class is in a different package, it still needs to be explicitly imported.
  • Common Use: The application entry point, main() method, must be public.

Summary of Access Levels

The following table summarizes accessibility across different scopes (from least restrictive to most restrictive):

  • Public: $\rightarrow$ Class $\rightarrow$ Package $\rightarrow$ Subclass $\rightarrow$ World
  • Protected: $\rightarrow$ Class $\rightarrow$ Package $\rightarrow$ Subclass $\rightarrow$ $\textrm{NO}$ World
  • Default: $\rightarrow$ Class $\rightarrow$ Package $\rightarrow$ $\textrm{NO}$ Subclass $\rightarrow$ $\textrm{NO}$ World
  • Private: $\rightarrow$ Class $\rightarrow$ $\textrm{NO}$ Package $\rightarrow$ $\textrm{NO}$ Subclass $\rightarrow$ $\textrm{NO}$ World

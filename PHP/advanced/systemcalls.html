PHP System Calls and External Program Execution

PHP provides a set of built-in functions that allow the execution of **operating system commands** and **external programs** directly from within the PHP script. These are crucial for tasks like file manipulation, process management, and integrating external utilities.

Functions for System Execution 💻

1. $\text{system()}$

Executes the command and **outputs the result line by line** directly to the output buffer (browser/console). It is useful when you want to show the output as it's being generated.

system(string $command, int &$result_code = null): string|false
  • Output: Prints the output and returns only the **last line** of the command's output as a string.
  • Return Code: The optional $\text{\$result\_code}$ parameter is populated with the shell's integer return status ($\text{0}$ usually means success).

2. $\text{shell\_exec()}$ and Backtick Operator ($\text{` `}$)

Executes the command via the shell and returns the **complete output as a single string**. This is identical to using the PHP **backtick operator** ($\text{`command`}$).

shell_exec(string $command): string|false|null
  • Output: Returns the entire command output as a single string.
  • Use Case: Ideal for capturing the full result of a command to process or log it within the PHP script.

3. $\text{exec()}$

Executes the command and is designed to capture the output line-by-line into an array, offering detailed control over the results.

exec(string $command, array &$output = null, int &$result_code = null): string|false
  • Output: Returns only the **last line** of output as a string.
  • Output Array: The optional $\text{\$output}$ array is filled with **every line** of output from the command.
  • Return Code: The optional $\text{\$result\_code}$ parameter stores the shell's integer return status.
  • Use Case: Best when you need the complete output of the command structured into an array of lines.

4. $\text{passthru()}$

Executes an external program and displays the **raw output** directly to the output stream. It bypasses any internal PHP buffering or processing.

passthru(string $command, int &$result_code = null): ?false
  • Output: Sends raw data directly to the output.
  • Use Case: Primarily used when the external command generates **binary data** (like an image or a PDF) that needs to be passed directly back to the browser without being corrupted by PHP's string handling.

JavaScript - Nested Loop

In JavaScript, a loop inside another loop is called a nested loop. Nested loops are commonly used when iterating over multi-dimensional arrays or matrices, or when performing repeated actions on each element of an array.

Syntax of Nested Loop

for (let i = 0; i < rows.length; i++) {
   for (let j = 0; j < columns.length; j++) {
      // code block to be executed
   }
}

Nested Loop Using for Loop

In the following example, we use nested for loops to iterate through two arrays: 

let rows = [1, 2, 3];
let columns = [4, 5, 6];

for (let i = 0; i < rows.length; i++) {
   for (let j = 0; j < columns.length; j++) {
      console.log(rows[i] + " " + columns[j]);
   }
}

Output

1 4
1 5
1 6
2 4
2 5
2 6
3 4
3 5
3 6

Here, we iterate over each element of rows, and for each row element, we iterate over all elements of columns.

Nested Loop Using while Loop

Nested loops can also be implemented using the while loop. Below is the example with while loops: 

let rows = [1, 2, 3];
let columns = [4, 5, 6];

let i = 0;
while (i < rows.length) {
   let j = 0;
   while (j < columns.length) {
      console.log(rows[i] + " " + columns[j]);
      j++;
   }
   i++;
}

Output

1 4
1 5
1 6
2 4
2 5
2 6
3 4
3 5
3 6

Just like the for loop example, the nested while loop iterates through both arrays to produce all possible row-column pairs.

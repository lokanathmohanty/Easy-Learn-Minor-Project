PowerShell: Brackets

PowerShell uses three types of brackets, each with specific roles in scripting:

  • Parenthesis Brackets ()
  • Braces Brackets {}
  • Square Brackets []

Parenthesis Brackets ()

Used to:

  • Pass arguments to functions or cmdlets.
  • Enclose multiple instructions.
  • Resolve ambiguity in expressions.
  • Create arrays.

Example:

$array = @("item1", "item2", "item3")
foreach ($element in $array) { $element }
# Outputs: item1, item2, item3

Braces Brackets {}

Used to:

  • Enclose statements or script blocks.
  • Group commands within control statements.

Example:

$x = 10
if ($x -le 20) {
  Write-Host "This is if statement"
}
# Output: This is if statement.

Square Brackets []

Used to:

  • Access array elements by index.
  • Access hashtable values by key.
  • Filter using regular expressions or character classes.

Example:

$array = @("item1", "item2", "item3")
for ($i = 0; $i -lt $array.Length; $i++) {
  $array[$i]
}
# Outputs: item1, item2, item3

Get-Process [r-s]*
# Lists processes starting with letter 'r' or 's'

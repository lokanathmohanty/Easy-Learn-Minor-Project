Node.js - File System

Overview

The Node.js fs module allows interacting with the file system to perform operations like reading, writing, and managing files and directories. It supports both synchronous and asynchronous methods for efficient handling.

Basic File Operations

Writing to a File

const fs = require('fs');
const data = `Tutorials Point is giving self learning content
to teach the world in simple and easy way!!!!!`;

// Synchronous write
fs.writeFileSync("input.txt", data);

// Asynchronous write
fs.writeFile("input.txt", data, (err) => {
  if (err) console.error(err);
  else console.log("Write operation complete.");
});

Reading from a File

const fs = require('fs');

// Synchronous read
const data = fs.readFileSync("input.txt");
console.log(data.toString());

// Asynchronous read
fs.readFile("input.txt", (err, data) => {
  if (err) console.error(err);
  else console.log(data.toString());
});

Working with File Descriptors

Open a file, write data, read data and close it:

const fs = require('fs');
const content = "Sample content for file.";

// Open file for writing
fs.open('input.txt', 'w', (err, fd) => {
  if (err) throw err;

  fs.write(fd, content, (err) => {
    if (err) throw err;

    fs.close(fd, (err) => {
      if (err) throw err;
      console.log("File written and closed successfully.");
    });
  });
});

Modifying Files

Truncate file content to a specific length:

fs.open('input.txt', 'r+', (err, fd) => {
  if (err) throw err;

  fs.ftruncate(fd, 10, (err) => {
    if (err) throw err;

    console.log("File truncated to 10 bytes.");

    fs.close(fd, (err) => {
      if (err) throw err;
      console.log("File closed.");
    });
  });
});

File and Directory Management

Deleting a File

fs.unlink('input.txt', (err) => {
  if (err) console.error(err);
  else console.log("File deleted successfully.");
});

Creating a Directory

fs.mkdir('testDir', (err) => {
  if (err) console.error(err);
  else console.log("Directory created.");
});

Reading a Directory

fs.readdir('.', (err, files) => {
  if (err) console.error(err);
  else files.forEach(file => console.log(file));
});

Removing a Directory

fs.rmdir('testDir', (err) => {
  if (err) console.error(err);
  else console.log("Directory removed.");
});

Using the fs.stat() method

fs.stat('input.txt', (err, stats) => {
  if (err) console.error(err);
  else {
    console.log(stats);
    console.log("Is File? " + stats.isFile());
    console.log("Is Directory? " + stats.isDirectory());
  }
});

Notes

  • Asynchronous methods are preferred for non-blocking operations.
  • File descriptors are unique integers returned from fs.open() and used for read/write operations.
  • Remember to close files after operations using fs.close() to free up resources.

C++ Strings: C-Style vs. std::string 📝

C++ supports two primary types of string representations, each with different mechanisms and capabilities:

  1. The **C-style character string** (null-terminated character array).
  2. The **std::string class type** (part of the Standard C++ Library).

1. The C-Style Character String

Originating from C, this string type is a **one-dimensional array of characters** that must be explicitly or implicitly terminated by a **null character** (`'\0'`). The length of the array must be at least one greater than the number of visible characters.

Declaration:

char greeting[6] = {'H', 'e', 'l', 'l', 'o', '\0'};

Or, more commonly, letting the compiler handle the size and null terminator:

char greeting[] = "Hello";

C-Style String Functions (from <cstring>/<string.h>)

These functions operate directly on null-terminated character arrays. **Caution:** Many of these functions do not check array bounds, which can lead to buffer overflow vulnerabilities.

FunctionPurpose
strcpy(s1, s2)Copies string s2 into string s1.
strcat(s1, s2)Concatenates string s2 onto the end of s1.
strlen(s1)Returns the length of string s1 (excluding the '\0').
strcmp(s1, s2)Compares strings lexicographically.

2. The std::string Class

This is the preferred and modern way to handle strings in C++. It is an object type defined in the **<string>** header file and offers dynamic memory management and powerful member functions, abstracting away the need for manual null termination and buffer sizing.

Declaration and Operations:

string str1 = "Hello";
string str2 = "World";

// Concatenation using the overloaded '+' operator:
string str3 = str1 + str2; // Result: "HelloWorld"

// Assignment using the overloaded '=' operator:
str3 = str1; // Result: "Hello"

Essential std::string Member Functions:

FunctionDescription
length() / size()Returns the number of characters in the string.
append(str)Concatenates the given string to the end.
push_back(char)Adds a single character to the end.
find()Searches for a substring and returns the starting position.

compare(str)Compares the string with another string.

Input and Traversal Methods

String Input Methods

  • **cin >> s;:** Reads input only until the first whitespace (space, tab, newline) is encountered.
  • **getline(cin, s);:** **Reads an entire line** of input, including spaces, until a newline character is encountered. This is generally preferred for reading user input sentences.
  • **stringstream:** Used to treat a string as an input stream, allowing you to easily extract words or tokens from it.

Traversing (Iterating) a String

Characters in an std::string can be accessed or modified like an array element using its index (s[i]), or using loops:

  • **Traditional for Loop:** Accesses characters by index: 
    for (int i = 0; i < s.length(); i++) { /* use s[i] */ }
  • **Range-Based for Loop (Foreach):** Iterates over the characters directly, often using a reference (&c) to allow modification: 
    for (char& c : s) { c = 'B'; }

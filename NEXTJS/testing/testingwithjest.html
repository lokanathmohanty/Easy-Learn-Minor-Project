Next.js - Testing With Jest

What is Jest?

Jest is a popular, feature-rich **JavaScript testing framework** developed by Facebook. It is widely adopted in the React ecosystem, making it a natural choice for testing Next.js applications. Jest provides built-in tools for:

  • **Code Coverage** reporting.
  • **Snapshot Testing** for UI components.
  • Powerful **Mocking** capabilities for external dependencies (like API calls).

Jest allows developers to write tests that simulate user interactions (e.g., button clicks) and verify that components render and behave as expected.

Setting Up Jest in a Next.js Application

Option 1: Create a New Project with Jest

The easiest way to start is by initializing a new Next.js project with a pre-configured Jest setup:

npx create-next-app@latest --example with-jest

This command creates a project that includes necessary dependencies, configuration files (jest.config.js, jest.setup.js), and example test files.

Option 2: Manual Setup in an Existing Project

To set up Jest in an existing project, follow these steps:

Step 1: Install Dependencies

Install Jest and the React Testing Library helpers, which provide utilities for testing React components:

npm install --save-dev jest @testing-library/react @testing-library/jest-dom

Step 2: Create Jest Configuration (jest.config.js)

Create a configuration file in the project root to set up the testing environment and ignore non-test directories:

// File - /jest.config.js
module.exports = {
    testPathIgnorePatterns: [ "<rootDir>/.next/", "<rootDir>/node_modules/"],
    setupFilesAfterEnv: ["<rootDir>/jest.setup.js"],
    testEnvironment: "jsdom",
};

Step 3: Add Scripts to package.json

Add scripts to easily run tests from the command line:

// File - /package.json
{
    "scripts": {
      "test": "jest",
      "test:watch": "jest --watch"
    }
}

Step 4: Create Test Directory

Create a directory named **__tests__** in the root where all test files (ending with .test.tsx or .test.jsx) will be stored.

Writing Component Tests with Jest and RTL

This example demonstrates how to test a simple Next.js component to verify both its initial rendering and its response to user interaction.

The Component (app/Home/page.tsx)

A simple component that displays text and a button that triggers an alert.

export default function Home() {
    return (
        <div>
            <h1>Welcome to Next.js</h1>
            <button onClick={() => alert('Hello!')}>
                Click Me
            </button>
        </div>
    );
}

The Test File (/__tests__/Home.test.tsx)

The test uses **render** to simulate the component mounting, **screen.getByText** to find elements based on user-visible text, and **fireEvent.click** to simulate a click.

import { render, screen, fireEvent } from '@testing-library/react';
import Home from '@/pages/index';

describe('Home Page', () => {
    // Test 1: Renders the expected static text
    it('renders welcome message', () => {
        render(<Home />);
        expect(screen.getByText('Welcome to Next.js')).toBeInTheDocument();
    });

    // Test 2: Handles the button click event
    it('handles button click', () => {
        render(<Home />);
        // Mock the window.alert function to track calls
        const alertMock = jest.spyOn(window, 'alert').mockImplementation();
        
        fireEvent.click(screen.getByText('Click Me'));
        
        // Assert that the alert function was called with the correct message
        expect(alertMock).toHaveBeenCalledWith('Hello!');
        
        alertMock.mockRestore(); // Clean up the mock
    });
});

Running the Tests

To execute the tests, use the script defined in your package.json:

npm test

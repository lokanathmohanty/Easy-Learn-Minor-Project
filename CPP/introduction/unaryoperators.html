C++ Unary Operators Overview ✨

A **unary operator** is an operator that acts upon a **single operand** to produce a new value or perform a side effect. C++ has several unary operators used for arithmetic, logic, bitwise manipulation, memory management, and explicit type conversion.

Primary Unary Operators

1. Arithmetic Operators (+, -, ++, --)

  • **Unary Plus (+):** Indicates a positive value; typically has no effect, just returns the operand's value (e.g., +5).
  • **Unary Minus (-):** Negates the value, changing its sign (e.g., -(5) results in -5).
  • **Increment (++) & Decrement (--):** These modify the operand's value by one.
    • **Prefix (++x / --x):** Increments/decrements the operand **before** the value is used in the expression.
    • **Postfix (x++ / x--):** Increments/decrements the operand **after** the original value is used in the expression.

2. Logical & Bitwise Operators (!, ~)

  • **Logical NOT (!):** Reverses the Boolean meaning of the operand. Converts a true (non-zero) value to 0, and a false (zero) value to 1.
  • **Bitwise NOT (~):** Flips every bit of an integral operand (0 becomes 1, and 1 becomes 0). For signed integers, this results in the one's complement, typically yielding a negative result in two's complement systems (e.g., ~5 is -6).

3. Pointer Operators (*, &)

  • **Address-of (&):** Returns the memory address of the operand (e.g., &variable).
  • **Indirection/Dereference (*):** Returns the value stored at the memory address contained in the pointer operand (e.g., *pointer).

Miscellaneous Unary Operators

  • **sizeof:** A compile-time operator that returns the size, in bytes, of its operand (variable or data type). It's crucial for understanding memory consumption.
  • **Cast Operator ((type) expression or C++ Named Casts):** Forces the explicit conversion of one data type into another (e.g., (int)9.57). The C++ standard encourages safer named casts like static_cast, dynamic_cast, const_cast, and reinterpret_cast.
  • **new:** The memory allocation operator used to dynamically allocate memory for an object or array on the heap (e.g., int* p = new int;).
  • **delete:** The memory deallocation operator used to free memory that was previously allocated with new (e.g., delete p;).

R - Data Frames

A data frame is a two-dimensional table-like structure where each column contains values of one variable and each row contains one set of values from each column.

Characteristics of a data frame:

  • Column names should be non-empty.
  • Row names should be unique.
  • Data in columns can be numeric, factor, or character.
  • Each column must have the same number of data items.

Create Data Frame

# Create the data frame
emp.data <- data.frame(
  emp_id = c(1:5),
  emp_name = c("Rick","Dan","Michelle","Ryan","Gary"),
  salary = c(623.3,515.2,611.0,729.0,843.25),
  start_date = as.Date(c("2012-01-01", "2013-09-23", "2014-11-15", "2014-05-11", "2015-03-27")),
  stringsAsFactors = FALSE
)
print(emp.data)

Output:

  emp_id emp_name salary start_date
1      1     Rick  623.30 2012-01-01
2      2      Dan  515.20 2013-09-23
3      3 Michelle  611.00 2014-11-15
4      4     Ryan  729.00 2014-05-11
5      5     Gary  843.25 2015-03-27

Expand Data Frame

Add Row

# Create new data frame of rows to add
emp.newdata <- data.frame(
  emp_id = c(6:8),
  emp_name = c("Rasmi", "Pranab", "Tusar"),
  salary = c(578.0, 722.5, 632.8),
  start_date = as.Date(c("2013-05-21", "2013-07-30", "2014-06-17")),
  dept = c("IT", "Operations", "Finance"),
  stringsAsFactors = FALSE
)

# Combine with existing data frame
emp.finaldata <- rbind(emp.data, emp.newdata)
print(emp.finaldata)

CSS Display Property

The CSS display property is one of the most powerful and commonly used properties in web design. It controls how an element is displayed in the document flow. By changing the display value, you can control whether an element behaves as a block, inline, flex, grid, table, or even whether it disappears completely from the page layout.

Every HTML element has a default display behavior. For example, headings and paragraphs are block-level elements, while links and spans are inline elements. With the display property, we can override these defaults to create highly flexible layouts.

Syntax

The basic syntax of the display property is:

display: value;

Common Display Values

  • inline - Displays the element as an inline element. Width and height do not apply.
  • block - Displays the element as a block, starting on a new line and taking up full width.
  • inline-block - Inline flow with block properties like width and height.
  • flex - Turns an element into a flex container.
  • grid - Turns an element into a grid container.
  • none - Removes the element completely from the document flow.
  • contents - Makes the element disappear but keeps its children in place.
  • table - Behaves like a table element, with related values like table-row and table-cell.
  • inherit - Inherits the display property from the parent element.

Examples of CSS Display Property

1. Inline Example

By default, a <span> element is inline. If we set display: inline; on a <div>, it will also behave like text and appear in the same line as other inline elements.

Example:

  • <div style="display:inline">Item 1</div><div style="display:inline">Item 2</div>

2. Block Example

A <span> normally appears inline, but if we set display: block;, each span will start on a new line like a paragraph.

Example:

  • <span style="display:block">Item A</span><span style="display:block">Item B</span>

3. Inline-Block Example

display: inline-block; allows elements to sit next to each other (like inline), but you can still set width and height (like block).

Example:

  • <div style="display:inline-block; width:150px;">Box 1</div><div style="display:inline-block; width:150px;">Box 2</div>

4. Flex Example

Flexbox is one of the most used display types for modern layouts. It distributes items along a single axis, either horizontally or vertically.

Example:

  • <div style="display:flex"><div>Item 1</div><div>Item 2</div></div>

5. Grid Example

CSS Grid allows two-dimensional layouts with rows and columns. Using display: grid; lets us create advanced layouts more easily than flex alone.

Example:

  • <div style="display:grid; grid-template-columns:1fr 1fr;"><div>Cell 1</div><div>Cell 2</div></div>

6. None Example

Setting display: none; removes the element from the layout completely. It will not take up space on the page.

Example:

  • <div style="display:none">This is hidden</div>

7. Contents Example

With display: contents;, the element itself disappears but its children stay visible as if they were direct children of the parent.

Example:

  • <div style="display:contents"><span>Child A</span><span>Child B</span></div>

8. Table Example

Using display: table;, table-row;, and table-cell;, we can create table-like layouts without using the HTML table element.

Example:

  • <div style="display:table">
      <div style="display:table-row">
        <div style="display:table-cell">Row1 Cell1</div>
        <div style="display:table-cell">Row1 Cell2</div>
      </div>
    </div>

Browser Support

The display property is widely supported across all modern browsers. Some values like run-in and contents may not be fully supported in older browsers.

  • Chrome: Supported from version 4+
  • Firefox: Supported from version 3+
  • Edge: Supported from version 8.5+
  • Safari: Supported from version 3.1+
  • Opera: Supported from version 7+

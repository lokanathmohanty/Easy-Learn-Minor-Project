Java Scanner Class Summary ⌨️🔍

The **java.util.Scanner** class is a versatile text parser that can break input into **tokens** using a **delimiter pattern**, which defaults to **whitespace**. It can read input from various sources like **InputStream** (including the console), **File**s, and **String**s, making it the primary tool for simple console input and file parsing.

I. Input Sources and Construction

Scanner is highly flexible, accepting many different types of input sources in its numerous constructors. The most common use cases involve reading from the console or a file:

  • **Console Input:** Scanner consoleScanner = new Scanner(System.in); (Uses the standard input stream)
  • **String Input:** Scanner stringScanner = new Scanner("10 apple 20");
  • **File Input:** Scanner fileScanner = new Scanner(new File("data.txt"));

II. Tokenization and Parsing

The core functionality relies on identifying tokens based on a delimiter and then parsing those tokens into specific primitive types or strings.

Checking for Tokens (hasNext...)

These methods check if the next token is available and if it matches the pattern for a specific primitive type:

  • **boolean hasNext():** Checks if *any* next token exists.
  • **boolean hasNextInt() / hasNextDouble() / hasNextBoolean(), etc.:** Checks if the next token can be successfully parsed into the corresponding type.
  • **boolean hasNextLine():** Checks if there is another line of input.

Retrieving Tokens (next...)

These methods retrieve the token and convert it to the requested type:

  • **String next():** Retrieves the next complete token (delimited by whitespace by default).
  • **int nextInt() / double nextDouble() / String nextBigDecimal(), etc.:** Scans and returns the next token as the specified type.
  • **String nextLine():** Advances the scanner past the current line and returns the input that was skipped (up to the line terminator).

If a next...() method is called and the token is not the expected type, an **InputMismatchException** is thrown.

III. Configuration and Control

Scanner provides methods to customize parsing behavior:

  • **Delimiter:** The default delimiter is whitespace. Use **useDelimiter(Pattern pattern)** or **useDelimiter(String patternString)** to set a custom one (e.g., a comma).
  • **Radix:** The default radix for integers is 10. Use **useRadix(int radix)** to change it (e.g., to 16 for hexadecimal input).
  • **Locale:** Use **useLocale(Locale locale)** to handle locale-specific formatting for numbers (e.g., using a comma for the decimal separator).
  • **Close:** The **void close()** method is critical to release the underlying input source (especially important for files or streams).

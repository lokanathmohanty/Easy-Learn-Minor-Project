CSS - accent-color Property

The CSS accent-color property allows developers to define a custom accent color for user interface controls such as checkboxes, radio buttons, range sliders, and progress bars. This property provides flexibility in matching form controls with a website’s theme.

Syntax

accent-color: auto | color | initial | inherit;

Values

  • auto – Browser automatically selects the accent color (default).
  • color – Specifies a custom color using name, hex, rgb, or hsl values.
  • initial – Resets the property to its default value.
  • inherit – Inherits the property from its parent element.

Example 1: Setting Default Accent Color

By using accent-color: auto;, the browser automatically assigns the accent color to the controls. 

input {
  accent-color: auto;
}

Explanation: The browser handles the styling of checkboxes, radio buttons, and ranges with its default theme color.

Example 2: Customizing Accent Color

You can define the accent color using different color formats such as name, rgb(), or hex. 

input[type=radio] {
  accent-color: #ffa500; /* Orange using hex */
}

input[type=range] {
  accent-color: rgb(55, 255, 0); /* Bright green using RGB */
}

progress {
  accent-color: red; /* Named color */
}

Explanation: In this example, radio buttons are styled with orange, range sliders use bright green, and progress bars use red.

Supported Browsers

The accent-color property is supported in most modern browsers, including:

  • Chrome
  • Edge
  • Firefox
  • Safari
  • Opera

Final Example

The accent-color property is particularly useful for maintaining design consistency across forms and UI elements. It eliminates the need for complex custom styling when applying colors to standard HTML controls.

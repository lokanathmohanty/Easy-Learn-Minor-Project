C++ Standard Library Structure 🏛️

The **C++ Standard Library** is a comprehensive collection of functionalities that extends the core C++ language. It can be broadly categorized into two major parts:

I. The Standard Function Library (Inherited from C)

This part consists of **general-purpose, stand-alone functions** that are **not part of any class**. C++ incorporates all Standard C libraries, often with minor changes for type safety.

Key Categories:

  • **I/O**: Input/Output operations (inherited from C's `stdio.h`).
  • **String and character handling**: Functions for manipulating C-style strings (inherited from C's `string.h`).
  • **Mathematical**: Functions for common math operations (inherited from C's `math.h`).
  • **Time, date, and localization**.
  • **Dynamic allocation** (`malloc`, `free`).
  • **Wide-character functions**.

II. The Object-Oriented Class Library

This is a vast collection of **classes and associated functions** that provide advanced support for common activities, forming the core of **Modern C++** functionality, including the **Standard Template Library (STL)**.

Key Components:

  • **The Standard C++ I/O Classes**: Class-based I/O operations (`std::cout`, `std::cin` through ``).
  • **The String Class**: The `std::string` class, which manages strings automatically.
  • **The Numeric Classes**: Support for numeric processing and complex number types.
  • **The STL (Standard Template Library) Components**:
    • **STL Container Classes** (`std::vector`, `std::map`, etc.)
    • **STL Algorithms** (`std::sort`, `std::find`, etc.)
    • **STL Iterators** (The bridge between containers and algorithms)
    • **STL Function Objects** (Functors)
    • **STL Allocators** (Manage memory for containers)
  • **The Localization Library**: Tools for supporting different cultural conventions (e.g., date formats, currency).
  • **Exception Handling Classes**.
  • **Miscellaneous Support Library**.

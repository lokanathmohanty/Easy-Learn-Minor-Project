Recursion in C

What is Recursion?

Recursion is the process by which a function calls itself. C language allows writing such functions which solve complicated problems by breaking them down into simpler problems. These functions are known as recursive functions.

Why Use Recursion?

Recursion is used to perform complex tasks such as tree and graph traversals. Popular problems solved using recursion include factorial calculation, binary search, tower of Hanoi, and the Fibonacci series.

Key Points

  • Recursive functions call themselves.
  • Must always have a base case to avoid infinite recursion.
  • Can simplify code but may use more resources.

Example: Recursive Factorial Function

The following function calculates the factorial of a number recursively:


int factorial(int i) {
  if (i <= 1) {
    return 1;
  }
  return i * factorial(i - 1);
}

In this example, the function calls itself with a decremented value until it reaches 1.

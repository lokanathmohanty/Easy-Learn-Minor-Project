Python and R Script Visuals in Power BI

Power BI supports integration with Python and R scripting languages, allowing users to create advanced and custom visuals beyond standard charts. Both scripting environments need to be installed on the local machine to use these capabilities within Power BI Desktop.

Setting Up and Using Python Script Visual

  1. Ensure Python is installed and configured in Power BI Desktop via File → Options and Settings → Options → Python scripting.
  2. Load data into Power BI, then select the Python script visual from the Visualizations pane.
  3. Add necessary fields to the Values section.
  4. Write Python code in the script editor to process data and generate visuals. Example: 
    import pandas as pd
data = {'Student': ['Rihaan','Henry','Karan','Joseph','Diana'],
        'Marks':[95,85,78,89,54]}
df = pd.DataFrame(data)
# Plot code here
  5. Click Run to render the resulting visualization on the canvas.

Setting Up and Using R Script Visual

  1. Ensure R is installed and connected in Power BI Desktop via File → Options and Settings → Options → R scripting.
  2. Open dataset and select the R script visual from Visualizations.
  3. Add necessary fields into Values.
  4. Write R code in the script editor to generate plots. Example code may include plotting with ggplot2 or base R.
  5. Run the script to display the R-based visual.

Customizing Python and R Visuals

  • Adjust visual size (height and width) via Properties—Size settings.
  • Format titles and subtitles: enable them, set font family, style (bold, italic), size, color, and alignment.
  • Enhance visuals with effects such as background color, borders, and shadow.
  • Customize header icons colors and borders for better UI presentation.
  • Use alt text for accessibility; screen readers describe visuals based on provided text.

PHP Filters: Validation and Sanitization

The PHP **Filter Extension** provides a set of functions and constants designed to simplify and standardize the process of **validating and sanitizing** input data received from client requests ($\text{GET}$, $\text{POST}$, etc.). This is a critical security measure to prevent vulnerabilities like **SQL injection** and **cross-site scripting (XSS)**.

Types of Filters

The extension provides two main categories of filters:

  • Validation Filters: Check if data meets specific criteria (e.g., is it a valid email, URL, or integer). They **return $\text{false}$ on failure** but **do not alter the data itself**. Example: $\text{FILTER\_VALIDATE\_EMAIL}$.
  • Sanitization Filters: Remove illegal or undesired characters from the input. They **may alter the data** by stripping or encoding characters. Example: $\text{FILTER\_SANITIZE\_EMAIL}$ removes characters inappropriate for an email address.

Filter Functions and Usage

1. $\text{filter\_has\_var()}$

Checks if an external variable of a specified type exists.

filter_has_var(int $input_type, string $var_name): bool
If the URL is $\text{http://localhost/script.php?email=test@a.com}$, then: 
filter_has_var(INPUT_GET, "email");
Would return $\text{true}$.

2. $\text{filter\_input()}$

Retrieves a single external variable ($\text{GET, POST, COOKIE, ENV, SERVER}$) and filters it according to the specified filter constant and options.

filter_input(int $type, string $var_name, int $filter, array|int $options): mixed
  • Returns the filtered value on success.
  • Returns $\text{false}$ if the filter fails validation.
  • Returns $\text{null}$ if the variable name is not set.
Validating a $\text{GET}$ email: 
filter_input(INPUT_GET, "email", FILTER_VALIDATE_EMAIL);

3. $\text{filter\_input\_array()}$

Retrieves multiple external variables (e.g., all $\text{POST}$ data) and optionally filters them based on a defined options array. This avoids repetitive $\text{filter\_input()}$ calls.

filter_input_array(int $type, array|int $options): array|false|null

An example of using a filters array to validate multiple inputs:

$filters = [
   "age" => ["filter" => FILTER_VALIDATE_INT, "options" => ["min_range" => 20]],
   "email" => FILTER_VALIDATE_EMAIL
];
print_r(filter_input_array(INPUT_POST, $filters));

4. $\text{filter\_list()}$

Returns an array containing the names of all supported filters in the current PHP installation.

Predefined Input Constants

These integer constants are used as the $\text{\$input\_type}$ in the filter functions to specify the source of the data:

  • $\text{INPUT\_POST}$
  • $\text{INPUT\_GET}$
  • $\text{INPUT\_COOKIE}$
  • $\text{INPUT\_SERVER}$
  • $\text{INPUT\_ENV}$

Filter Flags (Options)

Filter flags are used to fine-tune the behavior of a filter, often passed as the $\text{\$options}$ argument. They modify what the filter accepts or how it sanitizes the data.

  • **String/Text Flags:**
    • $\text{FILTER\_FLAG\_STRIP\_LOW}$: Removes non-printable characters ($\text{<32}$).
    • $\text{FILTER\_FLAG\_NO\_ENCODE\_QUOTES}$: Prevents single/double quotes from being HTML encoded during sanitization.
  • **Number Flags:**
    • $\text{FILTER\_FLAG\_ALLOW\_FRACTION}$: Allows the period ($\text{.}$) as a decimal separator.
    • $\text{FILTER\_FLAG\_ALLOW\_THOUSAND}$: Allows the comma ($\text{,}$ ) as a thousands separator.
  • **IP Address Flags:**
    • $\text{FILTER\_FLAG\_IPV4}$: Requires the address to be in IPv4 format.
    • $\text{FILTER\_FLAG\_NO\_PRIV\_RANGE}$: Fails validation if the IP falls within common private ranges ($\text{10.0.0.0/8}$, $\text{192.168.0.0/16}$, etc.).

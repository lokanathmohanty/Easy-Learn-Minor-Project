JavaScript - Prototypal Inheritance

Introduction

The classical inheritance phenomenon involves making a new class that actually extends or reuses the attributes, functions, or methods of another class that are used by different programming languages (like C, C++, Java, and so on). JavaScript uses Prototype Inheritance rather than classical inheritance.

Prototype Inheritance happens when one object uses the prototype linkage to access another object's attributes or methods. All JavaScript objects derive properties and methods from their prototypes. Prototypes are hidden objects that inherit properties and methods from their parent classes.

Syntax

The prototype inheritance syntax contains the __proto__ property:

child.__proto__ = parent;

Example of Prototypal Inheritance

Assume you have a basic car (a "prototype") with parts like wheels and an engine. A sports car can inherit these features without starting from scratch, and still extend functionality. 


// Basic car object (prototype)
let car = {
  wheels: 4,
  drive: function() {
    console.log("The car is driving");
  }
}; 

// SportsCar object
let sportsCar = {
  speed: 200,
}; 

// SportsCar inherits from car
sportsCar.__proto__ = car;

sportsCar.drive();        // inherited method
console.log(sportsCar.wheels); // inherited property
console.log(sportsCar.speed);  // new property

Properties of Prototypal Inheritance

  • Properties are characteristics that identify an object.
  • Prototype's properties are shared by all instances that inherit from it.
  • JavaScript searches for a property first in the object, then in its prototype chain.
  • Properties can be values, arrays, objects, or any other JavaScript data type.

Methods of Prototypal Inheritance

Methods are functions bound to an object. With prototypal inheritance, methods can be shared across objects.

1. Object.create


// Prototype object
const animalPrototype = {
  describe: function() {
    console.log(`This is a ${this.species}, and it is ${this.age} years old.`);
  }
};

const tiger = Object.create(animalPrototype);
tiger.species = 'Tiger';
tiger.age = 5;
tiger.describe();

2. Object.prototype.constructor


// Constructor function
function Animal(species, age) {
  this.species = species;
  this.age = age;
}

const animal = new Animal('Tiger', 5);
console.log(animal.constructor);

3. hasOwnProperty


const animal = {
  species: 'Lion',
  habitat: 'Grasslands'
};

console.log(animal.hasOwnProperty('species')); 
console.log(animal.hasOwnProperty('habitat')); 
console.log(animal.hasOwnProperty('diet'));

The Prototype Chain


let pupil = { id: 1 };
let fee = { id: 2 };
let institution = { id: 3 };

pupil.__proto__ = institution; 
pupil.__proto__.__proto__ = fee; 

console.log(pupil.id); 
console.log(pupil.__proto__.id);

Inheriting Methods


let userBase = {
  canRead: true,
  profession: "",
  showReadPermission: function () {
    console.log(this.canRead);
  },
  set info(value) {
    this.profession = value;
  },
  get info() {
    return `${this.profession}`;
  },
};

let writer = { canWrite: true };
writer.__proto__ = userBase;

writer.showReadPermission(); 
writer.info = "blogger"; 
console.log(writer.info);

Drawbacks of Prototypal Inheritance

  • Limits flexibility because a single __proto__ can only inherit from one object.
  • Multiple inheritances require chaining with __proto__.__proto__, making hierarchy complex.
  • Prototype relationships can only be created using objects.
  • Accessing properties with the same name across prototypes is difficult.
  • Same prototypes cannot be inherited as it creates loops.

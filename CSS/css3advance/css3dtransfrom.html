CSS - 3D Transforms

CSS transforms are used to animate elements in three-dimensional space by using properties like translate, scale, and rotate. These functions let you rotate, scale, and move elements along the X, Y, and Z axes, adding depth and perspective to your designs.

Types of Transforms

  • 2D Transform
  • 3D Transform

CSS 3D Translate()

The translate3d() function moves an element in 3D space by specifying offsets along the X, Y, and Z axes, where the Z-axis controls depth (distance towards or away from the viewer). The perspective property is used to give a sense of depth for a 3D effect.

Example

<div class="container">
  <div class="box">
    3D Box
  </div>
</div>

CSS 3D Rotate()

The rotate3d() function allows you to rotate an element around a specified axis in 3D space by defining the X, Y, and Z components of the rotation vector and the angle of rotation.

Example

<div class="container">
  <div class="box">
    3D Box
  </div>
</div>

CSS 3D Scale()

The scale3d() function scales an element in 3D space by specifying scaling factors along the X, Y, and Z axes, allowing for uniform or non-uniform scaling.

Example

<div class="container">
  <div class="box">
    3D Box
  </div>
</div>

CSS 3D Transform Related Properties

The following are properties used to transform elements in three-dimensional space:

  • backface-visibility – Sets the visibility of the back face of an element.
  • perspective – Determines the distance between the z=0 plane and the user.
  • perspective-origin – Determines the position at which the user is looking at the 3D-positioned element.
  • rotate3d() – Rotates an element in 3D space.
  • scale3d() – Scales an element in 3D space.
  • transform – Transforms an element in 3D space.
  • translate – Translates an element in 3D space.
  • rotateZ() – Rotates an element around the Z-axis.
  • scaleZ() – Scales an element up or down along the Z-axis.
  • translateZ() – Translates an element up or down along the Z-axis.

Java 15 - Major New Features Summary (Non-LTS Release)

Overview of Java 15

**Java 15**, released in **September 2020**, is a **non-LTS (Long-Term Support)** release that focused on advancing several key language preview features and moving the next-generation garbage collectors to a stable state. It solidified Java's commitment to expressive language features and high-performance, low-latency VM options.

Language and Type System Innovations

1. Text Blocks (Standard) (JEP 378) ✨

The feature that simplifies multi-line string literals, introduced in preview in Java 13 and 14, is now a **standard and permanent feature** of the Java language. Text blocks use triple-quotes (""") to handle string data like JSON or HTML easily, without boilerplate concatenation or explicit escape sequences.

2. Sealed Classes (First Preview) (JEP 360) 🆕

This is a major feature that allows a class or interface to **control which other classes or interfaces may extend or implement it**. This provides fine-grained control over inheritance, enabling better security and providing a foundation for future, more powerful pattern matching features. A sealed class is declared using the **sealed** keyword and lists permitted subclasses using the **permits** keyword.

3. Records (Second Preview) (JEP 384)

The new type introduced in Java 14 for creating concise, immutable data classes saw its second preview. Records automatically synthesize the canonical constructor, accessor methods, equals(), hashCode(), and toString() from the components defined in its header.

4. Pattern Matching for instanceof (Second Preview) (JEP 375)

The enhancement to the instanceof operator continued its preview phase, allowing the compiler to automatically cast the object to a new, local pattern variable if the check succeeds. This further reduces boilerplate casting code.

JVM and Core API Updates

Next-Generation Garbage Collectors Standardized

Two highly performant, low-latency garbage collectors are now officially part of the Java SE standard, having shed their experimental/incubator status:

  • **ZGC (Z Garbage Collector) (JEP 377):** Now a production feature, ZGC is designed for systems with massive heaps, offering ultra-low pause times (typically less than 10ms).
  • **Shenandoah GC (JEP 379):** Also moved to production, focusing on consistent, short pause times independent of heap size.

New Low-Level APIs

  • **Hidden Classes (JEP 371):** Provides a standard API for creating non-discoverable classes at runtime that are intended to be used by frameworks (like lambda expressions or code generation tools) but not visible to other runtime components.
  • **Foreign-Memory Access API (Second Incubator) (JEP 383):** Continues development of the API allowing Java programs to safely and efficiently access memory outside of the Java heap (native memory).

Core System APIs Reimplemented and Security

  • **Legacy DatagramSocket API Reimplementation (JEP 373):** The implementation of the older **java.net.DatagramSocket** and **java.net.MulticastSocket** was replaced with a cleaner, more maintainable, and modern underlying architecture.
  • **Edwards-Curve Digital Signature Algorithm (EdDSA) (JEP 339):** Implemented the EdDSA for cryptographic signatures, a modern and highly secure digital signature scheme.

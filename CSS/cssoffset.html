CSS - offset Property

The CSS offset property is a shorthand property that simplifies the process of animating an element along a path. It combines multiple properties such as offset-anchor, offset-path, offset-distance, offset-rotate, and offset-position.

With this property, a specified point inside an element (defined by offset-anchor) is aligned to a path position (defined by offset-position) at different stages of the animation. The element can also be rotated (offset-rotate) to follow the direction of the path.

Constituent Properties

  • offset-anchor – Defines the reference point within the element aligned to the path.
  • offset-path – Defines the motion path along which the element moves.
  • offset-distance – Determines how far along the path the element is placed.
  • offset-rotate – Rotates the element to align with the direction of the path.
  • offset-position – Defines the starting position along the path.

Syntax

offset = [ <'offset-position'>? [ <'offset-path'> [ <'offset-distance'> || <'offset-rotate'> ]? ]? ]! [ / <'offset-anchor'> ]?

Possible Values

  • offset-anchor – Point inside the element that aligns to the path.
  • offset-path – Defines the trajectory of motion.
  • offset-distance – Distance traveled along the path.
  • offset-rotate – Controls element rotation along the path.
  • auto – Resets all properties to their defaults.

Example 1: CSS offset with Path Value

The following example demonstrates the offset shorthand property where text slides smoothly along a curved path. 

@keyframes slide {
  0% { offset-distance: 0%; }
  100% { offset-distance: 100%; }
}

.text {
  animation: slide 6s ease-in-out infinite alternate;
  offset: path('M 10 100 Q 50 50 90 100 T 170 100 T 250 100');
}

In this example, the text element animates along a quadratic curve path.

Example 2: CSS offset with Path and Auto Value

This example demonstrates a planet orbiting around the sun using offset shorthand with auto. 

@keyframes orbit {
  0% { offset-distance: 0%; offset-rotate: 0deg; }
  100% { offset-distance: 100%; offset-rotate: 360deg; }
}

#planet {
  animation: orbit 6s linear infinite;
  offset: path('M 200 200 m -100, 0 a 100,100 0 1,0 200,0 a 100,100 0 1,0 -200,0') auto;
}

Here, the planet moves in a circular orbit around the sun while also rotating.

Related Properties

  • offset-anchor – Position inside the element’s box aligned with the path.
  • offset-distance – Controls how far along the path the element is placed.
  • offset-path – Defines the trajectory inside the parent container.
  • offset-rotate – Specifies element orientation while moving.
  • offset-position – Defines the starting position along the route.

Final Example

The offset shorthand property is a powerful tool for CSS motion animations, making it easier to define and control element paths, distances, and rotations. It is commonly used in creative animations like sliders, loaders, and orbiting effects.

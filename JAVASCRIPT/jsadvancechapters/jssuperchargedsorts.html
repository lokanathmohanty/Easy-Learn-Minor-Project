JavaScript - Supercharged Sorts

Introduction

The Array.sort() method in JavaScript is a powerful tool for ordering data. While simple numeric or alphabetical sorts are straightforward, sorting arrays of objects based on multiple properties can be more complex. In this session, we will explore advanced techniques to create multi-criteria, reusable, and efficient sorting logic.

Basics of Sorting

The sort() method accepts an optional comparator function that takes two parameters (a and b) and returns:

  • A negative value → a comes before b.
  • A positive value → b comes before a.
  • Zero → Order remains unchanged.

Example: Sorting Numbers


const numbers = [12, 7, 19, 3, 8, 5, 10, 15];

// Sorting in descending order
numbers.sort((a, b) => b - a);

console.log(numbers);

Output:


[ 19, 15, 12, 10, 8, 7, 5, 3 ]

Chaining Multiple Sort Criteria

When sorting objects by multiple properties, we can chain comparisons using the || operator. This allows fallback sorting when earlier criteria are equal.

Example: Products Sorting


const products = [
   { name: 'Smartphone', price: 699.99, rating: 4.7 },
   { name: 'Headphones', price: 129.99, rating: 4.3 },
   { name: 'Tablet', price: 399.99, rating: 4.1 },
   { name: 'Smartwatch', price: 199.99, rating: 4.5 },
];

// Sort by price (asc), then rating (desc), then name (asc)
products.sort((a, b) => 
   a.price - b.price ||
   b.rating - a.rating ||
   a.name.localeCompare(b.name)
);

console.log(products);

Reusable Comparator Functions

To improve readability, we can extract reusable comparator functions for each property. 


const byPrice = (a, b) => a.price - b.price;
const byRating = (a, b) => b.rating - a.rating;
const byName = (a, b) => a.name.localeCompare(b.name);

products.sort((a, b) =>
  byPrice(a, b) || byRating(a, b) || byName(a, b)
);

Higher-Order sortBy Function

We can go further by writing a higher-order function sortBy that dynamically generates comparator functions based on property names.

Example: Higher-Order sortBy


const sortBy = (prop) => (a, b) =>
  a[prop] < b[prop] ? -1 :
  a[prop] > b[prop] ? 1 : 
  0;

products.sort(
  (a, b) => sortBy('price')(a, b) ||
    sortBy('rating')(b, a) || 
    sortBy('name')(a, b)
);

console.log(products);

Summary

  • Use Array.sort() with custom comparator functions.
  • Chain multiple criteria using || for fallback sorting.
  • Extract comparators into reusable functions for clarity.
  • Build higher-order sortBy functions for flexibility.

By applying these techniques, you can implement clean, scalable, and powerful sorting logic for complex datasets in JavaScript.

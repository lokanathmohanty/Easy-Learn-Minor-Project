C++ Constructor with Default Arguments 🎁

A **constructor with default arguments** is a single constructor definition that allows for the creation of objects using a varying number of parameters. This is achieved by providing **default values** for one or more parameters in the constructor's declaration.

If a user omits an argument during object creation, the compiler automatically substitutes the predefined default value for that parameter. This technique often reduces the need for extensive **constructor overloading**.

Syntax and Mechanism

Default values are specified in the parameter list of the constructor declaration (or the definition, if declared in the class header). The constructor will be called with the arguments provided, filling in any missing arguments with their defaults.

class Box {
   public:
      // Constructor with multiple default arguments
      Box(int l = 5, int w = 10, int h = 2) { 
         length = l; // l defaults to 5 if not provided
         width = w;  // w defaults to 10 if not provided
         height = h; // h defaults to 2 if not provided
      }
      // ...
};

The flexibility of this approach is shown by the following object creations, all calling the *same* constructor:

  • Box box1; $\rightarrow$ Uses all defaults: (5, 10, 2).
  • Box box2(15); $\rightarrow$ Provides the first argument (l=15) and uses defaults for the rest: (15, 10, 2).
  • Box box3(15, 20); $\rightarrow$ Provides the first two arguments: (15, 20, 2).
  • Box box4(15, 20, 25); $\rightarrow$ Provides all arguments: (15, 20, 25).

Key Rules for Default Arguments

  1. **Placement Restriction:** Once you start assigning default arguments, all subsequent parameters to the right **must also** have default arguments. 
    Box(int l = 1, int w);  // ❌ INVALID: w has no default after l has one.
Box(int l, int w = 10, int h = 2); // ✅ VALID
  2. **Overloading Conflict:** Using default arguments can sometimes lead to **ambiguity** if combined improperly with overloaded constructors (e.g., creating a separate parameterless default constructor `Box()` and a parameterized constructor `Box(int l = 5)` would cause a conflict).
  3. **Declaration vs. Definition:** Default arguments should be specified **only once**, usually in the function's declaration (inside the class definition).

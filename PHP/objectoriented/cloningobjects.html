PHP: Cloning Objects

In PHP, simply assigning one object variable to another (e.g., $obj1 = $obj2;) creates a **reference copy**, where both variables point to the exact same object in memory. To create a true, independent duplicate of an object, you must use the **clone** keyword.

Shallow Copy vs. Deep Copy

The method used for duplication determines whether the new object shares internal data with the original:

  • Shallow Copy (clone keyword): Creates a new object and copies all of the original object's property values. If a property contains a primitive value (like a string or integer), the value is copied. If a property contains another **object**, only the **reference** (pointer) to that nested object is copied. Thus, the new object shares the nested object with the original.
  • Deep Copy (clone + __clone() magic method): Creates a completely independent copy. It duplicates the main object *and* recursively duplicates any nested objects referenced within the original.

The Magic Method __clone()

When the clone keyword is used, PHP first performs a shallow copy. If a **__clone()** magic method is defined in the class, it is immediately called on the newly created object. This method is where you place logic to turn the shallow copy into a deep copy by explicitly cloning any nested object properties:

public function __clone() {
   $this->nestedObject = clone $this->nestedObject;
}

This ensures the copied object holds a reference to a brand new nested object, rather than sharing the original's.

Example Session

Cloning Behavior with Nested Objects

Consider a class Basket containing a property $item, which is an object. Without __clone(), changes to $obj1->item affect $obj2->item.


class Item { 
   public $name = 'Apple'; 
}

class Basket {
   public $item;
   public $count;
}

$obj1 = new Basket();
$obj1->item = new Item();
$obj1->count = 1;

// 1. Shallow Copy (using clone)
$obj2 = clone $obj1;

// Change simple property: only affects $obj1 (Shallow Copy works here)
$obj1->count = 5; 

// Change nested object: affects BOTH $obj1 and $obj2! (Shared reference)
$obj1->item->name = 'Orange'; 

// $obj1->count is 5, $obj2->count is 1 (independent)
// $obj1->item->name is 'Orange', $obj2->item->name is 'Orange' (shared object)

Creating a Deep Copy (Fixing the Shared Object)

By adding the __clone() method to Basket, we ensure the nested object is also duplicated.


class Basket {
   // ... properties ...
   public function __clone() {
      // Deep copy: explicitly clone the nested object
      $this->item = clone $this->item; 
   }
}
// After this, the nested Item object is no longer shared.
// $obj2->item->name remains 'Apple' after $obj1 changes it to 'Orange'.

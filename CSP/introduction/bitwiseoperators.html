C# Bitwise Operators

What Are Bitwise Operators?

C# Bitwise Operators manipulate the **individual bits** (0s and 1s) of integer numbers. They are primarily used for low-level programming tasks, performance optimization (as they are generally faster than their mathematical counterparts), and handling **flags** (sets of boolean options).

List and Functionality

These operators perform logical or shifting operations on the binary representation of the operands:

  • Binary AND (&): Sets a bit to 1 if the bit is 1 in **both** operands.
  • Binary OR (|): Sets a bit to 1 if the bit is 1 in **either** operand.
  • Binary XOR (^): Sets a bit to 1 if the bits are **different** (one is 1 and the other is 0).
  • Ones Complement (~): Inverts every bit (flips 1s to 0s and 0s to 1s).
  • Left Shift (<<): Shifts bits to the left, effectively **multiplying by $2^n$**.
  • Right Shift (>>): Shifts bits to the right, effectively **dividing by $2^n$**.

Examples and Real-World Use Cases

Left Shift (<<) and Right Shift (>>)

These are efficient ways to multiply or divide by powers of two:

int a = 5; // Binary: 00000101
int leftShift = a << 2;  // 00010100 (20). Equivalent to 5 * $2^2$
int rightShift = a >> 1; // 00000010 (2). Equivalent to 5 / $2^1$ (integer division)

Swapping Numbers with XOR (^)

XOR can swap two variables without using a temporary variable, saving memory.

int a = 5, b = 10;
a = a ^ b; // a now holds 15 (0101 ^ 1010 = 1111)
b = a ^ b; // b now holds 5 (1111 ^ 1010 = 0101)
a = a ^ b; // a now holds 10 (1111 ^ 0101 = 1010)

// Result: a = 10, b = 5

Checking Even/Odd with AND (&)

A number is even if its least significant bit (LSB) is 0. Checking if (number & 1) is 0 efficiently determines if the number is even.

Best Practices and Twos Complement

  • Twos Complement: The **tilde (~)** operator and operations on negative numbers rely on the **twos complement** format used by C# to represent signed integers. Applying ~ to a positive number will result in a negative number (e.g., ~5 is -6).
  • Flag Operations: Use & for checking if a flag is set (masking) and | for setting multiple flags at once.
  • **Avoid Negative Shifts:** The C# language specifies that the shift count must be non-negative.

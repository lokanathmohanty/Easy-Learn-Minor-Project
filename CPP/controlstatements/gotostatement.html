C++ goto Statement (Unconditional Jump) ⚠️

The **goto statement** provides an **unconditional jump** in program execution from the `goto` point to a designated **labeled statement** within the same function. While it is part of C++, its use is generally **highly discouraged** in modern programming because it creates "spaghetti code," making the control flow difficult to trace, which significantly hurts readability and maintainability.

Syntax and Operation

Syntax:

goto label;
// ... intervening code ...
label: statement; // Labeled statement

The label is a user-defined identifier followed by a colon (:). When the program encounters goto label;, control is immediately transferred to the statement following label:, skipping all code in between.

Example: Loop Control

In the provided code, `goto LOOP` is used as a less conventional replacement for a `continue` or `break` when `a == 15`. Instead of continuing to the next iteration (like `continue`), it jumps back to the **beginning** of the loop block (`LOOP:do`):

LOOP:do {
   if( a == 15) { // When a becomes 15
      a = a + 1;  // a becomes 16
      goto LOOP;  // Jumps back to 'LOOP:do', skipping the print statement for a=15.
   }
   // ... rest of loop
} while( a < 20 );

When is goto Considered?

Despite strong arguments against its use, goto can be the most straightforward solution in limited, specific scenarios, primarily to simplify exiting multi-level structures:

  • **Breaking Out of Deeply Nested Loops:** If you need to immediately exit two or more nested loops (where a simple `break` only exits the innermost one), `goto` provides a clean jump to a termination point.
  • **Legacy Code or Error Handling:** In older codebases or complex resource cleanup/error handling where using structured exceptions or flags would be significantly more verbose.

Example: Exiting Nested Loops

The code fragment below clearly demonstrates the advantage: a single `goto` replaces complex flag checks to exit both the `for` loops instantly.

for (int i = 0; i < 3; ++i) {
  for (int j = 0; j < 3; ++j) {
    if (i == 1 && j == 1) {
      goto exitLoops; // Jumps directly out of BOTH loops.
    }
    cout << "i: " << i << ", j: " << j << endl;
  }
}

exitLoops:
  cout << "Exited the nested loops!" << endl;
// Output confirms the jump happened after i: 1, j: 0

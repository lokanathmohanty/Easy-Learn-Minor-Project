PHP: File Inclusion

**File Inclusion** is a PHP feature that allows developers to reuse blocks of code, such as headers, footers, navigation menus, or configuration files, across multiple pages. This promotes code organization, reduces redundancy, and simplifies site-wide maintenance.

File Inclusion Functions

PHP offers four functions to include the content of one file into another before execution. They differ primarily in how they handle file loading errors:

1. include()

  • **Behavior:** Copies the content of the specified file into the current script.
  • **Error Handling:** If the file is not found, it generates a **Warning (E_WARNING)**, and the **script execution continues**.
  • **Use Case:** Recommended for non-critical files like headers, footers, or optional sidebars.

2. require()

  • **Behavior:** Copies the content of the specified file into the current script.
  • **Error Handling:** If the file is not found, it generates a **Fatal Error (E_COMPILE_ERROR)**, and the **script execution halts immediately**.
  • **Use Case:** Recommended for critical files like database connection settings or core configuration files.

3. include_once() and require_once()

These variants ensure that the specified file is included **only once**, even if the function is called multiple times. This prevents issues like function re-declarations or re-initialization of variables, commonly used for classes or configuration files.

Security Risk: Local File Inclusion (LFI)

File inclusion is susceptible to a vulnerability known as **Local File Inclusion (LFI)** if the included file path is determined by unsanitized user input (e.g., a GET parameter).

Vulnerable Code Example


// WARNING: Do not use this code in production
$page = $_GET['page']; 
include($page);

An attacker could set the URL parameter to ?page=../../../../etc/passwd, causing the PHP script to display sensitive server files instead of the intended page.

Preventing LFI

Always sanitize user input or use a whitelist approach to restrict file inclusion to known, safe files:


$allowed_pages = ['home.php', 'about.php', 'contact.php'];
$page = basename($_GET['page']); // Sanitize input
if (in_array($page, $allowed_pages)) {
   include($page); 
} else {
   echo "Page not found.";
}

ReactJS - Form Component (React Bootstrap)

React provides form components through third-party UI libraries. One of the most popular options is React Bootstrap (react-bootstrap.github.io), which ports almost all Bootstrap UI components to React, including forms.

Forms are used to collect user input, validate it, and send it to the server. React Bootstrap provides multiple components to make working with forms easier and more customizable.

Form Component

The Form component is the base wrapper for form elements.

  • ref − Access underlying DOM node.
  • as − Specify a custom element instead of <form>.
  • validated − Enable validation styles when set to true.

Example:

<Form>
   <!-- Use form control -->
</Form>

Form.Control

The Form.Control component is used to render input elements of various types.

  • type − Defines input type (text, email, password, etc.).
  • size − Controls size (sm, lg).
  • disabled, readOnly, plaintext − Modify behavior.
  • isValid / isInvalid − Show validation states.

Example:

<>
   <Form.Control type="text" size="lg" placeholder="Large text" />
   <br />
   <Form.Control type="text" placeholder="Normal text" />
   <br />
   <Form.Control type="text" size="sm" placeholder="Small text" />
</>

Form.Label & Form.Group

Form.Label is used to render labels, while Form.Group groups labels and controls together.

Example:

<Form.Group controlId="formFile" className="mb-3">
   <Form.Label>Upload file</Form.Label>
   <Form.Control type="file" />
</Form.Group>

Form.Text

Use Form.Text to display helper text below inputs.

Example:

<Form.Label htmlFor="pwd">Password</Form.Label>
<Form.Control type="password" id="pwd" aria-describedby="passwordHelp" />
<Form.Text id="passwordHelp" muted>
   Password must be 8–12 characters, include 1 digit, 1 special character, and 1 capital letter.
</Form.Text>

Form.Select

Used to render <select> dropdowns.

Example:

<Form.Select aria-label="Select category">
   <option value="sm">Small</option>
   <option value="lg">Large</option>
   <option value="xl">Extra large</option>
</Form.Select>

Form.Check

Form.Check is used for checkboxes, radios, and switches.

Example (radio buttons):

<Form.Group controlId="gender" className="mb-3">
   <Form.Label>Select your gender</Form.Label>
   <Form.Check type="radio" id="male" label="Male" name="gender" />
   <Form.Check type="radio" id="female" label="Female" name="gender" />
</Form.Group>

Example (checkboxes with labels):

<Form.Group controlId="language" className="mb-3">
   <Form.Label>Favorite Languages</Form.Label>
   <Form.Check type="checkbox" id="java">
      <Form.Check.Input type="checkbox" isValid />
      <Form.Check.Label>Java</Form.Check.Label>
   </Form.Check>
   <Form.Check type="checkbox" id="js">
      <Form.Check.Input type="checkbox" isValid />
      <Form.Check.Label>JavaScript</Form.Check.Label>
   </Form.Check>
</Form.Group>

Form.Range

Form.Range renders a slider input.

Example:

<Form.Label>Select by range</Form.Label>
<Form.Range value="25" />

InputGroup

Use InputGroup to combine inputs and text.

Example:

<Form.Group controlId="email" className="mb-3">
   <Form.Label>Enter your email</Form.Label>
   <InputGroup className="mb-3">
      <Form.Control aria-label="Email address" aria-describedby="domain" />
      <InputGroup.Text id="domain">@tutorialspoint.com</InputGroup.Text>
   </InputGroup>
</Form.Group>

Applying Form Component

Steps to use React Bootstrap form:

create-react-app myapp
cd myapp
npm start
npm install --save bootstrap react-bootstrap

Create SimpleForm.js:

import { Form, Button } from 'react-bootstrap';

function SimpleForm() {
   return (
      <Form>
         <Form.Group className="mb-3" controlId="email">
            <Form.Label>Email address</Form.Label>
            <Form.Control type="email" placeholder="Enter email" />
            <Form.Text className="text-muted">
               This email address will be used for communication purpose.
            </Form.Text>
         </Form.Group>

         <Form.Group className="mb-3" controlId="password">
            <Form.Label>Password</Form.Label>
            <Form.Control type="password" placeholder="Password" />
         </Form.Group>

         <Form.Group className="mb-3" controlId="formBasicCheckbox">
            <Form.Check type="checkbox" label="Save password" />
         </Form.Group>

         <Button variant="primary" type="submit">
            Submit
         </Button>
      </Form>
   );
}
export default SimpleForm;

Update App.js:

import './App.css'
import "bootstrap/dist/css/bootstrap.min.css";
import SimpleForm from './Components/SimpleForm'

function App() {
   return (
      <div className="container">
         <SimpleForm />
      </div>
   );
}
export default App;

Summary

The React Bootstrap form component provides a wide range of form elements with easy-to-use props and Bootstrap styling. It allows developers to quickly build responsive, validated, and accessible forms.

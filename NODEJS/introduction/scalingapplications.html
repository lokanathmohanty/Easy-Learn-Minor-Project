Node.js - Scaling Application

Overview

Scalability in Node.js refers to handling increasing workloads by processing more requests concurrently. Node.js achieves this by using child processes — separate Node.js runtime instances spawned and managed by the main process.

Child processes run in parallel, improving application performance. They each have three streams: stdin, stdout, and stderr. These streams can be shared with the parent process.

child_process Module

This core module provides methods to create, manage, and communicate with child processes. The three major methods to create child processes are: exec, spawn, and fork.

exec() Method

Runs a command in a shell and buffers the output until the command completes. 

child_process.exec(command[, options], callback)

Example:

// child.js
console.log("Starting Child Process-" + process.argv[2]);
console.log("Child Process-" + process.argv[2] + " executed.");

// main.js
const child_process = require('child_process');
for (var i=0; i<3; i++) {
  var child = child_process.exec('node child.js ' + i, (error, stdout, stderr) => {
    if (error) {
      console.log(error.stack);
      return;
    }
    console.log('stdout: ' + stdout);
  });
  child.on('exit', (code) => {
    console.log('Child process exited with exit code ' + code);
  });
}

spawn() Method

Launches a new process and streams output immediately. Ideal for processes with large data outputs. 

child_process.spawn(command[, args][, options])

Example similar to exec but listens to stdout data events:

// main.js
const child_process = require('child_process');
for (let i=0; i<3; i++) {
  const child = child_process.spawn('node', ['child.js', i]);
  child.stdout.on('data', data => console.log('stdout: ' + data));
  child.on('exit', code => console.log('Child process exited with exit code ' + code));
}

fork() Method

Special case of spawn to create Node.js processes, enabling IPC between parent and child. 

child_process.fork(modulePath[, args][, options])

Example:

// main.js
const child_process = require('child_process');
for (let i=0; i<3; i++) {
  const child = child_process.fork('child.js', [i]);
  child.on('close', code => console.log('child process exited with code ' + code));
}

execFile() Method

Similar to exec(), but does not spawn a shell by default. More efficient for directly running executable files. 

child_process.execFile(command[, args][, options][, callback])

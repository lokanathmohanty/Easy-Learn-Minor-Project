Power Query Editor - Merge Queries (Part 2)

Inner Join and Left Outer Join

The inner join merges two tables, returning only the rows with matching values in the common column of both tables. The left outer join retrieves all records from the first table along with matching records from the second table.

Implementation of Inner Join in Power BI

  1. Load two tables, e.g., employee.xls and emp_dept.xls, into Power BI.
  2. Open Power BI Desktop, navigate to Home, and select Get Data to load Excel workbooks.
  3. Select the Excel file, choose the worksheet, and click Load.
  4. Repeat for the second table.
  5. Click Home > Transform Data to open Power Query Editor.
  6. Choose Combine > Merge Queries > Merge Queries.
  7. Select the tables and the common column (e.g., Employee ID).
  8. Choose Join Kind: "Inner (only matching rows)" and click OK.
  9. Update columns as needed to display department info.

Left Outer Join in Power Query Editor

  1. Follow the same steps but select "Left Outer (all from first, matching from second)" as Join Kind.
  2. Click OK to see all first table records with matching second table data.
  3. To see only unmatched rows, choose the "Left Anti" join.

What is Full Outer Join?

The full outer join retrieves all records from both tables, filling in nulls where there are no matches.

Example Steps for Full Outer Join

  1. Load tables into Power BI.
  2. Open Power Query Editor, select Merge Queries.
  3. Choose the join kind: "Full Outer (all rows from both tables)".
  4. Select common columns and click OK.
  5. Expand the merged columns to see data from both tables, with nulls where no match exists.

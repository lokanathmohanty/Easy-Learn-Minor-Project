C# Generics: Type-Safe Reusable Code 🛠️

What are Generics?

**Generics** allow you to design classes, methods, interfaces, delegates, and events that defer the specification of one or more data types until the client code actually instantiates or calls the element. In essence, generics enable you to write a single piece of code that can operate on various data types while maintaining **type safety**.

Generics address the shortcomings of the older, non-generic collections (like `ArrayList`), which operated on the base **`Object`** type, leading to performance costs (boxing/unboxing) and potential runtime type errors.

Features and Benefits

Generics provide significant advantages in C# programming:

  • **Type Safety:** The compiler enforces the data type at the time of creation, eliminating the need for runtime type checking and casting.
  • **Performance:** By avoiding the need to box value types (like `int`, `char`) to `Object` and unbox them later, generics offer superior performance, especially for collection classes.
  • **Code Reuse:** A single generic implementation (e.g., a **`List<T>`**) can be reused for any data type (e.g., `List<int>`, `List<string>`).

Implementation: Generic Types

Generic types are specified using angle brackets (`< >`) containing a **type parameter** (conventionally, a single uppercase letter like `T`).

1. Generic Classes

A generic class defines its structure using one or more type parameters, which are substituted by actual types upon instantiation.

// Class defined with type parameter T
public class MyGenericArray<T> {
   private T[] array; // The array holds type T
   
   public void setItem(int index, T value) { /* ... */ }
}

// Instantiation with specific types
MyGenericArray<int> intArray = new MyGenericArray<int>(5);
MyGenericArray<char> charArray = new MyGenericArray<char>(5);

2. Generic Methods

A method can be generic even if the class containing it is not. The type parameter is declared immediately after the method name.

// Method signature using type parameter T
static void Swap<T>(ref T lhs, ref T rhs) {
   T temp = lhs; // T is substituted with the type used in the call
   // ...
}

3. Generic Delegates and Interfaces

Delegates and interfaces can also be defined with type parameters, ensuring that any method referenced by the delegate or any class implementing the interface adheres to the type specifications.

// Generic Delegate
delegate T NumberChanger<T>(T n);

// Generic Interface
public interface IRepository<T> {
    void Add(T item);
    IEnumerable<T> GetAll();
}

CSS - Specificity

When multiple CSS rules are declared for the same element, CSS uses a specificity order to determine which rule has the highest priority.

Specificity Hierarchy

Each CSS selector has a specificity level. The hierarchy is as follows:

  • Inline Styles: Highest priority. Example: <h1 style="color: blue;">
  • ID Selectors: Next highest. Example: #mainDiv { color: blue; }
  • Classes, Attributes, Pseudo-classes: Example: .subDivs { color: blue; }
  • Elements, Pseudo-elements: Lowest priority. Example: div { color: blue; }

How to Calculate Specificity?

The specificity values are:

  • Inline styles = 1000
  • ID selectors = 100
  • Class, attribute, pseudo-class = 10
  • Element, pseudo-element = 1
  • Universal selector = 0

Examples of Specificity Values

  • <div style="color: green"> → 1000
  • #uniqueId → 100
  • .mainClass → 10
  • div → 1
  • div #uniqueId → 101
  • div .mainClass → 11
  • div .mainClass .navbar → 21
  • div #uniqueId .navbar → 111

Specificity Rules Examples

Selector with highest specificity value takes effect

In the following example, the id selector and inline style override others.

Example Heading: Id and Inline Style Priority

<p id="unique" class="special">
   This paragraph will be darkgreen. Id selector wins!!!!
</p>

<p class="special">
   This paragraph will be blue. Class selector wins!!!!
</p>

<p class="special" style="color: darkblue;">
   This paragraph will be darkblue. Inline style wins!!!!
</p>

Equal specificity value, latest rule wins

If two rules have the same specificity, the one written later is applied.

Example Heading: Latest Rule Priority

<p class="special superSpecial">
   This paragraph is gold color. Class superSpecial wins!!!
</p>

Internal CSS preferred over external stylesheet

Selectors in <style> inside HTML have higher priority than external CSS.

Example Heading: Internal over External

/* From external file */
#uniqueID { color: red; }

/* In HTML file */
<style>
   #uniqueID { color: yellow; }
</style>

Yellow will be applied.

Override Specificity with !important

The !important keyword overrides all specificity rules.

Example Heading: !important Overrides

<p id="unique" class="special">
   This paragraph is darkred. !important wins!!!
</p>

<p class="special" style="color: green">
   This paragraph is darkred. !important even beats inline style!!!
</p>

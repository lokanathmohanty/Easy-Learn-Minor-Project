Python - URL Processing

URLs (Uniform Resource Locators) identify resources on the Internet. Python's urllib package provides tools to parse URLs, fetch web content, and handle URL-related errors.

Modules in urllib

  • urllib.parse: For parsing URLs into components.
  • urllib.request: For opening and reading URLs.
  • urllib.error: For handling errors during URL operations.
  • urllib.robotparser: For parsing robots.txt files.

Parsing URLs with urllib.parse

The urlparse() function splits a URL into parts: scheme, netloc, path, params, query, and fragment.

from urllib.parse import urlparse

url = "https://example.com/employees/name/?salary>=25000"
parsed = urlparse(url)
print("Scheme:", parsed.scheme)
print("Netloc:", parsed.netloc)
print("Path:", parsed.path)
print("Params:", parsed.params)
print("Query:", parsed.query)
print("Fragment:", parsed.fragment)

Output:

Scheme: https
Netloc: example.com
Path: /employees/name/
Params:
Query: salary>=25000
Fragment:

Extracting Query Parameters

Use parse_qs() to convert query strings into dictionaries.

from urllib.parse import urlparse, parse_qs

url = "https://example.com/employees?name=Anand&salary=25000"
parsed = urlparse(url)
query_params = parse_qs(parsed.query)
print(query_params)

Output:

{'name': ['Anand'], 'salary': ['25000']}

Constructing URLs

urlunparse() and urlunsplit() create URLs from parts.

from urllib.parse import urlunparse

parts = ('https', 'example.com', '/employees/name/', '', 'salary>=25000', '')
url = urlunparse(parts)
print(url)

Output:

https://example.com/employees/name/?salary>=25000

Opening URLs with urllib.request

urlopen() opens URLs and returns a response object.

from urllib.request import urlopen

response = urlopen('https://www.example.com')
data = response.read()
print(data[:100])  # print first 100 bytes

Using Request Objects

Request objects allow fine control over URL requests including headers and methods.

from urllib.request import Request, urlopen

req = Request('https://www.example.com', headers={'User-Agent': 'Mozilla/5.0'})
response = urlopen(req)
print(response.status)

Handling URL Errors

Exceptions like URLError and HTTPError are raised for network or HTTP errors.

from urllib.request import Request, urlopen
from urllib.error import URLError, HTTPError

try:
    response = urlopen('http://no-such-url.example')
except HTTPError as e:
    print('HTTP Error:', e.code)
except URLError as e:
    print('URL Error:', e.reason)

Summary

Python's urllib package facilitates working with URLs, including parsing, fetching, and error handling, making web operations easier.

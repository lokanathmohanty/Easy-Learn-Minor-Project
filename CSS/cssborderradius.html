CSS - border-block Property

The CSS border-block property is a shorthand property that allows you to set the border in the block direction of an element. This shorthand combines three individual properties: border-block-width, border-block-style, and border-block-color. Among these, the border-block-style is mandatory, while the width and color will use their default values if not specified.

The block direction depends on the writing-mode property of the document. For example, in the default horizontal-tb writing mode, the block direction is vertical (top to bottom), while in vertical-rl or vertical-lr, the block direction becomes horizontal.

Syntax

The syntax of the border-block property looks like this: 

border-block: border-block-width border-block-style border-block-color | initial | inherit;

Property Values

  • border-block-width: Specifies the width of the border in the block direction. Default is medium.
  • border-block-style: Defines the style of the border (e.g., solid, dashed). Default is none.
  • border-block-color: Sets the color of the border in the block direction. Default is the element's text color.
  • initial: Resets the property to its default value.
  • inherit: Inherits the property value from the parent element.

Examples of CSS border-block Property

1. Setting the Width of Border

The border-block-width defines how thick the block border will appear. Below is an example showing two different widths: thick and 10px. 

<p style="border-block-style: solid; border-block-width: thick;">
  This example shows the border-block with thick width.
</p>

<p style="border-block-style: solid; border-block-width: 10px;">
  This example shows the border-block with 10px width.
</p>

2. Setting the Style of Border

The border-block-style is a required property. It specifies how the border will be drawn. Common values include solid, dashed, dotted, double, and groove. 

<p style="border-block-style: solid;">
  This border-block uses solid style.
</p>

<p style="border-block-style: dashed;">
  This border-block uses dashed style.
</p>

3. Setting the Color of Border

You can apply colors to the block border using border-block-color. By default, the text color of the element will be used, but you can override it with any valid CSS color. 

<p style="border-block-style: solid; border-block-color: red;">
  This border-block has a red color.
</p>

<p style="border-block-style: solid; border-block-color: blue;">
  This border-block has a blue color.
</p>

4. Setting all Values at Once

The shorthand border-block allows you to set width, style, and color together in a single line. 

<p style="border-block: 5px dashed green;">
  This example sets all border-block values at once.
</p>

5. Border Block with Writing Mode

The writing-mode property defines the direction of text flow, and the border-block will adjust accordingly. For example:

  • horizontal-tb: Block borders appear horizontally (top/bottom).
  • vertical-rl: Block borders appear vertically (right/left).
<div style="writing-mode: horizontal-tb; border-block: 5px dashed red;">
  Horizontal block border.
</div>

<div style="writing-mode: vertical-rl; border-block: 5px dashed green;">
  Vertical block border.
</div>

Supported Browsers

The border-block property is supported in modern browsers:

  • Chrome: 87+
  • Edge: 87+
  • Firefox: 66+
  • Safari: 14.1+
  • Opera: 73+

Key Takeaways

  • The border-block shorthand makes CSS cleaner by combining width, style, and color.
  • It respects the document’s writing-mode, making it useful for multilingual layouts.
  • It is especially useful for supporting vertical writing systems like Japanese or Chinese.
  • Always remember to set the border-block-style, since it is mandatory.

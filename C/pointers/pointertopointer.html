Pointer to Pointer (Double Pointer) in C

A pointer to pointer, also known as a double pointer in C, stores the address of another pointer.

A pointer variable stores the address of another variable. It can point to any type, including basic data types, arrays, structs, etc. A pointer can also store the address of another pointer, which is called a "pointer to pointer" or "double pointer".

This concept represents multiple levels of indirection: a pointer points to another pointer, which in turn points to the actual value.

Declaration of Pointer to a Pointer

The declaration is similar to a normal pointer but uses an additional asterisk (*):

int **var;

To access the target value pointed to by a double pointer, you need to dereference twice.

Example of Pointer to Pointer (Double Pointer)


#include <stdio.h>

int main() {
  int a = 100;
  int *ptr = &a;
  int **dptr = &ptr;

  printf("Value of 'a' is : %d\n", a);
  printf("Value of 'a' using pointer (ptr) is : %d\n", *ptr);
  printf("Value of 'a' using double pointer (dptr) is : %d\n", **dptr);

  return 0;
}

Output:

Value of 'a' is : 100
Value of 'a' using pointer (ptr) is : 100
Value of 'a' using double pointer (dptr) is : 100

How Does a Normal Pointer Work?

Assume an integer variable a is located at an address, and its pointer b stores that address:

int a = 10;
int *b = &a;

The dereference operator * fetches the value pointed by the pointer.


#include <stdio.h>

int main() {
  int a = 10;
  int *b = &a;
  printf("a: %d \nPointer to 'a' is 'b': %d \nValue at 'b': %d", a, b, *b);
  return 0;
}

Output example:

a: 10
Pointer to 'a' is 'b': 6422036
Value at 'b': 10

How Does a Double Pointer Work?

Declare a pointer c that stores the address of b, which itself points to a:

int **c = &b;

Accessing values:


printf("b: %d \nPointer to 'b' is 'c': %d \nValue at b: %d\n", b, c, *c);
printf("Value of 'a' from 'c': %d", **c);

Output example:

b: 6422036
Pointer to 'b' is 'c': 6422024
Value at b: 6422036
Value of 'a' from 'c': 10

Complete Double Pointer Program Example


#include <stdio.h>

int main() {
  int a = 10;
  int *b = &a;
  printf("a: %d \nAddress of 'a': %d \nValue at a: %d\n\n", a, b, *b);

  int **c = &b;
  printf("b: %d \nPointer to 'b' is c: %d \nValue at b: %d\n", b, c, *c);
  printf("Value of 'a' from 'c': %d", **c);

  return 0;
}

Output:

a: 10
Address of 'a': 1603495332
Value at a: 10

b: 1603495332
Pointer to 'b' is c: 1603495336
Value at b: 1603495332
Value of 'a' from 'c': 10

Double Pointer Size

A double pointer behaves like a normal pointer; hence, both have the same size.


printf("Size of b - a normal pointer: %d\n", sizeof(b));
printf("Size of c - a double pointer: %d\n", sizeof(c));

Output example:

Size of b - a normal pointer: 8
Size of c - a double pointer: 8

Note: Sizes and addresses may vary based on CPU architecture and OS.

Multilevel Pointers in C

There is no theoretical limit on the number of asterisks in pointer declarations.

For example, a pointer to a double pointer can be declared as:

int ***d = &c;

Double pointers are commonly used to represent 2D arrays or arrays of strings.

Java Programming: Object-Oriented Concepts

Session: Understanding Inheritance

What is Java Inheritance?

**Inheritance** is a core OOP concept where one class acquires the properties (methods and attributes) of another class. This makes information manageable in a hierarchical order, promoting **code reusability** and **extensibility**.

  • The inheriting class is the **subclass** (or derived/child class).
  • The class being inherited from is the **superclass** (or base/parent class).

Inheritance is implemented using the **extends** keyword in Java.

Implementing Inheritance with extends

The extends keyword signals that the subclass will inherit all accessible members (excluding constructors) from the superclass.

Syntax:

class Super {
   // base class members
}
class Sub extends Super {
   // derived class members (and inherited members)
}

Example: Subclass Extending Superclass

The My_Calculation class extends Calculation to reuse the addition() and Subtraction() methods and add its own multiplication() method.

class Calculation {
   public void addition(int x, int y) { ... }
   public void Subtraction(int x, int y) { ... }
}

public class My_Calculation extends Calculation {
   public void multiplication(int x, int y) { ... }
   
   public static void main(String args[]) {
      My_Calculation demo = new My_Calculation();
      demo.addition(20, 10); // Inherited
      demo.multiplication(20, 10); // Own method
   }
}

Output shows inherited and own methods are callable:

The sum of the given numbers:30
The difference between the given numbers:10
The product of the given numbers:200

The super Keyword

The super keyword is used to access members of the immediate superclass, especially when there is a naming conflict (shadowing) or when invoking a superclass constructor.

  • **Differentiate Members:** Use super.variable or super.method() to call the superclass version.
  • **Invoke Constructor:** Use super(values) as the first statement in the subclass constructor to call a parameterized superclass constructor.

Example: Using super to Call Superclass Method

class Super_class {
   int num = 20;
   public void display() { ... }
}

public class Sub_class extends Super_class {
   int num = 10;
   public void display() { ... } // Overrides superclass method

   public void my_method() {
      display();       // Calls subclass display()
      super.display(); // Calls superclass display()
      System.out.println(super.num); // Accesses superclass num
   }
}

Types of Inheritance in Java

Java directly supports three types of inheritance using classes. Java **does not support Multiple Inheritance** (a class extending more than one class), but this is achieved through Interfaces.

  1. **Single Inheritance:** One superclass is inherited by one subclass.
  2. **Multilevel Inheritance:** A chain where Class C extends Class B, and Class B extends Class A.
  3. **Hierarchical Inheritance:** One superclass is inherited by multiple different subclasses (Class B extends A, and Class C also extends A).

JavaScript — User Defined Iterators

Overview

In JavaScript, an iterator is an object that defines a sequence and potentially a return value upon its completion. Iterators are based on the Symbol.iterator() method, which returns an object with a next() method. Each call to next() produces an object containing two keys:

  • value — the current element.
  • done — a boolean, true if iteration is finished.

Built-in Iterators

Arrays, Sets, Maps, and Strings are iterable by default:

const nums = [10, 72, 45];
const iter = nums[Symbol.iterator]();

console.log(iter.next()); // { value: 10, done: false }
console.log(iter.next()); // { value: 72, done: false }
console.log(iter.next()); // { value: 45, done: false }
console.log(iter.next()); // { done: true }

Creating a User-defined Iterator

You can create custom iterators for more control. The iterator is a function that returns an object with a next() method. 

function customIterator(chars) {
  let n = 0;
  return {
    next() {
      if (n < chars.length) {
        return { value: chars[n++], done: false };
      }
      return { done: true };
    }
  }
}

const chars = ['A', 'C', 'E'];
const iter = customIterator(chars);

console.log(iter.next()); // { value: "A", done: false }
console.log(iter.next()); // { value: "C", done: false }
console.log(iter.next()); // { value: "E", done: false }
console.log(iter.next()); // { done: true }

This approach works, but since it's just a function returning an object, you cannot directly use for...of with it.

Iterator with Symbol.iterator

To make your custom object iterable with for...of, define Symbol.iterator. Below is an iterator that generates odd numbers until 7: 

const oddNum = {
  [Symbol.iterator]() {
    let p = -1;
    return {
      next() {
        p += 2;
        if (p === 9) return { done: true };
        return { value: p, done: false };
      }
    }
  }
};

for (const odd of oddNum) {
  console.log(odd); 
}
// Output: 1, 3, 5, 7

Here, the for...of loop automatically calls next() until done is true.

Key Points

  • Iterators expose a next() method.
  • next() returns an object with value and done.
  • Objects with Symbol.iterator can be used in for...of loops.
  • Custom iterators are useful for special traversals (e.g., only odd numbers, alternate elements).

Practice Tasks

  • Create an iterator that yields even numbers up to 20.

  • Make a string iterator that yields characters in uppercase only.

Summary

Iterators in JavaScript provide a standardized way to access elements sequentially. User-defined iterators allow custom traversal logic, especially when combined with Symbol.iterator for compatibility with loops like for...of.

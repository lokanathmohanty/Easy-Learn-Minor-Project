C# `for` Loop

Introduction to the `for` Loop

The **`for` loop** is a repetition control structure used to execute a block of code a **specific, known number of times**. It is ideal for scenarios where the number of iterations is predetermined, such as processing every element in an array.

It condenses the control of the loop into a single, concise line, managing the loop variable's **initialization, condition, and update**.

Syntax and Control Flow

Syntax:

for ( init; condition; increment ) {
   statement(s);
}

Control Flow Steps:

  1. init (Initialization): Executed **once** at the very beginning. Declares and initializes the loop control variable (e.g., int i = 0).
  2. condition: Evaluated **before** each iteration. If true, the loop body executes. If false, the loop terminates.
  3. Loop Body: The statements within the curly braces {} execute.
  4. increment: Executed **after** the loop body. Updates the loop control variable (e.g., i++ or a = a + 1).
  5. The process repeats from step 2 (condition check).

Example: Simple Iteration

This basic example uses the standard three parts to iterate 10 times, starting from a = 10:

using System;
class Program {
   static void Main(string[] args) {
      
      for (int a = 10; a < 20; a = a + 1) {
         Console.WriteLine("value of a: {0}", a);
      }
   }
}

Output: Values 10 through 19 are printed, as the loop stops when a reaches 20.

Nested `for` Loops

A **nested `for` loop** is a `for` loop placed inside the body of another `for` loop. The inner loop executes all its iterations for **every single iteration** of the outer loop.

Example: Multiplication Table

The outer loop (i) controls the row (number being multiplied), and the inner loop (j) controls the columns (multipliers).

using System;
class Program{
    static void Main()
    {
        for (int i = 1; i <= 5; i++) // Outer loop (rows)
        {
            for (int j = 1; j <= 5; j++) // Inner loop (columns)
            {
                Console.Write(i * j + "\t");
            }
            Console.WriteLine(); // Newline after each row completes
        }
    }
}

Common Use Cases

  • Iterating Arrays/Lists: Using the index (i) from 0 up to Length - 1 to access every element.
  • Printing Patterns: Using nested loops to control row and column structure (like printing a triangle of asterisks).
  • Implementing Counters & Search: Iterating through data to count occurrences or search for a specific target, often paired with the break statement to stop early once the element is found.
  • Generating Sequences: Calculating and printing mathematical sequences like the Fibonacci series.

CSS - writing-mode Property

The CSS writing-mode property is used to define the direction in which text content flows within an element. It controls whether the text should be laid out horizontally or vertically. This property is very useful when dealing with non-Latin scripts such as Chinese, Japanese, Korean, and Arabic, or when creating unique and creative text layouts.

Possible Values

  • horizontal-tb − Default value. Text flows horizontally, left to right, top to bottom. This is used in most Western languages.
  • vertical-rl − Text flows vertically, starting from the right side of the page and moving left. Common in East Asian scripts.
  • vertical-lr − Text flows vertically, starting from the left and moving right. Used in scripts like Mongolian.
  • sideways-rl − Text flows vertically top to bottom, rotated 90° clockwise, with lines arranged from right to left.
  • sideways-lr − Text flows vertically top to bottom, rotated 90° counterclockwise, with lines arranged from left to right.

Note: The older writing modes like lr, rl, tb, and their variations are deprecated. Instead, you should use horizontal-tb, vertical-rl, or vertical-lr.

Examples

The following examples demonstrate the use of the writing-mode property with different values.

Horizontal Text Flow (horizontal-tb)

Example: Text flows from left to right and top to bottom, the default for English and many Western languages. 

.box {
   width: 250px;
   writing-mode: horizontal-tb;
}

Vertical Text Flow Right-to-Left (vertical-rl)

Example: Text flows vertically from top to bottom, and lines are arranged from right to left. 

.box {
   height: 250px;
   writing-mode: vertical-rl;
}

Vertical Text Flow Left-to-Right (vertical-lr)

Example: Text flows vertically from top to bottom, and lines are arranged from left to right. 

.box {
   height: 250px;
   writing-mode: vertical-lr;
}

Sideways Text Flow (sideways-rl and sideways-lr)

These values rotate characters to make text flow sideways. However, browser support is limited (mostly Firefox). 

.box {
   height: 300px;
   writing-mode: sideways-rl;
}
        
.box {
   height: 300px;
   writing-mode: sideways-lr;
}

Aesthetic Use in English

Vertical writing modes can also be used for visual appeal in English designs, for example placing titles vertically along the side of content blocks. 

h2 {
   writing-mode: vertical-rl;
   font-size: 40px;
   font-weight: bold;
}

Related Properties

  • display − Controls how text is displayed.
  • unicode-bidi − Manages the behavior of bidirectional text.
  • text-orientation − Sets the orientation of characters in vertical writing.
  • text-combine-upright − Combines multiple characters into a single upright glyph.

In summary, the writing-mode property is crucial for supporting international scripts and designing innovative layouts. When working with multilingual websites or artistic typography, this property provides flexibility to control text flow beyond the traditional horizontal direction.

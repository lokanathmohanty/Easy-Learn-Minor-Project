JavaScript - Proxies

Proxy in JavaScript

The JavaScript proxies are objects that allow you to wrap a particular object and customize the fundamental operations of the object, like getting and setting object properties. Using the proxy object, you can add custom behavior to the object.

Proxies are used to implement features such as logging, caching, and security.

We can create a proxy object using the Proxy() constructor. It accepts two parameters: the target object and the handler object, and returns a new proxy object.

Syntax

const obj = new Proxy(targetObj, handler);
  • targetObj − The target object for which you want to create a proxy.
  • handler − An object containing functionality to customize behavior.

Example: Proxy with Getter


const person = {
   name: "Same",
   age: 32,
}
const handler = {
   get: function (object, property) {
      return object[property] ? object[property] : 
      'Object doesnt contain the property.';
   }
}
const proxyObj = new Proxy(person, handler);
console.log("Name:", proxyObj.name);
console.log("Height:", proxyObj.height);

Output:


Name: Same
Height: Object doesnt contain the property.

JavaScript Proxy Handlers

Proxy handlers allow you to override the default behavior of an object. Below are some commonly used handlers.

The get() Handler

The get() handler allows you to change the property accessing behavior. 


const watch = {
   brand: "Casio",
   color: "Blue",
   price: null,
}
const handler = {
   get(object, property) {
      return object[property] != null ? object[property] : "Property is null.";
   }
}
const watchProxy = new Proxy(watch, handler);
console.log("Brand:", watchProxy.brand);
console.log("Price:", watchProxy.price);

Output:


Brand: Casio
Price: Property is null.

The set() Handler

The set() handler changes the behavior of updating properties. 


const watch = {
   brand: "Casio",
   color: "Blue",
   price: null,
}
const handler = {
   set(object, property, value) {
      if (property === "price") {
         object[property] = value;
      } else {
         object[property] = "Not Available";
      }
   }
}
const watchProxy = new Proxy(watch, handler);
watchProxy.price = 2000;
watchProxy.dial = "Round";
console.log("Price:", watchProxy.price);
console.log("Dial:", watchProxy.dial);

Output:


Price: 2000
Dial: Not Available

The apply() Handler

The apply() handler is used to modify function calls. 


const watch = {
   brand: "Casio",
   color: "Blue",
   price: 2000,
}
const getWatchDetails = function (watch) {
   return `Brand: ${watch.brand}, Color: ${watch.color}, Price: ${watch.price}`;
}
const getDetails = new Proxy(getWatchDetails, {
   apply(target, thisArg, args) {
      return target(...args).toUpperCase();
   }
});
console.log(getDetails(watch));

Output:


BRAND: CASIO, COLOR: BLUE, PRICE: 2000

Uses of Proxy in JavaScript

1. Validation


const numbers = { num1: 10, num2: 20, num3: 30 }
const handler = {
   set(object, property, value) {
      if (value > object[property]) {
         object[property] = value;
      }
   }
}
const numberProxy = new Proxy(numbers, handler);
numberProxy.num1 = 20;
numberProxy.num2 = 10;
console.log("num1:", numbers.num1, "num2:", numbers.num2);

Output:


num1: 20, num2: 20

2. Access Control


const numbers = { num1: 10, num2: 20, num3: 30 }
const handler = {
   set(object, property, value) {
      console.log("Object is read-only.");
   }
}
const numberProxy = new Proxy(numbers, handler);
numberProxy.num1 = 20;
console.log("num1:", numberProxy.num1);

Output:


Object is read-only.
num1: 10

3. Side Effects


const emails = { email1: "abcd@gmail.com" }
function emailValidator(email) {
   return email.includes("@");
}
const handler = {
   set(object, property, value) {
      if (emailValidator(value)) {
         object[property] = value;
      }
   }
}
const emailProxy = new Proxy(emails, handler);
emailProxy.email1 = "nmc@gmail.com";
console.log("email1:", emailProxy.email1);

Output:


email1: nmc@gmail.com

JavaScript Proxy Handlers List

Handler Description
apply()Changes the behavior of function calls.
construct()Traps object construction with new.
defineProperty()Intercepts property definition.
deleteProperty()Intercepts property deletion.
get()Intercepts property access.
getOwnPropertyDescriptor()Intercepts property descriptor retrieval.
getPrototypeOf()Intercepts prototype access.
has()Intercepts the in operator.
isExtensible()Intercepts Object.isExtensible().
ownKeys()Intercepts Object.keys() and similar.
preventExtension()Intercepts attempts to prevent extensions.
set()Intercepts property updates.

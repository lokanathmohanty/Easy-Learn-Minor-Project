JavaScript - Placement in HTML File

There is flexibility to place JavaScript code anywhere in an HTML document. However, the most preferred ways to include JavaScript in an HTML file are as follows:

  • Script in <head>...</head> section.
  • Script in <body>...</body> section.
  • Script in both <body> and <head> sections.
  • Script in an external file and then include it in <head> section.

You can add JavaScript code using the <script> tag.

JavaScript in <head> Section

Place scripts in the head section when you want them to run on an event, such as a button click.

Example

<html>
<head>
   <script type="text/javascript">
      function sayHello() {
         alert("Hello World")
      }
   </script>
</head>
<body>
   <input type="button" onclick="sayHello()" value="Say Hello" />
</body>
</html>

JavaScript in <body> Section

Place scripts in the body section when you want them to run as the page loads.

Example

<html>
<head></head>
<body>
   <script type="text/javascript">
      document.write("Hello World")
   </script>
   <p>This is web page body</p>
</body>
</html>

JavaScript in <head> and <body>

You can combine both approaches and place scripts in the head and body together.

Example

<html>
<head>
   <script type="text/javascript">
      function sayHello() {
         alert("Hello World")
      }
   </script>
</head>
<body>
   <script type="text/javascript">
      document.write("Hello World")
   </script>
   <input type="button" onclick="sayHello()" value="Say Hello" />
</body>
</html>

JavaScript in External File

External JavaScript allows you to reuse identical code across multiple pages.

filename.js

function sayHello() {
   alert("Hello World")
}

Example

<html>
<head>
   <script type="text/javascript" src="filename.js"></script>
</head>
<body>
   ...
</body>
</html>

Adding Multiple Scripts

<head>
  <script src="filename1.js"></script>
  <script src="filename2.js"></script>
  <script src="filename3.js"></script>
</head>

External References

  • Using full file path 
    <head>
  <script src="C://javascript/filename.js"></script>
</head>
  • Using relative file path 
    <head>
  <script src="javascript/filename.js"></script>
</head>
  • Using filename only 
    <head>
  <script src="filename.js"></script>
</head>

Advantages of Using the <script> Tag

  • Ease of Integration with HTML
  • Immediate Execution
  • Support for Inline and External Scripts
  • Integration of External Libraries and Frameworks
  • Global Scope Access

Example: Adding jQuery via CDN

<script src="https://cdnjs.cloudflare.com/ajax/libs/jquery/3.7.0/jquery.min.js"></script>

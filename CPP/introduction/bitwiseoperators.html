C++ Bitwise Operators and Example Walkthrough 💻

**Bitwise operators** perform operations directly on the individual **bits** of integer types. They are essential in low-level programming, manipulating flags, and efficient mathematical operations.

Bitwise Operations (A=60, B=13)

The example uses two unsigned int variables, a = 60 and b = 13. In 8-bit binary representation (for clarity, though standard int is typically 32 bits):

  • A (60): 0011 1100
  • B (13): 0000 1101

Operator Details

  • **AND (&), OR (|), XOR (^):** These operators compare the corresponding bits of the two operands column-by-column.
    • **AND:** Bit is set to 1 only if **both** input bits are 1.
    • **OR:** Bit is set to 1 if **at least one** input bit is 1.
    • **XOR:** Bit is set to 1 if the input bits are **different**.
  • **One's Complement (~):** This **unary** operator flips every bit (0 becomes 1, 1 becomes 0). The output is **-61** because c is an int (signed) variable, and the result is interpreted using **two's complement** representation.
  • **Left Shift (<<):** Moves all bits in the left operand to the left by the number of places specified by the right operand. New positions are filled with zeros. This is often equivalent to multiplying the value by $2^{\text{shift amount}}$ (e.g., $60 \times 2^2 = 240$).
  • **Right Shift (>>):** Moves all bits in the left operand to the right. This is often equivalent to integer division of the value by $2^{\text{shift amount}}$ (e.g., $60 / 2^2 = 15$).

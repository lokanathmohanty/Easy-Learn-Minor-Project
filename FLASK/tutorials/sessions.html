Flask Sessions: Managing Client-Side State 🔑

A **Session** represents the time interval during which a client interacts with a server. In Flask, session data is stored on the **client side** (in the browser), typically on top of a cookie. This allows data to be held across multiple requests within the session.

Session Security and Mechanism

  • **Session ID:** Each client's session is assigned a unique Session ID.
  • **Storage:** The session data is stored in a cookie that is cryptographically **signed** by the server to prevent tampering.
  • **Requirement:** Due to the encryption requirement, a Flask application **must** define a **SECRET_KEY**. This key is used for the signing process.

Session Object Manipulation

The **session object** is a dictionary-like structure containing key-value pairs of session variables. You must import the session object from the Flask module to use it.

  • **Setting a Variable:** Assign a value to a key: session['username'] = 'admin'
  • **Checking for a Variable:** Use the in operator: if 'username' in session:
  • **Releasing (Deleting) a Variable:** Use the pop() method: session.pop('username', None)

Example: Login, Logout, and Index Logic

This demonstration uses sessions to manage a simple login state:

1. The SECRET_KEY Setup (Mandatory)

Before running the app, the SECRET_KEY must be set for session signing:

app.secret_key = 'any random string'

2. The Index Page (/)

The index() function checks the existence of the 'username' key in the session object to determine the user's login status:

  • **Logged In:** If 'username' is found, it displays a welcome message and a link to log out.
  • **Logged Out:** If 'username' is not found, it displays a "not logged in" message and a link to log in.

3. The Login Process (/login)

The login() function handles the form submission (POST):

if request.method == 'POST':

session['username'] = request.form['username']

The application retrieves the username from the submitted form data (request.form) and immediately **sets the session variable**. It then redirects the user to the index page (/), which will now recognize the user as logged in.

4. The Logout Process (/logout)

The logout() function simply removes the session variable:

session.pop('username', None)

The function then redirects the user back to the index page, which now displays the "not logged in" message.

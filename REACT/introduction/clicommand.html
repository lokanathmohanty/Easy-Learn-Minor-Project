ReactJS - CLI Commands

React provides command-line interface (CLI) commands, mainly used to create a new React application from the command line. These commands generate a default project template with a consistent structure across all applications.

Basic CLI Commands in React

Let us learn the basic commands available in Create React App CLI.

Creating a New Application

Create React App supports multiple ways to create a new React application:

Using npx

npx create-react-app <react-app-name>
npx create-react-app hello-react-app

Using npm

npm init react-app <react-app-name>
npm init react-app hello-react-app

Using yarn

yarn init react-app <react-app-name>
yarn init react-app hello-react-app

Selecting a Template

By default, Create React App uses a standard template. Developers can select other templates using the --template option.

create-react-app my-app --template typescript

This example uses the cra-template-typescript package from the npm registry.

Installing a Dependency

Dependencies can be installed using either npm or yarn:

Using npm

npm install --save react-router-dom

Using yarn

yarn add react-router-dom

Running the Application

The application can be started using:

Using npm

npm start

Using yarn

yarn start

Running in HTTPS Mode

To start the application in HTTPS mode, set the HTTPS environment variable before running the start command.

set HTTPS=true && npm start

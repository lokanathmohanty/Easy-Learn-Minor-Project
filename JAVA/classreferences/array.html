Java Arrays Class Summary 🛠️🗃️

The **java.util.Arrays** class is a **utility class** that consists exclusively of **static methods** for operating on arrays, including **sorting**, **searching**, **comparing**, and creating **list views**. It is the primary tool for manipulating array data structures in Java.

I. Key Functional Categories

The methods within the `Arrays` class are generally overloaded to support all primitive array types (int[], double[], etc.) and object arrays (T[]).

1. Sorting and Parallel Operations

  • **static void **sort**(T[] a):** Sorts the specified array into ascending order. For primitive types, it uses a tuned Quicksort/Dual-Pivot Quicksort. For objects, it uses a highly optimized Timsort (MergeSort/InsertionSort hybrid).
  • **static void **parallelSort**(T[] a):** Sorts the array using parallel processing (fork/join framework). This is generally faster than `sort()` for very large arrays on multi-core machines.
  • **static void **fill**(T[] a, T val):** Assigns the specified value to every element of the array.

2. Searching and Comparison

  • **static int **binarySearch**(T[] a, T key):** Searches for the specified key in the array using the binary search algorithm. **Crucially, the array MUST be sorted beforehand, or the results are undefined.** Returns the index if found, or a negative value indicating the insertion point if not found.
  • **static boolean **equals**(T[] a1, T[] a2):** Checks if two arrays are equal. They are equal if they contain the same number of elements and all corresponding pairs of elements are equal (using `equals()` for objects or `==` for primitives).
  • **static boolean **deepEquals**(Object[] a1, Object[] a2):** Used for arrays of arrays (multidimensional arrays) or arrays containing other collection objects. It performs a recursive equality check on the contents.

3. Array Manipulation and Collection Interoperability

  • **static <T> List<T> **asList**(T... a):** This is a crucial method that returns a **fixed-size List** backed by the specified array.
    • **Caution:** This List is tightly bound to the original array. Changes to the List **write back** to the array, and vice versa.
    • **Caution:** Because the size is fixed, calling `add()` or `remove()` on the returned List will throw an `UnsupportedOperationException`.
  • **static T[] **copyOf**(T[] original, int newLength) / static T[] **copyOfRange**(...):** Methods used for safely creating a new array copy of a specific length or range. New elements are padded with defaults (e.g., `null` for objects, `0` for `int`).
  • **static String **toString**(T[] a):** Returns a user-friendly string representation of the array's contents (e.g., `[1, 2, 3]`).

The example correctly demonstrates the **prerequisite for binarySearch**: the array must first be sorted using Arrays.sort() to guarantee the correct result. After sorting, the array becomes `[1, 2, 3, 5, 8, 10, 15, 20]`, where `15` is correctly located at index 6.

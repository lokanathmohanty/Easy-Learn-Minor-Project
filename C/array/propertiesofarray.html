C - Properties of Array

Arrays are an important data structure in C, enabling easy handling of large amounts of similar data. Their usefulness arises from a set of fundamental properties derived from their definition as a contiguous collection of elements of the same data type.

The key properties of arrays in C include:

  • Collection of Same Data Type
  • Contiguous Memory Allocation
  • Fixed Size
  • Length Depends on Type
  • Indexing
  • Pointer Relationship
  • Lower and Upper Bounds
  • Multi-dimensional Array
  • Implementation of Complex Data Structures

Collection of Same Data Type

All elements in an array must have the same data type to ensure consistent access and operations.

int arr[] = {50, 67.55, "hello", 21};

This will cause a compiler warning due to mismatched data types.

Contiguous Memory Allocation

Array elements are stored in a continuous memory block, enabling efficient random access and better memory locality.

Fixed Size

The size of an array is fixed at declaration and cannot change during program execution.

// Accepted
#define SIZE 10
int arr[SIZE];

// Also accepted
const int SIZE = 10;
int arr[SIZE];

// Not accepted
int SIZE = 10;
int arr[SIZE];  // Error

// Invalid
float num[10.5];  // Error: size must be an integer

Length Depends on Type

Example

#include <stdio.h>

int main() {
   int num[10] = {50, 55, 67, 73, 45, 21, 39, 70, 49, 51};
   int size = sizeof(num) / sizeof(int);
   printf("element at lower bound num[0]: %d \n", num[0]);
   printf("at upper bound: %d byte \n", num[size-1]); 
   printf("length of int array: %ld \n", sizeof(num));

   double nm[10] = {50, 55, 67, 73, 45, 21, 39, 70, 49, 51};
   size = sizeof(nm) / sizeof(double);
   printf("element at lower bound nm[0]: %f \n", nm[0]);
   printf("element at upper bound: %f \n", nm[size-1]);
   printf("byte length of double array: %ld \n", sizeof(nm));

   return 0;
}

Output:

element at lower bound num[0]: 50 
at upper bound: 51 byte 
length of int array: 40 
element at lower bound nm[0]: 50.000000 
element at upper bound: 51.000000 
byte length of double array: 80

Indexing

Arrays are indexed starting at 0. You can use the index to access or modify individual elements.

#include <stdio.h>

int main() {
   int a[] = {1, 2, 3, 4, 5};
   for (int i = 0; i < 4; i++) {
      printf("a[%d]: %d \n", i, a[i]);
   }
   return 0;
}

Pointer Relationship

The name of the array is treated as a constant pointer to the first element of the array.

#include <stdio.h>

int main() {
   int num[10] = {50, 55, 67, 73, 45, 21, 39, 70, 49, 51};
   printf("num[0]: %d Address of 0th element: %d\n", num[0], &num[0]);
   printf("Address of array: %d", num);
   return 0;
}

Both addresses will be the same.

Lower and Upper Bounds

The lower bound is always index 0, and the upper bound is size - 1.

#include <stdio.h>

int main() {
   int num[10] = {50, 55, 67, 73, 45, 21, 39, 70, 49, 51};
   int size = sizeof(num) / sizeof(int);
   printf("element at lower bound num[0]: %d at upper bound: %d Size of array: %d", 
   num[0], num[size-1], size);
   return 0;
}

Multi-dimensional Array

Arrays can have more than one dimension, such as 2D (matrix), 3D, etc. A 1D array is like a list, a 2D array is like a table.

int a[3][3] = {
   {1, 2, 3},
   {11, 22, 33},
   {111, 222, 333}
};

Multi-dimensional arrays are commonly used in databases, spreadsheets, and simulations.

Implementation of Complex Data Structures

Arrays are foundational in implementing data structures like stacks, queues, and trees.

ReactJS - Formik

Formik is a third-party React form library that provides basic form programming and validation. It is based on controlled components and greatly reduces the time required to build and manage forms.

Since React does not store or maintain state information by itself, form programming requires explicit state management. Formik simplifies this process by handling form state, validation, and submission in a structured way.

Expense Form Using Formik

Steps to build an expense form using Formik:

  • Create a new React app react-formik-app.
  • Install Formik: npm install formik --save.
  • Create ExpenseForm.css for form styling.
  • Create ExpenseForm.js with Formik integration.
  • Set initial values, validation rules, and handle submission.
  • Render the form using Formik-provided handlers like handleChange, handleBlur, and handleSubmit.

Validation

Formik uses a custom validation function that receives current values and returns an errors object if validation fails. Example rules:

  • name is required.
  • amount is required.
  • date is required.
  • category is required.

Submission

On form submission, Formik passes values to a handleSubmit method. Here, values can be validated, sent to a server, or simply displayed using alert().

Example: Form values are displayed as formatted JSON after a small delay to simulate an async request.

Example: Expense Form with Formik

The form includes the following fields:

  • Title (text)
  • Amount (number)
  • Spend Date (date)
  • Category (select)

Each field uses Formik handlers for state updates and validation. Error messages appear next to invalid fields.

Running the Application

  • Create index.js and render ExpenseForm component.
  • Create index.html with a <div id="root"> container.
  • Run the app with npm start.
  • Open http://localhost:3000, fill in the form, and click submit. The entered data will be displayed in a popup.

PHP - Access Modifiers

**Access Modifiers** (or **Visibility Markers**) in PHP—namely **public**, **private**, and **protected**—control the visibility and accessibility of a class's properties and methods. These keywords are fundamental to implementing **Encapsulation**, one of the core principles of Object-Oriented Programming (OOP).

The Principle of Encapsulation

Encapsulation is the practice of hiding an object's internal data (properties) from direct outside access and exposing it only through controlled means (public methods). This is typically achieved by making data members **private** or **protected**, and methods that access or modify that data **public**.

Access Modifier Definitions

The three access modifiers determine the scope from which a class member can be accessed:

  • Public: Members are accessible **from anywhere**: inside the class, by inherited classes, and from the outside environment via an object instance. Class members are **public by default** if no keyword is specified (though modern practice requires explicit declaration).
  • Protected: Members are accessible **only** within the class in which they are declared, and by all classes that **inherit** from it (child classes). They are not accessible from outside the object.
  • Private: Members are accessible **only** within the class in which they are declared. They are not accessible by inherited classes or from the outside environment.

Accessibility Rules Summary

This table summarizes where each type of member is accessible:

Context Public Protected Private
Access from within the same class ✅ Yes ✅ Yes ✅ Yes
Access from a child (inherited) class ✅ Yes ✅ Yes ❌ No
Access from outside the class (via object) ✅ Yes ❌ No ❌ No

Example: Private Access Control

By declaring $price and $title as **private**, direct access from outside the class (e.g., $b1->title) is prevented, enforcing the use of the public methods (e.g., getTitle()) for controlled access. 

<?php
   class Book {
      private $price; // Only accessible inside Book
      private $title; 

      public function __construct(string $param1, int $param2) {
         // Access is allowed here because it's inside the class
         $this->title = $param1;
         $this->price = $param2;
      }

      public function getTitle() { // Public function provides controlled access
         echo "Title: $this->title <br/>";
      }
   }
   $b1 = new Book("Private Data Test", 500);
   $b1->getTitle(); // Works
   
   // echo $b1->title; 
   // ^- This line would cause a Fatal Error: Cannot access private property
?>

Example: Protected Access Control

The fatal error shown in the source material confirms that a protected member ($title in Book) **cannot** be accessed by an object ($b) passed to a function (getmytitle) of an **unrelated** class (mybook). Access is only granted within the Book class and any class that directly extends Book. 

<?php
   class Book {
      protected $title; // Accessible in Book and child classes
      // ... constructor and other public methods
   }

   // This class is NOT a child of Book
   class mybook {
      public function getmytitle($b) {
         // This causes an error because mybook is not a child of Book
         echo "Title: $b->title <br/>"; 
      }
   }
   
   $b = new Book();
   $b1 = new mybook();
   
   // $b1->getmytitle($b);
   // ^- This causes a Fatal Error: Cannot access protected property Book::$title
?>

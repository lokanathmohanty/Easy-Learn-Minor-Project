CSS - min-block-size Property

The CSS min-block-size property sets the minimum block size of an element. The block direction is determined by the writing-mode property. If the content already fits within the block, this property has no effect.

Syntax

min-block-size: auto | length | percentage | initial | inherit;

Property Values

  • auto – No minimum block size limit is set. This is the default value.
  • length – Sets the minimum block size using length units (px, em, rem, etc.).
  • percentage – Sets the minimum block size relative to the containing element.
  • initial – Resets the property to its default value.
  • inherit – Inherits the value from the parent element.

Examples of CSS min-block-size Property

The following examples demonstrate different values for the min-block-size property.

Example 1: Using Auto Value

When set to auto, the element's block size depends entirely on its content.

Code Example

.container {
  min-block-size: auto;
}

Example 2: Using Length Values

Here, we set a minimum block size using fixed units like px and em. If content exceeds the value, the element grows to accommodate it.

Code Example

.container {
  min-block-size: 90px;
}

.container {
  min-block-size: 4.5em;
}

Example 3: Using Percentage Values

Here, the minimum block size is set relative to the containing element.

Code Example

.outer-container {
  height: 100px;
}

.container {
  min-block-size: 58%;
}

.container {
  min-block-size: 75%;
}

Example 4: With Writing Mode

When used with the writing-mode property, the min-block-size adapts to different block flow directions.

Code Example

.outer-container {
  height: 150px;
}

.container {
  min-block-size: 40%;
}

.horizontal {
  writing-mode: horizontal-lr;
}

.vertical {
  writing-mode: vertical-rl;
}

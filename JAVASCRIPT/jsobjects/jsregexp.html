JavaScript - Regular Expressions and RegExp Object

A regular expression (RegExp) in JavaScript is an object that describes a pattern of characters. It can contain alphabetical, numeric, and special characters. The JavaScript RegExp class represents regular expressions, and both String and RegExp define methods that use them for pattern matching and search-and-replace operations.

There are two ways to construct a regular expression in JavaScript:

  • Using the RegExp() constructor
  • Using a regular expression literal

Syntax

var pattern = new RegExp(pattern, attributes);
var pattern = /pattern/attributes;

Parameters

  • pattern − A string that specifies the pattern or another regular expression.
  • attributes − An optional string containing g, i, or m.

Modifiers

  • i − Case-insensitive match
  • m − Multi-line match
  • g − Global match (find all matches)

Brackets

  • [...] − Any one character inside brackets
  • [^...] − Any one character not inside brackets
  • [0-9] − Matches digits 0 through 9
  • [a-z] − Matches lowercase a–z
  • [A-Z] − Matches uppercase A–Z
  • [a-Z] − Matches any character from a to Z

Quantifiers

  • p+ − One or more occurrences
  • p* − Zero or more occurrences
  • p? − Zero or one occurrence
  • p{N} − Exactly N occurrences
  • ^p − Matches if string starts with p
  • p$ − Matches if string ends with p

Examples

  • [^a-zA-Z] − Matches any string not containing a–z or A–Z
  • p.p − Matches "p" followed by any character, then another "p"
  • ^.{2}$ − Matches any string with exactly two characters
  • <b>(.*)</b> − Matches content inside bold tags

Literal Characters

  • \n − Newline
  • \t − Tab
  • \r − Carriage return
  • \uxxxx − Unicode character

Metacharacters

  • . − Any single character
  • \d − Digit (0–9)
  • \D − Non-digit
  • \w − Word character
  • \W − Non-word character
  • \s − Whitespace
  • \S − Non-whitespace

Example: search() vs RegExp

<html>
<body>
  <p id="output"></p>
  <script>
    const output = document.getElementById("output");
    let pattern = /tutorialspoint/i;
    let str = "Welcome to TuTorialsPoint!";
    let res = str.search("tutorialspoint");
    output.innerHTML += "Search using string: " + res + "<br>";
    res = str.search(pattern);
    output.innerHTML += "Search using regex: " + res;
  </script>
</body>
</html>

Example: replace()

<html>
<body>
  <p id="output"></p>
  <script>
    let pattern = /\d+/g;
    let str = "10, 20, 30, 40, 50";
    let res = str.replace(pattern, "100");
    document.getElementById("output").innerHTML = "Result: " + res;
  </script>
</body>
</html>

Example: Email Validation

<html>
<body>
  <p id="output"></p>
  <script>
    const pattern = new RegExp('^[a-zA-Z0-9]+@[a-zA-Z]+\\.[a-zA-Z]{2,3}$');
    document.getElementById("output").innerHTML = 
      "abcd@gmail.com valid? " + pattern.test("abcd@gmail.com") + "<br>" +
      "abcdgmail.com valid? " + pattern.test("abcdgmail.com");
  </script>
</body>
</html>

RegExp Properties

  • constructor − Function that creates an object’s prototype
  • global − True if "g" flag is set
  • ignoreCase − True if "i" flag is set
  • lastIndex − Index where next match starts
  • multiline − True if "m" flag is set
  • source − The text of the pattern

RegExp Methods

  • exec() − Executes a search
  • test() − Tests for a match
  • toSource() − Returns object literal form
  • toString() − Returns string representation

Python - Thread Pools

A thread pool efficiently manages multiple threads to execute tasks concurrently. Python's standard threading module does not provide direct thread pooling, but thread pools are available via the multiprocessing.dummy module and the concurrent.futures module.

Thread pools reuse worker threads to reduce the overhead of creating/destroying threads repeatedly, improving performance for large numbers of tasks.

Two main classes for thread pools in Python are:

  • ThreadPool from multiprocessing.dummy
  • ThreadPoolExecutor from concurrent.futures

Using the Python ThreadPool Class

The ThreadPool class manages a pool of worker threads submitting jobs for concurrent execution. It shares an interface with the Pool class (for processes) and should be closed or terminated properly.

Example: Concurrently computing squares and cubes of numbers using a thread pool with 3 worker threads.

from multiprocessing.dummy import Pool as ThreadPool
import time

def square(number):
   sqr = number * number
   time.sleep(1)
   print("Number:{} Square:{}".format(number, sqr))

def cube(number):
   cub = number * number * number
   time.sleep(1)
   print("Number:{} Cube:{}".format(number, cub))

numbers = [1, 2, 3, 4, 5]
pool = ThreadPool(3)
pool.map(square, numbers)
pool.map(cube, numbers)
pool.close()

Output:

Number:2 Square:4
Number:1 Square:1
Number:3 Square:9
Number:4 Square:16
Number:5 Square:25
Number:1 Cube:1
Number:2 Cube:8
Number:3 Cube:27
Number:4 Cube:64
Number:5 Cube:125

Using the Python ThreadPoolExecutor Class

The ThreadPoolExecutor class from the concurrent.futures module provides a high-level interface for asynchronous function execution using threads. It manages a pool of worker threads executing submitted tasks.

The Future class encapsulates asynchronous execution, allowing you to check task status and obtain results.

Example: Submit square and cube functions to a thread pool and check their execution status.

from concurrent.futures import ThreadPoolExecutor
from time import sleep

def square(numbers):
   for val in numbers:
      ret = val * val
      sleep(1)
      print("Number:{} Square:{}".format(val, ret))

def cube(numbers):
   for val in numbers:
      ret = val * val * val
      sleep(1)
      print("Number:{} Cube:{}".format(val, ret))

if __name__ == '__main__':
   numbers = [1, 2, 3, 4, 5]
   executor = ThreadPoolExecutor(4)
   thread1 = executor.submit(square, numbers)
   thread2 = executor.submit(cube, numbers)
   print("Thread 1 executed ? :", thread1.done())
   print("Thread 2 executed ? :", thread2.done())
   sleep(2)
   print("Thread 1 executed ? :", thread1.done())
   print("Thread 2 executed ? :", thread2.done())

Output:

Thread 2 executed ? : False

Number:1 Cube:1
Thread 1 executed ? : False
Thread 2 executed ? : False

Number:2 Cube:8
Number:3 Square:9

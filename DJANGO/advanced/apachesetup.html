Django: Deploying with Apache using mod_wsgi 🚀

The **Django development server** is suitable only for testing and should not be used in a production environment. To deploy a Django application in production, a dedicated web server like **Apache** or Nginx is required. Serving a Django application via Apache is typically accomplished using the **mod_wsgi** module.

Apache Configuration using mod_wsgi

The link between Django and Apache is handled by the **wsgi.py** file located inside your main Django project folder (e.g., myproject/myproject/wsgi.py).

To configure Apache to serve your Django project, you need to edit its configuration file (e.g., httpd.conf or a virtual host configuration file) and add the following directives:

# The WSGIScriptAlias directive maps a URL path to a WSGI script file.
# Here, it maps the root URL (/) to your project's wsgi.py file.
WSGIScriptAlias / /var/www/html/myproject/myproject/wsgi.py

# WSGIPythonPath tells the WSGI process to add your project directory 
# to the Python path, allowing Python to import your project's settings.
WSGIPythonPath /var/www/html/myproject/

# The <Directory> block grants Apache access permissions to the WSGI file.
<Directory /var/www/html/myproject/>
   <Files wsgi.py>
      Order deny,allow
      Allow from all
   </Files>
</Directory>

Explanation of Directives:

  • WSGIScriptAlias / /path/to/wsgi.py: This is the core directive. It tells Apache to pass all requests made to the root URL (/) to the specified WSGI application file (wsgi.py) for handling by Django.
  • WSGIPythonPath /path/to/project/: This ensures that the Python interpreter running the WSGI process can find and import your Django project modules, including settings.py.
  • <Directory>: This block ensures that Apache has the necessary permissions to read and execute the wsgi.py file, allowing the application to run.

After making these changes, restarting Apache will allow the server to correctly interpret the URLs and serve the Django application instead of just listing the files.

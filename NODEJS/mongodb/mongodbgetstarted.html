Node.js - MongoDB Get Started

Overview

MongoDB is a document-oriented NoSQL database that stores data in BSON (binary JSON) format. It is well-suited for Node.js applications due to its schema-free design and JSON-like data representation.

Installation

Windows

  1. Download MongoDB installer from MongoDB official site.
  2. Run installer, choose Custom setup, uncheck "Install as service".
  3. Create data directory e.g. d:\data\db and start MongoDB with: mongod --dbpath=d:\data\db
  4. Use MongoDB Compass or CLI to connect to mongodb://localhost:27017.

Ubuntu

sudo apt-get update
sudo apt-get install -y mongodb-org

Node.js MongoDB Driver Setup

  1. Initialize Node.js project:
    npm init -y
  2. Install MongoDB driver:
    npm install mongodb

Connecting to MongoDB

const { MongoClient } = require('mongodb');
const url = 'mongodb://localhost:27017';
const client = new MongoClient(url);
const dbName = 'myProject';

async function main() {
  await client.connect();
  console.log('Connected successfully to server');
  const db = client.db(dbName);
  const collection = db.collection('documents');

  // Further database operations here

  return 'done.';
}

main()
  .then(console.log)
  .catch(console.error)
  .finally(() => client.close());

Run with node app.js. Output:

done.

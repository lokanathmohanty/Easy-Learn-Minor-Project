Return a Pointer from a Function in C

Introduction

In C programming, a function can take multiple arguments but return only one expression. This return value can be of any type, including a pointer to a primary or user-defined type. Returning a pointer allows access to variables or structures beyond the function's local scope.

Return a Static Array from a Function

Returning a pointer to a local variable is invalid because the variable no longer exists after the function ends. To return a pointer safely, use a static array.

Example 1: Returning a static array

#include <stdio.h>
#include <math.h>

float * arrfunction(int);

int main() {
  int x = 100;
  float *arr = arrfunction(x);
  printf("Square of %d: %f\n", x, arr[0]);
  printf("Cube of %d: %f\n", x, arr[1]);
  printf("Square root of %d: %f\n", x, arr[2]);
  return 0;
}

float *arrfunction(int x) {
  static float arr[3];
  arr[0] = pow(x, 2);
  arr[1] = pow(x, 3);
  arr[2] = pow(x, 0.5);
  return arr;
}

Example 2: Returning random numbers

#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int *getRandom() {
  static int r[10];
  srand((unsigned)time(NULL));
  for (int i = 0; i < 10; ++i) {
    r[i] = rand();
  }
  return r;
}

int main() {
  int *p = getRandom();
  for (int i = 0; i < 10; i++) {
    printf("*(p + %d): %d\n", i, *(p + i));
  }
  return 0;
}

Return a String from a Function

Strings in C are character arrays. You can dynamically allocate memory, manipulate a string, and return it from a function.

Example: Returning a string

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

char *hellomsg(char *x) {
  char *arr = (char *)malloc(50 * sizeof(char));
  strcpy(arr, "Hello ");
  strcat(arr, x);
  return arr;
}

int main() {
  char *name = "TutorialsPoint";
  char *arr = hellomsg(name);
  printf("%s\n", arr);
  return 0;
}

Return a Struct Pointer from a Function

You can return a pointer to a struct by using a static struct variable inside a function.

Example: Returning struct pointer

#include <stdio.h>

struct rectangle {
  float len, brd;
  double area;
};

struct rectangle *area(float x, float y) {
  static struct rectangle r;
  r.len = x;
  r.brd = y;
  r.area = x * y;
  return &r;
}

int main() {
  float x = 10.5, y = 20.5;
  struct rectangle *r = area(x, y);
  printf("Length: %f\nBreadth: %f\nArea: %lf\n", r->len, r->brd, r->area);
  return 0;
}

Summary

  • Use static variables when returning array or struct pointers.
  • For strings, use malloc() to allocate memory dynamically.
  • Returning pointers provides flexible data handling across functions.

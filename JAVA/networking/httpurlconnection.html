Java - HttpURLConnection Class

java.net.HttpURLConnection is an abstract class representing the HTTP-specific URL connection. Instances can be used to read from and write to the resource referenced by the URL.

For example −

  • If you connect to a URL whose protocol is HTTP, URL.openConnection() returns an HttpURLConnection object.

Steps to make a connection to a URL

  • Invoke URL.openConnection() to get an HttpURLConnection object.
  • Update parameters and request properties using setter methods.
  • Create a connection using connect() method.
  • Access content and headers once connected.

HttpURLConnection Class Declaration

public abstract class HttpURLConnection extends URLConnection

HttpURLConnection Class Fields

  • chunkLength: Chunk length for chunked streaming mode.
  • fixedContentLength and fixedContentLengthLong: Fixed content length for streaming mode.
  • HTTP_OK (200), HTTP_NOT_FOUND (404), HTTP_INTERNAL_ERROR (500), etc.: HTTP status codes as constants.
  • instanceFollowRedirects: Whether to follow redirects automatically.
  • method: HTTP request method (GET, POST, etc.).
  • responseCode: The HTTP status code returned.
  • responseMessage: The HTTP response message.

HttpURLConnection Class Methods

  • disconnect(): Indicate no further requests to server.
  • getErrorStream(): Retrieve error stream on failure.
  • getResponseCode(): Get HTTP status code.
  • getRequestMethod(): Get HTTP method used.
  • setRequestMethod(String method): Set HTTP method (GET, POST, etc.).
  • setFollowRedirects(boolean): Enable or disable automatic redirects.
  • And many others for managing connection and streaming modes.

HttpURLConnection Example

The following program connects to an HTTP URL and reads the data line by line:

package com.tutorialspoint;

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.net.HttpURLConnection;
import java.net.URL;
import java.net.URLConnection;

public class HttpUrlConnectionDemo {
   public static void main(String[] args) {
      try {
         URL url = new URL("https://www.tutorialspoint.com");
         URLConnection urlConnection = url.openConnection();
         HttpURLConnection connection = null;
         if (urlConnection instanceof HttpURLConnection) {
            connection = (HttpURLConnection) urlConnection;
         } else {
            System.out.println("Please enter an HTTP URL.");
            return;
         }

         BufferedReader in = new BufferedReader(
            new InputStreamReader(connection.getInputStream()));
         String urlString = "";
         String current;

         while ((current = in.readLine()) != null) {
            urlString += current;
         }
         System.out.println(urlString);
      } catch (IOException e) {
         e.printStackTrace();
      }
   }
}

Sample Output:

The complete HTML content of the homepage of tutorialspoint.com.

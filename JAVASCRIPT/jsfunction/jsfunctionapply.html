JavaScript - Function apply() Method

The Function apply() method in JavaScript allows us to invoke a function with a specific value for this and arguments provided as an array.

The call() and apply() methods are very similar, but the key difference is:

  • call() takes arguments individually.
  • apply() takes arguments as an array.

We can also use apply() to manipulate the this value and assign any object as the context.

Syntax

func.apply(thisArg, [arg1, arg2, ... argN]);

  • thisArg − The object to use as this inside the function.
  • [arg1, arg2, ... argN] − The arguments to pass, inside an array.

Return value: The value returned by the function.

Examples

Using apply() without arguments


function test() {
  return "The function test is invoked!";
}
test();
test.apply();

Output:

  • The function test is invoked!
  • The function test is invoked!

Using apply() with this argument


function showCar() {
  return "The price of the " + this.name + " " + this.model + " is: " + this.price;
}
let car = { name: "OD", model: "Q6", price: 10000000 };
showCar.apply(car);

Output: The price of the OD Q6 is: 10000000

Using apply() with an array of arguments


function printSum(p1, p2) {
  return this.num1 + this.num2 + p1 + p2;
}
const nums = { num1: 5, num2: 10 };
printSum.apply(nums, [40, 32]);

Output: Total sum is 87

Using apply() with built-in functions


const numbers = [7, 6, 4, 3, 9];
Math.max.apply(null, numbers);
Math.min.apply(null, numbers);

Output:

  • Max element in the array: 9
  • Min element in the array: 3

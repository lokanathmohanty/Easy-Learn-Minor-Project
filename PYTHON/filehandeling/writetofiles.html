Python - Write to File

Writing to a file involves opening the file in a specific mode, writing data to it, and then closing the file to ensure that all data is saved and resources are released. Python provides a built-in function open() to handle file operations and various methods for writing data.

Opening a File for Writing

The open() function is used to open files in different modes, each suited for specific use cases.

  • w (Write mode) - Opens the file for writing. If the file exists, it truncates it before writing. Creates a new file if not existing.
  • a (Append mode) - Adds data to the end of the file. Creates the file if it does not exist.
  • x (Exclusive creation mode) - Creates a new file and fails if the file already exists.
  • b (Binary mode) - Used with other modes to open in binary.
  • + (Update mode) - Opens the file for both reading and writing.

Example: Opening a File in Write Mode

This example opens a file "example.txt" in write mode and writes a string to it: 

file = open("example.txt", "w")
file.write("Hello, World!")
file.close()
print("File opened successfully!!")

Output:

File opened successfully!!

Example: Opening a File in Append Mode

This example appends a line to the existing file contents without altering current data: 

file = open("example.txt", "a")
file.write("Appending this line.\n")
file.close()
print("File opened successfully!!")

Output:

File opened successfully!!

Writing to a File Using write() Method

The write() method writes a single string to a file without adding newlines automatically. 

with open("example.txt", "w") as file:
    file.write("Hello, World!\n")
    file.write("This is a new line.\n")
print("File opened successfully!!")

Output:

File opened successfully!!

Writing to a File Using writelines() Method

The writelines() method writes a list of strings sequentially to the file without inserting newlines automatically. 

lines = ["First line\n", "Second line\n", "Third line\n"]

with open("example.txt", "w") as file:
    file.writelines(lines)

print("File opened successfully!!")

Output:

File opened successfully!!

Writing to a New File

Steps to write to a new file include opening or creating it in write mode, writing data, and closing the file properly. 

fo = open("foo.txt", "w")
fo.write("Python is a great language.\nYeah its great!!\n")
fo.close()

This creates a file "foo.txt" with content:

Python is a great language.
Yeah its great!!

Writing to a New File in Binary Mode

Open the file in binary write mode ('wb') to write binary data. 

with open('test.bin', 'wb') as f:
    data = b"Hello World"
    f.write(data)

To write text as binary, convert the string to bytes using encode(): 

with open('test.bin', 'wb') as f:
    data = "Hello World".encode('utf-8')
    f.write(data)

Writing to an Existing File

Opening a file in append mode ('a') allows adding content without overwriting existing data. 

fo = open("foo.txt", "a")
text = "TutorialsPoint has a fabulous Python tutorial"
fo.write(text)
fo.close()

The file would contain:

Python is a great language.
Yeah its great!!
TutorialsPoint has a fabulous Python tutorial

Writing with Reading Using Update Modes

Opening files with 'w+' mode allows reading and writing without closing. The seek() method can reposition the read/write pointer. 

fo = open("foo.txt", "w+")
fo.write("This is a rat race")
fo.seek(10, 0)
data = fo.read(3)
fo.seek(10, 0)
fo.write("cat")
fo.close()

Opening the file afterward shows:

This is a cat race

CSS :root Selector

The :root selector in CSS is a pseudo-class that matches the root element of a document tree. In an HTML document, :root refers to the <html> element itself. Functionally, it is similar to using the html selector, but :root has higher specificity.

Syntax

/* Selects the root element (<html>) of the document */
:root {
    /* CSS variable declarations or properties */
}

Declaring Global CSS Variables

One of the main purposes of the :root selector is to declare CSS custom properties (variables). These variables can then be accessed globally throughout the stylesheet.

Example:

:root {
   --main-color: blue;
   --secondary-color: white;
}

body {
   background-color: var(--main-color);
}

h1 {
   color: var(--secondary-color);
}

Why Use :root?

  • It allows defining CSS variables at the global scope.
  • Variables declared in :root can be reused across the entire stylesheet.
  • Improves maintainability and reduces repetition in styling.

Supported Browsers

The :root selector is well supported across modern browsers:

  • Chrome: 4.0+
  • Edge: 9.0+
  • Firefox: 3.5+
  • Safari: 3.2+
  • Opera: 9.6+

Conclusion

The :root selector is an effective way to define global variables and apply consistent styling across a project. It makes managing color schemes, font sizes, and reusable values much easier.

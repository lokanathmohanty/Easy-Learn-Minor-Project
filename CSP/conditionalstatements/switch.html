C# `switch` Statement

Introduction to `switch` Statements

The **`switch` statement** is a control flow structure that simplifies decision-making by comparing a single **expression** (usually a variable) against a list of possible constant values, known as **cases**. It provides a clean, readable alternative to a long chain of if...else if...else statements when testing for equality against multiple discrete values.

  • The variable being switched on is checked against each `case` value.
  • When a match is found, the code block associated with that `case` executes.

Syntax and Rules

Syntax:

switch(expression) {
   case constant-expression1:
      statement(s);
      break;
   case constant-expression2:
      statement(s);
      break;
   default: /* Optional */
      statement(s);
      break;
}

Key Rules:

  • **Expression Type:** The expression must be of an integral type (like int or char) or an enumerated type (enum).
  • **Case Constants:** Each constant-expression must be of the **same data type** as the switch variable and must be a constant or a literal value.
  • **The `break` Keyword:** In C#, falling through from one case to the next is **not allowed** (unlike C++ or C). Every non-empty `case` must end with a **jump statement**, usually break, to terminate the switch.
  • **Multiple Cases:** You can group multiple cases together by listing them without a break, allowing the same code block to handle several values (e.g., case 'B': case 'C':).
  • **`default` Case:** The optional default case executes if none of the preceding case expressions match the switch variable's value. It typically appears at the end.

Example: Grading System

This example demonstrates grouped cases (B and C) and the use of the `default` case:

using System;

class Program {
    static void Main(string[] args) {
        char grade = 'B';
         
        switch (grade) {
            case 'A':
               Console.WriteLine("Excellent!");
               break;
            case 'B': // Match! Flow falls to the next non-empty case
            case 'C':
               Console.WriteLine("Well done"); // This executes
               break; // Switch terminates here
            case 'D':
               Console.WriteLine("You passed");
               break;
            default:
               Console.WriteLine("Invalid grade");
               break;
         }
    }
}

Output:

Well done

CSS - Units

CSS Units define the measurement system used to specify the values. CSS offers a number of different units for expressing length and measurement. CSS unit is used to specify the property size for a page element or its content.

There are a number of ways to specify and measure length in CSS. It is used to specify margins, padding, font size, width, height, border, etc.

For example - font-size: 50px, here number 50 has a suffix px i.e., pixel, it is a CSS measurement unit.

There should be no whitespace between the number and the unit. The unit can be left out when the value is 0.

Length Units

Length units can be categorized into two types:

  • Absolute units: Fixed unit lengths that does not depend on screen width.
  • Relative units: Responsive unit lengths that changes according to screen width.

Absolute Length Units

These units are categorized as fixed-length units, which means that lengths specified with absolute units maintain an exact, unchanged size on the screen.

These units prove to be very effective when the browser has comprehensive information about the properties of the screen, the printer being used, or other appropriate user agents.

  • Height: 2px
  • Height: 2cm
  • Height: 2in
  • Height: 2pt

The following are examples of absolute units:

  • mm: Millimeter — 1mm = 1/10th of 1cm (e.g., font-size: 10mm;)
  • cm: Centimeter — 1cm = 37.8px = 25.2/64in (e.g., font-size: 5cm;)
  • Q: Quarter-millimeter — 1Q = 1/40th of 1cm (e.g., font-size: 5Q;)
  • in: Inch — 1in = 2.54cm = 96px (e.g., font-size: 1in;)
  • pt: Point — 1pt = 1/72 of 1in (e.g., font-size: 20pt;)
  • pc: Pica — 1pc = 1/6th of 1in (e.g., width: 6pc;)
  • px: Pixel — 1px = 1/96th of 1in (e.g., font-size: 15px;)

Absolute units are valuable for non-responsive projects but less useful for responsive websites since they do not adjust to screen dimensions.

Relative Length Units

Relative length units are measured in relation to other elements or viewport of the screen.

They are great for responsive websites because they adjust proportionally based on window size or parent elements.

  • Height: 3em
  • Height: 3ex
  • Height: 3lh
  • Height: 3vh

The following are examples of relative units:

  • em: Relative to the font-size of the element (e.g., font-size: 4em;)
  • ex: Relative to the x-height of the current font (e.g., font-size: 4ex;)
  • ch: Relative to width of the "0" (e.g., font-size: 4ch;)
  • rem: Relative to font-size of the root element (e.g., font-size: 2rem;)
  • lh: Relative to the line height of the element (e.g., font-size: 4lh;)
  • rlh: Relative to the line height of the root element (e.g., font-size: 4rlh;)
  • vh: Relative to the height of the viewport (e.g., font-size: 4vh;)
  • vw: Relative to the width of the viewport (e.g., width: 4vw;)
  • vmin: Relative to smaller viewport dimension (e.g., width: 4vmin;)
  • vmax: Relative to larger viewport dimension (e.g., width: 4vmax;)
  • vb: Relative to size of initial containing block’s block axis (e.g., font-size: 4vb;)
  • vi: Relative to size of initial containing block’s inline axis (e.g., font-size: 4vi;)
  • svw / svh: Relative to smaller viewport’s width/height (e.g., width: 40svw; height: 40svh;)
  • lvw / lvh: Relative to larger viewport’s width/height (e.g., width: 40lvw; height: 40lvh;)
  • dvw / dvh: Relative to dynamic viewport (e.g., width: 40dvw; height: 40dvh;)

Example: Relative Units

Here is an example of relative units (em, rem, vw, vh, %) used for font sizes:

Example Heading:

Font size 2em
Font size 1.5rem
Font size 5vw
Font size 5vh
Font size 150%

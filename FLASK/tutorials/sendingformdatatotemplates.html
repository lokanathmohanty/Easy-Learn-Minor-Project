Flask: Sending Form Data to a Template 📤

A common pattern in Flask is to collect data from an HTML form, process it in a view function, and then dynamically render a new HTML page (a template) with that received data. The **request.form** attribute is used to collect the submitted form data as a dictionary-like object.

Application Workflow Overview

The Python application defines two key routes:

  • **/ (student()):** This route uses render_template('student.html') to display the initial HTML form to the user.
  • **/result (result()):** This route is configured to accept **POST** requests from the form. The function collects the form data and passes it to the results template.

Python Logic (result() function)

The **result()** function handles the incoming data:

@app.route('/result',methods = ['POST', 'GET'])

def result():

if request.method == 'POST':

result = request.form

return render_template("result.html",result = result)

When a POST request arrives:

  1. It checks if the method is 'POST'.
  2. It assigns the entire dictionary of form data (request.form) to a variable named result.
  3. It renders the result.html template, passing the result dictionary as a variable also named result to the template context.

HTML Templates and Data Display

1. The Form (student.html)

The form is set to submit data using the **POST** method to the **/result** URL:

<form action = "http://localhost:5000/result" method = "POST">

The names of the input fields (e.g., Name, Physics) become the **keys** in the request.form dictionary.

2. The Result Display (result.html)

The template receives the form data as the result variable and uses a **Jinja2 for loop** to dynamically iterate over the dictionary's key-value pairs (using result.items()) and render them into an HTML table:

{% for key, value in result.items() %}

<tr>

<th> {{ key }} </th>

<td> {{ value }} </td>

</tr>

{% endfor %}

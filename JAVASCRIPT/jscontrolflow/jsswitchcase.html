JavaScript — Switch Case

Overview

The switch statement in JavaScript is a conditional statement used to execute different blocks of code depending on the value of an expression. It provides a cleaner and often more efficient way than multiple if...else if statements when checking a single variable against multiple values.

Syntax

switch (expression) {
  case value1:
    // statements
    break;
  case value2:
    // statements
    break;
  ...
  default:
    // statements
}

  • case: Defines a block of code to run if the expression matches the case value.

  • break: Terminates a case. If omitted, execution continues to the next case.

  • default: Defines code that runs if no case matches. (Optional)

Example — Basic Switch

Here, the grade variable is used in a switch statement:

let grade = 'A';
switch (grade) {
  case 'A':
    console.log("Good job");
    break;
  case 'B':
    console.log("Passed");
    break;
  case 'C':
    console.log("Failed");
    break;
  default:
    console.log("Unknown grade");
}

Output: Good job

Example — Without break

If you omit break, execution "falls through" into the next cases:

let grade = 'A';
switch (grade) {
  case 'A':
    console.log("Good job");
  case 'B':
    console.log("Passed");
  case 'C':
    console.log("Failed");
  default:
    console.log("Unknown grade");
}

Output: Good job, Passed, Failed, Unknown grade

Example — Common Code Blocks

You can group multiple cases to run the same block of code:

let grade = 'C';
switch (grade) {
  case 'A':
  case 'B':
    console.log("Passed");
    break;
  case 'C':
  case 'D':
    console.log("Failed!");
    break;
  default:
    console.log("Unknown grade");
}

Output: Failed!

Example — Strict Comparison

The switch statement uses strict equality (===). Types must match exactly:

let num = 10;
switch (num) {
  case '10':
    console.log("10 Marks!");
    break;
  case '11':
    console.log("11 Marks!");
    break;
  default:
    console.log("Input is not a string!");
}

Output: Input is not a string!

Key Points

  • switch is ideal for multi-branch decisions based on one variable.

  • break prevents fall-through into the next case.

  • Multiple cases can share the same block of code.

  • Comparison uses strict equality (===).

Practice Tasks

  • Write a switch statement that prints the day of the week based on a number (1–7).

  • Modify the example to group weekdays and weekends into two cases.

  • Create a calculator using switch that performs +, -, *, and / based on an operator input.

Summary

The switch statement is a structured way to replace multiple if...else if checks on a single variable. With break and default, it provides flexible control flow and clean handling of multiple conditions.

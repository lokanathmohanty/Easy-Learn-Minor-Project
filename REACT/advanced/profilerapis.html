ReactJS - Profiler API

Profiling is an important technique to collect and show the time taken for a specific function to execute in the live environment. Profiling is normally used to find performance bottlenecks in an application. React provides two options to profile a React application:

  • Profiler Component
  • Profiler DevTools

Profiler Component

The React Profiler component is used to record profiling information of a React component. It can be used anywhere in the element tree and allows multiple and nested profilers.

Signature of the Profiler Component

The Profiler component requires two props:

  • id – Identifier for the Profiler component
  • onRender – Callback function executed during each render phase

The callback function signature is as follows:

function onRenderCallback(
   id,
   phase,
   actualDuration,
   baseDuration,
   startTime,
   commitTime,
   interactions
){
   // Do anything with the profiler information
}

Example implementation to log profiling data:

const logProfilerData = (id, phase, actualTime, baseTime, startTime, commitTime) => {
   console.log(`${id}'s ${phase} phase:`);
   console.log(`Actual time: ${actualTime}`);
   console.log(`Base time: ${baseTime}`);
   console.log(`Start time: ${startTime}`);
   console.log(`Commit time: ${commitTime}`);
};

Applying Profiler

Steps to apply Profiler in a React application:

  • Create a new React application and start it
  • Remove default CSS classes in App.css
  • Create a simple Hello component

Example Hello component:

Profiler React DevTools

React DevTools provides a dedicated Profiler tab to visualize performance. Some features include:

  • Browsing commits
  • Filtering commits
  • Flame chart
  • Ranked chart
  • Component chart

Conclusion

The React Profiler component and Profiler DevTools are powerful tools for profiling and optimizing React applications.

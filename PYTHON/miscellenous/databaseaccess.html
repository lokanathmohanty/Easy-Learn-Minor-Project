Python Database Access

Database access in Python enables applications to store, retrieve, update, and manage persistent data. Python supports various databases using specific packages.

Popular databases include SQLite, MySQL, PostgreSQL, Oracle, Microsoft SQL Server, and more.

Python uses the standardized DB-API (PEP 249) for database connectivity, making it easier to switch between databases.

SQLite Database with Python

SQLite is a file-based, serverless relational database supported via the built-in sqlite3 module.

Steps to work with SQLite:

  1. Create a connection with sqlite3.connect().
  2. Create a cursor to execute SQL statements.
  3. Execute SQL commands and commit transactions.
  4. Close the connection after work is finished.
import sqlite3
conn = sqlite3.connect('testdb.sqlite3')
cur = conn.cursor()
# Create table
cur.execute('''CREATE TABLE Employee (
    EmpID INTEGER PRIMARY KEY AUTOINCREMENT,
    FIRST_NAME TEXT,
    LAST_NAME TEXT,
    AGE INTEGER,
    SEX TEXT,
    INCOME FLOAT)''')
conn.commit()
conn.close()

Schema created successfully.

CRUD Operations

Insert Data

cur.execute("INSERT INTO Employee (FIRST_NAME, LAST_NAME, AGE, SEX, INCOME) VALUES (?, ?, ?, ?, ?)",
            ('Mac', 'Mohan', 20, 'M', 2000))
conn.commit()

Read Data

cur.execute("SELECT * FROM Employee")
rows = cur.fetchall()
for row in rows:
    print(row)

Update Data

cur.execute("UPDATE Employee SET INCOME = INCOME + 1000 WHERE INCOME = ?", (2000,))
conn.commit()

Delete Data

cur.execute("DELETE FROM Employee WHERE INCOME < ?", (3000,))
conn.commit()

Transaction Management

Transactions ensure consistency with four properties: Atomicity, Consistency, Isolation, Durability (ACID).

Use conn.commit() to save changes and conn.rollback() to revert.

try:
    cur.execute("DELETE FROM Employee WHERE AGE > ?", (20,))
    conn.commit()
except:
    conn.rollback()

Connecting to MySQL with PyMySQL

PyMySQL is a pure Python MySQL client following DB-API standard.

To install:

pip install pymysql

To connect:

import pymysql
db = pymysql.connect(
    host="localhost",
    user="testuser",
    password="test123",
    database="TESTDB")

Then use cursor() and execute queries similarly to sqlite3.

Error Handling

DB-API implementations provide standardized exceptions:

ExceptionDescription
WarningNon-fatal issues
ErrorBase for all database errors
InterfaceErrorErrors in the interface
DatabaseErrorDatabase-related errors
DataErrorErrors related to data
OperationalErrorOperational errors like connection failures
IntegrityErrorConstraint violations
InternalErrorInternal database errors
ProgrammingErrorProgramming mistakes
NotSupportedErrorUnsupported operations

Variable Arguments in C

Sometimes, you may need a function that accepts a variable number of arguments instead of a fixed number. C provides a way to do this using stdarg.h.

The syntax for such a function is:

int func(int, ... ) {
   ...
}

Here, the last parameter is an ellipsis (...) and the parameter just before it (usually an int) typically represents the number of variable arguments passed.

How to implement variable arguments in C

  1. Define the function with its last parameter as ellipses, and the preceding parameter as an int representing the count of variable arguments.
  2. Create a va_list variable in the function (defined in stdarg.h).
  3. Use the macro va_start to initialize the va_list variable.
  4. Use the macro va_arg to access each argument in the list.
  5. Use the macro va_end to clean up.

Example

This example shows a function that calculates the average of a variable number of integer arguments.

#include <stdio.h>
#include <stdarg.h>

double average(int num, ...) {
   va_list valist;
   double sum = 0.0;
   int i;

   /* initialize valist for num number of arguments */
   va_start(valist, num);

   /* access all the arguments assigned to valist */
   for (i = 0; i < num; i++) {
      sum += va_arg(valist, int);
   }

   /* clean memory reserved for valist */
   va_end(valist);

   return sum / num;
}

int main() {
   printf("Average of 2, 3, 4, 5 = %f\n", average(4, 2, 3, 4, 5));
   printf("Average of 5, 10, 15 = %f\n", average(3, 5, 10, 15));
}

Output

Average of 2, 3, 4, 5 = 3.500000
Average of 5, 10, 15 = 10.000000

Note that the first argument to average() indicates how many variable arguments are passed. The ellipses ... allow the function to accept that variable number of arguments.

Python Pandas Tutorial

Pandas is an open-source, BSD-licensed Python library providing high-performance, easy-to-use data structures and data analysis tools for the Python programming language. This Pandas tutorial has been prepared for those who want to learn about the foundations and advanced features of the Pandas Python package.

Python with Pandas is used in a wide range of fields including academic and commercial domains such as finance, economics, statistics, and analytics. In this tutorial, we will learn the various features of Python Pandas and how to use them in practice.

What is Pandas?

Pandas is a powerful Python library that is specifically designed to work on data frames that have "relational" or "labeled" data. Its aim aligns with doing real-world data analysis using Python. Its flexibility and functionality make it indispensable for various data-related tasks.

To work with Pandas, we first need to install it using: 

pip install pandas

Then we can import it in Python: 

import pandas as pd

Pandas primarily provides two main structures:

  • Series - A one-dimensional labeled array that can hold any data type (integers, strings, objects, etc.).
  • DataFrame - A two-dimensional labeled data structure with rows and columns, similar to a spreadsheet or SQL table.

Why Pandas?

The beauty of Pandas is that it simplifies many of the time-consuming and repetitive tasks involved in working with data frames:

  • Import datasets from CSV, Excel, JSON, SQL, and more.
  • Data cleansing, including handling missing values.
  • Size mutability (adding or removing columns).
  • Data normalization and alignment.
  • Intuitive merging, joining, reshaping, and pivoting of datasets.
  • Efficient slicing, indexing, and subsetting of datasets.
  • Statistical analysis and data visualization.

Applications of Pandas

  • Data Cleaning: Handle missing values, remove duplicates, and standardize formats.
  • Data Exploration: Summarize statistics, detect trends, and visualize data.
  • Data Preparation: Pivoting, melting, and merging datasets.
  • Data Analysis: Supports descriptive statistics, time series analysis, and group operations.
  • Data Visualization: Integrates with Matplotlib, Seaborn, and Plotly.
  • Time Series Analysis: Resampling, frequency conversion, and rolling statistics.
  • Data Aggregation and Grouping: Group and summarize datasets with groupby().
  • Machine Learning: Works with Scikit-learn for preprocessing and feature engineering.
  • Financial Analysis: Used for stock data analysis and portfolio optimization.
  • Web Scraping: Combine with BeautifulSoup or Scrapy to analyze structured data.
  • Experimental Data Analysis: Handle large datasets and perform statistical tests.

Example: Creating a DataFrame

import pandas as pd

# Create a simple DataFrame
data = {
    'Name': ['Alice', 'Bob', 'Charlie'],
    'Age': [25, 30, 35],
    'City': ['New York', 'Paris', 'London']
}

df = pd.DataFrame(data)

print(df)

Next.js - Lazy Loading

What is Lazy Loading?

Lazy Loading is an optimization strategy that postpones the loading of **non-critical resources** (such as JavaScript bundles, components, or images) until the exact moment they are needed, typically when they enter the user's viewport. The core benefit is an improved **initial loading performance** by reducing the amount of JavaScript and assets required for the first page render.

How Lazy Loading Works

  1. At build time, Next.js automatically **splits the code** into separate, smaller JavaScript bundles.
  2. When a user navigates, the application only loads the required initial bundle.
  3. Other resources (components, images, modules) are loaded asynchronously, **on demand**, usually when proximity or visibility in the viewport is detected.

Lazy Loading Components and Modules

In Next.js, component and module lazy loading is primarily achieved through **Dynamic Imports**, which is a combination of React's React.lazy() and Suspense capabilities.

Using Dynamic Imports (next/dynamic)

The **next/dynamic** function allows you to import JavaScript modules asynchronously, controlling exactly when they are loaded.

Example: Conditional and Client-Only Loading

'use client'
import { useState } from 'react'
import dynamic from 'next/dynamic'

// Load immediately, but in a separate client bundle
const ComponentA = dynamic(() => import('../components/A'))

// Load only when the 'showMore' condition is true
const ComponentB = dynamic(() => import('../components/B'))

// Load only on the client side (server-side rendering disabled)
const ComponentC = dynamic(() => import('../components/C'), { ssr: false })

export default function ClientComponentExample() {
  const [showMore, setShowMore] = useState(false)
 
  return (
    <div>
        <ComponentA />
        
        {/* Conditional Load */}
        {showMore && <ComponentB />}
        <button onClick={() => setShowMore(!showMore)}>Toggle</button>
        
        {/* Client-Only Load */}
        <ComponentC />
    </div>
  )
}

Lazy Loading Images

Image lazy loading is controlled by the built-in **<Image> component**.

  • By default, all images loaded via <Image> are **lazy loaded** (loading='lazy'). They are only loaded when they become visible in the user's viewport.
  • To disable lazy loading and load an image immediately (e.g., for images critical to the user's initial view), you can set the **loading** prop to **eager**.

Example: Lazy vs. Eager Image Loading

import Image from 'next/image';

export default function Example() {
    return (
    <div>
        <h1>Lazy Loading (Default):</h1>
        <Image
            src="/file.svg"
            alt="Example Image"
        />

        <h1>Eager Loading (Priority Load):</h1>   
        <Image
            src="/next.svg"
            alt="Example Image"
            loading='eager'    // Disable Lazy Loading
        />
    </div>
    );
}

When to Use and Avoid Lazy Loading

Use Lazy Loading For:

  • Complex dashboard widgets and charts.
  • Modal dialogs and hidden sidebars.
  • Content that is initially **below the fold** (not visible without scrolling).
  • Heavy, non-essential third-party components (e.g., complex ad units, large map components).

Avoid Lazy Loading For:

  • The **Header and footer** sections.
  • Primary **navigation bars** and menus.
  • Any component that is **always visible** or critical for the user's initial interaction (e.g., the Largest Contentful Paint image).

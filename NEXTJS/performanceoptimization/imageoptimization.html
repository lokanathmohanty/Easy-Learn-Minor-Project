Next.js - Image Optimization

The Next.js <Image> Component

The Next.js **<Image> component** is an extension of the standard HTML <img> tag designed to automatically optimize images for performance. By using this component, applications gain significant benefits in areas vital for Core Web Vitals:

  • Size Optimization: Automatically serves correctly sized images for different devices and uses modern, efficient formats like **WebP** and **AVIF**.
  • Visual Stability: Automatically prevents **layout shift** (a major cause of poor user experience) while images are loading.
  • Faster Page Loads: Implements native browser **lazy loading** by default, loading images only when they enter the viewport.
  • Asset Flexibility: Supports on-demand image resizing for both local and remote assets.

Optimizing Local Images

Local images are stored directly within the Next.js application directory. When importing a local image, Next.js performs automatic optimizations at build time:

  • It automatically determines the image's **intrinsic width and height** from the file.
  • These intrinsic values are used to calculate the aspect ratio, which is crucial for preventing layout shift.
  • It also automatically provides a **blurDataURL** for an optional low-quality placeholder (LQIP) while the image loads.

Example: Local Image Import

import Image from 'next/image';
import logo from './logo.png' // Automatic size detection

export default function Page() {
  return (
    <Image
        src={logo} // src is the imported module
        alt="Picture of the Logo"
        // width, height, and blurDataURL are automatically handled
    />
  )
}

Optimizing Remote Images

Remote images have a src property that is an external URL string. Since Next.js cannot access remote files during the build process, it cannot determine the intrinsic size automatically. Therefore, you **must manually specify the width and height** props.

The specified dimensions infer the correct aspect ratio to prevent layout shift; they do not dictate the final rendered size (which is controlled by CSS).

Example: Remote Image Usage

import Image from 'next/image'

export default function Page() {
  return (
    <Image
      src="https://www.tutorialspoint.com/css/images/logo.png"
      alt="Picture of the Logo"
      width={500}       // Manually specified
      height={500}      // Manually specified
    />
  )
}

Image Loading Priority

The **priority** prop is used to prioritize the loading of images that are critical for the user's initial view, especially the **Largest Contentful Paint (LCP)** image. Setting priority does two things:

  1. It automatically sets loading="eager".
  2. It adds resource hints (like <link rel="preload">) to the HTML header for immediate fetching.

Example: Setting Priority

import Image from 'next/image';

export default function Example() {
  return (
    <div>
      <p>First Priority (Loads instantaneously):</p>
      <Image src="/next.svg" alt="Image" priority /> 

      <p>Second Priority (Default lazy loading):</p>
      <Image src="/file.svg" alt="Image" />
    </div>
  )
}

Lazy Loading Images

By default, all images in Next.js use **lazy loading** (loading='lazy'), meaning they are only loaded when they are near or visible in the viewport. This is a primary optimization for page speed.

To disable lazy loading for a non-priority image, you can explicitly set the **loading** prop to **eager**.

Example: Disabling Lazy Loading

import Image from 'next/image';

export default function Example() {
    return (
    <div>
        <h1>Lazy Loading (Default):</h1>
        <Image src="/file.svg" alt="Example Image" />

        <h1>Eager Loading (Disabled Lazy Loading):</h1>   
        <Image src="/next.svg" alt="Example Image" loading='eager' />
    </div>
    );
}

ReactJS - Using useReducer

The useReducer hook is an advanced alternative to useState for state management. It works by using a reducer function to handle state transitions based on actions, making complex state logic easier to manage.

Signature

const [state, dispatch] = useReducer(reducerFunction, initialState, initFunction)
  • state − Current state information.
  • dispatch − Function used to trigger actions.
  • reducerFunction − Function handling state updates.
  • initialState − The starting state value.
  • initFunction − Optional initializer for computed state.

Reducer Function

(state, action) => updatedState

Example: Counter with useReducer

function reducer(state, action) {
   switch (action.type) {
      case 'increment':
         return { count: state.count + 1 }
      case 'decrement':
         return { count: state.count - 1 }
      default:
         throw new Error()
   }
}

function Counter() {
   const [state, dispatch] = useReducer(reducer, { count: 0 })

   return (
      <>
         Count: {state.count}
         <button onClick={() => dispatch({ type: 'increment' })}>+</button>
         <button onClick={() => dispatch({ type: 'decrement' })}>-</button>
      </>
   )
}

Example: Todo List with useReducer

function todoReducer(items, action) {
   switch (action.type) {
      case 'add':
         return [...items, { id: Date.now(), todo: action.payload }]
      case 'delete':
         return items.filter(item => item.id !== action.payload.id)
      default:
         throw new Error()
   }
}

function TodoReducerList() {
   const [todo, setTodo] = useState('')
   const [items, dispatch] = useReducer(todoReducer, [])

   const handleAdd = () => {
      dispatch({ type: 'add', payload: todo })
      setTodo('')
   }

   const handleDelete = (id) => {
      dispatch({ type: 'delete', payload: { id } })
   }

   return (
      <div>
         <p>List of Todo Items</p>
         <ul>
            {items.map(item => (
               <li key={item.id}>
                  {item.todo}
                  <button onClick={() => handleDelete(item.id)}>Delete</button>
               </li>
            ))}
            <li>
               <input value={todo} onChange={(e) => setTodo(e.target.value)} />
               <button onClick={handleAdd}>Add</button>
            </li>
         </ul>
      </div>
   )
}

Key Points

  • useReducer simplifies handling of complex state updates.
  • It uses a reducer function to manage state transitions.
  • dispatch triggers state changes based on action types.
  • Great for managing state logic involving multiple sub-values.

Summary

The useReducer hook introduces the reducer pattern in React state management. It improves code readability, encourages reuse, and makes complex logic easier to maintain. It’s an essential tool for building scalable React applications.

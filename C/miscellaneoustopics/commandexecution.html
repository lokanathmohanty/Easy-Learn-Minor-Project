Command Execution in C

C provides ways to execute system commands from within a program.

Using system() Function

The system() function executes a command on the host OS shell.

Syntax:

int system(const char *command);

Example of system() Function

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main() {
    char cmd[50];
    strcpy(cmd, "dir C:\\users\\user\\*.c");
    system(cmd);
    return 0;
}

Output:

C:\Users\user>dir *.c
 Volume in drive C has no label.
 Volume Serial Number is 7EE4-E492

 Directory of C:\Users\user

04/01/2024  01:30 PM               104 add.c
04/02/2024  01:37 PM               159 add1.c
... (rest of output)

The exec Family of Functions

These functions replace the current process image with a new process image, effectively running a new program.

They are declared in <unistd.h>.

  • execl() - Execute a file with a list of arguments (null-terminated).
  • execlp() - Like execl, but searches for the executable in PATH.
  • execle() - Like execl, but allows passing environment variables.
  • execv() - Execute a file with an argument vector (array).
  • execvp() - Like execv, but searches in PATH.
  • execve() - Execute a file with arguments and environment variables.

1. execl()

Execute a file with a list of arguments (last argument must be NULL).

Example of execl()

#include <unistd.h>

int main(void) {
    char *file = "/usr/bin/echo";
    char *arg1 = "Hello world!";

    execl(file, file, arg1, NULL);
    return 0;
}

Output:

Hello world!

2. execlp()

Searches for executable in PATH.

Example of execlp()

#include <unistd.h>

int main(void) {
    char *file = "echo";
    char *arg1 = "Hello world!";

    execlp(file, file, arg1, NULL);
    return 0;
}

Output:

Hello world!

3. execle()

Allows passing environment variables.

Example of execle()

#include <unistd.h>

int main(void) {
    char *file = "/usr/bin/bash";
    char *arg1 = "-c";
    char *arg2 = "echo $ENV1 $ENV2!";
    char *const env[] = {"ENV1=Hello", "ENV2=World", NULL};

    execle(file, file, arg1, arg2, NULL, env);
    return 0;
}

Output:

Hello World!

4. execv()

Executes with argument vector.

Example of execv()

#include <unistd.h>

int main(void) {
    char *file = "/usr/bin/echo";
    char *const args[] = {"/usr/bin/echo", "Hello world!", NULL};

    execv(file, args);
    return 0;
}

Output:

Hello world!

5. execvp()

Like execv, but searches executable in PATH.

Example of execvp()

#include <unistd.h>

int main(void) {
    char *file = "echo";
    char *const args[] = {"/usr/bin/echo", "Hello world!", NULL};

    execvp(file, args);
    return 0;
}

Output:

Hello world!

6. execve()

Executes with arguments and environment variables.

Example of execve()

#include <unistd.h>

int main(void) {
    char *file = "/usr/bin/bash";
    char *const args[] = {"/usr/bin/bash", "-c", "echo Hello $ENV!", NULL};
    char *const env[] = {"ENV=World", NULL};

    execve(file, args, env);
    return 0;
}

Output:

Hello World!

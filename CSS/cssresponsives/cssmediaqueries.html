CSS RWD - Media Query

In Responsive Web Designing, media queries rules are used to conditionally apply styles for specific screen widths, aspect ratios, and resolutions. In this session, we will learn how to design a responsive web page using the media query rule.

What is Media Query?

Media queries in CSS are used to apply different styles based on the screen size, resolution, and other characteristics of the user's device. They use the @media rule to include an extra block of CSS properties when certain conditions are met.

Adding a Breakpoint

A breakpoint is a specific screen width where the layout changes to suit the screen size. We can define breakpoints using media queries.

Example syntax:

@media (max-width: 768px) {
    .container {
        flex-direction: column;
    }
}

In this example, when the screen width is 768px or smaller, the container layout changes to a column direction.

Media Query Setting Width Limit

We can set both minimum and maximum width limits in media queries to control how styles apply within specific screen size ranges.

Example: Background color changes when viewport width is between 35em and 85em.

Example

@media (min-width: 35em) and (max-width: 85em) {
    body {
        background-color: plum; 
    }
}

Resize the browser window to see the effect. The background color will turn plum in the defined range.

Media Query Multiple Breakpoints

We can use multiple breakpoints to design layouts for different screen sizes. This allows content to adapt smoothly across devices.

Example

  • Small screens (up to 600px): Font size = 14px
  • Medium screens (601px - 900px): Font size = 16px
  • Large screens (901px and above): Font size = 18px
@media (max-width: 600px) {
    body {
        font-size: 14px;
    }
}

@media (min-width: 601px) and (max-width: 900px) {
    body {
        font-size: 16px;
    }
}

@media (min-width: 901px) {
    body {
        font-size: 18px;
    }
}

CSS Media Queries for Screen Orientation

Media queries can also be applied based on the device orientation such as portrait or landscape.

General syntax:

@media (orientation: portrait) {
    /* Styles */
}

Example

When the viewport width is at least 500px and the device is in landscape mode, the text color changes to blue. 

@media (min-width: 500px) and (orientation: landscape) {
    body {
        color: blue;
    }
}

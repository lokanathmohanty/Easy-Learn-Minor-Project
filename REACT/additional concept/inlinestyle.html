ReactJS - Inline Styling (CSS in JS)

React provides a unique way of directly writing the CSS inside the component and using it in JSX. This concept is called CSS in JS and provides many advantages over traditional usage of styles.

Concept of Inline Styling

React allows CSS to be imported directly into components, but this leads to the problem of global namespace, where one component’s styles can conflict with another. To avoid this, React supports inline styling using JavaScript objects.

Rules for inline styles:

  • Keys must be written in CamelCase instead of kebab-case. Example: background-color → backgroundColor.
  • Values must be strings. Example: { fontSize: "12px" }.
{
   backgroundColor: "red",
   fontSize: "12px"
}

React handles conflicts and ensures styles are scoped correctly.

Applying Inline Style

Steps to apply inline style in a React app:

  • Create a new React app with create-react-app myapp.
  • Remove all styles from App.css.
  • Create a component SimpleStyle and apply inline styles.
import React from "react";

class SimpleStyle extends React.Component {
   displayStyle = {
      fontFamily: 'Times New Roman',
      fontSize: "24px",
      color: "red"
   }
   render() {
      return (
         <div>
            <div style={this.displayStyle}>
               Sample text to understand inline style (object as variable) in React component
            </div>
            <hr />
            <div style={{ fontFamily: 'Arial', fontSize: "24px", color: "grey"}}>
               Sample text to understand inline style (object as expression) in React component
            </div>
         </div>
      )
   }
}

export default SimpleStyle;

In this example:

  • The first div uses a variable (displayStyle) for styles.
  • The second div uses an inline object expression.

Using Inline Style in App

import './App.css'
import React from 'react';
import SimpleStyle from './Components/SimpleStyle'

function App() {
   return (
      <div className="container">
         <div style={{ padding: "10px" }}>
            <div>
               <SimpleStyle />
            </div>
         </div>
      </div>
   );
}

export default App;

Here, the SimpleStyle component is imported and rendered inside the main App.

Summary

Inline styling helps developers quickly include CSS styles without worrying about conflicts. Since the syntax is very similar to CSS, it’s easy for developers to adapt and use this feature efficiently.

Flask-Mail: Sending Emails from a Flask Application 📧

The **Flask-Mail** extension simplifies the process of sending emails from a web application by providing a straightforward interface to any email server (SMTP). To begin, the extension must be installed using pip install Flask-Mail.

Configuration Parameters

Flask-Mail requires configuration settings to connect to the email server. These are set on the Flask application's config object:

  • **MAIL_SERVER / MAIL_PORT:** The address and port number of the email server (e.g., smtp.gmail.com and 465).
  • **MAIL_USE_TLS / MAIL_USE_SSL:** Used to enable/disable security protocols like Transport Security Layer (TLS) or Secure Sockets Layer (SSL).
  • **MAIL_USERNAME / MAIL_PASSWORD:** Credentials for the sender's email account.
  • **MAIL_DEFAULT_SENDER:** Sets the default sender address for messages.
  • **MAIL_SUPPRESS_SEND:** If set to True, emails are suppressed (not actually sent), often used during testing.

Core Classes and Methods

1. The Mail Class

The Mail class manages the overall email-messaging system. An instance is created by passing the Flask application object to its constructor: mail = Mail(app).

Key Methods:

  • **send(message):** Sends the contents of a Message class object.
  • **connect():** Opens a connection with the mail host.

2. The Message Class

The Message class encapsulates a single email, holding all its content and metadata.

Constructor Parameters include: subject, **recipients** (a list), **body** (plain text), **html** (HTML content), and **sender**.

Key Methods:

  • **attach():** Adds an attachment to the message, taking parameters like filename, content_type, and raw data.
  • **add_recipient():** Adds another recipient to the message's list.

Example: Sending an Email with Gmail SMTP

This example demonstrates sending a basic email using Flask-Mail configured for Gmail's SMTP service (note: specific security settings might be needed on the Gmail account):

First, configuration is set up for SSL connection on port 465:

app.config['MAIL_SERVER']='smtp.gmail.com'

app.config['MAIL_PORT'] = 465

app.config['MAIL_USE_SSL'] = True

The index() view function creates and sends the message:

def index():

msg = Message('Hello', sender = 'yourId@gmail.com', recipients = ['id1@gmail.com'])

msg.body = "Hello Flask message sent from Flask-Mail"

mail.send(msg)

This creates a message with a subject, sender, and list of recipients, sets the plain text body, and finally calls the mail.send() method to transmit the email.

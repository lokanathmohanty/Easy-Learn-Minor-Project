CSS - Buttons

Buttons are interactive elements that allow users to perform actions on a webpage or application. They are usually rectangular or circular and contain a label that indicates the action triggered when clicked.

How to Style a Button in CSS?

  1. Dimensions: Use height and width to size buttons.
  2. Colors & Borders: Style with background-color and border.
  3. Shadow Effect: Use box-shadow for depth.
  4. Hover Effect: Change styles on hover using :hover.
  5. Animation: Add transitions or animated effects.

CSS Buttons Colors

Buttons can be styled with background-color. Example: yellow, blue, white, orange, lime buttons.

CSS Button Borders

Borders are styled with border property: thickness, style, color.

CSS Rounded Buttons

Use border-radius for rounded or circular buttons.

  • 10px = slightly rounded corners
  • 20px = more rounded
  • 50% = perfect circle

CSS Button Hover Effect

Use :hover pseudo-class to apply effects like color changes, scaling, or opacity adjustments.

CSS Button Focus and Active

:focus styles appear when the button is selected. :active styles apply when the button is clicked.

CSS Button Shadow Effect

Use box-shadow to add shadows for depth. Example: box-shadow: 0 5px 10px red;.

CSS Disabled Buttons

Disabled buttons appear faded and non-clickable, often styled with cursor: not-allowed and reduced opacity.

CSS Buttons Width

The width property sets button size in px or percentage (%).

CSS Buttons Groups

A button group arranges multiple buttons horizontally by removing margins and using display: flex or float: left.

CSS Vertical Buttons Groups

Vertical groups stack buttons using display: block.

CSS Buttons on Image

Buttons can be overlaid on images by placing them in a container with position: relative and setting the button to position: absolute.

CSS Animated Buttons

CSS animations and pseudo-elements (like ::before) can create animated effects, such as sliding highlights or expanding backgrounds on hover.

Next.js - Testing With Cypress

What is Cypress?

Cypress is a powerful, modern **JavaScript testing framework** designed for end-to-end (E2E) testing and component testing. It operates directly within the browser, allowing it to execute tests in the environment where the code actually runs.

  • It is used to simulate realistic **user interactions** (navigation, clicks, form submissions) in your Next.js application.
  • It helps verify complex user flows, test linking, check that components render correctly, and ensure API routes function properly from the client perspective.

Setting Up Cypress in Next.js

Option 1: Create a New Project with Cypress

Start a new Next.js project with a pre-configured Cypress setup using this command:

npx create-next-app@latest --example with-cypress with-cypress-app

Option 2: Manual Setup in an Existing Project

For an existing project, follow these steps:

Step 1: Install Cypress

Install Cypress as a development dependency:

npm install -D cypress

Step 2: Update Scripts in package.json

Add a script to easily open the Cypress Test Runner:

// File: /package.json
{
    "scripts": {
      "cypress:open": "cypress open",
      // ... other scripts ...
    }
}

Step 3: Run Cypress to Configure

Run the command to launch the Cypress testing suite for the first time:

npm run cypress:open

Cypress will guide you through setting up either **E2E Testing** or **Component Testing**, automatically creating the necessary configuration file (cypress.config.js) and the cypress folder structure.

Writing E2E Tests with Cypress (Navigation Example)

Cypress E2E tests are written using JavaScript and reside in the cypress/e2e (or cypress/integration) folder. The tests use the global cy object to interact with and assert against the application's behavior.

The Scenario: Testing Page Navigation

This test verifies that clicking the "About" link on the Home page successfully navigates the user to the About page.

The Test File (/cypress/e2e/navigation.cy.js)

describe('Navigation', () => {
    it('should navigate from Home to the About page', () => {
      // 1. Start from the Next.js index page
      cy.visit('http://localhost:3000/')
   
      // 2. Find the link with 'about' in its href and click it
      cy.get('a[href*="about"]').click()
   
      // 3. Assert that the URL has changed to include "/about"
      cy.url().should('include', '/about')
   
      // 4. Assert that the content of the new page is correct
      cy.get('h1').contains('About')
    })
})

Running the Test

Since Cypress simulates a real user accessing your application, the **Next.js server must be running**.

  1. Build and Start Server: Run your application in production mode for the most accurate testing environment (in one terminal window): 
    npm run build && npm run start
  2. Run Cypress: In a **separate terminal window**, open the Cypress Test Runner: 
    npm run cypress:open
  3. Select the E2E test suite and click on the test file to execute the navigation simulation in the browser.

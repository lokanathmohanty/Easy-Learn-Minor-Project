ReactJS - Introduction to Hooks

Until React 16.8, function components were simply stateless. To add state to a component, developers had to convert the function component into a class-based component. Function components also lacked lifecycle event handling. To address this, React introduced Hooks.

Hooks are plain JavaScript functions that provide access to state and lifecycle events inside a function component. They generally start with the use keyword. React provides several built-in hooks and also allows developers to create custom hooks.

Built-in Hooks

  • useState − Manage state inside a function component.
  • useReducer − Advanced state management using reducers.
  • useEffect − Hook into component lifecycle.
  • useLayoutEffect − Runs synchronously after DOM mutations, before painting.
  • useContext − Access context provider values.
  • useMemo − Memoize values or functions to optimize performance.
  • useCallback − Memoize callback functions to avoid re-creation.
  • useRef − Access raw DOM nodes or persist values across renders.
  • useImperativeHandle − Expose child ref values to parent components.
  • useDeferredValue − Defer updates similar to debouncing/throttling.
  • useDebug − Label custom hooks in React DevTools.
  • useTransition − Track pending states during transitions.
  • useId − Generate unique IDs for elements.

Applying Hooks

Let’s create an example using the useState hook. 

import { useState } from 'react';

export default function HelloWorld() {
   const [name, setName] = useState("World")
   return (
      <div>
         <input 
            id="name" 
            name="name"
            value={name}
            onChange={(e) => setName(e.target.value)} />
         <div>Hello {name}</div>
      </div>
   )
}

Here, useState initializes the state with "World". It returns two items: the current state value (name) and a function to update it (setName). When the input changes, setName updates the state and re-renders the component.

Using in App Component

import './App.css';
import HelloWorld from './components/HelloWorld';

function App() {
   return (
      <HelloWorld />
   );
}

export default App;

Open the browser, type into the input field, and the greeting updates instantly.

Advantages of Hooks

  • Simpler and easier to start coding with.
  • Reduces complexity compared to class components.
  • No need to handle this keyword confusion.
  • Reusability of stateful logic between components.
  • Compatible with existing class-based components.
  • Less code compared to class components.

Disadvantages of Hooks

  • Must be called only at the top level (not inside loops, conditions, or nested functions).
  • Not always the best fit; sometimes class components are preferable.
  • React abstracts hook internals, limiting optimization in some cases.

Summary

Hooks are a relatively new way to create components, but many projects still rely on class-based components. Converting large codebases entirely to hooks may not be practical, so migration often happens gradually.

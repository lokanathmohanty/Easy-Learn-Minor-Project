Java Method References (Java 8+)

What are Method References?

Method references, introduced in **Java 8**, are syntactic sugar for a **lambda expression** that simply calls an existing method. They provide a concise way to refer to a method by its name, making code more readable and compact than a full lambda expression.

A method reference is only used where a lambda expression is accepted, which is when working with **functional interfaces** (interfaces with a single abstract method).

The syntax uses the **double colon operator (::)**.

How it Works

The compiler infers the functional interface method's arguments from the context and passes them directly to the referenced method.

A lambda like s -> System.out.println(s) can be replaced by the method reference System.out::println.

Types of Method References

There are four main forms of method references:

1. Reference to a Static Method

Uses the class name to reference a static method. The arguments required by the functional interface method are passed to the static method.

Syntax: ClassName::staticMethodName

// Using a lambda
numbers.forEach(n -> Math.abs(n)); 

// Using a static method reference
numbers.forEach(Math::abs);

2. Reference to an Instance Method of a Particular Object

Uses a specific object instance to reference its instance method.

Syntax: objectInstance::instanceMethodName

// If printer is an instance of a Logger class
Logger printer = new Logger();

// Using a lambda
names.forEach(name -> printer.log(name));

// Using an instance method reference
names.forEach(printer::log);

3. Reference to an Instance Method of an Arbitrary Object of a Particular Type

This is commonly used in Stream operations like map or sorted. The method is called on the object that is being passed as an argument to the functional interface.

Syntax: ClassName::instanceMethodName

// Lambda: (a, b) -> a.compareTo(b)
// Method Reference: Integer::compareTo
numbers.stream().sorted(Integer::compareTo);

4. Reference to a Constructor

Used to reference a constructor of a class using the new keyword. This is typically done when creating new objects within Stream operations.

Syntax: ClassName::new

// Lambda: name -> new Student(name)
// Method Reference: Student::new
studentNames.stream().map(Student::new).toList();

CSS - What Is Cascading in CSS?

Cascading in CSS refers to the way browsers determine which style rule to apply when multiple conflicting rules target the same element. This process follows a structured hierarchy where rules are prioritized based on specificity, importance, and source order.

Key Factors of CSS Cascading

  • Specificity – Rules with higher specificity take precedence over less specific ones.
  • Importance – Rules marked with !important override all other rules.
  • Source Order – If specificity and importance are the same, the rule defined later in the source code wins.

1. Specificity

Specificity determines how targeted a CSS selector is. For example, #id has more weight than .class, and both have more weight than an element selector. 

#txt {
  color: #04af2f;
}

.txt {
  color: blue;
}

In this example, an element with both id="txt" and class="txt" will display green text because ID selectors outrank class selectors.

2. Importance

Adding !important to a style makes it the highest priority, even overriding inline styles unless the inline style itself is marked !important. 

.txt {
  color: #04af2f !important;
}

3. Source Order

When rules have the same specificity and no !important, the one defined last takes precedence. 

.txt {
  color: red;
}

.txt {
  color: #04af2f; /* This will apply */
}

CSS Cascading Hierarchy

The general priority of CSS rules is:

  • !important (highest priority)
  • Inline CSS
  • Internal CSS (inside <style>)
  • External CSS (separate file linked via <link>)
  • User/Browser styles (default styles)

Priority Order: !important > Inline CSS > Internal CSS > External CSS > Browser styles.

CSS Specificity Point System

  • Inline CSS = 1000 points
  • ID selector = 100 points
  • Class, attributes, pseudo-classes = 10 points
  • Element, pseudo-elements = 1 point
/* Lowest Priority */
p { color: red; } /* 1 point */

/* Higher Priority than element */
.myClass { color: blue; } /* 10 points */

/* Even Higher Priority */
#myId { color: green; } /* 100 points */

/* Highest Priority */
<p style="color: #04af2f;">Hello</p> /* 1000 points */

CSS Rule Overriding

CSS decides which rule to apply when multiple rules conflict using specificity, importance, and source order. Below is an example where later rules override earlier ones: 

p {
  color: aqua;
}
#txt {
  color: red;
}
.txt {
  color: #04af2f;
}
p {
  color: blueviolet; /* This overrides the first p rule */
}

Summary

Cascading in CSS ensures that styles are applied in a predictable and logical manner. Understanding specificity, importance, and source order is essential for writing maintainable and conflict-free CSS.

Example

A practical example showing CSS cascade in action:

<p id="txt">This text is red (ID selector wins).</p>
<p class="txt">This text is green (class selector applied).</p>
<p>This text is blueviolet (last p rule applied).</p>

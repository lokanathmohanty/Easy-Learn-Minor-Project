CSS - Data Types

CSS data types define the types of values that can be used for various CSS properties. Each CSS property expects a specific type of value, and understanding these data types is essential for properly styling and formatting web content.

The types listed below are the most common, however it is not a complete list of all types defined in any CSS specification.

Syntax

selector {
   property: <unit-data-type>;
}

CSS syntax uses a keyword between the inequality signs "<" and ">" to indicate data types.

Textual Data Types

These types include keywords, identifiers, strings, and URLs.

Pre-defined Keywords

Represents a predefined keyword that is specific to the property it's used with (e.g., auto, inherit, none).

CSS-wide Keywords

  • <custom-ident> — A user-defined identifier, such as a name given with the grid-area property.
  • <dashed-ident> — Using CSS Custom Properties, a <custom-ident> begins with two dashes.
  • <string> — A string that has been quoted, such as the value for the content property.
  • url() — A reference to a resource, such as the background-image value.

Numeric Data Types

These data types represent quantities, indexes, and positions.

  • <integer> — One or more decimal units (09).
  • <number> — Real numbers may include a fractional component, such as 1 or 1.54.
  • <dimension> — A numerical value that includes a unit, such as 23px or 15em.
  • <percentage> — A numerical value that includes a percentage symbol, such as 15%.
  • <ratio> — A ratio is represented as <number> / <number>.
  • <flex> — Flexible length used in CSS Grid Layout, such as 1fr.

Quantities

  • <length> — Refers to distances (e.g., 10px, 5em).
  • <angle> — Represented as a <dimension> with deg, grad, rad, or turn units.
  • <time> — Duration units, such as 2s or 500ms.
  • <resolution> — Units such as dpi, dpcm, dppx, or x.

Combinations of Types

  • <length-percentage> — Accepts a length or percentage value.
  • <angle-percentage> — Accepts an angle or percentage value.
  • <time-percentage> — Accepts a time or percentage value.

Color

Color-related data types:

  • <color> — Represented as a keyword or numerical value.
  • <color-interpolation-method> — Defines color space for transitions.
  • <hex-color> — Hexadecimal syntax (#ff0000).
  • <system-color> — Linked to default system colors.
  • <alpha-value> — Transparency of a color (0–1 or 0%–100%).
  • <hue> — Angle on the color wheel.
  • <named-color> — Named colors like red, blue, black.

Images

  • <image> — A URL pointing to an image or gradient.

2D Positioning

  • <position> — Position of an element using keywords or <length-percentage>.

Calculation Data Types

  • <calc-sum> — Series of values using + or - operators.
  • <calc-constant> — Constants such as e or π.

Display

  • <display-box> — Determines if an element creates display boxes.
  • <display-inside> — Defines inner display type.
  • <display-internal> — Relevant for layout models.
  • <display-legacy> — Old single-keyword syntax from CSS2.
  • <display-listitem> — Generates ::marker pseudo-element.
  • <display-outside> — Defines outer display type.

Other Data Types

  • <absolute-size> — Absolute font sizes.
  • <basic-shape> — Shapes for clip-path, shape-outside, offset-path.
  • <blend-mode> — Defines blending behavior of colors.
  • <box-edge> — Refers to edges like content-box and border-box.
  • <easing-function> — Controls transition/animation speed.
  • <filter-function> — Applies graphical effects to images.
  • <generic-family> — Generic font families.
  • <gradient> — Smooth transition between colors.
  • <ident> — Arbitrary identifier string.
  • <line-style> — Line appearance (solid, dashed, none).
  • <overflow> — Values for overflow properties.
  • <relative-size> — Size relative to parent element.
  • <transform-function> — Rotate, scale, skew, or move elements.

Example

.box {
   width: 50%;
   height: 200px;
   background-color: rgba(255, 0, 0, 0.5);
   transform: rotate(45deg);
}

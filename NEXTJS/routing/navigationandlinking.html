Next.js Navigation and Linking 🔗

Client-Side Navigation with the `<Link>` Component

The primary way to handle navigation between routes in Next.js is through the built-in **`<Link>`** component, which extends the standard HTML `<a>` tag. The `<Link>` component provides client-side, smooth transitions between pages and handles prefetching for improved performance.

Basic Usage:

You import `<Link>` from `'next/link'` and use the **`href`** attribute to specify the destination route.

// app/layout.tsx (Example in a shared layout)
import Link from 'next/link'; 

export default function RootLayout({ children }) {
  return (
    <header>
        <ul> 
            <li><Link href="/">Home</Link></li> 
            <li><Link href="/about">About Us</Link></li>
        </ul>
        <main>{children}</main>
    </header>
  );
}

Linking to Dynamic Paths:

To link to dynamic routes (e.g., `/products/[id]`), you use **template literals** (backticks) in the `href` to embed the variable path segment.

import Link from 'next/link'

export default function Products() {
    const productId = "Mac-Book-Pro";

    return (
        <ul>
            <li><Link href="/products/IPhone">Iphone</Link></li>
            <li><Link href={`/products/${productId}`}>{productId}</Link></li> <!-- Dynamic link -->
        </ul>
    );
}

Programmatic (Imperative) Navigation

For scenarios where navigation must occur based on a dynamic condition, a form submission, or a button click, you must use **imperative routing** with the **`useRouter`** hook.

Implementation:

  • The logic must be in a **Client Component** (marked with `"use client"`).
  • Import `useRouter` from **`next/navigation`**.
  • Use methods like `router.push(path)` to navigate.

Example: Redirecting After User Action

"use client";
import { useRouter } from "next/navigation";

export default function ProductPage({ params }) {
    const router = useRouter();

    const handleClick = () => {
        alert("Order Placed...");
        
        // Programmatic navigation to the home page (/)
        router.push("/"); 
    };
    return (
        <div>
            <h1>Product {params.id}</h1>
            <button onClick={handleClick}>Order Item</button>
        </div>
    );
}

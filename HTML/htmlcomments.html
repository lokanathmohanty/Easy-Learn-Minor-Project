HTML - Comments

HTML comments are non-executable lines of code that do not display on the webpage and are used to add notes or explanations. It is a good practice to add comments into your HTML code, especially in complex documents, to indicate sections of a document and any other notes for developers.

Comments are completely ignored by web browsers, so they don't affect how your page looks or works. They are placed between <!-- ... --> tags.

Example of HTML Comments

<!DOCTYPE html>
<html>
<head>
   <!-- Document Header Starts -->
   <title>This is document title</title>
</head>
<!-- Document Header Ends -->
<body>
   <p>Document content goes here.....</p>
</body>
</html>

Valid vs Invalid Comments

Comments in HTML have certain rules:

  • Comments do not support nesting (a comment cannot be inside another comment).
  • You can't have the sequence -- inside a comment, except to close it.
  • No space is allowed in the opening <!-- tag.

Valid Comment Example:

<!-- This is valid comment -->

Invalid Comment Example:

< !-- This is not a valid comment -->

Multiline Comments

You can span comments across multiple lines:

<!--
   This is a multiline comment and it can
   span through as many lines as you like.
-->

Conditional Comments

Conditional comments are specific to Internet Explorer (IE) and ignored by other browsers. They are useful when you want to target different IE versions. 

<!--[if IE 6]>
   Special instructions for IE 6 here
<![endif]-->

Comments Using <comment> Tag

Some older browsers supported the <comment> tag, though it's not standard. 

<p>This is <comment>not</comment> Internet Explorer.</p>

Commenting Script Code

In old browsers, it was recommended to wrap script code inside comments so that the page doesn't break if the browser didn't support JavaScript. 

<script>
   <!-- document.write("Hello World!") -->
</script>

Commenting Style Sheets

To comment inside CSS, use /* ... */ syntax. 

<style>
/* commenting in stylesheet 
.example {
   border: 1px solid #4a7d49;
} */
</style>

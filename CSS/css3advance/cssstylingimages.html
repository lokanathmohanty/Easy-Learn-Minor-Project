CSS - Styling Images

CSS provides several properties to style images in a webpage. These properties allow developers to control image dimensions, borders, effects, responsiveness, and interactivity.

How to Style an Image in CSS?

There are several ways to style an image in CSS:

  • Set Dimensions using height and width.
  • Style the Border with color, thickness, and type.
  • Add Shadow effects using box-shadow.
  • Apply Hover Effects like opacity, transforms, or filters.
  • Ensure Responsiveness with flexbox, grid, or media queries.

Set Image Dimensions

The height and width properties control an image’s dimensions.

  • Pixels: Fixed value in px (e.g., 100px).
  • Percentage: Relative to parent container (e.g., 30%).
  • Auto: Maintains original aspect ratio.

<img src="flower.jpg" alt="flower" width="100" height="100">

CSS Image Opacity

The opacity property controls transparency. Values range from 0.0 (transparent) to 1.0 (opaque).

<img src="flower.jpg" alt="opacity example" style="opacity:0.5">

CSS Image Filter

The filter property applies visual effects like blur, grayscale, brightness, contrast, and saturation.

filter: grayscale(80%);

CSS Image Shadow Effect

The box-shadow property adds shadow around an image.

box-shadow: 10px 10px 5px grey;

CSS Image as Background

You can set an image as the background of an element using background-image.

background-image: url('background.jpg');

CSS Image Border

Images can have styled borders using border and border-radius for rounded or circular shapes.

border: 5px solid black; border-radius: 50%;

CSS Image as Border

The border-image property allows images to be used as borders around an element.

border-image: url('border.png') 40 round;

Position Text in an Image

Using position: relative for the image container and position: absolute for text allows text placement on images.

top: 10px; left: 20px;

CSS Image Object Fit

The object-fit property controls how an image is resized within its container.

  • fill: Stretches the image.
  • cover: Fills container, cropping if necessary.
  • contain: Fits image without cropping.

object-fit: cover;

Center an Image

Using flexbox is a common way to center images horizontally and vertically.

display: flex; justify-content: center; align-items: center;

Image Hover Overlay Effect

Overlay effects can be achieved using hover and transform. Common effects include fade-in overlays, text overlays, and flip effects.

.image:hover { transform: scaleX(-1); }

CSS - box-decoration-break Property

The CSS box-decoration-break property specifies how the background, border, border-image, box-shadow, margin, padding, and clip-path of an element should behave when the content is broken across multiple lines or columns. It controls whether these properties should be continuous or fragmented across the line breaks.

Syntax

box-decoration-break: slice | clone | initial | inherit;

Property Values

  • slice: Padding, border, and background are rendered continuously across line breaks (default value).
  • clone: Each box fragment is rendered individually with its border, padding, and margin. Border-radius and box-shadow are applied separately to each fragment.
  • initial: Sets the property to its default value.
  • inherit: Inherits the property from the parent element.

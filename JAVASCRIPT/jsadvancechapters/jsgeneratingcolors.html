JavaScript - Generate Colors

Generating random colors is a common task in web development. It can be used to enhance UI elements, backgrounds, or any component requiring a dynamic appearance. In JavaScript, we can generate colors in different formats such as HEX and RGB.

Generating Random Hex Color

A HEX color code is a six-digit hexadecimal number that represents RGB values. Each pair of digits corresponds to Red, Green, and Blue values ranging from 00 to FF.

Using Math.random() and Math.floor()

  • Math.random() generates a number between 0 (inclusive) and 1 (exclusive).
  • Math.floor() rounds the number down to the nearest integer.

function hex() {
  const randomHex = "#" + Math.floor(Math.random() * 16777215).toString(16);
  document.body.style.backgroundColor = randomHex;
  console.log(randomHex);
}

Example


<div id="demo">Mouse-over on this box to get a new random color</div>
<p id="color"></p>

<script>
  function hex() {
    const ranHexColor = "#" + Math.floor(Math.random()*16777215).toString(16);
    document.body.style.backgroundColor = ranHexColor;
    document.getElementById("color").innerText = ranHexColor;
  }
  document.getElementById("demo").addEventListener("mouseover", hex);
  hex();
</script>

Generating Random RGB Color

An RGB color is represented as rgb(red, green, blue), where each component is an integer between 0 and 255. 


function rgb() {
  const ranRGBColor = "rgb(" 
    + Math.floor(Math.random() * 256) + "," 
    + Math.floor(Math.random() * 256) + "," 
    + Math.floor(Math.random() * 256) + ")";
  document.body.style.backgroundColor = ranRGBColor;
  console.log(ranRGBColor);
}

Conclusion

By combining Math.random() and Math.floor(), we can generate random HEX or RGB colors dynamically in JavaScript. These methods are commonly used for styling interactive components in modern web applications.

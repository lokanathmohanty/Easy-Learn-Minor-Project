PHP Variables: Declaration, Types, and Assignment

**Variables** in PHP are used to store data and are a fundamental part of the language. A key feature of PHP is that it is a **loosely typed language**, meaning you do not need to explicitly declare a variable's data type; PHP determines the type based on the value assigned to it.

How to Declare a Variable in PHP

To declare a variable, you must prefix the name with a dollar sign (`$`) and then assign a value.

$variable_name = value;

PHP Variable Rules:

  • A variable must start with the **`$` symbol**.
  • The variable name must start with a **letter or an underscore** (`_`).
  • A variable name **cannot start with a number**.
  • Variable names are **case-sensitive** (e.g., `$Name` and `$name` are distinct).

$Name = "Amit"; // Different from $name
$name = "Samay";
Output: AmitSamay

Variable Types and Automatic Type Conversion

Primary Variable Types:

  • **String:** Sequence of characters (text).
  • **Integer:** Whole numbers (no decimals).
  • **Float (Double):** Decimal numbers.
  • **Boolean:** Represents `true` or `false`.
  • **Array:** Stores multiple values in one variable.
  • **Object:** An instance of a class.
  • **NULL:** Represents a variable with no value.

Automatic Type Conversion (Type Juggling)

PHP automatically converts variable types when necessary, such as during arithmetic operations.

$x = 10; // Integer
$y = "20"; // String
echo "x + y is: ", $x + $y;
Output: x + y is: 30 (PHP converts "20" to an integer 20 before addition)

Variable Assignment Methods

1. Assigned by Value (Default)

When you assign one variable to another, a **copy** of the value is made. Changes to the original variable after the assignment will **not** affect the new variable.

$x = 10; $y = 20;
$z = $x + $y; // z is 30
$y = 5; // Change y
Output: (after) z = 30 (z is unchanged)

2. Assigned by Reference

Using the **ampersand (`&`)** symbol creates an **alias** (or reference) to the original variable. Both variables point to the same value in memory, so changing one variable **will change the other**.

$x = 10;
$y = &$x; // y references x
$y = 20; // y changes, so x also becomes 20
Output: x=20 y=20 z = 40 (Both x and y are now 20)

Variable Scope in PHP

**Scope** defines the accessibility range of a variable within the program. PHP variables can have one of four scope types:

  • **Local Variables:** Declared inside a function and only accessible within that function.
  • **Global Variables:** Declared outside a function and accessible anywhere in the script, **except** inside a function without using the `global` keyword or the `$GLOBALS` array.
  • **Static Variables:** Declared inside a function but retain their last value between calls to that function.
  • **Function Parameters:** Variables that receive the values passed to a function.

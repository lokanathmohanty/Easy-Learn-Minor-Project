Python - Decision Making

In Python, decision making is achieved using the if..elif..else statements. The if keyword requires a boolean expression followed by a colon (:). The colon indicates the start of an indented block. If the boolean expression evaluates to True, the indented block is executed. Otherwise, the interpreter skips the block and continues execution from the earlier indentation level.

Decision structures evaluate expressions that result in either True or False. Based on this result, the program decides which block of code to execute.

Types of Decision Making Statements in Python

  • if statements − A simple conditional block that executes when the condition is true.
  • if...else statements − Executes one block if the condition is true, otherwise executes the else block.
  • nested if statements − An if or else if inside another if structure to check multiple conditions sequentially.

Single Statement Suites

If the suite of an if clause consists of only a single line, it may be written on the same line as the header statement.

var = 100
if (var == 100): print("Value of expression is 100")
print("Good bye!")

Output:

Value of expression is 100
Good bye!

if...else Statement

An if...else statement executes one block when the condition is true, otherwise executes the else block.

var = 100
if (var == 100): 
   print("Value of var is equal to 100")
else:
   print("Value of var is not equal to 100")

Output:

Value of var is equal to 100

Nested if Statements

A nested if statement means one if inside another. It allows checking multiple conditions in sequence.

var = 100
if (var == 100):
   print("The number is equal to 100")
   if var % 2 == 0:
      print("The number is even")
   else:
      print("The given number is odd")
elif var == 0:
   print("The given number is zero")
else:
   print("The given number is negative")

Output:

The number is equal to 100
The number is even

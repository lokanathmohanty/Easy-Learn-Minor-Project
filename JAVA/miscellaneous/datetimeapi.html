Java 8 - New Date-Time API (java.time)

Why a New Date-Time API? 🕰️

The new Date-Time API, introduced in **Java 8** under the package **java.time**, addresses major drawbacks of the legacy java.util.Date and java.util.Calendar classes:

  • Not Thread-Safe: The old API was mutable and not thread-safe, forcing developers to deal with concurrency issues. The new API classes are **immutable**, resolving this problem.
  • Poor Design & Uniformity: The old API had non-uniform conventions (e.g., months starting at 0, years starting at 1900). The new API provides **clearer, direct utility methods** for date operations and adheres to the ISO 8601 standard.
  • Difficult Time Zone Handling: Time zone complexities required excessive boilerplate code in the old API. The new API offers specialized classes for clear and simple time zone management.

Local Date-Time API (Zone-Neutral)

These classes are for date and time development where time zone context is **not required**:

  • LocalDate: A date without time-of-day (e.g., 2024-10-16).
  • LocalTime: A time without date or time zone (e.g., 14:25:54).
  • LocalDateTime: A combination of LocalDate and LocalTime, without a time zone (e.g., 2024-10-16T14:25:54).

These classes offer methods for creation (now(), of(), parse()) and modification (plus(), withDayOfMonth(), etc.).

Zoned Date-Time API (Time Zone Support)

This API is used when time zone context is critical:

  • ZoneId: Represents a time zone identifier (e.g., Europe/Paris, Asia/Karachi).
  • ZonedDateTime: A full date and time combined with a time zone (e.g., 2007-12-03T10:15:30+05:00[Asia/Karachi]). This is the class to use for global/multi-zone applications.

Temporal Manipulation Classes

  • ChronoUnit Enum

    Replaces integer constants for date and time fields. Used with methods like plus() to add or subtract specific units of time:

    LocalDate nextWeek = today.plus(1, ChronoUnit.WEEKS);

  • Period and Duration

    Classes used to represent amounts of time:

    • Period: Deals with **date-based** time amounts (years, months, days). E.g., Period.between(date1, date2).
    • Duration: Deals with **time-based** time amounts (hours, minutes, seconds, nanos). E.g., Duration.ofHours(2).

  • TemporalAdjusters

    A utility class used with the with() method to perform complex date mathematics, such as finding the next Tuesday or the last day of the month.

    LocalDate nextTuesday = date1.with(TemporalAdjusters.next(DayOfWeek.TUESDAY));

CSS - hyphenate-character Property

The hyphenate-character property in CSS specifies the character that should be used when a word is broken at a hyphenation point. This property works together with the hyphens property, which enables or disables hyphenation in text. By default, browsers use a standard hyphen (-) or another language-specific symbol, but with hyphenate-character you can override it and provide your own character.

Syntax

hyphenate-character: auto | string | initial | inherit;

Property Values

  • auto → The browser automatically selects a suitable character based on language and typography conventions. Default.
  • string → A user-defined character or symbol is used instead of the default hyphen.
  • initial → Resets the property to its default value (auto).
  • inherit → Inherits the value from its parent element.

Example 1: Using auto

The browser decides which character to use (usually a normal hyphen).

div {
  width: 80px;
  border: 2px solid blue;
  hyphens: auto;
  hyphenate-character: auto;
}

Example 2: Using string values

You can specify different characters, such as =, *, or %, for hyphenation breaks.

.box1 {
  hyphenate-character: "=";
}

.box2 {
  hyphenate-character: "*";
}

.box3 {
  hyphenate-character: "%";
}

Example 3: Using inherit

The child element inherits the hyphenation character from its parent.

.parent {
  hyphenate-character: "*";
}

.child {
  hyphenate-character: inherit;
}

Example 4: Using initial

This resets the property back to the browser default (auto).

.text {
  hyphenate-character: initial;
}

Real-World Example: Customizing Text Flow

Imagine you have a narrow column layout where long words must break gracefully. Instead of the default hyphen, you might want to use a middle dot (·) or a tilde (~) for visual style.

.article {
  width: 120px;
  hyphens: auto;
  hyphenate-character: "·";
  border: 1px solid black;
}

Supported Browsers

  • Chrome → 106.0+
  • Edge → 106.0+
  • Firefox → 98.0+
  • Safari → 17.0+
  • Opera → 92.0+

Practical Use Cases

  • Design-heavy websites where default hyphenation symbols might not match the branding.
  • Educational platforms demonstrating hyphenation rules with custom symbols.
  • Localization and typography in languages where alternative hyphenation characters are preferred.
  • Stylistic emphasis in articles, blogs, or print-style layouts.

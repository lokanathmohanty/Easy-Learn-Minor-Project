Python - Environment Setup

Introduction

Installing Python is the first step in starting your journey. Many Linux systems already have Python pre-installed, though it may not be the latest version. Python is available on a wide variety of platforms including Linux, Windows, Mac OS X, and many others. It has even been ported to Java and .NET virtual machines.

Local Environment Setup

To check if Python is already installed, open a terminal and type:

$ python

If installed, you will see something like:

Python 3.11.2 (main, Feb 8 2023, 14:49:24) [GCC 9.4.0] on linux
Type "help", "copyright", "credits" or "license" for more information.

Downloading Python

The latest source code, binaries, and documentation are available on the official website: https://www.python.org/

Documentation is available at https://www.python.org/doc/ in HTML, PDF, and PostScript formats.

Installing Python

Download the binary package for your platform and install. If no binary is available, you can compile from source using a C compiler.

Install Python on Ubuntu Linux

$ python3.11 --version
$ sudo apt update
$ sudo apt-get install software-properties-common
$ sudo add-apt-repository ppa:deadsnakes/ppa
$ sudo apt update
$ sudo apt-get install python3.11

Check installation:

$ python3
>>> print("Hello World")
Hello World

Install Python on Other Linux

  1. Go to Python downloads
  2. Download and extract the source code
  3. Edit Modules/Setup if needed
  4. Run the commands:
$ ./configure
$ make
$ make install

Using Yum Command

On RHEL/CentOS:

$ sudo yum install python3

Install Python on Windows

Download installer from Windows downloads.

For example, 64-bit installer: python-3.11.2-amd64.exe

Steps:

  • Double-click the installer
  • Choose installation folder
  • Tick option to update PATH variable
  • Finish installation wizard

Check installation:

C:\> python
Python 3.11.2 (tags/v3.11.2:878ead1, Feb 7 2023, 16:38:35) [MSC v.1934 64 bit]
>>>

Install Python on Mac

Recent Macs have Python pre-installed but may be outdated. Download the latest from Python Mac downloads. For older versions, MacPython is available from Jack Jansen’s site.

Setting up PATH

The PATH variable defines where executables are searched.

Unix/Linux

# csh
setenv PATH "$PATH:/usr/local/bin/python"

# bash
export PATH="$PATH:/usr/local/bin/python"

# sh or ksh
PATH="$PATH:/usr/local/bin/python"

Windows

path %path%;C:\Python

Python Environment Variables

  • PYTHONPATH − Specifies module search path.
  • PYTHONSTARTUP − Path to initialization file executed at startup.
  • PYTHONCASEOK − On Windows, enables case-insensitive imports.
  • PYTHONHOME − Alternative module search path.

Running Python

Interactive Interpreter

Start Python directly:

$ python   # Unix/Linux
C:\> python   # Windows

Command Line Options

  • -d − Debug output
  • -O − Optimized bytecode
  • -S − Skip import site
  • -v − Verbose output
  • -X − Disable class-based exceptions (obsolete)
  • -c cmd − Run code passed as string
  • file − Run Python script

Script from the Command Line

$ python script.py    # Unix/Linux
C:\> python script.py # Windows

Integrated Development Environment

  • Unix − IDLE
  • Windows − PythonWin
  • Macintosh − IDLE IDE available from Python website

Python Online Compiler

You can also run Python code in an online compiler. Example:

# This is my first Python program.
# This will print 'Hello, World!' as the output

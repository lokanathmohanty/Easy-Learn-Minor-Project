Node.js - Buffers

Overview

Buffers in Node.js handle raw binary data. They are fixed-length sequences of bytes, similar to arrays of integers but located outside the V8 heap. Buffers are subclasses of JavaScript's Uint8Array.

Although Buffers are globally available, it's recommended to explicitly require or reference the Buffer class.

Creating Buffers

  • Using new (deprecated): var buf = new Buffer(10);
  • From array: var buf = new Buffer([10, 20, 30]);
  • From string: var buf = new Buffer("String", "utf8");

New methods: 

const buf1 = Buffer.alloc(10); // Zero-filled
const buf2 = Buffer.allocUnsafe(10); // Uninitialized
const buf3 = Buffer.from([1, 2, 3]);
const buf4 = Buffer.from('hello world', 'utf8');

Static Methods

alloc() method

Creates a zero-filled buffer of specified size:

Buffer.alloc(size[, fill[, encoding]])

Example:

const buf = Buffer.alloc(5);
console.log(buf); // Output:

allocUnsafe()

Creates an uninitialized buffer:

const buf = Buffer.allocUnsafe(10);
console.log(buf);
buf.fill('a');
console.log(buf); // Filled with 'a'

from() method

Creates Buffer from array or string:

const buf1 = Buffer.from([0x62, 0x75, 0x66, 0x66, 0x65, 0x72]);
const buf2 = Buffer.from([10, 20, 30, 40, 50]);
const buf3 = Buffer.from('Hello World');

Buffer Operations

  • compare(): compares two buffers to determine order.
  • copy(): copies data between buffers.
  • entries(): iterates over buffer indices and bytes.
  • slice(): crops a buffer to specified indices.
  • write(): writes a string into a buffer with encoding.
  • toJSON(): converts buffer to JSON object.
  • concat(): joins multiple buffers into one.

Examples

// compare()
const bufA = Buffer.from('APPLE');
const bufB = Buffer.from('APPLY');
console.log(Buffer.compare(bufA, bufB)); // -1: bufA < bufB

// copy()
const bufOriginal = Buffer.from('Buff data');
const bufCopy = Buffer.alloc(10);
bufOriginal.copy(bufCopy);
console.log(bufCopy.toString()); // 'Buff data'

// slice()
const bufSliced = bufOriginal.slice(0, 4);
console.log(bufSliced.toString()); // 'Buff'

// write()
const bufWrite = Buffer.alloc(20);
const bytesWritten = bufWrite.write('Hello Buffer');
console.log(bytesWritten); // 12
console.log(bufWrite.toString('utf8', 0, bytesWritten)); // 'Hello Buffer'

// toJSON()
const bufJson = Buffer.from('JSON data');
console.log(bufJson.toJSON());

// concat()
const buf1 = Buffer.from('Part1 ');
const buf2 = Buffer.from('Part2');
const bufferConcat = Buffer.concat([buf1, buf2]);
console.log(bufferConcat.toString()); // 'Part1 Part2'

PHP File Handling (File I/O)

**File Handling** in PHP refers to the functions used to perform persistent read and write operations on disk files. A file, when opened in PHP, is treated as a **stream**, which is a resource object for linear data transfer. This process is crucial for tasks like **logging, configuration management, and data persistence**.

The Four Fundamental Steps

1. Opening a File (`fopen()`) 🔓

The `fopen()` function establishes a connection to the file resource. It takes the file path and a **mode** as parameters and returns a file pointer resource or `FALSE` on failure.

$file = **fopen**("myfile.txt", "**r**");

**Common Modes:**

  • **`r`**: Read only (starts at the beginning).
  • **`w`**: Write only (creates the file if it doesn't exist, **TRUNCATES** to zero length if it does).
  • **`a`**: Write only (appends to the end of the file; creates if it doesn't exist).
  • **`r+`**: Read and write (starts at the beginning).
  • **`w+`**: Read and write (TRUNCATES the file).

2. Reading Data (`fgets()` / `fread()`) 📖

Once the file is open, you can retrieve its contents using various functions:

  • **`fgets($file)`**: Reads a **single line** from the file pointer. Useful for processing text files line by line.
  • **`fread($file, $length)`**: Reads a specified number of **bytes** (or the entire file if the length is specified as the file size).

3. Writing Data (`fwrite()`) ✍️

The `fwrite()` function is used to write content to a file that has been opened in a write (`w`, `a`, `w+`, `a+`, etc.) mode.

$file = fopen("log.txt", "a");
**fwrite**($file, "Log entry: " . date('Y-m-d'));

4. Closing a File (`fclose()`) 🛑

It is essential to use `fclose()` when you are finished with a file pointer. This frees up system resources and ensures that all buffered output is written to the file on disk, preventing data loss or resource leaks.

// ... operations ...
**fclose**($file);

Error Handling and Stream Wrappers

  • **Error Checking:** Always check the return value of `fopen()` to ensure the file was opened successfully (e.g., `if (!$file) { ... }`) before attempting to read or write.
  • **Stream Wrappers:** PHP handles various resource types (files, network sockets, data URLs) using **stream wrappers** (schemes). The default is the `file://` scheme, but others like `http://` and `ftp://` are also available and returned by the `stream_get_wrappers()` function.
  • **Standard Streams:** PHP also recognizes the standard I/O streams: **`php://stdin`** (keyboard input), **`php://stdout`** (screen output), and **`php://stderr`** (error output), represented by constants `STDIN`, `STDOUT`, and `STDERR`.

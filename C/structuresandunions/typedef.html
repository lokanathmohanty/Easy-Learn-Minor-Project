Typedef in C

What is Typedef?

The typedef keyword in C provides an alias (alternate name) to an existing data type. It is useful for assigning convenient shortcuts to built-in types or derived types like structs, unions, or pointers.

This helps make code more readable, especially when dealing with long or complex type names.

Typedef Syntax

General form:

typedef existing_type new_type;

Examples of Typedef

Example 1: Alias for Unsigned Short

Instead of repeatedly writing short unsigned int, use:

typedef short unsigned int USHORT;
USHORT x;

Example 2: Using Typedef with Long Signed Integer

Although static can't be used directly in typedef, you can alias the type and then declare static variables of that alias:

typedef signed long SLONG;
static SLONG x;

Example 3: Using Typedef in a Program

#include <stdio.h>

int main() {
  typedef short unsigned int USHORT;
  typedef signed long int SLONG;

  static SLONG x = 100;
  USHORT y = 200;

  printf("Size of SLONG: %d \nSize of USHORT: %d", sizeof(SLONG), sizeof(USHORT));
  return 0;
}

Output:

Size of SLONG: 8

Size of USHORT: 2

Defining Structures using Typedef

Normally, you declare structs with:

struct struct_type var;

Using typedef, you can create an alias to avoid repeating struct keyword:

typedef struct struct_type ALIAS;

Example: Struct Typedef

#include <stdio.h>

int main() {
  typedef unsigned long int ULONG;
  typedef short int SHORT;

  struct mystruct {
    ULONG a;
    SHORT b;
  };

  typedef struct mystruct STR;
  STR s1 = {10, 20};
  printf("%ld %u", s1.a, s1.b);

  return 0;
}

Output: 10 20

Alternatively, combine typedef with struct definition:

typedef struct mystruct {
  ULONG a;
  SHORT b;
} STR;

STR s1 = {10, 20};

Typedef for Struct Pointers

Instead of declaring pointers with:

struct mystruct *x;

Use typedef for concise pointer declarations:

typedef struct mystruct {
  ULONG a;
  SHORT b;
} STR;

typedef STR * strptr;

strptr ptr;

Example: Struct Pointer Typedef

#include <stdio.h>

int main() {
  typedef unsigned long int ULONG;
  typedef short int SHORT;

  typedef struct mystruct {
    ULONG a;
    SHORT b;
  } STR;

  STR s1 = {10, 20};
  typedef STR * strptr;
  strptr ptr = &s1;

  printf("%d %d \n", s1.a, s1.b);
  printf("%d %d", ptr->a, ptr->b);

  return 0;
}

Output:

10 20

10 20

Typedef for Unions

You can also assign aliases to union types:

Example: Union Typedef

#include <stdio.h>

int main() {
  typedef unsigned long int ULONG;
  typedef short int SHORT;

  typedef union myunion {
    char a;
    int b;
    double c;
  } UNTYPE;

  UNTYPE u1;
  u1.c = 65.50;

  typedef UNTYPE * UNPTR;
  UNPTR ptr = &u1;

  printf("a:%c b: %d c: %lf \n", u1.a, u1.b, u1.c);
  printf("a:%c b: %d c: %lf \n", ptr->a, ptr->b, ptr->c);

  return 0;
}

Output:

a: b: 0 c: 65.500000

a: b: 0 c: 65.500000

Typedef vs #define in C

#define is a preprocessor directive used to define constants or macros, whereas typedef is evaluated by the compiler to create type aliases.

  • #define can define values or macros (e.g. #define PI 3.14159).
  • typedef only creates symbolic names for types (e.g. typedef unsigned int UINT;).
  • typedef is safer and respects scope rules; #define is simple text substitution.

Example: Using Typedef and #define

#include <stdio.h>
#define MAX 10

int main() {
  typedef unsigned long int ULONG;
  typedef short int SHORT;

  typedef struct employee {
    char name[MAX];
    int age;
  } EMP;

  EMP e1 = {"Krishna", 25};
  printf("Name: %s \nAge: %d", e1.name, e1.age);

  return 0;
}

Output:

Name: Krishna

Age: 25

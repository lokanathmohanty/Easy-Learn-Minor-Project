The printf() Function in C

The printf() function in C is used to display output on the screen. It is defined in the standard I/O library <stdio.h>, which must be included at the start of the program to use this function.

The function can print text, numbers, characters, variables, and formatted data using placeholders called format specifiers.

Syntax

The basic syntax of printf() is:

printf("format_string", args...);

Here, the format_string contains text and format specifiers, and args are the values to be printed in place of specifiers.

Return Value

printf() returns an integer representing the number of characters printed, or a negative value on error.

Examples of printf() Usage

Basic Example

Printing an integer variable with a placeholder:


#include <stdio.h>

int main() {
    int age = 20;
    printf("Hello! I am %d years old.\n", age);
    return 0;
}

Common Format Specifiers

  • %d, %i: Integer (decimal)
  • %f: Floating-point number
  • %.2f: Floating-point with 2 decimal places
  • %c: Single character
  • %s: String
  • %u: Unsigned integer
  • %x, %X: Hexadecimal lowercase and uppercase
  • %p: Pointer (memory address)
  • %%: Percent sign

Format Flags and Width

printf() supports flags to control alignment and padding, as well as width and precision for formatting output. Examples include left-align (-), padding with zeros (0), and showing signs (+).

Escape Sequences

Special characters like newline (\n) and tab (\t) can be embedded in strings to format output.

PHP Conditional (Ternary) Operators Examples

The **Conditional Operator** (often called the **Ternary Operator**) provides a concise, single-line way to write conditional expressions, typically replacing simple `if-else` statements. It evaluates a condition and returns one of two values based on whether the condition is `true` or `false`.

Ternary Operator Syntax and Structure

The operator consists of three parts (hence "ternary"):

condition ? value_if_true : value_if_false
  • **`condition`**: The expression that is evaluated (must result in a Boolean value).
  • **`value_if_true`**: The value returned if the condition is `true`.
  • **`value_if_false`**: The value returned if the condition is `false`.

Basic Usage Examples

1. Assigning a Value Based on Comparison

This is the most common use: assigning one of two values to a variable based on a simple comparison.

$a = 10; $b = 20;
$result = ($a > $b ) ? $a : $b;

Since $a > $b (10 > 20) is **false**, the `value_if_false` ($b, which is 20) is assigned to `$result`.

Output: TEST1 : Value of result is 20

2. Check Even or Odd

Using the modulus operator (`%`) within the condition to determine the output string.

$num = 15;
$result = ($num % 2 == 0) ? "Even" : "Odd";

Output: Number 15 is Odd

Nested Ternary Operators

Ternary operators can be **nested** to handle more than two outcomes, effectively replacing `if-elseif-else` constructs. However, nesting should be used sparingly as it can quickly reduce code readability.

Find Maximum of Three Numbers (Nested Example)

The outer condition checks if `$x` is greater than `$y`. The inner ternary then resolves the maximum of the remaining two possibilities.

$x = 50; $y = 30; $z = 80;
$max = ($x > $y) ? (($x > $z) ? $x : $z) : (($y > $z) ? $y : $z);

**Evaluation Path:**
1. $x > $y (50 > 30) $\rightarrow$ **True**.
2. Execute `value_if_true`: `($x > $z) ? $x : $z`
3. $x > $z (50 > 80) $\rightarrow$ **False**.
4. Return `value_if_false` from inner: **$z** (80).

Output: The maximum number is 80

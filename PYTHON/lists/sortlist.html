Python - Sort Lists

Sorting a list in Python is a way to arrange the elements of the list in either ascending or descending order based on a defined criterion, such as numerical or lexicographical order.

This can be achieved using the built-in sorted() function or by calling the sort() method on the list itself, both of which modify the original list or return a new sorted list depending on the method used.

Sorting Lists Using sort() Method

The Python sort() method is used to sort the elements of a list in place. This means that it modifies the original list and does not return a new list.

Syntax:

list_name.sort(key=None, reverse=False)

  • list_name − the name of the list to be sorted.
  • key (optional) − a function that defines the sorting criterion. Default is None.
  • reverse (optional) − boolean. If True, sorts in descending order; if False (default), ascending order.

Example: Lexicographical Order

list1 = ['physics', 'Biology', 'chemistry', 'maths']
print("list before sort:", list1)
list1.sort()
print("list after sort:", list1)

Output: ['Biology', 'chemistry', 'maths', 'physics']

Example: Numerical Order

list2 = [10, 16, 9, 24, 5]
print("list before sort", list2)
list2.sort()
print("list after sort:", list2)

Output: [5, 9, 10, 16, 24]

Sorting Lists Using sorted() Method

The sorted() function sorts the elements of an iterable and returns a new sorted list, leaving the original iterable unchanged.

Syntax:

sorted(iterable, key=None, reverse=False)

  • iterable − list, tuple, string, etc.
  • key (optional) − function for sorting criterion.
  • reverse (optional) − boolean for descending/ascending order.

Example

numbers = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5]
sorted_numbers_desc = sorted(numbers, reverse=True)
print(sorted_numbers_desc)

Output: [9, 6, 5, 5, 5, 4, 3, 3, 2, 1, 1]

Sorting List Items with Callback Function

We can pass a callback function using the key parameter in sort() or sorted(). This function defines how elements are compared.

Example Using str.lower()

list1 = ['Physics', 'biology', 'Biomechanics', 'psychology']
print("list before sort", list1)
list1.sort(key=str.lower)
print("list after sort:", list1)

Output: ['biology', 'Biomechanics', 'Physics', 'psychology']

Example Using User-defined Function

def myfunction(x):
   return x % 10

list1 = [17, 23, 46, 51, 90]
print("list before sort", list1)
list1.sort(key=myfunction)
print("list after sort:", list1)

Output: [90, 51, 23, 46, 17]

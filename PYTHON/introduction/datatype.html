Python - Data Types

Python data types are actually classes, and the defined variables are their instances or objects. Since Python is dynamically typed, the data type of a variable is determined at runtime based on the assigned value.

Data types define the type of a variable and determine what operations can be performed on it. Each programming language classifies data differently, but in Python we have a rich set of built-in types.

Types of Data Types in Python

  • Numeric Data Types (int, float, complex)
  • String Data Type
  • Sequence Data Types (list, tuple, range)
  • Binary Data Types (bytes, bytearray, memoryview)
  • Dictionary Data Type
  • Set Data Type (set, frozenset)
  • Boolean Data Type
  • None Type

1. Numeric Data Types

Numbers in Python include integers, floats, and complex numbers.

Example

a = 100
print(type(a))   # int

c = 20.345
print(type(c))   # float

d = 10+3j
print(type(d))   # complex

2. String Data Type

A string is a sequence of Unicode characters enclosed in single, double, or triple quotes. Strings are immutable in Python.

Example

str = "Hello World!"
print(str)
print(str[0])
print(str[2:5])
print(str * 2)
print(str + "TEST")

3. Sequence Data Types

Sequences are ordered collections such as list, tuple, and range.

(a) List

list1 = ['abcd', 786, 2.23, 'john']
print(list1[0])
print(list1[1:3])

(b) Tuple

tuple1 = ('abcd', 786, 2.23, 'john')
print(tuple1[0])
print(tuple1[1:3])

(c) Range

for i in range(1, 5, 2):
    print(i)

4. Binary Data Types

Python provides bytes, bytearray, and memoryview for binary handling.

b1 = bytes([65, 66, 67])
print(b1)

value = bytearray([72, 101, 108])
print(value)

data = bytearray(b'Hello')
view = memoryview(data)
print(view)

5. Dictionary Data Type

Dictionaries store key-value pairs.

dict1 = {'name': 'john', 'code': 6734}
print(dict1['name'])
print(dict1.keys())
print(dict1.values())

6. Set Data Type

A set is an unordered collection of unique elements.

set1 = {123, 452, 5, 6}
print(set1)

7. Boolean Data Type

Booleans represent truth values: True or False.

a = True
print(a)
print(type(a))

8. None Type

None represents the absence of a value.

x = None
print(x)
print(type(x))

Primitive vs Non-Primitive Data Types

  • Primitive: int, float, bool, string
  • Non-Primitive: list, tuple, dictionary, set

Data Type Conversion

Type casting is done using functions like int(), float(), str(), etc.

a = int(2.2)     # 2
b = float("3.3") # 3.3
c = str(10)      # "10"

JavaScript - DOM NodeList

DOM NodeList

The NodeLists are similar to an array or HTMLCollection containing the HTML elements. However, it is not the same as the array or HTML collection.

All modern browsers return the node list when you use querySelectorAll() method and childNodes properties. You can traverse the NodeList as an array but can't use other array methods like map(), filter(), etc, with node lists.

JavaScript DOM NodeList Methods

  • entries() − Retrieves an iterator that allows iterating through all key/value pairs in the object.
  • forEach() − Calls the callback function once for each value pair in the list in the order of their insertion.
  • item() − Retrieves a node from the NodeList specified by the index in the parameter.
  • keys() − Retrieves an iterator that allows us to go through all the keys contained in the NodeList.

JavaScript DOM NodeList Properties

  • length − Returns the number of items in the NodeList.

Example 1: Retrieving a specific element from a NodeList

This example uses querySelectorAll() to select all p elements as a NodeList and retrieves the third element:

<!DOCTYPE html>
<html lang="en">
<head>
    <title>JavaScript DOM NodeList</title>
</head>
<body>
    <div>
        <p>This is first paragraph.</p>
        <p>This is second paragraph.</p>
        <p>This is third paragraph.</p>
        <p>This is fourth paragraph.</p>
    </div>
    <script>
        let myNodeList = document.querySelectorAll('p');
        alert("This is third P: " + myNodeList[2].innerHTML);
    </script>
</body>
</html>

Example 2: Adding Style to NodeList (div) element

In this example, getElementsByTagName('div') returns all div elements as a NodeList, and styles are applied:

<!DOCTYPE html>
<html lang="en">
<head>
    <title>JavaScript DOM NodeList</title>
</head>
<body>
    <p>Click the button below to add style to all "div" elements.</p>
   <div>Div 1</div>
   <div>Div 2</div>
   <div>Div 3</div>
   <div>Div 4</div>
   <div>Div 5</div>
   <button id="btn">Add style</button>
   <script>
   document.getElementById('btn').addEventListener("click", ()=>{
      let myNodeList = document.getElementsByTagName('div');
      for(let i = 0; i<myNodeList.length; i++){
          myNodeList[i].style.color = 'white';
          myNodeList[i].style.padding = "10px";
          myNodeList[i].style.margin = "5px";
          myNodeList[i].style.border = "1px solid black";
          myNodeList[i].style.backgroundColor = "green";
      }
   });
    </script>
</body>
</html>

Example 3: Using the forEach() method to traverse the NodeList elements

Here, querySelectorAll('.lang') selects all elements with the class lang and uses forEach() to iterate:

<!DOCTYPE html>
<html>
<body>
   <p class="lang"> English </p>
   <p class="lang"> German </p>
   <p class="lang"> Arabic </p>
   <p class="lang"> Hindi </p> <br>
   <div id="output"> </div>
   <script>
      const output = document.getElementById('output');
      output.innerHTML += "All languages are: <br>";
      const langs = document.querySelectorAll('.lang');
      langs.forEach((language) => {
         output.innerHTML += language.innerHTML + '<br>';
      })
   </script>
</body>
</html>

Example 4: Retrieving the length of the NodeList

This example uses the length property of NodeList to count the number of nodes:

<!DOCTYPE html>
<html>
<body>
   <div class="fruit"> Apple </div>
   <div class="fruit"> Orange </div>
   <div class="fruit"> Banana </div>
   <div class="fruit"> Mango </div>
   <div id="output">Total number of fruits are : </div>
   <script>
      const fruits = document.querySelectorAll('.fruit');
      document.getElementById('output').innerHTML += fruits.length;
   </script>
</body>
</html>

Difference between HTMLCollection and NodeList

  • Return by − HTMLCollection is generally returned by getElementsByClassName(), getElementsByTagName(), and children. NodeList is generally returned by querySelectorAll() and childNodes.
  • Array methods − HTMLCollection supports limited array methods. NodeList also supports limited array methods like forEach().
  • Live collection − Some browsers support live collection with HTMLCollection. NodeList updates if you update the DOM element.

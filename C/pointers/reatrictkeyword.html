Restrict Keyword in C

The restrict keyword, introduced in the C99 standard, is a type qualifier used with pointers. It tells the compiler that the pointer is the only way to access the memory it points to during its lifetime. This allows the compiler to optimize code by assuming no other pointer will access the same memory.

Syntax for Declaring a Restrict Pointer

The general syntax is:

type* restrict pointer_name;

  • type — the data type of the pointer (e.g., int, char).
  • restrict — the qualifier indicating exclusive access.
  • pointer_name — the variable name of the pointer.

Example: Using restrict to Update Variables

#include <stdio.h>

void update(int *restrict x, int *restrict y) {
   *x = *x + 10;
   *y = *y + 20;
}

int main() {
   int a = 5, b = 10;
   update(&a, &b);
   printf("a = %d, b = %d\n", a, b);
   return 0;
}

Output: a = 15, b = 30

Why Use restrict?

Even though programs produce the same output with or without restrict, using it allows the compiler to optimize memory access safely by knowing pointers don't overlap. This can lead to faster code execution especially in large, performance-critical applications such as scientific computing and graphics.

Example: Adding Elements of Two Arrays

#include <stdio.h>

void add(int *restrict a, int *restrict b, int *restrict r, int n) {
    for (int i = 0; i < n; i++)
        r[i] = a[i] + b[i];
}

int main() {
    int a[] = {1,2,3,4,5};
    int b[] = {5,6,7,8,10};
    int r[5];
    add(a, b, r, 5);
    for (int i = 0; i < 5; i++)
        printf("%d ", r[i]);
    return 0;
}

Output: 6 8 10 12 15

Usage Notes

  • The restrict keyword tells the compiler no other pointers access the same memory.
  • It enables optimizations such as instruction re-ordering, vectorization, and parallel execution.
  • Misusing restrict (allowing overlapping pointers) leads to undefined behavior and potential logic errors.
  • It is particularly useful when working with large data sets or performance-critical code.

Conclusion

The restrict keyword is a powerful tool in C to help compilers generate faster, optimized code by informing them about exclusive memory access through a pointer.

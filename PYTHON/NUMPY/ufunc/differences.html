NumPy Differences

A discrete difference means subtracting two successive elements in an array.

Example: For [1, 2, 3, 4], the discrete difference is [2-1, 3-2, 4-3] = [1, 1, 1].

To compute this, use the np.diff() function.

Example 1: Basic discrete difference

Compute the discrete difference of the following array:

import numpy as np

arr = np.array([10, 15, 25, 5])

newarr = np.diff(arr)

print(newarr)

Output:

[5 10 -20]

Explanation:

  • 15 - 10 = 5
  • 25 - 15 = 10
  • 5 - 25 = -20

Example 2: Repeated discrete difference (using n parameter)

You can perform the discrete difference operation multiple times by specifying the parameter n.

For example, for [1, 2, 3, 4] with n=2, the first difference is [1, 1, 1], then the difference of that is [1-1, 1-1] = [0, 0].

import numpy as np

arr = np.array([10, 15, 25, 5])

newarr = np.diff(arr, n=2)

print(newarr)

Output:

[5 -30]

Explanation:

  • First difference: [15-10, 25-15, 5-25] = [5, 10, -20]
  • Second difference: [10-5, -20-10] = [5, -30]

C - Constants

A constant in C is a user-assigned name to a memory location whose value cannot be modified once declared. In contrast, a variable can have its value changed during the execution of a program.

Constants are useful when the same value is used repeatedly in the program, especially if the value is error-prone or should not be altered. For example, the mathematical constant PI can be declared once and reused.

In essence, a constant is like a read-only variable.

Ways to Declare Constants

  • Using the const keyword
  • Using the #define directive

Defining a Constant Using the const Keyword

The syntax of declaring a constant is:

const type NAME = value;

Example:

#include <stdio.h>

int main(){
   const float PI = 3.14159265359;
   float radius = 5;
   float area = PI * radius * radius;
   printf("area: %f", area);
   return 0;
}

Output:

area: 78.539818

Prohibited Changes

Once declared, trying to change the value of a constant results in a compile-time error.

const float PI = 3.14159265359;
PI = 22 / 7;  // Error: assignment of read-only variable 'PI'

Also, declaring a constant without initialization and assigning later will result in an error:

const float PI;
PI = 3.14159265359;  // Error: assignment of read-only variable 'PI'

Therefore, a constant must be declared and initialized at the same time.

Defining a Constant Using #define Directive

The #define directive creates symbolic constants or macros, without specifying a data type. Its syntax is:

#define NAME VALUE

Example:

#include <stdio.h>
#define LENGTH 10
#define WIDTH 5
#define NEWLINE '\n'

int main() {
   int area;
   area = LENGTH * WIDTH;
   printf("length: %d width: %d", LENGTH, WIDTH);
   printf("%c", NEWLINE);
   printf("value of area : %d", area);
   return 0;
}

Output:

length: 10 width: 5
value of area : 50

Naming Convention

Constants are case-sensitive and follow the rules of identifiers. By convention, constants are written in uppercase, though it is not mandatory.

Changing the Value of a Constant (Using Pointers)

By definition, constants are immutable. However, using pointers, it is technically possible to change the value of a constant (not recommended in practice).

#include <stdio.h>

int main(){
   const int x = 10;
   printf("Initial Value of Constant: %d\n", x);

   int* y = &x;
   *y = 100;
   printf("Value of Constant after change: %d", x);
   return 0;
}

Output:

Initial Value of Constant: 10
Value of Constant after change: 100

This only works for constants declared using the const keyword. It does not apply to constants defined with #define, as they are handled by the preprocessor and do not have an address in memory.

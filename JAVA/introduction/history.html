Java - History

The Java programming language was originally developed by Sun Microsystems, initiated by James Gosling, and released in 1995 as a core component of Sun's Java platform (Java 1.0 [J2SE]). Even the naming history of Java is quite interesting as it went through multiple names.

Java Name History

GreenTalk

James Gosling led a team named the 'Green' team whose goal was to create a language that worked seamlessly on multiple electronic devices. C++ was initially considered, but due to high memory usage, the idea was rejected. The team started a new language called GreenTalk with the extension .gt. Later, it was renamed to Oak, and finally to Java.

Oak

The language was renamed to Oak after a tree outside Gosling’s office. Oak symbolized strength and was the national tree of countries like the USA, France, and Romania. However, Oak Technologies already had the trademark, so a new name was needed.

Finally Java

The team considered several names like DNA, Silk, Ruby, and Java. Java was inspired by an espresso coffee bean from the island of Java in Indonesia. It was selected because it sounded dynamic, revolutionary, and fun to say.

Sun released the first public implementation as Java 1.0 in 1995 with the promise of Write Once, Run Anywhere (WORA). It allowed no-cost runtimes on popular platforms.

On 13 November 2006, Sun released much of Java under the GNU General Public License (GPL) as free and open-source software. By 8 May 2007, the entire Java core was made open-source, except for a small portion Sun did not own.

With Java's popularity, different configurations were built for various platforms: J2EE for Enterprise Applications, J2ME for Mobile Applications. These were later renamed to Java EE, Java ME, and Java SE.

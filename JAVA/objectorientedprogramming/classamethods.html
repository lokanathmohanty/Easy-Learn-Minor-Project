Java - Class Methods

Class methods in Java are functions declared inside a class that define behaviors or actions the class can perform. They can access or modify class attributes.

Creating (Declaring) Java Class Methods

Syntax:

public class ClassName {
  modifier returnType methodName(Parameter List) {
    // method body
  }
}
  • modifier: (optional) access level (e.g., public)
  • returnType: type of value the method returns
  • methodName: name of the method
  • Parameter List: optional list of input values

Example:

class Util {
  public int minimum(int n1, int n2) {
    if (n1 > n2)
      return n2;
    else
      return n1;
  }
}

Accessing Java Class Methods

To access a public class method, create an object and use the dot . operator.

object_name.method_name(parameters);

Example:

package com.tutorialspoint;

class Util {
  public int minimum(int n1, int n2) {
    return (n1 > n2) ? n2 : n1;
  }
}

public class Tester {
  public static void main(String[] args) {
    Util util = new Util();
    int result = util.minimum(11, 6);
    System.out.println("Minimum Value = " + result);
  }
}

Output:

  • Minimum Value = 6

Using this Keyword in Class Methods

this is a reference to the current object. It is used to:

  • Differentiate between local and instance variables
  • Invoke one constructor from another
class Student {
  int age;
  Student(int age) {
    this.age = age;  // refers to instance variable
  }
}

Constructor Chaining:

class Student {
  int age;
  Student() {
    this(20);  // calls the parameterized constructor
  }
  Student(int age) {
    this.age = age;
  }
}

Example: Full Program Using this

package com.tutorialspoint;

public class Tester {
  int num = 10;

  Tester() {
    System.out.println("This is an example program on keyword this");
  }

  Tester(int num) {
    this(); // call default constructor
    this.num = num;
  }

  public void greet() {
    System.out.println("Hi Welcome to Tutorialspoint");
  }

  public void print() {
    int num = 20;
    System.out.println("value of local variable num is : " + num);
    System.out.println("value of instance variable num is : " + this.num);
    this.greet();
  }

  public static void main(String[] args) {
    Tester obj1 = new Tester();
    obj1.print();

    Tester obj2 = new Tester(30);
    obj2.print();
  }
}

Output:

  • This is an example program on keyword this
  • value of local variable num is : 20
  • value of instance variable num is : 10
  • Hi Welcome to Tutorialspoint
  • This is an example program on keyword this
  • value of local variable num is : 20
  • value of instance variable num is : 30
  • Hi Welcome to Tutorialspoint

Public vs Static Class Methods

  • Public Methods: Accessed through object instances
  • Static Methods: Accessed directly via class, no object needed
public class Main {
  static void fun1() {
    System.out.println("fun1: This is a static method.");
  }

  public void fun2() {
    System.out.println("fun2: This is a public method.");
  }

  public static void main(String[] args) {
    fun1(); // static method call

    Main obj = new Main();
    obj.fun2(); // public method call
  }
}

Output:

  • fun1: This is a static method.
  • fun2: This is a public method.

The finalize() Method

The finalize() method is called just before an object is garbage collected. It is useful for cleanup operations like closing files or releasing resources.

Syntax:

protected void finalize() {
  // cleanup code here
}

Note: You cannot rely on finalize() to always be executed. If the program ends before GC runs, it won't be called.

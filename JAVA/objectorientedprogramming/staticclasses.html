Java Programming: Nested Class Types

Session: Static Nested Classes

Concept of Static Classes in Java

In Java, the **static** keyword can only be applied to **nested classes** (classes defined inside another class). An **Outer Class** cannot be declared static.

A **Static Nested Class** is essentially a static member of the outer class, similar to a static variable or method. It is the official term for what is often loosely referred to as a "static class."

Key Features of Static Nested Classes

Static nested classes are fundamentally different from non-static inner classes because they:

  • **No Outer Instance Dependency:** They **do not** require an instance of the outer class to be created. You can instantiate them directly using the outer class name.
  • **Access Restriction:** They **cannot** access the non-static (instance) members (variables or methods) of the outer class. They can only access the **static** members of the outer class.
  • **Scope:** They are members of the outer class's namespace, accessible via the outer class name.

Syntax:

class MyOuter {
   static class Nested_Demo {
      // Class definition...
   }
}

Instantiation and Access

Since a static nested class doesn't depend on an outer object, its instantiation syntax is similar to calling a static member, but with the new keyword:

1. Accessing Static Members Directly (If within the Outer Class)

If the calling code (like main) is part of the outer class, the nested class can be accessed directly:

public class Outer {
   static class NestedDemo {
      public static void print() { ... }
   }
   public static void main(String args[]) {
      NestedDemo.print(); // Direct call
   }
}

2. Accessing from External Classes (Static Context)

Use the outer class name to scope the access:

public class Tester {
   public static void main(String[] arguments) {
	   Outer.NestedDemo.print(); // Scoped call via Outer class
   }
}

3. Instantiating to Call Instance Methods (If within External Classes)

If the static nested class has instance methods, you must instantiate it, still using the outer class name for scope:

public class Tester {
   public static void main(String[] arguments) {
	   // Instantiation: Outer.NestedDemo object = new Outer.NestedDemo();
	   new Outer.NestedDemo().print();
   }
}

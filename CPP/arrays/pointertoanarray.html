C++ Pointer to an Array (Array Name Decay) ⭐

In C++, the **name of an array** acts as a **constant pointer** to its **first element** (index 0). This relationship between arrays and pointers is fundamental to C++ memory access and operation.

Array Name as a Pointer

When you declare an array like double balance[50];, the identifier balance is synonymous with the **address of the first element** (&balance[0]).

double balance[10];
double *p;

// 'balance' decays to a pointer to the first element
p = balance; 
// p now holds the address of balance[0]

Accessing Array Elements via Pointers

Because the array name acts as a pointer, you can access any element using standard **pointer arithmetic** and the **dereference operator** (`*`).

Pointer Arithmetic

The expression *(p + i) is a legitimate and common way to access the element at index `i` of the array, and it is entirely equivalent to balance[i].

  • *(p + 0) is equivalent to balance[0]
  • *(p + 4) is equivalent to balance[4]

The compiler automatically handles the memory address calculation: it adds $i \times (\text{size of data type})$ to the starting address `p` before dereferencing.

double balance[5] = {1000.0, 2.0, 3.4, 17.0, 50.0};
double *p = balance; 

// Accessing the element at index 2 (value 3.4)
double value_ptr = *(p + 2); 
double value_arr = balance[2]; 
// Both expressions yield the same result.

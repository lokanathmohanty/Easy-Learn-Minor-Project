Relational Operators in C

Relational operators in C are used to compare two values. They are typically used in Boolean expressions and control flow statements like if, while, and for.

All relational operations return either:

  • 0 → False
  • 1 (or any non-zero value) → True

Note: C does not have a Boolean type by default, so it uses integers (0 = false, non-zero = true).

Relational Operators Table

Operator Description Example
==Equal to(A == B)
!=Not equal to(A != B)
>Greater than(A > B)
<Less than(A < B)
>=Greater than or equal to(A >= B)
<=Less than or equal to(A <= B)

All relational operators are binary operators and require two operands.

Example 1: Simple Comparison

#include <stdio.h>

int main(){
   int op1 = 5;
   int op2 = 3;

   printf("op1: %d op2: %d op1 < op2: %d\n", op1, op2, op1 < op2);
   return 0;
}

Output:

op1: 5 op2: 3 op1 < op2: 0

Example 2: Using All Relational Operators

#include <stdio.h>

int main(){
   int a = 21;
   int b = 10;

   printf("a: %d b: %d\n", a, b);

   if(a == b)
      printf("Line 1 - a is equal to b\n");
   else
      printf("Line 1 - a is not equal to b\n");

   if (a < b)
      printf("Line 2 - a is less than b\n");
   else
      printf("Line 2 - a is not less than b\n");

   if (a > b)
      printf("Line 3 - a is greater than b\n");
   else
      printf("Line 3 - a is not greater than b\n");

   // Change values
   a = 5;
   b = 20;

   printf("\na: %d b: %d\n", a, b);

   if (a <= b)
      printf("Line 4 - a is either less than or equal to b\n");

   if (b >= a)
      printf("Line 5 - b is either greater than or equal to a\n");

   if(a != b)
      printf("Line 6 - a is not equal to b\n");
   else
      printf("Line 6 - a is equal to b\n");

   return 0;
}

Output:

a: 21 b: 10
Line 1 - a is not equal to b
Line 2 - a is not less than b
Line 3 - a is greater than b

a: 5 b: 20
Line 4 - a is either less than or equal to b
Line 5 - b is either greater than or equal to a
Line 6 - a is not equal to b

Example 3: Common Mistake Using = Instead of ==

#include <stdio.h>

int main(){
   int a = 5;
   int b = 3;

   if (a = b)  // Mistake: should be == not =
      printf("a is equal to b");
   else
      printf("a is not equal to b");

   return 0;
}

Output:

a is equal to b

Explanation: a = b assigns 3 to a, which is non-zero. Hence, the condition evaluates as true.

Example 4: Relational Operators with char

#include <stdio.h>

int main(){
   char a = 'B';
   char b = 'd';

   printf("a: %c b: %c\n", a, b);

   if(a == b)
      printf("Line 1 - a is equal to b\n");
   else
      printf("Line 1 - a is not equal to b\n");

   if (a < b)
      printf("Line 2 - a is less than b\n");
   else
      printf("Line 2 - a is not less than b\n");

   if (a > b)
      printf("Line 3 - a is greater than b\n");
   else
      printf("Line 3 - a is not greater than b\n");

   if(a != b)
      printf("Line 4 - a is not equal to b\n");
   else
      printf("Line 4 - a is equal to b\n");

   return 0;
}

Output:

a: B b: d
Line 1 - a is not equal to b
Line 2 - a is less than b
Line 3 - a is not greater than b
Line 4 - a is not equal to b

Note: Characters are compared based on their ASCII values.

Important Notes

  • Relational operators cannot be used to compare arrays or structures directly.
  • Always double-check your usage of = vs == in conditionals.
  • You can use relational operators with char because it is internally treated as an integer type.

C++ Socket Programming (Network Communication) 🔌

**C++ Socket Programming** is the method of establishing communication endpoints (**sockets**) on a network, enabling data exchange between applications using protocols like **TCP** and **UDP**. Sockets are the foundation of most internet communication.

Types of Sockets

  • **Stream Sockets (TCP)**: Provides **reliable, connection-oriented** communication. Data is sent as a continuous stream, guaranteeing order and delivery.
  • **Datagram Sockets (UDP)**: Provides **connectionless** communication. Data is sent in independent packets, offering speed but **no guarantee of order or delivery**.

Server-Side Socket Steps (Listening for Connections)

A server uses a sequence of system calls to listen for and accept incoming client connections. This process is connection-oriented (TCP).

  1. **socket()**: Creates a new socket file descriptor. 
    int sockfd = socket(AF_INET, SOCK_STREAM, 0);

    Uses `AF_INET` (IPv4) and `SOCK_STREAM` (TCP).

  2. **bind()**: Associates the created socket with a specific **local IP address** and **port number**. 
    bind(sockfd, (struct sockaddr*)&address, sizeof(address));
  3. **listen()**: Marks the socket as passive, preparing it to accept connections. The backlog parameter sets the maximum queue size for pending connections. 
    listen(sockfd, 3); // 3 is the backlog
  4. **accept()**: Extracts the first connection request from the queue, creates a **new socket descriptor** for that specific client, and blocks until a client connects. 
    int clientSocket = accept(sockfd, (struct sockaddr*)&clientAddress, &clientLen);

Client-Side Socket Steps (Connecting to a Server)

A client initiates communication by connecting to the server's specific IP and port.

  1. **socket()**: Creates a new socket file descriptor (same as the server).
  2. **connect()**: Attempts to establish a connection to the specified server address and port. 
    connect(sockfd, (struct sockaddr*)&serverAddress, sizeof(serverAddress));

Data Exchange and Cleanup

Sending and Receiving Data

Once a connection is established (or immediately for UDP), data is exchanged using the following functions:

  • **send()**: Sends data to the connected socket. 
    send(sockfd, data_ptr, data_len, 0);
  • **recv()** (or `read()`): Receives data from the connected socket and stores it in a buffer. 
    recv(sockfd, buffer, sizeof(buffer), 0);

Closing the Socket

The **close()** method (or `closesocket()` on Windows) is a system call used to close the file descriptor associated with the socket, releasing its resources.

close(sockfd);

Required Header Files

Socket programming typically requires platform-specific headers. The provided examples for Unix/Linux require:

  • `<sys/socket.h>` (Core socket functions like `socket`, `bind`, `connect`)
  • `<netinet/in.h>` (Internet address structures like `sockaddr_in`)
  • `<arpa/inet.h>` (Functions to convert addresses, like `inet_pton`)
  • `<unistd.h>` (Standard functions like `close`, `read`)

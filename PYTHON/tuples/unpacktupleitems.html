Python - Unpack Tuple Items

The term "unpacking" refers to the process of parsing tuple items into individual variables. In Python, parentheses are the default delimiters for tuple literals.

The following statements to declare a tuple are equivalent:

>> t1 = (x, y)
>>> t1 = x, y
>>> type(t1)
<class 'tuple'>

Example

To store tuple items in individual variables, use multiple variables on the left side of the assignment operator:

tup1 = (10, 20, 30)
x, y, z = tup1
print("x:", x, "y:", y, "z:", z)

Output:

x: 10 y: 20 z: 30

ValueError While Unpacking a Tuple

If the number of variables is more or less than the length of the tuple, Python raises a ValueError.

tup1 = (10, 20, 30)
x, y = tup1             # Raises ValueError: too many values to unpack (expected 2)
x, y, p, q = tup1       # Raises ValueError: not enough values to unpack (expected 4, got 3)

Unpack Tuple Items Using Asterisk (*)

Use the "*" symbol to collect multiple items into a list when the number of variables does not match the number of tuple items.

Example 1

tup1 = (10, 20, 30)
x, *y = tup1
print("x:", x, "y:", y)

Output:

x: y: [20, 30]

The first value is assigned to x and the rest to y as a list.

Example 2

tup1 = (10, 20, 30, 40, 50, 60)
x, *y, z = tup1
print("x:", x, "y:", y, "z:", z)

Output:

x: 10 y: [20, 30, 40, 50] z: 60

Values are assigned to x and z first, and the middle values become the list y.

Example 3

tup1 = (10, 20, 30, 40, 50, 60)
*x, y, z = tup1
print("x:", x, "y:", y, "z:", z)

Output:

x: [10, 20, 30, 40] y: 50 z: 60

The tuple is unpacked so that x receives the first values as a list, while y and z take the last two values individually.

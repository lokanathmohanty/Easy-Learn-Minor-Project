C++ Files and Streams (FStream Library) 📂✍️

C++ uses the **<fstream>** standard library to handle file input/output operations. This library defines stream classes that link a program to physical files on disk, allowing information to be read from or written to them.

Core File Stream Data Types

These classes manage the connection between your program and the file:

  • **ofstream**: **Output file stream** (used for **writing** to a file).
  • **ifstream**: **Input file stream** (used for **reading** from a file).
  • **fstream**: General **file stream** (capabilities for both **reading and writing**).

File Operations: Opening and Closing

Opening a File (open())

Before any I/O operation, a file object must be linked to a file using the open() member function, which specifies the file name and the operating mode:

void open(const char *filename, ios::openmode mode);

Common Mode Flags (using ios::openmode)

Mode FlagDescriptionUsage Example
**ios::out**Open for writing.ofstream file; file.open("data.txt", ios::out);
**ios::in**Open for reading.ifstream file; file.open("data.txt", ios::in);
**ios::app**Append mode. Output is added to the end.ios::out | ios::app
**ios::trunc**Truncate file content (erase everything) if it exists.Used with ios::out by default.
**Combine Modes**Use the bitwise OR operator (|).fstream file.open("rw.dat", ios::out | ios::in);

Closing a File (close())

It's best practice to explicitly close the file stream when done, releasing system resources:

outfile.close();
infile.close();

Reading and Writing Data

I/O operations on file streams mirror standard I/O (cin and cout) but use the stream object instead.

  • **Writing to a File:** Use the **stream insertion operator** (<<) with an ofstream or fstream object. 
    outfile << data << endl; // Writes 'data' to the file
  • **Reading from a File:** Use the **stream extraction operator** (>>) with an ifstream or fstream object. 
    infile >> data; // Reads data from the file into the variable

File Position Pointers

File streams maintain internal pointers to track the current position for reading and writing. These can be manually repositioned:

  • **seekg()**: Sets the position of the **get** (read) pointer (for istream/ifstream).
  • **seekp()**: Sets the position of the **put** (write) pointer (for ostream/ofstream).

These functions take an offset (long integer) and an optional direction constant:

// Position the read pointer 10 bytes from the start (ios::beg)
fileObject.seekg( 10 ); 

// Position the write pointer 5 bytes back from the current position
fileObject.seekp( -5, ios::cur ); 

// Position the read pointer at the very end of the file
fileObject.seekg( 0, ios::end );

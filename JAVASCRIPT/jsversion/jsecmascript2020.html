JavaScript - ECMAScript 2020

The ECMAScript 2020 version of JavaScript was released in 2020. Notable features added in this version include the nullish coalescing operator (??) for more concise default value assignment and dynamic import() for on-demand module loading. BigInt provides a way to safely work with very large integers. This chapter will discuss all the newly added features in ECMAScript 2020.

Features Added in ECMAScript 2020

  • BigInt
  • Promise.allSettled()
  • String.matchAll()
  • The Nullish Coalescing Operator (??)
  • The Optional Chaining Operator (?.)

BigInt Primitive DataType

The ECMAScript 2020 introduced BigInt to the primitive data types. You can use the BigInt when you need to store a large number, which cannot be represented using the 64-bit representation. To convert the number into BigInt, write the number followed by n.

Example


const bigNum = 1325461651565143545565n;
console.log(bigNum);

Output: The number of bigint type is: 1325461651565143545565

The Nullish Coalescing Operator (??)

The JavaScript nullish coalescing operator returns the left operand if it is not undefined or null. Otherwise, it returns the right operand. It is used to set default values to variables.

Example


let str = undefined ?? "Hello";
console.log(str);

Output: The value of the str is: Hello

Promise.allSettled() Method

The Promise.allSettled() method returns the status of all promises once all promises have been fulfilled or rejected.

Example


const promises = [
  Promise.resolve("Hello"),
  Promise.reject("Error message"),
  Promise.resolve(21342)
];

Promise.allSettled(promises).then(results => {
  console.log(results);
});

Output:


[
  {"status":"fulfilled","value":"Hello"},
  {"status":"rejected","reason":"Error message"},
  {"status":"fulfilled","value":21342}
]

The String.matchAll() Method

The String.matchAll() method matches all occurrences of a substring. It takes a string or regular expression as a parameter and returns an iterator of matches.

Example


let str = "Abcd abcd abcd";
let matches = str.matchAll('abcd');
for (let x of matches) {
  console.log(x[0]);
}

Output:


abcd
abcd

The Optional Chaining Operator (?.)

The optional chaining operator is used to access nested object properties. If any nested object is undefined, it returns undefined instead of throwing an error.

Example


let obj = {
  obj1: {
    name: "JavaScript",
  }
};

console.log(obj?.obj2?.name);

Output: The name of obj2 is: undefined

Warning: Some of the above features are not supported by older browsers. Use a polyfill to avoid errors.

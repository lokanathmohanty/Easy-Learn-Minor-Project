R - Excel File

Microsoft Excel is a popular spreadsheet program that stores data in .xls or .xlsx formats. R can read data directly from these files using specific packages such as XLConnect, xlsx, and gdata. The xlsx package will be demonstrated here, which also supports writing to Excel files.

Install xlsx Package

# Install the xlsx package in R console
install.packages("xlsx")

Installing the package may prompt to install additional dependencies as well.

Verify and Load the xlsx Package

# Verify that package is installed
any(grepl("xlsx", installed.packages()))

# Load the package into the R workspace
library("xlsx")

Output example when loaded:

[1] TRUE
Loading required package: rJava
Loading required package: methods
Loading required package: xlsxjars

Input as xlsx File

Create an Excel file named input.xlsx with two worksheets:

  • sheet1 with columns: id, name, salary, start_date, dept, and respective rows of sample data.
  • city with columns: name, city mapping names to cities.

Reading the Excel File

# Read the first sheet from input.xlsx file
data <- read.xlsx("input.xlsx", sheetIndex = 1)
print(data)

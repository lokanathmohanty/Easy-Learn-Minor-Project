Assignment Operators in C

In C language, the assignment operator stores a value in an already declared variable. The variable to the left of the = symbol is assigned the value of the right-hand operand, which can be a literal, another variable, or an expression.

Besides the simple assignment operator, C supports several augmented assignment operators combining arithmetic or bitwise operations with assignment for convenience.

Assignment Operators

  • = : Simple assignment. Example: C = A + B
  • += : Add and assign. C += A is equivalent to C = C + A
  • -= : Subtract and assign. C -= A is equivalent to C = C - A
  • *= : Multiply and assign. C *= A is equivalent to C = C * A
  • /= : Divide and assign. C /= A is equivalent to C = C / A
  • %= : Modulus and assign. C %= A is equivalent to C = C % A
  • <<= : Left shift and assign. C <<= 2 equivalent to C = C << 2
  • >>= : Right shift and assign. C >>= 2 equivalent to C = C >> 2
  • &= : Bitwise AND and assign. C &= 2 equivalent to C = C & 2
  • ^= : Bitwise XOR and assign. C ^= 2 equivalent to C = C ^ 2
  • |= : Bitwise OR and assign. C |= 2 equivalent to C = C | 2

Simple Assignment

Variables must be declared before use and assigned values either at declaration or later.

Example:

int x = 10;      // declaration with initialization
int y;            // declaration
y = 20;           // assignment later
int z = x + y;    // assign expression
char c = 'x';     // char assignment

Variables must be of compatible types; type mismatch causes compile errors.

Augmented Assignment Operators

These combine an arithmetic or bitwise operation with assignment in one step.

Example 1:

#include <stdio.h>

int main(){
   int a = 10;
   int b = 20;

   a += b;
   printf("a: %d", a);

   return 0;
}

Output:

a: 30

Example 2:

#include <stdio.h>

int main(){
   int a = 60;
   int b = 2;

   a <<= b;
   printf("a: %d", a);

   return 0;
}

Output:

a: 240

Comprehensive Demo

   c -= a;
   printf("Line 3 - -= Operator Example, Value of c = %d\n", c);

   c *= a;
   printf("Line 4 - *= Operator Example, Value of c = %d\n", c);

   c /= a;
   printf("Line 5 - /= Operator Example, Value of c = %d\n", c);

   c = 200;
   c %= a;
   printf("Line 6 - %%= Operator Example, Value of c = %d\n", c);

   c <<= 2;
   printf("Line 7 - <<= Operator Example, Value of c = %d\n", c);

   c >>= 2;

   c &= 2;

   c ^= 2;
   printf("Line 10 - ^= Operator Example, Value of c = %d\n", c);

   c |= 2;

   return 0;
}

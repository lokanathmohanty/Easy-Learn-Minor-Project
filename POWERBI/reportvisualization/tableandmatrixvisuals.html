Power BI: Table and Matrix Visuals

Table visuals display data in a straightforward tabular format, while Matrix visuals extend tables by allowing rows, columns, and values, enabling pivot-like reports. Both support visualizing measures and filtering through drill-through.

Creating a Table Visual

  • Import the dataset (e.g., emi.xlsx) into Power BI Desktop.
  • Select the Table visual and expand it on the report canvas.
  • Add fields like Employee ID, Name, Designation, Salary, and Current_EMI to the Columns section.
  • Set summarization to "Don't summarize" for showing individual field values (especially for numerical fields).
  • Use Drill Through with a field like Age to filter the table by categories (e.g., employees aged 35).

Creating a Matrix Visual

  • Select the Matrix visual.
  • Add Employee ID to Rows, Name to Columns, and Current_EMI to Values.
  • The Matrix displays data pivoted by rows and columns, different from a simple table.
  • Use Drill Through with fields like Designation to filter employees by specific categories (e.g., Software Engineers).

Formatting the Matrix Visual

  • Style Presets: Choose styles like "Flashy rows" for alternating colorful rows.
  • Grid: Enable horizontal and vertical gridlines and customize their colors.
  • Borders: Set borders for the entire matrix or specific parts like column headers; customize border colors.
  • Options: Adjust row padding and global font size for clarity.
  • Values: Customize font style, size, text color, background color, and alternate row colors.
  • Column Headers: Style text and background colors for column headers.
  • Row Headers: Modify styling of row headers including text.
  • Subtotals: Toggle on or off column and row subtotals for readability.
  • Grand Totals: Customize font style, size, and background colors of column and row grand totals.
  • Cell Elements: Use conditional formatting (fx) to highlight cells, e.g., color background to highlight highest values.

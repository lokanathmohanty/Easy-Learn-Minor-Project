C++ Dynamic Memory (new and delete) 🧠

C++ program memory is primarily split into the **Stack** (for local variables and function calls) and the **Heap** (or "free store"). **Dynamic memory allocation** is the process of allocating memory from the **Heap** at **runtime**, which is necessary when the required memory size isn't known until the program is executing.

The new Operator (Allocation)

The **new** operator is used to dynamically allocate memory on the heap for a variable or object of a given data type. It returns the **address** of the newly allocated memory space.

Syntax

// Single variable
data-type* pointer = new data-type; 

double* pvalue = new double;

Unlike C's malloc(), the C++ new operator not only allocates memory but also **calls the constructor** for the object being created, which is vital for classes.

The delete Operator (Deallocation)

The **delete** operator is used to de-allocate (free up) memory that was previously allocated using the new operator. Releasing unused memory prevents **memory leaks**.

Syntax

// For a single variable/object
delete pointer; 

delete pvalue;

Dynamic Allocation for Arrays

When allocating an array, the syntax for new changes slightly to include the size, and the syntax for delete **must** use square brackets ([]) to ensure all elements in the array are properly destructed and de-allocated.

Syntax

// Allocate an array of 20 chars
char* pvalue = new char[20];       

// Deallocate the array (REQUIRED for arrays!)
delete [] pvalue;

If you allocate an array of objects (e.g., new Box[4]), using delete [] ensures the **destructor** is called for all four objects before the memory is released.

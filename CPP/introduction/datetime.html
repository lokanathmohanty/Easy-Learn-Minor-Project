C++ Date and Time (Using C-style <ctime>) 🕰️

The C++ Standard Library relies on the C-style date and time functions, which require including the **<ctime>** header file. These functions primarily deal with two representations of time: the raw calendar time (time_t) and a broken-down structure (struct tm).

Time Data Types and Structures

The key types used for time manipulation are:

  • time_t: An integral type capable of representing the system's calendar time, typically as the number of seconds elapsed since the **Epoch** (January 1, 1970).
  • struct tm: A structure that holds the date and time components (broken down) with the following fields:
    • tm_sec (seconds: 0-61)
    • tm_min (minutes: 0-59)
    • tm_hour (hours: 0-24)
    • tm_mday (day of month: 1-31)
    • tm_mon (month of year: 0-11)
    • tm_year (years since 1900)

Core Time Functions

A set of functions is available to convert between the time representations and formats:

  • time_t time(time_t *time): Returns the current calendar time as a time_t value (seconds since Epoch).
  • char *ctime(const time_t *time): Converts a time_t value to a standard, human-readable **local time string**.
  • struct tm *localtime(const time_t *time): Converts a time_t value to a tm structure, adjusted for the **local time zone**.
  • struct tm *gmtime(const time_t *time): Converts a time_t value to a tm structure, representing **Coordinated Universal Time (UTC)**.
  • char *asctime(const struct tm *time): Converts a tm structure to a standard, human-readable string.

Accessing Components via struct tm

To print individual date and time components (like year, month, day), you first convert the raw time into the struct tm format using localtime() or gmtime(). Note the offsets needed for the year and month:

time_t now = time(0); // Get raw time
tm *ltm = localtime(&now);

// tm_year is years since 1900
cout << "Year: " << 1900 + ltm->tm_year << endl; 

// tm_mon is months since January (0-11)
cout << "Month: " << 1 + ltm->tm_mon << endl;

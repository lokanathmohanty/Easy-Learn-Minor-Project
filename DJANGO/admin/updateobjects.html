Django Admin: Updating Model Objects (CRUD) ✏️

Once a custom model (like the **Employee model**) is registered with the Django Admin application, users with the correct permissions can easily perform **CRUD (Create, Read, Update, Delete)** operations on its data directly through the browser interface.

Accessing and Modifying Objects

  1. **Display the List:** On the Admin homepage, click the model name (e.g., **Employees** under the **MYAPP** section) to view the list of all existing objects.
  2. **Open the Object:** To update an object, simply **click on its row** in the list. This opens the **change form**, which displays all the object's attributes (fields).
  3. **Update and Save:** Modify the values for the desired fields (e.g., changing the Empname or Salary). Clicking the **SAVE** button executes the update operation, propagating the changes to the corresponding row in the backend database table.

The list of objects will then refresh, showing the newly updated details.

Important Limitation: Structure vs. Data

It's crucial to understand the limitation of the Admin interface:

  • **Data Changes (CRUD):** The Admin site is used to change the **data/content** of the objects (rows in the table).
  • **Structure Changes (Schema):** It is **not possible to change the structure** (the fields/columns) of the model from the Admin interface. To add, modify, or delete an attribute of a model, you must manually edit the model's **class definition** in models.py and then run Django's **migration commands** (makemigrations and migrate) to apply the structural changes to the database.

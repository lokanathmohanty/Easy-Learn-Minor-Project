CSS - Web Fonts

Font that is used in a website, but not installed by default on the user's device, is known as the web font. CSS allows to specify the font files, that are available on the web, to be easily downloaded along with your website when accessed.

CSS Web Fonts - Font Format Types

  • TrueType Fonts (TTF): Outline font developed by Apple. Most common font format for MacOS and Windows.
  • OpenType Fonts (OTF): Derived from TrueType with additional intricate data structures and more typographic control.
  • Web Open Font Format (WOFF): Developed by Mozilla, compressed format based on TrueType and OpenType with metadata support.
  • Web Open Font Format2 (WOFF2): Improved compression compared to WOFF.
  • SVG Fonts / Shapes: Based on OpenType, allows multi-color, transparency, and animation in characters.
  • Embedded Open Type Fonts (EOT): Compact form of OpenType developed by Microsoft, supported only by Internet Explorer.

CSS Web Fonts - Key Points

  • Web fonts are generally not free; licensing rules must be followed.
  • WOFF and WOFF2 formats are supported by most browsers.
  • WOFF2 supports variable, chromatic, and collection fonts.
  • Order of font listing is important, browser picks the first supported format.
  • Legacy browsers may require EOT, TTF, and SVG fonts.

CSS Web Fonts - @font-face At-Rule

The @font-face rule allows you to specify fonts not installed on the user’s device. Example syntax:

@font-face {
   font-family: "Sansation Light Font";
   src: url("font/SansationLight.woff") format("woff");
   font-weight: normal;
   font-style: normal;
}

Key descriptors:

  • font-family: Name used to reference the font in CSS.
  • src: Path to the font file, can include multiple formats.
  • font-weight: Specifies font thickness (e.g., 100–400).
  • font-style: Normal, italic, or oblique style.

Example: Using @font-face

@font-face {
   font-family: "Sansation Light Font";
   src: url("font/SansationLight.woff");
}
body {
   font-family: "Sansation Light Font", serif;
}

This applies the custom Sansation Light font to the webpage.

CSS Web Fonts - font-stretch

You can set stretch values for a font face, either as percentages or named values:

  • 50% → Condensed
  • 100% → Normal
  • 200% → Expanded
  • Named values include: semi-condensed, extra-condensed, ultra-condensed, semi-expanded, extra-expanded, ultra-expanded

CSS Web Fonts - Online Font Service

Many font services exist, often subscription-based. Google Fonts is free and easy to use:

  • Browse and select fonts.
  • Click the (+) button to add to your selection.
  • Copy the generated HTML link and place inside your <head>.
  • Apply the font using CSS font-family property.

CSS Web Fonts - Import Font

Example of importing Google Fonts:

<link href="https://fonts.googleapis.com/css?family=Lobster|Raleway" rel="stylesheet">

h1, h2 {
   font-family: 'Lobster', cursive;
}
p {
   font-family: 'Raleway', sans-serif;
}

This imports and applies the Lobster and Raleway fonts to headings and paragraphs.

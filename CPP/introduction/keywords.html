C++ Keywords Summary and Categorization

C++ keywords are **reserved words** with special meanings to the compiler. They are integral to the C++ syntax and cannot be used as identifiers (like variable or function names).

Basic Data Type Keywords

These define fundamental data types in C++:

  • int, char, float, double: Standard numeric and character types.
  • void: Indicates no value or type.
  • bool: Boolean data type (true or false).
  • wchar_t: Wide character type for internationalization.

Control Flow Keywords

Used for decision-making and repetitive tasks:

  • Conditional Statements: if, else, switch, case, default.
  • Looping Constructs: for, while, do.
  • Control Statements: break, continue, return, goto.

Storage Class Keywords & Modifiers

Control storage, duration, and properties of variables:

  • Storage Classes: auto (type deduction), register, static, extern, mutable.
  • Modifiers: const, volatile, signed, unsigned, short, long.

Object-Oriented & Function Keywords

Key to OOP and function definition:

  • Class Definitions: class, struct, union, enum.
  • Access Specifiers: public, protected, private.
  • Memory Management: new, delete.
  • Functions: inline, virtual, explicit.

Miscellaneous & Advanced Keywords

Keywords for error handling, scoping, and type manipulation:

  • Exception Handling: try, catch, throw.
  • Namespace Management: namespace, using.
  • Type Casting: static_cast, dynamic_cast, const_cast, reinterpret_cast.
  • Operators/Other: sizeof, typeid, decltype, typedef, this.

Keywords vs. Identifiers

Keywords are predefined and reserved by the language (e.g., int, while, class).

Identifiers are user-defined names for program elements (e.g., myVariable, calculateSum).

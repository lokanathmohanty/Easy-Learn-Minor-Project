Django Development Environment Setup 🛠️

A complete Django development environment requires setting up **Python**, **Django**, and a **Database System**. For serving the application, Django includes a lightweight development server, but also supports production web servers like Apache or Nginx.

Step 1: Installing Python

Since Django is written entirely in Python, you must have Python installed. The latest Django versions typically require Python 2.6.5 or higher (modern versions mandate Python 3.x).

  • **Verification:** Check your installation by typing python in your command prompt or terminal.
  • **Installation:** Download the latest version from the official Python website if necessary.

Step 2: Installing Django

Django is installed as a platform-independent package. The simplest and recommended way to install it in a modern environment is typically using **pip** (not covered here, but the most common method today), or manually using the downloaded archive.

Manual Installation (Archive Method)

If you have the Django archive (e.g., Django-x.xx.tar.gz):

  • **UNIX/Linux and Mac OS X:** 
    $ tar xzvf Django-x.xx.tar.gz
$ cd Django-x.xx
$ sudo python setup.py install
  • **Windows:** Navigate to the extracted directory in the command prompt and run python setup.py install.

Verification of Django Installation

To confirm Django is installed correctly:

  • **UNIX/Linux and Mac OS X:** $ django-admin.py --version (or django-admin --version for newer versions).
  • **Windows (Python Shell):** python -c "import django; print(django.get_version())" OR enter the Python shell and type: 
    >>> import django
>>> django.VERSION

Step 3: Database Setup

Django supports multiple major relational and non-relational database systems. You must install and configure one of these based on your project's needs:

  • **Relational:** **MySQL**, **PostgreSQL** (often favored for larger projects), **SQLite 3** (default and easiest for development), **Oracle**.
  • **NoSQL:** **MongoDB** (via Django-nonrel or similar engines) and **Google App Engine Datastore**.

Step 4: Web Server

For development, Django provides a **lightweight, built-in web server**. This server is pre-configured and automatically restarts when code is modified, making the development and testing process efficient.

For production deployment, however, you will use dedicated web servers like **Apache** or **Lighttpd**, which interact with Django via WSGI.

CSS - Group Selectors

A CSS group selector is used to apply the same style to multiple elements at once. Instead of writing separate CSS rules for each element, group selectors combine them using a comma (,). This makes the CSS concise, avoids redundancy, and ensures consistency across multiple elements.

Syntax

selector1, selector2, selector3 {
  /* property: value; */
  color: #04af2f;
}

In the above syntax, the same styles will apply to selector1, selector2, and selector3.

Group Selectors Example

In this example, the same styles are applied to a span, a paragraph with ID para, and a div with class myClass. 

span, #para, .myClass {
  background-color: #04af2f;
  color: white;
}

<p id="para">This is a paragraph element.</p>
<div class="myClass">This is a div element.</div>
<br>
<span>This is a span element.</span>

Group Selectors Example with Pseudo-classes

Group selectors can also be combined with pseudo-classes such as :hover and :active. 

.link:active, #btn:active {
  color: #04af2f;
}

.myDiv:hover, #para:hover {
  background-color: #031926;
  color: white;
}

<div class="myDiv">
  Hover over me
</div>

<p id="para">This is a paragraph.</p>

<a class="link" href="#">Click on this link.</a>
<br><br>

<button id="btn">Click me</button>

Key Notes

  • Group selectors use commas (,) to combine multiple selectors.
  • They reduce redundancy and keep CSS more readable.
  • Useful when applying identical styles to different elements.
  • Can be combined with pseudo-classes and pseudo-elements.

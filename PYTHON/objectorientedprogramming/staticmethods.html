Python - Static Methods

A static method in Python is a method that does not require an instance or class reference to be called. Unlike instance methods or class methods, static methods take neither self (instance reference) nor cls (class reference) as their first parameter.

Static methods are bound to the class rather than instances. They are typically used to perform utility functions that have logical connection to the class but do not access or modify class state or instance data.

How to Create Static Methods

There are two ways to create static methods:

  • Using the staticmethod() function
  • Using the @staticmethod decorator

Using staticmethod() Function

class Employee:
    empCount = 0

    def __init__(self, name, age):
        self.__name = name
        self.__age = age
        Employee.empCount += 1

    def showcount():
        print(Employee.empCount)

    counter = staticmethod(showcount)

e1 = Employee("Bhavana", 24)
e2 = Employee("Rajesh", 26)
e3 = Employee("John", 27)

e1.counter()
Employee.counter()

Output:
3
3

Using @staticmethod Decorator

class Student:
    stdCount = 0

    def __init__(self, name, age):
        self.__name = name
        self.__age = age
        Student.stdCount += 1

    @staticmethod
    def showcount():
        print(Student.stdCount)

e1 = Student("Bhavana", 24)
e2 = Student("Rajesh", 26)
e3 = Student("John", 27)

print("Number of Students:")
Student.showcount()

Output:
Number of Students:
3

Advantages of Static Methods

  • Static methods can be used as utility functions to perform frequently reused tasks.
  • They can be called using the class name, eliminating instance dependency.
  • Static methods have predictable behavior as they don't depend on class or instance state.
  • Declaring a method static prevents it from being overridden in subclasses.

HTML - Web Messaging

Introduction

Web Messaging provides a way for documents in different browsing contexts to share data without relying on the DOM. It solves the problem of cross-domain communication across different domains, protocols, or ports.

For example, if we want to send data from a page to an ad container placed in an <iframe>, the browser would normally throw a security exception. With Web Messaging, we can safely pass data across as a message event.

Message Event

Message events are fired in scenarios like cross-document messaging, channel messaging, server-sent events, and WebSockets. They are described by the MessageEvent interface.

Properties of Message Event

  • data − Contains string data
  • origin − Contains domain name and port
  • lastEventId − Unique identifier for the current message event
  • source − Reference to the originating document’s window
  • ports − Data sent by any message port

Sending a Cross-Document Message

Before sending a cross-document message, we need to create a new browsing context, such as an <iframe> or new window. We can then send data using postMessage() with two arguments:

  • message − The message to send
  • targetOrigin − Origin name

Example: Sending message from iframe to button

var iframe = document.querySelector('iframe');
var button = document.querySelector('button');

var clickHandler = function(){
   iframe.contentWindow.postMessage('The message to send.','https://www.tutorialspoint.com');
}
button.addEventListener('click', clickHandler, false);

Receiving a Cross-Document Message

var messageEventHandler = function(event){
   if(event.origin == 'https://www.tutorialspoint.com'){
      alert(event.data);
   }
}
window.addEventListener('message', messageEventHandler, false);

Channel Messaging

Channel messaging enables two-way communication between browsing contexts, even across multiple origins. It uses MessageChannel and MessagePort objects.

MessageChannel Methods

  • postMessage() − Posts a message through a channel
  • start() − Starts sending messages
  • close() − Closes the ports

Example: Sending Data Between Iframes

var loadHandler = function(){
   var mc, portMessageHandler;
   mc = new MessageChannel();

   window.parent.postMessage('documentAHasLoaded','http://foo.example',[mc.port2]);

   portMessageHandler = function(portMsgEvent){
      alert(portMsgEvent.data);
   }

   mc.port1.addEventListener('message', portMessageHandler, false);
   mc.port1.start();
}
window.addEventListener('DOMContentLoaded', loadHandler, false);

Example: Forwarding Data to Another Iframe

var loadHandler = function(){
   var iframes, messageHandler;
   iframes = window.frames;

   messageHandler = function(messageEvent){
      if(messageEvent.ports.length > 0){
         iframes[1].postMessage('portopen','http://foo.example', messageEvent.ports);
      }
   }

   window.addEventListener('message', messageHandler, false);
}
window.addEventListener('DOMContentLoaded', loadHandler, false);

Example: Receiving Data in Second Document

var loadHandler = function(){
   var messageHandler = function(messageEvent){

      var formHandler = function(){
         var msg = 'add <foo@example.com> to game circle.';
         messageEvent.ports[0].postMessage(msg);
      }

      document.forms[0].addEventListener('submit', formHandler, false);
   }
   window.addEventListener('message', messageHandler, false);
}
window.addEventListener('DOMContentLoaded', loadHandler, false);

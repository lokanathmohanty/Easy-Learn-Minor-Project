HTML - Geolocation API

The HTML Geolocation API allows web applications to access the geographical location of the user. Most modern browsers and mobile devices support this API.

JavaScript can capture your latitude and longitude and send it to a backend server for location-aware applications like maps or local business search.

Syntax

The Geolocation object can be accessed as follows:

var geolocation = navigator.geolocation;

This object provides methods to get the location of the device.

Geolocation API Methods

  • getCurrentPosition() – Retrieves the current geographic location of the user.
  • watchPosition() – Retrieves periodic updates of the device’s current position.
  • clearWatch() – Cancels an ongoing watchPosition() call.

Location Properties

The Position object contains location data:

  • coords.latitude – Latitude in decimal degrees.
  • coords.longitude – Longitude in decimal degrees.
  • coords.altitude – Altitude in meters above sea level (optional).
  • coords.accuracy – Accuracy of the latitude/longitude values.
  • coords.speed – Device’s ground speed (optional).
  • timestamp – Time when the position was recorded.

Handling Errors

The API provides error handling through a PositionError object:

  • PERMISSION_DENIED – User denied the request for location.
  • POSITION_UNAVAILABLE – Location data is not available.
  • TIMEOUT – Request for location timed out.
  • UNKNOWN_ERROR – An unknown error occurred.

Position Options

The getCurrentPosition() method accepts an optional third parameter called options:

  • enableHighAccuracy – Boolean to request high accuracy.
  • timeout – Maximum time (in ms) to wait for position.
  • maximumAge – Cache duration (in ms) for stored positions.

Example – Get Current Location

This example retrieves the current latitude and longitude:

<button onclick="getLocation()">Show Location</button>

<script>
function getLocation() {
  if (navigator.geolocation) {
    navigator.geolocation.getCurrentPosition(showPosition);
  } else {
    alert("Geolocation not supported.");
  }
}

function showPosition(position) {
  alert("Latitude: " + position.coords.latitude +
  " Longitude: " + position.coords.longitude);
}
</script>

Example – Error Handling

This example shows how to handle location errors:

function showError(error) {
  switch(error.code) {
    case error.PERMISSION_DENIED:
      alert("User denied the request.");
      break;
    case error.POSITION_UNAVAILABLE:
      alert("Location unavailable.");
      break;
    case error.TIMEOUT:
      alert("Request timed out.");
      break;
    case error.UNKNOWN_ERROR:
      alert("An unknown error occurred.");
      break;
  }
}

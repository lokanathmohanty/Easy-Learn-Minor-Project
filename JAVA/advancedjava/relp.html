Java - REPL (JShell)

Introduction to REPL (JShell)

REPL stands for Read Evaluate Print Loop. JShell was introduced in Java 9 as an interactive console. JShell allows running arbitrary snippets of Java code in the console without needing to save and compile Java files. This is useful for quickly testing code, like evaluating regular expressions, checking string formatting, date formats, and more.

JShell reads each line entered, evaluates it, prints the result, and then waits for the next input.

Advantages of Using JShell

  • No editor is needed to write Java programs; JShell itself acts as the editor and executor.
  • No need to save, compile, and run cycles — code can be tested directly.
  • No prior compilation needed before execution.
  • If compile-time or runtime errors occur, you can start fresh easily.

Running JShell

Open a command prompt and type jshell:

D:\test>jshell
|  Welcome to JShell -- Version 20.0.2
|  For an introduction type: /help intro

With JShell, you can test methods, classes, and expressions. Below are some feature demonstrations.

Examples

Create and Invoke Method in JShell

Define a simple method greet() that prints "Hello World!" and invoke it.

jshell> void greet() { System.out.println("Hello World!");}
|  created method greet()

jshell> greet()
Hello World!
jshell>

Creating Variables in JShell

Variables can be declared with or without semicolons. Uninitialized variables get default values or null for object references.

jshell> int i = 10
i ==> 10

jshell> String name = "Mahesh";
name ==> "Mahesh"

jshell> Date date = new Date()
date ==> Fri Feb 02 14:52:49 IST 2024

jshell> long l
l ==> 0

jshell> List list
list ==> null

jshell> name
name ==> "Mahesh"

Evaluate Expression in JShell

JShell evaluates expressions and stores results in automatically created variables.

jshell> String.format("%d pages read.", 10);
$9 ==> "10 pages read."

jshell> $9
$9 ==> "10 pages read."

JShell Built-In Commands

JShell supports commands for managing code snippets and environment:

  • /drop – delete snippets by name or ID
  • /edit – open an editor
  • /env – show environment settings
  • /exit – exit JShell
  • /history – show command history
  • /help – show help for commands
  • /imports – list active imports

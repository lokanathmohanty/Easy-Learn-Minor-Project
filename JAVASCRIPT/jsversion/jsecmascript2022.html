JavaScript - ECMAScript 2022

The ECMAScript 2022 standard was released in 2022. It introduced several important features such as private methods and fields, Array.at() and String.at() methods, Object.hasOwn(), error.cause, and await import. This chapter discusses all the newly added features in ECMAScript 2022.

New Features Added in ECMAScript 2022

  • Array at() Method
  • String at() Method
  • Private Methods and Fields
  • Object.hasOwn()
  • error.cause
  • await import

Array at() Method

The Array.at() method allows accessing elements at a given index, supporting negative indices for easier access to elements from the end.

Example


const arr = [10, 20, 60, 72, 6, 12, 23];
console.log("The last array element is:", arr.at(-1));
console.log("The third last array element is:", arr.at(-3));

Output:


The last array element is: 23
The third last array element is: 6

String at() Method

The String.at() method allows accessing characters at a given index, with support for negative indices.

Example


let str = "Hello world";
console.log("The last string character is:", str.at(-1));
console.log("The fourth last string character is:", str.at(-4));

Output:


The last string character is: d
The fourth last string character is: o

Private Methods and Fields

Private fields and methods are defined using the # prefix. They cannot be accessed outside of the class, only within the class itself.

Example


class Car {
  #brand;
  constructor(brand) {
    this.#brand = brand;
  }
  getBrand() {
    return this.#carBrand();
  }
  #carBrand() {
    return "The car brand is " + this.#brand;
  }
}

const BMW = new Car("BMW");
console.log(BMW.getBrand());

Output: The car brand is BMW

Object.hasOwn()

The Object.hasOwn() method is a safer replacement for Object.hasOwnProperty(), checking if an object has a specific property.

Example


const obj = { name: "sam", age: 50 };
console.log("Does obj contain name property?", Object.hasOwn(obj, "name"));

Output: Does obj contain name property? true

The error.cause Property

The cause property provides additional context for an error, describing why it occurred.

Example


try {
  throw new Error("New error", { cause: "Testing with error." });
} catch (error) {
  console.log("The reason for the error is:", error.cause);
}

Output:


The reason for the error is: Testing with error.

Await Import

Dynamic modules can be imported asynchronously using await import. This is useful when loading modules conditionally or lazily.

Example


(async function () {
  await (await import('./math.js')).default();
  await (await import('./operations.js')).default();
})();

Warning: Some of the above features may not be supported in older browsers. Use polyfills if necessary.

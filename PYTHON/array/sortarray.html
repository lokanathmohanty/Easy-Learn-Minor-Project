Sort Arrays in Python

Python's array module provides a homogenous collection for strings, integers, or floats, similar to arrays in other languages. The array class itself does not have a built-in sort method, but sorting can be achieved via several approaches:

  • Implementing a sorting algorithm (e.g., bubble sort)
  • Using the list sort() method
  • Using the built-in sorted() function

Sort Using Bubble Sort Algorithm

import array as arr
a = arr.array('i', [10, 5, 15, 4, 6, 20, 9])
for i in range(len(a)):
    for j in range(i+1, len(a)):
        if a[i] > a[j]:
            a[i], a[j] = a[j], a[i]
print(a)
# Output:
# array('i', [4, 5, 6, 9, 10, 15, 20])

Sort Using List sort() Method

Convert the array to a list, sort it, then convert back to an array.

import array as arr
orgnlArray = arr.array('i', [10, 5, 15, 4, 6, 20, 9])
print("Original array:", orgnlArray)
sortedList = orgnlArray.tolist()
sortedList.sort()
sortedArray = arr.array('i', sortedList)
print("Array after sorting:", sortedArray)
# Output:
# Original array: array('i', [10, 5, 15, 4, 6, 20, 9])
# Array after sorting: array('i', [4, 5, 6, 9, 10, 15, 20])

Sort Using Built-in sorted() Function

The sorted() function returns a new sorted list. The original array remains unchanged.

import array as arr
a = arr.array('i', [4, 5, 6, 9, 10, 15, 20])
sortedList = sorted(a)
sortedArray = arr.array('i', sortedList)
print(sortedArray)
# Output:
# array('i', [4, 5, 6, 9, 10, 15, 20])

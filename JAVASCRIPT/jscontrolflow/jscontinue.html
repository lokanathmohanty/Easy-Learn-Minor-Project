JavaScript — Continue Statement

Overview

The continue statement in JavaScript is used to skip the current iteration of a loop and continue with the next iteration. It is often used with an if statement to check a condition and bypass certain iterations.

When encountered, continue jumps to the next loop evaluation, skipping any remaining code in the current iteration.

Syntax

continue;

continue label;

The label is optional and can be used to control outer loops in nested structures.

Key Points

  • Skips the current iteration of the loop.

  • Execution resumes at the loop’s condition check.

  • Can be used in for, while, and do...while loops.

  • Labeled continue can skip iterations of an outer loop.

Example — Continue with for loop

Here, the loop skips printing the value 3:

for (let x = 1; x < 5; x++) { if (x == 3) continue; }

Output: 1, 2, 4

Example — Continue with while loop

This while loop skips iterations when x is 2 or 3:

while (x < 5) { x++; if (x == 2 || x == 3) continue; }

Output: 4, 5

Example — Continue with nested loops

You can use continue inside nested loops. In the parent loop below, iterations for x equal to 2 or 3 are skipped. In the nested loop, iterations where y equals 3 are skipped:

for (let x = 1; x < 5; x++) { if (x == 2 || x == 3) continue; for (let y = 1; y < 5; y++) { if (y == 3) continue; } }

Output: 1-1, 1-2, 1-4, 4-1, 4-2, 4-4

Using labels with continue

A labeled continue statement allows skipping the current iteration of an outer loop from within an inner loop.

Example pattern:

outer: for (let i = 0; i < n; i++) { for (let j = 0; j < m; j++) { if (condition) continue outer; } }

Common Pitfalls

  • Overusing continue can make loop logic harder to understand.

  • Using continue without updating loop variables may cause infinite loops.

  • Labeled continue is rarely needed — use it cautiously.

Practice Tasks

  • Write a loop that prints only even numbers between 1 and 10 using continue.

  • Create a while loop that skips numbers divisible by 3.

  • Implement nested loops where an inner condition uses continue to skip processing certain combinations.

Summary

The continue statement is useful when you want to skip specific iterations within loops without breaking out of them entirely. It provides fine control over which parts of a loop’s body should execute.

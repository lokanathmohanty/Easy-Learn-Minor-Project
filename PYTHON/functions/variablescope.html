Python - Variable Scope

The scope of a variable in Python is defined as the specific area or region where the variable is accessible. It depends on where and how the variable is defined. In Python, a variable can have either a global or a local scope.

Types of Scope for Variables in Python

  • Local Variables
  • Global Variables
  • Nonlocal Variables

Local Variables

A local variable is defined within a function or block of code. It can only be accessed inside that function, and attempting to access it outside results in an error. Multiple local variables can exist with the same name in different functions. 

def myfunction():
    a = 10
    b = 20
    print("variable a:", a)
    print("variable b:", b)
    return a+b

print(myfunction())

Output:

variable a: 10
variable b: 20
30

Global Variables

A global variable is defined outside of any function and can be accessed anywhere in the program. 

# global variables
name = 'TutorialsPoint'
marks = 50
def myfunction():
    print("name:", name)
    print("marks:", marks)

myfunction()

Output:

name: TutorialsPoint
marks: 50

Nonlocal Variables

Nonlocal variables are used in nested functions. They are neither local nor global, but allow modification of variables in the enclosing function. 

def yourfunction():
    a = 5
    b = 6
    def myfunction():
        nonlocal a, b
        a = 10
        b = 20
        print("variable a:", a)
        print("variable b:", b)
        return a+b
    print(myfunction())

yourfunction()

Output:

variable a: 10
variable b: 20
30

Namespace and Scope of Python Variables

A namespace is a collection of identifiers (variables, functions, classes, etc.). Python uses namespaces to manage variable scope and avoid naming conflicts.

  • Built-in namespace: contains built-in functions and exceptions, loaded when the interpreter starts.
  • Global namespace: contains names defined in the main program.
  • Local namespace: contains names defined inside a function, valid until the function ends.

Python globals() Function

globals() returns a dictionary of symbols in the global namespace.

>>> globals()
{'__name__': '__main__', '__doc__': None, '__package__': None, ...}

Example

name = 'TutorialsPoint'
marks = 50
result = True
def myfunction():
    a = 10
    b = 20
    return a+b

print(globals())

Python locals() Function

locals() returns a dictionary of variables in the local namespace of a function.

name = 'TutorialsPoint'
marks = 50
result = True
def myfunction():
    a = 10
    b = 20
    c = a+b
    print("globals():", globals())
    print("locals():", locals())
    return c

myfunction()

Output:

globals(): {... 'name': 'TutorialsPoint', 'marks': 50, 'result': True, 'myfunction': }
locals(): {'a': 10, 'b': 20, 'c': 30}

Namespace Conflict in Python

If a variable with the same name exists in both global and local scope, Python prioritizes the local variable.

Example 1

marks = 50 # global
def myfunction():
    marks = 70 # local
    print(marks)

myfunction()
print(marks)

Output:

70
50

Example 2

Trying to modify a global variable inside a function without global keyword causes an error.

marks = 50
def myfunction():
    marks = marks + 20
    print(marks)

myfunction()

Error:

UnboundLocalError: cannot access local variable 'marks' where it is not associated with a value

Example 3

To modify global variables, use globals() or the global keyword.

var1 = 50
var2 = 60
def myfunction():
    globals()['var1'] = globals()['var1'] + 10
    global var2
    var2 = var2 + 20

myfunction()
print("var1:", var1, "var2:", var2)

Output:

var1: 60 var2: 80

Example 4

Accessing a local variable outside its scope causes a NameError.

var1 = 50
var2 = 60
def myfunction(x, y):
    total = x + y
    print("Total is a local variable:", total)

myfunction(var1, var2)
print(total) # ❌ NameError

Error:

NameError: name 'total' is not defined

CSS - Variables

CSS Variables are custom properties that allow you to store and reuse values throughout your CSS program. They are similar to variables in other programming languages and make your code more maintainable.

How to Declare a Variable in CSS?

CSS variables are typically defined using the :root selector. Example syntax: 

:root {
  --variable-name: value;
}

selector {
  property: var(--variable-name, fallback-value);
}

The Traditional Way

Without variables, developers need to repeat the same values multiple times in CSS, leading to redundancy and harder maintenance. 

body {
  background-color: #f0f0f0;
  color: #333;
  font-family: Arial, sans-serif;
}
header {
  background-color: #0044cc;
  color: #fff;
}

Using CSS Variables

CSS variables reduce redundancy by storing values in one place and reusing them everywhere. 

:root {
  --main-bg-color: #f0f0f0;
  --main-text-color: #333;
  --primary-font: Arial, sans-serif;
  --blue: #0044cc;
  --header-text: #fff;
}
body {
  background-color: var(--main-bg-color);
  color: var(--main-text-color);
  font-family: var(--primary-font);
}
header {
  background-color: var(--blue);
  color: var(--header-text);
}

The Root Pseudo-Class

Declaring variables in :root makes them global, meaning they can be accessed anywhere in the CSS. Variable names are case-sensitive. 

:root {
  --pink-color: pink;
  --blue-color: blue;
}
.box {
  background-color: var(--pink-color);
  color: var(--blue-color);
}

Inheritance of Custom Properties

CSS variables can be inherited by child elements, which helps in applying consistent values across multiple elements. 

:root {
  --pink-color: pink;
}
.box {
  --box-background: var(--pink-color);
  background-color: var(--box-background);
}
.box1, .box2 {
  background-color: var(--box-background);
}

CSS Variables Fallback Value

Fallback values ensure that if a variable is not defined, the browser uses a backup value. 

.box {
  background-color: var(--white-color, white);
  color: var(--black-color, black);
}

CSS Variables Invalid Value

If a variable has an invalid value, the property using it will fallback to the default behavior. 

:root {
  --red-color: 15px; /* Invalid value */
}
h2 {
  color: var(--red-color); /* ignored, defaults to black */
}

CSS Variables in JavaScript

JavaScript can be used to manipulate CSS variables dynamically at runtime. 

const root = document.documentElement;
root.style.setProperty('--padding', '20px');

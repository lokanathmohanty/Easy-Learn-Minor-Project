PowerShell - Cmdlets

A cmdlet (or "command-let") is a lightweight command used in the Windows PowerShell environment. Cmdlets are invoked by the PowerShell runtime directly from the command prompt. They can also be created and used programmatically through the PowerShell APIs.

Cmdlet vs Command

Cmdlets are significantly different from traditional commands found in other command-line shells. Here’s how:

  • Cmdlets are .NET Framework class objects, not standalone executables.
  • Cmdlets can be constructed using just a few lines of code.
  • Parsing, error handling, and output formatting are managed by the PowerShell runtime—not the cmdlet itself.
  • Cmdlets work with objects, not plain text, allowing for object-based pipelining.
  • Cmdlets are record-based; they process one object at a time.

Getting Help

The first step to understanding any cmdlet is using the Get-Help command. It provides detailed information about how a command works and what parameters it accepts.

Example: Using Get-Help

Get-Help Get-Process

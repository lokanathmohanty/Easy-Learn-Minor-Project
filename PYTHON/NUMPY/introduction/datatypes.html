NumPy Data Types

Data Types in Python

By default, Python has the following data types:

  • strings – text data, written in quotes. Example: "ABCD"
  • integer – whole numbers. Example: -1, 42
  • float – real numbers. Example: 3.14, 42.0
  • boolean – True or False
  • complex – complex numbers. Example: 1.0 + 2.0j

Data Types in NumPy

NumPy provides additional data types and represents them using single-character codes:

  • i - integer
  • b - boolean
  • u - unsigned integer
  • f - float
  • c - complex float
  • m - timedelta
  • M - datetime
  • O - object
  • S - string
  • U - unicode string
  • V - void (raw memory)

Checking the Data Type of an Array

You can check the data type of a NumPy array using the dtype attribute.

import numpy as np

arr = np.array([1, 2, 3, 4])
print(arr.dtype)

Example with string values:

import numpy as np

arr = np.array(['apple', 'banana', 'cherry'])
print(arr.dtype)

Creating Arrays With a Defined Data Type

Use the dtype argument to define the expected data type:

import numpy as np

arr = np.array([1, 2, 3, 4], dtype='S')
print(arr)
print(arr.dtype)

Define the size of the data type (e.g. 4-byte integer):

import numpy as np

arr = np.array([1, 2, 3, 4], dtype='i4')
print(arr)
print(arr.dtype)

What if a Value Cannot Be Converted?

If an element cannot be converted to the specified type, NumPy will raise a ValueError.

For example, trying to convert the string 'a' to an integer will cause an error:

import numpy as np

arr = np.array(['a', '2', '3'], dtype='i')

Converting Data Type on Existing Arrays

Use the astype() method to convert the data type of an existing array. This returns a new array.

Example using a string type code:

import numpy as np

arr = np.array([1.1, 2.1, 3.1])
newarr = arr.astype('i')

print(newarr)
print(newarr.dtype)

Example using Python’s built-in type int:

import numpy as np

arr = np.array([1.1, 2.1, 3.1])
newarr = arr.astype(int)

print(newarr)
print(newarr.dtype)

Convert integer array to boolean:

import numpy as np

arr = np.array([1, 0, 3])
newarr = arr.astype(bool)

print(newarr)
print(newarr.dtype)

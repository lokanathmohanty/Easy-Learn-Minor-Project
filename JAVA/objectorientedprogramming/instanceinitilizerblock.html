Java Programming: Object Initialization

Session: Instance Initializer Block

What is an Instance Initializer Block?

An **Instance Initializer Block** is a block of code (enclosed in curly braces {}) that is declared directly inside a class, outside any method or constructor. It is primarily used to **initialize instance data members**.

An initializer block is executed **once for every object** created from the class, making it useful for setting initial values for instance variables.

Execution and Characteristics

The Instance Initializer Block is executed automatically during object creation, but its order relative to constructors is strict:

  • It is called immediately after the object is created.
  • It is called **before** any constructor of the object is invoked.
  • In an inheritance hierarchy, it is executed after the **superclass constructor** but before the subclass constructor.
  • It is often used to hold common initialization logic shared by multiple constructors.

Order of Execution: Initializer Block vs. Constructor

When an object is created, the steps follow a precise order, demonstrating that the initializer block runs before the constructor.

public class Tester {
   // Instance Initializer Block
   {
      System.out.println("1. Inside instance initializer block");
   }
   
   Tester(){
      System.out.println("2. Inside constructor");
   }
   
   public static void main(String[] arguments) {
      Tester test = new Tester();
   }
}

Output proves the execution order:

1. Inside instance initializer block
2. Inside constructor

Example: Initializer Block and Inheritance Order

In the case of inheritance, the instance initializer block of the subclass is guaranteed to execute *after* the superclass constructor, ensuring all inherited members are initialized first.

class SuperTester {
   SuperTester(){
      System.out.println("1. Inside super constructor");
   }
}

public class Tester extends SuperTester {
   {
      System.out.println("2. Inside instance initializer block");
   }
   Tester(){
      System.out.println("3. Inside child constructor");
   }
}

Output (The initializer block is called in step 2, between the parent and child constructors):

1. Inside super constructor
2. Inside instance initializer block
3. Inside child constructor

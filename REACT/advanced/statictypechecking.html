ReactJS - Static Type Checking

Since JavaScript is a dynamically typed language, it is hard to find type mismatch errors before running the code. React supports type checking for props through the prop-types package, which can be used to identify type mismatches during development.

For the rest of the application, we need additional tools to properly identify type issues during development. Two popular static type checker options that integrate smoothly into React projects are:

  • Flow
  • TypeScript

Flow

Flow is a static type checker for JavaScript. It extends JavaScript with type annotations that are checked at development time.

Example

// @flow
function sum(a: number, b: number) : number {
   return a + b;
}
sum(10, 20)     // Pass
sum("10", "20") // Fail

Here, // @flow enables Flow type checking. The function sum enforces number arguments.

Steps to enable Flow in React

  1. Create a React project: 
    create-react-app myapp
  2. Install Flow: 
    cd myapp
npm install --save-bin flow-bin
  3. Add Flow script in package.json: 
    "scripts": {
   "flow": "flow"
}
  4. Initialize Flow: 
    npm run flow init
  5. Edit .flowconfig (ignore node_modules): 
    [ignore]
.*/node_modules/.*
[include]
[libs]
[lints]
[options]
react.runtime=automatic
[strict]
  6. Run Flow check: 
    npm run flow
  7. Create HelloWorld component (src/components/HelloWorld.js):
    8. import React from 'react'
class HelloWorld extends React.Component {
   render() {
      return <h1>Hello, {this.props.name}</h1>
   }
}
export default HelloWorld
  8. Use it in App.js with Flow annotations:
    9. // @flow
import React from "react";
import HelloWorld from "./components/HelloWorld";
function App() : any {
   var name: string = 10
   return (
      <div>
         <HelloWorld name={name} />
      </div>
   )
}
export default App;
  9. Run Flow to catch type mismatch errors and fix them by providing a valid string.

TypeScript

TypeScript is a language that adds static typing to JavaScript. It catches type errors at compile time and is fully supported by React.

Create a TypeScript React project

create-react-app myapp --template typescript

HelloWorld Component

// src/components/HelloWorld.tsx
import React from 'react'
class HelloWorld extends React.Component {
   render() {
      return <h1>Hello, {this.props.name}</h1>
   }
}
export default HelloWorld

Using the Component

import React from "react";
import HelloWorld from "./components/HelloWorld";
function App() : any {
   var name: string = 10
   return (
      <div>
         <HelloWorld name={name} />
      </div>
   )
}
export default App;

TypeScript compiler will show an error because name expects a string, not a number.

Fixing Props with Interface

import React from 'react'
interface HelloWorldProps {
   name: string
}
class HelloWorld extends React.Component<HelloWorldProps> {
   render() {
      return <h1>Hello, {this.props.name}</h1>
   }
}
export default HelloWorld

Now the application compiles successfully with proper type checking.

Summary

React supports static type checking using:

  • Flow – lightweight type checker for JavaScript with annotation support.
  • TypeScript – a superset of JavaScript with built-in static typing.

Both tools help identify type-related errors during development, making React applications more robust and easier to maintain.

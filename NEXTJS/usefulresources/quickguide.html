Next.js - Overview

Next.js is a React-based framework with server-side rendering capability. It is fast and SEO-friendly.

With Next.js, you can create robust React applications easily and test them effectively. Below are the key features of Next.js:

  • Hot Code Reload: Automatically reloads the server when files are modified.
  • Automatic Routing: Routes are based on the file system structure inside the pages folder.
  • Component-specific Styles: Supports scoped and global styles using styled-jsx.
  • Server-side Rendering: Components are pre-rendered on the server for faster loading.
  • Node Ecosystem: Works seamlessly with the Node.js ecosystem.
  • Automatic Code Splitting: Loads only necessary JavaScript for each page.
  • Prefetch: Prefetch resources using the Link component.
  • Dynamic Components: Supports dynamic imports of components and modules.
  • Export Static Site: Allows exporting the entire site as static HTML.
  • Built-in TypeScript Support: Offers excellent TypeScript support out of the box.

Next.js - Environment Setup

Make sure Node.js and npm are installed. Install Next.js using the command:

npm install next react react-dom

After successful installation, create a package.json:

npm init

Example package.json:

{
  "name": "nextjs",
  "version": "1.0.0",
  "main": "index.js",
  "dependencies": {
    "next": "^9.4.4",
    "react": "^16.13.1",
    "react-dom": "^16.13.1"
  },
  "scripts": {
    "dev": "next",
    "build": "next build",
    "start": "next start"
  }
}

Create a pages directory and add index.js:

function HomePage() {
  return <div>Welcome to Next.js!</div>
}
export default HomePage

Start the development server:

npm run dev

Next.js - Pages

Pages are React components inside the pages folder. Routing is based on file structure.

  • pages/index.js maps to /
  • pages/posts/first.js maps to /posts/first

Create posts/first.js:

export default function FirstPost() {
  return <h1>My First Post</h1>
}

Add navigation with Link:

import Link from 'next/link'

export default function FirstPost() {
  return (
    <>
      <h1>My First Post</h1>
      <h2>
        <Link href="/"><a>Home</a></Link>
      </h2>
    </>
  )
}

Update index.js to include link to First Post:

import Link from 'next/link'

function HomePage() {
  return (
    <>
      <div>Welcome to Next.js!</div>
      <Link href="/posts/first"><a>First Post</a></Link>
    </>
  )
}
export default HomePage

Next.js - Static File Serving

Place static assets like images in the public directory.

Update first.js to include an image:

import Link from 'next/link'

export default function FirstPost() {
  return (
    <>
      <h1>My First Post</h1>
      <h2>
        <Link href="/"><a>Home</a></Link>
      </h2>
      <br />
      <img src="/logo.png" alt="TutorialsPoint Logo" />
    </>
  )
}

Next.js - Meta Data

Use the <Head> component from Next.js to modify the page's metadata.

Update index.js:

import Link from 'next/link'
import Head from 'next/head'

function HomePage() {
  return (
    <>
      <Head>
        <title>Welcome to Next.js!</title>
      </Head>
      <div>Welcome to Next.js!</div>
      <Link href="/posts/first"><a>First Post</a></Link>
      <br />
      <img src="/logo.png" alt="TutorialsPoint Logo" />
    </>
  )
}
export default HomePage

Update first.js:

import Link from 'next/link'
import Head from 'next/head'

export default function FirstPost() {
  return (
    <>
      <Head>
        <title>My First Post</title>
      </Head>
      <h1>My First Post</h1>
      <h2>
        <Link href="/"><a>Home</a></Link>
      </h2>
    </>
  )
}

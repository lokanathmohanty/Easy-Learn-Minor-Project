JavaScript - Null Checking

In JavaScript, the null value indicates the intentional absence of any object value. It is a primitive value that evaluates to false in Boolean operations.

This is different from undefined, which means a variable has been declared but has not been assigned a value.

Example: think of a box that is empty — it has nothing inside. That box is like a null variable in JavaScript.

Checking Null Values

We can check null values in JavaScript using different methods:

  • Using the Strict Equality Operator (===)
  • Using the typeof operator
  • Using Object.is() method

1. Using the Strict Equality Operator (===)

The strict equality operator checks both the value and the type. 

var v = null;
if (v === null) {
   console.log("Value is null");
} else {
   console.log("Value is not null");
}

Output

Value is null

2. Using the typeof Operator

The typeof operator checks the type of a variable. For null, it returns "object". 

var v = null;
if (!v && typeof v === "object") {
   console.log("Value is null");
} else {
   console.log("Value is not null");
}

Output

Value is null

3. Using Object.is() Method

The Object.is() method compares two values and returns true if they are the same. 

var v = null;
if (Object.is(v, null)) {
   console.log("Value is null");
} else {
   console.log("Value is not null");
}

Output

Value is null

Conclusion

We can check for null values in JavaScript using:

  • === (strict equality operator)
  • typeof (type checking)
  • Object.is() (value comparison)

Each method confirms whether a variable contains a null value.

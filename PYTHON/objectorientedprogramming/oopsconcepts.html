Python - OOP Concepts

OOP stands for Object-Oriented Programming paradigm. It is a programming model that uses the concept of objects, which represent real-world entities with state and behavior. Python supports OOP, making it simple to create and use classes and objects.

Procedural Oriented Approach

Earlier programming languages were procedural, where a program was described as a sequence of instructions. While functions were reusable blocks, this approach had some problems:

  • Top-down approach made programs hard to maintain.
  • Heavy reliance on global data increased memory overhead.
  • Data movement was unrestricted, lacking clear association with functions.

OOP Concepts: Attributes and Behavior

Objects combine both data (attributes) and functions (behavior) related to real-world entities:

  • Attributes: e.g., name, class, marks of a student.
  • Behavior: e.g., computing percentage of marks, calculating incentives.

OOP defines these attributes and behaviors as a single unit called a class, which acts as a blueprint. An individual instance created from the class is called an object.

Principles of OOP

  • Class
  • Object
  • Encapsulation
  • Inheritance
  • Polymorphism

Class and Object

A class defines attributes and methods accessible via dot notation. An object is an instance of a class containing specific data.

Example

Creating a class and object in Python:

class Smartphone:
  def __init__(self, device, brand):
    self.device = device
    self.brand = brand

  def description(self):
    return f"{self.device} of {self.brand} supports Android 14"

phoneObj = Smartphone("Smartphone", "Samsung")
print(phoneObj.description())

Output: Smartphone of Samsung supports Android 14

Encapsulation

Encapsulation restricts direct access to data members and allows access only through methods, protecting object data.

Example

Using encapsulation to control access to data:

class Desktop:
  def __init__(self):
    self.__max_price = 25000

  def sell(self):
    return f"Selling Price: {self.__max_price}"

  def set_max_price(self, price):
    if price > self.__max_price:
      self.__max_price = price

desktopObj = Desktop()
print(desktopObj.sell())
desktopObj.__max_price = 35000
print(desktopObj.sell())
desktopObj.set_max_price(35000)
print(desktopObj.sell())

Output:
Selling Price: 25000
Selling Price: 25000
Selling Price: 35000

Inheritance

Inheritance allows building new classes from existing classes to promote code reuse and extend functionality.

Example

Demonstrating inheritance:

class Parent:
  parentAttr = 100

  def __init__(self):
    print("Calling parent constructor")

  def parentMethod(self):
    print("Calling parent method")

  def setAttr(self, attr):
    Parent.parentAttr = attr

  def getAttr(self):
    print("Parent attribute :", Parent.parentAttr)

class Child(Parent):
  def __init__(self):
    print("Calling child constructor")

  def childMethod(self):
    print("Calling child method")

c = Child()
c.childMethod()
c.parentMethod()
c.setAttr(200)
c.getAttr()

Output:
Calling child constructor
Calling child method
Calling parent method
Parent attribute : 200

Polymorphism

Polymorphism means having multiple forms. Subclasses can override base class methods to provide specialized behavior.

Example

Overriding a parent method in a child class:

class Parent:
  def myMethod(self):
    print("Calling parent method")

class Child(Parent):
  def myMethod(self):
    print("Calling child method")

c = Child()
c.myMethod()

Output:
Calling child method

Operator Overloading Example

Python allows overloading operators such as + by defining special methods like __add__.

class Vector:
  def __init__(self, a, b):
    self.a = a
    self.b = b

  def __str__(self):
    return 'Vector (%d, %d)' % (self.a, self.b)

  def __add__(self, other):
    return Vector(self.a + other.a, self.b + other.b)

v1 = Vector(2,10)
v2 = Vector(5,-2)
print(v1 + v2)

Output: Vector (7, 8)

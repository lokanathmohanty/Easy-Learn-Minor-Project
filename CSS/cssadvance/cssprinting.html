CSS Printing

CSS printing involves using specific CSS rules and properties to control how a webpage is formatted when printed. Generally, for any printable version of a webpage, the styling should use light colors because dark colors like black or red consume more printer ink. In this session, we will learn how to design printer-friendly webpages using CSS.

Styles For Printer-Friendly Pages

Here are the key styles that can be applied for creating printer-friendly pages:

  • Simplify the Layout: Remove unnecessary elements like sidebars, menus, ads, or interactive content by setting display: none;.
  • Remove Background Colors: Use white or light colors for the background and black text to save ink.
  • Adjust Font Sizes: Use readable, larger, and more legible fonts for print.
  • Display URLs for Links: Replace hyperlinks with their exact URL in print versions.
  • Manage Page Breaks: Control where content breaks across pages to avoid splitting important sections.

Using a Print Style Sheet

You can create an external stylesheet for printing needs and link it with the media="print" attribute in the <link> tag.

Example

<link href="/path/to/print.css" media="print" rel="stylesheet" />

The print.css might look like:

body {
    background-color: white;
    color: black;
}
.navbar {
    display: none;
}

Using Media Queries and @page

Instead of a separate file, you can use media queries in the internal stylesheet itself.

Example

@media print {
    body {
        background-color: white;
        color: black;
    }
    .navbar {
        display: none;
    }
}

@page {
    size: A4 portrait;
    margin: 2cm;
}

@page :first {
    margin: 5cm;
}

Complete Example

<!DOCTYPE html>
<html>
<head>
    <title>CSS Printing Example</title>
</head>
<body>
    <h3>Tutorialspoint</h3>
    <p>CSS Media Type - Print</p>
    <p>Background is white for printable version of this page.</p>
    <button onclick="printPage()">Print Page</button>
    <script>
        function printPage() {
            window.print();
        }
    </script>
</body>
</html>

Detecting Print Requests

Browsers trigger beforeprint and afterprint events to identify when printing is happening. These can be used to modify the user interface during or after printing.

Example

<script>
    window.addEventListener("afterprint", () => self.close);
</script>

Full Example with Events

<!DOCTYPE html>
<html>
<head>
    <title>CSS Print Event Example</title>
</head>
<body>
    <h2>Header1</h2>
    <p>Section one</p>
    <button>Print</button>

    <script>
        const button = document.querySelector("button");
        button.addEventListener("click", () => {
            window.print();
        });
        window.addEventListener("afterprint", () => self.close);
    </script>
</body>
</html>

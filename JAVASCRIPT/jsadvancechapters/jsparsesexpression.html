JavaScript - Parse S-expressions

The Lisp programming language family is built around S-expressions. In this session, you will learn the steps of making a simple S-expression parser using JavaScript. This can form the basis for a Lisp parser.

Lisp is one of the easiest languages to implement, and creating a parser is the first step. While parser generators exist, it is simpler to write the parser manually.

What are S-expressions?

To define nested list data structures, we use S-expressions, which are commonly used in Lisp and other functional programming languages. An S-expression can either be an atom or a sequence of S-expressions.

Example of an S-expression:

(+ (second (list "xxx" 10)) 20)

This format represents data where atoms or lists are surrounded by parentheses, and atoms from other lists are separated by spaces.

Like JSON, S-expressions support different data types such as numbers, strings, and symbols. For example: 

(1 . b)

Lists can also be represented as dotted pairs, which align with linked list structures: 

(1 2 3 4)

Equivalent dotted notation:

(1 . (2 . (3 . (4 . Nil))))

Here, the special symbol nil represents the end of an empty list. This allows representing binary trees, although for simplicity, our parser avoids dotted notation.

What are the Uses of S-expressions?

  • Creating Lisp code that can also communicate data.
  • Used in the textual representation of WebAssembly.
  • Can be used instead of JSON for communication between server and browser.

Step-by-step S-expression Parser in JavaScript

The parser is built with the following steps:

  • Tokenize the Input: Split the string into tokens (parentheses, numbers, symbols).
  • Recursive Parsing: Build nested lists based on parentheses.
  • Base Cases: Return numbers or symbols as atomic values.

Example

The following code demonstrates a simple parser:

// Function to tokenize the input string into S-expression tokens
function tokenize(input) {
   return input
      .replace(/\(/g, ' ( ')    // Add spaces around '('
      .replace(/\)/g, ' ) ')    // Add spaces around ')'
      .trim()
      .split(/\s+/);            // Split by whitespace
}

// Recursive function to parse tokens into an S-expression
function parse(tokens) {
   if (tokens.length === 0) {
      throw new Error("Unexpected end of input");
   }
   let token = tokens.shift();  
   if (token === '(') {        
      let list = [];
      while (tokens[0] !== ')') {   
        list.push(parse(tokens)); 
      }
      tokens.shift();  // Remove ')'
      return list;
   } else if (token === ')') {
      throw new Error("Unexpected ')'");
   } else {
      return atom(token);  
   }
}

// Function to identify if a token is a number or symbol
function atom(token) {
   let number = Number(token);
   if (!isNaN(number)) {
      return number;  
   } else {
      return token;   
   }
}

// Usage
let input = "(+ 1 (* 2 3))";
let tokens = tokenize(input);    
let ast = parse(tokens);         
console.log(ast);

Output

If you run the above code with the given input, the output will be: 

["+", 1, ["*", 2, 3]]

CSS - ID Selectors

A CSS ID selector is used to select and style a single unique element that has a specific id attribute. IDs are unique within a page, which means the same id should not be applied to multiple elements. In CSS, an ID selector is defined using the # (hash) symbol.

Syntax

#id {
  /* property: value; */
  color: #04af2f;
}

In the syntax above, any element with the id="id" will have its text color set to green.

ID Selector for Styling a div Element

An ID selector can be used on any element like div, p, section, etc. 

#myId {
  background-color: #04af2f;
  color: white;
  font-size: 20px;
  font-family: Verdana, sans-serif;
  padding: 10px;
  border: 1px solid black;
  text-align: center;
}

<div id="myId">
  This is a div element having various styles.
</div>

ID Selector with Pseudo-Classes

The ID selector can also be combined with pseudo-classes like :hover to add interactivity. 

#myId {
  color: #04af2f;
}

#myId:hover {
  color: #031926;
}

<a href="#" id="myId">
  Hover over this link to change its color.
</a>

Using ID Selector with Forms

ID selectors are useful when designing form elements like inputs and buttons. 

#user {
  border: 2px solid black;
  border-radius: 5px;
  font-size: 16px;
  font-family: Verdana, sans-serif;
}

#btn {
  background-color: #031926;
  color: white;
  padding: 10px 15px;
  border: none;
  border-radius: 5px;
  cursor: pointer;
}

<form>
  <label for="username">Username:</label>
  <input type="text" id="user" name="username" placeholder="Enter your username">
  <br><br>
  <button type="submit" id="btn">Submit</button>
</form>

ID Selector for Animations

CSS ID selectors can also be applied with animations to create effects such as a bouncing ball. 

#animated {
  width: 100px;
  height: 100px;
  background-color: #04af2f;
  font-family: Verdana, sans-serif;
  text-align: center;
  line-height: 100px;
  color: white;
  border-radius: 50%;
  animation: bounce 1s infinite;
}

@keyframes bounce {
  0%, 100% {
    transform: translateY(20px);
  }
  50% {
    transform: translateY(0);
  }
}

<div id="animated">Bounce</div>

ID Selector with Transitions

ID selectors can also be combined with transitions to create smooth state changes. 

#box {
  width: 400px;
  height: 100px;
  background-color: #04af2f;
  text-align: center;
  font-family: Verdana, sans-serif;
  line-height: 100px;
  color: white;
  border-radius: 10px;
  transition: all 0.5s ease;
  margin: auto;
}

#box:hover {
  background-color: #031926;
  transform: scale(0.95);
  cursor: pointer;
}

<div id="box">Hover Over this div Element</div>

Key Notes

  • An ID must be unique within an HTML document.
  • ID selectors have higher specificity than class selectors.
  • Useful for targeting one specific element for styling or JavaScript manipulation.
  • Should be used sparingly compared to classes for better reusability.

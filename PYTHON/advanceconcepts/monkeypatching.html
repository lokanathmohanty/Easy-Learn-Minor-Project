Python - Monkey Patching

Monkey patching in Python refers to the practice of dynamically modifying or extending code at runtime, typically replacing or adding new functionalities to existing modules, classes, or methods without altering their original source code.

The term "monkey patching" originates from the idea of making changes in an ad-hoc or temporary manner, akin to how a monkey might patch something up using whatever materials are at hand.

Steps to Perform Monkey Patching

  1. Import the module or class you want to modify.
  2. Define a new function or method with the desired behavior.
  3. Replace the original function or method by assigning the new implementation to the attribute of the class or module.

Example of Monkey Patching

Original Module:

# original_module.py
class MyClass:
   def say_hello(self):
      return "Hello, Welcome to Tutorialspoint!"

Patch Module:

# patch_module.py
from original_module import MyClass

def new_say_hello(self):
   return "Greetings!"

MyClass.say_hello = new_say_hello

Testing the Patch:

# test_patch.py
from original_module import MyClass
import patch_module

obj = MyClass()
print(obj.say_hello())    # Output: Greetings!

Drawbacks of Monkey Patching

  • Overuse: Excessive monkey patching can make code hard to understand and maintain. Use it judiciously.
  • Compatibility: It may introduce unexpected behaviors, especially in complex or large code bases.

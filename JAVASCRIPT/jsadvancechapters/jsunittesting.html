JavaScript - Unit Testing

Unit testing is an important part of the software development life-cycle. It is the process of testing small units of code individually to ensure that they are working correctly. In JavaScript, various unit testing frameworks can be used to test our code.

Unit testing helps developers catch bugs early in the development process. Instead of testing the entire application, small units of code are tested independently.

Why Unit Testing?

  • Catch bugs early: By testing smaller parts of code, bugs can be identified early in the development process.
  • Easier refactoring: Unit testing gives confidence when making changes, since existing code has already been tested.
  • Improves code quality: Writing unit tests encourages modular and maintainable code that is easier to test.

Unit Testing Frameworks

Some popular JavaScript unit testing frameworks include:

  • Jest: Developed by Facebook, Jest is widely used, fast, and comes with everything needed for testing.
  • Mocha: Runs on Node.js and in the browser, supports asynchronous testing, and provides flexible reporting.
  • Jasmine: A behavior-driven development framework that does not rely on browsers or DOM, inspired by other testing tools.
  • QUnit: A powerful and easy-to-use framework used by the jQuery project, suitable for any JavaScript code.

Structure of Unit Testing

Typical unit test cases follow these steps:

  • Setup: Prepare the test environment (create objects, initialize variables, etc.).
  • Execute: Run the code you want to test.
  • Assert: Verify that the result matches the expected outcome.
  • Teardown: Clean up the test environment (destroy objects, reset variables, etc.).

Example: Unit Test Using Jest

Code:

function sum(a, b) {
    return a + b;
}
module.exports = sum;

// test.js
const sum = require('./sum');

test('adds 1 + 2 to equal 3', () => {
    expect(sum(1, 2)).toBe(3);
});

Output:

PASS  ./sum.test.js
  adds 1 + 2 to equal 3 (3ms)

In this example, a function sum is defined which returns the sum of two numbers. A test case is written using Jest to check if the function works correctly.

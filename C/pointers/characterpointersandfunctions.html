Character Pointers and Functions in C

What Is a Character Pointer?

A character pointer stores the address of a char or the address of the first character in a character array (string). In C, strings are represented as arrays of char, so a char* often refers to a string.

Declaring a Character Pointer

Syntax:

char *pointer_name;

Initializing a Character Pointer

To point to a single character:

char c = 'A';
char *ptr = &c;

To point to a character array (string):

char arr[] = "Hello";
char *ptr = arr;
// or equivalently
char *ptr = &arr[0];

Character Pointer Example

#include <stdio.h>

int main() {
  char x = 'P';
  char arr[] = "TutorialsPoint";

  char *ptr_x = &x;
  char *ptr_arr = arr;

  printf("Value of x : %c\n", *ptr_x);
  printf("Value of arr: %s\n", ptr_arr);

  return 0;
}

Output:

Value of x : P
Value of arr: TutorialsPoint

Understanding Character Pointers and Strings

The string char arr[] = "Hello"; is a NULL-terminated array of characters. The last character is '\0'. You can traverse this string via a char*:

char *ptr = arr;
while (*ptr != '\0') {
  printf("%c", *ptr);
  ptr++;
}

You can also directly print the string via printf("%s", ptr);.

Character Pointer Functions (string.h)

strlen()

Returns the length (number of characters) of a string. Prototype:

size_t strlen(const char *s);

Example:

#include <stdio.h>
#include <string.h>

int main() {
  char *ptr = "Hello";
  printf("Given string: %s\n", ptr);
  printf("Length of the string: %zu\n", strlen(ptr));
  return 0;
}

strcpy()

Copies one string to another. Prototype:

char *strcpy(char *dest, const char *src);

Example usage:

#include <stdio.h>
#include <string.h>

int main() {
  char source[] = "Hello";
  char dest[20];
  strcpy(dest, source);
  printf("%s\n", dest);
  return 0;
}

strcmp()

Compares two strings lexicographically. Prototype:

int strcmp(const char *s1, const char *s2);

Return values:

  • 0 if both strings are identical
  • Positive if first non-matching character in s1 > in s2
  • Negative if first non-matching character in s1 < in s2

Example:

#include <stdio.h>
#include <string.h>

int main() {
  char *s1 = "BASK";
  char *s2 = "BALL";
  int ret = strcmp(s1, s2);

  if (ret == 0)
    printf("Both strings are identical\n");
  else if (ret > 0)
    printf("First string appears after second\n");
  else
    printf("First string appears before second\n");

  return 0;
}

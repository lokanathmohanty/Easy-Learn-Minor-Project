CSS - Resize

The CSS resize property allows users to adjust the size of an element on a webpage. This property gives a resizable handle (typically at the bottom-right corner) that lets users click and drag to change the width, height, or both dimensions of an element. The property is especially useful for textareas, divs, images, and other replaceable elements.

By default, only elements with overflow set to a value other than visible can be resized. The property can be controlled using different values such as none, vertical, horizontal, both, block, and inline.

Possible Values

  • none − The element cannot be resized. This is the default value.
  • vertical − The element can only be resized vertically (up or down).
  • horizontal − The element can only be resized horizontally (left or right).
  • both − The element can be resized both vertically and horizontally.
  • block − The element can be resized in the block direction, depending on the writing mode.
  • inline − The element can be resized in the inline direction, depending on the writing mode.

Syntax

The syntax of the CSS resize property is:

resize: none | vertical | horizontal | both;

Examples of CSS Resize

1. Resize: none

In this example, the textarea cannot be resized in any direction. This demonstrates the none value.

<textarea style="resize: none; overflow: auto;">Content...</textarea>

2. Resize: vertical

Here, the user can only resize the element vertically, meaning the height can be changed but not the width.

<div style="resize: vertical; overflow: auto;">Content...</div>

3. Resize: horizontal

In this case, the user can only adjust the element’s width by dragging horizontally.

<div style="resize: horizontal; overflow: auto;">Content...</div>

4. Resize: both

With both, the user can resize the element in both width and height directions.

<div style="resize: both; overflow: auto;">Content...</div>

5. Resize: inherit

The inherit value means the element inherits its resize behavior from its parent container.

<div style="resize: inherit;">Content...</div>

6. Arbitrary Elements

It is also possible to make multiple nested elements resizable. For example, a div container and a p tag inside it can both be resized.

<div style="resize: both; overflow: scroll;"><p style="resize: both;">Content...</p></div>

Practical Use Cases

  • Forms: Making a textarea resizable allows users to expand the text area to better view long text.
  • Widgets: Dashboard widgets or containers can be made resizable for improved customization.
  • Design Tools: Resizable divs can allow users to create dynamic layouts.

Conclusion

The resize property provides flexibility to users when interacting with content. By combining it with overflow and other properties, developers can create responsive and interactive web experiences. However, care should be taken not to break layouts by overusing resizable containers.

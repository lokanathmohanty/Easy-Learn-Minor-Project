Zipf Distribution

Zipf distributions are used to sample data based on Zipf's law.

Zipf's Law: In a collection, the nth most common term occurs approximately 1/n times as often as the most common term. For example, the 5th most common word in English occurs nearly 1/5 times as often as the most common word.

Parameters:

  • a — Distribution parameter.
  • size — The shape of the returned array.

Example: Generating Zipf Distribution Samples

Generate a 2x3 sample from a Zipf distribution with distribution parameter 2:

from numpy import random

x = random.zipf(a=2, size=(2, 3))

print(x)

Visualization of Zipf Distribution

Sample 1000 points but plot only those with value less than 10 for a more meaningful chart:

from numpy import random
import matplotlib.pyplot as plt
import seaborn as sns

x = random.zipf(a=2, size=1000)
sns.displot(x[x < 10])

plt.show()

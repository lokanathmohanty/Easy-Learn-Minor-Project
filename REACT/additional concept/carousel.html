ReactJS - Carousel

React provides carousel component through third party UI component library. React community provides a large collection of UI / UX components and it is tough to choose the right library for our requirement. Bootstrap UI library is one of the popular choices and React Bootstrap has best support for Carousel component.

Let us learn how to use Carousel component from react-bootstrap library in this chapter.

What is Carousel?

Carousel is a slideshow cycling through a series of content with animation support. It accepts images as main content and titles for each slide. It provides navigation buttons or indicators to switch between slides and allows configuration of time duration between slides.

Carousel component

Carousel component allows developers to create simple carousel with bootstrap design in a web application. It accepts two components:

  • Carousel.Item − Represents a slide with image content.
  • Carousel.Caption − Displays description about the slide.

Example: Carousel with Carousel.Item

<Carousel>
  <Carousel.Item>
    <img className="d-block w-100" src="react_bootstrap_carousel_slide1.png" alt="First slide" />
  </Carousel.Item>
  <Carousel.Item>
    <img className="d-block w-100" src="react_bootstrap_carousel_slide2.png" alt="Second slide" />
  </Carousel.Item>
</Carousel>

Example: Carousel with Carousel.Caption

<Carousel.Item>
  <img className="d-block w-100" src="react_bootstrap_carousel_slide1.png" alt="First slide" />
  <Carousel.Caption>
    <h3>React Bootstrap</h3>
    <p>React component library providing bootstrap components</p>
  </Carousel.Caption>
</Carousel.Item>

Carousel Props

Carousel supports the following props:

  • controls (boolean) − Enables/disables navigation buttons
  • keyboard (boolean) − Enables keyboard controls
  • touch (boolean) − Enables/disables touch controls
  • indicators (boolean) − Enables/disables slide indicators
  • nextIcon (React node) − Custom next icon
  • nextLabel (string) − Custom next label
  • prevIcon (React node) − Custom previous icon
  • prevLabel (string) − Custom previous label
  • interval (number) − Time duration for slides
  • activeIndex (number) − Index of slide to show
  • slide (boolean) − Enables/disables auto slide
  • variant (dark) − Switches carousel theme
  • bsPrefix (string) − Custom CSS class prefix
  • onSelect (function) − Event handler for selecting a slide
  • onSlide (function) − Event handler for slide change

Carousel.Item Props

  • interval (number) − Time duration for individual slide
  • bsPrefix (string) − Custom CSS class prefix

Example: Applying Carousel component

Create and start a react application:

create-react-app myapp
cd myapp
npm start

Install bootstrap and react-bootstrap:

npm install --save bootstrap react-bootstrap

Example component (SimpleCarousel.js):

import { Carousel } from 'react-bootstrap';
function SimpleCarousel() {
  return (
    <Carousel fade indicators={false} controls={false}>
      <Carousel.Item>
        <img className="d-block w-100" src="react_bootstrap_carousel_slide1.png" alt="First slide" />
        <Carousel.Caption>
          <h3>React Bootstrap</h3>
          <p>React component library providing bootstrap components</p>
        </Carousel.Caption>
      </Carousel.Item>
      // more slides...
    </Carousel>
  );
}
export default SimpleCarousel;

Example usage in App.js:

import './App.css'
import "bootstrap/dist/css/bootstrap.min.css";
import SimpleCarousel from './Components/SimpleCarousel'

function App() {
  return (
    <div className="container">
      <SimpleCarousel />
    </div>
  );
}
export default App;

Example: Add controls and indicators

Update SimpleCarousel to enable controls and indicators:

<Carousel fade indicators={true} controls={true}>
  <Carousel.Item>
  // ...
</Carousel>

Summary

React-bootstrap Carousel component provides all necessary options to create a clean and simple carousel component with customization support.

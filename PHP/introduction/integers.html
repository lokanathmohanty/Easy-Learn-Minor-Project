PHP Integers (`int`) Data Type

The **Integer (`int`)** data type is a basic scalar type in PHP used to represent **whole numbers** (positive, negative, or zero) without a decimal point. Integers are a fundamental data type for arithmetic operations and counting.

Representation and Syntax

Integers can be declared in several bases (notations):

  • **Decimal (Base 10):** Standard numbers (e.g., `1234`, `-5`).
  • **Hexadecimal (Base 16):** Prefixed with **`0x`** (e.g., `0x1A`).
  • **Octal (Base 8):** Prefixed with **`0`** (pre-PHP 8.1) or **`0o`** / **`0O`** (e.g., `0123`, `0o123`).
  • **Binary (Base 2):** Prefixed with **`0b`** (e.g., `0b1111`).

Readability Enhancements (PHP 7.4.0+):

Underscores (`_`) can be used as separators between digits for better readability; they are ignored by the PHP parser.

$large_num = 1_234_567; // Interpreted as 1234567

Integer Range and Overflow

The size and range of an integer are **platform-dependent**.

  • **32-bit Systems:** Max value is approximately 2 billion.
  • **64-bit Systems:** Max value is approximately $9 \times 10^{18}$.

You can check the system's limits using the predefined constants:

  • **`PHP_INT_MAX`**: Maximum integer value.
  • **`PHP_INT_MIN`**: Minimum integer value.
  • **`PHP_INT_SIZE`**: Size of an integer in bytes.

Overflow:

If an integer operation results in a value that is **beyond the bounds** of the `int` type (i.e., greater than `PHP_INT_MAX` or less than `PHP_INT_MIN`), it is automatically interpreted as a **float** (floating-point number).

$y = 50000000000000 * 1000000; $\rightarrow$ `var_dump($y)` outputs `float(5.0E+19)`

Integer Arithmetic and Division

Standard arithmetic operations are supported. However, PHP's division operator (`/`) always returns a **float** when dividing an integer by a float, or if the result is not a whole number.

Integer Division

To obtain the integral part of a division result, you can use the **`intdiv()`** function.

$x = 10; $y = 3.5;
$z = $x / $y; $\rightarrow$ `float(2.857...)` (Standard division)
$z = intdiv($x, $y); $\rightarrow$ `int(3)` (Integer division, truncates the result)

Checking for Integers

PHP provides built-in functions to verify if a variable is of the integer type:

  • **`is_int($variable)`**
  • **`is_integer($variable)`** (Alias of `is_int()`)
  • **`is_long($variable)`** (Alias of `is_int()`, rarely used)

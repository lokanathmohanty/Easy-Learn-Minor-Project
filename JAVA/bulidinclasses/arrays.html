Java Programming: Data Structures

Session: Arrays

What are Arrays in Java?

An **array** is a fundamental data structure in Java used to store a **fixed-size sequential collection of elements of the same data type**. Arrays provide a way to store multiple variables of the same type under a single reference name.

Array elements are accessed using a **0-based index**, meaning the first element is at index 0 and the last element is at index arrayRefVar.length - 1.

Declaring and Creating Arrays

Declaration Syntax

The preferred syntax for declaring an array reference variable is:

dataType[] arrayRefVar; // Preferred style (e.g., double[] myList;)

Creation and Initialization

Arrays are objects in Java and must be created using the **new** operator, which allocates memory for the elements. Declaring and creating can be combined:

// 1. Creation with size (elements initialized to default values)
dataType[] arrayRefVar = new dataType[arraySize];

// 2. Creation with initialization values (size determined by elements)
dataType[] arrayRefVar = {value0, value1, ..., valuek};

Processing Array Elements

Standard `for` Loop

Used when you need to access the index of the elements (e.g., for reversing an array, or calculating sums):

double total = 0;
for (int i = 0; i < myList.length; i++) {
   total += myList[i]; // Accessing element by index
}

Enhanced `for` Loop (`foreach`)

Introduced in JDK 1.5, this loop simplifies iterating over all elements sequentially when the index is not needed:

// Print all the array elements
for (double element: myList) {
   System.out.println(element); // Accessing element value directly
}

Arrays and Methods

Passing Arrays to Methods

Arrays are reference types in Java. When an array is passed to a method, the method receives a copy of the **reference** to the array. Changes made to the array elements inside the method affect the original array.

public static void printArray(int[] array) {
   // ... processing array
}

Returning an Array from a Method

A method can declare an array as its return type, allowing it to generate and return a new array object.

public static int[] reverse(int[] list) {
   int[] result = new int[list.length];
   // logic to reverse elements
   return result; // Returns a reference to the new array
}

The `java.util.Arrays` Class

This class provides static utility methods for common array operations, overloaded for all primitive types:

  • **sort(Object[] a)**: Sorts the array into ascending order.
  • **binarySearch(Object[] a, Object key)**: Searches for a value (array must be sorted first).
  • **equals(Object[] a, Object[] a2)**: Compares two arrays for equality (same elements in the same order).
  • **fill(int[] a, int val)**: Assigns a specified value to every element of the array.

Java Vector Class Summary 🏗️

The **java.util.Vector** class is an implementation of the **List** interface that models a **dynamic array** (an array whose size can grow or shrink). It is a **legacy** class that was retrofitted into the Java Collections Framework (JCF) in Java 1.2.

Key Characteristics and Differences from ArrayList

While similar to ArrayList in its underlying data structure, Vector has two crucial distinctions:

  • Synchronization: **Vector is synchronized** (thread-safe). All its public methods are synchronized, ensuring that multiple threads can safely operate on a single Vector instance without external synchronization. This thread-safety, however, results in **slower performance** in single-threaded environments compared to the non-synchronized ArrayList.
  • Legacy Methods: It contains numerous legacy methods (like addElement(), elementAt(), and elements(), which returns an **Enumeration**) that are not part of the standard JCF List interface.

Capacity Management

A Vector manages its size using two properties:

  • **Capacity:** The size of the internal array.
  • **Capacity Increment:** A value that determines how much the capacity increases when the vector becomes full. This can be controlled via the constructor: 
    // initialCapacity is 3, capacityIncrement is 2
Vector v = new Vector(3, 2);
    When the size reaches the capacity, the new capacity becomes $Capacity + CapacityIncrement$. If the increment is zero (the default), the capacity typically doubles.
  • **int capacity():** Returns the size of the internal array.
  • **void trimToSize():** Reduces the capacity of the vector to its current size to conserve memory.

JavaScript - Array Destructuring

JavaScript Array destructuring allows us to unpack the values from an array and assign them to variables. After that, you can use the variables to access their value and use them in the code. The destructuring assignment is basically a JavaScript expression.

Syntax

const array = [10, 20];
const [var1, var2] = array;

In the above syntax, the array is the original array containing 10 and 20. When you unpack the array elements, var1 contains 10, and var2 contains 20.

Example: Basic Array Destructuring

const arr = [100, 500, 1000];
const [num1, num2, num3] = arr;

Output:

num1: 100
num2: 500
num3: 1000

Example: Unpacking with initial N elements

const arr = [1, 2, 3, 4, 5, 6];
const [num1, num2] = arr;

Output:

num1: 1
num2: 2

Skipping Array Elements

const arr = [1, 2, 3, 4, 5, 6];
const [num1, , num3, , num5] = arr;

Output:

num1: 1
num3: 3
num5: 5

Array Destructuring and Rest Operator

const arr = [1, 2, 3, 4, 5, 6];
const [num1, num2, ...nums] = arr;

Output:

num1: 1
num2: 2
nums: 3,4,5,6

Array Destructuring and Default Values

const arr = [1];
const [num1 = 10, num2 = 20, num3 = 30] = arr;

Output:

num1: 1
num2: 20
num3: 30

Swapping Variables Using Array Destructuring

let a = 50, b = 100;
[b, a] = [a, b];

Output:

Before Swapping: a = 50, b = 100
After Swapping: a = 100, b = 50

Destructuring the Returned Array from a Function

function getNums() {
   return [99, 80, 70];
}
const [num1, num2, num3] = getNums();

Output:

num1: 99
num2: 80
num3: 70

Node.js - MongoDB Create Database

Overview

MongoDB is a document-oriented NoSQL database where data is stored in JSON-like documents. Collections group documents, and multiple collections exist in a database.

MongoDB Editions

  • Community Edition: Free, self-managed, available for Windows, Linux, macOS.
  • Enterprise Edition: Commercial, subscription-based with advanced features.
  • Atlas: Cloud-based fully managed MongoDB service supporting AWS, Azure, GCP.

Connection Strings

MongoDB connection strings vary:

  • Standard: mongodb://[username:password@]host[:port]/[defaultdb]
  • SRV: mongodb+srv://[username:password@]host/[defaultdb] (used by Atlas)

Example:

const uri = "mongodb://localhost:27017";

List Databases using Node.js

const { MongoClient } = require('mongodb');

async function main() {
   const uri = "mongodb://localhost:27017";
   const client = new MongoClient(uri);

   try {
      await client.connect();

      const databasesList = await client.db().admin().listDatabases();

      console.log("Databases:");
      databasesList.databases.forEach(db => console.log(` - ${db.name}`));
   } catch (e) {
      console.error(e);
   } finally {
      await client.close();
   }
}

main().catch(console.error);

Sample Output:

Databases:
 - admin
 - config
 - local
 - myProject
 - mydb

Create a New Database

Use db() method of the MongoClient instance to get a database instance.

const db = client.db("mydatabase");
console.log("Database instance created");
console.log(db);

Note: The database is not physically created until at least one collection and one document exist.

Complete Example

const { MongoClient } = require('mongodb');

async function main() {
   const uri = "mongodb://localhost:27017";
   const client = new MongoClient(uri);

   try {
      await client.connect();

      const db = client.db("mydatabase");
      console.log("Database instance created");
      console.log(db);
   } catch (e) {
      console.error(e);
   } finally {
      await client.close();
   }
}

main().catch(console.error);

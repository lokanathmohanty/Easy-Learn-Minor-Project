Java - Date and Time

Java provides the Date class available in java.util package, this class encapsulates the current date and time.

Date Class Constructors

The Date class supports two constructors as shown below:

  • Date(): Initializes the object with the current date and time.
  • Date(long millisec): Accepts milliseconds elapsed since midnight, January 1, 1970.

Date Class Methods

  • boolean after(Date when): Tests if this date is after the specified date.
  • boolean before(Date when): Tests if this date is before the specified date.
  • Object clone(): Returns a copy of this object.
  • int compareTo(Date anotherDate): Compares two Dates for ordering.
  • boolean equals(Object obj): Compares two dates for equality.
  • static Date from(Instant instant): Obtains an instance of Date from an Instant object.
  • long getTime(): Returns milliseconds since January 1, 1970 GMT.
  • int hashCode(): Returns a hash code value for this object.
  • void setTime(long time): Sets this Date object to a given time in milliseconds.
  • Instant toInstant(): Converts this Date object to an Instant.
  • String toString(): Converts this Date object to a String.

Getting Current Date and Time

This is a very easy method to get current date and time in Java using Date object and toString() method.

Example

import java.util.Date;
public class DateDemo {
   public static void main(String args[]) {
      // Instantiate a Date object
      Date date = new Date();
      // display time and date using toString()
      System.out.println(date.toString());
   }
}

This will produce the following output:

on May 04 09:51:52 CDT 2009

Date Comparison

Three ways to compare two dates:

  • Use getTime() to compare milliseconds.
  • Use before(), after(), and equals() methods.
  • Use compareTo() method.

Date Formatting Using SimpleDateFormat

SimpleDateFormat formats and parses dates using user-defined patterns.

Example

import java.util.*;
import java.text.*;

public class DateDemo {
   public static void main(String args[]) {
      Date dNow = new Date();
      SimpleDateFormat ft = new SimpleDateFormat("E yyyy.MM.dd 'at' hh:mm:ss a zzz");
      System.out.println("Current Date: " + ft.format(dNow));
   }
}

This produces output like:

Current Date: Sun 2004.07.18 at 04:14:09 PM PDT

SimpleDateFormat Format Codes

  • G: Era designator (e.g., AD)
  • y: Year in four digits (e.g., 2001)
  • M: Month in year (e.g., July or 07)
  • d: Day in month (e.g., 10)
  • h: Hour in A.M./P.M. (1~12)
  • H: Hour in day (0~23)
  • m: Minute in hour
  • s: Second in minute
  • S: Millisecond
  • E: Day in week
  • ... (and others)

Date Formatting Using printf

Use printf method with formatting strings starting with 't' to format date and time.

Example

import java.util.Date;
public class DateDemo {
   public static void main(String args[]) {
      Date date = new Date();
      String str = String.format("Current Date/Time : %tc", date );
      System.out.printf(str);
   }
}

Sample output:

Current Date/Time : Sat Dec 15 16:37:57 MST 2012

Date and Time Conversion Characters

  • c: Complete date and time (Mon May 04 09:51:52 CDT 2009)
  • F: ISO 8601 date (2004-02-09)
  • D: U.S. formatted date (02/09/2004)
  • T: 24-hour time (18:05:19)
  • ... (and others)

Parsing Strings into Dates

SimpleDateFormat's parse() method parses a string according to its format.

Example

import java.util.*;
import java.text.*;

public class DateDemo {
   public static void main(String args[]) {
      SimpleDateFormat ft = new SimpleDateFormat("yyyy-MM-dd");
      String input = args.length == 0 ? "1818-11-11" : args[0];

      System.out.print(input + " Parses as ");
      try {
         Date t = ft.parse(input);
         System.out.println(t);
      } catch (ParseException e) {
         System.out.println("Unparseable using " + ft);
      }
   }
}

Sample output:

1818-11-11 Parses as Wed Nov 11 00:00:00 EST 1818

Sleeping for a While

Thread.sleep() pauses execution for a specified time.

Example

import java.util.*;
public class SleepDemo {
   public static void main(String args[]) {
      try {
         System.out.println(new Date() + "\n");
         Thread.sleep(5*60*10);
         System.out.println(new Date() + "\n");
      } catch (Exception e) {
         System.out.println("Got an exception!");
      }
   }
}

Sample output:

Sun May 03 18:04:41 GMT 2009
Sun May 03 18:04:51 GMT 2009

Measuring Elapsed Time

Measure elapsed time using System.currentTimeMillis().

Example

import java.util.*;
public class DiffDemo {
   public static void main(String args[]) {
      try {
         long start = System.currentTimeMillis();
         System.out.println(new Date() + "\n");
         Thread.sleep(5*60*10);
         System.out.println(new Date() + "\n");
         long end = System.currentTimeMillis();
         long diff = end - start;
         System.out.println("Difference is : " + diff);
      } catch (Exception e) {
         System.out.println("Got an exception!");
      }
   }
}

Sample output:

Sun May 03 18:16:51 GMT 2009
Sun May 03 18:16:57 GMT 2009
Difference is : 5993

GregorianCalendar Class

GregorianCalendar implements the Gregorian calendar. It offers multiple constructors and useful methods for date manipulation.

Constructors

  • GregorianCalendar(): Default calendar with current date/time.
  • GregorianCalendar(int year, int month, int date): Sets specific date.
  • GregorianCalendar(int year, int month, int date, int hour, int minute): Sets date and time.
  • ... (other constructors)

Key Methods

  • add(int field, int amount): Add time to a field.
  • get(int field): Get value of a field.
  • isLeapYear(int year): Checks leap year.
  • set(int field, int value): Set time field.
  • toString(): Returns string representation.
  • ... (others)

Example

import java.util.*;
public class GregorianCalendarDemo {
   public static void main(String args[]) {
      String months[] = {"Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", 
         "Oct", "Nov", "Dec"};
      int year;
      GregorianCalendar gcalendar = new GregorianCalendar();
      System.out.print("Date: ");
      System.out.print(months[gcalendar.get(Calendar.MONTH)]);
      System.out.print(" " + gcalendar.get(Calendar.DATE) + " ");
      System.out.println(year = gcalendar.get(Calendar.YEAR));
      System.out.print("Time: ");
      System.out.print(gcalendar.get(Calendar.HOUR) + ":");
      System.out.print(gcalendar.get(Calendar.MINUTE) + ":");
      System.out.println(gcalendar.get(Calendar.SECOND));
      if(gcalendar.isLeapYear(year)) {
         System.out.println("The current year is a leap year");
      } else {
         System.out.println("The current year is not a leap year");
      }
   }
}

Sample output:

Date: Apr 22 2009
Time: 11:25:27
The current year is not a leap year

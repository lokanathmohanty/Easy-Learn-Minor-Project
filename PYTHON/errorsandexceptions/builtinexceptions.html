Python Built-in Exceptions

Built-in exceptions are pre-defined error classes in Python that handle various error conditions and exceptional situations in programs. They are derived from the base class BaseException and are part of the standard library.

Standard Built-in Exceptions

Exception Name Description
ExceptionBase class for all exceptions
StopIterationRaised when the next() method does not point to any object
SystemExitRaised by the sys.exit() function
ArithmeticErrorBase class for numeric calculation errors
ZeroDivisionErrorRaised for division or modulo by zero
AssertionErrorRaised for assert statement failures
AttributeErrorRaised for attribute access or assignment errors
EOFErrorRaised when input() hits end of file
ImportErrorRaised if an import fails
LookupErrorBase class for lookup errors
IndexErrorRaised for invalid sequence index
KeyErrorRaised for missing dictionary keys
NameErrorRaised for undefined identifiers
TypeErrorRaised for invalid operation on a data type
ValueErrorRaised for invalid argument values
RuntimeErrorRaised for unspecified runtime errors
NotImplementedErrorRaised for missing abstract method implementation

Example Exceptions

IndexError - Accessing an invalid list index:

numbers = [10, 20, 30, 40]
for i in range(5):
    print(numbers[i])
# Raises IndexError at i=4

KeyError - Accessing a missing dictionary key:

d = {'a': 1, 'b': 2}
print(d['c'])  # KeyError: 'c'

ZeroDivisionError - Dividing by zero:

x = 10 / 0
# Raises ZeroDivisionError

Using Built-in Exceptions

Handle exceptions in your code using try-except blocks:

try:
    result = 10 / 0
except ZeroDivisionError as e:
    print(f"Caught exception: {e}")

Output:

Caught exception: division by zero

Handle multiple exceptions:

try:
    value = int('abc')
except (ValueError, TypeError) as e:
    print(f"Caught error: {e}")

Output:

Caught error: invalid literal for int() with base 10: 'abc'

Use else and finally clauses in try-except:

try:
    num = int(input("Enter a number: "))
except ValueError as e:
    print(f"Invalid input: {e}")
else:
    print(f"You entered: {num}")
finally:
    print("Execution completed.")

Python - Tuple Methods

Tuples in Python provide a limited set of built-in methods to analyze their contents because they are immutable. These methods mainly allow retrieving information about the elements.

Listing All Tuple Methods

You can list all available tuple methods and properties using dir() and get detailed documentation using help().

print(dir((1, 2)))
print(help((1, 2).index))

Common methods include:

  • count(obj) - Returns how many times the object appears in the tuple.
  • index(obj) - Returns the first index where the object appears.

Finding the Index of a Tuple Item

The index() method returns the first occurrence of an element in the tuple.

tup1 = (25, 12, 10, -21, 10, 100)
print("Tup1:", tup1)
x = tup1.index(10)
print("First index of 10:", x)

Output:

Tup1: (25, 12, 10, -21, 10, 100)
First index of 10: 2

Counting Tuple Items

The count() method returns how many times a specified object occurs in the tuple.

tup1 = (10, 20, 45, 10, 30, 10, 55)
print("Tup1:", tup1)
c = tup1.count(10)
print("Count of 10:", c)

Output:

Tup1: (10, 20, 45, 10, 30, 10, 55)
Count of 10: 3

Counting with Expressions

Items involving expressions are evaluated before counting.

tup1 = (10, 20/80, 0.25, 10/40, 30, 10, 55)
print("Tup1:", tup1)
c = tup1.count(0.25)
print("Count of 0.25:", c)

Output:

Tup1: (10, 0.25, 0.25, 0.25, 30, 10, 55)
Count of 0.25: 3

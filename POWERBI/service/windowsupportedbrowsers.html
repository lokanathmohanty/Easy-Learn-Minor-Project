Power BI - Window Supported Browsers

To use Power BI Service effectively via a web browser, it is important to use supported and modern browsers for optimal performance and experience.

Supported Browsers

  • Microsoft Edge (latest versions, e.g., version 120 and newer)
  • Google Chrome (latest desktop versions, e.g., version 94 and newer; on Windows 10 and newer)
  • Safari on Mac (recent versions, including Safari 16.4 and above)
  • Mozilla Firefox (latest desktop versions, e.g., version 93 and newer)

Note: Internet Explorer is not supported by Power BI and may have poor performance. Also, Power BI and related products do not run on iOS 10 or older browser versions.

Additional Information

Power BI uses fonts like Segoe UI and Din, which may not be available on all platforms, potentially causing differences in report appearance between Windows and macOS.

Getting Started with Power BI Service

Log in at https://app.powerbi.com with a valid account. Explore features such as recommended reports, creating new datasets, browsing recent files, accessing workspaces, and more.

Other Features

  • Use OneLake data hub to search and explore organizational datasets.
  • Create, manage, and share dashboards, reports, and apps.
  • Collaborate through shared workspaces; manage roles and security.
  • Leverage deployment pipelines for content lifecycle management.
  • Access training, community forums, and insights from the Power BI learning center.

Python - Syntax

Introduction

The Python syntax defines rules used to create a Python program. Python syntax is simple, readable, and similar to languages like Perl, C, and Java, but with some important differences.

First Python Program

We can run a Python program in two modes:

  • Interactive Mode
  • Script Mode

Interactive Mode

$ python3
>>> print("Hello, World!")
Hello, World!

Script Mode

Create a test.py file with the following:

print("Hello, World!")

Run it using:

$ python3 test.py
Hello, World!

Python Identifiers

Identifiers are names used for variables, functions, classes, etc. Rules:

  • Must begin with a letter or underscore, followed by letters, digits, or underscores.
  • Cannot contain symbols like @, $, %.
  • Case sensitive (Manpower and manpower are different).

Naming conventions:

  • Class names start with uppercase.
  • Leading underscore → private identifier.
  • Double leading underscores → strongly private.
  • Double leading and trailing underscores → special system names.

Python Reserved Words

These are reserved and cannot be used as identifiers:

and, as, assert, break, class, continue,
def, del, elif, else, except, False,
finally, for, from, global, if, import,
in, is, lambda, None, nonlocal, not,
or, pass, raise, return, True, try,
while, with, yield

Lines and Indentation

Python uses indentation (not braces) for blocks of code:

if True:
    print("True")
else:
    print("False")

Incorrect indentation causes errors.

Multi-Line Statements

Use \ for line continuation:

total = item_one + \
        item_two + \
        item_three

Inside [], {}, () continuation is automatic.

Quotations

Python supports single ('), double ("), and triple (''' or """) quotes.

word = 'word'
sentence = "This is a sentence."
paragraph = """This is a paragraph
spanning multiple lines."""

Comments

Use # for single-line comments:

# This is a comment
print("Hello, World!")  # Inline comment

Triple-quoted strings can act as multi-line comments.

Blank Lines

Blank lines are ignored by Python. In the interactive shell, an empty line terminates multi-line input.

Waiting for User Input

#!/usr/bin/python
input("\n\nPress the enter key to exit.")

Multiple Statements on One Line

Use semicolons:

import sys; x = 'foo'; sys.stdout.write(x + '\n')

Suites

Groups of statements form suites, used in if, while, def, class.

if condition:
    suite
elif condition:
    suite
else:
    suite

Command Line Arguments

Run Python with -h to see available options:

$ python3 -h
usage: python3 [option] ... [-c cmd | -m mod | file | -] [arg] ...

Arguments and options can be passed to scripts for dynamic behavior.

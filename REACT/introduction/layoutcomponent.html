ReactJS - Layout in Component

Introduction

One of the advanced features of React is that it allows arbitrary user interface (UI) content to be passed into the component using properties. Unlike React’s special children property, which allows only a single UI content, this option enables multiple UI content to be passed into the component. This can be seen as an extension of children property.

A common use case is creating layouts with customizable header and footer.

Example

A simple example with header and footer props:


<Layout header={<h1>Header</h1>} footer={<p>footer</p>} />

Layout render logic:


return (
   <div>
      <div>{props.header}</div> 
      <div>Component user interface</div> 
      <div>{props.footer}</div> 
   </div>
);

Adding Layout to ExpenseEntryItemList

  • Open ExpenseEntryItemList.js in src/components.
  • Use header and footer props in the render() method.

return (
   <div> 
      <div>{this.props.header}</div> 
         ... existing code ... 
      <div>{this.props.footer}</div> 
   </div>
);

Using Header and Footer in index.js


ReactDOM.render(
   <React.StrictMode>
      <ExpenseEntryItemList 
         items={items}
         header={<div><h1>Expense manager</h1></div>}
         footer={
            <div style={{ textAlign: "left" }}>
               <p style={{ fontSize: 12 }}>Sample application</p>
            </div>
         } 
      />
   </React.StrictMode>,
   document.getElementById('root')
);

Run npm start and open http://localhost:3000 to see the customized header and footer in the expense manager.

Sharing Logic in Component (Render Props)

Introduction

Render props is an advanced concept used to share logic between React components. As we saw in children and layout concepts, a component can receive arbitrary UI content or React elements via properties. Normally, the component renders the UI it receives, but does not share logic.

With Render Props, a component can take a function as a property. This function returns UI and can receive computed values from the component, enabling logic sharing.

Definition

A component property that accepts a function returning UI is called a Render Prop. The receiving component performs advanced logic and passes results to the Render Prop function, which then renders the UI.

Use Cases

Many advanced third-party libraries use Render Props, such as:

  • React Router
  • Formik
  • Downshift

Example: Formik handles form validation and submission, while the Render Prop function defines the form UI. Similarly, React Router manages routing logic while delegating UI rendering through Render Props.

HTML - QR Code

Introduction

A QR Code (Quick Response Code) is a type of 2D matrix barcode. It consists of black squares arranged on a white background. QR codes can store many types of information, including:

  • Phone numbers
  • Website URLs
  • Plain text (up to 4000 characters)

Usage

QR codes are widely used in mobile payments, product labels, authentication systems, and easy URL sharing. When scanned with a smartphone or QR scanner, the code reveals the encoded information instantly.

QR Code Generator Tool

The QR Generator below lets you input any text or URL, and it will automatically generate a QR code for it.


Example Code

<!-- HTML QR Code Example -->
<div class="qr-generator">
  <input type="text" id="qr-input" placeholder="Enter text or URL">
  <div id="qr-output"></div>
</div>

<script src="https://cdn.jsdelivr.net/npm/qrcodejs/qrcode.min.js"></script>
<script>
  const input = document.getElementById('qr-input');
  const output = document.getElementById('qr-output');
  let qr = new QRCode(output, { text: "https://www.tutorialspoint.com", width: 128, height: 128 });

  input.addEventListener('input', function() {
    output.innerHTML = "";
    qr = new QRCode(output, { text: input.value, width: 128, height: 128 });
  });
</script>

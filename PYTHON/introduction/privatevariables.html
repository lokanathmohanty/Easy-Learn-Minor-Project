Python - Private Variables

Python is an object-oriented programming language that allows you to create classes and objects. Encapsulation is one of the core principles of OOPs. To achieve encapsulation, we use private variables and methods. In this session, we will discuss private variables in Python and how to use them.

What are Private Variables?

Private variables are a special type of variable that is only accessible within the class they are defined in. They are not directly accessible from outside the class or from any subclass. This helps protect data from unauthorized access or modification.

Access to private variables can be allowed using getter and setter methods.

Defining Private Variables in Python

In Python, private variables are defined using a double underscore __ before the variable name. A single underscore _ indicates a protected variable.

Example

class MyClass:
    def __init__(self):
        self.__private_var = "I am Private"

    def show_private(self):
        return self.__private_var

obj = MyClass()
print(obj.show_private())   # ✓ Access through method
# print(obj.__private_var)  # ✗ AttributeError

Name Mangling for Private Variables

Private variables can still be accessed outside the class using name mangling. Python internally changes __var to _ClassName__var.

Example

obj = MyClass()
print(obj._MyClass__private_var)  # Access using name mangling

Private Methods in Python

Similar to variables, methods can also be private by prefixing with double underscore.

Example

class MyClass:
    def __init__(self):
        self.__private_var = "I am Private"

    def __private_method(self):
        return "This is a private method"

    def show_private(self):
        return self.__private_var + " and " + self.__private_method()

obj = MyClass()
print(obj.show_private())                  # ✓ Access through method
print(obj._MyClass__private_method())      # ✓ Access using name mangling

Real World Example of Private Variables

A banking application ensures sensitive data like balance is private. Access is provided through methods like deposit and withdraw.

Example

class BankAccount:
    def __init__(self, account_number, balance):
        self.__account_number = account_number
        self.__balance = balance

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
        return self.__balance

    def withdraw(self, amount):
        if 0 < amount <= self.__balance:
            self.__balance -= amount
        return self.__balance

    def get_balance(self):
        return self.__balance

account = BankAccount("12345", 1000)
print(account.get_balance())  # 1000
account.deposit(500)
print(account.get_balance())  # 1500

Public vs Protected vs Private Variables

  • Public Variables: Accessible from anywhere.
  • Protected Variables: Accessible within class and subclasses.
  • Private Variables: Accessible only within the class itself.

Syntax

  • Public: var
  • Protected: _var
  • Private: __var

Conclusion

Private variables help achieve encapsulation in Python. Although name mangling allows access from outside, it is not recommended as it breaks encapsulation principles. Getter and setter methods should be used instead.

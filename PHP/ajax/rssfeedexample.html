PHP - AJAX RSS Feed Integration Example

Really Simple Syndication (RSS) and AJAX

The **Really Simple Syndication (RSS)** format is used to publish frequently updated web content (like news, blogs, and media). This example demonstrates integrating **RSS feeds** into a website using the **AJAX** pattern with **PHP** as the server-side processor. The user can select a news source, and the latest headlines are fetched and displayed dynamically without reloading the page.

Client-Side Logic ($\text{index.html}$)

The client page contains a $\text{select}$ form element. When the user changes the selection ($\text{onchange}$), the **$\text{showRSS()}$** JavaScript function is executed. This function performs the following steps:

  • Creates an **$\text{XMLHttpRequest}$ ($\text{XHR}$)** object.
  • Sends an asynchronous $\text{GET}$ request to $\text{rss.php}$, passing the selected feed value ($\text{cnn}$, $\text{bbc}$, $\text{pc}$) as the $\text{q}$ query parameter.
  • Upon receiving a successful response ($\text{readyState} = 4$, $\text{status} = 200$), it updates the content of the $\text{\div id="output"}$ element with the $\text{responseText}$ received from the server.

Example: Server-Side RSS Parsing ($\text{rss.php}$)

PHP Feed Selection and Parsing

The $\text{rss.php}$ script receives the feed choice ($\text{\$q}$) via $\text{\$_GET}$ and uses PHP's **$\text{DOMDocument}$** class to retrieve and parse the external RSS XML data.

  1. **Determine URL:** An $\text{if/elseif}$ structure maps the input query ($\text{\$q}$) to the corresponding RSS feed $\text{URL}$ ($\text{\$xml}$).
  2. **Load XML:** The $\text{\$xmlDoc->load(\$xml);}$ method loads the external XML data directly from the $\text{URL}$.
  3. **Extract Channel Info:** It uses $\text{getElementsByTagName()}$ to extract and $\text{echo}$ the channel's general information ($\text{title}$, $\text{link}$, $\text{description}$).
  4. **Extract Items:** It fetches all $\text{}$ elements ($\text{\$x}$), which represent the individual news stories. The script then iterates through the first few items (up to $\text{i <= 2}$) to extract the $\text{item}$'s $\text{title}$, $\text{link}$, and $\text{description}$.
  5. **Generate HTML Output:** The extracted data is formatted into HTML paragraphs and links and $\text{echo}$ed back to the client as the AJAX response.

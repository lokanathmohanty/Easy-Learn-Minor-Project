Node.js - MongoDB Create Collection

Overview

A MongoDB database contains collections, which group documents. Collections are similar to tables in relational databases but have no fixed schema.

Creating a Collection

Use the createCollection() method on a database object in Node.js to explicitly create collections. 

const db = client.db("mydatabase");
const collection = await db.createCollection("MyCollection");
console.log("Collection created");
console.log(collection);

Note: A collection is implicitly created if you insert a document into a non-existent collection.

Example Code

const { MongoClient } = require("mongodb");

async function main() {
  const uri = "mongodb://localhost:27017/";
  const client = new MongoClient(uri);

  try {
    await client.connect();
    await createCollection(client, "mydatabase");
  } finally {
    await client.close();
  }
}

async function createCollection(client, dbName) {
  const db = client.db(dbName);
  const collection = await db.createCollection("MyCollection");
  console.log("Collection created");
  console.log(collection);
}

main().catch(console.error);

After running, verify in MongoDB shell: 

use mydatabase
show collections

This will confirm the creation of MyCollection.

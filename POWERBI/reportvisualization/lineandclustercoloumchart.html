Power BI: Line and Clustered Column Chart

The Line and Clustered Column Chart is a combination chart made of a line chart and a clustered column chart. It helps uncover trends and compare sales production or other measures by categories such as country or year.

Creating the Chart

  • Load the dataset into Power BI Desktop.
  • Select the "Line and Clustered Column Chart" visual from the Visualizations pane.
  • Add the Country field to the X-axis.
  • Add the sales production fields (e.g., Sales Production in 1990 and Sales Production in 1991) to the Column Y-axis.
  • Add the Sales Production in 1992 field to the Line Y-axis.
  • Use Small Multiples by adding the Country field to subdivide the visual into smaller charts by country.
  • Enhance Tooltips by adding additional sales fields (e.g., Sales Production in 1993) to show detailed info on hover.

Customization Options

  • X-axis: Change font style to "DIN", size to 14, color from palette, enable and customize title text (e.g., "Interactive chart") with font "Constantia".
  • Y-axis: Set minimum value to 1, modify font style to "Georgia", color to #717bc5, customize title text ("Sales productions") and styling.
  • Secondary Y-axis: Configure range, set font style to "Symbol", size 12, color #09124f, and customize title similarly.
  • Legend: Position at bottom left, customize font to "Segoe UI", italic style, color #e8d166.
  • Gridlines: Enable, change to dashed style, and select desired color for horizontal gridlines.
  • Zoom Sliders: Add zoom controls for both Y-axes to zoom in/out on data.
  • Columns: Adjust transparency of column bars, enable border with chosen color.
  • Lines: Set line style to dotted, choose "Miter" line type, and increase stroke width for emphasis.
  • Markers: Add marker shapes (e.g., circles) on line data points for clarity.
  • Data Labels and Series Labels: Enable and customize font style, size, and color for better readability on the chart.

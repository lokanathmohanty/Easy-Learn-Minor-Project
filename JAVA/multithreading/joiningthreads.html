Joining Threads in Java

Joining threads in Java means waiting (or blocking) one thread until another thread finishes its execution. The join() method of the Thread class is used for this purpose.

Syntax

The basic syntax of the join() method is:

void join();

Overloaded join() Methods

  • join() - Blocks the current thread until the other thread terminates.
  • join(long millisec) - Blocks the current thread until the other thread terminates or the specified milliseconds elapse.
  • join(long millisec, int nanos) - Blocks until the other thread terminates or the specified milliseconds plus nanoseconds elapse.

How join() Works

When a thread calls join() on another thread, it waits for that thread to complete before continuing its own execution. This is useful for coordinating multiple threads in a program.

Example: Sequential Thread Execution Using join()

This example creates three threads and uses join() to ensure they execute one after another.


class MyThread extends Thread {
    @Override
    public void run() {
        System.out.println(Thread.currentThread().getName() + " is running");
    }
}

public class ThreadJoinExample {
    public static void main(String[] args) throws InterruptedException {
        MyThread t1 = new MyThread();
        MyThread t2 = new MyThread();
        MyThread t3 = new MyThread();

        t1.start();
        t1.join();

        t2.start();
        t2.join();

        t3.start();
        t3.join();

        System.out.println("All threads have finished execution");
    }
}

Example: Using Timed join()

This example demonstrates waiting for a thread with a timeout, using join(long millis).


class TimedThread extends Thread {
    @Override
    public void run() {
        try {
            Thread.sleep(1000);
            System.out.println(Thread.currentThread().getName() + " has finished work");
        } catch (InterruptedException e) {
            System.out.println(Thread.currentThread().getName() + " was interrupted");
        }
    }
}

public class TimedJoinExample {
    public static void main(String[] args) throws InterruptedException {
        TimedThread t1 = new TimedThread();
        t1.start();
        t1.join(500);

        if (t1.isAlive()) {
            System.out.println(t1.getName() + " is still running after 500ms");
        } else {
            System.out.println(t1.getName() + " has finished within 500ms");
        }
    }
}

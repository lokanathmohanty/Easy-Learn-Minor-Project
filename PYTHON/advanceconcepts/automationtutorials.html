Python - Automation Tutorial

Automation with Python involves using programming techniques to perform tasks automatically without human intervention. Python offers numerous libraries for automating repetitive tasks such as scheduling, web scraping, GUI automation, and testing.

Key automation libraries include:

  • unittest: Unit testing framework.
  • Selenium: Web automation for browsers.
  • Beautiful Soup: HTML and XML parsing for web scraping.
  • pandas: Data manipulation and analysis.
  • requests: HTTP requests handling.
  • PyAutoGUI: GUI automation for mouse and keyboard actions.

This tutorial covers scheduling with the schedule module, web scraping with Beautiful Soup, and GUI automation with PyAutoGUI.

Ensure required packages are installed:
pip install schedule beautifulsoup4 pyautogui

Scheduling Tasks with schedule Module

import schedule
import time

def alarm():
    print("Time to restart the server")

def job():
    print("Starting daily tasks")

def meet():
    print("Weekly standup meeting")

schedule.every(5).seconds.do(alarm)  # Runs every 5 seconds
schedule.every().day.at("10:30").do(job)  # Runs daily at 10:30 AM
schedule.every().monday.at("12:15").do(meet)  # Runs Mondays at 12:15 PM

while True:
    schedule.run_pending()
    time.sleep(0.5)

Web Scraping with Beautiful Soup

from bs4 import BeautifulSoup
from urllib.request import urlopen
import re

html = urlopen("https://www.tutorialspoint.com/python/index.htm")
content = html.read()
soup = BeautifulSoup(content, "html.parser")

for a in soup.findAll('a', href=True):
    if re.findall('python', a['href']):
        print("Python URL:", a['href'])

Automating Mouse Movements with PyAutoGUI

import pyautogui

for i in range(5):
    pyautogui.moveTo(300, 100, duration=0.25)
    pyautogui.move(300, 0, duration=0.25)
    pyautogui.move(0, 300, duration=0.25)
    pyautogui.move(-300, 0, duration=0.25)
    pyautogui.move(0, -300, duration=0.25)

Output:

Mouse moves in a square pattern multiple times.

Automated Unit Testing with unittest Module

import unittest

class TestingStringMethods(unittest.TestCase):

    def test_string_equality(self):
        self.assertEqual('ttp' * 5, 'ttpttpttpttpttp')

    def test_string_case(self):
        self.assertEqual('Tutorialspoint'.upper(), 'TUTORIALSPOINT')

    def test_is_string_upper(self):
        self.assertTrue('TUTORIALSPOINT'.isupper())
        self.assertFalse('TUTORIALSpoint'.isupper())

    def test_string_startswith(self):
        self.assertTrue('tutorialspoint'.startswith('putor'))
        self.assertFalse('tutorialspoint'.startswith('point'))

if __name__ == '__main__':
    unittest.main(verbosity=2)

JavaScript - Function() Constructor

The Function() constructor in JavaScript can dynamically create a function object at runtime. Functions created this way always have global scope.

Although powerful, it should be used with caution because it can introduce vulnerabilities into your code.

Multiple arguments can be passed to the constructor. All arguments except the last one are treated as parameter names, while the last argument is the function body.

Syntax


const obj = new Function(arg1, arg2, ..., functionBody);

The constructor can be called with or without the new keyword.

  • arg1, arg2... → Names of parameters (optional)
  • functionBody → JavaScript statements comprising the function definition

Example: Multiplication


const func = new Function("p", "q", "return p * q");
func(5, 7); // 35

Output: The value returned from the function is: 35

Example: Single Argument (Function Body Only)


const func = new Function("return 10 + 20");
func(); // 30

Output: The value returned from the function is: 30

Function Declaration or Expression as Parameter

Creating functions with the Function() constructor is generally less efficient than using function declarations or expressions. However, you can pass multiple statements (separated by semicolons) in the functionBody.

Example: Function Expression


const add = new Function(
  "const sum = function (a, b) { return a + b }; return sum"
)();
add(5, 10); // 15

Example: Function Declaration


const sayHello = new Function(
  "return function (name) { return `Hello, ${name}` }"
)();
sayHello("world"); // Hello, world

Note: In both examples, the new Function is self-invoked.

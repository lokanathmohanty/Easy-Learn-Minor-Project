PHP Function Default Arguments

In PHP, a function parameter can be assigned a **default value** directly in the function definition. This makes the argument optional when the function is called. If the caller omits the argument, the default value is used; otherwise, the passed argument value **overrides** the default.

Function Definition and Usage

**Syntax:**
function fun($arg1 = val1, $arg2 = val2) { /* ... */ }

**Calling Scenarios:**

  • `fun()`: Both `$arg1` and `$arg2` use their default values.
  • `fun($x)`: `$arg1` uses `$x`, and `$arg2` uses its default value.
  • `fun($x, $y)`: Both arguments use the values passed (`$x` and `$y`).

Example: Overriding Defaults

The `greeting()` function below demonstrates how default values can be selectively overridden.

function greeting($arg1="Hello", $arg2="world") { /* ... */ }
greeting(); $\rightarrow$ Hello world
greeting("Thank you"); $\rightarrow$ Thank you world (*$arg2$ uses default*)
greeting("Welcome", "back"); $\rightarrow$ Welcome back (*Both arguments passed*)

Rule for Default Arguments

When defining a function, any parameter with a default value must be placed **after** all parameters that do not have a default value.

This is because PHP resolves arguments positionally, from left to right. If a parameter without a default value is omitted, PHP cannot determine which argument is intended for which parameter, leading to an error.

Invalid Default Argument Order

If you define a required argument (`$arg2`) after an optional argument (`$arg1="Hello"`), the function call must provide values for **all** arguments, effectively making the default value on `$arg1` useless when `$arg2` is required.

function greeting($arg1="Hello", **$arg2**) { /* ... */ }
greeting("PHP"); // Intent was to use "Hello PHP"

$\rightarrow$ **PHP Fatal error:** Uncaught ArgumentCountError: Too few arguments... exactly 2 expected.

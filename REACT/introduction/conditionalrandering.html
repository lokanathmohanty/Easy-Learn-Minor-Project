ReactJS - Conditional Rendering

Conditional rendering in React is used to show or hide parts of the UI depending on a specific situation. For example, if a user is not logged in, the app will show a login button. Once logged in, the same section can display a welcome message instead.

React provides several methods to implement conditional rendering in components.

Methods of Conditional Rendering

  • Conditional statement
  • JSX / UI variable
  • Logical && operator in JSX
  • Conditional operator in JSX
  • null return value

Conditional Statement

A straightforward way is to use an if statement to decide what to render.

Example: A component that shows a login link if the user is not logged in, or a welcome message if logged in.

JSX / UI Variable

React allows developers to store JSX elements in a variable and return it later. This makes it easy to assign conditional UI to a variable and render it.

Logical && Operator

In JavaScript, logical expressions are evaluated left to right. React allows this behavior in JSX to conditionally render content only when all conditions are true.

Example: Render a list of users only if the users array exists and has elements.

Conditional Operator

The ternary operator condition ? expression1 : expression2 can be used directly in JSX. It is often used to choose between two UI options inline.

Null Return Value

If a React component returns null, nothing will be rendered. This can be used to skip rendering when conditions are not met.

Example: A component that shows a welcome message only when the user is logged in, otherwise returns null.

Summary

React provides multiple ways to conditionally render UI:

  • Using if statements
  • Storing JSX in variables
  • Using logical && operator
  • Using ternary operator
  • Returning null when nothing should be displayed

Developers can choose the method that best fits the situation and complexity of their application.

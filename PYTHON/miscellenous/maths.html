Python math Module

The math module is a built-in Python library that provides numerous functions to perform mathematical operations efficiently. Note that the math module does not support complex numbers; for that, the cmath module is used.

To use the math functions, import the module with import math.

Math Module Functions

Theoretic and Representation

  • ceil(x): Smallest integer greater than or equal to x.
  • comb(n,k): Number of ways to choose k items from n without repetition and order.
  • copysign(x, y): Returns float with magnitude of x but sign of y.
  • fabs(x): Absolute value of x.
  • factorial(n): Factorial of n.
  • floor(x): Largest integer less than or equal to x.
  • fmod(x, y): Floating-point modulo operation.
  • frexp(x): Returns mantissa and exponent of x.
  • fsum(iterable): Accurate floating-point sum.
  • gcd(): Greatest common divisor of integers.
  • isclose(a, b): Checks closeness of two floats.
  • isfinite(x), isinf(x), isnan(x): Checks for numeric finiteness, infinity, or NaN.
  • isqrt(n): Integer square root.
  • ldexp(x, i): Computes x * 2**i.
  • modf(x): Returns fractional and integer parts of x.
  • nextafter(x, y): Next floating point value after x towards y.
  • perm(n, k): Number of permutations.
  • prod(iterable): Product of all elements.
  • remainder(x, y): IEEE 754-style remainder.
  • trunc(x): Truncates the decimal part.

Power and Logarithmic Functions

  • cbrt(x): Cube root.
  • exp(x): e raised to the power x.
  • exp2(x): 2 raised to the power x.
  • expm1(x): e^x - 1, accurate for small x.
  • log(x): Natural logarithm.
  • log1p(x): log(1+x), accurate for small x.
  • log2(x): Base-2 logarithm.
  • log10(x): Base-10 logarithm.
  • pow(x, y): x to the power y.
  • sqrt(x): Square root.

Trigonometric Functions

  • acos(x): Arc cosine in radians.
  • asin(x): Arc sine in radians.
  • atan(x): Arc tangent in radians.
  • atan2(y, x): Arc tangent of y/x.
  • cos(x): Cosine of x radians.
  • sin(x): Sine of x radians.
  • tan(x): Tangent of x radians.
  • hypot(x, y): Euclidean norm, sqrt(x*x + y*y).

Angular Conversion Functions

  • degrees(x): Convert radians to degrees.
  • radians(x): Convert degrees to radians.

Mathematical Constants

  • pi: 3.141592...
  • e: 2.718281...
  • tau: 6.283185..., ratio of circumference to radius.
  • inf: Positive infinity.
  • nan: Not a number.

Hyperbolic Functions

  • acosh(x): Inverse hyperbolic cosine.
  • asinh(x): Inverse hyperbolic sine.
  • atanh(x): Inverse hyperbolic tangent.
  • cosh(x): Hyperbolic cosine.
  • sinh(x): Hyperbolic sine.
  • tanh(x): Hyperbolic tangent.

Special Functions

  • erf(x): Gauss error function.
  • erfc(x): Complementary error function (1 - erf(x)).
  • gamma(x): Gamma function.
  • lgamma(x): Natural logarithm of gamma function's absolute value.

Example Usage

import math

print(math.sqrt(9))          # 3.0
print(math.pow(3, 3))        # 27.0
print(math.exp(1))           # 2.718281828459045
print(math.log(100, 10))     # 2.0
print(math.factorial(4))     # 24
print(math.gcd(12, 3))       # 3

.NET Core - Creating a Universal Windows Platform (UWP) App

This chapter discusses the process of creating a **Universal Windows Platform (UWP)** application, also known as a Windows 10 UWP application, using **.NET Core** and **Visual Studio 2015**.

UWP applications are designed to run on all Windows 10 devices (and future versions) and require the following to run and develop locally:

  • **Windows 10** for smooth local execution (though development on Windows 8 might allow running on an Emulator).
  • The **Windows 10 SDK** (Software Development Kit).

Installing UWP Development Tools (VS 2015 Modification)

To enable UWP project templates and functionality in Visual Studio 2015, you must modify your installation to include the necessary tools:

  1. Open the Visual Studio 2015 setup program and choose the **Modify** option.
  2. On the Select Features page, scroll down and check the option for **Universal Windows App Development Tools**.
  3. Ensure the different versions of the SDK and the latest update on Tools are selected, and proceed to installation.
  4. Click the **Install** button to begin the modification.
  5. Once finished, you may be required to restart your system.

Creating the UWP Project

Follow these steps to create a new UWP application project:

  1. Launch **Visual Studio 2015**.
  2. Click **File → New → Project**.
  3. In the New Project dialog, select the **Universal** template from the tree view under **Templates → Visual C# → Windows**.
  4. From the center pane, select the **Blank App (Universal Windows)** template.
  5. Name the project UWPFirstApp and click **OK**.
  6. In the next dialog, accept the default **Target version** and **Minimum version** settings, and click **OK** to create the project.

This creates a single project capable of targeting all Windows 10 devices, illustrating the simplification of multi-targeting inherent in UWP and .NET Core.

Implementing the Application UI (MainPage.xaml)

To implement a simple UI with input and output fields, open MainPage.xaml and add the following XAML code:

<Page 
   x:Class = "UWPFirstApp.MainPage" 
   xmlns = "http://schemas.microsoft.com/winfx/2006/xaml/presentation" 
   xmlns:x = "http://schemas.microsoft.com/winfx/2006/xaml" 
   xmlns:local = "using:UWPFirstApp" 
   xmlns:d = "http://schemas.microsoft.com/expression/blend/2008" 
   xmlns:mc = "http://schemas.openxmlformats.org/markup-compatibility/2006" 
   mc:Ignorable = "d">  
   
   <Grid Background = "{ThemeResource ApplicationPageBackgroundThemeBrush}"> 
      <StackPanel HorizontalAlignment = "Center"> 
         <TextBlock Text = "Hello, world!"  
            Margin = "20" 
            Width = "200" 
            HorizontalAlignment = "Left"/> 
         <TextBlock Text = "Write your name." 
            Margin = "20" 
            Width = "200" 
            HorizontalAlignment = "Left"/> 
         <TextBox x:Name = "txtbox"  
            Width = "280" 
            Margin = "20" 
            HorizontalAlignment = "Left"/> 
         <Button x:Name = "button" Content = "Click Me" 
            Margin = "20" 
            Click = "button_Click"/> 
         <TextBlock x:Name = "txtblock"  
            HorizontalAlignment = "Left" 
            Margin = "20"/> 
      </StackPanel> 
   </Grid> 
</Page>

Implementing the Button Click Event (MainPage.xaml.cs)

Next, implement the logic for the button_Click event in the code-behind file (typically MainPage.xaml.cs). Note: The namespace in the provided example is UWPHellowWorld, which should align with your project's generated namespace.

using System; 
// ... other usings ...
using Windows.UI.Xaml.Controls; 
// ... other usings ...

namespace UWPHellowWorld 
{ 
   /// <summary> 
   /// An empty page that can be used on its own or navigated to within a Frame. 
   /// </summary> 
   public sealed partial class MainPage : Page 
   { 
      public MainPage() 
      { 
         this.InitializeComponent(); 
      }  
      
      private void button_Click(object sender, RoutedEventArgs e) 
      { 
         if (txtbox.Text != "") 
            txtblock.Text = "Hello: " + txtbox.Text; 
         else 
            txtblock.Text = "You have not write your name"; 
      } 
   } 
}

After running the application (e.g., on the Local Machine target), you will see the UWP window. When you type a name into the text box and press the **Click Me** button, the text below the button will update with the greeting.

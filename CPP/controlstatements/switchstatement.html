C++ switch Statement 📋

The **switch statement** is a control structure that allows a program to test a variable or expression for equality against a list of constant values. It provides a cleaner and often more efficient alternative to long chains of if...else if statements when checking a single variable against multiple, distinct values.

Syntax and Rules

The flow of control starts with the switch expression, which is compared sequentially to each case value:

switch (expression) {
   case constant-1:
      // Code to execute if expression == constant-1
      break; // Stops execution and exits the switch block
   case constant-2:
   case constant-3:
      // Code to execute if expression == constant-2 OR constant-3
      // ...
   default: // Optional: Executes if no case matches
      // Code for all other values
}
  • **Expression Type:** The expression must evaluate to an **integral type** (like int, char, enum), but not floating-point types (float, double).
  • **Case Value:** Each constant-expression must be a **literal constant** or a constant expression (e.g., 5, 'A', or MAX_VALUE) and must match the data type of the switch expression.
  • **break:** The break statement is crucial. If omitted, the code flow will **fall through** and continue executing the statements in the next case block until a break or the end of the switch is reached.
  • **default:** This is an optional case. If present, its statements execute when the switch expression does not match any of the preceding case values. It typically appears at the end and does not require a break.

Example Analysis (grade = 'D')

The program checks the value of the char variable grade ('D') against the defined cases:

char grade = 'D';

switch(grade) {
   // Cases 'A', 'B', 'C' are skipped.
   case 'D' : // Match found!
      cout << "You passed" << endl;
      break; // Exit switch block
   // Remaining cases are skipped due to break.
   default :
      // ...
}
cout << "Your grade is " << grade << endl;

The output is:

You passed
Your grade is D

Note how cases 'B' and 'C' are grouped: since 'B' has no break, execution would fall through to 'C' (which *does* have a break), allowing the same code to run for multiple conditions.

R - Decision Making

Decision making structures allow the programmer to specify conditions to be evaluated and statements to execute depending on whether these conditions are true or false. These structures form the basis for controlling program flow.

The general form of a decision making structure in many programming languages involves evaluating a Boolean expression and executing code blocks based on the result.

Types of Decision Making Statements

  • if statement: Executes statements if a Boolean expression is true.
  • if...else statement: Executes one block if the condition is true, another block if false.
  • switch statement: Tests a variable for equality against a list of values, executing the matching block.

Example: Check if Variable is an Integer

x <- 30L
if (is.integer(x)) {
  print("X is an Integer")
}

Output:

[1] "X is an Integer"

Example: Nested if-else Statement

x <- 10
y <- 20
z <- 30

if (x >= y) {
  if (x >= z)
    cat(x, "is the largest.")
  else
    cat(z, "is the largest.")
} else {
  if (y >= z)
    cat(y, "is the largest.")
  else
    cat(z, "is the largest.")
}

Output:

30 is the largest.

Example: String-based Switch

x <- switch(
  "apple",
  apple = "A red fruit",
  banana = "A yellow fruit",
  orange = "A citrus fruit"
)
print(x)

Output:

[1] "A red fruit"

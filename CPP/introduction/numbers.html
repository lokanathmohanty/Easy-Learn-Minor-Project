Numbers and Math Operations in C++ 🔢

C++ uses **primitive data types** to handle numbers, including integers and floating-point values. The choice of type depends on the required size and precision:

  • **Integers (Whole Numbers):** short, int, long (and their unsigned versions).
  • **Floating-Point (Decimals):** float (single-precision) and double (double-precision).

Example of Definitions:

short  s = 10;
int    i = 1000;
long   l = 1000000;
float  f = 230.47;
double d = 30949.374;

Built-in Math Operations

C++ provides a rich set of built-in mathematical functions, which are located in the **<cmath>** header file. These functions primarily operate on double-type arguments.

Key Mathematical Functions:

  • **Trigonometric:** cos(), sin(), tan() (return cosine, sine, and tangent, respectively).
  • **Logarithm/Power:** log() (natural log), pow(base, exp) (base raised to a power).
  • **Roots/Geometry:** sqrt(x) (square root), hypot(side1, side2) (hypotenuse of a right triangle).
  • **Absolute Value:** abs(int) (for integers), fabs(double) (for floating-point numbers).
  • **Rounding:** floor(x) (returns the largest integer $\le x$).

Random Number Generation

To generate pseudo-random numbers in C++, you need to use two functions from the **<cstdlib>** library (and <ctime> for seeding):

  1. **Seed the Generator (srand()):** The srand() function is called once to set the starting point (seed) for the random sequence. It is best practice to seed it with a value that changes constantly, such as the current system time obtained via time(NULL).

    srand( (unsigned)time( NULL ) );

  2. **Generate the Number (rand()):** The rand() function returns a pseudo-random integer number.

    j = rand();

Without calling srand(), the rand() function will return the exact same sequence of "random" numbers every time the program runs.

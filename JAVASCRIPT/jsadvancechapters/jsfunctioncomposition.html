JavaScript - Function Composition

What is Function Composition?

Function composition is a functional programming technique that allows programmers to combine multiple functions into a single function. The output of one function becomes the input of the next, forming a chain of operations. This improves readability, modularity, and reusability.

The compose function enables this by applying functions from right to left, meaning the function on the right runs first.

Example

Let’s look at three simple functions and compose them together:

const increaseBy5 = (num) => num + 5;
const tripleValue = (num) => num * 3;
const reduceBy10 = (num) => num - 10;

const applyOperations = compose(reduceBy10, tripleValue, increaseBy5);
const finalResult = applyOperations(7);

console.log("The final result after applying the operations is:", finalResult);

Output:

The final result after applying the operations is: 26

In this case:

  • increaseBy5(7) → 12
  • tripleValue(12) → 36
  • reduceBy10(36) → 26
The functions are applied in sequence to produce the final result.

Implement the Compose Function

The compose function can be implemented using reduceRight to apply functions in reverse order: 

const compose = (...ops) => {
  return (value) => {
    return ops.reduceRight((result, operation) => {
      return operation(result);
    }, value);
  };
};
console.log("Chained functions have been successfully executed.");

Output:

Chained functions have been successfully executed.
The final result after applying the operations is: 26

Benefits of Function Composition

  • Re-usability: Build larger operations by combining smaller, reusable functions without duplicating code.
  • Readability: Express complex operations clearly by chaining simple transformations.
  • Maintainability: Each function is focused on a single task, making it easy to test, modify, and debug.

Summary

Function composition is a powerful way to write modular, reusable, and maintainable code. By chaining functions together with compose, JavaScript developers can express complex operations in a clean and expressive manner.

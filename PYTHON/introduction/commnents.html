Python - Comments

Python comments are programmer-readable annotations in the source code. They are used to improve readability and provide explanations, but are ignored by the Python interpreter. Comments help developers understand the purpose and logic of code without affecting its execution.

For example:

# This is a comment
print("Hello, World!")

Output:

Hello, World!

Types of Python Comments

  • Single-line comments
  • Multi-line comments
  • Docstring comments

Single-Line Comments

Single-line comments start with a hash symbol (#) and extend to the end of the line. They can be placed on their own line or inline with code.

Example: Standalone single-line comment

# Standalone single-line comment
def greet():
    print("Hello, World!")
greet()

Example: Inline single-line comment

print("Hello, World!")  # Inline single-line comment

Multi-Line Comments

Python has no dedicated multi-line comment syntax, but two common approaches are used:

  • Consecutive single-line comments
  • Triple-quoted strings (not assigned to a variable)

Example: Consecutive single-line comments

# This function calculates factorial
# using an iterative approach
def factorial(n):
    if n < 0:
        return "Not defined for negative numbers"
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result

print(factorial(5))

Example: Triple-quoted string as comment

"""
This function calculates the GCD of two numbers
using the Euclidean algorithm.
"""
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

print(gcd(48, 18))

Docstrings (Documentation Strings)

Docstrings are special comments used to document functions, classes, and modules. They are written using triple quotes (''' or """) and placed immediately after the definition line.

Example: Function docstring

def greet(name):
    """
    This function greets the person whose name is passed.

    Parameters:
    name (str): The name of the person to greet
    """
    print(f"Hello, {name}!")

greet("Alice")

Accessing docstrings:

  • Using .__doc__ attribute
  • Using help() function
print(greet.__doc__)
help(greet)

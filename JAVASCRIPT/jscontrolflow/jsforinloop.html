JavaScript for...in Loop — E-Learning Session

Overview

The for...in loop is used to iterate over an object's enumerable properties (keys). It assigns each property name to a loop variable and runs until all properties are visited. Although arrays and strings are objects and can be traversed with for...in, it is generally not recommended for arrays; use for...of or traditional for loops instead.

Syntax

for (variableName in object) { statement or block to execute }

Parameters

  • variableName — receives the property name (key) on each iteration.

  • in — JavaScript 'in' operator used by this loop.

  • object — the object whose properties are being traversed.

Important Notes

  • The loop iterates over enumerable properties — inherited enumerable properties are included unless filtered (for example with hasOwnProperty).

  • Property order is not guaranteed for plain objects in older engines; do not rely on insertion order for critical logic.

  • Prefer for...of or index-based loops for arrays to avoid unexpected keys and performance issues.

Examples

Iterate through object properties

Example object traversal:

let car = { brand: "OD", model: "Q7", color: "Black" }

for (key in car) { /* use key and car[key] */ }

Output lines (key -> value):

  • brand -> OD

  • model -> Q7

  • color -> Black

Iterating over a string

Strings are array-like objects; indices are keys:

let str = "Hello"

for (key in str) { /* str[key] is the character */ }

Output (index -> character):

  • 0 -> H

  • 1 -> e

  • 2 -> l

  • 3 -> l

  • 4 -> o

Iterating over an array

Arrays are objects too, but using for...in can enumerate unexpected keys and is less efficient:

let arr = ["Hi", "Hello", 900]

for (key in arr) { /* arr[key] */ }

Output (index -> value):

  • 0 -> Hi

  • 1 -> Hello

  • 2 -> 900

Update object property values

You can modify values while iterating:

for (key in car) { car[key] = null }

Resulting object: {"brand":null,"model":null,"color":null}

Iterating built-in objects (example: navigator)

Enumerating properties of browser objects can reveal many keys; be cautious and avoid relying on a specific set of properties.

Common Pitfalls

  • Using for...in for arrays can include inherited properties and non-numeric keys.

  • Modifying the object structure while iterating may produce unexpected behavior.

  • Relying on property order across environments is unsafe for critical logic.

Practice Tasks

  • Write a loop that prints only an object's own properties (use hasOwnProperty inside the loop).

  • Given an array with extra prototype properties added, demonstrate why for...in can be problematic.

  • Create a function that sets all object values to a default while preserving keys.

Summary

for...in is designed for enumerating object property names. Use it when you need keys from objects, but prefer other iteration patterns for arrays and when property order or performance matters.

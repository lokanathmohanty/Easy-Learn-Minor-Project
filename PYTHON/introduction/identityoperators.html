Python - Identity Operators

Python identity operators are used to compare whether two objects share the same memory location. They check if two variables refer to the exact same object, not just if their values are equal.

There are two identity operators in Python:

  • is Operator
  • is not Operator

Python is Operator

The is operator evaluates to True if both operands share the same memory location. The memory location can be checked using the id() function.

Example:

a = [1, 2, 3, 4, 5]
b = [1, 2, 3, 4, 5]
c = a

print(a is c)
print(a is b)

print("id(a) : ", id(a))
print("id(b) : ", id(b))
print("id(c) : ", id(c))

Output:

True
False
id(a) :  140114091859456
id(b) :  140114091906944
id(c) :  140114091859456

Python is not Operator

The is not operator evaluates to True if both operands do not share the same memory location.

Example:

a = [1, 2, 3, 4, 5]
b = [1, 2, 3, 4, 5]
c = a

print(a is not c)
print(a is not b)

print("id(a) : ", id(a))
print("id(b) : ", id(b))
print("id(c) : ", id(c))

Output:

False
True
id(a) :  140559927442176
id(b) :  140559925598080
id(c) :  140559927442176

Examples with Explanations

Example 1

a = "TutorialsPoint"
b = a
print("id(a), id(b):", id(a), id(b))
print("a is b:", a is b)
print("b is not a:", b is not a)

Output:

id(a), id(b): 2739311598832 2739311598832
a is b: True
b is not a: False

Example 2

When comparing two lists with identical elements but stored in different memory locations:

a = [1, 2, 3]
b = [1, 2, 3]
print("id(a), id(b):", id(a), id(b))
print("a is b:", a is b)
print("b is not a:", b is not a)

Output:

id(a), id(b): 1552612704640 1552567805568
a is b: False
b is not a: True

Example 3

Even though the lists themselves are stored at different locations, their elements may still share the same memory addresses:

print(id(a[0]), id(a[1]), id(a[2]))
print(id(b[0]), id(b[1]), id(b[2]))

Output:

140734682034984 140734682035016 140734682035048
140734682034984 140734682035016 140734682035048

Thus, a is b returns False even though both contain the same values.

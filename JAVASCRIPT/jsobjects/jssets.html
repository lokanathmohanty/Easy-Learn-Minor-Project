JavaScript - Sets

A JavaScript Set object is a collection of unique values. Each value can only occur once in a Set. A Set can hold any value of any data type. The sets were introduced in ECMAScript 6 (ES6).

JavaScript Sets are similar to Arrays, but there are some key differences:

  • Sets can only hold unique values, while Arrays can hold duplicate values.
  • Sets are not ordered, while Arrays are ordered.
  • Sets are faster to add and remove items from than Arrays.

JavaScript Sets are often used to store unique values, such as the unique users who have visited a website. They can also be used to remove duplicate values from an Array.

Syntax

You can define a Set using the Set() constructor: 

let set1 = new Set([iterable]);

Parameters: Iterable − An optional parameter. The constructor function traverses through the elements of the iterable and creates a new set using those elements.

Examples

Access Set Elements


const num_set = new Set([10, 20, 20, 20]);

for (let value of num_set.values()) {
   console.log(value);
}

Output:

  • 10
  • 20

Insert Elements into Sets


const num_set = new Set();
num_set.add(60);
num_set.add(50);
num_set.add(50);

for (let value of num_set.values()) {
   console.log(value);
}

Output:

  • 60
  • 50

Remove Set Elements


let num_set = new Set([100, 200, 300, 400, 500]);

num_set.delete(200);
num_set.delete(400);

for (let value of num_set.values()) {
   console.log(value);
}

Check if Set Contains Value


const num_set = new Set([100, 200, 300, 400, 500]);
console.log(num_set.has(100)); // true

Mathematical Set Operations

JavaScript's Set does not include built-in methods for union, intersection, or difference. You can implement them using custom code.

Union of Two Sets


const set1 = new Set(["BMW", "Audi", "TATA"]);
const set2 = new Set(["BMW", "TaTa", "Honda", "Suzuki"]);

const union = new Set([...set1, ...set2]);
console.log(union);

Intersection of Two Sets


const set1 = new Set(["BMW", "Audi", "TATA"]);
const set2 = new Set(["BMW", "TATA", "Honda", "Suzuki"]);

const inter = new Set();
for (let car of set1) {
   if (set2.has(car)) {
      inter.add(car);
   }
}
console.log(inter);

Difference of Two Sets


const set1 = new Set(["BMW", "Audi", "TATA"]);
const set2 = new Set(["BMW", "TATA", "Honda", "Suzuki"]);

const diff = new Set(set1);
for (let car of set2) {
   diff.delete(car);
}
console.log(diff);

JavaScript Set Reference

Constructor

  • Set() – Creates and returns a set of unique values.

Properties

  • size – Returns the size of the set.

Methods

  • add() – Insert elements into the set.
  • clear() – Removes all elements from the set.
  • delete() – Deletes a single element.
  • difference() – Returns elements in the first set but not in the second.
  • entries() – Returns an iterator containing all entries.
  • forEach() – Executes a function once per value.
  • has() – Checks if an element exists.
  • intersection() – Returns common elements in both sets.
  • keys() – Alias for values().
  • values() – Returns a new Set iterator object containing values.

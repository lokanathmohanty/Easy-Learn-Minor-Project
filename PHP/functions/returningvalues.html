PHP Function Return Values

The **`return`** statement is used in a PHP function to send a value back to the code that called it and to transfer the program control back to the calling environment. The function's execution stops immediately upon encountering the first `return` statement.

Key Rules for Returning Values

  1. **Returns One Value:** A PHP function can technically only return **one value** (an expression). Attempting to return multiple values separated by a comma (e.g., `return $a, $b;`) will result in a fatal `Parse error`.
  2. **Any Data Type:** The returned value can be any data type, including scalar variables (int, string, bool), arrays, or objects.
  3. **`return;` (Returning `NULL`):** A `return` keyword without an expression (or just allowing the function to end) returns the value `NULL`.

Example: Returning a Scalar Value

The returned value can be stored in a variable or used directly in an expression or output statement.

<?php
   function addition($first, $second) {
      return $first + $second;
   }

   $z = addition(10, 20); // Value 30 is stored in $z
   echo "Addition: $z"; // Output: Addition: 30
?>

Conditional Return Statements

A function may contain multiple `return` statements within conditional blocks (`if`/`else`). The flow will only hit one of them, and the function will exit immediately.

function raiseto($x, $i) {
   if ($i == 2) { return $x**2; } // Exits here if true
   elseif ($i == 3) { return $x**3; } // Exits here if true
}

Calling `raiseto(7, 3)` returns 343 and stops.

Returning Multiple Values (Using an Array)

To effectively return multiple values, the function must package them into a single data structure, such as an **indexed** or **associative array**, and return that array. The calling code then unpacks the required values from the array.

function raiseto($x){
   $sqr = $x**2;
   $cub = $x**3;
   return **["sqr" => $sqr, "cub" => $cub]**; // Returns one associative array
}

$val = raiseto(5);
echo "Square: " . $val["sqr"]; // Output: Square: 25

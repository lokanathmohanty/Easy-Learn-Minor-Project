JavaScript - Current Date/Time

In JavaScript, we can use the Date object to work with dates and times. It provides multiple methods to get the current year, month, day, hours, minutes, and seconds.

Date Object

The simplest way to create a new date instance is: 

var date = new Date();

Get Year, Month, and Day


var date = new Date();
var year = date.getFullYear();
var month = date.getMonth() + 1; // Months are 0-11
var day = date.getDate();

Get Hours, Minutes, and Seconds


var date = new Date();
var hours = date.getHours();
var minutes = date.getMinutes();
var seconds = date.getSeconds();

Example: Current Date and Time


<html>
<body>
  <p id="demo"></p>
  <script>
    var date = new Date();
    var year = date.getFullYear();
    var month = date.getMonth() + 1;
    var day = date.getDate();
    var hours = date.getHours();
    var minutes = date.getMinutes();
    var seconds = date.getSeconds();
    
    document.getElementById('demo').innerHTML = 
      'Current Date and Time: ' + day + '-' + month + '-' + year + 
      ' ' + hours + ':' + minutes + ':' + seconds;
  </script>
</body>
</html>

Sample Output


Current Date and Time: 15-12-2024 12:30:45

Using toLocaleString() Method

The toLocaleString() method provides localized date and time formatting. You can specify a locale and formatting options.

Basic Syntax


var date = new Date();
var current_date_and_time = date.toLocaleString();
var current_time = date.toLocaleTimeString();
var current_date = date.toLocaleDateString();

Example


<html>
<body>
  <script>
    var date = new Date();
    var current_date_and_time = date.toLocaleString();
    var current_time = date.toLocaleTimeString();
    var current_date = date.toLocaleDateString();

    document.write('Current Date and Time: ' + current_date_and_time + '<br>');
    document.write('Current Time: ' + current_time + '<br>');
    document.write('Current Date: ' + current_date + '<br>');
  </script>
</body>
</html>

Sample Output


Current Date and Time: 12/15/2024, 12:30:45 PM
Current Time: 12:30:45 PM
Current Date: 12/15/2024

Working with Locales & Time Zones

You can format date and time for different regions using the locale and options parameters. 


var date = new Date();
var newYorkTime = date.toLocaleString('en-US', { timeZone: 'America/New_York' });
var indiaTime = date.toLocaleString('en-IN', { timeZone: 'Asia/Kolkata' });

console.log("New York Time: " + newYorkTime);
console.log("India Time: " + indiaTime);

Conclusion

JavaScript Date object and methods like toLocaleString() give developers flexibility to fetch and format date and time according to different regions and requirements.

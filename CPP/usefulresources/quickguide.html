C++ Quick Guide: Fundamentals and Concepts 🚀

**C++** is a powerful, high-performance, compiled language that supports **procedural**, **object-oriented**, and **generic programming**. It's often called a superset of C.

I. Basic Structure & Data Types

Hello World Example

#include <iostream>

int main() {
   std::cout << "Hello World!" << std::endl;
   return 0;
}

Primitive Built-in Types

The core data types are fundamental building blocks:

  • **`bool`**: Boolean values (`true` or `false`).
  • **`char`**: Character types.
  • **`int`**: Integer types (modified by `short`, `long`, `signed`, `unsigned`).
  • **`float` / `double`**: Floating-point numbers.
  • **`void`**: Valueless (used for functions that return nothing or generic pointers).

Variables & Constants

  • **Variables:** Declared and optionally initialized (e.g., `int age = 30;`).
  • **Constants:** Fixed values that cannot be altered after definition (e.g., `const int MAX_USERS = 100;`).

II. Control Flow & Functions

Decision Making

Uses standard constructs for conditional execution:

  • **`if`, `else if`, `else`**
  • **`switch`** statement for multi-way branching.

Loop Types

Used for repetitive execution of code blocks:

  • **`for` loop:** Executes a fixed number of times.
  • **`while` loop:** Executes as long as a condition is true.
  • **`do...while` loop:** Executes at least once, then as long as the condition is true.
  • **Range-based `for` loop (Modern C++):** Iterates over elements of a container (e.g., `for (int element : container)`).

Functions

A function is a block of code that performs a specific task. They support **return values**, **parameters**, and **overloading** (multiple functions with the same name but different parameters).

int add(int a, int b) { // Function definition
   return a + b;
}

III. Object-Oriented Programming (OOP)

C++ is built around OOP, emphasizing **Classes** and **Objects**.

  • **Class:** A blueprint or template for creating objects, defining their **states** (member variables) and **behaviors** (member methods/functions).
  • **Object:** An instance of a class.
  • **Constructor:** A special method called when an object is created, often used for initialization.
  • **Destructor:** A special method called when an object is destroyed, often used for cleanup.

The Four Pillars of OOP

  1. **Encapsulation:** Bundling data and the methods that operate on that data into a single unit (the class), and restricting direct access to some components (using `public`, `private`, `protected`).
  2. **Abstraction:** Hiding complex implementation details and showing only the essential information to the user.
  3. **Inheritance:** Allowing a new class (derived class) to acquire the properties and methods of an existing class (base class).
  4. **Polymorphism:** The ability of an object to take many forms, typically achieved via **virtual functions** (runtime polymorphism) or **function/operator overloading** (compile-time polymorphism).

IV. Memory, Pointers, and Modern C++

Pointers and Memory

  • **Pointer (`*`):** A variable that stores the **memory address** of another variable.
  • **Reference (`&`):** An **alias** or another name for an existing variable.
  • **Dynamic Memory:** Memory allocated at runtime using `new` (on the **Heap**) and manually released using `delete`.

Modern Resource Management

  • **RAII (Resource Acquisition Is Initialization):** A programming technique that ties resource ownership to the lifetime of stack-allocated objects, ensuring resources are freed automatically.
  • **Smart Pointers:** RAII wrappers around raw pointers to manage dynamic memory automatically, preventing **memory leaks**. Common types: **`std::unique_ptr`** (exclusive ownership) and **`std::shared_ptr`** (shared ownership).

Standard Template Library (STL)

A collection of pre-written templates providing fundamental algorithms and data structures:

  • **Containers:** `std::vector` (dynamic array), `std::string`, `std::map` (key/value), `std::set`, etc.
  • **Algorithms:** `std::sort`, `std::find`, `std::for_each`, etc.
  • **Iterators:** Objects that act like pointers to elements within containers.

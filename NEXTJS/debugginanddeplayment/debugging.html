Next.js - Debugging

Debugging with Browser DevTools 🐞

Browser Developer Tools are the standard method for debugging **Client-Side Code** in a Next.js application. You can pause execution, inspect variables, and step through code using either the **debugger** statement or manually set breakpoints.

Using the debugger Statement

The debugger statement is a simple way to pause code execution when a certain condition is met:

Example Client Component:

// /app/page.tsx
"use client"
import { useState } from "react";
// ...
    if (count > 5) {
        debugger; // Code execution will pause here
    }
// ...

Steps to Debug:

  1. Start the development server: npm run dev.
  2. Open the page in your browser (e.g., http://localhost:3000).
  3. Open **Developer Tools** (Sources tab in Chrome/Edge, Debugger tab in Firefox).
  4. When the condition (count > 5) is met, the browser execution will automatically pause at the debugger statement, displaying the source file for inspection.

Debugging with Visual Studio Code (VS Code)

VS Code offers built-in debugging tools that are ideal for inspecting **Server-Side Code** (e.g., Server Components, API Routes) or for a unified debugging experience across both server and client environments.

Setting up launch.json

To fully customize debugging, you must configure the **./.vscode/launch.json** file. In the Debugging tab (Run and Debug view), select the "create a launch.json file" option and choose the appropriate environment (Node.js or Chrome/Edge).

Using Breakpoints

Breakpoints are set directly in your source code files by clicking in the gutter next to a line number. Execution will pause when the code hits a breakpoint, allowing you to inspect variables, the call stack, and control execution flow.

Example Server Component with Breakpoint Logic:

export default function Home() {
    var variable = 34;

    for (let i = 0; i < 10; i++) {
        // Breakpoint can be set here to inspect 'i' and 'variable'
        console.log(`Iteration: ${i}, Variable: ${variable}`); 
        
        variable += i;
        
        if (i === 5) {
            // Can be set as a Conditional Breakpoint (only pauses if i === 5)
            console.log("Reached iteration 5");
        }
    }
    // ...
}

Starting the Debug Session

  1. Ensure you have a configured launch configuration in launch.json for Next.js.
  2. Go to the **Run and Debug** panel in VS Code.
  3. Select the desired launch configuration (e.g., "Next.js: Debug Server Side").
  4. Press **F5** or click the "Start Debugging" button.

The code will execute until it hits a breakpoint. The **Variables panel** will show the current values (like i and variable), and the **Debug Console** will display logs, including those printed by console.log.

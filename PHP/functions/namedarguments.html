PHP Named Arguments (PHP 8.0+)

**Named Arguments** is a feature introduced in **PHP 8.0** that allows arguments to be passed to a function based on the **parameter name** rather than their positional order. This makes function calls more flexible and self-documenting, especially when dealing with functions that have many optional parameters.

Syntax and Principle

To pass a named argument, you specify the parameter name (without the `$`) followed by a colon (`:`) and the value.

**Definition:** function myfunction($x, $y) { /* ... */ }
**Named Call:** myfunction(**x:10**, **y:20**);

Order Independence

With named arguments, the order in which arguments are passed no longer matters, unlike traditional positional arguments.

myfunction(x:10, y:20); $\rightarrow$ x = 10, y = 20
myfunction(y:20, x:10); $\rightarrow$ x = 10, y = 20

Advantages of Named Arguments

  • **Self-Documenting Code:** The function call clearly indicates the purpose of each passed value.
  • **Skipping Defaults:** It allows skipping optional parameters that have default values, even if they are defined in the middle of the parameter list.
  • **Order Flexibility:** Arguments can be passed in any order.

Combining Positional and Named Arguments

You can mix both types of arguments, but there is a strict rule: **positional arguments must always come before named arguments.**

**Valid Combination:** function myfunction($x, $y, $z) { /* ... */ }
myfunction(**10**, z:20, y:30); // 10 is positional for $x.

Output: x = 10 y = 30 z = 20

**Invalid Combination (Fatal Error):** myfunction(x:10, y:20, **30**);

$\rightarrow$ PHP Fatal error: Cannot use positional argument after named argument.

Named Arguments and Array Unpacking (PHP 8.1+)

PHP 8.1.0 introduced the ability to use array unpacking (`...`) along with named arguments. Positional arguments can be unpacked from an array first, followed by specific named arguments.

function myfunction($x, $y, $z=30) { /* ... */ }
myfunction(**...[10, 20]**, z:30);

Output: x = 10 y = 20 z = 30

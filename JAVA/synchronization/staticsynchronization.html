Java - Static Synchronization

Introduction

Synchronization ensures safe cooperation between multiple threads accessing shared resources. In static synchronization, the lock is applied at the class level, not object level, which means if one thread is executing a static synchronized method, all other threads trying to access any static synchronized method on the same class are blocked.

Multithreading

Multithreading allows simultaneous execution of two or more parts of a program. Each thread runs independently and enables better resource utilization, especially CPU time, improving performance.

Synchronization

Since threads run asynchronously, their interactions can be unpredictable. If multiple threads try to access the same resource (like writing to a file), results may be faulty. Synchronization ensures that only one thread accesses a resource at a time by acquiring a lock.

Static Synchronization

Static synchronization applies a class-level lock, meaning the lock is on the class object rather than instance objects. Only one thread can access a static synchronized method of a class at a time, across all instances.

Syntax

static synchronized returnType methodName(parameters) {
   // synchronized code
}

Example: Without Static Synchronization

This version doesn't use static synchronization, so threads might interleave and print the counter values out of order.

package com.tutorialspoint;

class PrintDemo {
   public static void printCount() {
      try {
         for (int i = 5; i > 0; i--) {
            Thread.sleep(50);
            System.out.println("Counter   ---   " + i);
         }
      } catch (Exception e) {
         System.out.println("Thread  interrupted.");
      }
   }
}

class ThreadDemo extends Thread {
   private Thread t;
   private String threadName;

   ThreadDemo(String name) {
      threadName = name;
   }

   public void run() {
      PrintDemo.printCount();
      System.out.println("Thread " + threadName + " exiting.");
   }

   public void start() {
      System.out.println("Starting " + threadName);
      if (t == null) {
         t = new Thread(this, threadName);
         t.start();
      }
   }
}

public class TestThread {
   public static void main(String args[]) {
      ThreadDemo t1 = new ThreadDemo("Thread - 1");
      ThreadDemo t2 = new ThreadDemo("Thread - 2");

      t1.start();
      t2.start();

      try {
         t1.join();
         t2.join();
      } catch (Exception e) {
         System.out.println("Interrupted");
      }
   }
}

Example: With Static Synchronization

Now we synchronize the static method. This ensures the counter prints in order every time because the class-level lock prevents overlapping access to the printCount() method.

package com.tutorialspoint;

class PrintDemo {
   public static synchronized void printCount() {
      try {
         for (int i = 5; i > 0; i--) {
            Thread.sleep(50);
            System.out.println("Counter   ---   " + i);
         }
      } catch (Exception e) {
         System.out.println("Thread  interrupted.");
      }
   }
}

class ThreadDemo extends Thread {
   private Thread t;
   private String threadName;

   ThreadDemo(String name) {
      threadName = name;
   }

   public void run() {
      PrintDemo.printCount();
      System.out.println("Thread " + threadName + " exiting.");
   }

   public void start() {
      System.out.println("Starting " + threadName);
      if (t == null) {
         t = new Thread(this, threadName);

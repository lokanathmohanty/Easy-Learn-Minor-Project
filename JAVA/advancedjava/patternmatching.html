Java - Pattern Matching with instanceof (Java 16+)

The Enhancement to instanceof

Pattern Matching for instanceof, made a standard feature in **Java 16** (after being a preview in Java 14 and 15), simplifies the common code idiom of checking an object's type and then casting it to perform type-specific operations. It reduces the need for redundant type casting.

Syntax: Pattern Variable

The enhanced instanceof operator now accepts a **type pattern** consisting of a type and a new variable, called the **pattern variable**. If the type check is successful, the object is automatically cast to that type and assigned to the pattern variable.

if (person instanceof Employee e) {
   // 'e' is the pattern variable, automatically cast to Employee
   return e.getEmployeeId(); 
}

In this syntax, the code combines two steps into one:

  1. **Type Test:** Checks if person is an instance of Employee.
  2. **Conditional Binding:** If true, it implicitly casts person to Employee and assigns it to the new local variable e.

Scope of the Pattern Variable

The **scope** of the pattern variable (like e in the example) is intelligently managed by the compiler. It is only accessible in the regions of code where the type test is logically guaranteed to have succeeded. This prevents errors that could arise from using an uncast or incorrectly cast object.

Comparison of Syntaxes

Old Syntax (Pre-Java 16) New Syntax (Java 16+) 
if (person instanceof Employee) {
   Employee e = (Employee) person;
   // ... use e
}
 
if (person instanceof Employee e) {
   // e is already an Employee
   // ... use e
}

Example: Eliminating Redundant Casting

The method getId() is cleanly implemented using pattern matching to determine and process different subtypes of Person:

public static int getId(Person person) {
   // Test type and bind to 'e' in one step
   if (person instanceof Employee e) {
      return e.getEmployeeId();
   } 
   // Test type and bind to 'm' in one step
   else if (person instanceof Manager m) {
      return m.getManagerId();
   }
   return -1;
}

Python - Signal Handling

Signal handling in Python allows defining custom handlers for asynchronous events such as keyboard interrupts, alarms, and termination requests. Using the signal module, you can control how your program responds to various signals.

A signal handler is a function executed when a specific signal is received. The signal.signal() function associates signals with handlers.

Some default handlers include:
SIGPIPE is ignored.
SIGINT triggers a KeyboardInterrupt exception.

Common Signals

  • SIGINT: Interrupt from keyboard (Ctrl+C) raises KeyboardInterrupt.
  • SIGTERM: Termination signal.
  • SIGALRM: Timer signal from alarm().
  • SIGCHLD: Child process stopped or terminated.
  • SIGUSR1 and SIGUSR2: User-defined signals.

Signal handlers execute in the main thread; signals cannot be used for inter-thread communication.

Setting a Signal Handler

import signal
import time

def handle_signal(signum, frame):
   print(f"Signal {signum} received")

signal.signal(signal.SIGINT, handle_signal)

print("Press Ctrl+C to trigger SIGINT")
while True:
   time.sleep(1)

Output example:

Press Ctrl+C to trigger SIGINT
Signal 2 received
Signal 2 received
Signal 2 received

Signal Handling on Windows

On Windows, signal.signal() supports limited signals. Unsupported signals raise ValueError, and unknown signal names raise AttributeError.

Supported signals include:

  • SIGABRT
  • SIGFPE
  • SIGILL
  • SIGINT
  • SIGSEGV
  • SIGTERM
  • SIGBREAK

Handling Timers and Alarms

import signal
import time

def handler(signum, stack):
   print('Alarm: ', time.ctime())

signal.signal(signal.SIGALRM, handler)
signal.alarm(2)
time.sleep(5)
for i in range(5):
   signal.alarm(2)
   time.sleep(5)
   print("interrupted #%d" % i)

Getting Signal Names from Numbers

Python does not provide a direct way to get signal names from numbers, but you can reverse the signal module attributes into a dictionary to map numbers to names. 

import signal

sig_items = reversed(sorted(signal.__dict__.items()))
final = dict((k, v) for v, k in sig_items if v.startswith('SIG') and not v.startswith('SIG_'))
print(final)

Output example:

{: 'SIGXFSZ', : 'SIGXCPU', : 'SIGWINCH', ...}

Java - Files mismatch() Method

The mismatch() method is available in the Files class from Java 12 onwards. It provides an easy way to compare two files.

Syntax

The syntax of the Files.mismatch() method is:

public static long mismatch(Path path, Path path2) throws IOException

Return Value: Returns the position of the first mismatch or -1L if there is no mismatch.

How it works

  • Returns -1L if files are identical.
  • Returns the position of the first mismatch if the files differ in size or byte content.
  • Files are considered identical if:
    • Both paths point to the same file.
    • Both paths are the same but the file does not exist.
    • Files are the same size and every byte matches.

Parameters

  • path − the path to the first file
  • path2 − the path to the second file

Exceptions

  • IOException − if an I/O error occurs.
  • SecurityException − if read access to files is denied.

Example: No Mismatch in Files

This example creates two temporary text files with the same content and uses Files.mismatch() to confirm they are identical.

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;

public class APITester {
   public static void main(String[] args) throws IOException {
      Path path1 = Files.createTempFile("file1", ".txt");
      Path path2 = Files.createTempFile("file2", ".txt");

      Files.writeString(path1, "tutorialspoint");
      Files.writeString(path2, "tutorialspoint");

      long mismatch = Files.mismatch(path1, path2);

      if (mismatch > 1L) {
         System.out.println("Mismatch occurred in file1 and file2 at : " + mismatch);
      } else {
         System.out.println("Files matched");
      }

      path1.toFile().deleteOnExit();
      path2.toFile().deleteOnExit();
   }
}

Output: Files matched

Example: Mismatch Identification in Files

This example creates two temporary text files with different content. The method returns the position of the first mismatch.

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;

public class APITester {
   public static void main(String[] args) throws IOException {
      Path path1 = Files.createTempFile("file1", ".txt");
      Path path2 = Files.createTempFile("file2", ".txt");

      Files.writeString(path1, "tutorialspoint");
      Files.writeString(path2, "tutorialspoint Java 12");

      long mismatch = Files.mismatch(path1, path2);

      if (mismatch > 1L) {
         System.out.println("Mismatch occurred in file1 and file2 at : " + mismatch);
      } else {
         System.out.println("Files matched");
      }

      path1.toFile().deleteOnExit();
      path2.toFile().deleteOnExit();
   }
}

Output: Mismatch occurred in file1 and file2 at : 1

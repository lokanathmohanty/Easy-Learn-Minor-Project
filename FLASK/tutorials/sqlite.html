Flask and SQLite3 Integration 💾

The **SQLite3** module is built into Python, making it straightforward to interact with SQLite databases directly from a Flask application without needing a separate extension. This section details the steps for creating a database, handling user input, and displaying data using Flask's view functions and Jinja2 templates.

Database Setup (Initial Step)

The application first requires a database file (database.db) and a table (students) to be created using the sqlite3 module:

conn.execute('CREATE TABLE students (name TEXT, addr TEXT, city TEXT, pin TEXT)')

The table includes fields for name, addr (address), city, and pin (pincode).

View Functions and Data Flow

1. The Home Page (/)

The home() function serves as the application's entry point, rendering home.html which provides links to add new data or view the list.

2. Adding a New Record (/enternew and /addrec)

  • **new_student() (/enternew):** Renders student.html, which contains the HTML form for entering student information.
  • **addrec() (/addrec):** Handles the form submission (POST method).
    • It extracts form data using **request.form**.
    • It establishes a connection to database.db.
    • It uses a **try...except...finally** block for safe data insertion, executing the SQL INSERT statement with placeholders (?) for parameterized queries.
    • **con.commit()** saves the changes; **con.rollback()** handles errors.
    • The final result (success or error) is passed as the msg variable to the **result.html** template.

3. Listing Records (/list)

The list() function retrieves all records from the table and sends them to list.html:

  • A connection is established, and **con.row_factory = sql.Row** is set. This is crucial as it allows records to be accessed like dictionaries (e.g., row["name"]) instead of simple tuples.
  • **cur.execute("select * from students")** fetches all data.
  • **rows = cur.fetchall()** retrieves all resulting rows.
  • The rows object is passed to the **list.html** template for display.

Template Logic (Jinja2)

The **list.html** template uses a Jinja2 for loop to dynamically generate an HTML table based on the rows data received from the view function:

{% for row in rows %}

<tr>

<td>{{row["name"]}}</td>

...

</tr>

{% endfor %}

The use of row["column_name"] is enabled by setting the row_factory in the Flask view function.

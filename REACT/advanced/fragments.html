ReactJS - Fragments

Fragments provide a simple way to group multiple React elements without adding extra nodes to the DOM. They are useful when a component needs to return multiple elements but wrapping them in an additional container (like <div>) is undesirable.

Why Fragments?

By default, React components can only return a single parent element. Wrapping elements in a generic container works, but may cause issues in scenarios like:

  • Returning list elements such as <li> or <td>, which must be children of specific tags.
  • When only part of the list should be returned, to be wrapped later by the parent.

Example Without Fragment

<div>
   <p>One</p>
   <p>Two</p>
</div>

This adds unnecessary <div> wrappers into the DOM.

Using a Component Without Fragment

ListOfCustomer.js

import React from 'react';

class ListOfCustomer extends React.Component {
   render() {
      var names = this.props['names'];
      var namesList = names.map(
         (name, index) => <li>{name}</li>
      );
      return <ul>{namesList}</ul>;
   }
}

export default ListOfCustomer;

App.js

import ListOfCustomer from './components/ListOfCustomer';

function App() {
   var names = ["John", "Peter"];
   return (
      <ul>
         <ListOfCustomer names={names} />
      </ul>
   );
}

export default App;

This produces invalid nested lists: 

<ul><ul><li>John</li><li>Peter</li></ul></ul>

Using React.Fragment

ListOfCustomer.js

import React, { Fragment } from 'react';

class ListOfCustomer extends React.Component {
   render() {
      var names = this.props['names'];
      var namesList = names.map(
         (name, index) => <li>{name}</li>
      );
      return <React.Fragment>{namesList}</React.Fragment>;
   }
}

export default ListOfCustomer;

Now the component returns valid markup: 

<ul><li>John</li><li>Peter</li></ul>

Keyed Fragments

React requires a unique key for each child element in a list. React.Fragment supports a key attribute for this purpose: 

var namesList = names.map(
   (name, index) => <li key={index}>{name}</li>
);

return <React.Fragment>{namesList}</React.Fragment>;

Short Syntax

Instead of writing <React.Fragment></React.Fragment>, a shorter syntax <> </> can be used: 

return <>{namesList}</>;

Summary

Fragments let you group a list of children elements without adding extra nodes to the DOM. They support keys when rendering lists and provide a clean short syntax for readability.

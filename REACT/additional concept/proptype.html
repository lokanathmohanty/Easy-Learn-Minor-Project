ReactJS - PropTypes

JavaScript is a dynamically typed language, meaning variable types are not declared explicitly. Instead, the type is inferred at runtime. While this speeds up development, it can cause unexpected issues when variables receive values of incorrect types.

var num = 'John' // The type of `num` is string
var num = 10     // The type of `num` is number

For example:

var num = 10
var name = 'John'
var result = num + name // throws error during runtime

React and Types

In React, components often receive props. If props have incorrect types, they may cause unexpected behavior. Consider the following Sum component:

import React from 'react'
class Sum extends React.Component {
   render() {
      return <p>The sum of {this.props.num1} and {this.props.num2}
      is {parseInt(this.props.num1) + parseInt(this.props.num2)}</p>
   }
}
export default Sum

When provided correct numeric props, it works. However, if props are strings, the result will be NaN.

Using Sum Component

import Sum from "./components/PropTypes/Sum";

function App() {
   var num1 = 10
   var num2 = 200
   var name1 = "John"
   var name2 = "Peter"

   return (
      <div>
         <Sum num1={num1} num2={num2} />
         <Sum num1={name1} num2={name2} />
      </div>
   );
}

export default App;

The second usage causes issues because strings are passed instead of numbers.

PropTypes

The prop-types package helps validate prop types in React components. It ensures that props are passed with the correct type during development.

Installation:

npm i prop-types --save

Example usage:

import React from 'react'
import PropTypes from 'prop-types'

class Sum extends React.Component {
   render() {
      return <p>The sum of {this.props.num1} and {this.props.num2}
      is {parseInt(this.props.num1) + parseInt(this.props.num2)}</p>
   }
}

Sum.propTypes = {
   num1: PropTypes.number,
   num2: PropTypes.number
}

export default Sum

This will throw warnings in the console during development if the wrong types are passed.

Available Validators

  • PropTypes.array
  • PropTypes.bigint
  • PropTypes.bool
  • PropTypes.func
  • PropTypes.number
  • PropTypes.object
  • PropTypes.string
  • PropTypes.symbol
  • PropTypes.node - Anything renderable
  • PropTypes.element - React component
  • PropTypes.elementType - Type of React component
  • PropTypes.instanceOf(Class)
  • PropTypes.oneOf(['A', 'B'])
  • PropTypes.oneOfType([PropTypes.number, PropTypes.string])
  • PropTypes.arrayOf(PropTypes.number)
  • PropTypes.objectOf(PropTypes.string)
  • PropTypes.func.isRequired
  • PropTypes.any.isRequired

Custom Validators

You can also create custom validators. For example, validating an email prop:

Sum.propTypes = {
   num1: PropTypes.number,
   num2: PropTypes.number,
   email: function(myProps, myPropName, myComponentName) {
      if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(myProps[myPropName])) {
         return new Error(
            'Invalid prop value `' + myProps[myPropName] + '` supplied to ' +
            '`' + myComponentName + '/' + myPropName + '`. Validation failed.'
         );
      }
   }
}

Here:

  • myProps → all props of the component
  • myPropName → the current property being validated
  • myComponentName → the name of the component

Summary

PropTypes provides runtime type checking for React props during development. It helps catch bugs early without impacting performance in production. React developers can use built-in validators or create custom validators for specific requirements.

PHP - Regular Expressions (Regex)

Regular Expressions (Regex) are sequences or patterns of characters used to define search criteria for string manipulation. In PHP, regular expressions are essential for tasks like searching for specific text, validating input formats, replacing substrings, and splitting strings into chunks based on a pattern.

Types of Regular Expressions in PHP

PHP traditionally supports two sets of regular expression functions, though the POSIX set is officially **deprecated** and largely replaced by the PERL set.

  • POSIX Regular Expressions: An older, simpler set of expressions and functions. **(Deprecated in recent PHP versions)**
  • PERL Style Regular Expressions (PCRE): A more powerful and flexible set of expressions based on Perl's syntax, which is the **recommended standard** in modern PHP.

1. POSIX Regular Expressions (Legacy)

POSIX expressions use a structure similar to arithmetic expressions. They employ brackets and quantifiers to define patterns.

Brackets and Ranges

Brackets ($\text{[]}$) define a set or range of characters to match:

  • $\text{[0-9]}$: Matches any single digit ($\text{0}$ to $\text{9}$).
  • $\text{[a-z]}$: Matches any single lowercase character.
  • $\text{[^a-zA-Z]}$: Matches any character that is $\text{not}$ an alphabetic character.
  • $\text{[[:alpha:]]}$: Matches any alphabetic character (a predefined character class).

Quantifiers (Frequency and Position)

Quantifiers specify how many times the preceding character or group should occur, or its position within the string:

  • $\text{p+}$: Matches one or more $\text{p}$'s.
  • $\text{p*}$: Matches zero or more $\text{p}$'s.
  • $\text{p?}$: Matches zero or one $\text{p}$.
  • $\text{p\{2,3\}}$: Matches two or three $\text{p}$'s.
  • $\text{p\$}$: Matches a string that **ends** with $\text{p}$.
  • $\text{^p}$: Matches a string that **begins** with $\text{p}$.

POSIX Functions (Deprecated)

Functions like $\text{ereg()}$, $\text{ereg\_replace()}$, $\text{eregi()}$, and $\text{split()}$ were used for POSIX-style matching, searching, and replacing, but are no longer recommended.

2. PERL Style Regular Expressions (PCRE)

PCRE offers greater power through the use of **delimiters** (e.g., $\text{/pattern/}$), **metacharacters**, and **modifiers**.

Metacharacters (Shorthands)

Metacharacters use a backslash ($\text{\backslash}$) followed by an alphabetical character to represent common character classes:

Character Description
$\text{.}$ A single character (excluding newline, unless $\text{s}$ modifier is used).
$\text{\s}$ A whitespace character (space, tab, newline).
$\text{\d}$ A digit ($\text{0}$ - $\text{9}$).
$\text{\w}$ A word character ($\text{a-z, A-Z, 0-9, \_}$).

Modifiers

Modifiers are appended after the closing delimiter to change how the pattern matching is performed:

Modifier Description
$\text{i}$ Makes the match **case-insensitive**.
$\text{m}$ Multiline mode. $\text{\^}$ and $\text{\$}$ match the beginning/end of a $\text{line}$, not just the whole string.
$\text{s}$ Single-line mode. Allows $\text{.}$ to match **newline** characters.
$\text{g}$ (In Perl, for PHP use $\text{preg\_match\_all()}$) Finds all matches **globally**.

PCRE Functions (Recommended)

These functions are the modern standard for regular expression processing in PHP:

  • $\text{preg\_match()}$: Searches a string for a pattern and returns $\text{true}$ or $\text{false}$.
  • $\text{preg\_match\_all()}$: Matches **all occurrences** of the pattern in a string.
  • $\text{preg\_replace()}$: Searches for a pattern and replaces it with a specified string.
  • $\text{preg\_split()}$: Splits a string into an array based on the pattern as the delimiter.
  • $\text{preg\_grep()}$: Searches all elements of an input array and returns elements that match the pattern.

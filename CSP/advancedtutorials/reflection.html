C# Reflection: Runtime Type Discovery and Manipulation

What is Reflection? 🔍

**Reflection** is the ability of managed code (like C# running on .NET) to **examine its own metadata** at runtime. It provides objects that allow you to obtain information about an assembly, its modules, and the types defined within it (classes, methods, fields, properties, etc.).

The core classes for reflection are found in the **`System.Reflection`** namespace.

Primary Applications of Reflection

Reflection is a powerful feature with several advanced uses in C# development:

  • **Metadata Viewing:** Viewing information about types, including their members and any applied **Attributes** (like the `DeBugInfo` example).
  • **Dynamic Instantiation:** Creating instances of types at runtime (e.g., using `Activator.CreateInstance(type)`).
  • **Late Binding:** Invoking methods and accessing properties/fields on an object whose type isn't known until runtime.
  • **Creating New Types:** Generating new types and emitting code at runtime (used in advanced scenarios like dynamic proxy generation).

Accessing Type Information (Metadata)

To use reflection, you first need a **`System.Type`** object for the element you wish to inspect. This is often obtained using:

  • The **`typeof()`** operator (at compile time): `Type type = typeof(Person);`
  • The **`GetType()`** method (at runtime): `Type type = myObject.GetType();`

Discovering Members

Once you have a `Type` object, you can discover its members:

Console.WriteLine("Class Name: " + type.Name);
// Retrieves all public properties:
foreach (var prop in type.GetProperties()) {
    Console.WriteLine(prop.Name);
}
// Retrieves all public, instance, and only-declared methods:
foreach (var method in type.GetMethods(BindingFlags.Public | BindingFlags.Instance | BindingFlags.DeclaredOnly)) {
    Console.WriteLine(method.Name);
}

Example: Reading Custom Attributes with Reflection

Reflection is the mechanism for reading **Attributes** applied to code elements. The `GetCustomAttributes` method on `Type` or `MemberInfo` is key.

To read attributes on the `Rectangle` class and its `GetArea` method from the previous session:

Step 1: Get the Type Object

Type type = typeof(Rectangle);

Step 2: Retrieve Class-level Attributes

// Get all attributes applied directly to the class (not inherited)
object[] attributes = type.GetCustomAttributes(false); 
foreach (object attr in attributes) {
   DeBugInfo dbi = (DeBugInfo)attr;
   if (null != dbi) {
      Console.WriteLine("Bug no: {0}", dbi.BugNo);
      // ... output other properties
   }
}

Step 3: Retrieve Method-level Attributes

// Iterate through all methods in the type
foreach (MethodInfo m in type.GetMethods()) { 
   // Iterate through attributes on each method
   foreach (Attribute a in m.GetCustomAttributes(true)) {
      DeBugInfo dbi = (DeBugInfo)a;
      if (null != dbi) {
         Console.WriteLine("Bug no: {0}, for Method: {1}", dbi.BugNo, m.Name);
         // ... output other properties
      }
   }
}

Dynamic Method Invocation

Reflection enables you to call a method on an object whose type you only have at runtime:

// 1. Get the Type
Type type = typeof(Greeter);
// 2. Instantiate the Object
object obj = Activator.CreateInstance(type);
// 3. Get the Method Info
MethodInfo method = type.GetMethod("SayHello");
// 4. Invoke the Method with parameters
method.Invoke(obj, new object[] { "Ravi" }); // Outputs: Hello, Ravi!

JavaScript - Self-Invoking Functions

Self-invoking functions are JavaScript functions that execute immediately as they are defined. To define a self-invoking function, you enclose an anonymous function in parentheses followed by another set of parentheses. These are also called immediately invoked function expressions (IIFE).

Syntax


(function () {
  // function body
})();

Alternative syntax: 


(function () {
  // function body
}());

Example: Basic Self-Invoking Function


(function () {
  document.getElementById("output").innerHTML = 
    "Self-invoked function is executed!";
}());

Self-invoked function is executed!

Self-Invoking Functions with Parameters


(function (name) {
  document.getElementById("demo").innerHTML = `Welcome to ${name}`;
})("Tutorials Point !");

Welcome to Tutorials Point !

Private Scope of Self-Invoking Functions

Variables and code inside a self-invoking function remain in a private scope and do not pollute the global scope. This prevents naming conflicts and keeps code isolated. 


let a = 10;
(function () {
  console.log("Entering to the function");
  var a = 20;
  console.log("The value of a is " + a);
  console.log("Exiting to the function");
}());
console.log("The value outside the function is " + a);

Entering to the function

The value of a is 20

Exiting to the function

The value of the outside the function is 10

Example: Accessing Variables Globally


(function () {
  var string = "JavaScript";
  window.string = string;
})();
console.log("The value of the string variable is: " + string);

The value of the string variable is: JavaScript

Benefits of Using Self-Invoking Functions

  • Avoiding the global scope − Prevents naming conflicts by isolating variables and functions.
  • Initialization − Can be used for one-time setup or initialization of variables.
  • Code privacy − Code remains hidden and inaccessible from other parts of the program.

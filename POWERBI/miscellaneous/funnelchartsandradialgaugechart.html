Power BI: Funnel Charts and Radial Gauge Chart

Funnel Chart: Visualizes how data reduces through stages, with the final stage representing the highest value and the first stage the smallest. Stages display data as percentages of 100% and do not use axes. Example uses include monthly sales production, employee salary ranges, and net revenue by month.

Creating a Funnel Chart Example

  • Import an "Employee" dataset with fields like Name, Salary, and others.
  • Select Funnel Chart visual and resize for visibility.
  • Add Name to Category and Salary to Values.
  • Hovering stages shows employee details including name, percentage, and salary.
  • Another example: Use Year as Category and Gross Sales as Values to visualize annual gross sales trends.

Radial Gauge Chart

The Radial Gauge Chart shows a semi-circular arc representing progress toward a target between minimum and maximum values. It is used to track KPIs like gross sales and quickly identify if targets are met.

Creating a Radial Gauge Chart

  • Use a dataset with columns such as Age, Designation, Gross Sales, Net Sales, etc.
  • Select the Radial Gauge visual in Power BI.
  • Drag Gross Sales to the Value field. The chart shows default minimum (0) and maximum values.
  • Create a measure (e.g., smallest = 2) to set a custom minimum and drag it to Minimum value field.
  • Drag Net Sales to Target value to display with a line showing the goal on the gauge.
  • Customize chart appearance using "Format Visual" — modifying fill colors, axis, background, data labels, and more.

Benefits

  • Funnel charts efficiently visualize gradual reductions through stages, highlighting percentages.
  • Radial gauge charts provide a clear view of progress against targets for quick decision-making.

Next.js - Script Optimization

The Next.js <Script> Component

The Next.js **<Script> component** extends the standard HTML <script> tag, providing extra props to include and **optimize the loading of external scripts** (typically third-party resources). Using this component helps prevent heavy external scripts from blocking the main thread and degrading performance.

For scripts needed across multiple routes, import next/script and include the script directly in your **Layout component**.

The <Script> component optimizes script loading by:

  • Defining an optimized **loading strategy** using the strategy prop.
  • Specifying **callback functions** to execute upon loading success or failure.
  • Setting **priority** for critical scripts.

Defining Script Loading Strategy

The **strategy** prop is the core mechanism for controlling script loading. It dictates when the script should be loaded and executed relative to the page's render cycle. The default value is **afterInteractive**.

Strategy Value Description
afterInteractive (Default) The script is loaded after the page has finished rendering and is interactive. Use for scripts that can be deferred but are needed relatively soon (e.g., analytics).
lazyOnload The script is loaded lazily after the page and all critical resources have finished loading. Use for background or low-priority scripts (e.g., chat bots, social widgets).
beforeInteractive The script is loaded and executed before the page starts rendering. Use only for essential scripts that must run before any part of the page is interactive (e.g., critical polyfills, consent managers).
worker The script is loaded and executed as a Web Worker, off the main thread. (Requires Next.js configuration and should be used with caution).

Example: Using the lazyOnload Strategy

import Script from 'next/script'

export default function Page() {
    return (
        <Script src="link/to/script.js" strategy="lazyOnload"></Script>
    );
}

Script Loading Callbacks and Priority

The <Script> component supports several optional props for controlling behavior and reacting to load events:

Callback Functions

These functions are essential for managing state or reacting to the external script's status:

  • onLoad: Called when the script successfully loads and is ready to execute. 
    <Script src="..." onLoad={() => console.log('Script loaded successfully')}>
  • onReady: Called when the script finishes loading and its execution is complete. 
    <Script src="..." onReady={() => console.log('Script is ready')}>
  • onError: Called if the script fails to load.

Script Loading Priority

Setting the **priority** prop to true is a signal to Next.js that the script is crucial and should be loaded quickly. This is typically only used alongside the beforeInteractive or afterInteractive strategies for truly important resources.

<Script src="link/to/script.js" priority={true}></Script>

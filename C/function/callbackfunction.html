Callback Function in C

Callback functions are extremely versatile, especially in event-driven programming. When a specific event is triggered, a callback function mapped to it is executed in response. For example, in GUI applications, a button click can trigger a series of predefined actions.

What is a Callback Function?

A callback function is any executable code passed as an argument to other code, which is expected to call or execute it at a given time. In other words, if a function's reference is passed as an argument to another function for later execution, it is called a callback function.

The mechanism relies on function pointers, which are variables storing the memory address of a function.

Function Pointer Example

void hello() {
    printf("Hello World.");
}

// Declare a function pointer pointing to hello
void (*ptr)() = &hello;

// Call the function via pointer
(*ptr)();

Example of Callback Function in C

#include <stdio.h>

void hello() {
    printf("Hello World\n");
}

void callback(void (*ptr)()) {
    printf("Calling a function with its pointer\n");
    (*ptr)();   // calling the callback function
}

int main() {
    void (*ptr)() = hello;
    callback(ptr);
    return 0;
}

Output:

Calling a function with its pointer
Hello World

Callback Function With Arguments

Here, two functions with identical prototypes are defined: square() and root().

int square(int val) {
    return val * val;
}

int root(int val) {
    return pow(val, 0.5);
}

The callback function receives an integer argument and a function pointer matching the prototype.

int callback(int a, int (*ptr)(int)) {
    int ret = (*ptr)(a);
    return ret;
}

Complete Example: Callback with Arguments

#include <stdio.h>
#include <math.h>

int callback(int a, int (*print_callback)(int));
int square(int value);
int root(int value);

int main() {
    int x = 4;

    printf("Square of x: %d is %d\n", x, callback(x, square));
    printf("Square root of x: %d is %d\n", x, callback(x, root));

    return 0;
}

int callback(int a, int (*ptr)(int)) {
    int ret = (*ptr)(a);
    return ret;
}

int square(int val) {
    return val * val;
}

int root(int val) {
    return pow(val, 0.5);
}

Output:

Square of x: 4 is 16
Square root of x: 4 is 2

Types of Callbacks in C

  • Synchronous Callback: The calling function waits for the callback to complete before proceeding. Useful for immediate results or ensuring a task finishes before moving on.
  • Asynchronous Callback: The calling function triggers the callback but does not wait for it to finish. It continues execution, enabling non-blocking operations. Common in event-driven programming.

Generic callback functions enhance the flexibility and adaptability of C programs by allowing functions to be passed and executed dynamically.

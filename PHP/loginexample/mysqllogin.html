PHP - MySQL Login Example (Basic Authentication)

Overview and Setup

This example demonstrates a fundamental user authentication system for a PHP application using **MySQL** as the backend database. It validates a user's $\text{username}$ and $\text{password}$ against records in a $\text{MySQL}$ table ($\text{admin}$).

Database Requirements

A database named $\text{mydb}$ with a table named $\text{admin}$ is required. The following $\text{SQL}$ creates the table and inserts test credentials:

CREATE TABLE `admin` (
   `username` varchar(10) NOT NULL PRIMARY KEY,
   `passcode` varchar(10) NOT NULL
);
INSERT INTO `admin` (`username`, `passcode`) VALUES
('guest', 'abc123'), ('manager', 'secret'), ('user', 'test');

1. Database Connection ($\text{config.php}$)

This script establishes the connection to the MySQL database using the **$\text{mysqli}$** extension.

<?php
   define('DB_SERVER', 'localhost');
   define('DB_USERNAME', 'root');
   define('DB_PASSWORD', '');
   define('DB_DATABASE', 'mydb');
   $db = mysqli_connect(DB_SERVER,DB_USERNAME,DB_PASSWORD,DB_DATABASE);
?>

2. Login Logic ($\text{login.php}$)

The $\text{login.php}$ script handles the $\text{HTML}$ form, processes the submitted credentials, queries the database, and manages the session state.

<?php
   include("config.php");
   session_start();
   $error='';

   if($_SERVER["REQUEST_METHOD"] == "POST") {
      // Basic input sanitization to prevent SQL Injection
      $myusername = mysqli_real_escape_string($db,$_POST['username']);
      $mypassword = mysqli_real_escape_string($db,$_POST['password']); 

      // Execute SQL query
      $sql = "SELECT * FROM admin WHERE username = '$myusername' AND passcode = '$mypassword'";
      $result = mysqli_query($db,$sql);      
      $count = mysqli_num_rows($result);

      if($count == 1) {
         // Success: Create session and redirect
         $_SESSION['login_user'] = $myusername;
         header("location: welcome.php");
      } else {
         $error = "Your Login Name or Password is invalid";
      }
   }
// ... HTML form follows ...
?>

3. Session and Protection ($\text{session.php}$)

This script is included at the beginning of all protected pages (like $\text{welcome.php}$). It verifies if a valid session exists; otherwise, it redirects the user back to the login page.

<?php
   session_start();

   if(!isset($_SESSION['login_user'])){
      header("location: login.php");
      die(); // Stop script execution
   }
   $login_session = $_SESSION['login_user'];
?>

4. Welcome and Logout

  • **$\text{welcome.php}$:** Displays a personalized greeting by retrieving the $\text{\$login\_session}$ variable, which holds the authenticated username.
  • **$\text{logout.php}$:** Clears the session data ($\text{session\_destroy()}$) and redirects the user back to the login page, effectively ending the user's logged-in state.

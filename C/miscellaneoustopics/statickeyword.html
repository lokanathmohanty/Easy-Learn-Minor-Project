Static Keyword in C

What is static Keyword in C?

The static keyword in C is one of the storage class specifiers which has different meanings based on the context in which it is used.

The "static" keyword is used to declare a static variable as well as to define a static function. When declared as "static", a variable represents a static storage class.

A static function is available only inside the program file (with ".c" extension) in which it is defined. One cannot use the "extern" keyword to import a static function into another file.

Uses of static Keyword

  • Static Local Variable: Lifetime is till the end of the program and retains value between function calls.
  • Static Global Variable: Accessible only within the file it is declared in.
  • Static Functions: Scope limited to the file in which the function is declared.

Static Variables (static Keyword with Variables)

When a variable is declared as static, it is initialized only once. It persists for the duration of the program and retains its value across function calls.

  • Compiler allocates space in main memory.
  • Initialized to zero by default.
  • Not re-initialized on every function call.
  • Has local scope.

Example: Static Variable in a Function

#include <stdio.h>

int counter();

int main() {
   counter();
   counter();
   counter();
   return 0;
}

int counter() {
   static int x;
   printf("Value of x as it enters the function: %d\n", x);
   x++;
   printf("Incremented value of x: %d\n", x);
}

Output

Value of x as it enters the function: 0
Incremented value of x: 1
Value of x as it enters the function: 1
Incremented value of x: 2
Value of x as it enters the function: 2
Incremented value of x: 3

A static variable is similar to a global variable in terms of lifetime but differs in scope. Static variables are private to the function or block in which they are declared.

Static Functions (static Keyword with Functions)

By default, all functions are global and accessible anywhere in the program. When a function is declared static, its scope is restricted to the object file it resides in.

Example: Static Function in Different Files

Contents of file1.c:

static void staticFunc(void) {
   printf("Inside the static function staticFunc()");
}

Contents of main.c:

#include <stdio.h>
#include <stdlib.h>

int main() {
   staticFunc();
   return 0;
}

This will result in an error: undefined reference to staticFunc() because the function is not visible outside its file.

Example: Static Function in Same File

#include <stdio.h>

static void staticFunc(void){
   printf("Inside the static function staticFunc()");
}

int main(){
   staticFunc();
   return 0;
}

Output

Inside the static function staticFunc()

Example: Multiple Static Functions

#include <stdio.h>
#include <stdlib.h>
#include <math.h>

static int square(int num) {
   return num * num;
}

static void voidfn() {
   printf("From inside the static function.\n");
}

static int intfn(int num2) {
   return sqrt(num2);
}

int main() {
   int n1 = 16;
   int val;

   val = square(n1);
   printf("The square of the %d : %d\n", n1, val);

   voidfn();

   val = intfn(n1);
   printf("The square root of the %d : %d\n", n1, val);

   return 0;
}

Output

The square of the 16 : 256
From inside the static function.
The square root of the 16 : 4

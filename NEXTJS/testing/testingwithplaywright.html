Next.js - Testing With Playwright

What is Playwright?

Playwright is a modern, open-source **End-to-End (E2E) testing framework** developed by Microsoft. It primarily focuses on high-level **browser automation** and provides a powerful API for testing complex, modern web applications.

  • It supports simultaneous testing across all major browser engines: **Chromium**, **Firefox**, and **WebKit**.
  • It is known for its reliability and speed, offering features like auto-wait and cross-browser stability.

Setting Up Playwright in Next.js

Option 1: Create a New Project with Playwright

The simplest way to integrate is by using the Next.js official example template:

npx create-next-app@latest --example with-playwright with-playwright-app

This provides a pre-configured setup including playwright.config.ts and example tests.

Option 2: Manual Setup in an Existing Project

Step 1: Install Playwright

Use the initialization command in your existing Next.js project. This command installs Playwright and its browser dependencies:

npm init playwright@latest

Step 2: Update Scripts in package.json

Add scripts to easily run the E2E tests:

// File: /package.json
{
  "scripts": {
    // Command to run all E2E tests
    "test:e2e": "playwright test", 
    // Command to run tests with the interactive UI mode
    "test:e2e:ui": "playwright test --ui" 
  }
}

Creating a Playwright E2E Test (Navigation)

Playwright tests are written asynchronously and use a page fixture (object) to interact with the browser. It's crucial that your Next.js application is running (e.g., via npm run start or npm run dev) before running the E2E tests.

The Test (tests/home.spec.ts)

This test simulates a user clicking a navigation link and verifies the resulting URL and page content.

// tests/home.spec.ts
import { test, expect } from '@playwright/test'
 
test('should navigate to the about page', async ({ page }) => {
    // 1. Navigate to the base URL
    await page.goto('http://localhost:3000/')
    
    // 2. Find the link containing the text 'About' and click it
    await page.click('text=About')
    
    // 3. Assert that the current URL has changed to the expected path
    await expect(page).toHaveURL('http://localhost:3000/about')
    
    // 4. Assert that the h1 element on the new page contains 'About'
    // Playwright recommends using locators for reliability
    await expect(page.locator('h1')).toContainText('About')
})

Running Tests

Run your tests using the scripts defined in package.json:

# Runs all tests in headless mode by default
npm run test:e2e

# Opens the browser and interactive UI for debugging
npm run test:e2e:ui

# Runs tests only in the Chromium browser
npx playwright test --project=chromium

Generating a Web Report

Playwright can generate a comprehensive, interactive HTML report of the test results, including test steps, screenshots, and videos, which is invaluable for debugging failed tests.

  1. Generate the report: Run the tests with the HTML reporter flag. 
    npx playwright test --reporter=html
  2. View the report: The report is saved to the playwright-report directory and can be viewed in your browser using this command: 
    npx playwright show-report

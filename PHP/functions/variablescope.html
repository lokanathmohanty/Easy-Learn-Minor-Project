PHP Variable Scope

The **scope** of a variable in PHP is the context within which it is defined and accessible. PHP defines several variable scope types, the most crucial distinction being between variables inside and outside a function.

Variable Scope Types

1. Local Variables

A variable declared **inside a function** has a **local scope**. It can only be accessed and manipulated within that function. When the function finishes execution, the variable is destroyed.

function myfunction() {
   $local_var = "Hello"; // Local Scope
   echo $local_var;
}
// Trying to access $local_var here results in an error.

2. Global Variables

A variable declared **outside a function** has a **global scope**. It can be accessed throughout the script (outside of functions), but it is **not automatically available** inside any function's local scope.

The `global` Keyword

To access and modify a global variable from within a function, you must explicitly declare it inside the function using the **`global`** keyword.

$a = 10; // Global variable
function myfunction() {
   **global $a;** // Makes the global $a accessible
   $a = $a + 10; // Modifies the global variable
}
myfunction();
echo $a; // Output: 20

The `$GLOBALS` Array (Superglobal)

PHP stores all global variables in a special associative array called **`$GLOBALS`**. The variable name is the key, and its value is the array's value. This array is always available inside functions without the need for the `global` keyword.

$a = 10;
function myfunction() {
   $GLOBALS['a'] += 10; // Accesses and modifies the global $a
}
myfunction();
echo $a; // Output: 20

3. Static Variables

A variable declared inside a function with the **`static`** keyword is only initialized once (on the first call). It retains its last assigned value between function calls, unlike regular local variables, which are destroyed upon function exit.

function myfunction() {
   **static $x = 0;** // Initialized once
   echo "x = $x \n";
   $x++;
}
myfunction(); // Output: x = 0
myfunction(); // Output: x = 1 (Retains value from previous call)

Node.js - REPL Terminal

What is REPL?

REPL stands for Read-Eval-Print Loop. It is an interactive programming environment that allows running JavaScript code directly in the terminal without needing separate script files.

  • Read: Reads user input and parses it into JavaScript expressions.
  • Eval: Evaluates the JavaScript expressions.
  • Print: Prints the result of the evaluation to the console.
  • Loop: Repeats the process for the next input.

Starting the REPL

Open your terminal or command prompt and enter the command node. This launches the REPL environment and you will see a prompt like: 

Welcome to Node.js v22.13.1.
Type ".help" for more information.
>

Using REPL

You can directly type JavaScript expressions and see results instantly. For example: 

> 2 + 3
5
> console.log("Welcome to TutorialsPoint!")
Welcome to TutorialsPoint!
undefined

Variable Declarations

Variables can be declared dynamically. Their values persist throughout the REPL session: 

> let a = 1121;
undefined
> a * 2
2242

Multiline Code Execution

REPL supports multiline code, useful for defining functions and loops. It enters multiline mode automatically for incomplete expressions: 

> function greet(name) {
...   return "Welcome To, " + name;
... }
undefined
> greet("TutorialsPoint")
'Welcome To, TutorialsPoint'

Using the Underscore Variable

The special variable _ holds the value of the last evaluated expression: 

> 112 + 234
346
> _ / 2
173

Working with Global Objects

The REPL provides direct access to Node.js global objects such as process and Buffer:

> console.log(process.version)
v22.13.1

> Buffer.from('TutorialsPoint')
<Buffer 54 75 74 6f 72 69 61 6c 73 50 6f 69 6e 74>

Handling Errors

REPL shows meaningful error messages helpful for debugging:

> let y = 123
undefined
> y()
Uncaught TypeError: y is not a function

REPL Commands

Some useful commands include:

  • .exit: Exit the REPL session.
  • .clear: Clear the REPL environment.
  • .save: Save current REPL session to a file.
  • .load: Load commands from a file into REPL.
  • .editor: Enter multiline editor mode.

PHP Spread Operator (`...`)

The **Spread Operator** (`...`), introduced in **PHP 7.4**, is used to expand an iterable (like an array) into its individual elements. It significantly improves the readability and efficiency of code, especially when dealing with arrays and function arguments.

1. Expanding (Unpacking) Arrays

The primary use of the spread operator is to unpack the elements of one or more arrays directly into another array literal.

$arr1 = [4, 5];
$arr2 = [1, 2, 3, **...$arr1**];

Output: `[1, 2, 3, 4, 5]`

Multiple Usage and Efficiency

The operator can be used multiple times in a single expression. While it achieves the same result as `array_merge()` for indexed arrays, the spread operator is generally **more efficient** as it avoids the overhead of a function call.

$arrA = [1, 2]; $arrB = [3, 4];
$arrC = [**...$arrA**, 10, **...$arrB**]; $\rightarrow$ [1, 2, 10, 3, 4]

The spread operator also works seamlessly when unpacking the array returned directly by a function.

2. Named Arguments with Spreading (PHP 8.1+)

In functions, the spread operator can be used to unpack an indexed array into positional arguments. As of PHP 8.1, this can be combined with **Named Arguments**. When an array is spread, its elements fill the positional arguments, and any named arguments are applied afterward.

function myfunction($x, $y, $z=30) { /* ... */ }
myfunction(**...[10, 20]**, z: 50);

The array `[10, 20]` is spread, setting `$x=10` and `$y=20`. The named argument `z: 50` overrides the default value of `$z`.

Output: `x = 10 y = 20 z = 50`

**Note:** When using the spread operator with associative arrays (arrays with string keys), only the values are spread, and the numeric keys are re-indexed. For merging associative arrays while preserving string keys, `array_merge()` or the `+` array union operator is still necessary.

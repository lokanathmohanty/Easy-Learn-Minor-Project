JavaScript - Throttling

What is Throttling?

Throttling is a technique that limits how many times a function can be called in a specific period of time. It improves website responsiveness by restricting execution of heavy or expensive tasks such as animations, scrolling, resizing, or fetching data.

For example, instead of calling an API hundreds of times while scrolling, you can throttle requests to once per second, reducing bandwidth usage and preventing server overload.

Why use Throttling in JavaScript?

  • Improves performance by limiting execution frequency.
  • Prevents overloading the browser or server with too many requests.
  • Keeps applications smooth and responsive even during frequent events.

Steps to Implement Throttling

  1. Create a throttle function that accepts a callback and delay.
  2. Track the last time the function was executed.
  3. Check if the required delay has passed before running the callback.
  4. Return the throttled version of the function.

How Throttling Works

Consider a scroll event: without throttling, hundreds of events are fired rapidly. With throttling, only one event fires per set interval, ensuring efficiency while producing the same result for the user.

Example Without Throttling


<button id="pressButton">Press Me</button>

<script>
// Without throttling: executes every click immediately
const button = document.querySelector("#pressButton");
button.addEventListener("click", () => {
   console.log("The button has been pressed");
});
</script>

Output: Each click logs immediately without restriction.

Example With Throttling


<button id="pressButton">Press Me</button>

<script>
const button = document.querySelector("#pressButton");

// Throttle function
const throttle = (callback, waitTime) => {
   let lastCalled = 0;
   return (...args) => {
      const currentTime = new Date().getTime();
      if (currentTime - lastCalled > waitTime) {
         lastCalled = currentTime;
         return callback(...args);
      }
   }
};

button.addEventListener("click",
   throttle(() => {
      console.log("Button has been pressed!");
   }, 1500)
);
</script>

Output: Logs appear only once every 1500ms, even if clicked rapidly.

Use Cases for Throttling

  • Gaming: Limit button presses for actions like shooting or punching.
  • Scrolling & Ads: Control scroll-triggered animations or content loads.
  • Button Clicks: Prevent multiple quick submissions (e.g., ATMs).
  • Mouse Events: Limit frequent pointer/mouse move events.
  • API Calls: Prevent excessive requests and ensure efficient performance.

Summary

JavaScript throttling restricts a function’s execution to fixed intervals. It ensures smooth performance, avoids overloading systems, and maintains a consistent execution rate regardless of how many times the function is invoked.

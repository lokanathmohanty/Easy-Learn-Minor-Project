Java - Data Structures

Java provides powerful data structures through its utility package. The key legacy data structures include:

  • Enumeration
  • BitSet
  • Vector
  • Stack
  • Dictionary
  • Hashtable
  • Properties

All these are legacy classes/interfaces. The newer Collections Framework is introduced in Java-2 and will be discussed separately.

Enumeration

Enumeration is not a data structure but an interface for iterating through other structures. It provides the method nextElement() to access elements sequentially.

Example: Using Enumeration with Vector

import java.util.Vector;
import java.util.Enumeration;

public class EnumerationTester {
   public static void main(String args[]) {
      Enumeration<String> days;
      Vector<String> dayNames = new Vector<>();

      dayNames.add("Sunday");
      dayNames.add("Monday");
      dayNames.add("Tuesday");
      dayNames.add("Wednesday");
      dayNames.add("Thursday");
      dayNames.add("Friday");
      dayNames.add("Saturday");

      days = dayNames.elements();
      while (days.hasMoreElements()) {
         System.out.println(days.nextElement()); 
      }
   }
}

Output:

Sunday
Monday
Tuesday
Wednesday
Thursday
Friday
Saturday

BitSet

The BitSet class represents a group of bits or flags that can be individually set or cleared. It's useful for handling sets of boolean flags.

Example: BitSet Operations

import java.util.BitSet;

public class BitSetDemo {
  public static void main(String args[]) {
    BitSet bits1 = new BitSet(16);
    BitSet bits2 = new BitSet(16);

    for(int i = 0; i < 16; i++) {
      if((i % 2) == 0) bits1.set(i);
      if((i % 5) != 0) bits2.set(i);
    }

    System.out.println("Initial pattern in bits1: ");
    System.out.println(bits1);

    System.out.println("\nInitial pattern in bits2: ");
    System.out.println(bits2);

    bits2.and(bits1);
    System.out.println("\nbits2 AND bits1: ");
    System.out.println(bits2);

    bits2.or(bits1);
    System.out.println("\nbits2 OR bits1: ");
    System.out.println(bits2);

    bits2.xor(bits1);
    System.out.println("\nbits2 XOR bits1: ");
    System.out.println(bits2);
  }
}

Output:
Initial pattern in bits1:
{0, 2, 4, 6, 8, 10, 12, 14}

Initial pattern in bits2:
{1, 2, 3, 4, 6, 7, 8, 9, 11, 12, 13, 14}

bits2 AND bits1:
{2, 4, 6, 8, 12, 14}

bits2 OR bits1:
{0, 2, 4, 6, 8, 10, 12, 14}

bits2 XOR bits1:
{}

Vector

A Vector is like an array but can grow/shrink dynamically. It allows indexed access and stores heterogeneous objects.

Example: Vector Usage

import java.util.*;
public class VectorDemo {
   public static void main(String args[]) {
      Vector v = new Vector(3, 2);
      v.addElement(new Integer(1));
      v.addElement(new Integer(2));
      v.addElement(new Integer(3));
      v.addElement(new Integer(4));
      v.addElement(new Double(5.45));
      v.addElement(new Double(6.08));
      v.addElement(new Integer(7));
      v.addElement(new Float(9.4));
      v.addElement(new Integer(10));
      v.addElement(new Integer(11));
      v.addElement(new Integer(12));

      Enumeration vEnum = v.elements();
      while(vEnum.hasMoreElements())
         System.out.print(vEnum.nextElement() + " ");
   }
}

Output:
1 2 3 4 5.45 6.08 7 9.4 10 11 12

Stack

Stack is a last-in, first-out (LIFO) data structure. You push elements on top and pop them off from the top.

Example: Stack Operations

import java.util.*;

public class StackDemo {
   static void showpush(Stack st, int a) {
      st.push(a);
      System.out.println("push(" + a + ")");
      System.out.println("stack: " + st);
   }

   static void showpop(Stack st) {
      System.out.print("pop -> ");
      Integer a = (Integer) st.pop();
      System.out.println(a);
      System.out.println("stack: " + st);
   }

   public static void main(String args[]) {
      Stack st = new Stack();
      showpush(st, 42);
      showpush(st, 66);
      showpush(st, 99);
      showpop(st);
      showpop(st);
      showpop(st);
      try {
         showpop(st);
      } catch (EmptyStackException e) {
         System.out.println("empty stack");
      }
   }
}

Output:
push(42)... pop -> 99... empty stack

Dictionary

Dictionary is an abstract class for mapping keys to values. It provides a foundation for key-based data retrieval.

Example: Dictionary Usage

import java.util.*;

public class DictionaryDemo {
   public static void main(String[] args) {
      Dictionary<Integer, Integer> dictionary = new Hashtable<>();
      dictionary.put(1, 1);
      dictionary.put(2, 2);
      Enumeration<Integer> enumeration = dictionary.keys();
      while(enumeration.hasMoreElements()) {
         System.out.println(enumeration.nextElement());
      }
   }
}

Output:
2
1

Hashtable

Hashtable maps keys to values and uses hash codes for fast access. It's synchronized and stores unique keys.

Example: Hashtable Usage

import java.util.Hashtable;

public class HashtableDemo {
   public static void main(String args[]) {
      Hashtable<Integer,Integer> hashtable = new Hashtable<>();
      hashtable.put(1, 1);
      hashtable.put(2, 2);
      hashtable.put(3, 3);
      System.out.println("Contains 2? " + hashtable.contains(2));
      System.out.println("Contains 4? " + hashtable.contains(4));
   }
}

Output:
Contains 2? true
Contains 4? false

NumPy Joining Array

Joining NumPy Arrays

Joining means putting contents of two or more arrays into a single array.

In SQL we join tables based on a key, whereas in NumPy we join arrays by axes.

Use the concatenate() function to join arrays. If axis is not specified, it defaults to 0.

import numpy as np

arr1 = np.array([1, 2, 3])
arr2 = np.array([4, 5, 6])

arr = np.concatenate((arr1, arr2))
print(arr)

Join two 2-D arrays along rows (axis=1):

import numpy as np

arr1 = np.array([[1, 2], [3, 4]])
arr2 = np.array([[5, 6], [7, 8]])

arr = np.concatenate((arr1, arr2), axis=1)
print(arr)

Joining Arrays Using Stack Functions

Stacking is similar to concatenation, except it joins arrays along a new axis.

Use stack() to join along a new axis. Default axis is 0.

import numpy as np

arr1 = np.array([1, 2, 3])
arr2 = np.array([4, 5, 6])

arr = np.stack((arr1, arr2), axis=1)
print(arr)

Stacking Along Rows

Use hstack() to stack arrays horizontally (along rows).

import numpy as np

arr1 = np.array([1, 2, 3])
arr2 = np.array([4, 5, 6])

arr = np.hstack((arr1, arr2))
print(arr)

Stacking Along Columns

Use vstack() to stack arrays vertically (along columns).

import numpy as np

arr1 = np.array([1, 2, 3])
arr2 = np.array([4, 5, 6])

arr = np.vstack((arr1, arr2))
print(arr)

Stacking Along Height (Depth)

Use dstack() to stack arrays along height (also called depth).

import numpy as np

arr1 = np.array([1, 2, 3])
arr2 = np.array([4, 5, 6])

arr = np.dstack((arr1, arr2))
print(arr)

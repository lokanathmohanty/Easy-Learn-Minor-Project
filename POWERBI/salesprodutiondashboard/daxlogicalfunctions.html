DAX Logical Functions in Power BI

DAX logical functions allow you to build powerful conditional expressions that support complex decision-making in Power BI models. These functions evaluate boolean logic to return TRUE, FALSE, or custom results based on conditions.

They are essential for data modeling, enabling users to implement row-level logic, error handling, and conditional formatting.

Primary DAX Logical Functions with Examples

  • AND() - Returns TRUE if both conditions are TRUE, otherwise FALSE.
    Example: cal = AND(Sheet1[Theory Marks]>40, Sheet1[Practical Marks]>2)
  • OR() - Returns TRUE if either condition is TRUE, otherwise FALSE.
    Example: cal = OR(Sheet1[Theory Marks]>40, Sheet1[Practical Marks]>2)
  • NOT() - Reverses the logical value.
    Example: c1 = NOT(Sheet1[cal])
  • IF() - Returns one value if TRUE, another if FALSE.
    Example: cal = IF(AND(Sheet1[Theory Marks]>40, Sheet1[Practical Marks]>2), "Pass", "Fail")
  • COALESCE() - Returns first non-blank value from the parameters.
    Example: mn = COALESCE(Sheet1[Wr_lf_balance], Sheet1[Jb_st], Sheet1[EST])
  • SWITCH() - Evaluates multiple conditions and returns corresponding results.
    Example: pr = SWITCH(TRUE(), Sheet1[cal]=TRUE(), "Student Pass", Sheet1[cal]=FALSE(), "Student Fail")
  • IFERROR() - Returns specified value if expression results in error.
    Example: err = IFERROR('Sheet1'[Theory Marks], 0)

Additional Logical Functions

  • BITAND() - Returns bitwise AND of two numbers.
  • BITOR() - Returns bitwise OR of two numbers.
  • BITXOR() - Returns bitwise XOR of two numbers.
  • BITLSHIFT() - Bitwise left shift operation.
  • TRUE() - Returns logical TRUE.
  • FALSE() - Returns logical FALSE.

Using Logical Expressions in Power BI

Logical functions can be combined with other DAX functions for conditional calculations, data cleaning, and error handling.

They form the basis for creating dynamic measures and calculated columns that respond to user interactions and report contexts.

JavaScript - try...catch Statement

The try...catch statement in JavaScript is used to handle runtime errors (exceptions). It allows developers to write safer code by catching unexpected issues at runtime.

The try block contains the code that may throw an error, and the catch block handles the error if it occurs.

Syntax

try {
   // JavaScript code
} catch(error) {
   // Handle error
}

The error object is optional and contains useful information like the name and message of the error.

Example: Basic try...catch

<script>
   const output = document.getElementById("demo");
   try {
      let num = num1;
   } catch (err) {
      output.innerHTML += "The error name is: " + err.name + "<br>";
      output.innerHTML += "The error message is: " + err.message + ".<br>";
   }
</script>

Example: Execution Flow

<script>
   const output = document.getElementById("demo");
   try {
      output.innerHTML += "In the start of try block <br>";
      welcome();
      output.innerHTML += "In the end of try block <br>";
   } catch (err) {
      output.innerHTML += "In the catch block <br>";
      output.innerHTML += "The error name is: " + err.name + "<br>";
      output.innerHTML += "The error message is: " + err.message + ".<br>";
   }
</script>

try...catch...finally Statement

The finally block executes code after the try and catch blocks, regardless of whether an error occurred.

Example: try...catch...finally

<script>
   try {
      let a = b;
   } catch (e) {
      document.getElementById("output").innerHTML = e;
   } finally {
      document.getElementById("output").innerHTML += "<br>Finally block always executes";
   }
</script>

Throwing Errors

You can manually throw errors using the throw statement. This is useful for custom validations and error handling.

Example: Throw Custom Error

<script>
   try {
      throw new Error("Custom error");
   } catch (e) {
      console.log(e.name + " : " + e.message);
   }
</script>

Advanced Error Handling

  • Nesting Try Blocks − Inner try can pass errors to outer catch.
  • Rethrowing Errors − Re-throw an error from a catch block if not handled.
  • Conditional Catch − Use instanceof to handle different error types.

Example: Nested try-catch

<script>
   try {
      try {
         throw Error("Error in the inner try block");
      } finally {
         console.log("Inside the inner finally block.");
      }
   } catch (e) {
      console.log("Inside the outer catch block.");
      console.log("Error: " + e.message);
   }
</script>

Error Handling with Promises

Errors in promises are handled with the .catch() method rather than try-catch.

Example: Promise Rejection

<script>
   let promise = new Promise((resolve, reject) => {
      setTimeout(() => reject("The promise is rejected!"), 1000);
   });

   promise
      .then((result) => console.log(result))
      .catch((error) => console.log(error));
</script>

Types of JavaScript Errors

  • RangeError − A value is out of range.
  • ReferenceError − Using undefined variables/functions.
  • TypeError − Invalid type usage.
  • URIError − Invalid URI usage.

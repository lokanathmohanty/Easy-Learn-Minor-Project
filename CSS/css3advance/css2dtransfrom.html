CSS - 2D Transforms

CSS transforms are used to modify the element's shape and size and are responsible for movements of elements in two-dimensional space using functions like translate(), scale(), rotate(), and skew(). These functions allow you to move, scale, rotate, and skew elements along the X and Y axes, creating various visual effects and manipulations.

CSS 2D Translate

The translate() function moves an element along the X and Y axes.

Example

The following example shows a box that moves along these axes when hovered over.


.box {
    transform: translate(50px, 50px);
}
.box:hover {
    transform: translate(-50px, -50px);
}

CSS 2D Rotate

The rotate() function rotates an element around a specified point on the 2D plane.

Example

The following example shows a box that rotates when hovered over.


.box {
    transform: rotate(15deg);
}
.box:hover {
    transform: rotate(-15deg);
}

CSS 2D Scale

The scale() function scales an element along the X and Y axes.

Example

The following example shows a box that scales up and down when hovered over.


.box {
    transform: scale(1);
}
.box:hover {
    transform: scale(1.5);
}

CSS 2D Skew

The skew() function skews an element along the X and Y axes.

Example

The following example shows a box that skews when hovered over.


.box {
    transform: skewX(10deg) skewY(10deg);
}
.box:hover {
    transform: skewX(-10deg) skewY(-10deg);
}

CSS 2D Transform Related Functions

  • translate() – Moves an element along the X and Y axes.
  • rotate() – Rotates an element around a point in 2D space.
  • scale() – Scales an element along the X and Y axes.
  • skew() – Skews an element along the X and Y axes.
  • transform() – Applies a 2D or 3D transformation to an element.

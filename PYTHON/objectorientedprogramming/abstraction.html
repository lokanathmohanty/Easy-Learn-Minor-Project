Python - Abstraction

Abstraction is a major principle of object-oriented programming. It means exposing only relevant data and functionalities to the user, while hiding complex implementation details. This helps manage complexity and enhances maintainability in software design.

In Python, abstraction can be achieved using abstract classes, which serve as blueprints and enforce that derived classes implement specific methods.

Types of Abstraction

  • Data abstraction: Hides the actual data details and shows only essential features.
  • Process abstraction: Hides the implementation details of underlying processes or logic.

Python Abstract Classes

An abstract class provides a common interface for its subclasses and cannot be instantiated directly. It must inherit from ABC (Abstract Base Class) and contain at least one method marked with the @abstractmethod decorator.

Abstract Class Example

from abc import ABC, abstractmethod

class Demo(ABC):
    @abstractmethod
    def method1(self):
        print("abstract method")

    def method2(self):
        print("concrete method")

# obj = Demo()  # TypeError: Can't instantiate abstract class Demo

An abstract class must be used as a base for another class. The child class must override all abstract methods from the abstract class to be instantiable.

Abstract Method Overriding

from abc import ABC, abstractmethod

class DemoClass(ABC):
    @abstractmethod
    def method1(self):
        print("abstract method")
    def method2(self):
        print("concrete method")

class ConcreteClass(DemoClass):
    def method1(self):
        super().method1()

obj = ConcreteClass()
obj.method1()
obj.method2()
# Output:
# abstract method
# concrete method

Benefits of Abstraction

  • Keeps code modular and clean by hiding unnecessary details.
  • Promotes reusability and ease of code maintenance.
  • Enforces consistency and contract in derived classes.

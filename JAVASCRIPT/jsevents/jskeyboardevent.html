JavaScript - Keyboard Events

The keyboard events in JavaScript provide a way to interact with a web page or application based on the user's keyboard input. These events allow developers to capture and respond to various keyboard actions, such as key presses, key releases, and character inputs. The primary keyboard events in JavaScript include keydown, keypress, and keyup.

Common Keyboard Events

  • Keydown Event − Triggered when a key on the keyboard is pressed down. It provides details such as the key code and modifier keys (Shift, Ctrl, Alt).
  • Keypress Event − Triggered when a character key is typed. Non-character keys like Shift or Ctrl do not activate this event.
  • Keyup Event − Triggered when a pressed key is released. Useful for tracking key releases and creating interactivity.

Keyboard Event Properties

Several properties are commonly used with keyboard events to gather information:

  • event.key − String representing the key value.
  • event.code − String representing the physical key.
  • event.location − Indicates the location of the key on the keyboard.
  • event.ctrlKey, event.shiftKey, event.altKey, event.metaKey − Booleans for modifier keys.
  • event.repeat − Indicates whether the event is a repeat.
  • event.isComposing − Indicates if the event is part of composition.
  • event.which − Deprecated, used for numeric key code.
  • event.getModifierState(keyArg) − Returns whether a modifier key is pressed.

Example: Keydown Event

This example shows how to capture a key press using the keydown event.

<!DOCTYPE html>
<html>
<body>
   <h3>Press any key</h3>
   <script>
      document.addEventListener('keydown', function (event) {
         document.getElementById('output').innerHTML =
         "Key pressed: " + event.key;
      });
   </script>
   <div id="output"></div>
</body>
</html>

Example: Keypress Event

This example captures a typed character using the keypress event.

<!DOCTYPE html>
<html>
<body>
   <h3>Type a character</h3>
   <div id="output"></div>
   <script>
      document.addEventListener('keypress', function (event) {
         document.getElementById('output').innerHTML =
         "Character pressed: " + event.key;
      });
   </script>
</body>
</html>

Example: Keyup Event

This example captures a key release using the keyup event.

<!DOCTYPE html>
<html>
<body>
   <h3>Press and Release a key</h3>
   <div id="output"></div>
   <script>
      document.addEventListener('keyup', function (event) {
         document.getElementById('output').innerHTML =
         "Key released: " + event.key;
      });
   </script>
</body>
</html>

Difference Between Keydown and Keypress

Keydown fires when any key is pressed, including modifiers, and continues firing as long as the key is held down. Keypress fires only when a character key is pressed, providing the typed character but not modifiers.

Example: Without addEventListener

Keyboard events can also be handled by directly assigning event handlers.

<!DOCTYPE html>
<html>
<body>
   <div>Enter some text: 
      <input onkeydown="handleKeyDown(event)" onkeyup="handleKeyUp(event)">
   </div>
   <div id="output"></div>
   <script>
      function handleKeyDown(event) {
         document.getElementById('output').innerHTML +=
         "Key pressed: " + event.key + '<br>Key code: ' + event.keyCode + '<br>';
      }
      function handleKeyUp(event) {
         document.getElementById('output').innerHTML +=
         "Key released: " + event.key + '<br><br>';
      }
   </script>
</body>
</html>

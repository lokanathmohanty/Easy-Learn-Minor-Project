CSS - shape-outside Property

The CSS shape-outside property is used to define a shape around which inline content (such as text or images) should wrap. This allows for creating non-rectangular or complex text wrapping shapes, giving more control over the flow of content around elements.

Possible Values

  • none − Content flows normally around the element’s margin box.
  • margin-box − Defines a shape around the outside edge of the margin.
  • content-box − Defines a shape around the element’s content box.
  • border-box − Defines a shape around the element’s border box.
  • padding-box − Defines a shape around the element’s padding box.
  • <basic-shape> − Uses functions like circle(), ellipse(), polygon(), or path().
  • url() − Defines an image to use as the wrapping shape.
  • linear-gradient() − Creates gradient shapes for wrapping content.

Applies to

This property applies only to floated elements.

Syntax

shape-outside = none | margin-box | content-box | border-box | padding-box | circle() | ellipse() | inset() | polygon() | path() | url() | linear-gradient();

Examples

1. shape-outside: margin-box

This makes inline content wrap around the margin box of the floated element.

shape-outside: margin-box;

2. shape-outside: content-box

Defines the shape based on the element’s content box.

shape-outside: content-box;

3. shape-outside: padding-box

Content wraps around the padding box of the element.

shape-outside: padding-box;

4. shape-outside: border-box

The shape is defined by the outer border box of the element.

shape-outside: border-box;

5. shape-outside: circle()

Defines a circular shape around which text flows.

shape-outside: circle(50%);

6. shape-outside: ellipse()

Defines an elliptical shape for text wrapping.

shape-outside: ellipse(50px 100px at 50% 50%);

7. shape-outside: url()

Wraps text around a shape defined by an image.

shape-outside: url("images/yellow-flower.jpg");

8. shape-outside: polygon()

Defines a custom polygonal shape.

shape-outside: polygon(0 0, 0 200px, 200px 300px);

9. shape-outside: inset()

Creates a rectangular inset shape for text wrapping.

shape-outside: inset(10px 10px 10px 10px);

10. shape-outside: path()

Defines a path-based shape using polygonal points.

shape-outside: path("M10,10 L100,10 L50,100 Z");

11. shape-outside: linear-gradient()

Allows wrapping around gradient-based shapes.

shape-outside: linear-gradient(45deg, #fff 150px, red 150px);

Related Properties

  • shape-margin − Adds margin around CSS shapes created with shape-outside.
  • shape-image-threshold − Sets the alpha threshold for shape extraction when using an image.

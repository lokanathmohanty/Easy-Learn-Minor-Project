PHP: Complete Form Handling Example

This session consolidates the concepts of **Form Validation**, **Data Sanitization**, and **Data Extraction** into a single, functional PHP script. The script is structured in three logical parts: 1) PHP for Error Tracking and Validation, 2) The HTML Form, and 3) PHP for Displaying Submitted Data.

Three-Part Structure

To handle errors and re-display the form in a single file (a self-processing form), the code follows this flow:

  1. PHP Validation Block (Top): This code runs first. It initializes error variables and checks if the form has been submitted ($_SERVER["REQUEST_METHOD"] == "POST"). If submitted, it performs validation (e.g., checking for empty fields, verifying email format) and stores errors in respective $xxxErr variables.
  2. HTML Form (Middle): The form's action is set to $_SERVER["PHP_SELF"] (sanitized with htmlspecialchars()). **Inline PHP** is used here to display any validation errors next to the corresponding input field (e.g., <span class="error"><?php echo $nameErr;?></span>).
  3. PHP Display Block (Bottom): This section executes only if the form has been submitted. It echoes the collected, processed, and sanitized user data.

Data Sanitization Helper Function

The **test_input()** function is used globally to clean all incoming data, providing security and consistency:


function test_input($data) {
   $data = trim($data);
   $data = stripslashes($data);
   $data = htmlspecialchars($data); // Essential security measure
   return $data;
}

Example Session: Form Elements and Validation Logic

Key Validation Points Demonstrated

  • Required Fields: Checking $_POST["name"] and $_POST["email"] with empty().
  • Email Format: Using the robust **filter_var($email, FILTER_VALIDATE_EMAIL)** function.
  • Multiple Selection: The <select name="subject[]" multiple> element is handled as an **array** in PHP's $_POST["subject"].

<?php
   // --- PART 1: PHP Validation Block (Top) ---
   $nameErr = $emailErr = $genderErr = "";
   $name = $email = $gender = $class = $course = $subject = "";

   if ($_SERVER["REQUEST_METHOD"] == "POST") {
      // Name validation
      if (empty($_POST["name"])) { $nameErr = "Name required"; } else { $name = test_input($_POST["name"]); }

      // Email validation
      if (empty($_POST["email"])) {
         $emailErr = "Email required";
      } else {
         $email = test_input($_POST["email"]);
         if (!filter_var($email, FILTER_VALIDATE_EMAIL)) { $emailErr = "Invalid email format"; }
      }
      
      // Gender validation
      if (empty($_POST["gender"])) { $genderErr = "Gender required"; } else { $gender = test_input($_POST["gender"]); }

      // Class/Course fields (simple sanitization if not required)
      $course = isset($_POST["course"]) ? test_input($_POST["course"]) : "";
      $class = isset($_POST["class"]) ? test_input($_POST["class"]) : "";
      
      // Multiple selection (Subject is an array)
      $subject = isset($_POST["subject"]) ? $_POST["subject"] : [];
   }
   // ... test_input function definition ...
?>

<!-- PART 2: HTML Form (Middle) -->
<form method="POST" action="<?php echo htmlspecialchars($_SERVER["PHP_SELF"]);?>">
   Name: <input type="text" name="name"> <span class="error">* <?php echo $nameErr;?></span><br>
   Email: <input type="text" name="email"> <span class="error">* <?php echo $emailErr;?></span><br>
   Gender:
   <input type="radio" name="gender" value="Female">Female
   <input type="radio" name="gender" value="Male">Male
   <span class="error">* <?php echo $genderErr;?></span><br>
   <input type="submit" value="Submit">
</form>

<?php
   // --- PART 3: PHP Display Block (Bottom) ---
   if ($_SERVER["REQUEST_METHOD"] == "POST" && empty($nameErr) && empty($emailErr) && empty($genderErr)) {
      echo "<h2>Submitted Data:</h2>";
      echo "<p>Name: $name</p>";
      echo "<p>Email: $email</p>";
      // ... display other fields ...
      
      // Displaying multiple subjects
      if (!empty($subject)) {
         echo "<p>Subjects Chosen: " . implode(", ", $subject) . "</p>";
      }
   }
?>

Java EnumSet Class Summary 🔢🔠

The **java.util.EnumSet** class is a high-performance, specialized **Set** implementation designed exclusively for use with elements of a single **enum type**. It is an abstract class, meaning you instantiate it using its static factory methods rather than constructors.

I. Key Characteristics and Performance

EnumSet is arguably the most efficient and concise Set implementation in the Java Collections Framework:

  • Bit Vector Implementation: Internally, `EnumSet` is represented as a **bit vector** (or bit mask). Since the set of enum constants is fixed and finite, membership is tracked using a single bit for each constant. This makes operations extremely fast.
  • Performance: All basic operations like **add()**, **remove()**, and **contains()** execute in **constant time ($O(1)$)** and are faster than general-purpose Sets like `HashSet`.
  • Ordering: Elements are always maintained and iterated over in the **natural order** of their keys (the order in which the enum constants are declared).
  • Single Enum Type: All elements must come from the single enum type specified at creation.
  • Non-Synchronized: It is **not thread-safe**. External synchronization is required for concurrent modification.

II. Static Factory Methods (Creation)

Because the class is abstract, instances are created using various static methods tailored for common set-up patterns:

Method Description
static <E> EnumSet<E> **noneOf** (Class<E> elementType) Creates an **empty** set for the specified enum type.
static <E> EnumSet<E> **allOf** (Class<E> elementType) Creates a set containing **all** of the enum constants for the specified type.
static <E> EnumSet<E> **of** (E e1, ...) Creates a set initially containing the specified element(s).
static <E> EnumSet<E> **range** (E from, E to) Creates a set containing all elements in the range between the two specified endpoints (inclusive).
static <E> EnumSet<E> **complementOf** (EnumSet<E> s) Creates a set containing all constants in the enum type that are **not** in the specified set s.

III. Example of Usage

The example demonstrates the simple use of the of() factory method to create a small, efficient set containing only a single enum constant:

public enum Numbers {ONE, TWO, THREE, FOUR, FIVE};

// Creates a set of type Numbers containing only ONE.
EnumSet<Numbers> set = EnumSet.of(Numbers.ONE);

// Output: Set:[ONE]

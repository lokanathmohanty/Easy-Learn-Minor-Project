Node.js Web Module and Creating a Web Server

What is a Web Server?

The http module in Node.js enables data transfer over HTTP. Using http.createServer(), you can create an HTTP server instance that listens for requests on a specified host and port.

The web server handles HTTP requests from clients and returns web pages, usually HTML, along with related assets like images and scripts. Dynamic content can be served by interfacing with databases or application logic.

Web Application Architecture

  • Client: Browsers or apps making HTTP requests.
  • Server: Web server managing client requests and responses.
  • Business: Application server processing logic and data retrieval.
  • Data: Databases or other data sources.

Creating a Simple Web Server

var http = require('http');
var fs = require('fs');
var url = require('url');

http.createServer(function(request, response) {
  var pathname = url.parse(request.url).pathname;

  console.log("Request for " + pathname + " received.");

  fs.readFile(pathname.substr(1), function(err, data) {
    if (err) {
      console.log(err);
    } else {
      response.writeHead(200, {'Content-Type': 'text/html'});
      response.write(data.toString());
    }
    response.end();
  });
}).listen(5000);

console.log('Server running at http://127.0.0.1:5000');

Run the server and access pages like http://localhost:5000/index.html to view your HTML files served by this server.

Creating a Web Client

var http = require('http');
var fs = require('fs');
var path = require('path');

var options = {
  host: 'localhost',
  port: '5000',
  path: path.join('/', process.argv[2])
};

var body = '';
var callback = function(response) {
  response.on('data', function(data) {
    body += data;
  });

  response.on('end', function() {
    console.log(body);
    fs.writeFile(options.path.substr(1), body, function(err) {
      if (err) console.log(err);
      else console.log('Write operation complete.');
    });
  });
};

var req = http.request(options, callback);
req.end();

Run the client script with the file name as argument to download the file from the server:

node client.js index.html

This will save the requested file to the client's folder.

R - CSV Files

In R, data can be read from and written to files outside the R environment. CSV (Comma Separated Values) files are a common text format where values are separated by commas. R offers functions to read from and write to CSV files, which should be located in the working directory or accessed via set paths.

Getting and Setting the Working Directory

# Get current working directory
print(getwd())

# Set new working directory
setwd("/web/com")

# Verify current working directory
print(getwd())

Reading a CSV File

Read a CSV file available in the current working directory using read.csv():

data <- read.csv("input.csv")
print(data)

Sample output:

  id     name   salary  start_date     dept
1  1     Rick    623.30 2012-01-01       IT
2  2      Dan    515.20 2013-09-23 Operations
3  3 Michelle   611.00 2014-11-15       IT
4  4     Ryan    729.00 2014-05-11       HR

6  6     Nina    578.00 2013-05-21       IT
7  7    Simon    632.80 2013-07-30 Operations

Analyzing the CSV Data Frame

data <- read.csv("input.csv")

print(is.data.frame(data))
print(ncol(data))
print(nrow(data))

Output:

[1] TRUE
[1] 5
[1] 8

Get the Maximum Salary

# Find maximum salary in the data
sal <- max(data$salary)
print(sal)

Output:

[1] 843.25

Get Details of Person with Maximum Salary

retval <- subset(data, salary == max(salary))
print(retval)

Output:

   id   name  salary  start_date  dept
5 NA    Gary 843.25   2015-03-27  Finance

Get All People Working in IT Department

retval <- subset(data, dept == "IT")
print(retval)

Output:

  id   name  salary  start_date  dept
1  1   Rick  623.3   2012-01-01   IT
3  3 Michelle 611.0   2014-11-15   IT
6  6   Nina  578.0   2013-05-21   IT

Get the People in IT with Salary Greater Than 600

info <- subset(data, salary > 600 & dept == "IT")
print(info)

Output:

  id   name  salary  start_date  dept
1  1   Rick  623.3   2012-01-01   IT
3  3 Michelle 611.0  2014-11-15   IT

Get People Who Joined on or After 2014

retval <- subset(data, as.Date(start_date) >= as.Date("2014-01-01"))
print(retval)

Output:

  id   name  salary  start_date  dept
3  3 Michelle 611.00 2014-11-15   IT
4  4 Ryan   729.00 2014-05-11   HR
5 NA Gary 843.25 2015-03-27   Finance
8  8 Guru 722.50 2014-06-17   Finance

Writing Data Frame into a CSV File

# Write a subset into a new CSV file
write.csv(retval, "output.csv")

newdata <- read.csv("output.csv")
print(newdata)

Output (with row.names column X):

  X id    name     salary  start_date  dept
1 3 Michelle 611.00 2014-11-15   IT
2 4 Ryan    729.00 2014-05-11   HR
3 5 Gary    843.25 2015-03-27 Finance
4 8 Guru    722.50 2014-06-17 Finance

Writing CSV without Row Names

write.csv(retval, "output.csv", row.names = FALSE)
newdata <- read.csv("output.csv")
print(newdata)

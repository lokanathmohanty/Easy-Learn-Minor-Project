ReactJS - Icons

Web Icons are important assets in a web application. Developers use them extensively in multiple places to better visualize the context. For example, a menu can be easily identifiable with a menu icon.

Icons have evolved over time:

  • Initially, icons were simple images in fixed sizes like 24x24, 32x32, etc.
  • Later, multiple icons were grouped in a single image called icon sprite and used through CSS positioning.
  • Then, fonts were used to hold multiple icons via font-family.
  • The latest and most popular option is SVG icons, which can be used via <img> tag or inline SVG.

React provides a community-based icon library called React Icons, which includes a wide range of icons from different sources.

React Icon Library

The React Icons library collects thousands of icons from different vendors and wraps them as React components. Developers can simply import and use them in projects. Some popular sets include:

  • Bootstrap Icons
  • Material Design Icons
  • Font Awesome
  • Devicons
  • Boxicons
  • Ant Design Icons
  • GitHub Octicons
  • VS Code Icons

Full list of icons is available at React Icons Website.

Installing React Icons

To install React Icons library, use the following command:

npm install react-icons --save

Using React Icon Component

Each icon is available as a React component. For example, the Material Design calendar icon is MdCalendarToday from the package react-icons/md.

import { MdCalendarToday } from "react-icons/md";

class SimpleIcon extends React.Component {
  render() {
    return <div>This icon <MdCalendarToday /> is a calendar icon imported from React Icons</div>
  }
}

You can change the icon’s color and size using CSS or inline styles:

<MdCalendarToday style={{ color: "red", size: "24px" }} />

Applying React Icon Library

Steps to use React Icons in an application:

create-react-app myapp
cd myapp
npm start

Install React Icons:

npm install react-icons --save

Create a new component (SimpleIcon.js):

import React from "react";
import { MdCalendarToday } from "react-icons/md";

class SimpleIcon extends React.Component {
  render() {
    return <div>This icon <MdCalendarToday style={{ color: "red", size: "24px" }} />
    is calendar icon imported from React Icons</div>
  }
}
export default SimpleIcon;

Update App.js:

import './App.css'
import React from 'react';
import SimpleIcon from './Components/SimpleIcon'

function App() {
  return (
    <div className="container">
      <SimpleIcon />
    </div>
  );
}
export default App;

Summary

The React Icons library provides a large collection of icons from different sources in one place. It makes adding icons to applications simple and flexible, with easy customization for color and size.

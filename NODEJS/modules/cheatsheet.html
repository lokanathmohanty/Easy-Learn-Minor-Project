Node.js Cheat Sheet

Content

  • Initialize Project: npm init or npm init -y
  • Install Package: npm install package-name
  • Create HTTP Server: Use http module
  • Read File: fs.readFile or fs.readFileSync
  • Write File: fs.writeFile or fs.writeFileSync
  • Use Express: const express = require('express');
  • Environment Variables: process.env.VARIABLE_NAME
  • Export/Import Module: module.exports and require()
  • Run App: node app.js or nodemon app.js
  • Common Modules: http, fs, path, os, events

Example

Basic HTTP server using the http module:

const http = require('http');

const server = http.createServer((req, res) => {
    res.writeHead(200, { 'Content-Type': 'text/plain' });
    res.end('Hello World');
});

server.listen(3000, () => {
    console.log('Server running at http://localhost:3000/');
});

Using Express for the same server:

const express = require('express');
const app = express();

app.get('/', (req, res) => {
    res.send('Hello from Express!');
});

app.listen(3000, () => {
    console.log('Server is listening on port 3000');
});

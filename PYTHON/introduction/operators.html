Python - Operators

What are Python Operators?

Python operators are special symbols used to perform specific operations on one or more operands. The variables, values, or expressions can be used as operands. For example, Python's addition operator (+) performs addition on two operands.

Related Terms

  • Unary operators: Require one operand.
  • Binary operators: Require two operands.
  • Operands: Variables, values, or expressions that work with operators.

Types of Python Operators

  • Arithmetic Operators
  • Comparison (Relational) Operators
  • Assignment Operators
  • Logical Operators
  • Bitwise Operators
  • Membership Operators
  • Identity Operators

Python Arithmetic Operators

Used for mathematical operations.

a = 21
b = 10

print(a + b)   # Addition
print(a - b)   # Subtraction
print(a * b)   # Multiplication
print(a / b)   # Division
print(a % b)   # Modulus
print(2 ** 3)  # Exponent
print(10 // 5) # Floor Division

Python Comparison Operators

Compare values and return Boolean results.

a = 21
b = 10

print(a == b)  # Equal
print(a != b)  # Not equal
print(a > b)   # Greater than
print(a < b)   # Less than
print(a >= b)  # Greater or equal
print(a <= b)  # Less or equal

Python Assignment Operators

Assign values to variables.

a = 10
a += 5   # a = a + 5
a -= 3   # a = a - 3
a *= 2   # a = a * 2
a /= 4   # a = a / 4
a %= 3   # a = a % 3
a **= 2  # a = a ** 2
a //= 2  # a = a // 2

Python Bitwise Operators

Work on binary representations.

a = 20  # 10100
b = 10  # 01010

print(a & b)  # AND
print(a | b)  # OR
print(a ^ b)  # XOR
print(~a)     # NOT
print(a << 2) # Left shift
print(a >> 2) # Right shift

Python Logical Operators

Combine conditions.

x = 5
print(x > 3 and x < 10)  # True
print(x > 3 or x < 4)    # True
print(not(x > 3 and x < 10))  # False

Python Membership Operators

Test membership in sequences.

nums = [1, 2, 3, 4, 5]
print(3 in nums)       # True
print(10 not in nums)  # True

Python Identity Operators

Check object identity (memory location).

a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a is c)     # True
print(a is b)     # False
print(a is not b) # True

Python Operator Precedence

Order in which operators are evaluated:

  1. ** → Exponentiation
  2. ~ + - → Unary operators
  3. * / % // → Multiplication, division, modulus, floor division
  4. + - → Addition, subtraction
  5. >>, << → Bitwise shift
  6. & → Bitwise AND
  7. ^ | → Bitwise XOR, OR
  8. < <= > >= → Comparisons
  9. == != → Equality
  10. =, +=, -= … → Assignment
  11. is, is not → Identity
  12. in, not in → Membership
  13. not, or, and → Logical

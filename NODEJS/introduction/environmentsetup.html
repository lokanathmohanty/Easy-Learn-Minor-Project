Node.js Environment Setup

Overview

This tutorial includes ready-to-run examples to help learners understand Node.js concepts by executing code. You can either use the online Node.js environment or install Node.js on your local machine to practice.

Try it Option Online

You don't need to set up your own environment to start learning Node.js. An online Node.js environment is available where you can run and modify example codes directly through the tutorial website.

Example: 


/* Hello World! program in Node.js */
console.log("Hello World!");

Use the "Live Demo" button to try this example online and see the results instantly.

Local Environment Setup

To set up Node.js on your computer, you need:

  • Node.js binary installer
  • Node Package Manager (NPM)
  • IDE or text editor

Visit the official Node.js downloads page to get the correct binary for your operating system: https://nodejs.org/en/download

There are two versions provided: the latest version and an LTS (Long Term Support) version recommended for most users. Both 32-bit and 64-bit installers and archives are available for Windows, macOS, and Linux.

Installation on Windows

Download the 64-bit Windows installer from: Node.js Windows Installer. Run the installer and follow the wizard steps. It adds Node.js to your system path automatically.

To verify the installation, open the command prompt and execute: 

node -v

If installed properly, this will display the installed Node.js version.

Installation on Ubuntu Linux

Download the Linux binary tarball: Node.js Linux Binary. Extract it using the command: 

tar -xf node-v20.9.0-linux-x64.tar.gz

Move the extracted files to the installation directory: 

sudo mv node-v20.9.0-linux-x64 /usr/local/node-v20.9.0

Create a symbolic link to make Node.js accessible: 

sudo ln -s /usr/local/node-v20.9.0/bin/node /usr/bin/node

Verify the installation by running: 

node -v

Alternatively, use Ubuntu package manager to install Node.js: 

sudo apt update
sudo apt install nodejs
node -v

NPM comes bundled with Node.js binaries since version 0.6.0, so no separate installation is needed.

Editing Node.js Code

You can use any text editor to write Node.js scripts, but an IDE like Visual Studio Code is recommended for better developer experience with syntax highlighting and debugging support.

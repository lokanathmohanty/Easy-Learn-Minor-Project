CSS - isolation Property

The CSS isolation property is used to control how an element's content interacts with its parent and sibling elements in terms of rendering and stacking context. It determines whether an element establishes a new stacking context or not.

Syntax

isolation: auto | isolate | initial | inherit;

Property Values

  • auto – The element does not create a new stacking context, but instead inherits its parent’s context. Default.
  • isolate – The element creates a new stacking context, isolating its content from siblings and parent elements.
  • initial – Sets the property to its default value.
  • inherit – Inherits the property value from the parent element.

Examples of CSS isolation Property

Isolation Property with auto Value

In this example, the auto value does not create a new stacking context. The mix-blend-mode: difference subtracts the top color from the bottom color, creating a high-contrast effect.

Example

.container {
  background-color: yellow;
  width: 250px;
  height: 200px;
  padding: 5px;
}
.box2 {
  width: 130px;
  height: 130px;
  border: 5px solid red;
  padding: 5px;
  mix-blend-mode: difference;
  margin-left: 50px;
}
.box1 {
  isolation: auto;
}
      
<div class="container">
  <div class="box1">
    <div class="box2">
      isolation: auto;
    </div>
  </div>
</div>

Isolation Property with isolate Value

In this example, the isolate value creates a new stacking context. This prevents the element’s blending behavior from affecting outside elements, so box1 is isolated and independent of its siblings.

Example

.container {
  background-color: yellow;
  width: 250px;
  height: 200px;
  padding: 5px;
}
.box2 {
  width: 130px;
  height: 130px;
  border: 5px solid red;
  padding: 5px;
  mix-blend-mode: difference;
  margin-left: 50px;
}
.box1 {
  isolation: isolate;
}
      
<div class="container">
  <div class="box1">
    <div class="box2">
      isolation: isolate;
    </div>
  </div>
</div>

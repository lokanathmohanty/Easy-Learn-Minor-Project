JavaScript - Short-Circuiting

In JavaScript, short-circuiting is a feature that checks conditions and stops as soon as it knows the result. It avoids evaluating the rest of the expression, preventing unnecessary operations.

Short-Circuiting with && Operator

Short-circuit evaluation with the && (AND) operator means if the first expression is false, the entire expression will be false and the rest will not be evaluated. 

let x = 0 && "hello";        // x = 0, because 0 is falsy
let y = true && "world";     // y = "world", first value is truthy
let z = "hello" && "world";  // z = "world", both are truthy

console.log(x);  // 0
console.log(y);  // world
console.log(z);  // world

Output:
0
world
world

Short-Circuiting with || Operator

Short-circuit evaluation with the || (OR) operator means if the first expression is true, the entire expression will be true and the rest will not be evaluated. 

let x = 0 || "hello";        // x = "hello", 0 is falsy
let y = true || "world";     // y = true, first value is truthy
let z = "hello" || "world";  // z = "hello", first value is truthy

console.log(x);  // hello
console.log(y);  // true
console.log(z);  // hello

Output:
hello
true
hello

Short-Circuiting in Assignments

Short-circuiting can also be used in assignments, making it easier to assign fallback values. 

let x = 0;
let y = 10;
let z = x || y;  // z = 10, because x is falsy

console.log(z);  // 10

Output:
10

Short-Circuiting in Function Calls

Short-circuiting is useful in function calls. For example, we can provide default values if an argument is falsy. 

function greet(name) {
   return name || "Guest";
}

let x = greet("John");  // "John" because name is truthy
let y = greet("");      // "Guest" because name is falsy

console.log(x);  // John
console.log(y);  // Guest

Output:
John
Guest

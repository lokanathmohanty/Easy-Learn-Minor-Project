R - Operators

Operators are symbols that instruct the compiler to perform specific mathematical or logical manipulations. R provides various built-in operators classified as Arithmetic, Relational, Logical, Assignment, and Miscellaneous operators.

Arithmetic Operators

Operator Description Example
+ Adds two vectors element-wise 
v <- c(2,5.5,6)
t <- c(8,3,4)
print(v + t)
Outputs: [1] 10.0 8.5 10.0
- Subtracts second vector from the first 
print(v - t)
Outputs: [1] -6.0 2.5 2.0
* Multiplies both vectors element-wise 
print(v * t)
Outputs: [1] 16.0 16.5 24.0
/ Divides the first vector by the second element-wise 
print(v / t)
Outputs: [1] 0.25 1.83 1.5
%% Remainder of division of first vector by second 
print(v %% t)
Outputs: [1] 2.0 2.5 2.0
%/% Integer division quotient 
print(v %/% t)
Outputs: [1] 0 1 1
^ First vector raised to the power of second vector element-wise 
print(v ^ t)
Outputs: [1] 256.000 166.375 1296.000

Relational Operators

These operators compare elements of two vectors and return Boolean values element-wise.

Operator Description Example
>Greater than
print(v > t)
[1] FALSE TRUE FALSE FALSE
<Less than
print(v < t)
[1] TRUE FALSE TRUE FALSE
==Equal to
print(v == t)
[1] FALSE FALSE FALSE TRUE
<=Less than or equal to
print(v <= t)
[1] TRUE FALSE TRUE TRUE
>=Greater than or equal to
print(v >= t)
[1] FALSE TRUE FALSE TRUE
!=Not equal to
print(v != t)
[1] TRUE TRUE TRUE FALSE

Logical Operators

Logical operators work element-wise on logical, numeric, or complex vectors, treating numbers > 1 as TRUE.

Operator Description Example
& Element-wise AND 
print(v & t)
[1] TRUE TRUE FALSE TRUE
| Element-wise OR 
print(v | t)
[1] TRUE FALSE TRUE TRUE
! Logical NOT 
print(!v)
[1] FALSE TRUE FALSE FALSE
&& Logical AND (First element only) 
print(v && t)
[1] TRUE
|| Logical OR (First element only) 
print(v || t)
[1] FALSE

Assignment Operators

Operator Description Example
<- , = , <<- Left assignment 
v1 <- c(3,1,TRUE,2+3i)
v2 <<- c(3,1,TRUE,2+3i)
v3 = c(3,1,TRUE,2+3i)
print(v1); print(v2); print(v3)
Output: 
[1] 3+0i 1+0i 1+0i 2+3i
-> , ->> Right assignment 
c(3,1,TRUE,2+3i) -> v1
c(3,1,TRUE,2+3i) ->> v2
print(v1); print(v2)
Output: 
[1] 3+0i 1+0i 1+0i 2+3i

Miscellaneous Operators

Operator Description Example
: Creates a sequence of numbers 
v <- 2:8
print(v)
Output: [1] 2 3 4 5 6 7 8
%in% Checks membership of an element in a vector 
v1 <- 8
v2 <- 12
t <- 1:10
print(v1 %in% t)
print(v2 %in% t)
Output: [1] TRUE [1] FALSE
%*% Matrix multiplication (e.g., a matrix with its transpose) 
M = matrix(c(2,6,5,1,10,4), nrow = 2, ncol = 3, byrow = TRUE)
t = M %*% t(M)
print(t)
Output: 
     [,1] [,2]
[1,]   65   82
[2,]   82  117

Java - Multithreading

Java is a multi-threaded programming language, enabling the development of multi-threaded programs. A multi-threaded program contains two or more parts that can run concurrently, with each part handling a different task simultaneously, making optimal use of available resources, especially when the computer has multiple CPUs.

By definition, multitasking involves multiple processes sharing common processing resources such as a CPU. Multi-threading extends this concept within applications, allowing specific operations within a single application to be subdivided into individual threads. Each thread can run in parallel, with the operating system dividing processing time not only among different applications but also among each thread within an application.

Java Multithreading

Multi-threading enables writing programs where multiple activities can proceed concurrently within the same application. To achieve multithreading, the java.lang.Thread class is utilized.

Life Cycle of a Thread in Java Multithreading

A thread undergoes various stages in its life cycle, including being born, started, running, and eventually dying. The following diagram illustrates the complete life cycle of a thread.

Java Thread Life Cycle

The stages of the thread life cycle are as follows:

  • New – A new thread begins its life cycle in the new state. It remains in this state until the program starts the thread. It is also referred to as a born thread.
  • Runnable – After a newly born thread is started, it becomes runnable. In this state, a thread is considered to be executing its task.
  • Waiting – A thread transitions to the waiting state while it waits for another thread to perform a task. It returns to the runnable state when another thread signals it to continue executing.
  • Timed Waiting – A runnable thread can enter the timed waiting state for a specified interval. It transitions back to the runnable state when the time interval expires or when the event it is waiting for occurs.
  • Terminated (Dead) – A runnable thread enters the terminated state when it completes its task or otherwise terminates.

Thread Priorities

Every Java thread has a priority that helps the operating system determine the order in which threads are scheduled. Java thread priorities range from MIN_PRIORITY (1) to MAX_PRIORITY (10). By default, every thread is given NORM_PRIORITY (5). Threads with higher priority are more important to a program and should be allocated processor time before lower-priority threads. However, thread priorities cannot guarantee the order in which threads execute and are platform-dependent.

Creating a Thread by Implementing a Runnable Interface

To create a thread, you can implement the Runnable interface. The process involves the following steps:

  1. Implement the run() Method – Implement the run() method provided by the Runnable interface. This method serves as the entry point for the thread, where you place your business logic.
  2. Instantiate a Thread Object – Create a Thread object using the constructor Thread(Runnable threadObj, String threadName), where threadObj is an instance of a class that implements the Runnable interface and threadName is the name assigned to the new thread.
  3. Start the Thread – Start the thread by calling the start() method, which invokes the run() method.

Example: Create Thread by Implementing Runnable Interface

class RunnableDemo implements Runnable {
  private Thread t;
  private String threadName;

  RunnableDemo(String name) {
    threadName = name;
    System.out.println("Creating " + threadName);
  }

  public void run() {
    System.out.println("Running " + threadName);
    try {
      for (int i = 4; i > 0; i--) {
        System.out.println("Thread: " + threadName + ", " + i);
        Thread.sleep(50);
      }
    } catch (InterruptedException e) {
      System.out.println("Thread " + threadName + " interrupted.");
    }
    System.out.println("Thread " + threadName + " exiting.");
  }

  public void start() {
    System.out.println("Starting " + threadName);
    if (t == null) {
      t = new Thread(this, threadName);
      t.start();
    }
  }
}

public class TestThread {
  public static void main(String args[]) {
    RunnableDemo R1 = new RunnableDemo("Thread-1");
    R1.start();

    RunnableDemo R2 = new RunnableDemo("Thread-2");
    R2.start();
  }
}

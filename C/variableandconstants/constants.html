Constants in C

A constant in C is a named storage location whose value cannot be modified after initialization, unlike a variable which can change during program execution.

Constants are useful to represent fixed values that are used repeatedly and should not change, such as mathematical constants like PI.

Ways to Define Constants

You can define constants in C by:

  • Using the const keyword
  • Using the #define preprocessor directive

Using the const Keyword

To declare a constant variable, prefix the declaration with const. The variable is initialized at declaration and any modification afterward is prohibited.

<code>
const float PI = 3.14159265;

int main() {
    float radius = 5;
    float area = PI * radius * radius;
    printf("Area: %f\n", area);
    // PI = 3.14; // Error: cannot modify const variable
    return 0;
}
</code>

Using the #define Directive

The #define directive creates symbolic constants handled by the preprocessor at compile time, without requiring a specific data type.

<code>
#define LENGTH 10
#define WIDTH 5
#define NEWLINE '\n'

int main() {
    int area = LENGTH * WIDTH;
    printf("Length: %d Width: %d%cArea: %d\n", LENGTH, WIDTH, NEWLINE, area);
    return 0;
}
</code>

Notes and Considerations

  • Constants declared with const are type-safe and checked by the compiler, whereas #define constants are simple text replacements.
  • Attempting to modify a const variable results in a compile-time error.
  • Constants are usually named in uppercase by convention for clarity, though this is not mandatory.
  • Using pointers, it is possible (though unsafe and not recommended) to modify const variables, but not those defined by #define.

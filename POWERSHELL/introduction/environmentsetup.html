PowerShell - Environment Setup

You can find the PowerShell icon on the taskbar or in the Start menu. Simply click the icon to launch PowerShell.

PowerShell Ready

After launching, a console window opens indicating PowerShell is ready to use. You can now begin executing commands.

Checking PowerShell Version

The latest PowerShell version is 5.0. To check your current installed version, use the following command:

Example: Check PowerShell Version

$PSVersionTable

If the result shows PSVersion 4.0 or lower, you can upgrade by downloading Windows Management Framework 5.0 from the following link:

  • Download Windows Management Framework 5.0

PowerShell ISE

PowerShell ISE (Integrated Scripting Environment) is a GUI-based host for PowerShell that allows users to write, test, and debug scripts more effectively.

ISE supports features like multiline editing, tab completion, syntax highlighting, selective execution, context-sensitive help, and more.

Launching PowerShell ISE

  • Go to Start.
  • Search for PowerShell.
  • Select Windows PowerShell ISE from the list.

You can also find it by clicking the downward arrow to show all apps, then selecting PowerShell ISE.

PowerShell ISE Interface

The ISE interface is divided into three main sections:

  • 1. Console Pane – where commands are executed
  • 2. Script Pane – where scripts are written and saved
  • 3. Command Pane – where available modules and commands are listed

Creating and Running a Script

To create a new script, type your PowerShell commands into the Script Pane. You can then run them directly to see the output in the Console Pane.

Example: Running a Script in ISE

Get-Process
Get-Service

Basic Commands

PowerShell contains numerous commands. One of the most useful to start with is Get-Help, which provides syntax and parameter info for any cmdlet.

Example: Get Help

Get-Help Get-Process

Working with Updates

You can use PowerShell to view and manage system updates.

Example: Get and Install Hotfix

Get-HotFix
Get-HotFix -id kb2741530

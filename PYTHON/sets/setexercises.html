Python - Set Exercises

This section provides some practical exercises using Python sets to demonstrate their functionality in common programming tasks.

Exercise 1: Find Common Elements in Two Lists


l1 = [1, 2, 3, 4, 5]
l2 = [4, 5, 6, 7, 8]
s1 = set(l1)
s2 = set(l2)

commons = s1 & s2  # or s1.intersection(s2)
commonlist = list(commons)
print(commonlist)

Output:

[4, 5]

Exercise 2: Check if a Set is a Subset of Another


s1 = {1, 2, 3, 4, 5}
s2 = {4, 5}

if s2.issubset(s1):
   print("s2 is a subset of s1")
else:
   print("s2 is not a subset of s1")

Output:

s2 is a subset of s1

Exercise 3: Obtain a List of Unique Elements from a Tuple


T1 = (1, 9, 1, 6, 3, 4, 5, 1, 1, 2, 5, 6, 7, 8, 9, 2)
s1 = set(T1)
print(s1)

Output:

{1, 2, 3, 4, 5, 6, 7, 8, 9}

Assertions in Python

Assertions in Python are statements that assert or assume a condition to be true. If the condition turns out to be false, Python raises an AssertionError exception. They are used to detect programming errors that should never occur if the code is correct.

An assertion can be thought of as a raise-if-not statement: an expression is tested, and if the result is false, an exception is raised.

The assert statement was introduced in Python 1.5. Programmers often place assertions at the start of a function to check input validity, and after calls to check outputs.

The assert Statement Syntax

assert condition, message

Where:

  • condition − a boolean expression expected to be true.
  • message (optional) − a string message to display if the assertion fails.

Using Assertions

Assertions are mainly used during development and testing phases to check conditions that are expected to always hold true.

Example

print('Enter marks out of 100:')
num = 75
assert num >= 0 and num <= 100
print('Marks obtained:', num)

num = 125
assert num >= 0 and num <= 100
print('Marks obtained:', num)  # This line won't be reached if assertion fails

Output:

Enter marks out of 100:
Marks obtained: 75
Traceback (most recent call last):
  File "main.py", line 7, in 
    assert num >= 0 and num <= 100
AssertionError

Custom Error Messages

To show a custom message on assertion failure, include a string after the expression in the assert statement: 

assert num >= 0 and num <= 100, "Only numbers in the range 0-100 are accepted"

Handling AssertionError

Assertions can be caught with try-except just like other exceptions. If not caught, they terminate the program and show a traceback.

try:
   num = int(input('Enter a number: '))
   assert num >= 0, "Only non-negative numbers are accepted"
   print(num)
except AssertionError as msg:
   print(msg)

Example output:

Enter a number: -87
Only non-negative numbers are accepted

Assertions vs Exceptions

Assertions check internal states and invariants expected to be true, primarily for debugging. Exceptions handle runtime errors and unusual conditions during normal execution.

Assertions are disabled by default in Python's optimized mode (e.g. using -O). Therefore, they shouldn't enforce constraints necessary for correct production operation.

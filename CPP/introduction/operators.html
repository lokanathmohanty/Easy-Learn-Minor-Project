Operators in C++

An **operator** is a symbol that instructs the compiler to perform a specific mathematical, logical, or other manipulation on data. C++ is rich in built-in operators, which can be categorized into several types.

1. Arithmetic Operators 🧮

These are used for basic mathematical operations.

OperatorDescriptionExample (A=10, B=20)
+AdditionA + B = 30
-SubtractionA - B = -10
*MultiplicationA * B = 200
/DivisionB / A = 2
%Modulus (Remainder of integer division)B % A = 0
++Increment (increases value by one)A++ (A becomes 11)
--Decrement (decreases value by one)A-- (A becomes 9)

2. Relational Operators ⚖️

These compare two operands and return a **Boolean** value (true or false).

OperatorDescriptionExample (A=10, B=20)
==Checks if operands are equal(A == B) is false
!=Checks if operands are not equal(A != B) is true
>Checks if the left operand is greater(A > B) is false
<Checks if the left operand is less(A < B) is true
>=Checks if the left is greater than or equal to(A >= B) is false
<=Checks if the left is less than or equal to(A <= B) is true

3. Logical Operators 🧠

These perform logical operations on Boolean expressions (or non-zero values treated as true).

OperatorDescriptionExample (A=1, B=0)
&&Logical AND: True if both operands are true (non-zero)(A && B) is false
||Logical OR: True if at least one operand is true (non-zero)(A || B) is true
!Logical NOT: Reverses the logical state (True becomes False)!(A && B) is true

4. Bitwise Operators ⚙️

These perform operations directly on the individual bits of integer data types.

OperatorDescriptionExample (A=60, B=13)
&Binary AND: Bit is 1 if it is 1 in both operands.A & B = 12 (0000 1100)
|Binary OR: Bit is 1 if it is 1 in either operand.A | B = 61 (0011 1101)
^Binary XOR (Exclusive OR): Bit is 1 if it is 1 in exactly one operand.A ^ B = 49 (0011 0001)
~Binary NOT (One's Complement): Flips all bits.~A = -61
<<Binary Left Shift: Shifts bits left, filling with zeros on the right.A << 2 = 240
>>Binary Right Shift: Shifts bits right.A >> 2 = 15

5. Assignment Operators ➡️

These are used to assign values to variables, often combining an arithmetic or bitwise operation with assignment.

OperatorDescriptionExample
=Simple AssignmentC = A
+=Add and AssignC += A is same as C = C + A
-=Subtract and AssignC -= A is same as C = C - A
*=Multiply and AssignC *= A is same as C = C * A
/=Divide and AssignC /= A is same as C = C / A
%=Modulus and AssignC %= A is same as C = C % A

6. Miscellaneous Operators

These operators handle various other tasks:

  • **Conditional (Ternary) Operator (? :):** A shorthand for an if-else statement.

    result = (a > b) ? a : b; (If condition is true, returns a, otherwise returns b).

  • **sizeof:** Returns the size of a variable or data type in bytes.

    sizeof(int) or sizeof(variable)

  • **Scope Resolution Operator (::):** Used to define or access members of a namespace or class (e.g., std::cout, MyClass::value).
  • **Address of (&):** Returns the memory address of a variable (used for pointers and references).
  • **Dereference (*):** Used to access the value at the address held by a pointer.

Operators Precedence and Associativity

**Precedence** defines the order in which operators are evaluated (e.g., multiplication * is done before addition +). **Associativity** defines the order of evaluation when operators have the same precedence (e.g., most binary operators group left-to-right).

To explicitly control the order of evaluation, use **parentheses ()**.

Example: In x = 7 + 3 * 2, the multiplication (*) has higher precedence, so $x = 7 + (3 * 2) = 13$.

ReactJS - Building & Deployment

Once the development of a React application is complete, the next step is to create a production build and deploy it to a server. This chapter explains the build process and deployment methods.

Building

React provides a single command to create an optimized production build:

npm run build

Example output:

> expense-manager@0.1.0 build path\to\expense-manager
> react-scripts build

Creating an optimized production build...
Compiled with warnings.

File sizes after gzip:
   41.69 KB   build\static\js\2.a164da11.chunk.js
    2.24 KB   build\static\js\main.de70a883.chunk.js
    1.40 KB   build\static\js\3.d8a9fc85.chunk.js
    1.17 KB   build\static\js\runtime-main.560bee6e.js
   493 B      build\static\css\main.e75e7bbe.chunk.css

The build folder is ready to be deployed. You can preview it locally using serve:

npm install -g serve
serve -s build

You can enable profiling by adding the --profile flag:

npm run build -- --profile

Deployment

Once built, the application can be deployed locally or to any production server.

Local Deployment

Install serve globally:

npm install -g serve

Run the app from the root folder:

cd /go/to/app/root/folder
serve -s build

By default, the app runs on port 5000 and can be accessed at http://localhost:5000.

Production Deployment

For production, copy the contents of the build folder to your web server's root directory. This works with Apache, Nginx, IIS, and others.

Relative Path

If hosting the application in a subfolder, update the homepage field in package.json before building:

{
  ...
  "homepage": "http://domainname.com/path/to/subfolder",
  ...
}

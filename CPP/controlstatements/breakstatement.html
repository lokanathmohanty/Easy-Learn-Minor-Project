C++ break Statement (Loop Termination) 🛑

The **break statement** is a loop control statement used to immediately and unconditionally **terminate** the execution of the innermost enclosing loop (`for`, `while`, or `do...while`) or `switch` statement.

Once break is encountered, program control instantly resumes at the next statement following the terminated loop or switch block.

Usage in Loops and Nesting

  • **Loops:** When used inside any loop, `break` provides an **early exit** from the loop, even if the primary loop condition might still be true.
  • **Switch Statement:** `break` is essential in `switch` statements to prevent **fall-through**—ensuring that only the code block for the matched `case` is executed.
  • **Nested Loops:** If a `break` is used inside an inner loop, it only terminates that **innermost loop**. The outer loop continues its execution from its next iteration.

Example Analysis: Early Termination

In the provided example, the `do...while` loop is set to run until `a` is 20, but the `if` condition forces an early exit.

int a = 10;
do {
    cout << "value of a: " << a << endl; // Line executes
    a = a + 1;
    if( a > 15) { // Check if a > 15
        break; // Loop terminates when a becomes 16
    }
} while( a < 20 );

The loop stops as soon as `a` is incremented to 16. The final output confirms that the last value printed was 15, and the loop terminated before reaching the overall condition limit of 20:

value of a: 10 (a becomes 11)
value of a: 11 (a becomes 12)
value of a: 12 (a becomes 13)
value of a: 13 (a becomes 14)
value of a: 14 (a becomes 15)
value of a: 15 (a becomes 16) -> 16 > 15 is TRUE, BREAK!

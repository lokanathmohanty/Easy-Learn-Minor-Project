CSS - place-content Property

The place-content property in CSS is a shorthand for aligning content in both the block (column) and inline (row) axes simultaneously. It combines the functionality of align-content and justify-content in a single declaration.

Shorthand For

  • align-content
  • justify-content

Possible Values

  • start: Aligns items at the start edge of the container.
  • end: Aligns items at the end edge of the container.
  • flex-start: Aligns items at the start of the flex container.
  • flex-end: Aligns items at the end of the flex container.
  • center: Aligns items in the center.
  • left: Aligns items to the left (acts like start if axis differs).
  • right: Aligns items to the right (acts like start if axis differs).
  • space-between: Even spacing between items; edges aligned.
  • baseline / first baseline / last baseline: Aligns items by baseline rules.
  • space-around: Equal spacing around items.
  • space-evenly: Equal spacing between and around items.
  • stretch: Expands items to fill container if space remains.
  • safe: Prevents data loss by aligning safely within the container.
  • unsafe: Honors alignment even if content overflows.

Applies To

Multi-line flex containers.

Syntax

place-content: align-content justify-content;

/* Examples */
place-content: center start;
place-content: start center;
place-content: end right;
place-content: flex-start center;
place-content: flex-end center;
place-content: baseline center;
place-content: space-between space-evenly;
place-content: space-evenly stretch;

If only one value is provided, it applies to both align-content and justify-content. If the value is invalid for one of them, the entire property is invalid.

Examples

1. place-content: center start

.flex-container {
   display: flex;
   flex-wrap: wrap;
   height: 300px;
   place-content: center start;
}

Aligns items horizontally to the center and vertically to the top.

2. place-content: start center

.flex-container {
   display: flex;
   flex-wrap: wrap;
   height: 300px;
   place-content: start center;
}

Aligns items horizontally to the left edge and vertically in the center.

3. place-content: end right

.flex-container {
   display: flex;
   flex-wrap: wrap;
   height: 300px;
   place-content: end right;
}

Aligns items to the bottom-right of the container.

4. place-content: flex-start center

.flex-container {
   display: flex;
   flex-wrap: wrap;
   height: 300px;
   place-content: flex-start center;
}

Aligns items to the left (start) horizontally and centered vertically.

5. place-content: flex-end center

.flex-container {
   display: flex;
   flex-wrap: wrap;
   height: 300px;
   place-content: flex-end center;
}

Aligns items to the right horizontally and centered vertically.

6. place-content: last baseline

.flex-container {
   display: flex;
   flex-wrap: wrap;
   height: 300px;
   place-content: last baseline;
}

The last line of items aligns to the baseline of the tallest item on that line.

7. place-content: space-between

.flex-container {
   display: flex;
   flex-wrap: wrap;
   height: 300px;
   place-content: space-between;
}

Distributes items evenly with equal gaps between them, edges aligned.

8. place-content: space-around

.flex-container {
   display: flex;
   flex-wrap: wrap;
   height: 300px;
   place-content: space-around;
}

Distributes items with equal space around each item.

9. place-content: space-evenly

.flex-container {
   display: flex;
   flex-wrap: wrap;
   height: 300px;
   place-content: space-evenly;
}

Distributes items with equal space between and around items.

Content Summary

The place-content property simplifies alignment by combining align-content and justify-content. It provides powerful options to control spacing, alignment, and distribution of items within multi-line flex containers.

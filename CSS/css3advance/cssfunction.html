CSS - Value Functions

CSS value functions allow you to generate values for CSS properties dynamically. These functions take parameters and return a value that can be used in place of a static value. They make styling more powerful, flexible, and adaptive.

Syntax

selector {
   property: function([argument]? [, argument]!);
}

The function name appears first in the value syntax, followed by parentheses. Inside the parentheses, arguments are placed, separated either by spaces or commas depending on the function.

Transform Functions

The <transform-function> type represents visual transformations and is used inside the transform property.

  • translateX() - moves an element horizontally
  • translateY() - moves an element vertically
  • translateZ() - moves an element along the z-axis
  • translate() - moves an element in 2D
  • translate3d() - moves an element in 3D
  • rotateX() - rotates around x-axis
  • rotateY() - rotates around y-axis
  • rotateZ() - rotates around z-axis
  • rotate() - rotates in 2D
  • rotate3d() - rotates in 3D
  • scaleX(), scaleY(), scaleZ() - scales in respective directions
  • scale() - scales in 2D
  • scale3d() - scales in 3D
  • skewX(), skewY(), skew() - skews elements
  • matrix() - applies 2D matrix transform
  • matrix3d() - applies 3D matrix transform
  • perspective() - sets perspective for 3D transforms
.box {
  transform: translateX(100px) rotate(45deg) scale(1.5);
}

Math Functions

  • calc() - performs arithmetic calculations
  • min() - picks the smallest value
  • max() - picks the largest value
  • clamp() - constrains value between min and max
  • round() - rounds numbers
  • sin(), cos(), tan(), asin(), acos(), atan(), atan2() - trigonometric functions
div {
  width: calc(100% - 50px);
  font-size: clamp(14px, 2vw, 20px);
}

Filter Functions

<filter-function> applies graphical effects with filter or backdrop-filter.

  • blur() - blurs image
  • brightness() - adjusts brightness
  • contrast() - adjusts contrast
  • drop-shadow() - applies shadow
  • grayscale(), hue-rotate(), invert(), opacity(), saturate(), sepia()
img {
  filter: grayscale(100%) brightness(1.2);
}

Color Functions

  • rgb(), hsl(), hwb()
  • lch(), oklch(), lab(), oklab()
  • color(), color-mix()
div {
  background: color-mix(in srgb, red 40%, blue);
}

Image Functions

  • linear-gradient(), radial-gradient(), conic-gradient()
  • repeating-linear-gradient(), repeating-radial-gradient(), repeating-conic-gradient()
  • image-set(), cross-fade(), paint()
div {
  background: linear-gradient(to right, red, yellow);
}

Counter Functions

  • counter() - returns current counter
  • counters() - returns nested counters
ol {
  counter-reset: item;
}
li::before {
  counter-increment: item;
  content: counter(item) ". ";
}

Shape Functions

  • circle(), ellipse(), inset(), polygon(), path()
div {
  clip-path: circle(50% at center);
}

Reference Functions

  • attr() - pulls attribute value
  • env() - environment variable
  • url() - loads resource
  • var() - uses CSS custom property
a::after {
  content: " (" attr(href) ")";
}

Grid Functions

  • fit-content()
  • minmax()
  • repeat()
.container {
  display: grid;
  grid-template-columns: repeat(3, minmax(100px, 1fr));
}

Font Functions

  • stylistic(), styleset(), character-variant(), swash(), ornaments(), annotation()

Easing Functions

  • linear() - linear animation
  • cubic-bezier() - custom curve
  • steps() - stepped transition
div {
  transition: all 2s cubic-bezier(0.25, 1, 0.5, 1);
}

Practice Exercises

  • Use calc() to create a layout that adapts to available space.
  • Apply rotate() and scale() transforms on hover.
  • Create a linear-gradient() background with three colors.
  • Experiment with color-mix() to blend two colors.
  • Build a responsive grid using repeat() and minmax().
  • Add blur() and contrast() effects to an image.

JavaScript - Inheritance

Inheritance in JavaScript allows the child class to inherit the properties and methods of the parent class. It is a fundamental concept of object-oriented programming along with encapsulation and polymorphism.

For example, you may create a general class for bikes with shared properties and methods. Then you can create a class for "Honda" bikes that inherits from the general bike class.

Before ECMAScript 6 (ES6), inheritance was achieved using prototypes. In ES6, the extends keyword was introduced.

Terminologies

  • Parent class – The class whose properties are inherited by other classes.
  • Child class – The class that inherits the properties of another class.

Single Class Inheritance

A single class can inherit another class using the extends keyword. 

class ChildClass extends ParentClass {
  // Child class body
}

Example

// Parent class
class Bike {
  constructor() {
    this.gear = 5;
  }
  getGears() {
    return this.gear;
  }
}

// Child class
class Suzuki extends Bike {
  constructor() {
    super();
    this.brand = "Yamaha";
  }
  getBrand() {
    return this.brand;
  }
}

const suzukiBike = new Suzuki();
console.log(suzukiBike.getBrand()); // Yamaha
console.log(suzukiBike.getGears()); // 5

Using super() Keyword

The super() keyword invokes the constructor of the parent class and allows passing parameters to it.

Example

// Parent class
class Bike {
  constructor(gears) {
    this.gears = gears;
  }
}

// Child class
class Suzuki extends Bike {
  constructor(brand, gears) {
    super(gears);
    this.brand = brand;
  }
}

const suzukiBike = new Suzuki("Suzuki", 4);
console.log(suzukiBike.brand); // Suzuki
console.log(suzukiBike.gears); // 4

Multilevel Inheritance

class A {}
class B extends A {}
class C extends B {}

Example

class Bike {
  constructor(gears) {
    this.gears = gears;
  }
}

class Honda extends Bike {
  constructor(brand, gears) {
    super(gears);
    this.brand = brand;
  }
}

class Shine extends Honda {
  constructor(model, brand, gears) {
    super(brand, gears);
    this.model = model;
  }
}

const newBike = new Shine("Shine", "Honda", 5);
console.log(`The ${newBike.model} model of ${newBike.brand} has ${newBike.gears} gears.`);

Hierarchical Inheritance

class A {}
class B extends A {}
class C extends A {}

Example

class Bike {
  constructor(gears) {
    this.gears = gears;
  }
}

class Honda extends Bike {
  constructor(model, gears) {
    super(gears);
    this.model = model;
  }
}

class Suzuki extends Bike {
  constructor(model, color, gears) {
    super(gears);
    this.model = model;
    this.color = color;
  }
}

const hondaBike = new Honda("Shine", 5);
const suzukiBike = new Suzuki("Zx6", "Blue", 6);

console.log(hondaBike);
console.log(suzukiBike);

Inheriting Static Members

class Bike {
  static getDefaultBrand() {
    return "Yamaha";
  }
}

class Honda extends Bike {
  static BikeName() {
    return super.getDefaultBrand() + ", X6";
  }
}

console.log(Honda.BikeName()); // Yamaha, X6

Prototype-Based Inheritance

Child.prototype = new Parent();

Example

function Bike(brand) {
  this.brand = brand;
}
Bike.prototype.getBrand = function() {
  return this.brand;
};

function Vehicle(price) {
  this.price = price;
}

const newBike = new Bike("Yamaha");
Vehicle.prototype = newBike; // inheritance

const vehicle = new Vehicle(100000);
console.log(vehicle.getBrand()); // Yamaha
console.log(vehicle.price);     // 100000

Benefits of Inheritance

  • Code reusability – Child classes reuse parent code.
  • Functionality extension – Add new features to child classes.
  • Code maintenance – Easier to organize and maintain.
  • Multilevel and hierarchical inheritance allows structured data management.

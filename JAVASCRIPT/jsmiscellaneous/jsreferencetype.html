JavaScript - Reference Type

In JavaScript, data types are divided into two categories: primitive and reference types.

Primitive Data Types

Primitive data types are immutable and include:

  • Number
  • String
  • Boolean
  • Undefined
  • Null
  • Symbol

Reference Data Types

Reference types are mutable. Common examples are:

  • Object
  • Array
  • Function

When assigning a primitive, a copy of the value is stored. When assigning a reference type, a reference to the object in memory is stored. Thus, modifying one reference affects all references pointing to the same object.

Examples

Primitive Example

let x = 10;
let y = 10;

x = 20;
console.log(x); // 20
console.log(y); // 10

Reference Example

const x = [1, 2, 3];
const y = x;

x[0] = 4;
console.log(x); // [4, 2, 3]
console.log(y); // [4, 2, 3]

Objects

const person = {
  firstName: "John",
  lastName: "Doe",
  age: 30
};

Functions

function greet(name) {
  alert("Hello, " + name + "!");
}

Examples in Practice

Example 1: Object Mutability

<script>
const person = { name: "John", age: 25 };
let anotherPerson = person;
anotherPerson.age = 30;
console.log(person); // { name: "John", age: 30 }
</script>

Example 2: Array Modification

<script>
const colors = ["red", "green", "blue"];
let moreColors = colors;
moreColors.push("yellow");
console.log(colors); // ["red", "green", "blue", "yellow"]
</script>

Example 3: Function Reference

<script>
function greet(name) {
  return "Hello, " + name + "!";
}
let greetingFunction = greet;
console.log(greetingFunction("John")); // Hello, John!
greetingFunction = function(name) {
  return "Hola, " + name + "!";
};
console.log(greetingFunction("Maria")); // Hola, Maria!
</script>

Example 4: Custom Class

<script>
class Book {
  constructor(title, author, genre) {
    this.title = title;
    this.author = author;
    this.genre = genre;
  }
  getDetails() {
    return `Title: ${this.title}, Author: ${this.author}, Genre: ${this.genre}`;
  }
}
const book1 = new Book("1984", "George Orwell", "Dystopian");
console.log(book1.getDetails());
</script>

Example 5: Immutable Objects

<script>
'use strict';
const person = Object.freeze({ name: "Alice", age: 30 });
try {
  person.age = 35; // Error in strict mode
} catch (err) {
  console.log(err);
}
console.log(person.age); // 30
</script>

Conclusion

Understanding the difference between primitive and reference types is crucial for writing efficient and predictable JavaScript programs. Reference types allow shared access to objects, but immutability techniques such as Object.freeze() help preserve data integrity when needed.

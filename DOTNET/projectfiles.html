.NET Core - Project Files and Automatic Inclusion

This session explains a key difference between **.NET Core** and the traditional .NET Framework regarding how source files are included in a project. .NET Core simplifies the process through its project file structure (originally project.json) by **automatically including** files dropped into the project's root directory.

Example: Implementing and Adding Source Files

Consider the following two class files that define data models:

Student.cs Implementation

using System;
using System.Collections.Generic;
using System.Linq;
using System.Threading.Tasks; 
  
namespace FirstApp { 
   public class Student { 
      public int ID { get; set; } 
      public string LastName { get; set; } 
      public string FirstMidName { get; set; } 
      public DateTime EnrollmentDate { get; set; } 
   } 
}

Course.cs Implementation

using System;
using System.Collections.Generic;
using System.Linq;
using System.Threading.Tasks; 
  
namespace FirstApp { 
   public class Course { 
      public int CourseID { get; set; } 
      public string Title { get; set; } 
      public int Credits { get; set; } 
   } 
}

Process for Including Files in .NET Core

In the traditional **.NET Framework**, files needed to be manually referenced in the Visual Studio Solution Explorer (often by dragging and dropping to create a reference in the .csproj file).

The **.NET Core** approach (using project.json or the modern .csproj format that adopted this style) simplifies this significantly:

  1. **Save Files**: Save the new files (e.g., Student.cs and Course.cs) into the **root source folder** of your project (e.g., the FirstApp directory).
  2. **Visual Studio Prompt**: Visual Studio will detect the external changes and prompt you to reload the project.
  3. **Reload**: Click **Yes to All** to reload the project.

Once reloaded, the files will be **automatically included** in your project and visible in the Solution Explorer, without any manual referencing required. This automatic inclusion is a major benefit of the modern .NET Core project system.

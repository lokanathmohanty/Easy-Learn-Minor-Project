Flask request Object Attributes 🌐

In Flask, data sent from a client's web page (like form submissions or URL parameters) is made available to the server as the **global request object**. To use this object in your view functions, you must explicitly import it from the Flask module:

from flask import request

The request object is crucial for handling incoming client data, providing access to various components of the HTTP request:

Key Attributes of the request Object

  • **request.form:**

    A dictionary-like object containing key-value pairs of data submitted via a **form** using the **POST** HTTP method. This is typically used for standard form fields.

  • **request.args:**

    A dictionary-like object that holds the parsed contents of the **query string**, which is the part of the URL that follows the question mark (?). This is commonly used for data sent via the **GET** method.

  • **request.cookies:**

    A dictionary-like object containing the names and values of all **cookies** sent by the client with the request.

  • **request.files:**

    Contains data related to any **file uploads** included in the request (e.g., from an HTML <input type="file">). This requires a POST request with enctype="multipart/form-data".

  • **request.method:**

    A string representing the **current HTTP method** used for the request (e.g., 'GET', 'POST', 'PUT', 'DELETE'). This is used for conditional handling in view functions.

Example: Using request.args and request.form

Retrieving data from a POST form:

username = request.form['username_field']

Retrieving data from a GET query string:

page_number = request.args.get('page')

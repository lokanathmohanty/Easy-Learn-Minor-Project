PHP File Appending

**Appending** data to a file means adding new content to the **end** of an existing file without overwriting the original content. This is essential for tasks like maintaining **log files**, collecting sequential **user submissions**, or incremental **data gathering**.

The Recommended Method: Append Mode (`'a'`) ⭐

The simplest and safest way to append data is by using the **append mode (`'a'`)** when opening the file with `fopen()`. This mode automatically sets the file pointer to the end of the file before any write operation.

  • If the file does not exist, `'a'` will create it.
  • If the file exists, all subsequent `fwrite()` calls will add data to the end.

// Open file in append mode.
$fp = fopen("log.txt", "**a**");

// Data is automatically added to the end.
fwrite($fp, "\nNew log entry recorded.");
fclose($fp);

Alternative: Manually Moving the File Pointer

If a file is opened in a read/write mode (like `'r+'` or `'w+'`), the file pointer initially sits at the beginning, meaning any immediate write will **overwrite** the file's start. To append, you must manually move the pointer to the end using the **`fseek()`** function.

Using `fseek()`

The `fseek()` function changes the file pointer's position. To move it to the end, you set the offset to `0` and the whence parameter to `SEEK_END`.

$fp = fopen("data.txt", "**r+**");

// Manually move pointer to the end of the file (0 bytes offset from the end)
**fseek**($fp, 0, **SEEK_END**);

// Now fwrite() will append the data.
fwrite($fp, "\nNew appended data.");
fclose($fp);

Mode Comparison Summary

Mode Initial Pointer File Exists? Write Location
**`w`** Start **Truncated** (content lost) Start (Overwrites)
**`r+`** Start Must exist Start (Overwrites)
**`a`** End Preserved **End (Appends)**

When you need both read and append operations, use the **`a+`** mode. While you can use `fseek()` to read from anywhere in the file, every write operation will still automatically append to the end.

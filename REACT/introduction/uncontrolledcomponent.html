ReactJS - Uncontrolled Component

As we learned earlier, uncontrolled component does not support React-based form programming. Getting a value of a React DOM element (form element) is not possible without using React API. One way to get the content of the component is using the ref feature.

React provides a ref attribute for all DOM elements and a corresponding API, React.createRef(), to create a new reference. The reference can be attached to the form element, and its value can be accessed using this.ref.current.value during validation and submission.

Form Programming in Uncontrolled Component

  • Create a reference: this.inputRef = React.createRef();
  • Create a form element: <input type="text" name="username" />
  • Attach the reference: <input type="text" ref={this.inputRef} />
  • Use defaultValue (not value) for setting default values: <input type="text" defaultValue="default value" />
  • Access the value in submit handler: alert(this.inputRef.current.value);

Creating a Simple Form

Steps to create an uncontrolled component form:

  • Create a new React app react-form-uncontrolled-app.
  • Create ExpenseForm.css for styling.
  • Create ExpenseForm.js component with refs for all inputs.
  • Attach refs to name, amount, date, and category inputs.
  • On submit, collect values from refs and display them using alert().

Example Component

The ExpenseForm component demonstrates uncontrolled components by using React.createRef() for each input. The form collects user data and displays it as JSON in an alert box on submission.

Running the Application

  • Create index.js and render ExpenseForm.
  • Create index.html with a <div id="root">.
  • Run app with npm start.
  • Open http://localhost:3000, enter details, and click submit. The submitted data will appear in a pop-up alert.

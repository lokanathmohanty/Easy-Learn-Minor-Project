Python - Daemon Threads

Daemon threads run in the background and are not essential to the program. When only daemon threads remain, the Python program exits immediately, and daemon threads are abruptly terminated.

Daemon threads are ideal for background tasks like logging, web scraping, or saving data automatically without blocking program termination.

Daemon vs Non-Daemon Threads

Daemon Non-Daemon
Program exits if only daemon threads remain.Program waits for non-daemon threads to complete.
Used for background, non-critical tasks.Used for critical tasks.
Can be terminated abruptly.Run to completion.

Creating a Daemon Thread

Set the daemon attribute to True either during thread creation or before starting the thread.

import threading
from time import sleep

def run():
    thread = threading.current_thread()
    print(f'Daemon thread: {thread.daemon}')

# Create thread with daemon=True
thread = threading.Thread(target=run, daemon=True)
thread.start()
print('Main thread daemon:', threading.current_thread().daemon)
sleep(0.5)

Output:

Daemon thread: True
Main thread daemon: False

Note: If you create a thread in the main thread without specifying daemon=True, it's non-daemon by default.

# Alternative: set daemon before start
thread = threading.Thread(target=run)
thread.daemon = True
thread.start()
print('Main thread daemon:', threading.current_thread().daemon)
sleep(0.5)

Setting Daemon After Thread Start Raises Error

Attempting to change the daemon status after a thread has started raises RuntimeError.

from threading import Thread, current_thread
from time import sleep

def run():
    thread = current_thread()
    print(f'Daemon thread: {thread.daemon}')
    thread.daemon = True  # Raises RuntimeError if thread started

thread = Thread(target=run)
thread.start()
sleep(0.5)

Output:

Daemon thread: False
Exception: RuntimeError: cannot set daemon status of active thread

Flask-SQLAlchemy: Object Relational Mapping (ORM) 🐘

Using raw SQL for **CRUD** (Create, Read, Update, Delete) operations can be error-prone and tedious. **SQLAlchemy** is a powerful Python toolkit and **Object Relational Mapper (ORM)** that provides an abstraction layer over the database. **Flask-SQLAlchemy** is the extension that integrates this ORM support into Flask applications.

What is ORM?

**Object Relational Mapping (ORM)** is a technique that maps the object parameters and classes in an object-oriented programming language (like Python) to the structure of tables and rows in a Relational Database Management System (RDBMS). An ORM allows developers to perform database operations using object methods and attributes (e.g., db.session.add(student)) instead of writing raw SQL statements.

Setup and Model Declaration

The core steps for integrating Flask-SQLAlchemy are:

  1. **Installation:** pip install flask-sqlalchemy
  2. **Configuration:** Set the database URI in the app config (e.g., app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///students.sqlite3').
  3. **Initialization:** Create the SQLAlchemy object: db = SQLAlchemy(app).
  4. **Model Definition:** Declare your database tables as Python classes that inherit from db.Model. Attributes are defined using **db.Column()** with specified data types and constraints (e.g., primary_key = True).
  5. **Table Creation:** Call **db.create_all()** (usually in the main block) to create the tables in the database based on the declared models.

The **students** model maps the Python class properties (e.g., name, city) to columns in the underlying database table.

CRUD Operations via Session and Query

The **Session object** (db.session) manages all persistence operations for the ORM objects. The query object handles retrieval.

1. Create (Add Record)

A new model object is instantiated, and then added to the session:

student = students(name, city, addr, pin)

db.session.add(student)

db.session.commit()

2. Read (Query Records)

Data retrieval is handled through the **.query** attribute of the model class:

  • **Retrieve All:** students.query.all()
  • **Retrieve Filtered:** Use the filter_by() attribute to apply conditions: students.query.filter_by(city = 'Hyderabad').all()

3. View Function Flow (Adding a Student)

The new() function handles the form submission (POST):

It checks for missing fields and uses **flash()** for error messages. If successful, it creates the student object, uses db.session.add() to stage the change, and **db.session.commit()** to persist the record to the database, followed by a redirect to the main listing page.

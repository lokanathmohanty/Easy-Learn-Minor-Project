C# `if` Statement

Introduction to the `if` Statement

The **`if` statement** is a fundamental **control flow statement** in C# that allows the program to make decisions based on a specified condition. It consists of a **Boolean expression** that determines whether a certain block of code should be executed.

  • If the boolean_expression evaluates to **true**, the code block inside the `if` statement is executed.
  • If the boolean_expression evaluates to **false**, the program skips the code block and continues execution immediately after the `if` statement's closing brace.

Syntax

if(boolean_expression) {
   /* statement(s) will execute if the boolean expression is true */
}
// Code continues here if the expression is false

The curly braces {} define the scope of the `if` block. If the `if` statement's body contains only a single line of code, the braces are technically optional, but using them is highly recommended for clarity and avoiding logical errors.

Example: Conditional Execution

This example demonstrates how the `if` statement controls output based on a numerical comparison:

using System;

class Program {
    static void Main(string[] args) {
        int a = 10;
        
        /* The condition (a < 20) is true */
        if (a < 20) {
            Console.WriteLine("a is less than 20");
        }
        
        // This statement executes regardless of the condition
        Console.WriteLine("Value of a is: {0}", a);
    }
}

Output:

a is less than 20
Value of a is: 10

Example: Filtering Data

The `if` statement is commonly used within loops to filter elements based on a property, such as length:

using System;

public class Example{
   public static void Main(string[] args)
   {
      string[] arr = new string[] { "aman", "tutorialspoint", "India" };
      
      foreach (var item in arr)
      {
         // Only print items where length is >= 5
         if (item.Length >= 5)
         {
            Console.WriteLine(item);
         }
      }
   }
}

Output:

tutorialspoint
India

Node.js - Modules

Overview

A module in Node.js is a collection of independent and reusable code grouped logically, allowing modular and structured application development. Modules help organize functions, classes, and methods in separate files for easier maintenance and troubleshooting.

Node.js runs on the V8 JavaScript engine, executing JavaScript on the server. Server-side processes are managed by importing required Node.js modules using the require() function. Each module encapsulates specific functionality.

Example: Importing a Module

const http = require('node:http');

const listener = function (request, response) {
  // handle request and response
};

const server = http.createServer(listener);
server.listen(3000);

Types of Node.js Modules

  • Third-party modules: Developed externally and available via NPM. Installed globally or locally. Example: Express module (npm install express).
  • Built-in modules: Core Node.js modules pre-installed for tasks like file I/O, networking, etc. Imported via require(). Examples: http, fs, console.
  • Local modules: User-created JavaScript files in the project. Export functions or objects via exports and import them using require().

Example: Exporting Functions in a Local Module (functions.js)

exports.power = function powerval(x, y) {
  return Math.pow(x, y);
};

exports.root = function rootval(x) {
  return Math.sqrt(x);
};

exports.log = function logval(x) {
  return Math.log10(x);
};

Example: Importing and Using Local Module (main.js)

const mymodule = require('./functions');

console.log("10 Raised to 3: " + mymodule.power(10, 3));
console.log("Square root of 10: " + mymodule.root(10));
console.log("Log of 1000: " + mymodule.log(1000));

Output

10 Raised to 3: 1000
Square root of 10: 3.1622776601683795
Log of 1000: 3

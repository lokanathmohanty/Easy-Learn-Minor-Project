PHP File Writing Functions

**File Writing** in PHP involves either creating a new file or updating the content of an existing one. This capability is fundamental for tasks such as **data storage**, **application logging**, and creating dynamic content on the server.

Prerequisite: Opening the File

Before writing, the file must be opened using `fopen()` in a **writable mode**.

  • **`w` (Write)**: Creates a new file or **overwrites** content if the file exists.
  • **`a` (Append)**: Creates a new file or adds content to the **end** of an existing file.
  • **`w+` or `a+`**: Allows both reading and writing.

Basic Write Functions

PHP provides two core functions for performing write operations to a file stream: `fwrite()` and `fputs()`. These two functions are nearly identical aliases of each other.

1. `fwrite()` (Binary-Safe Write) 💾

The `fwrite()` function performs a binary-safe write operation. It is the preferred function for writing data, especially when dealing with non-text (binary) files.

**Syntax:** fwrite(resource $stream, string $data, ?int $length)

**Example (Overwriting a file):**
$fp = fopen("hello.txt", "**w**");
$bytes = **fwrite**($fp, "Hello Tutorialspoint!!!!!");
echo "bytes written: $bytes"; // Output: 25
fclose($fp);

2. `fputs()` (Alias of `fwrite()`) 📝

The `fputs()` function is an alias for `fwrite()` and performs the exact same operation: writing a string to a file stream opened in a writable mode.

**Example (Appending to a file):**
$fp = fopen("hello.txt", "**a**");
$bytes = **fputs**($fp, "\nHello PHP");
fclose($fp);

*Both `fwrite()` and `fputs()` return the number of bytes successfully written to the file, or `FALSE` on failure.*

Advanced File Copy Example

File writing functions are often used in combination with reading functions (like `fread()`) to process or copy data, including binary data like images.

$source = fopen("image.png", "**rb**"); // Read Binary
$dest = fopen("new.png", "**wb**"); // Write Binary
$size = filesize("image.png");
$data = **fread**($source, $size); // Read all bytes
**fwrite**($dest, $data, $size); // Write all bytes
fclose($source);
fclose($dest);

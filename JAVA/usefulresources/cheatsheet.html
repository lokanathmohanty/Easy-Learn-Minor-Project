Java Cheatsheet: Fundamentals and Core Concepts 🚀

I. Program Structure & I/O

Basic Structure

// Package Declaration (Optional)
// import java.util.Scanner; // Import external classes

public class Class_name {
   public static void main(String[] args) {
      // Main execution point
   }
}

Output

  • System.out.println("Hello");: Prints text and adds a **new line**.
  • System.out.print("Hello");: Prints text **without** a new line.

User Input (Scanner)

import java.util.Scanner;

Scanner myObj = new Scanner(System.in);
System.out.println("Enter input:");
String input = myObj.nextLine(); // Reads entire line (String)
// int number = myObj.nextInt(); // Reads an integer
myObj.close(); // Close the resource

Comments

  • Single-line: // This is a comment
  • Multi-line: /* This is a multi-line comment */

III. Control Flow (Loops & Conditionals)

Conditionals

If-Else

if (condition) {
   // runs if true
} else if (anotherCondition) {
   // runs if first is false, and this one is true
} else {
   // runs if all conditions are false
}

Switch Statement

switch (expression) {
   case value1:
      // code block
      break; // Essential to exit case
   default:
      // code block
}

Loops

For Loop

for (initialization; termination_condition; increment) {
   // code block runs repeatedly
}
// Example: for (int i = 0; i < 10; i++)

While Loop

while (condition) {
   // code block runs as long as condition is true
}

Loop Control

  • break: Immediately exits the **entire loop**.
  • continue: Skips the rest of the **current loop iteration** and proceeds to the next one.

IV. Object-Oriented Programming (OOP)

OOP Pillars

  1. Encapsulation: Bundling data (fields) and methods that operate on the data into a single unit (class). Use **private** fields and **public** methods (getters/setters) to control access.
  2. Inheritance: A class (subclass/child) inherits properties and methods from another class (superclass/parent) using the **extends** keyword. 
    class Child extends Parent { ... }
  3. Polymorphism: Allowing methods to do different things based on the object it is acting upon. Achieved via **Method Overriding** (same method signature in subclass) and **Method Overloading** (same method name, different parameters in the same class).
  4. Abstraction: Hiding complex implementation details and showing only essential features. Achieved using **abstract** classes/methods or **Interfaces**.

Constructors

  • Code block used to **initialize** a new object. It must have the **same name as the class**.
  • Default Constructor: Has no parameters (automatically generated if none are declared).
  • Parameterized Constructor: Accepts parameters to set initial values for instance variables.

V. Arrays and Strings

Arrays

  • Single-Dimensional: Stores multiple values of the same type. 
    int[] arr = new int[5]; // Declaration and initialization
arr[0] = 10; // Accessing by index
  • Multi-Dimensional: Arrays of arrays (e.g., a matrix). 
    int[][] matrix = new int[3][3];

String Comparison

  • Content: Use str1.equals(str2) for reliable content comparison.
  • Reference: The == operator compares object references (memory addresses). Use only for comparing primitive types or checking if two references point to the exact same object.
  • Lexicographical: Use str1.compareTo(str2) to determine ordering (-ve, 0, or +ve).

VI. Exception Handling

Try-Catch-Finally

Used to handle runtime errors gracefully, maintaining the program's flow.

try {
   // Code that might throw an exception (e.g., 10 / 0)
} catch (ArithmeticException e) {
   // Code to handle a specific exception type
} catch (Exception e) {
   // Code to handle any other exception
} finally {
   // Code that ALWAYS executes (e.g., closing resources)
}

Throwing Exceptions

The **throw** keyword is used to explicitly throw an exception object.

// Syntax:
if (condition_is_bad) {
   throw new CustomException("Error message");
}

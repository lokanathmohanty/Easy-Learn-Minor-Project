C++ Loop Types and Control Statements 🔁

In C++, **loop statements** are control structures that allow a statement or block of statements to be executed repeatedly as long as a specified condition remains true. This replaces the sequential execution of code with iterative execution.

C++ Loop Types

C++ offers three primary types of loops, categorized by when the loop condition is tested:

1. while Loop (Entry-Controlled)

Repeats a block of code as long as a given condition is true. The condition is tested **before** executing the loop body. If the condition is false initially, the loop body never executes.

2. for Loop (Entry-Controlled)

A compact loop structure designed for repeating a sequence of statements a specific number of times. It abbreviates the code for initialization, condition testing, and iteration (increment/decrement) of the loop variable.

3. do...while Loop (Exit-Controlled)

Similar to the while loop, but the condition is tested at the **end** of the loop body. This guarantees that the loop body executes **at least once**, regardless of the initial condition.

4. Nested Loops

The practice of placing one loop (while, for, or do...while) entirely inside the body of another loop. This is commonly used for working with two-dimensional data structures like matrices or grids.

Loop Control Statements

These statements modify the normal sequence of loop execution:

  • **break:** Immediately **terminates** the innermost loop (or switch statement) and transfers control to the statement immediately following the loop.
  • **continue:** Causes the loop to **skip the rest of the current iteration** and immediately retest the loop's condition for the next iteration.
  • **goto:** Transfers control directly to a specified labeled statement in the program. Its use is generally **discouraged** in modern C++ programming as it can make code logic convoluted and hard to maintain.

The Infinite Loop

An **infinite loop** is a loop whose condition never becomes false, causing it to run forever (until the program is manually terminated, usually with $\text{Ctrl} + \text{C}$).

In a for loop, omitting the conditional expression causes the condition to be implicitly treated as **true**, creating an infinite loop:

for( ; ; ) {
   // This code will repeat indefinitely
}

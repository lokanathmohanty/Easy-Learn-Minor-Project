PHP - Social Media Login (Single Sign-On with Facebook)

Introduction to Social Media Login (SSO)

Social Media Login, often referred to as **Single Sign-On (SSO)**, allows users to log into a web application using their existing credentials from providers like **Google, Facebook, LinkedIn, or Apple**. This eliminates the need for users to create and remember a new, separate account for your application, thereby improving the user experience and increasing conversion rates.

This section explains the steps for integrating **Facebook Login** into a PHP application.

Step 1: Create a Facebook App

Before integrating, you must register your application with Facebook to obtain the necessary credentials:

  • Visit $\text{https://developers.facebook.com/apps/creation/}$ and create a new Facebook App.
  • Obtain the unique **Application ID** ($\text{YOUR\_APP\_ID}$) and **App Secret** ($\text{YOUR\_APP\_SECRET}$) from the App Settings.
  • Configure the app's platform as a **Website** and specify the required Redirect URLs (the callback page where Facebook sends the user back after login).

Step 2: Set Up PHP SDK and Credentials

The **Facebook Graph SDK for PHP** is required to communicate with Facebook's API. It is best installed via Composer:

composer require "facebook/graph-sdk-v5"

In your PHP code, include the autoloader and define your application secrets:

require_once __DIR__ . '/vendor/autoload.php';

$app_id = 'YOUR_APP_ID';
$app_secret = 'YOUR_APP_SECRET';

Step 3: Create Login Button and JavaScript SDK

The client-side setup includes an $\text{HTML}$ button and the necessary Facebook JavaScript SDK to handle the initial login window pop-up:

<button id="facebook-login-button">Login with Facebook</button>

<script src="https://connect.facebook.net/en_US/sdk.js#xfbml=1&version=v13.0&appId=YOUR_APP_ID&autoLogApp=true" async defer></script>

Step 4: Handle the Login Callback in PHP

This PHP script initializes the Facebook SDK, handles the redirect logic, and manages the user session after successful authentication. This script typically resides at the Redirect URL specified in the Facebook App settings.

<?php
   session_start();

   $fb = new Facebook\Facebook([
      'app_id' => $app_id,
      'app_secret' => $app_secret,
      'default_graph_version' => 'v13.0',
   ]);

   $helper = $fb->getRedirectLoginHelper();
   $accessToken = $helper->getAccessToken();

   if ($accessToken) {
      // SUCCESS: Access token obtained. User is logged in.
      // Fetch user profile data (name, email, etc.)
      $response = $fb->get('/me?fields=id,name,email', $accessToken);
      $user = $response->getGraphUser();

      // Store necessary user data in the session
      $_SESSION['user_data'] = $user;
      
      // Redirect to the protected area
      header('Location: profile.php');
   } else {
      // FAILURE or FIRST VISIT: Generate the login URL
      $loginUrl = $helper->getLoginUrl(['scope' => 'public_profile,email']);
      
      // Redirect the user to the Facebook login page
      header('Location: ' . $loginUrl);
   }
?>

After successful authentication, the user's data is stored in the $\text{\$_SESSION['user\_data']}$ variable, which can be checked on $\text{profile.php}$ to ensure the user is logged in.

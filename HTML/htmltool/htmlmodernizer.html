HTML - Modernizr

Introduction

Modernizr is a small JavaScript library that detects whether a particular feature of web technologies is available in the user's browser. It helps developers handle feature support gracefully by applying fallbacks, displaying messages, or writing conditional CSS rules.

For example, if a browser does not support <video>, you can show a message or hide media controls.

Including Modernizr

To start using Modernizr, include its script in the HTML page header:

<script src="modernizr.min.js" type="text/javascript"></script>

Handling Supported and Unsupported Features

Modernizr automatically applies feature classes to the <html> element, allowing CSS-based feature detection.

<!-- In your CSS: -->
.no-audio #music {
   display: none; /* hide audio options */
}
.audio #music button {
   /* style play/pause buttons */
}

<!-- In your HTML: -->
<div id="music">
   <audio>
      <source src="audio.ogg" />
      <source src="audio.mp3" />
   </audio>
   <button id="play">Play</button>
   <button id="pause">Pause</button>
</div>

JavaScript Feature Detection

You can also check features directly in JavaScript using Modernizr.feature syntax: 

if (Modernizr.audio) {
   // Browser supports audio
} else {
   // Browser does not support audio
}

Common Features Detected by Modernizr

  • Canvas: .canvas / Modernizr.canvas
  • Audio: .audio / Modernizr.audio
  • Video: .video / Modernizr.video
  • CSS Animations: .cssanimations / Modernizr.cssanimations
  • Geolocation: .geolocation / Modernizr.geolocation
  • localStorage: .localstorage / Modernizr.localstorage
  • Web Workers: .webworkers / Modernizr.webworkers
  • IndexedDB: .indexeddb / Modernizr.indexeddb
  • WebSockets: .websockets / Modernizr.websockets
  • Drag and Drop: .draganddrop / Modernizr.draganddrop

Custom Feature Tests

Modernizr provides an addTest() API to define custom tests: 

Modernizr.addTest('customfeature', function() {
   return 'querySelector' in document;
});

Summary

Modernizr is a powerful way to ensure compatibility across browsers by detecting HTML5 and CSS3 features. It helps developers apply fallbacks or conditional rules to improve user experience.

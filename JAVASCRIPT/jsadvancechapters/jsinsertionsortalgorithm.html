JavaScript - Insertion Sort Algorithm

The Insertion Sort is a simple sorting algorithm that works similarly to how we sort playing cards in our hands. The array is divided into two parts: a sorted part and an unsorted part. Elements from the unsorted part are picked and inserted at their correct position in the sorted part.

This algorithm is simple to implement and efficient for small datasets or datasets that are already partly sorted.

Example

Consider the input and output below:

Input:  [24, 22, 26, 10, 12]  
Output: [10, 12, 22, 24, 26]

How Insertion Sort Works?

First Pass

Compare the first two elements 24 and 22. Since 22 is smaller, swap them. Now the sub-array [22, 24] is sorted.

Second Pass

Compare 24 and 26. They are in order, so no swapping is needed. The sorted sub-array is [22, 24, 26].

Third Pass

Next element is 10. Compare it with 26, 24, and 22. After multiple swaps, 10 moves to the beginning. Sorted sub-array is [10, 22, 24, 26].

Fourth Pass

Next element is 12. Compare it with 26, 24, and 22. After shifting, 12 takes its correct place. Final array is [10, 12, 22, 24, 26].

Algorithm

  1. If it is the first element, it is already sorted.
  2. Pick the next element.
  3. Compare it with all elements in the sorted sub-list.
  4. Shift all the larger elements in the sorted sub-list by one position.
  5. Insert the value at the correct position.
  6. Repeat until the list is sorted.

JavaScript Implementation

<!DOCTYPE html>
<html>
  <head>
    <title>Insertion Sort Algorithm</title>
  </head>
  <body>
    <p id="demo"></p>
    <script>
      function insertionSort(arr) {
        let n = arr.length;
        for (let i = 1; i < n; i++) {
          let current = arr[i];
          let j = i - 1;
          while ((j > -1) && (current < arr[j])) {
            arr[j + 1] = arr[j];
            j--;
          }
          arr[j + 1] = current;
        }
        return arr;
      }

      let arr = [24, 22, 26, 10, 12];
      document.getElementById("demo").innerHTML = insertionSort(arr);
    </script>
  </body>
</html>

Output

[10, 12, 22, 24, 26]

The array is successfully sorted using the Insertion Sort Algorithm.

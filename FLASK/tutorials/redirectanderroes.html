Flask Redirects and Error Handling (redirect() & abort()) ↩️🛑

Flask provides built-in functions to control navigation between pages (redirection) and to immediately stop a request due to an error (abortion).

The redirect() Function

The redirect() function returns a response object that instructs the user's browser to navigate to a new URL. This is essential for controlling the application flow after operations like form submission or login attempts.

Prototype and Parameters:

Flask.redirect(location, statuscode, response)

  • **location:** The target URL where the user should be redirected (often generated using url_for()).
  • **statuscode:** The HTTP status code sent to the browser's header. It **defaults to 302** (Found).

Common Redirection Status Codes (3xx):

The default 302 FOUND is typically used for temporary redirects. Other codes indicate different redirection types:

  • **HTTP_301_MOVED_PERMANENTLY**
  • **HTTP_302_FOUND** (Default)
  • **HTTP_303_SEE_OTHER** (Often used after a POST to prevent re-submission)
  • **HTTP_307_TEMPORARY_REDIRECT**

Example: Redirection on Login Failure

In the login example, if the username is not 'admin', the user is sent back to the index page (the login form) using redirect():

if request.method == 'POST' and request.form['username'] == 'admin' :

return redirect(url_for('success'))

else:

return redirect(url_for('index'))

The abort() Function for Error Handling

The **abort()** function immediately stops the execution of a request and raises a specified HTTP error code. This is used when a request cannot be fulfilled due to client or server errors.

Flask.abort(code)

Common Error Codes (4xx and 5xx):

  • **400** (Bad Request)
  • **401** (Unauthorized) - Access denied due to lack of valid credentials.
  • **403** (Forbidden) - Access denied even with valid credentials.
  • **404** (Not Found) - The requested resource does not exist.
  • **429** (Too Many Requests)

Example: Aborting on Unauthorized Access

The modified login function demonstrates using abort(401) instead of redirecting on failure:

if request.form['username'] == 'admin' :

return redirect(url_for('success'))

else:

abort(401)

If the login fails, the server stops processing and sends an **HTTP 401 Unauthorized** response to the client.

Flask URL Building with url_for() and Redirection 🔄

The **url_for()** function in Flask is a powerful tool used to dynamically build a URL for a specific view function. This is more reliable than hardcoding URLs, as it ensures URLs are updated automatically if route rules change.

Functionality of url_for()

The function accepts two types of arguments:

  • The first argument is the **endpoint name** (typically the name of the **view function**).
  • Subsequent arguments are passed as **keyword arguments** to satisfy any **variable parts** defined in the target URL's rule (e.g., <guest> in /guest/<guest>).

Code Logic Summary

The application defines three routes: /admin, /guest/<guest>, and /user/<name>. The hello_user(name) function acts as a dispatcher:

  • If the name passed in the URL is **'admin'**, the function uses redirect(url_for('hello_admin')) to send the user to the /admin page.
  • Otherwise, it uses redirect(url_for('hello_guest', guest = name)). Here, url_for() builds the URL for the hello_guest function and passes the URL variable name as the keyword argument guest.

Execution Results

Visiting the dispatcher URL leads to different results based on the input name:

  • **URL Input:** http://localhost:5000/user/admin

    Result: Redirects to /admin. Output is **Hello Admin**.

  • **URL Input:** http://localhost:5000/user/mvl

    Result: Redirects to /guest/mvl. Output is **Hello mvl as Guest**.

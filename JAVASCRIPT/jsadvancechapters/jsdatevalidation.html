JavaScript - Date Validation

In JavaScript, we often need to validate dates to ensure they are in the correct format, fall within the correct range, and are valid calendar dates.

Why Validate a Date?

When users enter dates in forms, they may input incorrect values. To prevent errors, we validate the date before processing it.

Ways to Validate a Date

  • Using getTime() method
  • Using isFinite() method
  • Using Regular Expressions to check date format
  • Using libraries like Moment.js (deprecated in modern apps)

1. Using getTime() Method

The getTime() method returns the number of milliseconds since January 1, 1970. If it returns NaN, the date is invalid. 


function isValid(date) {
  if (Object.prototype.toString.call(date) === "[object Date]") {
    return !isNaN(date.getTime());
  }
  return false;
}

console.log(isValid(new Date("No date"))); // false
console.log(isValid(new Date()));          // true

2. Using isFinite() Method

This method checks if the date is an instance of Date and if the time value is finite. 


function isValid(date) {
  return date instanceof Date && isFinite(date);
}

console.log(isValid(new Date("No date"))); // false
console.log(isValid(new Date()));          // true

3. Validate Date Format using Regular Expressions

Regular expressions help ensure the date string follows a specific pattern, such as YYYY-MM-DD. 


let reg = /^\d{4}-\d{2}-\d{2}$/;

console.log(reg.test("2022-07-31")); // true
console.log(reg.test("2022-07-32")); // true (but invalid calendar date)

Note: Regex only checks format, not actual validity of the date.

Conclusion

JavaScript provides multiple ways to validate dates. Use getTime() or isFinite() for actual date validation, and regular expressions for format validation. For advanced needs, libraries like date-fns or Luxon are recommended instead of Moment.js.

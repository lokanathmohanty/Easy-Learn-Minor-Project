HTML - MathML

Mathematical Markup Language (MathML)

HTML MathML (Mathematical Markup Language) is used to embed mathematical and chemical equations into an HTML document.

MathML is an XML-based markup language introduced in 2015. It helps to represent complex mathematical formulas in human-readable format, while also making them understandable by software.

MathML elements can be embedded in a web page using the <math> tag.

HTML MathML Elements

Element Description
<math>Top-level tag (root) of all MathML elements.
<mrow>Indicates a row in a table or matrix.
<msqrt>Displays square root in an expression.
<msub>Adds subscript to an expression.
<msup>Adds superscript to an expression.
<mo>Represents operators such as =, +, −.
<mi>Represents identifiers like variables or constants.
<mtable>Creates a table or matrix.
<mtr>Defines a row in a table or matrix.
<mtd>Defines a cell inside a table or matrix.

Purpose of HTML MathML

MathML is widely used in technical, scientific, and educational web pages to ensure clear representation of formulas. It is especially useful in e-learning, research papers, and algorithm documentation.

Currently, MathML is supported in Google Chrome and Mozilla Firefox browsers.

Examples of MathML in HTML

Pythagorean Theorem

<math>
  <mrow>
    <msup><mi>a</mi><mn>2</mn></msup>
    <mo>+</mo>
    <msup><mi>b</mi><mn>2</mn></msup>
    <mo>=</mo>
    <msup><mi>c</mi><mn>2</mn></msup>
  </mrow>
</math>

Quadratic Equation

<math>
  <mrow>
    <msup><mi>x</mi><mn>2</mn></msup>
    <mo>+</mo>
    <mn>4</mn><mo>⁢</mo><mi>x</mi>
    <mo>+</mo><mn>4</mn>
    <mo>=</mo><mn>0</mn>
  </mrow>
</math>

Matrix Example

<math>
  <mrow>
    <mi>A</mi>
    <mo>=</mo>
    <mfenced open="[" close="]">
      <mtable>
        <mtr>
          <mtd><mi>x</mi></mtd>
          <mtd><mi>y</mi></mtd>
        </mtr>
        <mtr>
          <mtd><mi>z</mi></mtd>
          <mtd><mi>w</mi></mtd>
        </mtr>
      </mtable>
    </mfenced>
  </mrow>
</math>

Redox Chemical Equation

<math>
  <mrow>
    <msub><mtext>Zn</mtext></msub>
    <mo>+</mo>
    <msub><mrow><mtext>CuSO</mtext><mn>4</mn></mrow></msub>
    <mo>→</mo>
    <msub><mrow><mtext>ZnSO</mtext><mn>4</mn></mrow></msub>
    <mo>+</mo>
    <msub><mtext>Cu</mtext></msub>
  </mrow>
</math>

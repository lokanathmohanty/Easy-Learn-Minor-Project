PHP Hashing and Cryptographic Functions

Hashing is a technique used to encrypt data (usually text) into a fixed-length value, known as the **hash** or **message digest**. The process is **one-way**—it's computationally infeasible to reverse the hash to obtain the original key (pre-image). PHP provides an extensive library of functions and algorithms for hashing.

Applications of Hashing 🔒

  • Password Authentication: Instead of storing user passwords directly, the server stores the hash of the password. When a user logs in, the submitted password is **hashed** and the result is compared against the stored hash. This protects the original password from theft.
  • Data Integrity: Hashing verifies that data (like a downloaded file) has not been tampered with or corrupted during transfer. The original hash value is published, and the user can hash the downloaded file and compare the two digests.

Hashing Algorithms in PHP

PHP supports a wide variety of algorithms, each producing a different fixed-length output:

  • MD5: A 128-bit hash function, often represented as a 32-digit hexadecimal number. Used primarily for file integrity verification. (e.g., "frog" hashes to $\text{8b1a...4d7}$).
  • SHA (Secure Hash Algorithm): A family of standards. **SHA-1** is 160-bit. **SHA-2** is a family of hashes, most commonly used at **256-bit** ($\text{SHA256}$).
  • **HMAC (Hash-Based Message Authentication Code):** A technique that uses a cryptographic hash function *and* a **secret key** to provide both data integrity and authentication.
  • **PBKDF2 (Password-Based Key Derivation Function 2):** A **key stretching** algorithm specifically designed to make password cracking computationally expensive, thus more secure for password hashing than MD5 or simple SHA.

Core PHP Hash Functions

1. $\text{hash()}$ (Hashing a String)

Generates the hash value (message digest) for a given string of data.

hash(string $algo, string $data, bool $binary = false): string|false
  • $\text{\$algo}$: The specific hashing algorithm to use (e.g., $\text{"sha256"}$, $\text{"md5"}$).
  • $\text{\$data}$: The string message to be hashed.
  • $\text{\$binary}$: If $\text{true}$, outputs raw binary data; otherwise, outputs lowercase hexadecimal digits (hexits).
<?php
   $message = 'The quick brown fox jumped over the lazy dog.';
   echo hash('md5', $message);
   // Output: 5c6ffbdd40d9556b73a21e63c3e0e904
?>
### 2. $\text{hash\_file()}$ (Hashing a File)

Calculates the message digest for the entire contents of a specified file. This is crucial for verifying data integrity after file transfer.

hash_file(string $algo, string $filename, bool $binary = false): string|false
  • $\text{\$filename}$: The path or URL of the file to be hashed.
### 3. $\text{hash\_algos()}$ (Listing Supported Algorithms)

Returns a numerically indexed array containing the names of all hashing algorithms supported by the current PHP installation.

hash_algos(): array

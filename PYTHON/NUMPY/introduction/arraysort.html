NumPy Sorting Arrays

Sorting Arrays

Sorting means putting elements in an ordered sequence.

An ordered sequence corresponds to elements arranged numerically, alphabetically, ascending or descending.

The NumPy ndarray object has a function called sort() that will sort a specified array.

import numpy as np

arr = np.array([3, 2, 0, 1])

print(np.sort(arr))

Note: This method returns a copy of the array, leaving the original array unchanged.

You can also sort arrays of strings or other data types:

import numpy as np

arr = np.array(['banana', 'cherry', 'apple'])

print(np.sort(arr))

Sort a boolean array:

import numpy as np

arr = np.array([True, False, True])

print(np.sort(arr))

Sorting a 2-D Array

If you use the sort() method on a 2-D array, each sub-array will be sorted independently.

import numpy as np

arr = np.array([[3, 2, 4], [5, 0, 1]])

print(np.sort(arr))

Next.js Response Helpers (Pages Router) ⚙️

What are Response Helpers?

**Response Helpers** are convenient methods available on the **Server Response Object (`res`)** within Next.js API Routes (Pages Router). They streamline the process of sending an HTTP response by automatically setting necessary headers, status codes, and formatting (like JSON), eliminating the need to do so manually.

Primary Response Helper Methods

Method Purpose Example
`res.send(body)` Sends a **text** response body. The argument is typically a string. `res.send("Hello, Next.js!")`
`res.status(code)` Sets the **HTTP status code** (e.g., 200, 404, 500). This method can be chained with other helpers. `res.status(200).send("Success!")`
`res.json(object)` Sends a **JSON** response. It automatically sets the `Content-Type: application/json` header. `res.json({ message: "Hello!" })`
`res.redirect(url)` Redirects the client to a new URL using a 302 Found status code. `res.redirect("/about")`

Example: Using Helpers to Handle Methods

This API Route uses status and send/json helpers to handle different request methods concisely:

// /pages/api/action.ts
export default function handler(req, res) {
    const { method } = req;

    if (method === "GET") {
        // Send JSON response with 200 OK status
        res.status(200).json({ message: "GET request received." });
    } else if (method === "POST") {
        // Send text response with 201 Created status
        res.status(201).send("POST request received.");
    } else {
        // Send 405 Method Not Allowed status and end the response
        res.status(405).end(); 
    }
}

JavaScript - Graph Algorithms

A graph is a data structure consisting of nodes (vertices) and edges. Nodes represent entities, and edges represent the connections between them. Graphs are non-linear data structures.

Graph algorithms in JavaScript are used to traverse graphs, find shortest paths, detect connectivity, and more.

Types of Graph

  • Directed Graph (Digraph): Edges have a direction (→).
  • Undirected Graph: Edges do not have any direction.
  • Weighted Graph: Edges have weights (costs, distances, etc.).
  • Unweighted Graph: Edges do not carry any weight.

Graph Representation

  • Adjacency Matrix: A 2D array where 1 indicates an edge exists, 0 means no edge.
  • Adjacency List: An array of lists, where each list stores neighbors of a vertex.

Graph Algorithms

Some commonly used graph algorithms include:

  • Breadth First Search (BFS)
  • Depth First Search (DFS)
  • Topological Sorting

Breadth First Search (BFS)

BFS traverses the graph level by level. It starts from the root node, explores all neighbors, then moves to the next level. It uses a queue.

Algorithm Steps

  • Create a queue and enqueue the root node.
  • Create a visited array and mark the root node as visited.
  • While the queue is not empty:
    • Dequeue a node and process it.
    • Enqueue all unvisited neighbors.

Implementation

function BFS(graph, root) {
   let visited = [];
   let queue = [];
   queue.push(root);

   while (queue.length > 0) {
      let node = queue.shift();

      if (!visited[node]) {
         console.log(node);
         visited[node] = true;
      }

      const neighbours = graph[node] || [];
      for (let i = 0; i < neighbours.length; i++) {
         let neighbour = neighbours[i];
         if (!visited[neighbour]) {
            queue.push(neighbour);
         }
      }
   }
}

BFS(graph, 0);

Depth First Search (DFS)

DFS explores as far as possible along each branch before backtracking. It uses a stack (or recursion).

Algorithm Steps

  • Create a stack and push the root node.
  • Create a visited array and mark the root node as visited.
  • While the stack is not empty:
    • Pop a node and process it.
    • Push all unvisited neighbors onto the stack.

Implementation

function DFS(graph, root) {
   let visited = [];
   let stack = [];
   stack.push(root);

   while (stack.length > 0) {
      let node = stack.pop();
      if (!visited[node]) {
         console.log(node);
         visited[node] = true;
      }

      const neighbours = graph[node] || [];
      for (let i = 0; i < neighbours.length; i++) {
         let neighbour = neighbours[i];
         if (!visited[neighbour]) {
            stack.push(neighbour);
         }
      }
   }
}

Topological Sorting

Topological Sorting arranges the vertices in a directed acyclic graph (DAG) so that for every edge u → v, vertex u appears before v.

Algorithm Steps

  • Mark all vertices as not visited.
  • Perform a DFS on each unvisited node.
  • After visiting all neighbors of a node, push it to a stack.
  • At the end, pop all elements from the stack to get the ordering.

Implementation

function topologicalSort(graph) {
   let visited = [];
   let stack = [];
   for (let i = 0; i < graph.length; i++) {
      if (!visited[i]) {
         topologicalSortUtil(graph, i, visited, stack);
      }
   }
   while (stack.length > 0) {
      console.log(stack.pop());
   }
}

function topologicalSortUtil(graph, node, visited, stack) {
   visited[node] = true;
   const neighbours = graph[node] || [];
   for (let i = 0; i < neighbours.length; i++) {
      let neighbour = neighbours[i];
      if (!visited[neighbour]) {
         topologicalSortUtil(graph, neighbour, visited, stack);
      }
   }
   stack.push(node);
}

Conclusion

Graph algorithms are powerful tools for solving real-world problems like shortest paths, connectivity, scheduling, and network analysis. JavaScript provides flexibility to implement BFS, DFS, Topological Sorting, and more using arrays and objects.

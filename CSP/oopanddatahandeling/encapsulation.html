C# Encapsulation and Access Specifiers

Understanding Encapsulation

Encapsulation is one of the core principles of Object-Oriented Programming (OOP). It is the process of **bundling data (fields) and the methods (functions) that operate on that data** into a single unit (a class).

The primary goal of encapsulation is to **prevent direct external access** to the internal implementation details of an object, thereby protecting the data from accidental corruption. It allows the programmer to enforce a desired level of **abstraction**.

Access Specifiers in C#

Encapsulation is primarily implemented using **access specifiers**, which define the **scope and visibility** of a class member (field, method, property, etc.).

Specifier Visibility Scope Description
public Anywhere Accessible from **any code** in the same assembly or another assembly. No restriction.
private Only within the **same class** The strictest level; members are hidden from derived classes and outside code. (Default for class members).
protected Same class and **derived classes** Accessible within the defining class and any class that inherits from it, even in a different assembly.
internal Only within the **same assembly** Accessible from any code within the current project/assembly, but hidden from other assemblies.
protected internal Same assembly **OR** derived classes in any assembly Accessible by code in the same assembly **OR** by derived classes defined in other assemblies.

Implementation: Private Fields and Public Properties

The best practice for encapsulation in C# involves making fields **`private`** and providing controlled access via **`public` properties** or methods. This hides the data while allowing logic to validate or transform the data during access.

Example: Encapsulation with Properties (Get/Set)

The private field salary is protected, and the public Salary property ensures the value meets the minimum requirement before being assigned.

class Employee {
    private double salary;  // Private field (data is hidden)

    public double Salary { // Public property (controlled access)
        get { 
            return salary; 
        }
        set {
            if (value >= 3000) { // Validation logic
                salary = value;
            } else {
                Console.WriteLine("Salary must be at least 3000.");
            }
        }
    }
}

Execution Demonstration:

Employee emp = new Employee();
emp.Salary = 5000;  // Valid: salary is set to 5000
emp.Salary = 2000;  // Invalid: Prints error, salary remains 5000
Console.WriteLine("Employee Salary: " + emp.Salary); // Output: 5000

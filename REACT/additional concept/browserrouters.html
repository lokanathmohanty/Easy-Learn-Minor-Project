ReactJS - BrowserRouter

Routing is an important concept in front-end applications. React community provides a router library called React Router. Let us learn the concept of React Router and how to use it in a React application.

Router Concepts

The primary purpose of the router is to match the given URL to a React component and render it. It should also manage browser history for forward and backward navigation.

Main components of React Router:

  • BrowserRouter – Top-level component that manages history and URL state.
  • Routes – Builds configuration by matching paths with components.
  • Route – Actual router configuration, supports nesting.
  • Outlet – Renders the next match inside the parent component.
  • Link – Used for navigation, similar to <a> tag.
  • navigate() – API to programmatically navigate to another route.
<BrowserRouter>
   <Routes>
      <Route path="/" element={<App />}>
         <Route index element={<Home />} />
         <Route path="admin" element={<Admin />}>
            <Route path="product" element={<ProductListing />} />
            <Route path="category" element={<CategoryListing />} />
            <Route index element={<Dashboard />} />
         </Route>
      </Route>
      <Route path="/login" element={<Login />} />
   </Routes>
</BrowserRouter>

Router Workflow

Example application pages:

  • Home (/)
  • Contact (/contact)
  • Register (/register)
  • Admin (/admin)
  • AdminDashboard (/admin/dashboard)
<BrowserRouter>
   <Routes>
      <Route path="/" element={<App />}>
         <Route index element={<Home />} />
         <Route path="contact" element={<Contact />} />
         <Route path="register" element={<Register />} />
         <Route path="admin" element={<Admin />}>
            <Route path="dashboard" element={<AdminDashboard />} />
            <Route path="category" element={<CategoryListing />} />
            <Route index element={<AdminDashboard />} />
         </Route>
      </Route>
   </Routes>
</BrowserRouter>

Steps for /admin/dashboard navigation:

  • BrowserRouter initializes history and state.
  • Routes checks child routes and finds a match.
  • Admin component renders with <Outlet />.
  • Outlet loads the nested route (AdminDashboard).
  • Link or navigate() updates URL and BrowserRouter re-renders.

Applying Routers

Steps to create a new application with router:

create-react-app myapp
cd myapp
npm start
npm install --save react-router-dom

Create Home component (src/Pages/Home.js):

function Home() {
   return <h3>Home</h3>
}
export default Home

Create Greeting component (src/Pages/Greeting.js):

function Greeting() {
   return <h3>Hello World!</h3>
}
export default Greeting

Setup App.js:

import { BrowserRouter, Route, Routes } from 'react-router-dom';
import Layout from './Pages/Layout';
import Home from './Pages/Home';
import Greeting from './Pages/Greeting';

function App() {
   return (
      <BrowserRouter>
         <Routes>
            <Route path="/" element={<Layout />}>
               <Route index element={<Home />} />
               <Route path="greet" element={<Greeting />} />
            </Route>
         </Routes>
      </BrowserRouter>
   );
}
export default App;

Layout Component

import { Outlet, Link } from "react-router-dom";
function Layout() {
   return (
      <>
         <nav>
            <ul>
               <li><Link to="/">Home</Link></li>
               <li><Link to="/greet">Greeting</Link></li>
            </ul>
         </nav>
         <Outlet />
      </>
   )
}
export default Layout;

The Outlet renders the selected nested component.

Handling Unknown Routes

Create PageNotAvailable component:

import { Link } from "react-router-dom"
function PageNotAvailable() {
   return (
      <p>The page is not available. Please <Link to="/">click here</Link> to go to home page.</p>
   )
}
export default PageNotAvailable

Update App.js:

import PageNotAvailable from './Pages/PageNotAvailable'

<Route path="*" element={<PageNotAvailable />} />

This ensures unmatched routes display a friendly error page.

Summary

React Router is simple and effective. It supports BrowserRouter, Routes, Route, Link, Outlet, and navigate() to build applications with navigation. It allows nested routing and handles unknown paths gracefully.

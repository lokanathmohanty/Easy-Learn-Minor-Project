Bit Fields in C

Introduction

Bit fields in C allow you to specify the exact number of bits a variable should use within a struct or union, optimizing memory usage by restricting field sizes.

Bit Field Syntax

Declare a bit field by appending a colon and the number of bits after the member name: 


struct {
  unsigned int widthValidated : 1;
  unsigned int heightValidated : 1;
} status;

Memory Usage

Although only 2 bits are used for the status fields, the entire structure occupies 4 bytes due to minimum storage sizes and alignment. Adding more bit fields up to the native word size fits into the same memory slot.

Example: Bit Fields vs Regular Fields


#include <stdio.h>

struct {
  unsigned int widthValidated;
  unsigned int heightValidated;
} status1;

struct {
  unsigned int widthValidated : 1;
  unsigned int heightValidated : 1;
} status2;

int main() {
  printf("Memory size occupied by status1: %d\n", sizeof(status1));
  printf("Memory size occupied by status2: %d\n", sizeof(status2));
  return 0;
}

Output

Typical output shows status1 occupying 8 bytes and status2 occupying 4 bytes, demonstrating memory efficiency of bit fields.

Bit Field Details

  • type: int, unsigned int, or signed int
  • member_name: name of the bit field
  • width: number of bits, must not exceed the bit width of type

Example: Storing Small Values


struct {
  unsigned int age : 3;
} Age;

int main() {
  Age.age = 4;
  printf("Sizeof(Age): %d\n", sizeof(Age));
  printf("Age.age: %d\n", Age.age);

  Age.age = 7;
  printf("Age.age: %d\n", Age.age);

  Age.age = 8;  // Overflow warning
  printf("Age.age: %d\n", Age.age);

  return 0;
}

Output Notes

Assigning values beyond 3 bits (max 7) results in overflow and unexpected zero values. Bit fields are ideal for memory-limited contexts or encoding multiple status flags into a single memory unit.

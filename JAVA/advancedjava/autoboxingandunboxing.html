Autoboxing and Unboxing in Java

Autoboxing is a technique used by the Java compiler to automatically convert a primitive value to its corresponding wrapper object. For example, assigning an int value to an Integer object triggers autoboxing.

Unboxing is the reverse process, where a wrapper object is automatically converted back to its primitive type when needed.

Key Points

  • Autoboxing converts primitive types to wrapper objects automatically.
  • Unboxing converts wrapper objects to primitive types automatically.
  • This automatic conversion happens when passing parameters, assigning values, or returning values.

Example

Below is a simple Java program demonstrating autoboxing and unboxing:


List<Integer> list = new ArrayList<>();
for (int i = 0; i < 5; i++) {
    list.add(i); // autoboxing: int to Integer
}

Integer integer = Integer.valueOf(-10);
int value = integer; // unboxing: Integer to int
System.out.println(value);

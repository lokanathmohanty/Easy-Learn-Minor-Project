Next.js - Request Memoization

What is Request Memoization?

Request Memoization is a crucial optimization technique used to prevent **duplicate data fetches** for identical requests within the same React component render cycle. It functions as a short-term, in-memory cache, ensuring that if multiple parts of the component tree request the exact same data, the network request is only executed once.

How It Works

  1. When a **fetch** request is first made (typically in a Server Component), Next.js (via the React extension of fetch) stores the resulting **Promise** in memory.
  2. Any **subsequent identical request** (same URL, same options) made during that same server request lifecycle returns the cached Promise instead of initiating a new network call.
  3. The memoization cache is local to the current incoming **server request** and is cleared once the React component tree has finished rendering for that request.

Key Facts on Request Memoization

Understanding these facts is key to leveraging memoization:

  • It is primarily a **React feature**, extended to Next.js's fetch capabilities.
  • It **only applies to the GET method** in fetch requests.
  • It applies across various **Server Components** and functions, including generateMetadata, generateStaticParams, Layouts, and Pages.
  • It **does not apply** to fetch requests in **Route Handlers** because Route Handlers exist outside the React component tree render cycle.
  • The cache duration is limited to the **lifetime of a single server request** (until rendering is complete).

Advanced Memoization with Parameters

Memoization is effective even when using a shared asynchronous function with parameters, as long as the calls within the same render cycle use identical arguments.

Example Server Component Logic:

The first call to getUser('1') executes the fetch. The second call, getUser('1'), uses the memoized result from the first. The third call, getUser('2'), is a new request because the parameter is different.

// app/dashboard/page.tsx
async function getUser(id: string): Promise<User> {
    // This fetch call is memoized based on the URL
    const res = await fetch(`https://jsonplaceholder.typicode.com/users/${id}`);
    if (!res.ok) throw new Error('Failed to fetch user');
    return res.json();
}

export default async function DashboardPage() {
    // 1. Initial Fetch
    const user1 = await getUser('1'); 
    
    // 2. Memoized (No new network request)
    const user1Again = await getUser('1'); 

    // 3. New Fetch (Different parameter)
    const user2 = await getUser('2'); 

    return (
        <div>
        <h1>User Dashboard</h1>
        <!-- ... display users ... -->
        </div>
    );
}

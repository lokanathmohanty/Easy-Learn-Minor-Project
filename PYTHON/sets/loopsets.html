Loop Through Set Items

Looping through set items in Python means iterating over each element in a set to perform operations such as printing, filtering, or applying conditions.

Sets are unordered collections, so elements are accessed in an arbitrary order. The most common way to loop through set items is using a for loop.

Loop Through Set Items with For Loop

A for loop is used to iterate over a set and access each element. 

for item in set:
   # Code block to execute

Example:

my_set = {25, 12, 10, -21, 10, 100}

for item in my_set:
   print("Item:", item)

Output example (order may vary):
Item: 100
Item: 25
Item: 10
Item: -21
Item: 12

Loop Through Set Items with While Loop

You can loop through a set with a while loop by converting the set to an iterator and iterating manually. 

my_set = {1, 2, 3, 4, 5}
set_iterator = iter(my_set)

while True:
   try:
      item = next(set_iterator)
      print("Item:", item)
   except StopIteration:
      break

Output example:
Item: 1
Item: 2
Item: 3
Item: 4
Item: 5

Iterate Using Set Comprehension

Set comprehensions provide a concise syntax to create a set by iterating over an iterable and optionally filtering elements. 

numbers = [1, 2, 3, 4, 5]
squares_of_evens = {x**2 for x in numbers if x % 2 == 0}
print(squares_of_evens)

Output:
{16, 4}

Iterate Through a Set Using enumerate()

The enumerate() function adds an index to each element during iteration. Since sets are unordered, convert the set into a list first. 

my_set = {1, 2, 3, 4, 5}
set_list = list(my_set)

for index, item in enumerate(set_list):
   print("Index:", index, "Item:", item)

Output example:
Index: 0 Item: 1
Index: 1 Item: 2
Index: 2 Item: 3
Index: 3 Item: 4
Index: 4 Item: 5

Loop Through Set Items with add() Method

The add() method adds an element to a set. You can loop over a sequence and add elements to a set with this method. 

my_set = set()

for i in range(5):
   my_set.add(i)

print(my_set)

Output:
{0, 1, 2, 3, 4}

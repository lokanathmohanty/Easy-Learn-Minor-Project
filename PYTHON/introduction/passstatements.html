Python - pass Statement

The pass statement in Python is a null operation — it does nothing when executed. It is often used as a placeholder in code where a statement is syntactically required but no action needs to be performed.

This is useful in function or class definitions where the implementation will be added later, or in control structures such as if, for, and while loops.

Syntax of pass Statement

pass

Example of pass Statement

for letter in 'Python':
   if letter == 'h':
      pass
      print("This is pass block")
   print("Current Letter:", letter)
print("Good bye!")

Output:

Current Letter: P
Current Letter: y
Current Letter: t
This is pass block
Current Letter: h
Current Letter: o
Current Letter: n
Good bye!

Dummy Infinite Loop with pass

You can create an infinite loop that does nothing by using pass as the loop body. 

while True: 
   pass
# Press Ctrl+C to stop execution

Using Ellipses (...) as Alternative

In Python 3.x, ellipses (...) can be used as an alternative to pass. They also act as placeholders in unfinished code blocks. 

def func1():
   # Alternative to pass
   ...

def func2(): ...
   # Does nothing when called

func1()
func2()

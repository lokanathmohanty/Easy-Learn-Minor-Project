Static Variables in C

By default, a variable in C is of auto storage class. A static variable retains its value between multiple function calls and is initialized only once.

Static variables are useful when you need to preserve state across function invocations or restrict variable scope to a single file.

Features of Static Variables

  • Allocated in static memory (not stack).
  • Initialized only once (default value is 0 if not explicitly set).
  • Retains value between function calls.
  • Scope is local to the function or file, but lifetime is entire program.

Declaring a Static Variable

Use the static keyword before the variable declaration. The syntax is:

static datatype variable = value;

Example: Basic Static Variable

Example

#include <stdio.h>

int main() {
    static int b = 8;
    printf("Static variable value: %d\n", b);
    return 0;
}

Output:

Static variable value: 8

Example: Counter Without Static

Example

#include <stdio.h>

void counter() {
    int x = 0;
    x++;
    printf("%d\n", x);
}

int main() {
    counter();
    counter();
    counter();
    return 0;
}

Output:

1
1
1

Example: Counter With Static

Example

#include <stdio.h>

void counter() {
    static int x = 0;
    x++;
    printf("%d\n", x);
}

int main() {
    counter();
    counter();
    counter();
    return 0;
}

Output:

1
2
3

Static vs Global Variables

Both static and global variables have static storage duration, but differ in scope:

  • Static variables: Limited to function or file.
  • Global variables: Accessible throughout the program.

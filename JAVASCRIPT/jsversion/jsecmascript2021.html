JavaScript - ECMAScript 2021

The ECMAScript 2021 standard was released in 2021. It introduced several notable features that improved developer productivity and code readability. Among them are the String.replaceAll() method, logical assignment operators (&&=, ||=, ??=), and numeric separators for readability.

New Features Added in ECMAScript 2021

  • Numeric Separators (_)
  • Promise.any() method
  • String.replaceAll() method
  • Logical AND Assignment Operator (&&=)
  • Logical OR Assignment (||=)
  • Nullish Coalescing Assignment (??=)

Numeric Separators (_)

ECMAScript 2021 introduced numeric separators to make numbers more readable. The underscore (_) can be used within numeric literals.

Example


let num = 90_00_000;
console.log(num);

Output: The value of the num is: 9000000

Promise.any() Method

The Promise.any() method fulfills as soon as any promise in the array resolves. If all promises are rejected, it throws an error.

Example


const promise1 = new Promise((res, rej) => res());
const promise2 = new Promise((res, rej) => rej());
const promises = [promise1, promise2];

Promise.any(promises)
  .then(() => {
    console.log('One or more promises are resolved!');
  })
  .catch((err) => {
    console.log('All promises are rejected:', err);
  });

Output: One or more promises are resolved!

String.replaceAll() Method

The replaceAll() method replaces all occurrences of a substring within a string. It accepts a string or regular expression as an argument.

Example


let str = "abcd abcd abcd abcd";
console.log("Original string is:", str);
let updatedStr = str.replaceAll("a", "A");
console.log("Updated string is:", updatedStr);

Output:


Original string is: abcd abcd abcd abcd
Updated string is: Abcd Abcd Abcd Abcd

Logical AND Assignment Operator (&&=)

The &&= operator updates the value of the left operand only if it is truthy.

Example


let str = "Hello";
str &&= "Hi";
console.log(str);

Output: The value of the str is: Hi

Logical OR Assignment (||=)

The ||= operator updates the value of the left operand if it is falsy.

Example


let str = false;
str ||= 10;
console.log(str);

Output: The value of the str is: 10

Nullish Coalescing Assignment (??=)

The ??= operator assigns a value to the left operand only if it is null or undefined.

Example


let str = null;
str ??= "default";
console.log(str);

Output: The value of the str is: default

Warning: Some of the above features may not be supported in older browsers. Use polyfills if necessary.

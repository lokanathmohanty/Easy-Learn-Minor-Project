HTML - Tags Reference

HTML tags define the structure and formatting of content in a webpage. Most tags have an opening <tag> and a closing </tag>, though some are self-closing.

Basic Tags

Tag Description Example
<!--...--> Specifies a comment. 
<!-- This is a comment -->
<!DOCTYPE> Defines the document type. 
<!DOCTYPE html>
<html> Root element of an HTML document. 
<html>...</html>
<head> Container for metadata. 
<head>...</head>
<title> Defines the document title. 
<title>My Page</title>
<body> Main container for page content. 
<body>Hello</body>
<h1>...<h6> Headings (largest to smallest). 
<h1>Main Title</h1>
<p> Defines a paragraph. 
<p>This is a paragraph.</p>
<br> Inserts a line break. 
Hello<br>World
<hr> Inserts a horizontal rule. 
<hr>

Formatting Tags

Tag Description Example
<abbr> Defines an abbreviation. 
<abbr title="HyperText Markup Language">HTML</abbr>
<blockquote> Defines a block quotation. 
<blockquote>Quoted text</blockquote>
<code> Displays computer code. 
<code>console.log("Hello")</code>
<em> Emphasizes text. 
<em>Important</em>
<strong> Defines strong importance. 
<strong>Warning!</strong>
<mark> Highlights text. 
<mark>Highlighted</mark>

PHP `foreach` Loop

The **`foreach`** loop is a specialized control structure in PHP designed exclusively for **iterating over arrays** (and other iterable objects). It simplifies the process of stepping through every element in an array without manually managing a counter or index variable.

`foreach` Syntax Variations

There are two primary forms of the `foreach` loop, catering to both indexed and associative arrays.

1. Value-Only Syntax (Indexed Arrays)

This syntax is primarily used when you only need to access the element's value and not its key/index.

foreach (array as $value) { statements }

In each iteration, the value of the current array element is assigned to the `$value` variable.

2. Key-Value Syntax (Associative Arrays)

This is the general and most versatile syntax, used when you need to access both the key/index and the value of each element.

foreach (array as $key => $value) { statements }

In each iteration, the current element's key is assigned to `$key` and its value to `$value`.

Practical Examples

Iterating an Indexed Array (Key-Value Syntax)

Although indexed arrays use numerical indices, they can still be treated as key-value pairs where the index is the key.

$arr = array(10, 20, 30);
foreach ($arr as $k => $v) { echo "Key: $k => Val: $v \n"; }

Output: Key: 0 => Val: 10 \n Key: 1 => Val: 20 \n Key: 2 => Val: 30

Iterating an Associative Array

The key-value syntax is essential for accessing the meaningful string keys in an associative array.

$capitals = array("UP" => "Lucknow", "Tamilnadu" => "Chennai");
foreach ($capitals as $state => $capital) { echo "Capital of $state is $capital \n"; }

Output: Capital of UP is Lucknow \n Capital of Tamilnadu is Chennai

Iterating a Multidimensional (2D) Array (Nested Loops)

To traverse an array of arrays, you use nested `foreach` loops. The outer loop iterates over the main array, and the inner loop iterates over the array contained within the current element.

$twoD = array( array(1, 2), array("a", "b") );
foreach ($twoD as $idx => $arr) {
   echo "Array no $idx \n";
   foreach ($arr as $k => $v) { echo "$k => $v" . "\n"; }
}

JavaScript - Arrow Functions

Arrow functions in JavaScript provide a shorter way to write anonymous functions. Introduced in ES6, they remove the need for the function keyword and allow cleaner syntax.

Syntax


const varName = (p1, p2, ...pN) => Expression;
      

const varName = (p1, p2, ...pN) => {
  // function body
};

Arrow Function with Single Statement


const add = (x, y) => x + y;
      

const add = (x, y) => { return x + y };
      

const divide = (x, y) => x / y;
document.getElementById("output").innerHTML = divide(10, 5);

Arrow Function with Multiple Statements


const divide = (x, y) => {
  let res = x / y;
  return res;
};
document.getElementById("output").innerHTML = divide(10, 5);

Arrow Functions Without Parameters


const greet = () => "Hello World!";
      

const greet = () => { return "Hello World!"; };

Hello World!

Arrow Function with Parameters

Single Parameter


const divide = x => 20 / x;
let res = divide(2);
document.getElementById("output").innerHTML = 
  "The value returned from the arrow function is: " + res;

The value returned from the arrow function is: 10

Multiple Parameters


const sum = (a, b, c, d) => {
  let sum = a + b + c + d;
  return sum;
};
let res = sum(10, 30, 45, 60);
document.getElementById("output").innerHTML = 
  "The sum of 10, 30, 45, and 60 is: " + res;

The sum of 10, 30, 45, and 60 is: 145

Arrow Function as an Expression


let isMul = true;
const func = isMul ? () => {
  let res = 5 * 5;
  document.getElementById("output").innerHTML += 
    "The multiplication value is: " + res + "
";
} : () => {
  let res = 5 + 5;
  document.getElementById("output").innerHTML += 
    "The sum value is: " + res + "
";
};

func();

The multiplication value is: 25

Arrow Function with Default Parameters


const mul = (a = 10, b = 15) => a * b;

document.getElementById("output").innerHTML += "mul(5, 8) = " + mul(5, 8) + "
";
document.getElementById("output").innerHTML += "mul(6) = " + mul(6) + "
";
document.getElementById("output").innerHTML += "mul() = " + mul() + "
";

mul(5, 8) = 40

mul(6) = 90

mul() = 150

Benefits of Using Arrow Functions

  • Shorter syntax − Reduces the amount of code needed to define functions.
  • Implicit return − Allows returning values directly without using the return keyword.
  • Ease of use as expression − Can be easily assigned and used in expressions.

Limitations of Using Arrow Functions

  • No arguments − Arrow functions do not have their own arguments object.
  • No prototype − Arrow functions cannot have a prototype property.
  • No new keyword − Arrow functions cannot be used as constructors.

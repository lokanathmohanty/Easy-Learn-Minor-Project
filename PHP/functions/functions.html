PHP Functions

A **function** in PHP is a self-contained, organized block of **reusable code** designed to perform a specific, single task. Functions promote **modularity** by breaking a large application into smaller, manageable parts, making code easier to read, maintain, and develop.

Types of Functions

  • **Built-in Functions:** Functions provided by the PHP core library (e.g., `strlen()`, `count()`, `array_search()`). PHP has over a thousand built-in functions.
  • **User-defined Functions:** Functions created by the programmer to meet specific application requirements.

Creating a User-Defined Function

Functions are defined using the **`function`** keyword, followed by a unique name, parentheses, and a block of statements enclosed in curly braces.

**General Syntax:**
function **functionName**($arg_1, $arg_2) {
   statements;
   return $retval; // Optional: sends a result back to the caller
}

Simple Creation Example

A basic function that performs an action (printing a message) without taking arguments or returning a value.

<?php
   function **writeMessage**() {
      echo "You are really a nice person, Have a nice time!";
   }
?>

Calling a Function

A function is not executed automatically; it must be explicitly **called** using its name followed by parentheses and a semicolon.

<?php
   /* Function definition goes here... */
   **writeMessage();** // Function Call
?>

Output: You are really a nice person, Have a nice time!

Key Concepts in PHP Functions

  • **Parameters and Arguments:** Variables listed in the function definition (parameters) that receive data when the function is called (arguments).
  • **Return Values:** The **`return`** statement sends a result back to the calling code and terminates the function's execution. It is optional; functions without `return` implicitly return `NULL`.
  • **Variable Scope:** Variables defined inside a function are **local** to that function. To access a global variable from inside a function, you must use the **`global`** keyword.
  • **Type Declarations:** PHP allows you to enforce the expected data types for arguments and return values (e.g., `int`, `string`, `array`).
  • **Passing by Reference:** Using the ampersand **`&`** before a parameter allows the function to modify the original variable instead of working on a copy.

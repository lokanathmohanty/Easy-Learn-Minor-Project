Node.js - Express Framework

Overview

Express.js is a minimal, flexible web framework for Node.js, providing robust features for web and mobile application development. It simplifies handling HTTP requests, routing, templating, and connecting with databases.

While Node.js has a built-in asynchronous http server, Express abstracts low-level HTTP request/response handling, letting developers focus on application logic.

Installing Express

npm init
npm install express --save

Installs Express locally and creates required project files.

Hello World Example

var express = require('express');
var app = express();

app.get('/', function (req, res) {
  res.send('Hello World');
});

var server = app.listen(5000, function () {
  console.log("Express App running at http://127.0.0.1:5000/");
});

Run with node index.js and visit http://localhost:5000/ to see "Hello World".

Application Object

The app object created by Express handles HTTP requests, renders views, and configures middleware.

The app.listen() method encapsulates Node.js’s http.createServer() to start a web server.

Basic Routing

Express supports asynchronous HTTP methods:

  • app.get(path, callback)
  • app.post(path, callback)
  • app.put(path, callback)
  • app.delete(path, callback)

Callback functions receive request and response objects. The send() method sends responses.

Serve HTML with sendFile()

var express = require('express');
var app = express();
var path = require('path');

app.get('/', function (req, res) {
  res.sendFile(path.join(__dirname, "index.html"));
});

var server = app.listen(5000, function () {
  console.log("Express App running at http://127.0.0.1:5000/");
});

Example index.html:

<html>
<body>
  <h2 style="text-align: center;">Hello World</h2>
</body>
</html>

Handling GET Form Data

HTML form submits data via GET to /process_get:

<form action="/process_get" method="GET">
  First Name: <input type="text" name="first_name"> <br>
  Last Name: <input type="text" name="last_name"> <br>
  <input type="submit" value="Submit">
</form>

Express route:

app.get('/process_get', function (req, res) {
  var response = {
    first_name: req.query.first_name,
    last_name: req.query.last_name
  };
  console.log(response);
  res.end(JSON.stringify(response));
});

Handling POST Form Data

Use body-parser middleware for URL-encoded POST data. 

npm install body-parser --save

var bodyParser = require('body-parser');
var urlencodedParser = bodyParser.urlencoded({ extended: false });

app.post('/process_post', urlencodedParser, function (req, res) {
  var response = {
    first_name: req.body.first_name,
    last_name: req.body.last_name
  };
  console.log(response);
  res.end(JSON.stringify(response));
});

Serve Static Files

Express middleware to serve static files (images, CSS, JS):

app.use(express.static('public'));

Place static assets like images in public/images/. For example, you can access public/images/logo.png at http://localhost:5000/images/logo.png.

Run the App

node index.js

Access http://127.0.0.1:5000/ in a browser to see the app.

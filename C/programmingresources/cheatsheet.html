C Language Cheatsheet

Basic Syntax

  • Program starts from int main() function
  • Statements end with a semicolon ;
  • Comments: // single-line, /* multi-line */

Data Types

  • int: Integer numbers
  • float: Floating-point numbers
  • double: Double precision float
  • char: Single character
  • void: No type / no return

Variables

  • Declaration: int x;
  • Initialization: int y = 10;
  • Constants: const int z = 5;

Operators

  • Arithmetic: +, -, *, /, %
  • Assignment: =, +=, -=
  • Comparison: ==, !=, <, >, <=, >=
  • Logical: &&, ||, !

Control Flow

  • if (condition) { ... }
  • if (condition) { ... } else { ... }
  • switch (variable) { case x: ... break; ... }
  • for (init; condition; increment) { ... }
  • while (condition) { ... }
  • do { ... } while (condition);

Functions

  • Declaration: return_type function_name(parameters);
  • Definition: 
    return_type function_name(parameters) {
    // function body
}
  • Example: 
    int add(int a, int b) {
    return a + b;
}

Arrays

  • Declaration: int arr[10];
  • Initialization: int arr[] = {1, 2, 3};
  • Access: arr[0] (first element)

Pointers

  • Declaration: int *p;
  • Assign address: p = &variable;
  • Dereference: *p (value at pointer)

Input / Output

  • Print: printf("Format", variables);
  • Scan: scanf("Format", &variables);
  • Format specifiers: %d (int), %f (float), %c (char), %s (string)

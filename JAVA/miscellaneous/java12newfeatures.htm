Java 12 - New Features Summary (Non-LTS Release)

Overview of Java 12

**Java 12**, released in **March 2019**, followed Java's 6-month release cadence and is a **non-LTS (Long-Term Support)** feature release. It focused on introducing preview features and several minor but highly useful API additions and performance enhancements.

Key API and Language Features

1. Switch Expressions (Preview)

Java 12 introduced a **preview** of enhanced **switch** statements (JEP 325) that can be used as an **expression**. This allows switch blocks to produce a value, eliminating the need for break statements and resulting in more compact and less error-prone code.

  • New Syntax: Uses the **arrow (->)** syntax for cleaner case labels.
  • Result as Value: The result of the selected case is the value of the entire switch expression.
// Example of Switch Expression in Java 12 (Preview)
int numLetters = switch (day) {
    case MONDAY, FRIDAY, SUNDAY -> 6;
    case TUESDAY                -> 7;
    case THURSDAY, SATURDAY     -> 8;
    case WEDNESDAY              -> 9;
};

2. File.mismatch() Method

A new utility method was added to **java.io.File** that efficiently compares two files. It returns the position of the first mismatching byte, or -1L if the files are identical. This simplifies file comparison operations.

3. Compact Number Formatting

New formatting styles were added to the **java.text.NumberFormat** class to produce human-readable, abbreviated strings for large numbers, useful for UI displays.

  • Example: Formatting 2000 as "2K" or 3000000 as "3M", based on the locale.

4. Teeing Collector in Stream API

The **Collectors** class gained the static factory method **teeing()**. This collector is a powerful tool that allows the results of a stream to be processed by **two different collectors simultaneously**, and then the results of those two collectors are merged by a final **BiFunction**.

// Example: Find both Min and Max in a single stream pass
stream.collect(Collectors.teeing(
    Collectors.minBy(...), // Collector 1
    Collectors.maxBy(...), // Collector 2
    (min, max) -> ...      // BiFunction to merge results
));

5. New String Methods

Four new formatting methods were added to the **String** class:

  • **indent(int n):** Indents the string by n spaces (positive n indents, negative n removes leading spaces if possible).
  • **transform(Function):** Applies a function to the string and returns the result, facilitating method chaining on a string value.

JVM and Garbage Collection

  • Shenandoah GC (JEP 189): Introduced as an experimental, low-pause-time garbage collector. Shenandoah works concurrently with the running Java application to minimize pause times, especially on large heaps.
  • G1 Garbage Collector Enhancements (JEP 344): The G1 collector gained the ability to automatically **abort a mixed garbage collection cycle** if the evacuation pause time budget is likely to be exceeded, improving reliability and responsiveness.

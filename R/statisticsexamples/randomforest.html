R - Random Forest

Random Forest creates multiple decision trees and uses majority voting on the output of these trees to classify observations. It improves accuracy and reduces overfitting compared to a single decision tree. The error rate for cases not used in training is called the Out-of-Bag (OOB) error estimate.

The R package randomForest is used to build and analyze random forest models.

Install Package

install.packages("randomForest")

Basic Syntax

randomForest(formula, data)

- formula: Specifies predictor and response variables.
- data: Name of the data frame.

Example

# Load necessary packages
library(party)
library(randomForest)

# Load sample data
print(head(readingSkills))

# Create random forest model
output.forest <- randomForest(nativeSpeaker ~ age + shoeSize + score, data = readingSkills)

# View random forest model summary
print(output.forest)

# Show importance of predictors
print(importance(output.forest, type = 2))

Python - Class Attributes

Attributes are properties or variables defined inside a class. They provide information about the data a class contains. There are two types of attributes in Python: instance attributes and class attributes.

Class Attributes (Variables)

Class attributes belong to the class itself and are shared by all instances of the class. They are defined inside the class but outside any method, typically outside the __init__() constructor. Class attributes can be accessed using the class name or objects.

Example: Accessing Class Attributes

class Employee:
    name = "Bhavesh Aggarwal"
    age = "30"

emp = Employee()
print("Name of the Employee:", emp.name)
print("Age of the Employee:", emp.age)

Output:
Name of the Employee: Bhavesh Aggarwal
Age of the Employee: 30

Modifying Class Attributes

You can modify a class attribute by assigning a new value using the class name and dot notation. For example, incrementing a count of employees:

class Employee:
    empCount = 0

    def __init__(self, name, age):
        self.__name = name
        self.__age = age
        Employee.empCount += 1
        print("Name:", self.__name, ", Age: ", self.__age)
        print("Employee Count:", Employee.empCount)

e1 = Employee("Bhavana", 24)
print()
e2 = Employee("Rajesh", 26)

Output:
Name: Bhavana , Age: 24
Employee Count: 1

Name: Rajesh , Age: 26
Employee Count: 2

Significance of Class Attributes

  • Define properties that should have the same value for all objects.
  • Set default values for instances.
  • Useful for creating singletons used across code.

Built-in Class Attributes

Python classes also have built-in attributes accessible via dot notation:

  • __dict__: Dictionary containing the class namespace.
  • __doc__: Class documentation string or None if undefined.
  • __name__: Class name.
  • __module__: Module name in which the class is defined.
  • __bases__: Tuple containing base classes.

Example: Accessing Built-In Class Attributes

class Employee:
    def __init__(self, name="Bhavana", age=24):
        self.name = name
        self.age = age

    def displayEmployee(self):
        print("Name : ", self.name, ", age: ", self.age)

print("Employee.__doc__:", Employee.__doc__)
print("Employee.__name__:", Employee.__name__)
print("Employee.__module__:", Employee.__module__)
print("Employee.__bases__:", Employee.__bases__)
print("Employee.__dict__:", Employee.__dict__)

Output:
Employee.__doc__: None
Employee.__name__: Employee
Employee.__module__: __main__
Employee.__bases__: (<class 'object'>,)
Employee.__dict__: {'__module__': '__main__', '__init__': <function Employee.__init__ at 0x...>, 'displayEmployee': <function Employee.displayEmployee at 0x...>, '__dict__': <attribute '__dict__' of 'Employee' objects>, '__weakref__': <attribute '__weakref__' of 'Employee' objects>, '__doc__': None}

Instance Attributes

Instance attributes are defined inside the constructor __init__() and are specific to each object instance. They are accessed and modified using the self parameter.

Example: Instance Attributes

class Student:
    def __init__(self, name, grade):
        self.__name = name
        self.__grade = grade
        print("Name:", self.__name, ", Grade:", self.__grade)

student1 = Student("Ram", "B")
student2 = Student("Shyam", "C")

Output:
Name: Ram , Grade: B
Name: Shyam , Grade: C

Instance vs Class Attributes

S.No. Instance Attribute Class Attribute
1 Defined inside __init__() constructor method. Defined inside class but outside __init__().
2 Unique to each object instance. Shared by all instances of the class.
3 Accessed via object name and dot notation. Accessed via class name or object name.
4 Modifications affect only that specific object instance. Modifications affect all instances.

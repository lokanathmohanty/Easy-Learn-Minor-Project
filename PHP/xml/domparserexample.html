PHP - DOM Parser Example ($\text{DOMDocument}$)

Document Object Model (DOM) Parser

The **DOM extension** in PHP provides powerful functionality for handling both $\text{XML}$ and $\text{HTML}$ documents. The **$\text{DOMDocument}$ class** is a key component; it represents the entire document and serves as the **root of the document tree**. Unlike event-based parsers ($\text{SAX}$), the $\text{DOM}$ parser loads the entire document into memory, allowing full access, navigation, and modification of the document's structure.

Key $\text{DOMDocument}$ Methods

The $\text{DOMDocument}$ class offers static methods to create, load, and save documents:

  • **Loading:** $\text{load()}$ ($\text{XML}$ file), $\text{loadXML()}$ ($\text{XML}$ string), $\text{loadHTMLFile()}$ ($\text{HTML}$ file), $\text{loadHTML()}$ ($\text{HTML}$ string).
  • **Saving:** $\text{save()}$, $\text{saveXML()}$, $\text{saveHTML()}$, $\text{saveHTMLFile()}$.
  • **Navigation/Search:** $\text{getElementById()}$, **$\text{getElementsByTagName()}$** (used extensively for structured parsing).
  • **Creation:** $\text{createElement()}$, $\text{createAttribute()}$, $\text{createTextNode()}$ (used for dynamically building a document).

Example: Parsing an HTML Table with $\text{DOMDocument}$

PHP Parsing Logic

The following PHP code demonstrates how to use the $\text{DOMDocument}$ class to load an $\text{HTML}$ file ($\text{hello.html}$) and traverse its table structure to extract the data row by row.

<?php 
   // Create a new DOMDocument object
   $dom = new domDocument; 

   // Load HTML content from a file
   $dom->loadHTMLFile("hello.html");

   // Set to false to avoid treating whitespace between tags as nodes
   $dom->preserveWhiteSpace = false; 

   // 1. Get all <table> tags
   $tables = $dom->getElementsByTagName('table'); 

   // Get all <tr> tags from the first table
   $rows = $tables[0]->getElementsByTagName('tr'); 

   // 2. Loop over each row (<tr>)
   foreach ($rows as $row) {
      // 3. Get all <td> tags within the current row
      $cols = $row->getElementsByTagName('td'); 

      // Extract and echo the nodeValue for specific column indices
      echo 'Designation: '.$cols->item(0)->nodeValue.'<br />'; 
      echo 'Manager: '.$cols->item(1)->nodeValue.'<br />'; 
      echo 'Team: '.$cols->item(2)->nodeValue; 
      echo '<hr />'; 
   }
?>

This approach effectively iterates through the $\text{DOM}$ tree by finding elements by tag name, demonstrating the parser's ability to easily navigate and extract data from complex structures like $\text{HTML}$ tables.

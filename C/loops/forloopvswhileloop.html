For Loop vs While Loop in C

Loops are a fundamental concept in programming. They allow developers to execute a block of code multiple times without rewriting it. Among the commonly used loops, for and while loops are the most widely used in C. Both serve iteration purposes but differ in syntax, control flow, and use-cases.

This guide explains the difference between for and while loops using examples and comparisons.

What is a for Loop?

The for loop is used when the number of iterations is known in advance. It contains three parts: initialization, condition, and update (increment or decrement).

for(initialization; condition; update) {
   // Code to execute
}

Example: Print Numbers from 1 to 5 Using for Loop

#include <stdio.h>

int main() {
   for(int i = 1; i <= 5; i++) {
      printf("%d\n", i);
   }
   return 0;
}

What is a while Loop?

The while loop is ideal when the number of iterations is unknown. It keeps executing until a specified condition becomes false.

while(condition){
   // code to execute
}

Example: Print Numbers from 1 to 5 Using while Loop

#include <stdio.h>

int main() {
   int i = 1;
   while(i <= 5) {
      printf("%d\n", i);
      i++;
   }
   return 0;
}

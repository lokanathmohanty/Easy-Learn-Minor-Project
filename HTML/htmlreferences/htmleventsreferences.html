HTML - Events Reference

When users interact with your website, they generate events such as clicks, mouse movements, keystrokes, and more. These events can be handled using JavaScript or VBScript by writing event handlers. In HTML, events are specified as attributes inside elements.

Window Events

Event Description
onafterprintTriggers after a document is printed
onbeforeprintTriggers before a document is printed
onbeforeunloadTriggers before a document unloads
onerrorTriggers when an error occurs
onhashchangeTriggers when the URL hash changes
onloadTriggers when a document loads
onofflineTriggers when the document goes offline
ononlineTriggers when the document comes online
onpagehideTriggers when a window is hidden
onpageshowTriggers when a window becomes visible
onresizeTriggers when a window is resized
onunloadTriggers when a user leaves the document

Form Events

Event Description
onblurTriggers when an element loses focus
onchangeTriggers when the value of an element changes
oncontextmenuTriggers when a context menu is opened
onfocusTriggers when an element gets focus
oninputTriggers when an element receives user input
oninvalidTriggers when an element is invalid
onresetTriggers when a form is reset
onsearchTriggers when a user performs a search in a search field
onselectTriggers when text is selected
onsubmitTriggers when a form is submitted

Keyboard Events

Event Description
onkeydownTriggers when a key is pressed
onkeyupTriggers when a key is released

Mouse Events

Event Description
onclickTriggers when an element is clicked
ondblclickTriggers when an element is double-clicked
onmousedownTriggers when a mouse button is pressed
onmousemoveTriggers when the mouse pointer moves
onmouseoutTriggers when the pointer leaves an element
onmouseoverTriggers when the pointer enters an element
onmouseupTriggers when a mouse button is released
onwheelTriggers when the mouse wheel is used

Drag Events

Event Description
ondragTriggers while an element is being dragged
ondragendTriggers at the end of a drag operation
ondragenterTriggers when an element enters a drop target
ondragleaveTriggers when an element leaves a drop target
ondragoverTriggers when an element is dragged over a target
ondragstartTriggers at the start of a drag operation
ondropTriggers when an element is dropped
onscrollTriggers when an element is scrolled

Clipboard Events

Event Description
oncopyTriggers when content is copied
oncutTriggers when content is cut
onpasteTriggers when content is pasted

Media Events

Event Description
ondurationchangeTriggers when the media duration changes
onendedTriggers when media playback ends
onerrorTriggers when an error occurs
onloadeddataTriggers when media data is loaded
onloadedmetadataTriggers when media metadata is loaded
onloadstartTriggers when media starts loading
onpauseTriggers when media is paused
onplayTriggers when media begins playing
onplayingTriggers when media is playing
onprogressTriggers when browser fetches media data
onratechangeTriggers when playback rate changes
onseekedTriggers when a seek operation ends
onseekingTriggers when a seek operation starts
onstalledTriggers when fetching media data fails
onsuspendTriggers when fetching media is paused
ontimeupdateTriggers when playback position updates
onvolumechangeTriggers when volume changes
onwaitingTriggers when playback is waiting to resume

Misc Events

Event Description
ontoggleTriggers when a details element is toggled

Java - The String Class

The String Object in Java

In Java, **Strings** are sequences of characters treated as **objects**. The Java platform provides the built-in **String class** (in java.lang) for creating and manipulating these sequences.

Key Concept: Immutability 🧱

The most important characteristic of the String class is that its objects are **immutable**. Once a String object is created, its value cannot be changed. Any operation that appears to modify a string (like concatenation or replacement) actually creates and returns a **new String object**.

If frequent modifications to character sequences are necessary, the **StringBuffer** or **StringBuilder** classes should be used instead, as they represent mutable character sequences.

Creating Strings

There are two primary ways to create a String object:

  1. Using a Literal: This is the most common and direct way. The compiler optimizes string literals by storing them in the **String Constant Pool** (a special area in the heap). 
    String greeting = "Hello world!";
  2. Using the new keyword: This forces the creation of a new object in the standard heap memory, even if the same string literal already exists in the String Constant Pool. 
    String helloString = new String(charArray);

Common String Operations

1. Length and Character Access

  • length(): An accessor method that returns the number of characters in the string.
  • charAt(int index): Returns the char value at the specified zero-based index.

2. Concatenating Strings

Strings can be concatenated (joined) using two methods:

  • The + operator: The most common and simple way. It works not just with other strings, but also with other data types (which are implicitly converted to a string). 
    "Hello, " + "world" + "!";
  • The concat(String str) method: Returns a new string that is the result of appending the specified string to the end of the original.

3. Comparison Methods

  • equals(Object anObject): Compares the string's content to the specified object. **Always use equals() to compare content.**
  • equalsIgnoreCase(String anotherString): Compares content while ignoring case differences.
  • compareTo(String anotherString): Performs a **lexicographical** comparison (based on Unicode values) and returns an integer indicating if the string is less than, equal to, or greater than the argument.

4. Formatting Strings

The static **String.format()** method allows you to create a reusable formatted string, similar to System.out.printf(), but returns a String object instead of printing directly.

String fs = String.format("The value is %f", floatVar);

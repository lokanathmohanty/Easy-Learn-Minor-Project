JavaScript - DOM Methods & Properties

In JavaScript, DOM methods are used to perform a particular action on HTML elements. The DOM represents an HTML document as a logical tree where each node contains objects. DOM methods allow programmatic access to this tree to change document structure, style, or content.

For example, you can use DOM methods to access HTML elements by id, attribute, tag name, or class name, add events to the document, or dynamically insert and remove elements.

Syntax

General syntax for executing a DOM method:

window.document.methodName();
OR
document.methodName();

Common DOM Methods

document.getElementById()

This method retrieves an element by its id attribute. 

const ele = document.getElementById("id");

Example

<button onclick="accessEle()">Access output and write</button>
<p id="output"></p>

<script>
  function accessEle() {
    document.getElementById("output").innerHTML = 
      "Hello User! You have just clicked the button!";
  }
</script>

document.addEventListener()

Adds an event listener to the document or element. 

document.addEventListener('mouseover', function () {
  // Perform action
});

Example

<h3>JavaScript document.addEventListener() Method</h3>
<p>Hover over here to change background color</p>

<script>
  document.addEventListener('mouseover', function () {
    document.body.style.backgroundColor = 'red';
  });
</script>

document.write()

The document.write() method writes HTML directly into the document. It replaces existing content if executed after the page loads. 

document.write("<p>Hello Users!</p>");

Example

<button onclick="writeText()">Add HTML</button>

<script>
  function writeText() {
    document.write("<p>Text written using document.write() method.</p>");
  }
</script>

List of DOM Methods

Some commonly used DOM methods include:

  • setAttribute() – Define or modify attributes of an element.
  • querySelector() – Select the first element matching a CSS selector.
  • querySelectorAll() – Select all elements matching a CSS selector.
  • remove() – Remove an element from the DOM.
  • appendChild() – Add a new child node to an element.
  • createElement() – Create a new HTML element.
  • addEventListener() – Attach an event listener to an element.
  • getElementsByClassName() – Access elements by class name.
  • getElementsByTagName() – Access elements by tag name.

List of DOM Properties

DOM properties provide information about elements or allow updates to them.

  • innerHTML – Get or set the HTML inside an element.
  • innerText – Get or set the visible text of an element.
  • style – Access inline styles of an element.
  • id – Access or modify the element’s ID.
  • classList – Access classes applied to an element.
  • parentElement – Access an element’s parent in the DOM tree.
  • children – Retrieve child elements of a node.
  • checked – Check or uncheck form inputs.
  • value – Get or set the value of form fields.
  • href – Access or update links (<a>).

These methods and properties together allow JavaScript to fully interact with and manipulate HTML documents.

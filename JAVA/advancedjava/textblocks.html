Java Text Blocks (Java 15+)

The Purpose of Text Blocks

Text Blocks, introduced as a standard feature in **Java 15**, provide a clean, simple way to represent **multi-line strings** in Java code. They are primarily intended for easily embedding code snippets, **JSON, XML, SQL, or HTML** without requiring cumbersome escape sequences, string concatenation, or explicit line terminators (like \n or \r\n).

Text Block Syntax

A text block is demarcated by three double-quote characters ("""), which must be followed immediately by a new line. The content is written as-is, and the block is closed by three double-quote characters on a separate line.

Syntax:

String json = """
{
    "key": "value",
    "id": 123
}
""";

The key benefits are clarity and reduced clutter compared to the old way:

// Old way: messy, error-prone, hard to read
String json = "{\n" +
              "    \"key\": \"value\",\n" +
              "    \"id\": 123\n" +
              "}";

Text Blocks are Still String Objects

Crucially, a text block is compiled into a regular **java.lang.String** object. This means:

  • They can be compared using equals().
  • They support all standard String methods (length(), contains(), indexOf(), etc.).
  • They support new, specialized methods designed to manage indentation and formatting.

Handling Incidental Whitespace (Indentation)

The compiler is smart about handling the indentation necessary to align the text block in your Java code:

  • The **incidental whitespace** (the shortest margin of white space from the left) is automatically stripped by the compiler to produce a clean string.
  • The **essential whitespace** (internal indentation) is preserved.

New String Methods for Text Blocks

  • String.stripIndent(): Programmatically removes the incidental white space, matching the compiler's behavior.
  • String.translateEscapes(): Translates traditional escape sequences (like \n or \t) if they appear within the block.
  • String.formatted(Object... args): A convenient way to format the text block content, similar to String.format().

Example: Using .formatted() for Dynamic Content

This shows how to easily inject variables into a template-like text block using the formatted() method:

public class APITester {
    public static void main(String[] args) {
        String template = """
            <user>
                <name>%s</name>
                <role>%s</role>
            </user>
            """.formatted("Robert", "Developer"); // Using String.formatted()

        System.out.println(template);
    }
}

Output:

<user>
    <name>Robert</name>
    <role>Developer</role>
</user>

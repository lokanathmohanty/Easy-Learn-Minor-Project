Essential PHP Array Functions

**PHP Array Functions** are a powerful set of built-in tools used to create, modify, sort, filter, and search through arrays. They are part of the PHP core, requiring no special installation.

Top Functions by Category

1. Creation and Merging

Function Description
**`array()` / `[]`** The primary way to **create an array**.
**`range()`** Creates an array containing a sequence of elements (e.g., numbers from 1 to 10).
**`array_combine()`** Creates an array using one array for **keys** and another for its **values**.
**`array_merge()`** **Merges one or more arrays** into a single new array.
**`array_fill()`** Fills an array with a specified value for a specified number of entries.

2. Adding and Removing Elements (Queue/Stack Operations)

Function Description
**`array_push()`** Inserts one or more elements to the **end** of an array (stack push).
**`array_pop()`** **Deletes and returns** the element from the **end** of an array (stack pop).
**`array_unshift()`** Adds one or more elements to the **beginning** of an array.
**`array_shift()`** **Removes and returns** the first element from the **beginning** of an array.

3. Counting and Existence Checks

Function Description
**`count()` / `sizeof()`** **Counts** the number of elements in an array.
**`in_array()`** Checks if a specified **value** exists in an array.
**`array_key_exists()`** Checks if the specified **key** exists in the array.
**`array_keys()`** Returns all the **keys** of an array.
**`array_values()`** Returns all the **values** of an array (as a new indexed array).

4. Sorting and Ordering

Function Description
**`sort()`** Sorts an array by **value** (ascending), resetting keys (indexed sort).
**`rsort()`** Sorts an array by **value** in **reverse** order, resetting keys.
**`asort()`** Sorts an array by **value** (ascending), **maintaining key association** (for associative arrays).
**`ksort()`** Sorts an array by **key** (ascending).
**`usort()`** Sorts an array by **value** using a **user-defined function**.

5. Comparisons and Filtering

Function Description
**`array_diff()`** Compares array **values**, returning entries in the first array that are not present in any other arrays.
**`array_intersect()`** Compares array **values**, returning all matches.
**`array_filter()`** **Filters** elements of an array using a **user-defined callback function**.
**`array_unique()`** Removes **duplicate values** from an array.

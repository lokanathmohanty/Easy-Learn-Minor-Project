Next.js Shallow Routing 🏷️

What is Shallow Routing?

**Shallow routing** is a Next.js technique that allows you to **update the URL** (specifically the query parameters or hash) without triggering a full page reload or re-executing data fetching methods like `getServerSideProps`, `getStaticProps`, or `getInitialProps`.

This method modifies the route state in the browser history while **maintaining the current page's component state and context**, offering a way to update the URL dynamically without disrupting the user experience or incurring performance penalties.

Implementing Shallow Routing

Shallow routing is implemented using the **`useRouter`** hook on a Client Component. You enable it by passing the **`shallow: true`** option in the options object of the `router.push()` or `router.replace()` methods.

Example: Updating URL Query Parameter

In this example, clicking the button updates the local `step` state and simultaneously updates the URL's query parameter (e.g., changing from `/shallow-routing?step=1` to `/shallow-routing?step=2`) without rerunning server-side data logic.

// 'use client'
import { useRouter } from 'next/navigation';
import { useState } from 'react';

export default function ShallowRoutingExample() {
  const router = useRouter();
  const [step, setStep] = useState(1);

  const handleRouteChange = () => {
    const nextStep = step + 1;
    setStep(nextStep); // Update UI state

    // Updates the URL's 'step' query param without reloading the page
    router.push(`/shallow-routing?step=${nextStep}`, { shallow: true });
  };
  // ... returns button with onClick={handleRouteChange}
}

Benefits of Shallow Routing

  • **Preserves State:** The component's current React state (e.g., form input, scroll position) is fully maintained during the URL update.
  • **Performance Boost:** Avoids unnecessary **full page reloads** and prevents costly **data refetching** functions from being re-executed.
  • **Enhanced UX:** Allows dynamic modifications of the URL (useful for filtering, tabs, or pagination state) without interrupting the user's flow.

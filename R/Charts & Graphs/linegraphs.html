R - Line Graphs

A line chart connects a series of data points with line segments, often to identify trends over time or another ordered variable. In R, line graphs are created using the plot() function with customizable styles and multiple lines on the same plot.

Basic Syntax

plot(v, type, col, xlab, ylab, main)
  • v: Numeric vector for Y-axis values
  • type: "p" (points only), "l" (lines only), "o" (both)
  • xlab: X-axis label
  • ylab: Y-axis label
  • main: Title of the chart
  • col: Color for points/lines

Simple Line Chart Example

# Data for the chart
v <- c(7, 12, 28, 3, 41)

png(file = "line_chart.jpg")
plot(v, type = "o")
dev.off()

Add Title, Color, and Labels

v <- c(7, 12, 28, 3, 41)

png(file = "line_chart_label_colored.jpg")
plot(v, type = "o", col = "red", xlab = "Month", ylab = "Rain fall", main = "Rain fall chart")
dev.off()

Multiple Lines on One Chart

v <- c(7, 12, 28, 3, 41)
t <- c(14, 7, 6, 19, 3)

png(file = "line_chart_2_lines.jpg")
plot(v, type = "o", col = "red", xlab = "Month", ylab = "Rain fall", main = "Rain fall chart")
lines(t, type = "o", col = "blue")
dev.off()

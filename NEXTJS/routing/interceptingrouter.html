Next.js Intercepting Routes 🖼️

What are Intercepting Routes?

**Intercepting Routes** are a feature in the Next.js App Router (v13+) that allows you to load a route's content (UI) within the context of the **current layout**, without fully navigating away from the parent page. This is primarily used to create seamless **overlay experiences**, such as displaying a **modal** or a pop-up, while the original page remains visible in the background.

Example Use Case: Photo Gallery

On a gallery page (`/gallery`) with thumbnails, clicking a thumbnail navigates to the image's URL (e.g., `/gallery/123`). If the navigation is intercepted, the full image will appear in a modal *over* the gallery, but if the user navigates directly to `/gallery/123`, they see the full image on a separate, dedicated page.

How Intercepting Routes Work

Intercepting routes rely on a special file naming convention that tells Next.js to render a different UI when navigating *from* a specific parent route.

Route Naming Convention (App Router):

The syntax uses parentheses and dots to indicate the segment level being intercepted:

  • `(.)[segment]`: Intercepts a route at the **same level** of the current segment. (e.g., from `/gallery` to `/gallery/[id]`)
  • `(..)[segment]`: Intercepts a route **one level above**.
  • `(..)(..)[segment]`: Intercepts a route **two levels above**.
  • `(...)segment`: Intercepts a route from the **root** `/app` directory.

The Overlay Experience:

When an interception occurs, the UI defined in the special file (e.g., `app/gallery/(.)[id]/page.js`) is rendered instead of the dedicated route file (`app/gallery/[id]/page.js`). The intercepted content is often styled to be a modal using CSS.

Implementation Example Structure

Consider the structure for the photo gallery:

app/
  gallery/
    page.js           // Base Gallery UI (e.g., /gallery)
    [id]/
      page.js         // Dedicated Full Photo Page
    (.)[id]/
      page.js         // ← INTERCEPTED ROUTE (Modal UI)
User Action URL File Rendered Behavior
Direct URL access `/gallery/123` `gallery/[id]/page.js` Full page load of the photo.
Clicking a link from `/gallery` `/gallery/123` `gallery/(.)[id]/page.js` Photo is displayed as a modal over the gallery page.

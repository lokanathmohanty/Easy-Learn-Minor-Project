JavaScript - Logical Operators

The logical operators in JavaScript are generally used with Boolean operands and return a boolean value. There are mainly three types of logical operators in JavaScript - && (AND), || (OR), and ! (NOT). These operators are used to control the flow of the program.

Although the logical operators are typically used with Boolean values, they can be used with any type. Non-boolean values are converted into their boolean equivalents. The falsy values are: false, null, undefined, 0, "", and NaN. All other values are treated as truthy.

The && and || operators return the value of one of the operands based on conditions. The ! operator always returns a Boolean value.

Logical Operators with Examples

  • && (Logical AND) → (x && y) is false if x = true and y = false.
  • || (Logical OR) → (x || y) is true if x = true and y = false.
  • ! (Logical NOT) → !(x) is false if x = true.

JavaScript Logical AND (&&) Operator

The logical AND (&&) operator evaluates operands from left to right. If the first operand is falsy, it returns the first operand. Otherwise, it returns the second operand.

Examples with Boolean values:

  • true && true → true
  • true && false → false
  • false && true → false
  • false && false → false

Examples with numbers:

  • 0 && 10 → 0
  • 10 && 20 → 20
  • 20 && 0 → 0

Examples with strings:

  • '' && 'Hello' → '' (empty string)
  • 'Hello' && 'World' → World

JavaScript Logical OR (||) Operator

The logical OR (||) operator evaluates operands from left to right. If the first operand is truthy, it returns the first operand. Otherwise, it returns the second operand.

Examples with Boolean values:

  • true || true → true
  • true || false → true
  • false || true → true
  • false || false → false

Examples with numbers:

  • 0 || 10 → 10
  • 10 || 20 → 10
  • 20 || 0 → 20

Examples with strings:

  • '' || 'Hello' → Hello
  • 'Hello' || 'World' → Hello

JavaScript Logical NOT (!) Operator

The logical NOT (!) operator is unary. It converts its operand to boolean and returns the opposite.

Examples:

  • !true → false
  • !false → true
  • !0 → true
  • !20 → false
  • !'Hello' → false

Logical Operators Precedence

When multiple logical operators appear in an expression, precedence rules apply:

  • ! (NOT) → highest precedence
  • && (AND) → next highest precedence
  • || (OR) → lowest precedence

Example: false || true && !false → true

Short Circuit Evaluation

JavaScript uses short-circuit evaluation for logical operators:

  • false && any_value → false (second operand not evaluated)
  • true || any_value → true (second operand not evaluated)

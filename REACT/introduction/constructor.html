ReactJS - Constructor

In JavaScript, the constructor method is used to set the initial values of a newly created object. In React class-based components, the constructor() serves the same purpose. It is mainly used for:

  • Initializing props
  • Initializing state
  • Binding event handlers

1. Initialization of Props

Props must be initialized using super(props) inside the constructor. If not properly initialized, this.props may not work correctly. 

class Welcome extends React.Component {
   constructor(props) {
      super(props);
   }
   render() {
      return (
         <div><h3>Welcome {this.props.name}</h3></div>
      )
   }
}

Usage:

function App() {
   return (
      <div className="container">
         <Welcome name="John" />
      </div>
   );
}

2. Initialization of State

State can also be initialized inside the constructor using this.state.

  • this.state = { key: value } → to initialize state
  • this.state.key → to access state
  • this.setState() → to update state
class Welcome extends React.Component {
   constructor(props) {
      super(props);
      this.state = {
         welcomeMessage: "Hello"
      }
   }
   render() {
      return (
         <div><h3>{this.state.welcomeMessage}, {this.props.name}</h3></div>
      )
   }
}

Usage:

function App() {
   return (
      <div className="container">
         <Welcome name="John" />
      </div>
   );
}

3. Event Binding

Event handlers must be bound to the component instance in the constructor to ensure this works correctly inside them. 

import React from "react";

class Welcome extends React.Component {
   constructor(props) {
      super(props);
      this.state = {
         welcomeMessage: "Hello"
      }
      this.changeMessageHandler = this.changeMessageHandler.bind(this);
   }

   changeMessageHandler() {
      this.setState(prevState => ({
         welcomeMessage: prevState.welcomeMessage === "Hello" ? "Welcome" : "Hello"
      }));
   }

   render() {
      return (
         <div>
            <h3>{this.state.welcomeMessage}, {this.props.name}</h3>
            <button onClick={this.changeMessageHandler}>Change welcome message</button>
         </div>
      );
   }
}
export default Welcome;

Usage:

function App() {
   return (
      <div className="container">
         <Welcome name="John" />
      </div>
   );
}

Steps for Event Binding

  • Add a button with an onClick event
  • Set the event handler method as the onClick function
  • Bind the method inside the constructor
  • Update state using this.setState()

Summary

The constructor() in React class components is essential for setting up the component correctly. It ensures that props, state, and event handlers are properly initialized before the component renders.

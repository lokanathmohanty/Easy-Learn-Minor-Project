JavaScript - DOM Elements

The HTML DOM (Document Object Model) elements represent the structure of a web page. With JavaScript, you can access and manipulate these elements using their id, name, tag name, class name, and more.

When a web page loads in the browser, it creates a DOM tree representing the structure of the page. JavaScript provides methods and properties to access, modify, or replace DOM elements dynamically.

Accessing DOM Elements

Get Element by ID

Use getElementById() to access an element by its unique id. 

document.getElementById('id');

Example:

<div id="output"></div>
<script>
  document.getElementById('output').innerHTML = "The element is accessed using the id.";
</script>

Get Elements by Name

Use getElementsByName() to access elements by their name attribute. Returns a NodeList. 

document.getElementsByName('name');

Example:

<div name="text">Hello World!</div>
<script>
  const divEle = document.getElementsByName('text');
  console.log(divEle[0].innerHTML);
</script>

Get Elements by Class Name

Use getElementsByClassName() to access elements by their class name. 

document.getElementsByClassName('className');

Example:

<div class="fruit">Apple</div>
<script>
  const divEle = document.getElementsByClassName('fruit');
  console.log(divEle[0].innerHTML);
</script>

Get Elements by Tag Name

Use getElementsByTagName() to access elements by their tag. 

document.getElementsByTagName('p');

Example:

<p>This is the first paragraph.</p>
<p>This is the second paragraph.</p>
<script>
  const paras = document.getElementsByTagName('p');
  console.log(paras[0].innerHTML);
  console.log(paras[1].innerHTML);
</script>

Modifying DOM Elements

Modify Content

Use textContent or innerHTML to update content of an element. 

element.textContent = "New Text";

Example:

<p id="text">Hello World!</p>
<script>
  document.getElementById("text").textContent = "This is updated text!";
</script>

Replace Child Element

Use replaceChild() to replace a child node. 

parent.replaceChild(newNode, oldNode);

Example:

<div id="text">
  <p>Hi Users!</p>
</div>
<script>
  let textDiv = document.getElementById("text");
  let newText = document.createTextNode("Hello World");
  textDiv.replaceChild(newText, textDiv.childNodes[1]);
</script>

Adding Events to DOM Elements

Use addEventListener() to add events. 

element.addEventListener(eventName, callback);

Example:

<div id="text">Click me</div>
<script>
  let text = document.getElementById("text");
  text.addEventListener("click", function () {
    console.log("You clicked on the div element");
  });
</script>

List of JavaScript DOM Element Methods

  • toString() – Converts element to string.
  • setAttribute() – Sets an attribute.
  • querySelector() – Returns first element matching selector.
  • querySelectorAll() – Returns all elements matching selector.
  • remove() – Removes element from DOM.
  • appendChild() – Adds a new child node.
  • replaceChild() – Replaces one child with another.
  • addEventListener() – Adds an event listener.
  • cloneNode() – Duplicates a node.
  • matches() – Tests if element matches a selector.

List of JavaScript DOM Element Properties

  • id – Gets/sets the element’s id.
  • className – Gets/sets class value.
  • classList – Returns collection of CSS classes.
  • innerHTML – Gets/sets HTML content.
  • textContent – Gets/sets text content.
  • outerHTML – Gets/sets full HTML including element itself.
  • tagName – Returns the tag name.
  • children – Returns child elements.
  • childElementCount – Number of child elements.
  • style – Access inline styles.

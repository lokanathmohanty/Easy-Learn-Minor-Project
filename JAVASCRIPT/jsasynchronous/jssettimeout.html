JavaScript - setTimeout() Method

Introduction

In JavaScript, the setTimeout() is a global method that allows you to execute a function or code only once after a specified time. It is part of the window object but can be used without explicitly referencing it.

The setTimeout() method can also be used to manipulate DOM elements after a given delay from user interaction.

Syntax

window.setTimeout(callback, delay, param1, param2, ..., paramN);
OR
setTimeout(callback, delay, param1, param2, ..., paramN);

Parameters:

  • callback – A function to be executed after the delay.
  • delay – Time in milliseconds (1000 ms = 1 second).
  • param1, param2, ..., paramN – Optional arguments passed to the callback.

Return Value: A numeric ID which can be used with clearTimeout().

Example 1 – Basic Usage

The following code defines a timeout() function and executes it after 1 second (1000 ms). 

<html>
<body>
   <div id="output"> </div>
   <script>
      document.getElementById('output').innerHTML = "Wait for a message! <br>";
      setTimeout(timeout, 1000);
      function timeout() {
         document.getElementById('output').innerHTML += 
            "This message is printed after 1 second!";
      }
   </script>
</body>
</html>
Wait for a message!
This message is printed after 1 second!

Example 2 – Arrow Function

You can also use an arrow function instead of defining a separate function. 

<html>
<body>
   <div id="output"> </div>
   <script>
      document.getElementById('output').innerHTML += 
         "You will see the message after 2000 milliseconds! <br>";
      setTimeout(() => {
         document.getElementById('output').innerHTML += 'Hi! How are you?';
      }, 2000);
   </script>
</body>
</html>
You will see the message after 2000 milliseconds!
Hi! How are you?

Example 3 – Passing Multiple Arguments

You can pass extra arguments after the delay. They will be forwarded to the callback function. 

<html>
<body>
   <div>Wait for a sum of 3 numbers!</div>
   <div id="output"></div>
   <script>
      setTimeout(sum, 1000, 10, 20, 30);
      function sum(num1, num2, num3) {
         let result = num1 + num2 + num3;
         document.getElementById('output').innerHTML = "Sum = " + result;
      }
   </script>
</body>
</html>
Wait for a sum of 3 numbers!
Sum = 60

Example 4 – Recursive setTimeout (Counter)

By calling setTimeout() inside a function, you can create repeated execution similar to setInterval(). 

<html>
<body>
   <div id="output"></div>
   <script>
      let output = document.getElementById('output');
      output.innerHTML += "The output of the counter is below. <br>";
      let p = 0;
      function counter() {
         output.innerHTML += "count is - " + p + ".<br>";
         setTimeout(counter, 1000);
         p++;
      }
      counter();
   </script>
</body>
</html>
The output of the counter is below.
count is - 0.
count is - 1.
count is - 2.
count is - 3.
count is - 4.

JavaScript clearTimeout() Method

The clearTimeout() method cancels a scheduled timeout before it executes. 

clearTimeout(id);

Parameter: id is the numeric identifier returned by setTimeout().

Example – Start and Stop Timeout

<html>
<body>
   <p>Click Stop within 3 seconds after pressing Start.</p>
   <button onclick="startTimeOut()">Start Timeout</button>
   <button onclick="stopTimeOut()">Stop Timeout</button>
   <p id="output"></p>
   <script>
      let output = document.getElementById('output');
      let timeout;
      function startTimeOut() {
         timeout = setTimeout(() => {
            output.innerHTML = "Timeout is done";
         }, 3000);
      }
      function stopTimeOut() {
         clearTimeout(timeout);
         output.innerHTML = "Timeout is stopped";
      }
   </script>
</body>
</html>

Zero Delay Timeout

Passing 0 milliseconds doesn’t guarantee immediate execution. The callback is queued and runs after all currently pending tasks. 

<html>
<body>
   <div id="output"></div>
   <script>
      let output = document.getElementById('output');
      output.innerHTML += "The code execution started. <br>";
      setTimeout(function() {
         output.innerHTML += "Inside the zero delay timeout. <br>";
      }, 0);
      output.innerHTML += "The code execution ended. <br>";
   </script>
</body>
</html>
The code execution started.
The code execution ended.
Inside the zero delay timeout.

PHP Recursive Functions

A **Recursive Function** is a function that **calls itself** until a specific **base condition** is met. Recursion is an elegant approach used to solve problems that are defined in terms of themselves, often resulting in concise code compared to iterative solutions (loops).

Key Components of Recursion

  1. **Base Case (Stop Condition):** A condition that, when met, stops the function from calling itself further. This is crucial to prevent infinite recursion and a stack overflow error.
  2. **Recursive Case:** The step where the function calls itself, usually with a modified input that brings it closer to the base case.

Example 1: Factorial Calculation

The factorial of a number $n$ ($n!$) is defined as $n \times (n-1)!$. This self-referential definition makes it a perfect candidate for recursion. The base case is when $n$ equals 1, where the factorial is 1.

<?php
   function factorial ($n) {
      if ($n == 1) {
         return 1; // **Base Case**
      } else {
         return $n * **factorial($n-1)**; // **Recursive Case**
      }
   }

   echo factorial(5); // 120
?>

Example 2: Recursive Binary Search

Recursion is also frequently used in searching and traversing nested data structures. The binary search algorithm efficiently finds an element in a sorted list by repeatedly dividing the search interval in half.

The recursive function `bsearch` continually narrows the search range by adjusting the `low` or `high` index until the element is found or the `high` index is no longer greater than the `low` index (the base case).

*If $\text{list}[\text{mid}] > \text{elem}$, search left:*
return **bsearch**($my\_list, $low, **$mid - 1**, $elem);

*If $\text{list}[\text{mid}] < \text{elem}$, search right:*
return **bsearch**($my\_list, **$mid + 1**, $high, $elem);

*If $\text{high} < \text{low}$, element not found:*
return -1; // **Base Case** (Failure)

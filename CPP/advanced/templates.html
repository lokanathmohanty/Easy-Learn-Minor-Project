C++ Templates (Generic Programming) 🧬

**Templates** are the core of **generic programming** in C++. They allow you to write functions and classes (algorithms and data structures) that operate with different data types **without rewriting the same logic**. A template acts as a **blueprint** or formula for creating type-specific code instances at compile time.

The two keywords used to define a template are **template** and **typename** (or class, which are interchangeable in this context).

1. Function Templates

A function template provides a single function definition that can be used with different data types.

Syntax

template <typename T> 
T const& Max (T const& a, T const& b) { 
   return a < b ? b:a; 
}

When the compiler sees `Max(i, j)` where `i` and `j` are `int`, it generates a specific `Max` function. When it sees `Max(f1, f2)` where they are `double`, it generates `Max`.

2. Class Templates

Class templates define a blueprint for creating generic classes that work with any data type. Standard Library containers like `std::vector` and `std::stack` are implemented as class templates.

Syntax

template <class T> 
class Stack { 
private: 
   std::vector<T> elems; // T is the generic type 
public: 
   void push(T const&);
   // ... other methods
};

// Instantiation:
Stack<int> intStack;         // Creates Stack class
Stack<std::string> stringStack; // Creates Stack class

Template Argument Deduction

**Template Argument Deduction** is a feature that allows the compiler to automatically infer the data type (`T`) of the template arguments, saving you the need to specify them explicitly.

  • **Function Template Deduction:** For function templates, the compiler deduces `T` based on the types of the arguments passed during the function call. 
    // Compiler deduces T as 'int'
add(5, 3);
  • **Class Template Deduction (CTAD):** Since C++17, the compiler can also infer template parameters for class templates based on the arguments passed to the constructor. 
    template<typename T>
class Holder {
   public: Holder(T value);
};

// Compiler deduces T as 'double' from the constructor argument
Holder h2(3.14);

Benefits of Templates

  • **Code Reusability:** Write one generic algorithm that works for all types, eliminating code duplication.
  • **Reduced Maintenance:** Fixing a bug in the single template definition fixes it for all type instantiations.
  • **Enhanced Performance:** Instantiation and type-specific optimization occur entirely at **compile time**, leading to zero runtime overhead.

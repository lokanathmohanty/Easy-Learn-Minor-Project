PHP: Call by Reference

**Call by Reference** is a mechanism that allows a function to **modify the original variable** passed as an argument from the calling environment. Unlike the default "Call by Value" mechanism (which works on a copy), Call by Reference passes an **alias** or **reference** to the original variable.

Mechanism: The Reference Operator (`&`)

To enable call by reference, the **ampersand (`&`)** symbol must be placed before the formal parameter name in the function's definition.

1. Declaring a Function for Call by Reference

function change_data(**&**$arg1, **&**$arg2) {
   // Changes here modify the original variables passed in
}

2. Example: Modifying the Original Variable

In this example, the formal parameter `&$nm` acts as an alias to the actual argument `$name`. When `&$nm` is modified inside the function, the change is instantly reflected in `$name` outside the function.

<?php
   function change_name(**&**$nm) {
      $nm = $nm."_new";
   }

   $name = "John";
   change_name($name);
   echo "My name now is **$name**"; // Output: John_new
?>

Practical Use Case: Swapping Variables

A classic example is swapping two variables. Using call by value fails to affect the actual arguments, but using call by reference makes the swap persistent outside the function.

**Reference Swap Function:**
function swap_ref(**&**$a, **&**$b) {
   $c = $a; $a = $b; $b = $c;
}

$x = 10; $y = 20;
swap_ref($x, $y);
echo "$x $y"; // Output: 20 10

Return by Reference

A function can also **return a reference** to a variable (usually a static or global variable). This allows the variable receiving the returned value to also become an alias to the original variable inside the function.

**Syntax:** Prefix both the function declaration and the variable assignment with `&`.
function **&**myfunction() { /* ... */ return $x; }
$a = **&**myfunction();

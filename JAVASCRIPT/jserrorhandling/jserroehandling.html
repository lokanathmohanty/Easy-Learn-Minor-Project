JavaScript - Errors & Exceptions Handling

Error handling in JavaScript is a process to detect and handle errors that occur during program execution. Errors can be syntax, runtime, or logical errors. Runtime errors are also known as exceptions.

Effective error handling ensures robust, reliable, and user-friendly applications.

What is an Error?

An error is an event that prevents a program from continuing normally. Types include:

  • Syntax Errors − Occur when JavaScript code has invalid syntax.
  • Runtime Errors (Exceptions) − Happen during execution due to invalid operations.
  • Logical Errors − Result from mistakes in program logic.

Example: Syntax Error

<script>
   window.print();
</script>

Example: Runtime Error

<script>
   window.printme();
</script>

Error Handling Mechanisms

  • try...catch...finally statements
  • throw statements
  • onerror event handler
  • Custom Errors

Example: try...catch...finally

<script>
   try {
      var a = 100;
      alert(myFunc(a));
   } 
   catch (e) {
      alert(e);
   } 
   finally {
      alert("Finally block will always execute!");
   }
</script>

Example: throw Statement

<script>
   function myFunc() {
      var a = 100;
      var b = 0;

      try {
         if ( b == 0 ) {
            throw("Divide by zero error.");
         } else {
            var c = a / b;
         }
      }
      catch ( e ) {
         alert("Error: " + e );
      }
   }
</script>

Example: onerror Event Handler

<script>
   const output = document.getElementById("demo");
   window.onerror = function (msg, url, line) {
      output.innerHTML = "Error: " + msg + "<br>";
      output.innerHTML += "URL: " + url + "<br>";
      output.innerHTML += "Line: " + line + "<br>";
   }
</script>

Error Object

When errors occur, JavaScript throws an Error object that contains information about the error.

  • name − Sets or gets the error name.
  • message − Sets or gets the error message.

Types of JavaScript Errors

  • Error
  • SyntaxError
  • ReferenceError
  • TypeError
  • RangeError
  • URIError
  • EvalError (deprecated)
  • AggregateError

Custom Errors

const customError = new Error("Custom error message");
customError.name = "CustomError";

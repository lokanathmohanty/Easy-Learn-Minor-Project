While Loop in C

In C, the while loop is one of the most commonly used loop constructs, along with for and do-while. It is known as an entry-verified loop, meaning the condition is checked before the loop body executes.

Syntax of while Loop

while(expression){
   statement(s);
}

The while keyword is followed by a boolean expression inside parentheses. If the expression evaluates to true, the block inside the curly brackets is executed.

How while Loop Works in C?

  • The condition is evaluated before executing the loop body.
  • If the condition is true, the code block runs.
  • If false, the block is skipped, and control moves to the next statement.
  • This makes it possible for a while loop to run zero times if the condition fails initially.

Example: Print "Hello World" 5 Times

#include <stdio.h>

int main(){
   int a = 1;

   while(a <= 5){
      printf("Hello World \n");
      a++;
   }

   printf("End of loop"); 
   return 0;
}

Output

  • Hello World
  • Hello World
  • Hello World
  • Hello World
  • Hello World
  • End of loop

Now, if we set a = 10, the output will simply be:

End of loop

This is because the condition a <= 5 is false before the loop starts.

Using while as a Conditional Loop

In this example, we use a while loop to print whether a number is even or odd. The loop continues until a negative number is entered.

#include <stdio.h>

int main(){
   char choice = 'a';
   int x = 0;

   while(x >= 0){
      (x % 2 == 0) ? printf("%d is Even\n", x) : printf("%d is Odd\n", x);

      printf("\nEnter a positive number: ");
      scanf("%d", &x);
   }

   printf("\nEnd of loop");
   return 0;
}

Sample Output

0 is Even

Enter a positive number: 12
12 is Even

Enter a positive number: 25
25 is Odd

Enter a positive number: -1

End of loop

Break and Continue with while Loop

Using break to Exit Early

while (expr){
   ...
   if (condition)
      break;
   ...
}

Using continue to Skip to Next Iteration

while (expr){
   ...
   if (condition)
      continue;
   ...
}

More Examples

Example: Print Lowercase Alphabets

#include <stdio.h>

int main(){
   char a = 'a';

   while(a <= 'z') {
      printf("%c", a);
      a++;
   }

   printf("\nEnd of loop"); 
   return 0;
}

Output

abcdefghijklmnopqrstuvwxyz
End of loop

Example: Equating Two Variables

#include <stdio.h>

int main(){
   int a = 10, b = 0;

   while(a != b){
      a--;
      b++;
      printf("a: %d b: %d\n", a, b);
   }

   printf("\nEnd of loop");
   return 0;
}

Output

a: 9 b: 1
a: 8 b: 2
a: 7 b: 3
a: 6 b: 4
a: 5 b: 5

End of loop

while vs. do-while Loops

The while loop is an entry-controlled loop. If the condition is false at the beginning, the loop won’t run at all.

The do-while loop is an exit-controlled loop, which guarantees that the loop body runs at least once.

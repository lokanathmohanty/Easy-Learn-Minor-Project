Java Programming: Wrapper Classes and Characters

Session: The Character Class

The Java Character Class

The **java.lang.Character** class is the wrapper class for the primitive data type **char**. Like other wrapper classes, it enables a primitive character to be treated as an **object**, which is necessary for working with Java Collections and utility methods.

The class is declared as **public final class Character** and implements `Serializable` and `Comparable`. It provides a comprehensive set of **static methods** for character manipulation, classification, and Unicode handling.

Core Utility Methods

The most commonly used features of the `Character` class are its static methods for checking and manipulating characters. These methods are crucial for input validation, parsing, and text processing.

Classification Methods:

  • **static boolean isLetter(char ch)**: Checks if a character is a letter.
  • **static boolean isDigit(char ch)**: Checks if a character is a digit ('0' through '9').
  • **static boolean isLetterOrDigit(char ch)**: Checks if the character is a letter or a digit.
  • **static boolean isUpperCase(char ch)** / **isLowerCase(char ch)**: Checks the case of the character.
  • **static boolean isWhitespace(char ch)**: Checks if the character is Java whitespace (includes space, tab, newline, etc.).

Conversion Methods:

  • **static char toUpperCase(char ch)**: Converts the character to uppercase.
  • **static char toLowerCase(char ch)**: Converts the character to lowercase.

Unicode and Escape Sequences

Unicode Support

The `Character` class provides extensive support for **Unicode**, including handling supplementary characters (those requiring more than 16 bits) using **surrogate pairs** (a high surrogate followed by a low surrogate).

  • **Code Point Methods:** Methods like codePointAt() and charCount() help manage characters that may be represented by two `char` values. The constant fields like MAX_CODE_POINT and MIN_HIGH_SURROGATE define the boundaries for Unicode characters and UTF-16 encoding.

Escape Sequences

Escape sequences are characters preceded by a **backslash (`\`)** that have special meaning to the compiler, allowing control characters or reserved symbols to be embedded in strings and character literals.

Sequence Description
\nNewline (Line Feed)
\tTab
\"Double quote
\\Backslash

Summary of .NET Core Prerequisites for Windows

This session outlines the necessary dependencies and supported environments for deploying and developing **.NET Core applications** on **Windows** using **Visual Studio**.

Supported Windows Versions

The following versions of Windows are officially supported for running .NET Core applications:

  • Windows 7 SP1
  • Windows 8.1
  • Windows 10

Supported Server Versions:

  • Windows Server 2008 R2 SP1 (Full Server or Server Core)
  • Windows Server 2012 SP1 (Full Server or Server Core)
  • Windows Server 2012 R2 SP1 (Full Server or Server Core)
  • Windows Server 2016 (Full Server, Server Core or Nano Server)

Dependencies

For running .NET Core applications on Windows versions **earlier than Windows 10 and Windows Server 2016**, the **Visual C++ Redistributable** is required.

  • If you use the **.NET Core installer**, this dependency is installed automatically.
  • If you use the installer script or deploy a self-contained application, you must manually install the **Visual C++ Redistributable for Visual Studio 2015**.

Specific Requirement for Windows 7 and Windows Server 2008:

  • The Windows installation must be up-to-date and include **hotfix KB2533623** installed via Windows Update.

Prerequisites with Visual Studio (Development)

While any editor can be used to develop .NET Core applications with the SDK, using Visual Studio on Windows requires one of the following two versions:

  • **Visual Studio 2015** (Projects are typically project.json-based)
  • **Visual Studio 2017 RC** (Projects are always **MSBuild**-based)

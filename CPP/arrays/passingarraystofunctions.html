C++ Passing Arrays to Functions ➡️

C++ does not pass an entire array **by value** to a function. Instead, when an array name is passed as an argument, it **decays** into a **pointer** to its first element. Therefore, when a function receives an array, it is actually receiving a memory address (a pointer).

Because the array size is lost in this process, it is standard practice to pass the size of the array as a **separate integer argument** to prevent buffer overflows.

Formal Parameter Declaration Methods

When declaring a function that accepts a single-dimension array, you have three ways to define the formal parameter. All three methods are equivalent to the compiler, as they all indicate that a pointer to the array's element type will be received:

  1. As a Pointer (Recommended for Clarity): 
    void myFunction(int *param);
  2. As an Unsized Array (Common): 
    void myFunction(int param[]);
  3. As a Sized Array (Size is Ignored): 
    void myFunction(int param[10]);

    Note: The size `10` is generally ignored by the compiler, as C++ performs **no bounds checking** on array parameters.

Example: Calculating Array Average

This example demonstrates the standard method of passing the array (as a pointer) and its size separately to safely process the elements.

// Function Definition: Receives the array (as a pointer) and its size
double getAverage(int arr[], int size) {
   int sum = 0;
   for (int i = 0; i < size; ++i) {
      sum += arr[i];
   }
   return (double)sum / size;
}

int main () {
   int balance[5] = {1000, 2, 3, 17, 50};
   double avg;

   // Function Call: Pass the array name and the size
   avg = getAverage(balance, 5); 
 
   // Output: 214.4
   cout << "Average value is: " << avg << endl; 
   
   return 0;
}

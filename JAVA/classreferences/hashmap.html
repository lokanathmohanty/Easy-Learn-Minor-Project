Java HashMap Class Summary 🗺️

The **java.util.HashMap** class is the foundational, **hash table-based implementation** of the **Map** interface. It stores data in **key-value pairs** and is designed for high-speed retrieval and insertion operations.

I. Core Characteristics and Performance

HashMap is optimized for quick lookups, but its iteration order is non-deterministic:

  • Hashing: It uses the `hashCode()` and `equals()` methods of the key objects for storage and retrieval. Access, insertion, and deletion operations (like get() and put()) are typically **constant time ($O(1)$)**, assuming a good hash function and minimal collisions.
  • Unordered: **No guarantees are made about iteration order.** The order of elements is determined by the hash codes and internal structure, and it may change over time or across different Java versions. (Use **LinkedHashMap** for insertion order or **TreeMap** for sorted order).
  • Nulls Permitted: It permits **one null key** and **multiple null values**.
  • Non-Synchronized: It is **not thread-safe**. For concurrent use, the **ConcurrentHashMap** class should be used.

II. Capacity Parameters

The performance of a HashMap relies heavily on two adjustable parameters, which can be set via constructors:

  • Initial Capacity (Default: 16): The initial number of buckets (storage locations) in the hash table. Setting this too low increases the frequency of resizing (rehashing).
  • Load Factor (Default: 0.75): A threshold that dictates when the map should resize. When the number of entries exceeds (Capacity * Load Factor), the internal array is resized (typically doubled), and all elements are rehashed. A lower load factor reduces collisions but increases memory overhead.

III. Key Map Operations

The following methods are fundamental for map usage:

Method Action Notes
V put(K key, V value) Associates value with the key. If the key already exists, the old value is replaced and returned. Primary insertion method.
V get(Object key) Returns the value mapped to the key, or `null` if the key is not found. Primary retrieval method ($O(1)$).
V remove(Object key) Removes the mapping for the key and returns the associated value. Primary deletion method.
Set<K> keySet() Returns a `Set` view of the keys. Used for iterating over keys.
Set<Map.Entry<K,V>> entrySet() Returns a `Set` view of the key-value pairs (`Map.Entry` objects). Used for efficient iteration over both keys and values (as shown in the example).

IV. Java 8 Default Methods

HashMap provides implementations for functional methods introduced in Java 8 to simplify common map patterns:

  • V computeIfAbsent(...): Computes a value and adds it only if the key is missing or mapped to null.
  • V merge(...): Combines a new value with an existing value for a key using a provided function, or inserts the new value if the key is absent.

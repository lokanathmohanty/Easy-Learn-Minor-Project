CSS - Descendant Selectors

A CSS descendant selector is used to apply styles to elements that are nested (at any level) inside a specified parent element. A single space is used between selectors to indicate a descendant relationship. Unlike the child selector (>), the descendant selector applies to all levels of nesting.

Syntax

selector_1 selector_2 {
  /* property: value; */
  color: #04af2f;
}

Example 1: Styling Paragraphs Inside a Div

In this example, all <p> elements inside a <div> are given a green border. Paragraphs outside the div remain unchanged. 

div p {
  border: 2px solid #04af2f;
}

<div>
  <p>This is a p element inside a div.</p>
  <p>This is second p element inside a div.</p>
</div>

<p>This is a p element outside the div element.</p>

Example 2: Using Hover with Descendant Selector

In this example, we use the descendant selector to target a <div> inside a container. When the inner div is hovered over, it rotates by 45 degrees. 

.container, .container2 {
  display: inline-block;
  height: 100px;
  width: 100px;
  background-color: #04af2f;
  color: white;
  font-size: 20px;
  font-family: Verdana, sans-serif;
  padding: 10px;
  border: 1px solid black;
  text-align: center;
  line-height: 100px;
}

.container div:hover {
  transition: transform 0.5s ease;
  transform: rotate(45deg);
}

<div class="container">
  <div>Box 1</div>
</div>
<div class="container2">Box 2</div>

Key Notes

  • Descendant selectors match elements nested inside the parent, no matter how deep.
  • They are written with a space between parent and child selectors.
  • Use descendant selectors for applying styles to grouped sections of a page.
  • For direct children only, use the child selector (>) instead.

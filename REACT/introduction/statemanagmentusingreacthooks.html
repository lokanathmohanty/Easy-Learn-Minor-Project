Introduction

React introduces an entirely new concept called React Hooks from React 16.8. Even though it is a relatively new concept, it enables React functional components to have their own state and life-cycle. Also, React Hooks enable functional components to use many features not available earlier.

Let us see how to do state management in a functional component using React Hooks in this chapter.

What is React Hooks?

React Hooks are special functions provided by React to handle a specific functionality inside a React functional component. For example, React provides the useState() function to manage state in a functional component.

The general signature of useState() Hook is as follows: 

const [stateVariable, setStateFunction] = useState(initialValue);

Example

State management in a clock component using Hooks: 


const [currentDateTime, setCurrentDateTime] = useState(new Date());
setInterval(() => setCurrentDateTime(new Date()), 1000);
  • currentDateTime − Variable used to hold current date and time.
  • setCurrentDateTime() − Function used to set current date and time.

Create a Stateful Component

Steps to recreate a clock component using Hooks:

  • Create a new React application react-clock-hook-app.
  • Open the app in your editor and create src/components/Clock.js.
  • Import React and useState.
import React, { useState } from 'react';

Create Clock component and state Hook:


function Clock() {
  const [currentDateTime, setCurrentDateTime] = useState(new Date());
  setInterval(() => setCurrentDateTime(new Date()), 1000);
  return (
    <div><p>The current time is {currentDateTime.toString()}</p></div>
  );
}
export default Clock;

Using the Component


import React from 'react';
import ReactDOM from 'react-dom';
import Clock from './components/Clock';

ReactDOM.render(
  <React.StrictMode>
    <Clock />
  </React.StrictMode>,
  document.getElementById('root')
);

Serve the application with npm start and open http://localhost:3000.

Cleanup with useEffect

The above application works fine. However, the interval has to be cleared when the application ends. This can be done using the useEffect Hook, which will be discussed in the upcoming chapter.

Introducing State in Expense Manager App

Let us introduce state management in the expense manager application by adding a feature to remove an expense item using Hooks.

Steps

  • Create ExpenseEntryItemListFn.js under src/components.
  • Import React, useState, and CSS.
  • Create the ExpenseEntryItemListFn component.
  • Initialize state with props.
  • Add event handlers for hover and delete.
  • Calculate total amount.
  • Render a table of expense items.

Complete Code


import React, { useState } from 'react';
import './ExpenseEntryItemList.css';

function ExpenseEntryItemListFn(props) {
  const [items, setItems] = useState(props.items);

  function handleDelete(id, e) {
    e.preventDefault();
    let newItems = items.filter(item => item.id !== id);
    setItems(newItems);
  }

  function getTotal() {
    return items.reduce((total, item) => total + item.amount, 0);
  }

  const lists = items.map(item =>
    <tr key={item.id}>
      <td>{item.name}</td>
      <td>{item.amount}</td>
      <td>{new Date(item.spendDate).toDateString()}</td>
      <td>{item.category}</td>
      <td><a href="#" onClick={(e) => handleDelete(item.id, e)}>Remove</a></td>
    </tr>
  );

  return (
    <table>
      <thead>
        <tr>
          <th>Item</th>
          <th>Amount</th>
          <th>Date</th>
          <th>Category</th>
          <th>Remove</th>
        </tr>
      </thead>
      <tbody>
        {lists}
        <tr>
          <td colSpan="1">Total Amount</td>
          <td colSpan="4">{getTotal()}</td>
        </tr>
      </tbody>
    </table>
  );
}
export default ExpenseEntryItemListFn;

Running the Expense Manager

Update index.js to include the component, serve the app using npm start, and open http://localhost:3000. Clicking "Remove" will delete the expense item and update the UI.

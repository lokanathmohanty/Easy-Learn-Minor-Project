Java switch Statement

Session Content

The Java switch statement allows testing a variable for equality against multiple values called cases. It is a cleaner alternative to multiple if-else statements when checking one variable for many possible constants.

The syntax is:

switch(expression) {
   case value:
      // Statements
      break; // optional
   // other cases
   default:
      // Statements (optional)
}

Important rules:

  • Switch expression can only be an integer, byte, short, char, String, or enum.
  • Case values must be constant or literal and match the switch expression's type.
  • When a case matches, statements execute until a break statement or the end of the switch block.
  • break prevents fall-through to subsequent cases.
  • default case executes if no other case matches. It is optional and usually placed last.

Example 1: switch with char cases

public class Test {
   public static void main(String args[]) {
      char grade = 'C';
      switch(grade) {
         case 'A':
            System.out.println("Excellent!");
            break;
         case 'B':
         case 'C':
            System.out.println("Well done");
            break;
         case 'D':
            System.out.println("You passed");
         case 'F':
            System.out.println("Better try again");
            break;
         default:
            System.out.println("Invalid grade");
      }
      System.out.println("Your grade is " + grade);
   }
}

Output:

  • Well done
  • Your grade is C

Example: Using default case

public class SwitchWithDefault {
   public static void main(String[] args) {
      int month = 13; // Invalid month
      switch (month) {
         case 1: System.out.println("January"); break;
         case 2: System.out.println("February"); break;
         case 3: System.out.println("March"); break;
         case 4: System.out.println("April"); break;
         case 12: System.out.println("December"); break;
         default: System.out.println("Invalid month");
      }
   }
}

Output:

  • Invalid month

Example: Without default case

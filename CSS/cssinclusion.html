CSS Inclusion - How To Add CSS?

You need to include the CSS file in your HTML document before using it. There are multiple ways to include CSS in an HTML file, such as writing inline CSS, internal CSS, or including a CSS file.

Styles can be associated with your HTML document in different ways, such as:

  • Inline CSS − The CSS styling is placed inside an HTML element tag, which has an effect only on that element.
  • Internal CSS − The CSS styling is placed inside the <style> tag, under the <head> tag.
  • External CSS − The CSS styling is placed in an external file (.css extension) inside the <link> tag, under the <head> tag.

Embedded / Inline CSS - <style> Attribute

You can use style attribute of any HTML element to define style rules. These rules will be applied to that element only.

Syntax
<element style = "...style rules....">

The value of style attribute is a combination of style declarations separated by semicolon (;).

Internal CSS - <style> Element

You can put your CSS rules into an HTML document using the <style> element. This tag is placed inside the <head> tag. Rules defined using this syntax will be applied to all the elements available in the document.

Syntax: CSS rules are defined inside the <style> block.

Attributes of <style> element:

  • type: text/css (required) – Specifies the style sheet language.
  • media: screen, tty, tv, projection, handheld, print, braille, aural, all (optional).

External CSS - <link> Element

The <link> element can be used to include an external stylesheet file in your HTML document. An external style sheet is a separate text file with .css extension. You can define all the style rules in this file and include it using the <link> element.

Syntax: <link type="text/css" href="..." media="..." />

Attributes:

  • type: text/css (required).
  • href: URL of the style sheet (required).
  • media: specifies the device (optional).

You can create a stylesheet file ext_style.css and include it using the <link> element.

Imported CSS - @import Rule

The @import rule is used to import an external stylesheet in a manner similar to the <link> element. It must be declared at the top of the stylesheet.

Example: A stylesheet can import another stylesheet using @import.

CSS Rules Overriding

  • Inline style sheet takes highest priority and overrides all others.
  • Internal styles (<style> tag) override external stylesheets.
  • External style sheets take the lowest priority.

Random Number Generation in C

The stdlib.h library in C includes the rand() function that returns an integer randomly, between 0 and the constant RAND_MAX.

The rand() function generates pseudo-random numbers. They are not truly random and are based on the Linear Congruential Generator (LCG) algorithm.

int rand(void);

Example 1 – rand()

The following code calls the rand() function three times. Each call is likely to return a different integer:

#include <stdio.h>
#include <stdlib.h>

int main() {
   printf("%ld\n", rand());
   printf("%ld\n", rand());
   printf("%ld\n", rand());

   return 0;
}

Output

41
18467
6334

Note: The rand() function doesn't automatically seed itself with a varying value. Without setting a seed, results may be the same across runs.

Use srand() to seed the random number generator and improve randomness.

Example 2 – Random Number (0–99)

This example generates random integers from 0 to 99 using rand() % 100:

#include <stdio.h>
#include <stdlib.h>

int main() {
   for(int i = 1; i <= 5; i++) {
      printf("random number %d: %d \n", i, rand() % 100);
   }

   return 0;
}

Output

random number 1: 41
random number 2: 67
random number 3: 34
random number 4: 0
random number 5: 69

Example 3 – Random Number in a Range

To generate random numbers between a specified range, use the following logic:

num = (rand() % (upper - lower + 1)) + lower;
#include <stdio.h>
#include <stdlib.h>

int main() {
   int i, num;
   int lower = 50, upper = 100;

   for (i = 1; i <= 5; i++) {
      num = (rand() % (upper - lower + 1)) + lower;
      printf("random number %d: %d \n", i, num);
   }

   return 0;
}

Output

random number 1: 91
random number 2: 55
random number 3: 60
random number 4: 81
random number 5: 94

The srand() Function

The srand() function seeds the pseudo-random number generator used by rand().

void srand(unsigned int seed);

Note: If srand() is not called, the generator behaves as if seeded with srand(1).

To ensure varied random output on every run, use srand() with time(NULL).

Example 4 – Seeding with Time

Using the current time as a seed ensures different random sequences on each program execution.

#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main() {
   srand(time(NULL));
   printf("Random number: %d \n", rand());

   return 0;
}

Output

Random number: 1436786055

Output will differ each time the program runs.

Example 5 – Random in Range with Seed

Combining srand() and range logic to produce better randomized numbers:

#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main() {
   int i, num;
   time_t t;
   int lower = 100, upper = 200;

   srand((unsigned) time(&t));

   for (i = 1; i <=5; i++) {
      num = (rand() % (upper - lower + 1)) + lower;
      printf("random number number %d: %d \n", i, num);
   }

   return 0;
}

Output

random number number 1: 147
random number number 2: 171
random number number 3: 173
random number number 4: 112
random number number 5: 181

Limitations and Tips

  • rand() is not truly random. It is deterministic based on seed.
  • Same seed → Same output sequence.
  • Range limited to 0 to RAND_MAX (usually 32767 or more).
  • Use a good seed source like time(NULL) for better randomness.
  • For cryptographic or high-quality randomness, use third-party libraries or system-level APIs.

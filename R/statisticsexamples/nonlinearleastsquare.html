R - Nonlinear Least Squares

Real-world data often fits nonlinear regression models where the fitted curve is not a straight line, involving polynomial, exponential, or other nonlinear functions. Nonlinear least squares aims to find parameter values minimizing the sum of squares of vertical residuals from the fitted curve.

The nls() function in R fits nonlinear models, requiring an initial guess of coefficients which are then optimized.

Syntax

nls(formula, data, start)
  • formula: Nonlinear model formula with variables and parameters
  • data: Data frame with variables in the formula
  • start: Named list or numeric vector for initial coefficient estimates

Example

Given model: \(a = b_1 \times x^2 + b_2\), fit data with initial guesses \(b_1 = 1\), \(b_2 = 3\).

xvalues <- c(1.6, 2.1, 2, 2.23, 3.71, 3.25, 3.4, 3.86, 1.19, 2.21)
yvalues <- c(5.19, 7.43, 6.94, 8.11, 18.75, 14.88, 16.06, 19.12, 3.21, 7.58)

png(file = "nls.png")

plot(xvalues, yvalues)

# Fit nonlinear model
model <- nls(yvalues ~ b1 * xvalues^2 + b2, start = list(b1 = 1, b2 = 3))

# Predict fitted values over sequence and add line to plot
new.data <- data.frame(xvalues = seq(min(xvalues), max(xvalues), length = 100))
lines(new.data$xvalues, predict(model, newdata = new.data))

dev.off()

# Sum of squared residuals
print(sum(resid(model)^2))

# Confidence intervals for parameters
print(confint(model))

Output Sample

The estimated \(b_1\) is close to 1 and \(b_2\) close to 2, indicating better fit than initial guess.

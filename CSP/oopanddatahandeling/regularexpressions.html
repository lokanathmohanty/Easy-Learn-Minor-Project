C# Regular Expressions (`Regex`)

Fundamentals of Regular Expressions

A **Regular Expression (RegEx)** is a sequence of characters that defines a search **pattern**. The .NET Framework provides a dedicated engine via the **System.Text.RegularExpressions** namespace to perform pattern matching against input text.

RegEx is a powerful tool used for **Pattern Matching**, **Validation** (e.g., emails, phone numbers), **Replacement**, and **Extraction** of specific data from strings.

Required Namespace:

using System.Text.RegularExpressions;

The `Regex` Class and Key Methods

The **Regex** class represents a regular expression engine instance. It provides static and instance methods for working with patterns.

Method Description
IsMatch(string input) Checks if the pattern finds **at least one match** in the input string, returning a bool.
Matches(string input) Searches and returns **all occurrences** of the pattern as a MatchCollection.
Replace(string input, string replacement) Replaces all matching substrings in the input with a specified replacement string.
Split(string input) Splits the input string into an array of substrings based on the positions defined by the pattern.

Basic RegEx Syntax Constructs

Patterns are built using a combination of literal characters and special constructs:

Syntax Description Example
. Matches **any single character** (except newline). "h.t" matches "hat", "hit".
\d **Any digit** (0-9). Equivalent to [0-9]. "abc\d\d" matches "abc12".
\w **Any word character** (letters, digits, or underscore). "\w+" matches "hello_world".
^ **Start of the string** or line. "^Hello" matches "Hello" only at the start.
$ **End of the string** or line. "World$" matches "World" only at the end.
* **Quantifier:** Zero or more occurrences of the preceding element. "A*" matches "", "A", "AAA".
+ **Quantifier:** One or more occurrences of the preceding element. "A+" matches "A", "AA", but not "".
{n,m} **Quantifier:** Between n and m occurrences. "\d{2,4}" matches 2, 3, or 4 digits.

Note on String Literals: Since backslashes (`\`) are used both in C# string escape sequences and RegEx syntax, it is highly recommended to use **verbatim string literals** (prefixed with @) for patterns to avoid double-escaping. E.g., @"\bS\S*" instead of "\\bS\\S*".

Example: Pattern Matching and Extraction

This demonstrates using \b (word boundary) and \S* (zero or more non-whitespace characters) to extract specific words.

string str = "A Thousand Splendid Suns";
string expr = @"\bS\S*"; // Word starts with 'S'

MatchCollection mc = Regex.Matches(str, expr);
// Output will be:
// Splendid
// Suns

Example: String Replacement

Replacing multiple consecutive whitespace characters with a single space.

string input = "Hello   World   ";
string pattern = @"\s+"; // Match one or more whitespace characters
string replacement = " ";
         
string result = Regex.Replace(input, pattern, replacement);

// Output: Original String: Hello   World   
// Output: Replacement String: Hello World

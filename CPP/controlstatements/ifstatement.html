C++ if Statement 🧐

The **if statement** is the most basic decision-making structure in C++. It allows a program to execute a specific block of code only if a given condition is met.

Syntax and Flow

The syntax for a basic if statement involves a **Boolean expression** enclosed in parentheses, followed by a block of code enclosed in curly braces ({}):

if (boolean_expression) {
   // Statement(s) to execute ONLY if the expression evaluates to true
}
// Code execution continues here, regardless of the 'if' result.
  • If the `boolean_expression` is **true** (or non-zero), the code inside the curly braces is executed.
  • If the `boolean_expression` is **false** (or zero), the code inside the curly braces is skipped, and execution resumes immediately after the closing brace.

Example Analysis

In the provided code, the variable a is initialized to 10.

int a = 10;
if ( a < 20 ) { // 10 < 20 is TRUE
    cout << "a is less than 20;" << endl; // This line executes
}
cout << "value of a is : " << a << endl; // This line always executes

The condition `a < 20` is **true**, so the print statement inside the `if` block is executed. The program then continues to the next print statement, resulting in the following output:

a is less than 20;
value of a is : 10

Do-While Loop in C

The do-while loop is one of the most frequently used types of loops in C. It differs from the while loop in that it is an exit-controlled loop, meaning the condition is checked after the loop executes.

Syntax of do-while Loop

do {
   statement(s);
} while(condition);

How do-while Loop Works?

The program control enters the do block and executes it unconditionally once. After the block ends, the condition in the while statement is evaluated:

  • If the condition is true, the loop repeats.
  • If the condition is false, the loop ends.

Note: There is a semicolon at the end of the while statement.

Example: Simple do-while Loop

This example prints "Hello World" five times.

#include <stdio.h>

int main() {
   int a = 1;

   do {
      printf("Hello World\n");
      a++;
   } while(a <= 5);

   printf("End of loop");

   return 0;
}

Output

  • Hello World
  • Hello World
  • Hello World
  • Hello World
  • Hello World
  • End of loop

Now, if we initialize a to 10, the loop still runs once before stopping:

Modified Output (a = 10)

  • Hello World
  • End of loop

This proves that a do-while loop runs at least once, regardless of the condition.

Difference Between while and do-while Loops

While both loops are similar, here are their differences:

  • Syntactic: do-while starts with do and ends with while(condition);
  • Execution: do-while checks condition after executing, ensuring at least one run.
  • Semicolon: Required at the end of the while in do-while.

Example: Comparing while and do-while Loops

#include <stdio.h>

int main() {
   int a = 0, b = 0;

   printf("Output of while loop:\n");
   while(a < 5) {
      a++;
      printf("a: %d\n", a);
   }

   printf("Output of do-while loop:\n");
   do {
      b++;
      printf("b: %d\n", b);
   } while(b < 5);

   return 0;
}

Initial Output (a = 0, b = 0)

  • While loop: a: 1, 2, 3, 4, 5
  • Do-while loop: b: 1, 2, 3, 4, 5

When a = 3, b = 3

  • While loop: a: 4, 5
  • Do-while loop: b: 4, 5

When a = 10, b = 10

  • While loop: (no output)
  • Do-while loop: b: 11

This demonstrates that the while loop skips execution if the condition is false initially, while do-while executes once regardless.

Use Cases

  • Use while when condition must be true before any execution.
  • Use do-while when the loop must execute at least once.

do-while loops can also include break and continue statements to control flow.

Django: Different Methods for Inserting Data (CRUD: Create) 💾

Django's **Object-Relational Mapper (ORM)** allows data manipulation (CRUD operations) using Python objects, abstracting away the underlying SQL. Here are the three main ways to insert (create) new data records for a given model (e.g., the Dreamreal model):

1. Direct ORM Methods (Shell or View)

This is the programmatic approach, used for scripting or directly within a view function. It bypasses form validation layers.

A. Model Instance and .save()

You instantiate the model class, set its attributes, and then call the .save() method. This executes an INSERT query in the database.

>>> from myapp.models import Dreamreal
>>> obj = Dreamreal(website="www.polo.com", name="sorex", ...)
>>> obj.save()

B. Model Manager .create()

A shortcut that instantiates, sets attributes, and saves the object in a single line. This is often preferred for simple insertions.

>>> obj = Dreamreal.objects.create(
... website="www.polo.com", name="sorex", ...)

2. Handling Data from a Manual HTML Form

This method involves defining a view function (e.g., addnew) that handles both the display of the blank form and the submission of data.

  • **GET Request:** The view checks the request method. If it's a **GET**, it simply renders the blank HTML template (myform.html).
  • **POST Request:** If it's a **POST**, the view manually retrieves data from request.POST, creates a model instance using the extracted data, and calls .save().
def addnew(request):
   if request.method == "POST":
      ws = request.POST['website']
      # ... retrieve other fields ...
      obj = Dreamreal(website=ws, ...)
      obj.save()
      return HttpResponse("
Record Added Successfully
")
   return render(request, "myform.html")

*(The HTML form must include {% csrf_token %} for security.)*

3. Using Django Forms (ModelForm)

This is the standard, secure, and most recommended method, as it leverages Django's built-in validation.

  • **Define ModelForm:** Create a DreamrealForm class in forms.py that inherits from forms.ModelForm and links to the Dreamreal model.
  • **In View:**
    1. On **POST**, the view binds the form to the POST data: form = DreamrealForm(request.POST).
    2. It calls **form.is_valid()** to validate the data.
    3. If valid, it calls **form.save()**, which handles the creation and persistence of the new model object automatically.
def addnew(request):
   if request.method == 'POST':
      form = DreamrealForm(request.POST)
      if form.is_valid():
         form.save() # Saves the valid data to the model
         return HttpResponse("
Book added successfully
")

   context={'form' : DreamrealForm}
   return render(request, "myform.html", context)

4. Using Generic Class-Based Views (CreateView)

For even faster development, Django provides **Generic Views** that handle common tasks without defining extensive logic in views.py. The CreateView is specialized for object creation.

from django.views.generic import CreateView

class DRCreateView(CreateView):
   model = Dreamreal
   fields = "__all__"
   template_name = 'myform.html'
   success_url = '../success/' # Redirect on successful save

This class automatically handles form rendering (GET), data binding/validation (POST), saving, and redirection. It is registered in urls.py using DRCreateView.as_view().

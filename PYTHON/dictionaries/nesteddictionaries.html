Nested Dictionaries in Python

Nested dictionaries in Python are dictionaries that contain other dictionaries as their values, forming a hierarchical structure. They allow organizing complex, multi-level data.

Creating a Nested Dictionary

You can create nested dictionaries by assigning dictionaries as values for keys within an outer dictionary.

Example: Direct Assignment

# Define the outer dictionary
nested_dict = {
  "outer_key1": {"inner_key1": "value1", "inner_key2": "value2"},
  "outer_key2": {"inner_key3": "value3", "inner_key4": "value4"}
}
print(nested_dict)

Example: Using a Loop

# Initialize outer dictionary
nested_dict = {}

outer_keys = ["outer_key1", "outer_key2"]
for key in outer_keys:
  nested_dict[key] = {"inner_key1": "value1", "inner_key2": "value2"}

print(nested_dict)

Adding Items to a Nested Dictionary

# Initial nested dictionary
students = {
  "Alice": {"age": 21, "major": "Computer Science"},
  "Bob": {"age": 20, "major": "Engineering"}
}

# Add to existing nested dictionary
students["Alice"]["GPA"] = 3.8

# Add a new nested dictionary
students["Charlie"] = {"age": 22, "major": "Mathematics"}

print(students)

Accessing Nested Dictionary Items

Use chained square brackets or the get() method to safely access nested values.

Example: Using Direct Indexing

alice_major = students["Alice"]["major"]
print("Alice's major:", alice_major)

bob_age = students["Bob"]["age"]
print("Bob's age:", bob_age)

Example: Using get() Method

alice_major = students.get("Alice", {}).get("major", "Not Found")
print("Alice's major:", alice_major)

dave_major = students.get("Dave", {}).get("major", "Not Found")
print("Dave's major:", dave_major)

Deleting a Nested Dictionary Item

# Delete nested dictionary for Bob
del students["Bob"]

print(students)

Iterating Through a Nested Dictionary

for student, details in students.items():
  print(f"Student: {student}")
  for key, value in details.items():
    print(f"  {key}: {value}")

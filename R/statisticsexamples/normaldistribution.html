R - Normal Distribution

Normal distribution is a common data distribution where values cluster around the mean, forming a bell-shaped curve. Roughly 50% of values lie on each side of the mean. R provides built-in functions to generate and analyze normal distributions.

Key Functions

  • dnorm(x, mean, sd): Density/probability height for values x
  • pnorm(x, mean, sd): Cumulative distribution function (CDF) for x
  • qnorm(p, mean, sd): Quantile function, returns value for cumulative probability p
  • rnorm(n, mean, sd): Generates n random samples from the normal distribution

dnorm() Example

# Sequence from -10 to 10
x <- seq(-10, 10, by = 0.1)

# Density values (mean=2.5, sd=0.5)
y <- dnorm(x, mean = 2.5, sd = 0.5)

# Plot density
png(file = "dnorm.png")
plot(x, y)
dev.off()

pnorm() Example

# Sequence from -10 to 10
x <- seq(-10, 10, by = 0.2)

# CDF values (mean=2.5, sd=2)
y <- pnorm(x, mean = 2.5, sd = 2)

# Plot CDF
png(file = "pnorm.png")
plot(x, y)
dev.off()

qnorm() Example

# Probability values from 0 to 1
x <- seq(0, 1, by = 0.02)

# Quantiles (mean=2, sd=1)
y <- qnorm(x, mean = 2, sd = 1)

# Plot quantiles
png(file = "qnorm.png")
plot(x, y)
dev.off()

rnorm() Example

# Generate 50 random samples (normal distribution)
y <- rnorm(50)

# Plot histogram of samples
png(file = "rnorm.png")
hist(y, main = "Normal Distribution")
dev.off()

These examples illustrate generating and plotting normal distribution data and related functions in R.

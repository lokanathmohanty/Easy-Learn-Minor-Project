JavaScript - Classes

Introduction

JavaScript classes are a blueprint or template for object creation. They encapsulate the data and functions to manipulate that data. Creating an object from a class is referred to as instantiating the class.

Classes were introduced in ECMAScript 6 (ES6) and are built on prototypes. For example, a class can be used to represent a car entity, with properties like brand, model, and year.

Before ES6: Constructor Functions

Before ES6, constructor functions were used to define a blueprint of the object. 

function Car(brand) {
  this.brand = brand; // property initialization
}
const carObj = new Car("Audi");

Defining JavaScript Classes

The syntax of a class is very similar to a constructor function, but it uses the class keyword. Classes can be defined using either a class declaration or a class expression. 

// class declaration
class ClassName {
  // Class body
}

// class expression
const ClassName = class {
  // Class body
};

Type of JavaScript Classes

A JavaScript class is a type of function. Using the typeof operator confirms that classes are functions. 

class Car {
  // Class body
}
console.log(typeof Car); // function

The constructor() Method

The constructor() method initializes object properties when a class instance is created. 

class Car {
  constructor(brand) {
    this.brand = brand;
  }
}
const myCar = new Car("Audi");

Creating JavaScript Objects

Objects are created using the new operator with the class name.

Example: Without Arguments

class Car {
  constructor() {
    this.brand = "BMW";
    this.model = "X5";
    this.year = 2019;
  }
}
const myCar = new Car();
console.log(myCar.brand, myCar.model, myCar.year);

Example: With Arguments

class Car {
  constructor(brand, model, price, year) {
    this.brand = brand;
    this.model = model;
    this.price = price;
    this.year = year;
  }
}
const carObj = new Car("BMW", "X5", 9800000, 2019);
console.log(carObj.brand, carObj.model, carObj.price, carObj.year);

JavaScript Class Methods

Methods can be defined inside a class and invoked using its instance. 

class Car {
  constructor(brand, model, price, year) {
    this.brand = brand;
    this.model = model;
    this.price = price;
    this.year = year;
  }

  updatePrice(newPrice) {
    this.price = newPrice;
  }
}

const myCar = new Car("BMW", "X5", 9800000, 2019);
console.log(myCar.price); // 9800000
myCar.updatePrice(8800000);
console.log(myCar.price); // 8800000

Class Hoisting

Unlike functions, class declarations are not hoisted. You must define the class before using it. 

const carObj = new Car(); // Error
class Car {}

Strict Mode with Classes

All class code is executed in strict mode by default. For example, declaring a variable without var, let, or const inside a class will throw an error. 

class Numbers {
  constructor() {
    num = 90; // Error: variable not declared
  }
}
const numObj = new Numbers();

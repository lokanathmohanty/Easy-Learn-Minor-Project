PHP $\text{IntlChar}$ Class (Unicode Utilities)

The $\text{IntlChar}$ class, introduced in PHP 7, provides static methods and constants for accessing detailed information about **Unicode characters**. It offers utility functions that adhere to the behavior of the underlying **ICU (International Components for Unicode)** library. To use it, the $\text{Intl}$ extension must be enabled in the $\text{php.ini}$ file.

Character Information and Properties

$\text{IntlChar::charAge()}$

Retrieves the **Unicode version** (or "age") when the given code point was first assigned a character. The result is an array representing the version number.

<?php
   // Checks the age of SNOWMAN code point (\u{2603})
   var_dump(IntlChar::charAge("\u{2603}")); 
   // Output: array(4) { [0]=> int(1) [1]=> int(1) ... } (Unicode version 1.1)
?>

$\text{IntlChar::charName()}$ and $\text{IntlChar::charFromName()}$

These functions facilitate lookup between a character and its official Unicode name.

  • $\text{IntlChar::charName(codepoint)}$: Retrieves the official **name** of a Unicode character. 
    var_dump(IntlChar::charName("\u{2603}")); // Output: string(7) "SNOWMAN"
  • $\text{IntlChar::charFromName(name)}$: Finds a Unicode character by its official name and returns its **code point value** (integer). 
    var_dump(IntlChar::charFromName("SNOWMAN")); // Output: int(9731)

Character Classification (is...)

The $\text{IntlChar}$ class offers numerous $\text{is...}$ methods to determine a character's general category property, providing much more accurate classification than simple ASCII checks.

  • $\text{IntlChar::isalpha(codepoint)}$: Checks if the code point is a **letter character** (general category "L"). 
    var_dump(IntlChar::isalpha("A")); // bool(true)
  • $\text{IntlChar::islower(codepoint)}$: Checks if the code point is a **lowercase letter** (general category "Ll"). 
    var_dump(IntlChar::islower("a")); // bool(true)
  • **Similar Methods:** $\text{isdigit()}$, $\text{isalnum()}$, $\text{isblank()}$, $\text{isupper()}$, $\text{istitle()}$, $\text{iswhitespace()}$, etc.

Case Mapping

$\text{IntlChar::toupper()}$

Maps the given character to its **uppercase equivalent**. If no uppercase equivalent exists, the character itself is returned.

<?php
   var_dump(IntlChar::toupper("a")); // Output: string(1) "A"
?>

Similarly, there are $\text{IntlChar::tolower()}$ and $\text{IntlChar::totitle()}$ methods for other case conversions.

CSS - Grid Property

Introduction

The CSS grid property is a shorthand property used to declare all explicit and implicit grid properties in one declaration. It provides a convenient and concise way to define the grid layout of an element. Instead of writing multiple grid-related properties separately, you can use grid to set them at once.

The grid property is a shorthand for:

  • grid-template-rows
  • grid-template-columns
  • grid-template-areas
  • grid-auto-rows
  • grid-auto-columns
  • grid-auto-flow

Syntax

The syntax for the grid property is:

grid: none | grid-template-rows / grid-template-columns | grid-template-areas | grid-template-rows / [grid-auto-flow] grid-auto-columns | [grid-auto-flow] grid-auto-rows / grid-template-columns | initial | inherit;

Property Values

  • none – No specific sizing of rows or columns. Default.
  • grid-template-rows / grid-template-columns – Specifies row heights and column widths.
  • grid-template-areas – Defines the grid layout with named areas.
  • grid-template-rows / grid-auto-columns – Specifies row heights with auto-sized columns.
  • grid-auto-rows / grid-template-columns – Specifies auto-sized rows with defined columns.
  • grid-template-rows / grid-auto-flow grid-auto-columns – Specifies row heights, flow direction, and auto-sized columns.
  • grid-auto-flow grid-auto-rows / grid-template-columns – Defines placement of auto-placed items, auto row sizes, and column widths.
  • initial – Resets property to its default value.
  • inherit – Inherits property value from parent.

Grid Property with Row Height and Column Width

We can specify row heights and column widths directly using the grid property. For example, grid: 150px 100px / auto auto auto; defines two rows and three columns.

Example Code:

<!DOCTYPE html>
<html>
<head>
   <style>
      .container {
         display: grid;
         grid: 150px 100px / auto auto auto;
      }
   </style>
</head>
<body>
   <h2>CSS Grid Property</h2>
   <p><strong>grid: 150px 100px / auto auto auto</strong></p>
   <div class="container">
      <div>Item-1</div>
      <div>Item-2</div>
      <div>Item-3</div>
      <div>Item-4</div>
      <div>Item-5</div>
      <div>Item-6</div>
   </div>
</body>
</html>

Grid Property with Template Areas

We can also use grid-template-areas within the grid property to define named sections of the grid layout. This allows placing elements in specific portions of the layout by assigning them area names.

Example Code:

<!DOCTYPE html>
<html>
<head>
   <style>
      .container {
         display: grid;
         grid: "header header header header" 100px
               "sidebar content content content" 100px
               "footer footer footer footer" 100px;
      }
      .item1 { grid-area: header; }
      .item2 { grid-area: sidebar; }
      .item3 { grid-area: content; }
      .item4 { grid-area: footer; }
   </style>
</head>
<body>
   <h2>CSS Grid Property</h2>
   <p><strong>grid-template-areas</strong> example</p>
   <div class="container">
      <div class="item1">This is header</div>
      <div class="item2">This is sidebar</div>
      <div class="item3">This is content</div>
      <div class="item4">This is footer</div>
   </div>
</body>
</html>

Supported Browsers

The grid property is supported in modern browsers:

  • Chrome: 57+
  • Edge: 16+
  • Firefox: 52+
  • Safari: 10+
  • Opera: 44+

Practice

  • Create a grid with 2 rows and 3 columns using the grid shorthand property.
  • Design a page layout with header, sidebar, content, and footer using grid template areas.
  • Experiment with grid-auto-flow to see how items are automatically placed.

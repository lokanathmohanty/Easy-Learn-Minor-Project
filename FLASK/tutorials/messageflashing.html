Flask Message Flashing: User Feedback 💬

The **message flashing system** in Flask provides a simple way to give user feedback (like success or error notifications) across multiple requests. It allows you to create a message in one view function and display it in the view function that is called **next**, typically a template after a redirect.

Creating a Flash Message

The **flash()** method, imported from the Flask module, is used to store a message in the session for the next request:

flash(message, category)

  • **message:** The actual text you want to display to the user (e.g., "You were successfully logged in").
  • **category:** An optional parameter to classify the message (e.g., 'error', 'info', or 'warning'). Categories are useful for styling the message appropriately in the template.

Like sessions, the flashing mechanism requires a **SECRET_KEY** to be set on the application for cryptographic signing.

Displaying Flashed Messages in Templates

Messages are removed from the session and displayed to the user by calling the **get_flashed_messages()** function within the template. A common Jinja2 pattern is used to check for and iterate over any pending messages:

{% with messages = get_flashed_messages() %}

{% if messages %}

<ul>

{% for message in messages %}

<li>{{ message }}</li>

{% endfor %}

</ul>

{% endif %}

{% endwith %}

Once called, get_flashed_messages() clears the messages from the session so they are not displayed again on a subsequent page load.

Example: Login Success Flash

The login() view function demonstrates conditional flashing and redirection:

  • **Success Case:** If the credentials match 'admin'/'admin', a success message is flashed, and the user is immediately redirected to the **index()** function (which renders the index.html template):

    • flash('You were successfully logged in')

    return redirect(url_for('index'))

  • **Failure Case:** If the credentials are wrong, an **error** variable is set locally, and the login.html template is re-rendered immediately with that variable, **without** using the flashing system (since there is no redirect).

When the user lands on index.html, the Jinja2 code calls get_flashed_messages() and displays the "You were successfully logged in" message.

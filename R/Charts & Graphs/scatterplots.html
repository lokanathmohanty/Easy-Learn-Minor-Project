R - Scatterplots

Scatterplots display points on the Cartesian plane, visually showing the relationship between two variables. Each point's position is determined by paired values on horizontal (x) and vertical (y) axes. Scatterplots help identify correlations and patterns.

Basic Syntax

plot(x, y, main, xlab, ylab, xlim, ylim, axes)
  • x: Values for horizontal axis
  • y: Values for vertical axis
  • main: Title of the plot
  • xlab: Label for x axis
  • ylab: Label for y axis
  • xlim: Limits for x axis values
  • ylim: Limits for y axis values
  • axes: Logical indicating if axes are drawn

Example: Create Basic Scatterplot

# Extract weight and mpg from mtcars
input <- mtcars[, c('wt', 'mpg')]
print(head(input))

# Create image file
png(file = "scatterplot.png")

# Plot scatterplot with axis limits and labels
plot(x = input$wt, y = input$mpg,
     xlab = "Weight",
     ylab = "Mileage",
     xlim = c(2.5, 5),
     ylim = c(15, 30),
     main = "Weight vs Mileage")

# Save file
dev.off()

Scatterplot Matrices

To visualize relationships between multiple variables simultaneously, use the pairs() function to create scatterplot matrices.

# Create image file
png(file = "scatterplot_matrices.png")

# Plot scatterplot matrix for 4 variables
pairs(~wt + mpg + disp + cyl, data = mtcars,
      main = "Scatterplot Matrix")

# Save file
dev.off()

These examples demonstrate how to create individual scatterplots as well as matrices for deeper multivariate analysis.

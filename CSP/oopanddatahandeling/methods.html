C# Methods

Definition and Structure of a Method

A **method** is a block of code containing a group of statements that together perform a specific task. Methods are essential for code organization, reusability, and modularity.

To use a method, you must first **define** it and then **call** it.

Syntax for Defining a Method:

<Access Specifier> <Return Type> <Method Name>(Parameter List) {
   Method Body
}

Key Elements:

  • Access Specifier: Determines the visibility (e.g., public, private).
  • Return Type: The data type of the value the method returns. Use void if the method returns no value.
  • Method Name: A unique identifier (case-sensitive).
  • Parameter List: Optional. Defines the types, order, and number of inputs the method accepts.
  • Method Body: The instructions to be executed.

Calling Methods

Methods are executed by **calling** them. The way you call a method depends on whether it's an instance method or a static method.

  • Instance Method (Non-static): Requires an **object instance** of the class (e.g., objectName.Method()).
  • Static Method: Can be called directly using the **class name** (e.g., ClassName.StaticMethod()). The Main() method is always static.

class NumberManipulator {
    public int FindMax(int num1, int num2) {
        // ... method body ...
        return result;
    }
    
    static void Main(string[] args) {
        // Create an instance of the class
        NumberManipulator n = new NumberManipulator();

        // Call the instance method using the object 'n'
        int ret = n.FindMax(100, 200); 
        Console.WriteLine("Max value is : {0}", ret ); // Output: 200
    }
}

Recursive Method Call

A **recursive method** is one that calls itself within its own body. Recursion is often used to solve problems that can be broken down into smaller, similar sub-problems, such as calculating factorials.

Example: Factorial Calculation

public int factorial(int num) {
    if (num == 1) {
        return 1; // Base case (stops the recursion)
    } else {
        // Recursive call: num * factorial(num - 1)
        return factorial(num - 1) * num; 
    }
}

Types of Methods by Functionality

  • Simple Method Without Parameters (void): Performs a task without input and doesn't return data. 
    static void WelcomeMsg() { /* ... */ }
  • Method With Parameters: Accepts values as input to perform dynamic operations. 
    static void Add(int a, int b) { /* ... */ }
  • Method With Return Value: Performs an operation and returns a single result using the return statement. 
    static int Multiply(int x, int y) { return x * y; }
  • Method with Default Parameters: Parameters are assigned default values, which are used if no argument is explicitly passed during the call. 
    static void WelcomeMsg(string name = "Guest") { /* ... */ }

Passing Parameters to a Method

C# offers three main mechanisms for passing arguments to a method:

  1. Value Parameters (Default): The method receives a copy of the argument's value. Changes made to the parameter inside the method **do not** affect the original argument.
  2. Reference Parameters (using ref): The method receives a reference to the argument's memory location. Changes made to the parameter **do** affect the original argument. The variable **must** be initialized before passing.
  3. Output Parameters (using out): Similar to ref, but the primary purpose is to return a value out of the method. The variable **does not** need to be initialized before passing, but the method **must** assign a value to it before returning. Useful for returning multiple values.

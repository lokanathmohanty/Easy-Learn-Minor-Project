JavaScript - Arithmetic Operators

Arithmetic operators in JavaScript perform mathematical calculations on numeric values (operands). Most of the arithmetic operators are binary operators as they perform calculations on two operands. Some arithmetic operators are unary operators, performing computation on a single operand.

JavaScript supports many arithmetic operators such as addition, subtraction, multiplication, division, etc. It uses common symbols such as +, -, *, /.

Operators Overview

  • + → Addition
  • - → Subtraction
  • * → Multiplication
  • / → Division
  • % → Modulus
  • ++ → Increment
  • -- → Decrement

JavaScript Addition (+) Operator

The addition operator adds two operands or concatenates strings. 


var x = 5, y = 10;
var sum = x + y;   // 15
var z = '10' + 3;  // "103"
var w = '10' + '3'; // "103"

JavaScript Subtraction (-) Operator

Subtracts the right operand from the left operand. 


20 - 10;     // 10
'20' - 10;   // 10
'20' - '10'; // 10
'20ee' - 10; // NaN

JavaScript Multiplication (*) Operator

Multiplies two operands. If one operand is a string, JavaScript converts it to a number when possible. 


var x = 20, y = 10;
var z = x * y;     // 200
"20" * "10";       // 200
"20ee" * 10;       // NaN

JavaScript Division (/) Operator

Divides the left operand (dividend) by the right operand (divisor). 


20 / 10;   // 2
20 / -10;  // -2
100 / 0;   // Infinity
0 / 0;     // NaN

JavaScript Modulus (%) Operator

Returns the remainder when one operand is divided by another. 


20 % 9;    // 2
-20 % 9;   // -2
20.43 % 9; // 2.43

JavaScript Increment (++) Operator

Increases the value of a variable by one. Can be used as prefix or postfix. 


var a = 10;
var b = ++a; // prefix → a=11, b=11
var c = a++; // postfix → a=12, c=11

JavaScript Decrement (--) Operator

Decreases the value of a variable by one. Can be used as prefix or postfix. 


var a = 10;
var b = --a; // prefix → a=9, b=9
var c = a--; // postfix → a=8, c=9

Python - Join Tuples

Joining tuples in Python means combining elements from multiple tuples into a single new tuple without modifying the original tuples.

Joining Tuples Using Concatenation (+) Operator

The + operator joins two or more tuples to form a new tuple.

# Example
T1 = (10, 20, 30, 40)
T2 = ('one', 'two', 'three', 'four')
joined_tuple = T1 + T2
print("Joined Tuple:", joined_tuple)

Output:

Joined Tuple: (10, 20, 30, 40, 'one', 'two', 'three', 'four')

Joining Tuples Using List Comprehension

Using list comprehension to iterate over tuples and merge the elements into a list which can also represent joined tuples.

# Example
T1 = (36, 24, 3)
T2 = (84, 5, 81)
joined_tuple = [item for subtuple in [T1, T2] for item in subtuple]
print("Joined Tuple:", joined_tuple)

Output:

Joined Tuple: [36, 24, 3, 84, 5, 81]

Joining Tuples Using extend() Function

The extend() function works with lists, so convert tuples to lists, extend, then convert back to tuple.

# Example
T1 = (10, 20, 30, 40)
T2 = ('one', 'two', 'three', 'four')
L1 = list(T1)
L2 = list(T2)
L1.extend(L2)
T1 = tuple(L1)
print("Joined Tuple:", T1)

Output:

Joined Tuple: (10, 20, 30, 40, 'one', 'two', 'three', 'four')

Join Tuples Using sum() Function

The sum() function can join tuples by concatenating elements if the tuples contain numeric elements.

# Example
T1 = (10, 20, 30, 40)
T2 = ('one', 'two', 'three', 'four')
T3 = sum((T1, T2), ())
print("Joined Tuple:", T3)

Output:

Joined Tuple: (10, 20, 30, 40, 'one', 'two', 'three', 'four')

Joining Tuples Using for Loop

Iterate over one tuple and append each element to another tuple using the += operator within a loop.

# Example
T1 = (10, 20, 30, 40)
T2 = ('one', 'two', 'three', 'four')
for t in T2:
    T1 += (t,)
print(T1)

Output:

(10, 20, 30, 40, 'one', 'two', 'three', 'four')

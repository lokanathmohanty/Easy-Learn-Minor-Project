JavaScript - var Keyword

The var keyword in JavaScript is used to declare variables. Before ES6, there was only var keyword to declare a variable. In ES6, let and const were introduced as better options. A variable declared with var has function scope, while let has block scope.

Syntax

You can declare variables using var as follows:

  • var identifier;
  • var identifier = value;

Example

Declaring variables using var:


var num1 = 30;
var str1 = "Hello World!";
var bool = true;

JavaScript Variable Scopes

Variables declared with var have function scope or global scope.

Function Scope


function demo() {
   var x = 10;
   {
      var y = 20;
   }
   console.log(x); // 10
   console.log(y); // 20
}
demo();

Global Scope


var num1 = 10;
function sum(num2) {
   console.log(num1 + num2);
   console.log(window.num1 + num2);
}
sum(20); // 30, 30

Variable Hoisting

Variables declared with var are hoisted to the top of their scope. 


function checkHoisting() {
   a = 98;
   console.log(a); // 98
   var a;
}
checkHoisting();

Redeclaration

You can redeclare variables using var without errors. 


var a = 10;
var a = 20;
console.log(a); // 20

Many Variables in One Statement


var a = 70, b = 80;
console.log(a); // 70
console.log(b); // 80

Using var in Loops

Loop variables declared with var can be accessed outside the loop. 


for (var p = 0; p < 5; p++) {
   console.log(p);
}
console.log(p); // 5

Declaration with Destructuring


var arr = [4, 5, 6];
var [a, b, c] = arr;
console.log(a, b, c); // 4, 5, 6

JavaScript - Microtasks

Microtasks in JavaScript are small functions that are executed after the completion of the function or program code that creates them and if the JavaScript execution stack is empty. Microtasks are executed before any macrotasks, such as setImmediate() and setTimeout(). Microtasks are used to implement features such as promises.

JavaScript is a single-threaded programming language. However, you can use promises, callbacks, and asynchronous functions to run JavaScript code in parallel.

JavaScript runs the code based on the event loop. The event loop is responsible for executing the code, processing it, collecting the event data, and executing the sub-tasks.

JavaScript Event Loop

The event loop executes the JavaScript code line-by-line. It adds the code to the call stack, a queue to execute it. JavaScript contains two types of queues to execute tasks:

  • Microtasks queue
  • Macrotasks queue

When the call stack is empty, the event loop executes all tasks inside the microtask queue. After that, it executes all functions and code in the macrotask queue.

What is a Microtask in JavaScript?

In JavaScript, a microtask is a shorter function that is produced by a promise or asynchronous function, and consumed later. Examples include:

  • Promise callbacks (then(), catch(), finally())
  • queueMicrotask()

Example: Microtask with Promise

<html>
<body>
   <div id="output"></div>
   <script>
      const output = document.getElementById("output");
      output.innerHTML += "The start of the code execution. <br>";

      let promise = new Promise(function (resolve, reject) {
         resolve("The promise is resolved. <br>");
      });

      promise.then(function (result) {
         output.innerHTML += result;
      });

      output.innerHTML += "The end of the code execution. <br>";
   </script>
</body>
</html>

Output:

  • The start of the code execution.
  • The end of the code execution.
  • The promise is resolved.

What is a Macrotask?

A macrotask is also a short function that gets executed after all code inside the call stack and microtask queue is completed. Callback functions from the following methods are added to the macrotask queue:

  • setTimeout
  • setInterval
  • setImmediate

Example: Macrotask with setTimeout

<html>
<body>
   <div id="demo"></div>
   <script>
      let output = document.getElementById("demo");
      output.innerHTML += "The start of the code execution.<br>";
      setTimeout(function () {
         output.innerHTML += "The code execution is being delayed for 0 seconds.<br>";
      }, 0);
      output.innerHTML += "The end of the code execution.<br>";
   </script>
</body>
</html>

Output:

  • The start of the code execution.
  • The end of the code execution.
  • The code execution is being delayed for 0 seconds.

Example: Microtasks vs Macrotasks

<html>
<body>
   <div id="output"></div>
   <script>
      let output = document.getElementById("output");
      output.innerHTML += "Start <br>";

      setTimeout(function () { // Macro task
         output.innerHTML += "In setTimeOut() method. <br>";
      }, 0);

      let promise = new Promise(function (resolve, reject) {
         resolve("In Promise constructor. <br>");
      });
      promise.then(function (value) { // Micro task
         output.innerHTML += value;
      });

      output.innerHTML += "End <br>";
   </script>
</body>
</html>

Output:

  • Start
  • End
  • In Promise constructor.
  • In setTimeOut() method.

Summary

JavaScript executes tasks using the event loop. When the call stack is empty:

  • All microtasks are executed first.
  • Then all macrotasks are executed.

By carefully using microtasks and macrotasks, developers can control the execution order of asynchronous operations.

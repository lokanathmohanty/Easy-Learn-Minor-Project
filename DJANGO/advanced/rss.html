Django: RSS and Atom Syndication Feeds 📰

Django simplifies the creation of **RSS (Really Simple Syndication)** and **Atom feeds** using its built-in syndication framework. To generate a feed, you define a class that subclasses **django.contrib.syndication.views.Feed** and define specific methods and attributes that correspond to the standard feed elements.

Creating a Custom Feed Class

A feed class must define the metadata for the feed (title, link, description) and methods to generate the feed items.

from django.contrib.syndication.views import Feed
from django.contrib.comments import Comment # Example Model

class DreamrealCommentsFeed(Feed):
   # 1. Feed Metadata (corresponds to <title>, <link>, <description>)
   title = "Dreamreal's comments"
   link = "/drcomments/"
   description = "Updates on new comments on Dreamreal entry."

   # 2. Method to fetch items (the feed content)
   def items(self):
      # Returns the last 5 comments, ordered by submission date
      return Comment.objects.all().order_by("-submit_date")[:5]
		
   # 3. Methods to define item content
   def item_title(self, item):
      return item.user_name # The title of a feed item
		
   def item_description(self, item):
      return item.comment # The body/description of a feed item
		
   def item_link(self, item):
      # Generates the URL to the full article/comment using reverse lookup
      return reverse('comment', kwargs = {'object_pk':item.pk})

Mapping the Feed and Item URLs

For the feed to be accessible and for the items within the feed to link to full content, two URL patterns must be configured:

  1. **Feed URL:** Maps a URL to an instance of the feed class using the .as_view() method (or the direct class call shown below, common in older Django versions).
  2. **Item URL:** Maps a URL to a regular Django view that displays the full content of a single feed item. The item_link() method uses this URL's name (e.g., 'comment') for reverse lookup.
# myapp/urls.py
from myapp.feeds import DreamrealCommentsFeed

urlpatterns += patterns('',
   # 1. URL to access the RSS feed itself
   url(r'^latest/comments/', DreamrealCommentsFeed()), 
   
   # 2. URL for individual feed items (links generated by item_link)
   url(r'^comment/(?P<object_pk>\w+)/', 'comment', name = 'comment'),
)

Accessing the feed URL (e.g., /myapp/latest/comments/) will display the XML-formatted feed, while clicking an item in the feed will take the user to the single item view (e.g., /myapp/comment/123/).

C# Multithreading: Concurrent Execution 🔄

What is a Thread?

A **thread** is defined as a unique flow of control or an execution path within a program. Threads are considered **lightweight processes** and are essential for **concurrent programming**, allowing an application to perform multiple tasks simultaneously, increasing CPU utilization and application efficiency.

In C#, multithreading involves the **`System.Threading.Thread`** class.

Thread Life Cycle and States 🚦

The life cycle of a thread spans from its creation as a **`Thread`** object to its termination. Key states include:

  • **Unstarted:** The thread object is created, but the **`Start()`** method has not been called.
  • **Ready:** The thread is waiting for its turn to be executed by the CPU.
  • **Not Runnable (Blocked):** The thread is temporarily paused due to conditions like a call to **`Sleep()`**, **`Wait()`**, or blocking I/O operations.
  • **Dead:** The thread has completed its execution or was explicitly aborted.

Creating and Starting Threads

Main Thread

The first thread that executes when a C# program starts is the **main thread**. All other threads created are its child threads, accessible via **`Thread.CurrentThread`**.

Creating Child Threads

New threads are typically created by:

  1. Creating a delegate instance (**`ThreadStart`** or **`ParameterizedThreadStart`**) that points to the method the thread will execute.
  2. Passing the delegate to a new **`Thread`** object.
  3. Calling the **`Start()`** method on the **`Thread`** object to begin execution.
// Example using ThreadStart delegate
ThreadStart childref = new ThreadStart(CallToChildThread);
Thread childThread = new Thread(childref);
childThread.Start();

Passing Parameters

Parameters can be passed to the thread's execution method using the **`ParameterizedThreadStart`** delegate or, more commonly in modern C#, using a **lambda expression**.

// Using a lambda to pass parameters
Thread thread = new Thread(() => PerformTask("Hello from thread!"));
thread.Start();

Managing and Destroying Threads

Pausing a Thread

The static method **`Thread.Sleep(int millisecondsTimeout)`** causes the calling thread to pause execution for the specified duration.

Waiting for Termination

The **`Join()`** method blocks the calling thread (e.g., the main thread) until the target thread completes its execution.

Destroying (Aborting) a Thread ❌

The **`Abort()`** method is used to forcefully terminate a thread by raising a **`ThreadAbortException`** in the target thread. While the thread is typically terminated, the exception cannot be caught in a standard `catch` block; control is immediately transferred to the **`finally`** block (if one exists) before the thread dies.

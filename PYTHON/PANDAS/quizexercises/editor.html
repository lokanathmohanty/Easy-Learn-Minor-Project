Example: Read CSV with Pandas

This example reads a CSV file and prints the contents using pandas.read_csv() and to_string():


import pandas as pd

df = pd.read_csv('data.csv')

print(df.to_string())

Output:


   Duration  Pulse  Maxpulse  Calories
0        60    110       130     409.1
1        60    117       145     479.0
2        60    103       135     340.0

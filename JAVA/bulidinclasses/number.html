Java Programming: Data Type Hierarchy

Session: The Abstract Number Class

The Java Number Class

The **Number** class, part of the **java.lang** package, is an **abstract superclass** for all classes that represent numeric primitive values in object form. It serves as the common base for the six numeric wrapper classes: **Byte**, **Short**, **Integer**, **Long**, **Float**, and **Double**.

The primary purpose of the `Number` class is to provide a standardized set of methods for converting any of its numeric subclasses into the six primitive numeric types.

Wrapper Classes and Autoboxing

Wrapper classes (subclasses of Number, plus Boolean and Character) allow primitive values to be used as objects, which is required by **Java Collections** (like ArrayList) and other object-centric APIs.

  • **Boxing (Autoboxing):** The automatic conversion of a primitive type (e.g., int) into its corresponding wrapper object (e.g., Integer).
  • **Unboxing:** The automatic conversion of a wrapper object back into its primitive type.

The compiler handles these conversions automatically to simplify mixed operations, as shown in the example:

Integer x = 5;   // Autoboxing (int to Integer)
x = x + 10;      // Unboxing (Integer to int), addition, then Autoboxing (int to Integer)

Core Conversion Methods (Implemented by Subclasses)

The abstract Number class defines the following instance methods, which are implemented by all its numeric subclasses. These methods allow universal casting from any wrapper type to any primitive numeric type:

  • **byteValue()**: Returns the number's value as a `byte`.
  • **shortValue()**: Returns the number's value as a `short`.
  • **intValue()**: Returns the number's value as an `int`.
  • **longValue()**: Returns the number's value as a `long`.
  • **floatValue()**: Returns the number's value as a `float`.
  • **doubleValue()**: Returns the number's value as a `double`.

In addition to these, wrapper classes also contain utility methods (like parseInt(), valueOf(), min(), max(), and overridden equals()/toString()) that operate on or retrieve numeric values.

PHP: Interfaces

An **interface** in PHP serves as a **template** or a contract for classes. It defines a set of methods (along with their arguments and return types) that a class must implement.

Defining and Using Interfaces

  • An interface is defined using the **interface** keyword.
  • Interface methods **cannot have a body** (no functionality is defined).
  • A class uses the **implements** keyword to adopt an interface (e.g., class MyClass implements MyInterface).
  • The implementing class **must** provide a concrete, public implementation for **all** methods declared in the interface.
  • All methods declared in an interface **must be public**.
  • Interfaces can define **constants** (e.g., const TYPE = "Value";).

Interfaces and Inheritance

PHP does not support extending multiple classes (multiple inheritance of state), but it **does** support implementing multiple interfaces. This is a powerful feature for establishing contracts across disparate classes.

A class can both **extend** a parent class and **implement** one or more interfaces simultaneously:

class ChildClass extends ParentClass implements InterfaceA, InterfaceB {...}

Interface vs. Abstract Class

While similar, interfaces and abstract classes differ:

  • **Methods:** An interface can only have abstract methods (no bodies). An abstract class can have both abstract and normal (concrete) methods.
  • **Properties:** An abstract class can have properties (public, private, protected). An interface cannot declare properties, only constants.
  • **Keywords:** Abstract classes are extended; interfaces are implemented.

Example Session

The Shape Contract

The shape interface mandates that any class representing a geometric shape must have a public area() method that returns a float. This enforces a consistent method signature across all shapes, regardless of how the area is calculated.


interface shape {
   // Defines a contract: every implementing class must have this method.
   public function area(): float; 
}

class circle implements shape {
   // Must implement area() with the exact signature.
   public function area(): float {
      return pow($this->radius, 2) * pi();
   }
   // ... other methods and properties
}

class square implements shape {
   // Must implement area() with the exact signature.
   public function area(): float {
      return pow($this->side, 2);
   }
   // ... other methods and properties
}

// Both circle and square objects can be treated interchangeably
// when calling the area() method because they adhere to the 'shape' contract.

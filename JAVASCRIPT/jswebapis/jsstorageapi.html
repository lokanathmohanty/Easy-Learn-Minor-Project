JavaScript - Storage API

What is Web Storage API?

The web storage API in JavaScript allows us to store the data in the user's local system or hard disk. Before the storage API, cookies were used to store the data in the browser.

Cookies have drawbacks such as sending data with every request and security issues. With storage API, data remains in the user's device.

JavaScript provides two storage objects:

  • localStorage
  • sessionStorage

The Window localStorage Object

The localStorage object stores data as key-value pairs in the browser with a maximum limit of 5 MB. Data never expires unless removed using removeItem() or clear().

Syntax

localStorage.setItem(key, value); // Set item
localStorage.getItem(key); // Get item

Example: Storing and Getting Data

<button onclick="setItem()"> Set Item </button>
<button onclick="getItem()"> Get Item </button>
<p id="demo"></p>

<script>
  const output = document.getElementById('demo');
  function setItem() {
    localStorage.setItem("fruit", "Apple");
  }
  function getItem() {
    const fruitName = localStorage.getItem("fruit");
    output.innerHTML = "The name of the fruit is: " + fruitName;
  }
</script>

Example: Storing Objects

localStorage.setItem("animal", JSON.stringify({ name: "Lion", color: "Yellow" }));

Example: Removing Items

localStorage.removeItem("name");
localStorage.clear(); // Removes all items

The Window sessionStorage Object

The sessionStorage object stores data in key-value pairs up to 5 MB. Unlike localStorage, the data is removed when the browser tab is closed.

Syntax

sessionStorage.setItem(key, value); // Set item
sessionStorage.getItem(key); // Get item

Example: Using sessionStorage

sessionStorage.setItem("username", "tutorialspoint");
const user = sessionStorage.getItem("username");

Example: Storing Images in sessionStorage

<input type="file" id="image" accept="image/*" onchange="handleImageUpload()">
<button onclick="getImage()"> Get Image </button>

<script>
  function handleImageUpload() {
    const file = document.getElementById('image').files[0];
    if (file) {
      const reader = new FileReader();
      reader.onload = function (event) {
        sessionStorage.setItem('image', event.target.result);
      };
      reader.readAsDataURL(file);
    }
  }
  function getImage() {
    const data = sessionStorage.getItem("image");
    document.body.innerHTML += `<img src="${data}" width="300">`;
  }
</script>

Cookie vs localStorage vs sessionStorage

Feature Cookie localStorage sessionStorage
Storage Limit 4 KB 5 MB 5 MB
Expiry Has expiry date Never expires Expires on tab close
Accessibility Client + Server Client only Client only
Security Less secure More secure More secure

Storage Object Methods

  • key(n) – Get name of nth key
  • length – Number of stored items
  • getItem(key) – Get value
  • setItem(key, value) – Add/update value
  • removeItem(key) – Remove specific item
  • clear() – Remove all items

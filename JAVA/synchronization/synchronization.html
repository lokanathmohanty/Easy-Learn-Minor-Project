Java - Thread Synchronization

Need of Thread Synchronization?

When multiple threads try to access the same resource at the same time, unexpected results can occur. For example, two threads writing to the same file might overwrite or corrupt data. To avoid these concurrency issues, threads must be synchronized.

Java uses monitors to synchronize threads. Every object has a monitor associated with it. Only one thread can hold a lock on a monitor at any given time.

Thread Synchronization in Java

Java provides the synchronized block to help with thread synchronization:

synchronized(objectidentifier) {
   // Access shared variables and other shared resources
}

The objectidentifier is a reference to the object whose lock is used for synchronization.

Multithreading Example without Thread Synchronization

This program may produce different output every time it is run, depending on thread scheduling.


class PrintDemo {
   public void printCount() {
      try {
         for(int i = 5; i > 0; i--) {
            System.out.println("Counter   ---   "  + i );
         }
      } catch (Exception e) {
         System.out.println("Thread  interrupted.");
      }
   }
}

class ThreadDemo extends Thread {
   private Thread t;
   private String threadName;
   PrintDemo  PD;

   ThreadDemo(String name, PrintDemo pd) {
      threadName = name;
      PD = pd;
   }
   
   public void run() {
      PD.printCount();
      System.out.println("Thread " + threadName + " exiting.");
   }

   public void start() {
      System.out.println("Starting " + threadName);
      if (t == null) {
         t = new Thread(this, threadName);
         t.start();
      }
   }
}

public class TestThread {
   public static void main(String args[]) {
      PrintDemo PD = new PrintDemo();

      ThreadDemo T1 = new ThreadDemo("Thread - 1", PD);
      ThreadDemo T2 = new ThreadDemo("Thread - 2", PD);

      T1.start();
      T2.start();

      try {
         T1.join();
         T2.join();
      } catch (Exception e) {
         System.out.println("Interrupted");
      }
   }
}

Multithreading Example with Thread Synchronization

Now we use the synchronized block to ensure only one thread at a time accesses the printCount method.


class PrintDemo {
   public void printCount() {
      try {
         for(int i = 5; i > 0; i--) {
            System.out.println("Counter   ---   "  + i );
         }
      } catch (Exception e) {
         System.out.println("Thread  interrupted.");
      }
   }
}

class ThreadDemo extends Thread {
   private Thread t;
   private String threadName;
   PrintDemo PD;

   ThreadDemo(String name, PrintDemo pd) {
      threadName = name;
      PD = pd;
   }
   
   public void run() {
      synchronized(PD) {
         PD.printCount();
      }
      System.out.println("Thread " + threadName + " exiting.");
   }

   public void start() {
      System.out.println("Starting " + threadName);
      if (t == null) {
         t = new Thread(this, threadName);
         t.start();
      }
   }
}

public class TestThread {
   public static void main(String args[]) {
      PrintDemo PD = new PrintDemo();

      ThreadDemo T1 = new ThreadDemo("Thread - 1", PD);
      ThreadDemo T2 = new ThreadDemo("Thread - 2", PD);

      T1.start();
      T2.start();

      try {
         T1.join();
         T2.join();
      } catch (Exception e) {
         System.out.println("Interrupted");
      }
   }
}

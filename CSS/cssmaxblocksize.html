CSS - max-block-size Property

The CSS max-block-size property sets the maximum block size of an element. The block dimension is determined by the writing-mode property. If the content naturally fits within the defined block size, the property has no effect.

Syntax

max-block-size: auto | length | percentage | initial | inherit;

Property Values

  • auto – Default. No maximum block size is enforced.
  • length – Sets the maximum block size using units such as px, em, rem, etc.
  • percentage – Sets the maximum block size relative to the containing element’s size.
  • initial – Resets the property to its default value.
  • inherit – Inherits the property value from its parent element.

Examples of CSS max-block-size

Example 1: Auto Value

Using auto allows the block size to expand as needed, based on the content. 

.container {
  background-color: lightgreen;
  max-block-size: auto;
}

Example 2: Length Values

You can restrict the maximum block size using absolute or relative length units. 

.size1 {
  max-block-size: 85px;
}

.size2 {
  max-block-size: 4.5em;
}

Example 3: Percentage Values

Percentage values set the maximum block size relative to the container element. 

.outer-container {
  height: 100px;
}

.size1 {
  max-block-size: 55%;
}

.size2 {
  max-block-size: 75%;
}

Example 4: With Writing Mode

The writing-mode property changes how block size is calculated:

  • horizontal-lr – block size grows from top to bottom.
  • vertical-rl – block size grows from right to left.
.container {
  max-block-size: 55%;
}

.horizontal {
  writing-mode: horizontal-lr;
}

.vertical {
  writing-mode: vertical-rl;
}

Supported Browsers

  • Chrome – 57+
  • Edge – 79+
  • Firefox – 41+
  • Safari – 12.1+
  • Opera – 44+

Summary

The max-block-size property provides a flexible way to control the maximum block dimension of an element, adapting to different writing modes. It is useful when designing responsive layouts, ensuring that blocks don’t grow excessively beyond desired limits.

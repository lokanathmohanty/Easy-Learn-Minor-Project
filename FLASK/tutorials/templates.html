Flask Templates and Jinja2 Template Engine 🖼️

While a Flask function can return hardcoded HTML strings, this is **cumbersome** when variable data or Python logic (like conditionals and loops) must be included. To avoid this, Flask utilizes the **Jinja2 template engine** to separate application logic from presentation.

Web Templating System

A web templating system allows you to design an **HTML file** (the template) with **placeholders** that are dynamically replaced by values when the template is rendered by a **template engine**. Jinja2 is Flask's default template engine.

The render_template() Function

Instead of returning an HTML string, a Flask function uses the **render_template()** function to process and return a template file. This function:

  • Accepts the template file name as the first argument.
  • Accepts any number of **keyword arguments**, which are the variables passed from the Python script to the template.

Flask automatically looks for template files inside a folder named **templates** located in the same directory as the main application script.

Example: Passing a Variable to a Template

The Python script passes the user variable to the template as name:

return render_template('hello.html', name = user)

The template (hello.html) uses the expression delimiter to display the variable:

<h1>Hello {{ name }}!</h1>

Jinja2 Delimiters

Jinja2 uses specific syntax elements to allow Python logic and variables within the HTML structure:

  • **{{ ... }}:** Used for **Expressions** to be printed (like a variable's value).
  • **{% ... %}:** Used for **Statements** (like loops, conditionals, or setting variables).
  • **{# ... #}:** Used for **Comments** that are not included in the final output.

Example: Conditional Logic and Loops in Templates

Conditional Rendering (if/else)

You can use conditional statements within the template using the {% ... %} delimiters:

{% if marks > 50 %}

<h1> Your result is pass!</h1>

{% else %}

<h1>Your result is fail</h1>

{% endif %}

Looping (for) to Display Dictionary Data

The for loop statement can be used to iterate over a collection (like the result dictionary passed from the Python function) to generate HTML content dynamically, such as table rows:

{% for key, value in result.items() %}

<tr>

<th> {{ key }} </th>

<td> {{ value }} </td>

</tr>

{% endfor %}

Notice that the loop logic is in {%...%}, while the data (key and value) to be rendered is in {{...}}.

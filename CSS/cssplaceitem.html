CSS - place-items Property

The place-items property in CSS is a shorthand property used to define both align-items and justify-items simultaneously. It is particularly useful in CSS Grid Layouts, where developers need to control the alignment of items along both the block (column) and inline (row) axes in a concise manner.

By using this shorthand, you avoid writing two separate properties, and you can achieve compact alignment configurations for grid and, to some extent, flex items.

Shorthand For

  • align-items
  • justify-items

Possible Values

  • Single Value: Applies the same alignment for both block and inline directions. Example: place-items: center;
  • Two Values: The first defines align-items (block axis) and the second defines justify-items (inline axis). Example: place-items: start end;

Common Values

  • normal – Default alignment based on the container.
  • start – Aligns items to the start edge.
  • end – Aligns items to the end edge.
  • center – Aligns items at the center.
  • stretch – Stretches items to fill the container.
  • self-start, self-end – Aligns relative to the item’s writing mode.
  • flex-start, flex-end – Similar to start and end but for flex contexts.
  • baseline, first baseline, last baseline – Aligns items to text baselines.
  • legacy values – Provide backward compatibility in certain layouts.

Applies To

All elements, but primarily useful with CSS Grid containers. Its effect on flex containers is limited and experimental.

Syntax

/* Single keyword applies to both axes */
place-items: center;

/* Align block axis then inline axis */
place-items: normal start;
place-items: end center;

/* Using baseline alignment */
place-items: first baseline legacy;
place-items: last baseline normal;

/* Using stretch */
place-items: stretch;

Examples

1. Place items inside a Grid Container

.grid-container {
   display: grid;
   grid-template-columns: repeat(3, 100px);
   height: 400px;
   width: 350px;
   place-items: center;
}

.grid-container > div {
   border: 1px solid black;
   padding: 10px;
}

In this example, all grid items are centered both vertically and horizontally inside the grid cells.

2. Place items with different alignment values

.grid-container {
   display: grid;
   grid-template-columns: repeat(3, 100px);
   height: 400px;
   width: 350px;
   place-items: start end;
}

Here, grid items align to the top (start of block axis) and to the right (end of inline axis).

3. Place items in a Flex Container (limited support)

.flex-container {
   display: flex;
   flex-wrap: wrap;
   height: 350px;
   width: 350px;
   place-items: center stretch;
}

.flex-container > div {
   border: 1px solid black;
   padding: 10px;
   width: 60px;
   height: 60px;
}

While place-items is not fully standardized for flex containers, some browsers allow it. In this case, items will align to the center vertically and stretch horizontally.

Content Summary

The place-items property provides a convenient shorthand for align-items and justify-items. It is most powerful when used in grid containers to align items along both axes. For flex layouts, its support is partial and may vary across browsers. Using place-items allows for cleaner, shorter code while keeping alignment rules consistent.

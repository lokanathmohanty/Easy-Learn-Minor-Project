JavaScript - Changing CSS

Changing CSS with JavaScript

JavaScript allows you to change the CSS of HTML elements dynamically. Each HTML element in the DOM has a style object containing properties such as color, backgroundColor, fontSize, etc. By updating these properties, you can modify the element’s appearance in real time.

Syntax

Use the following syntax to change an element’s style:

element.style.property = value;

Example: Changing the Style of an HTML Element

In this example, we change the background color of a div element when the user clicks a button. 


<div id="square">Changing the color of this Div.</div>
<button onclick="changeColor()">Change Color</button>

<script>
  function changeColor() {
    let square = document.getElementById('square');
    square.style.backgroundColor = 'red';
  }
</script>

Changing Style When an Event Triggers

You can also change styles when an event occurs. For example, the code below changes the background color and font size of a div when clicked. 


<div id="square">Click Me</div>

<script>
  const square = document.getElementById('square');
  square.addEventListener('click', () => {
    square.style.backgroundColor = 'green';
    square.style.fontSize = '25px';
  });
</script>

Changing CSS Dynamically

You can update styles dynamically using variables and user inputs. For example, selecting a radio button can change a div’s background color. 


<p id="square">Select a color</p>
<input type="radio" id="yellow" name="color"> Yellow
<input type="radio" id="green" name="color"> Green
<input type="radio" id="red" name="color"> Red

<script>
  let square = document.getElementById('square');
  let colors = document.getElementsByName('color');
  for (let i = 0; i < colors.length; i++) {
    colors[i].addEventListener('change', function () {
      square.style.backgroundColor = this.id;
    });
  }
</script>

List of Common JavaScript Style Properties

  • backgroundColor – Sets the background color.
  • color – Sets the text color.
  • fontSize – Sets the font size.
  • width / height – Sets element dimensions.
  • margin / padding – Sets spacing.
  • border – Sets border style, width, and color.
  • display – Controls element display (block, inline, none, etc.).
  • opacity – Controls element transparency.
  • zIndex – Controls stacking order of elements.
  • transform – Applies 2D/3D transformations.

There are many more style properties available in the DOM style object for advanced CSS manipulations.

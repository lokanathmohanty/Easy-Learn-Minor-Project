HTML - JavaScript

JavaScript allows you to create dynamic and interactive HTML pages. It is a high-level programming language and a core technology behind web development.

A script is a small piece of program that can add interactivity to a website, such as generating a pop-up alert box message or providing a dropdown menu. Nowadays, only JavaScript and its frameworks are used, as VBScript is not supported by major browsers.

Adding JavaScript in HTML

There are multiple ways of adding scripts to an HTML document:

  • Inline JavaScript
  • Internal JavaScript
  • External JavaScript

Inline JavaScript

You can directly add JavaScript code to HTML elements using attributes such as onclick or onload.

Example

<!DOCTYPE html>
<html>
<head>
   <title>Example of Inline JavaScript</title>
</head>
<body>
  <button onclick="alert('Hi there!')">Click Me</button>
</body>
</html>

Internal JavaScript

JavaScript code can be written directly inside the HTML document within the <script> tag.

Example

<!DOCTYPE html>
<html>
<head>
   <title>JavaScript Internal Script</title>
   <script type="text/JavaScript"> 
      function Hello(){
         alert("Hello, World");
      }
   </script>
</head>
<body>
   <input type="button" onclick="Hello();" value="Click Me" />
</body>
</html>

External JavaScript

Reusable JavaScript code can be stored in a separate file with a .js extension and linked using the <script> tag with the src attribute.

Example

// script.js
function Hello() {
   alert("Hello, World");
}
      
<!DOCTYPE html>
<html>
<head>
   <title>JavaScript External Script</title>
   <script src="/html/script.js" type="text/JavaScript"></script>
</head>
<body>
   <input type="button" onclick="Hello();" value="Click Me" />
</body>
</html>

Event Handlers

Event handlers are functions executed in response to user actions, such as mouse or keyboard events.

Example

<!DOCTYPE html>
<html>
<head>
   <title>Event Handlers Example</title>
   <script type="text/JavaScript"> 
      function EventHandler(){
         alert("I'm event handler!!");
      }
   </script>
</head>
<body>
   <p onmouseover="EventHandler();">Bring your mouse here to see an alert</p>
</body>
</html>

Hide Scripts from Older Browsers

Older browsers may display JavaScript code as text. To prevent this, wrap the code in HTML comments.

JavaScript Example

<script type="text/JavaScript">
   <!--
   document.write("Hello JavaScript!");
   // -->
</script>

VBScript Example

<script type="text/vbscript">
   <!--
   document.write("Hello VBScript!")
   '-->
</script>

The <noscript> Element

The <noscript> tag provides alternative content for users whose browsers do not support or have disabled scripts.

Example

<script type="text/JavaScript">
   document.write("Hello JavaScript!");
</script>
<noscript>Your browser does not support JavaScript!</noscript>

Default Scripting Language

You can specify a default scripting language for all <script> tags in a page using the <meta> tag.

Example

<meta http-equiv="Content-Script-Type" content="text/JavaScript" />

HTML Script Tags

  • <script> − Used to import or write JavaScript inside an HTML document.
  • <noscript> − Provides alternate content if a browser does not support scripts.

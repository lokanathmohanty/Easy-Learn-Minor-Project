JavaScript Location Object Properties

You can use the following properties of the location object:

  • hash — Sets or gets the anchor part of the URL.
  • host — Sets or gets the hostname or port number of the URL.
  • hostname — Sets or gets the hostname.
  • href — Sets or gets the full URL of the current window.
  • origin — Returns the protocol, domain, and port of the URL.
  • pathname — Sets or gets the path name.
  • port — Sets or gets the port of the URL.
  • protocol — Sets or gets the protocol.
  • search — Sets or gets the query string of the URL.

Syntax

window.location.property;
OR
location.property;

Examples

Example 1: Accessing location.host

const host = location.host;
document.getElementById("output").innerHTML = "The host is: " + host;

Output: The host of the current location is: www.tutorialspoint.com

Example 2: Accessing location.protocol

document.getElementById("output").innerHTML = "The protocol is: " + location.protocol;

Output: The protocol of the current location is: https:

Example 3: Accessing location.hostname

document.getElementById("output").innerHTML = "The host name is: " + location.hostname;

Output: The host name of the current location is: www.tutorialspoint.com

Example 4: Accessing location.pathname

document.getElementById("output").innerHTML = "The path name is: " + location.pathname;

Output: /javascript/javascript_location_object.htm

JavaScript Location Object Methods

The location object provides methods to navigate or reload the current page.

  • assign(url) — Loads a new document at the specified URL.
  • replace(url) — Replaces the current document with a new one at the specified URL.
  • reload() — Reloads the current document.
  • toString() — Returns the URL in string format.

Example: location.assign()

function changePage() {
  window.location.assign("https://www.tutorialspoint.com/");
}

When the button is clicked, the page redirects to the home page.

Location Object Properties List

  • hash — Anchor part of the URL.
  • host — Hostname or port number.
  • hostname — Hostname only.
  • href — Full URL.
  • origin — Protocol, domain, and port.
  • pathname — Path of the URL.
  • port — Port number.
  • protocol — Protocol used (e.g., http:, https:).
  • search — Query string.

Location Object Methods List

  • assign() — Loads a new document at the specified URL.
  • reload() — Reloads the web page.
  • replace() — Replaces the current document with another one.
  • toString() — Returns the URL as a string.

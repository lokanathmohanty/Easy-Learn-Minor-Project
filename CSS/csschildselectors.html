CSS - Child Selectors

A CSS child selector selects all the direct children of a specified element. It is represented using the > (greater than) symbol. Unlike descendant selectors, child selectors do not apply styles to nested elements that are deeper than one level.

Syntax

selector > child-selector {
  /* property: value; */
  color: #04af2f;
}

Example 1: Styling Direct Child Elements

In this example, the style is applied only to the <p> element that is a direct child of the <div>. The <p> inside the <span> is not affected. 

.myDiv > p {
  color: #04af2f;
}

<div class="myDiv">
  <p>Direct child paragraph of div.</p>
  <span><p>Paragraph inside span, not direct child of div.</p></span>
</div>

<p>This paragraph is outside div.</p>

Example 2: Adding Border and Font Styles

In this example, only the direct child paragraph of the <div> receives a border, font size, and font family. 

.myDiv > p {
  border: 2px solid #031926;
  font-size: 20px;
  font-family: Verdana, sans-serif;
}

<div class="myDiv">
  <p>Direct child paragraph of div.</p>
  <span><p>Paragraph inside span, not direct child of div.</p></span>
</div>

<p>This paragraph is outside div.</p>

Key Notes

  • The child selector uses the > symbol.
  • It targets only the immediate (direct) children, not deeper nested elements.
  • Useful when you want precise control over hierarchical structures in HTML.

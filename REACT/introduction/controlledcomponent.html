ReactJS - Controlled Component

In controlled component, React provides a special attribute value for all input elements and controls the input elements. The value attribute can be used to get and set the value of the input element. It has to be in sync with the state of the component.

In other words, a React component that renders a form also controls what happens in that form on subsequent user input. An input form element whose value is controlled by React in this way is called a controlled component.

Controlled component has to follow a specific process to do form programming.

Controlled Component With Single Input

Step by step process for handling a single input element:

  • Create a form element: <input type="text" name="username" />
  • Initialize state: this.state = { username: '' }
  • Add a value attribute and assign the value from state: <input type="text" value={this.state.username} />
  • Add onChange and assign a handler method: <input type="text" value={this.state.username} onChange={this.handleUsernameChange} />
  • Write the handler method to update state: this.setState({ username: e.target.value })
  • Bind the handler in constructor: this.handleUsernameChange = this.handleUsernameChange.bind(this)
  • Use this.state.username during validation and submission.

Creating a Simple Form

Let us create a simple form to add expense entry using controlled component:

  • Create a new React app react-form-app and open in editor.
  • Create ExpenseForm.css for styling.
  • Create ExpenseForm.js with controlled inputs for title, amount, date, and category.
  • Bind change handlers to update this.state.item.
  • Handle submit with onSubmit to display form data.

Example Component

The complete ExpenseForm component uses controlled inputs to track and submit expense details. Each input is bound to component state and updated with handlers.

The data is displayed in a popup (alert) after submission.

Running the Application

  • Create index.js and render ExpenseForm component.
  • Create index.html with a <div id="root">.
  • Start app with npm start.
  • Open http://localhost:3000, enter sample expense, and submit. The data will be shown in a pop-up alert.

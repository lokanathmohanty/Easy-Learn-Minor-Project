CSS Quick Guide

Introduction to CSS

CSS (Cascading Style Sheets) is used to define the presentation of HTML elements. It controls the layout, colors, fonts, spacing, and overall look of a web page. CSS helps separate content from design, making web pages easier to maintain and more visually appealing.

Basic Syntax

A CSS rule consists of a selector and a declaration block:

Syntax:

selector { property: value; }

Types of CSS

  • Inline CSS: Applied directly to an element using the style attribute.
  • Internal CSS: Written inside a <style> tag in the HTML <head>.
  • External CSS: Linked via an external stylesheet using the <link> tag.

Selectors

Selectors are used to target HTML elements for styling.

  • Element Selector: Targets HTML tags (e.g., p, h1).
  • Class Selector: Targets elements with a specific class using a dot (.).
  • ID Selector: Targets an element with a specific ID using a hash (#).
  • Group Selector: Applies the same style to multiple selectors separated by commas.

Box Model

The CSS box model describes how elements are structured:

  • Content: The actual text or image.
  • Padding: Space between content and border.
  • Border: Surrounds padding and content.
  • Margin: Space outside the border.

Conclusion

CSS is essential for designing responsive and user-friendly web pages. By mastering CSS, you can control the appearance of web applications and enhance user experience.

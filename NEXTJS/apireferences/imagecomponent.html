Next.js `<Image>` Component 🖼️

Overview and Syntax

The Next.js **`` component** extends the standard HTML `` tag, providing automatic features for optimizing images, improving loading performance, and preventing layout shift. It accepts all standard `` attributes plus additional Next.js-specific props for control over optimization.

Basic Syntax:

The `src`, `width`, `height`, and `alt` props are typically **required** when the image is not set to fill its container.

import Image from 'next/image' 

export default function Page() {
  return (
    <Image
        src="/relative/path/to/image.jpg"
        width={500}
        height={300}
        alt="Descriptive alternative text"
    />
  )}

If using images from your project's **`public`** directory, use a relative path like `/image.jpg`. For external URLs, you must configure **`remotePatterns`** in your `next.config.ts` file for security.

Key Next.js Props for ``

Prop Status Purpose & Default Value
`src` **Required** The URL or local path to the image source.
`width` / `height` **Required*** The intrinsic dimensions of the image (in pixels) to prevent layout shift. (Not required if using `fill` or `sizes`).
`alt` **Required** Alternative text for screen readers and SEO.
`fill` Optional If `true`, the image scales to fill the parent element, and `width`/`height` are not needed.
`priority` Optional If `true`, loads the image eagerly (non-lazy) and includes it in the preloaded resources, usually for **LCP (Largest Contentful Paint)** images.
`quality` Optional Defines the optimization quality (1-100), defaults to 75.
`placeholder` Optional Defines a low-quality placeholder displayed until the main image loads, often set to `"blur"` to use `blurDataURL`.
`loading` Optional Specifies native loading behavior: `"lazy"` (default for non-priority) or `"eager"`.

Example: Applying Inline Styles

You can apply standard CSS inline styles using the **`style`** prop, passed as a JavaScript object. This is useful for presentation aspects like borders, rounded corners, or object fitting.

import Image from 'next/image'

export default function Page() {
    const imageStyle = {
        borderRadius: '50%',
        border: '5px solid black',
    };

    return (
        <Image
            src="/profile.jpg"
            width={200}
            height={100}
            alt="Profile Image"
            style={imageStyle} // ← Applying the custom style
        />
    )}

PHP Indexed Arrays

An **Indexed Array** is a collection of values where each element is automatically assigned a numerical index (key) starting from **0** and incrementing sequentially. It is the simplest type of array in PHP.

Creating an Indexed Array

You can create an indexed array using the `array()` function or the short square bracket syntax `[]`:

$arr1 = array("a", 10, 9.99, true);
$arr2 = ["a", 10, 9.99, true];

**Note:** An indexed array can hold mixed data types, including strings, numbers, floats, Booleans, and even other arrays.

Accessing and Manipulating Elements

Elements are accessed using the syntax **`array[index]`**.

$arr1 = [10, 20, 30];
echo $arr1[1]; // Output: 20
$arr1[0] = 100; // Modification in place

The values can also be assigned in reverse order to a new array, demonstrating access and modification:

Reversing an array using `for` loop:
$arr1[0]=10, $arr2[4]=10
$arr1[4]=50, $arr2[0]=50

Traversing an Indexed Array

Any loop construct can be used to iterate over an indexed array:

1. `for` Loop (Using `count()` and Index)

This is the traditional method, requiring the array size to be determined first using the **`count()`** function.

$numbers = array(10, 20, 30);
for ($i=0; $i<count($numbers); $i++){
   echo "numbers[$i] = $numbers[$i] \n";
}

Output: numbers[0] = 10 ...

2. `foreach` Loop (Recommended for Simple Iteration)

The `foreach` loop simplifies traversal by automatically handling the indexing.

**Value-Only:** `foreach ($arr1 as $val) { echo $val; }`
**Key-Value:** `foreach ($arr1 as $key => $val) { echo "arr1[$key] = $val \n"; }`

Output: arr1[0] = 10 ...

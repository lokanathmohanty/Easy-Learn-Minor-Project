JavaScript - DOM Document

The JavaScript DOM document object owns all objects in the webpage. It represents the webpage. When the webpage is loaded in the browser, it creates an HTML DOM document object. It is the root of the HTML document.

The document object contains various properties and methods you can use to get details about HTML elements and customize them. With document objects, JavaScript can access and change a document's structure, content, or style.

Accessing DOM Document Object

The webpage is represented as the DOM document object. To access any element in the webpage, you start from the document object. In JavaScript, document is a property of the window object: 

window.document
// or simply
document

Window Document Object - URL Property

You can extract and work with the URL of the document using the URL property.

JavaScript DOM Document Methods

  • writeln() – Writes HTML or JavaScript to a document and adds a newline.
  • write() – Writes HTML or JavaScript directly to a document.
  • hasFocus() – Checks if the document or element has focus.
  • renameNode() – Renames a node.
  • open() – Opens a document for writing.
  • normalizeDocument() – Normalizes the entire document.
  • normalize() – Removes empty text nodes and merges adjacent ones.
  • adoptNode() – Adopts a node from another document.
  • addEventListener() – Attaches an event handler.
  • execCommand() – Executes a command on an editable section.
  • createTextNode() – Creates a text node.
  • createEvent() – Creates an event object.
  • createDocumentFragment() – Creates an empty document fragment.
  • createComment() – Creates a comment node.
  • createAttribute() – Creates an attribute object.
  • close() – Closes the output stream.
  • getElementsByTagName() – Gets elements by tag name.
  • getElementsByName() – Gets elements by name attribute.
  • getElementsByClassName() – Gets elements by class name.
  • getElementById() – Gets an element by ID.
  • createElement() – Creates an HTML element.

JavaScript DOM Document Properties

  • URL – Returns the complete document URL.
  • title – Gets or sets the title of the document.
  • scripts – Returns all script elements.
  • links – Returns all <a> and <area> elements with href.
  • lastModified – Returns last modified date/time.
  • inputEncoding – Returns document character encoding.
  • images – Returns all image elements.
  • forms – Returns all form elements.
  • head – Returns the head element.
  • domain – Returns the domain of the document.
  • documentURI – Gets or sets the document location.
  • documentElement – Returns the document element object.
  • doctype – Returns the document type declaration.
  • designMode – Checks if document is editable.
  • cookie – Allows create/read/delete cookies.
  • anchors – Lists all <a> tags with name attribute.
  • baseURI – Returns the base URI.

Examples

childElementCount Property

<div>First Element</div>
<div>Second Element</div>
<div>Third Element</div>
<div id="output"></div>

<script>
  document.getElementById('output').innerHTML =
    "Total number of child elements: " + document.childElementCount;
</script>

links Property

<div><a href="https://tutorialspoint.com/">Home</a></div>
<div><a href="https://www.tutorialspoint.com/articles/category/javascript">JavaScript</a></div>
<div id="output"></div>

<script>
  const allLinks = document.links;
  document.getElementById("output").innerHTML += "The webpage contains the below links:<br>";
  for (let link of allLinks) {
    output.innerHTML += link + "<br>";
  }
</script>

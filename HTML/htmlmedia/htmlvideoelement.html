HTML <video> Element

Overview

The HTML <video> element embeds video content in a web page. Use it to provide video playback support directly in the page. Browsers natively support common formats such as MP4, WebM and Ogg. You can supply multiple sources so the browser chooses the best supported format.

Key Points

  • The <video> element works similarly to <img>, but for video.
  • Supported formats commonly include: MP4, WebM, Ogg.
  • Provide multiple <source> elements to improve cross-browser compatibility.
  • The controls attribute enables built-in playback controls (play, pause, volume, seek).

Basic Syntax

Embed a video by adding src inside the <video> tag, or by adding one or more <source> tags:

<video width="640" height="360" controls>
  <source src="video-file.mp4" type="video/mp4">
  <source src="video-file.ogg" type="video/ogg">
  Your browser does not support the video tag.
</video>

Example: Multiple Sources

This example provides several formats. The browser picks the first supported one.

<!DOCTYPE html>
<html>
<head><title>HTML Video Element</title></head>
<body>
  <p>Playing video using video element</p>
  <video width="450" height="250" controls>
    <source src="/html/media/video/sampleTP.webm" type="video/webm">
    <source src="/html/media/video/sampleTP.mp4" type="video/mp4">
    <source src="/html/media/video/sampleTP.ogv" type="video/ogg">
    <p>Sorry, video element is not supported!</p>
  </video>
</body>
</html>

The controls Attribute

Add controls to show built-in UI controls (play, pause, seek, volume). Example: <video controls>…</video>.

Customizing Video Size

Set the width and height attributes to define the video viewport. The browser will preserve aspect ratio where possible; match dimensions to the source aspect ratio for best results. 

<video width="450" height="250" controls>
  <source src="/html/media/video/sampleTP.mp4" type="video/mp4">
</video>

Autoplay and Loop

Use autoplay and loop to auto-play and repeat the video. Many browsers restrict autoplay unless the video is muted, so combine autoplay with muted for reliable behavior. 

<video width="450" height="250" autoplay muted loop>
  <source src="/html/media/video/sampleTP.mp4" type="video/mp4">
</video>

Poster (Video Thumbnail)

The poster attribute specifies an image to show before playback begins. 

<video width="450" height="250" controls muted poster="tutorials_point.jpg">
  <source src="/html/media/video/sampleTP.mp4" type="video/mp4">
</video>

Best Practices & Accessibility

  • Provide multiple source formats for broad compatibility.
  • Always include fallback text inside the <video> element for very old browsers.
  • Use captions, transcripts, or <track> elements for accessibility (not shown here; add as needed).
  • When using autoplay, prefer muted to avoid unexpected audio for users.

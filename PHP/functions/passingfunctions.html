PHP: Passing Functions (Callbacks)

In PHP, a **function can be passed as an argument** to another function. The function being passed is known as a **callback function** or **callable**. The receiving function then invokes (calls) the callback internally to perform a specific action, promoting powerful, reusable, and modular code.

Mechanism and Syntax

A function is typically passed as a **string** containing its name. The receiving function will then execute the callback using its internal mechanism.

1. Built-in Functions that Accept Callbacks

`array_map()` (Mapping/Transformation)

This function applies a callback function to every element of one or more arrays and returns a new array containing the results.

function **square**($n) { return $n * $n; }
$arr = [1, 2, 3];
$squares = **array_map**('square', $arr);

Output: [1, 4, 9]

`call_user_func()` (Direct Call)

This function executes a given callback function, passing the remaining arguments to it.

echo **call_user_func**('square', 5); // Calls `square(5)`

Output: 25

`usort()` (Sorting)

This function sorts an array by comparing pairs of elements using a custom callback function (a comparison function that must return -1, 0, or 1).

usort($myArray, "mysort"); // `mysort` is the comparison function

2. Passing a Callback to a User-defined Function

You can define your own function to accept and call another function dynamically. This is achieved by treating the string argument containing the function name as a **variable function**.

<?php
   function **myfunction**($function, $number) {
      return **$function($number)**; // Invokes the function whose name is in $function
   }

   function cube($n) { return $n ** 3; }

   $result = **myfunction**('cube', 5);
   echo $result; // Output: 125
?>

PHP Mathematical Functions Summary

PHP includes a variety of built-in **Math Functions** to perform common mathematical operations efficiently, such as rounding numbers, calculating exponents, and finding extreme values.

Rounding and Absolute Values

These functions handle rounding and magnitude:

  • **`abs($num)`**: Returns the **absolute (positive) value** of a number, regardless of its sign.
    abs(-9.99) $\rightarrow$ `9.99`
  • **`ceil($num)`**: Rounds a float number **up** to the next highest integer. Always returns a float. (e.g., "ceiling")
    ceil(5.78) $\rightarrow$ `6.0`
    ceil(-3.95) $\rightarrow$ `-3.0` (Rounds towards zero)
  • **`floor($num)`**: Rounds a float number **down** to the next lowest integer. Always returns a float. (e.g., "floor")
    floor(5.78) $\rightarrow$ `5.0`
    floor(-3.95) $\rightarrow$ `-4.0` (Rounds away from zero)
  • **`round($num, $precision, $mode)`**: Rounds a number to the nearest integer (default precision) or to a specified number of decimal places.
    round(1234.567, 1) $\rightarrow$ `1234.6`

Exponents, Roots, and Logarithms

These functions handle exponential and logarithmic calculations:

  • **`pow($base, $exp)`**: Returns the result of **raising $base to the power of $exp** ($base^{\exp}$). Equivalent to the `**` operator.
    pow(10, 2) $\rightarrow$ `100`
  • **`sqrt($num)`**: Returns the **square root** of a number. (Equivalent to `pow($num, 0.5)`)
    sqrt(100) $\rightarrow$ `10.0`
  • **`exp($num)`**: Returns **Euler's number ($e$) raised to the power of $num$** ($e^{num}$).
  • **`log10($num)`**: Returns the **base-10 logarithm** ($\log_{10}num$) of a number.
    log10(100) $\rightarrow$ `2.0`

Comparison and Division

These functions find extreme values or perform specific division:

  • **`max($values)`**: Returns the **highest value** from an array or a list of multiple values.
    max(array(23, 142, 99)) $\rightarrow$ `142`
  • **`min($values)`**: Returns the **lowest value** from an array or a list of multiple values.
    min(array(23, 142, 99)) $\rightarrow$ `23`
  • **`intdiv($x, $y)`**: Returns the **integer quotient** of the division $x/y$, discarding the remainder.
    intdiv(10, 3) $\rightarrow$ `3`

JavaScript - Date Comparison

Date comparison is a common requirement in JavaScript applications. For example, when your internet service provider notifies you that your plan will expire in a certain number of days, this calculation is made by comparing the current date with the expiry date.

In this session, we will learn different ways to compare dates in JavaScript:

  • Using the getTime() method
  • Using the Moment.js diff() method

Using the getTime() Method

JavaScript represents dates using the Date class. The getTime() method returns the number of milliseconds since January 1, 1970 (epoch time). By comparing these values, we can check whether one date is before, after, or equal to another date.

Syntax


let date1 = new Date();
let date2 = new Date(2012, 11, 21);

if (date1.getTime() < date2.getTime()) {
   // date1 is earlier than date2
} else if (date1.getTime() > date2.getTime()) {
   // date1 is later than date2
} else {
   // both dates are equal
}

Example


let output = document.getElementById("output");

function compareDates(date1, date2) {
   if (date1.getTime() < date2.getTime()) {
      output.innerHTML += date1 + " is earlier than " + date2 + "<br/>";
   } else if (date1.getTime() > date2.getTime()) {
      output.innerHTML += date2 + " is earlier than " + date1 + "<br/>";
   } else {
      output.innerHTML += date1 + " is the same as " + date2 + "<br/>";
   }
}

// Example usage
let now = new Date();
let oldDate = new Date(2012, 11, 21);
compareDates(now, oldDate);

Using Moment.js diff() Method

Moment.js is a popular library for working with dates and times in JavaScript. Its diff() method calculates the difference between two dates in a specific unit (years, months, days, hours, seconds, etc.).

Syntax


moment(date1).diff(date2, "unit");

Example


// Include the Moment.js library first:
// <script src="https://cdnjs.cloudflare.com/ajax/libs/moment.js/2.30.1/moment.min.js"></script>

let output = document.getElementById("output");

function compareDates(date1, date2) {
   if (date1.diff(date2, "seconds") < 0) {
      output.innerHTML += date1.format("YY-MM-DD, HH:mm:ss") + " is earlier than " + date2.format("YY-MM-DD, HH:mm:ss") + "<br/>";
   } else if (date1.diff(date2, "seconds") > 0) {
      output.innerHTML += date2.format("YY-MM-DD, HH:mm:ss") + " is earlier than " + date1.format("YY-MM-DD, HH:mm:ss") + "<br/>";
   } else {
      output.innerHTML += date1.format("YY-MM-DD, HH:mm:ss") + " is the same as " + date2.format("YY-MM-DD, HH:mm:ss") + "<br/>";
   }
}

// Example usage
let currentDate = moment();
let futureDate = moment("2024-11-21");
compareDates(currentDate, futureDate);

Conclusion

We explored two approaches to date comparison in JavaScript. Using the getTime() method is a built-in solution, while Moment.js offers convenience and additional formatting features. Depending on your project needs, you can choose either approach.

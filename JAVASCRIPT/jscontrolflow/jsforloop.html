JavaScript For Loop — E-Learning Session

Overview

The JavaScript for loop is used to run a block of code repeatedly while a condition remains true. It is ideal when the number of iterations is fixed or predictable.

Learning Objectives

  • Identify the three parts of a for loop: initialization, condition, and iteration.
  • Write basic and variant for loops for arrays and strings.
  • Avoid infinite loops by managing loop conditions and breaks.

Prerequisites

  • Basic JavaScript variables and expressions.
  • Understanding of comparison and arithmetic operators.

Syntax

for (initialization; condition; iteration) { Statement(s) }

  • Initialization: runs once before the loop starts.
  • Condition: checked before each iteration; loop runs while true.
  • Iteration: updates the counter after each pass.

Examples

  • Counting from 0 to 9

    for (let i = 0; i < 10; i++) { do something with i }

  • Initialization outside the loop

    let p = 0; for (; p < 5; p++) { use p } after loop: p is 5

  • No condition (use break)

    for (;;) { if (done) { break } }

  • No iteration in header

    for (let i = 0; i < n;) { work; i++ }

Common Pitfalls

  • Forgetting to update the counter, causing infinite loops.
  • Using a loop boundary that is off by one.
  • Modifying an array while iterating without adjusting the index.

Practice Tasks

  • Create a loop that sums numbers from 1 to 100 and displays the total.
  • Iterate over an array of names and display each with its index.
  • Loop through a string and count how many vowels it contains.

Summary

The for loop is compact and flexible. Use it when the number of iterations is known, manage your condition carefully, and ensure the counter updates correctly to avoid infinite loops.

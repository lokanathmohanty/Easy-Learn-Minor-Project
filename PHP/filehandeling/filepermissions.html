PHP - File Permissions

File **permissions** are central to the Unix/Linux file system, determining who can access a file and how (read, write, or execute). In PHP, you can programmatically manage these permissions using functions that mirror the Linux terminal commands like chmod, chown, and chgrp.

The Permissions String

Permissions are displayed using a 10-character string (e.g., -rwxr-xr-x) where the characters define access for three types of users: **User (Owner)**, **Group**, and **Other (World)**.

  • **Position 1:** Indicates the file type (d for directory, - for file).
  • **Positions 2-4 (User):** Read (r), Write (w), Execute (x) permissions for the file **owner**.
  • **Positions 5-7 (Group):** Read, Write, Execute permissions for the **group**.
  • **Positions 8-10 (Other):** Read, Write, Execute permissions for **everyone else**.

Octal Representation of Permissions

The PHP chmod() function requires permissions to be specified as an **octal number**, which is a combination of the following values:

Value Permission Binary (rwx)
4 Read (r) 100
2 Write (w) 010
1 Execute (x) 001

Each digit in the 4-digit octal number (e.g., 0755) is the sum of the permissions for a specific user class (Owner, Group, Other).

  • 7 (Full Permissions) = 4 (Read) + 2 (Write) + 1 (Execute)
  • 5 (Read & Execute) = 4 (Read) + 0 (Write) + 1 (Execute)
  • 0 (No Permissions) = 0 + 0 + 0

The chmod() Function

The chmod() function changes the file mode (permissions) and is effective primarily on Linux/Unix systems. 

chmod(string $filename, int $permissions): bool

The $permissions parameter is a four-digit octal number (the first digit is often 0, followed by digits for Owner, Group, and Other).

Example: Using chmod()

Examples of setting permissions on sample.txt:

  • chmod("/PhpProject/sample.txt", 0600): Read and Write for owner, nothing for everybody else (-rw-------).
  • chmod("/PhpProject/sample.txt", 0644): Read and Write for owner, Read for everybody else (-rw-r--r--).
  • chmod("/PhpProject/sample.txt", 0755): Everything for owner, Read and Execute for everybody else (-rwxr-xr-x).
<?php

   // Everything for owner (7), read and execute for group/other (5)
   chmod("/PhpProject/sample.txt", 0755);

   // Read and write for owner (6), read for owner's group (4), nothing for others (0)
   chmod("/PhpProject/sample.txt", 0640);
?>

The chown() and chgrp() Functions

These functions change the ownership of a file; they typically require superuser (root) privileges to execute.

chown() (Change Owner)

Attempts to change the **owner** of the file to a new user. 

chown(string $filename, string|int $user): bool

chgrp() (Change Group)

Attempts to change the **group** of the file. A non-superuser may change the group only to a group they are a member of. 

chgrp(string $filename, string|int $group): bool

Example: Using chgrp()

This example changes the group of sample.txt to "admin" and then retrieves the new group ID. 

<?php
   $filename = "/PhpProject/sample.txt";
   
   // Attempt to change the file's group
   chgrp($filename, "admin");
   
   // Clear stat cache to ensure filegroup() returns the new value
   clearstatcache();
   
   // Output the new group information (actual output depends on system configuration)
   printf("File group ID after chgrp: %d\n", filegroup($filename));
?>

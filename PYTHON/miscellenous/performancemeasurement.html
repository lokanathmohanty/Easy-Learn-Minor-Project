Python Performance Measurement

Performance measurement is essential when multiple algorithms can solve the same problem. Python's timeit module measures execution time of Python code snippets.

The timeit.timeit() function executes the given code multiple times and returns the total time taken.

Syntax:

timeit.timeit(stmt, setup, timer, number)
  • stmt: Code snippet to measure.
  • setup: Code to prepare environment.
  • timer: Timer function (optional).
  • number: Number of executions (default 1,000,000).

Example: List Comprehension vs For Loop

List comprehension is generally more efficient than explicit loops in Python.

from timeit import timeit

# Using list comprehension
time_lc = timeit('[n*2 for n in range(100)]', number=10000)

# Using for loop with append
code_loop = '''
numbers = []
for n in range(100):
    numbers.append(n*2)
'''
time_loop = timeit(code_loop, number=10000)

print("List comprehension time:", time_lc)
print("For loop time:", time_loop)

Example output:

List comprehension time: 0.086

For loop time: 0.101

This shows list comprehension is faster.

Example: Factorial Function Performance

Compare performance of iterative vs recursive factorial implementations.

def fact(x):
    fact = 1
    for i in range(1, x+1):
        fact *= i
    return fact

def rfact(x):
    if x == 1:
        return 1
    else:
        return x * rfact(x-1)

print("Using loop:", fact(10))
print("Using recursion:", rfact(10))

Output:

Using loop: 3628800

Using recursion: 3628800

import timeit

setup1 = "from __main__ import fact; x=10"
setup2 = "from __main__ import rfact; x=10"

time_loop = timeit.timeit("fact(x)", setup=setup1, number=10000)
time_rec = timeit.timeit("rfact(x)", setup=setup2, number=10000)

print("Performance of factorial function with loop:", time_loop)
print("Performance of factorial function with recursion:", time_rec)

Typical output shows recursive version is slower.

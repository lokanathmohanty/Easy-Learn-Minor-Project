JavaScript - Assignment Operators

Assignment operators in JavaScript are used to assign values to variables. They take two operands: the left operand (always a variable) and the right operand (which can be a literal, variable, or expression).

Example:

  • let x = 10; (right operand is a literal)
  • let y = x; (right operand is a variable)
  • let z = x + 10; (right operand is an expression)

Arithmetic Assignment Operators

Arithmetic assignment operators combine arithmetic operations with assignment.

  • = (Assignment) → a = b
  • += (Addition Assignment) → a += b (equivalent to a = a + b)
  • -= (Subtraction Assignment) → a -= b
  • *= (Multiplication Assignment) → a *= b
  • /= (Division Assignment) → a /= b
  • %= (Remainder Assignment) → a %= b
  • **= (Exponentiation Assignment) → a **= b

Examples

  • Simple Assignment (=): let x = 5;
  • Assignment Chaining: let x = y = 5;
  • Addition Assignment: x += 7; → adds and assigns
  • String Concatenation: x += " World";
  • Subtraction Assignment: x -= 5;
  • Multiplication Assignment: x *= 5;
  • Division Assignment: x /= 5;
  • Remainder Assignment: x %= 5;
  • Exponentiation Assignment: x **= 3;

Bitwise Assignment Operators

These perform a bitwise operation first, then assign the result.

  • &= (Bitwise AND Assignment) → a &= b
  • |= (Bitwise OR Assignment) → a |= b
  • ^= (Bitwise XOR Assignment) → a ^= b

Shift Assignment Operators

  • <<= (Left Shift Assignment) → a <<= b
  • >>= (Right Shift Assignment) → a >>= b
  • >>>= (Unsigned Right Shift Assignment) → a >>>= b

Logical Assignment Operators

  • &&= (Logical AND Assignment) → a &&= b
  • ||= (Logical OR Assignment) → a ||= b
  • ??= (Nullish Coalescing Assignment) → a ??= b

Key Points

  • Assignment operators evaluate the right-hand expression first, then assign the result.
  • Compound assignment operators combine operations like arithmetic, bitwise, or logical with assignment.
  • Useful for writing concise and efficient code.

PHP Variable Handling Functions

**PHP Variable Handling Functions** are a set of built-in functions that provide tools to inspect, test, manipulate, and convert the data types and states of variables in your code. They are part of the PHP core and require no special installation.

Key Variable Handling Categories

The provided list of 36 functions can be grouped into several key areas:

1. Type Testing Functions (is_*) 🧐

These functions check if a variable belongs to a specific data type and return a boolean (`TRUE` or `FALSE`).

  • **Basic Types:** is_int() (or is_integer(), is_long()), is_float() (or is_double(), is_real()), is_string(), is_bool(), is_array(), is_object(), is_null().
  • **Special Types:** is_resource(), is_callable(), is_countable(), is_iterable().
  • **General Tests:** is_numeric() (checks for a number or numeric string), is_scalar() (checks if the variable holds a simple scalar value: boolean, integer, float, or string).

2. Type Casting and Conversion Functions 🔄

These functions explicitly convert a variable's value to a different type.

  • **Casting:** intval(), floatval() (or doubleval()), strval(), boolval().
  • **Setting Type:** settype() (changes the actual type of the variable).
  • **Getting Type:** gettype() (returns the current data type as a string).

3. State and Existence Functions ✅

These functions check the existence and emptiness of a variable.

  • **Check Existence:** isset() (checks if a variable is declared and is not NULL).
  • **Check Emptiness:** empty() (checks if a variable is empty, e.g., NULL, `0`, empty string `""`, empty array `[]`).
  • **Destroy/Unset:** unset() (destroys a variable).

4. Debugging and Output Functions 🐛

These functions help developers inspect the content and structure of variables for debugging purposes.

  • **Detailed Dump:** var_dump() (displays structured information, including type and value).
  • **Readable Print:** print_r() (prints a human-readable representation, especially useful for arrays/objects).
  • **Export:** var_export() (returns a parsable string representation of a variable).
  • **All Variables:** get_defined_vars() (returns an array of all currently defined variables).

5. Serialization Functions 💾

These functions allow complex data structures to be saved and restored.

  • **Store:** serialize() (converts a variable into a storable string representation).
  • **Restore:** unserialize() (converts a serialized string back into a PHP variable).

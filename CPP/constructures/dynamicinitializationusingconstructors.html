Dynamic Initialization Using Constructors in C++ 🚀

**Dynamic initialization** is the process of initializing variables or objects at **runtime** (execution time). When this is performed using a class's constructor, it allows objects to be created and initialized with values that are determined, calculated, or retrieved only during program execution, providing great flexibility.

Mechanism and Syntax

Dynamic object creation uses the **new operator** along with the class constructor. The `new` operator allocates memory for the object on the heap and then automatically calls the specified constructor to initialize that memory.

Syntax

ClassName* objectName = new ClassName(constructor_arguments);
  • The result is a **pointer** (`objectName`) to the newly created object.
  • When the object is no longer needed, its memory must be explicitly released using **delete objectName;** to prevent memory leaks.

Example

// Constructor: Rectangle(int w, int h)
// Dynamic Initialization:
Rectangle* rect = new Rectangle(10, 5); // Width=10, Height=5 are set at runtime

rect->display(); // Accessing members using the arrow operator

delete rect;     // Essential to free allocated memory

Advantages

Using constructors for dynamic initialization is beneficial because it:

  • **Runtime Flexibility:** Allows initialization with values that are not compile-time constants (e.g., user input, file data).
  • **Encapsulation:** Keeps the initialization logic clean and encapsulated within the constructor definition, making the main code block simpler.
  • **Controlled Lifespan:** Objects created dynamically exist until they are explicitly destroyed with `delete`, allowing for memory management beyond block scope.

Python - Assignment Operators

The assignment operator in Python is =. It assigns the value of the expression on its right-hand side to the variable on the left-hand side. Unlike Mathematics, here the = symbol does not mean equality but assignment.

Example:

a = 10
b = 5
a = a + b
print(a) # Output: 15

Python also provides augmented assignment operators (or cumulative assignment operators). They combine an arithmetic operator with the assignment operator. For example, a += b is equivalent to a = a + b.

These operators work with integers, floats, and complex numbers (with some restrictions).

Types of Augmented Assignment Operators

  • Augmented Addition (+=)
  • Augmented Subtraction (-=)
  • Augmented Multiplication (*=)
  • Augmented Division (/=)
  • Augmented Modulus (%=)
  • Augmented Exponent (**=)
  • Augmented Floor Division (//=)

Examples

Augmented Addition (+=)

a=10; b=5
a += b
print(a, type(a)) # 15, int

a=10; b=5.5
a += b
print(a, type(a)) # 15.5, float

a=10.5; b=5+6j
a += b
print(a, type(a)) # (15.5+6j), complex

Augmented Subtraction (-=)

a=10; b=5
a -= b
print(a, type(a)) # 5, int

a=10; b=5.5
a -= b
print(a, type(a)) # 4.5, float

a=10.5; b=5+6j
a -= b
print(a, type(a)) # (5.5-6j), complex

Augmented Multiplication (*=)

a=10; b=5
a *= b
print(a, type(a)) # 50, int

a=10; b=5.5
a *= b
print(a, type(a)) # 55.0, float

a=6+4j; b=3+2j
a *= b
print(a, type(a)) # (10+24j), complex

Augmented Division (/=)

a=10; b=5
a /= b
print(a, type(a)) # 2.0, float

a=10; b=5.5
a /= b
print(a, type(a)) # 1.818..., float

a=6+4j; b=3+2j
a /= b
print(a, type(a)) # (2+0j), complex

Augmented Modulus (%=)

a=10; b=5
a %= b
print(a, type(a)) # 0, int

a=10; b=5.5
a %= b
print(a, type(a)) # 4.5, float

Note: Not supported for complex numbers.

Augmented Exponent (**=)

a=10; b=5
a **= b
print(a, type(a)) # 100000, int

a=10; b=5.5
a **= b
print(a, type(a)) # 316227.76..., float

a=6+4j; b=3+2j
a **= b
print(a, type(a)) # complex result

Augmented Floor Division (//=)

a=10; b=5
a //= b
print(a, type(a)) # 2, int

a=10; b=5.5
a //= b
print(a, type(a)) # 1.0, float

Note: Not supported for complex numbers.

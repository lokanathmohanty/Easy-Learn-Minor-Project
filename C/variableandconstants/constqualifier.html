The const Qualifier in C

The const qualifier in C is used to declare variables whose values should remain constant throughout the program. Once declared as const, a variable becomes read-only and cannot be modified.

Why Use const?

Using const improves code safety, readability, and maintainability by clearly signaling which values are meant to remain fixed. It protects important constants such as mathematical values (like PI), array sizes, or configuration values from accidental changes.

Example of const Variable


#include <stdio.h>

int main() {
   const float PI = 3.14;
   printf("Value of PI: %f\n", PI);
   // PI = 10;  // Not allowed, will cause error
   return 0;
}

Using const with Pointers

The const qualifier can be used in three pointer-related scenarios:

  • Pointer to constant: The pointer can point to different variables, but the value pointed to cannot be changed through the pointer.
  • Constant pointer to variable: The pointer cannot point elsewhere but the value it points to can be changed.
  • Constant pointer to constant: The pointer cannot be changed to point elsewhere, nor can the value be changed through it.

Pointer to Constant Example


#include <stdio.h>

int main() {
   int x = 10, y = 20;
   const int *ptr = &x;
   printf("Value pointed by ptr: %d\n", *ptr);
   // *ptr = 15; // Error: cannot modify value through ptr
   ptr = &y;    // Allowed: pointer can point elsewhere
   printf("Value pointed by ptr: %d\n", *ptr);
   return 0;
}

Constant Pointer to Variable Example


#include <stdio.h>

int main() {
   int i = 10, j = 20;
   int* const ptr = &i;
   printf("ptr: %d\n", *ptr);
   *ptr = 100; // Allowed: value can be changed
   printf("ptr: %d\n", *ptr);
   // ptr = &j; // Error: pointer cannot point elsewhere
   return 0;
}

Constant Pointer to Constant Example


#include <stdio.h>

int main() {
   int i = 10, j = 20;
   const int* const ptr = &i;
   printf("ptr: %d\n", *ptr);
   // ptr = &j; // Error: pointer cannot point elsewhere
   // *ptr = 50; // Error: value cannot be changed
   return 0;
}

Advantages of const

  • Prevents accidental modification of important values.
  • Improves program safety and reduces bugs.
  • Makes intentions clear to programmers and the compiler.
  • Allows compiler optimizations for read-only data.
  • Reduces unnecessary copying of values, improving performance.

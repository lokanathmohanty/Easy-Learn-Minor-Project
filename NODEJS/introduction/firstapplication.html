Node.js - First Application

Console Application

Node.js allows execution of JavaScript code outside the browser via a command-line interface. To test installation, create a simple "Hello World" program.

Save the following code in a file named hello.js:

console.log("Hello World");

Open a terminal, navigate to the file's directory, and run the command: 

node hello.js

The output will display:

Hello World

Creating a "Hello, World!" Web Application

Building on the console app, the web application requires:

  • Importing required Node.js modules with require
  • Creating a server to listen for client requests
  • Reading requests and returning HTTP responses

Step 1 - Import Required Module

var http = require("http");

Step 2 - Create Server

Use http.createServer() method, passing a request listener function that sends an HTTP response with a "Hello World" message. 


listener = function (request, response) {
  response.writeHead(200, {'Content-Type': 'text/html'});
  response.end('<h2 style="text-align: center;">Hello World</h2>');
};

Step 3 - Testing Request & Response

Combine the components as below in a file named hello.js: 


http = require('node:http');
listener = function (request, response) {
  response.writeHead(200, {'Content-Type': 'text/html'});
  response.end('<h2 style="text-align: center;">Hello World</h2>');
};
server = http.createServer(listener);
server.listen(3000);
console.log('Server running at http://127.0.0.1:3000/');

Run the application with the command: 

node hello.js

The terminal displays:

Server running at http://127.0.0.1:3000/

Open a browser and navigate to http://127.0.0.1:3000/ to see the "Hello World" message displayed.

JavaScript - Lazy Loading

In JavaScript, lazy loading is a technique to improve website performance by only loading what is immediately needed, such as images or videos in the current viewport. Content not visible on the screen is loaded later when it becomes necessary.

For example, when you open Instagram, only the images and videos visible on the current screen are loaded. As you scroll down, more images and videos are fetched. This makes the app load faster and improves the user experience.

Why Do We Need Lazy Loading?

  • Useful when a website contains many images or files.
  • Improves overall performance of the website.
  • Enhances user experience by loading content on demand.
  • Reduces initial loading time of the website.

Example of Lazy Loading

The following code snippet demonstrates how to implement lazy loading in JavaScript: 

const images = document.querySelectorAll("[data-src]");

function preloadImage(img) {
  const src = img.getAttribute("data-src");
  if (!src) {
    return;
  }
  img.src = src;
  img.removeAttribute("data-src");
}

const imgOptions = {
  threshold: 0,
  rootMargin: "0px 0px 300px 0px"
};

const imgObserver = new IntersectionObserver((entries, imgObserver) => {
  entries.forEach(entry => {
    if (!entry.isIntersecting) {
      return;
    } else {
      preloadImage(entry.target);
      imgObserver.unobserve(entry.target);
    }
  });
}, imgOptions);

images.forEach(image => {
  imgObserver.observe(image);
});

Explanation

This code sets up lazy loading for images using the IntersectionObserver API:

  • Images with the attribute data-src act as placeholders.
  • The IntersectionObserver watches when an image enters the viewport.
  • When an image is visible, its data-src is replaced with src and loaded.
  • The observer then stops watching that image to avoid reloading.

This ensures that the page doesn’t load all images at once, improving performance and reducing load time.

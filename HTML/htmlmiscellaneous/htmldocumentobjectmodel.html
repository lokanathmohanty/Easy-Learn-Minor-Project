HTML Document Object Model (DOM)

The HTML Document Object Model (in short, HTML DOM) represents all the elements of an HTML document in a hierarchical order (or tree structure). Each node in this tree represents an element in the HTML document.

Accessing and Modifying HTML DOM

Using HTML DOM methods, we can access the tree and modify the structure or contents of the document. We can also attach events to the nodes.

HTML DOM Tree Structure

If your document contains elements like <html>, <head>, <body>, <title>, <link>, <img>, and <p>, the browser will create a DOM Tree with <html> as the root, and <head> and <body> as its child elements.

What is Document Object Model?

The Document Object Model (DOM) is a programming interface that represents web documents as a tree of objects. It acts as a bridge between web pages and programming languages. Each branch of the tree ends with a node, and each node represents an object.

The DOM provides methods that allow programming languages, such as JavaScript, to access and manipulate the tree. It enables dynamic and interactive web pages. The DOM itself is language-independent.

HTML DOM vs JavaScript DOM

We use HTML to structure a web page and JavaScript to make it interactive. However, JavaScript relies on the HTML DOM to interact with the page. When an HTML page loads, the browser creates a DOM, which JavaScript can then use to manipulate the page.

  • Access and replace HTML elements.
  • Access and replace HTML attributes.
  • Change CSS styles dynamically.
  • Respond to user events.
  • Add animations to the page.
HTML DOM JavaScript DOM
The HTML DOM represents all elements of a document in a tree structure. The JavaScript DOM is an API that allows JavaScript to add, change, and replace elements, attributes, and events.

DOM Methods Reference

  • toString() – Converts an element into a string format.
  • setAttribute() – Defines attributes for an element.
  • setAttributeNode() – Defines a specific attribute node.
  • scrollIntoView() – Scrolls an element into view.
  • querySelector() – Selects the first element matching a CSS selector.
  • querySelectorAll() – Selects all elements matching a CSS selector.
  • remove() – Deletes an element from the document.
  • removeAttribute() – Deletes an attribute from an element.
  • removeChild() – Removes a child element.
  • replaceChild() – Replaces one child with another.
  • hasAttribute() – Checks if an attribute exists.
  • hasChildNodes() – Checks if an element has child nodes.

DOM Properties Reference

  • title – Access or update the title attribute.
  • textContent – Access or update the text content of an element.
  • tagName – Returns the tag name of an element.
  • style – Access CSS styles set on an element.
  • scrollTop / scrollLeft – Get or set scroll position.
  • id – Get or set the element’s ID.
  • innerText – Get or change visible text content.
  • lastChild / lastElementChild – Access the last child node/element.

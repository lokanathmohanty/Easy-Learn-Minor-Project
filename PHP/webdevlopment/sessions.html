PHP - Managing Web Sessions

Web Sessions: Maintaining User State

A **web session** represents the period a user interacts with a website. Since HTTP is stateless, PHP sessions provide a way to make data accessible across multiple pages of an entire website, allowing the application to maintain information about a user's actions and preferences. The session data is managed in the superglobal associative array **$\text{\$_SESSION}$**.

Starting and Identifying a Session

To access or start a session, the **$\text{session\_start()}$** function must be called at the beginning of the PHP script, before any output. This function either resumes an existing session or initiates a new one by:

  • Creating a **unique identifier** (a random 32-character hexadecimal string).
  • Automatically sending a cookie named **$\text{PHPSESSID}$** to the client to store this ID.
  • Creating a temporary file on the server (location set by $\text{session.save\_path}$ in $\text{php.ini}$) to store session variables.

The unique identifier can be retrieved using the **$\text{session\_id()}$** function.

Example: Handling Session Variables and Destruction

Accessing and Setting Variables

Session variables are simple key-value pairs stored in the $\text{\$_SESSION}$ array and persist across page loads. The $\text{isset()}$ function is used to check if a session variable already exists.

<?php
   session_start();

   // Set a new session variable
   $_SESSION['user_theme'] = 'dark';

   // Example: Incrementing a counter for each visit during the session
   if( isset( $_SESSION['counter'] ) ) {
      $_SESSION['counter'] += 1;
   } else {
      $_SESSION['counter'] = 1;
   }

   echo "Visits in this session: " . $_SESSION['counter'];
?>

Destroying Sessions

To stop maintaining the user's state, a session can be destroyed:

  • **To destroy a single variable:** Use the **$\text{unset()}$** function on the specific $\text{\$_SESSION}$ key (e.g., $\text{unset(\$_SESSION['counter'])}$).
  • **To destroy the entire session:** Call the **$\text{session\_destroy()}$** function. This removes the session data file on the server.

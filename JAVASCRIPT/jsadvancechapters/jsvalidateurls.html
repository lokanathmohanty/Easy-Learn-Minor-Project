JavaScript - Validate URLs

In this chapter, we will learn how to validate URLs in JavaScript. Before that, let’s understand what a URL is.

What is a URL?

A URL (Uniform Resource Locator) identifies web pages, images, videos, and other resources on the internet. It is essentially the website address that helps transfer files, send emails, and navigate the web.

URLs usually consist of a protocol (e.g., http, https), a domain name, and a top-level domain (e.g., .com, .org).

Since URLs are used in links and buttons to navigate, we must verify their validity before using them.

Validating URLs in JavaScript

There are multiple ways to validate URLs in JavaScript. Let’s first look at some rules that define a valid URL.

Rules to Validate URLs

  • URL must start with http://, https://, or www.
  • URL must contain a valid domain name.
  • URL must include a top-level domain like .com, .org, .net, etc.
  • URL must not contain spaces.

Using Regular Expression

A regular expression describes a pattern of characters. We can use it to check whether a string follows the rules of a valid URL.

Syntax

string.match(regExp);
var pattern = new RegExp(regExp);
pattern.test(string);

Example

let url = "https://www.tutorialspoint.com";
let pattern = new RegExp("^(http:\/\/www\.|https:\/\/www\.|http:\/\/|https:\/\/)?[a-z0-9]+([\-\.]{1}[a-z0-9]+)*\.[a-z]{2,5}(:[0-9]{1,5})?(\/.*)?$");

if (pattern.test(url)) {
   console.log("URL is valid");
} else {
   console.log("URL is not valid");
}

Using URL() Constructor

The built-in URL() constructor creates a new URL object. If the string is invalid, it throws a TypeError. We can also check the protocol property to confirm validity.

Syntax

var url = new URL(urlStr);
new URL(url, base);
return url.protocol === 'http:' || url.protocol === 'https:';

Example

try {
   let url = new URL("https://www.tutorialspoint.com");
   if (url.protocol === 'http:' || url.protocol === 'https:') {
      console.log("URL is valid");
   } else {
      console.log("URL is not valid");
   }
} catch (e) {
   console.log("URL is not valid");
}

Conclusion

We explored two methods to validate URLs:

  • Regular Expression: Matches URL patterns.
  • URL() Constructor: A simpler, built-in way to check validity.

Both methods are useful, and the choice depends on the project requirements.

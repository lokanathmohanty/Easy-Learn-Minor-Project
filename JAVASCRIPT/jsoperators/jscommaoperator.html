JavaScript - Comma Operator

The comma operator (,) in JavaScript evaluates multiple expressions from left to right. Each expression is evaluated, but only the result of the rightmost expression is returned. This operator can also be used in for loops, arrays, objects, and other contexts.

Syntax


var answer = (exp1, exp2, exp3, exp4, ...);

Return Value: Returns the value of the last (rightmost) expression.

Examples

Example: The Comma Operator with Strings

Here, each string is treated as an expression, but only the rightmost string is returned.


<html>
<body>
    <p id="output"></p>
    <script>
        let output = document.getElementById("output");
        let ans = ("JavaScript", "Python", "HTML", "CSS");
        output.innerHTML = "The value of the ans variable is: " + ans;
    </script>
</body>
</html>

Example: The Comma Operator with Expressions

The variable a is updated step by step, but the final result is from the last expression.


<html>
<body>
    <p id="output"></p>
    <script>
        let output = document.getElementById("output");
        let a = 5;
        let ans = (a = 8, a++, a += 2);
        output.innerHTML = "The value of the ans variable is: " + ans;
    </script>
</body>
</html>

Example: The Comma Operator with Functions

Both functions are executed, but the return value comes from the last function.


<html>
<body>
    <p id="output"></p>
    <script>
        let output = document.getElementById("output");
        function first() {
            output.innerHTML += "The first function is called! <br/>";
            return 1;
        }

        function second() {
            output.innerHTML += "The second function is called! <br/>";
            return 2;
        }

        let ans = (first(), second());
        output.innerHTML += "The value of the ans variable is: " + ans;
    </script>
</body>
</html>

Other Use Cases of the Comma Operator

  • Defining multiple variables in a single row: 
    let m = 1, n = 2, x = 3;
  • Initializing an array: 
    const arr = [10, 20, 30, 40, 50, 60];
  • Defining an object with multiple properties: 
    
const obj = {
   name: "tutorialspoint",
   age: 10,
   // other properties
}
  • Using in a for loop: 
    
for (let p = 0, q = 1; p < n; p++, q++) {
   // Code for the loop
}
  • Passing multiple arguments to a function: 
    
function func(param1, param2, ...) {  
   // function code
}

func(10, 20, 30, ...);
  • Importing/exporting multiple members: 
    
import { func2, variable } from './module2.js';
export { func1, variable, num };
  • Destructuring arrays: 
    let [a, b, c] = [34, 72, 23];
  • Printing multiple values in the console: 
    console.log(a, b, c);

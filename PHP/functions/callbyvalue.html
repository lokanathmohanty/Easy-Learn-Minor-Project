PHP: Call by Value (Default Argument Passing)

By default, PHP uses the **Call by Value** mechanism for passing arguments to a function. This means that when a function is called, the **value** of the actual argument is **copied** into the formal parameter variable inside the function.

Key Principle: Immutability of the Original Value

Because the function works on a **copy**, any changes made to the formal parameter (the local variable inside the function) **do not affect** the original variable (the actual argument) passed from the calling environment.

  • **Actual Arguments:** The variables/values passed during the function call (outside the function).
  • **Formal Arguments:** The variables declared in the function definition (inside the function). They act as **local variables**.

Demonstration of Call by Value

In the following example, the function attempts to increment the value of the number, but the change is confined to the function's scope.

<?php
   function increment($num) {
      echo "Initial inside: $num \n";
      $num++; // Only the copy is incremented
      echo "Final inside: $num \n";
   }

   $x = 10;
   increment($x);
   echo "Outside: $x"; // The original value remains 10
?>

Output:
Initial inside: 10
Final inside: 11
Outside: 10

Suitability

Call by value is the ideal mechanism for functions that perform a computation (e.g., addition, subtraction, or formula calculation) and return a result, but are **not intended to modify** the input variables themselves.

C# `do...while` Loop

Introduction to the `do...while` Loop

The **`do...while` loop** is a repetition control structure similar to the `while` loop, but with one critical difference: it is a **post-test loop**. This means the loop body executes **first**, and the condition is checked **at the end**.

This structure guarantees that the statements within the loop will execute **at least once**, even if the condition is initially false. This makes it ideal for scenarios requiring a mandatory initial execution, such as menu display or input validation.

Syntax and Control Flow

Syntax:

do {
   statement(s);
} while( condition ); // Note the mandatory semicolon

Control Flow:

  1. The code block within the **`do`** section executes.
  2. The **`condition`** (in the `while` part) is then evaluated.
  3. If the condition is true, the flow of control jumps back to the **`do`** block, and the process repeats.
  4. If the condition is false, the loop terminates, and execution continues with the statement following the `while` line.

Example: Guaranteed Execution (10 to 19)

The loop executes once before checking if a < 20 is true. Since the starting value of a is 10, the loop continues until a reaches 20.

using System;
class Program {
    static void Main(string[] args) {
        int a = 10;
         
        do {
            Console.WriteLine("value of a: {0}", a);
            a = a + 1;
        } while (a < 20);
    }
}

Output: Values 10 through 19 are printed.

Common Use Cases

The `do...while` loop is specifically chosen when the task requires an initial run:

  • **User Input & Validation:** Prompting the user for input and continuing to loop until the input satisfies a criteria (e.g., entering a positive number). This ensures the prompt is shown at least once.
  • **Menu-Driven Programs:** Displaying a main menu to the user and looping back until a specific exit option is chosen. The menu must be displayed initially.
  • **Retry Mechanisms:** Attempting an operation (like connecting to a server) once, then checking a condition (success) to determine if further attempts are needed.

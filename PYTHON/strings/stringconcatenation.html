Python - String Concatenation

Concatenate Strings in Python

String concatenation in Python is the operation of joining two or more strings together. The result is always a new string that contains the original strings combined.

Ways to Concatenate Strings

In Python, there are multiple ways to concatenate strings. The most common are:

  • Using + operator
  • Concatenating strings with space
  • Using multiplication (*) operator
  • Using both + and * operators together

1. Using '+' Operator

The + operator acts as a concatenation operator when used with string operands. It appends the characters of the second string to the first string, returning a new string.

str1 = "Hello"
str2 = "World"
print("String 1:", str1)
print("String 2:", str2)
str3 = str1 + str2
print("String 3:", str3)

Output:

String 1: Hello
String 2: World
String 3: HelloWorld

2. Concatenating Strings with Space

To insert a space between two strings, add a third string containing whitespace during concatenation.

str1 = "Hello"
str2 = "World"
blank = " "
print("String 1:", str1)
print("String 2:", str2)
str3 = str1 + blank + str2
print("String 3:", str3)

Output:

String 1: Hello
String 2: World
String 3: Hello World

3. String Concatenation by Multiplying

The * operator acts as a repetition operator when used with a string and an integer. It concatenates multiple copies of the string.

newString = "Hello" * 3
print(newString)

Output:

HelloHelloHello

4. String Concatenation with '+' and '*' Operators

You can combine the + and * operators in a single expression. Note that * has higher precedence than +.

str1 = "Hello"
str2 = "World"
print("String 1:", str1)
print("String 2:", str2)

str3 = str1 + str2 * 3
print("String 3:", str3)

str4 = (str1 + str2) * 3
print("String 4:", str4)

Output:

String 1: Hello
String 2: World
String 3: HelloWorldWorldWorld
String 4: HelloWorldHelloWorldHelloWorld

Note: Apart from + and *, no other arithmetic operators can be used with string operands.

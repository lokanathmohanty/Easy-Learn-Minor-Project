NumPy: Array Copy vs View

In NumPy, the distinction between copy and view is fundamental. A copy creates a new, independent array, while a view provides a new perspective on the original array's data without duplicating it. This affects how changes to one are reflected in the other.

  • Copy: Modifications to a copied array do not impact the original array, and vice versa.
  • View: Changes to a view or the original array are reflected in both, since they share the same data.

Example: Array Copy

This example demonstrates how changing the original array does not affect its copy:

import numpy as np
arr = np.array([1, 2, 3, 4, 5])
x = arr.copy()
arr[0] = 42
print(arr)  # [42 2 3 4 5]
print(x)    # [1 2 3 4 5]

Example: Array View

Modifying the original array will also change the view, and vice versa:

import numpy as np
arr = np.array([1, 2, 3, 4, 5])
x = arr.view()
arr[0] = 42
print(arr)  # [42 2 3 4 5]
print(x)    # [42 2 3 4 5]
      
x[0] = 31
print(arr)  # [31 2 3 4 5]
print(x)    # [31 2 3 4 5]

Checking Data Ownership

Use the base attribute to check if an array owns its data. If base is None, the array owns the data (copy). If not, it references another array (view):

import numpy as np
arr = np.array([1, 2, 3, 4, 5])
x = arr.copy()
y = arr.view()
print(x.base)  # None
print(y.base)  # array([...])

Next.js - Using OpenTelemetry

What is OpenTelemetry? 🔭

OpenTelemetry (OTel) is an open-source framework that provides a standardized set of APIs, SDKs, and tools to **collect and analyze telemetry data** from applications. This data includes **traces**, **metrics**, and **logs** (collectively, "observability").

  • It is a language and vendor-agnostic tool, meaning it supports various languages, frameworks, and monitoring backends (like Jaeger, Prometheus, or Datadog).
  • It is used to gain **insights** into application behavior, making it easier to identify and diagnose issues in complex, distributed systems.

Next.js supports OpenTelemetry **out of the box**, meaning the Next.js framework itself already includes instrumentation to generate basic telemetry data.

Setting Up OpenTelemetry in Next.js

To simplify setting up and configuring the OpenTelemetry SDK in a Next.js project, it is recommended to use the official Vercel package, **@vercel/otel**.

Step 1: Install Packages

Install the necessary packages, including the Vercel helper and related OpenTelemetry dependencies:

npm install @vercel/otel @opentelemetry/sdk-logs @opentelemetry/api-logs @opentelemetry/instrumentation

Step 2: Setup Instrumentation File

Create a custom file named **instrumentation.ts** (or .js) in the **root directory** of your project. This file registers the OpenTelemetry configuration when the application starts.

// /instrumentation.ts
import { registerOTel } from '@vercel/otel'
 
export function register() {
  // Registers the OpenTelemetry SDK with a specified service name
  registerOTel({ serviceName: 'next-app' })
}

Step 3: Test Instrumentation

To view the collected telemetry data, you need an **OpenTelemetry Collector** running alongside a compatible **backend** (a place to store and visualize the data). When configured correctly, the application will begin sending traces, logs, and metrics to your chosen monitoring system.

Creating Custom Spans for Tracing

In OpenTelemetry, a **span** is a fundamental unit of work or operation that can be individually timed and traced. It represents a single, timed event—like an API call, a database query, or a function execution—that is part of a larger trace.

To create a custom span, you use the OpenTelemetry tracing API to start and end the operation:

// Creates a span named 'fetchGithubStars'
trace.getTracer('nextjs-example').startActiveSpan('fetchGithubStars', async (span) => {
    try {
        // The code block inside measures the duration of this operation
        return await getValue()
    } finally {
        // It is crucial to always end the span to record the duration
        span.end()
    }
})

This code measures the exact duration it takes to execute the getValue() function, providing precise performance data for that specific unit of work.

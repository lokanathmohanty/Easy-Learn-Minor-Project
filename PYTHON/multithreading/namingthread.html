Python - Naming the Threads

In Python, naming a thread involves assigning a string identifier to the thread object. Thread names serve only for identification purposes and do not influence thread behavior. Multiple threads can share the same name, and names can be set during initialization or changed dynamically.

Assigning meaningful thread names helps in debugging and managing threads in complex concurrent programs.

Naming Threads Using the name Parameter

If no name is provided, Python auto-assigns a name like "Thread-N" or "Thread-N (target_function_name)". You can specify a custom name using the name parameter of threading.Thread().

Example: Assigning Custom and Default Thread Names

from threading import Thread
import threading
from time import sleep

def my_function_1(arg):
   print("This thread name is", threading.current_thread().name)

# Create thread objects with and without custom names
thread1 = Thread(target=my_function_1, name='My_thread', args=(2,))
thread2 = Thread(target=my_function_1, args=(3,))

print("This thread name is", threading.current_thread().name)  # Main thread

# Start and join threads
thread1.start()
thread1.join()

thread2.start()
thread2.join()

Output:

This thread name is MainThread
This thread name is My_thread
This thread name is Thread-1 (my_function_1)

Dynamically Changing Thread Names

You can change a thread's name at runtime by modifying its name attribute.

Example: Dynamically Changing Thread Names

from threading import Thread
import threading
from time import sleep

def my_function_1(arg):
   threading.current_thread().name = "custom_name"
   print("This thread name is", threading.current_thread().name)

thread1 = Thread(target=my_function_1, name='My_thread', args=(2,))
thread2 = Thread(target=my_function_1, args=(3,))

print("This thread name is", threading.current_thread().name)

thread1.start()
thread1.join()

thread2.start()
thread2.join()

Output:

This thread name is MainThread
This thread name is custom_name
This thread name is custom_name

Example: Creating and Renaming Threads

import threading

def addition_of_numbers(x, y):
   print("This Thread name is :", threading.current_thread().name)
   result = x + y

def cube_number(i):
   result = i ** 3
   print("This Thread name is :", threading.current_thread().name)

def basic_function():
   print("This Thread name is :", threading.current_thread().name)

t1 = threading.Thread(target=addition_of_numbers, name='My_thread', args=(2, 4))
t2 = threading.Thread(target=cube_number, args=(4,))
t3 = threading.Thread(target=basic_function)

t1.start()
t1.join()

t2.start()
t2.join()

t3.name = 'custom_name'  # Rename after creation
t3.start()
t3.join()

print(threading.current_thread().name)  # Main thread name

Output:

This Thread name is : My_thread
This Thread name is : Thread-1 (cube_number)
This Thread name is : custom_name
MainThread

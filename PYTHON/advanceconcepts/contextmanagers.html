Python - Context Managers

Context managers in Python provide a powerful and clean way to manage resources such as file streams, database connections, and locks safely and efficiently. They encapsulate setup and cleanup logic by defining a runtime context for use with the with statement.

A context manager ensures that resources are properly acquired and released, even in the presence of errors or exceptions.

How Context Managers Work

Context managers implement either the synchronous methods __enter__() and __exit__(), or asynchronous methods __aenter__() and __aexit__() for use with with or async with statements. The __enter__() method is executed at the beginning of the block and the __exit__() method runs at the end to perform cleanup.

Example: Synchronous Context Manager

class MyContextManager:
    def __enter__(self):
        print("Entering the context")
        return self

    def __exit__(self, exc_type, exc_value, traceback):
        print("Exiting the context")
        if exc_type:
            print("An exception occurred")
        return True  # Suppress exception

with MyContextManager():
    print("Inside the block")
    # Intentionally raise an exception
    result = 1 / 0

Output: 

Entering the context
Inside the block
Exiting the context
An exception occurred

Example: Asynchronous Context Manager

import asyncio

class AsyncContextManager:
    async def __aenter__(self):
        print("Entering async context")
        return self

    async def __aexit__(self, exc_type, exc_value, traceback):
        print("Exiting async context")
        if exc_type:
            print("Exception occurred")
        return True

async def main():
    async with AsyncContextManager():
        print("Inside async block")
        # Trigger an exception
        raise ValueError("Oops!")

asyncio.run(main())

Output: 

Entering async context
Inside async block
Exiting async context
Exception occurred

Creating Context Managers Using contextlib

The contextlib module simplifies context manager creation. The @contextlib.contextmanager decorator lets you write generator-based context managers easily by yielding control inside a try-finally block. 

from contextlib import contextmanager

@contextmanager
def my_context():
    print("Entering")
    try:
        yield
    finally:
        print("Exiting")

with my_context():
    print("Inside with block")

Output: 

Entering
Inside with block
Exiting

For asynchronous context managers, use @contextlib.asynccontextmanager with async functions and async with. 

from contextlib import asynccontextmanager
import asyncio

@asynccontextmanager
async def async_context():
    print("Entering async")
    try:
        yield
    finally:
        print("Exiting async")

async def main():
    async with async_context():
        print("Inside async block")
        await asyncio.sleep(1)

asyncio.run(main())

Output: 

Entering async
Inside async block
Exiting async

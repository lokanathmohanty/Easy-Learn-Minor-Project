CSS - Rounded Corners

CSS rounded corners are created using the border-radius property. This property allows you to specify the radius of the corners of an element's outer border edge.

Possible Values

  • <length>: Size of circle radius is denoted, using length values. Negative values are not valid.
  • <percentage>: Size of circle radius is denoted, using percentage values. Horizontal axis percentage is referred to the width of the box. Vertical axis percentage is referred to the height of the box. Negative values are not valid.

Applies to

All the HTML elements, except for table and inline-table elements with border-collapse set to collapse. Applies to ::first-letter.

DOM Syntax

object.style.borderRadius = "length";

Border-Radius Values

ValueDescription
radius (All Corner)Sets the radius for all four corners (one-value syntax).
top-left and bottom-rightSets radius for top-left and bottom-right corners (two-value syntax).
top-right and bottom-leftSets radius for top-right and bottom-left corners (two- and three-value syntax).
top-leftSets radius for top-left corner (three and four-value syntax).
top-rightSets radius for top-right corner (four-value syntax).
bottom-rightSets radius for bottom-right corner (three and four-value syntax).
bottom-leftSets radius for bottom-left corner (four-value syntax).

Individual border radius properties, such as border-top-left-radius, cannot inherit from their parent element. Instead, you must use the individual longhand properties to set the border radius of each corner.

Example: Rounded Box

<div class="rounded-box">
   This is a rounded corner box.
</div>

Example: Border and Image

<div class="border-box">This is a rounded corner box.</div>
<div class="img-border-radius">This is a rounded corner image.</div>

Example: Different Corner Styles

<div class="rounded-box tl">top-left rounded corner.</div>
<div class="rounded-box tr">top-right rounded corner.</div>
<div class="rounded-box bl">bottom-left rounded corner.</div>
<div class="rounded-box br">bottom-right rounded corner.</div>

Example: Rounded Corner Images

<img class="top-left" src="images/tree.jpg" />
<img class="top-right" src="images/tree.jpg" />
<img class="bottom-left" src="images/tree.jpg" />
<img class="bottom-right" src="images/tree.jpg" />

Example: Circle and Ellipse

<div class="rounded-circle">circle</div>
<div class="rounded-ellipse">ellipse</div>

Related Properties

  • border-top-left-radius – Sets the roundness of the top-left corner.
  • border-top-right-radius – Sets the roundness of the top-right corner.
  • border-bottom-right-radius – Sets the roundness of the bottom-right corner.
  • border-bottom-left-radius – Sets the roundness of the bottom-left corner.
  • border-start-start-radius – Sets roundness of block-start and inline-start corner.
  • border-start-end-radius – Sets roundness of block-start and inline-end corner.
  • border-end-start-radius – Sets roundness of block-end and inline-start corner.
  • border-end-end-radius – Sets roundness of block-end and inline-end corner.

JavaScript - The Map Object

A Map object in JavaScript is a collection of key-value pairs where the keys can be of any type, including objects or functions. The order of elements is maintained based on insertion.

You can create a new Map using the new Map() constructor. Use the set() method to add key-value pairs, get() to retrieve values, and delete() to remove entries.

Syntax

const map = new Map([iterable]);

Parameters:

  • iterable − Optional. An iterable containing key-value pairs to initialize the map.

Map Properties

  • size − Returns the number of elements in the Map.

Map Methods

  • clear() − Removes all elements from the Map.
  • delete() − Removes a specified element by key.
  • entries() − Returns an iterator with [key, value] pairs.
  • forEach() − Executes a callback for each key/value pair.
  • get() − Returns the value for a specified key.
  • has() − Checks if a key exists in the Map.
  • keys() − Returns an iterator with all keys.
  • set() − Adds a key-value pair to the Map.
  • values() − Returns an iterator with all values.

Map Constructor

  • Map() − Creates a new Map object.

Examples

Example: Creating a new Map Object


const map = new Map([["Apple", 100], ["Banana", 20], ["Orange", 50]]);
for (let [key, value] of map) {
  console.log(key + " : " + value);
}

Output:

  • Apple : 100
  • Banana : 20
  • Orange : 50

Example: Inserting Key-Value Pair


const map = new Map();
map.set("Grapes", 40);
map.set("Apples", 50);

for (let [key, value] of map) {
  console.log(key + " : " + value);
}

Output:

  • Grapes : 40
  • Apples : 50

Example: Accessing Map Elements


const map = new Map();
map.set("name", "John");
map.set("rollId", 123);

console.log(map.get("name"));   // John
console.log(map.get("rollId")); // 123

Output:

  • Name: John
  • Roll Id: 123

Example: Removing a Map Element


const map = new Map([[10, 20], [20, 30], [30, 40]]);
map.delete(20);

for (let [key, value] of map) {
  console.log("Key: " + key + " Value: " + value);
}

Output:

  • Key: 10 Value: 20
  • Key: 30 Value: 40

Example: Size of the Map


const map = new Map();
map.set("Grapes", 40);
map.set("Apples", 50);

console.log(map.size); // 2

Output: Size of the map object is: 2

Example: Use Object as a Key


const map = new Map();
const laptop = { brand: "HP", model: "Pavilion" };

map.set(laptop, 100000);
console.log(map.get(laptop)); // 100000

Output: The laptop price is: 100000

Map vs. Object in JavaScript

  • Keys: Map allows objects, functions, and primitives as keys, while Object keys are strings or symbols.
  • Size: Map has a built-in size property, Object requires manual counting.
  • Key Comparison: Map compares keys by reference, Object converts keys to strings.
  • Iteration: Map supports for...of, Object supports for...in.
  • Performance: Map is slightly slower due to structure, Object is faster for simple keys.
  • Use Cases: Map is better for dynamic key-value pairs, Object is better for static structures.

R - Mean, Median and Mode

In R, statistical analysis includes calculating measures of central tendency like mean, median, and mode using built-in or user-defined functions. These functions take a vector as input and return the desired statistic.

Mean

The mean is the sum of values divided by the number of observations. Use mean() to calculate it. 

# Create vector
x <- c(12, 7, 3, 4.2, 18, 2, 54, -21, 8, -5)

# Calculate mean
result.mean <- mean(x)
print(result.mean)

Output:

[1] 8.22

Trimmed Mean

The trim parameter removes observations from both ends of the sorted vector before calculating the mean. 

# Calculate trimmed mean with 30% trimming
result.mean <- mean(x, trim = 0.3)
print(result.mean)

Output:

[1] 5.55

Handling Missing Values

By default, mean() returns NA if missing values are present. Use na.rm = TRUE to remove NA values. 

# Vector with NA
x <- c(12, 7, 3, 4.2, 18, 2, 54, -21, 8, -5, NA)

# Mean with NA (returns NA)
print(mean(x))

# Mean ignoring NA
print(mean(x, na.rm = TRUE))

Output:

[1] NA
[1] 8.22

Median

The median is the middle value of a sorted data vector. Calculate it using median(). 

# Calculate median
median.result <- median(x, na.rm = TRUE)
print(median.result)

Output:

[1] 5.6

Mode

The mode is the value occurring most frequently. R lacks a built-in mode() for this purpose, so define a custom function. 

# User-defined function to find mode
getmode <- function(v) {
  uniqv <- unique(v)
  uniqv[which.max(tabulate(match(v, uniqv)))]
}

# Numeric vector mode
v <- c(2, 1, 2, 3, 1, 2, 3, 4, 1, 5, 5, 3, 2, 3)
result <- getmode(v)
print(result)

# Character vector mode
charv <- c("o", "it", "the", "it", "it")
result <- getmode(charv)
print(result)

Output:

[1] 2
[1] "it"

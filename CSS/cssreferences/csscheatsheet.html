Basics of CSS

CSS specify how an HTML element should be displayed on the web page. If you think of the human body as a web page then CSS is styling part of the body. Like color of the eyes, size of the nose, skin tone, etc.

Syntax

selector { property: value; }

Ways to use CSS

  • Inline CSS: Directly applied on the HTML elements using style attribute.
  • Internal CSS: Defined in the <head> section using <style> tag.
  • External CSS: Defined in a separate file and linked with <link> tag.

CSS Selectors

CSS Selectors are used to select the HTML elements you want to style on a web page.

Examples

* { color: blue; }
div { border: 5px inset gold; }
.myClass { background-color: #04af2f; }
#myId { background-color: #04af2f; }
a[href] { font-size: 2em; }
h3, h4 { text-align: center; }
p::before { content: "Note: "; font-weight: bold; }
a:hover { background-color: peachpuff; }
div p { color: blue; }
div > p { color: blue; }
div + p { color: blue; }
div ~ p { color: blue; }

Font Properties

CSS Font is a set of text characters with a consistent design and style.

p { font: oblique small-caps bold 20px Arial, sans-serif; }
#para1 { font-family: verdana, georgia; }
p { font-feature-settings: 'smcp', off; }
#nokern { font-kerning: none; }
.text { font-language-override: "DAN"; }
.myDiv { font-optical-sizing: auto; }
font-size: medium | xx-small | x-small | ...
font-weight: normal | bold | bolder | lighter | number;
font-variant: normal | small-caps | initial;

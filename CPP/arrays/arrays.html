C++ Arrays: Fixed-Size Data Collections 💾

A C++ **array** is a fundamental data structure used to store a fixed-size, sequential collection of elements of the **same data type**. All array elements occupy **contiguous memory locations**.

  • The first element is at index **0** (the base index).
  • Elements are accessed using an **index** enclosed in square brackets [].

Declaration and Initialization

Declaring Arrays

You must specify the element type and the size (an integer constant greater than zero) at the time of declaration:

type arrayName [ arraySize ];

// Example: A 10-element array of type double
double balance[10];

Initializing Arrays

Arrays can be initialized during declaration using an initializer list {}. If the size is omitted, the compiler automatically determines the size based on the number of initializers.

// Initializes a 5-element array explicitly
double balance[5] = {1000.0, 2.0, 3.4, 17.0, 50.0};

// Implicitly creates an array of size 5
int numbers[] = {10, 20, 30, 40, 50};

Accessing and Manipulating Elements

Accessing and Changing Elements

An element is accessed or modified using the array name followed by its index in square brackets. Remember that the index range is from 0 to arraySize - 1.

int arr[] = {10, 20, 30, 40, 50}; // Index 2 holds 30

// Accessing the element
int value = arr[2]; // value is 30

// Changing the element
arr[2] = 108;       // The array element at index 2 is now 108

Getting Array Length (Static Arrays)

For statically declared arrays, you can calculate the number of elements using the sizeof() operator:

int arr[] = {10, 20, 30, 40, 50};
// Calculates total bytes of the array / bytes of a single element
int arr_length = sizeof(arr) / sizeof(arr[0]); 
// arr_length is 5

Related Array Concepts

  • Multi-dimensional Arrays: C++ supports arrays with more than one dimension, such as the common two-dimensional array (e.g., int table[3][4];), which is useful for representing matrices or tables.
  • Pointers to an Array: The array name itself, when used without an index, acts as a **pointer** to the first element (index 0) of the array.
  • Passing Arrays to Functions: Arrays are typically passed to functions by passing the **pointer** to their first element. The size of the array must often be passed as a separate argument.

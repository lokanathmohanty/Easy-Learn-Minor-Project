CSS - transition Property

The transition property allows you to animate changes in an element's style properties over a specified duration. It provides a simple way to add animations without using JavaScript or external libraries.

The transition shorthand property includes:

  • transition-property
  • transition-duration
  • transition-timing-function
  • transition-delay
  • transition-behavior (experimental)

Possible Values

<length> − Specifies values such as pixels (px), centimeters (cm), inches (in), etc.

Applies to

All elements, ::before and ::after pseudo-elements.

Syntax

  • transition: margin-right 4s;
  • transition: margin-right 4s 1s;
  • transition: margin-right 4s ease-in-out;
  • transition: margin-right 4s ease-in-out 1s;
  • transition: display 4s allow-discrete;
  • transition: margin-right 4s, color 1s;

Notes:

  • none → No transitions applied (default).
  • all → Applies to all properties that change.
  • You can specify a property name (e.g., color or margin-left).
  • You can specify an easing function like ease-in-out.
  • You can define duration and optional delay.

Examples

Transition with Two Values

This example applies a transition to the padding property with a duration of 2s.

<style>
.box {
  font-size: 14px;
  width: 100px;
  padding: 5px;
  transition: padding 2s;
  background-color: lightskyblue;
}
.box:hover {
  background-color: greenyellow;
  padding: 15px;
}
</style>

<div class="box">Hover over me</div>

Transition with Delay

<style>
.box {
  transition: padding 2s .5s;
}
</style>

Transition with Easing Function

<style>
.box {
  transition: background-color 4s ease-in-out;
}
</style>

Transition with Easing and Delay

<style>
.box {
  transition: padding 4s ease-in-out 0.7s;
}
</style>

Transition with Behavior

<style>
.box {
  transition: background-color 5s allow-discrete;
}
</style>

Transition Applied to Two Properties

<style>
.box {
  transition: color 2s, margin-left 4s;
}
</style>

Related Properties

  • transition-delay − Wait time before starting a transition.
  • transition-duration − Time a transition takes to complete.
  • transition-property − Specifies which CSS properties have transition effects.
  • transition-timing-function − Defines how intermediate values are generated.

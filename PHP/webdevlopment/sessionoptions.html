PHP - Session Configuration Options ($\ge$ PHP 7)

Overriding Configuration with $\text{session\_start()}$

From PHP 7 onwards, the **$\text{session\_start()}$** function accepts an associative array of options to override the default settings defined in the **$\text{php.ini}$** file's $\text{[session]}$ section. When using this array, the keys must **not** include the "$\text{session.}$" prefix.

This method provides a clean, per-script way to configure session behavior, as demonstrated by setting the cache control and read/close behavior:

<?php
   session_start([
      'cache_limiter' => 'private',
      'read_and_close' => true,
   ]);
?>

Key Configurable Session Options

The following are some important session directives that can be configured either via $\text{php.ini}$, $\text{ini\_set()}$, or the $\text{session\_start()}$ options array:

  • $\text{session\_name}$

    Specifies the name of the session, which is also used as the cookie name (default is **$\text{PHPSESSID}$**). It should only contain alphanumeric characters.

  • $\text{session.cookie\_lifetime}$

    Defines the duration, in seconds, the session cookie will last on the client's browser. A value of **$\text{0}$** (the default) means the cookie expires when the browser is closed.

  • $\text{session.cache\_limiter}$

    Controls the HTTP cache control headers sent with session pages, governing how the browser should cache the content. Common values include **$\text{nocache}$** (default), $\text{private}$, and $\text{public}$.

  • $\text{session.sid\_length}$

    Allows setting the length of the unique Session ID string, which ranges from $\text{22}$ to $\text{256}$ characters (default is $\text{32}$). Longer IDs can enhance security against brute-force attacks.

Example: Using $\text{ini\_set()}$ for Configuration

Before PHP 7, or as an alternative to the $\text{session\_start()}$ options array, $\text{ini\_set()}$ is used to change these directives at runtime:

<?php
   // Set cookie to last for 1 hour (3600 seconds)
   ini_set('session.cookie_lifetime', 3600);

   // Increase session ID length for better security
   ini_set('session.sid_length', 64);

   // Start the session with the new settings
   session_start();
?>

Other important options include $\text{session.save\_handler}$ (defaults to $\text{files}$) and $\text{session.lazy\_write}$ (defaults to $\text{1}$, only rewriting session data if changes occurred).

Python - Literals

What are Python Literals?

Python literals or constants are the notation for representing a fixed value in source code. In contrast to variables, literals (123, 4.3, "Hello") are static values which do not change throughout the program. For example:

x = 10

Here 10 is a literal. However:

y = x * 2

The result 20 is not a literal because it is evaluated at runtime.

Different Types of Python Literals

  • Integer Literal
  • Float Literal
  • Complex Literal
  • String Literal
  • List Literal
  • Tuple Literal
  • Dictionary Literal

Python Integer Literal

Integer literals can be decimal, octal, or hexadecimal.

# Decimal
x = 10
y = -25
z = 0

# Octal
x = 0O34

# Hexadecimal
x = 0X1C

Even with octal or hexadecimal, Python treats them as int type.

Example

x = 0O34
print("0O34 in octal is", x, type(x))

x = 0X1c
print("0X1c in Hexadecimal is", x, type(x))

Python Float Literal

A float has an integral and a fractional part, separated by a decimal point.

x = 25.55
y = 0.05
z = -12.2345

Floats can also use scientific notation:

Example

x = 1.23
print(x, type(x))

x = 1.23E5
print(x, type(x))

x = 1.23E-2
print(x, type(x))

Python Complex Literal

A complex number has a real and an imaginary part. The imaginary unit is written with j or J.

Example

x = 2+3j
print(x, type(x))

y = 2.5+4.6j
print(y, type(y))

Python String Literal

A string is a sequence of Unicode code points. It can be written in single, double, or triple quotes.

Example

var1 = 'hello'
var2 = "hello"
var3 = '''hello'''
var4 = """hello"""

Embedding quotes:

var1 = 'Welcome to "Python Tutorial"'
var2 = "Welcome to 'Python Tutorial'"

Python List Literal

A list is an ordered collection enclosed in square brackets [].

Example

L1 = [1, "Ravi", 75.50, True]
print(L1, type(L1))

Python Tuple Literal

A tuple is similar to a list but enclosed in parentheses (). A comma-separated sequence without parentheses also forms a tuple.

Example

T1 = (1, "Ravi", 75.50, True)
print(T1, type(T1))

T2 = 1, "Ravi", 75.50, True
print(T2, type(T2))

Python Dictionary Literal

A dictionary is an unordered collection of key-value pairs enclosed in curly braces {}.

Example

capitals = {"USA":"New York", "France":"Paris", "Japan":"Tokyo", "India":"New Delhi"}
numbers = {1:"one", 2:"Two", 3:"three", 4:"four"}
points = {"p1":(10,10), "p2":(20,20)}

print(capitals, type(capitals))
print(numbers, type(numbers))
print(points, type(points))

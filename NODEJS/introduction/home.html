Understanding Node.js: An Introduction

What is Node.js?

Node.js is a JavaScript runtime environment built on Chrome's V8 JavaScript engine. It allows developers to use JavaScript for server-side programming, making it possible to develop applications that use a single programming language for both frontend and backend tasks.

  • Open-source and cross-platform
  • Event-driven and non-blocking I/O
  • Perfect for I/O-intensive applications

Why Use Node.js?

Node.js is widely used for creating web servers, APIs, streaming and real-time applications. Its lightweight architecture and efficient event loop make it suitable for data-intensive and real-time applications.

  • Efficient handling of multiple connections
  • Scalable for large-scale applications
  • Extensive package ecosystem through NPM

Example: Basic Node.js Application

The following example shows how to create a simple HTTP server in Node.js that returns "Hello World" for every request. 


const http = require('http');

const server = http.createServer((req, res) => {
  res.writeHead(200, {'Content-Type': 'text/plain'});
  res.end('Hello World');
});

server.listen(3000, () => {
  console.log('Server running at http://127.0.0.1:3000/');
});
  • Save the code above in a file named app.js.
  • Run it with the command: node app.js.
  • Visit http://127.0.0.1:3000/ to see the result.

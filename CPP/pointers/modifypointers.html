C++ Modifying Pointers ✏️

Modifying pointers in C++ involves changing one of two things:

  1. **The Pointer's Address (Reassignment):** Changing the **memory address** that the pointer variable is storing. This makes the pointer point to a different location or variable.
  2. **The Pointed-to Value (Dereferencing):** Changing the **data value** stored at the memory address the pointer currently points to.

Pointers are variables themselves, meaning their values (the stored memory addresses) can be changed.

1. Modifying the Pointer's Address (Reassignment)

This is done by assigning a new address to the pointer variable. The pointer can be reassigned to point to another existing variable or a newly allocated memory block.

int var1 = 10;
int var2 = 20;
int* ptr = &var1;  // ptr = address of var1

ptr = &var2;       // MODIFICATION: ptr now holds the address of var2
cout << *ptr << endl; // Output: 20

Reassignment to Dynamic Memory

A pointer can be reassigned to point to memory allocated on the heap using the **new** operator.

int* dynamicPtr = new int(30);
ptr = dynamicPtr; // MODIFICATION: ptr points to the new heap memory
cout << *ptr << endl; // Output: 30

// Crucial step: Release dynamic memory to prevent leaks
delete dynamicPtr;

2. Modifying the Pointed-to Value (Dereferencing)

This is done using the **dereference operator** (*****) to access the memory location and assign a new value to the original variable.

int var = 100;
int* ptr = &var; // ptr points to var

*ptr = 500; // MODIFICATION: The value of 'var' is changed to 500
cout << var << endl; // Output: 500

ReactJS - Stateless Component

A React component with internal state is called a Stateful component, while a component without internal state management is called a Stateless component. React recommends creating and using as many stateless components as possible, and creating stateful components only when absolutely necessary.

Also, React does not share state with child components. Data must be passed to a child component through its properties.

Example – Passing data to the FormattedDate component:

<FormattedDate value={this.state.item.spend_date} />

The general idea is not to overcomplicate application logic and use advanced features only when necessary.

Create a Stateful Component

Let us create a React application to show the current date and time.

Step 1

Create a new React application react-clock-app using Create React App or Rollup bundler. Open the app in your editor.

Step 2

Create a src folder under the root directory, then create a components folder under src. Inside it, create a file Clock.js.

Import React and create the Clock component:

import React from 'react';

class Clock extends React.Component {
  constructor(props) {
    super(props);
  }
}

Step 3

Initialize state with the current date and time:

constructor(props) {
  super(props);
  this.state = { date: new Date() }
}

Step 4

Add a setTime() method to update the current time:

setTime() {
  console.log(this.state.date);
  this.setState((state, props) => ({ date: new Date() }));
}

Step 5

Use setInterval to call setTime() every second:

constructor(props) {
  super(props);
  this.state = { date: new Date() };
  setInterval(() => this.setTime(), 1000);
}

Step 6

Create a render() method:

render() {
  return ( <div><p>The current time is {this.state.date.toString()}</p></div> );
}

Export the component:

export default Clock;

Complete Code of Clock Component

import React from 'react';

class Clock extends React.Component {
  constructor(props) {
    super(props);
    this.state = { date: new Date() };
    setInterval(() => this.setTime(), 1000);
  }

  setTime() {
    console.log(this.state.date);
    this.setState((state, props) => ({ date: new Date() }));
  }

  render() {
    return ( <div><p>The current time is {this.state.date.toString()}</p></div> );
  }
}

export default Clock;

index.js

Create an index.js file under src and use the Clock component:

import React from 'react';
import ReactDOM from 'react-dom';
import Clock from './components/Clock';

ReactDOM.render(
  <React.StrictMode>
    <Clock />
  </React.StrictMode>,
  document.getElementById('root')
);

index.html

Create public/index.html:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Clock</title>
</head>
<body>
  <div id="root"></div>
  <script type="text/javascript" src="./index.js"></script>
</body>
</html>

Run the app using npm start and open http://localhost:3000 to see the live clock.

Error: setState on Unmounted Component

The application may throw an error:

"Can't call setState on a component that is not yet mounted."

This happens because setState should only be called after the component is mounted. Mounting is part of the React component life-cycle, which we will learn in the next chapters.

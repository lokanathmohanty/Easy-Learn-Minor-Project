.NET Core - Package References and Management

This session covers methods for identifying, finding, and adding **NuGet packages** (dependencies) to a **.NET Core** application, focusing on the file-based approach using project.json.

Finding a Specific Package (The CoreFx Approach)

Because .NET Core is modular (using **CoreFx** as the reimplementation of the class libraries), familiar types from the old .NET Framework are now distributed as separate packages. You can find these packages in two main ways, besides searching directly on the NuGet website:

  • **GitHub CoreFx Repository**: By navigating to the **CoreFx source code** on GitHub (https://github.com/dotnet/corefx) and opening the src folder, you can see a list of folders corresponding to the various packages (e.g., searching for "Json" leads to related packages).
  • **Type Search Tool**: If you know the namespace or type (e.g., DataContractJson) but not the package name, there are external tools that scan NuGet to find the containing package for that specific type.

Adding a Package Dependency Manually (via project.json)

One primary way to add a package is by directly editing the **project.json** file (the project format at the time of this documentation). The package reference is added within the **dependencies** section.

Original project.json Structure

{ 
   "version": "1.0.0-*", 
   "buildOptions": { 
      "emitEntryPoint": true 
   }, 
   "dependencies": { 
      "Microsoft.NETCore.App": { 
         "type": "platform", 
         "version": "1.0.1" 
      } 
   }, 
   "frameworks": { 
      "netcoreapp1.0": { 
         "imports": "dnxcore50" 
      } 
   } 
}

Adding a Package Reference

To add a package like System.Runtime.Serialization.Json with version 4.0.2, you insert it as a new key-value pair under "dependencies":

{ 
   "version": "1.0.0-*", 
   "buildOptions": { 
      "emitEntryPoint": true 
   }, 
   "dependencies": { 
      "Microsoft.NETCore.App": { 
         "type": "platform", 
         "version": "1.0.1" 
      }, 
      /** NEW PACKAGE ADDED HERE **/
      **"System.Runtime.Serialization.Json": "4.0.2"** }, 
   "frameworks": { 
      "netcoreapp1.0": { 
         "imports": "dnxcore50" 
      } 
   } 
}

Once the file is saved, the package is automatically added to your project's references in Visual Studio.

Alternative Method: NuGet Package Manager

The standard way to manage packages visually is by using the **NuGet Package Manager** within Visual Studio, where you can browse, search for, and install packages directly through the user interface.

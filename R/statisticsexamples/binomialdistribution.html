R - Binomial Distribution

The binomial distribution models the probability of a fixed number of successes in a series of independent trials, each with the same probability of success. For instance, the probability of getting exactly 3 heads in 10 coin tosses.

Key Functions

  • dbinom(x, size, prob): Probability mass function - gives probability of exactly x successes in size trials.
  • pbinom(x, size, prob): Cumulative distribution - probability of up to x successes.
  • qbinom(p, size, prob): Quantile function - number of successes for cumulative probability p.
  • rbinom(n, size, prob): Generates n random numbers from binomial distribution.

dbinom() Example

# Values from 0 to 50 successes
x <- seq(0, 50, by=1)

# Probability mass function with 50 trials, prob = 0.5
y <- dbinom(x, size=50, prob=0.5)

# Save plot
png(file="dbinom.png")

# Plot probability mass function
plot(x, y)

# Close device
dev.off()

pbinom() Example

# Probability of getting 26 or fewer heads in 51 tosses
result <- pbinom(26, size=51, prob=0.5)
print(result)

Output:

[1] 0.610116

qbinom() Example

# Number of heads corresponding to 25% cumulative probability in 51 tosses
result <- qbinom(0.25, size=51, prob=0.5)
print(result)

Output:

[1] 23

rbinom() Example

# Generate 8 random binomial values - 150 trials with prob 0.4
values <- rbinom(8, size=150, prob=0.4)
print(values)

Output:

[1] 58 61 59 66 55 60 61 67

Python - Nested Loops

A nested loop in Python refers to having one or more loops inside another loop. The outer loop is the main loop, while the loops inside it are called inner loops.

Both for and while loops can be nested, and you can mix them (for inside while or vice versa).

Python Nested for Loop

A nested for loop means using one or more for loops inside another. They are often used for iterating over multiple sequences simultaneously.

Syntax

for outer_var in sequence:
   for inner_var in sequence:
      statement(s)
   statement(s)

Example

months = ["jan", "feb", "mar"]
days = ["sun", "mon", "tue"]

for x in months:
   for y in days:
      print(x, y)

print("Good bye!")

Output:

jan sun
jan mon
jan tue
feb sun
feb mon
feb tue
mar sun
mar mon
mar tue
Good bye!

Python Nested while Loop

A nested while loop means using one or more while loops inside another. They are useful when the number of iterations is not fixed.

Syntax

while expression:
   while expression:
      statement(s)
   statement(s)

Example

i = 2
while (i < 25):
   j = 2
   while (j <= (i/j)):
      if not(i % j):
         break
      j = j + 1
   if (j > i/j):
      print(i, "is prime")
   i = i + 1

print("Good bye!")

Output:

2 is prime
3 is prime
5 is prime
7 is prime
11 is prime
13 is prime
17 is prime
19 is prime
23 is prime
Good bye!

Example: Practice Tasks on Nested Loops

  • Use a nested while loop to print all pairs of numbers (x, y) where x and y range from 1 to 3.
  • Combine for and while loops: Use a for loop for rows and a while loop for columns.
  • Modify the prime number program to check primes up to 50 instead of 25.

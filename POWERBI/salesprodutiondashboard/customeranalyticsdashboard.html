Power BI: Customer Analytics Dashboard

Richard's Customer Analytics Dashboard aims to provide insights such as total customers, customer satisfaction (CSAT), support ticket counts, and data source popularity. The dashboard leverages multiple visualizations to display these metrics comprehensively.

Key Business Questions

  • Total number of customers
  • Sum of CSAT scores
  • Total number of customer support tickets (CS tickets)
  • Data resources distribution by popularity
  • Customer counts segmented by purchase data resource frequency (Pur_dr_f)

Dashboard Creation Steps

  1. Import the data file (e.g., customer.xlsx) into Power BI Desktop.
  2. Add a title textbox with "Customer Analytics Dashboard," format font size and style, and set background color.
  3. Set report wallpaper with desired color for visual appeal.
  4. Create a Gauge Chart for total customers by placing the customer count field in Values; set the title accordingly.
  5. Create additional Gauge Charts to display sums of CSAT and CS tickets similarly.
  6. Use a Donut Chart to visualize data resources by popularity; place popularity in Legend and data resource in Values.
  7. Build a Stacked Column Chart to display customer counts by purchase data resource frequency; place frequency on X-axis and customer counts on Y-axis.
  8. Add a Multi-row Card, adding fields like data resources, CSAT, customer counts, and tickets to display detailed info per resource.
  9. Enable drill-through or interaction on visuals to display details such as for "Banks-Credit/Debit cards" showing respective metrics.

Dashboard Insights and Usage

This interactive dashboard enables quick understanding of customer behavior, interests, resource popularity, and service metrics such as support tickets and satisfaction ratings.

It provides businesses with actionable insights to optimize customer engagement and support strategies.

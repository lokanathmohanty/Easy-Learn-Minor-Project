Data Discrepancy and Reshaping Data in Power Query Editor

Determining Data Discrepancy

Power Query Editor enables monitoring of data quality by profiling columns to reveal errors, nulls, and inconsistencies.

Case Study: Monitoring Data Quality

Richard loads and inspects a dataset, enabling "Column Quality" to view data validity. He observes error-free columns as well as columns with null or empty values.

Column Distribution

Enabling the "Column Distribution" option displays bar charts for categorical columns to show distinct and unique value counts.

Column Profile

Further inspection with "Column Profile" reveals statistical metrics such as counts, standard deviation, mean, minimum, and maximum values.

Reshaping Data

Various techniques are used to reformat and clean data:

Changing Column Data Type

Users can change the data type of columns to correct formats suitable for analysis.

Altering Columns

  • Reordering Columns: Drag and move columns to desired positions.
  • Removing Columns: Delete unwanted columns via right-click or ribbon options.
  • Merging Columns: Combine two or more columns, optionally specifying a delimiter such as space.
  • Removing Duplicates: Remove duplicate rows based on selected columns.
  • Sorting: Sort columns in ascending or descending order.
  • Filtering: Apply filters like "Equals" or number filters to extract specific data.

Example: Filtering Data

Filtering a column by "Equals 4" will extract rows where the column's value is exactly 4.

Reshaping the dataset in Power Query Editor improves data quality and prepares it for accurate reporting and analysis.

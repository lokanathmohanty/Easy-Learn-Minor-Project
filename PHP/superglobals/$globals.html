PHP `$GLOBALS` Superglobal Array

The **`$GLOBALS`** is a **superglobal** associative array that provides access to **all globally defined variables** from anywhere in a PHP script, regardless of the current scope (including inside functions and methods). It acts as a reference to the global symbol table.

  • **Keys:** The names of the global variables (without the dollar sign, `$`).
  • **Values:** The current values of the corresponding global variables.

Access and Modification

Accessing Global Variables

You can retrieve the value of any global variable by using its name as a key in the `$GLOBALS` array. This is especially useful for accessing global variables inside functions where they are normally unavailable.

$var1 = "Hello World"; // Global variable

function myfunction() {
   $var1 = "Hello PHP"; // Local variable
   echo **$GLOBALS['var1']** . "\n"; // Accesses the Global value
   echo $var1; // Accesses the Local value
}

Output:
Hello World
Hello PHP

Updating Global Variables from Functions

You can directly modify the value of a global variable from inside any function by assigning a new value to its entry in the `$GLOBALS` array.

$counter = 0;

function incrementCounter() {
   **$GLOBALS['counter']++;** // Direct modification of global variable
}
incrementCounter();
echo $counter; // Output: 1

Handling Arrays and Nested Functions

The `$GLOBALS` array works seamlessly with complex data types, such as arrays, and retains its accessibility across nested function calls.

Storing and Modifying Arrays

You can manipulate global arrays directly through `$GLOBALS`, for instance, by adding new elements to them.

$var = array("Apple");
function addFruit($fruit) {
   **$GLOBALS['var'][] = $fruit;**
}
addFruit("Orange");
// $var is now ["Apple", "Orange"]

Accessibility in Nested Functions

Since `$GLOBALS` is a superglobal, it is available without any extra declaration inside all nested functions.

Note on Copying `$GLOBALS` (PHP 8.1.0+)

As of **PHP 8.1.0**, if you attempt to assign `$GLOBALS` to another variable (e.g., `$globals = $GLOBALS;`), the new variable (`$globals`) is a **read-only copy** of the global symbol table. Modifying elements in this copy **will not** change the actual global variables, reinforcing explicit access via `$GLOBALS['key']`.

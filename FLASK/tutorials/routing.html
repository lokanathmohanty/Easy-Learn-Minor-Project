Flask Routing: Binding URLs to Functions

Routing is a technique used in modern web frameworks to map specific **URLs** (Uniform Resource Locators) to the functions that handle the request for that URL. This enables users to access any desired page directly without needing to navigate from the application's home page.

The @app.route() Decorator

The primary method for routing in Flask is the **@app.route()** decorator. It is placed directly above the function you want to execute when a specific URL is accessed.

Example: Using the Decorator

@app.route('/hello')

def hello_world():

return 'hello world'

When a user visits the URL **http://localhost:5000/hello**, the output of the hello_world() function ("hello world") is displayed in the browser.

Alternative Routing Method

The same purpose served by the @app.route() decorator can also be achieved by calling the **add_url_rule()** function directly on the Flask application object. This approach explicitly adds a URL rule to the application's routing system.

The representation equivalent to the decorator example above is:

app.add_url_rule('/hello', 'hello_world', hello_world)

*(The arguments typically represent the URL rule, the endpoint name (usually the function name), and the view function itself.)*

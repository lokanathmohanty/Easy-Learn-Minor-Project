ReactJS - Reconciliation

Reconciliation is the internal process React uses to update the DOM efficiently. React first creates a virtual DOM and compares it with the previous virtual DOM using a diffing algorithm. Only the necessary parts of the actual DOM are updated, leading to better performance.

While the diffing algorithm works internally in React, understanding its basics helps developers write optimized applications.

Diffing Algorithm

React applies several strategies to compare and update DOM elements:

1. Elements of different type

If an element changes its type (e.g., from <div> to <p>), React replaces the entire subtree. 

<!-- Before -->
<div>
   <Content />
</div>

<!-- After -->
<p>
   <Content />
</p>

2. Elements of same type (attributes)

If the type is the same, React only updates changed attributes. 

<!-- Before -->
<div className="someClass">
   <Content />
</div>

<!-- After -->
<div className="someOtherClass">
   <Content />
</div>

3. Elements of same type (style changes)

If only style properties differ, React updates just those properties. 

<!-- Before -->
<div style={{fontFamily: 'Arial'}}>
   <p> ... </p>
</div>

<!-- After -->
<div style={{color: 'red', fontFamily: 'Arial'}}>
   <p> ... </p>
</div>

4. Component elements of same type

If React encounters the same component type, it triggers lifecycle methods (like componentWillUpdate) and re-renders the component with new props or state.

5. Collection of child elements

When React compares lists, it checks elements in order. If the first child changes, React may re-render the entire list. 

<!-- Before -->
<ul>
   <li>Peter</li>
   <li>Olivia</li>
</ul>

<!-- After -->
<ul>
   <li>John</li>
   <li>Peter</li>
   <li>Olivia</li>
</ul>

To solve this, React uses the key attribute to uniquely identify elements. 

<!-- Before -->
<ul>
   <li key="1">Peter</li>
   <li key="2">Olivia</li>
</ul>

<!-- After -->
<ul>
   <li key="3">John</li>
   <li key="1">Peter</li>
   <li key="2">Olivia</li>
</ul>

Summary

  • React uses a virtual DOM and diffing algorithm to minimize DOM updates.
  • Elements with different types replace entire subtrees.
  • Same type elements only update changed attributes or styles.
  • Keys help React optimize updates in lists of children.
  • Understanding reconciliation helps developers write more efficient React apps.

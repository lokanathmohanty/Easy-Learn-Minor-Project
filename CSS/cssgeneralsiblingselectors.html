CSS - General Sibling Selectors

A CSS general sibling selector ( ~ ) is used to select all elements that are siblings of a specified element and share the same parent. Unlike the adjacent sibling selector (+), it applies to all matching siblings, not just the one immediately following.

Syntax

selector1 ~ selector2 {
  /* property: value; */
  color: #04af2f;
}

Example 1: Styling Paragraphs After a Div

In this example, all <p> elements that are siblings of a <div> (and come after it) are styled with green text. Paragraphs inside the div or before it remain unaffected. 

div {
  border: 2px solid #031926;
}
div ~ p {
  color: #04af2f;
}

<p>This paragraph is above the div and will not be styled.</p>

<div>
  <p>This paragraph is inside the div and will not be styled.</p>
</div>

<p>This paragraph comes after the div and will be green.</p>
<p>This second paragraph after the div will also be green.</p>

Example 2: Applying Styles After an h3 Tag

Here, the general sibling selector is applied to all <p> tags that are siblings of an <h3>. The styles include a background color, italic font style, and larger font size. 

.container {
  padding: 20px;
  border: 2px solid #031926;
  font-family: Verdana, sans-serif;
}
h3 ~ p {
  font-family: Verdana, sans-serif;
  font-size: 20px;
  font-style: italic;
  background-color: #04af2f;
  color: white;
}

<div class="container">
  <h3>This is an h3 tag</h3>
  <p>This paragraph follows the h3 tag and is styled.</p>
  <p>This is another p tag after the h3 and is also styled.</p>
</div>

<p>This p tag is outside the container and not affected.</p>

Key Notes

  • The general sibling selector (~) applies styles to all siblings that come after the referenced element.
  • It ignores siblings that appear before the reference element.
  • It is different from the adjacent sibling selector (+), which only applies to the immediately next sibling.
  • Useful when you want to style a group of elements following a particular tag.

C++ enum class (Scoped Enumerations) 🛡️

The **enum class** (or **scoped enumeration**, introduced in C++11) is a modern C++ feature designed to solve the problems of name clashes and lack of type safety associated with traditional C++ enumerations.

Key Features and Declaration

Improved Scope

The enumerator values are **scoped** (confined) to the enum class itself, meaning they do not "leak" into the surrounding scope (e.g., the global namespace). This prevents potential **name clashes**.

Declaration Syntax:

enum class EnumName {
    Value1,
    Value2,
    // ...
};

Accessing Values: You must use the **Scope Resolution Operator (::)** to access the values, ensuring clarity and preventing ambiguity:

EnumName::Value

For example, to access Friday from the Day enum class: Day today = Day::Friday;

Enhanced Type Safety

enum class values do **not implicitly convert to integers** (int). This is a crucial aspect of type safety, preventing accidental arithmetic operations or comparison with unrelated integer constants.

If you need the underlying integer value, you must use an **explicit type cast** (e.g., static_cast<int>(Day::Friday)).

Underlying Type of enum class

By default, the underlying type of an enum class is **int**. However, you can explicitly specify a different integral type using the colon (:) syntax. This is useful for optimizing memory usage or ensuring a required value range.

Syntax to Specify Underlying Type:

enum class EnumName : UnderlyingType { ... };

Example: Using unsigned int as the underlying type to guarantee non-negative storage and potentially reduce size.

enum class Status : unsigned int {
    Ok = 0,     
    Error = 1
};

In this example, each Status enumerator is guaranteed to be stored using the size and range of an unsigned int.

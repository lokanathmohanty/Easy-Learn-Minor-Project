JavaScript - Document Object Model (DOM)

The HTML DOM allows JavaScript to access and modify the content of HTML elements. JavaScript can change all HTML elements, attributes, CSS styles in the page. JavaScript can also add or remove HTML elements and attributes. Using JavaScript, we can even create new events in the page.

Every web page resides inside a browser window which can be considered as an object. A Document object represents the HTML document that is displayed in that window. The Document object has various properties that refer to other objects which allow access to and modification of document content.

What is DOM?

The DOM (Document Object Model) is a programming interface for Core, XML, and HTML DOM. It is a W3C standard.

The DOM defines the logical or tree-like structure of a web page. In this tree, each branch ends in a node, and each node contains objects. DOM methods allow programmatic access to the tree. Using DOM methods, you can change a document’s structure, content, or style.

What is HTML DOM?

HTML creates the structure of a web page, while JavaScript adds interaction by manipulating the HTML elements. JavaScript cannot interact directly with HTML elements. So, whenever a web page loads in the browser, it creates a DOM.

The document object represents the HTML document displayed in a window. Each <iframe> in a webpage creates a new DOM. The way content is accessed and modified is called the Document Object Model (DOM). Objects are organized in a hierarchy.

Hierarchy of Objects

  • Window object − Represents the current browser window and works as a global object. It is at the top of the hierarchy.
  • Document object − Represents the HTML document loaded into a window. It is used to access and modify page elements.
  • Form object − Represents everything enclosed in the <form>...</form> tags.
  • Form control elements − Represent elements inside a form, such as text fields, buttons, radio buttons, and checkboxes.

HTML DOM

There are several DOMs in existence. The following are the main ones:

  • Legacy DOM − Introduced in early versions of JavaScript. Supported by all browsers, but provides limited access.
  • W3C DOM − Standardized by W3C, allows access and modification of all document content, and is supported by modern browsers.

Types of DOM (W3C)

  • Core DOM − Standard model for all document types.
  • HTML DOM − Standard model for HTML documents.
  • XML DOM − Standard model for XML documents.

Why is DOM Required?

When a web page loads into the browser, it becomes a document object. JavaScript can then use the DOM to interact with the page.

Using the document object, JavaScript can:

  • Access HTML elements
  • Replace HTML elements
  • Add new HTML elements
  • Delete HTML elements
  • Change CSS styles
  • Change attributes
  • Add animations
  • Add events

DOM Interfaces

DOM interfaces are components that provide methods and properties to interact with and manipulate a webpage.

  • DOMTokenList
  • NodeList
  • HTMLCollection
  • Element
  • Document
  • Attribute (attr)

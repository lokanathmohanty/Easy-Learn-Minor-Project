Java - Directory Operations

Directories in Java are represented by File objects and can contain files as well as other directories. With the File class, you can create, list, and delete directories programmatically. The following sections illustrate key directory operations in Java.

Creating Directories

  • mkdir() creates a single directory and returns true on success.
  • mkdirs() creates the directory and all necessary parent directories.
String dirname = "/tmp/user/java/bin";
File directory = new File(dirname);
// Create parent and directory structure
directory.mkdirs();
System.out.println(directory.exists()); // Output: true

Using mkdirs() ensures all directories in the path are created as required.

Listing Directory Contents

You can read all files and directories inside a directory with the list() method:

File dir = new File("/tmp");
String[] paths = dir.list();
for(String path : paths) {
    System.out.println(path);
}

This prints the names of all files and subdirectories in "/tmp".

Deleting Directories

To delete a directory, use the delete() method. Note: The directory must be empty before it can be deleted.

File file = new File("/tmp/user/java/bin");
if(file.exists()) {
    boolean success = file.delete();
    if (success) {
        System.out.println("The directory has been successfully deleted.");
    } else {
        System.out.println("The directory deletion failed.");
    }
} else {
    System.out.println("The directory is not present.");
}

Attempting to delete a non-empty directory will fail—ensure the directory is empty or use recursion to remove all contents first.

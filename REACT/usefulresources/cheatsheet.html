ReactJS Cheat Sheet

A handy reference for ReactJS covering core concepts, syntax, and commonly used hooks and APIs.

Basic Setup

  • npx create-react-app myapp − Create a new React app.
  • npm start − Run the app locally.
  • npm build − Build the app for production.

JSX

  • Embed expressions: {expression}
  • Attributes: className instead of class
  • Fragments: <> </>
const element = <h1>Hello, {name}!</h1>;

Components

function Welcome(props) {
  return <h1>Hello, {props.name}</h1>;
}
      
class Welcome extends React.Component {
  render() {
    return <h1>Hello, {this.props.name}</h1>;
  }
}

Props & State

  • Props − Immutable data passed from parent to child.
  • State − Mutable data managed inside a component.
const [count, setCount] = useState(0);

Common Hooks

  • useState() − Manage component state.
  • useEffect() − Side effects (API calls, subscriptions).
  • useContext() − Consume context values.
  • useRef() − Access DOM elements or store mutable values.
  • useReducer() − Alternative to manage complex state.
  • useMemo() − Memoize values for performance.
  • useCallback() − Memoize functions.

Events

function Button() {
  function handleClick() {
    alert("Clicked!");
  }
  return <button onClick={handleClick}>Click</button>;
}

Conditional Rendering

{isLoggedIn ? <Dashboard /> : <Login />}
      
{messages.length > 0 && <h2>You have messages</h2>}

Lists

const numbers = [1, 2, 3];
const listItems = numbers.map(n => <li key={n}>{n}</li>);

Context API

const MyContext = React.createContext();
function App() {
  return (
    <MyContext.Provider value="Hello">
      <Child />
    </MyContext.Provider>
  );
}
function Child() {
  const value = useContext(MyContext);
  return <p>{value}</p>;
}

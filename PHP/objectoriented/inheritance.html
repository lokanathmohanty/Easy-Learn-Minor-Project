PHP - Inheritance

**Inheritance** is a core OOP concept that allows a new class (**Child Class**) to derive properties, methods, and constants from an existing class (**Parent Class**). This relationship is often described as an **"Is-a"** relationship (e.g., a "Dog is a Animal"). Inheritance promotes **code reuse** and provides a logical structure for software modeling.

Class Inheritance Syntax

In PHP, the extends keyword is used to establish an inheritance relationship: 

class ChildClass extends ParentClass {
   // New or overridden functionality goes here
}

The Child Class automatically inherits all **public** and **protected** members of the Parent Class.

Types of Inheritance in PHP

PHP primarily supports two types of class inheritance:

  • Single Inheritance: One Child Class inherits from one Parent Class.
  • Multilevel Inheritance: A class inherits from another class, which itself inherits from a third class (e.g., Puppy extends Dog, and Dog extends Animal).

**Note:** PHP does **not** support **Multiple Inheritance** (extending two or more classes simultaneously).

Example: Multilevel Inheritance

The Puppy object has access to its own methods, plus the methods inherited from Dog and Animal. 

<?php
   class Animal {  
      public function sound() { echo "Animals make sound\n"; }  
   }  
   
   class Dog extends Animal {  
      public function bark() { echo "Dog barks\n"; }  
   }  
   
   class Puppy extends Dog {  
      public function weep() { echo "Puppy weeps\n"; }  
   }  
   
   $myPuppy = new Puppy();  
   $myPuppy->sound(); // Inherited from Animal
   $myPuppy->bark();  // Inherited from Dog
   $myPuppy->weep();  // Defined in Puppy
?>

Method Overriding

**Method Overriding** occurs when a Child Class redefines a method that already exists in its Parent Class. The child's definition will be executed when the method is called on an object of the Child Class. 

<?php
   class ParentClass {
      public function thanks() { echo "Thank you from parent class\n"; }
   }
   class ChildClass extends ParentClass {
      // Overrides the parent's method
      public function thanks() { echo "Thank you from the child class\n"; }
   }

   $obj2 = new ChildClass;
   $obj2->thanks(); // Output: Thank you from the child class
?>

Calling Parent Methods

When overriding a method (or a constructor), you can call the parent's implementation using the **scope resolution operator** (::) with the parent keyword. This is especially useful for extending functionality rather than completely replacing it. 

public function getebook(...) {
   parent::getbook($param1, $param2); // Calls method in the immediate parent
   $this->format = $param3; // Adds new functionality
}

Constructors in Inheritance

  • If the **Child Class does NOT define a constructor**, the Parent Class's constructor (if public or protected) is automatically inherited and called upon instantiation.
  • If the **Child Class DOES define a constructor**, the parent's constructor is **NOT** automatically called. To execute the parent's initialization logic, you must explicitly call it inside the child's constructor: 
    public function __construct(){
   parent::__construct(); // Explicitly calls the Parent's constructor
   echo "This is child class constructor" . PHP_EOL;
}

Usage of final Keyword

The final keyword prevents further modification or extension:

  • When prefixed to a **method** (e.g., final public function sound()), it prevents any Child Class from **overriding** that method.
  • When prefixed to a **class** (e.g., final class Animal), it prevents any other class from **extending** (inheriting from) it.

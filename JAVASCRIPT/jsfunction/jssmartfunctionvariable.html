JavaScript - Smart Function Parameters

The concept of smart function parameters in JavaScript makes a function adaptable to different use cases. It allows the function to handle different kinds of arguments passed during invocation.

Functions are an important concept for reusing code. In many cases, we need to ensure that functions are flexible enough to handle different situations.

Here are different ways to define a function with smart parameters:

Default Function Parameters

Default parameters allow handling undefined argument values or arguments that are not passed to the function during invocation.

In the example below, we set default values of parameters a and b to 100 and 50.

function division(a = 100, b = 50) {
   return a / b;
}

Example

<script>
function division(a = 100, b = 50) {
   return a / b;
}
document.getElementById("output").innerHTML =
   division(10, 2) + "<br>" +
   division(10, undefined) + "<br>" +
   division();
</script>

Output:

  • 5
  • 0.2
  • 2

JavaScript Rest Parameter

When the number of arguments to pass is not fixed, you can use rest parameters. They allow collecting all remaining arguments into a single array. The rest parameter is represented by three dots (...) followed by the parameter name.

function funcName(p1, p2, ...args) {
   // Function body
}

Example

<script>
function sum(...nums) {
   let totalSum = 0;
   for (let p = 0; p < nums.length; p++) {
      totalSum += nums[p];
   }
   return totalSum;
}
document.getElementById("demo").innerHTML =
   sum(1, 5, 8, 20, 23, 45) + "<br>" +
   sum(10, 20, 30) + "<br>" +
   sum() + "<br>";
</script>

Output:

  • 102
  • 60
  • 0

Note: Always use the rest parameter as the last parameter.

JavaScript Destructuring or Named Parameters

You can pass a single object as a function argument and destructure it to extract only the required values. This is also called named parameters, since you get arguments based on property names.

function funcName({ prop1, prop2 }) {
   // Function body
}

Example

<script>
function printWatch({ brand, price }) {
   return "The price of the " + brand + "'s watch is " + price;
}

const watch = {
   brand: "Titan",
   price: 10000,
   currency: "INR"
};

document.getElementById("output").innerHTML = printWatch(watch);
</script>

Output:

  • The price of the Titan's watch is 10000

These three concepts give us flexibility to pass function arguments effectively.

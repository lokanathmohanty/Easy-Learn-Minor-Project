C# Attributes: Adding Metadata to Code

What are Attributes? 🏷️

An **attribute** is a **declarative tag** used to convey information (metadata) to the **.NET runtime** or the compiler about various program elements like classes, methods, structures, enumerators, and assemblies. This declarative information is added using square brackets (`[ ]`) placed immediately before the element it modifies.

Attributes are a form of **metadata**—data about data—used for purposes such as compiler instructions, description, or runtime behavior modification.

Specifying an Attribute (Syntax)

The general syntax for applying an attribute is:

[attribute(positional_parameters, name_parameter = value, ...)]
element
  • Positional Parameters: Specify essential, required information for the attribute's constructor.
  • Named Parameters: Specify optional information by setting public properties of the attribute class.

Predefined Attributes in .NET Framework

The .NET Framework provides several built-in attributes for common tasks. Three important ones are:

1. AttributeUsage

The `[AttributeUsage]` attribute is used when **defining a custom attribute class**. It dictates *how* that custom attribute can be used.

  • `validon` (Positional): Specifies the target elements (e.g., class, method, property) the attribute can be applied to, using the `AttributeTargets` enumerator (e.g., `AttributeTargets.Class | AttributeTargets.Method`).
  • `AllowMultiple` (Named, Optional): A Boolean value. If `true`, the attribute can be applied multiple times to the same target element. Default is `false`.
  • `Inherited` (Named, Optional): A Boolean value. If `true`, the attribute is inherited by derived classes or overriding members. Default is `false`.

2. Conditional

The `[Conditional]` attribute marks a method whose compilation and execution depend on a specified **preprocessing identifier** (like `DEBUG` or `TRACE`).

[Conditional("DEBUG")]

If the specified symbol is **not defined** (e.g., `DEBUG` is not defined), the compiler will entirely skip the method and all calls to it, resulting in no compiled code and no runtime overhead.

3. Obsolete

The `[Obsolete]` attribute marks a program entity (like a method or class) that should **no longer be used**. It's primarily used to inform developers about deprecation.

  • `message` (Positional, Optional): A string explaining why the item is obsolete and what to use instead.
  • `iserror` (Positional, Optional): A Boolean value. If `true`, using the marked element generates a **compiler error** instead of just a warning (the default).

Creating Custom Attributes

You can create your own custom attributes to add domain-specific metadata that can be read and used at runtime, typically via **Reflection** (which is discussed in the next chapter).

Steps for Custom Attribute Creation:

  1. Declare the Attribute: The custom attribute class must **inherit from `System.Attribute`**. Conventionally, the class name ends with `Attribute`, but C# allows omitting this suffix when applying it.
  2. Construct the Attribute: Define constructors to handle the **positional parameters**. Define public properties for the **named parameters**.
  3. Apply the Attribute: Place the attribute tag `[MyAttribute(...)]` immediately above the target element.
  4. **Access via Reflection:** (Future step) Use the **Reflection** API to inspect the metadata at runtime.

Example: Custom `DeBugInfo` Attribute

The `DeBugInfo` attribute is declared to track debugging metadata (Bug Number, Developer, Last Review Date, and Message).

Declaration and Construction:

// 1. Inherits from System.Attribute
[AttributeUsage(
   AttributeTargets.Class | AttributeTargets.Method, 
   AllowMultiple = true)]
public class DeBugInfo : System.Attribute {
   // Positional parameters handled by the constructor
   public DeBugInfo(int bg, string dev, string d) { /* ... */ }
   
   // Named parameter is a public property
   public string Message { get; set; } 
}

Application:

[DeBugInfo(45, "Zara Ali", "12/8/2012", Message = "Return type mismatch")]
class Rectangle {
   // ...
   [DeBugInfo(55, "Zara Ali", "19/10/2012")]
   public double GetArea() {
      // ...
   }
}

JavaScript - Dialog Boxes

JavaScript supports three important types of dialog boxes. These can be used to raise an alert, get confirmation, or collect input from the users. Let's go through them one by one.

1. Alert Dialog Box

An alert dialog box is mostly used to give a warning message to the users. For example, if one input field requires some text but the user does not provide it, you can use an alert box as part of validation. An alert box gives only one button "OK" to proceed.

Example

<html>
<head>
  <script type="text/javascript">
    function Warn() {
      alert("This is a warning message!");
      document.write("This is a warning message!");
    }
  </script>
</head>
<body>
  <p>Click the following button to see the result:</p>
  <form>
    <input type="button" value="Click Me" onclick="Warn();" />
  </form>
</body>
</html>

2. Confirmation Dialog Box

A confirmation dialog box is used to take the user's consent on an action. It displays a dialog with two buttons: OK and Cancel.

  • If the user clicks OK, the confirm() method returns true.
  • If the user clicks Cancel, it returns false.

Example

<html>
<head>
  <script type="text/javascript">
    function getConfirmation() {
      var retVal = confirm("Do you want to continue?");
      if (retVal == true) {
        document.write("User wants to continue!");
        return true;
      } else {
        document.write("User does not want to continue!");
        return false;
      }
    }
  </script>
</head>
<body>
  <p>Click the following button to see the result:</p>
  <form>
    <input type="button" value="Click Me" onclick="getConfirmation();" />
  </form>
</body>
</html>

3. Prompt Dialog Box

A prompt dialog box is useful when you want to pop up a text box to get input from the user. It takes two parameters:

  • A label to display in the text box.
  • A default string to display as initial value.

This dialog has two buttons: OK and Cancel.

  • If the user clicks OK, the prompt() method returns the entered value.
  • If the user clicks Cancel, it returns null.

Example

<html>
<head>
  <script type="text/javascript">
    function getValue() {
      var retVal = prompt("Enter your name:", "your name here");
      document.write("You have entered: " + retVal);
    }
  </script>
</head>
<body>
  <p>Click the following button to see the result:</p>
  <form>
    <input type="button" value="Click Me" onclick="getValue();" />
  </form>
</body>
</html>

Node.js - MySQL WHERE Clause

Overview

The WHERE clause in MySQL is used to filter records based on specified conditions during SELECT, UPDATE, or DELETE operations. Complex conditions can be created using logical operators like AND, OR, and NOT.

Basic WHERE Syntax

SELECT select_list
FROM table_name
WHERE search_condition;

The search_condition can combine multiple expressions using logical operators.

Comparison Operators

  • = (equal)
  • != (not equal)
  • > (greater than)
  • < (less than)
  • >= (greater than or equal)
  • <= (less than or equal)
  • BETWEEN (range)
  • LIKE (pattern matching)
  • IN (multiple values)

Example: Simple WHERE Condition

var mysql = require('mysql');
var con = mysql.createConnection({
   host: "localhost",
   user: "root",
   password: "mypassword",
   database: "mydb"
});
var qry = `SELECT name,salary FROM employee WHERE salary > 25000;`;

con.connect(function (err) {
   if (err) throw err;
   console.log("Connected!");
   con.query(qry, function (err, results) {
      if (err) throw err;
      console.log(results);
   });
   con.end();
});

Output example:

[
  { name: 'Anil', salary: 30000 },
  { name: 'Meena', salary: 27000 }
]

Example: Complex WHERE with AND

var qry = `SELECT name,salary FROM employee WHERE salary > 25000 AND salary < 30000;`;

Example: BETWEEN Clause

var qry = `SELECT name,salary FROM employee WHERE salary BETWEEN 27000 AND 30000;`;

Example: LIKE Clause - Pattern Matching

var qry = `SELECT name,salary FROM employee WHERE name LIKE '%n%';`;

Example: IN Clause - Match Multiple Values

var qry = `SELECT name,salary FROM employee WHERE name IN ('Anil', 'Tina', 'Ravi');`;

These queries refine data retrieval by matching conditions to get filtered results.

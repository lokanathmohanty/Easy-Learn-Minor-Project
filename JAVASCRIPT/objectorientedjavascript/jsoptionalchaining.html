JavaScript - Optional Chaining

The optional chaining in JavaScript allows you to access nested properties and methods of an object without checking if each property exists. This can help to make your code more concise and easier to read.

The optional chaining operator (?.) is used to achieve optional chaining in JavaScript. It is placed before the property or method that you want to access. If the property or method does not exist, the expression will evaluate to undefined instead of throwing an error.

The Non-existing Property Problem

While working with objects in JavaScript, you may have objects with dynamic properties. Some properties also contain nested objects. JavaScript can throw an error if you try to access the nested property whose parent doesn't exist. 

const parent = {
    child: {
        name: "Smith",
    }
}
const name = parent.child.name;

Error:

Uncaught TypeError: Cannot read properties of undefined

To solve this problem, the && operator was used before ES11: 

if (parent.child && parent.child.name) {
   // access parent.child.name here
}

However, this becomes messy when accessing deeply nested properties. The optional chaining operator (?.) solves this problem easily.

What is Optional Chaining?

In JavaScript, the optional chaining operator (?.) was introduced in ECMAScript 2020 (ES11). It provides a safe way to access object properties, array elements, and even functions.

Syntax

obj?.prop1?.nestedprop; // Accessing nested properties
obj?.[expression]; // Accessing object property via expression
array?.[index]; // Accessing array element
funcName?.(); // Executing the function

Return Value

If a property does not exist, the optional chain returns undefined without throwing any error.

Example

const car = {
   brand: "Audi",
   model: "Q6",
   info: {
      price: 5000000,
      color: "Black",
   }
}
console.log(car.info?.price);   // 5000000
console.log(car.engine?.gears); // undefined

Output:

The price of the Audi Q6 is: 5000000
Total gears in the Audi Q6 is: undefined

Optional Chaining with Function Calls

const car = {
   getBrand() {
      return "Audi";
   },
}
console.log(car.getBrand?.()); // "Audi"
console.log(car.getColor?.()); // undefined

Output:

The brand of the car is: Audi
The color of the car is: undefined

Optional Chaining with Expression

const animal = {
   name: "Tiger",
   info: {
      legs: 4,
      tail: 1,
   }
}
console.log(animal.info?.["legs"]); // 4
console.log(animal.specs?.["color"]); // undefined

Output:

Total number of legs of the tiger is: 4
The color of the tiger is: undefined

Optional Chaining with the "delete" Operator

const animal = {
   name: "Tiger",
   info: {
      legs: 4,
      tail: 1,
   }
}
delete animal.info?.legs;
delete animal.specs?.tail;
console.log(animal);

Output:

Updated object is: {"name":"Tiger","info":{"tail":1}}

Short-circuiting with Optional Chaining

const animal = {
   name: "Tiger",
   info: {
      legs: {
         first: 1.32,
         second: 1.31,
      },
      tail: 1,
   }
}
console.log(animal?.info?.legs?.first); // 1.32
console.log(animal?.specs?.legs?.third); // undefined

Output:

The size of the first leg is: 1.32
The size of the third leg is: undefined

Nullish Coalescing Operator with Optional Chaining

const animal = {
   name: "Tiger",
   info: {
      legs: 2,
      tail: 1,
   }
}
const color = animal?.spec?.color ?? "Red";
console.log(color);

Output:

The color of the animal is: Red

In simple terms, you can use the optional chaining operator wherever you need to access the properties of a dynamic object to avoid an error.

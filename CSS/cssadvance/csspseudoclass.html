CSS - Pseudo Classes

Pseudo-classes in CSS are used to select and style elements based on their state or position within the document tree, without the need for adding extra classes or JavaScript.

For example, pseudo-class can be used to change the color of an element when the mouse is hovered over it or when a button is clicked.

What is Pseudo-class?

Pseudo-classes are used along with CSS Selectors by inserting a colon (:) after the selector.

For example: a:hover {} — Here, the selector a selects all anchor tags, and :hover applies a style when hovered.

A functional pseudo-class contains parentheses for arguments, like :lang(en).

The element to which a pseudo-class is attached is called the anchor element. Example: button:hover, a:focus.

Pseudo-classes can depend on document structure, user interactions, or external factors (like :visited, :checked, :hover).

Syntax

selector:pseudo-class {
   property: value;
}

Pseudo-Class Hover

The :hover pseudo-class is used to specify the hovering state of an element when the mouse passes over it.

Syntax

tag:hover {
   property: value;
}

Example

<a href="#">Hover over me!</a>
<div>Hover me</div>

Pseudo-Class Active

The :active pseudo-class applies a style to an element when it is being activated (clicked or tapped).

Syntax

tag:active {
   property: value;
}

Example

<a href="#">Click Me</a>
<p>Click me to see the effect.</p>
<ul>
   <li>Item 1</li>
   <li>Item 2</li>
</ul>

Pseudo-Class Focus

The :focus pseudo-class applies a style when an element (like an input) gains focus.

Syntax

tag:focus {
   property: value;
}

Example

<input type="text" placeholder="Type Something!">

Pseudo-Class nth-child

The :nth-child(n) pseudo-class styles children of an element based on their position.

Syntax

tag:nth-child(number/expression/odd/even) {
   property: value;
}

Example

<div>
   <div>1st div</div>
   <div>2nd div</div>
   <div>3rd div</div>
</div>

<ul>
   <li>First item</li>
   <li>Second item</li>
</ul>

Pseudo-Class First-Child

The :first-child pseudo-class selects the first child of a parent element.

Syntax

tag:first-child {
   property: value;
}

Example

<p>This is the first child paragraph.</p>

Pseudo-Class Last-Child

The :last-child pseudo-class selects the last child of a parent element.

Syntax

tag:last-child {
   property: value;
}

Example

<p>This is the last child paragraph.</p>

Pseudo-Class Lang

The :lang() pseudo-class applies style based on the language attribute of an element.

Example

<q lang="en">This is English text</q>
<q lang="fr">Ceci est un texte français</q>

Pseudo-Class Not

The :not(selector) pseudo-class selects all elements except those matching the given selector.

Syntax

tag:not(selector) {
   property: value;
}

Example

<p>Normal paragraph</p>
<p class="special">Special paragraph</p>

List of CSS Pseudo Classes

Below is a list of commonly used CSS pseudo-classes:

  • :active — when an element is clicked
  • :hover — when the mouse hovers over an element
  • :focus — when an element is focused
  • :first-child — first child of a parent
  • :last-child — last child of a parent
  • :nth-child(n) — selects based on child position
  • :not(selector) — selects everything except the specified selector
  • :lang(language) — applies styles based on language

Node.js - MongoDB Insert

Overview

MongoDB is a document-oriented NoSQL database that stores data as JSON-like documents in collections. Each document is a set of key-value pairs and has a unique "_id" field acting as the primary key.

In Node.js, MongoDB documents can be added using insertOne() (single document) or insertMany() (multiple documents) from the MongoDB driver.

Document Structure

{
  field1: value1,
  field2: value2,
  ...
  fieldN: valueN
}

If _id is omitted, MongoDB automatically generates an ObjectId.

Insert a Single Document (insertOne)

const { MongoClient } = require('mongodb');

async function main() {
  const uri = "mongodb://localhost:27017";
  const client = new MongoClient(uri);

  try {
    await client.connect();
    await insertDoc(client, "mydatabase", "products", {
      ProductID: 1,
      Name: "Laptop",
      Price: 25000
    });
  } finally {
    await client.close();
  }
}

async function insertDoc(client, dbName, colName, doc) {
  const db = client.db(dbName);
  const collection = db.collection(colName);
  const result = await collection.insertOne(doc);
  console.log(`New document created with _id: ${result.insertedId}`);
}

main().catch(console.error);

Example output:

New document created with _id: 65809214693bd4622a5efc3

Insert Multiple Documents (insertMany)

async function insertDocs(client) {
  const docs = [
    { ProductID: 1, Name: "Laptop", price: 25000 },
    { ProductID: 2, Name: "TV", price: 40000 },
    { ProductID: 3, Name: "Router", price: 2000 },
    { ProductID: 4, Name: "Scanner", price: 5000 },
    { ProductID: 5, Name: "Printer", price: 9000 }
  ];
  const result = await client.db("mydatabase").collection("products").insertMany(docs);
  console.log(`${result.insertedCount} new documents inserted.`);
  console.log("Inserted IDs:", result.insertedIds);
}

Output example:

5 new documents inserted.
Inserted IDs: {
  '0': ObjectId("..."),
  '1': ObjectId("..."),
  ...
}

Data Verification

Documents inserted can be viewed in MongoDB shell:

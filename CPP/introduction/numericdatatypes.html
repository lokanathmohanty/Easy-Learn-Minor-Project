C++ Numeric Data Types: Integers and Floating-Point Numbers

Numeric data types in C++ are used to handle numerical values, encompassing **integers** (whole numbers) and **floating-point values** (numbers with decimal parts). They determine the amount of memory allocated and the range of values a variable can store.

Integer Data Types (int and Subtypes) 🔢

The core integer type is int, which is typically **4 bytes** (32 bits), ranging from $-2^{31}$ to $(2^{31}-1)$. It can be modified for size and sign:

Size Modifiers:

  • short int: Used for smaller numbers; typically **2 bytes** (16 bits).
  • long int: Used for larger numbers; typically **4 or 8 bytes** (32 or 64 bits).
  • long long int: Used for very large numbers; guaranteed to be at least as large as long int, typically **8 bytes** (64 bits).

Sign Modifiers:

The unsigned keyword restricts the variable to store **non-negative values** (zero and positive numbers). This doubles the positive range compared to the signed version.

  • unsigned int: Same memory as int (e.g., 4 bytes), range from $0$ to $(2^{32}-1)$.
  • unsigned short int: Typically 2 bytes, range from $0$ to $(2^{16}-1)$.
  • unsigned long int and unsigned long long int: Store only non-negative values in their respective memory sizes.

Floating-Point Data Types (float, double) 🧮

These types store numbers that include a decimal point (real numbers) and are primarily distinguished by their **precision**.

  • float: Single-precision floating-point type. Typically **4 bytes** (32 bits).
  • double: Double-precision floating-point type. Typically **8 bytes** (64 bits). It provides higher precision and a larger range than float.
  • long double: Extended precision floating-point type. Typically **12 or 16 bytes** (96 or 128 bits), offering the highest available precision.

Explicit Type Conversion

Explicit conversion (or type casting) allows manual conversion of a value from one data type to another by specifying the target type in parentheses.

Syntax: (target_data_type) expression_or_variable

Example: Casting a double to an int truncates the decimal part (e.g., (int)6.551555 becomes 6).

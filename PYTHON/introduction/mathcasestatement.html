Python - Match-Case Statement

The match-case statement in Python (introduced in Python 3.10) is used for pattern matching. It compares an expression’s value against multiple patterns defined in case blocks. Only the first matching case executes.

This is similar to switch-case in C/C++/Java, but Python’s implementation is more powerful, resembling pattern matching in languages like Rust and Haskell.

Syntax

match variable_name:
    case 'pattern1': statement1
    case 'pattern2': statement2
    ...
    case 'patternN': statementN

Example

Example showing weekdays using match-case:

def weekday(n):
    match n:
        case 0: return "Monday"
        case 1: return "Tuesday"
        case 2: return "Wednesday"
        case 3: return "Thursday"
        case 4: return "Friday"
        case 5: return "Saturday"
        case 6: return "Sunday"
        case _: return "Invalid day number"

print(weekday(3))
print(weekday(6))
print(weekday(7))

Output:

Thursday
Sunday
Invalid day number

The _ symbol is a wildcard case, executed when no other case matches.

Combined Cases

You can combine multiple cases using the | (OR) operator.

def access(user):
    match user:
        case "admin" | "manager": return "Full access"
        case "Guest": return "Limited access"
        case _: return "No access"

print(access("manager"))
print(access("Guest"))
print(access("Ravi"))

Output:

Full access
Limited access
No access

Using Lists in Match-Case

Lists can also be used in case clauses, including variable-length lists using *.

def greeting(details):
    match details:
        case [time, name]:
            return f"Good {time} {name}!"
        case [time, *names]:
            msg = ""
            for name in names:
                msg += f"Good {time} {name}!\n"
            return msg

print(greeting(["Morning", "Ravi"]))
print(greeting(["Afternoon", "Guest"]))
print(greeting(["Evening", "Kajal", "Praveen", "Lata"]))

Output:

Good Morning Ravi!
Good Afternoon Guest!
Good Evening Kajal!
Good Evening Praveen!
Good Evening Lata!

Using "if" in Case Clause

Conditional expressions can be added using if inside a case clause.

def intr(details):
    match details:
        case [amt, duration] if amt < 10000:
            return amt * 10 * duration / 100
        case [amt, duration] if amt >= 10000:
            return amt * 15 * duration / 100

print("Interest =", intr([5000, 5]))
print("Interest =", intr([15000, 3]))

Output:

Interest = 2500.0
Interest = 6750.0

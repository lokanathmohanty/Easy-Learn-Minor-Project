Node.js - NPM (Node Package Manager)

Overview

NPM is the default package manager for Node.js. It helps manage JavaScript packages, libraries, and dependencies efficiently in Node.js projects. NPM is installed automatically alongside Node.js.

Checking NPM Version

npm -v

This command shows the installed version of NPM, for example: 10.9.2

Installing a Package Locally

Local packages are installed inside the node_modules directory of the project and recorded in package.json. This ensures each project maintains its own dependencies and avoids conflicts.

npm install express

To install a specific package version use:

npm install <package-name>@<version>

Example:

npm install express@4.17.1

Benefits of Local Installation

  • Version control: Keeps dependency versions consistent across environments.
  • Security: Avoids unexpected changes from globally installed packages.

Package Installation Flags

  • --save-dev: Installs package as a development dependency (e.g., testing tools).
  • --save-exact: Locks the exact version of the package in package.json.
  • --no-save: Installs the package without adding it to package.json.

Installing a Package Globally

Global packages can be accessed anywhere on your system, useful for CLI tools.

npm install -g <package-name>

Example:

npm install -g nodemon

Benefits of Global Installation

  • Useful for command-line tools like nodemon, typescript, and eslint.
  • Provides system-wide access without project-level installs.
  • Streamlines development workflow.

Managing Global Packages

Check outdated global packages:

npm outdated -g

Update a global package:

npm update -g <package-name>

Managing Dependencies

View locally installed packages:

npm list

View globally installed packages:

npm list -g --depth=0

Checking Package Versions

Check the latest available version of a package:

npm show <package-name> version

Check all available versions:

npm show <package-name> versions

Removing a Package

Uninstall a package locally:

npm uninstall <package-name>

Uninstall a package globally:

npm uninstall -g <package-name>

Break Statement in C

The break statement in C is used to terminate the execution of loops or switch-case blocks. It is a powerful control flow tool that immediately stops the current loop or switch block and transfers control to the next statement outside of it.

Usage of break in C

  • In switch-case: To exit a case block after executing its statements.
  • In loops: To terminate a for, while, or do-while loop prematurely when a condition is met.

1. Break in While Loop

The break statement is usually used inside an if condition. If not, it may cause the loop to terminate in the very first iteration.

Example: Check if a Number is Prime

#include <stdio.h>

int main () {
   int i = 2;
   int x = 121;
   printf("x: %d\n", x);

   while (i < x/2) {
      if (x % i == 0)
         break;
      i++;
   }

   if (i >= x/2)
      printf("%d is prime", x);
   else
      printf("%d is not prime", x);

   return 0;
}

Output:

x: 121
121 is not prime

2. Break in For Loop

Sometimes, you may want to exit a for loop before it completes all iterations, usually based on a condition.

Example: Print Characters Until a Vowel

#include <stdio.h>
#include <string.h>

int main () {
   char string[] = "Rhythmic";
   int len = strlen(string);
   int i;

   for (i = 0; i < len; i++) {
      if (string[i] == 'a' || string[i] == 'e' || string[i] == 'i' ||
          string[i] == 'o' || string[i] == 'u')
         break;
      printf("%c\n", string[i]);
   }

   return 0;
}

Output:

R
h
y
t
h
m

3. Break in Nested Loops

If used inside a nested loop, break will only terminate the innermost loop where it's placed.

Example: Prime Numbers from 1 to 30

#include <stdio.h>

int main() {
   int i, num, flag;
   printf("The prime numbers in between the range 1 to 30:\n");

   for (num = 2; num <= 30; num++) {
      flag = 0;

      for (i = 2; i <= num/2; i++) {
         if (num % i == 0) {
            flag++;
            break;
         }
      }

      if (flag == 0)
         printf("%d is prime\n", num);
   }

   return 0;
}

Output:

2 is prime
3 is prime
5 is prime
7 is prime
11 is prime
13 is prime
17 is prime
19 is prime
23 is prime
29 is prime

4. Break in Infinite Loops

You can deliberately create an infinite loop and use break to exit it when a condition is met.

Example: Random Number Until Divisible by 5

#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main() {
   int num;
   printf("Program to get a random number from 1 to 100:\n");

   srand(time(NULL));

   for (;;) {
      num = rand() % 100 + 1;
      printf("%d\n", num);

      if (num % 5 == 0)
         break;
   }
}

Sample Output:

Program to get a random number from 1 to 100:
6
56
42
90

5. Break in Switch-Case

In switch statements, break is essential to prevent fall-through from one case to another.

Example: Greeting Based on Time Code

#include <stdio.h>

int main() {
   char ch = 'm';
   printf("Time code: %c\n\n", ch);

   switch(ch) {
      case 'm':
         printf("Good Morning\n");
         break;
      case 'a':
         printf("Good Afternoon\n");
         break;
      case 'e':
         printf("Good Evening\n");
         break;
      default:
         printf("Hello\n");
   }

   return 0;
}

Output:

Time code: m

Good Morning

If you remove the break statements, the output will fall through and execute all the remaining case blocks after the matched one.

Output Without Break:

Time code: m

Good Morning
Good Afternoon
Good Evening
Hello

Key Takeaways

  • break is used to exit loops and switch statements prematurely.
  • In loops, it stops the execution of the current loop only.
  • In nested loops, it only breaks the innermost loop.
  • In switch-case, it prevents fall-through to the next case.

Java - URLConnection Class

java.net.URLConnection is an abstract class whose subclasses represent the various types of URL connections. Instances of this class can be used both to read from and write to the resource referenced by the URL.

For example −

  • If you connect to a URL whose protocol is HTTP, the URL.openConnection() method returns an HttpURLConnection object.
  • If you connect to a URL that represents a JAR file, the URL.openConnection() method returns a JarURLConnection object.

Steps to make a connection to a URL

Follow these steps to make a connection to the URL and start processing:

  • Invoke URL.openConnection() method to get a connection object.
  • Update setup parameters and general request properties as required using the connection object's setter methods.
  • Create a connection to the remote object using the connect() method.
  • Once the remote object is available, access the content and headers.

URLConnection Class Declaration

public abstract class URLConnection extends Object

URLConnection Class Fields

  • allowUserInteraction: Allows user interaction such as authentication dialogs.
  • connected: Indicates if connection is established.
  • doInput: Set by setDoInput.
  • doOutput: Set by setDoOutput.
  • ifModifiedSince: Used to fetch object only if modified since given time.
  • url: Represents the remote URL object.
  • useCaches: If true, caching is allowed.

URLConnection Class Methods

This class provides many methods to manage and retrieve connection information, such as:

  • addRequestProperty(String key, String value): Add a general request property.
  • getContent(): Retrieves the content of the URL connection.
  • getInputStream(): Returns input stream to read from connection.
  • getOutputStream(): Returns output stream to write to connection.
  • setConnectTimeout(int timeout): Set connection timeout in milliseconds.
  • ...and many more.

Example of URLConnection Class Usage

The following code demonstrates connecting to an HTTP URL and reading data line-by-line:

URLConnectionDemo Example

package com.tutorialspoint;

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.net.HttpURLConnection;
import java.net.URL;
import java.net.URLConnection;

public class URLConnectionDemo {
   public static void main(String [] args) {
      try {
         URL url = new URL("https://www.tutorialspoint.com");
         URLConnection urlConnection = url.openConnection();
         HttpURLConnection connection = null;
         if(urlConnection instanceof HttpURLConnection) {
            connection = (HttpURLConnection) urlConnection;
         } else {
            System.out.println("Please enter an HTTP URL.");
            return;
         }
         
         BufferedReader in = new BufferedReader(
            new InputStreamReader(connection.getInputStream()));
         String urlString = "";
         String current;
         
         while((current = in.readLine()) != null) {
            urlString += current;
         }
         System.out.println(urlString);
      } catch (IOException e) {
         e.printStackTrace();
      }
   }
}

Sample output:

The complete HTML content of the home page of tutorialspoint.com.

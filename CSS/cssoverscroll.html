CSS - overscroll-behavior Property

The CSS overscroll-behavior property is a shorthand property that controls what happens when a user scrolls beyond the boundary of a scrollable area. By default, when a scroll reaches its limit, the scrolling may continue on ancestor elements, a phenomenon called scroll chaining.

This property allows developers to control or prevent this chaining effect. It is especially useful in UI components such as modal dialogs, side panels, or embedded scrollable containers where unwanted scroll propagation can break the user experience.

Scroll Chaining Explained

Scroll chaining occurs when you scroll past the end of a child element, and the parent element starts scrolling. For example, imagine a modal box with a lot of text. Once you scroll to the bottom of the modal, if the modal uses the default behavior, the background page will start scrolling as well. This can be disruptive in some cases, so overscroll-behavior allows you to manage this behavior precisely.

Syntax

overscroll-behavior = [ contain | auto | none ]{1,2}

  • auto − Default value. Normal scroll chaining occurs.
  • contain − Scrolling is contained within the element, preventing scroll chaining to parent containers.
  • none − Prevents both scroll chaining and default overflow behaviors such as bounce effects in some browsers.

Applies To

The overscroll-behavior property applies to all non-replaced block-level and inline-block elements. It does not apply when set directly on an <iframe>, but rather must be set inside its document (on <html> or <body>).

Examples of overscroll-behavior Property

Example 1: overscroll-behavior: auto

In this example, the auto value is applied, which means the scroll chaining continues normally. Once the blue box reaches the scroll boundary, the parent container also begins scrolling. 

div {
  overflow: auto;
  border: 2px solid black;
}
#box-1 {
  background-color: lightblue;
  overscroll-behavior: auto;
}

Behavior: When the inner content reaches the end, scrolling continues on the parent container.

Example 2: overscroll-behavior: contain

Here, the contain value ensures that scrolling is limited to the element itself. The parent container will not scroll once the element has reached its scroll boundary. 

#box-2 {
  background-color: aliceblue;
  overscroll-behavior: contain;
}

Behavior: Scrolls stop at the boundary of the element, preventing parent elements from scrolling.

Example 3: overscroll-behavior with Two Values

You can specify two values: one for the horizontal axis (x) and one for the vertical axis (y). For example: 

#box-3 {
  overscroll-behavior: auto none;
}

In this case, horizontal scrolling is normal (auto), but vertical scrolling is blocked from chaining (none).

Associated Properties

  • overscroll-behavior-x − Controls scroll behavior along the horizontal axis.
  • overscroll-behavior-y − Controls scroll behavior along the vertical axis.
  • overscroll-behavior-block − Controls scroll behavior in the block direction.
  • overscroll-behavior-inline − Controls scroll behavior in the inline direction.

Practical Use Cases

  • Prevent background scrolling when using modal dialogs.
  • Avoid nested scrolling issues in sidebars or chat windows.
  • Improve user experience in mobile web apps where bounce effects are not desirable.

Browser Support

The overscroll-behavior property is supported by most modern browsers including Chrome, Edge, Firefox, Safari, and Opera.

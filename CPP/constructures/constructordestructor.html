C++ Constructors and Destructors 🏗️/⚰️

**Constructors** and **Destructors** are special member functions automatically executed at the beginning and end of an object's lifecycle, respectively. They are crucial for initialization and resource cleanup.

The Class Constructor

A **constructor** is a special member function that is executed automatically whenever a new object of the class is created.

  • **Name:** Must have the **exact same name** as the class.
  • **Return Type:** Has **no return type** (not even `void`).
  • **Purpose:** Primarily used for **initializing** the object's data members.

Types of Constructors

  1. Default Constructor: Has no parameters. 
    Line(); // Declaration
Line::Line(void) { /* ... initialization ... */ }
  2. Parameterized Constructor: Takes one or more parameters, allowing initial values to be set during object creation. 
    Line(double len); // Declaration
Line::Line(double len) { length = len; }

Initialization Lists (Recommended)

For parameterized constructors, the preferred way to initialize member fields is by using a **member initialization list**, which ensures initialization happens before the constructor body executes.

// Member initialization list syntax
Line::Line(double len) : length(len) {
   cout << "Object created." << endl;
}

This is generally more efficient and required for initializing const and reference members.

The Class Destructor

A **destructor** is a special member function that is executed automatically whenever an object of the class is **destroyed** (e.g., when it goes out of scope or when delete is called on a pointer to the object).

  • **Name:** Must have the **exact same name** as the class, prefixed with a **tilde** (~).
  • **Parameters/Return:** Cannot take **any parameters** and has **no return type**.
  • **Purpose:** Primarily used for **releasing resources** acquired by the object, such as closing files, deallocating memory (using delete), or cleaning up network connections.
class Line {
   public:
      ~Line(); // Destructor declaration
      // ...
};

Line::~Line(void) {
   cout << "Object is being deleted" << endl; 
   // Resource cleanup code goes here
}

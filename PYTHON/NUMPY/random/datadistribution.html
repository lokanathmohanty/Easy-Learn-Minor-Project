Data Distribution and Random Data in NumPy

Data distribution is a list of all possible values in a dataset and the frequency of their occurrence. It is crucial in statistics and data science to understand the underlying pattern and spread of data.

Random data can be generated in NumPy via its random module, allowing creation of random values following specified distributions.

A random distribution is a set of numbers generated based on a specific probability density function, which defines the likelihood of various values occurring.

Generating Random Data with Probability Distribution

The function choice() can generate random samples from an array of values, with optional probabilities assigned to each value.

The probability list must sum to 1. Values with probability 0 will never be selected.

Example: Generate 100 random values from the set {3, 5, 7, 9}, where probabilities are 0.1, 0.3, 0.6, and 0 respectively:

from numpy import random

x = random.choice([3, 5, 7, 9], p=[0.1, 0.3, 0.6, 0.0], size=100)

print(x)

Values will be picked according to the provided probability distribution.

Generating Multi-dimensional Random Arrays with Distribution

You can create multi-dimensional arrays with values distributed as specified by passing a shape tuple to size.

Example: Generate a 3x5 array from the same value set and distribution:

from numpy import random

x = random.choice([3, 5, 7, 9], p=[0.1, 0.3, 0.6, 0.0], size=(3, 5))

print(x)

PHP Data Types Overview

In PHP, **Data Types** classify the kind of data a variable can store. PHP is a **dynamically typed language**, meaning you don't declare the variable type; the type is determined at runtime based on the assigned value.

The Eight Data Types in PHP

PHP's data types are divided into simple (scalar), compound, and special types:

1. Simple (Scalar) Types

  • **Integer (`int`)**: Whole numbers (positive or negative) without a decimal point, like `4195` or `-12`. Can be represented in decimal (base 10), hexadecimal (`0x`), octal (`0o`), or binary (`0b`).
  • **Double (Float)**: Floating-point numbers, or "real numbers," with a fractional component, like `3.14159`. Can use scientific notation (e.g., `1.2e3`).
  • **Boolean (`bool`)**: Represents a truth value, having only two possible values: **`true`** or **`false`**. Other types evaluate to boolean based on simple rules (e.g., `0`, empty string `""`, and `NULL` are all considered `false`).
  • **String**: A sequence of characters. PHP supports a 256-character set (byte-level).
  • **NULL**: A special type with only one possible value: **`NULL`**. It is used to indicate a variable is missing a value or has been unset.

2. Compound Types

These types can store collections of data:

  • **Array**: An **ordered map** that associates **keys** (numeric indices or strings) with **values**. Arrays can be indexed, associative, or multi-dimensional.
    $arr = ["foo" => "bar", "key" => "value"];
  • **Object**: An instance of a programmer-defined class, packaging up both data (properties) and functions (methods) specific to that class. Objects are created using the `new` statement.

3. Special Types

  • **Resource**: A special variable that holds a **reference to an external resource** outside of PHP, such as a file stream (`$fp = fopen(...)`) or a database connection.

String Delimiters and Syntax

Single-Quoted vs. Double-Quoted Strings

  • **Single Quotes (`'`)**: Strings are treated almost **literally**. Variable names (`$variable`) and most escape sequences are not interpreted.
  • **Double Quotes (`"`)**: Variables (starting with `$`) are **replaced with their values** (variable interpolation), and certain escape sequences (like `\n` for newline or `\t` for tab) are interpreted.

Checking the Type

The built-in function **`gettype()`** is used to determine the data type of a variable at runtime.

<?php
   $x = 10;
   echo gettype($x); // Output: integer
?>

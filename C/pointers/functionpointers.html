Function Pointers in C

What is a Function Pointer?

A function pointer in C is a variable that stores the address of a function. This allows functions to be passed as arguments, returned from other functions, and stored in arrays, enabling dynamic function calls and callbacks.

Declaring a Function Pointer

To declare a function pointer, specify the return type, followed by an asterisk, the pointer name, and the parameter types:

return_type (*pointer_name)(parameter_types);

Example: Calling a Function via Pointer

Consider the following simple function and its pointer usage:

void hello() {
  printf("Hello World");
}

int main() {
  void (*ptr)() = hello;
  (*ptr)();
  return 0;
}

This program defines a function hello and calls it using a function pointer ptr.

Function Pointer with Arguments

Function pointers can also point to functions with parameters:

int add(int a, int b) {
  return a + b;
}

int main() {
  int (*ptr)(int, int) = add;
  int result = (*ptr)(3, 4);
  printf("Result: %d", result);
  return 0;
}

This example demonstrates how to declare a function pointer ptr that points to the add function and uses it to compute the sum of 3 and 4.

Pointer to Function with Pointer Arguments

Function pointers can also point to functions that take pointer arguments:

void swap(int *a, int *b) {
  int temp = *a;
  *a = *b;
  *b = temp;
}

int main() {
  void (*ptr)(int*, int*) = swap;
  int x = 10, y = 20;
  (*ptr)(&x, &y);
  printf("x: %d, y: %d", x, y);
  return 0;
}

This program defines a swap function that swaps the values of two integers using their pointers and calls it via a function pointer ptr.

Array of Function Pointers

Function pointers can be stored in arrays, allowing dynamic function selection:

float add(int a, int b) { return a + b; }
float subtract(int a, int b) { return a - b; }
float multiply(int a, int b) { return a * b; }
float divide(int a, int b) { return a / b; }

int main() {
  float (*operations[])(int, int) = {add, subtract, multiply, divide};
  int a = 15, b = 5;
  int choice = 3; // multiplication
  printf("Result: %.2f", (*operations[choice - 1])(a, b));
  return 0;
}

This example demonstrates how to use an array of function pointers operations to select and perform different arithmetic operations based on user input.

Applications of Function Pointers

  • Callback Functions: Passing functions as arguments to other functions to customize behavior.
  • Dynamic Function Calls: Selecting functions at runtime based on conditions.
  • Implementing Interfaces: Using function pointers in structures to emulate object-oriented behavior.
  • Event Handling: Registering functions to handle specific events or signals.

Best Practices

  • Ensure the function pointer matches the signature of the target function.
  • Use typedefs to simplify complex function pointer declarations.
  • Be cautious when using function pointers in embedded systems or safety-critical applications, as they can complicate static analysis and debugging.

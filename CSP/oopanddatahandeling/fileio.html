C# File I/O (Input/Output)

Files and Streams

In C#, a **file** is a named collection of data stored on disk. When a file is accessed for reading or writing, it is treated as a **stream**. A stream is a sequence of bytes moving along a communication path.

  • **Input Stream**: Used for **reading** data from a file (input to the program).
  • **Output Stream**: Used for **writing** data to a file (output from the program).

The `System.IO` Namespace and Classes

All core file and directory operations are managed by classes within the **System.IO** namespace.

Class Purpose
File / FileInfo Static methods (File) or instance methods (FileInfo) for manipulating files (Create, Delete, Exists).
Directory / DirectoryInfo Manipulating directory structures.
FileStream The fundamental class for byte-level reading and writing at any location within a file.
StreamReader Optimized for **reading characters/text** from a stream (e.g., ReadLine()).
StreamWriter Optimized for **writing characters/text** to a stream (e.g., WriteLine()).

The `FileStream` Class

FileStream is used for raw, byte-level I/O. Its constructor requires specific enumerators to define how the file is opened and used.

Constructor Syntax:

FileStream F = new FileStream("sample.txt", 
   FileMode.OpenOrCreate, 
   FileAccess.ReadWrite, 
   FileShare.Read);

Key Enumerators:

  • **FileMode**: Defines how to open the file (e.g., Open, Create, Append, OpenOrCreate).
  • **FileAccess**: Defines what operations are allowed (Read, Write, ReadWrite).
  • **FileShare**: Defines how the file can be shared with other running processes (e.g., None, Read, ReadWrite).

High-Level File Operations (Text I/O)

The File class provides static helper methods and works seamlessly with StreamReader and StreamWriter for simpler text-based operations. The **using** statement is crucial here as it guarantees the stream resource is properly **closed** (disposed) even if an exception occurs.

Reading a File:

using (StreamReader reader = new StreamReader("data.txt")) {
    string line;
    while ((line = reader.ReadLine()) != null) {
        // Process line
    }
}

Creating and Writing a File:

using (StreamWriter writer = File.CreateText("data.txt")) {
    writer.WriteLine("This is the first line.");
    writer.WriteLine("This is the second line.");
}

Checking and Deleting a File:

string path = "data.txt";
if (File.Exists(path)) {
    File.Delete(path);
    Console.WriteLine("File deleted.");
}

Python - Thread Deadlock

A deadlock occurs when threads wait indefinitely for resources locked by each other, causing a program to freeze. Common causes include:

  • Thread tries to acquire the same lock twice.
  • Threads waiting circularly for locks held by each other.
  • Failure to release locks or resources.
  • Threads acquiring locks in inconsistent orders.

Avoiding Deadlocks with Locks

Python's threading.Lock provides simple mutual exclusion to avoid race conditions and reduce deadlocks by ensuring exclusive access.

import threading

counter = 10
lock = threading.Lock()

def increment(theLock, N):
   global counter
   for _ in range(N):
      theLock.acquire()
      counter += 1
      theLock.release()

t1 = threading.Thread(target=increment, args=(lock, 2))
t2 = threading.Thread(target=increment, args=(lock, 10))
t3 = threading.Thread(target=increment, args=(lock, 4))

t1.start(); t2.start(); t3.start()
t1.join(); t2.join(); t3.join()

print("All threads have completed")
print("Final Counter:", counter)

Output:

All threads have completed
Final Counter: 26

Using Semaphore to Avoid Deadlocks

Semaphore limits number of threads accessing resources simultaneously, reducing deadlock risk.

import threading
import time

sem = threading.Semaphore(4)

def synchronized(name):
   sem.acquire()
   for _ in range(3):
      print("Hello! ", end='')
      print(name)
      time.sleep(1)
   sem.release()

t1 = threading.Thread(target=synchronized, args=("Thread 1",))
t2 = threading.Thread(target=synchronized, args=("Thread 2",))
t3 = threading.Thread(target=synchronized, args=("Thread 3",))

t1.start(); t2.start(); t3.start()

Output:

Hello! Thread 1
Hello! Thread 2
Hello! Thread 3
...

Common Strategies to Prevent Deadlocks

  • Acquire locks in a consistent global order.
  • Use timeouts or non-blocking lock acquisitions.
  • Minimize locks held simultaneously.
  • Employ higher-level concurrency constructs.
  • Design with deadlock detection and avoidance algorithms.
  • Test and document concurrency designs well.

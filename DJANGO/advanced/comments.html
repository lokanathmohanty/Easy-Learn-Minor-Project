Django: The Deprecated Comments Framework 💬

The built-in **Django Comments Framework** was a utility designed to easily attach comments to any model in a Django application. However, it has been **deprecated since version 1.5** and removed entirely from core Django starting with version 1.8, encouraging developers to use external solutions or create custom comment systems instead.

Setup and Configuration (Historical)

To use the legacy comments framework, several steps were required:

1. Add Apps and Site ID

The framework relies on the Sites framework to identify the domain. Both apps must be added to INSTALLED_APPS, and the SITE_ID must be configured in settings.py.

# In settings.py
INSTALLED_APPS += (
   'django.contrib.sites', 
   'django.contrib.comments',
)
SITE_ID = 1 # The ID of your site (often retrieved from the database)

2. Sync Database and URLs

The necessary database tables (e.g., to store comments) needed to be created, and the framework's URLs had to be included in the project's URL configuration.

  • Sync DB: python manage.py syncdb (or migrate in modern Django versions).
  • URLconf: 
    # In urls.py
from django.conf.urls import include
url(r'^comments/', include('django.contrib.comments.urls')),

Integrating Comments in a Template

The framework provided specific template tags to display and process comments for any given model instance (e.g., a Dreamreal object).

1. Load Tags and View Logic

First, the template tags must be loaded, and the view must pass the specific model instance (dreamreal) to the template.

# hello.html template 
{% load comments %}
# hello view
def hello(request, Name):
   dreamreal = Dreamreal.objects.get(name = Name)
   return render(request, 'hello.html', locals())

2. Displaying Comments and Form

The following template tags were used, passing the model instance as the target for the comments:

  • {% get_comment_count for object as variable_name %}: Retrieves the total number of comments for the specified object.
  • {% render_comment_list for object %}: Displays the HTML list of all existing comments for the object.
  • {% render_comment_form for object %}: Displays the default HTML form used for submitting a new comment.
# hello.html usage example
<p>Number of comments: 
   {% get_comment_count for dreamreal as comment_count %} 
   {{ comment_count }}
</p>

<p>List of comments:</p>
{% render_comment_list for dreamreal %}

{% render_comment_form for dreamreal %}

JavaScript - new Keyword

The new keyword in JavaScript is used to create an instance of the object that has a constructor function. Using the new keyword, we can create instances of user-defined as well as built-in object types. We can create instances of classes, prototypes, or constructor functions.

When a JavaScript function is called with the new keyword, it acts as a constructor. The new keyword will do the following:

  • Creates a blank/empty JavaScript object.
  • Sets its prototype for inheritance.
  • Binds this variable internally with the newly created object.
  • Executes the constructor function using the new object whenever this is used.
  • Returns the newly created object, unless the constructor function returns a non-null object reference.

The new keyword is also used to create an instance of built-in JavaScript objects like String, Boolean, Number, etc.

Syntax

new Constructor(arguments);

Parameters:

  • Constructor − The name of the constructor function or class.
  • arguments − One or more arguments to initialize the object properties.

Return Value:

  • If the constructor function returns nothing or a primitive value, it returns the newly created object.
  • If the constructor returns a non-primitive value, it returns that value.

Using 'new' keyword with Function Constructor

A function can be used as a constructor if it is called with the new keyword. The function then works as the prototype for the object.

new FuncName(arguments);

Example: Watch Constructor

function Watch(brand, price, type) {
  this.brand = brand;
  this.price = price;
  this.type = type;
}
const titan = new Watch('titen', 4000, 'analog');
const sonata = new Watch('sonata', 3000, 'digital');

Output:

  • The titan object is: {"brand":"titen","price":4000,"type":"analog"}
  • The sonata object is: {"brand":"sonata","price":3000,"type":"digital"}

Example: Laptop Constructor

function Laptop(brand, model, processor) {
  this.brand = brand;
  this.model = model;
  this.processor = processor;
  this.getLaptop = function () {
    return this.brand + ", " + this.model + ", " + this.processor;
  }
}
const HP = new Laptop('HP', "VIKING", "i7");
const Dell = new Laptop('Dell', "Inspiron", "i5");
HP.getLaptop();
Dell.getLaptop();

Output:

  • HP, VIKING, i7
  • Dell, Inspiron, i5

Using 'new' keyword with Class

After ES6, JavaScript classes can also be instantiated using the new keyword.

Example: WindowClass

class WindowClass {
  constructor(color, size, type) {
    this.color = color;
    this.size = size;
    this.type = type;
  }
  getDetails() {
    return "Color: " + this.color + 
           ", Size: " + this.size + 
           ", Type: " + this.type;
  }
}
const window1 = new WindowClass('blue', 'small', 'wooden');
window1.getDetails();

Output:

  • Color: blue
  • Size: small
  • Type: wooden

Using 'new' keyword with Built-in Objects

The new keyword can also be used to create instances of built-in objects.

Example: Number and String Objects

const num = new Number(10);
const str = new String("Hello");

typeof num; // "object"
typeof str; // "object"

Output:

  • num = 10, typeof num = object
  • str = Hello, typeof str = object

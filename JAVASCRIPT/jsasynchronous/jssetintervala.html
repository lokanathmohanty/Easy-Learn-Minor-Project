JavaScript - setInterval() Method

The setInterval() method in JavaScript is used to execute a function repeatedly at a specific interval. Unlike setTimeout(), which runs only once, setInterval() keeps executing until it is stopped using clearInterval().

Syntax

setInterval(callback, interval, arg1, arg2, ..., argN);
  • callback − Function to be executed repeatedly.
  • interval − Time interval in milliseconds between each execution.
  • arg1, arg2, ... − Optional parameters passed to the callback.

Return Value: A numeric ID which can be used with clearInterval() to stop the execution.

Example 1: Basic setInterval() Timer

<button onclick="startTimer()">Start Timer</button>
<div id="output"></div>

<script>
  let output = document.getElementById('output');
  let seconds = 0;

  function startTimer() {
    setInterval(timer, 1000); // Executes every 1 second
  }

  function timer() {
    seconds++;
    output.innerHTML += "Total seconds: " + seconds + "<br>";
  }
</script>

Example 2: Using Arrow Function

<button onclick="startTimer()">Start Timer</button>
<div id="output"></div>

<script>
  let output = document.getElementById('output');
  let seconds = 0;

  function startTimer() {
    setInterval(() => {
      seconds++;
      output.innerHTML += "Total seconds: " + seconds + "<br>";
    }, 1000);
  }
</script>

Example 3: Passing Extra Arguments

<button onclick="startTimer()">Start Date Timer</button>
<div id="output"></div>

<script>
  let output = document.getElementById('output');

  function startTimer() {
    let message = "The date and time is: ";
    setInterval(printDate, 1000, message);
  }

  function printDate(message) {
    let date = new Date();
    output.innerHTML += message + date + "<br>";
  }
</script>

Stopping Execution with clearInterval()

The clearInterval() method stops execution by taking the interval ID returned by setInterval().

<div id="output"></div>

<script>
  let output = document.getElementById('output');
  let number = 10;

  let id = setInterval(() => {
    if (number === 50) {
      clearInterval(id);
      output.innerHTML += "The timer stopped.<br>";
    }
    output.innerHTML += "Number: " + number + "<br>";
    number += 10;
  }, 1000);
</script>

Real-Life Use Cases

  • Refreshing date/time display
  • Slideshows
  • Animations
  • Live clocks
  • Updating live scores or weather
  • Running background tasks (cron-like)

Example 4: Flipping Colors

<div id="square" class="red"></div>

<script>
  setInterval(() => {
    let square = document.getElementById('square');
    if (square.classList.contains('red')) {
      square.classList.remove('red');
      square.classList.add('green');
    } else {
      square.classList.remove('green');
      square.classList.add('red');
    }
  }, 1000);
</script>

Example 5: Moving Animation

<div id="parent">
  <div id="child"></div>
</div>

<script>
  let child = document.getElementById('child');
  let left = 0;

  setInterval(() => {
    if (left < 450) {
      left += 5;
      child.style.left = left + 'px';
    }
  }, 50);
</script>

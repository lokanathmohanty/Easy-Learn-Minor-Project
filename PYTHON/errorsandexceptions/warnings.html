Warnings in Python

In Python, a warning is a message alerting that something unexpected happened while running code. Unlike errors, warnings do not stop program execution and are used to indicate potential issues or deprecated features.

Display a Warning Message

import warnings

print("TutorialsPoint")

warnings.warn("You got a warning!")

Output:

TutorialsPoint
/path/to/script.py:7: UserWarning: You got a warning!
  warnings.warn("You got a warning!")

Types of Warning Classes

  • UserWarning: Default for general warnings.
  • DeprecationWarning: Indicates deprecated features.
  • SyntaxWarning: Warns of syntax-related issues.
  • RuntimeWarning: Indicates runtime-related doubts.
  • ImportWarning: Indicates issues during module import.

Warning Filters

Control warning behavior using warnings.filterwarnings(). Common actions:

  • default - Show first occurrence per location.
  • always - Always show warning.
  • ignore - Suppress warnings.
  • error - Convert warnings to exceptions.
  • module - Show first warning per module.
  • once - Show warning only once.

Example: Turn Warning into an Error

import warnings

warnings.filterwarnings("error", category=UserWarning)

try:
    warnings.warn("This is a warning!", UserWarning)
except UserWarning as e:
    print("Caught as error:", e)

Output:

Caught as error: This is a warning!

Example: Ignore Warnings

import warnings

warnings.filterwarnings("ignore")

print("Warning message: ")
warnings.warn("This warning will be ignored!")

Output:

Warning message:

Functions Available in warnings Module

Common functions include:

  • warnings.warn(message, category): Issue a warning.
  • warnings.showwarning(): Write warning to a file.
  • warnings.warn_explicit(): More control issuing warnings.
  • warnings.filterwarnings(action, ...): Set warning filters.
  • warnings.simplefilter(action, category): Simplified filter control.
  • warnings.resetwarnings(): Reset filters to default.

Summary

Warnings in Python provide a mechanism to alert about potential issues without stopping program execution. The warnings module offers comprehensive tools to issue and control warning messages effectively.

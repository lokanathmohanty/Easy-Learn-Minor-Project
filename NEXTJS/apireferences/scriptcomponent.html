Overview

The <Script> component in Next.js is similar to the <script> tag in HTML and can be used to include external scripts in the page. In this chapter, you will learn about the <Script> component in Next.js, its props, and how to use it to include external scripts.

Script Component in Next.js

The <Script> component is used to include external JavaScript files in a Next.js page. These scripts can be from a CDN, third-party libraries, or any other external source.

Syntax

Example usage of the <Script> component:

import Script from 'next/script'

export default function Home() {
  return (
    <div>
      <h2>Hello, Next.js!</h2>
      <Script src="link/to/script.js" />
    </div>
  );
}

Props of Script Component

  • src: The URL of the external script file. Required
  • strategy: Defines the loading strategy of the script. Optional
  • onLoad: Callback when the script is successfully loaded. Optional
  • onError: Callback when the script fails to load. Optional
  • onReady: Callback when the script is ready to be executed. Optional

Using the src Prop

The src prop is required and specifies the script URL: 

import Script from 'next/script'

export default function Page() {
  return (
    <Script src="link/to/script.js" />
  );
}

Using the strategy Prop

Defines how the script is loaded. Possible values:

  • afterInteractive (default)
  • lazyOnload
  • beforeInteractive
  • worker
import Script from 'next/script'

export default function Page() {
  return (
    <Script src="link/to/script.js" strategy="lazyOnload" />
  );
}

Using the onLoad Prop

Callback triggered when the script loads successfully: 

import Script from 'next/script'

export default function Page() {
  return (
    <Script 
      src="link/to/script.js"
      onLoad={() => console.log('Script loaded successfully')} 
    />
  );
}

Using the onError Prop

Callback triggered when the script fails to load: 

import Script from 'next/script'

export default function Page() {
  return (
    <Script 
      src="link/to/script.js"
      onError={() => console.log('Script failed to load')} 
    />
  );
}

Using the onReady Prop

Callback triggered when the script is ready to run (only in client components): 

import Script from 'next/script'

export default function Page() {
  return (
    <Script 
      src="link/to/script.js"
      onReady={() => console.log('Script is ready')} 
    />
  );
}

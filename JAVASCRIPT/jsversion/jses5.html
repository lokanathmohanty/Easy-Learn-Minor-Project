JavaScript ES5 (JS 2009)

Introduction

JavaScript 2009 (ES5) refers to the fifth edition of the ECMAScript language specification, standardized in 2009. It introduced several features like strict mode, new methods, JSON support, and improved syntax for better programming practices and compatibility across browsers.

ECMAScript 5 (ES5) introduced several significant features to JavaScript, enhancing the language's capabilities.

Key Features in ES5

  • use strict — Enforces stricter parsing and error handling in JavaScript code.
  • String.trim() — Removes whitespace from the beginning and end.
  • Multiline strings — Use backslashes at the end of each line to continue.
  • Array.isArray() — Check if an object is an array.
  • Array.forEach(), Array.map(), Array.filter(), Array.reduce() — New array methods.
  • JSON.parse() / JSON.stringify() — Work with JSON data.
  • Date.now(), Date.toISOString(), Date.toJSON() — Date handling methods.
  • Getters and Setters — Control object property access and modification.
  • Object methods — New property definition and control methods.

Method 1: use strict

The use strict directive enforces strict mode in JavaScript, catching errors and promoting better coding practices. It's used at the beginning of scripts or functions. 

'use strict';
function strictFunction(a, b) {
    // Throws an error in strict mode due to undeclared variable "result"
    result = a + b;
    return result;
}

let sum = strictFunction(5, 10);
console.log("Sum:", sum);

Output: ReferenceError: result is not defined

Method 2: String.trim()

The trim() method removes whitespace from both ends of a string. 

function func() {
    let str = "GeeksforGeeks     ";
    let st = str.trim();
    console.log(st);
}
func();

Output: GeeksforGeeks

Method 3: Multiline Strings

In ES5, multiline strings can be created using backslashes at the end of each line, or concatenated with +. 

let str1 = "GeeksforGeeks \
A computer science \
Portal.";
console.log(str1);

let str2 = "Geeksfor" +
    "Geeks";
console.log(str2);

Output:

  • GeeksforGeeks A computer science Portal.
  • GeeksforGeeks

Method 4: Array Methods

Examples of Array.isArray(), map(), filter(), and reduce():

// Array.isArray()
let numbers = [1, 2, 3, 4, 5];
console.log(Array.isArray(numbers));

// Array.map()
let doubled = numbers.map(n => n * 2);
console.log(doubled);

// Array.filter()
let even = numbers.filter(n => n % 2 === 0);
console.log(even);

// Array.reduce()
let sum = numbers.reduce((acc, val) => acc + val, 0);
console.log(sum);

Output:

  • true
  • [2, 4, 6, 8, 10]
  • [2, 4]
  • 15

Method 5: JSON.parse()

let str = '{"name": "Aman", "age": 21, "city": "Noida"}';
let result = JSON.parse(str);

console.log(result.name);
console.log(result.age);
console.log(result.city);

Output:

  • Aman
  • 21
  • Noida

Method 6: JSON.stringify()

const value = {
    Company: "GeeksforGeeks",
    Estd: 2009,
    location: "Noida"
};
const result = JSON.stringify(value);
console.log(result);

Output: {"Company":"GeeksforGeeks","Estd":2009,"location":"Noida"}

Date Methods

let currentDate = new Date();

console.log(Date.now());
console.log(currentDate.toISOString());
console.log(currentDate.toJSON());

Output: Current timestamp, ISO string, and JSON date string.

Method 7: Getters and Setters

const person = {
    firstName: "John",
    lastName: "Doe",
    get fullName() {
        return `${this.firstName} ${this.lastName}`;
    },
    set fullName(name) {
        const parts = name.split(" ");
        this.firstName = parts[0];
        this.lastName = parts[1];
    }
};

console.log(person.fullName);
person.fullName = "Jane Smith";
console.log(person.firstName);
console.log(person.lastName);

Output: John Doe, Jane, Smith

Method 8: Object Property Methods

let person = {};

Object.defineProperty(person, 'name', {
    value: 'Ankit',
    writable: false,
    enumerable: true,
    configurable: false
});

Object.defineProperties(person, {
    age: { value: 21, writable: true },
    gender: { value: 'Male', writable: true }
});

console.log(Object.keys(person));
console.log(Object.getOwnPropertyNames(person));
console.log(Object.isExtensible(person));

Object.seal(person);
console.log(Object.isSealed(person));

Object.freeze(person);
console.log(Object.isFrozen(person));

Output: Demonstrates property definition, sealing, and freezing objects.

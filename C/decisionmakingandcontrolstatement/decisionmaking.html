C - Decision Making

Every programming language, including C, provides decision-making statements to support conditional logic. These constructs control the program flow based on specific conditions and help in designing complex algorithms.

A computer program can be broken into three types of logic:

  • Sequential logic
  • Decision or branching
  • Repetition or iteration

By default, a C program executes sequentially. However, decision-making statements allow us to alter this flow based on conditions. These conditions are usually evaluated as Boolean expressions — non-zero (or non-null) is considered true, and zero (or null) is false.

Common decision-making keywords and operators in C include: if, else, switch, case, default, goto, the ?: operator, and the break and continue statements.

Types of Decision Making Statements

  • if statement – Evaluates a condition and executes a block if it is true.
  • if...else statement – Executes one block if true, another if false.
  • nested if statements – if or else-if statements within another if/else-if.
  • switch statement – Tests a variable against multiple constant values.
  • nested switch statements – A switch inside another switch.

If Statement in C

Used for conditional branching. Executes a block only if the condition is true.

if (condition) {
  // statements
}

If...Else Statement in C

Provides an alternative block of code to execute if the condition is false.

if (condition) {
  // statements if true
} else {
  // statements if false
}

Nested If Statements

Allows multiple levels of decision making by placing if or else-if blocks inside one another.

Switch Statement in C

Used for selecting one of many blocks of code based on the value of a single variable.

switch(expression) {
  case constant1:
    // statements
    break;
  case constant2:
    // statements
    break;
  default:
    // default statements
}

The Ternary (?:) Operator

The conditional operator provides a shorthand way to write simple if...else logic.

condition ? expression_if_true : expression_if_false;

This can also be nested to simulate multiple conditions.

C# Nullable Types and Null Coalescing Operator (`??`)

C# Nullable Types

In C#, **value types** (like int, double, bool, struct) normally **cannot** be assigned a value of null. **Nullable types** overcome this limitation, allowing value type variables to store their normal range of values **plus** the null value.

Nullable types are instances of the generic type System.Nullable<T>, but they are most often declared using a shorthand syntax.

Declaration Syntax:

You declare a nullable type by appending the **question mark (`?`)** symbol after the data type:

<data_type>? <variable_name> = null;

// Example:
int? num1 = null; 
double? num4 = 3.14157;
bool? boolval = new bool?(); // Long-form equivalent

Example: Using Nullable Types

The output shows that when a nullable type holds null, it displays as an empty string in the console.

using System;
class NullablesAtShow {
    static void Main(string[] args) {
        int? num1 = null;
        int? num2 = 45;
        double? num3 = new double?(); // Holds null
        double? num4 = 3.14157;
         
        Console.WriteLine("Values: {0}, {1}, {2}, {3}", num1, num2, num3, num4);
    }
}

Output:

Values: , 45, , 3.14157

C# Null Coalescing Operator (`??`)

The **Null Coalescing Operator (`??`)** is a binary operator that provides a concise way to handle nullable types and reference types that might be null.

  • It checks if the left-hand operand is null.
  • If the left operand is **NOT `null`**, it returns the value of the left operand.
  • If the left operand **IS `null`**, it returns the value of the right operand (the default value).

Syntax:

<result_variable> = <nullable_value> ?? <default_value>;

Example: Using Null Coalescing Operator

This demonstrates how the `??` operator selects the left value if available, or the right default value if the left is null.

using System;
class NullablesAtShow {
    static void Main(string[] args) {
        double? num1 = null;
        double? num2 = 3.14157;
        double num3;
         
        // Case 1: num1 is null, so 5.34 is assigned to num3
        num3 = num1 ?? 5.34;      
        Console.WriteLine("Value of num3 (Case 1): {0}", num3);
         
        // Case 2: num2 is NOT null, so 3.14157 is assigned to num3
        num3 = num2 ?? 5.34;
        Console.WriteLine("Value of num3 (Case 2): {0}", num3);
    }
}

Output:

Value of num3 (Case 1): 5.34
Value of num3 (Case 2): 3.14157

ReactJS - Routing

Introduction

In web applications, routing is the process of binding a web URL to a specific resource. In React, it means binding a URL to a component. React does not support routing natively, but the React community provides third-party libraries to handle routing. The most popular library is React Router.

Install React Router

To install React Router in the Expense Manager application, run the following:

cd /go/to/expense/manager
npm install react-router-dom --save

React Router Components

  • Router – Top-level component enclosing the entire app.
  • Link – Similar to an HTML anchor tag, used for navigation.
  • Route – Maps the target URL to a component.

Link Example

<Link to="/">Home</Link>

Nested Routing

React Router supports nested routing. Let us create components Home, About, and Contact and set up navigation.

Home.jsx

function Home() {
  return (
    <div className="Home">
      <h1>This is Home</h1>
    </div>
  );
}
export default Home;

About.jsx

function About() {
  return (
    <div className="About">
      <h1>About Us</h1>
      <p>TutorialsPoint India</p>
    </div>
  );
}
export default About;

Contact.jsx

function Contact() {
  return (
    <div className="Contact">
      <h1>Contact Us</h1>
      <p>Tutorials Point India Pvt Ltd, Hyderabad, India</p>
    </div>
  );
}
export default Contact;

Creating Navigation

To enable navigation between screens, create a Navigate component that links to Home, About, and Contact.

Navigate.jsx

import { Outlet, Link } from "react-router-dom";

function Navigate() {
  return (
    <div>
      <ul>
        <li><Link to="/">Home</Link></li>
        <li><Link to="/about">About Us</Link></li>
        <li><Link to="/contact">Contact Us</Link></li>
      </ul>
      <Outlet />
    </div>
  );
}
export default Navigate;

Configuring Routes

In App.jsx, configure BrowserRouter, Routes, and Route to handle navigation.

App.jsx

import { Route, Routes, BrowserRouter } from "react-router-dom";
import Home from "./Router/Home";
import About from "./Router/About";
import Contact from "./Router/Contact";
import Navigate from "./Router/Navigate";

function App() {
  return (
    <div className="App">
      <BrowserRouter>
        <Routes>
          <Route path="/" element={<Navigate />}>
            <Route index element={<Home />} />
            <Route path="about" element={<About />} />
            <Route path="contact" element={<Contact />} />
          </Route>
        </Routes>
      </BrowserRouter>
    </div>
  );
}
export default App;

Running the Application

npm start

Open http://localhost:3000 in the browser. Use the navigation links to switch between pages and confirm routing is working.

Advantages of React Router

  • Fast navigation between components with minimal re-rendering.
  • Easy to implement animations and transitions between routes.
  • Supports single-page applications without full page reloads.

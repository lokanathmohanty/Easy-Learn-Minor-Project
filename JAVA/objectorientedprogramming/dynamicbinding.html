Java Programming: Binding Mechanisms

Session: Dynamic Binding (Run-Time Polymorphism)

What is Dynamic Binding?

**Binding** is the mechanism that links a **method call** to its actual **method implementation**. **Dynamic Binding** (also known as **Run-Time Polymorphism** or **Late Binding**) is the process where this linking is resolved during the program's execution (at runtime), not at compile time.

Dynamic binding is a key concept that enables **Method Overriding** to work correctly in Java.

Characteristics of Dynamic Binding

  • **Linking Time:** Resolution occurs at **Run Time**.
  • **Resolution Mechanism:** It uses the actual **object type** (instance on the heap), not the reference variable type, to determine which method to call.
  • **Example:** **Method Overriding** is the primary example.
  • **Methods Involved:** Overridden methods are effectively **virtual methods** that utilize dynamic binding.

Example: Dynamic Binding in Action

When the `move()` method is called on the reference `b`, the Java Virtual Machine (JVM) checks the actual object type (`Dog`), not the reference type (`Animal`), leading to the execution of the overridden method.

class Animal {
   public void move() { ... } // Parent method
}

class Dog extends Animal {
   public void move() { ... } // Overridden child method
}

public class Tester {
   public static void main(String args[]) {
      // Animal reference points to a Dog object (Dynamic Binding)
      Animal b = new Dog();
      
      // At compile time: Check is made on Animal type.
      // At run time: JVM invokes the Dog's move() method.
      b.move(); 
   }
}

Output shows the runtime decision:

Dogs can walk and run

Combining Dynamic Binding with super

The **super** keyword allows the overridden method in the subclass to execute the original implementation in the superclass, even while the method call itself is resolved dynamically.

class Dog extends Animal {
   public void move() {
      super.move();   // Invokes the super class method explicitly
      System.out.println("Dogs can walk and run");
   }
}

// Calling b.move() still uses dynamic binding to find Dog.move(), 
// but Dog.move() then calls Animal.move() internally.

Combined Output:

Animals can move
Dogs can walk and run

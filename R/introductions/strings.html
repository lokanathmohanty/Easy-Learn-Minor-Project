R - Strings

Any value written within a pair of single or double quotes in R is treated as a string. Internally, R stores every string within double quotes, even if it was created with single quotes.

Rules for String Construction

  • The opening and closing quotes must match — both single or both double.
  • Double quotes can be included inside strings created with single quotes, and vice versa.
  • Mixing different quote types for opening and closing is not allowed.
  • Double quotes within double quotes or single quotes within single quotes are not allowed without escaping.

Examples of Valid Strings

a <- 'Start and end with single quote'
print(a)
b <- "Start and end with double quotes"
print(b)
c <- "single quote ' in between double quotes"
print(c)
d <- 'Double quotes " in between single quote'
print(d)

Output:

[1] "Start and end with single quote"
[1] "Start and end with double quotes"
[1] "single quote ' in between double quote"
[1] "Double quote \" in between single quote"

Examples of Invalid Strings

e <- 'Mixed quotes"
print(e)
f <- 'Single quote ' inside single quote'
print(f)
g <- "Double quotes " inside double quotes"
print(g)

These produce errors due to invalid quote usage.

String Manipulation

Concatenating Strings: paste() Function

a <- "Hello"
b <- 'How'
c <- "are you? "
print(paste(a, b, c))
print(paste(a, b, c, sep = "-"))
print(paste(a, b, c, sep = "", collapse = ""))

Output:

[1] "Hello How are you? "
[1] "Hello-How-are you? "
[1] "HelloHoware you? "

Formatting Numbers & Strings: format() Function

# Display total digits; round last digit
result <- format(23.123456789, digits = 9)
print(result)
# Numbers in scientific notation
result <- format(c(6, 13.14521), scientific = TRUE)
print(result)
# Set minimum number of digits after decimal
result <- format(23.47, nsmall = 5)
print(result)
# Format treats everything as string
result <- format(6)
print(result)
# Pad with blanks for width
result <- format(13.7, width = 6)
print(result)
# Left justify
result <- format("Hello", width = 8, justify = "l")
print(result)
# Center justify
result <- format("Hello", width = 8, justify = "c")
print(result)

Output:

[1] "23.1234568"
[1] "6.000000e+00" "1.314521e+01"
[1] "23.47000"
[1] "6"
[1] "  13.7"
[1] "Hello   "
[1] " Hello  "

Counting Characters: nchar() Function

result <- nchar("Count the number of characters")
print(result)

Output:

[1] 30

Changing Case: toupper() & tolower()

# To upper
result <- toupper("Changing To Upper")
print(result)
# To lower
result <- tolower("Changing To Lower")
print(result)

Output:

[1] "CHANGING TO UPPER"
[1] "changing to lower"

Extract Parts of a String: substring() Function

# Extract characters 5 to 7
result <- substring("Extract", 5, 7)
print(result)

Output:

[1] "act"

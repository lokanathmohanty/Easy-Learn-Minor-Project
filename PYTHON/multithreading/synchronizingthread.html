Python - Synchronizing Threads

In Python, synchronizing threads is essential when multiple threads access shared resources to ensure data consistency and prevent race conditions. The threading module provides synchronization primitives such as locks, conditions, semaphores, and barriers.

Thread Synchronization Using Locks

Locks allow one thread at a time to execute critical sections by acquiring and releasing exclusive access.

import threading

counter = 10

def increment(theLock, N):
   global counter
   for _ in range(N):
      theLock.acquire()
      counter += 1
      theLock.release()

lock = threading.Lock()
t1 = threading.Thread(target=increment, args=(lock, 2))
t2 = threading.Thread(target=increment, args=(lock, 10))
t3 = threading.Thread(target=increment, args=(lock, 4))

t1.start()
t2.start()
t3.start()

for t in (t1, t2, t3):
   t.join()

print("All threads have completed")
print("The Final Counter Value:", counter)

Output:
All threads have completed
The Final Counter Value: 26

Condition Objects for Synchronization

Condition variables enable threads to wait for certain conditions to be met and coordinate execution using wait() and notify() methods.

import threading

counter = 0
cv = threading.Condition()

def consumer(cv):
   global counter
   with cv:
      print("Consumer is waiting")
      cv.wait()
      print("Consumer notified. Counter value:", counter)

def increment(cv, N):
   global counter
   with cv:
      print("Increment producing items")
      for i in range(1, N+1):
         counter += i
      cv.notify()
      print("Increment finished")

consumer_thread = threading.Thread(target=consumer, args=(cv,))
increment_thread = threading.Thread(target=increment, args=(cv, 5))

consumer_thread.start()
increment_thread.start()

consumer_thread.join()
increment_thread.join()

print("Final Counter Value:", counter)

Output:
Consumer is waiting
Increment producing items
Increment finished
Consumer notified. Counter value: 15
Final Counter Value: 15

Synchronizing with Join

The join() method makes the calling thread wait for another thread to finish.

import threading
import time

class MyThread(threading.Thread):
   def __init__(self, t_id, name, count):
      super().__init__()
      self.t_id = t_id
      self.name = name
      self.count = count

   def run(self):
      print(f"Starting {self.name}")
      internal_count = self.count
      while internal_count > 0:
         time.sleep(3)
         print(f"{self.name}: {time.ctime()}")
         internal_count -= 1
      print(f"Exiting {self.name}")

t1 = MyThread(1, "Thread-1", 3)
t2 = MyThread(2, "Thread-2", 3)

t1.start()
t2.start()

t1.join()
t2.join()

print("Exiting Main Thread")

Output:
Starting Thread-1
Starting Thread-2
Thread-1: Thu Sep 20 10:20:05 2024
Thread-2: Thu Sep 20 10:20:05 2024
...
Exiting Main Thread

Other Synchronization Primitives

  • RLocks: Reentrant locks allowing the same thread to acquire multiple times.
  • Semaphores: Limit simultaneous access to resources by maintaining a counter.
  • Barriers: Block threads until a set number have reached a synchronization point.

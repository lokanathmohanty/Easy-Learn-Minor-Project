ReactJS - State Management API

As we learned earlier, a React component maintains and exposes its state through the this.state object. React provides a single API to maintain and update state in a component: this.setState(). It accepts either a JavaScript object or a function that returns a JavaScript object.

setState() schedules an update to the component’s state object. When the state changes, the component automatically re-renders to reflect the update.

Syntax

The signature of the setState API is as follows:

this.setState({ ...object... });

Example – updating the name property:

this.setState({ name: 'John' });

setState() with Function

The function form of setState has the following signature:

this.setState((state, props) => ... function returning JavaScript object ... );

  • state refers to the current state of the component.
  • props refers to the current properties of the component.

React recommends using the function form of setState because it works reliably in asynchronous environments. Instead of an arrow function, a regular function can also be used:

this.setState(function(state, props) {
  return ... JavaScript object ...
});

Example – updating amount using a function:

this.setState((state, props) => ({
  amount: state.amount + props.additionalAmount
}));

Important: React state should not be modified directly using this.state. Updating state directly does not trigger a re-render. Always use setState.

Special Feature of React State API

A key feature of setState is that it performs a shallow merge with the existing state instead of replacing it entirely. This means you can update only one field at a time while preserving the others.

For example, consider the following initial state:

{ name: 'John', age: 16 }

You can update only the age field:

this.setState((state, props) => ({
  age: 18
}));

This automatically merges with the existing state, so the name property remains unchanged.

Java - Thread Pools

Thread Pools

A thread pool is a collection of pre-initialized threads that can be reused to execute multiple tasks. Threads in the pool wait for tasks and are reused, reducing the overhead of thread creation.

Why Use Thread Pools in Java?

  • Improves performance by reusing existing threads.
  • Used in web technologies like Servlets and JSP to handle requests efficiently.

Creating Thread Pools in Java

Java provides the java.util.concurrent.Executors class with several static methods to create thread pools:

  • newCachedThreadPool() – Creates a pool that grows as needed and reuses idle threads.
  • newFixedThreadPool(int n) – Creates a pool with a fixed number of threads.
  • newScheduledThreadPool(int corePoolSize) – Supports delayed and periodic task execution.
  • newWorkStealingPool() – Uses all available processors for parallelism.

Example: Creating a Thread Pool Using newFixedThreadPool()

This example demonstrates how to use Executors.newFixedThreadPool() to create a thread pool with two threads and submit tasks to it.


ExecutorService executor = Executors.newFixedThreadPool(2);
executor.submit(new Task());
executor.submit(new Task());
executor.shutdown();

The thread pool reuses the two created threads to execute the submitted tasks.

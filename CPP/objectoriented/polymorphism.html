Polymorphism in C++ (Many Forms) 🦄

The word **polymorphism** means "having many forms." In C++, polymorphism allows a function call to execute a different function based on the **type of object** that invokes it at **runtime**. It relies on an inheritance hierarchy and is key to flexible, extendable code design.

Static vs. Dynamic Polymorphism

Static Resolution (Early Binding)

Without special keywords, C++ uses **static resolution** (early binding). When a base class pointer points to a derived class object and calls a method, the compiler only looks at the **pointer's type (Base Class)**, not the object's actual type. This results in the base class version of the function being called, even if the derived class overrides it (as shown in the first example's incorrect output).

Dynamic Resolution (Late Binding) with Virtual Functions

To achieve true, or **dynamic**, polymorphism, you must use **Virtual Functions**.

Virtual Functions (Dynamic Polymorphism)

A **virtual function** is a member function in a base class that is declared using the keyword **virtual**. This signals to the compiler that it should use **dynamic linkage** (late binding) for this function.

  • The function to be executed is selected based on the **actual type of the object** being pointed to, not the type of the pointer itself.
  • This is why adding `virtual` to `Shape::area()` correctly calls the respective `Rectangle::area()` and `Triangle::area()` methods when accessed via the `Shape*` pointer.
class Shape {
   public:
      // Enables dynamic polymorphism
      virtual int area() { /* ... */ } 
};

Pure Virtual Functions (Abstract Classes)

A **pure virtual function** is a virtual function in the base class that is declared with **= 0**.

  • It tells the compiler that the function has **no body** (no meaningful implementation) in the base class.
  • A class containing one or more pure virtual functions is called an **abstract class**. You **cannot** create direct instances (objects) of an abstract class; you must derive from it and provide implementations for all pure virtual functions.
class Shape {
   public:
      // Pure virtual function: forces derived classes to define area()
      virtual int area() = 0;
};

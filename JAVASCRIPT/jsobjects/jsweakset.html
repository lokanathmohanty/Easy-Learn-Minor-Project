JavaScript - The WeakSet Object

The JavaScript WeakSet object is a collection of objects. It is similar to the Set object, but with key differences:

  • WeakSet contains only objects, while Set can contain any data type.
  • Objects in a WeakSet are held weakly, meaning they can be garbage collected if no other references exist.

WeakSets are useful for keeping track of objects without preventing them from being garbage collected, such as DOM nodes.

Syntax

To define a WeakSet:

const weakSet = new WeakSet([iterable]);

Parameters:

  • iterable − Optional. An iterable object whose elements are added to the WeakSet.

WeakSet Properties

  • constructor − Returns the WeakSet constructor function.

WeakSet Methods

  • add() − Insert an object into the WeakSet.
  • delete() − Delete a single object from the WeakSet.
  • has() − Check whether a particular object exists in the WeakSet.

Examples

Example: Similar Objects with WeakSet


const obj1 = {};
const obj2 = {};
const weak_set = new WeakSet([obj1, obj2]);

console.log(weak_set.has(obj1)); // true
console.log(weak_set.has(obj2)); // true

Output:

  • The weak_set contains the obj1 object!
  • The weak_set contains the obj2 object!

Example: Add Object in WeakSet


const weak_set = new WeakSet();
const car = { brand: "Audi", model: "Q5" };
weak_set.add(car);

console.log(weak_set.has(car)); // true

Output: The car object is added successfully to the weak_set.

Example: Delete Object from WeakSet


const car = { brand: "Audi", model: "Q5" };
const carWeakSet = new WeakSet([car]);
const flag = carWeakSet.delete(car);

console.log(flag); // true

Output: The car object is deleted successfully from the carWeakSet? true

Note: WeakSet is not iterable, so you cannot traverse through its elements.

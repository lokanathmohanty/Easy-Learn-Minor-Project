Python Array Methods

The Python array module provides an efficient way to represent homogeneous sequences like arrays of integers, floats, or characters. The array class supports various methods for adding, removing, manipulating, and converting array elements.

Creating Arrays

Arrays are created using array.array(typecode[, initializer]), where typecode specifies element type and initializer is an optional list of elements.

Adding and Removing Elements

MethodDescription
append(x)Appends item x to end of array.
extend(iterable)Appends items from iterable to end of array.
insert(i, x)Inserts item x before position i.
pop([i])Removes and returns item at index i. If i not specified, removes last item.
remove(x)Removes first occurrence of x.

Information and Utility Methods

MethodDescription
buffer_info()Returns tuple (address, length) showing memory address and number of elements.
count(x)Returns number of times x appears in array.
index(x[, start[, stop]])Returns smallest index of x, optionally within start and stop range.

Manipulating Elements

MethodDescription
reverse()Reverses order of items.
byteswap()Swaps bytes of all items (useful for endian data translation).

Conversion Methods

MethodDescription
frombytes()Appends items from bytes-like object.
tobytes()Converts array to bytes representation.
fromfile()Reads items from a file into array.
tofile()Writes items of array to a file.
fromlist()Appends items from list.
tolist()Converts array to list.
fromunicode()Appends from Unicode string (only for typecode 'u').
tounicode()Converts array to Unicode string (only for typecode 'u').

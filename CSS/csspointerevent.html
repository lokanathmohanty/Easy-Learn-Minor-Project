CSS - pointer-events Property

The pointer-events property in CSS is used to control how an element responds to pointer interactions such as mouse clicks, hover effects, and touch gestures. This property is especially useful when working with overlapping elements, SVG graphics, or when you want certain elements to ignore user interactions.

Possible Values

  • auto: Default. The element behaves normally and responds to pointer events.
  • none: The element does not respond to pointer events, allowing clicks and hovers to pass through it to underlying elements.
  • visiblePainted: Only visible painted parts of the element respond to pointer events.
  • visibleFill: Only the visible fill area of the element responds to pointer events.
  • visibleStroke: Only the visible stroke area of the element responds to pointer events.
  • visible: The element responds only if its visibility is set to visible.
  • painted: The element responds only to events on painted areas.
  • fill: The element responds only to events on its fill.
  • stroke: The element responds only to events on its stroke.
  • all: The element responds to pointer events on both fill and stroke regardless of visibility.

Syntax

pointer-events: auto | none | visiblePainted | visibleFill | 
                visibleStroke | visible | painted | fill | 
                stroke | all;

Key Notes

  • If not specified, SVG elements behave as if pointer-events: visiblePainted is applied.
  • Disabling pointer events on a parent does not automatically disable them for its children.
  • Elements with pointer-events: none can still be focused using keyboard navigation.

Content Summary

The pointer-events property controls how elements react to user interactions such as clicks, hovers, and touches. It can be used to disable interactions (none), allow interactions only on visible areas (visiblePainted, fill, stroke), or enforce full interactivity (all, auto). This property is crucial when managing layered content and SVG graphics.

Example: pointer-events with none

a[href="https://example.com"] {
   pointer-events: none;
}

<a href="https://example.com">This link cannot be clicked</a>

Example: pointer-events with auto

a[href="https://example.com"] {
   pointer-events: auto;
}

<a href="https://example.com">This link is clickable</a>

Example: pointer-events on Images

img {
   pointer-events: none;
   width: 150px;
   height: 150px;
}

<img src="flower.jpg" alt="Flower Image">

Managed Extensibility Framework (MEF)

The Managed Extensibility Framework (MEF) is a library for creating lightweight, extensible applications. It allows developers to discover and use extensions with minimal configuration, enabling a **loosely-coupled plugin-like architecture**.

  • MEF is an integral part of the **.NET Framework 4** and enhances the flexibility, maintainability, and testability of large applications (client or server).
  • For .NET Core, MEF has been partially ported as **Microsoft.Composition**. Only **System.Composition** is available; the older **System.ComponentModel.Composition** (which included assembly catalogs) is not yet available.

Setting up MEF in .NET Core (project.json)

The following steps outline how to set up the necessary components to use MEF in a .NET Core console application:

  1. **Create Project:** Create a new **Console Application (.NET Core)** project.
  2. **Add NuGet Package:** Right-click the project, select **Manage NuGet Packages**, search for **Microsoft.Composition**, and click **Install**.
  3. **Update project.json:** The default framework import setting in the project.json file ("imports": "dnxcore50") is not compatible with the Microsoft.Composition package. You must replace it with a compatible Portable Class Library profile.

project.json (Corrected Imports)

{ 
   "version": "1.0.0-*", 
   "buildOptions": { 
      "emitEntryPoint": true 
   }, 
   "dependencies": { 
      "Microsoft.Composition": "1.0.30", 
      "Microsoft.NETCore.App": { 
         "type": "platform", 
         "version": "1.0.1"
      } 
   }, 
   "frameworks": { 
      "netcoreapp1.0": { 
         "imports": "portable-net45+win8+wp8+wpa81" 
      } 
   } 
}

Saving this file resolves the package compatibility error, and the **Microsoft.Composition** reference will correctly appear in your project.

Creating the Export and Import Parts

MEF works by defining an **interface** to be exported, and a **class** that implements that interface and is decorated with the [Export] attribute. A separate consumer class uses the [Import] attribute to receive an instance of the exported type.

1. Defining the Exported Interface and Class (PrintData.cs)

Create a class file, e.g., **PrintData.cs**, which defines the contract IPrintData and provides an implementation PrintData marked for export.

PrintData.cs (Exported Component)

using System; 
using System.Composition; 
  
namespace MEFDemo { 
   public interface IPrintData { 
      void Send(string message); 
   } 
   
   [Export(typeof(IPrintData))] 
   public class PrintData : IPrintData { 
      public void Send(string message) { 
         Console.WriteLine(message); 
      } 
   } 
}

2. Importing and Composing (Program.cs)

The main class, **Program.cs**, performs the composition. Because the Catalogs for loading types from directories are unavailable in this version of MEF for .NET Core, we manually load types from the current assembly and compose the container.

  • The PrintData property is decorated with [Import] to signal that it should receive an exported instance of IPrintData.
  • The Compose() method uses ContainerConfiguration to discover types with the [Export] attribute in the current assembly and resolve the imported parts.

Program.cs (Importing and Composition)

using System; 
using System.Composition; 
using System.Composition.Hosting; 
using System.Reflection; 
  
namespace MEFDemo { 
   public class Program { 
      public static void Main(string[] args) { 
         Program p = new Program(); 
         p.Run(); 
      } 
      
      public void Run() { 
         Compose(); 
         PrintData.Send("Hello,this is MEF demo"); 
      } 
      
      [Import] 
      public IPrintData PrintData { get; set; } 
      
      private void Compose() { 
         var assemblies = new[] { typeof(Program).GetTypeInfo().Assembly }; 
         var configuration = new ContainerConfiguration() 
            .WithAssembly(typeof(Program).GetTypeInfo().Assembly); 
         
         using (var container = configuration.CreateContainer()) { 
            PrintData = container.GetExport<IPrintData>(); 
         } 
      } 
   } 
}

Running the application will execute the Run() method, which calls Compose() to instantiate the PrintData class and assign it to the imported property, resulting in the output "Hello,this is MEF demo".

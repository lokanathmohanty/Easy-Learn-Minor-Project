JavaScript - DOM Animation

Introduction

DOM animation can be achieved by changing an element's style using JavaScript. When changes are made gradually with a small time interval, the animation appears continuous. There are three main ways to animate DOM elements:

  • Using CSS transitions – triggered by changes in element properties.
  • Using CSS animations – allows keyframes and more control over timing.
  • Using JavaScript – provides the most flexibility for complex animations.

Animating with setInterval()

You can use the setInterval() method to update the style of a DOM element at regular intervals. This creates the effect of animation.

Syntax


let id = setInterval(frame_func, timeframe);
function frame_func() {
    if (animation_end) {
        clearInterval(id);
    } else {
        // change style to animate
    }
}

Example: Moving a Div


<div id="parent">
  <div id="child"></div>
</div>
<button onclick="startAnimation()">Animate Div</button>

<script>
function startAnimation() {
  const elem = document.getElementById("child");
  let pos = 0;
  let id = setInterval(animationFrame, 5);
  function animationFrame() {
    if (pos == 350) {
      clearInterval(id);
    } else {
      pos++;
      elem.style.left = pos + "px";
    }
  }
}
</script>

Example: Fading a Div


<div id="parent"></div>
<button onclick="startAnimation()">Animate Div</button>

<script>
function startAnimation() {
  const parent = document.getElementById("parent");
  let opacity = 1;
  let id = setInterval(animationFrame, 50);
  function animationFrame() {
    if (opacity <= 0) {
      clearInterval(id);
      parent.style.opacity = 1;
      parent.style.backgroundColor = "red";
    } else {
      parent.style.opacity = opacity;
      opacity = opacity - 0.1;
    }
  }
}
</script>

Animating with requestAnimationFrame()

The requestAnimationFrame() method provides smoother animations compared to setInterval() by syncing with the browser’s repaint cycle.

Syntax


function animate() {
    // animation logic
    requestAnimationFrame(animate);
}
animate();

Example: Moving a Div


<div id="parent">
  <div id="child"></div>
</div>
<button onclick="startAnimation()">Animate Div</button>
<button onclick="stopAnimation()">Stop Animation</button>

<script>
let animationId;
let pos = 0;
function startAnimation() {
  const elem = document.getElementById("child");
  function animationFrame() {
    if (pos < 650) {
      pos++;
      elem.style.left = pos + "px";
      animationId = requestAnimationFrame(animationFrame);
    }
  }
  animationFrame();
}
function stopAnimation() {
  if (animationId) {
    cancelAnimationFrame(animationId);
    animationId = null;
  }
}
</script>

Animating by Changing CSS Properties

JavaScript can dynamically update the CSS animation property to apply predefined keyframe animations.

Syntax


element.style.animation = "key_frame_name duration timing_function iterationCount";

Example: Using Keyframes


<div id="element">Animate</div>
<button onclick="animateDiv()">Animate Div</button>

<style>
@keyframes moveAnimation {
  from { transform: translateX(0); }
  to { transform: translateX(550px); }
}
</style>

<script>
function animateDiv() {
  const element = document.getElementById("element");
  element.style.animation = "moveAnimation 3s ease-in-out infinite";
}
</script>

Conclusion

While CSS transitions and animations are simple to use, JavaScript offers more flexibility. Among JavaScript methods, requestAnimationFrame() is generally the best choice for smooth, efficient animations.

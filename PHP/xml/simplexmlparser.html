PHP - SimpleXML Parser

Introduction to SimpleXML

The **SimpleXML** extension provides PHP with an extremely easy-to-use **tree-based parser** for processing XML data. It converts a well-formed XML document into a **$\text{SimpleXMLElement}$ object** where elements can be accessed using standard **object properties** and iterated over like **arrays**.

It is best suited for **simple, smaller XML files**. For large or highly complex XML documents, event-based parsers ($\text{XMLReader}$) or the $\text{DOMDocument}$ class are usually preferred due to performance and memory constraints.

Core SimpleXML Functions

1. $\text{simplexml\_load\_file()}$

This function parses an **XML file** from the filesystem and converts its structure into a $\text{SimpleXMLElement}$ object.

<?php
   $xml = simplexml_load_file("test.xml") or die("Error: Cannot create object");
   // The root node <note> is now the $xml object.
   // Child elements (Course, Subject, etc.) are its properties.
   print_r($xml); 
?>

The output is a $\text{SimpleXMLElement}$ object where XML tags become properties:

SimpleXMLElement Object
(
   [Course] => Android
   [Subject] => Android
   [Company] => TutorialsPoint
   [Price] => $10
)

2. $\text{simplexml\_load\_string()}$

Similar to $\text{simplexml\_load\_file()}$, but it parses a **string** containing the $\text{XML}$ data instead of a file.

3. $\text{simplexml\_import\_dom()}$

This function acts as a bridge, converting a $\text{DOMNode}$ object (created using the more complex $\text{DOMDocument}$ class) into a **SimpleXMLElement** object. This is useful when complex manipulation is done with $\text{DOMDocument}$, but simple reading/access is preferred afterward.

<?php
   $dom = new DOMDocument;
   $dom->loadXML('<books><book><title>PHP Handbook</title></book></books>');

   $s = simplexml_import_dom($dom);
   // Accessing the element via array and property access
   echo $s->book[0]->title; 
   // Output: PHP Handbook
?>

Accessing XML Node Values and Iteration

Once an $\text{XML}$ document is loaded into a $\text{SimpleXMLElement}$ object, traversing the tree and accessing data is straightforward using **$\text{foreach}$ loops** and **property access** ($\text{->}$).

Example: Iterating over $\text{}$ Elements

If the root element is $\text{}$, its direct children are $\text{}$ elements. The $\text{children()}$ method or simple object iteration allows traversing these elements.

<?php
   $xml = simplexml_load_file("books.xml") or die("Error: Cannot create object");

   // Iterate through all direct children of the root (all <course> nodes)
   foreach($xml->children() as $books) { 
      // Access child elements (title, tutor, etc.) as properties of the $books object
      echo $books->title . "<br> "; 
      echo $books->tutor . "<br> "; 
      echo $books->price . "<hr>"; 
   }
?>

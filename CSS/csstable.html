CSS - Styling Tables

Styling tables in a webpage involves using CSS properties to customize their appearance. Properties such as border-collapse, border-spacing, and caption-side help control the look of table borders, spacing, and captions.

This session discusses how to apply different CSS properties to HTML tables for better design and readability.

CSS Table Border Styling

You can style table borders using the border and border-radius properties.

  • border: Defines the width, style, and color of the border.
  • border-radius: Rounds the corners of the border. Example: border-radius: 10px;.

Example:

<table>
  <tr>
    <th>Header 1</th>
    <th>Header 2</th>
  </tr>
  <tr>
    <td>Data 1</td>
    <td>Data 2</td>
  </tr>
</table>

CSS Table Border Collapse

The border-collapse property defines whether borders are separated or merged.

  • collapse: Merges borders into a single border.
  • separate: Keeps borders distinct (default).

Example:

<table style="border-collapse: collapse;">
  <tr><td>Data</td></tr>
</table>

CSS Table Border Spacing

The border-spacing property defines the distance between adjacent cell borders.

  • border-spacing: 10px; → Applies spacing both horizontally and vertically.
  • border-spacing: 20px 5px; → Horizontal spacing 20px, vertical spacing 5px.

Example:

<table style="border-collapse: separate; border-spacing: 15px 5px;">
  <tr><td>Cell</td></tr>
</table>

CSS Tables Caption Side

The caption-side property controls the placement of the table caption.

  • caption-side: top; → Places caption above the table.
  • caption-side: bottom; → Places caption below the table.

Example:

<table>
  <caption>Table Caption</caption>
  <tr><td>Data</td></tr>
</table>

CSS Tables Empty Cells

The empty-cells property controls how empty cells are displayed.

  • show → Displays empty cells (default).
  • hide → Hides empty cells and removes their borders.

Example:

<table style="empty-cells: hide;">
  <tr><td>Data</td><td></td></tr>
</table>

CSS Table Layout

The table-layout property defines how the table calculates column widths.

  • auto → Adjusts column width based on content (default).
  • fixed → Uses fixed widths, faster rendering.

Example:

<table style="table-layout: fixed; width:100%;">
  <tr><td>Content</td></tr>
</table>

CSS Table Content Alignment

Use text-align and vertical-align to align text in cells.

  • text-align: center; → Centers text horizontally.
  • vertical-align: top; → Aligns text at the top of the cell.

Example:

<td style="text-align: center; vertical-align: top;">Aligned</td>

CSS Tables Background Color

The background-color property is used to style table cells, rows, or the entire table.

Example:

<tr style="background-color: lightgrey;">
  <td>Shaded Cell</td>
</tr>

CSS Table Text Font Styles

Font styles like font-size, font-family, and font-weight can be applied to th and td.

Example:

<th style="font-family: Arial; font-size: 18px;">Heading</th>

CSS Table Dividers

Dividers help separate rows and columns for readability. You can use border-right for vertical dividers and border-bottom for horizontal dividers.

Example:

<td style="border-right: 2px solid black;">Cell</td>

CSS Striped Table

Striped tables use alternating row colors with the :nth-child selector for readability.

Example:

tr:nth-child(odd) { background-color: #f2f2f2; }
tr:nth-child(even) { background-color: white; }

CSS Responsive Table

Responsive tables adapt to small screens using overflow-x: auto; to enable horizontal scrolling when needed.

Example:

<div style="overflow-x: auto;">
  <table>
    <tr><td>Data</td></tr>
  </table>
</div>

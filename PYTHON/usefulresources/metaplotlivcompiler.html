Understanding Python Compilation

Code Input

def factorial(n):
    if n == 0:
        return 1
    else:
        return n * factorial(n - 1)

AST (Abstract Syntax Tree)

Module(
  body=[
    FunctionDef(
      name='factorial',
      args=arguments(posonlyargs=[], args=[arg(arg='n')], kwonlyargs=[], kw_defaults=[], defaults=[]),
      body=[
        If(
          test=Compare(Name('n', Load()), [Constant(0)], []),
          body=[Return(Constant(1))],
          orelse=[Return(BinOp(Name('n', Load()), Mult(), Call(Name('factorial', Load()), [BinOp(Name('n', Load()), Sub(), Constant(1))], [])))]
        )
      ],
      decorator_list=[]
    )
  ]
)

Bytecode Output

  0 LOAD_FAST                0 (n)
  2 LOAD_CONST               1 (0)
  4 COMPARE_OP               2 (==)
  6 POP_JUMP_IF_FALSE        14
  8 LOAD_CONST               2 (1)
 10 RETURN_VALUE
 12 LOAD_GLOBAL              0 (factorial)
 14 LOAD_FAST                0 (n)
 16 LOAD_CONST               3 (1)
 18 BINARY_SUBTRACT
 20 CALL_FUNCTION            1
 22 BINARY_MULTIPLY
 24 RETURN_VALUE

Explanation

  • The FunctionDef node defines a function named factorial with one argument n.
  • The If node checks if n == 0. If true, returns 1, else executes the recursive call.
  • The bytecode instructions map fairly directly: load arguments, compare, branch based on result, etc.

Example

Change the code so that it prints the result instead of returning it. Observe the differences in AST & bytecode.

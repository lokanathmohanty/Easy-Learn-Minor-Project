JavaScript Built-in Functions Reference

Here, you can find all the JavaScript's built-in methods on the following classes:

  • Number Methods
  • Boolean Methods
  • String Methods
  • String HTML Wrappers
  • Array Methods
  • Date Methods
  • Date Static Methods
  • Math Methods
  • RegExp Methods

Number Methods

  • constructor() − Returns the function that created this object's instance.
  • toExponential() − Displays number in exponential notation.
  • toFixed() − Formats number with digits after decimal.
  • toLocaleString() − Returns locale-specific string representation.
  • toPrecision() − Defines number of total digits to display.
  • toString() − Returns number as a string.
  • valueOf() − Returns primitive number value.

Boolean Methods

  • toSource() − Returns string source of Boolean object.
  • toString() − Returns "true" or "false".
  • valueOf() − Returns primitive Boolean value.

String Methods

  • charAt() − Returns character at given index.
  • charCodeAt() − Returns Unicode value of character.
  • concat() − Joins two strings.
  • indexOf() − Finds first index of substring.
  • lastIndexOf() − Finds last index of substring.
  • localeCompare() − Compares strings by locale order.
  • length() − Returns string length.
  • match() − Matches string with regex.
  • replace() − Replaces substring with new value.
  • search() − Searches with regex.
  • slice() − Extracts string section.
  • split() − Splits string into array.
  • substr() − Extracts string from start index and length.
  • substring() − Extracts string between two indexes.
  • toLocaleLowerCase() − Converts to lowercase using locale.
  • toLocaleUpperCase() − Converts to uppercase using locale.
  • toLowerCase() − Converts to lowercase.
  • toUpperCase() − Converts to uppercase.
  • toString() − Returns string object as string.
  • valueOf() − Returns primitive string value.

String HTML Wrappers

  • anchor() − Creates HTML anchor.
  • big() − Displays text in big font.
  • blink() − Creates blinking text.
  • bold() − Displays text as bold.
  • fixed() − Displays text in fixed-pitch font.
  • fontcolor() − Displays text in given color.
  • fontsize() − Displays text in given font size.
  • italics() − Displays text in italics.
  • link() − Creates hyperlink.
  • small() − Displays text in small font.
  • strike() − Displays struck-out text.
  • sub() − Displays text as subscript.
  • sup() − Displays text as superscript.

Array Methods

  • concat() − Joins arrays.
  • every() − Checks if all elements pass test.
  • filter() − Filters elements based on test.
  • forEach() − Executes function on each element.
  • indexOf() − Returns index of element.
  • join() − Joins elements into string.
  • lastIndexOf() − Returns last index of element.
  • map() − Maps array values to new array.
  • pop() − Removes last element.
  • push() − Adds elements to end.
  • reduce() − Reduces array to single value.
  • reduceRight() − Reduces array from right.
  • reverse() − Reverses array.
  • shift() − Removes first element.
  • slice() − Extracts portion of array.
  • some() − Checks if at least one element passes test.
  • sort() − Sorts array.
  • splice() − Adds/removes elements.
  • toString() − Returns array as string.
  • unshift() − Adds elements to beginning.

Date Methods

Includes methods for getting/setting date and time values.

  • getDate() − Returns day of month.
  • getDay() − Returns day of week.
  • getFullYear() − Returns year.
  • getHours() − Returns hours.
  • getMinutes() − Returns minutes.
  • getSeconds() − Returns seconds.
  • setDate() − Sets day of month.
  • setFullYear() − Sets year.
  • setHours() − Sets hours.
  • toDateString() − Returns date as string.
  • toLocaleString() − Returns locale string.
  • toUTCString() − Returns UTC string.

Date Static Methods

  • Date.parse() − Parses date string to milliseconds.
  • Date.UTC() − Returns milliseconds for UTC date.

Math Methods

  • abs() − Absolute value.
  • ceil() − Rounds up.
  • floor() − Rounds down.
  • max() − Largest number.
  • min() − Smallest number.
  • pow() − Power calculation.
  • random() − Random number (0–1).
  • round() − Rounds to nearest integer.
  • sqrt() − Square root.

RegExp Methods

  • exec() − Executes regex on string.
  • test() − Tests regex match.
  • toSource() − Returns source representation.
  • toString() − Returns regex as string.

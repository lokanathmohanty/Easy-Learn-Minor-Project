ReactJS - Table

React provides table components through third-party UI libraries. One of the most popular is React Bootstrap, which ports almost all Bootstrap UI components into React, including tables.

Table Component

The Table component from react-bootstrap allows developers to create simple tables styled with Bootstrap. It supports table tags such as thead, tbody, and tfoot.

Props supported by the Table component include:

  • bordered − Adds border to all sides of the table and cells.
  • borderless − Removes borders from all sides.
  • hover − Enables hover state for rows.
  • responsive − Makes the table scrollable on smaller devices (options: sm, md, lg, xl).
  • size − Enables compact rendering (sm, md, etc.).
  • striped − Adds zebra striping to rows or columns.
  • variant − Enables dark mode when set to dark.
  • bsPrefix − Custom prefix for CSS classes.

Applying Table Component

Steps to use the Table component in a React app:

  1. Create a new React app: create-react-app myapp
  2. Install Bootstrap and React Bootstrap: npm install --save bootstrap react-bootstrap
  3. Create SimpleTable.js under src/Components.

SimpleTable.js

import { Table } from 'react-bootstrap';

function SimpleTable() {
   return (
      <Table striped bordered hover>
         <thead>
            <tr>
               <th>#</th>
               <th>Name</th>
               <th>Age</th>
               <th>Email</th>
            </tr>
         </thead>
         <tbody>
            <tr>
               <td>1</td>
               <td>John</td>
               <td>25</td>
               <td>john.example@tutorialspoint.com</td>
            </tr>
            <tr>
               <td>2</td>
               <td>Peter</td>
               <td>15</td>
               <td>peter.example@tutorialspoint.com</td>
            </tr>
            <tr>
               <td>3</td>
               <td>Olivia</td>
               <td>23</td>
               <td>olivia.example@tutorialspoint.com</td>
            </tr>
         </tbody>
      </Table>
   );
}
export default SimpleTable;

Here we used:

  • striped for zebra striping.
  • bordered for borders.
  • hover for row hover state.

App.js

import './App.css'
import "bootstrap/dist/css/bootstrap.min.css";
import SimpleTable from './Components/SimpleTable'

function App() {
   return (
      <div className="container">
         <SimpleTable />
      </div>
   );
}
export default App;

Add Dark Variant and Column Striping

You can extend the table with dark mode and column striping:

<Table bordered hover striped="columns" variant="dark">
   ...
</Table>
  • striped="columns" adds zebra striping to columns.
  • variant="dark" enables dark mode for the table.

Summary

React Bootstrap’s Table component provides all the necessary options to design intuitive and responsive tables with minimal effort.

Python Method Overriding

Method overriding in Python allows a subclass to provide a specific implementation for a method that is already defined in its superclass. The method to be called is determined at runtime based on the actual object invoking it.

Overriding is useful when a child class wants to modify or extend the behavior of inherited methods.

Basic Method Overriding Example

class Parent:
    def myMethod(self):
        print('Calling parent method')

class Child(Parent):
    def myMethod(self):
        print('Calling child method')

c = Child()
c.myMethod()  # Output: Calling child method

Here, the child class overrides the myMethod of the parent class. When called on a child instance, the child's method is executed.

Overriding With Constructor and Method

class Employee:
    def __init__(self, nm, sal):
        self.name = nm
        self.salary = sal

    def getName(self):
        return self.name

    def getSalary(self):
        return self.salary

class SalesOfficer(Employee):
    def __init__(self, nm, sal, inc):
        super().__init__(nm, sal)  # Call parent constructor
        self.incnt = inc

    def getSalary(self):
        return self.salary + self.incnt

e1 = Employee("Rajesh", 9000)
print(f"Total salary for {e1.getName()} is Rs {e1.getSalary()}")

s1 = SalesOfficer("Kiran", 10000, 1000)
print(f"Total salary for {s1.getName()} is Rs {s1.getSalary()}")

Output:
Total salary for Rajesh is Rs 9000
Total salary for Kiran is Rs 11000

Common Overridable Methods in Python

Python's base class object has special methods that can be overridden to customize class behavior:

  • __init__(self[, args...]): Constructor method.
  • __del__(self): Destructor method called when an object is deleted.
  • __repr__(self): Method to return an evaluatable string representation of the object.
  • __str__(self): Method to return a readable string representation of the object.

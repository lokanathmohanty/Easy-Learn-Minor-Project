Infinite Loop in C

An infinite loop in C is a loop that never terminates because its condition always evaluates to true. It executes a block of code repeatedly without end.

Creating Infinite Loops

Infinite loops can be created using any loop construct (while, for, or do-while) with a condition that is always true, such as 1.

Examples

Infinite While Loop

#include <stdio.h>

int main(){
   int i = 0;
   while(i <= 10){
      // No increment leads to infinite loop
      printf("i: %d\n", i);
   }
   return 0;
}

Infinite For Loop

#include <stdio.h>

int main(){
   for( ; ; ){
      printf("Hello World\n");
   }
   return 0;
}

Infinite Do-While Loop

#include <stdio.h>

int main(){
   do {
      printf("Hello World\n");
   } while(1);
   return 0;
}

Breaking out of Infinite Loops

The break statement can be used inside a loop to exit when a specific condition is met.

#include <stdio.h>

int main(){
   for(int i = 1; ; i++){
      printf("%d\n", i);
      if(i == 5) break;
   }
   return 0;
}

This loop prints numbers 1 to 5, then exits.

Stopping Infinite Loops

Infinite loops do not stop automatically and must be manually interrupted, often using Ctrl + C.

Summary

  • Infinite loops run indefinitely due to conditions that never become false.
  • They can be intentional or accidental.
  • Use break to control loop termination.
  • Interrupt execution to stop unwanted infinite loops.
